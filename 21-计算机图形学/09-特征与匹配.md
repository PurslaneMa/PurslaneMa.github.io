# $\rm Chapter \, 9$ 特征与匹配：角点、描述子与 RANSAC

上一章把图像变成了函数，并造出了卷积这套局部运算。现在用它解决一个具体的任务：给你同一场景的两张照片（手机全景拼接、无人机定位、视频目标跟踪都归结为它），怎么知道「这张图里的这个点」对应「那张图里的哪个点」？逐像素比较行不通：光照变了、视角转了、目标缩放了，同一物理点的像素值就变了。本章的路线是：先挑出少数「稳定可重认」的位置（角点），给每个位置配一个对上述变化不敏感的编码（描述子），再靠最近邻配对，最后用 RANSAC 把配错的那部分剔除。流水线的最后一步，即单应变换，把整章串成完整的图像拼接。

> **开始前自检**：本章假设你已经会：
>
> 1. □ 卷积与图像梯度的计算（本册 §8.2 与 §8.4；本章的角点检测和描述子都建在梯度上）；
> 2. □ 特征值 $2\times2$ 实对称矩阵的定性含义：两个特征值衡量两个互相垂直方向上的「响应强度」（竞赛线性代数基础；§9.2 当场重述判据）；
> 3. □ 最小二乘拟合直线的基本思想：让残差平方和最小（本站概率论分册第 5 章估计的思路；§9.4 展示它被坏数据带偏的过程）；
> 4. □ 齐次坐标与 $3\times3$ 矩阵表示平面射影变换（本册第 3 章渲染侧的投影矩阵；§9.5 只用其形式，§10.2 再展开）。

## $\rm \S \, 9.1$ 问题：两张图怎么对上

图像匹配要找的是「同一物理点」在两幅图中的位置对应，用途至少有四类：全景拼接、从运动恢复结构（§10.6）、目标跟踪、增强现实定位。为什么不能直接逐像素比？做一个思想实验：把相机绕光轴转 $10^{\circ}$，场景没变，但每个像素的值换了位置；光源动一下，所有值整体平移。像素值是「内容 + 光照 + 视角」的混合物，而匹配需要的是与后两者无关的「内容锚点」。经验与实验都指向同一种锚点：角点。在图像里它们是小而明亮、可重认性极强的位置：窗口移动一点，窗口内的内容就大不一样。这一章的任务链是：找出角点（§9.2）→ 描述它们（§9.3）→ 配对并剔除错配（§9.4）→ 用对应点恢复几何关系（§9.5）。

## $\rm \S \, 9.2$ 角点：窗口移动下的自相似性

取一个以点 $p$ 为中心的小窗口，把它朝某个方向挪一小步，比较移动前后窗口内内容的差异。三种地形给出三种命运：

1. **平坦区**（天空、白墙）：往哪挪都差不多，移不动视线，这个点无法定位；
2. **边**（门框、桌沿）：沿边挪差不多，垂直于边挪剧变，只有一个方向能定位；
3. **角**（桌角、窗角）：往哪挪都剧变，两个方向都能定位，是唯一「钉得住」的位置。

Harris 角点检测把这三种情形写成一个数。对窗口内每个像素取梯度 $\nabla I=\left(\frac{\partial I}{\partial x},\frac{\partial I}{\partial y}\right)^{\mathsf T}$（用 §8.4 的差分近似），累加成**结构张量（structure tensor）**$M=\sum_{\text{窗口}}\nabla I\,\nabla I^{\mathsf T}$。它的两个特征值 ${\lambda_1,\lambda_2}$ 直接回答「窗口往哪个方向挪会变」：特征值大表示该方向上的亮度变化能量大。判据完全定性：

| ${\lambda_1,\lambda_2}$ | 地形 | 定位能力 |
| --- | --- | --- |
| 都小 | 平坦区 | 不可定位 |
| 一大一小 | 边 | 只沿一个方向可定位 |
| 都大 | 角 | 两个方向都可定位 |

用一个 $7\times7$ 合成图案验证：全零、左半为 $1$（竖直边）、左上 $4\times4$ 为 $1$（角），分别算 $M$ 的特征值：

```python
import numpy as np
def harris(img):
    gy, gx = np.gradient(img)
    M = np.zeros((2,2))
    for i in range(7):
        for j in range(7):
            M += np.outer([gx[i,j],gy[i,j]], [gx[i,j],gy[i,j]])
    return np.linalg.eigvalsh(M)
print(harris(np.zeros((7,7))))          # [0. 0.]      平坦：都小
e = np.zeros((7,7)); e[:,:3] = 1
print(harris(e))                        # [0.  3.5]    边：一大一小
c = np.zeros((7,7)); c[:4,:4] = 1
print(harris(c))                        # [1.75 2.25]  角：都大
```

角点情形两个特征值都不为零且同量级：横向与纵向的边各贡献一个方向的变化，这正是「角」的代数写照。完整的 Harris 算法还带一个把三个情形合并成分数的响应函数与抑制邻近重复检测的非极大值步骤（§8.4 见过同一手法），概念上你已经有了全部零件。

## $\rm \S \, 9.3$ 描述子：把邻域变成向量

角点只解决「在哪」，匹配还需要「这是什么」。给每个角点的邻域算一个向量，要求同一物理点在不同光照、视角下向量相近，这个向量叫**描述子（descriptor）**。概念上理解 SIFT（Scale-Invariant Feature Transform）只需要三件事：

1. **尺度空间找极值**：在高斯金字塔（§8.5）的每一层找角点，同一物理点总会在某个尺度上被找到，对缩放稳定；
2. **主方向归一化**：统计邻域梯度方向的主峰，把邻域坐标转到主方向上再计算，对旋转稳定；
3. **邻域梯度直方图**：把归一化后的邻域切成小格，每格统计梯度方向的直方图，串成一个百余维的向量，对小扰动鲁棒。

至于为什么偏偏是直方图而不是原始像素：直方图对亮度平移、微小的形变都钝感，这正是描述子要的性质。至于完整的数学，工程上用现成实现即可，本章停留在「为什么这样设计」的层面。匹配由此变成最近邻问题：左图描述子在右图描述子里找最近邻；再加一道**比值检验（ratio test）**：最近距离与次近距离之比小于约 $0.8$ 才接受，因为真匹配只有一个显著近邻，伪匹配往往一堆都差不多近。

## $\rm \S \, 9.4$ 误匹配与 RANSAC

再严格的描述子也挡不住所有错配：重复纹理（两扇一样的窗）天然多对一。于是最后的防线是几何一致性：正确的对应点集应当共同满足一个简单模型（比如共线），错误的配对不满足。**最小二乘**对这类数据有天生的弱点：它把每个点的残差平方都算进目标，少数坏点能拖偏整体。

一个 $20$ 个点的最小例（固定种子，可复现）：$14$ 个内点（inlier）落在直线 $y=2x+1$ 附近（噪声 $0.2$），$6$ 个外点（outlier）在平面内随机撒。对全部 $20$ 个点做最小二乘，得斜率 $1.313$、截距 $4.808$，离真值 $2$ 与 $1$ 相去甚远，$30\%$ 的坏数据把直线整个拽歪了；只用 $14$ 个内点拟合，斜率 $2.006$、截距 $0.856$。**RANSAC（random sample consensus，随机抽样一致）**的思路是不问「哪些点好」而问「哪个模型支持者多」：

1. 随机抽最小点集（直线 $s=2$ 个点），由它们确定一个候选模型；
2. 数全体点中落在模型容差带内的支持者（内点）个数；
3. 重复足够多次，取支持者最多的模型，再用这些内点重新拟合一次。

```python
import numpy as np
rs = np.random.RandomState(42)
xi = rs.uniform(0,10,14); yi = 2*xi+1+rs.normal(0,0.2,14)
xo = rs.uniform(0,10,6);  yo = rs.uniform(0,20,6)
X, Y = np.r_[xi,xo], np.r_[yi,yo]
print(np.polyfit(X,Y,1))    # [1.313 4.808]  全体拟合：被外点带偏
best = None
for _ in range(500):
    i,j = rs.choice(20,2,replace=False)
    a = (Y[j]-Y[i])/(X[j]-X[i]); b = Y[i]-a*X[i]
    inl = abs(a*X+b-Y) < 0.5
    if best is None or inl.sum() > best[0]: best = (inl.sum(), inl.copy())
print(np.polyfit(X[best[1]],Y[best[1]],1))  # [2.006 0.856]  RANSAC：回到真值
```

「重复足够多次」到底要多少次？设单个随机样本全是内点的概率为 $w$，模型需要 $s$ 个点，则一次采样成功的概率是 $w^s$，要使至少一次成功的置信度达到 $p$，迭代次数为

$$
N=\frac{\log(1-p)}{\log(1-w^s)}
$$

代入 $w=0.5$、$p=0.99$、$s=4$（单应矩阵的情形，§9.5）：$N=\frac{\log 0.01}{\log 0.9375}\approx71.4$，向上取整 $72$ 轮，外点占一半也不怕。本例 $w=\frac{14}{20}=0.7$、$s=2$，只需约 $6.8$ 即 $7$ 轮。注意 $N$ 对 $w$ 极其敏感：$w$ 从 $0.6$ 掉到 $0.5$（$s=4$ 时），轮数就从 $34$ 涨到 $72$；外点占九成的匹配任务，RANSAC 会慢到不可用：描述子质量决定几何验证的代价。

## $\rm \S \, 9.5$ 单应：把匹配换成一张变换表

几何验证不只用来剔错，还能给出正解本身。当两幅图拍到的是同一个平面（比如斜拍一块招牌），两幅图之间的对应由一个 $3\times3$ 矩阵，即**单应（homography）**，完整描述：$\tilde{\mathbf u}'\sim H\tilde{\mathbf u}$，其中 $\sim$ 表示齐次坐标下相差一个非零比例因子视为同一点。$H$ 有 $8$ 个自由度（差一个整体缩放），每对对应点提供 $2$ 个方程，故 $4$ 对点恰好定出它。这正是 RANSAC 里 $s=4$ 的出处。

至此整条流水线可以走通了，图像拼接的五步：

1. 特征检测：两图各找角点（§9.2）；
2. 描述与匹配：描述子最近邻加比值检验（§9.3）；
3. RANSAC 估单应：随机抽 $4$ 对，数一致者，剔除外点（§9.4）；
4. 用单应把第二幅图 Warp 到第一幅的坐标系；
5. 融合重叠区（加权过渡即可）。

注意流水线里两种角色互为表里：描述子负责「候选对应」，几何模型负责「裁决对应」。这个分工在下一章会原样重演，只是模型从单应换成更一般的对极几何。

## $\rm \S \, 9.8$ 本章自测答案

> 先闭卷作答上面两节，再核对。

### $\rm \S \, 9.8.1$ 关键概念回顾答案

1. 像素值混合了内容、光照与视角，逐像素比在光照或视角一变时就崩。能当锚点的位置必须对窗口的小位移敏感（挪一点内容就大变），这样才能在另一幅图里被唯一地重新认出。（§9.1、§9.2）
2. 平坦区怎么挪都差不多，边沿边挪不变而垂直挪剧变，角往哪挪都剧变。特征值都小＝平坦，一大一小＝边，都大＝角；$7\times7$ 合成实验给出的特征值分别为 ${[0,0]}$、${[0,3.5]}$、${[1.75,2.25]}$。（§9.2）
3. 目标：同一物理点在不同光照视角下向量相近。尺度空间找极值换缩放稳定，主方向归一化换旋转稳定，邻域梯度直方图换小扰动鲁棒。（§9.3）
4. RANSAC 优化「支持者数量」而非「平方残差和」，外点要么支持错误模型（难成多数）要么被抛弃，最小二乘则把外点的平方残差直接计入目标。$N=\frac{\log(1-p)}{\log(1-w^s)}$：$w$ 是单样本全内点率，$p$ 是置信度，$s$ 是模型最小点数。（§9.4）
5. $8$ 个自由度。每对点给 $2$ 个方程，$4$ 对恰好 $8$ 个方程；它是流水线第 $3$ 步被 RANSAC 估出的几何模型，第 $4$ 步用它 Warp 图像。（§9.5）

### $\rm \S \, 9.8.2$ 应用与辨析答案

1. 相同瓷砖的邻域长得一样，描述子彼此高度相似，最近邻与次近邻距离接近，比值检验失灵，配对呈多对多错乱。几何上正确内点率 $w$ 被拉低，RANSAC 轮数按公式暴涨；$w$ 过低时理论上就要换更强的几何先验或更独特的描述子。（§9.3、§9.4）
2. RANSAC 的目标函数是内点计数（离散、对坏数据鲁棒），它给出的是「支持者最多的粗模型」；不是最小化残差意义下的最优。最终的精确模型来自最后一步：只用内点重新做一次最小二乘（本例斜率从抽样的 $2.002$ 精化到 $2.006$）。（§9.4）
3. 放宽阈值让更多伪匹配通过描述子级检验，$w$ 下降；由公式，$w$ 变小使 $N$ 变大，RANSAC 轮数与计算量上升。总成本是「描述子匹配便宜」换「几何验证变贵」，两级流水线的代价会被推到几何那一端。（§9.4）
