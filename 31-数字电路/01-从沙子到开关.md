## $\rm \S \, 1.1$ 半导体：能被控制的导电

材料按导电能力分三档。铜这类导体里自由电子浓度极高，想拦都拦不住；二氧化硅这类绝缘体几乎没有自由电子。硅处在中间：纯硅每个原子与四个邻居共价成键，室温下绝大多数电子被锁在键里，自由载流子（carrier，能搬运电荷的粒子）浓度只有约 $10^{10}$ 个/cm³（300 K，公开物理手册口径），而硅原子本身有 $5 \times 10^{22}$ 个/cm³，数万亿个原子才摊上一个自由电子。所以纯硅接近绝缘体。

接近绝缘体不是缺点。导体的问题是「关不掉」，绝缘体的问题是「打不开」，工程师要的是第三种：平时关着，给个信号就开。硅的载流子浓度落在两者之间，而且可以被精确地改写，这正是半导体（semiconductor）被选中的原因。怎么改写？往里面掺原子。

历史上第一只晶体管（1947 年，贝尔实验室）用的是锗，同为四价元素，掺杂逻辑完全相同。硅最终胜出靠的是一样副产品：它的氧化物二氧化硅恰好是优秀的绝缘体，能直接在硅表面生长成致密薄层。下一节 MOSFET 里「隔在栅极与沟道之间」的那层氧化物，用的就是它。

**本节小结**：这一节回答「为什么是硅」——它导电能力居中且可以被掺杂精确改写，而氧化层是白送的绝缘屏障；下一节就讲「改写」的具体手段：掺杂与 PN 结。

## $\rm \S \, 1.2$ 掺杂与 PN 结

硅是四价的，每个原子用四个电子配对成键。往硅里掺一个五价的磷，它用四个电子与邻居成键，多出一个电子闲在外面，成了自由电子：这种以负电荷载流子为主的材料叫 N 型。掺三价的硼则相反，配对时缺一个电子，留下一个空位；这个空位叫空穴（hole），行为像一个可移动的正电荷，以空穴为主的材料叫 P 型。把空穴想成剧院里往前挪的空座位：动的是座位（电子填补空位），效果等价于空位反向移动。

控制力的来源是剂量。手算一个账：每 $10^6$ 个硅原子掺 1 个磷（百万分之一），载流子浓度就是 $5 \times 10^{22} \times 10^{-6} = 5 \times 10^{16}$ 个/cm³，是纯硅的 $5 \times 10^6$ 倍。换算到器件尺度（Python 实跑，纯除法）：一个 $1\,\mu\text{m}^3$ 的方块里有约 500 亿个硅原子、5 万个磷原子。百万分之一级别的「杂质」，把导电能力改写了六个数量级。掺杂（doping）不是污染，是设计。

> **账本**：纯硅载流子约 $10^{10}$/cm³；掺百万分之一磷后约 $5 \times 10^{16}$/cm³。六个数量级的操纵杆，就是「半导体可控」的全部含义；本册后续每一章的器件行为，都建立在这根杠杆上。

P 型区与 N 型区贴在一起，交界处就是 PN 结：电子与空穴在交界处相互扩散、留下一个内建电场区，电流只能从 P 流向 N，反向被挡住。一个单向阀门。二极管是它的名字，本章只需要记住「单向」这两个字。

> **验算**：剂量账的每一环都能重算：$5 \times 10^{22} \times 10^{-6} = 5 \times 10^{16}$ 个/cm³，再乘 $10^{-12}$（立方微米换成立方厘米）得每个 $1\,\mu\text{m}^3$ 方块 5 万个磷原子，两步都是乘除法。

**本节小结**：这一节给了两样东西：N 型与 P 型（多电子与缺电子的硅），和把它们贴在一起得到的单向阀门——PN 结。单向导电这一点，正是下一节 MOSFET 能「接通/断开」的物理底座。

## $\rm \S \, 1.3$ MOSFET：电压控制的开关

在 P 型与 N 型之上再叠一层结构，就得到本册的主角 MOSFET（metal-oxide-semiconductor field-effect transistor，金属-氧化物-半导体场效应晶体管）。它有三个端子：

1. 栅极（gate，G）：隔着一层二氧化硅绝缘体「贴」在沟道上方，不导电，只加电场；
2. 源极（source，S）与漏极（drain，D）：电流的两个端点。

栅极电压够高时，电场把电子吸引到沟道表面，源漏之间出现一条导电通道，开关接通；电压不够，通道消失，开关断开。靠电场而非电流控制，栅极几乎不耗功率，这是它能被集成上百亿只的根本原因。N 型沟道的这种管子叫 NMOS：栅极高电平导通。把掺杂反过来做，得到 PMOS：沟道靠空穴导电，栅极低电平导通。加上永远导通的导线，本册的开关三兄弟如下：

| 元件 | 导通条件 | 一句话行为 |
| --- | --- | --- |
| 导线 | 无条件 | 两点永远连通 |
| NMOS | 栅极 $=1$ | 见 1 就通 |
| PMOS | 栅极 $=0$ | 见 0 就通 |

> **器件视角**：NMOS 与 PMOS 不是同一只管子的两种接法，而是掺杂相反的两只管子。同样的几何尺寸下 PMOS 更弱，因为空穴迁移率只有电子的约二分之一到三分之一（公开物理手册口径），这个事实在第 2 章决定网络的接法。

开关接成网络就能实现逻辑。两只 NMOS 串联（一头接地），栅极各接输入 ${a, b}$：只有 $a = b = 1$ 时输出端才通到地；两只并联则 ${a, b}$ 有一个为 1 就通到地。Python 实跑核对（函数模拟开关网络，先手算：$a=b=1$ 时串联通、并联也通）：

```python
NMOS = lambda g: g == 1                    # 栅 1 导通
series  = lambda *cs: all(cs)              # 串联 = 逻辑与
parallel = lambda *cs: any(cs)             # 并联 = 逻辑或
```

| 输入 ${a, b}$ | 串联网络通到地 | 并联网络通到地 |
| --- | --- | --- |
| 0, 0 | 0 | 0 |
| 0, 1 | 0 | 1 |
| 1, 0 | 0 | 1 |
| 1, 1 | 1 | 1 |

串联就是与，并联就是或。再把 NMOS 与 PMOS 凑成一对：输出端经 PMOS 接电源、经 NMOS 接地（第 2 章的主角）。实跑验证三个网络的输出行为：反相器在 $a=0$ 时输出 1；NAND 网络四组输入全对；一个更大的网络（下拉为「$a$ 串 $b$ 再并上 $c$」）对全部 8 组输入输出 $\lnot((a \land b) \lor c)$，且任何输入下上拉、下拉绝不同时导通。开关网络就是逻辑，这句话在第 2 章展开成一门工艺。

两个本章用不上、第 2 章要还的债。其一，NMOS 传 0 干脆利落，传 1 却要打折扣：栅极电压必须比沟道高出阈值，用 NMOS 把 1 从一端送到另一端，到达的只有 $V_{DD} - V_{th}$。PMOS 恰好反过来，传 0 打折。这对不对称是「传输门」存在的原因。其二，真实的 MOSFET 还有第四个端子衬底（substrate），默认接固定电位，本册所有电路一律省略它。

**本节小结**：这一节把上一节的 PN 结叠成了三端开关 MOSFET，并收齐三件工具：见 1 就通的 NMOS、见 0 就通的 PMOS、以及「串联是与、并联是或」的接线规律——下一节先看这些开关是怎么被大规模「印」出来的，第 2 章再正式拿它们搭门。

## $\rm \S \, 1.4$ 制造一瞥：光刻与密度账

几十亿只晶体管不是焊上去的，是「印」上去的。光刻（lithography）的一句话版本：把晶体管版图做成掩模，让紫外光透过掩模在硅片上复制出图案，循环往复。一轮完整工序分四步：

1. 涂胶：硅片表面均匀覆盖一层光刻胶，见光后化学性质改变；
2. 曝光：紫外光（最尖端工艺用极紫外光 EUV）透过掩模打在光刻胶上，图案转印；
3. 显影与刻蚀：洗掉变质的光刻胶，等离子体把裸露出的材料层刻穿；
4. 掺杂与生长：对刻开的窗口注入杂质、生长绝缘层或金属层。

整个过程像套色版画：一层版图一张掩模，套印几十次，每次套印的对准误差以纳米计。

工艺节点名（如 3 nm）早已不是任何结构的真实尺寸，而是营销代号，密度才是硬指标。算一笔公开口径的账（Python 实跑，除法）：苹果 A17 Pro 集成约 190 亿只晶体管，die 面积约 $100\,\text{mm}^2$（两个数字均为公开发布口径，die 面积为拆解估算）：

$$
\text{密度} = \frac{1.9 \times 10^{10}}{100\,\text{mm}^2} = 1.9 \times 10^8 \text{ 只}/\text{mm}^2
$$

即每平方毫米 1.9 亿只，摊到每只晶体管约 $0.005\,\mu\text{m}^2$，等效边长 73 nm。一指甲盖大的芯片里，晶体管的数量是地球人口的两倍多。这批 die 掉在晶圆上命运如何，由良率决定：$100\,\text{mm}^2$ 恰是 $1\,\text{cm}^2$，代入计算机系统结构册 §10.1 的账（$D = 0.4$，$\alpha = 4$），良率 $(1 + 0.1)^{-4} \approx 0.683$，约七成。密度往上压、良率跟着跌，这条经济约束勒住了每一代工艺，也是第 2 章要讲的「为什么门电路要省晶体管」的远因。

**本节小结**：这一节看了一眼制造：光刻是套色版画式的循环套印，密度用「总数 ÷ 面积」一笔除法算清，而良率把这笔记账拉回经济现实。至此本章三样武器齐备——NMOS、PMOS、接线规律。

下一章拿这三样东西开工：见 1 就通的 NMOS、见 0 就通的 PMOS，和「串联是与、并联是或」的接线规律。

## $\rm \S \, 1.7$ 本章自测答案

> 先闭卷作答 §1.5 与 §1.6，再核对。

### $\rm \S \, 1.7.1$ 关键概念回顾答案

1. 硅的载流子浓度介于两者之间且可被掺杂精确改写。导体关不掉（无控制手段），绝缘体打不开（没有可动用的载流子）。（§1.1）
2. 从约 $10^{10}$ 到 $5 \times 10^{16}$/cm³，约六个数量级。掺杂是乘法级的杠杆：百万分之一的剂量改写整体导电性。（§1.2）
3. NMOS 栅 1 通，PMOS 栅 0 通。栅极隔着绝缘层靠电场控制，几乎不取电流，功耗与驱动成本极低，才集成得起上百亿只。（§1.3）
4. 串联实现与（$a=b=1$ 才通），并联实现或。PMOS 相反：栅 0 才通，串联网络要求 $a=b=0$，对应的是「或非」一侧的行为。（§1.3）
5. 节点名是营销代号不是尺寸。密度 = 晶体管总数 ÷ die 面积，如 190 亿 ÷ $100\,\text{mm}^2$ = 1.9 亿只/mm²。（§1.4）
6. 剂量账回答「可控性」：多少掺杂换来多少载流子；密度账回答「集成度」：单位面积塞得下多少开关。两者的输入输出都是可直接测量的物理量，所以除法就算得清。（§1.2、§1.4）

### $\rm \S \, 1.7.2$ 应用与辨析答案

1. 差不了一个量级：$10^{-6}$ 到 $2 \times 10^{-6}$ 都在 $10^{16}$/cm³ 档。宣传词里「电流翻倍」若真发生，靠的是结构或工艺细节，不是掺杂剂量本身。（§1.2）
2. 能。四价元素的掺杂逻辑相同：五价杂质给 N 型、三价给 P 型，改变的只是具体能级与迁移率。（§1.2）
3. $5 \times 10^{10} / 200 = 2.5 \times 10^8$ 只/mm²，是 A17 Pro（1.9 亿）的约 1.3 倍，宣传更密成立（口径均为公开数字）。（§1.4）
4. PMOS 栅 0 通：$a = b = 0$ 时串联网络导通，输出端通到电源。这正是「或非」结构的一半，第 2 章 §2.1 的 NOR 下拉是它的对偶。（§1.3）
5. 缺陷数随面积近似线性涨，好 die 比例跌得更快（$\S 10.1$ 公式里 $A$ 在分母的指数位置）。面积翻倍常常让良率从约 0.68 跌向 0.5 以下，多出的晶体管抵不过报废的 die。（§1.4）
