# $\rm Chapter \, 5$ Babai 与 Coppersmith

第 4 章交付了一台多项式时间的短向量发生器：任何整基进去，LLL 约化基出来。本章立刻让它干两件正事。第一件是近似解 CVP——Babai 最近平面算法（1986）：先归约、再逐层舍入，把「外来点靠哪个格点」做到 $2^{d/2}$ 倍以内（§5.1，本章主证一，误差界的推导写全）。第二件是 Coppersmith 的小根方法（1997）：低次多项式在模 $N$ 下的小根可以多项式时间找出来，机关是 Howgrave-Graham 引理——把多项式的幂次系数排成格，短向量恰好是「在根处取值很小」的多项式（§5.2，本章主证二，陈述级加构造性直觉）。两件事在结构上是一回事：**把一个看似无结构的问题（最近点、小根）翻译成格上的短向量问题，然后让 LLL 买单**。§5.3 用程序把两笔账对齐，§5.4 列出这套武器在 OI/CTF 实战中的出口。

## $\rm \S \, 5.1$ Babai 最近平面算法（本章主证一）

白话：第 2 章的 Babai 简单舍入是「按刻度读数、整体取整」——解 $Bz = t$ 得实系数，逐坐标四舍五入。它输在斜基：一个坐标的舍入误差会顺着斜方向把别的坐标带歪。最近平面算法的修正是**逐层掰直**：先在最靠外的一层选定正确的「超平面切片」，把残量投回去，再处理下一层——每一步的误差都被关在当层正交化向量的半格以内。

**算法（最近平面，Babai 1986）**：输入 LLL 约化基 $b_1, \ldots, b_d$ 与目标点 $t$。

1. 置 $w = t$。
2. 对 $i = d, d-1, \ldots, 1$：令 $c_i = \left\lfloor \dfrac{\langle w, b_i^*\rangle}{\|b_i^*\|^2} \right\rceil$（残量沿 $b_i^*$ 的坐标舍入到最近整数），然后 $w \leftarrow w - c_i\, b_i$。
3. 输出 $c = \sum_i c_i b_i \in L$。

读法：与简单舍入 $c = B\lfloor B^{-1}t \rceil$ 对照——简单舍入在**基坐标**上一次取整，最近平面在 **GSO 坐标**上从顶层往回逐层取整，每取一层就把残量沿该层的方向修正一次；顺序必须从 $d$ 往回走，因为舍入 $b_i$ 方向不影响已经处理过的更外层。第 2 章五局全负的斜基，先 Gauss 归约再舍入就五局全中——本章要证明的是：先 LLL 归约再用最近平面，误差有一个**可证明的、只依赖维数的**上限。

**引理（绝对误差界，任意基）**：最近平面的输出 $c$ 满足

$$
\|t - c\|^2 \le \frac{1}{4}\sum_{i=1}^{d} \|b_i^*\|^2 \;\le\; \frac{d}{4}\,\max_i \|b_i^*\|^2
$$

证：对维数 $d$ 归纳。$d = 1$ 时 $t - c = (\alpha - \lfloor\alpha\rceil)\,b_1^*$，其中 $\alpha = \langle t, b_1^*\rangle/\|b_1^*\|^2$，取近整数使 $|\alpha - \lfloor\alpha\rceil| \le \frac{1}{2}$，平方后即得。$d > 1$ 时：第 $d$ 层的舍入把 $t$ 沿 $b_d^*$ 的坐标 $\alpha$ 调到最近的整数 $c_d$，于是残量 $t - c_d b_d$ 分解成两段正交的部分——沿 $b_d^*$ 的尾巴 $(\alpha - c_d)b_d^*$（长度平方 $\le \frac{1}{4}\|b_d^*\|^2$），以及落在 $\operatorname{span}(b_1, \ldots, b_{d-1})$ 里的前段；前段恰是低一维的最近平面问题，由归纳假设其误差平方 $\le \frac{1}{4}\sum_{i \le d-1}\|b_i^*\|^2$。正交部分的平方可加，合并即得。$\blacksquare$

读法：误差被切成 $d$ 个互相垂直的小段，每段不超过当层正交化向量的一半——**斜基的失败模式（误差沿斜方向叠加）在这里被 GSO 的正交性物理隔断了**。第二个不等号是直接放缩：$d$ 项都压到最大项。

接下来把 LLL 请进来。由第 4 章的主链 $\|b_i^*\|^2 \ge \frac{1}{2}\|b_{i-1}^*\|^2$ 倒着读：从末根回望，每退一根至多胀 $\sqrt{2}$ 倍，即

$$
\|b_i^*\|^2 \le 2^{d-i}\,\|b_d^*\|^2 \quad\Longrightarrow\quad \sum_{i=1}^{d}\|b_i^*\|^2 \le (2^d - 1)\,\|b_d^*\|^2
$$

于是绝对界升级为 $\|t - c\| \le \frac{1}{2}\cdot 2^{d/2}\,\|b_d^*\| = 2^{d/2 - 1}\|b_d^*\|$。而真正的主定理是**相对**形式的：

**定理（Babai 1986；Regev 讲义 Lecture 3 的整理）**：$B$ 为 LLL 约化基，$t$ 任意，最近平面输出 $c$，则

$$
\|t - c\| \;\le\; 2^{d/2}\,\operatorname{dist}(t, L)
$$

证：对维数归纳。记 $\alpha = \frac{\langle t, b_d^*\rangle}{\|b_d^*\|^2}$，$c_d = \lfloor\alpha\rceil$，把最近的格点写成 $y = y' + z\,b_d$（$y' \in L' = L(b_1, \ldots, b_{d-1})$，$z \in \mathbb{Z}$，分解唯一），$r = \operatorname{dist}(t, L) = \|t - y\|$。

1. **情形一：$z = c_d$**（最近点恰好落在算法选中的那层平移切片里）。算法把问题交到 $t' = t - c_d b_d$ 与 ${L'}$ 上，而 ${y'}$ 正是 ${L'}$ 中离 ${t'}$ 最近的点（否则 $y'' + c_d b_d$ 会比 $y$ 更靠近 $t$，矛盾）。归纳假设给 $\|c' - t'\| \le 2^{(d-1)/2}\,\|y' - t'\|$；左边就是 $\|c - t\|$，右边 $\|y' - t'\| = \|y - t\| = r$（$c_d = z$ 把平移量消干净了）。故 $\|c - t\| \le 2^{(d-1)/2} r \le 2^{d/2} r$。
2. **情形二：$z \ne c_d$**。$c_d$ 是离 $\alpha$ 最近的整数，任何别的整数 $z$ 满足 $|\alpha - z| \ge \frac{1}{2}$；而 $t - y$ 沿 $b_d^*$ 的 GSO 坐标恰为 $\alpha - z$，正交性给出 $r^2 \ge (\alpha - z)^2 \|b_d^*\|^2 \ge \frac{1}{4}\|b_d^*\|^2$，即 $r \ge \frac{1}{2}\|b_d^*\|$。此情形直接搬绝对界的 LLL 版：$\|c - t\| \le 2^{d/2 - 1}\|b_d^*\| \le 2^{d/2} r$。$\blacksquare$

读法：两情形各管一头——目标点离格远时（情形一）递归的质量保证接棒，离格近时（情形二）绝对界接棒，接缝恰好在 $\frac{1}{2}\|b_d^*\|$ 处对齐。这就是「$2^{d/2}$ 倍近似 CVP」的完整出处。

关于常见的 $\det$ 口径，需要一句诚实的辨析。不少笔记把链条再接一刀，写成 $\|t - c\| \le 2^{d/2}(\det L)^{1/d}$——这一步**对一般格不成立**：$\det L$ 是全部 $\|b_i^*\|$ 的几何平均，而末根可以是平均值的任意多倍。反例：扁格 $\langle(5,0),(2, 5 \times 10^6)\rangle$，它是 LLL 约化的（$\mu = 0.4$，$\|b_2^*\| = 5\times 10^6$ 满足 Lovász 条件绰绰有余），但 $\|b_2^*\| = 1000 \times (\det L)^{1/2}$——目标点 $(0, 2.5 \times 10^6)$ 的最近距离约 $2.5 \times 10^6$，远超 $2^{d/2}(\det L)^{1/d} = 10^4$。$\det$ 口径的口号版在「GSO 长度齐整」的格上以常数因子成立（格密码实际遇到的随机 $q$-ary 格正是这类，第 6 章），普适的承诺是上面的相对版。至于 $2^{d/2}$ 这个因子本身：它是陈述级可证的紧量级——存在目标点使最近平面差满 $2^{d/2}$ 因子的常数倍（Babai 1986 的分析基本紧），而多项式时间内近似 CVP 到 $2^{d^{1-\varepsilon}}$ 以内在难度上也是被排除的（NP-难，Dinur–Kind–Moni–Naor–Safra–Steinke 时代的结果链），所以「指数近似因子」不是算法偷懒，是问题本身的质地。

**本节小结**：最近平面把简单舍入的「整体取整」改成「逐层取整」，误差被 GSO 切成互不叠加的 $d$ 段：任意基给 $\frac{1}{2}\sqrt{d}\max_i\|b_i^*\|$，LLL 基给相对保证 $2^{d/2}\operatorname{dist}(t, L)$；$\det$ 口径只在 GSO 齐整的格上成立。

## $\rm \S \, 5.2$ Coppersmith 一瞥（本章主证二）

白话：给定模数 $N$ 与多项式 $f$，想知道 $f(x) \equiv 0 \pmod N$ 有没有「小」的根——比如根不超过 $N^{0.25}$。直接解同余方程没有结构可抓，但「小」本身就是结构：把 $f$ 的幂次、平移、模数 $N$ 的倍数一起铺成一张格，小根对应的系数向量就是短向量，LLL 把它拽出来。

**问题（模多项式小根）**：设 $f$ 是首一整系数多项式、次数 $d$，模数 $N$ 给定。求全部满足

$$
f(x_0) \equiv 0 \pmod{N}, \qquad |x_0| \le N^{1/d}
$$

的 $x_0$。Coppersmith 1997 证明这可以多项式时间完成（Howgrave-Graham 1997 给了沿用至今的简化表述）。

主角是引理（陈述级）：

**引理（Howgrave-Graham）**：设整系数多项式 $g(x) = \sum_i g_i x^i$ 满足

1. $g(x_0) \equiv 0 \pmod{N^m}$（模 $N^m$ 零点）；
2. $|g(x_0)| < N^m$（在 $|x_0| \le X$ 时可由系数范数控制：$|g(x_0)| \le \sum_i |g_i|\,X^i$）。

则 $g(x_0) = 0$ 在整数上严格成立。

读法：一条几乎免费的观察——绝对值小于一个正的模数、又模它为零，那只能是零本身。全部戏法在于**造出满足这两条的多项式**，而造法就是格：

1. 取一族「种子多项式」$N^{m-j}\, f(x)^j\, x^i$（$j = 0, \ldots, m$，$i = 0, \ldots, d-1$）。每个种子在 $x_0$ 处都模 $N^m$ 为零（$f(x_0)^j \equiv 0 \bmod N^j$，再乘 $N^{m-j}$ 补齐），整系数组合 $g$ 自动继承第 1 条。
2. 把每个种子按 $X^i$ 缩放后写成系数行向量，张成一张格。行向量的长度恰好量的是 $\sum_i |g_i|\,X^i$——**引理第 2 条里那个需要控制的量，就是格向量的长度**。
3. LLL 找短向量：若 $\|v\| < N^m/\sqrt{\text{维数}}$，则对应的 $g$ 满足引理，于是 $g(x_0) = 0$ 在整数上成立——解一个真正的多项式方程 $g(x) = 0$（实根、数值验证），候选根到手。
4. 取够大的 $m$，LLL 的界 $2^{(D-1)/4}\det^{1/D}$（第 4 章界 1）恰好压进 $N^m$ 以内当且仅当 $|x_0| \lesssim N^{1/d}$——常数 $N^{1/d}$ 就这么从两边的指数里被挤了出来。

这就是第 4 章「万能扳手」的标准用法：问题的可行性边界（根多大能找）被 LLL 的近似因子精确决定。两个招牌应用，都是 RSA（[密码学册第 6 章](../24-密码学/06-RSA与签名.md)）：

1. **已知高位比特的因子恢复**：设 $N = pq$、$p \approx N^{1/2}$，若攻到了 $p$ 的最高一半比特（侧信道、广播泄漏、随机数缺陷都可能是来源），写 $p = P + x_0$，$P$ 是已知部分，$x_0$ 是不到 $N^{1/4}$ 的未知量——$f(x) = P + x$ 是一次首一多项式，根 $x_0 \le N^{1/4} = N^{1/d}$ 恰好落在 Coppersmith 的射程内。RSA 的一半比特不是一半的安全。
2. **小指数与固定模板**：$e = 3$ 且消息带固定格式（如「头部长度字段＋内容」）时，把模板常数 $M$ 露在外面，$f(x) = (M + x)^e - c$ 次数 $e$，根（内容部分）小于 $N^{1/e}$ 即可恢复——这是 Håstad 广播攻击的内核。私指数一侧的对应结果：$d < N^{0.292}$ 时 RSA 可破（Boneh–Durfee 1999，把 Coppersmith 的格造得更省）。出处统一标 Coppersmith（1997）与 Howgrave-Graham（1997）。

**本节小结**：Howgrave-Graham 引理把「模零点＋绝对值小」焊成「整数零点」，格构造把第二个条件变成 LLL 的本职工作；已知高位比特（根 $N^{1/4}$）与小指数广播是两件现成的凶器。

## $\rm \S \, 5.3$ 数值锚：舍入误差表与小根演示

两笔账并列，都由 §5.5 程序实跑照抄。

第一笔：Babai 最近平面在二维格 $L = \langle(19,7),(5,2)\rangle$ 上（$\det = 3$，$\lambda_1 = \sqrt{2}$）。坏基 $(19,7),(5,2)$ 的 $\|b_1\| = 20.25$；LLL 一步归约成 $(-1,-1),(1,-2)$（长 $\sqrt{2}$ 与 $\sqrt{5}$）。五个目标点三方对账（暴力枚举为基准）：

第二笔：Coppersmith 的小根演示。取 $N = 91 = 7 \times 13$，

$$
f(x) = x^2 + x + 61
$$

验证 $f(5) = 25 + 5 + 61 = 91 \equiv 0 \pmod{91}$：$x_0 = 5$ 是根，且 $5 < N^{1/2} = 9.539$，落在 $d = 2$ 的射程 $N^{1/d}$ 内。枚举全部余类可得 $f$ 模 $91$ 的完整根集 $\{5, 33, 57, 85\}$——四个根全都小于 $N$ 本身，**但只有 $x_0 = 5$ 小于 $N^{1/2}$**。这个演示正好说破小根方法的价值边界：同余方程的根从来不缺，缺的是小范围内的唯一性；Coppersmith 的承诺「把 $|x_0| \le N^{1/d}$ 的根一网打尽」之所以锋利，正因为在这个窗口里根是孤立的、可验证的。

**本节小结**：舍入误差表三方对账——坏基失手 $8$ 倍量级、LLL 基全中、引理上界两边都罩住；小根演示在 $N = 91$ 上复现了「$N^{1/d}$ 窗口内唯一」的核心结构。

## $\rm \S \, 5.4$ 出口：LLL 在 OI/CTF 的实用场景

1. **RSA 已知高位比特**：拿到 $p$ 或 $q$ 的一半比特就够，$f(x) = P + x$、根 $N^{1/4}$，一次 LLL 到手（§5.2）。
2. **Håstad 广播与固定模板**：同一消息低指数发给多个接收者（或模板泄漏），次数 $e$ 的多项式小根直接还原明文。
3. **低密度子集和 / 背包**：把 0-1 向量的组合等式排成格，密度低于阈值时最短向量就是解（Coster–Joux–LaMacchia–Odlyzko–Schnorr 的联合改进线，源头是第 4 章 §4.4 的 Shamir 击破）。
4. **一般构格套路**：遇到「求一组满足若干线性同余、且各变量都很小」的题（CTF 的 misc/crypto 常客），标准动作是把每个约束写成格的一行、把「小」变成目标向量的短——翻译对了，剩下的交给 LLL；本册第 6 章的对偶攻击就是这套套路的密码学正装版。

## $\rm \S \, 5.7$ 本章自测答案

> 先闭卷作答上面两节，再核对。

### $\rm \S \, 5.7.1$ 关键概念回顾答案

1. 简单舍入解 $Bz = t$ 后在基坐标上一次取整；最近平面在 GSO 坐标上从外层向内逐层取整，每层顺手修正残量。顺序必须从 $d$ 往回：舍入 $c_i$ 影响的是 $b_i$ 及更内层方向的残量，先定外层才不会把内层刚修好的坐标搅乱。（§5.1）
2. 第 $d$ 层把残量沿 $b_d^*$ 的尾巴 $(\alpha - c_d)b_d^*$（平方 $\le \frac{1}{4}\|b_d^*\|^2$）与落在 $\operatorname{span}(b_1, \ldots, b_{d-1})$ 的前段分开；两者正交，平方相加；前段是低一维的同款问题，归纳假设接管；底座 $d = 1$ 一行即得。（§5.1）
3. 条件一（模 $N^m$ 零点）由种子的构造自动继承——每个种子都含 $N^{m-j}f^j$ 因子；条件二（绝对值小）由 LLL 短向量保证——种子按 $X^i$ 缩放后行向量的长度恰量着 $\sum |g_i|X^i$。$N^{1/d}$ 在「LLL 的界 $2^{(D-1)/4}\det^{1/D} < N^m$」与「根窗口 $X$」联立时出现：两边指数配平的位置就是 $X \approx N^{1/d}$。（§5.2）

### $\rm \S \, 5.7.2$ 应用与辨析答案

1. $t \in L$ 时各层的 GSO 坐标都是整数，舍入原样通过，输出 $c = t$，误差为零——最近平面在格点上是无损的。（§5.1）
2. 不成立。反例是扁格 $\langle(5,0),(2, 5\times 10^6)\rangle$：LLL 约化基的 $\|b_2^*\| = 5 \times 10^6 = 1000\,(\det L)^{1/2}$，目标点 $(0, 2.5\times 10^6)$ 的最近距离约 $2.5 \times 10^6$，远超 $2^{d/2}(\det L)^{1/d} = 10^4$。普适的是相对版 $\|t - c\| \le 2^{d/2}\operatorname{dist}(t, L)$；$\det$ 口径需要 GSO 长度齐整这个额外前提。（§5.1）
3. Coppersmith 的承诺是窗口内的完备性：$|x_0| \le N^{1/d}$ 的根全部到手。窗口外（${33, 57, 85}$ 都大于 $9.539$）本来就不在服务范围——而应用场景（恢复被截断的密钥、固定模板的明文）关心的恰恰只有小根；窗口内唯一性还附赠验证手段：找到的候选根代回 $f$ 检查即可确认真伪。（§5.3）

## $\rm \S \, 5.8$ 可当场复跑的程序段

下面这段纯 Python 把两笔账一次算全：最近平面的实现与三方对账（暴力、坏基、LLL 基），加上 $N = 91$ 的小根演示（LLL 实现沿用第 4 章 §4.8 的写法）：

```python
 # 最近平面：坏基 vs LLL 基，三方对账（纯 Python）
import itertools, math

def gso(B):
    d = len(B)
    bs, mu = [], [[0.0]*d for _ in range(d)]
    for i in range(d):
        v = list(B[i])
        for j in range(i):
            mu[i][j] = sum(v[k]*bs[j][k] for k in range(len(v))) / sum(x*x for x in bs[j])
            v = [v[k] - mu[i][j]*bs[j][k] for k in range(len(v))]
        bs.append(v)
    return bs, mu

def n2(v):
    return sum(x*x for x in v)

def lll(B, delta=0.75):
 # 第 4 章同款实现，此处只保留主循环
    B = [list(v) for v in B]; k = 1
    while k < len(B):
        bs, mu = gso(B)
        for j in range(k-1, -1, -1):
            q = round(mu[k][j])
            if q:
                B[k] = [B[k][t] - q*B[j][t] for t in range(len(B[k]))]
                bs, mu = gso(B)
        bs, mu = gso(B)
        if n2(bs[k]) >= (delta - mu[k][k-1]**2) * n2(bs[k-1]): k += 1
        else:
            B[k-1], B[k] = B[k], B[k-1]
            k = max(k-1, 1)
    return B

def nearest_plane(B, t):
 # 从最后一层往回：每层把残量沿 b_i* 的坐标舍入到半格内
    d = len(B); bs, mu = gso(B)
    w = list(t); c = [0]*d
    for i in range(d-1, -1, -1):
        c[i] = round(sum(w[k]*bs[i][k] for k in range(len(w))) / n2(bs[i]))
        w = [w[k] - c[i]*B[i][k] for k in range(len(w))]
    p = [sum(c[i]*B[i][k] for i in range(d)) for k in range(len(t))]
    return p, math.sqrt(sum((p[k]-t[k])**2 for k in range(len(t))))

def brute(B, t, R=10):
    d = len(B); n = len(B[0]); best = None
    for z in itertools.product(range(-R, R+1), repeat=d):
        p = [sum(z[i]*B[i][k] for i in range(d)) for k in range(n)]
        dd = math.sqrt(sum((p[k]-t[k])**2 for k in range(n)))
        if best is None or dd < best: best = dd
    return best

bad = [(19, 7), (5, 2)]
good = [tuple(v) for v in lll(bad)]
print("bad basis:", bad, " norms:", [round(n2(v)**0.5, 4) for v in bad])
print("LLL basis:", good, " norms:", [round(n2(v)**0.5, 4) for v in good])
for basis, name in [(bad, "bad"), (good, "LLL")]:
    bs, _ = gso(basis)
    print(f"{name}: error bound (1/2)*sqrt(sum||bi*||^2) =",
          round(0.5 * math.sqrt(sum(n2(v) for v in bs)), 4))
for t in [(10.4, 3.7), (52.6, 19.3), (7.5, 2.8), (101.2, 37.4), (31.9, 11.8)]:
    b0 = brute(bad, t)
    _, e1 = nearest_plane(bad, t)
    p2, e2 = nearest_plane(good, t)
    print(f"t={t}: brute {b0:.4f} | NP@bad {e1:.4f} (x{e1/b0:.2f}) | NP@LLL {e2:.4f} at {p2} (x{e2/b0:.2f})")

 # Coppersmith 小例：N=91，f(x)=x^2+x+61
N = 91
roots = [x for x in range(N) if (x*x + x + 61) % N == 0]
print("N=91, f=x^2+x+61: f(5) =", 25 + 5 + 61)
print("all roots mod 91:", roots, " | N^(1/2) =", round(N**0.5, 4),
      " -> roots below N^(1/2):", [x for x in roots if x < N**0.5])
```

## $\rm \S \, 5.9$ 带走清单

1. 最近平面：从 $i = d$ 往回逐层舍入 GSO 坐标；与简单舍入 $c = B\lfloor B^{-1}t \rceil$ 的差别在于误差被正交性隔断、不沿斜方向叠加。
2. 绝对界（任意基）：$\|t - c\|^2 \le \frac{1}{4}\sum_i \|b_i^*\|^2 \le \frac{d}{4}\max_i \|b_i^*\|^2$；LLL 基给 $\|t - c\| \le 2^{d/2-1}\|b_d^*\|$。
3. 主定理（本章主证一）：LLL 基上 $\|t - c\| \le 2^{d/2}\operatorname{dist}(t, L)$，归纳证明在 $\frac{1}{2}\|b_d^*\|$ 处接缝；$\det$ 口径 $2^{d/2}(\det L)^{1/d}$ 需要 GSO 齐整，扁格 $\langle(5,0),(2,5\times 10^6)\rangle$ 是现成反例；$2^{d/2}$ 因子陈述级紧。
4. 数值锚——格 $\langle(19,7),(5,2)\rangle$（$\det = 3$，$\lambda_1 = \sqrt{2}$）：坏基最近平面失手至 $8.49$ 倍，LLL 基五局全中；上界 $10.12$ 对 $1.275$ 双双兑现。
5. Coppersmith（本章主证二）：Howgrave-Graham 引理「模 $N^m$ 零点＋绝对值小 $\Rightarrow$ 整数零点」；格构造把第二个条件交给 LLL；射程 $|x_0| \le N^{1/d}$（Coppersmith 1997、Howgrave-Graham 1997）。
6. 应用锚：已知 $p$ 的一半高位 $\to N^{1/4}$ 的根恢复因子；$e = 3$ 固定模板广播（Håstad）；私指数 $d < N^{0.292}$（Boneh–Durfee 1999）。$N = 91$、$f = x^2 + x + 61$ 的根集 $\{5,33,57,85\}$ 里唯有 $5$ 落在 $N^{1/2}$ 窗口内。
