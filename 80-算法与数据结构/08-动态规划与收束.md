## $\rm \S \, 8.1$ 两块地基：重叠子问题与最优子结构

先看朴素递归怎么赔钱。取最坏情形的两个串：$A$ 为 $n$ 个互不相同的小写字母，$B$ 为 $n$ 个互不相同的大写字母，问最长公共子序列（Longest Common Subsequence，LCS；保持相对顺序的公共字符列）。每个格子 $A[i]$ 与 $B[j]$ 都对不上，递归每层分两叉，§8.3 会把调用数精确数出来：$n=13$ 时 20,801,199 次调用。可「子问题」总共只有多少个？每个子问题由一对前缀长度 ${(i,j)}$ 唯一编号，$i$ 取 ${0..n_1}$、$j$ 取 ${0..n_2}$，合计 ${(n_1+1)(n_2+1)}$ 个。$n_1=n_2=13$ 时是 196 个。196 个问题被问了两千万次，多出来的全是重复计工。定义（重叠子问题，overlapping subproblems）：递归展开后，同一编号的子问题被多次触达。定义（最优子结构，optimal substructure）：大问题的最优解可以写成某个小问题最优解加一步收尾，且小问题的解只取决于小问题自身的输入，不受「大问题是怎么走到它的」影响。

这两块地基各对应一种填表姿势。自顶向下：递归照写，每次先查表、没算过才算，叫记忆化（memoization）。自底向上：按依赖顺序把表从小格填到大格，叫迭代 DP。两者的总票数都是「状态数 × 每状态转移价」，DP 的合同价就是按这个乘积报的。所以写一个 DP 只需四件事：给子问题编号（状态）、写出状态之间的递推关系（转移）、钉住最小的几个状态（边界）、把拓扑排序出来（填表顺序）。转移是否合法靠最优子结构担保，表是否划算靠重叠子问题担保：没有重叠，存表白付内存；没有最优子结构，表里存的「次优答案」拼不出大问题的答案。第 6 章的 Dijkstra 已经预演过一次这个结构：dist 表就是按「出袋即封账」的顺序填的表。本章把它变成通用工法。

填表顺序为什么必须是拓扑序：转移是「$i$ 号状态读 $k<i$ 号状态」的有向依赖，一张「状态为点、依赖为边」的图若出现环，就找不到第一个能填的格子，表永远填不动。这个概念 §5.6 已在图上见过：拓扑排序给 DAG 排出「先有因后有果」的顺序，DP 的填表顺序就是状态依赖图的拓扑序，区别只在状态的编号方式（本章用前缀长度，§5.6 用图的顶点）。检查一张转移表能不能填，第一步就是把依赖图画出来看有没有环。

白话：重叠子问题是「同一道题被反复考」，最优子结构是「大题的标准答案由小题的标准答案拼成」；表是补课笔记，第一次算完记下来，之后谁来问都直接翻，而填笔记的顺序得跟着依赖图走。

> 本节小结：朴素递归的爆炸来自重复计工，而子问题总数往往只有多项式个；DP 合同价 = 状态数 × 转移价，四件套（状态/转移/边界/顺序）齐了就能签。

## $\rm \S \, 8.2$ 最长递增子序列：二维账压成一维

定义（最长递增子序列，Longest Increasing Subsequence，LIS）：给定数列 $a[0..n-1]$，找最长的下标递增且值严格递增的子序列。论文管理器用它给「排序改动」定价：把同一个作者在两版稿件作者列表里的名次对上号，从新版找一条名次单调上升的最长链，就知道多少作者原封未动，这里把它当独立例题走流程。第一版合同按「以每个位置结尾」编号状态：定义 ${\operatorname{dp}[i]}$ 为「结尾恰为 $a[i]$」的 LIS 长度。转移：$a[i]$ 要么单开一截，要么接在某个 $a[k]<a[i]$、$k<i$ 的结尾之后，

$$
\operatorname{dp}[i] = 1 + \max\bigl(\{\,\operatorname{dp}[k] : k<i,\ a[k]<a[i]\,\}\cup\{0\}\bigr),
$$

读法：在所有能接的尾巴里挑最长的，接上后加一。转移合法性分两步证。先证下界：任取满足条件的 $k$，把「以 $a[k]$ 结尾的最长递增子序列」整体接上 $a[i]$，得到以 $a[i]$ 结尾、长 ${\operatorname{dp}[k]+1}$ 的递增子序列，故 $\operatorname{dp}[i]\ge\operatorname{dp}[k]+1$ 对每个 $k$ 成立。再证上界：任取以 $a[i]$ 结尾的递增子序列 $Z$，若 $Z$ 长为 $L>1$，去掉末元后是某条以 $a[k]$ 结尾（$k<i$、$a[k]<a[i]$）的递增子序列，长 $L-1$，按 $\operatorname{dp}[k]$ 的定义 $\operatorname{dp}[k]\ge L-1$，故 $L\le\operatorname{dp}[k]+1\le$ 右端。两向夹死，等式成立。边界 $\operatorname{dp}[i]=1$ 对所有 $i$（单开一截），填表顺序 $i$ 从小到大。注意答案是 ${\max_i \operatorname{dp}[i]}$ 而不是 ${\operatorname{dp}[n-1]}$：状态编号是「以谁结尾」，最长的那条递增子序列可以在任何位置收尾，表填完还要扫一遍取最大，这一步票是 $n$ 张，不改量级。转移要扫一遍候选 $k$，总票 ${\Theta(n^2)}$：

```python
def lis_quadratic(a):
    n = len(a)
    dp = [1] * n                 # dp[i]: 以 a[i] 结尾的 LIS 长
    for i in range(n):
        for k in range(i):
            if a[k] < a[i] and dp[k] + 1 > dp[i]:
                dp[i] = dp[k] + 1   # 接在 a[k] 之后
    return max(dp) if n else 0
```

能不能更便宜？注意答案只用到 $\operatorname{dp}$ 的最大值，而所有 $\operatorname{dp}$ 值里藏着单调结构。定义（尾值表，tails）：处理完前缀 $a[0..i]$ 后，记 $\operatorname{tails}[t]$ 为「长为 $t+1$ 的递增子序列的结尾最小可达值」。引理（tails 严格递增）：$\operatorname{tails}[t]<\operatorname{tails}[t+1]$。证：设某条长 $t+2$ 的递增子序列以 $\operatorname{tails}[t+1]$ 结尾，去掉末元得长 $t+1$、结尾严格小于 $\operatorname{tails}[t+1]$ 的递增子序列；按最小性 $\operatorname{tails}[t]$ 不超过这个更小的结尾值，故 $\operatorname{tails}[t]<\operatorname{tails}[t+1]$。有了单调性就能二分：新来一个 $x$，若 $x>\operatorname{tails}$ 末元，则最长的递增子序列延长一格，$x$ 追加进表尾（更长的子序列此前不存在，因旧表已记到旧最长）；否则在表中找第一个 ${\operatorname{tails}[t]\ge x}$ 的位置改写为 $x$。改写不破坏不变量：长 $t+1$、尾小于 $x$ 的方案若存在，其尾小于旧 $\operatorname{tails}[t]$，违反旧最小性，故改写后 $\operatorname{tails}[t]$ 的最小可达值恰为 $x$；表长从不减，处理完全部元素后表长即 LIS 长。每元素一次二分，合同价 ${\Theta(n\log n)}$：

```python
def lis_nlogn(a):
    tails = []            # tails[t]: 长 t+1 的递增子序列最小可达尾值
    for x in a:
        lo, hi = 0, len(tails)
        while lo < hi:    # 二分找第一个 tails[t] >= x
            mid = (lo + hi) // 2
            if tails[mid] >= x:
                hi = mid
            else:
                lo = mid + 1
        if lo == len(tails):
            tails.append(x)   # x 比所有尾巴都大: 最长档延长一格
        else:
            tails[lo] = x     # 否则改写该档尾值, 表长不变
    return len(tails)
```

同一任务两张价目表，取决于查询次数是一次性还是逐元素流式：预知全列可用二分档，边到边答用平方档也够。两版各付各的票：平方版每元素扫全部候选尾巴，${\log}$ 版靠「尾巴越压越小越好接」的单调结构把扫描换成二分。要还原子序列本身，平方版在更新 ${\operatorname{dp}[i]}$ 时顺手记下「接的哪个 $k$」，取到最大值后沿指针倒走；${\log}$ 版的 tails 表只存尾值不存全序列，还原要另挂一列「该尾值对应的倒数第二元素」，账要另付一份内存。

白话：dp 数组记「每个位置当结尾能攒多长」，tails 表记「想要长 $t+1$ 的递增串，尾巴最小能压到多小」；尾巴越小，后面的人越容易接上，所以二分找的第一个放不下的位置值得一换。

> 本节小结：状态选「以 $i$ 结尾」让转移只有一种拼法，证明靠去尾归约；tails 数组把「逐个问尾巴」升级成「二分改尾巴」，票从 $n^2$ 降到 $n\log n$。

## $\rm \S \, 8.3$ 最长公共子序列：三版合同实测对账

回到 §8.1 的任务。定义（LCS）：$A[0..n_1-1]$ 与 $B[0..n_2-1]$ 的公共子序列中最长者，长记 $L(i,j)$，编号取两个前缀 ${A[0..i-1]}$ 与 ${B[0..j-1]}$。转移按「两串末字符是否相等」分支：

$$
L(i,j)=\begin{cases}L(i-1,j-1)+1, & A[i-1]=B[j-1],\\[2pt] \max\bigl(L(i-1,j),\ L(i,j-1)\bigr), & A[i-1]\ne B[j-1].\end{cases}
$$

匹配分支两向证。下界：${(i-1,j-1)}$ 的任一公共子序列整体后接 $A[i-1]$（它与 $B[j-1]$ 相等，仍是公共子序列），得 $L(i,j)\ge L(i-1,j-1)+1$。上界分两案：最优解 $Z$ 的末字符若为 $c=A[i-1]=B[j-1]$，去掉末元后是 ${(i-1,j-1)}$ 的公共子序列（末元占的两串位置都是各自最大的已用位置，其余更靠前），故 $L-1\le L(i-1,j-1)$；若 $Z$ 末字符不是 $c$，则 $Z$ 既不能用 $A[i-1]$（子序列按下标递增使用，用 $i-1$ 必为末元）也不能用 $B[j-1]$（同理，用了末字符就该是 $c$），$Z$ 是 ${(i-1,j-1)}$ 的公共子序列，$L\le L(i-1,j-1)$。两案都压回右端。失配分支：$Z$ 不能同时用两个末元（用了则两末元相等，矛盾），至少回避其一，回避 $A[i-1]$ 者落在 ${(i-1,j)}$、回避 $B[j-1]$ 者落在 ${(i,j-1)}$，故 $L\le\max(\cdot)$；反向下界把任一侧的解原样带过来即得。边界 ${L(i,0)=L(0,j)=0}$，顺序按 $i$ 外层 $j$ 内层，答案 ${L(n_1,n_2)}$，合同价 ${\Theta(n_1 n_2)}$ 格、每格常数票。记忆化与迭代两版骨架如下，计数器就是后面实测的票表：

```python
def lcs_memo(A, B):
    memo, calls = {}, 0
    def rec(i, j):
        nonlocal calls
        calls += 1                    # 调用票: 每次触达子问题记一张
        if i == 0 or j == 0:
            return 0
        if (i, j) in memo:
            return memo[(i, j)]       # 已算过: 直接翻表, 不再分叉
        if A[i-1] == B[j-1]:
            r = rec(i-1, j-1) + 1
        else:
            r = max(rec(i-1, j), rec(i, j-1))
        memo[(i, j)] = r
        return r
    return rec(len(A), len(B)), calls, len(memo)

def lcs_table(A, B):
    n1, n2 = len(A), len(B)
    dp = [[0] * (n2 + 1) for _ in range(n1 + 1)]
    for i in range(1, n1 + 1):
        for j in range(1, n2 + 1):
            if A[i-1] == B[j-1]:
                dp[i][j] = dp[i-1][j-1] + 1
            else:
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])
    return dp[n1][n2], n1 * n2
```

要公共子序列本身而不只是长度，从 ${\operatorname{dp}[n_1][n_2]}$ 逆着转移走：两字符相等则收下这个字符、跳到 ${(i-1,j-1)}$；否则比较上游两格谁的值撑起了当前格，往大的一格挪。每步一票，至多 ${n_1+n_2}$ 步走到边界，收集到的字符逆序即方案。这份回溯账说明「表里存的是答案，方案是答案的路径」，不必给每格另存一条完整序列。

朴素递归、记忆化、迭代 DP 三版在同一机器上对账。最坏实例取两串字母表不相交（每个格子都分叉），一般实例取随机 DNA 串：

| $n$ | 朴素调用数 | 朴素耗时 | 记忆化调用数 | 记忆化耗时 | DP 填格数 |
| --- | --- | --- | --- | --- | --- |
| 6 | 1,847 | 0.0002 s | 73 | 0.26 ms | 36 |
| 8 | 25,739 | 0.0032 s | 129 | 0.04 ms | 64 |
| 10 | 369,511 | 0.0328 s | 201 | 0.08 ms | 100 |
| 12 | 5,408,311 | 0.3569 s | 289 | 0.06 ms | 144 |
| 13 | 20,801,199 | 1.1998 s | 339 | 0.08 ms | 169 |

交叉点在 $n=8$：朴素 25,739 次调用付 3.2 ms，记忆化 129 次调用付 0.04 ms，此后差距按指数裂开，$n=13$ 处朴素耗时是 DP 的约三万倍，调用数与填格数之比 123,084 倍。朴素调用数能精确封账：不相交字母表下每格必然分叉，调用数满足 ${T(i,0)=T(0,j)=1}$ 与

$$
T(i,j)=1+T(i-1,j)+T(i,j-1),
$$

用帕斯卡恒等式 ${\binom{i+j-1}{i-1}+\binom{i+j-1}{i}=\binom{i+j}{i}}$ 归纳得 $T(i,j)=2\binom{i+j}{i}-1$；实测 $n=13$ 的 20,801,199 恰为 ${2\binom{26}{13}-1}$，理论线与实测线重合。字母表不相交是最坏构造，随机 DNA 没这么惨但量级照样压不住：$n=13$ 时朴素 223,837 次调用对记忆化 218 次、DP 169 格。指数合同与多项式合同的交叉在两位数的输入规模就发生了，这正是 §1.3 交叉点论证的又一次兑现。

白话：朴素递归是同一道题反复重考，记忆化是第一次考完记答案，迭代 DP 是干脆按考号顺序把整张答题卡填满；三版的答案一样，账单差出四个数量级以上。

> 本节小结：LCS 的转移按末字符匹配与否二分，匹配分支靠「去尾归约」双向夹死；实测交叉点 $n=8$，最坏调用数精确等于 ${2\binom{2n}{n}-1}$，合同价差出指数倍。

## $\rm \S \, 8.4$ 编辑距离：给「改了多少字」定价

LCS 答「保留多少」，论文管理器的 diff 还要答「改动多少」：删、插、替换各记一次操作，把 $A$ 改成 $B$ 的最少操作次数叫编辑距离（edit distance），记 ${\operatorname{ed}(i,j)}$，编号同样是前缀对。转移看最优改写稿的末步对两串末字符做了什么，只有四种可能：

$$
\operatorname{ed}(i,j)=\begin{cases}\operatorname{ed}(i-1,j-1), & A[i-1]=B[j-1],\\[2pt] 1+\min\bigl(\operatorname{ed}(i-1,j-1),\ \operatorname{ed}(i-1,j),\ \operatorname{ed}(i,j-1)\bigr), & A[i-1]\ne B[j-1].\end{cases}
$$

匹配分支保留末字符零票，其余照 LCS 的去尾归约夹死。失配分支三种末步各有归属：替换把两个末字符对消，剩 ${(i-1,j-1)}$ 的子问题付 1 票；删除 $A[i-1]$ 剩 ${(i-1,j)}$ 付 1 票；删除 $B[j-1]$ 剩 ${(i,j-1)}$ 付 1 票。下界按枚举归：最优稿的末步必属三案之一，各案给出 $\operatorname{ed}(i,j)$ 至少是 $1$ 加对应子问题的答案。上界按拼接证：三案的子问题各自有最优改写稿，接上对应末步都是合法改写，故 $\operatorname{ed}(i,j)$ 不超过右端。边界 ${\operatorname{ed}(0,j)=j}$、${\operatorname{ed}(i,0)=i}$，合同价同样 ${\Theta(n_1 n_2)}$。

编辑距离与 LCS 是同一张表的两个读法。只允许删与插（替换票价记 $\infty$）时，两者锁死为

$$
\operatorname{ed}(A,B)=n_1+n_2-2\,L(i,j)\big|_{i=n_1,\,j=n_2}.
$$

证：改动稿保留的字符在两串中按同序出现，故保留集合是一个公共子序列，$Z$ 长 $k$ 的保留方案花 ${n_1+n_2-2k}$ 票（其余字符各付一票删或插）；保 $k$ 越大越省，取 $k=L$ 即得右端为下界，而按最长公共子序列保留确实可行，等号成立。于是「两串差多少」在纯增删的口径下就是「共同部分有多少」的补账，两张表一张就够。票价本身也是合同条款：替换算 1 票还是 2 票、删除与插入是否同价，改的只是转移里三个分支前的系数，状态、边界与填表顺序原样不动；把票价表换成任意非负函数，这份推导的每一步照抄。工程的 diff 工具（如 `git diff`）正是在这张表上换了票价与打平规则（倾向保留整段、倾向晚删早插），所以同一对文件的 diff 结果可能因工具配置不同而不唯一，合同价不变、条款可以谈。

白话：编辑距离是「改稿的最少动笔次数」，三个分支分别问末字符是替换掉、从 $A$ 删掉还是从 $B$ 删掉；纯增删口径下，动笔次数等于两边长度之和减去两倍的公共部分。

> 本节小结：编辑距离按最优改写稿的末步三分支归约，LCS 是它的「替换免费禁止」姊妹表；两表共用 ${\Theta(n_1 n_2)}$ 格，口径换算公式 $n_1+n_2-2L$ 两向可证。

## $\rm \S \, 8.5$ 0-1 背包：伪多项式合同与贪心的失败实测

最后一个例题换一维决策。定义（0-1 背包，0-1 knapsack）：$n$ 件物品各带重量 $w_i$ 与价值 $v_i$，容量 $W$，每件要么整件装入要么不装，求总重不超 $W$ 的最大总价值。状态按「考虑前 $i$ 件、剩余容量 $c$」编号：${\operatorname{dp}[i][c]}$ 为该子问题的最优总价值。转移看第 $i$ 件装不装：

$$
\operatorname{dp}[i][c]=\max\bigl(\operatorname{dp}[i-1][c],\ \operatorname{dp}[i-1][c-w_i]+v_i\ \ (\text{当}\ w_i\le c)\bigr).
$$

两案互斥完备：最优解要么不含第 $i$ 件（账就是 ${\operatorname{dp}[i-1][c]}$），要么含（先为它腾出 $w_i$ 容量，剩下的恰是更小的子问题）。边界 ${\operatorname{dp}[0][c]=0}$，答案 ${\operatorname{dp}[n][W]}$。工程上把二维表压成一维：只留容量那一行，每件物品**倒序**扫容量更新。倒序是正确性条款：更新 ${\operatorname{dp}[c]}$ 要读的 ${\operatorname{dp}[c-w_i]}$ 必须还是「未考虑第 $i$ 件」的旧值，倒序保证同轮内 $c-w_i$ 尚未被改写；正序扫则同一件物品可能被计两次，那解的是另一道题（完全背包）。这张表的格子数是 ${n(W+1)}$，对 $n$ 多项式，但 $W$ 是数值不是输入长度：$W$ 以二进制写出只占 $\log W$ 个字符，票数 ${nW}$ 对输入长度是指数级。这样的账有个专名，定义（伪多项式，pseudo-polynomial）：票数是某个数值参数的多项式、却是输入位数的指数。背包合同因此在小容量下便宜、大容量下天价，报价格时两个参数都要报。

贪心在这道题上有没有证书？比值法（单位重量价值 ${v_i/w_i}$ 高者先装）是最常用的贪心，本节用固定种子实测它的败绩。固定反例：$W=10$，物品甲 ${(5,49)}$、乙 ${(5,47)}$、丙 ${(7,70)}$。比值排序丙 10.0 最高，贪心先拿丙，剩余容量 3，甲乙都装不下，总价值 70；DP 最优是甲加乙，重恰 10、价值 96。贪/优 比 0.7292，亏 26。失败机理在转移的互斥完备性上：贪心的交换论证想「拿甲乙换丙」，可甲乙合占 10 格容量恰好顶满，丙占 7 格剩下 3 格是碎容量，0-1 的整件条款不许切割，交换论证在碎容量处断链。对照组是分数背包（物品可切）：比值贪心在那道题上可证最优，因为分数恰好补齐碎容量，交换证书买得到。同一张贪心价目表，条款换了就作废，与 §6.5 割性质「先拿证书再贪」的纪律一致。迭代 DP 的一维压缩版连同倒序条款如下：

```python
def knapsack(items, W):
    dp = [0] * (W + 1)            # dp[c]: 已处理物品中, 容量 c 的最优价值
    for w, v in items:
        for c in range(W, w - 1, -1):   # 倒序: 保证 dp[c-w] 还是旧行
            dp[c] = max(dp[c], dp[c-w] + v)
    return dp[W]
```

要还原选了哪些物品，一维表压掉了行号、回溯信息跟着丢了，得退回二维表存「本格是否取了第 $i$ 件」或反向重放转移判定；这是压缩省内存付的条款价。

实测第二组账：固定种子扫 2,000 个随机实例（$n=12$、${w_i\in[1,30]}$、${v_i\in[1,100]}$、$W=100$），比值贪心在 753 个实例上严格吃亏，占 37.6%；最差一例贪心 336 对最优 389，亏 13.6%。0-1 背包比值贪心的账有个理论下限：任何实例上贪心值不低于最优的一半，固定反例的 0.7292 与随机族最差的 0.864 都压在这条线上方，这条「保证不亏过半」的合同正是 §8.8 要交接的近似算法的语言。顺带一组结构对账：同一随机实例上，背包的记忆化递归触达 899 个状态，迭代 DP 平铺 ${12\times 101=1212}$ 格；记忆化只算可达格子，迭代版不漏格但免掉递归开销，两版各有便宜的条款。

白话：0-1 背包的表按「第几件物品 × 剩余容量」编号，每格问「这件装不装更划算」；倒序填表是防同件物品被装两次的锁；比值贪心遇到「大件占满、碎容量装不下整件」就断链，实测近四成随机实例会亏。

> 本节小结：背包转移两案互斥完备、一维压缩必须倒序；$W$ 是数值参数，$nW$ 是伪多项式票数；比值贪心无证书可买，固定反例 0.7292、随机族 37.6% 吃亏、最差亏 13.6%，但保底不亏过半。

## $\rm \S \, 8.6$ 贪心与 DP 的分界：证书在不在

四个例题走完，可以回头把 §6.5 埋下的问题答完：什么时候贪心够用，什么时候必须 DP。判据就一条：局部选择背后有没有证书。证书是「跳过的选择必亏」的证明，MST 的割性质、Dijkstra 的出袋封账、分数背包的交换论证都是；有证书，贪心按 ${\Theta(n\log n)}$ 上下签字，最优白送。证书的标准签法是交换论证，三步走：第一步，取一个贪心解 $G$ 与一个最优解 $O$；第二步，构造一串从 $O$ 到 $G$ 的逐步交换，每一步把 $O$ 里的一个选择换成 $G$ 的对应选择，并证明目标值不降（割性质在证这一步：最便宜的横割边换进去只会更省）；第三步，交换有限步收尾，$O$ 被改写成 $G$ 而目标值不减，故 $G$ 也是最优。三步里第二步是命门，它要用到任务的结构性质；0-1 背包的结构性质在碎容量处断裂，证书就签不出来。证书买不到时，贪心的局部最优拼不出全局最优，0-1 背包的碎容量就是断链点；此时 DP 是兜底合同，用「状态数 × 转移价」的票数把全部子问题的答案买齐，最优解从表里读出。决策顺序因此是固定的：先找证书，找不到再填表，找不到证书还硬贪，就等于拿固定反例赌运气，§8.5 实测的 37.6% 亏率就是赌输的频率（在该随机分布下）。两张表还有一处在结构上同源：Dijkstra 的 dist 表本身就是按依赖序填的 DP 表，它比本章的表多一条「出袋即封」的顺序证书，比贪心多一张完整的表，正好站在两族工具的交界上。

白话：贪心是「只看眼前这一步还有证书保你不亏」，DP 是「没证书就把所有小题的标准答案都买齐」；先找证书，找不到才掏 DP 的票钱。

> 本节小结：贪心与 DP 的分界是证书的有无；贪心价低但需证明，DP 票多但通用，Dijkstra 站在两族交界。

## $\rm \S \, 8.7$ 收束：八个工具的价格表

本册八章，每章交付一件 COS 226 主线里的工具，全册心智模型「复杂度是合同」到此可以兑成一张总账。八件工具各自的合同价、背面条款与出处章号如下：

## $\rm \S \, 8.8$ 全站接口：这套语言在别的册叫什么

合同语言出了本册照样流通，四条交接线各指一处。其一，《随机算法》§1.1 把「掷骰子换性能」分成 Monte Carlo 与 Las Vegas 两档，§2.4 随机化快排的期望账是这两档的第一次出场，该册 §1.2 的期望线性性则是 §4.2 随机 BST ${2\ln n}$ 账的正式地基；本册的对抗输入条款到了那边改叫「最坏情形与期望情形的分离」。其二，《近似算法》§1.1 定义近似比为「买不到最优时按比例赔付的合同」，§8.5 背包比值贪心的「保底不亏过半」正是该册 §2.1 顶点覆盖 2-近似与 §2.2 集合覆盖调和记账的同族先声；贪心与 DP 的分界在那边升级成「精确、近似、参数化」三张地图。其三，《编译原理》§6.5 至 §6.6 的数据流分析把「状态 × 转移」的表搬到程序图上：每个程序点一个状态、每条边一次转移，半格给出合并规则；DP 的表无环、按拓扑序一遍填完，数据流的图有环，改用不动点迭代到收敛，同一套递推语言的两档。其四，《图机器学习》册把「状态按依赖序更新」推广到图上的消息传递：每个节点一轮更新一次状态，Weisfeiler–Lehman 式的逐轮递推就是「图版的填表」，该册的章号以站内目录为准。

白话：DP 的「状态、转移、按序更新」是全站通用语法，随机算法册给它配骰子，近似算法册给它配赔率，编译原理册把它搬到程序图上迭代到不动点，图机器学习册让节点互为对方的转移来源。

## $\rm \S \, 8.11$ 本章自测答案

概念回顾答案：

1. 重叠子问题担保「存表划算」：没有重叠，表付了内存却无人来查；最优子结构担保「表内容够拼」：没有它，小格的最优拼不出大格的答案，整张表作废（来源：§8.1）。
2. 两案：末字符为 $c$ 则去尾归约到 ${(i-1,j-1)}$；末字符不是 $c$ 则 $Z$ 不能用 $A[i-1]$（子序列按下标递增使用，用 $i-1$ 必为末元），同理不能用 $B[j-1]$，于是 $Z$ 整体落在 ${(i-1,j-1)}$ 内（来源：§8.3）。
3. 边界 $T(i,0)=1$，失配格 $T(i,j)=1+T(i-1,j)+T(i,j-1)$，用帕斯卡恒等式归纳出 $T(i,j)=2\binom{i+j}{i}-1$；实测 $n=13$ 的 20,801,199 恰为 ${2\binom{26}{13}-1}$（来源：§8.3）。
4. 更新 ${\operatorname{dp}[c]}$ 要读「未考虑本件物品」的 ${\operatorname{dp}[c-w_i]}$ 旧值，倒序保证同轮内它尚未被改写；正序扫则旧值被先更新，同一件物品可被计入两次，解的是每件可装无限次的完全背包（来源：§8.5）。
5. 票数是数值参数（这里是 $W$）的多项式、却是输入位数的指数：$W$ 的二进制表示长 $\log W$，$nW$ 对 $\log W$ 指数增长；容量小则便宜、容量大则天价（来源：§8.5）。
6. 断链点在「拿甲乙换丙」：甲乙合占 10 格顶满容量，丙留下 3 格碎容量装不下任何整件，0-1 条款不许切割，交换无从做起；分数背包允许切割，碎容量被分数补齐，交换证书买得到（来源：§8.5）。

应用与辨析答案：

1. 用 §8.3 的 LCS 表：保留的字符即公共子序列，diff 高亮的「未改动段」就取它；从 ${L(n_1,n_2)}$ 沿回溯指针往 ${L(0,0)}$ 走，每步读「字符相等（保留）」还是「来自上/左（删或插）」即可还原保留集合与改动账。若替换也要单独标色（改字而非删插），换 §8.4 的编辑距离表（来源：§8.3、§8.4）。
2. 理由只在随机分布下成立：实测该分布下贪心 37.6% 的实例吃亏，最差亏 13.6%，且固定反例亏 26.4%（0.7292）；「62.4% 最优」意味着 37.6% 的单子注定亏，好在这种亏有半价保底、不会亏到一半以下。正确流程按 §8.6：先问有没有证书（0-1 背包没有），再按伪多项式预算估 ${nW}$ 的格子数，装得下就 DP，装不下才谈近似合同（来源：§8.5、§8.6）。
3. 交叉点实测在 $n=8$：朴素 25,739 次调用已比记忆化的 129 次贵 200 倍，$n=13$ 就差到三万倍；「$n$ 小」不是豁免条款，因为交叉点在两位数就到。工程考虑是合同价随规模的斜率，不是今天的绝对值；至少该加记忆化，代价只是一个字典（来源：§8.3）。
