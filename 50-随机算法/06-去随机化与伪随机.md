# $\rm Chapter \, 6$ 去随机化与伪随机

前五章一直在花随机性：掷硬币选主元、掷硬币决定层高、掷硬币在图上走。可随机性是要付账的——真随机源难弄、结果不可复现（一个只在某次运行偶发的 bug 能把人逼疯）、随机黑盒塞不进并行机器。于是有两件相反的事要做：能把随机算法**拧成确定算法**的，就拧掉它；拧不掉的，就用一条**可复现的种子流**去冒充真随机。本章讲这两条路——条件期望法（本章主证一）与 Luby 的并行极大独立集（主证二），再落到伪随机生成器与 $\mathrm{BPP} \subseteq \mathrm{P/poly}$，最后看一眼 $\mathrm{P} = \mathrm{BPP}$ 这个猜想站在哪。

> **开始前自检**：本章假设你已经会：
>
> 1. □ 条件期望与全期望公式 $\mathrm{E}[X] = \mathrm{E}\big[\mathrm{E}[X \mid Y]\big]$（本站概率论册第 3 章）。
> 2. □ 期望线性性（第 1 章 §1.2）、Markov 不等式与联合界 $\Pr[\bigcup A_i] \le \sum \Pr[A_i]$（第 2 章 §2.1、§2.4）。
> 3. □ Chernoff 界 $\Pr[S \ge (1+\delta)\mu] \le \mathrm{e}^{-\delta^2\mu/3}$（第 2 章 §2.1）与「重复取多数票把错误率压成指数小」（第 1 章 §1.5）。
> 4. □ $\mathrm{BPP}$ 的定义与 $\mathrm{P} \subseteq \mathrm{RP} \subseteq \mathrm{BPP} \subseteq \mathrm{PP}$ 的坐标（第 1 章 §1.5、本站计算理论册第 7 章）。
>

## $\rm \S \, 6.1$ 为什么需要去随机化：随机性的三笔账

随机算法的期望与分析确实漂亮，但真要用它，有三笔账要付。

1. **真随机源难。** 计算机里没有免费的随机：`rand()` 是伪随机、系统熵池有限、量子随机源贵。算法要的随机位数越多，这笔账越重。
2. **可复现性。** 同一份输入跑两次结果不同，会让调试、回归测试、竞赛评测全部失灵——你无法用一个失败的运行去复现成功。
3. **并行化。** 一台机器上要开几千个线程，每个都得有自己的独立随机流；共享一个种子会破坏独立性，独立熵源又难同步。

于是有两条去随机化的路：

1. **条件期望法（method of conditional expectations）**：不碰随机性本身，只在**证明**里把它消掉——概率法先证「随机解平均地好」，再把这个存在性证明改造成逐位决策的构造。它给出**无条件**的确定算法，是本章主证一。
2. **伪随机代替真随机**：承认还要随机数，但把它换成一条**短的种子**经确定性扩展出来的串，并论证它在一切多项式时间检验者眼里与真随机不可区分。这给出**条件性**的保证（押在计算困难假设上），是 §6.4 的主题。

**本节小结**：随机性要付真随机源、可复现、并行三笔账；去随机化因此有两条路——条件期望法（无条件、把证明变构造）与伪随机替换（条件性、押在困难假设上）。

## $\rm \S \, 6.2$ 条件期望法：把存在性证明变成构造（本章主证一）

概率法最常用的一句话是：若随机变量 $f(r)$ 的**期望** $\ge T$，则必存在某个具体取值 $r^*$ 使 $f(r^*) \ge T$（否则所有取值都 $< T$、期望也 $< T$）。这句话只保证「好解存在」，不给「怎么找」。条件期望法把它升级成构造。

**模板**：设 $r = (r_1, \ldots, r_m)$ 是一串独立随机位，$\mathrm{E}[f(r)] \ge T$。逐位固定：

$$
\text{对 } i = 1, \ldots, m:\quad \text{把 } r_i \text{ 钉成使 } \mathrm{E}\big[f \mid r_1, \ldots, r_{i-1}, r_i\big] \text{ 最大的那个取值}.
$$

**命题 6.1（条件期望不下降）**：上述过程结束时，得到的确定解 $r^{**}$ 满足 $f(r^{**}) \ge T$。

全证：只需证每一步条件期望都不下降。设已固定前 $i-1$ 位、当前条件期望为 $E_i = \mathrm{E}[f \mid r_1, \ldots, r_{i-1}] \ge T$。第 $i$ 位是独立的 $\{0, 1\}$ 位，由全期望公式

$$
E_i = \frac12\,\mathrm{E}\big[f \mid r_1, \ldots, r_{i-1}, r_i = 0\big] + \frac12\,\mathrm{E}\big[f \mid r_1, \ldots, r_{i-1}, r_i = 1\big].
$$

读法：当前条件期望是「$r_i$ 取 $0$ / 取 $1$」两分支期望的**平均**，平均不超过最大者，故至少一支使条件期望 $\ge E_i \ge T$——**钉它**。归纳到全部位固定，条件期望塌缩成确定值 $f(r^{**}) \ge T$。$\blacksquare$

读法：这个证明的全部内容是「平均不超过最大」——一句连初中生都认的话，却把「存在」变成了「照着选就行」。代价是每一步要能**算出**条件期望并比较两个分支，这要求 $f$ 结构可快速求条件期望。

**应用一：Max-Cut 的去随机化**（第 1 章 §1.4 的回声）。随机染色给期望割权 $W/2$；现在逐顶点定色：比较「钉成黑」与「钉成白」两种情形下的条件期望割权，取不低于当前值的那种。每步条件期望不降、起点 $W/2$，作完 $n$ 个决定得到一个确定割 $\ge W/2$。

**应用二：MAX-SAT 的 $7/8$**。给每个变量独立随机取真假，含 $k$ 个文字的子句被满足的概率是 $1 - 2^{-k}$。由线性性，满足权重之和的期望是

$$
\mathrm{E}[\text{满足权重}] = \sum_{c} w_c\big(1 - 2^{-k_c}\big)\ \ge\ \Big(1 - 2^{-k_{\min}}\Big)\sum_c w_c.
$$

对 $3$-SAT（$k = 3$）即 $\ge \frac78\sum_c w_c \ge \frac78\,\mathrm{OPT}$。条件期望法去随机化：逐个变量决策，每步比较「取真 / 取假」的条件期望满足权重、取不降的那种，作完 $n$ 个变量即得确定赋值，满足权重 $\ge \frac78\sum_c w_c$（$7/8$ 近似）。

$$
\text{逐变量固定：}\quad \mathrm{E}\big[\text{权重} \mid x_1, \ldots, x_{i}\big] \text{ 每步不降},\qquad \text{终点} \ge \tfrac78\sum_c w_c.
$$

**本节小结**：条件期望法把概率法的「存在好解」升级为「逐位钉出不降分支」的构造，核心证明只有「平均不超过最大」一句；Max-Cut 与 MAX-SAT 的 $7/8$ 是它的两个标准应用。

## $\rm \S \, 6.3$ Luby 算法：并行求极大独立集的随机贪心（本章主证二）

给定图 $G = (V, E)$，要一个**极大独立集（maximal independent set, MIS）**：两两不相邻、且无法再加入任何顶点。串行贪心是「随便挑一个顶点、删掉它和邻居、重复」。Luby 把它变成**并行**的：每一轮所有还活着的顶点同时掷骰子。

**一轮的规则**：

1. 每个**存活**顶点 $v$ 独立取一个均匀随机数 $r_v \in [0, 1]$。
2. 若 $r_v$ 严格大于它所有存活邻居的随机数，则把 $v$ 选进独立集。
3. 把所有被选顶点**及其存活邻居**从图中删掉；被选者成为 MIS 的一员。

**一轮能删掉多少**。固定存活顶点 $v$、设它此刻有 $d$ 个存活邻居。考察「$v$ 加上它的 $d$ 个邻居」这 $d+1$ 个数，谁是最大完全由随机性决定、均匀落在其中之一，于是

$$
\Pr[v \text{ 被选}] = \frac{1}{d+1},\qquad \Pr[v \text{ 被删}] \ge \Pr[v \text{ 被选}] = \frac{1}{d+1}.
$$

读法：$v$ 被选当且仅当它是「自己加邻居」里的冠军，概率 $1/(d+1)$；被删的条件更宽（邻居夺魁也算），所以是下界。这就是「每个顶点被选或邻居被选的概率 $\ge 1/(d+1)$」。

**期望轮数（顶点度数视角）**。上面那条对**任一历史**都成立——不论前面怎么删，只要 $v$ 还活着、删除它的概率每轮都 $\ge 1/(d+1)$。于是 $v$ 存活 $t$ 轮的概率 $\le (1 - \frac{1}{d+1})^t$，它被删的**期望轮数 $\le d+1$**。对最大度 $\Delta$ 的图，单个顶点期望 $O(\Delta+1)$ 轮被清掉——这就是「期望 $O(1)$ 轮」在**定点**意义上的准确版本。

整张图呢？对 $n$ 个顶点取联合界：某个顶点活过 $t = (d+1)\ln n \cdot c$ 轮的概率 $\le n\,(1-\frac{1}{d+1})^t \le n\,\mathrm{e}^{-t/(d+1)}$，取 $t \gtrsim (d+1)\ln n$ 即压成 $n^{-c}$。所以**全图高概率在 $O(\Delta \log n)$ 轮内清空**。

$$
\Pr\big[\text{某顶点 } > t \text{ 轮才被删}\big] \le n\Big(1 - \tfrac{1}{d+1}\Big)^{t} \le n\,\mathrm{e}^{-t/(d+1)}.
$$

读法：单点是指数尾巴，联合界乘 $n$ 的代价是多留一个 $\ln n$——与第 2 章 §2.4 的账本同款。实测 $n = 1000$、平均度 $3/4/5$ 的随机图只需 $3.1/3.2/3.4$ 轮，远快于 $(\Delta+1)\ln n$ 这个粗界——每轮实测删掉约 $0.79$，存活集按固定比例萎缩，不只按 $1/(d+1)$ 掉。

**去随机化版本**一句话：Luby 1988 用成对独立（而非完全独立）的随机数与条件期望法把这个并行算法改成**确定性**的，轮数仍是 $O(\Delta \log n)$，代价是每轮的随机数换成由种子确定性扩展、再逐顶点做条件期望决策。

**本节小结**：Luby 每轮让存活顶点同时掷骰、冠军及其邻居出局；单点被选概率 $1/(d+1)$、期望 $O(\Delta+1)$ 轮清掉，全图高概率 $O(\Delta\log n)$ 轮；确定性版本用成对独立随机数加条件期望。

## $\rm \S \, 6.4$ 伪随机生成器：把短种子印成随机串

第二条去随机化路的想法是：既然真随机贵，就用一条**短的、真正随机的种子** $s$，经一个确定函数**拉长**成任意长的串，并论证「没人能高效地把这条串和真随机区分开」。

**定义 6.2（伪随机生成器，PRG）**：$G : \{0,1\}^s \to \{0,1\}^n$（$n \gg s$）是一个多项式时间的确定函数。$G$ 是**伪随机的（pseudorandom）**，若对每个多项式时间的**区分器** $D$，

$$
\Big|\Pr_{u \sim \{0,1\}^s}\big[D(G(u)) = 1\big] - \Pr_{r \sim \{0,1\}^n}\big[D(r) = 1\big]\Big| \le \text{可忽略}.
$$

白话：PRG 的输出不要求「真随机」，只要求「一切高效算法都认不出它不随机」。由鸽笼原理，$2^s$ 个种子只能生成 $2^s$ 个串、远少于 $2^n$ 个真随机串——所以「不可区分」必须限定在**多项式时间**，跑不完指数时间的区分器抓不住那点破绽。这是一条计算假设，不是信息论事实。

**定理 6.3（$\mathrm{BPP} \subseteq \mathrm{P/poly}$）**：每个 $\mathrm{BPP}$ 中的语言都落在非均匀多项式时间 $\mathrm{P/poly}$ 里。

证明要点（用 Chernoff 把「好随机串」印成建议）：设 $M$ 是判定 $L \in \mathrm{BPP}$ 的多项式时间随机算法，输入长 $n$ 时用 $m = \mathrm{poly}(n)$ 个随机位。先**放大**：把 $M$ 独立跑 $O(n)$ 次取多数票，错误率压到 $\le 2^{-(n+1)}$。

固定一个输入 $x$（$|x| = n$）。因为多数票的错误率指数小，

$$
\Pr_{r \in \{0,1\}^m}\big[ M(x, r) \ne L(x) \big] \le 2^{-(n+1)}.
$$

现在**对所有 $2^n$ 个长为 $n$ 的输入取联合界**：

$$
\Pr_r\big[\exists x \in \{0,1\}^n:\ M(x, r) \ne L(x)\big] \le \sum_{x} 2^{-(n+1)} = 2^n \cdot 2^{-(n+1)} = \frac12 < 1.
$$

存在概率 $< 1$ 的事件「不」发生的概率 $> 0$，故**存在**一条固定随机串 $r^* \in \{0,1\}^m$，使 $M(x, r^*) = L(x)$ 对**所有** $|x| = n$ 都成立。把 $r^*$ 作为**建议串（advice）**、长度为 $m = \mathrm{poly}(n)$ 只依赖于 $n$，硬写进算法：输入 $x$ 时确定性地算 $M(x, r^*)$，对每个 $x$ 都正确。这就是 $\mathrm{P/poly}$ 算法，定理成立。$\blacksquare$

读法：概率法又出现一次——「一条随机串对所有输入都好」被 Chernoff 加联合界证明为**正概率**，于是好串存在。代价是建议**非均匀**（每个 $n$ 一条、不能边跑边造），这正是 $\mathrm{P/poly}$ 与 $\mathrm{P}$ 的区别。

**工程里的伪随机**一句话：这里的 PRG 是理论对象，工程用的 `mersenne twister`、`xoshiro` 等**统计随机数**并不承诺对多项式攻击者不可区分（它们是可预测的），所以密码学场景要用 `CSPRNG`（如 `ChaCha20`、`AES-CTR`）并严格管理种子——**种子一旦泄露，整条流就退化成确定串**。

**本节小结**：PRG 用短种子拉长成「多项式时间不可区分」的串；$\mathrm{BPP} \subseteq \mathrm{P/poly}$ 由 Chernoff 压制单输入错误、再对 $2^n$ 个输入联合界，把一条好随机串印成长度 $\mathrm{poly}(n)$ 的建议；工程随机数分统计与密码两级，后者才谈得上「不可区分」。

## $\rm \S \, 6.5$ 与复杂性理论的接缝：$\mathrm{P} = \mathrm{BPP}$ 站在哪

第 1 章留过一句话：多数复杂度理论家相信 $\mathrm{P} = \mathrm{BPP}$，随机性在多项式时间内带不来本质加速。本章的两条路线把这句话的**条件**摆清楚了。

1. **$\mathrm{P} = \mathrm{BPP}$ 猜想**：至今无条件的 $\mathrm{P} \ne \mathrm{BPP}$ 与 $\mathrm{P} = \mathrm{BPP}$ 都没被证明；$\mathrm{BPP} \subseteq \mathrm{P/poly}$（定理 6.3）是能证的那一半，差就差在「建议不能边跑边造」。
2. **Impagliazzo–Wigderson 1997**：若存在一个函数落在 $\mathrm{E} = \mathrm{DTIME}(2^{O(n)})$ 里、其电路复杂度为 $2^{\Omega(n)}$（即需要指数大的电路），则 $\mathrm{BPP} = \mathrm{P}$。换句话说，**足够的计算困难性可以兑换成去随机化**——难函数本身就是伪随机性的来源（Nisan–Wigderson 构造）。
3. 与本站计算理论册第 7 章互文：那一章从 $\mathrm{BPP}$ 的定义、放大讲到去随机化的地图；本章的 PRG 与 $\mathrm{P/poly}$ 是地图上「随机性能不能被穷举掉」这条边。

**本节小结**：$\mathrm{P} = \mathrm{BPP}$ 无条件未决，能无条件证明的只有 $\mathrm{BPP} \subseteq \mathrm{P/poly}$；Impagliazzo–Wigderson 给出「指数电路困难 $\Rightarrow \mathrm{BPP} = \mathrm{P}$」的兑换条件。

## $\rm \S \, 6.6$ 数值锚与实验

**条件期望去随机化 Max-Cut 的 trace**。取 $5$ 个顶点、$6$ 条带权边的图，总权重 $W = 9$。起点条件期望 $= W/2 = 4.5$，逐顶点钉品牌（$\S6.10$ 程序）：

| 步骤 | 顶点 | $\mathrm{E}[\text{黑}]$ | $\mathrm{E}[\text{白}]$ | 选择 | 之后条件期望 |
| --- | --- | --- | --- | --- | --- |
| $1$ | $0$ | $4.500$ | $4.500$ | 黑 | $4.500$ |
| $2$ | $1$ | $4.000$ | $5.000$ | 白 | $5.000$ |
| $3$ | $2$ | $5.500$ | $4.500$ | 黑 | $5.500$ |
| $4$ | $3$ | $5.000$ | $6.000$ | 白 | $6.000$ |
| $5$ | $4$ | $7.000$ | $5.000$ | 黑 | $7.000$ |

条件期望 $4.5 \to 4.5 \to 5.0 \to 5.5 \to 6.0 \to 7.0$ 单调不降，终点染色 $[0,1,0,1,0]$ 的真实割权是 $7 \ge 4.5$。第一、二步的平局/上升都是「平均不超过最大」的具体演出——第一步两色条件期望都等于 $4.5$，是恰好取等的情形。

**Luby 算法的期望轮数**（$n = 1000$ 随机图、$200$ 次试验）：

| 平均度 | 平均轮数 | 最大轮数 | 粗界 $(\Delta+1)\ln n$ |
| --- | --- | --- | --- |
| $3$ | $3.115$ | $4$ | $27.63$ |
| $4$ | $3.200$ | $4$ | $34.54$ |
| $5$ | $3.405$ | $4$ | $41.45$ |

实测轮数只有 $3$ 出头，远低于粗界——每轮实测删掉约 $0.79$ 的存活顶点（$1 - 1/(d+1)$ 只给 $0.83$ 的**单点**下界，但邻居连带删除让整体萎缩得快得多）。这提醒一句：$O(\Delta\log n)$ 是保底承诺，真实常数取决于图的结构。

**本节小结**：条件期望去随机化的 trace 逐行展示条件期望不降、终点割权 $\ge W/2$；Luby 在 $n=1000$ 上 $3.1$ 到 $3.4$ 轮完成，粗界偏松是常数而非量级的问题。

## $\rm \S \, 6.7$ 关键概念回顾

1. 随机性的三笔账各是什么？条件期望法与伪随机替换分别属于「无条件」还是「条件性」的保证？
2. 条件期望法的核心证明用到的唯一一句话是什么？为什么每一步都有「不降」的分支可选？
3. Max-Cut 与 MAX-SAT 的条件期望去随机化各在比较什么量？$7/8$ 这个常数来自哪一步期望？
4. Luby 一轮里「$v$ 被选」的概率为什么是 $1/(d+1)$？「$v$ 被删」的概率为什么要用 $\ge$ 而不是 $=$？
5. 单点的期望轮数是 $O(\Delta+1)$，全图的轮数为什么要多一个联合界、得到 $O(\Delta\log n)$？成本落在哪？
6. PRG 的「不可区分」为什么必须限定多项式时间？$\mathrm{BPP}\subseteq\mathrm{P/poly}$ 的证明里，Chernoff 与联合界各压在哪里？

## $\rm \S \, 6.8$ 应用与辨析

1. 有同学说「条件期望法既然能构造出 $\ge T$ 的解，那它一定是最优算法」。指出问题：它保证的是哪个量、对 $f$ 的结构有什么要求？
2. Max-Cut 条件期望去随机化要逐顶点比较两色条件期望。若图的边权很大、顶点很多，每步「算条件期望」的代价是多少？这份代价与随机算法相比多付了什么？

## $\rm \S \, 6.9$ 本章自测答案

> 先闭卷作答 $\S6.7$ 与 $\S6.8$，再核对。

### $\rm \S \, 6.9.1$ 关键概念回顾答案

1. 真随机源难、不可复现、难并行。条件期望法给出**无条件**确定算法；伪随机替换给出**条件性**保证（押在「存在难函数 / 区分器跑不动」上）。（$\S6.1$）
2. 唯一一句话：「当前期望是两分支期望的平均，平均不超过最大」。故两分支里至少一个的条件期望 $\ge$ 当前值，钉它即可。（$\S6.2$）
3. Max-Cut 比较「钉黑 / 钉白」的条件期望割权；MAX-SAT 比较「取真 / 取假」的条件期望满足权重。$7/8$ 来自单个含 $3$ 个文字的子句被满足概率 $1 - 2^{-3} = 7/8$，再由线性性加总。（$\S6.2$）
4. $v$ 被选当且仅当它是「自己加 $d$ 个邻居」这 $d+1$ 个随机数里的冠军，均匀故 $1/(d+1)$。被删还包含「某邻居夺冠」的情形，故是 $\ge$。（$\S6.3$）
5. 单点尾巴对固定历史成立，但「所有顶点都好」要对 $n$ 个顶点取联合界、乘 $n$，指数里就要多留 $\ln n$，得 $O(\Delta\log n)$。成本是那个对数因子。（$\S6.3$）
6. 鸽笼原理保证 $2^n$ 个随机串必有人能区分，故「不可区分」只能对**多项式时间**区分器成立。Chernoff 压单输入错误到 $2^{-(n+1)}$，联合界对 $2^n$ 个输入求和得 $1/2 < 1$，从而好串存在。（$\S6.4$）

### $\rm \S \, 6.9.2$ 应用与辨析答案

1. 不成立。它保证的是**该目标函数 $f$ 的取值** $\ge \mathrm{E}[f]$，不保证全局最优（比如 Max-Cut 只保证 $\ge W/2$，最优可能接近 $W$）。而且每步要能**快速算出**「已定部分下的条件期望」，$f$ 结构不够规整时这份计算本身可能是瓶颈。（$\S6.2$）
2. 每算一次条件期望要过一遍全部边，一次决策 $O(|E|)$、共 $n$ 次即 $O(n|E|)$。相对随机算法「染一次 $O(n + |E|)$」多付 $O(n)$ 倍——去随机化一般比随机版本贵，代价就花在「把期望算准」上。（$\S6.2$）
3. 不足以。单点下界只保证每个顶点**至少**有 $1/(\Delta+1)$ 的概率被删，但删除是**连带**的：一个顶点被选会同时删掉它的所有邻居，所以实际删掉的比例可能远高于 $1/(\Delta+1)$。实测 $0.79 > 1/6$ 正说明连带删除的威力，但它依赖图的局部结构、不是普适的每轮下界。（$\S6.3$）
4. 压到 $2^{-(n+1)}$ 才能让联合界给 $2^n \cdot 2^{-(n+1)} = 1/2 < 1$，从而「好串存在」。若只压到 $2^{-n}$，联合界得 $2^n \cdot 2^{-n} = 1$，只能证明「坏串的概率 $\le 1$」——一个空话，推不出好串存在。多留一个 $2^{-1}$ 就是留给 $2^n$ 个输入的利息，与第 2 章 §2.4 的账本同构。（$\S6.4$）
5. `mersenne twister` 的输出由有限状态完全决定、状态可反推，所以给足输出就能预测后续——它对多项式时间的密码学区分器**不是**伪随机的。种子管理的风险：伪随机路线里种子泄露即整条流可复现，条件期望路线里则根本不存在种子、也就没有这份风险。（$\S6.4$、$\S6.5$）
6. $\mathrm{P} = \mathrm{BPP}$ 说随机性不带来多项式加速；Impagliazzo–Wigderson 说「存在指数电路复杂度的函数」可推出 $\mathrm{P} = \mathrm{BPP}$。机制是：难函数构造出伪随机生成器、用短种子代替真随机，再用条件期望消掉剩余随机性，两条路合起来把 $\mathrm{BPP}$ 拉回 $\mathrm{P}$。（$\S6.4$、$\S6.5$）

## $\rm \S \, 6.10$ 程序对账

下面一段重算 §6.6 的两组锚：条件期望去随机化的 Max-Cut trace、Luby 算法的轮数。固定种子可复现。

```python
import random, math

R = random.Random(20261103)                    # 固定种子，结果可复现

# ---------- 条件期望去随机化：小图的 Max-Cut ----------
edges = [(0,1,1),(1,2,2),(2,3,1),(3,4,3),(4,0,1),(0,2,1)]
W = sum(w for _,_,w in edges); n = 5
color = [None]*n

def cond_expected(color):                      # 未定边贡献 w/2，已定边按异色计
    ce = 0.0
    for u, v, w in edges:
        if color[u] is not None and color[v] is not None:
            ce += w if color[u] != color[v] else 0
        else:
            ce += w/2
    return ce

print(f"W={W}  start CE = {cond_expected(color):.4f} = W/2")
for v in range(n):
    c0 = color[:]; c0[v] = 0
    c1 = color[:]; c1[v] = 1
    e0, e1 = cond_expected(c0), cond_expected(c1)
    pick = 0 if e0 >= e1 else 1
    color[v] = pick
    print(f"v={v}: E[black]={e0:.4f}  E[white]={e1:.4f}  choose={'black' if pick==0 else 'white'}  CE={cond_expected(color):.4f}")
final = sum(w for u, v, w in edges if color[u] != color[v])
print(f"final coloring = {color}  cut = {final}  (>= W/2 = {W/2})")

# ---------- Luby 极大独立集 ----------
def luby_rounds(n, p):
    adj = [[] for _ in range(n)]
    for i in range(n):
        for j in range(i+1, n):
            if R.random() < p:
                adj[i].append(j); adj[j].append(i)
    alive = [True]*n; rounds = 0
    while True:
        idx = [i for i in range(n) if alive[i]]
        if not idx: break
        rounds += 1
        key = {i: R.random() for i in idx}
        selected = [i for i in idx if all(key[i] > key[j] for j in adj[i] if alive[j])]
        remove = set(selected)
        for i in selected:
            for j in adj[i]: remove.add(j)
        for i in remove: alive[i] = False
    return rounds

n = 1000; trials = 200
for d in (3, 4, 5):
    rs = [luby_rounds(n, d/(n-1)) for _ in range(trials)]
    print(f"luby  n={n}  avg-deg={d}  avg rounds = {sum(rs)/len(rs):.3f} (max {max(rs)})")
```

输出（本机实测）：

1. `W=9  start CE = 4.5000 = W/2`；五行逐步输出条件期望 ${4.5, 4.5, 5.0, 5.5, 6.0, 7.0}$，与 §6.6 的表逐格吻合。
2. `final coloring = [0, 1, 0, 1, 0]  cut = 7  (>= W/2 = 4.5)`——确定割权 $7$，高于随机期望。
3. `luby  n=1000  avg-deg=3  avg rounds = 3.115 (max 4)`、`avg-deg=4` 为 `3.200`、`avg-deg=5` 为 `3.405`——与 §6.6 的表一致。

**带走清单**：随机性的三笔账与两条去随机化路线；条件期望法「平均不超过最大」的逐位不降证明；Max-Cut 与 MAX-SAT 的 $7/8$ 去随机化；Luby 的 $1/(d+1)$ 被选概率、单点 $O(\Delta+1)$ 轮、全图 $O(\Delta\log n)$ 轮与确定性版本；PRG 的计算不可区分定义、$\mathrm{BPP}\subseteq\mathrm{P/poly}$ 的 Chernoff 加联合界证明；$\mathrm{P} = \mathrm{BPP}$ 猜想与 Impagliazzo–Wigderson 的兑换条件。

---

去随机化把「随机」从必需品降成一种**便利**：条件期望法干脆把硬币抽掉，伪随机则用一条短种子冒充整条随机流。两件事合起来指向同一个猜想——随机性也许从来不曾真正必要，它只是让我们暂时不必知道那串「好随机数」长什么样。全书到此收束：从指示变量与浓度工具，到素性判定、随机化数据结构、MCMC，再到把随机性本身消掉，随机算法的每一层都在做同一件事——**把不确定性翻译成可证明的承诺**。
