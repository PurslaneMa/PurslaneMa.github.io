# $\rm Chapter \, 2$ Marchenko–Pastur 律

本册第 1 章的主角是对称的 Wigner 矩阵——那是为「谱长什么样」铺路的纯数学对象。数据科学真正攥在手里的矩阵不是对称的：$p$ 个变量、$n$ 个样本的数据矩阵 $X$，长方形，统计里的一切从它的**样本协方差矩阵** $S = \frac{1}{n} X X^{\mathsf T}$ 出发。本章给 $S$ 的谱找法律：当 $p$ 与 $n$ 同量级增长、比值 $\beta = p/n$ 停在常数时，$S$ 的特征值不再聚焦在总体协方差的真实值上，而是摊成一条固定的斜坡——Marchenko–Pastur 律。本章的数值锚：$p = 400$、$n = 1600$（$\beta = 0.25$）的样本协方差，实测特征值范围 $[0.246, 2.184]$ 对理论支撑 $[0.25, 2.25]$；外加两台实验——$\beta \to 1$ 时质量在 $0$ 处的堆积，以及一个真实信号如何从噪声斜坡里冒头。

## $\rm \S \, 2.1$ 主角更换：样本协方差矩阵与形状比 $\beta$

先说清为什么要换主角。第 1 章的 Wigner 矩阵是方的、对称的、元素围绕零摆动；真实数据矩阵是长方形的、非对称的、元素往往非负或量纲各异。但有一层标准化的桥：把数据矩阵的各列中心化、各元素除以共同尺度后，统计推断的核心对象是**样本协方差矩阵**

$$
S = \frac{1}{n} X X^{\mathsf T}
$$

（读法：$X$ 是 $p \times n$ 矩阵，$p$ 个变量、$n$ 个样本，列是观测；$S$ 是 $p \times p$ 的半正定矩阵，第 $i$ 个对角元是第 $i$ 个变量的样本方差，非对角元是样本协方差——PCA、回归、假设检验全都踩在它的谱上。）

经典统计的剧本是维数固定、样本无限：$n \to \infty$、$p$ 不动，$S$ 贴住总体协方差 $\Sigma$，特征值个个收敛到真值。现代数据的剧本反过来了：基因表达测几万个基因、用户画像上千维特征，$p$ 与 $n$ 一起涨，摊到每个参数上的样本不再增长。这时 $S$ 的谱**不聚焦**——本站高维概率与矩阵分析册第 3 章维数诅咒的谱面版：维数与样本同量级时，「协方差估计」这个动作本身就会让谱歪掉。歪多少、歪成什么形状，由一个比值决定：

$$
\beta = \frac{p}{n}
$$

（读法：形状比——每维摊到几个样本的倒数。$\beta$ 停在常数（比如 $0.25$，即每维 $4$ 个样本）时，经典结论全部失效；$\beta \to 0$（每维样本数爆炸）才收回「$S$ 聚焦于 $\Sigma$」。）

有一个必须先拆掉的错觉：$S$ 是「无偏」的——当总体协方差 $\Sigma = I$ 时 $\operatorname{E} S = I$，每个元素都围绕真值摆动。但**无偏管元素、谱管整体**，两本账：把 $p$ 个特征值平均，确实得到 $1$（迹不骗人，§2.2 实测）；可特征值全体并不个个是 $1$，它们摊成一条从 $0.25$ 到 $2.25$ 的斜坡。这就是「维数让谱变歪」的精确含义。

还有一条换算要记牢（本站高维概率与矩阵分析册第 4 章定义 4.7 的读法）：$X X^{\mathsf T}$（$p \times p$）与 $X^{\mathsf T} X$（$n \times n$）共享全部非零特征值。所以「样本协方差的谱」与「数据矩阵 Gram 矩阵的谱」是同一批数，只是零的个数归谁记账不同——$\beta > 1$（变量比样本多）时 $X X^{\mathsf T}$ 必然秩亏，$p - n$ 个特征值**恒等于零**，这个原子只有协方差取向看得见，§2.3 会用到。

**本节小结**：主角换成 $S = \frac{1}{n} X X^{\mathsf T}$；形状比 $\beta = p/n$ 停在常数时谱不聚焦，无偏与聚焦是两本账；两种矩阵取向共享非零特征值、零原子归大边管。下一节给 $S$ 的谱立法律。

## $\rm \S \, 2.2$ Marchenko–Pastur 律：密度、支撑与两笔账

**定理 2.1（Marchenko–Pastur 律，1967，陈述级）**：设 $X$ 为 $p \times n$ 矩阵、元素独立、零均值、方差 $1$，$\beta = p/n \to \beta_\infty \in (0, 1]$，则 $S$ 的 ESD 弱收敛（几乎必然）到密度

$$
f_\beta(x) = \frac{1}{2\pi \beta x} \sqrt{(b - x)(x - a)}
$$

（读法：支撑 $[a, b]$，其中

$$
a = \left(1 - \sqrt{\beta}\right)^2, \qquad b = \left(1 + \sqrt{\beta}\right)^2
$$

$1/x$ 因子让密度右偏——质量偏向下边缘，峰值出现在下边缘附近而不是中间。$\beta = 1$ 时 $a = 0$，密度在 $0$ 处像 $x^{-1/2}$ 一样发散，这是 §2.3 的主角。$\beta > 1$ 时测度还多出一块贴在 $0$ 的原子，质量 $1 - \beta$ 的倒数——正好是 $p - n$ 个恒零特征值摊上的权重，两种取向的账在这里并轨。）$\beta$ 定一切：知道 $\beta$ 就知道整条曲线。

半圆律与 MP 律的字典（只列要点）：半圆对称、支撑 $[-2, 2]$ 由 $n^2$ 个元素的方差定调；MP 右偏、支撑 $[(1-\sqrt\beta)^2, (1+\sqrt\beta)^2]$ 由形状比定调；半圆的矩是 Catalan 数，MP 的矩是 Narayana 多项式（第 3 章 §3.4 提一笔）。两者的共同点是「谱不聚焦、形状固定」。

验货。$\beta = 0.25$（$p = 400$、$n = 1600$，每维 $4$ 个样本），理论支撑

$$
a = (1 - 0.5)^2 = 0.25, \qquad b = (1 + 0.5)^2 = 2.25
$$

程序生成高斯数据矩阵、算 $S$ 的全部特征值（完整程序在 §2.6）：

```python
import numpy as np
p, n = 400, 1600
rng = np.random.default_rng(3560)
X = rng.standard_normal((p, n))
S = X @ X.T / n
ev = np.linalg.eigvalsh(S)
print("min = %.4f  max = %.4f" % (ev.min(), ev.max()))
print("mean eig = %.6f" % ev.mean())
```

```text
min = 0.2463  max = 2.1837
mean eig = 0.999905
```

实测特征值范围 $[0.2463, 2.1837]$，对理论 $[0.25, 2.25]$：下端几乎压线（差 $0.004$），上端回缩 $0.066$。这笔不对称的账有讲究：MP 下边缘是**软边**——密度在那里有限、特征值可以有少量越界，实测有 $0.25\%$ 的特征值落在 $0.25$ 之下；上边缘对高斯数据是**硬边**——$\lambda_{\max}$ 集中在 $b$ 附近、涨落只有 $n^{-2/3}$ 尺度（Bai–Yin 定理管住它，本站高维概率与矩阵分析册第 10 章 §10.4），越界个数为零。软硬之别在第 1 章半圆的边缘也有（谱范数 $2\sqrt n$ 天花板一侧是硬的），这里再次现身。

两笔整体账当场对清：

1. **均值账**：$400$ 个特征值平均 $0.999905$ 对理论 $1$——迹不骗人，$\operatorname{tr} S / p = \frac{1}{pn} \sum_{i,j} X_{ij}^2 \to 1$，大数定律一行。歪的是形状，不是重心。
2. **质量账**：$\int f_\beta = 1$、$\int x f_\beta(x)\, \mathrm dx = 1$，全部质量在 $[a, b]$ 内。谱整体没丢没多，只是从「一根刺」（全在 $1$）摊成了「一条斜坡」。

白话：MP 律说的其实是——**当维数吃掉了样本，样本协方差的特征值天然铺成一条斜坡，哪怕总体协方差是完美的单位阵**。你看到谱里有一段从 $0.25$ 爬到 $2.25$ 的坡，不等于数据里有任何结构；这段坡是纯噪声的地形。分辨「地形」与「信号」就是 §2.4 的任务。

**本节小结**：MP 律把 $S$ 的 ESD 钉在 $f_\beta(x) = \sqrt{(b-x)(x-a)}/(2\pi\beta x)$ 上，支撑 $[(1-\sqrt\beta)^2, (1+\sqrt\beta)^2]$；$\beta = 0.25$ 实测 $[0.2463, 2.1837]$，下软上硬；均值账归 $1$、质量账不丢。下一节推 $\beta \to 1$，看斜坡的下端如何坍进 $0$。

## $\rm \S \, 2.3$ $\beta \to 1$：质量在 $0$ 处的堆积

看下边缘 $a = (1 - \sqrt\beta)^2$ 随 $\beta$ 的走向：$\beta = 0.25$ 时 $a = 0.25$；$\beta = 0.5$ 时 $a = 0.0858$；$\beta = 0.9$ 时 $a = 0.0026$；$\beta = 1$ 时 $a = 0$。下边缘不是匀速滑向 $0$，而是**贴地加速**：在 $\beta = 1$ 附近，$a \approx (1 - \beta)^2 / 4$——二次方坍缩。同时密度里那颗 $1/x$ 因子越来越凶：质量持续往 $0$ 的方向堆积。$\beta = 1$ 恰好是临界点：还没有恒零特征值（$p = n$ 时矩阵满秩），但密度在 $0$ 处发散成 $x^{-1/2}$ 的尖峰——**堆积而不成原子**；$\beta$ 一旦越过 $1$，$p - n$ 个方向干脆没有数据，$0$ 处长出质量 $1 - \beta$ 的真原子。

数值看堆积。$\beta = 1$（$p = n = 800$）与 $\beta = 1.1$（$p = 880$、$n = 800$）：

```python
r2 = np.random.default_rng(7)
X1 = r2.standard_normal((800, 800)); S1 = X1 @ X1.T / 800
e1 = np.linalg.eigvalsh(S1)
print("beta=1: 1%%-quantile = %.6f, frac(e<0.05) = %.4f, frac(e<0.1) = %.4f"
      % (np.quantile(e1, 0.01), np.mean(e1 < 0.05), np.mean(e1 < 0.1)))
X2 = r2.standard_normal((880, 800)); S2 = X2 @ X2.T / 800
e2 = np.linalg.eigvalsh(S2)
print("beta=1.1: zeros = %.4f, frac(e<0.1) = %.4f" % (np.mean(e2 < 1e-9), np.mean(e2 < 0.1)))
```

```text
beta=1: 1%-quantile = 0.000368, frac(e<0.05) = 0.1425, frac(e<0.1) = 0.2013
beta=1.1: zeros = 0.0909, frac(e<0.1) = 0.2341
```

三笔数：$\beta = 1$ 时最小的 $1\%$ 特征值挤在 $0.0004$ 以下，全体有 $14.3\%$ 落在 $0.05$ 之下、$20.1\%$ 落在 $0.1$ 之下——五分之一的谱贴着地板；$\beta = 1.1$ 时恰有 $80/880 = 9.1\%$ 的特征值**精确为零**（矩阵秩亏 $p - n = 80$，浮点世界表现为 $10^{-9}$ 量级），再把附近斜坡算上，$0.1$ 之下有 $23.4\%$。

白话：$\beta \to 1$ 说的是「样本刚够」的世界——$800$ 个样本撑 $800$ 个方向，平均每方向一个样本，总有方向几乎没见过数据。对统计的后果直接写在谱上：特征值小到 $10^{-4}$，样本协方差**不可逆**（条件数爆炸），回归系数估计的方差被 $1/\lambda_{\min}$ 顶上天——这就是高维回归里「正则化不是可选项」的谱面原因：岭回归往特征值上垫一个 $\lambda$，垫的正是这片贴地的堆积。

**本节小结**：下边缘 $(1-\sqrt\beta)^2$ 二次方坍向 $0$，$\beta = 1$ 密度以 $x^{-1/2}$ 发散、质量堆积不成原子，$\beta > 1$ 出现质量 $1 - \beta$ 的零原子；实测 $\beta = 1$ 时 $20\%$ 的特征值低于 $0.1$。下一节站到应用侧：这段噪声斜坡，正是 PCA 图上那条让人误读的地板线。

## $\rm \S \, 2.4$ 与 PCA 的关系：噪声特征值的形状

PCA 把协方差矩阵的特征值从大到小排成碎石图（scree plot），让人挑「前几个主成分」。教科书的心照不宣是：大特征值是信号、小特征值是噪声。MP 律把这句模糊话变成精确地形图：**当总体协方差是单位阵（纯噪声、无任何结构）时，PCA 的谱不是一条平的尾巴，而是一条从 $(1+\sqrt\beta)^2$ 滑到 $(1-\sqrt\beta)^2$ 的 MP 斜坡**。碎石图上那条「慢慢变平的尾巴」不是噪声太小看不清，而是噪声自己的形状——$\beta$ 越大，坡越陡、拖得越长。

有信号时呢？给总体协方差加一个秩一尖峰：$\Sigma = I + \tau u u^{\mathsf T}$（数据在固定方向 $u$ 上多出强度 $\tau$ 的信号）。BBP 相变（Baik–Benoît Arous–Péché；本站高维概率与矩阵分析册第 4 章命题 4.9、第 10 章 §10.5 的完整推导）给出门槛与归宿：

1. **门槛**：$\tau > \sqrt\beta$ 时信号露头——$\lambda_{\max}$ 离开噪声带、跑到尖峰极限 $(1 + \tau)\left(1 + \frac{\beta}{\tau}\right)$；
2. **隐身**：$\tau \le \sqrt\beta$ 时信号在谱里看不出——$\lambda_{\max}$ 仍贴住噪声带上边缘 $b$，再多信号也推不动。

数值过一遍。$\beta = 0.25$（门槛 $\sqrt\beta = 0.5$），$\tau = 3$（远超门槛），尖峰极限 $(1 + 3)(1 + 0.25/3) = 4.3333$；纯噪声的上边缘是 $2.25$：

```python
rs = np.random.default_rng(11)
u = np.r_[1.0, np.zeros(p - 1)]              # 信号方向
Xs = rs.standard_normal((p, n)) + np.sqrt(3.0) * np.outer(u, np.ones(n))
Ss = Xs @ Xs.T / n
evs = np.linalg.eigvalsh(Ss)
print("top = %.4f, second = %.4f" % (evs[-1], evs[-2]))
```

```text
top = 4.3395, second = 2.2014
```

实测顶特征值 $4.3395$ 对尖峰极限 $4.3333$（差 $0.006$，有限 $n$ 涨落），第二名 $2.2014$ 稳稳留在噪声带内（上边缘 $2.25$）——**一个信号方向顶穿斜坡，其余 $399$ 个特征值原样按 MP 摊坡**。这就是「普适噪声底座上找离群点」的数据版：第 1 章 §1.4 结尾预告的套路在此兑现。

给实践者三句话（每句背后都是上面的定理）：

1. 看碎石图先问 $\beta$ 是多少：$\beta = 0.25$ 时特征值落在 $[0.25, 2.25]$ 内的一段坡，一个主成分都不该挑——那是地形不是山头；
2. 想判断「第 $k$ 个特征值是不是信号」，拿 MP 上边缘 $b = (1+\sqrt\beta)^2$ 当警戒线：超过且明显者才算露头；
3. 想压住噪声斜坡，两个标准动作：加大样本让 $\beta$ 变小（坡整体收窄成刺），或正则化/收缩（显式修正 MP 已知的歪，本站高维概率与矩阵分析册第 10 章 §10.6 的去噪出口）。

**本节小结**：纯噪声的 PCA 谱就是 MP 斜坡——碎石图的尾巴有确定的形状；秩一信号有精确的露头门槛 $\sqrt\beta$ 与归宿 $(1+\tau)(1 + \beta/\tau)$，$\beta = 0.25$、$\tau = 3$ 实测顶特征值 $4.34$ 对 $4.33$、其余按坡摊开。本章现象齐了，下一章开机器：这些定律是怎么被证明钉死的。

## $\rm \S \, 2.6$ 程序段：MP 律的三台实验

把 §2.2 的验收与 §2.3、§2.4 的两台实验合成一个可复跑的程序（三段各自固定种子）：

```python
import numpy as np

# ---------- 实验一: beta = 0.25 的谱范围 ----------
p, n = 400, 1600
beta = p / n
rng = np.random.default_rng(3560)
X = rng.standard_normal((p, n))
S = X @ X.T / n
ev = np.linalg.eigvalsh(S)
a, b = (1 - np.sqrt(beta))**2, (1 + np.sqrt(beta))**2
print("support: [%.4f, %.4f] vs theory [%.4f, %.4f]" % (ev.min(), ev.max(), a, b))
print("mean eig = %.6f (trace account)" % ev.mean())
print("frac below a = %.5f (soft edge), above b = %.5f (hard edge)"
      % (np.mean(ev < a), np.mean(ev > b)))

# ---------- 实验二: beta -> 1 的堆积 ----------
r2 = np.random.default_rng(7)
X1 = r2.standard_normal((800, 800))
e1 = np.linalg.eigvalsh(X1 @ X1.T / 800)
print("beta=1: 1%%-q = %.6f, frac<0.05 = %.4f, frac<0.1 = %.4f"
      % (np.quantile(e1, 0.01), np.mean(e1 < 0.05), np.mean(e1 < 0.1)))
X2 = r2.standard_normal((880, 800))
e2 = np.linalg.eigvalsh(X2 @ X2.T / 800)
print("beta=1.1: zeros = %.4f (= (p-n)/p), frac<0.1 = %.4f"
      % (np.mean(e2 < 1e-9), np.mean(e2 < 0.1)))

# ---------- 实验三: 秩一尖峰露头 ----------
rs = np.random.default_rng(11)
u = np.r_[1.0, np.zeros(p - 1)]
tau = 3.0
Xs = rs.standard_normal((p, n)) + np.sqrt(tau) * np.outer(u, np.ones(n))
evs = np.linalg.eigvalsh(Xs @ Xs.T / n)
print("spike: top = %.4f vs BBP %.4f, second = %.4f vs noise edge %.4f"
      % (evs[-1], (1 + tau) * (1 + beta / tau), evs[-2], b))
```

实跑输出：


## $\rm \S \, 2.7$ 六问参考答案

1. 不矛盾：$\operatorname{E} S = I$ 是元素级的账（每个元素围绕真值摆动），谱不聚焦是整体级的账（$p$ 个特征值摊成斜坡）——无偏管元素、迹管重心，形状另算。$\beta \to 0$ 时斜坡收窄成刺，两本账合流，经典统计回归。（§2.1、§2.2）
2. 密度 $f_\beta(x) = \sqrt{(b-x)(x-a)}/(2\pi\beta x)$，支撑 $[(1-\sqrt\beta)^2, (1+\sqrt\beta)^2]$；$\beta = 0.25$ 时 $a = 0.25$、$b = 2.25$。下端 $0.25\%$ 越界是软边缘（密度有限、允许涨落）；上端零越界是硬边缘（$\lambda_{\max}$ 集中于 $b$，Bai–Yin 定理）。（§2.2）
3. 二次方：$a \approx (1-\beta)^2/4$。$\beta = 1$ 时满秩但密度以 $x^{-1/2}$ 发散、质量堆积不成原子（实测 $20.1\%$ 低于 $0.1$）；$\beta = 1.1$ 时出现质量 $9.1\%$ 的精确零原子。（§2.3）
4. 质量 $1 - \beta$（$p \times p$ 的 ESD 里 $p - n$ 个零摊上的权重）：$\beta = 1.1$ 时 $80/880 = 0.0909$，与秩亏账 $p - n$ 精确对上。（§2.3）
5. 门槛 $\sqrt\beta$ 是信号强度 $\tau$ 的显形阈值：超过则顶特征值跑到 $(1+\tau)(1+\beta/\tau)$，不超过则谱上隐身。$\tau = 3$、$\beta = 0.25$：顶特征值 $4.3395$ 对 $4.3333$ 露头，第二名 $2.2014$ 留在噪声带内——一个方向冒尖、其余按坡摊开。（§2.4）
6. 它是 MP 斜坡本身——纯噪声的确定形状。两个理由：$\beta$ 不小时坡太宽（$\beta = 0.25$ 已有 $[0.25, 2.25]$ 两倍带宽），坡上的「主成分」只是噪声方向；正确的警戒线是上边缘 $b$，超线才算信号。（§2.4）
