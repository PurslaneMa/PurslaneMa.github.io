# $\rm Chapter \, 4$ NP 完全性：Cook–Levin 与归约设计模式

第 3 章留下一个嫌疑名单：NP 里的问题彼此之间存在「一荣俱荣」的关系。本章证明这个关系真实存在，且名单有头目：SAT。头目之下，3SAT、CLIQUE、3 着色、子集和等难题经一条归约链与 SAT 连成一体，任何一个进了 P，全体跟着进 P。本章把链条上每一步都拿小实例真算一遍，最后提炼出可复用的归约设计套路。

## $\rm \S \, 4.1$ Cook–Levin：把计算历史写成布尔公式

**Cook–Levin 定理**：SAT 是 NP 完全的，即 SAT 属于 NP，且 NP 里任何语言都多项式归约到 SAT。SAT 属于 NP 由 §3.2 的验证者直接给出；全部难度在另一半：对 NP 里的任意语言 $L$ 与输入 $x$，要在多项式时间内构造一个公式 $\varphi_{L,x}$，使 $\varphi_{L,x}$ 可满足当且仅当 $x \in L$。

构造的原料是「表格式」的：把判定 $x$ 的整台机器的计算历史铺成一张二维表格。先数一数规模再动笔：时间步至多 $p(n)$，纸带格至多 $p(n)$ 个（机器每步至多走一格，用不到更远），符号集常数大小，于是布尔变量 $T_{t,q,s}$ 至多 $p(n) \times p(n) \times O(1)$ 个，多项式。规模这关一过，剩下的问题只有一个：怎么用子句把「表格是真的」说出来。行是时间步 $t = 0, 1, \ldots, p(n)$（$p$ 是 $L$ 的判定器的多项式时间界），列是纸带格的位置，格子内容是纸带符号。整张表有 $\mathrm{poly}(n)$ 行、$\mathrm{poly}(n)$ 列，每个格子内容取自固定符号集。为每个三元组 $(t, \text{位置}, \text{符号})$ 建一个布尔变量 $T_{t, q, s}$，含义是「第 $t$ 步第 $q$ 格是符号 $s$」。计算历史存在 $\iff$ 这张表能按机器规则填出来 $\iff$ 下列四组子句全部可满足：

1. **合法性**：每个位置 $(t, q)$ 上恰好一个符号成立。$(\bigvee_s T_{t,q,s})$ 保证至少一个，$(\bigwedge_{s \ne s'} \neg T_{t,q,s} \vee \neg T_{t,q,s'})$ 保证至多一个，两组子句对每个格子一份，总量多项式；
2. **初始格局**：$t = 0$ 行整行钉死为输入 $x$ 与初始状态，一组单元子句；
3. **接受**：某行某格出现接受状态，$\bigvee_{t, q} T_{t, q, \text{接受}}$ 一条子句；
4. **转移合法**：机器是局部的，第 $t+1$ 行的格子内容由第 $t$ 行的 $2 \times 3$ 邻域（自身格与左右邻）决定。枚举一切合法的「上窗口 $\to$ 下窗口」内容组合（组合总数只依赖符号集大小，是常数），把不合法的组合排除：对每种非法组合写一条子句禁止它同时出现。窗口个数是格子数，多项式。

四组子句的总量都是 $\mathrm{poly}(n)$，构造本身逐格扫描也只要多项式时间。读法上要把方向咬准：公式可满足 $\iff$ 存在一张全部合法的表 $\iff$ 存在一条导致接受的历史 $\iff x \in L$。 Cook–Levin 的全部魔法就是把「机器算得对」压缩成「每个窗口合乎转移表」，而窗口是常数大小的，多项式性由此保住。

「窗口合法」值得拿一台真机器看一眼。借第 1 章的二进制加 1 机器：它读到 $\mathrm{q_0}$、当前格 1 时抄写并右移。把这个转移翻译成窗口约束：若上行某连续三格是（$1$，$1\mathrm{q_0}$，$0$）这样的格局（中格带头、状态 $\mathrm{q_0}$），则下行对应三格必须是（$1$，$1$，$0\mathrm{q_0}$），即中格抄 1、带头右移一格。反过来，上行中格是 $\mathrm{q_0}$ 加 1、下行中格却变成 $\mathrm{q_1}$ 且带头没动，就违反转移表，对应子句禁止这种组合。全部转移表只有几条，每条展开成常数个禁止子句；整台机器的合法历史就是「每一步都过窗口检查」的表。加 1 机器太小看不出威力，换成跑 $p(n)$ 步的判定器，表格有 $\mathrm{poly}(n)$ 行，公式规模多项式，威力来自局部性而非机器大小。

## $\rm \S \, 4.2$ 归约链前两环：SAT $\to$ 3SAT $\to$ CLIQUE

头目到手，往下搬。3SAT 自己属于 NP（证书就是赋值，验证即逐子句核对，与 SAT 共用 §3.2 的验证者），所以「3SAT NP 完全」的两个方向里，难的是把别人归约进来。**3SAT** 只允许每个子句恰 3 个文字。归约按子句长短分派：超过 3 个文字的子句引新变量 $z$ 拆分，$(l_1 \vee l_2 \vee l_3 \vee l_4)$ 变为 $(l_1 \vee l_2 \vee z) \wedge (\neg z \vee l_3 \vee l_4)$。注意这里是**可满足性等价**而非逐点等价：原子句为真时可挑合适的 $z$ 让两段都真（$l_1$ 为真则取 $z$ 假），原子句为假时两段无论 $z$ 如何一真一假必有一段假。16 种赋值逐一核对（枚举 $l_1..l_4$ 与 $z$ 的全部取值，可满足性等价零分歧），不足 3 个文字的子句用重复文字补齐到 3 个。3SAT 落袋。

下一环 **CLIQUE**（图中有 $k$ 团）：给 3SAT 公式的每个子句造一组顶点，组内顶点一一对应子句的文字；两个顶点之间连边，当且仅当它们属于不同子句、且对应文字不互相矛盾（$x$ 与 $\neg x$ 不连边）。$k$ 取子句数。走一个 $k=3$ 的实例：$C_1 = (x_1 \vee \neg x_2)$，$C_2 = (\neg x_1 \vee x_2)$，$C_3 = (x_1 \vee x_2)$。顶点一共 6 个，按子句分组：

| 子句 | 顶点 | 与其他子句的连边 |
| --- | --- | --- |
| $C_1$ | $x_1$，$\neg x_2$ | $x_1$ 连 $x_2$（$C_2$）与 $C_3$ 全部，不连 $\neg x_1$（矛盾）；$\neg x_2$ 连 $\neg x_1$（$C_2$）、$x_1$（$C_3$），不连 $x_2$（矛盾） |
| $C_2$ | $\neg x_1$，$x_2$ | $\neg x_1$ 不连 $x_1$（$C_3$）；$x_2$ 连 $C_3$ 全部 |
| $C_3$ | $x_1$，$x_2$ | 组内不连边（同子句） |

枚举全部三角形，程序找到 2 个，且都投影到同一个赋值：

```python
for a, b, c in combinations(vertices, 3):        # 每子句取一个文字顶点
    if consistent(a, b) and consistent(b, c) and consistent(a, c):
        yield a, b, c                            # 三角形 <-> 满足赋值
```

两个三角形分别是 $\{x_1(C_1), x_2(C_2), x_1(C_3)\}$ 与 $\{x_1(C_1), x_2(C_2), x_2(C_3)\}$，都读出赋值 $x_1 = x_2 = \text{真}$，而这个公式恰好只有这一个满足赋值。正确性的两侧都清楚：三角形要求每子句贡献一个文字、彼此不矛盾，这正是一份满足赋值；满足赋值在每个子句里挑一个真文字，两两不同子句且真值一致，自然成团。k 团与满足赋值一一对应（投影意义下），归约成立。链条进度：SAT 到 3SAT 到 CLIQUE，每环一个 gadget 或一个列表，难度一路向北。

## $\rm \S \, 4.3$ 3COL：三角 gadget 的手算

**3 着色（3COL）**问一个图能否用 3 种颜色染所有顶点、使每条边两端异色。归约的道具是 gadget：用小图强行实现一个逻辑门。三件套：

1. **调色板**：三个顶点连成三角形，强制它们取遍 3 种颜色，命名真、假、基底；
2. **变量**：每个变量 $x_i$ 造一个顶点，与真、基底各连一条边。它被夹在真与基底之外，只能取假；与假、基底之外，只能取真。变量顶点的颜色就是真值；
3. **子句**：对子句 $(l_1 \vee l_2 \vee l_3)$ 造一个小子图（标准 OR-gadget，含 5 个辅助顶点），它 3 可着色当且仅当 $l_1, l_2, l_3$ 中至少一个顶点被染成真。方向反接时用 $\neg x_i$ 顶点染假表示 $x_i$ 取真。

gadget 的正确性验收要靠一个已知答案的小图。全连通 4 顶点图 $K_4$ 是最小的需要 4 种颜色的图：枚举全部着色，3 色下合法着色 0 种，4 色下 24 种（即 ${4!}$，四色各用一次）。手算口径：$K_4$ 任取 3 个顶点已构成三角形吃掉 3 种颜色，第 4 个顶点与三者都相邻，无色可用。竞赛生对这个事实的对应物：树永远 2 可着色、二分图判定就是 2 着色判定，而一般图 3 着色已是 NP 完全。着色问题在竞赛里的常态是搜索：$n \le 20$ 级别直接枚举 $3^n$ 或状压，更大规模靠题目给的特殊结构（区间图、弦图有多项式着色）。NP 完全性理论把这条经验线钉牢：没有结构可吃的 3 着色，不要指望多项式算法。OR-gadget 的内部结构也交代一句：5 个辅助顶点搭成一个对称小图，三个文字顶点各与 gadget 内若干顶点相连，迫使 gadget 内部出现一条「假链」；三个文字全为假时假链无处安放，至少一个文字为真时总有一种着色把链铺开。细节可在任何教材查到，竞赛里要带走的只有口径：gadget 的正确性靠枚举其常数种着色逐一核对，与 $K_4$ 的验收同一手法。

## $\rm \S \, 4.4$ SUBSET-SUM、三招与竞赛视角

**SUBSET-SUM**（子集和）：给定正整数集合与目标 $t$，问能否选出子集使其和恰为 $t$。归约把 3SAT 公式的赋值编码成十进制数字表：变量 $x_i$ 对应两个数 $y_i$（选它表示 $x_i$ 真）与 $z_i$（表示假），第 $i$ 位（变量位）各为 1，保证变量位恰好选一个；每个含 $x_i$ 的子句在 $y_i$ 的对应子句位上放 1（$z_i$ 对 $\neg x_i$ 同理）；每个子句位再配两个松弛数各贡献 1。目标数：变量位全是 1，子句位全是 3。子句位凑成 3 的途径只有「1 到 3 个被选中的真文字 + 合适数目的松弛」，0 个真文字时最多凑 2，凑不出 3，于是子集和存在当且仅当公式可满足；十进制各位互不进位（每位最大 3，远小于 10），数字表读法安全。真跑一个小实例：公式 $(x_1 \vee x_2 \vee x_3) \wedge (\neg x_1 \vee x_2 \vee x_3)$，造出的 10 个数与目标如下（5 位十进制，前 3 位是变量位，后 2 位是子句位）：

| 数字 | 编码 | 变量位 | 子句 1 位 | 子句 2 位 |
| --- | --- | --- | --- | --- |
| 10010 | $y_1$（$x_1$） | 1 | 1 | 0 |
| 10001 | $z_1$（$\neg x_1$） | 1 | 0 | 1 |
| 01011 | $y_2$（$x_2$） | 1 | 1 | 1 |
| 01000 | $z_2$（$\neg x_2$） | 1 | 0 | 0 |
| 00111 | $y_3$（$x_3$） | 1 | 1 | 1 |
| 00100 | $z_3$（$\neg x_3$） | 1 | 0 | 0 |
| 00010 / 00010 | $g_1, h_1$（松弛） | 0 | 1 | 0 |
| 00001 / 00001 | $g_2, h_2$（松弛） | 0 | 0 | 1 |
| 11133 | 目标 $t$ | 1 | 3 | 3 |

meet-in-the-middle 求解器找到子集 $\{z_1, y_2, y_3, g_1\}$，即 $10001 + 01011 + 00111 + 00010 = 11133$，读出赋值 $x_1 = \text{假}, x_2 = x_3 = \text{真}$，逐子句核对确实满足（子句 1 靠两个真文字加一个松弛凑 3，子句 2 靠三个真文字凑 3）；换上 3 变量全部 8 个完全子句的不可满足公式，同法造 22 个数，求解器报告无解。可满足性与子集和同起同落。

链走完了，回头提炼套路。归约设计三招：

1. **局部 gadget**：把一个逻辑概念（变量取值、子句判断）压进一个常数大小的小图或数字位，Cook–Levin 的 $2 \times 3$ 窗口、3COL 的调色板都是；
2. **选择＋一致性**：先造「每个变量二选一」的机制（变量位恰好选一个、变量顶点夹在两色之间），再造「选择之间互不打架」的机制（不矛盾才连边、子句位凑数）；
3. **放大与填充**：子句不足 3 个文字就重复文字补齐，时间不足多项式上界就填充哑步，把不规整的实例整形到链条需要的形状。

顺带把本章链条收拢成一句话：SAT、3SAT、CLIQUE、3COL、SUBSET-SUM 在链条方向上互相多项式归约，它们要么全体在 P，要么全体不在；这正是第 3 章「一荣俱荣」那句话的落地形态。

三招之外有一条元规则：归约必须保方向。本章所有构造都是「从 3SAT 到目标问题」，即 3SAT $\le$ 目标；写反了就把证明做成了「目标有解则 3SAT 有解」，对证明目标问题的难度毫无用处。检查方向的最快办法是看构造消费什么、生产什么：消费公式、生产图（或数字表），才是把难度往外搬。

竞赛视角收尾。拿到一道题，若它已知 NP 完全（或你把 SAT 归约了过去），多项式精确解基本无望，出路按优先级是：状压与搜索（$n \le 20$ 的指数档，§3.4）、近似算法（答案差个常数倍可接受时）、参数化（按某个小参数 $k$ 做 $f(k) \cdot n^{O(1)}$）、以及题目特殊性质。NPC 不是「此题放弃」的标签，它是「换武器」的信号。

## $\rm \S \, 4.7$ 本章自测答案

> 先闭卷作答 §4.5 与 §4.6，再核对。

### $\rm \S \, 4.7.1$ 关键概念回顾答案

1. 行是时间步 $t$，列是纸带格位置 $q$，格子内容是符号 $s$；$T_{t,q,s}$ 为真表示「第 $t$ 步第 $q$ 格是 $s$」。（§4.1）
2. 合法性管一格一符号，初始格局钉死第 0 行，接受子句要求某处出现接受状态，转移合法保证行间按转移表推进。机器是局部的，下一格只由当前 $2 \times 3$ 邻域决定，非法组合是常数多个。（§4.1）
3. $z$ 是拆分引的新变量，不对应原变量；可满足性等价指「两侧存在满足赋值」同真同假，逐点等价要求每个赋值下真值相同，拆分只保证前者。（§4.2）
4. 顶点来自子句中的文字（每子句一组），边连「不同子句且不矛盾」的文字对，$k$ 是子句数。（§4.2）
5. 调色板用三角形三边互异锁死三色；变量顶点与真、假、基底中的两个相连，只剩一色可选。（§4.3）
6. 变量位：$y_i$ 与 $z_i$ 二选一，目标和该位是 1，恰好凑成；子句位：被选真文字贡献 1 到 3，松弛数补足到 3，0 个真文字最多 2、凑不成。（§4.4）

### $\rm \S \, 4.7.2$ 应用与辨析答案

1. 保不住。窗口是常数大小，非法组合常数多、每格常数条子句；整行有 $\mathrm{poly}(n)$ 格，合法组合数指数级，逐个排除的子句数量爆炸，多项式性丢失。局部性是 Cook–Levin 的命根。（§4.1）
2. 2SAT 的归约目标可以从 2SAT 换成 3SAT 吗？不能：2 子句补齐到 3 文字需引新变量，而 2SAT 的多项式算法依赖子句恰 2 文字的性质，补齐后性质被破坏。归约链要求的形状恰好是它算法失效的形状。（§4.2）
3. 恰被 1 个真文字满足的子句：真文字贡献 1、单个松弛补 1，最多凑 2，够不到 4，明明可满足却报无解。目标 3 配两个松弛才能覆盖 1、2、3 三种真文字数。（§4.4）
4. 同子句顶点连边会允许三角形取自同一子句的三个文字，k 团不再对应「每子句一份选择」，归约两侧断裂；不连边则 k 团必然跨子句取样。（§4.2）
5. 不能。归约证明的是「它至少和 3SAT 一样难」，除非 $\mathrm{P} \ne \mathrm{NP}$ 被证明，不能排除它碰巧有 nobody 找到的多项式算法；能断言的只是「找到它就找到全部 NP」。（§4.4）
