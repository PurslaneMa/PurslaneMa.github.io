# $\rm Chapter \, 6$ 流形上的优化

优化问题的解常常天生住在流形上：PCA 的最优子空间住在 Grassmann 流形、机器人姿态住在 SE(3)、概率模型参数住在单纯形。在欧氏空间里硬解再投影，既浪费结构又容易跑出可行域。本章建立黎曼梯度下降的完整机制：切空间里算、流形上落（retraction），并用球面实验把每一步的账算清——具身智能册第 1 章的 SE(3) 与第 12 章（HP 册）Davis–Kahan 在此会师。

## $\rm \S \, 6.1$ 为什么优化要管流形

**例一（本章全程的实验床）**：在单位球面 $S^{n-1}$ 上最大化 $f(x) = a^{\mathsf T} x$——平凡问题的流形版。欧氏解 $x^* = a / |a|$；但若把「球面约束」当欧氏罚项硬解，梯度下降会在球面内外来回穿行，收敛拖沓。

**例二**：PCA——在全体 $k$ 维子空间（**Grassmann 流形** $\mathrm{Gr}(k, n)$）上最大化 Rayleigh 商（HP 册 §12.2）。子空间不构成向量空间（两个子空间的「和」跑出 $k$ 维），可行域天生是流形。

**白话**：约束不只是「限制」，是**几何**——把几何喂给优化器，而不是拿罚项硬顶，这就是流形优化的全部动机。

## $\rm \S \, 6.2$ 黎曼梯度（本章主证一）

欧氏梯度 $\nabla f$ 未必是流形上的「上坡方向」——它可能指向流形外面。**黎曼梯度**＝欧氏梯度在切空间的投影：

$$
\mathrm{grad}\, f(p) = P_p\, \nabla f(p), \qquad P_p v = v - g_p(v, \cdot)\text{ 的对偶修正（诱导情形即正交投影）}
$$

**球面全证**：$S^{n-1} \subset \mathbb{R}^n$ 诱导度量，$T_x S^{n-1} = \{v : v^{\mathsf T} x = 0\}$（第 2 章 §2.2）。$f(x) = a^{\mathsf T}x$ 的欧氏梯度是 $a$；把它正交投影到切空间：

$$
\mathrm{grad}\, f(x) = a - (a^{\mathsf T} x)\, x
$$

（$v = a - \lambda x$ 要求 $v^{\mathsf T} x = 0$ ⟹ $\lambda = a^{\mathsf T} x$。）**读法**：切向分量才是「站在球面上能走的上坡」，法向分量（$-（a^{\mathsf T}x)x$）是「被球面顶住的白费劲」——黎曼梯度把白费劲剪掉。

**第二个例：$\mathrm{SO}(3)$ 上 $f(R) = \mathrm{tr}(R_0^{\mathsf T}R)$ 的黎曼梯度**（接第 3 章 §3.2：切空间 $=$ 李代数）。给定参考旋转 $R_0$，找与它最对齐的旋转——$f$ 的最大值点就是 $R = R_0$（$f = \mathrm{tr}(I) = 3$）。第 3 章已算过 $T_R\,\mathrm{SO}(3) = \{R\Omega : \Omega^{\mathsf T} = -\Omega\}$（切向量长成「旋转乘反对称」）。Frobenius 内积 $\langle A, B\rangle = \mathrm{tr}(A^{\mathsf T}B)$ 下欧氏梯度是 $\nabla f = R_0$（线性函数的梯度就是系数矩阵本身）。投影要找 $\mathrm{grad}\,f = R\Omega_*$，使对一切反对称 $\Omega$ 成立 $\langle R\Omega_*, R\Omega\rangle = \langle R_0, R\Omega\rangle$。正交的 $R$ 可以从内积里提出来（$\langle RA, RB\rangle = \langle A, B\rangle$），于是条件变成 $\langle \Omega_*, \Omega\rangle = \langle R^{\mathsf T}R_0, \Omega\rangle$ 对一切反对称 $\Omega$ 成立。关键一步：反对称矩阵「看不见」对称分量——对称阵 $S$ 与反对称阵 $\Omega$ 的迹内积为零（$\mathrm{tr}(S\Omega) = -\mathrm{tr}(S\Omega)$，转置一下即见）。所以只取反对称部分：

$$
\Omega_* = \mathrm{skew}(R^{\mathsf T}R_0) = \frac{R^{\mathsf T}R_0 - R_0^{\mathsf T}R}{2}, \qquad \mathrm{grad}\,f(R) = R\,\mathrm{skew}(R^{\mathsf T}R_0) = \frac{R_0 - R\,R_0^{\mathsf T}R}{2}
$$

（$\mathrm{skew}(S)$ 读作「取反对称部分」；末步展开 $R \cdot \frac{R^{\mathsf T}R_0 - R_0^{\mathsf T}R}{2} = \frac{R_0 - RR_0^{\mathsf T}R}{2}$。）**读法**：球面例投影「剪掉法向」，这里剪掉 $R_0$ 中「试图把 $R$ 拽离正交」的对称分量——流形换了一个，投影的戏码一模一样。数值验证（固定随机种子生成两个旋转 $R_0, R$，纯 NumPy 实跑）：

1. 切空间检查：$\|R^{\mathsf T}\mathrm{grad}\,f + (R^{\mathsf T}\mathrm{grad}\,f)^{\mathsf T}\|_{\max} = 1.1 \times 10^{-16}$——黎曼梯度确实落在切空间（反对称到机器精度）；
2. 李代数形态：$R^{\mathsf T}\mathrm{grad}\,f$ 与 $\mathrm{skew}(R^{\mathsf T}R_0)$ 逐元素最大偏差 $1.1 \times 10^{-16}$——体坐标（第 3 章 §3.4 的随体观点）下梯度就是李代数向量；
3. 方向导数对账：沿曲线 $R(t) = R(I + t\Omega)$（$\Omega$ 随机反对称，一阶相合于切向）取中心差商（$\varepsilon = 10^{-7}$）得 $-1.68255517$，与解析值 $\langle \mathrm{grad}\,f, R\Omega\rangle = -1.68255517$ 相差 $2.1 \times 10^{-11}$——投影定义与求导定义逐位吻合；
4. 梯度上升实测：$f$ 从 $0.038299$ 出发，步长 $0.1$、retraction 取 $R^+ = R\exp(\tau\Omega_*)$（第 3 章 §3.3 的 Rodrigues 指数），$60$ 步后 $f = 2.999674$，且 $\|R - R_0\|_F = 9.28 \times 10^{-3}$——收敛到最大值点 $R_0$ 本尊。

## $\rm \S \, 6.3$ Retraction：从切空间回到流形

沿切向方向走一步 $p + \tau v$ 会离开流形，需要一张「回 map」：**retraction** $R_p(v)$ 满足 $R_p(0) = p$、一阶相合 $\frac{\mathrm{d}}{\mathrm{d}\tau}\big|_0 R_p(\tau v) = v$。两个常用选项：

1. **测地线回**（几何精确）：$R_p(v) = \exp_p(v)$（第 4 章指数映射）；
2. **投影回**（工程便宜）：$R_p(v) = \frac{p + v}{|p + v|}$（球面情形）——一步归一化，比测地线便宜得多、一阶相合照样成立（Taylor 展开 $|p + \tau v| = 1 + O(\tau^2)$，切向速度一阶无损）。

**数值对比：同一方向，两种落点差多远**。取 $p = \frac{1}{\sqrt{3}}(1, 1, 1)$、单位切向 $w$（固定随机种子），沿 $w$ 走距离 $\tau$：测地回落点 $\exp_p(\tau w) = \cos\tau \cdot p + \sin\tau \cdot w$（第 4 章球面指数映射的显式公式），投影回落点 $\frac{p + \tau w}{|p + \tau w|}$。两落点的球面距离 $\arccos(\langle \cdot, \cdot \rangle)$ 实跑：

| $\tau$ | 测地回落点 | 投影回落点 | 两者距离 | $\frac{\tau^3}{6}$ |
| --- | --- | --- | --- | --- |
| 0.1 | (0.508665, 0.565701, 0.649032) | (0.508901, 0.565749, 0.648805) | $3.31 \times 10^{-4}$ | $1.67 \times 10^{-4}$ |
| 0.5 | (0.190680, 0.464580, 0.864758) | (0.221636, 0.477133, 0.850424) | $3.64 \times 10^{-2}$ | $2.08 \times 10^{-2}$ |
| 1.0 | (-0.242676, 0.238064, 0.940443) | (-0.057811, 0.346165, 0.936391) | $0.2146$ | $0.1667$ |
| 2.0 | (-0.839587, -0.320097, 0.438897) | (-0.331325, 0.179670, 0.926252) | $0.8929$ | $1.3333$ |

**读法**：小步长时两落点差是 $O(\tau^3)$——$\tau = 0.1$ 时差三万分之三弧度、与 $\frac{\tau^3}{6}$ 同量级，这就是「二阶以内等价」的账面：一阶相合保证两种 retraction 在梯度下降的收敛理论里同价，差别只进三阶项。$\tau$ 大起来差距拉开（$\tau = 2$ 差近一弧度），连 $\frac{\tau^3}{6}$ 估计也失效——投影回省下的计算是真的，丢掉的精度藏在远步长里；步长一节（§6.4）会看到实用的 $\tau$ 都在一阶区。

## $\rm \S \, 6.4$ 黎曼梯度下降与球面实验（本章主证二）

**算法**：$p_{k+1} = R_{p_k}\big(-\tau\, \mathrm{grad}\, f(p_k)\big)$（下降版）。

**球面实验**（全数值锚，本机实测）：$f(x) = a^{\mathsf T} x$、$a = (0, 0, 1)$、初值 $x_0 = (\frac{\sqrt2}{2}, 0, \frac{\sqrt2}{2})$、步长 $0.02$：

1. **上升流**（$x \leftarrow \mathrm{normalize}(x + 0.02\, \mathrm{grad})$）300 步终点 $(0.00194,\ 0,\ 0.999998)$——收敛到 $a/|a|$，即 $f$ 的最大值点（$\arccos$ 视角：从 ${45°}$ 纬度爬到北极）。
2. **梯度范数衰减**：$\|\mathrm{grad}\, f\| = \sqrt{1 - (a^{\mathsf T}x)^2}$（解析：投影的模 $= |a|\sin(\text{夹角})$）随迭代从 $\frac{\sqrt2}{2}$ 单调滑向 0——与轨迹逐点吻合。
3. **下降流**对称地收敛到 $(0, 0, -1)$——同一算法换个符号找最小。

**读法**：黎曼梯度下降 = 欧氏梯度下降 + 每步「剪掉法向 + 拉回流形」；收敛理论与欧氏版平行（对 geodesic 凸函数线性收敛，陈述级，标 Absil–Mahony–Sepulchre《Optimization Algorithms on Matrix Manifolds》2008）。

**完整收敛实验：步长三档的 $f$ 值轨迹表**。设定照旧（$f(x) = a^{\mathsf T}x$、$a = (0, 0, 1)$、$x_0 = (\frac{\sqrt2}{2}, 0, \frac{\sqrt2}{2})$、投影回），步长拉成 $0.02 / 0.1 / 0.5$ 三档、跑满 $20$ 轮。可跑实验段（纯 Python、纯 NumPy，数值实跑照抄）：

```python
import numpy as np

def descend(tau, niter=20):
    x = np.array([np.sqrt(2)/2, 0.0, np.sqrt(2)/2])
    vals = [x[2]]
    for _ in range(niter):
        g = np.array([0.0, 0.0, 1.0]) - x[2] * x   # 黎曼梯度
        x = x + tau * g
        x /= np.linalg.norm(x)                      # 投影回
        vals.append(x[2])
    return vals

for tau in (0.02, 0.1, 0.5):
    v = descend(tau)
    print(f"tau={tau}: " + " ".join(f"{v[i]:.6f}" for i in (0, 1, 2, 4, 8, 12, 16, 20)))

# 步长 1.2：看 x 坐标的符号振荡（过冲 = 跳过北极落到对侧）
x = np.array([np.sqrt(2)/2, 0.0, np.sqrt(2)/2])
for k in range(3):
    g = np.array([0.0, 0.0, 1.0]) - x[2] * x
    x = x + 1.2 * g
    x /= np.linalg.norm(x)
    print(f"tau=1.2 step {k+1}: x=({x[0]:+.6f}, {x[1]:+.1f}, {x[2]:.6f})")
```

实跑输出（$f$ 值按轮数 $k = 0, 1, 2, 4, 8, 12, 16, 20$ 抽样）：

| $k$ | $\tau = 0.02$ | $\tau = 0.1$ | $\tau = 0.5$ |
| --- | --- | --- | --- |
| 0 | 0.707107 | 0.707107 | 0.707107 |
| 1 | 0.717035 | 0.755221 | 0.902369 |
| 2 | 0.726682 | 0.796476 | 0.972903 |
| 4 | 0.745147 | 0.861050 | 0.998241 |
| 8 | 0.778899 | 0.937413 | 0.999993 |
| 12 | 0.808680 | 0.972507 | 1.000000 |
| 16 | 0.834829 | 0.988060 | 1.000000 |
| 20 | 0.857691 | 0.994840 | 1.000000 |

$20$ 轮末的梯度范数：$\tau = 0.02$ 时 $0.514$（几乎没动）、$\tau = 0.1$ 时 $0.1015$、$\tau = 0.5$ 时 $9.06 \times 10^{-7}$——三档差出六个数量级，步长的杠杆作用一览无余。**过冲现象**：$f$ 的上限是 $1$，过冲在 $f$ 轨迹上看不出来，得看轨迹坐标——步长加到 $1.2$ 实跑，$x$ 坐标逐轮变号：第 1 轮冲到 $(+0.0817, 0, 0.9967)$（离北极只剩 $0.08$ 弧度）、第 2 轮越过北极落到对侧 $(-0.0159, 0, 0.9999)$、第 3 轮折回 $(+0.0032, 0, 0.99999)$——此后在两侧之间振荡衰减。**读法**：完全复现欧氏梯度下降的步长直觉（机器学习册第 3 章：小步稳而慢、大步快而险）；流形版的新花样是过冲不表现为「目标值越界」（球面把它折叠掉了），而是**绕过极点跳到对侧**——几何把越界翻译成了绕行。

## $\rm \S \, 6.5$ 主战场一瞥：Grassmann 与 Stiefel

1. **Stiefel 流形** $\mathrm{St}(k, n) = \{X \in \mathbb{R}^{n \times k} : X^{\mathsf T} X = I\}$——正交列矩阵全体（球面的矩阵推广）；切空间 $X^{\mathsf T} V + V^{\mathsf T} X = 0$（约束求导），retraction 常用 ${QR}$ 分解。
2. **Grassmann 流形** $\mathrm{Gr}(k, n) = \mathrm{St}(k,n) / O(k)$（子空间不管标架）；PCA、子空间跟踪、鲁棒低秩恢复（Robust PCA）的主场。
3. **SE(3) 上的位姿优化**：具身智能册第 1 章、第 3 章 iLQR 的几何底座——李群优化的「不定参数化不出有效解」教训（第 1 章 §1.6）在这里变成 retraction 的必要性。
4. **一个能落地的完整例子：正交 Procrustes 问题**。$\min \|AX - B\|_F$ s.t. $X^{\mathsf T}X = I$，$A \in \mathbb{R}^{3 \times 3}$ 取正交阵、$B \in \mathbb{R}^{3 \times 2}$、$X \in \mathrm{St}(2, 3)$——「把点云 $B$ 刚性对齐到点云 ${AX}$」的姿态配准原型。展开范数：$\|AX - B\|_F^2 = \mathrm{tr}(X^{\mathsf T}A^{\mathsf T}AX) - 2\,\mathrm{tr}(X^{\mathsf T}A^{\mathsf T}B) + \|B\|_F^2$，而 $A$ 正交时首项 $= \mathrm{tr}(X^{\mathsf T}X) = 2$ 与 $X$ 无关，于是问题等价于在 Stiefel 流形上**极大化** $\mathrm{tr}(X^{\mathsf T}M)$（$M = A^{\mathsf T}B$）。谱定理收尾：对 $M$ 做 SVD $M = U\Sigma V^{\mathsf T}$（$\Sigma = \mathrm{diag}(\sigma_1, \sigma_2)$），最优解 $X^* = UV^{\mathsf T}$ 给出 $\mathrm{tr}({X^*}^{\mathsf T}M) = \sigma_1 + \sigma_2$（von Neumann 迹不等式的陈述级应用：正交标架能吸走的迹至多是奇异值之和），故极小值

$$
\min \|AX - B\|_F = \sqrt{2 + \|B\|_F^2 - 2(\sigma_1 + \sigma_2)}
$$

数值例（$A$ 固定为随机旋转、$B = \begin{pmatrix} -1.265421 & -0.623274 \\ 0.041326 & -2.325031 \\ -0.218792 & -1.245911 \end{pmatrix}$，纯 NumPy 实跑）：$M = A^{\mathsf T}B$ 的奇异值 $\sigma_1 = 2.739646$、$\sigma_2 = 1.221370$；SVD 解处 $\|AX^* - B\|_F = 1.753674$，与公式 $\sqrt{2 + 8.997402 - 2 \times 3.961015} = 1.753674$ 逐位一致；对账 $\mathrm{tr}({X^*}^{\mathsf T}M) = 3.961015 = \sigma_1 + \sigma_2$ ✓。**读法**：最小残差由「吸不到的奇异值质量」决定——SVD 不只给 PCA（§6.1 例二），还直接给出流形优化的精确极小值。

## $\rm \S \, 6.8$ 本章自测答案

1. PCA：可行域是子空间集合（Grassmann 流形），不是欧氏凸集。（§6.1）
2. 黎曼梯度＝欧氏梯度切向投影；球面 $\mathrm{grad} = a - (a^{\mathsf T}x)x$。（§6.2）
3. $R_p(0) = p$、一阶相合；测地线回与投影回（球面归一化）。（§6.3）
4. 上升流 300 步到 $(0, 0, 1)$（锚 0.999998）；梯度范数 $\sqrt{1 - (a^{\mathsf T}x)^2}$ 单调衰减；下降流对称到 $(0,0,-1)$。（§6.4）
5. Stiefel 是正交标架全体、Grassmann 是其 $O(k)$ 商（忘掉标架只记子空间）。（§6.5）
6. 前者定界「目标子空间离真值多远」，后者给「迭代路线」——分析与算法互补。（§6.6）
7. $\mathrm{grad}\,f(R) = R\,\mathrm{skew}(R^{\mathsf T}R_0) = \frac{R_0 - RR_0^{\mathsf T}R}{2}$：切向都是反对称的，与反对称矩阵迹内积为零的对称分量是白费劲，剪掉后只剩反对称部分。（§6.2）
8. 三阶：$\tau = 0.1$ 时两落点差 $3.31 \times 10^{-4}$ 弧度、与 $\frac{\tau^3}{6} = 1.67 \times 10^{-4}$ 同量级——一阶收敛的步长范围内两种 retraction 同价，差别只进三阶。（§6.3）
9. 对 $M = A^{\mathsf T}B$ 做 SVD，最优解 $X^* = UV^{\mathsf T}$，极小值 $\sqrt{2 + \|B\|_F^2 - 2(\sigma_1 + \sigma_2)}$；本例 $\sigma_1 + \sigma_2 = 3.961015$、最优值 $1.753674$。（§6.5）
