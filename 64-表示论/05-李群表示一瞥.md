## $\rm \S \, 5.1$ 从有限到连续：李群与李代数速览

白话：有限群的表示论靠两根柱子——对群元素求和（群代数、正则表示）与共轭类分桶（特征标正交）。连续群里这两根柱子都断了：求和变成积分（对紧群还行，对非紧群要操心收敛）、共轭类从有限个桶变成连续统。但连续性送来一件新工具：**群结构被无穷小处的一阶信息编码**——这就是李代数。说白了，李代数是李群的「本地方言」：在单位元附近把群操作线性化，弯曲的整体被平直的局部代替，而（对连通群）局部方言能听出整体故事。

定义来了。**李群** $G$ 是一个群，同时是光滑流形，且乘法 $(g, h) \mapsto gh$ 与求逆 $g \mapsto g^{-1}$ 都是光滑映射。本章的两个主角：

1. $SO(3)$：$\mathbb{R}^3$ 的保持定向、保持内积的线性变换群，即 $3\times 3$ 实矩阵满足 $R^{\mathsf T} R = I$ 且 $\det R = 1$——三维空间里的旋转；
2. $SU(2)$：$2\times 2$ 复矩阵满足 $U^\dagger U = I$ 且 $\det U = 1$——二维复空间上的行列式一酉变换。

**李代数** $\mathfrak{g}$ 是 $G$ 在单位元处的切空间，配上换位括号 $[X, Y] = XY - YX$（矩阵群的情形就是矩阵换位子）。它为什么是「无穷小的群」？关键观察：把一条过单位元的曲线 $g(t)$（$g(0) = e$）写出来，切向量 $X = g'(0)$ 满足的约束是线性的。对 $SO(3)$：把 $R(t)^{\mathsf T} R(t) = I$ 在 $t = 0$ 求导，得 $X^{\mathsf T} + X = 0$——李代数 $\mathfrak{so}(3)$ 是全体 $3\times 3$ 反对称实矩阵；对 $SU(2)$：把 $U(t)^\dagger U(t) = I$ 与 $\det U(t) = 1$ 求导，得 $\mathfrak{su}(2) = \{X : X^\dagger + X = 0,\ \mathrm{tr}\, X = 0\}$——反厄米无迹矩阵。两个李代数都由三个基撑起：

$$
\mathfrak{so}(3):\quad
L_1 = \begin{pmatrix} 0 & 0 & 0 \\ 0 & 0 & -1 \\ 0 & 1 & 0 \end{pmatrix},\;
L_2 = \begin{pmatrix} 0 & 0 & 1 \\ 0 & 0 & 0 \\ -1 & 0 & 0 \end{pmatrix},\;
L_3 = \begin{pmatrix} 0 & -1 & 0 \\ 1 & 0 & 0 \\ 0 & 0 & 0 \end{pmatrix}
$$

（读法：$L_k$ 是绕第 $k$ 个坐标轴的无穷小旋转——$\exp(\theta L_k)$ 正是绕 $k$ 轴转 $\theta$ 角的旋转矩阵。）$\mathfrak{su}(2)$ 的三个基取 $E_k = -\tfrac{i}{2}\sigma_k$，其中 $\sigma_1, \sigma_2, \sigma_3$ 是 Pauli 矩阵：

$$
\sigma_1 = \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix},\quad
\sigma_2 = \begin{pmatrix} 0 & -i \\ i & 0 \end{pmatrix},\quad
\sigma_3 = \begin{pmatrix} 1 & 0 \\ 0 & -1 \end{pmatrix}
$$

（读法：Pauli 矩阵是厄米无迹的，乘上 $-i/2$ 后变反厄米无迹，落进 $\mathfrak{su}(2)$；物理书里常写 $\mathrm{U}(\theta) = \exp(-i\theta\, \boldsymbol{\sigma}\cdot \boldsymbol{n}/2)$，就是这里的指数映射。）两套括号的关系可以逐对验算，结论是**同构**：把 $L_k$ 对应到 $E_k$，换位括号逐对匹配，即

$$
\mathfrak{su}(2) \;\cong\; \mathfrak{so}(3)
$$

（读法：$SU(2)$ 与 $SO(3)$ 在「无穷小」层面分不清——李代数相同的两个群，整体可以不同，差别是下一节的主角。）

李代数与李群表示的桥是**指数映射** $\exp: \mathfrak{g} \to G$。对矩阵群它就是矩阵指数；$\exp$ 把李代数的加法结构（近似地）搬到群上，精确说法是交换子的指数公式 $\exp X \exp Y \exp(-X)\exp(-Y) \approx \exp[X, Y]$（小 ${X, Y}$ 时的一阶近似，精确式含修正项）。表示论上真正要记的一条是：**连通单连通李群的光滑表示与它的李代数表示一一对应**——$SU(2)$ 恰好单连通（它是三维球面 $S^3$，见下节），于是研究它的表示可以整个搬到 $\mathfrak{su}(2)$ 上做，而李代数表示是线性代数问题。这条「降维打击」是李群表示论能发展下去的根本原因。

**本节小结**：李群是光滑的群；李代数是单位元处的切空间加换位括号，是群的无穷小编码；$\mathfrak{su}(2) \cong \mathfrak{so}(3)$ 由 Pauli 矩阵与反对称矩阵逐对验算；单连通性让李群表示退化成李代数表示。下一节看这两个群在「整体」层面差在哪。

## $\rm \S \, 5.2$ $SU(2)$ 与 $SO(3)$ 的双覆盖

白话：$\mathfrak{su}(2) \cong \mathfrak{so}(3)$ 说两个群「无穷小处一样」，但 $SU(2)$ 是 $2\times 2$ 复矩阵群、$SO(3)$ 是 $3\times 3$ 实矩阵群，尺寸都不同，怎么可能相同？答案：$SU(2)$ 是 $SO(3)$ 的**两倍大的拷贝**——存在一个满同态 $\Phi: SU(2) \to SO(3)$，恰好两对一：每个旋转对应**两个** $SU(2)$ 矩阵，像影子和人。本节把这个映射造出来并精确算出它的核。

构造走共轭路线。任取 $U \in SU(2)$，定义

$$
\Phi(U): \mathfrak{su}(2) \to \mathfrak{su}(2), \qquad X \mapsto UXU^{-1}
$$

（读法：$U$ 作用在自己李代数上的共轭——李代数是三维实向量空间，共轭是线性、保括号的，所以 $\Phi(U)$ 落在 $\mathfrak{su}(2)$ 的线性变换群里。）关键步骤两步。第一步，$\Phi(U)$ 保内积：$\mathfrak{su}(2)$ 上有天然内积 $\langle X, Y\rangle = -2\,\mathrm{tr}(XY)$（厄米矩阵的迹内积的符号修正版），共轭保迹所以保内积，于是 $\Phi(U) \in O(\mathfrak{su}(2)) \cong O(3)$；再由 $SU(2)$ 连通且 $\Phi(e) = I$，行列式只能恒正，得 $\Phi(U) \in SO(3)$。第二步，数核：$UXU^{-1} = X$ 对一切 $X \in \mathfrak{su}(2)$ 成立当且仅当 $U$ 与所有 $E_k$ 交换，逐个验算 $\sigma_k$ 的交换关系可知只有 $U = \pm I$。

于是 $\Phi$ 是满同态、核为 $\{\pm I\}$——**$SU(2)$ 是 $SO(3)$ 的二重覆盖群**。这句话有一个可以真算的、也值得真算的具体化身：绕 $z$ 轴的旋转在 $SU(2)$ 里对应的矩阵是

$$
\mathrm{U}(\theta) \;=\; \exp\Big( -\,\frac{i\theta}{2}\,\sigma_3 \Big) \;=\; \begin{pmatrix} \mathrm{e}^{-i\theta/2} & 0 \\ 0 & \mathrm{e}^{i\theta/2} \end{pmatrix}
$$

（读法：指数映射按对角矩阵逐项展开，$\mathrm{e}^{\pm i\theta/2}$ 是两个特征方向各自转的相位。）把 $\theta$ 从 $0$ 转到 $4\pi$，数值逐点验证（本章数值锚，照抄自 numpy 实跑）：

1. $\theta = \pi$：$\mathrm{U}(\pi) = \begin{pmatrix} -i & 0 \\ 0 & i \end{pmatrix} = -i\,\sigma_3$，对应 $SO(3)$ 里绕 $z$ 轴转 $\pi$；
2. $\theta = 2\pi$：$\mathrm{U}(2\pi) = -I$——**转过一整圈，$SU(2)$ 里的矩阵变成自己的负的**，而 $\Phi(-I) = I$，$SO(3)$ 里恰好回到单位元；
3. $\theta = 4\pi$：$\mathrm{U}(4\pi) = I$——转两圈才回到原样。

（读法：指数里的因子 $1/2$ 就是「两倍」的来源——$SO(3)$ 的角 $\theta$ 在 $SU(2)$ 里要用 $\theta/2$ 拧，$SO(3)$ 转 $2\pi$ 时 $SU(2)$ 只走了半程 $-I$。）「转两圈才回家」不是数学戏言：拓扑上 $SU(2) \cong S^3$（单位四元数球面）是单连通的，$SO(3) \cong S^3/\{\pm 1\}$（三维射影空间）有一条不可收缩的圈——绕轴转 $2\pi$ 的那一条——它提升到 $S^3$ 上是不闭合的路径，要 $4\pi$ 才闭合。量子力学一册（本站第 14 册）的出口处会看到它的物理肉身：自旋 $1/2$ 粒子的波函数转 $2\pi$ 变 $-\psi$，转 $4\pi$ 才复原。

**本节小结**：共轭作用造出满同态 $\Phi: SU(2) \to SO(3)$，核 $\{\pm I\}$，二对一；数值上表现为 $\mathrm{U}(2\pi) = -I$、$\mathrm{U}(4\pi) = I$。下一节在这个基础上定义连续群的表示并清点 $SU(2)$ 的全部不可约表示——自旋就在那里。

## $\rm \S \, 5.3$ 连续表示与自旋：$SU(2)$ 的完整清单

定义先行。李群 $G$ 的**（光滑）表示**是光滑同态 $\rho: G \to GL(V)$，$V$ 是复向量空间；对紧群（$SO(3)$、$SU(2)$ 都是）可以用不变内积的平均化把 $\rho$ 设成酉的——有限群情形「对群元素平均」的技巧换成「对群流形积分」，本册第 1、2 章的整套语言（不可约分解、Schur 引理、特征标正交）逐条照搬，只是求和换积分。$G$ 的**特征标**定义为 $\chi_\rho(g) = \mathrm{tr}\,\rho(g)$。

$SU(2)$ 的不可约表示清单短得迷人：**每个非负半整数 $j \in \{0, \tfrac{1}{2}, 1, \tfrac{3}{2}, \ldots\}$ 恰有一个**，记作 $V_j$，维度

$$
\dim V_j \;=\; 2j + 1
$$

（读法：$j = 0$ 是平凡表示、$j = \tfrac{1}{2}$ 是 $SU(2)$ 在 $\mathbb{C}^2$ 上的天然作用、$j = 1$ 是 $SO(3)$ 在 $\mathbb{R}^3$ 上的旋转作用复化后的样子；物理词汇里 $j$ 叫**自旋量子数**，$V_j$ 叫**自旋 $j$ 表示**。）清单的「存在」半边有个一行的构造：$V_j = \mathrm{Sym}^{2j}(\mathbb{C}^2)$——取 $\mathbb{C}^2$ 的 ${2j}$ 次对称幂（$2j+1$ 维），$SU(2)$ 天然地作用在上面，可验证它不可约；「唯一」半边要 Schur 引理加一点权分析，§5.4 的最高权语言正是它的干净版本。

$SO(3)$ 的清单是这份清单的一个子集：**只有整数 $j$ 的 $V_j$**。为什么半整数的被剔掉？一步关键论证：把 $SO(3)$ 的表示 $\rho$ 沿 $\Phi$ 拉回，就得到 $SU(2)$ 的一个表示，而凡是 $\Phi$ 映到 $SO(3)$ 单位元的元素都必须在这个拉回表示下平凡作用；$\mathrm{U}(2\pi) = -I$ 恰好是这种元素（$\Phi(-I) = I$），但它在 $V_j$ 上的作用是 $(-1)^{2j} I$——$j$ 半整数时这是 $-I \ne I$，矛盾。换句话说：

$$
SO(3) \text{ 的不可约表示} \;=\; \{\, V_j : j \in \mathbb{Z}_{\ge 0} \,\}, \qquad SU(2) \text{ 多出} \;\{\, V_j : j \in \tfrac{1}{2}\mathbb{Z}_{\ge 0} \text{ 半整数部分} \,\}
$$

（读法：半整数自旋表示是 $SU(2)$ 的私产——它感知不到双覆盖的粘合缝；想表示 $SO(3)$ 本身，表示必须对 $\pm I$ 一视同仁，即 $j$ 是整数。物理里「轨道角动量 $j$ 整数、自旋可半整数」这句话的数学根就在这。）

特征标也有闭式。绕 $z$ 轴转 $\theta$ 时，$V_j$ 上的作用有 $2j+1$ 个权 $m = j, j-1, \ldots, -j$，各贡献相位 $\mathrm{e}^{im\theta}$，求和得

$$
\chi_j(\theta) \;=\; \sum_{m=-j}^{j} \mathrm{e}^{im\theta} \;=\; \frac{\sin\big((2j+1)\,\theta/2\big)}{\sin(\theta/2)}
$$

（读法：等比级数求和；分母是权间隔的几何级数公比。）两头的价可以真算核对：$j = 1$ 时 $\chi_1(\theta) = 1 + 2\cos\theta$——它必须等于三维旋转矩阵的迹（本站微分几何与李群册算过旋转矩阵的谱：$1$ 加二维旋转块的两个特征值）；$j = \tfrac{1}{2}$ 时 $\chi_{1/2}(\theta) = 2\cos(\theta/2)$——正是 $\mathrm{U}(\theta)$ 的迹。取 $\theta = \pi/5$ 数值验证（numpy 实跑）：旋转矩阵迹 $\mathrm{tr}\, R_z(\pi/5) = 2.6180339887 = 1 + 2\cos(\pi/5)$，$\mathrm{tr}\, \mathrm{U}(\pi/5) = 1.9021130326 = 2\cos(\pi/10)$，与公式逐位一致。注意 $j$ 换成 $j + 1$ 时 $\chi$ 的分子换号、分母也换号，商不变——$\chi_j(2\pi) = (-1)^{2j}(2j+1)$，半整数表示在 $2\pi$ 处取负，这正是 §5.2 的 $-I$ 在特征标上的指纹。

**本节小结**：紧李群的表示论照抄有限群语法；$SU(2)$ 不可约表示被半整数 $j$ 完整编目、维度 $2j+1$、特征标是等比级数和；$SO(3)$ 只收整数 $j$，剔除的机械原因是核 $\{\pm I\}$ 必须平凡作用。下一节把「权」这个词说清楚，并望一眼一般李群的高塔。

## $\rm \S \, 5.4$ 张量积分解与最高权思想一览

表示多了，就要问组合规律。两个表示的张量积 $V \otimes W$（对角作用 $g(v \otimes w) = gv \otimes gw$）一般可约，分解它就是**Clebsch–Gordan 问题**。$SU(2)$ 的答案是最干净的「加法」：

$$
V_j \otimes V_k \;=\; \bigoplus_{l = |j-k|}^{j+k} V_l
$$

（读法：自旋 $j$ 与自旋 $k$ 耦合，总自旋 $l$ 从 $|j-k|$ 到 $j+k$ 逐个取值；维度账随时可查：左边 $(2j+1)(2k+1)$，右边 $\sum_l (2l+1)$，两边总相等。）最小的两个例子值得背下来：

1. $V_{1/2} \otimes V_{1/2} = V_1 \oplus V_0$：两个自旋 $1/2$ 耦合成一个三重态加一个单态——量子力学里两个电子的自旋配对，$3 + 1 = 2 \times 2$；
2. $V_1 \otimes V_1 = V_2 \oplus V_1 \oplus V_0$：维度 $3 \times 3 = 5 + 3 + 1 = 9$。

第二条不是背的，是真算的：把两个自旋 $1$ 系统的角动量算符铺成 $9\times 9$ 矩阵、对角化总角动量平方 $J^2 = J_x^2 + J_y^2 + J_z^2$，特征值是 $j(j+1)$，$9$ 个特征值落在 $\{6, 2, 0\}$ 上、简并度恰为 ${5,3,1}$（§5.5 程序段照抄）。这个分解在物理里就是**角动量耦合**——下一章的物理出口全压在它身上。

分解为什么长这个形状？把镜头推到无穷小处看。李代数 $\mathfrak{su}(2)$ 的表示里，$E_3$（乘 $i$ 后厄米化即 $J_z$）可对角化，特征值叫**权**；升降算符 $E_1 \pm iE_2$（即 $J_\pm$）把权沿整数台阶上下搬；权链必有顶——**最高权**，即被 $E_+$ 打死的那个向量。于是不可约表示被最高权完整编号：$SU(2)$ 的最高权恰是 ${2j}$（非负整数），这解释了清单的唯一性半边。三条平行线摆在同一张纸上：

1. $S_n$：划分编目不可约表示，钩长公式给维度（本册第 4 章）；
2. $SU(2)$：最高权编目不可约表示，$2j+1$ 给维度（本章）；
3. 一般半单李代数：Cartan 子代数（可同时对角化的一块极大交换李代数）给出权空间，根系编码权台阶的几何，**Weyl 群**管权链的对称，最后**最高权一一对应不可约表示**——这就是最高权定理，配合 Weyl 特征标公式给出维度与特征标。

（读法：第 3 条本章只指路不铺路——根系、Dynkin 图、Weyl 群是另一整章的体量；要带走的是**参数化的哲学**：把「所有不可约表示」这个看似不可数的目标，压成对一类离散参数（划分、最高权）的枚举，而枚举规则都是初等组合。）还有一条与第 4 章遥相呼应的账：$\bigoplus_{j+k=l} V_j \otimes V_k \cong \bigoplus_l V_l$ 这类分解在 $S_n$ 那边也有镜像（Kronecker 系数，第 4 章的 $\chi^\lambda \otimes \chi^\mu$ 分解问题），两边都还在各自的世界里等着被更初等地理解——表示论没有关门。

**本节小结**：Clebsch–Gordan 分解 $V_j \otimes V_k = \bigoplus_{l=|j-k|}^{j+k} V_l$，$1\otimes 1 = 2\oplus 1\oplus 0$ 真算过；最高权语言把 $SU(2)$ 的清单唯一性讲透，并把同样的参数化哲学指向一般半单李代数。下一节把本章的计算一次写全。

## $\rm \S \, 5.5$ 程序段：双覆盖、特征标与自旋耦合的数值验证

三笔账一次跑清：$\mathrm{U}(2\pi) = -I$ 与两头的特征标价、自旋 $1 \otimes 1$ 的 $J^2$ 谱分解。

```python
import numpy as np

sx = np.array([[0, 1], [1, 0]], complex)
sy = np.array([[0, -1j], [1j, 0]], complex)
sz = np.array([[1, 0], [0, -1]], complex)

def U(theta, n):                       # SU(2) 元素: exp(-i theta n.sigma / 2)
    n = np.array(n, float); n = n / np.linalg.norm(n)
    S = n[0]*sx + n[1]*sy + n[2]*sz
    return np.cos(theta/2)*np.eye(2) - 1j*np.sin(theta/2)*S

print(np.round(U(2*np.pi, (0, 0, 1)), 10))       # 期望 -I
th = np.pi/5
Rz = np.array([[np.cos(th), -np.sin(th), 0],
               [np.sin(th),  np.cos(th), 0], [0, 0, 1]])
print(np.trace(Rz).real, 1 + 2*np.cos(th))        # chi_{j=1}
print(np.trace(U(th, (0, 0, 1))).real, 2*np.cos(th/2))  # chi_{j=1/2}

def spin_ops(j):                       # 自旋 j 的 Jz 与升算符 J+
    d = int(2*j + 1); m = np.arange(j, -j-1, -1)   # m: j, j-1, ..., -j
    Jz = np.diag(m)
    Jp = np.zeros((d, d), complex)
    for b in range(d-1):
        Jp[b, b+1] = np.sqrt(j*(j+1) - m[b+1]*(m[b+1] + 1))
    return Jz, Jp

Jz1, Jp1 = spin_ops(1.0); Jz2, Jp2 = spin_ops(1.0)
I = np.eye(3)
Jz = np.kron(Jz1, I) + np.kron(I, Jz2)           # 总 Jz = Jz1 + Jz2
Jp = np.kron(Jp1, I) + np.kron(I, Jp2)           # 总 J+ = J+1 + J+2
Jm = Jp.conj().T
Jx, Jy = (Jp + Jm)/2, (Jp - Jm)/(2j)
J2 = Jx@Jx + Jy@Jy + Jz@Jz
print('algebra check [Jx,Jy]=iJz:', np.abs(Jx@Jy - Jy@Jx - 1j*Jz).max())
print('J^2 eigenvalues:', np.sort(np.linalg.eigvalsh(J2).real))
```

## $\rm \S \, 5.7$ 六问参考答案

1. $R(t)^{\mathsf T} R(t) = I$ 在 $t=0$ 求导给出 $X^{\mathsf T} + X = 0$（反对称）；$U(t)^\dagger U(t) = I$ 给出反厄米、$\det U(t) = 1$ 求导给出 $\mathrm{tr}\, X = 0$（无迹）。（§5.1）
2. 核里的 $U$ 要与 $\mathfrak{su}(2)$ 全体交换，即与三个基 $E_k = -i\sigma_k/2$ 逐个交换；由 $\sigma_1\sigma_2 = i\sigma_3$ 这组关系推出与全部 $\sigma_k$ 交换的矩阵是 $aI$，行列式为 $1$ 压出 $a^2 = 1$，得 $\pm I$。满射性由维数与连通性补齐。（§5.2）
3. $1/2$ 让 $SU(2)$ 参数里的角是 $SO(3)$ 的一半，$SO(3)$ 转 $2\pi$ 时 $SU(2)$ 只走半程到 $-I$，造成二对一；换成 $1$ 则 $\mathrm{U}(2\pi) = I$，映射退化为（局部）一对一，核只剩 $I$，双覆盖消失。（§5.2）
4. 设 $\rho: SO(3) \to GL(V)$ 是表示，沿 $\Phi$ 拉回得 $SU(2)$ 表示 $\rho \circ \Phi$。凡 $\Phi(U) = I_{SO(3)}$ 的 $U$（即核元素 $\pm I$）都满足 $\rho(\Phi(U)) = \rho(I) = I$，故拉回表示在 $\{\pm I\}$ 上平凡。半整数 $j$ 的 $V_j$ 中 $-I$ 作用为 $(-1)^{2j}I = -I \ne I$，无法平凡，这样的 $V_j$ 不可能从 $SO(3)$ 拉回得到。（§5.2、§5.3）
5. $\chi_j(2\pi) = \sin((2j+1)\pi)/\sin(\pi) = (-1)^{2j}(2j+1)$（洛必达或直接由权和 $(-1)^{2m}$ 得）。整数 $j$ 时取 $2j+1$、半整数时取 $-(2j+1)$——特征标在 $2\pi$ 的符号就是「表示是否感知双覆盖」的探针。（§5.3）
6. $V_{1/2} \otimes V_1 = V_{3/2} \oplus V_{1/2}$。维度账：$2 \times 3 = 6 = 4 + 2$；规则账：$l$ 从 $|1/2 - 1| = 1/2$ 到 $1 + 1/2 = 3/2$ 逐半整数取值，恰两个。（§5.4）
