# $\rm Chapter \, 1$ 刚体运动学与 SE(3)

具身智能的主角有身体：机械臂、无人机、四足机器人、自动驾驶汽车。它们的共同骨架是刚体——运动中任意两点距离不变的物体组合，连杆、机身、底盘都按刚体处理。刚体在三维空间的摆放由六个数决定：位置三个，姿态三个。位置好说；姿态这三个数是什么、怎么取才不出错，是本章第一主题。本章从零建立这套语言：SO(3) 给出无奇点的姿态群，指数映射把「绕哪根轴转多少度」变成可计算的公式，四元数用四个数存一个旋转并带出双覆盖这个拓扑奇景，SE(3) 把旋转与平移合并记账，伴随则是不同坐标系账本之间的汇率表。所有推导不跳步，所有结论都能在 §1.9 用一段脚本当场复算。

> **开始前自检**：本章假设你已经会：
>
> 1. □ 矩阵乘法、转置、行列式、内积与范数的操作规则（任意线性代数教材；旋转矩阵的直观版在图形学册第 3 章出现过，本章把它做严）。
> 2. □ 向量叉积：右手定则，以及两条恒等式 $a \times (b \times c) = b(a \cdot c) - c(a \cdot b)$（BAC–CAB）与 $a \cdot (b \times c) = \det[b, a, c]$ 型混合积——§1.2 与 §1.3 反复用它们。
> 3. □ 群的一句话定义：集合上一个封闭、可结合的二元运算，有单位元、每个元素有逆元（群论册第 1 章——只要这一句话，不需要任何定理）。
> 4. □ Taylor 级数：$\mathrm{e}^x = \sum_{k \ge 0} x^k / k!$ 与 $\sin$、$\cos$ 的展开（连续数学册第 3、4 章——指数映射的全部原料）。
> 5. □ 复数乘法把角度相加（$i^2 = -1$）；四元数是它的三维后代，§1.3 当场从零建，只需这条直觉。
>
> 不需要任何李群（Lie group）背景：这个词到 §1.6 才第一次出现，要用的部分全部当场教。

## $\rm \S \, 1.1$ 具身智能的第一课：身体在哪里，朝向哪里

控制回路每毫秒都在回答同一类问题：夹爪相对工件在哪里？IMU（惯性测量单元）读出的姿态怎么交给规划器？相机看到的物体坐标怎么换到机械臂底座？这些都是「同一个物理摆放，记在不同坐标系账本里数字不同」的问题。姿态与位姿的语言，就是管理这些账本的语言。

工程上最自然的起点是欧拉角（Euler angles）：任意姿态由绕三根指定轴各转一个角合成。本节用 ZYX 约定——先绕世界 $z$ 轴转航向 $\psi$，再绕新的 $y$ 轴转俯仰 $\theta$，最后绕再新的 $x$ 轴转横滚 $\phi$。三个数、直观、好填表——直到俯仰角碰到 $\pm 90^\circ$。

**万向节锁（gimbal lock）**的机制用图说话：

```text
俯仰角 0 度                     俯仰角 90 度
外环轴: 竖直 (z)                外环轴: 竖直 (z)
中环轴: 水平 (y)     ──→        中环轴: 被俯仰抬成竖直
内环轴: 水平 (x)                内环轴: 随着转回竖直
三根转轴互不相同                外环轴与内环轴重合：航向与横滚拧同一根轴
```

白话版：三根轴本该各管一个自由度；俯仰抬到 $90^\circ$ 时，外环与内环的转轴合成一根，两个旋钮只剩一个关节可拧——丢了一个自由度。注意丢的不是姿态本身，是这张参数表：姿态空间安然无恙，是欧拉角在那里退化了。机制的后半句用等式说更狠，在 $\theta = 90^\circ$ 处姿态只依赖组合 $\psi - \phi$：

$$
R_z(\psi)\,R_y\!\left(\tfrac{\pi}{2}\right)R_x(\phi) \;=\; R_z(\psi - \phi)\,R_y\!\left(\tfrac{\pi}{2}\right),
$$

航向与横滚从两个独立旋钮折叠成一个。这条等式要用 §1.2 的指数映射才证得动（证明放在 §1.2 末尾），数值演示在 §1.5 表二：俯仰 $90^\circ$ 处，「横滚加 $1^\circ$」与「航向减 $1^\circ$」给出的旋转矩阵逐位相同。

本册的地图由此展开：

1. **第 1 章（本章）运动学**：姿态与位姿的语言——SO(3)、四元数、SE(3)、伴随。
2. **第 2 章估计**：把 IMU、编码器、相机的带噪读数融合成姿态与位置的当前最优猜测，要在这套语言上做优化。
3. **第 3 章控制**：产生关节指令，让身体跟踪给定轨迹。
4. **第 4 章规划**：在构型空间里找一条无碰撞的路。

**小结**：本节立了两件事——姿态需要一套不退化的语言；欧拉角这张常用表在俯仰 $\pm 90^\circ$ 处塌掉。下面开始造新语言。

## $\rm \S \, 1.2$ SO(3)：旋转矩阵群与指数映射

我们要一套「无奇点、可连续变化、可复合、可求逆」的姿态语言。旋转矩阵（rotation matrix）是最诚实的一个：不省略任何信息，代价是九个数只装三个自由度。

**定义（旋转矩阵）**：线性映射 $R : \mathbb{R}^3 \to \mathbb{R}^3$，保持长度与（右手系）定向：$|Rx| = |x|$ 对一切 $x$，且 $\det R > 0$。

**第一步：保长推出正交。** 把保长平方：$x^\top R^\top R x = |Rx|^2 = |x|^2 = x^\top I x$ 对一切 $x$，即对称矩阵 $A = R^\top R - I$ 满足 $x^\top A x = 0$ 对一切 $x$。引理：对称矩阵若对一切 $x$ 有 $x^\top A x = 0$，则 $A = 0$。证明两步：取 $x = e_i$ 得对角元 $A_{ii} = 0$；取 $x = e_i + e_j$ 得 $A_{ii} + A_{jj} + 2A_{ij} = 0$，故 $A_{ij} = 0$（对称性让交叉项成对出现，非对称矩阵这一步不成立）。于是 $R^\top R = I$，即 $R$ 正交（orthogonal），列向量构成标准正交基，$R^{-1} = R^\top$。

**第二步：连续性钉死 $\det R = 1$。** 由 $R^\top R = I$ 取行列式：$(\det R)^2 = 1$，故 $\det R = \pm 1$。物理旋转是从单位阵出发的连续运动：沿连续路径 $R(t)$，$R(0) = I$，则 $\det R(t)$ 是只取 $\pm 1$ 的连续函数——取值集合离散、定义域（时间段）连通，函数只能恒为常数，即 $\det R(t) = \det I = 1$。读法：$\det R = -1$ 的正交阵（反射）是另一族，与旋转隔着一道走不过去的墙。

这两步合起来给了集合一个名字：$\mathrm{SO}(3) = \{ R \in \mathbb{R}^{3\times 3} : R^\top R = I,\ \det R = 1 \}$，称为三维特殊正交群（special orthogonal group）。它是群：两个旋转矩阵相乘仍是保长且行列式为一的矩阵（封闭、结合平凡成立），$I$ 是单位元，$R^{-1} = R^\top$ 是逆元——绕轴转与逆着转。

**李代数 so(3)：弯曲空间在单位元处的切平面。** 白话：SO(3) 是三维弯曲曲面，研究弯曲空间的标准手法是研究贴着它的线性空间——速度向量住的地方。设 $R(t) = I + t\,\dot R(0) + O(t^2)$ 是一条过 $I$ 的曲线，对恒等式 $R^\top R = I$ 求导：$\dot R(0)^\top + \dot R(0) = 0$，速度是反对称矩阵（skew-symmetric matrix）。反过来每个反对称矩阵都由一个三维向量生成：定义 hat 算子

$$
\hat\omega = \begin{bmatrix} 0 & -\omega_3 & \omega_2 \\ \omega_3 & 0 & -\omega_1 \\ -\omega_2 & \omega_1 & 0 \end{bmatrix},
\qquad \hat\omega\, x = \omega \times x .
$$

乘一遍第一行即可验证：$(\hat\omega x)_1 = -\omega_3 x_2 + \omega_2 x_3 = (\omega \times x)_1$。这个对应把三维向量空间 $\mathbb{R}^3$ 与三阶反对称矩阵空间等同起来，后者记作 $\mathfrak{so}(3)$，是 SO(3) 的李代数（Lie algebra）——本册只需知道「它就是切平面的代名词」。

**引理（幂的三条规则，$\|\omega\| = 1$）**：

1. $\hat\omega^2 = \omega\omega^\top - I$。证明：对一切 $x$，$\hat\omega^2 x = \omega \times (\omega \times x) = \omega\,(\omega^\top x) - (\omega^\top\omega)\,x$（BAC–CAB 取 $a = \omega, b = \omega, c = x$），矩阵作用于每个向量相同则矩阵相等。
2. $\omega^\top \hat\omega = 0$。证明：$\omega^\top \hat\omega = (\hat\omega^\top \omega)^\top = (-\hat\omega\,\omega)^\top = -(\omega \times \omega)^\top = 0$。
3. $\hat\omega^3 = -\hat\omega$。证明：$\hat\omega^3 = (\omega\omega^\top - I)\hat\omega = \omega\,(\omega^\top \hat\omega) - \hat\omega = -\hat\omega$，第二步用规则 2。

**指数映射（exponential map）与 Rodrigues 公式的全证。** 白话：「从 $I$ 出发、以恒定角速度 $\omega$ 转」的姿态轨迹 $\gamma(\theta)$ 该满足 $\gamma'(\theta) = \hat\omega\,\gamma(\theta)$、$\gamma(0) = I$；这个微分方程的解按定义就是矩阵指数

$$
\mathrm{e}^{\hat\omega\theta} = \sum_{k=0}^{\infty} \frac{(\hat\omega\,\theta)^k}{k!}
$$

（级数收敛对照连续数学册第 4 章；$\|\omega\| = 1$，转角就是 $\theta$）。现在逐项算出闭式。把级数按 $k$ 的奇偶拆开、把 $k = 0$ 项提出来：

$$
\mathrm{e}^{\hat\omega\theta} = I \;+\; \sum_{k=1}^{\infty} \frac{\theta^{2k}}{(2k)!}\,\hat\omega^{2k} \;+\; \sum_{k=0}^{\infty} \frac{\theta^{2k+1}}{(2k+1)!}\,\hat\omega^{2k+1}.
$$

用引理把高次幂归约。偶数幂：$\hat\omega^{2k} = (-1)^{k-1}\hat\omega^2$（$k \ge 1$）；奇数幂：$\hat\omega^{2k+1} = (-1)^k\hat\omega$（$k \ge 0$）。归纳基分别是 $k = 1$ 的 $\hat\omega^2$ 与 $k = 0$ 的 $\hat\omega$；归纳步是 $\hat\omega^{2k+2} = \hat\omega^{2k}\,\hat\omega^2$ 与 $\hat\omega^{2k+3} = \hat\omega^{2k+1}\,\hat\omega^2 = -\hat\omega^{2k+1}$（末步用规则 3）。代入并把标量级数与已知 Taylor 展开对认——偶数列是 $\sum_{k \ge 1} (-1)^{k-1}\theta^{2k}/(2k)! = 1 - \cos\theta$，奇数列是 $\sum_{k \ge 0} (-1)^k\theta^{2k+1}/(2k+1)! = \sin\theta$：

$$
\mathrm{e}^{\hat\omega\theta} \;=\; I \;+\; \sin\theta\,\hat\omega \;+\; (1 - \cos\theta)\,\hat\omega^2.
$$

这就是 Rodrigues 公式。读法：三项各司其职——$I$ 保持转轴方向不动，$\hat\omega$ 项让垂直分量以 $\sin\theta$ 转圈，$\hat\omega^2$ 项把垂直分量按 $1 - \cos\theta$ 往回拉拢成一个整圆。

**验证它在 SO(3) 里。** 记 $s = \sin\theta$、$t = 1 - \cos\theta$、$S = \hat\omega$，则 $R = I + sS + tS^2$，且 $R^\top = I - sS + tS^2$（$S^\top = -S$，$(S^2)^\top = (S^\top)^2 = S^2$）。乘开，交叉项 $stS^3$ 与 $-tsS^3$ 恰好抵消：

$$
R\,R^\top = I + (2t - s^2)\,S^2 + t^2\,S^4 = I + (2t - s^2 - t^2)\,S^2,
$$

末步用 $S^4 = -S^2$（引理幂规则的 $k = 2$ 情形）。而 $2t - s^2 - t^2 = 0$：两边都等于 $2 - 2\cos\theta$（右端展开 $\sin^2\theta + (1-\cos\theta)^2 = (1 - \cos^2\theta) + (1 - 2\cos\theta + \cos^2\theta)$）。故 $RR^\top = I$。行列式：$\theta$ 从 $0$ 连续增大时 $R(\theta)$ 连续、$\det R(\theta) \in \{\pm 1\}$、$\det R(0) = 1$，同第二步的连续性论证知 $\det \equiv 1$。所以每个 Rodrigues 公式给出的矩阵都是合法旋转。顺手记一个迹公式：$\mathrm{tr}\,R = 3 + s\,\mathrm{tr}\,S + t\,\mathrm{tr}\,S^2 = 3 + 0 + t\,(1 - 3) = 1 + 2\cos\theta$（用了规则 1 与 $\mathrm{tr}(\omega\omega^\top) = \omega^\top\omega = 1$、反对称矩阵迹为零）。

**轴角（axis-angle）与旋转矩阵互转。** 正向：给单位轴 $\mathbf n$ 与角 $\theta$，用 Rodrigues。反向：给 $R$，先由迹公式解角，再从反对称部分取轴：

$$
\theta = \arccos\!\frac{\mathrm{tr}\,R - 1}{2}, \qquad \omega = \frac{(R - R^\top)^\vee}{2\sin\theta},
$$

其中 $(\cdot)^\vee$ 是 hat 的逆（把反对称矩阵还原成向量）。证明一句话：$R - R^\top = s\,(S - S^\top) + t\,(S^2 - S^2) = 2\sin\theta\,S$，$S^2$ 对称、抵消，只剩 $\hat\omega$。两处退化如实声明：$\theta \approx 0$ 时 $\sin\theta \to 0$（旋转本身趋近恒等，无信息可提）；$\theta \approx \pi$ 时 $R - R^\top \to 0$，要改用对称部分从 $\hat\omega^2 = \omega\omega^\top - I$ 反解轴（对角元最大者定 $\omega$ 的分量）。鲁棒提取见 Lynch 与 Park《Modern Robotics》（Cambridge, 2017）第 3 章与 Murray、Li、Sastry《A Mathematical Introduction to Robotic Manipulation》（CRC, 1994）第 2 章。

**收掉 §1.1 的悬案。** 需要一条换轴恒等式：对 $A \in \mathrm{SO}(3)$，$A\,\mathrm{e}^{\hat\omega\theta}A^{-1} = \mathrm{e}^{\widehat{A\omega}\,\theta}$。证明两段。级数段：$A\hat\omega^k A^{-1} = (A\hat\omega A^{-1})^k$ 逐项配对。识别段：$(A\hat\omega A^{-1})\,x = A\,(\omega \times A^{-1}x)$，而 $(A\omega) \times x = A\,(\omega \times A^{-1}x)$ 对一切 $x$ 成立——因为对任意 $w$，$w \cdot (\omega \times A^{-1}x) = \det[\omega, A^{-1}x, w]$，两边作用 $A$ 后由 $\det A = 1$ 保持混合积、$A$ 又是满射，两向量对所有方向的内积相同故相等。于是 $A\hat\omega A^{-1} = \widehat{A\omega}$。

现在看欧拉角。ZYX 姿态 $R = R_z(\psi)R_y(\theta)R_x(\phi)$，每个 $R_{(\cdot)}$ 都是指数映射（绕坐标轴的特例）。取 $\theta = \pi/2$，把换轴恒等式用在中间一步：$R_y(\tfrac{\pi}{2})\,R_x(\phi) = \mathrm{e}^{\widehat{R_y(\pi/2)\,e_1}\,\phi}\,R_y(\tfrac{\pi}{2})$，而 $R_y(\tfrac{\pi}{2})\,e_1 = -e_3$（$y$ 轴转 $90^\circ$ 后原 $x$ 轴指向负 $z$），故 $R_x(\phi)$ 换账后成了 $R_z(-\phi)$：

$$
R_z(\psi)\,R_y\!\left(\tfrac{\pi}{2}\right)R_x(\phi) = R_z(\psi)\,R_z(-\phi)\,R_y\!\left(\tfrac{\pi}{2}\right) = R_z(\psi - \phi)\,R_y\!\left(\tfrac{\pi}{2}\right).
$$

这正是 §1.1 的等式：俯仰 $90^\circ$ 处，$\psi$ 与 $\phi$ 只以差 $\psi - \phi$ 进入，两个自由度塌成一个。锁死的不是 SO(3)，是欧拉角这张表。

**小结**：本节造了第一件工具——SO(3) 与它的切空间 so(3)，指数映射用幂级数三规则把「绕轴转角」变成 Rodrigues 公式，并用换轴恒等式解释了万向节锁。下一件工具管存储。

## $\rm \S \, 1.3$ 四元数：最小存储与双覆盖

矩阵九个数带六条约束，欧拉角带奇点。工程要的是折中：少几个数、无奇点、乘法即复合。这就是四元数（quaternion），Hamilton 在 1843 年的发明，今天机器人与游戏行业存储姿态的事实标准。

**定义（四元数代数）**：$\mathbb{H}$ 是实四维向量空间，基元 ${1, i, j, k}$ 满足 $i^2 = j^2 = k^2 = ijk = -1$。从这一条能导出全部乘法表，例如 $ij = k$（把 $ijk = -1$ 右乘 $k^{-1} = -k$）、$ji = -k$（反序变号）。非交换是特性不是缺陷：绕 $x$ 转再绕 $y$ 转本来就不等于换顺序（§1.5 表三有数值）。写成「实部加向量」形式 $q = (q_0, \mathbf q)$，共轭 $q^* = (q_0, -\mathbf q)$，模 $|q|^2 = q_0^2 + \|\mathbf q\|^2$。用乘法表逐项展开可得一般乘法公式（§1.3 后面全靠它）：

$$
(q_0, \mathbf q)\,(p_0, \mathbf p) = \big(q_0 p_0 - \mathbf q \cdot \mathbf p,\ \ q_0\,\mathbf p + p_0\,\mathbf q + \mathbf q \times \mathbf p\big).
$$

两个立即可得的推论。其一，纯虚数相乘：$(0, \mathbf u)(0, \mathbf v) = (-\mathbf u \cdot \mathbf v,\ \mathbf u \times \mathbf v)$——叉积就藏在四元数乘法的虚部里，这是四元数与三维几何深度绑定的原因。其二，$q\,q^* = (q_0^2 + \|\mathbf q\|^2,\ 0)$，故单位四元数的逆就是共轭：$q^{-1} = q^*$。模的乘法性 $|qp| = |q|\,|p|$ 直接展开即验证（展开后正是 Lagrange 四平方恒等式），数值锚点在 §1.9 复跑段（差 $10^{-16}$ 量级）。

**单位四元数对应旋转（全证）。** 任何单位四元数都能写成半角参数 $q = (\cos\frac{\theta}{2},\ \sin\frac{\theta}{2}\,\mathbf n)$，$\|\mathbf n\| = 1$（取 $\mathbf n = \mathbf q / \|\mathbf q\|$、$\theta = 2\arccos q_0$ 即可，$q_0^2 + \|\mathbf q\|^2 = 1$ 恰好保证模为一）。让它作用于纯虚数 $(0, \mathbf v)$：$\,(0, \mathbf v') = q\,(0, \mathbf v)\,q^{-1} = q\,(0, \mathbf v)\,q^*$。记 $a = \cos\frac{\theta}{2}$、$\mathbf b = \sin\frac{\theta}{2}\,\mathbf n$，三步算完。第一步，右半边用乘法公式：$(0, \mathbf v)\,q^* = (\mathbf v \cdot \mathbf b,\ a\,\mathbf v - \mathbf v \times \mathbf b)$。第二步，左乘 $(a, \mathbf b)$。实部 $a(\mathbf v \cdot \mathbf b) - \mathbf b \cdot (a\mathbf v - \mathbf v \times \mathbf b)$ 中间两项相消、末项为零（$\mathbf v \times \mathbf b$ 垂直于 $\mathbf b$），故结果仍是纯虚数；向量部分逐项整理

$$
a\,(a\mathbf v - \mathbf v \times \mathbf b) + (\mathbf v \cdot \mathbf b)\,\mathbf b + \mathbf b \times (a\mathbf v - \mathbf v \times \mathbf b) = \big(a^2 - \|\mathbf b\|^2\big)\mathbf v + 2(\mathbf v \cdot \mathbf b)\,\mathbf b + 2a\,(\mathbf b \times \mathbf v),
$$

其中用了 BAC–CAB 展开 $\mathbf b \times (\mathbf v \times \mathbf b) = (\mathbf b \cdot \mathbf b)\mathbf v - (\mathbf b \cdot \mathbf v)\mathbf b$ 与 $\mathbf b \times \mathbf v = -\mathbf v \times \mathbf b$。第三步，代回半角参数，用倍角公式 $\cos^2\frac{\theta}{2} - \sin^2\frac{\theta}{2} = \cos\theta$、$2\sin\frac{\theta}{2}\cos\frac{\theta}{2} = \sin\theta$、$2\sin^2\frac{\theta}{2} = 1 - \cos\theta$：

$$
\mathbf v' = \cos\theta\,\mathbf v + \sin\theta\,(\mathbf n \times \mathbf v) + (1 - \cos\theta)\,(\mathbf n \cdot \mathbf v)\,\mathbf n.
$$

把它与 §1.2 的 Rodrigues 公式作用在 $\mathbf v$ 上对比——用规则 1 重排 $\hat n^2 \mathbf v = \mathbf n\,(\mathbf n \cdot \mathbf v) - \mathbf v$ 后，两式逐项相同。所以 $qvq^*$ 的向量部分就是 $\mathrm{e}^{\hat n\theta}\mathbf v$：四元数与旋转矩阵是同一几何的两套代数。从第二步的公式直接读出矩阵形式：

$$
R(q) = \big(q_0^2 - \|\mathbf q\|^2\big)I + 2\,\mathbf q\,\mathbf q^\top + 2q_0\,\hat{\mathbf q},
$$

教科书上的九分量显式矩阵就是它的展开；§1.9 脚本用的正是这个紧凑式。

**双覆盖（double cover）。** 先看现象：$q$ 与 $-q$ 给出同一个矩阵——$R(-q)$ 的三项里二次项不变号、线性项 $2(-q_0)\widehat{(-\mathbf q)} = 2q_0\hat{\mathbf q}$ 也不变号；夹积版本同理，$(-q)\,v\,(-q)^{-1} = qvq^{-1}$。§1.9 实测 $\max|R(q) - R(-q)| = 0$，一位不差。

白话：这说 SO(3) 的每个点被数了两次。单位四元数集合 $S^3 = \{q : |q| = 1\}$ 是 $\mathbb{R}^4$ 里的三维球面；把每对 $\{q, -q\}$ 认作同一点（商掉 $\pm 1$）恰好得到 SO(3)。数学名词：$\Phi : S^3 \to \mathrm{SO}(3)$ 是覆盖映射（covering map），局部一一、整体二对一，拓扑上 $\mathrm{SO}(3) \cong \mathbb{RP}^3$。更贴身的图景：SO(3) 可以画成半径 $\pi$ 的实心球——轴角参数化（球内一点 = 方向乘长度 $\theta$），但球面上直径两端（绕同一轴转 $+\pi$ 与 $-\pi$）是同一姿态，必须把对径点粘起来；$S^3$ 是把这个粘合解开之前的干净球面。

这个拓扑事实有物理演示也有工程后果。物理版：把连续转 $2\pi$ 看成 SO(3) 里的闭合环路，它在 $S^3$ 上的提升从 $q$ 走到 $-q$，没有闭合——要转 $4\pi$ 才回到出发点。「皮带把戏」把这事搬上手：拧转 $360^\circ$ 的皮带回不到平扭状态，拧 $720^\circ$ 才可以。工程版：插值、平均、滤波前必须对齐符号——约定 $q_{\text{ref}} \cdot q \ge 0$，否则两个「同一姿态」的四元数平均出零向量。对齐之后，球面线性插值（slerp）在 $S^3$ 的大圆弧上匀角速行走：$q(t) \propto \sin((1 - t)\Omega)\,q_0 + \sin(t\Omega)\,q_1$，$\cos\Omega = q_0 \cdot q_1$（Shoemake 1985）。欧拉角三个分量各自插值给不出恒定角速度，还会路过奇点。

**对比与分工。** 四条账：

1. **无奇点**：单位四元数处处局部均匀；欧拉角在俯仰 $\pm 90^\circ$ 雅可比退化（§1.5 表二）。
2. **存储**：四元数 4 个数带 1 条归一化约束；矩阵 9 个数带 6 条正交约束。漂移后修复也轻：四元数除以模长，矩阵要投影回 SO(3)。
3. **复合开销**：四元数乘法 16 次乘 12 次加，矩阵乘法 27 次乘 18 次加——姿态树每帧成千上万次复合时是真实差距。
4. **用矩阵的场合**：要把旋转作用在一批点上（渲染、运动学）或要进线性代数分解时，转成矩阵一次、批量使用。存储格式与计算格式分工，不是敌我。

**小结**：本节造了第二件工具——四元数用 4 个数存旋转、乘法即复合；双覆盖 $S^3 \to \mathrm{SO}(3)$ 解释了 $\pm q$ 之谜并给出插值的符号纪律。还差平移。

## $\rm \S \, 1.4$ SE(3) 与伴随：位姿、速度与两本账

白话：只有姿态不够——「夹爪在工件左侧三厘米」还带一个平移。把旋转与平移打包成一个对象，复合与求逆才有统一语法。

**定义（齐次变换）**：位姿（pose）用齐次变换矩阵（homogeneous transformation matrix）表示：

$$
T = \begin{bmatrix} R & p \\ 0 & 1 \end{bmatrix}, \qquad
\begin{bmatrix} x \\ 1 \end{bmatrix} \mapsto \begin{bmatrix} Rx + p \\ 1 \end{bmatrix}.
$$

平移藏在最后一列、乘法照常进行，复合与求逆都是 $4\times 4$ 矩阵运算。求逆公式一步验证：$T^{-1} = \begin{bmatrix} R^\top & -R^\top p \\ 0 & 1 \end{bmatrix}$，乘回去得 $I$（旋转块正交、平移块相消）。这些矩阵构成群 SE(3)（special Euclidean group）。

**下标记法与账本读法**（本书全册沿用）：$T_{ab} = \begin{bmatrix} R_{ab} & p_{ab} \\ 0 & 1 \end{bmatrix}$ 读作「$\{b\}$ 系在 $\{a\}$ 系里的位姿」，作用是把 $b$ 系中的坐标搬进 $a$ 系：$p_a = R_{ab}\,p_b + p_{ab}$。比喻：每个坐标系是一本账，同一件刚体摆放记在不同账本里数字不同，$T_{ab}$ 是账本间的汇率表。复合的物理读法从右往左：$T_{ac} = T_{ab}\,T_{bc}$——先按 $\{b\}$ 的账读 $\{c\}$，再把 $\{b\}$ 的账折进 $\{a\}$。矩阵块的手算规则：旋转块相乘，平移块「先转后加」：$p_{ac} = R_{ab}\,p_{bc} + p_{ab}$——$c$ 的原点先被 $R_{ab}$ 搬进 $a$ 的朝向，再叠加 $b$ 的原点位移。顺序不能换（§1.5 表三）。

**速度也要打包。** 白话：刚体的瞬时运动 = 转动加移动，六个数一起记。运动旋量（twist）$\mathcal V = (\omega, v) \in \mathbb{R}^6$，写成 $4 \times 4$ 矩阵

$$
\hat{\mathcal V} = \begin{bmatrix} \hat\omega & v \\ 0 & 0 \end{bmatrix} \in \mathfrak{se}(3),
\qquad \mathrm{e}^{\hat{\mathcal V}\,\theta} = \begin{bmatrix} \mathrm{e}^{\hat\omega\theta} & G(\theta)\,v \\ 0 & 1 \end{bmatrix},
$$

$G(\theta) = \theta I + (1 - \cos\theta)\,\hat\omega + (\theta - \sin\theta)\,\hat\omega^2$（约定 $\|\omega\| = 1$；$\omega = 0$ 时退化为纯平移，平移块就是 $v\theta$）。读法：把 §1.2 的 Rodrigues 逐项对 $\theta$ 积分就得 $G$（$\int_0^\theta \sin = 1 - \cos$，$\int_0^\theta (1 - \cos) = \theta - \sin$）——「一边转一边移」的完整刚体运动正是拧螺丝（螺旋运动，screw motion）。全推导在 Murray–Li–Sastry 第 2 章与 Lynch–Park 第 3 章，本册用到时再展开。

力也有对偶的六元组：力旋量（wrench）$\mathcal F = (f, \tau)$，力加力矩。两者由功率锁在一起：$P = \mathcal V^\top \mathcal F$ 是物理量，不该依赖记账坐标系——这一句话直接逼出下面的伴随。

**伴随（adjoint）。** 同一个 twist 记在 $\{b\}$ 账与 $\{a\}$ 账里的换算由 $6\times 6$ 矩阵承担：

$$
\mathcal V_a = \mathrm{Ad}_{T_{ab}}\,\mathcal V_b, \qquad
\mathrm{Ad}_{T_{ab}} = \begin{bmatrix} R_{ab} & 0 \\ \hat p_{ab}\,R_{ab} & R_{ab} \end{bmatrix},
\qquad \text{定义为 } T_{ab}\,\hat{\mathcal V}_b\,T_{ab}^{-1} = \widehat{\mathcal V_a}.
$$

陈述级即可（定义式与矩阵式等价，§1.9 实测差 $10^{-16}$），读法重要：上块换账只把角速度转个方向；下块多出 $\hat p\,R$ 一项——坐标系原点搬了位置，线速度里混进「测量点绕新原点的杠杆臂」$p \times \omega_a$。你在车轮边缘测的速度，记到地面账本时要加这一笔。wrench 反向且带转置：$\mathcal F_a = \mathrm{Ad}_{T_{ab}}^{-\top}\,\mathcal F_b$，验证一行：$\mathcal V_a^\top \mathcal F_a = \mathcal V_b^\top\,\mathrm{Ad}^\top\mathrm{Ad}^{-\top}\,\mathcal F_b = \mathcal V_b^\top \mathcal F_b$，功率不因换账改变。

**左乘与右乘的纪律。** 给刚体加一个增量变换 $\Delta T$：世界账本里动，$T \leftarrow \Delta T\,T$（左乘）；体系账本里动，$T \leftarrow T\,\Delta T$（右乘）。一句话记忆：左乘 = 世界系指令，右乘 = 体坐标指令。机器人代码里把乘法顺序写反，是本章语言下最经典的 bug。

**小结**：本节把姿态与平移合并成 SE(3)，速度与力打包成 twist 与 wrench，伴随是账本间的汇率表且保功率；接口留给下一节——所有这些对象都要过数值验收。

## $\rm \S \, 1.5$ 数值实证：两路互证、锁死演示与复合手算

三个实验各钉一件事；完整脚本与全部打印在 §1.9，此处给数与读法。

**实验一：两路独立推导逐位互证。** 绕单位轴 $\mathbf n = (1, 2, 2)/3$ 转 $\theta = 70^\circ$：Rodrigues 公式与「半角四元数 → $R(q)$ 紧凑式」各算一遍旋转矩阵，再随便取一个 $\mathbf v = (0.3, -1.2, 2.0)$ 检查 $R\mathbf v$ 与 $qvq^{-1}$ 的向量部分：

1. 两路矩阵逐元差最大 $1.7\times 10^{-16}$，$R\mathbf v$ 与夹积差 $3.3\times 10^{-16}$——都在一个机器精度（ulp）之内，这是「四元数作用 = Rodrigues 矩阵」的端到端见证。
2. $R^\top R$ 对 $I$ 的最大偏差 $1.1\times 10^{-16}$，$\det R = 1.0$；迹 $1.6840402867$ 对 $1 + 2\cos 70^\circ = 1.6840402867$ 逐位一致。
3. 从 $R$ 反解轴角：$\theta$ 回收 $69.99999999999999^\circ$，轴回收 $(1/3, 2/3, 2/3)$。
4. 双覆盖实测：$\max|R(q) - R(-q)| = 0.0$，一位不差；模乘法性 $|qp| - |q||p| = -4.4\times 10^{-16}$。

**实验二：万向节锁的微分退化。** 雅可比 $J$ 的第 $j$ 列 = 第 $j$ 个欧拉角单位速度引起的体系角速度（中心差分算 $R_0^\top\,\mathrm{d}R$ 的 vee）。理论预言 $\det J = \cos\theta$（对 ZYX 逐项展开可手证），数值逐档对账：

| 俯仰角 | $\det J$ | $\cos\theta$ | $\sigma_{\min}$ | 条件数 |
| --- | --- | --- | --- | --- |
| $0^\circ$ | $+1.0000$ | $+1.0000$ | $1.0$ | $1.0$ |
| $30^\circ$ | $+0.8660$ | $+0.8660$ | $0.71$ | $1.7$ |
| $60^\circ$ | $+0.5000$ | $+0.5000$ | $0.37$ | $3.7$ |
| $80^\circ$ | $+0.1736$ | $+0.1736$ | $0.12$ | $11$ |
| $89^\circ$ | $+0.0175$ | $+0.0175$ | $0.012$ | $110$ |
| $90^\circ$ | $+0.0000$ | $+0.0000$ | $3.7\times 10^{-17}$ | $3.8\times 10^{16}$ |

更直的一刀：俯仰 $90^\circ$ 处，「横滚加 $1^\circ$」与「航向减 $1^\circ$」的旋转矩阵差 $1.1\times 10^{-16}$（同一姿态），而俯仰 $60^\circ$ 处同样两个扰动差 $0.0083$（可分辨）。读法：条件数每逼近锁死点恶化约一个数量级；到 $90^\circ$ 时 $\det J = 0$，欧拉角不是「误差变大」而是参数化把两个自由度折叠成一个——§1.2 末尾那条 $R_z(\psi - \phi)R_y(\pi/2)$ 的代数，在这里兑现成 $3.8\times 10^{16}$ 的条件数。

**实验三：两个 SE(3) 变换复合手算。** 取 $T_{ab} = \begin{bmatrix} R_z(90^\circ) & (1, 0, 0)^\top \\ 0 & 1 \end{bmatrix}$、$T_{bc} = \begin{bmatrix} R_y(90^\circ) & (0, 2, 0)^\top \\ 0 & 1 \end{bmatrix}$（$90^\circ$ 的矩阵分量全是 $0, \pm 1$，手算干净）：

$$
R_{ab} = \begin{bmatrix} 0 & -1 & 0 \\ 1 & 0 & 0 \\ 0 & 0 & 1 \end{bmatrix}, \quad
R_{bc} = \begin{bmatrix} 0 & 0 & 1 \\ 0 & 1 & 0 \\ -1 & 0 & 0 \end{bmatrix}, \quad
R_{ab}\,R_{bc} = \begin{bmatrix} 0 & -1 & 0 \\ 0 & 0 & 1 \\ -1 & 0 & 0 \end{bmatrix},
$$

平移块 $p_{ac} = R_{ab}(0, 2, 0)^\top + (1, 0, 0)^\top = (-2, 0, 0)^\top + (1, 0, 0)^\top = (-1, 0, 0)^\top$，与脚本打印逐位一致。反向复合 $T_{bc}\,T_{ab}$ 得完全不同的 $R = \begin{bmatrix} 0 & 0 & 1 \\ 1 & 0 & 0 \\ 0 & 1 & 0 \end{bmatrix}$、$p = (0, 2, -1)^\top$——旋转不交换的 SE(3) 版本。求逆与伴随也在同一段实测：$\max|T_{ab}T_{ab}^{-1} - I| = 0.0$，$\max|\mathrm{Ad}_{T_{ab}}\mathcal V_b - (T_{ab}\hat{\mathcal V}_b T_{ab}^{-1})^\vee| = 1.1\times 10^{-16}$。

**小结**：三个实验把本章每条推导按到了浮点地面上——两路公式互证到机器精度，锁死的退化被条件数量化，复合的手算规则与矩阵乘法逐位吻合。

## $\rm \S \, 1.6$ 出口：正运动学与流形上的优化

1. **正运动学（forward kinematics）一句话**：机械臂是关节串连杆的链，每个关节贡献一个 SE(3) 变换，工具位姿就是逐级复合 $T_{0n} = T_{01}\,T_{02}\cdots T_{n-1,n}$——本章的复合语法正是为此准备的（螺旋求积法见 Lynch–Park 第 4 章）。
2. **李群上的优化一句话**：第 2 章的估计要在 SO(3)/SE(3) 上迭代下降，但欧拉角参数化在奇点处雅可比退化、四元数带约束不能直接进无约束优化；现代做法是把增量定义在切空间 $\mathfrak{se}(3)$ 上、用指数映射拉回群（回缩，retraction），参数化处处有效——这正是本章把指数映射证全的回报。

## $\rm \S \, 1.7$ 关键概念回顾

1. 从「保长」到 $R^\top R = I$ 的证明里，对称矩阵零对角化引理用在哪一步？$\det R = 1$ 又靠什么性质钉死？
2. 引理的三条幂规则各自用了什么？Rodrigues 推导中偶数次幂列与奇数次幂列分别认成了哪个 Taylor 级数？
3. 从 $R$ 反解轴角时，为什么 $(R - R^\top)^\vee$ 能给出转轴？$\theta \approx 0$ 与 $\theta \approx \pi$ 各卡在哪？
4. 单位四元数推导 $qvq^*$ 的三步中，BAC–CAB 用在哪一步？双覆盖对插值代码的具体后果是什么？
5. 伴随矩阵的四个块各管什么？wrench 为什么必须用 $\mathrm{Ad}^{-\top}$ 而 twist 用 $\mathrm{Ad}$ 本身？
6. 左乘与右乘 $\Delta T$ 的物理差别是什么？$R_z(\psi - \phi)R_y(\pi/2)$ 这条等式如何说明万向节锁？

## $\rm \S \, 1.8$ 本章自测答案

1. 用在「$x^\top A x = 0$ 对一切 $x$ 推出 $A = 0$」这一步（取 $e_i$ 与 $e_i + e_j$）；$\det = 1$ 靠连续性：$\det R(t)$ 是离散取值的连续函数，只能恒等于 $\det I$。（§1.2）
2. 规则 1 用 BAC–CAB、规则 2 用反对称加自身叉积为零、规则 3 用规则 1 配规则 2；偶数列认成 $1 - \cos\theta$，奇数列认成 $\sin\theta$。（§1.2）
3. 因为 $R - R^\top = 2\sin\theta\,\hat\omega$，对称的 $\hat\omega^2$ 项抵消；$\theta \approx 0$ 没信息可提（旋转趋近恒等），$\theta \approx \pi$ 时反对称部分消失，改用 $\hat\omega^2 = \omega\omega^\top - I$ 的对称部分定轴。（§1.2）
4. 用在展开 $\mathbf b \times (\mathbf v \times \mathbf b)$；后果是插值、平均、滤波前必须做符号对齐（约定 $q_{\text{ref}} \cdot q \ge 0$），否则同一姿态的两个四元数平均出零向量。（§1.3）
5. 上块换角速度只乘 $R$，下块换线速度多出杠杆臂 $\hat p R$；wrench 与 twist 由功率 $\mathcal V^\top\mathcal F$ 配对，保持功率要求 $\mathcal F_a = \mathrm{Ad}^{-\top}\mathcal F_b$。（§1.4）
6. 左乘在世界账本里动刚体，右乘在体系账本里动；该等式说明俯仰 $90^\circ$ 时姿态只依赖 $\psi - \phi$，航向与横滚塌成一个自由度，雅可比行列式归零。（§1.1、§1.2、§1.5）

## $\rm \S \, 1.9$ 可当场复跑的验证段

纯 Python + numpy，三个实验与 §1.5 的数字一一对应。直接存成脚本运行即可。

```python
import numpy as np
np.set_printoptions(precision=6, suppress=True)

def hat(w):
    return np.array([[0, -w[2], w[1]], [w[2], 0, -w[0]], [-w[1], w[0], 0.0]])
def vee(S):
    return np.array([S[2, 1], S[0, 2], S[1, 0]])
def rodrigues(n, th):
    S = hat(n)
    return np.eye(3) + np.sin(th) * S + (1 - np.cos(th)) * S @ S
def qmul(q, p):
    a, u = q[0], q[1:]; b, v = p[0], p[1:]
    return np.r_[a * b - u @ v, a * v + b * u + np.cross(u, v)]
def q_to_R(q):
    a, b = q[0], q[1:]
    return (a * a - b @ b) * np.eye(3) + 2 * np.outer(b, b) + 2 * a * hat(b)

# 实验 1：绕 (1,2,2)/3 转 70 度，Rodrigues 与四元数两路对照
n = np.array([1.0, 2, 2]) / 3; th = np.deg2rad(70)
R_rod = rodrigues(n, th)
q = np.r_[np.cos(th / 2), np.sin(th / 2) * n]
v = np.array([0.3, -1.2, 2.0])
qstar = q * np.array([1, -1, -1, -1])
print(R_rod)
print("d(Rodrigues,quat) =", np.abs(R_rod - q_to_R(q)).max())
print("d(Rv, qvq*)       =", np.abs(R_rod @ v - qmul(qmul(q, np.r_[0, v]), qstar)[1:]).max())
print("d(R^T R, I), det  =", np.abs(R_rod.T @ R_rod - np.eye(3)).max(), np.linalg.det(R_rod))
print("trace, 1+2cos     =", np.trace(R_rod), 1 + 2 * np.cos(th))
th_rec = np.arccos((np.trace(R_rod) - 1) / 2)
print("theta_rec, axis   =", np.rad2deg(th_rec), vee(R_rod - R_rod.T) / (2 * np.sin(th_rec)))
print("d(R(q),R(-q)), |qp|-|q||p| =", np.abs(q_to_R(q) - q_to_R(-q)).max(),
      np.linalg.norm(qmul(q, np.r_[0, v])) - np.linalg.norm(v))

# 实验 2：ZYX 欧拉角，体系角速度对三个角的雅可比
def Rx(a): c, s = np.cos(a), np.sin(a); return np.array([[1, 0, 0], [0, c, -s], [0, s, c]])
def Ry(a): c, s = np.cos(a), np.sin(a); return np.array([[c, 0, s], [0, 1, 0], [-s, 0, c]])
def Rz(a): c, s = np.cos(a), np.sin(a); return np.array([[c, -s, 0], [s, c, 0], [0, 0, 1]])
def euler(x): return Rz(x[2]) @ Ry(x[1]) @ Rx(x[0])
def euler_jac(x, h=1e-5):
    R0 = euler(x); cols = []
    for d in np.eye(3):
        dR = (euler(x + h * d) - euler(x - h * d)) / (2 * h)
        cols.append(vee(R0.T @ dR))
    return np.array(cols).T
for deg in [0, 30, 60, 80, 89, 90]:
    J = euler_jac(np.array([0.3, np.deg2rad(deg), 0.7]))
    sv = np.linalg.svd(J, compute_uv=False)
    print(f"pitch={deg:5}  det J={np.linalg.det(J):+.4f}  sigma_min={sv[-1]:.1e}  cond={sv[0] / sv[-1]:.1e}")

print("pitch60 same two perturbations     =", np.abs(euler(np.array([0.3 + d, np.pi / 3, 0.7])) - euler(np.array([0.3, np.pi / 3, 0.7 - d]))).max())

def T_of(R, p):
    T = np.eye(4); T[:3, :3] = R; T[:3, 3] = p; return T
def T_inv(T):
    R, p = T[:3, :3], T[:3, 3]; return T_of(R.T, -R.T @ p)
```

## $\rm \S \, 1.10$ 带走清单

1. SO(3) 是保长保定向的矩阵群；保长给正交（零对角化引理），连续性给 $\det = 1$。
2. so(3) 就是反对称矩阵，$\hat\omega x = \omega \times x$；幂级数三条规则 $\hat\omega^2 = \omega\omega^\top - I$、$\omega^\top\hat\omega = 0$、$\hat\omega^3 = -\hat\omega$ 造出 Rodrigues 公式。
3. 轴角与矩阵互转：$\theta = \arccos\frac{\mathrm{tr}R - 1}{2}$，轴取 $(R - R^\top)^\vee / 2\sin\theta$，$\theta \approx \pi$ 换对称部分。
4. 单位四元数 $(\cos\frac{\theta}{2}, \sin\frac{\theta}{2}\,\mathbf n)$ 经 $qvq^{-1}$ 给出与 Rodrigues 完全相同的旋转；存储 4 个数对矩阵 9 个数，复合 16 乘 12 加对 27 乘 18 加。
5. 双覆盖：$S^3 \to \mathrm{SO}(3)$ 局部一一、整体二对一；$q$ 与 $-q$ 同一旋转，插值前必须符号对齐，slerp 在大圆上匀角速走。
6. SE(3) 打包位姿，twist/wrench 打包速度与力，$\mathrm{Ad}_{T_{ab}}$ 是账本汇率且保功率；左乘 = 世界系指令，右乘 = 体坐标指令。
