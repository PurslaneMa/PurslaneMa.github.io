# $\rm Chapter \, 2$ 同调群与 Betti 数

本册第 1 章把点云粘成了复形，本章给复形装上"数洞"的仪器。仪器的名字叫同调群，它把"这个复形有几个洞"变成一道纯线性代数题：写两个矩阵、算两次秩、做一次减法。本章全程用实系数（洞的个数落在向量空间的维数上），主算例继续用第 1 章的四点正方形——外加实心三角形、空心三角形（圆的离散模型）和四面体表面（球面的离散模型），四个算例的每个秩都用 numpy 真跑过。

> **开始前自检**：本章假设你已经会：
>
> 1. □ 第 1 章的单纯形、复形与 f-向量（本册第 1 章 §1.1），本章的链群就架在单纯形上；
> 2. □ 秩-零化度定理 $\dim V = \operatorname{rank} A + \dim \ker A$ 与像、核的记号 $\operatorname{im}$、$\ker$（线性代数标准内容），§2.2 与 §2.3 的每一步都在用；
> 3. □ 商向量空间 $V / W$ 的定义与"模掉子空间"的直观（本站交换代数拓扑同调速通册或线性代数标准内容），§2.2 的 $H_k = Z_k / B_k$ 是它的直接应用；

>
> 其中第 2 条是本章的工作马——"数洞"从头到尾就是数核与像的维数差。

## $\rm \S \, 2.1$ 链群与边缘算子：把几何翻译成线性代数

先说清同调解决什么问题。"环面上有几个洞"这类问题难在"洞"没有定义：洞不是点、不是子集，用排除法说"挖掉的部分"又依赖嵌进哪个空间。同调的绕法是反着来：**不直接数洞，先数"没有洞的块"，再数"装作没有洞的链"，两者一减，剩下的就是洞**。前两种都是线性代数对象，减法是商空间——洞就这样被翻译成了维数。

翻译的第一步是给单纯形装方向。$k$-单纯形的 $k+1$ 个顶点排一个次序，写成 $[v_0, \ldots, v_k]$；顶点做奇置换视为反号：$[v_1, v_0] = -[v_0, v_1]$。直观：线段有箭头，三角形有逆时针/顺时针，四面体有左旋/右旋。**$k$-维链群** $C_k$ 定义为以全部 $k$-单纯形为基的向量空间（实系数）：

$$
C_k \;=\; \Big\{\, \sum_{\sigma} a_\sigma\, \sigma \;:\; a_\sigma \in \mathbb{R} \,\Big\}, \qquad \dim C_k = f_k
$$

（读法：$k$-链是"$k$ 维块的加权组合"——四个三角形各带一个系数加起来，就是一个 2-链。系数是实数，负系数表示"反向的那块"。）

第二步是核心零件：**边缘算子** $\partial_k : C_k \to C_{k-1}$，把每块送到它的表面：

$$
\partial_k [v_0, \ldots, v_k] \;=\; \sum_{i=0}^{k} (-1)^i\, [v_0, \ldots, \widehat{v_i}, \ldots, v_k]
$$

（读法：$k$ 维块的边界是 $k+1$ 个 $(k-1)$ 维面，第 $i$ 个面是去掉第 $i$ 个顶点剩下的那块，符号 $(-1)^i$ 交替正负——它负责让方向在粘合处两两抵消。帽子 $\widehat{v_i}$ 表示"$v_i$ 被摘掉"。）两个低维实例先把式子焐热：

1. $\partial_1 [v_0, v_1] = [v_1] - [v_0]$：线段的边缘是终点减起点，箭头的两头；
2. $\partial_2 [v_0, v_1, v_2] = [v_1, v_2] - [v_0, v_2] + [v_0, v_1]$：三角形的边缘是三条有向边，绕一圈。

主例的 $\partial_1$ 现在就能真算。四点正方形（复形：4 点 4 边，边取 $e_1 = [p_0, p_1]$、$e_2 = [p_1, p_3]$、$e_3 = [p_0, p_2]$、$e_4 = [p_2, p_3]$），以顶点为行、边为列，矩阵把每条边的"+1 头、−1 尾"记下来：

$$
\partial_1 = \begin{pmatrix}
1 & 0 & 1 & 0 \\
-1 & 1 & 0 & 0 \\
0 & 0 & -1 & 1 \\
0 & -1 & 0 & -1
\end{pmatrix}
$$

（读法：第一列是 $e_1$ 的边缘 $[p_1] - [p_0]$——第 $0$ 行 $+1$、第 $1$ 行 $-1$；四列各记一条边。）numpy 实测：$\operatorname{rank} \partial_1 = 3 < 4$。四条边在四个顶点上"花掉了"三个自由度，剩下一个没花掉的——那就是环的影子，§2.2 把它抓出来。

边缘算子的灵魂是一条恒等式：**$\partial_{k-1} \circ \partial_k = 0$（"边缘的边缘是零"）**。先在 2-单纯形上验一遍，一步不跳：

$$
\partial_1 \partial_2 [v_0, v_1, v_2]
= \partial_1 \big( [v_1, v_2] - [v_0, v_2] + [v_0, v_1] \big)
= ([v_2] - [v_1]) - ([v_2] - [v_0]) + ([v_1] - [v_0]) = 0
$$

（读法：三个顶点两两抵消——每条"边中之边"出现两次、方向相反。）一般情形的证明关键步骤：看 $\partial\partial [v_0, \ldots, v_k]$ 中同时摘掉第 $i$、$j$ 个顶点（$i < j$）的那一项，它出现两次，一次先摘 $i$ 再摘 $j$，符号 $(-1)^i (-1)^{j-1}$；一次先摘 $j$ 再摘 $i$，符号 $(-1)^j (-1)^i$。两个符号差一个 $(-1)$，成对相消，全体为零。白话：纸片的边界是一条曲线，曲线没有边界；实心块的表面是一张曲面，曲面没有边界——"有边界的东西"到第二层就封口了。

**本节小结**：链群 $C_k$ 以 $k$-单纯形为基、维数 $f_k$；边缘算子 $\partial_k$ 带交替符号地把每块送到表面；$\partial \circ \partial = 0$ 是符号成对相消的恒等式，也是下一节一切定义的合法性来源。下一节把 $\ker$、$\operatorname{im}$、商空间三个词扣在这个算子上，同调群当场出现。

## $\rm \S \, 2.2$ 同调群与 Betti 数：数洞的标准动作

定义来了。设 $K$ 是单纯复形，边缘算子串

$$
\cdots \xrightarrow{\;\partial_3\;} C_2 \xrightarrow{\;\partial_2\;} C_1 \xrightarrow{\;\partial_1\;} C_0 \xrightarrow{\;\partial_0\;} 0
$$

（读法：$\partial_0$ 把每个点送到 $0$——点没有边缘。$\partial \circ \partial = 0$ 说的是"沿箭头走两步必得零"。）在此之上：

1. **闭链群** $Z_k = \ker \partial_k$：边缘为零的 $k$-链，直观是"圈"——首尾相接、没有悬空的边；
2. **边缘链群** $B_k = \operatorname{im} \partial_{k+1}$：由 $(k+1)$ 维块产生的边缘，直观是"实心块的表面"；
3. **同调群** $H_k = Z_k / B_k$，其维数叫第 $k$ 个 **Betti 数** $\beta_k = \dim H_k$。

（读法：$Z_k$ 里的链都"自称有洞"，但其中一部分其实是某个实心块的表面——假装出来的洞。把 $B_k$ 整体模掉（视为零），剩下的才是真洞。）$\partial \circ \partial = 0$ 保证 $B_k \subseteq Z_k$（边缘的边缘是零，故边缘链都是闭链），商空间合法。

白话：**同调是一门"验洞防伪"的手艺**。四条边加成一个圈，它闭链、自称有洞；但如果复形里还有中间那块实心三角形，这个圈恰好是三角形的边缘——验伪通过：假洞。同样的圈在空心正方形里找不到任何 2-维块当靠山——真洞，$\beta_1 = 1$。这就是第 1 章 §1.2 说"VR 替你决定高维全实心"的后果落地点：**洞的死活由复形里有没有实心块裁决**。

主例当场结账（每个秩都在 §2.3 用 numpy 复核）：

1. **空心正方形**（4 点 4 边）：$Z_1$：四条边系数相等才首尾平衡（每个顶点的出、入要抵消），故 $\dim Z_1 = 1$；$B_1 = 0$（没有三角形）。$\beta_1 = 1 - 0 = 1$。另有 $\beta_0 = 4 - \operatorname{rank} \partial_1 = 4 - 3 = 1$：一个连通分支；
2. **实心三角形**（3 点 3 边 1 面）：三条边之和是中间三角形的边缘（§2.1 的实例 2），假洞验出。$\operatorname{rank} \partial_2 = 1$，$\beta_1 = \dim Z_1 - \dim B_1 = 1 - 1 = 0$；
3. **空心三角形**（3 点 3 边无面）：同样的圈无靠山，$\beta_1 = 1$——这就是"圆"在 TDA 里的离散模型。

同调群是拓扑不变量：若两个复形的几何实现同伦等价，则各维同调群同构（定理，证明要一点同调代数的 Machinery，本章不证，记住它解释了为什么 $\beta_k$ 配叫"形状的量"——它不挑模型，只认形状）。第 1 章 Nerve 定理说"nerve $\simeq$ 空间"，配上本定理，数复形的洞就等于数空间的洞——两章在此合龙。

Betti 数还欠一本总账：**Euler–Poincaré 公式**。定义**欧拉特征** $\chi = \sum_k (-1)^k f_k$，则有限复形满足

$$
\chi \;=\; \sum_{k \ge 0} (-1)^k \beta_k
$$

证明的关键步骤一步不跳。记 $r_k = \operatorname{rank} \partial_k = \dim B_{k-1}$（第 $k$ 个算子的像恰是 $B_{k-1}$），秩-零化度给出 $\dim C_k = \dim Z_k + r_k$。交错求和，裂缝在 $Z_k$ 上对齐：

$$
\sum_k (-1)^k \dim C_k = \sum_k (-1)^k \dim Z_k + \sum_k (-1)^k r_k, \qquad \sum_k (-1)^k \dim Z_k - \sum_k (-1)^k r_k = \sum_k (-1)^k \beta_k
$$

（读法：$\beta_k = \dim Z_k - \dim B_k = \dim Z_k - r_{k+1}$，两条交错和相减时 $r_k$ 的项下标错一格、正负号反而对齐，全部消去。）主例对账：空心正方形 $\chi = 4 - 4 = 0$，$\beta_0 - \beta_1 = 1 - 1 = 0$；实心三角形 $\chi = 3 - 3 + 1 = 1$，$1 - 0 = 1$；第 1 章 §1.3 存的那笔账，就此还清。

**本节小结**：闭链 $\ker \partial_k$ 减边缘 $\operatorname{im} \partial_{k+1}$ 得同调群，维数即 Betti 数；$\partial^2 = 0$ 供合法性，Euler–Poincaré 供总账，拓扑不变性供"数的是形状"的资格。下一节把全部秩交给 numpy 真算一遍。

## $\rm \S \, 2.3$ 主例：numpy 数洞

本节把 §2.2 的手算全部实跑。完整程序（边界矩阵构造 + 秩计算一体）：

```python
import numpy as np
from itertools import combinations

def betti(n_vertices, edges, tris):
    """edges: 顶点对列表; tris: 顶点三元组列表（顶点已编号 0..n-1）
    返回 (beta0, beta1, rank_d1, rank_d2)"""
    d1 = np.zeros((n_vertices, len(edges)))
    for j, (a, b) in enumerate(edges):       # 边缘: 终点 +1, 起点 -1
        d1[a, j] = 1.0
        d1[b, j] = -1.0
    d2 = np.zeros((len(edges), len(tris)))
    for j, (t0, t1, t2) in enumerate(tris):  # 三角形边界: 三条有向边
        d2[edges.index((t0, t1)), j] = 1.0
        d2[edges.index((t1, t2)), j] = 1.0
        d2[edges.index((t0, t2)), j] = -1.0
    r1 = np.linalg.matrix_rank(d1)
    r2 = np.linalg.matrix_rank(d2) if d2.size else 0
    beta0 = n_vertices - r1                  # ker d0 = 全空间
    beta1 = (len(edges) - r1) - r2           # dim Z1 - dim B1
    return beta0, beta1, r1, r2, d1, d2

cases = {
    "一条线段":   (2, [(0, 1)], []),
    "空心正方形": (4, [(0, 1), (1, 3), (0, 2), (2, 3)], []),
    "实心三角形": (3, [(0, 1), (1, 2), (0, 2)], [(0, 1, 2)]),
    "空心三角形": (3, [(0, 1), (1, 2), (0, 2)], []),
}
for name, (nv, e, t) in cases.items():
    b0, b1, r1, r2, _, _ = betti(nv, e, t)
    print(f"{name}: rank d1={r1}, rank d2={r2} -> beta0={b0}, beta1={b1}")

_, _, _, _, d1, d2 = betti(3, [(0, 1), (1, 2), (0, 2)], [(0, 1, 2)])
print("d1 @ d2 (应全零):")
print((d1 @ d2).astype(int))
```

实跑输出（本章数值锚，照抄）：

```text
一条线段: rank d1=1, rank d2=0 -> beta0=1, beta1=0
空心正方形: rank d1=3, rank d2=0 -> beta0=1, beta1=1
实心三角形: rank d1=2, rank d2=1 -> beta0=1, beta1=0
空心三角形: rank d1=2, rank d2=0 -> beta0=1, beta1=1
d1 @ d2 (应全零):
[[0]
 [0]
 [0]]
```

四个算例与 §2.2 手算逐一吻合，几处细节值得抠：

1. **$\partial_2$ 的符号**：三角形 $(t_0, t_1, t_2)$ 的边界三项系数是 $+1, +1, -1$（对应 $[t_0,t_1]$、$[t_1,t_2]$、$[t_0,t_2]$）——第三条边按边的自然定向走时与环绕方向相反，所以要负号。符号写错，$\partial_1 \partial_2 \ne 0$，秩全乱；程序里那条"d1 @ d2 应全零"就是为此设的免费账本；
2. **手算对照（空心三角形）**：$Z_1 = \{(a, b, c) \in \mathbb{R}^3 : \partial_1(a e_1 + b e_2 + c e_3) = 0\}$。三个顶点各出一个平衡方程，解出来 $a = b = c$——解空间一维，圈就是"三条边等权绕一圈"；$B_1 = 0$，故 $\beta_1 = 1$。秩 $\operatorname{rank} \partial_1 = 2$ 与"3 个方程中只有 2 个独立"（三式相加恒为零）吻合；
3. **系数域的注记**：本章全用实系数。模 $2$ 系数（$-1 = +1$，方向消失）在同调里同样常用，本册的算例上两种系数答案一致；一般空间会出现实系数下消失、模 2 系数下多出来的洞（扭元现象），那是更深的章节的事，本册不进；
4. **数值注记**：`matrix_rank` 走奇异值分解，浮点世界里"整数矩阵"的秩判定要留心病态；本章矩阵的奇异值要么是 $0$ 要么 $\ge 1$ 量级，判定无歧义。正式的同调计算用整数系数加 Smith 标准形，numpy 只作佐证。

**本节小结**：四个小复形的 $\beta_0, \beta_1$ 全部落定——线段 $(1, 0)$、空心正方形 $(1, 1)$、实心三角形 $(1, 0)$、空心三角形（圆）$(1, 1)$；$\partial_1 \partial_2 = 0$ 的数值检查把符号约定钉死。下一节把"数洞"整理成可以直接心算的公式。

## $\rm \S \, 2.4$ $H_0$ 与 $H_1$ 的直观计算：图情形的全部答案

白话：只用到 1-骨架（没有 2-维面）的复形就是图论里的图，这时同调有闭式解，全部答案可以心算。先把两个维数的直观钉死：

1. $\beta_0$ = 连通分支数。$Z_0 = C_0$（点的边缘是零，人人都是闭链），$B_0 = \operatorname{im} \partial_1$——"被边连起来的两点算一个"，模掉它正好是按连通分支分类。$\beta_0 = \dim C_0 - \operatorname{rank} \partial_1$；
2. $\beta_1$ = 独立的圈数。"独立"指：没有一个圈能由别的圈的线性组合拼出来。

**定理（图情形的闭式解）**：设图 $G$ 有 $V$ 个顶点、$E$ 条边、$C$ 个连通分支，则

$$
\beta_0 = C, \qquad \beta_1 = E - V + C
$$

证明的关键步骤：$\operatorname{rank} \partial_1 = V - C$。一个连通分支里取生成树（$V_c$ 个顶点 $V_c - 1$ 条边），树的关联矩阵列满秩到 $V_c - 1$（逐条边剥叶子：每条叶边的列在叶子那行是唯一的非零项），非树边不添秩（圈的剩余部分能表出它）；$C$ 个分支加总得 $V - C$。于是 $\beta_0 = V - (V - C) = C$，且 $\dim Z_1 = E - (V - C)$，$B_1 = 0$（没有 2-面），$\beta_1 = E - V + C$。

主例对账：空心正方形 $\beta_1 = 4 - 4 + 1 = 1$；两个不相交的圆（$V = 6, E = 6, C = 2$）$\beta_0 = 2$、$\beta_1 = 6 - 6 + 2 = 2$——两个洞，互不抵消；一条线段 $1 - 2 + 1 = 0$。§2.3 的 numpy 输出全部吻合。

加上 2-维面后唯一的质变是 $\beta_1$ 被咬掉（圈成为假洞）与 $\beta_2$ 冒出来（空腔）。标准算例是**四面体表面**——球面 $S^2$ 的离散模型（4 点 6 边 4 面，全部按全复形取 $3$ 层以下）。numpy 实测：$\operatorname{rank} \partial_1 = 3$、$\operatorname{rank} \partial_2 = 3$，于是

$$
\beta_0 = 4 - 3 = 1, \qquad \beta_1 = (6 - 3) - 3 = 0, \qquad \beta_2 = \dim Z_2 - 0 = 4 - 3 = 1
$$

（读法：$Z_2$ 是 2-闭链——四个带权三角形的边缘为零。解方程得解空间一维：四个系数全相等，即"四个面等权合围"那一个闭链；它不是任何 3-维块的边缘（没有 3-单纯形），故 $\beta_2 = 1$：一个空腔。）欧拉特征对总账：$\chi = 4 - 6 + 4 = 2$，$\beta_0 - \beta_1 + \beta_2 = 1 - 0 + 1 = 2$——多面体公式 $V - E + F = 2$ 是 Euler–Poincaré 的特例。

$\beta_k$ 的字典至此齐备：$\beta_0$ 数连通分支，$\beta_1$ 数独立圈，$\beta_2$ 数空腔；更高维照此类推（"$k$ 维空腔"）。第 1 章 §1.3 那句"洞活在 $[1, \sqrt{2}]$"现在有了精确定义：$\beta_1(\varepsilon)$ 在 $[1, \sqrt{2})$ 上等于 $1$、在窗口外等于 $0$。但 $\beta_1(\varepsilon)$ 这个阶梯函数本身有损：同一时刻生死的洞会互相冒充，"出生早的死得早"这类配对信息全被抹平。第 3 章开正式账本：把每个洞的生卒年月一条条记下来——持久同调。

**本节小结**：图情形 $\beta_0 = C$、$\beta_1 = E - V + C$ 全闭式，证明靠"生成树剥叶子"；四面体表面给出 $\beta_2 = 1$ 的空腔算例与 $\chi = 2$ 的对账。Betti 字典：分支、圈、腔。下一章把 Betti 数从"一个 $\varepsilon$ 一张快照"升级成"每个洞一份户口"。

## $\rm \S \, 2.5$ 关键概念回顾（六问）

1. 同调为什么绕道"闭链减边缘"而不直接定义洞？"洞不是子集"这句话在 $H_k = Z_k / B_k$ 里对应哪一步？

## $\rm \S \, 2.6$ 程序段：四面体表面的完整同调

把 §2.4 的 $S^2$ 算例变成可复跑程序（含 $\partial_2$ 全矩阵与 $\partial^2 = 0$ 检查）：

```python
import numpy as np
from itertools import combinations

n = 4
edges = list(combinations(range(n), 2))      # 6 条边
tris = list(combinations(range(n), 3))       # 4 个面
d1 = np.zeros((n, len(edges)))
for j, (a, b) in enumerate(edges):
    d1[a, j], d1[b, j] = 1.0, -1.0
d2 = np.zeros((len(edges), len(tris)))
for j, (t0, t1, t2) in enumerate(tris):
    d2[edges.index((t0, t1)), j] = 1.0
    d2[edges.index((t1, t2)), j] = 1.0
    d2[edges.index((t0, t2)), j] = -1.0
assert np.allclose(d1 @ d2, 0), "d1@d2 != 0, 符号约定错了"
r1, r2 = np.linalg.matrix_rank(d1), np.linalg.matrix_rank(d2)
print("d2 =")
print(d2.astype(int))
print(f"beta0={n - r1}, beta1={(len(edges) - r1) - r2}, beta2={len(tris) - r2}")
print("chi check:", n - len(edges) + len(tris), "==", (n - r1) - ((len(edges) - r1) - r2) + (len(tris) - r2))
```

读程序的三句话：`assert d1 @ d2 == 0` 挡住最高频的错误（$\partial_2$ 符号约定），比事后对答案便宜；$\beta_2 = \dim Z_2 - \dim B_2$ 里 $B_2 = 0$（没有 3-单纯形），所以 $\dim Z_2 = 4 - \operatorname{rank} \partial_2$；欧拉对账一行写出"组合侧 = 同调侧"，两边不等必有一边算错。

## $\rm \S \, 2.7$ 六问参考答案

1. "洞"不是点、不是子集，无法直接当对象操作；而闭链与边缘都是矩阵的核与像，纯线性代数。$H_k = Z_k / B_k$ 里的"模掉"就是处理手段：假洞（实心块的表面）整体视为零，商掉后剩下的维数才是真洞的个数。（§2.2）
2. 同时摘第 $i < j$ 个顶点的项：先摘 $i$ 后摘 $j$ 符号 $(-1)^i(-1)^{j-1}$，先摘 $j$ 后摘 $i$ 符号 $(-1)^j(-1)^i$，两者差一个负号、成对相消。展开：$\partial_1([v_1,v_2] - [v_0,v_2] + [v_0,v_1]) = ([v_2]-[v_1]) - ([v_2]-[v_0]) + ([v_1]-[v_0]) = 0$。（§2.1）
3. $Z_1$ 记"自称有洞的圈"，但正方形的圈没有 2-维块撑腰（$\dim B_1 = 0$），三角形的圈恰是中间面的边缘（$\dim B_1 = 1$）。防的是"假洞"：能写成某个实心块边缘的圈冒充洞。（§2.2）
4. $\beta_k = \dim Z_k - r_{k+1}$，两条交错和一条含 $r_k$、一条含 $r_{k+1}$，下标错一格正负号恰好对齐，$r$ 项成对消去。正方形：$\chi = f_0 - f_1 = 0$，$\beta_0 - \beta_1 = 1 - 1 = 0$。（§2.2）
5. 论证 $\operatorname{rank} \partial_1 = V - C$：树剥叶子证树的秩 $= V_c - 1$，非树边不添秩（圈表出它）。两个圆 $\beta_1 = 2$：两家的圈谁也不能由谁线性组合出来——独立的"独立"是线性无关，不是几何互不相交。（§2.4）
6. 四个面的系数全相等（$\partial_2$ 的核是一维的"等权合围"向量）；复形里没有 3-单纯形，$B_2 = 0$，任何非零闭链都不是边缘——这个空腔是 $S^2$ 的指纹。（§2.4）
