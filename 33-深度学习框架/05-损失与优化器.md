## $\rm \S \, 5.1$ 拿到梯度之后：三种优化器怎么建

`model.parameters()` 给出一张参数张量的清单，`.grad` 给了每个参数的梯度；优化器就是“拿着这张清单和梯度，按某种规则定期改这些数”的对象。PyTorch 把三种经典规则做成三个类，构造方式几乎一样，只换类名与超参：

```python
import torch
from torch import nn
model = nn.Sequential(nn.Linear(2, 8), nn.ReLU(), nn.Linear(8, 1))
opt = torch.optim.SGD(model.parameters(), lr=0.1, momentum=0.9)          # 带动量的 SGD
opt = torch.optim.Adam(model.parameters(), lr=1e-3)                      # 自适应步长
opt = torch.optim.AdamW(model.parameters(), lr=1e-3, weight_decay=0.01)  # 解耦的正则
```

第一个实参 `model.parameters()` 是关键：优化器要拿到的是一张参数张量的清单，它只改这些张量，传 `model`、传 `loss` 都会当场报错（§5.6 有真报错原文）。三种规则各有习性：SGD 最朴素，每一步只看当前梯度；Momentum 记住过去的方向，梯度方向一致时加速、反转时冲过头；Adam 给每个参数算自适应步长，初期收敛快、调参省心，代价是多存两份状态。选哪个取决于数据规模与调参预算。

| 写法 | 说明 |
| --- | --- |
| `torch.optim.SGD(model.parameters(), lr=0.1, momentum=0.9)` | 沿梯度方向走；`lr` 是步长，`momentum` 给惯性 |
| `torch.optim.Adam(..., lr=1e-3)` | 每个参数自适应步长，默认 ${(\beta_1,\beta_2)=(0.9,0.999)}$ |
| `torch.optim.AdamW(..., lr=1e-3, weight_decay=0.01)` | 正则写进更新式，与自适应缩放解耦（§5.5） |

## $\rm \S \, 5.2$ 一步训练的三句顺序：zero_grad、backward、step

优化器建好之后，一步训练里它和反向传播的先后顺序是固定的：

```python
opt.zero_grad()                 # 1. 清掉上一步残留的 .grad
loss = loss_fn(model(xb), yb)   # 2. 前向 + 算损失
loss.backward()                 # 3. 反向：梯度写进各参数
opt.step()                      # 4. 优化器读 .grad、改参数
```

第 1、3、4 步归优化器管，顺序不能换：`zero_grad` 必须在 `backward` 之前，否则会把自己本步刚算出的梯度清掉；`step` 必须在 `backward` 之后，否则优化器读到的是上一步的旧梯度，更新滞后并错乱；写完 `backward` 忘了 `step`，梯度算了一堆，参数永远不动。忘了 `zero_grad` 则相反，梯度一路累加越滚越大（第 6 章有一个只看三个数的分叉实验）。

| 写法 | 说明 |
| --- | --- |
| `opt.zero_grad()` | 把上一步残留的 `.grad` 清零，每步开头调 |
| `loss.backward()` | 反向算出本步梯度，写进各参数（第 2 章） |
| `opt.step()` | 优化器按规则读 `.grad`、写参数 |

`opt.step()` 内部并不只有梯度：Momentum 要记住速度 ${v}$，Adam 要记住梯度的一阶矩与二阶矩（§5.5 的 ${m,s}$）与步数 ${t}$，这些数存在优化器里、不在模型参数里。真跑一步后 `opt.state_dict()['state'][0]` 的键是 `['step', 'exp_avg', 'exp_avg_sq']`（WSL Ubuntu，PyTorch 2.14.1+cpu，float64）。所以续训只存 `model.state_dict()` 会丢掉 ${v}$、${m,s,t}$，优化器状态得跟模型一起存，第 9 章给清单。

## $\rm \S \, 5.3$ 学习率与参数组：第一个该调的旋钮

真要动手调，第一个该动的旋钮是学习率（`lr`）：太大直接发散，太小半天不动，其他超参基本排它后面。`torch.optim.lr_scheduler` 让 `lr` 随训练自动变小，一行挂上去：

```python
sched = torch.optim.lr_scheduler.StepLR(opt, step_size=30, gamma=0.1)   # 每 30 epoch 乘 0.1
sched = torch.optim.lr_scheduler.CosineAnnealingLR(opt, T_max=100)      # 余弦曲线退火
```

两者都在每个 epoch 末尾调一次 `sched.step()`；更细的调度（按验证集降 `lr` 的 `ReduceLROnPlateau`、热启动、学习率与 batch size 的换算）放主线第 43 章（[PyTorch 与模型训练全过程](../06-编程语言/43-PyTorch与模型训练全过程.md)）。另一个常用写法是参数组：不同层给不同的 `lr` 与 `weight_decay`，比如分类头学快点、主干带正则：

```python
opt = torch.optim.SGD([{'params': model[0].parameters(), 'lr': 1e-3},
                       {'params': model[2].parameters(), 'lr': 1e-2, 'weight_decay': 0.01}], lr=0.1)
```

传的是一张“参数组”列表，每组里 `params` 必填，`lr`、`weight_decay` 等没写的项继承构造函数上的默认值。

## $\rm \S \, 5.4$ 打开盖子：log-sum-exp 与稳定 softmax

不打开盖子，你用 `nn.CrossEntropyLoss`（第 4 章）时不知道它内部替你做了什么，也不知道 logits 一大为什么损失会直接变成 `nan`。先写出最小实现，MSE 五行，照第 4 章层的签名写：

```python
def mse(pred, y):
    diff = pred - y
    return (diff * diff).mean(), 2 * diff / diff.size   # loss 与 dL/dpred
```

交叉熵加 softmax 麻烦在数值：logits 一大，`exp` 先溢出。真跑一组：logits 取 ${(1000,1001,1002)}$，朴素实现 `exp(z)` 得 `[inf, inf, inf]`，softmax 得 `[nan, nan, nan]`；float64 最大约 ${1.8\times10^{308}}$，而 ${e^{1000}\approx 10^{434}}$，早在溢出线上。稳定版利用一条恒等式：softmax 分子分母同乘 ${e^{-\max z}}$ 值不变，于是先把每个 logits 减去最大值再取指数，指数参数全部落到非正数：

```python
def softmax_ce(z, y):                        # z: (n,C)，y: one-hot
    z = z - z.max(axis=1, keepdims=True)     # 减最大值，指数不再溢出
    ez = np.exp(z)
    p = ez / ez.sum(axis=1, keepdims=True)
    return -(y * np.log(p)).sum(axis=1).mean(), (p - y) / len(y)
```

真跑验证：稳定版 softmax 得 ${[0.0900,\ 0.2447,\ 0.6652]}$，与 `torch.softmax` 的差 ${2.8\times10^{-17}}$（float64）。减最大值之所以合法，是把恒等式写成式子看（记 ${M=\max_j z_j}$）：

$$
\mathrm{softmax}(z)_k=\frac{e^{z_k}}{\sum_j e^{z_j}}=\frac{e^{z_k-M}}{\sum_j e^{z_j-M}},
$$

分子分母同乘了同一个 ${e^{-M}}$，比值不变；右边每个指数参数 ${z_k-M\le 0}$，最大只到 ${e^0=1}$，溢出从根上消失。这就是 log-sum-exp 技巧：凡是“指数后求和（或求 log）”的地方都必须先减最大值，梯度公式 ${\partial L/\partial z=p-y}$（softmax 减 one-hot）不受影响，推导见深度学习分册第 3 章。torch 的 `nn.CrossEntropyLoss` 内部就是这套稳定实现，所以你不用自己写，也就明白了它为什么直接吃 logits 而不吃已经 softmax 过的概率。

## $\rm \S \, 5.5$ 打开盖子：三个更新式与 torch.optim 逐数对照

不打开盖子，`opt.step()` 只是黑箱的一行；这一节把三种规则各写成 8 行，再用同超参的逐数对照证明 torch 走的就是它们。优化器只做一件事：拿着梯度改参数。

```python
def sgd_step(w, g, lr):
    return w - lr * g                    # 沿坡度往下走一步

def momentum_step(w, g, lr, v, beta=0.9):
    v = beta * v - lr * g                # 速度：过去方向的惯性
    return w + v, v

def adam_step(w, g, lr, m, s, t, b1=0.9, b2=0.999, eps=1e-8):
    m = b1 * m + (1 - b1) * g            # 一阶矩：梯度的滑动平均
    s = b2 * s + (1 - b2) * g * g        # 二阶矩：梯度平方的滑动平均
    m = m / (1 - b1 ** t)                # 偏置校正
    s = s / (1 - b2 ** t)
    return w - lr * m / (np.sqrt(s) + eps), m, s
```

Adam 的偏置校正是唯一需要解释的一行：${m,s}$ 从 0 起步，训练初期滑动平均被系统性低估（前几步的 ${m\approx(1-b_1^t)\,\mathbb{E}[g]}$），除以 ${1-b^t}$ 恰好补回这个系数；${t}$ 一大它趋于 1，校正自动退场。${v}$、${m}$、${s}$ 是跨步保存的优化器状态，`w` 是参数，来自第 4 章的 `parameters()`；优化器不碰前向反向，只读梯度、写参数。

实验设定：20 个样本、2 特征的小数据集（`np.random.default_rng(0)`，7 正 13 负），逻辑回归，损失用稳定的数值形式 ${L=\mathrm{mean}\big(\mathrm{logaddexp}(0,z)-yz\big)}$（等价于交叉熵，且无溢出问题）；初始 ${w_0=(0.1,-0.1)}$；超参 SGD ${\mathrm{lr}=0.5}$、Momentum ${\mathrm{lr}=0.1}$、Adam ${\mathrm{lr}=0.3}$。迷你实现跑出的 loss 轨迹（前 10 步）：

| 步 | SGD | Momentum | Adam |
| --- | --- | --- | --- |
| 0 | 0.6667 | 0.6667 | 0.6667 |
| 1 | 0.6400 | 0.6611 | 0.5972 |
| 2 | 0.6176 | 0.6510 | 0.5417 |
| 3 | 0.5985 | 0.6373 | 0.4969 |
| 4 | 0.5821 | 0.6212 | 0.4612 |
| 5 | 0.5677 | 0.6037 | 0.4333 |
| 6 | 0.5551 | 0.5857 | 0.4112 |
| 7 | 0.5439 | 0.5679 | 0.3939 |
| 8 | 0.5337 | 0.5509 | 0.3805 |
| 9 | 0.5246 | 0.5350 | 0.3704 |
| 10 | 0.5162 | 0.5202 | 0.3628 |

Adam 前期一骑绝尘：自适应步长在前几步等效放大了走步距离；Momentum 因 ${\mathrm{lr}}$ 设得保守起步最慢，惯性尚未积累。三种超参各不相同，这张表演示的是机制差异，不是排名。与 `torch.optim` 的同超参对照（float64，同一 ${w_0}$ 与数据）如下，torch 侧的实验代码三个优化器各跑一遍、只换一行构造：

```python
tw = torch.tensor(w0, requires_grad=True)
opt = torch.optim.Adam([tw], lr=0.3)     # SGD / SGD(momentum=0.9) 各换一行
for _ in range(10):
    opt.zero_grad()
    loss = F.binary_cross_entropy_with_logits(tX @ tw, ty)
    loss.backward()
    opt.step()
```

十步之后的逐数对照：

| 优化器 | torch 侧实现 | ${\max|\Delta w|}$ | ${\max|\Delta L|}$ |
| --- | --- | --- | --- |
| SGD | `torch.optim.SGD(lr=0.5)` | ${1.1\times10^{-16}}$ | ${1.1\times10^{-16}}$ |
| Momentum | `torch.optim.SGD(momentum=0.9)` | ${2.8\times10^{-17}}$ | ${1.1\times10^{-16}}$ |
| Adam | `torch.optim.Adam(lr=0.3)` | ${4.4\times10^{-16}}$ | ${1.1\times10^{-16}}$ |

验证环境：WSL Ubuntu，PyTorch 2.14.1+cpu，float64。十步之后参数与 loss 逐数一致，机器精度级。顺带一提，torch 的 Momentum 写法是 ${v=\beta v+g}$ 然后 ${w\mathrel{-}= \mathrm{lr}\cdot v}$，与上面的 ${v=\beta v-\mathrm{lr}\cdot g}$ 相差一个因子 ${-\mathrm{lr}}$，两种写法展开后逐项相同，对照实验也证实了这一点。weight decay 的位置也在这里落地：L2 惩罚把它算进梯度（${g\gets g+\lambda w}$），Adam 下它会被 ${1/\sqrt{s}}$ 的自适应缩放稀释，大梯度的参数反而衰减少；decoupled weight decay（AdamW）把它放进更新式（${w\gets w-\mathrm{lr}\cdot\lambda\cdot w}$），与自适应缩放解耦。一句话：罚在梯度里还是罚在更新里，SGD 下等价，Adam 下不等价，AdamW 是后者的名字。

## $\rm \S \, 5.6$ 常见错误与报错翻译

1. 忘了 `zero_grad()`：`.grad` 是累加写入，不清零就把上一步的旧账混进本步，表现为 loss 剧烈震荡甚至 `nan`；改法是每步开头 `opt.zero_grad()`（第 6 章的分叉实验只差这一个调用）。
2. 把 `model` 而不是 `model.parameters()` 传进优化器：报 `TypeError: optimizer can only optimize Tensors, but one of the params is torch.nn.modules.linear.Linear`；原因是优化器遍历实参翻出来的是一层层的 `Module` 而不是张量，改传 `model.parameters()`。
3. 把 `loss`（或任意普通张量）传进优化器：报 `TypeError: params argument given to the optimizer should be an iterable of Tensors or dicts, but got torch.DoubleTensor`（口径：模型与损失都是 float64，故显示 `DoubleTensor`）；优化器只吃“参数张量或参数组字典”的一串可迭代对象，改传参数清单。
4. 顺序写错：在 `step()` 之前 `zero_grad()`，等于把本步刚算的梯度清了白跑；写完 `backward()` 忘了 `step()`，参数永远不动。改法是固定 `zero_grad → backward → step`（§5.2）。

## $\rm \S \, 5.9$ 本章自测答案

### $\rm \S \, 5.9.1$ 关键概念回顾答案

1. `exp(1000)` 溢出为 inf，softmax 变 nan；稳定版靠“分子分母同乘 ${e^{-\max z}}$ 值不变”，先把 logits 平移到非正数。（§5.4）
2. 指数运算量级悬殊，直接算必溢出；${\partial L/\partial z=p-y}$。（§5.4）
3. ${v}$ 是过去梯度的指数滑动平均（带符号的惯性）；一致方向的梯度累积成大步，方向反转时惯性使它冲过头再回调。（§5.5）
4. 修正 ${m,s}$ 从零起步造成的初期低估；除以 ${1-b^t}$，${t}$ 大时趋于 1，校正自动退场。（§5.5）
5. L2 加在梯度上（${g\gets g+\lambda w}$），AdamW 加在更新上（${w\gets w-\mathrm{lr}\,\lambda w}$）；SGD 下两者等价，Adam 的自适应缩放使它们分道。（§5.5）

### $\rm \S \, 5.9.2$ 应用与辨析答案

1. 平移后 ${(0,1,2)}$：${e^0+e^1+e^2\approx 1+2.718+7.389=11.107}$，得 ${0.0900,\ 0.2447,\ 0.6652}$，与表一致。（§5.4）
2. 偏大：${m}$ 低估了 ${|\mathbb{E}[g]|}$，本应除以 ${1-b_1}$（第 1 步为 0.1 的补数即 ${\times 10}$）的修正消失，更新量约小一个数量级。（§5.5）
3. 更大：梯度 ${|p-y|\approx 1}$ 达到上界；交叉熵对自信的错判惩罚最重，这正是它比 MSE 适合分类的原因。（§5.4）
4. L2：在算出 ${g}$ 后加一行 `g = g + 0.01 * w`；AdamW：在更新行加一项 `w = w - lr * 0.01 * w`。第 1 步两者都给 ${w}$ 一个 ${-0.001}$ 到 ${-0.003}$ 量级的额外位移（${\mathrm{lr}\lambda w}$），方向相同、路径不同，差别要很多步后才显现。（§5.5）
5. 参数组写法见 §5.3 的片段：`torch.optim.SGD([{'params': model[0].parameters(), 'lr': 1e-3}, {'params': model[2].parameters(), 'lr': 1e-2}], lr=0.1)`，主干用小组、分类头用大组。（§5.3）
