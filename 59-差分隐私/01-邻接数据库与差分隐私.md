# $\rm Chapter \, 1$ 邻接数据库与 $(\varepsilon,\delta)$-差分隐私

前面所有册子处理数据时都默认一条铁律：数据是拿来用的——统计、回归、训练模型，都是把每个人的一条记录摊在桌面上。这一册问的是反面：能不能既用数据、又不认识任何一个具体的人？关键在于这不是工程问题。往表里加一列假名、涂掉身份证号，都是工程手段，而历史已经证明它们防不住认真的人。

要谈论「保护」，得先把「泄露隐私」定义成一个可证伪的数学命题，然后针对这个命题设计机制、给出证明。本章立起全册的三块基石：**邻接数据库**（「有没有我」的数学化）、$(\varepsilon,\delta)$-差分隐私（保护本身的定义）、**敏感度**（噪声大小的总开关）；并证明一件反直觉的事——任何确定性函数都不可能满足差分隐私，随机化不是实现细节，是入场券。第 2 章在这一地基上造出三台可用的机器（Laplace、Gaussian、指数机制），第 3 章回答「多问几个问题会怎样」。

## $\rm \S \, 1.1$ 为什么需要形式化的隐私定义

白话：「匿名化」听起来很朴素——把姓名、身份证号删掉再发布，剩下的就是「纯数据」。历史给出的结论残酷得多：删掉标识符之后，剩下的字段自己就是指纹。

1. **链接攻击（linkage attack）**：Sweeney 在 1997 年演示，马萨诸塞州把州政府雇员的医疗记录「匿名化」后公开（保留邮编、出生日期、性别），而这些字段与公开的选民名册完全重合——花几十美元买一份名册做交叉比对，就能把匿名记录逐条还原成真人，第一位被认出来的正是州长本人。她的统计更广：$87\%$ 的美国人会被 $\{$邮编, 出生日期, 性别$\}$ 三元组唯一标识。
2. **Netflix Prize**：2006 年 Netflix 公布 50 万用户的匿名影评办推荐算法竞赛，Narayanan 与 Shmatikov（2008）把它与 IMDb 上的公开影评按「评分模式」链接——每个人那几百条评分构成一个高维稀疏向量，几乎必然独一无二——于是「匿名」用户被逐个认出，连带暴露其影评里没写的政治倾向等敏感信息。

两条历史的共同教训：**删标识符防的是一张名单，防不了攻击者从别的渠道带来的背景知识**，而且你不知道背景知识是什么、有多少。维数越高、记录越个人化，唯一性越严重——这其实是[高维概率册第 3 章](../39-高维概率与矩阵分析/03-维数诅咒与高维几何.md) 维数诅咒的另一副面孔。

还要看清隐私损害本身是什么。Sweeney 讲过一个意象：假如你的医疗记录参与了研究，得出的结论让法庭对你从轻发落，你会觉得值得；假如换个研究问题，同一个字段让法庭对你从重处置，你还会因为「没人认出我」而觉得无妨吗？损害不来自「被点名」，来自「关于你的真实信息参与了某个对你的决定」。所以保护目标不能只盯身份，要盯**一切从数据里流出的、关于你的影响**。

既然堵不住背景知识，定义就只能换路线：不假设攻击者知道什么，只对**发布的结果**提要求。

差分隐私的目标可以压缩成一句话：**数据库里有没有我这一条记录，对发布结果的分布几乎没有影响。** 注意措辞是「分布」而不是「输出」。不是保证你算不出某个具体数字——那做不到，也是不必要的——而是保证同一套机制在「有我」和「没我」两个世界里跑，输出服从的概率规律几乎一样。攻击者拿到的任何结论（均值、区间、图）在两个世界里的可信度都被钉死在同一水平，它就无法从「结果长什么样」反推「我在不在里面」。

把这句话变成定理，是接下来三节的工作。

**本节小结**：匿名化的两次著名失败都来自链接攻击——删掉标识符后，剩余字段与外部知识交叉仍能定位个人；因此隐私定义绕开「删什么」，直接要求「有无一条记录，输出分布几乎不变」。

## $\rm \S \, 1.2$ 邻接数据库：「多一个人、少一个人」的数学化

白话：要说「有没有我几乎不影响结果」，先得把「有没有我」写成数学对象。差分隐私的答案是**邻接关系**：两个数据库相邻，如果它们只差一条记录。

设 $\mathcal{X}$ 是数据宇宙——单条记录的取值范围，例如「一条收入记录是区间 $[0,100]$（万元）里的一个数」；数据库是多重集 $D\in\mathcal{X}^n$。两种邻接口径都在用，差别必须分清：

1. **替换型（replace-one）**：$D$ 与 ${D'}$ 等长，且 Hamming 距离不超过 $1$——恰好一个位置上的记录不同。语义：某个人**改了**自己填报的信息。
2. **加去型（add/remove）**：$D'=D\cup\{x\}$ 或 $D'=D\setminus\{x\}$——两者比对方多一条或少一条记录。语义：某个人**到场或缺席**。

两种口径都记作 $D\sim D'$，全册通用，形式定义如下：

$$
D\sim D'\iff \mathrm{dist}_{\mathrm{Ham}}(D,D')\le 1\ \text{且}\ |D|=|D'|
$$

$$
D\sim D'\iff D'=D\cup\{x\}\ \text{或}\ D'=D\setminus\{x\},\quad x\in\mathcal{X}
$$

读法：上一行比较的是「同长度、至多换一人」，$\mathrm{dist}_{\mathrm{Ham}}$ 数的是位置不同的记录条数；下一行比较的是「多一条或少一条」，$x$ 就是那一位当事人的记录。两种口径对隐私的定义毫无影响（都刻画「只差一个人」），但**配什么查询**手感完全不同：

1. **计数查询**「满足性质 $P$ 的人数」配加去型：来一个人计数至多 $+1$，走一个人至多 $-1$，答案对邻接的响应恰为 $1$，而且语义干净——被保护的正是「我在不在这个数里」。
2. **人均收入** $\mathrm{mean}(D)=\frac{1}{n}\sum_i x_i$ 配替换型：替换型下 $n$ 不动，一条记录从 $x$ 换成 ${x'}$，均值至多挪动 $|x-x'|/n$；加去型下分母也在动（$n$ 变 $n\pm 1$），敏感度要背上 $n/(n+1)$ 一类的修正项，写起来别扭、用起来含糊。

选型经验：答案里带 $n$ 的查询（均值、比例、人均量）用替换型；纯数人头的用加去型。全册两种口径都会出现，用到时都会标明。

还有一个马上要用的几何视角：把所有数据库看成一张图的顶点、邻接关系看成边。计数查询的世界里这张图是连通的——任何两个库都能靠增删记录走到一起；§1.4 的证明恰好要踩这个性质。

最后一件小事值得现在说破：邻接是**对称**关系——$D\sim D'$ 蕴含 $D'\sim D$——所以后面任何「对相邻库成立的保证」都自动双向有效，这个性质在 §1.3 和第 3 章的证明里各要用一次。

> **易混点**：邻接刻画的是「库与库的差别」，不是「记录与记录的相似」。也别把它和 $k$-匿名（$k$-anonymity）混为一谈：后者是对**数据集**做的泛化处理（让每个等价类至少含 $k$ 条记录），是一种发布格式；差分隐私是对**机制**——查询如何被回答——下的定义，是带证明的保证。两者方向不同，而且 $k$-匿名挡不住同质攻击：一个等价类里 $k$ 条记录全一样时，「匿名」恰恰等于公开。

**本节小结**：邻接是「只差一条记录」的两种数学化——替换型（等长换一人）与加去型（多一条或少一条）；计数配加去型、人均量配替换型，选型看答案里有没有 $n$。

## $\rm \S \, 1.3$ $(\varepsilon,\delta)$-差分隐私：定义与逐符号读法（本章主证一）

白话：定义说的是——不管你拿这套机制查什么，在「库里有你」和「库里没你」两个世界里，任何一组输出出现的概率至多差 $\mathrm{e}^{\varepsilon}$ 倍，外加一笔小到可以忽略的豁免额度 $\delta$。

先立对象。**随机化机制（mechanism）** $M$ 把数据库映到一个随机输出：给定 $D$，$M$ 掷自己的硬币，输出分布 $\Pr[M(D)\in\cdot]$。定义只有一行：

> **定义（$(\varepsilon,\delta)$-差分隐私）**：$M$ 满足 $(\varepsilon,\delta)$-差分隐私（differential privacy），若对每一对相邻 $D\sim D'$ 与每一个可测事件 $S\subseteq\mathrm{Range}(M)$ 都有
>
> $$
> \Pr[M(D)\in S]\ \le\ \mathrm{e}^{\varepsilon}\,\Pr[M(D')\in S]+\delta
> $$

一句话总结这个定义的形状：**对最坏的相邻对、对一切事件，两个世界分布的似然比被封顶**。五个部件逐个读：

1. **$\Pr$ 的样本空间**是机制自己的随机硬币，不是数据库的随机性——$D$ 是确定的对象，一切随机性来自 $M$ 内部。这就是 §1.4 要证明「必须随机化」的原因。
2. **全称量词 $\forall D\sim D'$**：最坏情况口径。定义不假设攻击者面对的是哪个库，甚至不假设它只有一份背景知识；它要求**每一对**相邻库都通过同一关。最强的攻击者也只能挑一对相邻库、挑一个事件。
3. **全称量词 $\forall S$**：保护到事件级别，不是单点级别。攻击者可以构造任何有利可图的输出集合——例如「输出落在这个能识别我的小区间里」——来算这笔账；要求所有 $S$ 同时安全，等于把整套概率分布的似然比都管住。
4. **$\mathrm{e}^{\varepsilon}$ 是乘性项**，管**比值**：两个世界输出同一事件的概率之比被 $\mathrm{e}^{\varepsilon}$ 封顶。$\varepsilon\to 0$ 时两个世界几乎同分布，$\varepsilon$ 越大允许的偏向越大。
5. **$\delta$ 是加性项**，管**豁免**：以至多 $\delta$ 的概率，上述乘性保证整体失效。所以 $\delta$ 不能读成「误差大小」，要读成「事故概率」；经验判据取 $\delta\ll 1/n$（$n$ 是人数），否则豁免额度大到足以覆盖一整条真实记录的泄露而不违反定义。

两个立刻能记的特判。其一：$\delta=0$ 的情形叫**纯差分隐私（pure DP）**，简记 $\varepsilon$-DP；$\delta>0$ 叫**近似差分隐私（approximate DP）**。纯 DP 语义最干净（似然比永远被封顶），近似 DP 则换来更锋利的工具——高斯机制（第 2 章）与高级合成的 $\sqrt{k}$（第 3 章），这笔交易后面两章逐项清算。

其二：$\varepsilon$ 的体感锚点——$\varepsilon=0.1$ 时比值上界 $\mathrm{e}^{0.1}\approx 1.105$，$\varepsilon=1$ 时 $\approx 2.718$，$\varepsilon=5$ 时 $\approx 148$。所以实践里 $\varepsilon$ 取 $0.1$ 到 $1$ 的量级，超过 $5$ 的「隐私」基本等于没有。

还要记一件事：$\varepsilon$ 是**预算**不是开关——每回答一个问题就花掉一份，花完为止；记账的规矩在第 3 章。

两个常见误读也顺手排掉。误区一：把 $\delta$ 读成「噪声的方差」或「误差大小」——不是，$\delta$ 豁免的是整条不等式本身，跟噪声幅度无关。误区二：以为 DP 保证「任何一次输出都无害」——也不对，机制可以以 $\delta$ 的概率罕见地背叛一次；保护是关于整个输出分布的统计陈述，单次观测只在分布层面有意义。

**本节小结**：$(\varepsilon,\delta)$-DP 一行定义管三件事——对每一对相邻库、每一个事件，两世界概率之比被 $\mathrm{e}^{\varepsilon}$ 封顶、失效概率被 $\delta$ 封顶；$\delta=0$ 是纯 DP，$\delta>0$ 是拿小概率事故换更强的工具。

## $\rm \S \, 1.4$ 为什么必须随机化（本章主证二）

白话：定义里的 $\Pr$ 是对机制的随机硬币取的；如果机制根本不掷硬币，$\Pr$ 就只剩 $0$ 和 $1$ 两个取值，而这个不等式撑不住 $1$。

> **命题（确定性机制必败）**：设 $M$ 是确定性函数，且满足 $(\varepsilon,\delta)$-差分隐私，其中 $\delta<1$。则对每一对相邻 $D\sim D'$ 都有 $M(D)=M(D')$。

证明只有两行。反设 $M(D)=a$ 而 $M(D')=b\ne a$，取事件 $S=\{a\}$：

$$
1=\Pr[M(D)\in S]\ \le\ \mathrm{e}^{\varepsilon}\,\Pr[M(D')\in S]+\delta=\mathrm{e}^{\varepsilon}\cdot 0+\delta=\delta<1
$$

矛盾。$\blacksquare$

读法：左边是「确定性机制输出 $a$ 的概率当然是 $1$」；右边 $M(D')$ 从不输出 $a$，概率为 $0$，只剩豁免额度 $\delta$ 孤军奋战——而 $\delta\ge 1$ 的「保证」等于宣布机制可以想干嘛干嘛，形同虚设（回看 §1.3 对 $\delta$ 的语义）。把数据库空间看成一个图、相邻关系是边，命题等于说：$M$ 在每个连通分支上必须恒定。对计数查询而言整个空间连通，于是机制必须对**所有**数据库输出同一个数——一个把 5000 人和 5001 人的统计结果算成同一个数的系统，没有人要。

所以随机化不是实现层面的选择，是定义的入场券。随机性只有两个入口，各有代表作：

1. **输出扰动**：先老老实实算真值，再往输出上浇噪声——第 2 章的 Laplace 机制与 Gaussian 机制都是这条路。
2. **输入随机化**：在数据进入统计之前就掷硬币——随机化响应（每个人以概率 $p$ 如实回答、否则乱答，第 2 章 §2.5 给准确率表），以及子采样（只在随机抽出的样本上计算，让样本的随机性替机制分担隐私）。

随机化还有一个立刻能体会的副作用：同一个库问两次，答案不一样。这不是毛病，是隐私的物理代价——「有我」和「没我」两个世界本来差着一条记录，输出却要几乎重合，唯一的出路就是让输出「抖」起来，把那条记录的差异淹没在抖动里。抖动多大才够、又不至于毁掉统计，是下一节和整个第 2 章的课题。

一句话给第 2 章探路：输出扰动的全部学问在于「噪声浇多少才刚好够」——这就是 §1.5 敏感度要回答的问题。

**本节小结**：确定性函数不可能满足 $(\varepsilon,\delta)$-DP（$\delta<1$ 时两行反证），因为事件 $\{M(D)\}$ 概率为 $1$ 而对手侧为 $0$；随机化只有输出扰动与输入随机化两个入口，这是全册所有机制的出生地。

## $\rm \S \, 1.5$ 敏感度：噪声大小的总开关

白话：要往答案上加噪声，加多少？太小，盖不住「有我和没我」的差别，隐私是假的；太大，统计结果没人敢用。答案由一个量决定：**一条记录最多能把查询答案撬动多远**——这就是敏感度。

> **定义（全局敏感度）**：标量查询 $f$ 的全局敏感度（global sensitivity）为
>
> $$
> \Delta f=\max_{D\sim D'}\ \bigl|f(D)-f(D')\bigr|
> $$

读法：$\max$ 跑遍**所有**相邻对——「全局」的含义就是最坏情况，与当前手里是哪个库无关；机制在出厂时就按最坏挪动量校准噪声，不必偷看数据。两个必算的例子：

1. **计数查询**（加去型）：相邻库的计数至多差 $1$，且确实存在差 $1$ 的相邻对，故 $\Delta f=1$。
2. **人均收入**（替换型，收入 $\in[0,R]$）：一条记录从 $x$ 换成 ${x'}$，均值挪动 $\frac{|x-x'|}{n}\le\frac{R}{n}$，且可以取到，故 $\Delta f=\frac{R}{n}$。数值锚：$R=100$ 万元、$n=10^4$ 人，得 $\Delta f=100$ 元。
3. **求和查询**（加去型，收入 $\in[0,R]$）：来一个人总和至多加 $R$，故 $\Delta f=R$。同一个收入数据，问题从「数人头」换成「求总和」，敏感度就从 $1$ 涨到 $R$——敏感度是**查询的属性**，不是数据的属性。

现在把全册的主线立起来：第 2 章两台机器的噪声尺度，都直接乘着 $\Delta f$——

$$
b=\frac{\Delta f}{\varepsilon},\qquad \sigma=\frac{\Delta f\sqrt{2\ln(1.25/\delta)}}{\varepsilon}
$$

读法：Laplace 机制把尺度参数 $b$ 钉在 $\Delta f/\varepsilon$ 上；Gaussian 机制的标准差在 $\Delta f$ 之外只乘一个依赖 ${\varepsilon, \delta}$ 的常数。两条公式共同解释了三件事：隐私越强（$\varepsilon$ 越小）噪声越大；敏感度翻倍噪声翻倍——**保护一条记录的难度，等于盖住它最大杠杆的难度**；而敏感度失控的查询必须先改造查询本身再上噪声——典型是中位数：一半记录取 $0$、另一半取 $R$ 的库里，删掉正中间那条，答案直接跳约 $R$，敏感度与 $n$ 无关地大。

向量值查询时把绝对值换成 $\ell_1$ 或 $\ell_2$ 范数，Gaussian 机制配 $\ell_2$ 敏感度在高维更省（第 2 章 §2.3 的对照表）。

> **易混点**：敏感度有「全局」与「局部」两个版本——局部敏感度只对当前库取最大，数值常常小得多，但它本身是**关于库的函数**，直接拿去定噪声会把「这个库里哪条记录撬动最大」泄露出去。机制必须用与数据无关的全局版本；这是「机制不许偷看数据」的第一次兑现，第 2 章的机制全部如此。

**本节小结**：全局敏感度 $\Delta f$ 是相邻库上答案的最大挪动量，计数为 $1$、人均量为 $R/n$；下一章两台机制的噪声尺度都正比于它——「敏感度决定噪声」是全册的主线。

## $\rm \S \, 1.8$ 本章自测答案

> 先闭卷作答上面两节，再核对。

### $\rm \S \, 1.8.1$ 关键概念回顾答案

1. 目标原话：「数据库里有没有我这一条记录，对发布结果的分布几乎没有影响。」在定义里，「有我、没我」对应一对相邻库 $D\sim D'$，被比较的是同一事件 $S$ 在两个世界里的概率 $\Pr[M(D)\in S]$ 与 $\Pr[M(D')\in S]$。保护必须到分布级别，因为输出级别（「你看不出任何数字」）做不到——攻击者有背景知识，任何单个数字都可能有用；而分布级别恰好封死了「从结果反推我在不在」的全部通道。（§1.1、§1.3）

一个顺手的判据：判定某条保证够不够，先问攻击者手里有什么、再问定义管不管得住——差分隐私的回答是「管住一切背景知识」，匿名化的回答是「赌他没有」。
2. 替换型：等长、Hamming 距离 $\le 1$，语义是「改了填报信息」；加去型：$D'=D\cup\{x\}$ 或 $D\setminus\{x\}$，语义是「到场或缺席」。计数配加去型，因为答案对邻接的响应恰为 $1$ 且语义直指「我在不在这个数里」。人均收入配替换型，因为 $n$ 固定，均值挪动干净地等于 $|x-x'|/n$；加去型下分母同时变动，敏感度要带 $n/(n+1)$ 修正，口径含糊。（§1.2）
3. $\varepsilon$ 管乘性比值（两世界概率比的上界 $\mathrm{e}^{\varepsilon}$），$\delta$ 管加性豁免（保证整体失效的概率）。$\delta$ 不是误差大小而是事故概率——它豁免的是整条不等式，不是把误差抹平一点。确定性函数必败：取 $S=\{M(D)\}$，左边为 $1$，右边为 $\delta<1$，矛盾。随机性两个入口：输出扰动（算真值加噪）与输入随机化（随机化响应、子采样）。（§1.3、§1.4）

注意两步走的方向：先有定义（§1.3），再谈机制（第 2 章）——证明确定性函数必败用的就是定义本身，这也是为什么定义要写成一个全称不等式。

### $\rm \S \, 1.8.2$ 应用与辨析答案

1. 链接攻击根本不需要姓名：剩余字段（邮编、生日、评分模式……）与外部名册交叉即可定位个人，删标识符只删掉了「直接」那把钥匙，没关掉「旁证」的门。差分隐私换了对**发布机制**、在**分布层面**的保证：无论攻击者有什么背景知识，有无你的记录，输出分布至多差 $\mathrm{e}^{\varepsilon}$ 倍——背景知识再强，它能从结果里榨出的关于你的信息都被这个比值上界管住。（§1.1、§1.3）
2. 「以 110 开头的人数」是计数查询，配加去型，$\Delta f=1$。「以 110 开头者的平均年龄」带分母，配替换型：换一条记录，人数与总和同时可能变，这是子群体均值——严格说换的那条记录可能进出子群体，答案挪动上界在「子群体从空到一人」时最大，按年龄范围 $[0,120]$ 计 $\Delta f\le 120$（对应把均值定义为「子群体空时输出 $0$」）。

实践中更稳的做法是先发布子群体计数（$\Delta=1$）再发布子群体内均值（$\Delta=120/m$，$m$ 为子群体规模），分开计预算——把一个敏感度难看的查询拆成两个敏感度可控的查询，是第 3 章预算会计的日常操作。（§1.2、§1.5）
3. $n$ 条互不相同的记录，删去正中间那条，中位数从第 $\lfloor n/2\rfloor$ 位附近跳到第 $\lfloor n/2\rfloor+1$ 位附近——在值域上可以隔开任意远（前一半全取 $0$、后一半全取 $R$ 时，删一条中位数跳约 $R$），敏感度达到值域量级，与 $n$ 无关地大。也就是说中位数的全局敏感度没有「单条记录杠杆小」的性质，直接套 $\Delta f/\varepsilon$ 会得到淹没信号的噪声；出路是改造查询（截断、平滑）或改用别族技术——这提醒我们「敏感度决定噪声」的上半句是「先把敏感度做小」。（§1.5）

## $\rm \S \, 1.9$ 可当场复跑的程序段

下面这段纯 Python 做两件事：按加去型构造一对相邻库，然后把 §1.4 的两行反证演成真程序——用确定性中位数当机制，看看 DP 不等式怎么被攻破：

```python
 # 邻接库构造与确定性函数的非 DP 演示（纯 Python）
D  = [5.2, 3.1, 8.7, 4.4, 6.0, 2.9, 7.3, 5.5]
D2 = D + [9.9]                                   # 加去型相邻：只多一个人

def median(v):
    s = sorted(v)
    n = len(s)
    mid = n // 2
    return s[mid] if n % 2 else (s[mid - 1] + s[mid]) / 2

fD, fD2 = median(D), median(D2)
print(f"median(D)  = {fD},   median(D') = {fD2}")
S = {fD}                                         # 攻击者挑的事件：只含 M(D) 的输出
lhs = 1.0                                        # 确定性机制：M(D) 落进 S 的概率是 1
rhs = 0.0 + 0.1                                  # M(D') 从不输出 fD；取 delta = 0.1
print(f"Pr[M(D) in S] = {lhs},   e^eps*Pr[M(D') in S] + delta = {rhs}")
print("DP 不等式成立吗？", lhs <= rhs)
```

在本机（Python 3.12）输出：

```text
median(D)  = 5.35,   median(D') = 5.5
Pr[M(D) in S] = 1.0,   e^eps*Pr[M(D') in S] + delta = 0.1
DP 不等式成立吗？ False
```

读法：$D$ 与 ${D'}$ 只差一条记录（新来的 $9.9$），确定性中位数却从 $5.35$ 挪到 $5.5$——单条记录撬动了答案。攻击者取事件 $S=\{5.35\}$，不等式左边是 $1$、右边是 $0+0.1=0.1$，被击穿。把 `median` 换成任何确定性函数，只要它对这对库输出不同，结局一模一样——这正是 §1.4 命题的程序版。

**本节小结**：八行程序把「确定性机制必败」从定理变成现场演示；邻接对的构造、攻击事件的挑法、不等式的验算，三步都是第 2 章数值实验的骨架。

## $\rm \S \, 1.10$ 带走清单

1. 隐私定义绕开「删什么」：匿名化防不住链接攻击（Sweeney 的医疗记录、Netflix Prize 的评分指纹），目标改为「有无一条记录，输出分布几乎不变」。
2. 邻接两口径：替换型（等长换一人，配人均量）与加去型（多一条少一条，配计数）；记号 $D\sim D'$，对称关系。
3. $(\varepsilon,\delta)$-DP：对每对相邻库与每个事件 $S$，$\Pr[M(D)\in S]\le\mathrm{e}^{\varepsilon}\Pr[M(D')\in S]+\delta$；$\varepsilon$ 管比值、$\delta$ 管豁免概率，$\delta\ll 1/n$。
4. 纯 DP（$\delta=0$）语义最干净；近似 DP 用小概率事故换高斯机制与高级合成两件武器。
5. 确定性机制必败（两行反证）；随机化两个入口——输出扰动与输入随机化。
6. 全局敏感度 $\Delta f=\max_{D\sim D'}|f(D)-f(D')|$：计数为 $1$、人均量为 $R/n$；第 2 章 $b=\Delta f/\varepsilon$、$\sigma=\Delta f\sqrt{2\ln(1.25/\delta)}/\varepsilon$——敏感度决定噪声。
