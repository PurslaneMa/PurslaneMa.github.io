## $\rm \S \, 5.1$ 为什么经典独立装不下随机矩阵

经典概率论的研究对象是**数**：随机变量 ${X, Y}$ 是实值函数，$XY = YX$ 天经地义，「$(X, Y)$ 的联合分布」是乘积测度，「独立」说乘积测度因子化。随机矩阵一进场这套就裂了：两个 $n \times n$ 矩阵 ${A, B}$ 乘起来**不一定交换**，${AB}$ 与 ${BA}$ 是不同的矩阵——「$(A, B)$ 的联合分布」根本不存在能写下来的对象，$A$ 的谱与 $B$ 的谱也都各自是一整条经验分布而非一个数。

白话：**经典独立性是一部为「可交换变量」写的法律，随机矩阵是不服这部法的居民。** 要问「$A + B$ 的谱长什么样」「${AB}$ 的谱长什么样」，要么对每个具体矩阵实例硬算（第 3 章的迹方法干的就是这个，一次一个性质），要么造一部新法律——把「随机变量」的定义放宽成**非交换代数里的元素**，把「独立」重新发明到非交换世界里。量子力学早走过同一步：可观测量是算子、不对易，联合分布不存在——那边的出路是算子代数；Voiculescu 在 1980 年代研究算子代数里的自由群因子时发明了同一套语言，1991 年前后发现**大随机矩阵恰好是它的一个具体实现**——从那以后，自由概率成了随机矩阵的「渐近线性代数」。

裂缝能用数字直接拍出来。取两个独立的 $1000 \times 1000$ GUE 矩阵（元方差 $1/n$，本册第 1 章的口径），看四个量：

```python
import numpy as np
rng = np.random.default_rng(75)
def gue(n):
    G = rng.standard_normal((n, n)) + 1j * rng.standard_normal((n, n))
    return (G + G.conj().T) / 2 / np.sqrt(n)
n = 1000
A, B = gue(n), gue(n)
print(f"(1/n)tr A^2      = {np.trace(A @ A).real / n:.4f}")
print(f"(1/n)tr B^2      = {np.trace(B @ B).real / n:.4f}")
print(f"(1/n)tr (AB)^2   = {np.trace(A @ B @ A @ B).real / n:.4f}")
print(f"(1/n)tr A^2 B^2  = {np.trace(A @ A @ B @ B).real / n:.4f}")
```

实跑输出：

```text
(1/n)tr A^2      = 1.0012
(1/n)tr B^2      = 1.0022
(1/n)tr (AB)^2   = 0.0010
(1/n)tr A^2 B^2  = 1.0048
```

盯着后两行看。若 ${A, B}$ 是**经典独立**的均零方差一的随机数，$E[(XY)^2] = E[X^2]E[Y^2] = 1$——但矩阵交出的是 $0.0010$；而「不交错」的量 $\frac{1}{n}\mathrm{tr}(A^2B^2)$ 却是 $1.0048 \approx 1$。两个次序只差一点点的量，一个死了一个活着。经典独立性对这套数字**无话可说**：它既推不出 $0$，也解释不了为什么偏偏「交替次序」死、「成块次序」活。§5.2 的自由独立会把这两行数当成定理来复述。

**本节小结**：随机矩阵不对易，「联合分布」与经典独立都失效；两条出路——逐性质硬算的迹方法（第 3 章）与重新发明独立性的自由概率。数值上 $\frac{1}{n}\mathrm{tr}(AB)^2 \to 0$ 而 $\frac{1}{n}\mathrm{tr}(A^2B^2) \to 1$，交替死、成块活，这是新法律的第一个条文。

## $\rm \S \, 5.2$ 自由独立：定义一瞥与交替词的死亡

先把舞台搭出来。**非交换概率空间**是一个含单位元的 $*$-代数 $\mathcal{A}$（元素是「非交换随机变量」）配一个态 $\tau:\mathcal{A} \to \mathbb{C}$：线性、$\tau(I) = 1$、正性 $\tau(a^*a) \ge 0$。（读法：$\tau$ 扮演期望；对矩阵世界，$\tau(a) := \frac{1}{n}\mathrm{tr}(a)$，本册前三章一直在用的归一化迹。自伴元素 $a = a^*$ 扮演实值随机变量，它的「分布」就是矩序列 $\tau(a), \tau(a^2), \tau(a^3), \ldots$——对大矩阵，这正是第 1、2 章逐次算的极限矩。）经典概率是它的交换特例：取 $\mathcal{A} = L^\infty(\Omega)$、$\tau = E$，乘法交换，一切回到老世界。

**自由独立（freeness）的定义**。$\mathcal{A}$ 的两个子代数 $\mathcal{A}_1, \mathcal{A}_2$（$I$ 同属两者）称为**自由的**，若：任何「交错乘积」

$$
p_1(a_1)\, p_2(b_1)\, p_3(a_2) \cdots p_m(x_m), \qquad a_i \in \mathcal{A}_1,\ b_i \in \mathcal{A}_2,\ \text{相邻元素来自不同子代数}
$$

只要每个因子**中心化**（$\tau\big(p_i(a_i)\big) = 0$、$\tau\big(p_i(b_i)\big) = 0$，即每个块在各自子代数里期望为零），就有

$$
\tau\big(p_1(a_1)\, p_2(b_1) \cdots p_m(x_m)\big) = 0
$$

（读法：一个词，交替地取自两个子代数；把每一块都减去自己的均值后，整词的期望是零。注意条件比经典独立**弱**——它只管「交替且中心化」的词——推论却不同。）

对照经典独立性，差别一眼可见。经典独立说：任何形状的乘积都因子化，$E[XYZ] = E[X]E[Y]E[Z]$（均零时整句为 $0$，但 $E[X^2 Y^2] = E[X^2]E[Y^2]$ 也因子化）。自由独立只承诺一件事：**交错的词、逐块中心化、期望为零**。从这一条能推出什么、推不出什么，拿 §5.1 的数字当试金石：

1. **交替词死**。$\tau(ab\,ab)$：词形 $a\,b\,a\,b$ 交替，四块各自是「单字母 $a$（或 $b$）」，单字母均零故中心化——自由定义直接判 $\tau(abab) = 0$。§5.1 实测 $0.0010$：**这就是自由独立的条文在矩阵世界的兑现**。经典独立给出的却是 $1$——两种「独立」在这一个矩上分道扬镳，而且矩阵站在自由一边。
2. **成块词活，且因子化**。$\tau(a^2 b^2)$：把每块各自中心化，

$$
\tau(a^2 b^2) = \tau\big((a^2 - 1)(b^2 - 1)\big) + \underbrace{\tau(a^2 - 1)}_{=0} + \underbrace{\tau(b^2 - 1)}_{=0} + \tau(I) = 0 + 1 = 1
$$

（读法：第一项是「两块、各自中心化」——但词形是 $a\,a\,b\,b$，$a$-块与 $b$-块**不交替**，整个表达式只有两个块，这正是自由定义管辖的形状，判零；余下三项是展开式的其余部分。）结果 $\tau(a^2b^2) = \tau(a^2)\tau(b^2) = 1$：成块矩**像经典独立一样因子化**。§5.1 实测 $1.0048$。

所以自由独立的准确身份是：**在「交替词」上比经典独立狠（一律杀零），在「成块词」上与经典独立同款（因子化）**。还有一个漂亮的余韵：$\tau\big((ab)^*(ab)\big) = \tau(b\,a^2\,b)$，由迹的循环性质等于 $\tau(a^2b^2) = 1$——「乘积 $ab$ 的二范数」活着，只有「$(ab)^2$ 的期望」死了。非交换世界杀掉的是**相位**，不是**大小**；这正是量子力学「期望可为零而涨落不为零」的远亲。

最后补一句定义的诚实版：上面的定义针对两个子代数；多个子代数是「任意有限组都满足」；「渐近自由」则是把 $\tau$ 换成 $\frac{1}{n}\mathrm{tr}$ 后要求逐词收敛——这正是 §5.5 定理的内容。

**本节小结**：非交换概率空间＝代数加态，分布＝矩序列；自由独立一条条文——交替词逐块中心化后期望为零——推出「交替矩死（$\tau(abab)=0$）、成块矩活且因子化（$\tau(a^2b^2)=1$）」，$n = 1000$ 的 GUE 实验逐位兑现。半圆律在这个框架里将获得新身份：下一节它升格为自由高斯。

## $\rm \S \, 5.3$ 半圆律＝自由高斯：自由中心极限定理

经典 CLT 说：$n$ 个独立同分布、均零方差的随机变量，归一化 $\frac{1}{\sqrt{n}}\sum X_i$ 依分布趋于高斯。把「独立」换成「自由」，陈述几乎逐字照抄：

**自由 CLT**。设 $a_1, a_2, \ldots$ 是**自由**的自伴元，$\tau(a_i) = 0$、$\tau(a_i^2) = 1$，则

$$
\frac{a_1 + \cdots + a_n}{\sqrt{n}} \;\xrightarrow{\ d\ }\; s
$$

其中 $s$ 是标准**半圆元**：矩 $\tau(s^{2k}) = C_k$（第 $k$ 个 Catalan 数）、$\tau(s^{2k+1}) = 0$，即本册第 1 章的半圆分布。

白话：**半圆律之所以是半圆，是因为它是自由世界里「很多小扰动相加」的必然后果——它的地位就是高斯的地位。** 经典 CLT 的极限分布由「哪一族分布稳定」决定，自由 CLT 同理，只是「稳定族」换了：高斯在自由世界不再稳定，稳定的是半圆。

极限分布为什么偏偏是 Catalan？这就要把「累积量」搬进自由世界。经典矩可以展开成配对：$E[X_1 X_2 X_3 X_4]$（高斯）是三种配对之和——**全体**配对，共 $(2k-1)!!$ 个；自由矩的展开里**交叉的配对被禁掉**，只剩**非交叉配对（non-crossing pairings）**——${2k}$ 个点的非交叉配对数恰是 Catalan 数 $C_k$。（读法：把点排在圆上，配对用弦画出；「非交叉」指弦互不交叉。第 1 章算过的 $m_2 = 1, m_4 = 2, m_6 = 5, \ldots$ 就是 $C_1, C_2, C_3, \ldots$——当时以为是在数矩，原来是在数自由世界的配对方式。）据此定义**自由累积量** $\kappa_k$：把矩按非交叉配对展开时的系数，正如经典累积量把矩按全体配对展开。于是两条 CLT 的发动机可以并排写：

| | 经典世界 | 自由世界 |
| --- | --- | --- |
| 矩的展开 | 全体配对 | 非交叉配对 |
| 累积量 | $\kappa_k$（经典） | $\kappa_k$（自由） |
| 「高斯」 | 只有 $\kappa_2 \ne 0$ | 只有 $\kappa_2 \ne 0$，即**半圆元** |
| CLT 的机制 | 累积量可加、高阶稀释为 $n \to \infty$ | 同一套戏在非交叉世界里重演 |

（读法：表的说服力在第 3、4 行的平行——「高斯」的定义在两个世界是同一句话「二阶累积量以外全零」，只是累积量的品种不同，极限分布就从钟形换成了拱形。）

证明骨架三步，与经典 CLT 逐字平行：1. 自由累积量在自由独立下可加（$\kappa(a + b) = \kappa(a) + \kappa(b)$——对应经典「独立则累积量相加」）；2. 和的方差按 $n$ 增长、归一化 $1/\sqrt{n}$ 后二阶累积量稳定为 $1$，$k \ge 3$ 阶累积量按 $n^{1 - k/2}$ 消失；3. 矩由累积量决定，全部矩收敛到「只有 $\kappa_2$」的对象——半圆元。三步的严格化是 Voiculescu 的自由矩演算，本章不展开；但要看到它与第 1 章矩方法证明的分工：**第 1 章直接算 Wigner 矩阵的矩（现象学），本节说明「为什么极限必须是半圆」（结构学）**——同一枚硬币的两面。

**本节小结**：自由 CLT：自由、均零、方差的和按 $1/\sqrt{n}$ 归一后趋于半圆元——半圆律升格为「自由高斯」。机制在配对的品种：经典全配对出高斯，自由非交叉配对出半圆，Catalan 数是两章之间暗藏的接头暗号。

## $\rm \S \, 5.4$ 自由卷积：把「矩阵相加的谱」变成运算

经典概率里，「独立随机变量之和的分布」是一个二元运算：卷积 $\mu * \nu$，而特征函数（或累积量生成函数）的对数把它变成**加法**——这就是 CLT 证明的算盘。自由世界有一套完整的平行机器。

**定义**。设 ${a, b}$ 是自由的自伴元，分布各为 $\mu_a, \mu_b$（由矩序列决定），则 $a + b$ 的分布 $\mu_{a+b}$ 只依赖 $\mu_a, \mu_b$（自由独立的定义保证了混合矩全由两边矩决定），记

$$
\mu_a \boxplus \mu_b := \mu_{a + b}
$$

（读法：$\boxplus$ 读「自由卷积」，是经典卷积 $\boxplus = *$ 的自由表亲；它由矩序列唯一决定，是分布函数层面的二元运算。）线性化它的工具是 **R-变换**：$R_\mu(z) = \sum_{k \ge 0} \kappa_{k+1} z^k$（读法：自由累积量的生成函数——经典世界用 $\log$ 特征函数，自由世界用 $R$-变换），核心性质一条：

$$
R_{\mu \boxplus \nu}(z) = R_\mu(z) + R_\nu(z)
$$

（读法：$\boxplus$ 在 $R$-变换下变加法，正如经典卷积在 $\log$ 特征函数下变加法。）

**与随机矩阵加法的对应**是本节的正题。设 $A_n, B_n$ 是两族独立随机矩阵，各自依分布收敛（矩收敛）到自伴元 ${a, b}$，且渐近自由（§5.5），则

$$
\frac{1}{n}\mathrm{tr}\big((A_n + B_n)^k\big) \;\xrightarrow{\ a.s.\ }\; \tau\big((a + b)^k\big), \qquad \text{即 } \mu_{A_n + B_n} \to \mu_a \boxplus \mu_b
$$

（读法：「两个大矩阵相加，谱是什么」这道题被翻译成「两个分布做自由卷积」——而自由卷积有 $R$-变换这台机器，多数情形能显式算。）

最快的战果是半圆族：半圆（方差 $\sigma^2$）的自由累积量只有 $\kappa_2 = \sigma^2$，故 $R(z) = \sigma^2 z$——**线性**！于是

$$
\text{半圆}(\sigma_1^2) \boxplus \text{半圆}(\sigma_2^2) = \text{半圆}(\sigma_1^2 + \sigma_2^2)
$$

一行读出：两个独立 Wigner 矩阵相加，谱还是半圆、方差相加——§5.3 的自由 CLT 在最简单的族上的具体化。数值验收：两个独立 GUE（各半径 $2$、方差 $1$）相加，理论是半径 $2\sqrt{2} \approx 2.8284$ 的半圆：

```python
ev = np.linalg.eigvalsh(A + B)
print(f"(1/n)sum lam^2 = {np.mean(ev**2):.4f}")
print(f"support: [{ev.min():.3f}, {ev.max():.3f}]")
def sc_cdf(x, s2):
    R = 2 * np.sqrt(s2)
    x = np.clip(x, -R, R)
    return 0.5 + x * np.sqrt(4*s2 - x*x) / (4*np.pi*s2) + np.arcsin(x / R) / np.pi
for x in (-2.0, -1.0, 0.0, 1.0, 2.0):
    print(f"x={x:+.1f}: empirical {np.mean(ev <= x):.4f}   semicircle {sc_cdf(x, 2.0):.4f}")
```

实跑输出：

```text
(1/n)sum lam^2 = 2.0039
support: [-2.788, 2.800]
x=-2.0: empirical 0.0910   semicircle 0.0908
x=-1.0: empirical 0.2800   semicircle 0.2797
x=+0.0: empirical 0.5000   semicircle 0.5000
x=+1.0: empirical 0.7200   semicircle 0.7203
x=+2.0: empirical 0.9090   semicircle 0.9092
```

五个分位点的经验分布与半圆（$\sigma^2 = 2$）的差距全在万分位——**「半圆 ⊞ 半圆 ＝ 半圆」从定理变成了表格**。注意经验支撑 $[-2.788, 2.800]$ 略缩在理论半径 $2.8284$ 内：$n = 1000$ 的边缘特征值还没爬满理论端点（这正是第 4 章 TW 涨落在负侧的写照），但**分布的中部**已经严丝合缝——自由卷积管的是全局形状，边缘的精细涨落是第 4 章另一台机器的管辖范围。

乘法那边有一台对称的机器，一句带过：自由独立自伴元的**乘积**（或 $A^{1/2} B A^{1/2}$ 这类对称化乘积）的分布由**乘性自由卷积** $\otimes$ 描述，线性化工具叫 **S-变换**——本册第 2 章的 Marchenko–Pastur 律在自由概率里的户籍就是「**自由 Poisson 分布**」，它对 $\otimes$ 的稳定性正是「白噪声平方出 MP 律」的结构原因。分布层面的进出账至此理清：**加法用 $\boxplus$ 加 $R$-变换，乘法用 $\otimes$ 加 $S$-变换，账本都是一行线性式**。

**本节小结**：自由卷积 $\boxplus$ 是「自由之和的分布」运算，$R$-变换把它线性化；随机矩阵加法在渐近自由下整体搬进这个运算（$\mu_{A_n + B_n} \to \mu_a \boxplus \mu_b$）。半圆的 $R$-变换是线性的，于是「半圆 ⊞ 半圆 ＝ 半圆」一行得证，$n = 1000$ 实验五个分位点验到万分位；MP 律领到「自由 Poisson」的新护照，乘法侧由 $\otimes$ 与 $S$-变换接管。

## $\rm \S \, 5.5$ Voiculescu 定理：大矩阵渐近自由

前几节反复用到「渐近自由」这个赌注，现在兑现承诺，把定理本身摆上台面。

**Voiculescu 渐近自由定理（陈述级，Voiculescu 1991）**。设

1. $A_n^{(1)}, \ldots, A_n^{(k)}$ 是 $k$ 族**相互独立**的随机矩阵，每族在共轭变换 $A \mapsto U A U^*$（$U$ 独立 Haar 随机酉阵）下分布不变——**酉不变系综**，GUE 是标准例子；
2. $D_n^{(1)}, \ldots, D_n^{(k)}$ 是**确定性**矩阵列，各自的归一化矩 $\frac{1}{n}\mathrm{tr}\big((D_n^{(j)})^{m}\big)$ 收敛。

则这 ${2k}$ 族矩阵**渐近自由**：对任何由「中心化多项式」交错排成的词 $P_1\big(A_n^{(i_1)}\big)\, P_2\big(D_n^{(j_1)}\big) \cdots P_m\big(x_m\big)$（相邻因子来自不同族、每块在各自族里的迹为零），

$$
\frac{1}{n}\mathrm{tr}\Big( P_1\big(A_n^{(i_1)}\big) \cdots P_m\big(x_m\big) \Big) \;\xrightarrow{\ a.s.\ }\; 0
$$

（读法：把 §5.2 的自由定义逐字搬到大矩阵上，$\tau$ 换成 $\frac{1}{n}\mathrm{tr}$、「期望为零」换成「几乎必然收敛到零」。组合数 $k$ 无关紧要，要紧的是两个假设：**独立**与**酉不变**。）

三条推论把本章和前四章缝起来：

1. **独立的 GUE 们渐近自由**（取全部为随机系综、无确定性族）——§5.2 的矩实验（$\tau(abab) \to 0$、$\tau(a^2b^2) \to 1$）与 §5.3、§5.4 的自由 CLT、自由卷积实验全部因此合法；
2. **GUE ＋ 确定性对角阵渐近自由**——「信号 ＋ 噪声」模型（如 $M = D + W$，$D$ 是确定性算子、$W$ 是 Wigner 噪声）的谱由 $\mu_D \boxplus \mu_W$ 一式算出：第 4 章 BBP 模型的「海 ＋ 尖峰」正是这类变形模型，那里的外点公式是自由概率也能触及的对象（本册停在陈述层）；
3. **自由概率是渐近线性代数**——「大矩阵的谱行为」这类逐实例无从下手的题，在极限里变成非交换概率的常规运算：加法有 $\boxplus$ 与 $R$-变换，乘法有 $\otimes$ 与 $S$-变换，极限对象（半圆元、自由 Poisson 元）是查得到的「常数」。

证明的一句话路线（只为定位，不展开）：酉不变性允许把 GUE 换成任何同分布的酉共轭形式，组合下的单项按 Wigner 矩阵的图计数——非交叉的图才存活，存活的图恰好按自由独立的条文贡献零或因子化；「非交叉配对」在第 1 章算 Catalan 矩时出现过，在这里变成了**定理的发动机**。另一句诚实的提醒：**「独立」单枪匹马不够**——两个独立但对角的（交换）矩阵永远不自由，$AB = BA$ 当场违反交替词的死亡条文；酉不变（或某种足够的随机性）是「独立」能升级成「自由」的必要燃料。

**本节小结**：Voiculescu 定理：独立＋酉不变的随机矩阵族（与有极限分布的确定性族）渐近自由——自由概率的全部机器（交替词、$\boxplus$、$R$-变换）从此对大矩阵合法。半圆是自由高斯、MP 是自由 Poisson、矩阵加法的谱是自由卷积：前四章的现象在这套公理里各归其位。第 6 章带着整套工具去一个意想不到的工地：神经网络。

## $\rm \S \, 5.6$ 程序段：交替词之死与自由卷积完整复跑

```python
import numpy as np

def gue(n, rng):
    G = rng.standard_normal((n, n)) + 1j * rng.standard_normal((n, n))
    return (G + G.conj().T) / 2 / np.sqrt(n)

rng = np.random.default_rng(75)
n = 1000
A, B = gue(n, rng), gue(n, rng)

# --- 实验一：交替词死、成块词活 ---
print(f"(1/n)tr A^2      = {np.trace(A @ A).real / n:.4f}")
print(f"(1/n)tr (AB)^2   = {np.trace(A @ B @ A @ B).real / n:.4f}   (free pred 0, classical 1)")
print(f"(1/n)tr A^2 B^2  = {np.trace(A @ A @ B @ B).real / n:.4f}   (free pred 1)")

# --- 实验二：自由卷积 半圆+半圆=半圆 ---
ev = np.linalg.eigvalsh(A + B)
print(f"(1/n)sum lam^2 = {np.mean(ev**2):.4f}   (pred 2, radius {2*np.sqrt(2):.4f})")

def sc_cdf(x, s2):
    R = 2 * np.sqrt(s2)
    x = np.clip(x, -R, R)
    return 0.5 + x*np.sqrt(4*s2 - x*x)/(4*np.pi*s2) + np.arcsin(x/R)/np.pi

for x in (-2.0, -1.0, 0.0, 1.0, 2.0):
    print(f"x={x:+.1f}: empirical {np.mean(ev <= x):.4f}   semicircle {sc_cdf(x, 2.0):.4f}")
```

实跑输出：

```text
(1/n)tr A^2      = 1.0012
(1/n)tr (AB)^2   = 0.0010   (free pred 0, classical 1)
(1/n)tr A^2 B^2  = 1.0048   (free pred 1)
(1/n)sum lam^2 = 2.0039   (pred 2, radius 2.8284)
x=-2.0: empirical 0.0910   semicircle 0.0908
x=-1.0: empirical 0.2800   semicircle 0.2797
x=+0.0: empirical 0.5000   semicircle 0.5000
x=+1.0: empirical 0.7200   semicircle 0.7203
x=+2.0: empirical 0.9090   semicircle 0.9092
```

读程序的三句话：实验一的三个迹就是三个矩的蒙特卡洛，$n = 1000$ 下蒙特卡洛噪声约 $n^{-1/2}$ 量级，$0.0010$ 与 $1.0048$ 离自由预测的 $0$ 与 $1$ 都在噪声内；实验二真正要看的不是二阶矩（那只是方差的账），是五个分位点——它们验证的是**整条分布**而非一个数字；`sc_cdf` 里闭式写出的正是第 1 章见过的半圆分布函数，$\sigma^2 = 2$ 对应半径 $2\sqrt{2}$。想再进一步的读者可以把 $B$ 换成方差 $\sigma^2 \ne 1$ 的 GUE，验证 $\boxplus$ 下方差相加、半径按 $\sqrt{\sigma_1^2 + \sigma_2^2}$ 走。

## $\rm \S \, 5.8$ 带走清单

1. 裂缝：随机矩阵不对易，联合分布不存在，经典独立失效；指纹是 $\frac{1}{n}\mathrm{tr}(AB)^2 \to 0$ 而 $\frac{1}{n}\mathrm{tr}(A^2B^2) \to 1$——交替死、成块活。
2. 框架：非交换概率空间＝$*$-代数加态 $\tau$（矩阵世界 $\tau = \frac{1}{n}\mathrm{tr}$），分布＝矩序列；自由独立一条条文：交替词逐块中心化后期望为零。
3. 自由 CLT：自由、均零、方差一之和按 $1/\sqrt{n}$ 归一趋于半圆元；机制是非交叉配对（Catalan 数），半圆元＝「只有 $\kappa_2$」＝自由高斯。
4. 自由卷积：$\mu_a \boxplus \mu_b = \mu_{a+b}$（自由），$R$-变换线性化；矩阵加法 $\mu_{A_n + B_n} \to \mu_a \boxplus \mu_b$；半圆 ⊞ 半圆 ＝ 半圆（$R$ 线性），MP ＝ 自由 Poisson，乘法由 $\otimes$ 与 $S$-变换接管。
5. 定理：独立＋酉不变（含确定性族）$\Rightarrow$ 渐近自由（Voiculescu 1991）；独立 alone 不够（对角阵反例）。
6. 一句总纲：自由概率是把「大矩阵渐近行为」组织成公理体系的语法书——第 1—4 章的现象是词汇，本章给了语法。

## $\rm \S \, 5.9$ 六问参考答案

1. $\frac{1}{n}\mathrm{tr}(AB)^2 = 0.0010$ 与 $\frac{1}{n}\mathrm{tr}(A^2B^2) = 1.0048$。经典独立对两个量都预测 $1$（$E[X^2]E[Y^2]$）；自由预测分别是 $0$（交替词判零）与 $1$（成块因子化）——矩阵站自由一边，第二个量两种理论碰巧一致，分歧全在第一个量。（§5.1）
2. 词形必须**交替**（相邻元素来自不同子代数）；条件是每个块在各自子代数里**中心化**（期望为零）；结论是整词的 $\tau$ 为零。经典独立连 $E[X^2Y^2]$ 也因子化（得 $1$），自由世界这个交替词型矩死为零——分歧方向：自由更「狠」。（§5.2）
3. 展开式 $\tau(a^2b^2) = \tau\big((a^2-1)(b^2-1)\big) + \tau(a^2-1) + \tau(b^2-1) + \tau(I)$，共四项：第一项是「两个中心化块」的词，自由条文判零；二、三项各因中心化为零；第四项 $\tau(I) = 1$。合计 $1 = \tau(a^2)\tau(b^2)$。（§5.2）
4. 含义：自由中心极限定理的极限分布是半圆——正如经典 CLT 的极限是高斯，半圆占据「大量微小自由扰动之和」的吸引子位置。「高斯」的定义两边同一句话：除 $\kappa_2$ 外自由（或经典）累积量全零；差别在矩的展开品种——经典全配对给钟形，自由非交叉配对给拱形。（§5.3）
5. $R$-变换对位于 $\log$ 特征函数（累积量生成函数）；$\boxplus$ 在 $R$-变换下变**加法**。半圆（方差 $\sigma^2$）的 $R(z) = \sigma^2 z$，两条相加得 $(\sigma_1^2 + \sigma_2^2)z$，反查仍是一阶累积量独大的分布——半圆、方差相加、半径 $2\sqrt{\sigma_1^2 + \sigma_2^2}$。（§5.4）
6. 假设：各随机矩阵族相互独立、且每族在独立 Haar 酉共轭下分布不变（酉不变系综）；确定性族需矩收敛。反例：两个独立的对角矩阵——它们交换（$AB = BA$），交替词 $\tau(abab)$ 型条文当场被违反（对角阵的对角元可以强相关）。MP 律的户籍名：自由 Poisson 分布。（§5.5）
