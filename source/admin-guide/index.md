本博客提供一个专门做过中文适配的本地图形化后台：

```text
http://localhost:4000/admin-cn/
```

常用操作：

- `文章管理`：查看、编辑已有文章。
- `新建文章`：创建新的 Markdown 草稿。
- `页面管理`：管理关于页、搜索页等独立页面。
- `保存`：把当前内容写回本地 Markdown 文件。
- `发布为正式文章`：把草稿移动到正式文章区。
- `转为草稿`：把正式文章移回草稿区。
- `移入废稿`：把不想要的文章放到废稿区。

旧后台备用地址：

```text
http://localhost:4000/admin/
```

文章源码位置：

```text
D:\AI\github-blog\source\_posts
```

站点配置：

```text
D:\AI\github-blog\_config.yml
D:\AI\github-blog\_config.next.yml
```
