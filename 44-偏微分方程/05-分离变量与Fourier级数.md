# $\rm Chapter \, 5$ 分离变量与 Fourier 级数

前四章的特解各有各的巧，本章统一方法：**分离变量**把 PDE 拆成 ODE，**Fourier 级数**把一般初值拆成简谐波，**叠加原理**（§1.3 的许可证）把一切拼回去。这是求解线性 PDE 的总装流水线，也是连续数学册第 7 章 Fourier 级数在 PDE 上的正戏。

## $\rm \S \, 5.1$ 分离变量的机制

以带 Dirichlet 边界的杆上热方程为例：$u_t = u_{xx}$、$u(0, t) = u(L, t) = 0$、$u(x, 0) = f(x)$。猜解 $u(x, t) = X(x) T(t)$（时间和空间「各管各」）。代入：

$$
X T' = X'' T \implies \frac{T'}{T} = \frac{X''}{X} = -\lambda
$$

左边只含 $t$、右边只含 $x$，两边相等 ⟹ 两边都是同一个常数 $-\lambda$（**变量分离常数**）。于是：

1. 时间 ODE：$T' = -\lambda T \Rightarrow T = \mathrm{e}^{-\lambda t}$；
2. 空间 ODE：$X'' + \lambda X = 0$ 配边界 $X(0) = X(L) = 0$。

**读法**：一个 PDE 被拆成「一个一阶 ODE ＋ 一个特征值问题」——白话：把「时空合演」拆成「空间定形状、时间管伸缩」。

## $\rm \S \, 5.2$ 特征值问题与模

空间问题 $X'' + \lambda X = 0$、$X(0) = X(L) = 0$ 只有特定 $\lambda$ 才有非零解：$\lambda_n = (n\pi / L)^2$、$X_n = \sin(n\pi x / L)$，$n = 1, 2, \ldots$（$A\sin + B\cos$ 的一般解代边界：$B = 0$、$\sin(\sqrt\lambda L) = 0$）。每个 $(\lambda_n, X_n)$ 是一个**特征模**：

$$
u_n(x, t) = \mathrm{e}^{-\kappa \lambda_n t} \sin \frac{n\pi x}{L}
$$

**读法**：模是杆的「固有驻波」，衰减率 $\kappa \lambda_n \propto n^2$——**频率越高死得越快**（第 2 章 §2.5「高频先死」的定量版）。波动方程同款流程给 $u_{tt} = c^2 u_{xx}$ 的模 $u_n = \cos(c\sqrt{\lambda_n} t)\sin(\sqrt{\lambda_n} x)$——不衰减、只振荡（§3.3 对照表的又一格）。

## $\rm \S \, 5.3$ Fourier 拼装（本章主证）

一般初值 $f(x)$：按第 7 章展开 $f = \sum_n b_n \sin(n\pi x / L)$（系数 $b_n = \frac{2}{L}\int_0^L f \sin$），叠加（§1.3 许可证）：

$$
u(x, t) = \sum_{n=1}^{\infty} b_n\, \mathrm{e}^{-\kappa (n\pi/L)^2 t} \sin \frac{n\pi x}{L}
$$

**验证清单**（每条一句）：1. 逐项满足方程与边界（线性＋各模已验）；2. 初值：$t = 0$ 级数收敛到 $f$（Fourier 收敛定理）；3. 逐项求导合法性：$t > 0$ 时 $\mathrm{e}^{-\kappa \lambda_n t}$ 以 $e^{-c n^2}$ 级压住一切导数——**级数在 $t > 0$ 内绝对一致收敛且可任意次求导**（这就是「热方程瞬间无穷光滑」，§2.3 的级数版证据）。

**白话**：任意初始温度图样被拆成一把音叉（各频率驻波），每支音叉按自己的指数衰减率慢慢哑掉——高音先哑，最后只剩最低音（稳态）。

## $\rm \S \, 5.4$ 四类边界条件速查

同一流水线在别的边界条件下只有特征值表变化：

1. **两端 Dirichlet**：$\lambda_n = (n\pi/L)^2$，模 $\sin(n\pi x/L)$（§5.2）。
2. **两端 Neumann**（绝热）：$\lambda_n = (n\pi/L)^2$、$n = 0, 1, \ldots$，模 $\cos(n\pi x/L)$——多出零模 $\lambda_0 = 0$（常数解）：绝热杆的总热量守恒，长期归宿是「平均温度的常函数」。
3. **混合**（一端 Dirichlet 一端 Neumann）：$\lambda_n = ((n + \frac12)\pi / L)^2$，模 $\sin((n+\frac12)\pi x / L)$——半整数频率。
4. **周期边界**：$\lambda_n = (2\pi n / L)^2$，模 $\cos + \sin$ 成对——Fourier 级数的原装场景。

**读法**：边界条件决定的是「哪些频率被允许存在」——特征值表就是边界与波长的共振账。数值方法的稳定性分析（第 6 章 von Neumann）用的正是周期情形。

## $\rm \S \, 5.5$ 与前三章的会师

1. **热方程卷积解**（§2.2）与级数解（§5.3）是同一解的两种写法：卷积核展开成模即得级数（有限区间上 Fourier 级数替代 Fourier 积分）。
2. **波动方程 d'Alembert**（§3.2）与级数解等价：$\sin(x \pm t)$ 的和差化积正是两条行波——三角恒等式把两种形态焊死。
3. **Laplace 圆盘解**（§4.5）就是「时间维度消失」的分离变量：$r^n$ 扮演了 $\mathrm{e}^{-\kappa\lambda t}$ 的压扁角色。

**读法**：分离变量不是一种技巧，是线性 PDE 的**通用语法**——原型方程的每个显式解都是它的某个化身。

## $\rm \S \, 5.6$ 数值实验

杆长 $L = 1$、初值 $f(x) = x(1 - x)$（抛物线）：系数可手算 $b_n = \frac{4}{(n\pi)^3}(1 - (-1)^n)$（只有奇数模）。截断 $N = 20$、时刻 $t = 0.001, 0.01, 0.1$ 画剖面（纯 Python 30 行内）：$t = 0.001$ 已现光滑抛物拱的衰减版、$t = 0.1$ 只剩 $n = 1$ 模的半幅正弦拱（$b_1 \mathrm{e}^{-\kappa\pi^2 t} \approx$ 主导）——「高音先哑」的全过程可逐点对账。

## $\rm \S \, 5.7$ 关键概念回顾

1. 分离常数 $-\lambda$ 为什么「必须是常数」？（§5.1）
2. 特征值问题 $\lambda_n = (n\pi/L)^2$ 怎么从边界条件里逼出来？（§5.2）
3. 模的衰减率与频率的什么关系？谁先死？（§5.2）
4. 级数解在 $t > 0$ 可任意求导的靠山？（§5.3）
5. Neumann 边界多出的零模对应什么物理？（§5.4）
6. d'Alembert 与级数解怎么焊死？（§5.5）

## $\rm \S \, 5.8$ 本章自测答案

1. 左边只含 $t$、右边只含 $x$，恒等 ⟹ 都是常数（变量的函数等于另一变量的函数，只能是常数）。（§5.1）
2. 一般解代 $X(0) = X(L) = 0$：$B = 0$、$\sin(\sqrt\lambda L) = 0$ ⟹ $\sqrt\lambda L = n\pi$。（§5.2）
3. $\kappa \lambda_n \propto n^2$；高频先死。（§5.2）
4. $\mathrm{e}^{-\kappa\lambda_n t}$ 的 $e^{-cn^2}$ 级压制——绝对一致收敛。（§5.3）
5. 零模＝常数解＝守恒的平均温度（绝热不漏热）。（§5.4）
6. 三角和差化积把模叠加化成 $f(x \pm t)$ 行波。（§5.5）
