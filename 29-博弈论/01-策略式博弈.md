## $\rm \S \, 1.1$ 三要素：玩家、策略、支付

**策略式博弈（normal-form game）**由三部分组成：

1. 玩家（player）：做决策的人；
2. 策略集（strategy set）：每人可选的行动集合；
3. 支付函数（payoff function）：每种策略组合下每人拿到的效用数值，概括全部偏好。

与算法题的唯一区别是输入的来源：输入不是被构造的，而是来自多个会互相预判的源头。两人博弈可以把全部信息摆进一张矩阵，行是玩家 1 的策略、列是玩家 2 的策略，格子里写（玩家 1 支付，玩家 2 支付）。先摆囚徒困境，支付越大越好：

| 甲 $\backslash$ 乙 | 坦白 | 沉默 |
| --- | --- | --- |
| 坦白 | ${(-4,-4)}$ | ${(0,-8)}$ |
| 沉默 | ${(-8,0)}$ | ${(-2,-2)}$ |

读法举例：甲坦白、乙沉默时，甲无罪释放得 $0$，乙独自顶罪得 $-8$。

## $\rm \S \, 1.2$ 占优与逐次剔除

**严格占优（strictly dominates）**：策略 $s$ 严格占优 ${s'}$，指无论对手出什么，$s$ 的支付都严格更高。**弱占优（weakly dominates）**放宽为「处处不低于，且至少一处严格更高」。

囚徒困境里「坦白」严格占优「沉默」：对手坦白时 $-4>-8$，对手沉默时 $0>-2$。两人各剔除一次只剩（坦白，坦白）＝${(-4,-4)}$。每人单看都做了最优决策，合起来落在对双方都更差的格子上：个体理性与集体理性的裂缝，就是「困境」二字。

占优关系不是每个博弈都有。摆两个反例：

| 性别战 | 歌剧 | 足球 |
| --- | --- | --- |
| 歌剧 | ${(2,1)}$ | ${(0,0)}$ |
| 足球 | ${(0,0)}$ | ${(1,2)}$ |

| 猎鹿 | 猎鹿 | 抓兔 |
| --- | --- | --- |
| 猎鹿 | ${(3,3)}$ | ${(0,2)}$ |
| 抓兔 | ${(2,0)}$ | ${(1,1)}$ |

1. 性别战：两人想一起过周末，但各自偏爱不同项目。逐行逐列检查，谁的策略都不占优谁的，剔除法一格格都删不动；
2. 猎鹿：合猎一头鹿各得 3，单干只能抓兔得 1。同样没有占优策略，但能看出两个「互相都不想单方反悔」的格子：一起猎鹿、各自抓兔。

**逐次剔除占优（iterated elimination of dominated strategies）**指反复寻找并删除占优策略。用严格占优删，剩下的策略组合不丢任何均衡；用弱占优删则可能失手，删除顺序不同会留下不同的集合，所以严格版更可靠。性别战与猎鹿都过了这一关还剩全部策略，需要更强的稳定性概念。

## $\rm \S \, 1.3$ 最佳应对与纳什均衡

给定其他人的策略组合 $s_{-i}$，玩家 $i$ 的**最佳应对（best response）**是使 $i$ 支付最大的策略。**纳什均衡（Nash equilibrium）**是这样的策略组合：每个人的策略都是对其余所有人策略组合的最佳应对；等价的检验口诀是「任何一人单方面换成自己的另一个策略，都无利可图」。

拿口诀逐格验性别战：（歌剧，歌剧）里甲偏离得 $0<2$、乙偏离得 $0<1$，无人想动，是均衡；（足球，足球）同理；（歌剧，足球）里甲的收入是 $0$，换成足球得 $1$，他想动，不是均衡。性别战有两个纯均衡，猎鹿也有两个（一起猎鹿、各自抓兔），其中（抓兔，抓兔）明明更差却依然稳定：单方去猎鹿得 $0<1$。

猜拳是第三个世界：石头、剪刀、布九个格子，每格都有输家想换动作，逐格全灭，纯策略纳什均衡不存在。这不是定义的缺陷而是现实的写照：确定的行为必然被针对，出路是让对手猜不透，即随机化。

## $\rm \S \, 1.4$ 混合策略、等利润法与纳什定理

**混合策略（mixed strategy）**是策略集上的一个概率分布，支付按期望计。随机化的意义只在博弈内部：均衡处你愿意随机，是因为对手已被逼到对你的几个纯策略**无差异**，反过来你也一样。这条「让对方无差异」的等利润法把混合均衡变成方程组，性别战可以完整手算。设甲以概率 $p$ 出歌剧、乙以概率 $q$ 出歌剧：

$$
\begin{aligned}
\text{甲出歌剧的期望：} 2q, \quad \text{出足球：} 1-q &\quad\Rightarrow\quad 2q = 1-q \;\Rightarrow\; q = \tfrac{1}{3} \\
\text{乙出歌剧的期望：} p, \quad \text{出足球：} 2(1-p) &\quad\Rightarrow\quad p = 2(1-p) \;\Rightarrow\; p = \tfrac{2}{3}
\end{aligned}
$$

于是混合均衡是甲 ${(\tfrac{2}{3},\tfrac{1}{3})}$、乙 ${(\tfrac{1}{3},\tfrac{2}{3})}$（括号内是出歌剧的概率），各得期望支付 $\tfrac{2}{3}$，与两个纯均衡的 ${(2,1)}$、${(1,2)}$ 相比人人吃亏：协调失败有代价。用网格搜索独立验证（Python 3.12、numpy 2.4，实测输出）：

```python
import numpy as np
def uR(p, q): return p*2*q + (1-p)*(1-q)      # 甲的期望支付
def uC(p, q): return q*p + (1-q)*2*(1-p)      # 乙的期望支付
G = np.arange(301) / 300                      # 步长 1/300，使 2/3 恰在格点上
pts = [(p, q) for p in G for q in G
       if max(uR(1,q) - uR(p,q), 0) < 1e-9 and max(uC(p,1) - uC(p,q), 0) < 1e-9]
```

```text
[(0.0, 0.0), (0.6666666666666666, 0.3333333333333333), (1.0, 1.0)]
```

三个格点正好是两个纯均衡加一个混合均衡。再看这组概率在动力学下的命运：每轮两人都朝自己的最佳应对挪 10%（$p \leftarrow p + 0.1\,\mathrm{br}(q)$，$\mathrm{br}$ 取 0 或 1）。过程无随机性，复现只需固定初值：

| 轮 $t$ | 甲 $p$ | 乙 $q$ |
| --- | --- | --- |
| 0 | 0.5000 | 0.5000 |
| 1 | 0.5500 | 0.4500 |
| 2 | 0.5950 | 0.4050 |
| 3 | 0.6355 | 0.3645 |
| 4 | 0.6720 | 0.3281 |
| 5 | 0.6048 | 0.3952 |
| 6 | 0.6443 | 0.3557 |
| 7 | 0.6799 | 0.3201 |
| 8 | 0.6119 | 0.3881 |
| 9 | 0.6507 | 0.3493 |
| 10 | 0.6856 | 0.3144 |

第 4 轮 $p$ 冲过 $\tfrac{2}{3}$，乙转头推高歌剧、$q$ 回升；第 5 轮 $q$ 跌破 $\tfrac{1}{3}$，甲被拽回足球方向。轨迹绕着 ${(\tfrac{2}{3},\tfrac{1}{3})}$ 打转而不停下，跑到 2000 轮还在 (0.691, 0.309) 附近转圈：混合均衡是这股动力的中心，不是终点。想找到它，靠无差异条件，不靠迭代。猜拳的唯一均衡是三策略各 $\tfrac{1}{3}$，期望支付 $0$。

**纳什定理（Nash theorem, 1950）**：任何有限博弈都存在混合策略纳什均衡。证明只给直觉草图：把每个玩家的混合策略看成一张单纯形（概率向量的集合），全体策略组合构成一张紧凸集；「切换到某个最佳应对」定义了一个从这张集合到自身的连续映射；Brouwer 不动点定理说连续映射必有不动点；不动点上没人想换策略，它就是纳什均衡。猜拳说明纯均衡可以没有，定理保证混合的一定有。

## $\rm \S \, 1.7$ 本章自测答案

> 先闭卷作答 §1.5 与 §1.6，再核对。

### $\rm \S \, 1.7.1$ 关键概念回顾答案

1. 玩家、策略集、支付函数。普通算法题的输入是死的，博弈的「输入」来自会互相预判的多个决策者。（§1.1）
2. 弱占优只要求不低于且至少一处更高。弱占优的逐次剔除可能依赖顺序、删掉本该留下的均衡，严格版与顺序无关且不丢均衡。（§1.2）
3. 单方去猎鹿得 $0<1$，无利可图，是均衡。它是帕累托劣势的均衡：协调失败把两人锁在低收益上。（§1.3）
4. 两个纯（歌剧，歌剧）与（足球，足球）加一个混合。甲以 $\tfrac{2}{3}$、乙以 $\tfrac{1}{3}$ 出歌剧，各得期望 $\tfrac{2}{3}$。（§1.3、§1.4）
5. 任何确定行为都会被针对，每个格子都有人想偏离。混合均衡是三方各以概率 $\tfrac{1}{3}$ 出拳，期望支付 $0$。（§1.3、§1.4）
6. 保证「切换到最佳应对」这一连续映射存在不动点；不动点即无人想偏离的策略组合。（§1.4）

### $\rm \S \, 1.7.2$ 应用与辨析答案

1. 取石子是完美信息博弈：轮到谁，谁看得见全部局面。确定性最优策略可被双方都算出来，随机化只会白白放弃已知的最优分支；混合策略要对付的是「猜不透」，前提先得有东西可猜。（§1.3，另见 §2.4）
2. 错在把「随机」当成目的。均衡里的随机是手段：它让对手无法针对性反制，双方都以「对方猜不透我」为条件恰好互相锁住；预测的对象是概率分布，不是单次出拳。（§1.4）
3. 甲的无差异不变（$2q=1-q$，$q=\tfrac{1}{3}$）；乙的无差异变为 $p = 3(1-p)$，解得 $p=\tfrac{3}{4}$。乙在足球上更甜，甲就得更多押歌剧去讨好他。（§1.4）
4. 严格占优：是，且剔除过程不丢任何均衡。弱占优：不一定，弱占优剔除可能把某些均衡连同策略一起删掉，结果还依赖删除顺序。（§1.2）
