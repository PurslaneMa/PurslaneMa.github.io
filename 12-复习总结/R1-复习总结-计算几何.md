# R1 复习总结：计算几何

六章压成三句话：**基元决定正确性**（第 1 章）——叉积判向、整数算术优先、eps 不可传递；**凸包决定骨架**（第 2—3 章）——Andrew 单调链 O(n log n)、卡壳双指针 O(n) 求直径、最近点对分治；**结构决定规模**（第 4—6 章）——扫描线把判交从 O(n²) 降到 O((n+k) log n)、Voronoi/Delaunay 把邻近关系编码成图、kd 树/网格把查询组织起来。验收标准：闭卷清单答出几成、§R1.3 六条心智模型能默几条。

## $\rm \S \, R1.3$ 核心心智模型复读

1. **几何是证明不是统计**：浮点是概率、整数是确定性——能整数化就整数化。
2. **凸包是外形摘要**：极值问题的最优解总在凸包上（直径、最远点对）。
3. **双指针＝凸性红利**：凸壳上的目标函数单峰，卡壳才有 O(n)。
4. **扫描线＝时间换空间**：把「x 方向的远近」变成事件顺序，只看邻居。
5. **对偶＝同一张图两张脸**：Voronoi 的面对偶 Delaunay 的顶点——分析一侧、构造另一侧。
6. **先问 n 再选算法**：暴力/半平面/扫描线/树结构，规模决定选择。

## $\rm \S \, R1.5$ 易混点对照

1. **pop 条件 ≤ vs <**：≤0 保「无共线点」的严格凸包；<0 保留共线边——按题目口径选。
2. **条带半宽 δ/2 vs δ**：正确是**半宽 δ**（点距条带中线 < δ 才需互查）——写 δ/2 会漏解。
3. **对踵点对 vs 最远点对**：最远点在凸包上且必为对踵点对；对踵对不都是最远对。
4. **Voronoi 格 vs Delaunay 三角形**：一个是最远点分区（凸多边形）、一个是三角剖分（顶点是原 Point）——对偶但不同层。
5. **扫描线「有交」vs「报告所有交」**：判定可早停；报告必须处理全部事件，k 决定复杂度。
6. **网格 O(1) vs kd 树 O(log n)**：均匀点网格快；聚簇点网格爆——看数据分布选。

## $\rm \S \, R1.6$ 答案与提示

### 闭卷回忆清单

1. cross = (a−o)×(b−o)；>0 左转、<0 右转、=0 共线；点积判投影/直角。（§1.1）
2. 坐标放大整数化→整数算术（long long/int128）→自适应；eps 不可传递、尺度依赖。（§1.2）
3. 快速排斥（bbox 不相交直接否）＋跨立（d 符号异侧）＋共线 on_seg 特判。（§1.3）
4. $2A = \sum (x_i y_{i+1} - x_{i+1} y_i)$；射线法数穿越次数奇偶；边界点按「统一算内/外」约定。（§1.4）
5. cross(h[−2], h[−1], p) ≤ 0 则 pop；排序后每个点被弹出后不会再作为右端点回归。（§2.2）
6. 排序归约：能 O(n log n) 求凸包就能 O(n log n) 排序——下界成立。（§2.3）
7. 最远点对必为对踵点对；卡钳旋转时支撑点序号单调不减。（§3.1—3.2）
8. 半宽 δ；同侧格点 y 距 ≤ δ 的最多 7 个（8 格 packing 减一）。（§3.4）
9. 左端点（插入+查邻）、右端点（删除+邻邻互查）、交点（交换+查新邻）；相交对在交点前必曾相邻。（§4.2）
10. k 是实际交点数；共线族定序、共点批量、端点 on_seg、浮点顺序污染。（§4.2—4.3）
11. $V_i = \bigcap (n-1)$ 半平面；凸性来自半平面交。（§5.1）
12. 面↔顶、边↔边、顶↔面。（§5.2）
13. 外心最近 ⟹ Voronoi 顶点 ⟹ 三格相邻；局部＝逐三角形空圆、全局＝最小角最大。（§5.3）
14. 切平面距离 ≥ 当前最优则剪枝（距离下界论证）；网格适合均匀点+大量查询。（§6.2—6.3）
