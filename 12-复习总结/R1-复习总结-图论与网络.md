# R1 复习总结：图论与网络

六章压成三句话：**词汇与计数**（第 1—2 章）——握手引理 $\sum_v d(v) = 2m$ 与双计数打底，Prüfer 序列把 Cayley 公式变成数序列的题，不变量按「度序列弱于三角形数弱于谱」排序；染色给出 $\omega \le \chi \le \Delta + 1$（Brooks 收到 $\Delta$），Ramsey 断言压力之下秩序躲不掉（$R(3,3) = 6$）；**边界与谱**（第 3—4 章）——Turán 用对称化压路机把禁团图的边数钉死在 $t_r(n)$，Erdős–Stone 给色数加冕为渐近身份证；Laplacian 把连通变成 $\mu_2$、把生成树数变成特征值乘积，Cheeger 把割与谱锁进同一个不等式；**随机与过程**（第 5—6 章）——ER 在 $c = 1$ 相变、WS 用重连买距离、BA 长出度指数 3；Dijkstra 与最大流的正确性各押一条不等式，GNN 的信息传递把全册量法接回一台机器（过平滑、1-WL 上限、重尾偏斜）。验收标准：闭卷清单答出几成、§R1.3 六条心智模型能默几条。

## $\rm \S \, R1.3$ 核心心智模型复读

1. **双计数是图论的第一引擎**：握手引理、$A^k$ 计走道、迹公式全是「同一集合两本账」——奇偶性、边数、三角形数都从求和里逼出来。
2. **压力与禁令是硬币两面**：Ramsey 说点够多秩序躲不掉，Turán 说禁令之下边数有天花板，Erdős–Stone 把两边的裁判权都交给色数 $\chi$。
3. **谱是显微镜不是身份证**：迹公式从谱读边数与三角形数、$\mu_2$ 量连通、Cheeger 锁割，但同谱异构仍在——探针强不等于同构。
4. **相变是量变到质变的精确化**：巨分量 $c = 1$、连通窗口 $\ln n$、$R(3,3)$ 暴力账从 12 到 0——「从有到无的断崖」有方程也有数值锚。
5. **结构决定过程**：Dijkstra 靠非负权、GNN 的感受野是 $A^k$ 支持集、过平滑塌向度比例 $\pi$、1-WL 上限与重尾偏斜——算法跑在量过的结构上。
6. **数值锚钉死直觉**：Petersen 八条、2000 棵生成树、$23 = 12 + 7 + 4$、$p = 0.01$ 买走 43% 距离——每个结论配一个能复跑的数。

## $\rm \S \, R1.4$ 交错练习

1. 31 名同学每人恰好认识班里另外 3 人，这样的关系网可能吗？给两条独立理由。（答：不可能；度和 93 为奇违反握手引理，且 Havel–Hakimi 每步总和严格减 2、奇偶是不变量）
2. $K_6$ 的 $2^{15} = 32768$ 种红蓝二染色中，无单色三角形的有几种？（答：0 种，$R(3,3) = 6$ 的暴力面）
3. Petersen 图的生成树数是多少？用哪个定理算？（答：$2000 = (2^5 \times 5^4)/10$，Kirchhoff 矩阵–树定理）
4. 2000 个顶点的无三角形网络，超过多少条边才保证有三角形？实测 50 万条能断言有三角形吗？（答：超过 $\lfloor 2000^2/4 \rfloor = 10^6$ 条才保证；50 万不能断言，Mantel 给的是上限不是判据）
5. $n = 10^6$ 的 ER 传感器网络要连通概率超九成，$p$ 至少取多大？（答：$c \approx 2.25$ 使 $e^{-e^{-c}} > 0.9$，$p \approx 1.6 \times 10^{-5}$）
6. 图有负权边但无负圈，Dijkstra 还对吗？（答：不对；$s \to t$ 权 2 会被 $s \to x \to t$ 合计 1 打败——定案时后段还可能变便宜）
7. GNN 层数叠得越多效果越好吗？（答：不是；过平滑把特征塌缩到 $\mathbf{1}\pi^\top H^{(0)}$，$\pi = d/\sum d$，真实 GNN 只叠两三层）

## $\rm \S \, R1.5$ 易混点对照

1. **Ramsey vs Turán**：前者对染色——点够多、单色秩序躲不掉（$R(3,3) = 6$）；后者对子图——禁令之下边数有顶（$t_r(n)$）。别把 $R(k, l)$ 当边数上限用。
2. **邻接谱 vs Laplacian 谱**：$\lambda_1 = d$ 刻画连通正则、迹公式只对 $A$；$L$ 恒有 $\mu_1 = 0$、零重数计分量、$\mu_2$ 量连通——两套特征值各有各的读法，别互相搬运。
3. **电导率割 vs $s$-$t$ 割**：前者无向、按体积归一、只有 Cheeger 的 $\sqrt{2\nu_2}$ 谱近似；后者有向带容量、有多项式精确算法（最大流）——同一个「割」字跨两个世界。
4. **巨分量相变 vs 连通性窗口**：$c = 1$ 管「出现巨型分量」，$(\ln n + c)/n$ 管「连一个孤立点都没有」——后者贵一个 $\ln n$ 因子。
5. **WS vs BA**：WS 靠随机重连买距离、聚集几乎不动（$p = 0.01$ 折损 2% 聚集换 43% 距离）；BA 靠优先连接长重尾（度指数 3 与 $m$ 无关）——一个补聚集、一个补枢纽。
6. **极值思维 vs 随机生长**：Turán 均匀摊平（禁令惩罚聚集），BA 富者愈富（机制奖励聚集）——度分布一窄一重尾，是网络结构谱系的两端。

## $\rm \S \, R1.6$ 答案与提示

### 闭卷回忆清单

1. 接触对集合 $P = \{(v, e)\}$ 的两本账：按顶点数得 $\sum_v d(v)$、按边数得 ${2m}$；总和为偶数故奇度点两两配对。Havel–Hakimi 摘最大度 $d_1$、给后 $d_1$ 项各减一；2-换边靠 $d_i \ge d_j$ 找到 $x \in N(i) \setminus N(j)$，删 ${1,j}$、${i,x}$ 换 ${1,i}$、${j,x}$，度数不变且图仍简单。（§1.1）
2. 恰 $d(v) - 1$ 次：每记一次对应一个先于 $v$ 被摘走的邻居。编码解码互逆成双射，序列空间 $n^{n-2}$ 个元素，Cayley 公式到手。（§1.2）
3. 10 顶点 15 边 3-正则、围长 5、直径 2、独立数 4、强正则 ${10, 3, 0, 1}$、色数 3、谱 $3, 1^{(5)}, (-2)^{(4)}$、非哈密顿；反例名片是围长 5、非哈密顿、$\omega = 2$ 对 $\chi = 3$。（§1.2、§1.5）
4. 度序列最弱、三角形数次之、谱最强；$\rm K_{3,3}$ 与三棱柱度序列同为 $(3^6)$ 但三角形数 0 对 2；$\rm K_{1,4}$ 与 $C_4$ 加孤立点同谱 $2, 0, 0, 0, -2$——谱也非全能。（§1.3、§4.1）
5. $(A^k)_{ij}$ 是长 $k$ 途径条数；$(A^2)_{ii} = d(i)$，$(A^3)_{ii}$ 等于过 $i$ 的三角形数的两倍（无三角形则为零）。（§1.4）
6. 团内点两两异色吃掉 $\omega$ 种颜色；贪心逐点着色至多禁掉 $\Delta$ 色；Brooks 除 $K_{\Delta+1}$ 与奇圈外 $\chi \le \Delta$；脱钩可任意远（Erdős 概率构造），最小正则样本是 Petersen。（§2.1）
7. 上界：一点 5 条关联边必有 3 条同色（鸽笼），对面三点内必有同色边；下界：红 $C_5$ 加蓝 $C_5$ 两图都围长 5。12 个幸存者全是「红五边形蓝五角星」构型，$K_5$ 中五边形恰 $5!/10 = 12$ 个。（§2.2）
8. $R(k,l) \le R(k-1,l) + R(k,l-1)$，双重归纳加 Pascal 恒等式给 $\binom{k+l-2}{k-1}$；Schur 把边 ${i,j}$ 染 $|i-j|$ 的颜色，单色三角形给 $|i-j| + |j-k| = |k-i|$；锚 $S(2) = 4$、$W(2,3) = 9$。（§2.3—2.4）
9. 取边 ${u,v}$ 后 $N(u)$ 与 $N(v)$ 不交（公共邻居成三角形）故 $d(u) + d(v) \le n$；删去净损失 $d(u) + d(v) - 1$，归纳合并出 $\lfloor n^2/4 \rfloor$；等号仅 $\rm K_{\lfloor n/2 \rfloor, \lceil n/2 \rceil}$。（§3.1）
10. 边极大化、Zykov 对称化（不相邻且度小者换邻域边数严格增）、不相邻成等价关系、完全多部现形、搬点配平（净变化 $a - b - 1$）；$t_r(n) = \frac{1}{2}(n^2 - \sum_i n_i^2)$，各部差至多 1。（§3.2）
11. $\mathrm{ex}(n, H) = (1 - 1/(\chi(H) - 1) + o(1))\, n^2/2$，色数决定渐近；$\chi = 2$ 时系数归零只剩 $o(n^2)$，打到多低色数看不见——$C_4$ 的 $\frac{1}{2} n^{3/2}$ 是深水区地标。（§3.3）
12. $x^\top L x = \sum_{\{i,j\}} (x_i - x_j)^2$；0 特征值重数 = 分量数；$\tau(G) = \frac{1}{n}\prod_{i \ge 2} \mu_i$（$K_4$ 16、$C_4$ 4、Petersen 2000）；Cheeger $\nu_2/2 \le \varphi \le \sqrt{2\nu_2}$，Petersen 下界取等（$\varphi = 1/3$，外圈五边形取得）。（§4.2—4.3）
13. 把指示向量松弛成与 $\mathbf{1}$ 正交的实向量、目标换成 Rayleigh 商，解为 Fiedler 向量；前 $k$ 个特征向量做嵌入、k-means 收尾；双 $C_4$ 桥图谱缝 $0.2713$ 对 $0.7713$、符号切分还原两簇。（§4.4）
14. Poisson 指纹是均值等于方差（模拟 10.026 对 9.952）；$1 - S = e^{-cS}$、临界 $c = 1$；连通概率 $\approx e^{-e^{-c}}$；WS 的 $C(p) = C(0)(1-p)^3$ 缓降对 $L$ 断崖（$p = 0.01$：聚集折损 2%、距离折损 43%）。（§5.1—5.2）
15. BA 两步：$k_i(t) = m\sqrt{t/t_i}$、$P(k_i \ge k) = m^2/k^2$，密度 $p(k) = 2m^2 k^{-3}$，指数 3 与 $m$ 无关；三模型机制——不知道连谁 / 守家加出远门 / 挤向人多的地方；Dijkstra 非负权用在「前缀之后不变便宜」一步；最大流最小割：停机时残量可达集是最小割 $S$ 侧、割边全饱和（锚 $23 = 12 + 7 + 4$）；GCN 的 $k$ 层 = $k$ 步随机游走（$A^k$ 的度归一版）= $k$ 步 Laplacian 平滑，过平滑极限 $\mathbf{1}\pi^\top H^{(0)}$，1-WL 上限的证人是 $\rm K_{3,3}$ 与三棱柱。（§5.3—5.4、§6.1—6.3）
