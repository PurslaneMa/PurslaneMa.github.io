# R1 复习总结：微分几何与李群

六章压成三句话：**流形语言**（第 1—2 章）把「局部像欧氏、整体弯」的对象装上图册与切空间——隐函数定理是地基、切向量是曲线等价类、微分是切空间之间的线性映射；**对称与几何**（第 3—5 章）给李群-李代数对应、指数映射与 Rodrigues 正交性全证、黎曼度量与测地线、球面大圆定理与绝妙定理的内蕴链 $K \leftarrow R \leftarrow \Gamma \leftarrow g$；**算法落地**（第 6 章）把切空间投影、retraction、黎曼梯度下降三件套装进优化器，球面实验三锚与 SE(3)/Grassmann 主战场收口。验收标准：闭卷清单答出几成、§R1.3 六条心智模型能默几条。

## $\rm \S \, R1.3$ 核心心智模型复读

1. **流形＝平纸拼弯世界**：每张坐标卡是一张平纸，转移映射决定缝怎么焊。
2. **切空间＝脚下的平世界**：优化在切空间里走、retraction 把你拉回流形。
3. **李代数＝无穷小转动**：指数映射一条龙积成有限转动；括号度量「转动的不可交换性」。
4. **度量＝每点一把尺**：$\sin^2\theta$ 是纬度对经线尺的压缩；地图失真是度量账。
5. **测地线＝直线的两个化身**：不拐弯（协变加速零）⟺ 局部最短；球面上是大圆。
6. **曲率是内禀的**：二维生物不开口即可测出（圆周长偏差、内角和）——纸卷成筒居民无感。

## $\rm \S \, R1.4$ 交错练习

1. $f(x) = |x|^2$ 在 $\mathbb{R}^3$ 的哪些水平集是流形？（答：$r \ne 0$ 的球面，正则值定理）
2. $A, B \in \mathfrak{so}(3)$，$[A, B]$ 还在 $\mathfrak{so}(3)$ 里吗？（答：在，反对称封闭，残差 0 实测）
3. 单位球上 $p = (1, 0, 0)$、$q = (\frac12, \frac{\sqrt3}{2}, 0)$ 的最短距离？（答：$\arccos(\frac12) = \frac{\pi}{3}$）
4. 圆柱面上的测地线长什么样？（答：直纹线（母线）、圆环与螺旋线——展开到平面全是直线）
5. 球面上梯度上升 $f(x) = a^{\mathsf T}x$ 的终点？（答：$a/|a|$，锚 $(0.00194, 0, 0.999998)$）
6. Grassmann 流形与 Stiefel 流形什么关系？（答：Gr ＝ St 对 $O(k)$ 的商——忘标架、记子空间）

## $\rm \S \, R1.5$ 易混点对照

1. **切空间 vs 流形本身**：切空间是向量空间（可以加减）、流形不是（两点相加没有意义）——优化「在切空间算、在流形落」。
2. **李群 vs 李代数**：群是有限转动（非线性）、代数是无穷小转动（线性）；指数映射是桥。
3. **测地线 vs 最短线**：局部最短（测地线）不等于全局最短（球面上大圆绕远圈也是测地线）。
4. **内禀 vs 外禀曲率**：圆柱外看是弯的、内禀 $K = 0$（可展开）；球面两者皆弯（不可展开）。
5. **投影回 vs 测地回**：一步归一化便宜且一阶相合；测地线回几何精确但贵——工程默认前者。

## $\rm \S \, R1.6$ 答案与提示

### 闭卷回忆清单

1. 局部同胚 $\mathbb{R}^n$＋转移映射光滑＋图册；球极投影南北两卡。（§1.2）
2. 正则值水平集是流形；$S^2 = f^{-1}(1)$（$f = |x|^2$）、$O(n) = f^{-1}(I)$（$f(A) = A^{\mathsf T}A$）。（§1.4）
3. 曲线等价类 / 方向导数算子；$T_pS^2 = \{v : v^{\mathsf T}p = 0\}$。（§2.2）
4. 单位元切空间＋括号；$O(n)$ 定义式 $A^{\mathsf T}A = I$ 求导给 $A^{\mathsf T} = -A$。（§3.2）
5. $K^3 = -K$（单位轴）让幂级数只剩三项。（§3.3）
6. 每点一个光滑正定内积；经线尺随纬度压缩。（§4.1）
7. 协变加速零 ⟺ 局部长度最短；$\Gamma$ 由度量一阶导。（§4.2）
8. 等距保测地线＋赤道直验＋旋转扫全部大圆；$d = \arccos(p \cdot q) = \pi/3$。（§4.3）
9. 内蕴曲率：不开口可测 $K$。（§5.1）
10. $K \leftarrow R \leftarrow \Gamma \leftarrow g$；圆柱可展开贴平故 $K = 0$。（§5.3）
11. $\int_\Sigma K\,\mathrm{d}A = 2\pi\chi$；球 $4\pi$、环 0。（§5.4）
12. 欧氏梯度的切向投影；$\mathrm{grad} = a - (a^{\mathsf T}x)x$。（§6.2）
13. $R_p(0) = p$＋一阶相合；测地回/投影回；上升 $(0,0,1)$、衰减 $\sqrt{1 - (a^{\mathsf T}x)^2}$、下降 $(0,0,-1)$。（§6.3—6.4）
