# $\rm Chapter \, 1$ 半圆律

本册讲随机矩阵理论。这门学科回答一个问题：**往矩阵里灌满随机数，特征值服从什么法律**。单个大矩阵的特征值没法一个个算，但一片随机矩阵的特征值合起来，会贴上一条确定的曲线——就像单个气体分子轨迹不可追踪、全体分子却服从压强定律。第 1 章立对象、看现象：Wigner 矩阵、经验谱分布、以及最老牌的那条法律——半圆律；第 2 章换主角，把同样的剧本搬到样本协方差矩阵上，得到 Marčenko–Pastur 律；第 3 章开机器，讲清楚「谱极限是怎么被证明钉死的」——线性统计的集中、矩方法的配对计数、Hanson–Wright 不等式。本章的数值锚：一张 $n = 4000$ 的对称高斯矩阵，实测谱支撑 $[-1.99, 1.99]$ 对理论 $[-2, 2]$，直方图与半圆密度的最大偏差约 $0.009$——每个数都真跑得出。

## $\rm \S \, 1.1$ Wigner 矩阵与经验谱分布：把随机装进矩阵

先说清研究对象解决什么问题。数值线性代数里的矩阵是确定性的——给定了就有一个特征值清单。但一大类应用里的矩阵天生带随机：无线信道的采样矩阵、神经网络初始化的权重矩阵、图数据的邻接矩阵、统计里的数据矩阵。对它们问「第 37 个特征值是多少」没有意义（每次抽样都不同），有意义的是问**「特征值全体长什么样」**——分布的形状在抽样之间稳不稳。随机矩阵理论的全部内容，就是把这个「形状」变成可以证明的定理。

定义来了。对每个 $n$，取一个 $n \times n$ 实对称矩阵 $W_n$：对角线元素独立、方差 $2/n$；严格上三角的元素独立、零均值、方差 $1/n$；下三角按对称补齐。这样的 $W_n$ 叫**Wigner 矩阵**，元素取高斯分布时它就是 GOE（正交不变系综）的标准化版本。

（读法：三个细节各有用途。「对称」保证特征值全是实数，谱语言才有得谈；「独立」只要求上三角，对称性会制造下三角的镜像副本；「方差 $1/n$」是刻意的缩放——它的理由马上给。）

白话：**Wigner 矩阵是把 $n(n+1)/2$ 个独立噪声铸成的一件对称金属器件**。每个零件都是噪声，但铸成整体后，特征值不是噪声——它们服从法律。而「除以 $\sqrt n$」是这铸件工艺里的温度归一化：本站高维概率与矩阵分析册第 4 章 §4.3 量过这道天花板，不缩放的高斯对称矩阵谱范数随 $n$ 涨到 $2\sqrt n$，谱会一路漂出屏幕；除掉 $\sqrt n$ 这个自然尺度，谱就被按在数轴上的固定区间里。这个缩放是唯一的：除 $\sqrt n$ 少了谱发散，除多了谱塌成零，只有 $1/\sqrt n$ 让极限非平凡——与中心极限定理里「除 $\sqrt n$ 才得到极限分布」是同一个算术。

看一个对象长什么样，先做人口普查。对称矩阵 $W_n$ 的特征值为 $\lambda_1, \ldots, \lambda_n$，其**经验谱分布（empirical spectral distribution, ESD）**是概率测度

$$
\mu_n = \frac{1}{n} \sum_{i=1}^{n} \delta_{\lambda_i}
$$

（读法：$\delta_{\lambda_i}$ 是扎在 $\lambda_i$ 处的单位质点；$\mu_n$ 就是把 $n$ 个特征值各摊上 $1/n$ 的权重、撒在数轴上形成的一把沙。本站高维概率与矩阵分析册第 4 章定义 4.1 正是它。）「经验」二字与经验分布函数同源：不管矩阵从哪个随机规律来，抽出来这一次的谱就是一份经验样本。问题于是变成：$n \to \infty$ 时，这把沙会堆积成什么形状？

白话：ESD 把「$n$ 个特征值」这个高维对象压缩成数轴上的一团概率云。单个特征值是随机的、没有极限可言，但云的整体形状可以收敛——这正是「从个体无序到集体有序」的标准剧本，与「单次抛硬币无规律、频率收敛到 $1/2$」同构。

**本节小结**：Wigner 矩阵＝对称＋上三角独立＋方差 $1/n$ 的缩放；缩放是让极限非平凡的唯一温度；ESD 把特征值清单变成数轴上的概率云。下一节给这团云的极限形状，并用 $n = 4000$ 的实测把它钉在纸上。

## $\rm \S \, 1.2$ 半圆律：陈述与 $n = 4000$ 的数值验收

定理先上。

**定理 1.1（半圆律，Wigner 1955，陈述级）**：设 $W_n$ 为 Wigner 矩阵（元素分布只需零均值、方差 $1/n$、矩条件温和），则其 ESD $\mu_n$ 几乎必然弱收敛到**半圆律** $\mu_{\mathrm{sc}}$——支撑在 $[-2, 2]$、密度为

$$
\rho_{\mathrm{sc}}(x) = \frac{1}{2\pi} \sqrt{4 - x^2}
$$

（读法：这条密度只在 $[-2, 2]$ 上非零，端点处密度降到零但斜率陡——$\rho_{\mathrm{sc}}(x) \approx \sqrt{2} \cdot \sqrt{2 - x}\, / \pi$ 在右端点附近展开，是平方根式的「贴地起飞」；中心 $x = 0$ 处取最大值 $1/\pi \approx 0.3183$。曲线的形状确实是半个圆：把 $y = \sqrt{4 - x^2}$ 除以 $2\pi$，它就是半径为 $2$ 的上半圆周压上 $1/(2\pi)$ 的高度因子。）

三个必须当场指出的特征，防止「听着像高斯」的错觉：

1. **支撑是紧的**：全部质量关在 $[-2, 2]$ 里，端点外严格没有特征值（有限 $n$ 时有 $O(n^{-2/3})$ 尺度的少量越界，下面实测会看到）；高斯密度则拖着无穷长的尾巴。
2. **边缘是平方根奇性**：密度在端点附近像 $\sqrt{2 - x}$ 一样陡起陡落，这不是钟形——钟形（正态、Logistic）在边缘是指数式衰减，这里是代数式截断。
3. **对称**：密度是偶函数，因为 $W_n$ 与 $-W_n$ 同分布。

陈述说完了，验货。程序生成 $n = 4000$ 的 Wigner 矩阵、算全部特征值、把支撑和直方图与理论对照（程序段完整版在 §1.6，这里先看关键几行）：

```python
import numpy as np
n = 4000
rng = np.random.default_rng(2)
G = rng.standard_normal((n, n))
W = (G + G.T) / np.sqrt(2 * n)          # 对称化: off-diag 方差 1/n, diag 方差 2/n
ev = np.linalg.eigvalsh(W)              # 对称矩阵专用特征值例程
print("min = %.4f  max = %.4f" % (ev.min(), ev.max()))
```

实跑输出（本章数值锚，照抄）：

```text
min = -1.9925  max = 1.9921
```

实测支撑 $[-1.9925, 1.9921]$，对理论 $[-2, 2]$：两端各回缩约 $0.008$，这正是有限 $n$ 时边缘的涨落尺度——谱越往外越稀，最靠边的特征值离端点差一点是常态，$n$ 越大回缩越少。

再验形状。把 $[-2, 2]$ 均分成 $46$ 条 bin（宽 $0.0870$），数每条 bin 里的特征值个数、除以 $n \times$ 宽度得到密度估计，与 $\rho_{\mathrm{sc}}$ 逐格比对：

```python
bins = np.linspace(-2.0, 2.0, 47)
cnt, edges = np.histogram(ev, bins=bins)
width = edges[1] - edges[0]
centers = (edges[:-1] + edges[1:]) / 2
emp = cnt / (n * width)                 # ESD 密度估计
rho = np.sqrt(np.clip(4 - centers**2, 0, None)) / (2 * np.pi)
dev = np.abs(emp - rho)
print("max dev = %.5f at x = %.3f" % (dev.max(), centers[dev.argmax()]))
print("mean dev = %.5f" % dev.mean())
i = np.abs(centers).argmin()
print("density at 0: emp %.4f vs theory %.4f" % (emp[i], 1/np.pi))
print("mass in [1.9, 2.0]: emp %.5f vs theory %.5f"
      % (np.mean((ev > 1.9) & (ev < 2.0)),
         (np.pi - ((1.9/2)*np.sqrt(4-1.9**2) + 2*np.arcsin(1.9/2))) / (2*np.pi)))
```

```text
max dev = 0.00879 at x = 1.261
mean dev = 0.00282
density at 0: emp 0.3220 vs theory 0.3183
mass in [1.9, 2.0]: emp 0.00675 vs theory 0.00666
```

四笔账逐条对上：全谱 $46$ 格中最大偏差 $0.0088$（「约 $0.009$」的出处），平均偏差不到 $0.003$；中心密度实测 $0.3220$ 对理论 $1/\pi = 0.3183$；最右一条格 $[1.9, 2.0]$ 的质量实测 $0.00675$ 对理论积分值 $0.00666$——边缘的平方根小尾巴连质量都称得准。

最后这批数里藏着一条本节最深的性质，值得单独拍在桌上：$0.009$ 这个偏差**小得反常**。对照实验：从半圆密度独立抽 $4000$ 个点（拒绝采样）、用同样 $46$ 条格做直方图，最大偏差是 $0.0618$——特征值谱的偏差比独立抽样小 $7$ 倍。原因：特征值不是独立样本，它们**互相排斥**（eigenvalue repulsion）——两个特征值靠得太近时，联合密度在重合处趋于零，把彼此推开。排斥把 ESD 的整体涨落从独立抽样的 $O(n^{-1/2})$ 压到 $O(1/n)$ 量级（第 3 章 §3.1 的线性统计集中会给这半句一个证明骨架），$n = 4000$ 时直方图才能贴到千分位。

**本节小结**：半圆律说 ESD 弱收敛到 $\rho_{\mathrm{sc}}(x) = \sqrt{4 - x^2}/(2\pi)$，支撑 $[-2, 2]$、平方根边缘、中心 $1/\pi$；$n = 4000$ 实测支撑 $[-1.99, 1.99]$、最大偏差 $0.009$、边缘质量逐位吻合；偏差远小于独立抽样的对照实验暴露了特征值排斥。下一节回答「这条曲线是怎么被发现的」——Wigner 的矩方法，它同时是第 3 章整台机器的图纸。

## $\rm \S \, 1.3$ Wigner 的洞见：矩方法骨架

白话：1955 年 Wigner 手里没有 Stieltjes 变换这些现代工具（本站高维概率与矩阵分析册第 10 章走的那条路），他抓住的是一个朴素事实：**数轴上一团概率云，若各阶矩全算得出来、且矩列唯一决定测度，云的形状就被钉死了**。半圆律的矩有一张漂亮的脸——偶数阶矩是 Catalan 数。本节铺骨架，机器的完整运转在第 3 章。

第一步：半圆律的矩。对 $k \ge 1$，

$$
m_{2k} \;=\; \int x^{2k} \,\mathrm d\mu_{\mathrm{sc}}(x) \;=\; C_k \;=\; \frac{1}{k+1} \binom{2k}{k}
$$

（读法：$C_k$ 是第 $k$ 个 Catalan 数——$1, 2, 5, 14, 42, \ldots$，计数「$k$ 对括号的合法嵌套方式数」。奇数阶矩全为零，密度对称使然。） Catalan 数从积分里冒出来毫无线索，但配对计数会让它现形。

第二步：ESD 的矩可以换成矩阵的语言算。$\mu_n$ 的 ${2k}$ 阶矩就是

$$
\int x^{2k} \,\mathrm d\mu_n(x) \;=\; \frac{1}{n} \sum_{i=1}^{n} \lambda_i^{2k} \;=\; \frac{1}{n} \operatorname{tr} W_n^{2k}
$$

（读法：特征值的幂和等于矩阵幂的迹——谱分解的一行推论，本站高维概率与矩阵分析册第 5 章 §5.2 的记账法。）于是「$\mu_n$ 的矩收敛到 $C_k$」翻译成矩阵陈述：

$$
\frac{1}{n} \operatorname{E} \operatorname{tr} W_n^{2k} \;\longrightarrow\; C_k
$$

第三步：把期望拆开，配对计数登场。展开迹，

$$
\operatorname{tr} W_n^{2k} = \sum_{i_1, \ldots, i_{2k}} W_{i_1 i_2}\, W_{i_2 i_3} \cdots W_{i_{2k} i_1}
$$

（读法：指标沿一条闭合路径走 ${2k}$ 步，每步取矩阵的一个元素相乘。）每一项是 ${2k}$ 个高斯变量的乘积，期望用 **Wick 公式**（第 3 章定理 3.4 给证明）拆成所有配对：${2k}$ 个变量两两配成 $k$ 对，每对的期望相乘、再把所有配法加起来。关键的分岔在配对的几何：**非交叉配对**（把 ${2k}$ 个位置排成圆圈，配对的弦互不交叉）有 $C_k$ 种，每个贡献 $n$ 量级；交叉配对数目更多，但自由指标更少、贡献低一阶，$n \to \infty$ 时被甩掉。主导项恰好 $C_k$ 个、每个 $n$ 量级——

$$
\frac{1}{n} \operatorname{E} \operatorname{tr} W_n^{2k} \;=\; C_k + o(1)
$$

Catalan 数从「弦不交叉」里长出来。这条骨架的每一步（Wick 公式、配对的自由指标记账、交叉项为何低阶、以及「矩列唯一决定测度」这最后一块木板）都在第 3 章补全；本章先把骨架的预言拿到数值上过秤——用 $n = 4000$ 那张谱直接算各阶矩：

$$
m_2 = 1.0000,\quad m_4 = 1.9996,\quad m_6 = 4.9972,\quad m_8 = 13.9887
$$

对 Catalan 数 $C_1 = 1$、$C_2 = 2$、$C_3 = 5$、$C_4 = 14$：前四阶矩逐位咬合。一条 $n = 4000$ 的谱同时通过了形状检验（§1.2 的直方图）与矩检验——半圆律的两头都焊住了。

**本节小结**：半圆律的偶数阶矩是 Catalan 数；ESD 的矩翻译成 $(1/n)\operatorname{tr} W^{2k}$；Wick 配对计数里非交叉配对主导、给出 $C_k$，交叉配对低阶出局。骨架三步（化矩为迹、Wick 收缩、非交叉主导）在第 3 章装机成完整证明。下一节回答更上层的问题：这条曲线凭什么「普适」。

## $\rm \S \, 1.4$ 普适性：为什么大矩阵的谱有同一张脸

白话：半圆律最惊人的地方不在曲线本身，而在**曲线不挑材料**。定理 1.1 里元素的分布可以是高斯、可以是 $\pm 1$ 的 Rademacher 硬币、可以是截断的任何温和分布——只要零均值、方差 $1/n$，$n$ 大了谱都收敛到同一条半圆。这与中心极限定理的架构完全同构：CLT 里 $n$ 个独立变量的和经 $\sqrt n$ 标准化后收敛到正态，不管单变量是什么分布；这里 $n^2$ 个独立元素的谱经 $1/\sqrt n$ 缩放后收敛到半圆，不管单元素是什么分布。随机性足够多时，细节被冲刷掉，只剩下「有多少、方差多大」这种粗账——**普适性（universality）**说的就是这件事。

对照表把同构摆明（只列要点）：

1. 标准化：CLT 除 $\sqrt n$；Wigner 除 $\sqrt n$（每个元素摊到的随机性随 $n$ 变薄，厚度 $1/\sqrt n$ 是让谱不发散不塌缩的唯一档位）。
2. 极限对象：CLT 收敛到正态密度；Wigner 收敛到半圆密度。两者都由前两阶矩决定形状、都不挑高阶矩。
3. 极限的指纹：正态的指纹是 Bell 数式的矩递推；半圆的指纹是 Catalan 数——第 3 章会看到两者都出自「高斯配对」，只是配对所在的几何不同（时序直线 vs 闭合路径的非交叉性）。

「为什么有普适形状」可以从两个互补的方向看：

1. **证明的方向（第 3 章铺开）**：矩方法的账本里，极限矩只用到元素的一、二阶矩（方差 $1/n$ 定尺度），高阶矩全部躲进 $o(1)$ 项。极限由低阶矩决定，所以高阶分布细节无关——这是普适性的账面原因。
2. **物理的方向**：特征值排斥（§1.2 的对照实验已经现场演示过）是谱形状的局部机制，而排斥的强度由对称性与方差决定、不由分布的更高层细节决定。同一套排斥规则浇出同一条曲线——这是普适性的机制原因，其严格化（局部半圆律与 Tracy–Widom 波动）超出本册，读者记住这条线索即可。

普适不是无条件白给，三个前提缺一不可，每一个的破坏都各有下场：

1. **独立性**（至多允许弱相关）：元素全同相关的极端情形 $W_{ij} = u_i u_j$ 秩一，谱是一根刺不是半圆。
2. **方差齐一**：若方差结构 $V_{ij}$ 不是近似常数矩阵，极限变成形变半圆（deformed law），形状随 $V$ 变——普适的是「给定方差结构后的形状」，不是无条件同一张脸。
3. **矩不野**：单元素分布有足够多阶的矩。重尾元素（方差存在但四阶矩爆炸）会让最大特征值挣脱 $[-2, 2]$ 的牢笼——第 2 章 §2.4 讲 PCA 时还会遇到这个逻辑的数据版。

应用一瞥收尾。神经网络初始化的方差公式（本站高维概率与矩阵分析册第 4 章 §4.5）：Xavier 初始化取权重方差 $1/n_{\mathrm{in}}$，理由正是把每层的权重矩阵按 Wigner 的温度归一化，让信号前向不爆炸、梯度反向不消失——深度网络的「信号传播」分析把整叠权重矩阵当成一串 Wigner 矩阵来记账。图信号处理里，Erdős–Rényi 随机图（适当归一）的邻接矩阵谱收敛到半圆，半圆之外的离群特征值就是社区结构或 planted 信号的指纹——「普适噪声底座上找离群点」这个套路，第 2 章在 PCA 场景里会做成带数字的实验。

**本节小结**：半圆律是 CLT 的矩阵亲戚——极限形状只由方差定调、不挑分布，普适性由此而来；账面原因是矩方法的低阶矩账本，机制原因是特征值排斥；普适有三个前提（独立、方差齐、矩不野），每个的破坏方式都清晰。本章立完对象与现象，下一章换主角：数据矩阵的样本协方差。

## $\rm \S \, 1.6$ 程序段：半圆律的完整数值验收

把 §1.2 的验收变成可复跑的完整程序（固定种子，换 $n$、换 bin 数都能验）：

```python
import numpy as np

n = 4000
rng = np.random.default_rng(2)
G = rng.standard_normal((n, n))
W = (G + G.T) / np.sqrt(2 * n)      # off-diag var 1/n, diag var 2/n
assert np.allclose(W, W.T)          # 对称性: 谱语言的前提
ev = np.linalg.eigvalsh(W)

print("support: [%.4f, %.4f] vs theory [-2, 2]" % (ev.min(), ev.max()))

bins = np.linspace(-2.0, 2.0, 47)   # 46 条 bin
cnt, edges = np.histogram(ev, bins=bins)
width = edges[1] - edges[0]
centers = (edges[:-1] + edges[1:]) / 2
emp = cnt / (n * width)             # ESD 密度估计
rho = np.sqrt(np.clip(4 - centers**2, 0, None)) / (2 * np.pi)
dev = np.abs(emp - rho)
print("max |emp - semicircle| = %.5f, mean = %.5f" % (dev.max(), dev.mean()))
print("density at 0: %.4f vs 1/pi = %.4f" % (emp[np.abs(centers).argmin()], 1/np.pi))

for k in (1, 2, 3, 4):              # 矩检验: Catalan 数
    print("m_%d = %.4f  (C_%d = %d)" % (2*k, np.mean(ev**(2*k)), k, [1, 2, 5, 14][k-1]))
```

实跑输出：

```text
support: [-1.9925, 1.9921] vs theory [-2, 2]
max |emp - semicircle| = 0.00879, mean = 0.00282
density at 0: 0.3220 vs 1/pi = 0.3183
m_2 = 1.0000  (C_1 = 1)
m_4 = 1.9996  (C_2 = 2)
m_6 = 4.9972  (C_3 = 5)
m_8 = 13.9887  (C_4 = 14)
```

读程序的四句话：对称化 $(G + G^{\mathsf T})/\sqrt{2n}$ 一行同时完成「对称」与「方差 $1/n$」两件事，$\sqrt 2$ 是对称化贡献的方差修正；`eigvalsh` 只吃对称矩阵、比通用 `eig` 稳且快；密度估计的分母是 $n \times$ 宽度，量纲与 $\rho_{\mathrm{sc}}$ 对齐；矩检验用特征值的幂平均直接对照 Catalan 数，是比直方图更锋利的形状探针——形状差一点，高阶矩先报警。

## $\rm \S \, 1.7$ 六问参考答案

1. 谱范数随不缩放的随机对称矩阵涨到 $2\sqrt n$（本站高维概率与矩阵分析册第 4 章 §4.3），除 $\sqrt n$ 后谱被按在固定区间；少除谱发散、多除谱塌缩，只有 $1/\sqrt n$ 给出非平凡极限。与 CLT 的 $\sqrt n$ 标准化同一算术：$n$ 份独立贡献的总幅度是 $\sqrt n$。（§1.1）
2. 四特征：支撑紧（$[-2, 2]$ 外无质量）、平方根式边缘截断、关于 $0$ 对称、中心高度 $1/\pi \approx 0.3183$。正态在边缘指数衰减且中心更高（$1/\sqrt{2\pi} \approx 0.3989$），半圆代数式截断且中心更低更「平顶」。（§1.2）
3. 支撑由两端极值钉住：实测 $[-1.9925, 1.9921]$ 对 $[-2, 2]$；形状由全谱直方图钉住：$46$ 格最大偏差 $0.0088$、平均 $0.0028$、中心密度 $0.3220$ 对 $0.3183$；边缘细节由尾部质量钉住：$[1.9, 2.0]$ 内实测 $0.00675$ 对理论积分 $0.00666$。（§1.2）
4. 排斥指联合密度在两个特征值重合处为零、彼此推开；$7$ 倍的差距说明 ESD 的整体涨落远小于 $n$ 个独立样本的二项噪声——特征值之间有负相关，线性统计的方差是 $O(1)$ 而非 $O(n)$，第 3 章 §3.1 把这句话变成定理骨架。（§1.2）
5. 翻译成 $\frac{1}{n} \operatorname{E} \operatorname{tr} W_n^{2k} \to C_k$（对所有 $k$，加矩唯一性）。Wick 配对把 ${2k}$ 个因子两两相连，非交叉的配法在圆圈几何上正是 $k$ 对括号的合法嵌套——Catalan 数的定义对象。（§1.3）
6. 三前提：独立性（破坏后谱秩亏成刺）、方差齐一（破坏后极限形变、随方差结构走）、矩条件（破坏后重尾元素把极值推出牢笼）。方差改 $2/n$，尺度整体放大 $\sqrt 2$ 倍，极限是 $[-2\sqrt 2, 2\sqrt 2]$ 上的半圆。（§1.4）
