## $\rm \S \, 3.1$ 弦振动方程的推导

张紧的弦（线密度 $\rho$、张力 $T$）做横振动，位移 $u(x, t)$。小振动假设下斜率 $u_x \ll 1$。取微元 $[x, x + \mathrm{d}x]$：竖向合力 $= T\, u_x\big|_{x+\mathrm{d}x} - T\, u_x\big|_x \approx T\, u_{xx}\, \mathrm{d}x$（张力沿弦向，竖向分量 $\approx T u_x$）。Newton 第二定律：$\rho\, \mathrm{d}x\, u_{tt} = T\, u_{xx}\, \mathrm{d}x$：

$$
u_{tt} = c^2\, u_{xx}, \qquad c = \sqrt{T/\rho}
$$

**读法**：$c$ 是波速——绷得越紧（$T$ 大）、弦越轻（$\rho$ 小），波跑得越快。与热方程对照：**二阶时间导**换掉了**一阶**，这一字之差改写了全部性格。

## $\rm \S \, 3.2$ d'Alembert 公式（本章主证）

**定理 3.1**（d'Alembert, 1747）。初值问题 $u_{tt} = c^2 u_{xx}$，$u(x, 0) = f(x)$、$u_t(x, 0) = g(x)$，在 $c$ 常数、全直线情形的解是

$$
u(x, t) = \frac{f(x + ct) + f(x - ct)}{2} + \frac{1}{2c} \int_{x - ct}^{x + ct} g(s)\, \mathrm{d}s
$$

**证明**（换元对角化，逐步写）。令 $\xi = x + ct$、$\eta = x - ct$，即 $x = \frac{\xi + \eta}{2}$、$t = \frac{\xi - \eta}{2c}$。链式法则：

$$
\partial_x = \partial_\xi + \partial_\eta, \qquad \partial_t = c\,(\partial_\xi - \partial_\eta)
$$

于是

$$
u_{tt} - c^2 u_{xx} = c^2\big[(\partial_\xi - \partial_\eta)^2 - (\partial_\xi + \partial_\eta)^2\big] u = -4c^2\, u_{\xi\eta}
$$

方程 $u_{tt} = c^2 u_{xx}$ 变成 $u_{\xi\eta} = 0$——**先对 $\eta$ 积分得 $u_\xi = \Phi(\xi)$，再对 $\xi$ 积分得 $u = F(\xi) + G(\eta)$**：通解是「右行波 $F(x + ct)$ ＋ 左行波 $G(x - ct)$」。代初值定 ${F, G}$：$t = 0$ 时 $F(x) + G(x) = f(x)$、$c(F'(x) - G'(x)) = g(x)$。第一式求导、联立第二式解出 $F'(x) = \frac{1}{2}f'(x) + \frac{g(x)}{2c}$、$G'(x) = \frac{1}{2}f'(x) - \frac{g(x)}{2c}$，积分并代入即得公式。$\blacksquare$

**数值锚**（本机实测）：$c = 1$、$f = \sin$、$g = 0$ 时 $u(1, 1) = \frac{\sin 2 + \sin 0}{2} = \cos 1 \cdot \sin 1 = 0.45464871341284085$——d'Alembert 与 $u = \cos t \sin x$（分离变量解）逐位一致。

**读法**：d'Alembert 把解拆成两列对开的行波，公式里的 $\frac{f(x \pm ct)}{2}$ 是「初值剖面的两半各跑各路」，积分项是「初速度的累积搬运」。通解都写出来了——这在 PDE 世界是稀罕待遇（第 1 章 §1.1 说过），归功于换元后 $u_{\xi\eta} = 0$ 的彻底退化：**双曲型的实特征线（$\xi, \eta$ 两族）把方程拆平了**——这正是 §1.2 判别式分类预言的事。

**完整例题**（分段函数的分支处理——最容易翻车的地方全在这）：$f(x) = x(1-x)$ 只在 $[0, 1]$ 上给定，$g = 0$，$c = 1$。公式 $u(x, t) = \frac{f(x+t) + f(x-t)}{2}$ 要先回答两个问题：$x \pm t$ 各落在哪、落在 $[0, 1]$ 外怎么办。取零延拓（$[0, 1]$ 外 $f = 0$；$f(0) = f(1) = 0$，延拓连续）。先算点名的两个值：

1. $u(0.5, 0.2)$：$x \pm t = 0.7$ 与 $0.3$，**都**在 $[0, 1]$ 内——$f(0.7) = 0.7 \times 0.3 = 0.21$、$f(0.3) = 0.3 \times 0.7 = 0.21$，故 $u = \frac{0.21 + 0.21}{2} = 0.21$。
2. $u(0.5, 0.4)$：$x \pm t = 0.9$ 与 $0.1$ 仍都在内——$f(0.9) = 0.09 = f(0.1)$，故 $u = 0.09$。

翻车点在分支。看 $u(0.95, 0.2)$：$x + t = 1.15$ 出界、$x - t = 0.75$ 在内——两个参数**逐个**过一遍 $[0, 1]$ 检查，一个都不能省。零延拓下 $f(1.15) = 0$、$f(0.75) = 0.75 \times 0.25 = 0.1875$，故 $u = 0.09375$。但若题目背景是两端固定的弦（第 5 章分离变量的框架），延拓必须取**奇周期延拓**而不是零延拓：$f_{\mathrm{odd}}(1.15) = -f(2 - 1.15) = -f(0.85) = -0.1275$，于是 $u = \frac{-0.1275 + 0.1875}{2} = 0.03$。同一个公式、同一个点，两种口径差三倍——分支与延拓不是细节，是答案本身。

顺手把 $u(0.5, t)$ 的整条时间线写清：$t \le 0.5$ 时 $0.5 \pm t \in [0, 1]$，两支都在内，$u = \frac{(0.5 + t)(0.5 - t) + (0.5 - t)(0.5 + t)}{2} = 0.25 - t^2$；$t > 0.5$ 时 $x + t > 1$、$x - t < 0$ 双双出界，$u = 0$（$t = 0.5$ 时两支恰好落在弦端 ${0, 1}$，$f$ 在那里取零，前后衔接连续）。中点在 $t = 0.5$ 之前按抛物线往下走、之后完全放平——两半初值各跑各路、错开之后不再重叠，正是「$\frac{f(x \pm ct)}{2}$ 是初值剖面的两半各跑各路」的可视化。

## $\rm \S \, 3.3$ 依赖域、影响区与两章对照表

d'Alembert 公式里，$u(x, t)$ 只依赖 $[x - ct,\ x + ct]$ 上的初值——这段区间叫点 $(x, t)$ 的**依赖域**；反过来，初值点 $s$ 的影响局限在锥形 $|x - s| \le ct$ 内——**影响区**。信息以有限速度 $c$ 搬运，锥外的事件与此刻此点无关。

与第 2 章并排摆好：

| | 热方程（抛物） | 波动方程（双曲） |
| --- | --- | --- |
| 时间导数 | 一阶 | 二阶 |
| 传播速度 | 无穷（§2.3 悖论） | 有限（$c$，锥形影响区） |
| 平滑性 | $t > 0$ 立刻无穷光滑（热核糊脸） | 初值多光滑解多光滑，不白送 |
| 最大值原理 | 成立（§2.4） | 不成立（内部可造新最值） |
| 长期归宿 | 边界撑起的稳态 | 能量守恒，永远振下去 |
| 可逆性 | 反向不适定（§1.4） | 时间反演对称（$t \mapsto -t$ 方程不变） |

**读法**：这张表是「扩散 vs 搬运」的全卷对照——从数值格式（第 6 章）到物理直觉，每一条都会回来。

## $\rm \S \, 3.4$ 能量法与唯一性（本章主证二）

定义能量

$$
E(t) = \frac{1}{2} \int_{\mathbb{R}} \big( u_t^2 + c^2 u_x^2 \big)\, \mathrm{d}x
$$

**定理 3.2**（能量守恒）。对衰减足够的解，$E(t) = E(0)$。

**证明**。求导并分部积分：

$$
E'(t) = \int (u_t u_{tt} + c^2 u_x u_{xt})\, \mathrm{d}x = \int u_t (u_{tt} - c^2 u_{xx})\, \mathrm{d}x + \Big[ c^2 u_t u_x \Big]_{-\infty}^{\infty} = 0
$$

（第一项用方程 $u_{tt} = c^2 u_{xx}$ 归零；边界项由衰减假设归零。）$\blacksquare$

**唯一性**（全证）。设 $u_1, u_2$ 同初值同方程，差 $w = u_1 - u_2$ 满足波动方程且初始能量 $E_w(0) = 0$（$w(x, 0) = 0 \Rightarrow w_x(x, 0) = 0$；$w_t(x, 0) = 0$）。由守恒 $E_w(t) = 0$ 对一切 $t$，而被积函数非负 ⟹ $w_t = w_x = 0$ 处处 ⟹ $w$ 常数 ⟹ 由 $w(x, 0) = 0$ 得 $w = 0$。$\blacksquare$

**读法**：能量法是双曲世界的「守恒式常识」——能量不生不灭，两个解的差没有能量，只能是零。注意它与热方程的唯一性证明（最大值原理，§2.4）气质完全不同：那边靠「常识压制」，这边靠「守恒清账」。连续依赖（适定性第三件）双曲侧要用能量不等式 $E(t) \le C E(0)$ 的变形，陈述级，标 Evans §2.4。

**能量守恒的数值现场**（本机实测，纯 Python 可复跑）：跳点格式（§3.5 与第 6 章 §6.4 的主角）解 $u_{tt} = u_{xx}$（$c = 1$），区间 $[0, 1]$ 两端固定，初值 $u = \sin(2\pi x)$、$u_t = 0$，网格 $N = 200$。离散能量取连续能量的网格影子：

$$
E^n = \frac{1}{2} \sum_j \left( \frac{u_j^{n+1} - u_j^{n-1}}{2 \Delta t} \right)^2 \Delta x + \frac{1}{2} \sum_j \left( \frac{u_{j+1}^n - u_j^n}{\Delta x} \right)^2 \Delta x
$$

```python
import math
rho, N = 0.9, 200
dx, dt = 1/N, rho/N
u0 = [math.sin(2*math.pi*i*dx) for i in range(N+1)]; u0[0] = u0[-1] = 0.0
u1 = [0.0]*(N+1)
for j in range(1, N):                     # u_t = 0 的二阶精度启动
    u1[j] = u0[j] + 0.5*rho*rho*(u0[j+1] - 2*u0[j] + u0[j-1])
def energy(un, um):
    v = sum(((un[j]-um[j])/(2*dt))**2 for j in range(1, N))*dx
    g = sum(((un[j+1]-un[j])/dx)**2 for j in range(N))*dx
    return 0.5*(v + g)
E0 = energy(u1, u0)
for n in range(1, 445):
    u2 = [0.0]*(N+1)
    for j in range(1, N):
        u2[j] = 2*u1[j] - u0[j] + rho*rho*(u1[j+1] - 2*u1[j] + u1[j-1])
    u0, u1 = u1, u2
    if n % 111 == 0:
        print(round(n*dt, 2), round(energy(u1, u0)/E0, 6))
```

实跑输出（$\rho = 0.9$，即 $E^n / E^0$）：

| $\rho$ | $t = 0.5$ | $t = 1$ | $t = 1.5$ | $t = 2$ |
| --- | --- | --- | --- | --- |
| $0.9$（稳定侧） | $1.000149$ | $1.000283$ | $1.000402$ | $1.000507$ |
| $1.1$（越界） | $t \approx 0.25$ 起超过 $10^6$ | （溢出） | （溢出） | （溢出） |

$\rho = 0.9$ 时能量比全程漂移不到 $0.06\%$——离散世界里能量也近乎不生不灭（残差来自中心差分能量的 $O(\Delta t^2)$ 摆动）；$\rho = 1.1$ 时最高频模的放大因子 $4\rho^2 - 1 = 3.84$，每步翻近四倍，$t \approx 0.25$（约 46 步）能量比冲破 $10^6$，很快浮点溢出。守恒与爆炸之间只隔着 $\rho = 1$——§3.5 的 CFL 分水岭在能量语言里的原声。

## $\rm \S \, 3.5$ 数值一瞥：CFL 的物理来源

显式差分格式（第 6 章细讲）里，波在一个时间步 $\Delta t$ 内跑过的距离 $c\, \Delta t$ 不能超过一个网格间距 $\Delta x$——否则数值信息来不及送达，格式必炸。这就是 **CFL 条件** $c\, \Delta t \le \Delta x$ 的物理读法：**数值依赖域必须罩住真实依赖域**。数值锚（第 6 章复用，本机已验）：放大因子 $g(\theta) = 1 - 4r \sin^2(\theta/2)$（$r = c^2 \Delta t^2 / \Delta x^2$），$r \le 1$ 时 $|g| \le 1$ 稳定，$r = 0.51$ 时 $\max|g| = 1.04$、$r = 0.6$ 时 $1.40$——越界即爆（这两个数与解析式 $\max|g| = 4r - 1$（$r > \frac{1}{2}$ 时）逐位一致）。

与第 6 章的接口：§6.4 会把这道理分水岭从物理直觉升级成 von Neumann 代数证明——同一个 $\rho \le 1$（那里记作 $r \le 1$）从放大因子直接读出，§6.5 的波动对账直接复用本节的数值锚；§3.4 数值现场里 $\rho = 1.1$ 的能量爆炸就是这条分水岭的能量侧演示。

## $\rm \S \, 3.7$ 本章自测答案

1. 张力 $T$、线密度 $\rho$，$c$ 是波速。（§3.1）
2. 变成 $u_{\xi\eta} = 0$；通解 $F(x + ct) + G(x - ct)$——右行波＋左行波。（§3.2）
3. $\frac{f(x \pm ct)}{2}$ 搬运初值剖面，$\frac{1}{2c}\int g$ 搬运初速度的累积。（§3.2）
4. $u(x,t)$ 只依赖 $[x - ct, x + ct]$ 上的初值；初值点 $s$ 影响锥 $|x - s| \le ct$。热方程依赖域是全直线（无穷传播）。（§3.3）
5. $u_t^2$ 是动能密度、$c^2 u_x^2$ 是势能密度；守恒靠方程＋分部积分＋衰减边界项。（§3.4）
6. 数值依赖域必须罩住真实依赖域：$c\, \Delta t \le \Delta x$，否则格式不稳定。（§3.5）
7. 公式给 $u = \frac{\sin(x + t) + \sin(x - t)}{2}$；用和差化积 $\sin A + \sin B = 2 \sin\frac{A + B}{2} \cos\frac{A - B}{2}$（$A = x + t$、$B = x - t$）得 $u = \sin x \cos t$。验证：$u_{tt} = -\sin x \cos t$、$u_{xx} = -\sin x \cos t$，$u_{tt} = u_{xx}$ 成立。两列反向行波的和差化积就是一个驻波——「行波叠加 $=$ 驻波」，第 5 章分离变量会给同一个答案（§5.5 会师）。（§3.2）
8. $t \le 0.5$：$0.5 \pm t \in [0, 1]$，两支都在内，$u = \frac{(0.5 + t)(0.5 - t) + (0.5 - t)(0.5 + t)}{2} = 0.25 - t^2$。$t > 0.5$：$x + t > 1$、$x - t < 0$ 双双出界，零延拓给 $u = 0$；$t = 0.5$ 时两支恰好落在弦端 $f = 0$ 处，$u = 0$，前后衔接。断点 $t = 0.5$ 是两半初值错开的时刻：依赖域 $[0.5 - t,\ 0.5 + t]$ 从此完全滑出弦的支撑，中点再也收不到任何初始数据——有限传播速度给中点排的日程表。（§3.2、§3.3）
9. $u_t = -\sin x \sin t$、$u_x = \cos x \cos t$，代入能量（$c = 1$）：

$$
E(t) = \frac{1}{2} \int_0^{2\pi} \left( \sin^2 x\, \sin^2 t + \cos^2 x\, \cos^2 t \right) \mathrm{d}x = \frac{1}{2} \left( \pi \sin^2 t + \pi \cos^2 t \right) = \frac{\pi}{2}
$$

（用到 $\int_0^{2\pi} \sin^2 x\, \mathrm{d}x = \int_0^{2\pi} \cos^2 x\, \mathrm{d}x = \pi$。）动能与势能在 $\frac{\pi}{2}$ 里你增我减、总和纹丝不动——$\sin^2 t + \cos^2 t = 1$ 这条三角恒等式在这里就是能量守恒的化身。（§3.4）
