## $\rm \S \, 6.1$ NISQ 硬件现实：噪声与比特数的量级

**NISQ（noisy intermediate-scale quantum，含噪声中等规模量子，Preskill 2018）**指当下的硬件状态：几十到上千个**物理**比特、没有纠错、每道门都带误差。三个数字定基调（截至本册写作的量级，逐年都在改进）：

1. **比特数**：超导、离子阱、光子平台的设备从几十到上千物理比特不等——但物理比特不等于逻辑比特，纠缠规模与可用深度远小于比特数听起来给的预期；
2. **门保真度**：单比特门误差约 $10^{-4}$ 量级，两比特门约 $10^{-3}$ 量级——电路越深误差越滚，可行电路深度通常在几百到几千道门量级就触到噪声墙；
3. **读出与制备**：每次测量得到一个样本，态制备与读出各有百分之零点几到几个百分点的误差——第 4 章那种「跑 $1/\kappa^2$ 次电路取一个样本」的方案，每次还要再吃一道这道税。

这三条对 QML 的杀伤是定向的。深度预算直接判死深线路——第 2 章那种表达力强的高深度参数化线路在 NISQ 上要么跑不动、要么跑出来的早已被噪声抹平；qRAM 不存在，第 4 章的振幅编码账本在硬件上连第一步都迈不出；误差没有纠错，意味着任何「精确相位估计」级的算法（HHL 的第一段）都只能跑退化版。白话：**NISQ 设备是一台「浅电路、少样本、带静电」的机器，而 QML 的多数旗舰算法是按「深电路、多样本、理想噪声」设计的——落差本身就是一个研究课题，不是一个脚注。** §6.2 的三座大山里，第一座（数据加载）与第三座（barren plateau）都直接长在这个硬件现实上。

**本节小结**：NISQ 三数字——物理比特几十到上千、两比特门误差 $10^{-3}$ 量级、可行深度几百到几千道门；对 QML 的定向杀伤：深线路跑不动、qRAM 不存在、精确算法只能退化。下一座问题搬到算法侧：三座大山汇总。

## $\rm \S \, 6.2$ 三座大山：数据加载、去量子化、barren plateau

QML 的批评文献已经足够形成共识清单，三座大山按「多根本」排序：

1. **数据加载瓶颈**（第 4 章 §4.1 的账）：把经典数据装进振幅要 $O(N)$，qRAM 未工程化——「多对数」叙事的第一环就断在输入端。
2. **去量子化**（第 5 章 §5.2 的战果）：低秩土壤上的算法级优势已被成片打回——「多对数」叙事的价值端被经典对手削平。
3. **barren plateau（贫瘠高原）**（McClean 等人 2018）：参数化线路足够深、足够「量子随机」时，损失函数对参数的梯度方差随比特数**指数塌缩**——经典优化器站在一片平地上，看不到任何下坡方向。这座山与前两座不同：它不关乎叙事，关乎**可训练性本身**，而且能在小机器上实算。本册把它真算一遍。

实验设定：$n$ 比特、$L = 2n$ 层的「随机砖墙」线路——每层对全部比特上 $R_y$ 参数门，层间交错铺 CZ 纠缠门；梯度用参数移位法算第一个门的角度的偏导，对 $T = 400$ 组均匀随机参数重复，报方差。两种代价函数对表：**全局**代价 $\langle Z_1 Z_2 \cdots Z_n\rangle$（所有比特都参与）与**局域**代价 $\langle Z_1\rangle$（只看一个比特）。$16$ 维到 $256$ 维的状态矢量全模拟，逐位验证过暴力实现：

```text
n=4 L=8:  global mean=+6.95e-03 var=5.896e-02 | local mean=+3.02e-02 var=2.149e-01
n=6 L=12: global mean=-1.04e-02 var=2.107e-02 | local mean=-4.96e-02 var=2.214e-01
n=8 L=16: global mean=-6.09e-03 var=8.356e-03 | local mean=-2.20e-02 var=2.211e-01
1/2^n reference: 0.0625, 0.015625, 0.003906
```

两张脸对比刺眼。**全局代价**的梯度方差 $5.9 \times 10^{-2} \to 2.1 \times 10^{-2} \to 8.4 \times 10^{-3}$：每加两个比特大约砍半再砍半，与理论预言的 $1/2^n$ 型指数衰减同型——到 $n = 50$（NISQ 的实战规模），方差落在 $10^{-15}$ 附近，双精度浮点数的梯度全是数值噪声，优化无从谈起。均值同时在零附近（$10^{-2}$ 量级），即整片高原的平均海拔就是「随机猜测」。**局域代价**的方差三个尺寸几乎不动（$0.215 \to 0.221 \to 0.221$）——代价只挂在少数比特上时，指数压扁被推迟。这正是文献的处方：**浅线路＋局域代价是 barren plateau 的经典逃生通道**，但它同时牺牲表达力——逃生通道的另一头是「模型表达力不够」的老问题，表达力与可训练性在深线路里是一对换不出两个都占的筹码（Cerezo 等人后续工作把平台按代价函数与噪声结构细分，但主旋律未变：深的、表达的、随机的线路必高原）。

**本节小结**：三座大山——数据加载断输入、去量子化削价值、barren plateau 断训练；实算把第三座山钉成数字：全局代价梯度方差按 $1/2^n$ 型指数塌缩（$n = 8$ 已到 $10^{-3}$，外推 $n = 50$ 是浮点噪声），局域代价方差持平——逃生通道存在但以表达力为价。下一节把 QML 与经典 ML 理论放到同一张桌上。

## $\rm \S \, 6.3$ 与经典 ML 理论的对话

把两边的核心命题并排，对话就自然发生了。

**第一回合：特征学不学。** 经典深度学习理论的中心发现是：深度网络的实战胜利来自 **feature learning**（特征随数据移动），而无限宽极限下的 lazy training 退化为固定核方法（本站深度学习理论册的 NTK 语言；本站核方法册第 6 章给过全对照）。QML 这边，量子核（本册第 3 章）恰好是**固定特征映射**的极端形态——量子态空间是特征空间，编码线路一选，内积（态 overlap）全部定死，数据不改变特征。对话的结论很直白：**量子核站在核方法一侧，而经典实战的赢面在特征学习一侧**。这不是判 QML 死刑——固定特征意味着强先验，小数据、强结构的问题上先验是资产——但它精确划定了量子核该守的高地：数据少、结构先验强的场合，与经典核方法守高地的逻辑完全同构。

**第二回合：泛化从哪来。** 经典侧的谜题（过参数化网络为何泛化，本站机器学习与凸优化册第 9 章）在量子侧有一个精确的镜像：Schuld（2021）证明变分 QML 模型在足够宽的极限下「本质是核方法」——泛化行为由 RKHS 范数控制（本站核方法册第 3 章的表示定理直接套用）。于是量子模型的泛化理论有了一个现成的家：经典统计学习理论。代价是诚实：**借用来的理论也借来了经典核方法的局限**——样本复杂度由特征空间的谱决定，而量子特征空间动辄 $2^n$ 维，谱不加权的天真编码会把样本复杂度顶上天。

**第三回合：谁给谁出题。** 对话不是单向的「经典理论审查量子模型」。去量子化（第 5 章 §5.2）产出的「量子启发经典算法」是量子侧反哺经典算法学的实绩；barren plateau 的几何分析（参数空间的二维球面均匀性、表达力—可训练性权衡）也给经典随机网络的损失地形研究提供了新工具。健康的定位是：**QML 目前对 ML 的最大贡献是让两边的理论都更锋利，而不是让某一边的基准更好看。**

**本节小结**：三回合对话——量子核是固定特征映射（守小数据强先验高地）、宽极限 QML 是「换了特征空间的核方法」（泛化理论现成但样本复杂度受 $2^n$ 维谱威胁）、量子侧以去量子化算法与高原几何反哺经典。下一节从「不是什么」转到「是什么」。

## $\rm \S \, 6.4$ 什么问题值得量子人做

把三座大山与三回合对话折算成研究议程，值得做的四类（按证据强度排序）：

1. **量子数据上的量子学习**。这是唯一有物理同构背书的方向：数据本身就是量子态（分子、材料、量子传感器、量子实验的输出），经典设备表示一份 $n$ 体量子态就要指数资源，而量子设备天然住在态空间里。学习量子系统的哈密顿量、预测基态性质、压缩量子态——这里经典算法没有「主场优势」可守。
2. **证明级的工作**。oracle 分离、量子特征空间的 RKHS 几何、去量子化边界的刻画（第 5 章 §5.2 的分界线往哪边挪）——这些不依赖硬件成熟度，产出的是不会贬值的知（§5.1 的移动靶问题的唯一解药）。
3. **采样的谨慎赛道**。生成任务与分布估计（第 5 章 §5.4 的三层读法）——只有在「难采样分布与数据分布重合」有证据的具体问题上进场，且随时准备回答去量子化提问。
4. **给经典算法学出工具**。量子启发算法已经是实绩；量子线性代数的采样技术、高原几何的分析手法都是可迁移资产。

对应的**不值得**清单（当下时点）：在经典数据集上用 NISQ 设备刷基准对抗 GPU——数据加载税、高原、去量子化三面受敌；宣称「多对数优势」而不交代第 4 章四张牌；以及一切把 §5.1 三个强度级混着谈的论文。白话：**量子机器学习当下最诚实的姿势，是把「量子」当显微镜而不是当加速器——显微镜看量子世界（方向 1），加速器的故事等硬件与理论把牌发齐再讲。**

**本节小结**：值得做的四类——量子数据（物理同构背书）、证明级工作（不贬值）、谨慎的采样赛道、反哺经典的工具；不值得的一类——NISQ 上经典数据刷基准；主旨是显微镜先于加速器。下一节把全册钉回地图。

## $\rm \S \, 6.7$ 程序段：barren plateau 梯度方差实算

把 §6.2 的主实验整理成可复跑的完整程序（批量状态矢量演化，已对暴力实现逐位验证）：

```python
import numpy as np

def run_batch(n, L, TH, kind):
    """TH: (T, L, n) 参数；kind: 'global' 或 'local'。返回每组参数的代价。"""
    Tm = TH.shape[0]
    st = np.zeros((Tm,) + (2,)*n, dtype=complex)
    st[(slice(None),) + (0,)*n] = 1.0                  # 每条样本从 |0...0> 出发
    idx = np.arange(2**n)
    for l in range(L):
        for q in range(n):                             # R_y(q) 层
            ang = TH[:, l, q]
            st = np.moveaxis(st, q+1, 1).reshape(Tm, 2, -1)
            c, s = np.cos(ang/2), np.sin(ang/2)
            a0, a1 = st[:, 0].copy(), st[:, 1].copy()
            st = np.stack([c[:, None]*a0 - s[:, None]*a1,
                           s[:, None]*a0 + c[:, None]*a1], axis=1)
            st = np.moveaxis(st.reshape((Tm,) + (2,)*n), 1, q+1)
        for a in range(0, n-1, 2):                     # 砖墙 CZ：两比特皆 1 则变号
            both1 = ((idx >> (n-1-a)) & 1) & ((idx >> (n-1-a-1)) & 1)
            phase = np.where(both1.astype(bool), -1.0+0j, 1.0+0j)
            st = (st.reshape(Tm, 2**n) * phase[None, :]).reshape((Tm,) + (2,)*n)
    p = np.abs(st.reshape(Tm, 2**n))**2
    if kind == 'global':                               # <Z_1 ... Z_n>
        zs = 1 - 2*((idx[:, None] >> np.arange(n)[None, :]) & 1)
        return p @ np.prod(zs, axis=1)
    return p @ (1 - 2*((idx >> (n-1)) & 1))            # <Z_1>

rng, T = np.random.default_rng(11), 400
for n in (4, 6, 8):
    L = 2*n
    TH = rng.uniform(0, 2*np.pi, size=(T, L, n))
    THp = TH.copy(); THp[:, 0, 0] += np.pi/2           # 参数移位法取偏导
    THm = TH.copy(); THm[:, 0, 0] -= np.pi/2
    for kind in ('global', 'local'):
        g = 0.5*(run_batch(n, L, THp, kind) - run_batch(n, L, THm, kind))
        print(f"n={n} L={L} {kind:6s}: mean={g.mean():+.2e}  var={g.var():.3e}")
```

实跑输出（本章数值锚，照抄）：

```text
n=4 L=8 global : mean=+6.95e-03  var=5.896e-02
n=4 L=8 local  : mean=+3.02e-02  var=2.149e-01
n=6 L=12 global: mean=-1.04e-02  var=2.107e-02
n=6 L=12 local : mean=-4.96e-02  var=2.214e-01
n=8 L=16 global: mean=-6.09e-03  var=8.356e-03
n=8 L=16 local : mean=-2.20e-02  var=2.211e-01
```

读程序的三句话：状态张量排成 `(样本, 比特, ...)`，单比特门用 moveaxis 把目标轴转到最前再做 $2\times2$ 混合——这是 $2^n$ 维希尔伯特空间里省内存的通用手法；CZ 是对角门，实现成对特定基矢的相位翻转，一行完成；梯度走参数移位 $\frac{1}{2}\big[C(\theta + \frac{\pi}{2}) - C(\theta - \frac{\pi}{2})\big]$——它对任何单比特旋转门精确成立，是变分量子线路的「自动微分标准件」。复现实验只需换 `n`、加 `T`；对照 `1/2^n` 一列即可亲眼看到指数塌缩。

## $\rm \S \, 6.8$ 六问参考答案

1. 物理比特几十到上千（可用纠缠规模远小于此）、两比特门误差 $10^{-3}$ 量级、可行深度几百到几千道门。判刑：深度预算判死深参数化线路，无 qRAM 判停振幅编码方案，噪声判停精确相位估计型算法（HHL 第一段只能跑退化版）。（§6.1）
2. 数据加载断输入端（振幅编码 $O(N)$、qRAM 缺位），去量子化削价值端（低秩优势被经典对手追平），barren plateau 断训练端（梯度指数塌缩）。第三座不同在于：前两座关乎「叙事是否成立」，它关乎「算法在理想假设下是否可训练」——即使硬件与数据问题全部解决，深线路的优化本身仍是指数难题。（§6.2）
3. 全局代价方差 $5.9\times10^{-2} \to 2.1\times10^{-2} \to 8.4\times10^{-3}$（$n = 4, 6, 8$），每加两比特约减半再减半，$1/2^n$ 型指数塌缩；局域代价方差三个尺寸持平（约 $0.22$）。逃生通道（浅线路＋局域代价）的代价是牺牲表达力——表达力与可训练性在深线路里是一对必须二选一的筹码。（§6.2）
4. 固定特征映射一侧（数据不改特征，编码线路一选内积全定）。高地：小数据、强结构先验的问题——固定特征意味着强先验，与经典核方法守高地的逻辑同构。局限：谱不加权的天真编码把样本复杂度顶向 $2^n$ 维特征空间的规模。（§6.3）
5. 按证据强度排序：量子数据（物理同构背书）、证明级工作（oracle 分离、RKHS 几何、去量子化边界）、谨慎的采样赛道、反哺经典的工具。方向 1 背书最硬，因为量子态的经典表示本身是指数代价——经典算法在这里没有主场，而其余方向都要与不断进步的经典算法赛跑。（§6.4）
6. 量子核与 RKHS 的对接：本站核方法册第 1 章（再生性质：量子态 overlap $=$ 特征空间内积）、第 3 章（表示定理与核岭回归：变分 QML 宽极限的解结构）；泛化理论住在经典统计学习理论（RKHS 范数控制）里，样本复杂度由量子特征空间的谱决定。（§6.3、§6.5）
