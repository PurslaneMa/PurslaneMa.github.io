## $\rm \S \, 5.1$ 损失层与 log-sum-exp

MSE 五行，照 §4.1 的层签名写：

```python
def mse(pred, y):
    diff = pred - y
    return (diff * diff).mean(), 2 * diff / diff.size   # loss 与 dL/dpred
```

交叉熵加 softmax 麻烦在数值：logits 一大，`exp` 先溢出。真跑一组：logits 取 ${(1000,1001,1002)}$，朴素实现 `exp(z)` 得 `[inf, inf, inf]`，softmax 得 `[nan, nan, nan]`；float64 最大约 ${1.8\times10^{308}}$，而 ${e^{1000}\approx 10^{434}}$，早在溢出线上。稳定版利用一条恒等式：softmax 分子分母同乘 ${e^{-\max z}}$ 值不变，于是先把每个 logits 减去最大值再取指数，指数参数全部落到非正数：

```python
def softmax_ce(z, y):                        # z: (n,C)，y: one-hot
    z = z - z.max(axis=1, keepdims=True)     # 减最大值，指数不再溢出
    ez = np.exp(z)
    p = ez / ez.sum(axis=1, keepdims=True)
    return -(y * np.log(p)).sum(axis=1).mean(), (p - y) / len(y)
```

真跑验证：稳定版 softmax 得 ${[0.0900,\ 0.2447,\ 0.6652]}$，与 `torch.softmax` 的差 ${2.8\times10^{-17}}$（float64）。减最大值之所以合法，是把恒等式写成式子看（记 ${M=\max_j z_j}$）：

$$
\mathrm{softmax}(z)_k=\frac{e^{z_k}}{\sum_j e^{z_j}}=\frac{e^{z_k-M}}{\sum_j e^{z_j-M}},
$$

分子分母同乘了同一个 ${e^{-M}}$，比值不变；右边每个指数参数 ${z_k-M\le 0}$，最大只到 ${e^0=1}$，溢出从根上消失。这就是 log-sum-exp 技巧：凡是「指数后求和（或求 log）」的地方都必须先减最大值，梯度公式 ${\partial L/\partial z=p-y}$（softmax 减 one-hot）不受影响，推导见深度学习分册第 3 章。

## $\rm \S \, 5.2$ 迷你优化器

优化器只做一件事：拿着梯度改参数。三个经典更新式各 8 行：

```python
def sgd_step(w, g, lr):
    return w - lr * g                    # 沿坡度往下走一步

def momentum_step(w, g, lr, v, beta=0.9):
    v = beta * v - lr * g                # 速度：过去方向的惯性
    return w + v, v

def adam_step(w, g, lr, m, s, t, b1=0.9, b2=0.999, eps=1e-8):
    m = b1 * m + (1 - b1) * g            # 一阶矩：梯度的滑动平均
    s = b2 * s + (1 - b2) * g * g        # 二阶矩：梯度平方的滑动平均
    m = m / (1 - b1 ** t)                # 偏置校正
    s = s / (1 - b2 ** t)
    return w - lr * m / (np.sqrt(s) + eps), m, s
```

Adam 的偏置校正是唯一需要解释的一行：${m,s}$ 从 0 起步，训练初期滑动平均被系统性低估（前几步的 ${m\approx(1-b_1^t)\,\mathbb{E}[g]}$），除以 ${1-b^t}$ 恰好补回这个系数；${t}$ 一大它趋于 1，校正自动退场。

实现细节一句：${v}$、${m}$、${s}$ 是优化器的**状态**，要放在 step 函数外面跨步保存；`w` 是参数，来自第 4 章的 `parameters()`。优化器本身不碰前向反向，只读梯度、写参数。

## $\rm \S \, 5.3$ 对照实验：三优化器的轨迹与 torch.optim 逐数对照

实验设定：20 个样本、2 特征的小数据集（`np.random.default_rng(0)`，7 正 13 负），逻辑回归，损失用稳定的数值形式 ${L=\mathrm{mean}\big(\mathrm{logaddexp}(0,z)-yz\big)}$（等价于交叉熵，且无溢出问题）；初始 ${w_0=(0.1,-0.1)}$；超参 SGD ${\mathrm{lr}=0.5}$、Momentum ${\mathrm{lr}=0.1}$、Adam ${\mathrm{lr}=0.3}$。迷你实现跑出的 loss 轨迹（前 10 步）：

| 1 | 0.6400 | 0.6611 | 0.5972 |
| 2 | 0.6176 | 0.6510 | 0.5417 |
| 3 | 0.5985 | 0.6373 | 0.4969 |
| 4 | 0.5821 | 0.6212 | 0.4612 |
| 5 | 0.5677 | 0.6037 | 0.4333 |
| 6 | 0.5551 | 0.5857 | 0.4112 |
| 7 | 0.5439 | 0.5679 | 0.3939 |

| 10 | 0.5162 | 0.5202 | 0.3628 |

Adam 前期一骑绝尘：自适应步长在前几步等效放大了走步距离；Momentum 因 ${\mathrm{lr}}$ 设得保守起步最慢，惯性尚未积累。三种超参各不相同，这张表演示的是机制差异，不是排名。

与 `torch.optim` 的同超参对照（float64，同一 ${w_0}$ 与数据）。torch 侧的实验代码如下，三个优化器各跑一遍、只换一行构造：

```python
tw = torch.tensor(w0, requires_grad=True)
opt = torch.optim.Adam([tw], lr=0.3)     # SGD / SGD(momentum=0.9) 各换一行
for _ in range(10):
    opt.zero_grad()
    loss = F.binary_cross_entropy_with_logits(tX @ tw, ty)
    loss.backward()
    opt.step()
```

十步之后的逐数对照：

| 优化器 | torch 侧实现 | ${\max|\Delta w|}$ | ${\max|\Delta L|}$ |
| --- | --- | --- | --- |
| SGD | `torch.optim.SGD(lr=0.5)` | ${1.1\times10^{-16}}$ | ${1.1\times10^{-16}}$ |
| Momentum | `torch.optim.SGD(momentum=0.9)` | ${2.8\times10^{-17}}$ | ${1.1\times10^{-16}}$ |
| Adam | `torch.optim.Adam(lr=0.3)` | ${4.4\times10^{-16}}$ | ${1.1\times10^{-16}}$ |

验证环境：WSL Ubuntu，PyTorch 2.14.1+cpu，float64。十步之后参数与 loss 逐数一致，机器精度级。顺带一提，torch 的 Momentum 写法是 ${v=\beta v+g}$ 然后 ${w\mathrel{-}= \mathrm{lr}\cdot v}$，与 §5.2 的 ${v=\beta v-\mathrm{lr}\cdot g}$ 相差一个因子 ${-\mathrm{lr}}$，两种写法展开后逐项相同，对照实验也证实了这一点。

> **组装视角**：优化器与反向传播完全解耦，它只读 `.grad`、写参数；训练循环每步的固定顺序是 `zero_grad → backward → step`（第 4 章防旧账，本章花新账），下一章按这个顺序把五块积木拼成完整训练循环。

## $\rm \S \, 5.4$ weight decay 的位置：L2 与 AdamW 一句话

把正则加进上面的框架有两个位置：L2 惩罚把它算进梯度（${g\gets g+\lambda w}$），Adam 下它会被 ${1/\sqrt{s}}$ 的自适应缩放稀释，大梯度的参数反而衰减少；decoupled weight decay（AdamW）把它放进更新式（${w\gets w-\mathrm{lr}\cdot\lambda\cdot w}$），与自适应缩放解耦。一句话：罚在梯度里还是罚在更新里，SGD 下等价，Adam 下不等价，AdamW 是后者的名字。

## $\rm \S \, 5.7$ 本章自测答案

### $\rm \S \, 5.7.1$ 关键概念回顾答案

1. `exp(1000)` 溢出为 inf，softmax 变 nan；稳定版靠「分子分母同乘 ${e^{-\max z}}$ 值不变」，先把 logits 平移到非正数。（§5.1）
2. 指数运算量级悬殊，直接算必溢出；${\partial L/\partial z=p-y}$。（§5.1）
3. ${v}$ 是过去梯度的指数滑动平均（带符号的惯性）；一致方向的梯度累积成大步，方向反转时惯性使它冲过头再回调。（§5.2）
4. 修正 ${m,s}$ 从零起步造成的初期低估；除以 ${1-b^t}$，${t}$ 大时趋于 1，校正自动退场。（§5.2）
5. L2 加在梯度上（${g\gets g+\lambda w}$），AdamW 加在更新上（${w\gets w-\mathrm{lr}\,\lambda w}$）；SGD 下两者等价，Adam 的自适应缩放使它们分道。（§5.4）

### $\rm \S \, 5.7.2$ 应用与辨析答案

1. 平移后 ${(0,1,2)}$：${e^0+e^1+e^2\approx 1+2.718+7.389=11.107}$，得 ${0.0900,\ 0.2447,\ 0.6652}$，与表一致。（§5.1）
2. 偏大：${m}$ 低估了 ${|\mathbb{E}[g]|}$，本应除以 ${1-b_1}$（第 1 步为 0.1 的补数即 ${\times 10}$）的修正消失，更新量约小一个数量级。（§5.2）
3. 更大：梯度 ${|p-y|\approx 1}$ 达到上界；交叉熵对自信的错判惩罚最重，这正是它比 MSE 适合分类的原因。（§5.1）
4. L2：在算出 ${g}$ 后加一行 `g = g + 0.01 * w`；AdamW：在更新行加一项 `w = w - lr * 0.01 * w`。第 1 步两者都给 ${w}$ 一个 ${-0.001}$ 到 ${-0.003}$ 量级的额外位移（${\mathrm{lr}\lambda w}$），方向相同、路径不同，差别要很多步后才显现。（§5.4）
