# R1 复习总结：数理统计

六章压成三句话：**统一框架**（第 1—2 章）——指数族模板 $h(x)\exp(\eta T(x)-A(\eta))$ 把五个老分布收编进一个式子，两次求导白拿矩（$A'=\mathrm{E}[T]$、$A''=\mathrm{Var}[T]$），因子分解定理把「充分统计量」从口号变成一次数数游戏；**精度定价**（第 3—4 章）——Fisher 信息按得分方差与负曲率两种身份入场，CRLB 用信息倒数给一切无偏估计封顶，MLE 靠「得分为零 + Taylor + CLT + Slutsky」在大样本下踩着这条线走；**裁判与预言**（第 5—6 章）——风险函数给「好」标价，Bayes 后验均值与 minimax 常数风险两条主证各证各的，后验预测分布把参数的不确定性传给未来。验收标准：闭卷清单答出几成、§R1.3 六条心智模型能默几条。

## $\rm \S \, R1.3$ 核心心智模型复读

1. **入族然后求导**：分布小抄可以扔了——任何指数族成员的性质都从模板 $h\exp(\eta T - A)$ 里算出来，$A$ 的导数就是矩，不必再背「泊松均值等于方差」这类条目。
2. **充分性是无损压缩**：给定 $T$ 后数据把 $\theta$ 忘掉；因子分解 $f = g(T, \theta)\,h(D)$ 把判断充分性变成「含参项能不能打包」的数数游戏，$h$ 是参数摸不到的边角料。
3. **信息是精度的价签**：Fisher 信息量化「数据分辨参数的本事」，CRLB 按它的倒数给无偏估计封顶，$1/I_n$ 的 $\sqrt{n}$ 法则就是「多买数据多精度」的定量版。
4. **MLE 走的是坡度除以曲率**：渐近正态证明把误差拆成 $U_n/\sqrt{n}$ 除以 $-\ell_n''/n$，分子是 CLT 的钟形、分母是 LLN 的常数，Slutsky 一除，方差恰好落在 CRLB 上。
5. **准则不同冠军不同**：Bayes 押先验买平均分、minimax 防最坏情形买保险，正态考场上 MLE 与 minimax 合体为 $\bar X$——没有跨准则的排行榜，风险曲线的平坦处才是握手的地方。
6. **预测要对参数积分**：后验预测 $p(x_{\text{new}} \mid D) = \int f(x_{\text{new}} \mid \theta)\,\pi(\theta \mid D)\,d\theta$ 不是把 $\hat\theta$ 插进去——多次预测的方差比 plug-in 多出膨胀因子，「不确定性传给未来」写在公式里。

## $\rm \S \, R1.4$ 交错练习

1. Poisson 单样本入族后 $A(\eta)$ 是什么？${A'}$ 与 ${A''}$ 各等于谁？（答：$A = e^{\eta}$；两者都等于 $\lambda$）
2. Uniform$(0, \theta)$ 的充分统计量与 Rao–Blackwell 改进后的估计？（答：$T = \max_i x_i$；$(n+1)\max / n$）
3. Bernoulli$(p)$ 的 Fisher 信息与 $\hat p = k/n$ 的方差？（答：$I = 1/(p(1-p))$；$p(1-p)/n$ 恰是 $1/I_n$，有效）
4. 正态两参数 $(\mu, v)$ 的信息矩阵长什么样？两参数之间正交的账怎么算的？（答：$\mathrm{diag}(1/v, 1/(2v^2))$；三阶矩为零）
5. Beta$(a, a)$ 先验下二项的 Bayes 估计？$a$ 取多少时它 minimax、风险常数是多少？（答：$(k+a)/(n+2a)$；$a = \sqrt{n}/2$，$1/(4(1+\sqrt{n})^2)$）
6. 后验预测的方差比 plug-in 多出什么结构？（答：$m\mu(1-\mu)$ 乘膨胀因子 $1 + (m-1)/(a_1+b_1+1)$）
7. 先验 Beta$(2, 2)$、观测 $(n, k) = (10, 7)$，后验均值与 MLE 各是多少？（答：后验 $(2+7)/(4+10) = 9/14 \approx 0.643$；MLE $0.7$）

## $\rm \S \, R1.5$ 易混点对照

1. **$A(\eta)$ vs ${A'}$**：前者是对数配分函数（归一化的账本），后者直接是 $\mathrm{E}[T]$——求导才是矩，别把函数本身当均值。
2. **充分 vs 有效**：充分是「压缩不丢信息」（关于数据的性质），有效是「方差踩到 CRLB」（关于估计量的性质）；充分统计量不自动给有效估计，但 Rao–Blackwell 是两者的桥。
3. **得分 $U$ vs 信息 $I$**：得分是 $\partial_\theta \log f$（随机变量，零期望），信息是它的方差（数）；二阶导版本 $I = -\mathrm{E}[\partial_\theta^2 \log f]$ 是「平均负曲率」，别混成「曲率的期望取负号」之外的读法。
4. **Bayes 风险 vs minimax 风险**：前者按先验平均 $r(\pi, \delta)$，后者取 $\sup_\theta R(\theta, \delta)$；minimax 引理说任何先验的 Bayes 风险都是 minimax 风险的下界，方向别写反。
5. **置信区间 vs 可信区间**：前者 $95\%$ 是长期覆盖频率（关于程序的保证），后者是「$\theta$ 落在此区间的后验概率为 $95\%$」字面成立（关于本次分析的陈述）——两种保证不可互换。
6. **后验预测 vs plug-in 预测**：前者对后验积分、方差自带膨胀因子；后者把 $\hat\theta$ 当真值、过度自信——单次预测两者重合，多次立刻分岔。

## $\rm \S \, R1.6$ 答案与提示

### 闭卷回忆清单

1. $h$ 与参数无关、$T$ 压缩数据、$\eta$ 是线性化刻度尺、$A$ 配平归一化；Bernoulli $\eta = \log\frac{p}{1-p}$，Poisson $\eta = \log\lambda$。（§1.1—1.2）
2. 起点：归一化恒等式 $\int h \exp(\eta T - A)\,dx = 1$ 在积分号下求导两次；Poisson 的 $A = e^{\eta}$ 求导不变身，均值 $=$ 方差 $= \lambda$。（§1.3）
3. 都来自似然的指数形状：$T$ 天然充分、共轭后验 $\pi(\eta \mid x) \propto \exp((\nu + T_{\text{obs}})\eta - (\kappa + n)A(\eta))$、MLE 方程 $A'(\eta) = T_{\text{obs}}/n$。（§1.4）
4. 充分：$P(D \mid T(D) = t, \theta)$ 与 $\theta$ 无关；分解：$f(D \mid \theta) = g(T(D), \theta)\,h(D)$。（§2.1—2.2）
5. Bernoulli/Poisson/正态（$\sigma^2$ 已知）压成一个和；正态双参数压成 $(\sum x_i, \sum x_i^2)$；Uniform 压成 $\max_i x_i$——双参数下平方和躲不开 $\sigma^2$。（§2.3）
6. $\delta_{\text{RB}} = \mathrm{E}[\delta \mid T]$，方差分解 $\mathrm{Var}(\delta) = \mathrm{Var}(\mathrm{E}[\delta \mid T]) + \mathrm{E}[\mathrm{Var}(\delta \mid T)]$ 第二项非负；洗成 $\frac{n+1}{n}\max$。（§2.4）
7. $I(\theta) = \mathrm{E}[U^2]$（得分方差）$= -\mathrm{E}[\partial_\theta^2 \log f]$（负曲率）；对数似然逐项求二阶导取期望，线性给 $I_n = nI$。（§3.1）
8. $\mathrm{Var}(\hat\theta) \ge 1/I_n(\theta)$；无偏性给 $\mathrm{Cov}(\hat\theta, U) = 1$，Cauchy–Schwarz 接棒出不等式，取等当估计量是得分的线性函数。（§3.2）
9. $\sqrt{n}(\hat\theta - \theta_0) \xrightarrow{d} N(0, 1/I(\theta_0))$；分子走 CLT（方差 $I$），分母走 LLN（$\to I$），Slutsky 收口。（§4.2）
10. 统一方程 $A'(\eta) = T_{\text{obs}}/n$、渐近正态、渐近有效（渐近方差 $=$ CRLB）、不变性 $g(\hat\theta)$ 是 $g(\theta)$ 的 MLE。（§4.1—4.4）
11. $R(\theta, \delta) = \mathrm{E}_\theta[L(\theta, \delta(X))]$；Bayes 风险按先验平均，minimax 风险取曲线最高点再比谁的谷底浅。（§5.1）
12. 总风险按观测拆散、平方损失配方成 $(a - m(x))^2 + \mathrm{Var}(\theta \mid x)$；闭式拆成 $\frac{n}{a+b+n}\cdot\frac{k}{n} + \frac{a+b}{a+b+n}\cdot\frac{a}{a+b}$——数据与先验的加权平均。（§5.2）
13. 对称族 Beta$(a, a)$ 里求导找最不利者 $a = \sqrt{n}/2$；其 Bayes 估计 $\frac{k + \sqrt{n}/2}{n + \sqrt{n}}$ 的风险逐项抵消成常数 $\frac{1}{4(1+\sqrt{n})^2}$，下界引理夹逼坐实。（§5.3）
14. $p(x_{\text{new}} \mid D) = \int f(x_{\text{new}} \mid \theta)\,\pi(\theta \mid D)\,d\theta$；Beta–Binomial 闭式 $P(j \mid D) = \binom{m}{j}\frac{B(a_1 + j, b_1 + m - j)}{B(a_1, b_1)}$，方差 $= m\mu(1-\mu)\bigl(1 + \frac{m-1}{a_1+b_1+1}\bigr)$。（§6.2）
15. 先验是信息也是负担；频率派给长期覆盖保证、贝叶斯给单次相干性；输出点估计加区间 vs 整个后验；贝叶斯账本可流式递归、MLE 整体重算。（§6.1）

### 交错练习

1. $e^{\eta}$ 与 $\lambda$。2. $\max_i x_i$ 与 $\frac{n+1}{n}\max$。3. $\frac{1}{p(1-p)}$ 与 $\frac{p(1-p)}{n}$。4. 对角阵 $\mathrm{diag}(\frac{1}{v}, \frac{1}{2v^2})$，交由 $\mathrm{E}[(x-\mu)^3] = 0$ 消掉。5. $(k+a)/(n+2a)$，$a = \sqrt{n}/2$，$\frac{1}{4(1+\sqrt{n})^2}$。6. 因子 $1 + \frac{m-1}{a_1+b_1+1}$。7. $\frac{9}{14}$ 与 $0.7$。

## $\rm \S \, R1.7$ 衔接

向前：概率论册的矩、CLT 与 Beta 分布是第 1、4、5 章的零件库；优化册的凸性在第 4 章「对数似然求导置零」背后。向后：因果推断册的 IPW 与第 6 章后验预测是同一道题的两种计价；深度学习册的贝叶斯神经网络把「权重也讲后验」做成产品；MCMC 与变分推断在概率论册第 10—11 章有完整展开——本册的指数族结构是它们一切闭式计算的发动机。
