# $\rm Chapter \, 32$ 多模态 AI 与生成式模型

> 你在 ChatGPT 里输入文字，它回复文字。但你发给它一张截图问"这个报错是什么意思"，它也能看懂。你让 Midjourney "画一只穿着宇航服的柴犬"，它生成了一张图片。你给 Suno 一段歌词，它谱成了一首歌。这些不再是"文字进文字出"的对话模型——它们是多模态的生成式 AI。这一章拆解它们的工作原理、能力边界和工程实践。

## $\rm \S \, 32.1$ 从文本到万物：模态的扩展

### $\rm \S \, 32.1.1$ 什么叫"模态"

模态（modality）是数据的形式——文本、图像、音频、视频、3D 模型、蛋白质序列、传感器读数是不同的模态。传统 AI 系统通常只处理一种模态（如 CV 模型只看图像，NLP 模型只看文本）。

多模态 AI 的核心突破是：**把不同模态映射到同一个语义空间**。一张柴犬的照片和"一只柴犬"这段文字，在多模态模型的内部表示中会生成相似的向量——因为它们描述的是同一个概念。

### $\rm \S \, 32.1.2$ CLIP：多模态的转折点

2021 年 OpenAI 发布的 **CLIP**（Contrastive Language-Image Pre-training）是第一个大规模成功的多模态模型。它用 4 亿对（图片, 文字描述）训练——让模型学会"这张图片和这段文字是否匹配"。

关键洞察：不需要人工标注猫是猫、狗是狗——互联网上天然存在大量"图片+alt text/标题/caption"的配对数据。CLIP 用对比学习（contrastive learning）：匹配的图文对在向量空间中拉近，不匹配的推远。

### $\rm \S \, 32.1.3$ 多模态模型谱系

| 模型 | 输入 | 输出 | 核心能力 |
|---|---|---|---|
| **GPT-4V / GPT-5** | 文本 + 图片 | 文本 | 看图问答、OCR、图表理解 |
| **Claude 5** | 文本 + 图片 + PDF | 文本 | 文档理解、代码截图→分析 |
| **Gemini 2.5** | 文本 + 图片 + 音频 + 视频 | 文本 | 原生多模态（非拼接） |
| **DALL-E 3 / Midjourney** | 文本 | 图片 | 文本→图像生成 |
| **Sora** | 文本 + 图片 + 视频 | 视频 | 文本/图片→视频生成 |
| **Suno / Udio** | 文本 + 音频片段 | 音频 | 文本（歌词+风格描述）→音乐 |
| **Stable Diffusion** | 文本 + 图片 | 图片 | 开源文本→图像，可本地运行 |

## $\rm \S \, 32.2$ 扩散模型：生成式图像的核心原理

### $\rm \S \, 32.2.1$ 正向与反向过程

扩散模型（Diffusion Models）的核心思想很简单：

1. **正向过程（加噪）**：拿一张清晰的图片，逐步加上随机高斯噪声(Gaussian noise)，经过足够多步（通常 1000 步）后变成完全不可辨认的纯噪声。

2. **反向过程（去噪）**：训练一个神经网络，让它学会从加了噪声的图片中"预测并去除"噪声——逐步恢复原始清晰图片。

训练完成后，你给模型一张纯噪声图 + 一段文字描述（如"星空下的猫"），模型从纯噪声开始逐步去噪，每一步都"往文字描述的方向靠拢"，最终生成一张符合描述的清晰图片。

### $\rm \S \, 32.2.2$ Stable Diffusion：开源生态

**Stable Diffusion**（Stability AI）是第一个大规模开源的扩散模型。它可以在消费级 GPU（$8 \, \text{GB}$ 显存）上运行。围绕它建立的工具生态：**Automatic1111 WebUI**、**ComfyUI**（节点化工作流）、**ControlNet**（精确控制生成内容——如姿态、深度图、线稿→上色）。

### $\rm \S \, 32.2.3$ LoRA：低成本微调

**LoRA**（Low-Rank Adaptation）让你用几张自己的照片（如 10 张自拍）在几分钟内微调 Stable Diffusion，让它学会画你的脸。LoRA 不修改原模型权重——它在旁边附加小型可训练矩阵——所以 LoRA 文件只有几 MB 到几十 MB，可以像滤镜一样分享和叠加。

## $\rm \S \, 32.3$ 大语言模型(LLM)的多模态扩展

### $\rm \S \, 32.3.1$ 视觉编码器 + 语言模型

当前主流方案不是"从头训练一个同时理解图文的大模型"，而是**拼接**：用预训练的视觉编码器（如 CLIP 的视觉部分）把图片转换为一系列向量，然后把这些向量和文本 token 混在一起，输入给预训练的大语言模型。

```text
图片 → 视觉编码器 → [img1, img2, ..., img256]（图片 token）
文字 → 文本分词器 → [tok1, tok2, ...]（文本 token）
拼接 → [img1, ..., img256, tok1, tok2, ...] → 大语言模型 → 回答
```

### $\rm \S \, 32.3.2$ 音频处理

语音→文字的 ASR（Automatic Speech Recognition，如 OpenAI Whisper）已经非常成熟。文字→语音的 TTS（Text-to-Speech，如 ElevenLabs）也在快速进步——不只是"听起来像机器人"，而是自然的语调、停顿、情感。

音乐生成（Suno、Udio）本质上是把音乐建模为"音频 token 序列"，用类似语言模型的架构逐 token 生成——只是这些 token 代表的是音频片段而非文字。

## $\rm \S \, 32.5$ 总结

- 多模态 = 统一表示空间：把不同形式的输入映射到同一个语义空间，让文本和图片可以互相检索和推理。
- 扩散模型从噪声逐步去噪生成图片——Stable Diffusion + LoRA 让个性化图像生成变得廉价。
- 当前多模态 LLM 的主流架构是"视觉编码器 + 预训练语言模型"的拼接——不是从头训练。

## $\rm \S \, 32.6$ 关键概念回顾

1. 什么是"模态"？多模态模型的核心突破是什么？
> 模态是数据的形式（文本、图像、音频、视频等）；多模态模型把不同模态映射到同一个语义空间——同一概念的图片和文字在内部表示中生成的向量相近。

2. CLIP 是怎样训练的？关键洞察是什么？
> 用互联网上天然存在的海量"图片+文字描述"配对数据做对比学习：匹配的图文对在向量空间中拉近、不匹配的推远，不需要人工标注每张图的内容。

3. 扩散模型生成图片的两步过程是什么？
> 正向过程把清晰图片逐步加噪成纯噪声；训练好的模型从纯噪声开始逐步去噪，每一步向文字描述的方向靠拢，最终生成符合描述的清晰图片。

4. 为什么 LoRA 微调"廉价"？
> 它不修改原模型权重，只在旁边附加小型可训练矩阵——LoRA 文件只有几 MB 到几十 MB，用少量图片、几分钟即可完成，可以像滤镜一样分享和叠加。

5. 当前多模态大语言模型的主流架构是什么？
> "视觉编码器 + 预训练语言模型"的拼接：图片经编码器变成图片 token，与文本 token 混在一起输入语言模型——不是从头训练一个同时理解图文的大模型。

## $\rm \S \, 32.7$ 应用与辨析

6. "拼接式"多模态和"原生多模态"有什么区别？
> 拼接式（多数多模态 LLM）用现成的视觉编码器把图片转成向量再交给语言模型，工程上便宜；原生多模态（如 Gemini）从训练一开始就统一处理多种模态，整合更自然但训练成本高。

7. 什么情况下用本地 Stable Diffusion 而不是云端文生图 API？
> 需要隐私（图片数据不出本机）、需要批量生成控制成本、或需要和本地工作流（ControlNet、LoRA）深度集成时选本地 SD；追求开箱即用的生成质量和速度时选云端 API。
