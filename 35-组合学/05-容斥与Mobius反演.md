# $\rm \S \, Chapter \, 5$ 容斥与 Möbius 反演

上一章的二项式反演解决了「恰好 / 至少」的一维翻译，但它有个隐藏身份：它只是 Boolean 格（子集格）上 Möbius 反演的特形。本章把镜头拉远——容斥不是一堆「加回去、再减掉」的技巧杂烩，而是**一个代数结构**：任何有限偏序上都有一对互逆的变换（zeta 与 Möbius），容斥是它们在子集格上的名字。看清结构之后，两件事水到渠成：一是 OI 的高维前缀和与子集卷积（同一变换的位运算工业化），二是 min-max 容斥（同一思想的期望版）。全程零起点，偏序当堂定义。

> **开始前自检**：本章假设你已经会：
>
> 1. □ 第 4 章的二项式反演及其 GF 证明。
> 2. □ 集合的子集族记号：$T \subseteq S$、幂集 $2^S$、对称差。
> 3. □ 归纳法与双重求和交换（有限和内自由交换）。
> 4. □ 位运算基础：$S$ 的二进制掩码表示、$S \setminus \{i\}$ 对应 $S \mathbin{\&} \sim (1 \ll i)$。

## $\rm \S \, 5.1$ 容斥的标准形式：逐点验证

设 $A_1, \ldots, A_n$ 是全集合 $U$ 的子集，$N(x)$ 表示点 $x$ 落入的集合个数。白话：直接数「至少落进一个集合」的东西会重复计数，容斥给的方案是按「落入集合个数的奇偶」交错加减——恰好落进一处的加回来、落进两处的减出去，重复恰好两两抵消。容斥原理说：

1. **容斥原理**：
$$
\left| \bigcup_{i=1}^{n} A_i \right| = \sum_{\varnothing \ne S \subseteq \{1, \ldots, n\}} (-1)^{|S| + 1} \left| \bigcap_{i \in S} A_i \right| .
$$
2. 证明是逐点的（pointwise），这个视角比「画两个圈的 Venn 图」强得多。固定 $x \in U$，设它属于恰好 $m$ 个 $A_i$。右端 $x$ 的贡献：对每个含 $x$ 的指标子集 $S$（$S$ 必须落在那 $m$ 个指标里，且非空），贡献 $(-1)^{|S|+1}$，合计
$$
\sum_{s=1}^{m} (-1)^{s+1} \binom{m}{s} = -\sum_{s=0}^{m} (-1)^{s} \binom{m}{s} + 1 = 1,
$$
末步用了 $\sum_{s=0}^{m} (-1)^s \binom{m}{s} = (1-1)^m = 0$（$m \ge 1$）。所以 $x \in \bigcup A_i$（$m \ge 1$）时贡献 1，$x \notin$ 并集（$m = 0$）时贡献 0——右边逐点等于左边的指示函数。证毕。
3. 这个证明的副产品是**指示函数恒等式**：
$$
\mathbf{1}_{\bigcup A_i} = \sum_{\varnothing \ne S} (-1)^{|S|+1} \mathbf{1}_{\bigcap_{i \in S} A_i},
$$
它对每个点逐字成立，因此两边同乘任何「每个点的量」（权值、概率、随机变量）后求和依然成立——§5.5 的 min-max 容斥就从这里免费拿到。
4. 结构观点登场：定义「按包含关系重叠」的两种计数。$f(S)$ = 「坏点集**恰好**是 $S$」的对象数，$g(S)$ = 「坏点集**包含于** $S$」的对象数，则 $g(S) = \sum_{T \subseteq S} f(T)$。$f$ 难算（要精确控制），$g$ 易算（只需要求若干条约束）。容斥就是从 $g$ 解出 $f$ 的唯一公式：
$$
f(S) = \sum_{T \subseteq S} (-1)^{|S \setminus T|} g(T).
$$
下一节说明：这「两边互逆」不是巧合，而是一对矩阵互逆——zeta 变换与 Möbius 变换。

## $\rm \S \, 5.2$ 偏序、关联代数与 Möbius 函数

先当堂定义。白话：上一节的 $g(S) = \sum_{T \subseteq S} f(T)$ 之所以能反演，靠的是「包含关系」这个结构；偏序就是把「包含」这类结构的公共骨架（可以向上求和、就能向下解出）抽象出来，好让同一套反演在整除、分拆等场景全部生效。**偏序**是集合 $P$ 上满足自反（$x \le x$）、反对称（$x \le y$ 且 $y \le x$ 则 $x = y$）、传递（$x \le y \le z$ 则 $x \le z$）的二元关系 $\le$。本章的三个主角：子集格（$P = 2^S$，$\le$ = 包含）、整除格（$P$ = 正整数，$a \le b$ ⟺ $a \mid b$）、以及一般的有限偏序。

1. **关联代数**：有限偏序 $P$ 上，「区间 $[x, z] = \{y : x \le y \le z\}$」的函数全体配以**卷积**
$$
(f * g)(x, z) = \sum_{x \le y \le z} f(x, y) \, g(y, z)
$$
构成一个代数（结合律：三重求和按中点 $y$ 收缩，交换求和次序即得）。读法：这行卷积是「矩阵乘法」在「有序对指标」下的样子——从 $x$ 到 $z$ 的每条中转站 $y$ 上，把前段 $f$ 与后段 $g$ 相乘再加总；「按 $y \le x$ 求和」将被读成「卷一次 $\zeta$」。两个最重要的元素：**zeta 函数** $\zeta(x, z) = 1$（当 $x \le z$），它就是「$\le$ 关系本身的指示」；**Möbius 函数** $\mu$ 定义为 $\zeta$ 的卷积逆：$\mu * \zeta = \zeta * \mu = \delta$，其中 $\delta(x, z) = [x = z]$。
2. 存在性与递推：$\mu$ 可以逐层构造。$\mu(x, x) = 1$（来自 $\delta$ 的对角约束）；$x < z$ 时 $(\mu * \zeta)(x, z) = 0$ 展开为
$$
\mu(x, z) = -\sum_{x \le y < z} \mu(x, y),
$$
右端只依赖更低层（$y < z$），归纳推进。所以任何有限偏序都有唯一的 Möbius 函数。
3. **一般 Möbius 反演定理**：对函数 $f, g : P \to \mathbb{C}$，
$$
g(x) = \sum_{y \le x} f(y) \iff f(x) = \sum_{y \le x} \mu(y, x) \, g(y).
$$
4. 证明：正方向两边同乘 $\mu$ 作卷积——把「按 $y$ 求和」看成与 zeta 的卷积，则 $g = \zeta * f$（按 $y \le x$ 求和正是 $(\zeta * f)(x)$ 的定义），卷 $\mu$ 得 $f = \mu * g$，展开即右式。反方向对称（$\zeta$ 卷回去）。整个证明只有一行，全部难度都在「看出求和是卷积」这一步——这就是关联代数观点的回报：**容斥的公式不用背，逆矩阵算一次就有了**。
5. 子集格上的 Möbius 函数：$\mu(T, S) = (-1)^{|S \setminus T|}$。验证递推：$|S \setminus T| = d$ 时，
$$
-\sum_{T \subseteq U \subsetneq S} (-1)^{|U \setminus T|} = -\sum_{d' = 0}^{d-1} \binom{d}{d'} (-1)^{d'} = -(-1+1)^{d-1} = 0 \ (d \ge 1),
$$
与 $\mu(T,S) = (-1)^d$ 的递推要求一致。代回 §5.1 的 $f(S) = \sum_T \mu(T, S) g(T)$，正是容斥公式——**二项式反演与容斥从此统一为「子集格上的 Möbius 反演」**。
6. 比喻：zeta 变换是「把精确信息糊成模糊信息」（恰好在 $S$ 的账并入所有超集），Möbius 函数是「去糊系数表」——每个偏序有自己的去糊表，造表只需那条递推。

**本节小结**：本节把容斥升格为代数：偏序上的关联代数里，$\zeta$ 与 $\mu$ 是一对互逆变换，反演定理一行证完；下一节去第二个偏序——整除格——取数论里那个 Möbius 函数，看同一张表长什么样。

## $\rm \S \, 5.3$ 整除格：数论侧的同款

整除格 $P = \{1, 2, 3, \ldots\}$（$a \le b$ ⟺ $a \mid b$）上的 Möbius 函数就是数论里那个 $\mu$：设 $b / a = \prod p_i^{e_i}$，则

$$
\mu(a, b) = \begin{cases} (-1)^{\omega(b/a)} & b/a \text{ 无平方因子}, \\ 0 & \text{否则}, \end{cases}
$$

其中 $\omega$ 数质因子个数。推导走递推：区间 $[a, b]$ 同构于 $\prod p_i^{[0, e_i]}$（每个质因子的幂次独立取 0 到 $e_i$），区间函数在「格的直积」下卷积也按因子分解，所以只需算单质数链 $1 \le p \le p^2$：$\mu(1, 1) = 1$、$\mu(1, p) = -1$（递推 $-\mu(1,1)$）、$\mu(1, p^2) = -(\mu(1,1) + \mu(1,p)) = 0$、更高幂全为 0。多质数直积时系数相乘，得 $(-1)^{\omega}$ 与平方因子清零。数论册（36-数论）的 Möbius 反演 $\sum_{d \mid n} \mu(d) F(n/d) = f(n)$ 是本节定理在整除格上的实例——两册在这一点上完全同构。

第三个常用格是**划分格**（$P$ = $n$ 元集的分拆，按加细排序），其 Möbius 函数 $\mu(\hat 0, \pi) = (-1)^{|\pi| - 1} (|\pi| - 1)!$（$|\pi|$ 是块数；推导用递推加 Stirling 数的卷积关系，完整证明见 Stanley《Enumerative Combinatorics》Vol. 1 §3.10，此处标注出处）。它的经典应用是数「生成整个集合族的极小集合」类问题（primitive 族计数），竞赛里出现频率低，知道有这张表即可。

**本节小结**：本节在整除格上收回了数论 Möbius 函数、在划分格上登记了第三张 Möbius 表——同一递推造出所有表；下一节把子集格放进计算机，看 zeta/Möbius 变换如何变成位运算模板。

## $\rm \S \, 5.4$ OI 工业化：高维前缀和与子集卷积

把子集格放进计算机：$n$ 位掩码表示集合，$g(S) = \sum_{T \subseteq S} f(T)$ 是 $2^n$ 维数组上的变换。朴素枚举每个 $S$ 的全部子集代价 $3^n$（每个元素三态：在 $S$、在 $T$、都不在）。zeta 变换有 $O(n 2^n)$ 的工业化实现：

1. **SOS / 高维前缀和（FMT）**：按位 $i$ 从 0 到 $n-1$ 扫，每轮对所有含位 $i$ 的 $S$ 执行 $f[S] \mathrel{+}= f[S \setminus \{i\}]$。正确性归纳：第 $i$ 轮结束时，每个位置的值是其「前 $i$ 位可自由变动、其余位固定」的子集和；$n$ 轮后即全子集和。推导：第 0 轮把「位 0 可去可留」并进每个 $S$；第 1 轮在已并位 0 的基础上并位 1——每一位的去留决策独立叠加，正好覆盖 $T \subseteq S$ 的全部 $2^{|S|}$ 种，且每个 $T$ 恰被并到 $S$ 一次（按 $T \setminus S$ 的最高位归账：$T$ 在其补位的每一轮被并一次，路径唯一）。
2. 逆变换（Möbius / 差分）是同款反演：每轮 $f[S] \mathrel{-}= f[S \setminus \{i\}]$，顺序相反亦可——卷积逆在位运算层的镜像。
3. **子集卷积**：要算 $h = f * g$，$h(S) = \sum_{T \subseteq S} f(T) g(S \setminus T)$（要求 $T$ 与 $S \setminus T$ 不相交）。朴素 $O(3^n)$。工业化做法：给每个集合挂一个「秩」变量 $x$，定义 $\hat f = \sum_S f(S) \, x^{|S|} \, \text{mask}^S$。关键观察：普通并卷积（不相交限制放开）的 $k$ 次幂 $\hat f^k$ 中，$x^{|S|}$ 项只可能来自 $k$ 个两两不交、并为 $S$ 的分解——因为每个因子贡献的秩之和 $\sum |T_i| \ge |\bigcup T_i| = |S|$，等号成立当且仅当不交。于是「取 $\exp(\hat f)$ 再取 $x^{n}$ 层」自动执行了不交化：$\exp$ 的 $\frac{1}{k!}$ 同时把分解的无序性除掉。实现上 $\exp$ 与 $\ln$ 都在「秩分层 + 逐层并卷积」的框架里完成，总代价 $O(n^2 2^n)$。这套「加秩变量强制不交」的技巧是集合幂级数方法的核心，竞赛里直接以模板形式存在。
4. 复杂度总账（OI 常用档位）：子集和 SOS $O(n 2^n)$；子集卷积 $O(n^2 2^n)$；朴素子集枚举 $3^n$；第 1 章五边形数递推 $O(n \sqrt n)$。选型口诀：先看约束是「或」（并）还是「恰好不交」——前者 SOS，后者子集卷积。

## $\rm \S \, 5.5$ min-max 容斥：期望世界的同一招

1. **min-max 容斥**：对非空实数集 $S$，
$$
\max(S) = \sum_{\varnothing \ne T \subseteq S} (-1)^{|T| + 1} \min(T),
$$
读法：难算的最大值被拆成「各子集最小值」的交错和——交换的是算的东西：max 要联合信息，min 往往有独立结构。min 与 max 对调后同样成立。对随机变量也成立（两边逐样本点成立，线性期望随即免费）。
2. 证明（整数情形，实数由单调逼近或直接用指示函数版）：设 $S$ 非空、各元素为非负整数。对任意阈值 $t \ge 0$，$\max(S) = \sum_{t \ge 1} \mathbf{1}[\max(S) \ge t]$（把「最大值是多少」按「逐级门槛是否跨过」记账）。而 $\max(S) \ge t$ ⟺ 至少一个元素 $\ge t$，记 $A_x = \{\text{元素 } x \ge t\}$，由 §5.1 第 3 条的指示函数恒等式：
$$
\mathbf{1}[\max(S) \ge t] = \sum_{\varnothing \ne T \subseteq S} (-1)^{|T|+1} \mathbf{1}[\forall x \in T : x \ge t] = \sum_{\varnothing \ne T} (-1)^{|T|+1} \mathbf{1}[\min(T) \ge t].
$$
对 $t$ 求和，右边逐项重新组装成 $\sum_T (-1)^{|T|+1} \min(T)$（每个 $T$ 的 $\sum_t \mathbf{1}[\min(T) \ge t] = \min(T)$，$\min(T) \ge 0$）。$\blacksquare$
3. 为什么这个恒等式在竞赛里是「大杀器」： $\max$ 的直接计算需要联合分布，而 $\min$ 往往有简单的独立结构。经典场景：$n$ 个事件，每个时刻事件 $i$ 以概率 $p_i$ 独立发生，求「全部事件至少各发生一次」的期望时刻 $E[\max(T_1, \ldots, T_n)]$。$\min(T_{i_1}, \ldots, T_{i_k})$（钦定子集里第一个发生的时刻）服从几何分布、期望 $\frac{1}{\sum_{j} p_{i_j}}$，于是
$$
E\left[ \max_i T_i \right] = \sum_{\varnothing \ne T \subseteq \{1, \ldots, n\}} (-1)^{|T|+1} \frac{1}{\sum_{i \in T} p_i},
$$
一个 $O(2^n)$ 枚举子集的和——没有 min-max 容斥时这是算不动的高维积分。期望的线性性把「联合分布」化成「子集枚举」，这是指示函数恒等式的又一次免费转账。
4. 推广（陈述）：第 $k$ 大也有同款公式（$\mathrm{kth}(S) = \sum_T (-1)^{|T|-k} \binom{|T|-1}{k-1} \min(T)$），证明同一模板（逐阈值 + 容斥），细节留作 §5.7 的练习。

## $\rm \S \, 5.6$ 关键概念回顾

1. 容斥的逐点证明：每个点按「落入集合数 $m$」贡献 $\sum_{s=1}^m (-1)^{s+1}\binom{m}{s} = 1$。（§5.1）
2. 指示函数恒等式对权值、概率、随机变量全部免费生效。（§5.1）
3. 关联代数：区间函数 + 卷积；$\zeta$ 与 $\mu$ 互逆；$\mu$ 由递推 $\mu(x,z) = -\sum_{x \le y < z}\mu(x,y)$ 逐层构造。（§5.2）
4. 一般 Möbius 反演 $g = \zeta * f \iff f = \mu * g$；子集格 $\mu(T,S) = (-1)^{|S \setminus T|}$、整除格 $\mu$ 即数论 Möbius。（§5.2–5.3）
5. SOS 高维前缀和 $O(n2^n)$ 按位扫描；子集卷积 $O(n^2 2^n)$ 靠「秩变量强制不交 + exp」。（§5.4）
6. min-max 容斥 = 逐阈值记账 + 指示函数容斥；期望版是竞赛主战场。（§5.5）

## $\rm \S \, 5.7$ 应用与辨析

1. 用递推独立推导划分格的 $\mu(\hat 0, \pi) = (-1)^{|\pi|-1}(|\pi|-1)!$ 的 $|\pi| \le 3$ 情形，并与公式对照。
2. SOS 的正确性证明里「每个 $T$ 恰被并到 $S$ 一次」的精确含义是什么？写出 $T$ 被并进 $S$ 的唯一路径。
3. 子集卷积的秩变量技巧中，为什么普通并卷积的 $x^{|S|}$ 层「只可能来自不交分解」？给出不等式 $\sum|T_i| \ge |\bigcup T_i|$ 的证明与取等条件。
4. min-max 容斥对「随机变量」成立的严格理由是什么？哪些期望运算步骤依赖线性性、哪些不依赖？
5. 三张 Möbius 表（子集格、整除格、划分格）各配一个「天然易算的 $g$」：说出每个场景里 $g$ 与 $f$ 的组合含义，并指出哪个场景对应「生成极小覆盖」类问题。

### $\rm \S \, 5.8.2$ 应用与辨析答案

1. $|\pi| = 1$：$\mu(\hat 0, \hat 1) = 1$（递推基准）。$|\pi| = 2$：$\hat 0$ 与 $\pi$ 之间只有 $\pi$ 自己（除 $\hat 0$），$\mu = -\mu(\hat 0, \hat 0) = -1$。$|\pi| = 3$：$\hat 0$ 到 $\pi$ 的中间元是「两块分拆」，共 $S(3,2) - 1$ 个 $\pi$ 之下的……直接按定义 $\mu(\hat 0, \pi) = -\sum_{\sigma < \pi, \sigma \ne \hat 0} \mu(\hat 0, \sigma) - 1$，两块中间分拆有 $2^2 - 2 = 2$ 个对 $\pi$ 加细（三块并成两块的方式 $S(3,2) = 3$ 个中除完全并合），各自 $\mu = -1$，故 $\mu(\hat 0, \pi) = -(-1 -1) = 2 = (-1)^2 \cdot 2!$。与公式一致。（§5.3）
2. 含义：变换过程中 $T$ 的信息沿「逐位加入 $T \setminus S$ 的元素」的链传递到 $S$；路径按「位被加入的先后次序」唯一——第 $i$ 轮只会把「缺位 $i$」的版本并给「含位 $i$」的版本，所以每个 $T \subseteq S$ 的传递链由 $S \setminus T$ 的元素按扫描顺序唯一确定。（§5.4）
3. 不等式证明：$\bigcup T_i$ 的每个元素至少属于一个 $T_i$，所以按「元素-因子」的接触对计数得 $|\bigcup T_i| \le \sum |T_i|$；取等当且仅当没有元素被数两次，即各 $T_i$ 两两不交。（§5.4）
4. 成立理由：恒等式对每个样本点的实现值逐点成立（实数版由整数版的单调极限，或直接对实数阈值积分版本重复证明）；取期望只用线性性，不要求独立、不要求同分布。「不依赖」的部分：不需要任何联合分布信息——这正是它强于直接计算的地方。（§5.5）
5. 子集格：$g(S)$ = 「约束全部落在 $S$ 内」的计数（易），$f(S)$ = 「恰好坏 $S$」（难）——错排与「恰好 $k$」题。整除格：$g(n)$ = 「按倍数口径的计数」，$f(n)$ = 「恰为 $n$ 的口径」——Möbius 筛。划分格：$g(\pi)$ = 「允许以 $\pi$ 的块为粒度生成」的计数，$f$ 对应「生成整个集合的极小结构」——primitive 族问题。（§5.2–5.3）

容斥的偏序骨架立住了：同一套 $\zeta$-$\mu$ 互逆横跨「恰好/至少」、数论筛与期望计算。下一章换一件完全不同的武器——当对象在**对称群下不分彼此**时，硬数会把同一件东西数 $|G|$ 遍；Burnside 引理教我们「平均掉对称」，Polya 把它变成可执行的机器。
