# $\rm Chapter \, 5$ 射影空间

第 4 章两次撞见同一堵墙：$V(xz-1)$ 的投影挖了个洞，圆的有理参数化漏了一个点——丢的东西都逃向了「无穷远」。本章把这堵墙拆掉：**射影空间**给仿射空间补上无穷远点，让平行线相交、让「解的个数」守恒。三步走：齐次坐标（§5.1）、射影簇与仿射簇的粘合（§5.2）、Bézout 定理与「为什么射影几何更完备」（§5.3–§5.4）。

> **开始前自检**：本章假设你已经会：
>
> 1. □ 仿射簇 $V(I)$ 与理想的词典、Hilbert 零点定理的陈述（本册第 1、2 章）；
> 2. □ 消去理想与 Extension 定理：投影丢解、丢失点坐在首系数例外集上（本册第 4 章 §4.1–§4.2）——本章回答「为什么丢」并把丢的补回来；
> 3. □ 齐次多项式的意思（每个单项式总次数相同），Gröbner 基与结式随手可用（本册第 3、4 章）；
> 4. □ 线性代数的商空间直觉：等价类、模掉缩放——§5.1 的定义靠它。
>

## $\rm \S \, 5.1$ 齐次坐标：给仿射世界补上无穷远

白话：仿射空间里平行的直线永不相交——这是公理，也是缺陷：两条平行线「显然」该有一个交点，只是那个点跑到了无穷远。**射影空间**把所有方向的无穷远点正式收编进空间，方法是改变「点」的定义：不再是一个坐标向量，而是**一条过原点的直线**。

定义（射影空间）。域 $k$ 上的 $n$ 维**射影空间**：

$$
\mathbb{P}^n = \big( k^{n+1} \setminus \{0\} \big) \,/\, \sim, \qquad
(x_0, \ldots, x_n) \sim (\lambda x_0, \ldots, \lambda x_n),\;\; \lambda \in k \setminus \{0\}
$$

（读法：非零向量的全体按「非零倍数视为同一个」分等价类；一个点就是 $k^{n+1}$ 里一条过原点的直线。记号 $[x_0 : x_1 : \cdots : x_n]$ 强调「只在乎比例」：$[1 : 2 : 3] = [2 : 4 : 6] = [1/3 : 2/3 : 1]$。）

${x_0, \ldots, x_n}$ 叫**齐次坐标**（homogeneous coordinates）。先看最低维建立直觉：

1. $\mathbb{P}^1$：等价类 $[x_0 : x_1]$。凡 $x_0 \ne 0$ 的点唯一写成 $[1 : t]$（$t = x_1 / x_0$），这一片抄的就是仿射直线；剩下的唯一点 $[0 : 1]$ 记作 $\infty$。所以 $\mathbb{P}^1 = \mathbb{A}^1 \cup \{\infty\}$。实数上画出来：$t \to +\infty$ 与 $t \to -\infty$ 从两侧逼近同一点 $[0:1]$，两端粘合——实射影直线拓扑上是一个圆。
2. $\mathbb{P}^2$：$[x_0 : x_1 : x_2]$。$x_0 \ne 0$ 的一片是仿射平面（坐标 $x_1/x_0,\, x_2/x_0$）；$x_0 = 0$ 的点集 $\{[0 : x_1 : x_2]\}$ 是一条射影直线，叫**无穷远直线**——每个方向（$x_1 : x_2$ 的比例）贡献一个无穷远点。

为什么叫「齐次」坐标？因为只有**齐次条件**下的陈述才在射影世界里良定义。齐次多项式 $F$（每个单项式总次数都是 $d$）满足

$$
F(\lambda x) = \lambda^d F(x)
$$

（读法：缩放坐标只把函数值缩放 $\lambda^d$ 倍，**零与不零**不变——于是「$F = 0$ 是否成立」对等价类有意义。）非齐次的多项式没有这个性质，在射影空间里连「在一点取零」都说不清。

直线搬进 $\mathbb{P}^2$：仿射直线 $ax + by + c = 0$ 齐次化成

$$
aX + bY + cZ = 0
$$

（读法：约定仿射坐标 $x = X/Z,\; y = Y/Z$，则 $Z = 1$ 的那一片正是原直线。）平行线在此团聚：$y = 0$ 齐次化为 $Y = 0$，$y = 1$ 齐次化为 $Y - Z = 0$，联立得 $Y = 0,\; Z = 0$，交点是

$$
[1 : 0 : 0]
$$

（读法：水平方向的无穷远点。两条平行线在仿射平面里「永不相交」，在射影平面里相交于各自方向的 infinity 点——**任何两条不同直线都恰有一个交点**，这是射影几何的第一定律。）

**本节小结**：射影空间的点＝过原点的直线，齐次坐标只记比例；$\mathbb{P}^1 = \mathbb{A}^1$ 添一个无穷远点（实图景是圆），$\mathbb{P}^2 = \mathbb{A}^2$ 添一条无穷远直线；齐次多项式的缩放性质让「取零」成为良定义。下一节把「簇」搬进这个新空间，并说清它与仿射簇如何互相翻译。

## $\rm \S \, 5.2$ 射影簇与仿射簇的粘合

白话：仿射簇是「一组多项式的公共零点」；射影簇是同一件事，只是多项式必须齐次。两者不是两个世界，而是同一对象的两张切片：射影簇切开来看是仿射簇，仿射簇加顶「帽子」回射影世界。粘合的手术台就是坐标卡。

定义（射影簇）。齐次理想 $I \subset k[X_0, \ldots, X_n]$（由齐次多项式生成的理想）的**射影簇**：

$$
V_+(I) = \{\, [x] \in \mathbb{P}^n : F(x) = 0 \text{ 对所有齐次 } F \in I \,\}
$$

（读法：下标 $+$ 提醒「齐次世界」；良定义性来自 §5.1 的缩放性质——$F(\lambda x) = \lambda^d F(x)$，一个分量为零则全为零。）

**从射影到仿射：切开。** 第 $i$ 张坐标卡 $U_i = \{x_i \ne 0\}$ 上，把 $x_i$ 归一化成 $1$，得到仿射坐标。以 $U_0$ 为例：$[1 : x_1 : \cdots : x_n]$ 对应 $\mathbb{A}^n$ 的点 $(x_1, \ldots, x_n)$，而齐次 $F$ 在这张卡上变成去齐次多项式

$$
F^{\vee}(x_1, \ldots, x_n) = F(1, x_1, \ldots, x_n)
$$

于是

$$
V_+(I) \cap U_0 = V\big( F^{\vee} : F \in I \text{ 齐次} \big)
$$

（读法：射影簇切一刀是仿射簇——「每张卡一片」，$n + 1$ 张卡盖满 $\mathbb{P}^n$。）

**从仿射到射影：戴帽。** 反方向用**齐次化**：$f \in k[x_1, \ldots, x_n]$ 总次数 $d$，定义

$$
f^h(X_0, \ldots, X_n) = X_0^{\,d}\, f\Big( \frac{X_1}{X_0}, \ldots, \frac{X_n}{X_0} \Big)
$$

（读法：逐个单项式补 $X_0$ 的幂凑齐 $d$ 次——$x^2 y$ 变 $X_1^2 X_2$ 时 $d = 3$ 补一个 $X_0^0$，$x^2$ 补成 $X_0 X_1^2$。这样 $f^h$ 齐次，且在 $Z = 1$ 卡上退化回 $f$。）$V(f)$ 的**射影闭包**取 $V_+(\langle f^h \rangle)$。

例：抛物线 $y = x^2$ 齐次化。$d = 2$，$y \to YZ$？逐项：$y$ 补成 $YZ_0$……写开：$y - x^2$ 齐次化为

$$
Y_0 Y - X^2 = 0 \qquad (\text{记仿射坐标 } y = Y / Y_0)
$$

（读法：$y$ 补一个 $Y_0$ 凑二次，$x^2$ 已是二次。习惯记法 $YZ = X^2$，$Z$ 是那个「凑次数」的坐标。）它与无穷远直线 $Z = 0$ 的交：代入得 $X^2 = 0$，即 $X = 0$，交点是

$$
[0 : 1 : 0] \quad \text{且是二重的（方程给 } X^2 = 0\text{）}
$$

（读法：抛物线的两只「手臂」伸向无穷远，在射影世界汇合同一个点 $[0:1:0]$，且以重数 $2$ 相切——§5.3 数重数时这笔账要记两回。）

**粘合的全景**。$\mathbb{P}^n = U_0 \cup U_1 \cup \cdots \cup U_n$，每张 $U_i \cong \mathbb{A}^n$；两张卡的重叠处，坐标互换是「取倒数」：$U_0$ 的坐标 $t = x_1/x_0$ 与 $U_1$ 的坐标 $s = x_0/x_1$ 满足 $t = 1/s$（在 $x_0 x_1 \ne 0$ 处）。转移映射是多项式的有理式——射影簇由仿射簇沿开集粘合而成，粘合处自动把「跑出去的点」接回另一个卡。这就是第 4 章丢点的去向：$V(xz - 1)$ 投影挖掉的洞、参数化漏掉的 $(-1, 0)$，在射影世界都由另一张卡无缝接住。

还有一个全局视角值得存档：齐次理想 $I \subset k[X_0, \ldots, X_n]$ 同时定义仿射簇 $V(I) \subset \mathbb{A}^{n+1}$——它是 $V_+(I)$ 上的**仿射锥**：过原点、沿 $V_+(I)$ 的每条射线拉成的锥体。$V_+(I)$ 是锥的「方向集合」，锥是方向的并。原点这个孤立点被射影化扔掉了——射影空间天生就是「模掉缩放」的世界。

**本节小结**：射影簇 $V_+(I)$ 由齐次理想定义；坐标卡把它切成仿射簇，齐次化把仿射簇戴帽送回射影世界，$n+1$ 张卡沿取倒数的转移映射粘合。抛物线在无穷远处收拢成二重点，第 4 章的洞与漏点在此获得安放。下一节给「交点个数」立法。

## $\rm \S \, 5.3$ Bézout 定理：交点个数守恒

白话：两条曲线交几个点？仿射世界的答案支离破碎：平行线交 $0$ 个、相切交「半个」、有的交点跑到无穷远。射影世界一句话定案：**次数相乘**。这份整洁的代价是两个技术词——计重数、代数闭——本章把两个词都落到算例上。

先补**交的重数**（intersection multiplicity）的陈述级定义。曲线 $C: F = 0$ 与 $D: G = 0$ 在点 $p$ 无公共分支时，重数 $I(p, C \cap D)$ 度量两条曲线在 $p$ 处「缠了几圈」：

1. **横截情形**：两条曲线在 $p$ 的切线不同（梯度 $\nabla F(p)$ 与 $\nabla G(p)$ 不共线），则 $I(p, C \cap D) = 1$——干净利落的 crossings；
2. **相切情形**：切线重合时重数 $\ge 2$，切得越「深」重数越大；
3. **可计算定义**：$I(p, C \cap D) = \dim_k\, \mathcal{O}_p / \langle F, G \rangle$（局部环对两个方程的商的维数）——严格展开需要局部环的语言，本册点到为止；本节全部算例用梯度判据或结式验证。

定理（Bézout）。设 $C: F = 0$ 与 $D: G = 0$ 是 $\mathbb{P}^2_k$ 中两条曲线，次数 ${m, n}$（${F, G}$ 齐次且无公共分支），$k$ 代数闭。则

$$
\sum_{p \in C \cap D} I(p,\, C \cap D) = mn
$$

（读法：交点按重数计数后，总数恰好是次数之积——**一条守恒律**。仿射世界数不齐的账，在这里分毫不差。）

仿射世界为什么数不齐，三笔坏账各补一笔：

1. **平行线**（$m = n = 1$）：仿射交 $0$ 点，射影交于无穷远点 $[1:0:0]$（§5.1 真算）——$1 \times 1 = 1$ 补齐；
2. **相切**：单位圆与切线 $y = 1$：仿射只见 $1$ 个点 $(0, 1)$，重数记账 $2$——下例用结式真算；
3. **无穷远漏点**：抛物线与无穷远直线（§5.2）：仿射交 $0$ 点，射影在 $[0:1:0]$ 交出二重点——$2 \times 1 = 2$ 补齐。

**主算例：两条圆锥曲线交 $4$ 点。** 取

$$
C_1:\; X^2 + Y^2 - Z^2 = 0, \qquad C_2:\; X^2 + XY + Y^2 - Z^2 = 0
$$

（读法：$C_1$ 在 $Z = 1$ 卡上是单位圆；$C_2$ 是另一条光滑二次曲线——两式相减得 $XY = 0$，交点必在坐标轴上。）逐步求交：

1. 相减：$C_2 - C_1 = XY = 0$，交点满足 $X = 0$ 或 $Y = 0$；
2. $X = 0$：代入 $C_1$ 得 $Y^2 = Z^2$，给 $[0 : \pm 1 : 1]$ 两点；$Y = 0$：得 $X^2 = Z^2$，给 $[\pm 1 : 0 : 1]$ 两点；
3. 检查无穷远卡 $Z = 0$：两式变成 $X^2 + Y^2 = 0$ 与 $X^2 + XY + Y^2 = 0$；实数域上只有平凡解 $X = Y = 0$（不是射影点）；越过复数域验一遍：$Y = iX$ 代入第二式得 $X^2 + iX^2 - X^2 = iX^2 \ne 0$（除非 $X = 0$）——**无穷远处没有交点**，四点全在 $Z = 1$ 卡内。

四点齐了：$[\pm 1 : 0 : 1]$ 与 $[0 : \pm 1 : 1]$。数重数：在仿射卡上取 $g_1 = x^2 + y^2 - 1$、$g_2 = x^2 + xy + y^2 - 1$，梯度行列式

$$
\det \begin{pmatrix} 2x & 2y \\ 2x + y & x + 2y \end{pmatrix} = 2x(x + 2y) - 2y(2x + y) = 2x^2 - 2y^2
$$

在四个交点处取值 $\pm 2$（真算：$(1,0)$ 与 $(-1,0)$ 处 $2$，$(0,\pm 1)$ 处 $-2$），全不为零——**横截，重数全为 $1$**。合计

$$
1 + 1 + 1 + 1 = 4 = 2 \times 2
$$

Bézout 定理当场兑现。sympy 在 $Z = 1$ 卡上算 lex Gröbner 基得 $\{y^2 + x^2 - 1,\; xy,\; x^3 - x\}$，从 $xy = 0$ 与 $x^3 - x = 0$ 同样读出四点（§5.6 复跑）。

**重数非 1 的例**。圆 $X^2 + Y^2 - Z^2 = 0$ 与切线 $Y - Z = 0$（仿射 $y = 1$）：消去 $Z$，

$$
\mathrm{Res}_Z\big( X^2 + Y^2 - Z^2,\; Y - Z \big) = X^2
$$

（真算。读法：结式是 $X^2$，零点是 $X = 0$ 即 $[0:1:1]$，幂次 $2$ 泄露重数——切点按 $2$ 记。仿射图景：直线 $y = 1$ 与单位圆相切于 $(0,1)$，一个「点」两条账。）一般地直线与二次曲线：$1 \times 2 = 2$，割线给两个单点（如 $y = \tfrac{1}{2}$ 交单位圆于 $x = \pm\tfrac{\sqrt{3}}{2}$），切线给一个二重点——同一本账的两种花法。

Bézout 的两个使用须知：必须计重数（切点记 $2$）；必须在代数闭域（实数上 $x^2 + y^2 = 0$ 的「交点」看不见）。它的工程身影在计算机视觉：多视图几何里相机标定、对极几何的方程组，「解至多几个」全靠次数相乘计数，解的结构设计（几视图几个点能定标）背后站着 Bézout。

**本节小结**：交的重数在横截时为 $1$、相切时加倍，可计算定义走局部环维数；Bézout 定理在射影平面断言 $\sum I(p, C \cap D) = mn$。两圆锥曲线的四交点例全流程真算：相减降次、卡内求解、无穷远清点、梯度验横截，$4 = 2 \times 2$ 分毫不差。下一节回答「为什么非要搬到射影世界」。

## $\rm \S \, 5.4$ 为什么射影几何更完备

白话：「完备」在数学里是个有精确含义的词：一个空间若把所有极限点都收在体内（紧性），就少掉一类病态。射影空间是仿射空间**加完无穷远点**之后的版本——恰好把仿射世界的丢点、丢极限、丢解三类病一次治好。

**理由一：解的计数守恒。** 第 4 章 Extension 定理说丢解只发生在首系数例外集上；射影化之后，「例外」也有了去处。最朴素的例子：$x^2 + a = 0$ 随 $a$ 变化，实数世界解数在 $2$ 与 $0$ 之间跳（$a < 0$ 两个、$a > 0$ 零个）；复数世界永远是 $2$ 个（计重数），一个不多一个不少。方程组的「解的总数＝次数乘积」在射影、代数闭的世界里成为**不变量**：参数扰动时解不会凭空消失，只会沿连续路径移动或在无穷远处进出。Bézout 是这条守恒律对曲线交点的特例，而它反过来是数值代数几何的基石——同伦延拓法从「易解系统」走到「目标系统」，路径总数就取 $m \times n$（§6.3 软件段再遇）。

**理由二：紧性与它的代数影子。** 经典拓扑里：实射影直线是圆（§5.1 亲手粘过），实 $\mathbb{P}^n$ 是紧的；复 $\mathbb{P}^n$（把 $\mathbb{C}^{n+1} \setminus \{0\}$ 模掉缩放）是紧的，而仿射空间 $\mathbb{C}^n$ 永远不紧——无穷远敞着口。紧性的代数影子叫**完备性**（completeness）：射影簇在多项式映射下的像仍是（射影）闭的。对照第 4 章 §4.1 的病：仿射簇投影可以不闭（$\{x \ne 0\}$ 那个洞）；射影簇的投影是**闭映射**，洞无处可逃。完备性的另一个可陈述推论：

> 射影簇上的处处正则函数只有常数。（读法：$\mathbb{P}^1$ 上想造一个「处处有定义」的有理函数 $F/G$（${F, G}$ 同次齐次），$G$ 的每个零点都得被 $F$ 的零点抵消，齐次多项式做不成这种事——除非 $F/G$ 是常数。仿射世界随手写 $f(x) = x$，处处正则又非常数。）

（读法：这就是「射影簇像紧空间」的代数表述——紧空间上的连续实函数有界且取到最值，射影簇上的正则函数干脆只有常数，比紧还严。）

**理由三：齐次性消灭特权点。** 仿射世界有一个特权点——原点，以及一个特权方向集——无穷远；射影世界把「有限」与「无穷」平权处理：$\mathbb{P}^n$ 的 $n + 1$ 张坐标卡地位完全对称，任何一张都可以当「仿射片」，其余部分的「无穷远」只是别的卡的日常。这不仅是美学：齐次坐标下缩放自由度天然匹配「模型只定到常数倍」的场合——齐次化让消去、结式、Gröbner 基整套机器在无穷远处继续运转（§5.3 的结式验重数就是例子）。第 4 章参数化漏掉的 $(-1,0)$，在射影图景里是 $t = \infty$ 的正常取值——参数空间自己就该是 $\mathbb{P}^1$，漏点不过是用仿射卡硬塞的副作用。

**本节小结**：射影世界治好三类仿射病：解数守恒（Bézout 与同伦延拓的路径计数）、投影保闭（完备性；正则函数只有常数）、点与方向平权（齐次坐标无特权卡）。到此本册的代数装备与几何舞台都齐了——末章看这套装备开进统计，然后清点出口。

## $\rm \S \, 5.6$ 程序段：Bézout 算例与重数验证

主算例与重数账本的可复跑版本：

```python
from sympy import symbols, groebner, resultant, Matrix, Rational

X, Y, Z, x, y = symbols('X Y Z x y')

# 1. 两圆锥曲线：Z = 1 卡上求交
C1 = x**2 + y**2 - 1
C2 = x**2 + x*y + y**2 - 1
G = groebner([C1, C2], y, x, order='lex')
print([str(p.as_expr()) for p in G.polys])
# -> ['y**2 + x**2 - 1', 'x*y', 'x**3 - x']   交点 x in {0, 1, -1}, xy = 0
#    四点: (1,0), (-1,0), (0,1), (0,-1)

# 2. 无穷远卡 Z = 0：齐次联立无平凡解
sol = groebner([X**2 + Y**2, X**2 + X*Y + Y**2], Y, X, order='lex')
print([str(p.as_expr()) for p in sol.polys])
# -> ['Y**2 + X**2', 'X*Y + X**2']  复数域上 Y = ±iX 代入第二式给 ±i*X**2 = 0
#    强迫 X = 0、Y = 0 —— 无穷远无交点

# 3. 横截性：四个交点的梯度行列式
g1 = Matrix([[2*x, 2*y], [2*x + y, x + 2*y]]).det()   # = 2*x**2 - 2*y**2
for pt in [(1, 0), (-1, 0), (0, 1), (0, -1)]:
    print(pt, g1.subs({x: pt[0], y: pt[1]}))
# -> (1, 0) 2   (-1, 0) 2   (0, 1) -2   (0, -1) -2   全非零：重数全 1，4 = 2*2

# 4. 切线的二重性：结式给 X**2
print(resultant(X**2 + Y**2 - Z**2, Y - Z, Z))   # -> X**2，切点 [0:1:1] 重数 2

# 5. 平行线在无穷远相遇
G5 = groebner([Y, Y - Z], Z, Y, X, order='lex')  # y = 0 与 y = 1 的齐次式
print([str(p.as_expr()) for p in G5.polys])
# -> ['Y', 'Z']  交点 Y = Z = 0，即 [1:0:0]
```

读程序的三句话：卡内求交用仿射坐标、无穷远单独开卡清点，两笔账合并才数得全；梯度行列式是「重数 $= 1$」的廉价证书，非零即横截；结式的幂次泄露重数——$\mathrm{Res} = X^2$ 的平方就是那条二重账。

## $\rm \S \, 5.7$ 六问参考答案

1. 点＝等价类＝过原点的直线，「只记比例」因此 $[1:2:3] = [2:4:6]$；齐次多项式满足 $F(\lambda x) = \lambda^d F(x)$，取零与否不受缩放影响，「$F = 0$」于是对等价类有意义。（§5.1）
2. $U_0 = \{x_0 \ne 0\}$ 坐标 $t = x_1/x_0$，$U_1 = \{x_1 \ne 0\}$ 坐标 $s = x_0/x_1$；重叠处 $t = 1/s$。$U_0$ 是仿射直线，$U_1$ 补上唯一漏点 $[0:1]$；$t$ 从两侧跑向无穷时逼近同一点，两端粘合成圆。（§5.1、§5.2）
3. 总次数 $d$ 的多项式逐项补 $X_0$ 的幂凑齐 $d$ 次；$y - x^2$ 齐次化为 $YZ - X^2$（即 $YZ = X^2$）。与 $Z = 0$ 联立给 $X^2 = 0$：交点 $[0:1:0]$，重数 $2$——抛物线两臂在无穷远汇合且相切。（§5.2）
4. 三个前提：$k$ 代数闭、两曲线无公共分支、交点按重数计数；结论 $\sum_p I(p, C \cap D) = mn$。算例中无穷远卡上联立 $X^2 + Y^2 = 0$ 与 $X^2 + XY + Y^2 = 0$，代入 $Y = iX$ 得 $iX^2 \ne 0$，只有平凡解——无穷远无交点，$4$ 点全在有限卡内。（§5.3）
5. 依次为 $2, 2, -2, -2$。它验证「计重数」里每个交点取最小值 $1$：梯度不共线即横截、即重数 $1$，于是总和恰为 $4 = 2 \times 2$。（§5.3）
6. 说明射影簇的完备性（紧性的代数影子）；同一性质的另一面是「射影簇的投影是闭映射」——第 4 章 $\{x \ne 0\}$ 那个洞在射影世界无处可逃，投影像自动闭。（§5.4）
