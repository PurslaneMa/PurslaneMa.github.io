# $\rm Chapter \, R1$ 复习总结：组合学

> 组合学册二十章三线结构：第 1—8 章「精确线」（双射与符号反转、形式幂级数语法、Lagrange 反演、恒等式与反演、容斥与 Möbius、Burnside、树、格路与核方法）；第 9—12 章「渐近与谱线」（奇点分析、奇点摄动、邻接谱、扩张图）；第 13—14 章「天花板线」（Sperner/Dilworth/Ramsey 与概率方法、秩方法与收束）＋分析方法进阶（第 15—16 章：鞍点与 Hayman、Mellin 与 Tauberian）＋天花板机的四件新兵器（第 17—20 章：加性组合、多项式方法、Lovász 局部引理、熵方法与 Shearer）＋伪随机性的分层尺（第 22 章：Gowers 范数把「像不像随机」按 AP 阶数逐层定价）。全册一句话：**翻译、对消、独裁——把组合翻译成更好算的语言，让重复互相湮灭，让指数尺度上的主导者说话**。本章不教新东西：先合上书作答 §R1.2 的 37 道题，再到 §R1.6 核对。

## $\rm \S \, R1.1$ 本章任务

二十章压成三句话：**符号机**（第 1—8 章）把对象家族编码成代数表达式，禁令与结构全部语法化；**显微镜**（第 9—12 章）读奇点与特征值，把「巨大 $n$」的问题压缩成主项与谱隙；**天花板机**（第 13—14 章）用双计数、概率与维数回答「最多多大」「存在吗」，第 17—20 章给它加装四件新兵器——和集语法量结构、多项式探针压天花板、局部引理换存在、熵账本记代价；第 22 章给它补上精密齿轮（Gowers 范数把伪随机性按 AP 阶数分层定价，$U^2$ 层闭合 Roth 环路、二次相位逼出幂零零件）。验收标准：闭卷清单 37 题答出几成、§R1.3 九条心智模型能默几条，三机就取回多少。

## $\rm \S \, R1.3$ 核心心智模型复读

1. **翻译优先**（第 1、2、14 章）：数不出来就换名片、整族对象就上语法表、组合禁令就编成向量——「翻译」是三机的共同第一步。
2. **对消**（第 1、4、5、8 章）：符号反转引理是母版，容斥、反射、LGV 都是「造对合 + 数幸存者」的定制版；幸存者少的地方就是数学发生的地方。
3. **独裁**（第 9—12 章）：指数尺度上唯一主导者说话——最近奇点给增长底、最大特征值给共振；次主导者只付误差。
4. **语法先行**（第 2、10 章）：构造直接翻译成运算（SEQ/SET/CYC、$u$ 记号笔）；推导完成之后剩下的都是算法或查表。
5. **对偶即等价**（第 5、11、12、13 章）：$\zeta$-$\mu$ 互逆、谱隙-瓶颈（Cheeger）、宽度-链覆盖（Dilworth）——同一事实的两种语言，选便宜的一边算。
6. **存在 ≠ 构造**（第 13、14 章）：概率方法证明存在、秩方法给显式天花板；两者的差距（Ramsey 指数常数）是领域最深裂缝。
7. **局部稀疏换全局存在**（第 19 章）：union bound 把局部牵连错算成全局牵连，报出的废数不等于不可能；只要「爆炸概率 × 通信成本」压在 $\frac{1}{\mathrm{e}}$ 以下，全避开路线就存在——Moser–Tardos 再把「存在」翻成「平均每事件常数次重采样」的算法。
8. **熵是信息的会计**（第 20 章）：给组合对象装均匀分布，$|A|$ 翻译成 $2^{H}$；链式法则让账本允许负项（条件熵），Shearer 说分头记账的总额不低于覆盖次数倍的总账——投影不等式、和集下界、独立集界全是同一本账的三种记法。
9. **伪随机性是分层的，每层一把尺**（第 22 章）：白话：随机集自己就是 AP 制造机，「无 AP」是极端反随机的要求，得先给「像不像随机」定价，定价尺是 Gowers 范数族：$U^2$ 是 Fourier 的化身（管 3-AP），$U^3$ 起离开 Fourier 的世界（管 4-AP 及以上）；多项式相位按次数分层现形、范数按层数收网，AP 每长一项裁判范数升一层，Szemerédi 的 $k$ 越大筛网越深。与册内其他线的关系：它是第 17 章 Fourier 与密度增量的升级包、第 21 章 Roth 定理的精密齿轮。

## $\rm \S \, R1.5$ 易混点对照

1. **OGF vs EGF**（第 2 章）：无标号乘法纯分步；有标号乘法带标号分配，除 ${n!}$ 吸收二项式因子——选错记号是计数题第一大坑。
2. **容斥 vs Burnside**（第 5、6 章）：偏序排除用 Möbius、群合并用 Burnside；两者都处理「重复记账」但病不同——一个是「约束重叠」、一个是「对称重复」。
3. **精确 vs 渐近**（第 2、9 章）：有理 GF 两头都强（部分分式给精确指数和）；代数 GF 只有渐近路（奇点），精确系数要靠核方法或反演另算。
4. **谱隙 vs 组合扩张**（第 12 章）：Cheeger 双向钉死但常数因子互损；算谱容易、算 $h$ 难（NP 难），实践中永远用谱代劳。
5. **概率存在 vs 显式构造**（第 13、14 章）：$2^{k/2}$ 非构造对 $2^{ck}$ 显式——指数相同量级、常数差距半个世纪没追平；「哪个都行」的场合默认选概率路线。
6. **${2A}$ vs $2 \cdot A$**（第 17 章）：$2A = A + A$ 是和集（两袋数互相泼洒），$2 \cdot A = \{2a\}$ 是标量伸缩（$|2 \cdot A| = |A|$ 恒成立）；等差数列的 $|2A| = 2k - 1$ 与 Sidon 集的 $\frac{k(k+1)}{2}$ 都是前者的账，写错一个点号就把结构题读成平凡题。
7. **union bound vs Lovász 局部引理**（第 13、19 章）：前者对全部坏事件一视同仁求和、只认 $np$，后者只认依赖图的度数 $d$；$n = 10^8$、$p = 10^{-7}$ 时 union bound 报 $\Pr \le 10$ 的废数，而独立情形真值 $\approx \mathrm{e}^{-10} > 0$——「过估」不是「灭顶」，两者的落差正是 LLL 的生存空间。
8. **联合独立 vs 两两独立**（第 19 章）：依赖图要求 $A_i$ 与邻居之外整族事件的任意交并组合脱钩（对一切 $B_j \in \{A_j, \overline{A_j}\}$），逐对独立远不够；关键引理的情形一靠联合独立把条件概率剥回 $\Pr(A_i)$，换成两两独立这一步就断。
9. **条件不减的「平均」vs「逐分支」**（第 20 章）：$H(X \mid Y) \le H(X)$ 是按 $p(y)$ 加权后的平均语句，具体分支 $H(X \mid Y = y)$ 完全可以超过 $H(X)$；Shearer 引理同样是平均意义——误记成「求和在内、系数 $\frac{1}{r}$」时，$X_2 = X_1$ 一个反例就把 1 比特与 2 比特的方向打翻。

## $\rm \S \, R1.6$ 答案与提示

### 闭卷回忆清单

1. 定符号 → 造反转对合 → 刻画不动点 → 求幸存者和；失灵点是临界阶梯（$s = k$ 与 $s = k+1$ 两种构形、$k$ 两个方向），精确对应非线性项。（§1.3–1.4）
2. 相等 = 系数逐位相等；卷积第 $n$ 系数 $n+1$ 项有限；常数项非零可逆（逐位递归构造）。（§2.1）
3. $\exp \widehat{A}$ 与 $\ln \frac{1}{1-\widehat{A}}$；排列 EGF $= \exp \ln \frac{1}{1-z} = \frac{1}{1-z}$，系数 ${n!}$ 与排列数吻合。（§2.3）
4. $[z^n]T^k = \frac{k}{n}[u^{n-k}]\Phi^n$；四步 = 残差化、换元 $z = u/\Phi(u)$、分部吸收 $\Phi'$、合并因子。（§3.3）
5. 最后一个最低点保证窗口内不再回到最低值（第一个可能再次触底、旋转前缀和出现 0）。（§3.4）
6. GF 态：$\mathrm{e}^{\pm z}$ 互逆；对合态：对称差最小元素翻转、幸存 = 指定集恰为坏点集。（§4.3）
7. $\mu(x,z) = -\sum_{x \le y < z}\mu(x,y)$；子集格 $(-1)^{|S \setminus T|}$、整除格即数论 Möbius（平方因子清零、$(-1)^{\omega}$）。（§5.2–5.3）
8. 第 $i$ 位归「位 $i$ 去留」独立叠加、路径唯一；秩变量使 $\sum|T_i| \ge |\bigcup T_i|$ 的等号成为唯一贡献，$\exp/\ln$ 在秩分层里做不交化。（§5.4）
9. 逐阈值记账 + 指示函数恒等式；期望版只依赖线性性，不要联合分布。（§5.5）
10. 数 $\{(g,x) : gx = x\}$ 两本账；轨道-稳定子给「每轨道贡献 $|G|$」的第二本账。（§6.2）
11. 旋转 $s$ 的循环数 $= \gcd(n,s)$，按 $\gcd$ 归组计数 $\varphi(n/d)$。（§6.4）
12. 最小叶删除写序列 / 候选叶配对读序列；出现次数 = 度数减一。（§7.1）
13. $BB^{\mathsf T} = L$、森林引理、Cauchy–Binet 平方和；环 → 环上 $\pm1$ 组合零向量、树 → 叶消去行列式 $\pm1$。（§7.3）
14. $t_w \cdot \prod_v (\mathrm{out}(v) - 1)!$；每顶点最后一次离开的边构成入向树形图。（§7.4）
15. 前缀关于红线镜像、与平移后的自由路径双射；「第一次」保证双射可逆（多触点会多对一）。（§8.2）
16. 定义展开、最小编号 $+$ 最小 $j$ $+$ 第一公共点的对合、平面单调性逼 $\pi = \mathrm{id}$。（§8.4）
17. 整理成「未知 × 核 + 常数 = 0」直接除；未知量跨层纠缠（边界项含另一未知）时才动用小根杀项。（§8.5）
18. 部分分式 → $a_n = \sum c_i \rho_i^{-n}$（重根添多项式）；$|\rho|$ 最小者独裁、其余指数消失。（§9.2）
19. $\Delta$ 域 + $F \sim c(1 - z/\rho)^{-\alpha}$ 则 $[z^n]F \sim c\rho^{-n}n^{\alpha-1}/\Gamma(\alpha)$；位置换增长、类型换多项式、次近奇点付误差。（§9.5）
20. $E = -n\frac{\rho'}{\rho} + O(1)$、$\mathrm{Var} = n[-(\ln\rho)'' - \frac{\rho'}{\rho}] + O(1)$；常值参数必须给出零方差（二叉树叶子例）。（§10.2–10.3）
21. 正交分解 → 特征比值独裁 → $L_2$ 压 TV；Cheeger 用居中指示向量（跨边差恒 1、分母 $|S|(1 - |S|/n)$）。（§12.1–12.2）
22. 极大链双计数给 $\sum \frac{1}{\binom{n}{|A|}} \le 1$；König 覆盖-匹配互转；$E = \binom{n}{k}2^{1-\binom{k}{2}} \le \frac{2^{k/2+1}}{k!} < 1$。（§13.1–13.3）
23. $A(r_n)$ 给最大项总量级、$r_n^{-n}$ 还原坐标、$1/\sqrt{2\pi b(r_n)}$ 是 Gaussian 峰宽折扣；教训：鞍点位置的渐近近似会被 $r^{-n}$ 指数放大成常数级误差，三个量必须用精确值。（§15.2、§15.4）
24. 反演公式按 $k$ 求和得 $\sum (k/n)^{-s} = n^s\zeta(s)$——采样求和在频域就是乘 $\zeta$；Karamata 假设 = 实轴行为＋$a_k \ge 0$、产出 = 部分和主项；奇点分析付复邻域门票、给 $a_n$ 全展开。（§16.3–16.4）
25. $|2A|$ 小（接近 $2k-1$）说明集合里几乎没有加法自由度，只能是广义等差级数这类刚性结构；$3k-4$ 定理：$|A|=k$、$|2A| \le 3k-4$ 时 $A$ 装进等差级数。（§17）
26. 给组合断言配一台低次多项式机器：在禁止点全部消没、在自己点非零，再用维数账（切片维数 + 单峰性）压出上界；cap set 的 $2.756^n$ 来自 $\mathbb{F}_3^n$ 切片维数与 EG 构造。（§18）
27. 对每个 $x \in A - C$ 固定一个表示 $x = a_x - c_x$，令 $\Phi(x, b) = (a_x - b,\ b - c_x)$；单射的收回阶段 $u + v = x$ 先识别 $x$（随之收回固定的 $a_x, c_x$），再由 $u = a_x - b$ 收回 $b$——「固定表示」就用在这一步，不钉死则同一 $x$ 的两个表示让单射断裂。$B$ 换成 $-B$ 得工作马 $|A - C| \le \frac{|A+B||B+C|}{|B|}$，取 $B = C = A$ 即 $|A - A| \le \frac{|2A|^2}{|A|} = K^2|A|$——倍增常数平方控制差集。（§17.3）
28. 放大率 $D_j = \min_{\varnothing \ne Z \subseteq A}\frac{|Z + jB|}{|Z|}$ 满足 $D_{i+j} \le D_i D_j$，故 $|A+B| \le K|A|$ 时存在 $X \subseteq A$ 使 $|X + mB| \le K^m|X|$；最优汇率属于「最顺手的子集」，全集 $A$ 未必享受。密度增量：反设无三项级数，用 Fourier 找局部超密的子舞台，密度每层升 $c\delta^2$、升 $O(1/\delta)$ 层爆过 1；每层付一个对数，深度 $1/\delta$ 层就是 $\ln\ln N$ 屏障的来历——Sanders 2011 的 $N(\ln\ln N)^5/\ln N$ 贴住屏障，Bloom–Sisask 2020 的 $N/(\ln N)^{1+c}$ 首次破屏障，Kelley–Meka 2023 到 $N\mathrm{e}^{-c(\ln N)^{1/12}}$；下界一侧 Behrend 给 $N\mathrm{e}^{-C\sqrt{\ln N}}$。（§17.5–17.6）
29. $\Pr[P = 0] \le \frac{d}{|S|}$：按 $x_1$ 的**最高次**系数 $P_k$ 分情况——$P_k \ne 0$ 时条件概率 $\le \frac{k}{|S|}$，$P_k = 0$ 由归纳假设 $\le \frac{d-k}{|S|}$，两类相加恰为 $\frac{d}{|S|}$。Chevalley–Warning：$f_i^{q-1}$ 在 $f_i \ne 0$ 处为 1、$f_i = 0$ 处为 0，故 $P = \prod_i(1 - f_i^{q-1})$ 是公共零点的指示器，$N \equiv \sum_x P(x) \pmod p$；$\deg P = (q-1)\sum \deg f_i < n(q-1)$ 使每个单项式必有某变量次数 $< q-1$，幂和引理令其总和为零，故 $N \equiv 0$；再添 $f_i(0) = 0$（原点是公共零点）则 $N \ge p \ge 2$——除原点外还有非平凡零点。（§18.3–18.4）
30. $|K| \ge \binom{n+q-1}{n} \ge \frac{q^n}{n!}$。五步：欠定造非零消没多项式 $P$（$\deg \le d_0$）→ $d_0 \ge q$ 时最小性直接给下界收工 → $d_0 \le q-1$ 时保证次数恰 $d_0$、取首齐次部分 $P_{d_0}$ → 每个方向的整线 $\{a + tu\}$ 上 $g(t) = P(a+tu)$ 有 $q$ 个根却次数 $< q$，故 $P_{d_0}(u) = 0$ 对每个方向成立 → 指数各 $\le q-1$ 的单项式是函数空间的基，基成员作为函数恒零只能恒为零，矛盾。首齐次部分承载全部组合信息、低次项只是陪跑；与 Graham–Pollak 同属「代数不变量压住组合对象」纲领，升级点是天花板从环境维数换成次数预算换算的 $\binom{n+d}{n}$。（§18.6）
31. 重音在「联合」：对避开邻居的任意 $S$ 与任意 $B_j \in \{A_j, \overline{A_j}\}$，$\Pr\big(A_i \cap \bigcap_j B_j\big) = \Pr(A_i)\Pr\big(\bigcap_j B_j\big)$；标准构造 = 独立随机变量 + 共享变量才连边。$p$ 是单颗地雷的爆炸概率、$d$ 是通信度数、$\mathrm{e}$ 是归纳余量的常数化身。阈值：k-SAT 的 $d \le \frac{2^k}{\mathrm{e}} - 1$（$p = 2^{-k}$）、Property B 的 $d \le \frac{2^{k-1}}{\mathrm{e}} - 1$（$p = 2^{1-k}$，坏事件是「边单色」翻倍）、有限域避零的 $\mathrm{e}\frac{D}{q}\bigl(r(L-1)+1\bigr) \le 1$（坏概率 $\frac{D}{q}$ 由 Schwartz–Zippel 外包定价）。（§19.2、§19.5–19.7）
32. 三步 = 对任意避免集 $S$ 归纳陈述、从 $S \cap \Gamma(i)$ 挑 $j$ 约因子、链式展开收口。约掉 $(1 - x_j)$ 的前提是它在分子的乘积 $\prod_{\Gamma(i) \setminus T}(1-x_k)$ 里出场，即 $j \in \Gamma(i)$；随手挑 $j \notin \Gamma(i)$ 则商多出因子 $\frac{1}{1-x_j}$，归纳封不上口。$x(1-x)^d$ 在 $x = \frac{1}{d+1}$ 取最大（求导 $d(1-x)^{d-1}\bigl(1 - (d+1)x\bigr) = 0$），由 $\left(\frac{d}{d+1}\right)^d \ge \mathrm{e}^{-1}$ 得 $x(1-x)^d \ge \frac{1}{\mathrm{e}(d+1)} \ge p$；链式展开逐因子用引理右半，全避开概率 $\ge (1-x)^n > 0$。（§19.3）
33. 三行：全部变量独立随机抽样；有事件发生则任取其一、重抽它的 $\mathrm{vbl}(A_i)$；重复到无事发生。定理：非对称 LLL 条件下以概率 1 终止，每个 $A_i$ 的期望重采样次数 $\le \frac{x_i}{1-x_i}$（对称情形 $n\frac{x}{1-x}$）。事故树两要点：一棵树出现的概率只由树形决定、期望树数被 $\sum_i \frac{x_i}{1-x_i}$ 压住；每次实际重采样对应互不相同的事故树（时间戳标记），故重采样次数被树数压住。Lopsided 版把对称独立放宽为「不落井下石」$\Pr\big(A_i \mid \bigcap_{j \in S}\overline{A_j}\big) \le \Pr(A_i)$，随机置换的 $\sigma(i) = j$ 型互斥事件由此过关。模拟锚：250 对 3-子句、$d = 1$，$10^4$ 次运行总重采样均值 $62.46$（中位 62、最大 98），理论上界 $500 \times (3 - 2\sqrt2) \approx 85.8$。（§19.8）
34. 四条性质 = 非负（每项 $-p_x\log_2 p_x \ge 0$）、链式法则 $H(X, Y) = H(X) + H(Y \mid X)$、条件不减 $H(X \mid Y) \le H(X)$（由子可加性）、独立则加——全部由定义与一次 Gibbs 不等式 $\sum_i p_i\log_2\frac{p_i}{q_i} \ge 0$ 导出；支集上界 $H(X) \le \log_2|\mathrm{supp}(X)|$ 取 $q$ 为支集上的均匀分布。正确形式：每个下标恰被覆盖 $r$ 次时 $\sum_j H(X_{S_j}) \ge r\,H(X_{[m]})$——求和在外、乘子 $r$ 站在下界一侧；误记成 $H(X_{S_1}, \ldots, X_{S_k}) \ge \frac{1}{r}\sum_i H(X_i)$ 时，取 $X_2 = X_1$、$S_1 = \{1,2\}$、$r = 1$：左边 $H(X_1, X_2) = 1$ 比特、右边 $2$ 比特，荒谬。证明 = 引理 A（条件越多熵越少）+ 引理 B（对 $k$ 归纳的加权摊账）+ 链式法则收拢。（§20.2–20.3）
35. 四步：总账 $H(X) = \log_2|A|$；族 $S_i = [3]\setminus\{i\}$ 每个下标被覆盖 2 次，Shearer 给 $\sum_i H(X_{S_i}) \ge 2\log_2|A|$；每份快照的支集落在对应投影里，$H(X_{S_i}) \le \log_2|\pi_i|$；合并取 2 的幂得 $|A|^2 \le |\pi_{xy}||\pi_{xz}||\pi_{yz}|$（一般 $|A|^{d-1} \le \prod_i|\pi_i|$）。和集界：固定 $X$ 后 $Y \mapsto X + Y$ 是双射，链式法则给 $H(X, X+Y) = H(X) + H(Y)$，子可加性约去 $H(X)$ 得 $H(X+Y) \ge \max\bigl(H(X), H(Y)\bigr)$；纤维恒等式 $H(X+Y) = H(X) + H(Y) - H(X \mid X+Y)$——损失在纤维里的恰是「知道和之后关于 $X$ 的悬念」；合并支集上界得 $|A+B| \ge |A||B|\,2^{-H(X \mid X+Y)}$，罚项按平均纤维悬念计、比最大纤维界更准（$A = B = [6]$：熵界 $9.68$、最大纤维界 $6$、真值 $11$）。（§20.4–20.5）
36. LLL 吃依赖图稀疏、出存在性（正概率非空）；多项式方法吃全局代数刚性（低次函数空间的维数账）、出不可能性上界；熵方法吃覆盖性、出计数型不等式（上下界通吃）。cap set 里每个三点组与海量邻居耦合、依赖图稠密，LLL 无从下口，而且存在性工具给不出「任何 cap set 都长不过 $2.7551^n$」这种天花板；k-SAT 要的是「某个赋值避开关卡」，维数账只会说「某个代数对象装不下禁止结构」，对「随机赋值 + 局部坏事件」没有接口。选型口诀：问「能不能避开」找 LLL，问「必须付多少信息」找熵账本，问「好集合最多多大」找维数账。（§19.7、§20.7）
37. 定义：$\|f\|_{U^k}^{2^k}$ 是 $k$ 维加性立方体顶点的交替乘积（离原点奇数步取共轭）对全部 $x, h_1, \ldots, h_k$ 的平均；递归 $\|f\|_{U^{k+1}}^{2^{k+1}} = \mathbb{E}_h\,\|\Delta_h f\|_{U^k}^{2^k}$（$\Delta_h f = f(y+h)\overline{f(y)}$ 是乘法导数），非负性由递归归纳、三角不等式由 Gowers–Cauchy–Schwarz 兜底；$U^1$ 只看均值（半范数），塔从 $U^2$ 起算，$k \ge 2$ 单调递增（噪声地板随层数抬高）。（§22.2）主恒等式 $\|f\|_{U^2}^4 = \sum_\xi |\hat f(\xi)|^4$，三步＝平行四边形换元（第四顶点被 $b + c - a$ 钉死）＋代入反演式按变量归并字符＋正交性逼四个频率同一个 $\xi$；推论一 $\max_\xi |\hat f(\xi)| \le \|f\|_{U^2} \le \bigl(\max_\xi |\hat f(\xi)|\,\|f\|_{L^2}^2\bigr)^{1/2}$，逆 $U^2$ 两方向损耗指数 $1$ 与 $2$、几乎免费，「$U^2$ 就是 Fourier」是定理不是比喻。（§22.3）二次相位两个计算：三重差分把 $x^2$ 逐层降为 $2h_3x \to 2h_2h_3 \to 0$，每个立方体乘积 $\mathrm{e}(0) = 1$，$\|q\|_{U^3} = 1$ 顶格（$U^4$ 以上也顶格）；$U^2$ 层立方体乘积 $\mathrm{e}(2h_1h_2/N)$ 对 $h_2$ 平均被正交性杀掉，$\|q\|_{U^2}^4 = 1/N$（$N$ 奇），与独立随机相位同落噪声地板（频谱侧能量平铺在约 $N/2$ 个频率上）。（§22.4 第 5 条）读法：它把 4-AP 计数撑离基线（实测约 $6\%$）而一切 Fourier 系数都是噪声量级，逆 $U^3$ 必须到 Fourier 之外找零件（二次相位、Green–Tao 的 2-步幂零序列；$U^2$ 的逆是恒等式免费，往上每层要付结构定理的价钱）。Roth 环路：$1_A = \delta + g$ 展开给 $\delta^3 + \Lambda_3(g,g,g)$，无 3-AP 强制 $|\Lambda_3| \ge \delta^3/2$；控制（两次 Cauchy–Schwarz 的模型版）给 $\|g\|_{U^2} \ge \delta^2/2$，逆 $U^2$ 给 $\max_{\xi \ne 0}|\hat g(\xi)| \ge \delta^{7/2}/4$；与非平凡线性相位相关则子级数密度上升、每轮把舞台长度开一次平方，密度涨 $\delta$ 的多项式轮就爆过 1（$r_3(N) \ll N/\ln\ln N$ 的双对数即复利）。（§22.4 第 2、4 条）
