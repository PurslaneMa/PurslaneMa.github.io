## $\rm \S \, 3.1$ 蝴蝶效应：敏感依赖的数值现场

白话：**蝴蝶效应说的是——初始数据里一粒尘埃大的差别，过一阵子被放大成一场风暴的差别**。Lorenz 在 1963 年的流体对流模型里第一次撞见它：两次计算只差小数点后第 4 位，几周后天气图完全分道扬镳（Lorenz, *J. Atmos. Sci.* 20, 1963）；十年后他把这现象讲成那个著名的题目——巴西的蝴蝶扇一下翅膀，会不会在德克萨斯掀起龙卷风。数学上，这个现象叫**敏感依赖初值（sensitive dependence on initial conditions）**：存在一个正数，使任意靠近的两条轨道迟早被拉到明显分开的位置。

logistic 映射把这个现象演得干净利落。取两条轨道，初值只差 $10^{-8}$：$x_0 = 0.40000000$ 与 $x_0 = 0.40000001$，逐拍量它们的距离 $|x_n - y_n|$（本章数值锚，照抄）：

| $n$ | $r = 2.5$ 的距离 | $r = 4.0$ 的距离 |
| --- | --- | --- |
| $0$ | $1.00 \times 10^{-8}$ | $1.00 \times 10^{-8}$ |
| $5$ | $3.13 \times 10^{-10}$ | $5.21 \times 10^{-8}$ |
| $10$ | $9.77 \times 10^{-12}$ | $9.56 \times 10^{-6}$ |
| $15$ | $3.05 \times 10^{-13}$ | $2.28 \times 10^{-4}$ |
| $20$ | $9.66 \times 10^{-15}$ | $9.47 \times 10^{-3}$ |
| $25$ | $3.33 \times 10^{-16}$ | $7.14 \times 10^{-2}$ |
| $30$ | $0$（完全重合） | $5.38 \times 10^{-1}$ |

（读法：$r = 2.5$ 时距离每拍减半——$5$ 拍后恰为 $0.5^5 \times 10^{-8} = 3.125 \times 10^{-10}$，与表逐位吻合——两条轨道 $30$ 拍内合并成一条；$r = 4.0$ 时距离每拍**翻倍**，$25$ 拍放大 $700$ 万倍，$30$ 拍达到区间尺度的一半——两条轨道已成两个世界。）同一个函数、同一对初值，旋钮位置决定差别是被抹平还是被放大，放大的倍率就是下一节要计算的量。

**本节小结**：敏感依赖是「任意小的初值差别被放大到宏观尺度」；logistic 映射在 $r = 2.5$ 处每拍把初值差别减半（抹平），在 $r = 4$ 处每拍翻倍（放大）——倍率随参数改变，需要名字与算法。下一节定义李雅普诺夫指数。

## $\rm \S \, 3.2$ 李雅普诺夫指数：把放大倍率变成一个数

给「每拍放大几倍」立个账本。设两条轨道从 $x_0$ 与 $x_0 + \epsilon$ 出发，$n$ 拍后的距离由链式法则精确给出：

$$
x_n - y_n = \big(f^{n}(x_0 + \epsilon) - f^{n}(x_0)\big) \approx \big(f^{n}\big)'(x_0)\,\epsilon = \prod_{i=0}^{n-1} f'(x_i)\,\epsilon
$$

（读法：$n$ 拍的总伸缩率是**逐拍伸缩率的连乘**——每一拍经过 $f'(x_i)$ 这个放大镜，走完全程乘成一总账；这与第 1 章周期轨道乘子的连乘是同一件事，只是现在逐拍、全程都算。）连乘的分析工具是对数——把乘化加。**李雅普诺夫指数（Lyapunov exponent）**定义为

$$
\lambda(x_0) = \lim_{n \to \infty} \frac{1}{n} \ln \big| (f^{n})'(x_0) \big| = \lim_{n \to \infty} \frac{1}{n} \sum_{i=0}^{n-1} \ln \big| f'(x_i) \big|
$$

（读法：右端是 $\ln |f'|$ 沿轨道的**时间平均**——每拍记录一下当地放大率的对数，长期求平均。$\lambda$ 的单位是「每拍」，它就是偏差的对数增长率：$\lambda > 0$ 时距离平均每拍乘 $e^{\lambda}$，$\lambda < 0$ 时每拍乘 $e^{\lambda} < 1$ 收缩。）

logistic 映射的 $\lambda = \ln|r(1 - 2x)|$ 的长期平均可以直接算或精确算，逐站登记（本章数值锚，照抄；数值列为 $x_0 = 0.4$、丢 $1000$ 拍瞬态、取 $3 \times 10^{5}$ 拍平均的程序值）：

| $r$ | $\lambda$（数值） | 账目来源 |
| --- | --- | --- |
| $2.5$ | $-0.693147$ | 精确：$\ln\lvert 2 - r\rvert = \ln 0.5$（第 1 章乘子判据的时间平均版） |
| $3.2$ | $-0.916291$ | 精确：稳定周期 2 上平均，$\ln\sqrt{0.16} = \ln 0.4$ |
| $3.5$ | $-0.872507$ | 周期 4 上平均：$\ln\big(\lvert{(f^4)'}\rvert^{1/4}\big)$ |
| $3.56$ | $-0.077145$ | 周期 8 上平均，乘子贴 $1$ 故 $\lambda$ 贴 $0$ |
| $3.7$ | $+0.354408$ | 数值平均：混沌区，无周期可挂 |
| $3.9$ | $+0.497003$ | 数值平均 |
| $4.0$ | $+0.693147$ | 精确：$\ln 2$，§3.3 全证 |

（读法：周期区 $\lambda < 0$——轨道安顿进周期，差别被抹平；贴着走廊断点的周期 8 乘子贴 $1$，$\lambda$ 贴 $0$；混沌区 $\lambda > 0$——差别被平均每拍放大 $e^{0.354} \approx 1.43$ 倍。$\lambda$ 的正负号就是「安顿」与「翻脸」的分界线。）

对光滑单峰映射，**$\lambda > 0$ 就是混沌的工作判据**：正指数保证敏感依赖，而敏感依赖加上映射把区间折来折去的混合性，就是教科书意义上的混沌（对一维映射可证 $\lambda$ 与拓扑熵、Kolmogorov–Sinai 熵一致：$h_{KS} = \lambda$，Pesin 恒等式的一维情形）。两个诚实的附注：

1. $\lambda$ 依赖初值：挂在吸引周期轨道上的初值享受轨道的负 $\lambda$；「混沌」说的是**典型初值**（对不变测度几乎处处）取正 $\lambda$。周期窗口内典型初值的 $\lambda$ 就是负的（如 $r = 3.83$ 挂在周期 3 上），窗口是混沌海里的负指数岛。
2. 数值平均要丢瞬态、要足够长：瞬态还没走完就开平均，会把负指数段混进账本；§3.6 程序给出可直接复跑的版本。

**本节小结**：李雅普诺夫指数 $\lambda = \lim \frac{1}{n}\sum \ln|f'(x_i)|$ 把逐拍伸缩率连乘化成时间平均；周期区 $\lambda < 0$（可精确到 $\ln|2-r|$、$\ln 0.4$ 等），混沌区 $\lambda > 0$（$r = 3.7$ 实测 $+0.354$，$r = 4$ 精确 $\ln 2$）；$\lambda > 0$ 是一维映射混沌的工作判据，附注是初值依赖与瞬态处理。下一节解 $r = 4$ 的精确之谜。

## $\rm \S \, 3.3$ logistic 映射 $r = 4$ 的精确解：确定却不可预测

$r = 4$ 是整张分岔图的最右端、混沌最猛烈处，却恰好能**精确求解**。做代换 $x = \sin^2\theta$，三角恒等式当场收敛：

$$
f(x) = 4\sin^2\theta\,(1 - \sin^2\theta) = 4\sin^2\theta\cos^2\theta = \sin^2(2\theta)
$$

（读法：迭代一次等于角度翻倍——$x_n = \sin^2\theta_n$ 里的 $\theta$ 服从 $\theta_{n+1} = 2\theta_n$，迭代 $n$ 次就是乘 $2^n$。于是**精确解**为 $x_0 = \sin^2\theta_0$ 时 $x_n = \sin^2(2^n \theta_0)$，$\theta_0 = \arcsin\sqrt{x_0}$。）

精确解在手，第一件事是**拿它审判数值迭代**。用双精度浮点同时跑「公式 $x_n = \sin^2(2^n\theta_0)$」与「迭代 $x_{n+1} = 4x_n(1 - x_n)$」（$x_0 = 0.4$），逐拍比对误差（本章数值锚，照抄）：

| $n$ | 公式与迭代之差 |
| --- | --- |
| $1$ | $2.22 \times 10^{-16}$ |
| $2$ | $2.50 \times 10^{-16}$ |
| $5$ | $1.98 \times 10^{-16}$ |
| $10$ | $3.63 \times 10^{-14}$ |
| $20$ | $3.59 \times 10^{-11}$ |
| $30$ | $3.43 \times 10^{-8}$ |
| $40$ | $3.84 \times 10^{-5}$ |
| $50$ | $2.52 \times 10^{-2}$ |
| $53$ | $3.37 \times 10^{-1}$ |
| $60$ | $6.83 \times 10^{-1}$ |

（读法：误差从机器精度的 $10^{-16}$ 出发**每拍翻倍**——$10$ 拍到 $10^{-14}$、$20$ 拍到 $10^{-11}$、$30$ 拍到 $10^{-8}$，严格按 $e^{\lambda n} = 2^n$ 增长——$50$ 拍后误差已是宏观量。翻倍率正是 $\lambda = \ln 2$：§3.2 的账本在这里被误差自己念了一遍。）由此得出**可预测性视界**：设误差饱和尺度为 $\Delta \approx 0.5$、初始误差 $\delta_0 \approx 10^{-16}$，则 $n^* \approx \ln(\Delta/\delta_0)/\lambda \approx 36.6/0.693 \approx 53$ 拍——表里 $n = 53$ 处误差恰好冲到 $0.34$，逐位兑现。视界对初值精度只有**对数依赖**：初始精度提高一亿倍（$10^{-16} \to 10^{-24}$，物理测量远做不到），视界只延长 $\ln(10^8)/\ln 2 \approx 27$ 拍。这就是「确定却不可预测」的第一层含义：公式精确，视界有限。

第二层含义藏在角度的账本里。$\theta_{n+1} = 2\theta_n \bmod 1$ 是**倍角映射**：每拍把 $\theta$ 的二进制小数**左移一位**、丢掉移出去的头一位。所以 $x_n$ 的演化就是逐拍「读出 $\theta_0$ 的下一位二进制数字」：

1. 典型初值（$\theta_0$ 是无理数）的二进制数字序列无循环节，轨道永不重复——这正是混沌轨道；
2. 特殊初值（$\theta_0$ 是有理数）数字序列循环，轨道是周期的——混沌海里藏着的全部不稳定周期轨道（第 1 章 Sarkovskii 定理担保它们存在）就是这些「数字循环」的初值；
3. 信息账本：每拍丢掉一位 $\theta_0$ 的信息，$n$ 拍后精度要求 $2^{-n}$——「知道 $x_n$ 反推 $x_0$」的难度指数增长，正的信息流率就是 $h_{KS} = \lambda = \ln 2$ 每拍。

精确解还免费送出 $\lambda$ 的**全证**。$r = 4$ 的不变密度是 $\rho(x) = 1/(\pi\sqrt{x(1 - x)})$（由 $x = \sin^2\theta$、$\theta$ 在 $[0, \pi/2]$ 均匀分布换元而来——换元时 $\rho\,\mathrm{d}x = \frac{2}{\pi}\,\mathrm{d}\theta$，均匀性原样搬运）。对几乎处处的初值，时间平均换成空间平均：

$$
\lambda = \int_0^1 \rho(x)\,\ln|4(1 - 2x)|\,\mathrm{d}x
$$

代入 $x = \sin^2\theta$、$\mathrm{d}x = \sin 2\theta\,\mathrm{d}\theta$：

$$
\lambda = \frac{2}{\pi} \int_0^{\pi/2} \ln|4\cos 2\theta|\,\mathrm{d}\theta = \frac{2}{\pi}\left[\frac{\pi}{2}\ln 4 + \int_0^{\pi/2} \ln|\cos 2\theta|\,\mathrm{d}\theta\right]
$$

（读法：内层积分用 $u = 2\theta$ 化成标准结果 $\int_0^{\pi/2}\ln\cos u\,\mathrm{d}u = -\frac{\pi}{2}\ln 2$ 的两倍对称版。）合并：

$$
\lambda = \frac{2}{\pi}\left[\pi\ln 2 - \frac{\pi}{2}\ln 2\right] = \ln 2
$$

（读法：§3.2 表里 $r = 4$ 一行的 $\ln 2$ 至此从不变密度积分完整推出——数值 $+0.693147$ 与 $\ln 2 = 0.6931471805599453$ 逐位吻合。）

**本节小结**：$r = 4$ 的精确解 $x_n = \sin^2(2^n\theta_0)$ 把迭代化成倍角，精确性与不可预测性并存：误差按 $2^n$ 从 $10^{-16}$ 翻到宏观（视界约 $53$ 拍，对初值精度只对数依赖），倍角映射的二进制移位把轨道变成「逐拍读出初值数字」；不变密度给出 $\lambda = \ln 2$ 的全证。下一节把「混沌不是随机」说清楚。

## $\rm \S \, 3.4$ 混沌不是随机：确定性的指纹

白话：**混沌是「定律很硬 + 放大很狠」，随机是「根本没有定律」**——两者在短期行为上像，在结构上两副面孔。区分的指纹有三枚，每枚都能在 logistic 映射上当场验证：

1. **短期可预测**。混沌视界之内预测能力实打实：$\lambda = \ln 2$ 时头 $20$ 拍误差只从 $10^{-16}$ 涨到 $10^{-11}$——短期预报准、长期预报死，这条「准到第几拍」的界线本身就是 $\lambda$ 算出来的。真随机序列（掷硬币）连头一拍都不可预测：没有 $\lambda$，没有视界公式。
2. **回归图是一条曲线**。把 $\big(x_n, x_{n+1}\big)$ 逐对打点：logistic 映射的点全部落在抛物线 $y = 4x(1-x)$ 上——**下一步是上一步的确定函数**。真随机序列的回归图是一团云。这是时间序列分析里区分「混沌」与「噪声」的第一板斧：能拟合出低维光滑曲线者混沌嫌疑，拟合不出者随机嫌疑。
3. **混沌有统计结构**。$r = 4$ 的轨道看似乱窜，长期频率却严格服从不变密度 $\rho(x) = 1/(\pi\sqrt{x(1-x)})$——两端 $0$、$1$ 附近驻留多，中间驻留少；周期窗口、Sarkovskii 担保的全体周期轨道、$\lambda = \ln 2$ 的熵账，全部是「乱」底下的硬结构。真随机可以服从任何分布，但没有这些由方程逼出来的代数结构。

（读法：§3.3 的二进制移位把两层关系焊死——轨道的「随机相」来自 $\theta_0$ 的数字序列，而数字序列是初值的一部分：**随机性是初值里预装的，不是方程注入的**。方程干的只有一件事：以每拍 $\ln 2$ 的速率把预装信息读出来。所谓混沌，就是确定律把初值的无限信息量逐步曝光的过程。）

天气预报是这套分辨的现实注脚：大气方程确定（定律硬）， $\lambda > 0$（放大狠），于是预报视界有限且只能靠提高观测密度对数式延长——Lorenz 1972 年那道「蝴蝶」之问的数学内核正是本节的三枚指纹。

**本节小结**：混沌与随机的分界在于有没有定律：混沌短期可预测且视界由 $\lambda$ 决定、回归图是光滑曲线、统计结构（不变密度、周期窗口、熵率）由方程逼出；随机的回归图是云、无视界概念。logistic $r = 4$ 的移位图像说明「随机相」预装在初值里，方程只负责逐拍曝光。本章定量骨架到此齐备，下一节清点行李。

## $\rm \S \, 3.6$ 程序段：李雅普诺夫指数与误差翻倍

把 §3.1 到 §3.3 的数值锚变成可复跑的完整程序：

```python
import math

def logistic(r):
    return lambda x: r * x * (1 - x)

def lyapunov(r, x0=0.4, ntrans=1000, n=300000):
    """时间平均法：lambda = (1/n) sum ln|f'(x_i)|，先丢瞬态"""
    f = logistic(r)
    x = x0
    for _ in range(ntrans):
        x = f(x)
    s = 0.0
    for _ in range(n):
        s += math.log(abs(r * (1 - 2 * x)))
        x = f(x)
    return s / n

for r in [2.5, 3.2, 3.5, 3.56, 3.7, 3.9, 4.0]:
    print(f"r={r}  lambda~{lyapunov(r):+.6f}")

# 敏感依赖：dx0 = 1e-8 的两条轨道
for r in [2.5, 4.0]:
    f = logistic(r)
    x, y = 0.4, 0.4 + 1e-8
    row = []
    for n_ in range(31):
        if n_ % 5 == 0:
            row.append(f"n={n_}:{abs(x - y):.2e}")
        x, y = f(x), f(y)
    print(f"r={r}:  " + "  ".join(row))

# r=4 精确解 vs 浮点迭代：误差翻倍与视界
f = logistic(4.0)
x0 = 0.4
theta0 = math.asin(math.sqrt(x0))
x = x0
for n_ in range(61):
    if n_ in (1, 5, 10, 20, 30, 40, 50, 53):
        exact = math.sin((2 ** n_) * theta0) ** 2
        print(f"n={n_:3d}  |iterated - exact| = {abs(x - exact):.3e}")
    x = f(x)
print("horizon estimate: ln(0.5/1e-16)/ln(2) =",
      math.log(0.5 / 1e-16) / math.log(2))
```

## $\rm \S \, 3.7$ 六问参考答案

1. 存在正数使任意近的轨道迟早分开到宏观尺度。表中 $r = 2.5$ 的距离每拍减半、$30$ 拍归零——$\lambda = \ln 0.5 < 0$，差别被抹平；$r = 4$ 的距离每拍翻倍、$30$ 拍达区间一半——$\lambda = \ln 2 > 0$，差别被放大。符号决定命运。（§3.1、§3.2）
2. $\lambda = \lim_{n\to\infty} \frac{1}{n}\ln\big|(f^{n})'(x_0)\big| = \lim \frac{1}{n}\sum \ln|f'(x_i)|$；链式法则把 $n$ 拍伸缩化成连乘，对数把连乘化成可平均的和。不直接平均伸缩率是因为伸缩率是**乘性**的：有的拍放大 $4$ 倍、有的压缩到 $0$，直接平均会被个别大值淹没；对数把乘性账变加性账，平均才有稳定意义。（§3.2）
3. $r = 2.5$：$\ln|2-r| = \ln 0.5 = -0.693147$，挂在不动点上、精确；$r = 3.2$：$\ln\sqrt{0.16} = \ln 0.4 = -0.916291$，挂在稳定周期 2 上、精确；$r = 3.7$：$+0.354408$，混沌区无周期可挂、数值时间平均；$r = 4$：$\ln 2 = 0.693147$，由不变密度积分精确算出（§3.3 全证）。（§3.2、§3.3）
4. 代换给出 $4\sin^2\theta\cos^2\theta = \sin^2 2\theta$，迭代等于角度翻倍，故 $x_n = \sin^2(2^n\theta_0)$。精确解存在说的是公式无近似；不可预测说的是浮点初值携带 $10^{-16}$ 的误差、被每拍翻倍放大，$n^* \approx \ln(\Delta/\delta_0)/\lambda$ 拍后失真到宏观——$r = 4$ 处约 $53$ 拍。视界对初值精度是对数依赖：精度提高 $10^8$ 倍视界只延长约 $27$ 拍。（§3.3）
5. $\theta_{n+1} = 2\theta_n \bmod 1$ 等于把 $\theta_0$ 的二进制小数逐拍左移丢头位：典型无理初值数字不循环即混沌轨道，有理初值数字循环即周期轨道——混沌海里 Sarkovskii 担保的全体周期轨道都有这副「数字循环」面孔。每拍丢一位即信息流率每拍 $1$ 比特，与 $h_{KS} = \lambda = \ln 2$ 一致。（§3.3）
6. 三枚指纹：短期可预测（视界由 $\lambda$ 定，随机序列连一拍都没有）；回归图是光滑曲线（下一步是上一步的确定函数，随机是云）；统计结构由方程逼出（不变密度、周期窗口、熵率）。回归图有效是因为确定性映射强制 $x_{n+1} = f(x_n)$——所有点落在 $f$ 的图像上；这条几何约束随机序列天然不满足。（§3.4）
