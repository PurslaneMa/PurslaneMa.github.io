# $\rm Chapter \, 4$ 持久图的距离与稳定性

前三章的终点是一件战利品：**持久图**——把数据形状里每个洞的「出生尺度 $b$、死亡尺度 $d$」记成平面上的点，全体洞装进一个多重集 $D = \{(b_i, d_i)\}$。但战利品要能用，还差最后一块配件：**两个持久图之间怎么量距离**。有了距离，才能回答「两批数据的形状差多少」「噪声把图挪动了多少」「这个图能不能喂给回归和聚类」。本章把这块配件装上：§4.1 说明为什么需要距离；§4.2 定义瓶颈距离与 Wasserstein 距离，并用两张小图把每个数字真算出来；§4.3 证明本章的主角——稳定性定理，它保证「函数动一点，图只动一点」，是整个 TDA 能当统计工具用的合法性来源；§4.4 把持久图变成可回归、可聚类的函数对象——持久景观；§4.5 清点向量化路线的其余选项。

> 1. □ 持久图的定义：条形码、$(b, d)$ 点对、对角线 $\{b = d\}$ 的含义（本册第 3 章），§4.2 的距离定义直接作用在图上；
> 2. □ Vietoris–Rips 复形（本册第 1 章）与持久同调的条形码算法（本册第 3 章），§4.3 的稳定性定理说的正是「过滤函数变了，图怎么变」；

## $\rm \S \, 4.1$ 为什么持久图之间要量距离

先说清没有距离会卡在哪里。持久图 $D$ 是平面上的一个**多重集**（同一个位置可以落多个点），并且约定：持久 $d - b = 0$ 的点全体缩在对角线 $\Delta = \{(b, d) : b = d\}$ 上，讨论时把对角线当免费原料、任意添加。想比较 $D_1$ 与 $D_2$，朴素做法是逐点比——但两张图点数未必相同、点的顺序没有意义、对角线还无限多点，「逐点」根本无从谈起。

白话：**比较两张持久图，本质上是解一道「最便宜的一一配对」优化题**——把 $D_1$ 的每个点配给 $D_2$ 的一个点（或多出来的丢到对角线上），配错了交罚金，总罚金最省的那套配对方案就定义了距离。罚金怎么收（取最大还是取和），就分出两种距离。

为什么非较这个真不可？三个用途压过来：

1. **统计**：有一批持久图 $D_1, \ldots, D_n$（比如 $n$ 个受试者各算一张），想求「平均形状」、做假设检验——没有距离，平均与检验都是空谈；
2. **防噪**：数据带噪声，算出的图和「干净数据的真图」差多少？答案必须写成不等式，§4.3 的稳定性定理就是这条不等式；
3. **机器学习**：下游模型吃向量不吃图，得先把「图之间的差异」转成「特征之间的差异」，§4.4 与 §4.5 是两条转换流水线。

三个用途共用同一个地基：图上的一种度量。先把地基打好。

**本节小结**：持久图是无序多重集外加一条免费对角线，逐点比较不成立；比较的正规说法是带罚金的最优匹配，这个框架同时托起统计、防噪、机器学习三件事。下一节把罚金规则定出来。

## $\rm \S \, 4.2$ 瓶颈距离与 Wasserstein 距离

设 $D_1, D_2$ 是两个持久图（平面 $\mathbb{R}^2$ 中的多重集）。给每个补位一条规则：$D_1$ 或 $D_2$ 中多出来的点可以**匹配到对角线**，点 $p = (b, d)$ 到对角线的代价是它到 $\Delta$ 的 $L^{\infty}$ 距离：

$$
d(p, \Delta) = \frac{d - b}{2}
$$

（读法：持久的一半——一个活了很短的洞，丢掉它很便宜；持久很长的洞，丢掉代价高昂。这就是对角线当「免费垃圾场」的收费方式。）

**定义（$p$-Wasserstein 距离）**。对 $1 \le p < \infty$：

$$
d_p(D_1, D_2) = \inf_{\mu} \Big( \sum_{p \in D_1} d(p, \mu(p))^p \Big)^{1/p}
$$

（读法：$\mu$ 跑遍所有合法匹配——$D_1$ 的每个点（含对角线补位）与 $D_2$ 的每个点一一配对；方括号里是「每对匹配的 $L^{\infty}$ 罚金的 $p$ 次方之总和」，开 $p$ 次方还原成可比的量纲。取下确界：在一切配对方案里挑总罚金最省的。）

**定义（瓶颈距离）**。取 $p = \infty$ 的极限情形，罚金不求和、只看最贵的一对：

$$
d_{\mathrm{B}}(D_1, D_2) = \inf_{\mu} \sup_{p \in D_1} d(p, \mu(p))
$$

（读法：瓶颈距离只关心**配对方案里最贵的那一对**——木桶装多少水由最短的板决定，配对方案值多少由最贵的对决定。它是 $d_p$ 当 $p \to \infty$ 的极限：总和被最大项吞掉。）

两条性质先立此存照，§4.2 的实算会用到：

1. $d_p$（含 $p = \infty$ 的 $d_{\mathrm{B}}$）是持久图（模掉对角线）上的真度量：非负、对称、三角不等式都成立，且 $d_p(D, D) = 0$；
2. 单调链：对 $1 \le p \le q$ 有 $d_q \le d_p$，且 $d_{\mathrm{B}} \le d_p$ 对一切 $p$ 成立（最大项不超过 $p$ 次幂平均，逐条匹配都是）。

### 实算两张小图

设

$$
D_1 = \{(1, 3),\; (2, 5)\}, \qquad D_2 = \{(1.5, 3),\; (2, 4.5)\}
$$

（读法：两张图各两个点，尺寸相同，没有点必须丢对角线，但「丢对角线」仍是候选方案之一。）枚举全部匹配方案（$2$ 对 $2$ 只有两种本质配法），每一对的罚金是坐标差的 $L^{\infty}$ 范数：

1. **顺配**：$(1, 3) \leftrightarrow (1.5, 3)$ 罚金 $\max(0.5, 0) = 0.5$；$(2, 5) \leftrightarrow (2, 4.5)$ 罚金 $\max(0, 0.5) = 0.5$。瓶颈罚金 $\sup = 0.5$，总和 $0.5 + 0.5 = 1.0$；
2. **叉配**：$(1, 3) \leftrightarrow (2, 4.5)$ 罚金 $\max(1, 1.5) = 1.5$；$(2, 5) \leftrightarrow (1.5, 3)$ 罚金 $\max(1.5, 2) = 2$。瓶颈罚金 $2$，总和 $3.5$。

顺配全胜，所以 $d_{\mathrm{B}}(D_1, D_2) = 0.5$、$d_1(D_1, D_2) = 1.0$。要确认 $0.5$ 真是下确界（而不只是目前见过的最好值），看下界：点 $(2, 5)$ 只有三条出路——配 $(2, 4.5)$ 罚 $0.5$、配 $(1.5, 3)$ 罚 $2$、配对角线罚 $(5-2)/2 = 1.5$；三条路的最低罚金是 $0.5$，任何匹配方案的最贵一对都 $\ge 0.5$，下界与上界咬合。程序复核（全部枚举，含 $W_2$）：

```python
import numpy as np
from itertools import permutations

def diag_cost(p):                       # 点到对角线的 Linf 距离
    return (p[1] - p[0]) / 2.0

def match_cost(p, q):                   # 点到点的 Linf 距离
    return max(abs(p[0]-q[0]), abs(p[1]-q[1]))

def best_costs(A, B):
    n, m, k = len(A), len(B), max(len(A), len(B))
    B_full = list(B) + ['D'] * (k - m)  # 多出的槽位用对角线补
    sups, sums, sqs = [], [], []
    for perm in permutations(range(k)):
        cs = [diag_cost(A[i]) if isinstance(B_full[j], str)
              else match_cost(A[i], B_full[j])
              for i, j in enumerate(perm) if i < n]
        sups.append(max(cs)); sums.append(sum(cs)); sqs.append(np.sqrt(sum(c*c for c in cs)))
    return min(sups), min(sums), min(sqs)

D1 = [(1.0, 3.0), (2.0, 5.0)]
D2 = [(1.5, 3.0), (2.0, 4.5)]
print(best_costs(D1, D2))
```

实跑输出（本章数值锚，照抄）：

```text
(0.5, 1.0, 0.7071067811865476)
```

三个数依次是 $d_{\mathrm{B}} = 0.5$、$d_1 = 1.0$、$d_2 = 0.7071$（$W_2$ 的两个罚金平方和 $0.25 + 0.25 = 0.5$，开根得 $0.7071$）。单调链 $d_{\mathrm{B}} \le d_2 \le d_1$ 即 $0.5 \le 0.7071 \le 1.0$，当场兑现。顺带看叉配为什么输：它强行让寿命悬殊的洞互相顶班，罚金爆表——**好匹配让寿命相近的洞互配**，这也是肉眼配对的直觉。

**本节小结**：持久图之间的距离＝带对角线补位的最优匹配；罚金取最大得瓶颈距离 $d_{\mathrm{B}}$，取 $p$ 次幂和的 $p$ 次根得 $d_p$；两张二点小图实算出 $d_{\mathrm{B}} = 0.5$、$d_1 = 1.0$、$d_2 = 0.7071$，单调链成立。下一节回答这套距离最重要的性质：函数扰动时图动多少。

## $\rm \S \, 4.3$ 稳定性定理：函数动一点，图动不了一点以上

整本册子最值钱的一条定理登场。

**定理（瓶颈稳定性，Cohen-Steiner–Edelsbrunner–Harer 2007）**。设 $f, g : X \to \mathbb{R}$ 是 tame 函数（每个同调维数的持久图只有有限多个非对角点），则

$$
d_{\mathrm{B}}\big( \mathrm{Dgm}(f),\; \mathrm{Dgm}(g) \big) \;\le\; \lVert f - g \rVert_{\infty}
$$

（读法：两张持久图之间的瓶颈距离，不超过两张函数之间的上确界距离。函数在全域任何一点至多差 $\varepsilon$，则两图之间必有一套罚金不超过 $\varepsilon$ 的匹配。取下确界表述成「对一切 $\varepsilon > \lVert f - g \rVert_{\infty}$ 成立」。）

白话：**噪声有界，图的失真就有界**。数据 $f$ 加了至多 $\varepsilon$ 的扰动变成 $g$，则持久图至多被挪动 $\varepsilon$——一切持久不超过 $\varepsilon$ 的点（对角线宽 $\varepsilon$ 的条带里的点）都可能只是噪声的演技，而持久远超 $\varepsilon$ 的点必定对应 $f$ 与 $g$ 共有的真实结构。这条定理把「图上哪个点可信」变成了可以按 $\varepsilon$ 定价的工程问题，第 6 章的统计置信带就是它的统计版。

### 证明的关键步骤

完整证明超出本章篇幅，但骨架必须交底。现代标准路线把定理拆成三节车厢，每节一站：

1. **第一站：函数逼近 $\Rightarrow$ 模块交错。** 记 $\mathbb{F}_f$ 为 $f$ 的子水平集过滤诱导的持久同调模块（第 3 章的代数对象：一串向量空间 $F(a)$ 随 $a$ 增长，配结构映射）。若 $\lVert f - g \rVert_{\infty} \le \varepsilon$，则对每个 $a$ 有包含关系 $\{f \le a\} \subseteq \{g \le a + \varepsilon\}$ 与 $\{g \le a\} \subseteq \{f \le a + \varepsilon\}$，诱导出一对映射在两个模块之间来回：

$$
\phi_a : F(a) \to G(a + \varepsilon), \qquad \psi_a : G(a) \to F(a + \varepsilon)
$$

且复合 $\psi_{a+\varepsilon} \circ \phi_a$ 恰好等于 $F$ 自己从 $a$ 到 $a + 2\varepsilon$ 的结构映射（$G$ 同理）——这叫两模块 $\varepsilon$-**交错**（interleaving）。验证只有一步：复合后落在 $\{f \le a + 2\varepsilon\}$ 里且与 $F$ 的结构映射在生成元上逐点相同，靠的是包含链 $\{f \le a\} \subseteq \{g \le a+\varepsilon\} \subseteq \{f \le a + 2\varepsilon\}$ 与诱导映射的函子性。

2. **第二站：模块交错 $\Rightarrow$ 图匹配（代数稳定性）。** Chazal–Cohen-Steiner–Glisse–Guudasani–Oudot（2009）证明：若两个（点态有限维的）持久模块 $\varepsilon$-交错，则其持久图之间存在罚金 $\le \varepsilon$ 的匹配。核心引理是**盒引理**：把平面切成形如 $[b_1, b_2] \times [d_1, d_2]$ 的盒，交错性禁止「$\mathrm{Dgm}(F)$ 在某个盒里出的点数，超过 $\mathrm{Dgm}(G)$ 在放大 $\varepsilon$ 的相邻盒里能接住的点数」这类配置；对盒作归纳，把 $\mathrm{Dgm}(F)$ 的每个非对角点逐个搬进 $\mathrm{Dgm}(G)$ 的 $\varepsilon$-邻域，搬不动的丢对角线，持久 $\le \varepsilon$ 故代价 $\le \varepsilon$。

3. **第三站：收口。** 两站接力得：对一切 $\varepsilon > \lVert f - g \rVert_{\infty}$，$d_{\mathrm{B}}(\mathrm{Dgm}(f), \mathrm{Dgm}(g)) \le \varepsilon$。令 $\varepsilon$ 收缩，定理得证。

三站各留抓手：第一站下一段当场验；第二站是纯代数，Lesnick 的交错优化理论共用这块基石；第三站是账面功夫。

### 定理的另一面：反向不等式不成立

稳定性是**单向**的：图近推不出函数近。反例一挥而就：$f$ 恒为零，图无点；$g$ 在一个尖锐小峰处抬升 $1$ 又立刻落回（峰宽极小），$\lVert f - g \rVert_{\infty} = 1$ 但 $g$ 的图最多添一个点对的微小痕迹——图可以「比函数诚实得多」。反过来方向（函数近 $\Rightarrow$ 图近）才是应用中用到的方向，也是定理承诺的方向。还有一条容易被误读的话要钉死：定理控制的是**子水平集过滤**这张图；换一种过滤（比如第 5 章 Mapper 那类离散化构造），同样的保证不自动跟过去，要重新审。

### 用小图验一遍第一站

拿 §4.2 的实算当实验台。把 $D_1$ 与 $D_2$ 看成两个函数 ${f, g}$ 的图，$\lVert f - g \rVert_{\infty} = 0.5$（比如 $f$ 与 $g$ 逐点差不超过 $0.5$ 的任意 tame 函数对，其图恰为 $D_1$ 与 $D_2$）。定理承诺 $d_{\mathrm{B}} \le 0.5$，实算恰好 $0.5$——**界被打平**。这不足为奇：界是按最坏情形给的，而顺配方案的罚金恰好逐对用满 $0.5$。

**本节小结**：稳定性定理 $d_{\mathrm{B}}(\mathrm{Dgm}(f), \mathrm{Dgm}(g)) \le \lVert f - g \rVert_{\infty}$ 经三站证得——函数逼近给模块交错、代数稳定性把交错换成匹配、取极限收口；界单向、可打平；它给「对角线条带外的点才算数」定了价。下一节把图变成可以直接进回归与聚类的函数对象。

## $\rm \S \, 4.4$ 持久景观：把点集织成函数

距离解决了「两张图怎么比」，但统计与机器学习常要的是另一种对象：**每个图对应一个函数或向量**，然后用现成的 $L^2$ 理论、均值、方差、核方法。持久景观（persistence landscape，Bubenik 2015）是最顺路的一个转换——它几乎不引入新参数，且稳定性随 §4.3 免费带走。

**定义**。对每个点对 $(b, d)$（$b < d$）造一个**帐篷函数**：

$$
\Lambda_{(b,d)}(t) = \max\Big( 0,\; \min(t - b,\; d - t) \Big)
$$

（读法：从 $t = b$ 线性爬升、到中点 $t = \frac{b+d}{2}$ 达到峰值 $\frac{d-b}{2}$（恰为持久的一半）、再线性下降到 $t = d$ 归零；峰越高洞越长寿。）把图 $D$ 中所有点的帐篷函数叠在一起，**持久景观**是按高度排队的第 $k$ 名：

$$
\lambda_k(t) = k\text{ 第大的} \big\{ \Lambda_{(b_i, d_i)}(t) \big\}_{i}
$$

（读法：$\lambda_1(t)$ 是 $t$ 时刻最高的帐篷尖，$\lambda_2(t)$ 是次高的，以此类推；帐篷不够 $k$ 个的位置取 $0$。一张图变成一列递减的非负函数 $\lambda_1 \ge \lambda_2 \ge \cdots$。）

白话：**景观把「点集合」翻译成「函数列」**——在每个时刻 $t$ 问「$t$ 这个尺度上正开着的洞里，第 $k$ 长寿的开到多大」。点集的散乱无序被函数的排队结构接住，统计理论（均值、期望、大数定律）从此有处落脚：景观之间的距离就是普通的 $L^p$ 距离。

### 实算：§4.2 那两张图的景观

四顶帐篷的几何先钉死：

1. $D_1$ 的 $(1, 3)$：峰高 $\frac{3-1}{2} = 1$，峰位 $t = 2$；
2. $D_1$ 的 $(2, 5)$：峰高 $1.5$，峰位 $t = 3.5$；
3. $D_2$ 的 $(1.5, 3)$：峰高 $0.75$，峰位 $t = 2.25$；
4. $D_2$ 的 $(2, 4.5)$：峰高 $1.25$，峰位 $t = 3.25$。

$\lambda_1$ 与 $\lambda_2$ 在抽样点的值（程序见 §4.6）：

```text
t=1.50  lambda1(D1)=[0.5 0.]  lambda1(D2)=[0. 0.]
t=2.00  lambda1(D1)=[1. 0.]   lambda1(D2)=[0.5 0.]
t=3.50  lambda1(D1)=[1.5 0.]  lambda1(D2)=[1. 0.]
t=2.25  lambda2(D1)=[0.75 0.25]  lambda2(D2)=[0.75 0.25]
```

两个景观的差异量：

```text
||dlambda1||_inf = 0.5    （在 t=1.5 达到，t 属于 [1.5, 2] 时恒为 0.5）
int |dlambda1| dt = 1.125
||dlambda1||_2   = 0.707107
||dlambda2||_inf = 0.0    （两条 lambda2 逐点相同）
```

读这批数字的三句话：其一，$\lVert \lambda_1 - \lambda_1' \rVert_{\infty} = 0.5$ **恰好等于** $d_{\mathrm{B}} = 0.5$——下一条稳定性界的紧例当场出现；其二，$L^1$ 距离 $1.125$ 比上确界 $0.5$ 大得多，因为帐篷错位造成的差在长区间上持续（例如 $t \in [3.5, 4.5]$ 上两帐篷都以斜率 $1$ 下降、差恒 $0.5$，一段就贡献面积 $0.5$）；其三，$\lambda_2$ 逐点相同——两张图的「第二名帐篷」在所有 $t$ 处恰好同高，**上确界距离对图里的每一个点都敏感，景观的各层却各管一摊**，这是把图变函数后信息重新分布的直接证据。

### 景观的稳定性

**定理（景观稳定性，Bubenik 2015）**。对 $p = \infty$：

$$
\lVert \lambda_k(D) - \lambda_k(D') \rVert_{\infty} \;\le\; d_{\mathrm{B}}(D, D'), \qquad k = 1, 2, \ldots
$$

对 $1 \le p < \infty$：

$$
\lVert \lambda(D) - \lambda(D') \rVert_{p} \;\le\; 2^{1/p}\, d_p(D, D')
$$

（读法：上确界版逐层成立且常数是干净的 $1$；$L^p$ 版要付因子 $2^{1/p}$。）

证明关键步骤（上确界版，全验）：设某匹配把 $D$ 的每点 $p_i$ 配到 ${D'}$ 的 $\mu(p_i)$，坐标差至多 $\varepsilon$。则每个帐篷至多被挪 $\varepsilon$：

$$
\big| \Lambda_{(b,d)}(t) - \Lambda_{\mu((b,d))}(t) \big| \le \varepsilon \qquad \text{对一切 } t
$$

（理由：端点 ${b, d}$ 各挪至多 $\varepsilon$，上升段、下降段、峰位跟着挪至多 $\varepsilon$，两帐篷在同一点的值差至多 $\varepsilon$——逐段核对线性函数的平移即可。）两个「逐点相距 $\le \varepsilon$ 的多重集」，其第 $k$ 大元素也相距 $\le \varepsilon$（把 $\Lambda_{p_i}(t)$ 与 $\Lambda_{\mu(p_i)}(t)$ 排成两条队列，逐对咬合），故 $|\lambda_k(t) - \lambda_k'(t)| \le \varepsilon$ 对一切 $t$；对匹配取下确界即得。$L^p$ 版的因子 $2^{1/p}$ 来自帐篷错位在长时间区间上的累积——上面实算的 $1.125 > d_1 = 1.0$ 正是「常数 $1$ 在 $L^1$ 上不可能」的活证：差值必须比逐对罚金的总和还大，因子 $2$ 给这份累积留出额度。

### 从景观到特征向量

景观仍是函数，进模型前再斩一刀——在网格 $t_1 < \cdots < t_m$ 上采样，把 $\lambda_1, \ldots, \lambda_K$ 的取值串成一个向量：

$$
v(D) = \big( \lambda_1(t_1), \ldots, \lambda_1(t_m),\; \lambda_2(t_1), \ldots, \lambda_K(t_m) \big) \in \mathbb{R}^{Km}
$$

对本章小图取 $K = 2$、网格 $t \in \{1.5, 2, 2.25, 3.5, 4.5\}$，按上表与 §4.6 程序补齐：$v(D_1) = (0.5, 1, 0.75, 1.5, 0.5,\; 0, 0, 0.25, 0, 0)$，$v(D_2) = (0, 0.5, 0.75, 1, 0,\; 0, 0, 0.25, 0, 0)$——两个 $10$ 维向量，可直接进逻辑回归。更有统计味的是**平均景观** $\bar{\lambda}_k = \frac{1}{n} \sum_j \lambda_{k, j}$：它仍在景观空间里（凸性），且经验平均一致收敛于期望景观——持久图有了带大数定律的「样本均值」。

**本节小结**：景观 $\lambda_k(t)$＝帐篷函数按高度排队的第 $k$ 名；上确界稳定性逐层成立且常数 $1$（本例打平），$L^p$ 版付因子 $2^{1/p}$（本例证明常数 $1$ 不可能）；网格采样把图变成向量，平均景观带来期望与大数定律。下一节清点其余向量化路线，看各自的价码。

## $\rm \S \, 4.5$ 向量化路线清点：图像、剪影与核

景观之外还有三条主流水线，各附一句「什么时侯选它」。

1. **持久图像（persistence image，Adams 等 2017）**：把图的点搬到「出生－持久」平面（坐标 $\big(b,\, d-b\big)$），每点放一个高斯团、按持久加权，栅格化成一幅灰度图像，直接上卷积网络。持久长的点团大，低持久噪声被压扁。任务是图像类、想复用 CNN 兵器时选它。
2. **剪影（silhouette，Chazal 等 2014）**：$\phi(t) = \sum_i w_i \,\Lambda_{(b_i,d_i)}(t)$，帐篷函数的加权和（权重随持久增长）。它是景观 $\lambda_1$ 的「加权不分层版」，一个函数一锤定音，计算最便宜；适合当快速基线。
3. **核方法（persistence kernel）**：把「两张图的距离」做成正定核 $K(D_1, D_2)$（持久景观核、切片 Wasserstein 核等，Carrière 等 2017），核岭回归与核 PCA 照单全收（本站核方法册的机制无缝对接）。想保留图间距离的几何、又不想手工降维时选它。

三条线与景观共享同一个底层承诺：**对图的扰动稳定**。它们与景观的取舍不在「稳不稳」，而在「把信息压到哪一层」——景观分层保留最多，剪影一层最省，图像把信息重新排布成利于空间卷积的形状，核则完全不降维、把比较推迟到核函数内部。共同的价码也一致：任何向量化都是有损压缩，「哪些洞重要」的决定权从数据移交给转换超参数（层数 $K$、网格、带宽 $\sigma$）——§6.3 会把这句话升级成对整个 TDA 的批评之一。

**本节小结**：持久图像输出灰度图喂 CNN、剪影是单函数的廉价基线、持久核把图间距离接进核机器；四条向量化路线都稳定，差别在压缩层次与下游接口。至此图的「比较、防噪、变特征」三件套齐备——下一章换一条赛道，看不动持久同调也能读形状的 Mapper。

## $\rm \S \, 4.7$ 程序段：距离与景观的完整实算

把 §4.2 与 §4.4 的散装代码合成一份可复跑脚本（换图即用）：

```python
import numpy as np
from itertools import permutations

# ---------- 距离：全枚举（图小可行；大图用 Bierstone/bottleneck 库） ----------
def diag_cost(p):
    return (p[1] - p[0]) / 2.0

def match_cost(p, q):
    return max(abs(p[0]-q[0]), abs(p[1]-q[1]))

def best_costs(A, B):
    n, m, k = len(A), len(B), max(len(A), len(B))
    B_full = list(B) + ['D'] * (k - m)
    sups, sums, sqs = [], [], []
    for perm in permutations(range(k)):
        cs = [diag_cost(A[i]) if isinstance(B_full[j], str)
              else match_cost(A[i], B_full[j])
              for i, j in enumerate(perm) if i < n]
        sups.append(max(cs))
        sums.append(sum(cs))
        sqs.append(np.sqrt(sum(c * c for c in cs)))
    return min(sups), min(sums), min(sqs)   # d_B, d_1, d_2

# ---------- 景观 ----------
def tent(b, d, t):                          # t 可为数组
    return np.clip(np.minimum(t - b, d - t), 0.0, None)

def landscape(diag, k, grid):
    vals = np.sort(np.stack([tent(b, d, grid) for b, d in diag]), axis=0)[::-1]
    return vals[k]                          # 第 k 层（k 从 0 计）

D1 = [(1.0, 3.0), (2.0, 5.0)]
D2 = [(1.5, 3.0), (2.0, 4.5)]
grid = np.linspace(0, 6, 6000001)
h = grid[1] - grid[0]

d_B, d_1, d_2 = best_costs(D1, D2)
lam1A, lam1B = landscape(D1, 0, grid), landscape(D2, 0, grid)
lam2A, lam2B = landscape(D1, 1, grid), landscape(D2, 1, grid)
diff = np.abs(lam1A - lam1B)

print("d_B = %.4f  d_1 = %.4f  d_2 = %.6f" % (d_B, d_1, d_2))
print("sup |dlam1| = %.4f at t = %.4f" % (diff.max(), grid[diff.argmax()]))
print("int |dlam1| = %.6f   L2 = %.6f" % (diff.sum() * h, np.sqrt((diff**2).sum() * h)))
print("sup |dlam2| = %.4f" % np.abs(lam2A - lam2B).max())
print("d_B <= sup-norm landscape diff:", d_B <= diff.max() + 1e-12)   # 稳定性验收
```

实跑输出：

```text
d_B = 0.5000  d_1 = 1.0000  d_2 = 0.707107
sup |dlam1| = 0.5000 at t = 1.5000
int |dlam1| = 1.125000   L2 = 0.707107
sup |dlam2| = 0.0000
d_B <= sup-norm landscape diff: True
```

读程序的四句话：全枚举只在图很小时可行，生产环境换专门算法（库函数入口如 `gudhi.bottleneck_distance`）；景观层号 $k$ 从 $0$ 计数，`np.sort(...)[::-1]` 先按高度排队再取层；`diff.sum() * h` 是矩形法积分，网格够密即收敛到真值（与手算分段面积 $0.125 + 0.25 + 0.0625 + 0 + 0.0625 + 0.5 + 0.125 = 1.125$ 对账）；最后一行把稳定性定理当**运行时断言**用——景观差若大于瓶颈距离，说明有 bug 而不是定理错了。

## $\rm \S \, 4.8$ 六问参考答案

1. 两图点数未必相等，多余的点必须有去处；对角线按 $d(p, \Delta) = \frac{d-b}{2}$ 收费，鼓励「丢掉短命的洞」（收费低）、惩罚「丢掉长寿的洞」（收费高）——于是距离自动只对真正持久的差异敏感。（§4.2）
2. 三条出路：配 $(2, 4.5)$ 罚 $\max(0, 0.5) = 0.5$；配 $(1.5, 3)$ 罚 $\max(1.5, 2) = 2$；配对角线罚 $(5-2)/2 = 1.5$。任何匹配方案都必须安置 $(2, 5)$，其安置代价 $\ge 0.5$，故最贵一对 $\ge 0.5$——单点的最优出路就是全图的下界，因为瓶颈罚金由最贵一对决定。（§4.2）
3. 车厢一：函数逼近给 $\varepsilon$-交错（$\{f \le a\} \subseteq \{g \le a+\varepsilon\}$ 等两个方向的包含诱导映射）；车厢二：代数稳定性把交错换成罚金 $\le \varepsilon$ 的图匹配（盒引理）；车厢三：对 $\varepsilon$ 取下确界收口。包含关系用了 $\lVert f-g \rVert_{\infty} \le \varepsilon$ 的「$f$ 在 $a$ 以下 $\Rightarrow$ $g$ 在 $a + \varepsilon$ 以下」这一半（反向包含用另一半）。（§4.3）
4. 单向指只证了 $d_{\mathrm{B}} \le \lVert f - g \rVert_{\infty}$；反例是恒零函数与窄尖峰函数：$\lVert f - g \rVert_{\infty} = 1$ 而图几乎不变。应用只需单向：已知函数级噪声上界，要控制图级失真——正是不等式承诺的方向。（§4.3）
5. 帐篷从 $b$ 升到 $t = \frac{b+d}{2}$ 处的峰高 $\frac{d-b}{2}$（＝持久的一半）再降到 $d$ 归零；$\lambda_k(t)$ 是全体帐篷在 $t$ 处取值按大小排队的第 $k$ 名。实算 $\lVert \Delta \lambda_1 \rVert_1 = 1.125 > d_1 = 1.0$，故 $L^1$ 稳定性的常数不能是 $1$，$2^{1/1} = 2$ 的因子不可省。（§4.4）
6. 持久图像输出灰度图像，对接 CNN；剪影输出单个函数（帐篷的加权和），是最廉价的基线与快速原型；持久核输出一个正定核，直接对接核岭回归、核 PCA、SVM。共同价码：向量化是有损压缩，「哪些洞重要」由超参数（层数、网格、带宽、权重）接管，不再由数据说话。（§4.5）
