# $\rm Chapter \, 1$ 迭代与不动点

本册讲动力系统与混沌。整个故事压在一个朴素到近乎天真的动作上：**把一个函数反复地代入自己**。第 1 章把这个动作定义清楚——轨道、不动点、周期轨道，以及判定它们去留的导数判据；第 2 章看着参数旋钮转动时这些结构如何诞生与翻转（分岔与倍周期）；第 3 章到达终点站——轨道对初值的指数级敏感（混沌）与度量它的李雅普诺夫指数。三章共用同一个主角：logistic 映射 $x_{n+1} = r\,x_n(1 - x_n)$，一个二次多项式管尽全局，每个数值都真跑得出。

> **开始前自检**：本章假设你已经会：
>
> 1. □ 导数与泰勒展开：会写 $f(x^* + y) = f(x^*) + f'(x^*)\,y + O(y^2)$（本站连续数学册的微分部分），§1.2 的稳定性判据整个推导只靠它；
> 2. □ 几何级数与指数衰减：知道 $a^n \to 0$ 当且仅当 $|a| < 1$（本站连续数学册的级数部分），§1.2 判据的「收敛/发散」结论来自它；
> 3. □ 基本的函数复合记号：$f \circ f$、$f^{n}$ 表示「代入 $n$ 次」而不是「$n$ 次方」，§1.1 开头就钉死这个约定；
> 4. □ 三角恒等式 $\sin^2\theta + \cos^2\theta = 1$（中学内容），第 3 章解 logistic 映射 $r = 4$ 的精确解时要用，本章只需记着它存在。
>
> 其中第 1 条是本章的工作马——「稳定性」从头到尾都在读泰勒展开的一阶项，不熟先补齐再往下读。

## $\rm \S \, 1.1$ 迭代与轨道：把函数当引擎

先说清「迭代」在研究什么。微分方程研究的是连续时间演化（本站随机微分方程册的对象），而离散动力系统研究的是**节拍器式**的演化：时间只取整数拍，每一拍系统从状态 $x_n$ 跳到状态 $x_{n+1}$，跳法由同一个函数规定：

$$
x_{n+1} = f(x_n)
$$

（读法：$f$ 是引擎，$n$ 是拍数，$x_0$ 是初始状态。整个未来的历史由 $f$ 与 $x_0$ 两个信息完全决定——这是「确定性」三个字在本册的含义。）从 $x_0$ 出发逐拍代入得到的序列

$$
x_0,\;\; x_1 = f(x_0),\;\; x_2 = f(f(x_0)),\;\; \ldots
$$

叫**轨道（orbit）**。为了不每次都写嵌套括号，约定 $f^{2} := f \circ f$、$f^{n} := \underbrace{f \circ \cdots \circ f}_{n}$，于是 $x_n = f^{n}(x_0)$。注意这个上标是**迭代次数**，不是幂——$\sin^2\theta$ 是平方，$f^2(x)$ 是复合，两套记号并存，按上下文读。

白话：**迭代就是把一台固定机器反复开动**——机器不改，喂进去的纸片每轮被机器改写一遍。研究动力系统，就是研究这三件事：纸片最终停在哪（定态）、绕着什么圈转（周期）、以及会不会越走越没谱（混沌，第 3 章）。而「机器不改」恰恰是魔术的来源：规则明明简单到一行，历史却可以复杂到无法预测。

贯穿本册的引擎是 **logistic 映射**：

$$
f(x) = r\,x(1 - x), \qquad x \in [0, 1],\;\; r \in [0, 4]
$$

（读法：$x$ 是某物种规模占环境容量的比例，$rx$ 是按比例繁殖，$(1 - x)$ 是「剩余空间」的稀释项——种群越接近饱和，繁殖越打折扣。$r$ 是唯一的旋钮，管繁殖强度；$r \le 4$ 保证 $[0,1]$ 映回 $[0,1]$，轨道不出界。这个模型出自生态学，May 在 1976 年的 Nature 综述里让它成了混沌的教科书代言——一篇简单模型长出复杂动力学的宣言。）

它值得本册用三章，因为旋钮 $r$ 从 $0$ 拧到 $4$，轨道会依次经历本章的「安顿下来」、第 2 章的「周期越来越长」、第 3 章的「永不重复」。先跑一趟感受下：取 $r = 2.5$、$x_0 = 0.9$，逐拍算出（本章数值锚，照抄）：

| $n$ | $x_n$ |
| --- | --- |
| $0$ | $0.9000000000$ |
| $1$ | $0.2250000000$ |
| $2$ | $0.4359375000$ |
| $3$ | $0.6147399902$ |
| $4$ | $0.5920868366$ |
| $5$ | $0.6038000363$ |
| $10$ | $0.5998797353$ |
| $20$ | $0.5999998826$ |

（读法：前几拍大幅摆动，随后在 $0.6$ 附近越晃越小——轨道在「安顿」。它安顿到的那个值不是巧合，§1.2 会算出它正是 $1 - 1/r = 0.6$。）注意摆动是**左右交替**的：$0.6147$、$0.5921$、$0.6038$、$0.5981$……这个交替不是偶然，它背后是 $f'(x^*) < 0$，§1.2 马上给解释。

**本节小结**：离散动力系统＝一个函数 $f$ 加反复代入；轨道是 $x_n = f^{n}(x_0)$；logistic 映射 $x_{n+1} = r x_n (1 - x_n)$ 是本册主角，旋钮 $r$ 拧出从安定到混沌的全谱。下一节给「安顿」下一个精确定义，并导出判定它发生的判据。

## $\rm \S \, 1.2$ 不动点与周期轨道：稳定性判据 $|f'(x^*)| < 1$

轨道最常见的归宿是停下来。若

$$
f(x^*) = x^*
$$

（读法：喂进去等于吐出来——引擎对这个值不起作用），则 $x^*$ 叫**不动点（fixed point）**，轨道 $x_0, x^*, x^*, \ldots$ 从某一拍起永久停驻。logistic 映射的不动点解方程 $rx(1-x) = x$：

$$
rx - rx^2 = x \;\Rightarrow\; x\big(r - 1 - rx\big) = 0 \;\Rightarrow\; x = 0 \;\text{ 或 }\; x = 1 - \frac{1}{r}
$$

（读法：$x = 0$ 是「灭绝」——毫无悬念的平凡不动点；$x^* = 1 - 1/r$ 才是生态学上有内容的平衡态，$r$ 越大它越靠近饱和。）

但「存在不动点」与「轨道会去那里」是两回事。判据来自泰勒展开的一阶项。设 $x_n = x^* + y_n$，偏差 $y_n$ 很小，则

$$
y_{n+1} = x_{n+1} - x^* = f(x^* + y_n) - f(x^*) = f'(x^*)\, y_n + O(y_n^2)
$$

（读法：偏差的演化在最低阶是**线性放大**，放大倍数就是 $f$ 在不动点处的导数——习惯上称它为**乘子（multiplier）**。）忽略高阶项，$y_n \approx \big(f'(x^*)\big)^n y_0$，于是只看 $|f'(x^*)|$ 与 $1$ 的大小：

1. $|f'(x^*)| < 1$：偏差逐拍缩小，**吸引**——附近的轨道都安顿到 $x^*$，此时 $x^*$ 叫**稳定不动点**；
2. $|f'(x^*)| > 1$：偏差逐拍放大，**排斥**——除非初值分毫不差地落在 $x^*$ 上，轨道迟早被推走，$x^*$ 叫**不稳定不动点**；
3. $|f'(x^*)| = 1$：一阶项判不了生死，得看高阶项——这个「边缘情形」正是第 2 章一切分岔的出生地，先按下。

logistic 映射的乘子好算：$f'(x) = r(1 - 2x)$，在 $x^* = 1 - 1/r$ 处

$$
f'(x^*) = r\Big(1 - \frac{2(r-1)}{r}\Big) = r(2 - r) \cdot \frac{1}{r} = 2 - r
$$

（读法：内非零不动点的乘子恰好是 $2 - r$，一个惊人的简洁——旋钮 $r$ 直接就是稳定性的判决书。$r < 3$ 时 $|2 - r| < 1$ 稳定，$r > 3$ 时不稳定，$r = 3$ 是边缘。）$r = 2.5$ 时 $|2 - r| = 0.5$：偏差每拍减半——验算 §1.1 的表，$x_{20} - 0.6 = -1.17 \times 10^{-7}$，与理论值 $0.3 \times 0.5^{20} \approx 2.9 \times 10^{-7}$ 同量级（高阶项修正了系数）。这也解释了 §1.1 的左右交替：$f'(x^*) = -0.5$ 是负的，偏差每拍**变号再缩半**。

**周期轨道**是「停驻」的推广。若 $f^{p}(x^*) = x^*$ 且更小的迭代回不到原处，则 $x^*$ 是**周期 $p$ 点**，$x^*, f(x^*), \ldots, f^{p-1}(x^*)$ 这 $p$ 个点轮流出牌，构成一条**周期 $p$ 轨道**。它的稳定性把判据用在 $f^{p}$ 上：这条轨道是稳定的当且仅当

$$
\big| (f^{p})'(x^*) \big| < 1, \qquad (f^{p})'(x^*) = \prod_{i=0}^{p-1} f'\big(x_i\big)
$$

（读法：$f^{p}$ 在周期点的导数等于沿轨道一圈导数的**连乘**——链式法则把 $p$ 步的伸缩率乘成一总账，这就是「周期轨道乘子」。）手算看 $r = 3.2$ 的周期 $2$：迭代 $2000$ 拍后轨道稳定在 $\{0.5130445095,\; 0.7994554905\}$（本章数值锚）。${f'}$ 在两点处的值分别是 $-0.0835$ 与 $-1.9165$，连乘恰为 $0.16$，$|0.16| < 1$——周期 $2$ 轨道稳定，附近轨道都投奔它。$r = 3.5$ 与 $r = 3.56$ 的周期 $4$、周期 $8$ 用同样的办法验证（数值见 §1.6 程序段），本册的三章都靠这把乘子钥匙开门。

**本节小结**：不动点满足 $f(x^*) = x^*$，稳定性由乘子 $|f'(x^*)|$ 与 $1$ 的比较决定，判据的来源是「偏差线性放大」；周期轨道的稳定性归约为 $f^{p}$ 的不动点判据，乘子是一圈导数的连乘；logistic 映射内不动点乘子恰为 $2 - r$，$r = 3$ 处判据失效——那是下一章的入口。下一节先把这套判据画出来看看。

## $\rm \S \, 1.3$ 蛛网图：稳定性的几何课

白话：判据 $|f'(x^*)| < 1$ 有个不用计算器的版本——**蛛网图（cobweb diagram）**。画法三步：

1. 在同一张图上画 $y = f(x)$ 与对角线 $y = x$；
2. 从 $x_0$ 出发竖直走碰曲线，读出 $f(x_0)$；再水平走碰对角线，把这个值搬到横轴——这就是 $x_1$；
3. 重复：竖、横、竖、横……折线织出一张「蛛网」，网住的那条水平线高度就是轨道的归宿。

蛛网为什么能替你判断？关键在对角线的几何职责：水平搬移「把函数值变成下拍的自变量」，而**曲线与对角线的交点恰是不动点**（交点处 $f(x) = x$）。稳定性的几何判据是**斜率比**：曲线在交点处比对角线（斜率 $1$）更平缓，蛛网就向交点收拢；更陡峭，蛛网就被弹开。斜率是负数时蛛网绕着交点打转——这正是 §1.1 表中左右交替的几何版本。

三张对照（logistic 映射，都从 $x_0 = 0.9$ 出发）：

1. $r = 2.5$：曲线在 $x^* = 0.6$ 处斜率 $-0.5$，比 $1$ 平缓且反向。蛛网从右上角出发，一圈圈向内盘旋，经十来拍后密密地贴在交点上——§1.1 的表格就是这张蛛网的坐标账本。
2. $r = 3.1$：交点 $x^* = 1 - 1/3.1 \approx 0.677$ 处斜率 $+1.1$，比对角线陡。蛛网在交点附近被逐拍推开，向外盘旋——但出不了 $[0,1]$ 这个盒子，最终被「挤」进一个方框：与曲线的两个交点之间来回跳。这两个点正是迭代 $2000$ 拍后实收的周期 $2$ 轨道 $\{0.5580141252,\; 0.7645665200\}$（本章数值锚）。蛛网图上，$r = 3.1$ 的定局已经从「一个点」变成「一个方框」——这就是第 2 章倍周期分岔的预告片。
3. $r = 2.99$（贴着判据边缘）：斜率 $-0.99$，蛛网几乎沿着对角线爬行，要几百拍才能看出它在收拢还是散开——越贴近 $|f'| = 1$，蛛网动作越慢。这个「临界慢化」在 §1.2 里只是判据的边缘情形，到第 2 章会变成实测分岔点时最头疼的误差来源，届时再算账。

蛛网图的价值不在精确（它算不过程序），而在**一眼看清全局**：曲线长什么样、交点有几个、轨道被弹向何方，全部摆在一张图上。第 2 章的分岔图则是它的全球版——把每个旋钮位置的「蛛网归宿」叠画成一张总图。

**本节小结**：蛛网图用「竖碰曲线、横碰对角线」的折线把迭代画成几何；曲线与对角线的交点是不动点，交点处斜率的陡缓与正负分别给出吸引/排斥与单调/振荡。$r = 3.1$ 的蛛网被挤进周期 $2$ 的方框，$r$ 贴近 $3$ 时蛛网慢得像停——这两笔都记到下一章的账上。下一节带着判据与蛛网把 logistic 映射整个旋钮行程扫一遍，并陈述一枚惊人的定理。

## $\rm \S \, 1.4$ 数值漫游与 Sarkovskii 定理：周期 3 蕴含一切

装备齐全，把旋钮从 $0$ 拧到 $4$ 做一次数值漫游。判据与程序（§1.6）双管齐下，逐站登记（本章数值锚，照抄）：

| $r$ | 轨道归宿 | 乘子账本 |
| --- | --- | --- |
| $2.5$ | 不动点 $x^* = 0.6$ | $\|f'(x^*)\| = 0.5 < 1$，稳定 |
| $3.2$ | 周期 2：$\{0.5130,\; 0.7995\}$ | $(f^2)' = 0.16$，稳定 |
| $3.5$ | 周期 4：$\{0.3828,\; 0.5009,\; 0.8269,\; 0.8750\}$ | $(f^4)' = -0.031$，稳定 |
| $3.56$ | 周期 8：$\{0.3488,\; 0.3738,\; 0.4945,\; 0.5509,\; 0.8086,\; 0.8333,\; 0.8808,\; 0.8899\}$ | $(f^8)' = -0.539$，稳定 |

（读法：周期按 $1 \to 2 \to 4 \to 8$ 翻倍，每级乘子 $|{(f^{p})'}| < 1$ 但逐级逼近 $1$——越高级的周期越「勉强」维持稳定。翻倍的机制与精确的转折参数是第 2 章的主题。）在 $r \approx 3.5699$ 之后，这条翻倍走廊走到头，轨道不再落入任何有限周期——那是第 3 章的混沌地带。但走廊之后并非一片荒芜：$r = 3.83$ 处轨道又安顿进一条**周期 3** 轨道 $\{0.156149,\; 0.504666,\; 0.957417\}$（乘子 $0.33$，稳定）。这个「乱中恢复秩序」的窗口引出本节的主角。

**Sarkovskii 定理**（Sharkovsky，1964）。先把全体正整数排成一个特殊的队，叫 **Sarkovskii 序**：

$$
3 \succ 5 \succ 7 \succ \cdots \succ 2 \cdot 3 \succ 2 \cdot 5 \succ \cdots \succ 2^2 \cdot 3 \succ 2^2 \cdot 5 \succ \cdots \succ \cdots \succ 2^3 \succ 2^2 \succ 2 \succ 1
$$

（读法：队首是全体 $\ge 3$ 的奇数按升序，随后是它们的 $2$ 倍、$4$ 倍、$8$ 倍……每个「奇数 $\times$ $2^k$」块都按奇数升序排队；所有 $2$ 的纯幂次 ${8, 4, 2, 1}$ 殿后，从大到小。）定理说：$f$ 是区间上的连续映射，若 $f$ 有周期 $n$ 的点，则对 Sarkovskii 序中排在 $n$ 之后的每个 $m$，$f$ 必有周期 $m$ 的点。

队首选得极有心机：$3$ 排在全体整数的**最前面**，于是

$$
\text{周期 3 存在} \;\Rightarrow\; \text{一切周期的周期点都存在}
$$

（读法：这是定理的极端情形——李天岩与 Yorke 在 1975 年的名文《Period Three Implies Chaos》用它捅破了窗户纸：一个一维连续映射只要有周期 3，就同时有任意长的周期，且存在一团「永不重复又彼此靠近」的轨道——他们给这团现象起名叫 chaos，混沌这个词由此进入数学的主流词汇。）定理还有一个反向的锋利之处：序是**不可削弱**的——只保证排在后面的周期存在，排在前面的可以一律缺席。比如有周期 4 的映射可以没有任何周期 3。

程序在 $r = 3.83$ 处把定理验了一遍身：在 $[0,1]$ 上布 $2$ 万个网格点、对 $f^{p}(x) - x$ 找变号区间并用二分法收根， periods $1$ 到 $8$ **全部**有真周期轨道落网（周期 3 找到两条：上面那条稳定的，加一条不稳定的 $\{0.163570,\; 0.524001,\; 0.955294\}$；完整计数见 §1.6）。注意定理讲的是「存在与否」，不讲「看得到与否」——在 $r = 3.83$ 处你肉眼追轨道只会看到周期 3，因为其余周期的轨道都不稳定、它的吸引盆又窄，数值上稍偏就滑回稳定轨道。定理的锋刃与肉眼的盲区，是读混沌文献时要时刻区分的两件事。

**本节小结**：logistic 映射沿 $r$ 依次安顿进周期 ${1, 2, 4, 8}$，每级乘子逐级逼近 $1$；Sarkovskii 序把整数排队后断言「有周期 $n$ 则有序后一切周期」，队首的周期 3 蕴含一切周期——李与 Yorke 由此把 chaos 引进数学。数值在 $r = 3.83$ 处数出了周期 $1$ 到 $8$ 的全部存在，但除周期 3 外都不稳定。翻倍走廊为何恰好在这里断掉、转折点精确在哪里，下一章拆解。

## $\rm \S \, 1.6$ 程序段：轨道、周期与 Sarkovskii 计数

把本章数值锚变成可复跑的完整程序（换 $r$、换初值都能验）：

```python
import numpy as np

def logistic(r):
    return lambda x: r * x * (1 - x)

def find_cycle(r, p, x0=0.9, ntrans=2000):
    """先丢掉瞬态，再连采 p 拍，得到周期 p 轨道的 p 个点"""
    f = logistic(r)
    x = x0
    for _ in range(ntrans):
        x = f(x)
    cyc = []
    for _ in range(p):
        cyc.append(x)
        x = f(x)
    return cyc

def cycle_multiplier(r, cyc):
    """周期轨道乘子：一圈 f' 的连乘"""
    f = logistic(r)
    m = 1.0
    for x in cyc:
        m *= r * (1 - 2 * x)
    return m

for r, p in [(2.5, 1), (3.2, 2), (3.5, 4), (3.56, 8)]:
    cyc = find_cycle(r, p)
    m = cycle_multiplier(r, cyc)
    print(f"r={r}  period={p}  cycle={[f'{v:.4f}' for v in cyc]}  (f^p)'={m:+.4f}")

# Sarkovskii 计数：r=3.83 处周期 1..8 的真周期点
R = 3.83
def fp(p, x):
    x = float(x)
    for _ in range(p):
        x = R * x * (1 - x)
    return x

xs = np.linspace(1e-6, 1 - 1e-6, 20001)
for p in range(1, 9):
    g = np.array([fp(p, x) - x for x in xs])
    roots = []
    for i in range(len(xs) - 1):
        if g[i] * g[i + 1] < 0:                       # 变号区间必有根
            a, b = xs[i], xs[i + 1]
            for _ in range(80):                       # 二分法收根
                m = 0.5 * (a + b)
                if (fp(p, a) - a) * (fp(p, m) - m) <= 0:
                    b = m
                else:
                    a = m
            roots.append(0.5 * (a + b))
    genuine = [x for x in roots                       # 剔除周期整除 p 的低周期点
               if all(not (p % q == 0 and abs(fp(q, x) - x) < 1e-7)
                      for q in range(1, p))]
    print(f"period {p}: {len(genuine)} points -> {len(genuine) // p} cycle(s)")
```

读程序的四句话：追轨道找**稳定**周期只要「丢瞬态再采样」；乘子把 $r(1-2x)$ 连乘一圈，与理论值 $2 - r$（周期 1）、$4 + 2r - r^2$（周期 2）逐位吻合。Sarkovskii 计数找的是**不稳定**轨道，改用「变号加二分」——$f^p(x) - x$ 变号必藏根，与追轨道的成败无关。注意 $f^p$ 是 $2^p$ 次多项式，根又密又近，$2$ 万网格仍会漏掉贴在一起的根对（如 $r = 3.83$ 周期 4 理论上应有 $12$ 个真周期点，网格只逮住 $4$ 个），所以表里的计数是**下界**——但「每个周期都至少有一条」这个定性结论稳稳成立，Sarkovskii 定理要的正是它。

## $\rm \S \, 1.7$ 六问参考答案

1. 周期 $p$ 点满足 $f^{p}(x^*) = x^*$ 且更小周期回不到原处；$f^{p}$ 是 $p$ 次复合，链式法则沿轨道逐步相乘给出 $(f^{p})'(x^*) = \prod_{i} f'(x_i)$——每过一步偏差被 $f'(x_i)$ 伸缩一次，走完一圈总伸缩率就是连乘。（§1.2）
2. 乘子 $f'(x^*) = 2 - r$。$r = 2.5$ 时 $|{-0.5}| < 1$，轨道安顿到 $x^* = 0.6$；$r = 3.1$ 时 $|{1.1}| > 1$，不动点排斥轨道，轨道被挤进周期 2 方框。$r = 3$ 时乘子恰为 $-1$，一阶判据失效——偏差既不缩也不放，生死由高阶项定，这正是第 2 章倍周期分岔的位置。（§1.2）
3. 乘子 $2 - r = -0.5$ 是负数：偏差每拍**变号**（所以左右交替）再乘 $0.5$（所以幅度减半）。交替收敛是 $f'(x^*) \in (-1, 0)$ 的指纹；乘子为正时轨道单侧滑向不动点。（§1.2）
4. 画曲线 $y = f(x)$ 与对角线 $y = x$；从 $x_0$ 出发竖直碰曲线取函数值、水平碰对角线搬到横轴，重复即得轨道。「比对角线平缓」即 $|f'(x^*)| < 1$：蛛网每步向交点收拢。斜率为负时竖横交替把轨道甩到交点两侧，蛛网绕交点盘旋——左右交替的几何版本。（§1.3）
5. 排队规则：$\ge 3$ 的奇数升序在队首，其后依次是 $2$ 倍、$4$ 倍……各块（块内仍按奇数升序），$2$ 的纯幂从大到小殿后。$3$ 居全体之首，故有周期 3 则序后一切周期全有。不可削弱指：定理只保证「序后」的周期存在，「序前」的周期可以整体缺席，序不能改短。（§1.4）
6. 肉眼（追轨道）看到稳定的周期 3 轨道 $\{0.156149, 0.504666, 0.957417\}$；定理保证周期 1 到 8（乃至一切周期）的点全部存在，程序二分计数确认了这一点。看不到是因为其余轨道不稳定——乘子绝对值大于 $1$，数值上任何微小偏差都被指数放大，轨道迅速滑回稳定周期 3 的吸引盆。（§1.4）
