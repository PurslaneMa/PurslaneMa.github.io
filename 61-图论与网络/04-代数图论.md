# $\rm Chapter \, 4$ 代数图论：谱是图的显微镜

第 1 章把图翻译成邻接矩阵时留了一句伏笔：「谱是最强的不变量，也非全能——这条线到第 4 章收尾」。本章兑现。前半是邻接谱的旧账新算（迹公式、正则性判据）；中段换一台机器——Laplacian 矩阵 $L = D - A$，它把「连通」变成第二个特征值、把「生成树计数」变成特征值乘积、把「最小割」变成二次型极小化，Cheeger 不等式把割与谱钉在同一个不等式里；末段是这套数学最成功的应用之一：谱聚类，把「按结构切图」化成「取特征向量、做 k-means」。贯穿全章的数值锚是 Petersen 图——它的邻接谱在第 1 章手算过，这里用 numpy 逐位复核，再算出它的 Laplacian 谱、2000 棵生成树、以及「Cheeger 下界恰好取等」这个漂亮巧合。

> **开始前自检**：本章假设你已经会：
>
> 1. □ 实对称矩阵的特征分解：特征值全实、特征向量可取正交基。
> 2. □ 本册第 1 章：邻接矩阵 $A$、$A^k$ 计走道（§1.4）、Petersen 图的谱 $3, 1^{(5)}, (-2)^{(4)}$（§1.4 与 §1.5）。
> 3. □ Rayleigh 商 $\frac{x^\top M x}{x^\top x}$ 的含义：对称矩阵在单位向量上的极小值是它最小的特征值。
>
> 互文提示：§4.3 的「割」与第 3 章的极图同属「图的结构量」；§4.4 的谱聚类在第 6 章会以图神经网络的形态再登场。

## $\rm \S \, 4.1$ 邻接谱的新账：迹公式与正则性判据

白话：第 1 章已经知道 $A^k$ 的元素是走道数。现在把这件事按对角线求和——迹不看走到哪、只看走了几步，于是图的边数、三角形数这些组合量直接从特征值里读出来。

1. **命题（迹公式）**：设 $G$ 的邻接特征值为 $\lambda_1 \ge \cdots \ge \lambda_n$。则 $\sum_i \lambda_i = 0$，$\sum_i \lambda_i^2 = 2m$，$\sum_i \lambda_i^3 = 6 \times$（三角形数）。
2. 证明一列排开：对称矩阵的迹等于特征值之和也等于对角元之和，而 $A$ 对角全零，故 $\sum \lambda_i = \operatorname{tr}(A) = 0$。对 $A^2$：$\operatorname{tr}(A^2) = \sum_i (A^2)_{ii} = \sum_i d(i) = 2m$，这里用了第 1 章 §1.4 的 $(A^2)_{ii} = d(i)$；另一边 $\operatorname{tr}(A^2) = \sum \lambda_i^2$。对 $A^3$：$(A^3)_{ii}$ 是过 $i$ 的三角形数的两倍（第 1 章 §1.4 的推论），全体求和再除以 2，得 $\operatorname{tr}(A^3)/6$ 为三角形总数。读法：这三个式子把「数边」「数三角形」变成了特征值的初等对称函数——组合计数被线性代数收编。
3. **数值锚**：Petersen 图 $\sum \lambda_i^2 = 9 + 5 - 16 = -2$？验算：$3^2 + 5 \times 1^2 + 4 \times (-2)^2 = 9 + 5 + 16 = 30 = 2 \times 15$，握手账与谱账对上；$\operatorname{tr}(A^3) = 27 + 5 - 32 = 0$，无三角形（围长 5 的另一种说法）。三棱柱的 $\operatorname{tr}(A^3) = 27 + 1 - 16 = 12$，除以 6 恰是它的 2 个三角形——第 1 章 §1.3 那对双胞胎在谱的每一层都分家。
4. **命题（正则性判据）**：连通图 $G$ 是 $d$-正则的，当且仅当最大邻接特征值 $\lambda_1 = d$。
5. 证明两半。**（⇐ 方向的另一半先立）**若 $G$ 连通且 $d$-正则，全 1 向量 $\mathbf{1}$ 满足 $A\mathbf{1} = d\mathbf{1}$，故 $\lambda_1 \ge d$；反过来对任何特征值 $\lambda$ 与特征向量 $x$，取绝对值最大的分量 $|x_i| = \max_j |x_j|$，则
$$
|\lambda|\, |x_i| = |(Ax)_i| = \left|\sum_{j \in N(i)} x_j\right| \le \sum_{j \in N(i)} |x_j| \le d\, |x_i|,
$$
故 $|\lambda| \le d$，$\lambda_1 = d$。**（⇒）**设 $\lambda_1 = d$，Rayleigh 商给出 $\lambda_1 \ge \frac{\mathbf{1}^\top A \mathbf{1}}{\mathbf{1}^\top \mathbf{1}} = \frac{2m}{n} = \bar{d}$（平均度），等号在 $\lambda_1 = d$ 时要求 $A$ 的最大特征向量与 $\mathbf{1}$ 张成同一空间；由 Perron–Frobenius（连通图的最大特征向量可取全正），该特征向量是 $\mathbf{1}$ 的倍数，于是 $A\mathbf{1} = d\mathbf{1}$，即每点度恰为 $d$。读法：$\lambda_1 = d$ 这一个数同时锁死了「连通」与「处处同度」两件事。
6. 谱不变量的失效现场也一并摆出（兑现第 1 章伏笔）：星 $\rm K_{1,4}$ 与 $C_4$ 加孤立点的谱同为 $2, 0, 0, 0, -2$（§4.8 程序复核）——同谱异构，第 1 章 §1.3 说过的话现在有了 numpy 签名。谱比度序列强（双胞胎分家靠它）、但强不过同构本身。

**本节小结**：迹公式把边数与三角形数写成 $\sum \lambda_i^2$ 与 $\sum \lambda_i^3/6$，Petersen 的账（30、0）逐位对上；$\lambda_1 = d$ 刻画「连通正则」；同谱异构对 $\rm K_{1,4}$ 与 $C_4$ 加孤立点给「谱非全能」收尾。

## $\rm \S \, 4.2$ Laplacian：把连通写成第二个特征值

白话：邻接矩阵只记「谁连谁」，Laplacian 再减掉度数，成了图上的「差分算子」：向量 $x$ 想让 ${Lx}$ 变小，就得在每条边两端取值接近——「平滑」与「连通」从此有了同一个特征值坐标。

1. **定义（Laplacian）**：$L = D - A$，其中 $D = \operatorname{diag}(d(1), \ldots, d(n))$。L 是实对称半正定矩阵，特征值可排成 $0 = \mu_1 \le \mu_2 \le \cdots \le \mu_n$。
2. **命题（二次型）**：对任何向量 $x$，
$$
x^\top L x = \sum_{\{i, j\} \in E} (x_i - x_j)^2.
$$
证明：展开右边，每条边贡献 $x_i^2 + x_j^2 - 2 x_i x_j$；逐点聚合 $x_i^2$ 项，顶点 $i$ 出现 $d(i)$ 次，得 $x^\top D x$；交叉项聚成 $-2 \sum_{\{i,j\}} x_i x_j = -x^\top A x$。两项合并即 $x^\top L x$。
3. **命题（零特征值计分量）**：$L$ 的 0 特征值重数等于 $G$ 的连通分量数。证明：$Lx = 0$ 当且仅当 $x^\top L x = 0$（半正定），由二次型公式即 $x$ 在每条边两端取值相同，即 $x$ 在每个连通分量内为常数——这样的向量张成的空间维数恰是分量数。
4. **定义（代数连通度）**：$\mu_2 = \mu_2(L)$ 称为 $G$ 的代数连通度；对应的特征向量称 Fiedler 向量。$\mu_2 > 0$ 当且仅当 $G$ 连通（上一命题直接可得）；$\mu_2$ 越大，图越「难被切开」——§4.3 把这句话变成定理。
5. **定理（Kirchhoff 矩阵–树定理）**：$G$ 的生成树个数
$$
\tau(G) = \frac{1}{n} \prod_{i=2}^{n} \mu_i.
$$
证明思路一段：L 的任意 $n-1$ 阶主子式（划去第 $i$ 行第 $i$ 列）按矩阵–树定理等于 $\tau(G)$（消去–收缩递推可证，此处从略）；而特征多项式 $\det(tI - L) = t \cdot q(t)$ 的线性项系数恰为这 $n$ 个主子式的公共值，与 $\prod_{i \ge 2} \mu_i / n$ 相等，拼起来即得。
6. **数值锚**（§4.8 numpy 实跑）：$K_4$ 的 Laplacian 谱是 ${0, 4, 4, 4}$，$\tau = 4^3/4 = 16$——与第 1 章 §1.5 暴力数出的 $4^2 = 16$ 对账。$C_4$ 的 Laplacian 谱是 ${0, 2, 2, 4}$，$\tau = 8/2 = 4$，数一数：$C_4$ 删去四条边中任意一条都是树，恰 4 棵。Petersen 图的 Laplacian 谱是 $0, 2^{(5)}, 5^{(4)}$（3-正则，$L = 3I - A$，把邻接谱平移即得），$\tau = (2^5 \times 5^4)/10 = 2000$——最著名的反例收藏家连生成树数都有整整齐齐的名片。

**本节小结**：$L = D - A$ 的二次型是「边两端差平方和」，0 特征值重数数分量、$\mu_2$ 量连通、矩阵–树定理把生成树数写成非零特征值乘积除以 $n$；锚点 $K_4$ 的 16、$C_4$ 的 4、Petersen 的 2000。

## $\rm \S \, 4.3$ Cheeger 不等式：割与谱的锁链

白话：上一节末尾说 $\mu_2$ 量「难切程度」，本节给出精确定量。「切」的正式名字叫电导率：挑一小撮顶点 $S$，割边数除以 $S$ 的体积。Cheeger 不等式说这个组合量被第二个特征值夹在上下两个显式界之间——想找好切割，看 Fiedler 向量就够。

1. **定义（电导率）**：$d$-正则图 $G$ 中，对非空顶点集 $S$（$|S| \le n/2$），$\varphi(S) = \frac{\operatorname{cut}(S)}{d\,|S|}$，其中 $\operatorname{cut}(S)$ 是恰有一个端点在 $S$ 中的边数。图电导率 $\varphi(G) = \min_S \varphi(S)$。
2. 对 $d$-正则图，归一化 Laplacian $\mathcal{N} = I - \frac{1}{d} A$ 的特征值是 $0 = \nu_1 \le \nu_2 \le \cdots$，且 $\nu_2 = \mu_2 / d$（$L = dI - A$ 平移而得）。
3. **定理（Cheeger 不等式，离散版）**：
$$
\frac{\nu_2}{2} \le \varphi(G) \le \sqrt{2\, \nu_2}.
$$
4. **下界的完整证明**（$\varphi \ge \nu_2/2$）。任取 $|S| \le n/2$，造测试向量
$$
x_i = \begin{cases} 1/|S|, & i \in S, \\ -1/|\bar{S}|, & i \in \bar{S}. \end{cases}
$$
先验账：$\sum_i x_i = 1 - 1 = 0$，故 $x$ 与常数向量正交，Rayleigh–Ritz 给 $\mu_2 \le \frac{x^\top L x}{x^\top x}$。逐项算：割边两端 $x$ 值差为 $\frac{1}{|S|} + \frac{1}{|\bar{S}|} = \frac{n}{|S|\,|\bar{S}|}$，非割边差为 0，于是
$$
x^\top L x = \operatorname{cut}(S) \cdot \frac{n^2}{|S|^2 |\bar{S}|^2},
\qquad
x^\top x = \frac{1}{|S|} + \frac{1}{|\bar{S}|} = \frac{n}{|S|\, |\bar{S}|},
$$
两式相除：
$$
\mu_2 \le \operatorname{cut}(S)\, \frac{n}{|S|\, |\bar{S}|} \le \operatorname{cut}(S) \cdot \frac{2}{|S|} = 2 \varphi(S),
$$
末一步用了 $|\bar{S}| \ge |S|$。对 $S$ 取最小：$\mu_2 \le 2 \varphi(G)$，即 $\varphi(G) \ge \nu_2/2$。证毕。
5. **上界的证明思路**（$\varphi \le \sqrt{2 \nu_2}$，关键步骤）：取 Fiedler 向量 $f$，把顶点按 $f$ 值从小到大排序，让阈值 $t$ 从最小值扫到中位数，得到一族候选集 $S_t = \{i : f_i \le t\}$。对阈值做概率平均：可以证明存在某个 $t$ 使 $\varphi(S_t) \le \sqrt{2 \nu_2}$（技术核心是把 $\sum_{\{i,j\}} (f_i - f_j)^2 \le \nu_2 \sum_i f_i^2$ 的「梯度能量」转化为扫过过程中的「割的累计」，用 Cauchy–Schwarz 开方收账；完整论证此处从略）。读法：上界是构造性的——**想找到电导率不超过 $\sqrt{2\nu_2}$ 的割，沿着 Fiedler 向量排序扫一遍就行**，这正是 §4.4 谱聚类算法的灵魂。
6. **数值锚**：Petersen 图的电导率。§4.8 程序枚举全部 $2^{10} - 2 = 1022$ 个非平凡子集：$\varphi = 1/3$，由外圈五边形取得（割掉 5 条轮辐，体积 $3 \times 5 = 15$，$5/15 = 1/3$）。而 $\nu_2 = \mu_2/3 = 2/3$，Cheeger 下界 $\nu_2/2 = 1/3$——**Petersen 图让下界恰好取等**。上界 $\sqrt{2 \times 2/3} = \sqrt{4/3} \approx 1.155$ 则相当松（电导率本就 $\le 1$）。一紧一松，正是这套不等式的日常手感。

**本节小结**：电导率 $\varphi$ 定义「最难切」，Cheeger 把它锁进 $\nu_2/2 \le \varphi \le \sqrt{2\nu_2}$：下界用「割集测试向量 + Rayleigh」三行收账，上界靠 Fiedler 向量扫描；Petersen 图 1022 个子集枚举出 $\varphi = 1/3$，与下界严丝合缝。

## $\rm \S \, 4.4$ 谱聚类的数学：松弛、嵌入与 k-means

白话：给定一张图，把它按结构切成几团，团内边密、团间边稀——这是聚类问题最原始的形态。「最小化团间边」有个致命缺陷：把一个孤立点切出去割为零；改成「割边数除以体积」的电导率版（normalized cut）就好得多，但它仍是 NP 难的组合问题。谱聚类的招式：把组合问题**松弛**成连续问题，而连续问题的解恰好是特征向量。

1. **松弛**。把指示向量（$S$ 内为 1、外为 $-|\bar S|/|S|$ 缩放）换成任意实向量 $x \perp \mathbf{1}$，「找电导率最小的割」松弛为「找 Rayleigh 商 $\frac{x^\top L x}{x^\top x}$ 最小的向量」——由 Rayleigh–Ritz，**解是 Fiedler 向量**。§4.3 下界证明里的测试向量正是这一步的组合影子：离散最优割的缩放指示向量就是它的近似解。
2. **算法骨架**（谱聚类三步）：1）算归一化 Laplacian $\mathcal{N}$ 的最小若干特征向量 $v_1 = \mathbf{1}, v_2, \ldots, v_k$；2）把每个顶点 $i$ 嵌成 $k$ 维点 $(v_2(i), \ldots, v_k(i))$；3）在这 $n$ 个点上跑 k-means，聚成 $k$ 类。
3. 为什么第 2 步有效？直觉：$\mathcal{N}$ 的二次型「边两端差平方和」在低维嵌入下惩罚相邻点被分远，嵌入自动把连接紧密的区域挤到一起、稀疏区域拉远；k-means 只需要把已经分开的点云按位置归类。第 2 个特征向量管一刀，第 3、4 个管后续的刀，逐级切开。
4. **数值锚**（§4.8 实跑）：玩具图取两个 $C_4$，之间架两条桥边（顶点 $1$-$5$ 与 $2$-$6$）。归一化 Laplacian 谱：${0, 0.2713, 0.7713, 0.8333, 1.1667, 1.2287, 1.7287, 2}$——$\nu_2$ 与 $\nu_3$ 之间有一个宽缝（$0.2713$ 对 $0.7713$），「两个簇」的谱签名。Fiedler 向量取值 $(-0.308, -0.141, -0.141, -0.308)$ 与 $(0.308, 0.141, 0.141, 0.308)$：前四个点全负、后四个全正，**按符号切分恰好还原两个 $C_4$**，且桥端点（${1, 2, 5, 6}$）的绝对值比非桥端点小——它们离「分界」更近，谱连这点细节都记了账。非归一化的 $\mu_2 = 2 - \sqrt{2} \approx 0.586$，与簇内特征值 2 之间的缝隙同样清晰。
5. 何时失手？谱聚类读的是全局结构：簇间有少量重叠、或簇大小极不均匀时，Fiedler 向量可能偏向切小块而非按语义分组；这些病态各有补救（局部谱方法、深度聚类），但底线不变——**特征向量是松弛解，不是组合最优解**，Cheeger 的 $\sqrt{2\nu_2}$ 上界就是两者差距的定量承诺（可找到的割至多比理论最优差一个常数因子量级）。

**本节小结**：谱聚类 = 组合切割的 Rayleigh 松弛：Fiedler 向量是一刀的解，前 $k$ 个特征向量做嵌入、k-means 收尾；双 $C_4$ 桥图的谱缝（0.2713 对 0.7713）与符号切分是全程数值锚。

### $\rm \S \, 4.7.1$ 关键概念回顾答案

1. 由 $A^k$ 计走道：$(A^2)_{ii} = d(i)$、$(A^3)_{ii} = 2 \times$ 过 $i$ 三角形数；迹等于特征值之和，故 $\sum \lambda_i^2 = 2m$、$\sum \lambda_i^3 = 6 \times$ 三角形数。Petersen：$\sum \lambda_i^2 = 30 = 2 \times 15$（边数账），$\operatorname{tr}(A^3) = 0$（无三角形）。（§4.1）
2. 正则半：$\mathbf{1}$ 是特征向量给 $\lambda_1 \ge d$，分量绝对值论证给一切 $|\lambda| \le d$，故 $\lambda_1 = d$；反向半：Rayleigh 商给 $\lambda_1 \ge$ 平均度，等号要求最大特征向量是 $\mathbf{1}$ 的倍数，这里用 Perron–Frobenius 保证连通图最大特征向量全正。（§4.1）
3. 展开 $\sum_{\{i,j\}} (x_i - x_j)^2$ 逐点聚合成 $x^\top D x - x^\top A x$。$Lx = 0$ 等价于 $x^\top L x = 0$，即 $x$ 在每条边两端相等，即在每个分量内为常数；常数向量个数等于分量数。（§4.2）
4. $\tau(G) = \frac{1}{n} \prod_{i \ge 2} \mu_i$；$K_4$：$4^3/4 = 16$，$C_4$：$(2 \times 2 \times 4)/4 = 4$，Petersen：$(2^5 \times 5^4)/10 = 2000$。（§4.2）
5. 测试向量 $S$ 内 $1/|S|$、$\bar S$ 内 $-1/|\bar S|$；$x^\top L x = \operatorname{cut}(S) \frac{n^2}{|S|^2 |\bar S|^2}$（割边贡献差平方）、$x^\top x = \frac{n}{|S||\bar S|}$；相除得 $\mu_2 \le \operatorname{cut}(S) \frac{n}{|S||\bar S|}$，再由 $|\bar S| \ge |S|$ 放缩到 $2 \varphi(S)$。（§4.3）
6. 把「指示向量」松弛成任意 $\perp \mathbf{1}$ 的实向量、目标换成 Rayleigh 商，解为 Fiedler 向量。宽缝说明图在谱意义上恰好有两团，$\nu_2$ 的符号切分可信；Fiedler 向量绝对值小的点靠近分界（桥端点），携带「离哪个簇远」的局部信息。（§4.4）

### $\rm \S \, 4.7.2$ 应用与辨析答案

1. 5 个顶点；$\sum \lambda_i = 0$ 且 $\sum \lambda_i^2 = 16 + 4 = 20 = 2m$，故 $m = 10 = \binom{5}{2}$，是 $K_5$；三角形数 $\operatorname{tr}(A^3)/6 = (64 + 4 \times (-1))/6 = 10 = \binom{5}{3}$；$\lambda_1 = 4 = n - 1$，完全图必 4-正则。（§4.1）
2. $\mu_2$ 大保证 $\varphi \ge \nu_2/2$ 也大——**任何**割（按电导率）都不小，没有 skinny 分割；不保证不存在中等大小的割，也不保证没有局部的低度瓶颈结构（电导率是全局最小值，$\mu_2$ 只通过不等式单侧控制它）。（§4.3）
3. 桥变少，图更难连也更难切？方向相反：$\nu_2$ 会**变大**（图整体更「连成一体」，电导率与 $\nu_2$ 同向移动——唯一的桥承担全部跨簇流量，割更集中但簇更难被均匀切开，谱上反映为 $\nu_2$ 上升）；符号切分仍成立，只是 Fiedler 向量的负正分布更陡。（§4.4）
4. 迹公式：三角形数 $= \operatorname{tr}(A^3)/6$ 是谱的函数，所以同谱图必同三角形数——$\rm K_{3,3}$（谱 $3, 0^{(4)}, -3$）与三棱柱（谱 $3, 1^{(2)}, 0^{(2)}, (-2)^{(2)}$）谱不同，分家可以靠谱完成；而 $\rm K_{1,4}$ 与 $C_4$ 加孤立点谱同为 $2, 0, 0, 0, -2$，三角形数同为 0，谱在这一对上失手。两句话被同一条迹公式同时讲圆：谱读得出三角形，读不出全部结构。（§4.1）

## $\rm \S \, 4.8$ 可当场复跑的程序段

下面这段 numpy 程序把 §4.1–§4.4 的数值锚全部实算，输出与正文逐位一致：

```python
 # 谱账本：Petersen、C4、K4、双 C4 桥图（numpy 实算）
import numpy as np

def spec(M):
    return np.round(np.sort(np.linalg.eigvalsh(M)), 4)

 # Petersen 图
A = np.zeros((10, 10))
for i in range(5):
    for a, b in [(i, (i + 1) % 5), (5 + i, 5 + (i + 2) % 5), (i, 5 + i)]:
        A[a, b] = A[b, a] = 1
L = np.diag(A.sum(1)) - A
print("Petersen 邻接谱", spec(A))            # [3, 1x5, -2x4]
print("Petersen Laplacian 谱", spec(L))      # [0, 2x5, 5x4]
mu = np.sort(np.linalg.eigvalsh(L))
print("Petersen 生成树数", round(np.prod(mu[1:]) / 10))
print("Petersen 三角形数", np.trace(np.linalg.matrix_power(A, 3)) / 6)

 # C4 与 K4 的矩阵-树对账
def cycle(n, extra=()):
    M = np.zeros((n, n))
    for i in range(n):
        M[i, (i + 1) % n] = M[(i + 1) % n, i] = 1
    for a, b in extra:
        M[a, b] = M[b, a] = 1
    return M

for name, M in [("C4", cycle(4)), ("K4", np.ones((4, 4)) - np.eye(4))]:
    Lm = np.diag(M.sum(1)) - M
    w = np.sort(np.linalg.eigvalsh(Lm))
    print(name, "Laplacian 谱", spec(Lm), "生成树数", round(np.prod(w[1:]) / len(M)))

 # 双 C4 桥图：谱聚类玩具
G = cycle(4, extra=()) ; H = cycle(4, extra=())
A2 = np.zeros((8, 8)); A2[:4, :4] = G; A2[4:, 4:] = H
A2[1, 5] = A2[5, 1] = 1; A2[2, 6] = A2[6, 2] = 1
L2 = np.diag(A2.sum(1)) - A2
D2 = np.diag(A2.sum(1))
Ln = np.linalg.inv(np.sqrt(D2)) @ L2 @ np.linalg.inv(np.sqrt(D2))
w, V = np.linalg.eigh(Ln)
print("双 C4 桥图 归一化谱", np.round(w, 4))
fied = V[:, 1] / np.sqrt(np.diag(D2))
print("Fiedler 向量", np.round(fied, 3))
print("符号切分", ["A" if v < 0 else "B" for v in fied])

 # Petersen 的电导率：暴力枚举全部子集
best = (9, None)
for mask in range(1, 2**10 - 1):
    S = {i for i in range(10) if (mask >> i) & 1}
    if len(S) > 5:
        continue
    cut = sum(A[i, j] for i in S for j in range(10) if j not in S)
    phi = cut / (3 * len(S))
    if phi < best[0]:
        best = (phi, sorted(S))
print("Petersen 电导率", best[0], "取得它的 S", best[1])
print("Cheeger 下界 nu2/2 =", 2 / 3 / 2, " 上界 sqrt(2*nu2) =", round((2 * 2 / 3) ** 0.5, 4))

 # 同谱异构对：K_{1,4} 与 C4+孤立点
S1 = np.zeros((5, 5)); S1[0, 1:] = 1; S1[1:, 0] = 1
S2 = np.zeros((5, 5))
for i in range(4):
    S2[i, (i + 1) % 4] = S2[(i + 1) % 4, i] = 1
print("K_{1,4} 谱", spec(S1), " C4+孤立点 谱", spec(S2))
```
