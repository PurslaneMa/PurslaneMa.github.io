# $\rm Chapter \, 2$ 单纯形法

第 1 章把最优解钉在顶点上、顶点钉在基上。单纯形法（Dantzig, 1947）就是「顶点间的聪明爬坡」：从一个基本可行解出发，每次沿边走向目标更优的相邻顶点，直到无可再优。本章走完全部机制——进基/离基判据、比率检验、终结判据——并在贯穿小例上把每步的表格算清（全册锚，程序可复核）。

## $\rm \S \, 2.1$ 主问题与初始表

贯穿小例（第 1 章 §1.1）：$\max\ 3x + 2y$ s.t. $x + y \le 4$、$x + 3y \le 6$、$x, y \ge 0$。加松弛变量后的标准形：

$$
x + y + s_1 = 4, \qquad x + 3y + s_2 = 6, \qquad \max\ 3x + 2y - z,\ z = 3x + 2y
$$

初始基 $\{s_1, s_2\}$（全松弛，BFS $= (0, 0; 4, 6)$——原点，天然可行）。**单纯形表**：把目标行写成非基变量的系数形式 $z - 3x - 2y = 0$，系数 $(-3, -2)$ 叫**检验数**（reduced cost）——它是「把对应变量抬升一个单位、目标能涨多少」的标价。

## $\rm \S \, 2.2$ 一次迭代：进基、比率检验、离基

一次迭代三步（每一遍都问三个问题）：

1. **进基（选列）**：目标行里挑负得最多的检验数（能涨最多）——本例 $-3$，让 $x$ 进基。
2. **比率检验（选行）**：$x$ 从 0 往上抬，各约束的基变量被压向 0 的速率不同：$s_1: 4/1 = 4$、$s_2: 6/1 = 6$——最小比率 $4$ 先归零，$s_1$ 离基。**白话**：几个约束拔河，最先崩的那个决定能走多远；走过了它可行性就破。
3. **换基（转轴）**：用高斯消元把 $x$ 这一列变成本单位置（$x + s_1 = 4$ 作主行），更新整表。

第一轮转轴后的表（本机程序复算）：约束 $x + s_1 = 4$、$2y - s_1 + s_2 = 2$；目标行 $z + 3s_1 + y = 12$（即 $z = 12 - 3s_1 - y$）。当前 BFS：$x = 4$、$y = 0$、$s_1 = 0$、$s_2 = 2$——正是顶点 $(4, 0)$，目标 $12$。

**两次迭代全表**（把上面的三步逐格算清；程序实测见 §2.5）。全表 4 变量（$x, y, s_1, s_2$）× 2 约束行 + 检验数行，右端常数列放最右。初始表（基 $\{s_1, s_2\}$）：

| 基 | $x$ | $y$ | $s_1$ | $s_2$ | 右端 |
| --- | --- | --- | --- | --- | --- |
| $s_1$ | $1$ | $1$ | $1$ | $0$ | $4$ |
| $s_2$ | $1$ | $3$ | $0$ | $1$ | $6$ |
| 检验数 | $-3$ | $-2$ | $0$ | $0$ | $0$ |

第一次转轴（$x$ 进基、$s_1$ 离基、主元 $= 1$）。主元行除以主元：$s_1$ 行 $\div\, 1$ 原样变成 $x$ 行 $(1, 1, 1, 0 \mid 4)$。其余行减去「本行 $x$ 列系数 $\times$ 新主元行」：

$$
s_2 \text{ 行} = (1, 3, 0, 1 \mid 6) - 1 \times (1, 1, 1, 0 \mid 4) = (0, 2, -1, 1 \mid 2)
$$

逐格：$1 - 1 \cdot 1 = 0$、$3 - 1 \cdot 1 = 2$、$0 - 1 \cdot 1 = -1$、$1 - 1 \cdot 0 = 1$、$6 - 1 \cdot 4 = 2$。检验数行则是**加回** $3 \times$ 主元行（把 $-3$ 抬回 0）：

$$
\text{检验数行} = (-3, -2, 0, 0 \mid 0) + 3 \times (1, 1, 1, 0 \mid 4) = (0, 1, 3, 0 \mid 12)
$$

逐格：$-3 + 3 = 0$、$-2 + 3 \cdot 1 = 1$、$0 + 3 \cdot 1 = 3$、$0 + 3 \cdot 0 = 0$、$0 + 3 \cdot 4 = 12$——右端 12 正是当前目标值（$x = 4$ 的利润）。转轴后的完整表：

| 基 | $x$ | $y$ | $s_1$ | $s_2$ | 右端 |
| --- | --- | --- | --- | --- | --- |
| $x$ | $1$ | $1$ | $1$ | $0$ | $4$ |
| $s_2$ | $0$ | $2$ | $-1$ | $1$ | $2$ |
| 检验数 | $0$ | $1$ | $3$ | $0$ | $12$ |

第二次迭代只剩**检查**：检验数 $(0, 1, 3, 0)$ 全非负，没有进基列——表不再变化，算法终止。「第二次转轴后的表」与上表相同，因为第二轮没有转轴、只有终结检查：这就是 §2.3 最优性判据在表格上的长相。**读法**：转轴＝「主元行归一 + 其余行倍加」的高斯消元，唯一特殊之处是检验数行也跟着消（它的右端自动变成当前目标值）。

**进基次序影响路径长度，不影响终点。** 若第一轮强制让 $y$ 进基（检验数 $-2$），比率检验 $4/1 = 4$ 对 $6/3 = 2$ 选 $s_2$ 离基，之后还要再走两轮：$z$ 依次 $0 \to 4$（顶点 $(0, 2)$，检验数行 $(-7/3,\, 0,\, 0,\, 2/3 \mid 4)$）$\to 11$（顶点 $(3, 1)$，$s_2$ 列检验数 $-1/2$ 仍为负）$\to 12$（回到顶点 $(4, 0)$）。三次转轴对一次转轴——同一条最优性判据，不同进基规则给出不同长度的顶点路径（§2.4 转轴规则问题的伏笔）。

## $\rm \S \, 2.3$ 终结：最优性判据与锚点对账

第二张表里目标行系数全非负（$+3, +1$）：任何变量抬升都会**降低** $z$——当前顶点即最优。**最优性判据**：目标行检验数全 $\ge 0$（max 形式下）⟹ 当前 BFS 最优。

**全册锚对账**（两轮迭代，程序实测）：最优值 $12$ @ $(x, y) = (4, 0)$，与第 1 章顶点枚举逐位一致；总迭代 2 轮（顶点 $(0,0) \to (4,0)$）。**读法**：单纯形第一轮就选中了最优顶点——检验数 $-3$ 指的正是目标函数最陡的方向；运气成分有，机制保证无恙。

## $\rm \S \, 2.4$ 两个理论问题

1. **会循环吗？** 退化（多个 BFS 对应同一顶点）时可能原地打转——Bland 规则（永远选下标最小的进基/离基候选）保证不循环（陈述级，标 Chvátal 第 3 章）；实践中最小比率平局随便选极少真循环。
2. **会走多远？** 单纯形的路径长指数级存在实例（Klee–Minty 立方体），但实践平均多项式——线性规划的真正多项式算法是椭球法（Khachiyan 1979）与内点法（Karmarkar 1984），后者是现代求解器的引擎（出口一句话，本章不展开）。

**读法**：单纯形是「理论最坏指数、实践飞快」的著名案例——算法工程里「平均快」与「最坏保证」分家的教科书现场。

**Bland 反例实测**（Beale 1968 的标准循环例，程序实跑、输出照抄；第 1 条问题「会循环吗」的完整演示）。主问题：

$$
\max\ 0.75x_1 - 150x_2 + 0.02x_3 - 6x_4 \quad \text{s.t.} \quad 0.25x_1 - 60x_2 - 0.04x_3 + 9x_4 \le 0, \;\; 0.5x_1 - 90x_2 - 0.02x_3 + 3x_4 \le 0, \;\; x_3 \le 1
$$

四个结构变量加三个松弛变量，全体非负。这个例子右端大量为 0、专在退化顶点上打转。两种转轴配置的完整 trace：

**配置一：Dantzig 进基 + 比率平局取最小下标离基。**

1. 第 1 轮：$x_1$ 进基（检验数 $-0.75$），$s_1$ 离基（比率平局，取最小下标）；
2. 第 2 轮：$x_2$ 进基（检验数 $-30$），$s_2$ 离基；
3. 第 3 轮：$x_3$ 进基（检验数 $-0.08$），$x_1$ 离基（比率平局）；
4. 第 4 轮：$x_4$ 进基（检验数 $-3$），$x_2$ 离基；
5. 第 5 轮：$s_1$ 进基（检验数 $-1$），$x_3$ 离基（比率平局）；
6. 第 6 轮：$s_2$ 进基（检验数 $-2$），$x_4$ 离基；
7. 第 7 轮检查：基回到 $\{s_1, s_2, s_3\}$——**起点重逢，循环实锤**。

六步恰好绕基序列 $\{s_1, s_2, s_3\} \to \{x_1, s_2, s_3\} \to \{x_1, x_2, s_3\} \to \{x_2, x_3, s_3\} \to \{x_3, x_4, s_3\} \to \{x_4, s_1, s_3\} \to \{s_1, s_2, s_3\}$ 一圈，目标值始终 $z = 0$：算法永不停机。

**配置二：Bland 规则（进基、离基都取最小下标）。** 前四轮与配置一**逐轮相同**，第 5 轮分岔——此刻两张表是同一张，$s_1$ 的检验数是 $-1$、$x_1$ 的检验数是 $-0.5$：Dantzig 取负得最多的 $s_1$，Bland 取下标最小的 $x_1$。此后 Bland 路第 6 轮 $z = 0.008$ 转正，第 7 轮检验数全非负，最优 $z = 0.05$ @ $(x_1, x_3) = (0.04, 1)$（验证：$0.75 \times 0.04 + 0.02 \times 1 = 0.05$，两条 $\le$ 约束分别松 $0.03$ 与紧）。

**读法**：循环不是运气差，是转轴规则的结构缺陷——前四轮同路说明退化里埋着环，谁踩谁进去。Bland 用「牺牲眼前涨幅」（放着 $-1$ 不选、选 $-0.5$）换来终止保证；实践求解器多用微小摄动破坏退化，Bland 是理论保底。

## $\rm \S \, 2.5$ 数值实验

纯 Python 十几行的表格单纯形（二维小例 + 转轴函数），断言：最优 $12$ @ $(4, 0)$、两轮收敛——与 §2.3 锚逐位一致。本机实测通过。

完整实现照抄如下（转轴函数 + 主循环 + 最优性判据，25 行内）：

```python
def pivot(T, r, j):                              # 转轴：主元行归一，其余行倍加消元
    T[r] = [v / T[r][j] for v in T[r]]
    for i in range(len(T)):
        if i != r:
            f = T[i][j]
            T[i] = [a - f * b for a, b in zip(T[i], T[r])]

def simplex(T, basis):                           # T 末行是检验数行；basis[k] = 第 k 行的基变量
    for it in range(1, 100):
        neg = [j for j in range(len(T[0]) - 1) if T[-1][j] < -1e-12]
        if not neg:                              # 最优性判据：检验数全非负
            print(f'第{it}轮: 检验数全非负 -> 最优')
            return T[-1][-1], basis
        j = min(neg, key=lambda j: (T[-1][j], j))          # 进基：负得最多
        r = min((i for i in range(len(T) - 1) if T[i][j] > 1e-12),
                key=lambda i: T[i][-1] / T[i][j])          # 离基：最小比率
        leave = NAMES[basis[r]]
        pivot(T, r, j); basis[r] = j
        print(f'第{it}轮: 进基 {NAMES[j]}, 离基 {leave}, 基={[NAMES[b] for b in basis]}, '
              f'检验数={[round(v, 2) for v in T[-1][:-1]]}, z={T[-1][-1]:g}')

NAMES = ['x', 'y', 's1', 's2']
T = [[1, 1, 1, 0, 4], [1, 3, 0, 1, 6], [-3, -2, 0, 0, 0]]
z, basis = simplex(T, [2, 3])
xy = {NAMES[basis[i]]: T[i][-1] for i in range(2)}
print(f'最优 z={z:g} @ (x, y)=({xy.get("x", 0):g}, {xy.get("y", 0):g})')
```

本机实跑输出（每轮的基、检验数、目标值，逐行照抄）：

```text
第1轮: 进基 x, 离基 s1, 基=['x', 's2'], 检验数=[0.0, 1.0, 3.0, 0.0], z=12
第2轮: 检验数全非负 -> 最优
最优 z=12 @ (x, y)=(4, 0)
```

与 §2.2 的两次迭代全表逐格一致、与 §2.3 锚 $12$ @ $(4, 0)$ 逐位一致。两个接口：这张最优表的检验数行 $(0, 1, 3, 0 \mid 12)$ 正是第 3 章 §3.3「从单纯形表读对偶解」的输入——松弛列的 $(3, 0)$ 就是对偶最优解 $(u, v)$；而单纯形落脚过的两个基 $\{s_1, s_2\}$、$\{x, s_2\}$ 都在第 1 章 §1.3 的六基枚举表里——顶点枚举是「全部可能」，单纯形是「挑着走」。

## $\rm \S \, 2.7$ 本章自测答案

1. 非基变量抬升一单位时目标的净变化率；负 ⟹ 能涨。（§2.1）
2. 进基选「涨最多的方向」、比率检验选「最先崩的约束」、转轴完成基的交换。（§2.2）
3. 超过最小比率会让某个基变量变负、破坏可行性。（§2.2）
4. 检验数全非负 ⟹ 任何抬升都不涨 ⟹ 当前 BFS 最优。（§2.3）
5. 退化情形的循环（Klee–Minty 之外的理论死角）。（§2.4）
6. 单纯形实践快但最坏指数；内点法多项式保证、大规模问题用。（§2.4）
7. $s_2$ 离基（比率 $6/3 = 2 < 4$）。推导：$y$ 行 $= s_2$ 行 $\div\, 3 = (1/3,\, 1,\, 0,\, 1/3 \mid 2)$，检验数行加回 $2 \times$ 该行：$(-3 + 2/3,\; 0,\; 0,\; 2/3 \mid 0 + 2 \cdot 2) = (-7/3,\, 0,\, 0,\, 2/3 \mid 4)$。$z = 4$，对应顶点 $(0, 2)$——离最优还差两轮（§2.2 的备选路径 trace）。（§2.2）
8. 分岔发生时两张表是同一张：$s_1$ 检验数 $-1$、$x_1$ 检验数 $-0.5$，Dantzig 取 $-1$（涨最多）、Bland 取 $x_1$（下标最小）。代价是眼前涨幅变小（Bland 路第 6 轮 $z$ 才转正），收益是第 7 轮到达最优 $z = 0.05$，而不是像 Dantzig 路那样绕回起点永不停机。（§2.4）
9. 不会。第一轮负检验数只有 $x(-3)$ 与 $y(-2)$，Bland 取下标最小的 $x$，与 Dantzig 同选——两轮收敛、锚 $12$ @ $(4, 0)$ 不变。规则只在「负得最多者不是最小下标」时才分岔（Beale 例第 5 轮的 $s_1$ 对 $x_1$）。（§2.5）
