# R1 复习总结：信息论

六章压成三句话：**熵**（第 1—2 章）是「最优编码下每符号的平均位数」，Kraft 不等式把它变成硬下界、Huffman 把它逼近到 1 bit 之内；互信息是熵的三副面孔，数据处理不等式宣告「加工不能无中生有」；**两大定理**（第 3—4 章）把「压缩」与「传输」双双钉在天花板上——AEP 说典型序列只有 $2^{nH}$ 个、信道容量说速率 $R < C$ 才能无误传；**两个出口**（第 5—6 章）最大熵原理解释「模型为什么长得像指数族」，Kolmogorov 复杂度说「压缩即理解、随机即不可压」。验收标准：闭卷清单答出几成、§R1.3 六条心智模型能默几条。

## $\rm \S \, R1.3$ 核心心智模型复读

1. **熵＝最优码长的下界**：不是「混乱度」的模糊说法，是 $H \le L < H+1$ 的硬不等式。
2. **Kraft＝长度的会计约束**：任何前缀码的长度向量必须 $\sum 2^{-l_i} \le 1$——码长的预算表。
3. **互信息＝可传递的信息上限**：三副面孔一个数；DPI 说后处理只能减不能增。
4. **AEP＝典型集经济学**：$2^{nH}$ 个典型序列承担全部概率，其余「可忽略」。
5. **容量＝可达速率的红线**：$R < C$ 有码、$R > C$ 必败；构造留给编码理论册。
6. **最大熵＝不塞偏见；K＝压缩极限**：一个从约束推分布、一个从压缩读复杂度——同一件事的两面。

## $\rm \S \, R1.4$ 交错练习

2. $I(X; X) = ?$（答：$H(X)$）
3. 一枚均匀硬币抛 n 次的典型集大小量级？（答：$2^n$ 全是典型的，无压缩空间，§3.2）
4. 在 $[0,1]$ 上均匀分布与在 $\{0,1\}$ 上伯努利(0.5) 的熵比较？（答：离散的 1 bit vs 连续的微分熵 0——离散/连续口径不同，勿混）
5. BSC(0.5) 的容量？（答：0——输出与输入独立）
6. 固定方差下最大熵分布？（答：高斯，§5.2）
7. gzip 压缩后的长度是 $K$ 的什么？（答：上界，§6.2）

## $\rm \S \, R1.5$ 易混点对照

1. **熵 vs 微分熵**：离散有限、非负；连续可负、依赖坐标单位——别把公式硬搬。
2. **$H(X|Y)$ vs $H(Y|X)$**：一般不等；链式法则里顺序不能换（$H(X,Y)$ 才对两者对称）。
3. **互信息 vs 相关系数**：MI 抓一切依赖（含非线性）、相关只抓线性——$Y = X^2$ 时相关 0 而 MI 正。
4. **KL vs 距离**：KL 非对称、不满足三角不等式——不是度量；互信息是对称化的 KL（联合到边际积）。
5. **检错 vs 纠错**：CRC/哈希只标记错（可能漏检）；纠错要定位——码率代价差一个量级（第 49 册接口）。
6. **容量 vs 码率**：容量是存在性红线、码率是具体码的比值；好码的码率逼近容量。

## $\rm \S \, R1.6$ 答案与提示

### 闭卷回忆清单

1. $H = -\sum p \log_2 p$；自信息 $-\log_2 p$ 的期望；单位 bit。（§1.1）
2. 前缀码 ⟹ $\sum 2^{-l_i} \le 1$（区间不重叠）；反向可构造。（§1.3）
3. 下界：$H - L \le \sum p \log(p \cdot 2^{l_i}) \le 0$（Kraft＋Jensen）；上界：$l_i = \lceil -\log p_i \rceil$。（§1.4）
4. ${0, 11, 101, 100}$；$L = 1.85$；$H = 1.801609$。（§1.5）
5. $I = H(X) - H(X|Y) = H(Y) - H(Y|X) = H(X) + H(Y) - H(X,Y)$。（§2.1）
6. Jensen 作用于 $-\log$；$I = D(p(x,y) \| p(x)p(y))$。（§2.3）
7. $X \to Y \to Z$ ⟹ $I(X;Z) \le I(X;Y)$；用 $I(X;(Y,Z))$ 两种展开＋条件独立。（§2.4）
8. $H(P,Q) = H(P) + D(P\|Q)$；交叉熵是 MLE 的等价损失（负对数似然）。（§2.5）
9. 概率→1；每序列概率 ≈ $2^{-nH}$；大小 ≈ $2^{nH}$。（§3.2）
10. 每块 n 符号编一次，$L^{(n)}/n \to H$；余量 $O(1/n)$。（§3.5）
11. $C = \max_{p(x)} I(X;Y)$；BSC：$C = 1 - H(p)$；$p = 0.11$ → 0.500084。（§4.1—4.2）
12. 可达性用联合典型解码；逆用 Fano 不等式。（§4.3）
13. 均匀；高斯；截断指数。（§5.2）
14. 最短输出 x 的程序长度；不可计算（归约停机）；计数论证。（§6.1—6.3）
