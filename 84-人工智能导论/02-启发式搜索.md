## $\rm \S \, 2.1$ UCS 的盲区：排序里没有「未来」

UCS 按 ${g(n)}$ 排序，${g(n)}$ 是从起点到 ${n}$ 已经付出的真实代价。这个排序完全由过去决定：节点离起点越近越先被处理，像一个从起点均匀扩散的涟漪，涟漪每前进一格，就把那一圈所有节点都摸一遍，不管这一圈是朝着目标还是背着目标。

这不是抽象批评。本章 $\rm \S \, 2.7$ 的实验在八数码上把启发函数设为零（此时 A* 与 UCS 完全等价，理由见 $\rm \S \, 2.3$），30 个随机实例平均展开 36227.9 个节点；最难的一个实例展开 180184 个节点，而八数码全空间只有 181440 个可达状态，等于把整个空间几乎翻了一遍才碰到目标。展开一个节点就要生成它的全部后继、排一次堆，这些算力花在了大量「离目标越来越远」的方向上。

导航软件给了这个问题的直觉版本：你在高速上已经开了 40 分钟（这是 ${g}$），导航显示「预计还需 23 分钟」（这是对剩余代价的估计），你真正用来选路的其实是两项之和。UCS 只用了第一项。本章的任务就是把第二项加回来。

## $\rm \S \, 2.2$ 启发函数：给「还剩多远」定价

**启发函数（heuristic function）** ${h}$ 是从状态到非负整数的函数，${h(s)}$ 读作「从状态 ${s}$ 到最近目标的估计剩余代价」。它只做估计，不承诺准确。为了谈论「准确」，先定义真值：${h^*(s)}$ 表示从 ${s}$ 到目标的真实最优代价。${h}$ 是我们要设计的估计，${h^*}$ 是它想逼近的对象。

八数码上最常用的两个启发函数：

1. **错位砖**：不在自己目标位置上的非空砖块个数。每块错位的砖至少要动一步，所以它是对真实代价的下界式估计。
2. **曼哈顿距离**：每块砖到其目标位置的横向格数加纵向格数之和（不许斜走，与棋盘移动规则同口径），再求和。

拿一个具体状态算一遍。初始状态 ${S}$ 在左，目标在右：

```text
2 1 3        1 2 3
4 6 5        4 5 6
7 8 _        7 8 _
```

错位砖：2、1、6、5 四块砖不在目标位置，${h = 4}$。曼哈顿：2 和 1 互换位置各差 1 格，6 和 5 各差 1 格，${h = 4}$。两者都没看到一个问题：1 和 2 这对砖互相挡路，谁也不能一步滑到位。第三个启发函数**线性冲突**（linear conflict）在曼哈顿之上加罚：某一行（或列）里若有两块以上目标就在本行（列）的砖互相挡序，至少有一块要移出线外再回来，每多一块这样的砖罚 2。本例第 0 行 2 和 1 逆序、第 1 行 5 和 6 逆序，各罚 2，得 ${h = 8}$。这个状态的 ${h^*}$ 可以用全空间搜索算出，等于 18：三个估计都没超，但一个比一个贴近。启发函数的设计水平，就用「贴得多近」衡量。

## $\rm \S \, 2.3$ A*：把两笔账相加

**A\* 搜索（A* search）**只用一行公式改造 UCS：按**评估函数（evaluation function）**

$$
f(n) = g(n) + h(n)
$$

从小到大弹出节点。${g(n)}$ 是已付代价的真实账，${h(n)}$ 是剩余代价的估计账。这个结构解释了两个已知的搜索：令 ${h \equiv 0}$，${f = g}$，A* 逐字退化为 UCS；令排序只看 ${h}$，就是本节末尾要讲的贪心最佳优先。所以 A* 不是新算法，是 UCS 在排序键上开的一个口子。

图搜索版 A* 的主循环：

1. 把起点以 ${g = 0}$ 放入堆，堆项是 ${f}$、${g}$、状态三元组，另用一张表记录每个状态当前已知的最好 ${g}$。
2. 弹出 ${f}$ 最小的堆项。若这个 ${g}$ 大于表中记录（过期堆项，状态后来又找到了更短路径），丢弃，回到第 2 步。
3. 若状态是目标，返回 ${g}$。
4. 否则展开它：对每个后继，若新 ${g}$ 更小，更新表、以 ${f = g + h}$ 入堆。
5. 堆空则无解。

```python
import heapq

def astar(start, goal, h, neighbors):
    """图搜索 A*。h(s) 返回估计剩余代价；
    neighbors(s) 返回 (后继, 一步代价) 列表。返回最优代价或 None。"""
    pq = [(h(start), 0, start)]
    best_g = {start: 0}
    while pq:
        f, g, s = heapq.heappop(pq)
        if g > best_g[s]:            # 过期堆项：这个状态已有更短路径
            continue
        if s == goal:
            return g
        for t, c in neighbors(s):
            ng = g + c
            if ng < best_g.get(t, float("inf")):
                best_g[t] = ng
                heapq.heappush(pq, (ng + h(t), ng, t))
    return None
```

代码里唯一值得多看一眼的是第 10 行的过期判断：同一个状态可能被多条路径入堆，堆里留着旧账，弹出时对一下表就知道该不该扔。至于这个机制什么时候够用、什么时候会算错账，正是 $\rm \S \, 2.4$ 和 $\rm \S \, 2.5$ 的主题。

## $\rm \S \, 2.4$ 可采纳性：最优性的证明

估计可以悲观也可以乐观。导航把剩余时间报高了，你会绕开一条其实更快的路；报低了没大事，你只是碰巧走了好路。搜索同理：要保证 A* 找到的解最优，估计必须「不夸大」。于是有：

**定义（可采纳性，admissibility）**：若对每个状态 ${s}$ 都有

$$
0 \le h(s) \le h^*(s)
$$

（含约定 ${h(\text{goal}) = 0}$），称 ${h}$ 是可采纳的。直观说法：宁可低估，不许高估。

**定理 1**：${h}$ 可采纳时，树搜索版 A* 返回的解最优。

证明。设最优代价为 ${C^*}$，反设 A* 弹出目标时带回代价 ${G > C^*}$。取一条最优路径 ${s_0 = \text{start}, s_1, \ldots, s_k = \text{goal}}$，逐个考察路径上的节点。

1. 弹出目标那一刻，不可能路径上所有节点都已展开：若 ${s_0, \ldots, s_{k-1}}$ 全部展开过，它们沿这条路径的后继就都进了堆，包括 ${g = C^*}$ 的目标项，其 ${f = C^* < G}$，堆会先弹它，矛盾。
2. 所以存在沿路径第一个尚未展开的节点 ${s_i}$；它的前驱 ${s_{i-1}}$ 已展开，故 ${s_i}$ 已在堆中且 ${g(s_i) = i}$。
3. 由可采纳性，${f(s_i) = i + h(s_i) \le i + h^*(s_i) = C^* < G}$。
4. 堆按 ${f}$ 取最小，${s_i}$ 必须先于那个 ${f = G}$ 的目标项被弹出。对新的 ${s_i}$ 重复第 1 步的论证，沿路径一格一格推进，最终 ${g = C^*}$ 的目标项进堆并在任何 ${f > C^*}$ 的目标项之前弹出。与 ${G > C^*}$ 矛盾。∎

第 3 步是可采纳性出场的地方：它把「估计」换成了「真值下界」，排序键于是变成了真实代价的可靠上限比较。而树搜索的重复节点问题在图搜索里换了一副面孔：图搜索若对已弹出（closed）的状态不再重开，可采纳性不足以保最优，因为更优路径可能后到。两个补救：要么允许重开（代码里 ${ng < best_g}$ 分支就是干这个的，代价是重复展开），要么把 ${h}$ 的要求加码到一致性，见下一节。

## $\rm \S \, 2.5$ 一致性：图搜索的保险

**定义（一致性，consistency）**：对每条边 ${s \xrightarrow{c} s'}$（${c}$ 为一步代价）都有

$$
h(s) \le c + h(s')
$$

并把 ${h(\text{goal}) = 0}$ 作为定义的一部分。这就是测距里的三角不等式：直达的估计不能超过绕一站的估计加上那一站的票价。它比可采纳性强，强在哪由两个定理说明。

**定理 2**：一致 ⇒ 可采纳。

证明。设 ${s_0 = s, s_1, \ldots, s_k = \text{goal}}$ 是 ${s}$ 到目标的最优路径，${g^*(s_0)}$ 记其总代价。沿路径反复套一致性：

$$
h(s_0) \le c_1 + h(s_1) \le c_1 + c_2 + h(s_2) \le \cdots \le g^*(s_0) + h(s_k) = h^*(s_0)
$$

末步用了 ${h(\text{goal}) = 0}$。∎

**定理 3**：${h}$ 一致时，${f}$ 沿任何搜索路径单调不减，且图搜索 A* 不需要重开：每个状态第一次被弹出时其 ${g}$ 已最优，因而目标首次弹出即得最优解。

证明。若 ${s'}$ 是 ${s}$ 的后继、边代价 ${c}$，由一致性 ${h(s) \le c + h(s')}$，于是

$$
f(s') = g(s) + c + h(s') \ge g(s) + h(s) = f(s)
$$

${f}$ 沿路径不减。再证弹出时 ${g}$ 已最优：反设某状态 ${s}$ 第一次弹出时 ${g(s) > g^*(s)}$，取 ${s}$ 的一条最优路径，令 ${n}$ 为路径上第一个尚未弹出的节点（起点已弹出且 ${g}$ 正确，故这样的 ${n}$ 存在；设其前驱已弹出），则 ${n}$ 正在堆中且 ${g(n) = g^*(n)}$。对 ${n}$ 到 ${s}$ 的路径段逐边套上面的单调性，得 ${f(n) \le g^*(s) + h(s)}$；又 ${h \ge 0}$（可由定理 2 与 ${h^* \ge 0}$ 得），故

$$
f(s) = g(s) + h(s) > g^*(s) + h(s) \ge f(n)
$$

堆本该先弹 ${f}$ 更小的 ${n}$，与 ${s}$ 已被弹出矛盾。∎

一致的反方向不成立：可采纳不推出一致。构造一个反例，定义 ${h(s) = h^*(s)}$（当 ${h^*(s)}$ 为偶数），否则 ${h(s) = 0}$。逐状态看，${h(s) \le h^*(s)}$ 恒成立，可采纳；但取一个 ${h^* = 2}$ 的状态 ${s}$，它沿最优路径的前驱 ${s'}$ 满足 ${h^*(s') = 1}$，于是 ${h(s) = 2 > 1 + h(s') = 1}$，一致性被击穿。这个 ${h}$ 在实际中不可计算，但它证明了两条件之间没有反向通道，也让 $\rm \S \, 2.7$ 里即将实测的「一致性抽查」有了用武之地。

本章实测的三个启发函数在八数码上可以逐步验证一致：每次移动只动一块砖，错位砖计数至多翻转一块的状态（${|\Delta h| \le 1}$），曼哈顿和恰好变化 1。线性冲突的逐线罚分在 30000 对相邻状态抽查中零违反；抽查全对不等于证明，只说明未发现反例。

## $\rm \S \, 2.6$ 支配关系：换更聪明的 h 值不值

直觉说估计越准展开越少，这条直觉也能证出来，但需要先把「更准」说清。

**定义（支配，dominance）**：设 ${h_1, h_2}$ 都可采纳。若对所有状态 ${h_2(s) \ge h_1(s)}$，称 ${h_2}$ 支配 ${h_1}$。

**定理 4**：${h_2}$ 支配 ${h_1}$ 时，A*（用 ${h_2}$）展开的节点集不含任何 ${f_1(n) < C^*}$ 之外的「必然展开」节点；除最优代价并列的边界情形外，展开数不多于用 ${h_1}$。

证明。先立一个事实：可采纳 ${h}$ 下，A* 必展开每个 ${f(n) < C^*}$ 的节点。这直接来自定理 1 的证明：任何 ${f(n) < C^*}$ 的节点只要不展开，它就是最优路径论证中那个「该弹未弹」的节点，A* 无法停下。于是两个启发函数各自的「必然展开集」分别是 ${\{n : f_1(n) < C^* \}}$ 与 ${\{n : f_2(n) < C^* \}}$。由支配性 ${f_2(n) = g(n) + h_2(n) \ge g(n) + h_1(n) = f_1(n)}$，前者是后者的子集。∎

定理 4 的前提是两边都可采纳，这个前提不能省。${\S \, 2.7}$ 的实测里，线性冲突支配曼哈顿、曼哈顿支配错位砖、错位砖支配零函数，平均展开数 ${321.8 \le 563.5 \le 5594.1 \le 36227.9}$ 与支配链严格同向。而「1.5 倍曼哈顿」数值上处处不低于曼哈顿，展开数也确实最少（224.7），但它不可采纳，定理 4 的前提被拆掉，代价立刻从展开数转移到解的质量上：30 个实例里它返回了 1 个次优解。

把本章的条件排成一条链：任意函数、可采纳、一致。往右走一层，保证就厚一层：可采纳买到树搜索最优；一致再买到免重开与目标首次弹出即最优；同时每往右一层，满足条件的函数族就变小一圈，错位砖与曼哈顿都在最里层，$\rm \S \, 2.9$ 的成对计数线性冲突连中间层都进不去。选 ${h}$ 的流程于是固定：先问自己要哪一层保证，再逐条核对函数的资格，而不是写完代码再看运气。

## $\rm \S \, 2.7$ 实测：30 个八数码实例的账

实验设置：八数码，目标 ${1\,2\,3 / 4\,5\,6 / 7\,8\,\_}$；先用 BFS 从目标反扫全空间，得 181440 个可达状态的精确距离表（最大深度 31），于是每个实例的 ${h^*}$、每个启发函数是否可采纳都可以对账；再以固定种子 20261108 随机游走 120 步生成 30 个互不相同的实例；对每个实例分别以 ${h_0}$（零函数）、错位砖、曼哈顿、线性冲突、1.5 倍曼哈顿运行图搜索 A*，并以曼哈顿运行贪心最佳优先（排序只看 ${h}$）。计数口径与第 1 章 $\rm \S \, 1.5$ 一致：展开指从堆中弹出并真正生成后继的节点数，不含过期堆项；生成指入堆总次数。语言 Python 3.12.3，总耗时 3.87 秒。结果如下（30 个实例平均）：

| 启发函数 | 平均展开 | 平均生成 | 平均耗时 s | 最优解数 | 平均解长 |
| --- | --- | --- | --- | --- | --- |
| ${h_0}$（等价 UCS） | 36227.9 | 45714.9 | 0.0676 | 30/30 | 17.33 |
| 错位砖 | 5594.1 | 8048.1 | 0.0131 | 30/30 | 17.33 |
| 曼哈顿 | 563.5 | 884.6 | 0.0015 | 30/30 | 17.33 |
| 线性冲突 | 321.8 | 513.2 | 0.0023 | 30/30 | 17.33 |
| 1.5 倍曼哈顿 | 224.7 | 368.7 | 0.0005 | 29/30 | 17.40 |
| 贪心（只看 ${h}$） | 232.2 | 392.1 | 0.0005 | 7/30 | 33.80 |

三个读法。第一，启发函数把平均展开从 36227.9 压到 563.5，64 倍；错位砖到曼哈顿又是一个 10 倍：两个函数都数「错位的砖」，但曼哈顿数得更细。第二，估计的贴进度与展开数对得上：在两万个随机状态上，错位砖平均只达到真值的 33.2%，曼哈顿 64.3%，线性冲突 69.4%，比率越高展开越少，定理 4 的方向在数据里肉眼可见。第三，贪心展开数与 1.5 倍曼哈顿同档（232.2 对 224.7），但解长平均 33.80 对 17.40：只看估计的搜索跑得飞快、绕路惊人。

两个审计把「没翻车」和「不会翻车」区分开。其一，可采纳性抽查：从全空间随机抽 20000 个状态，逐个验证 ${h(s) \le h^*(s)}$。错位砖、曼哈顿、线性冲突零违反；1.5 倍曼哈顿违反 7630 次（38.2%，最大超出量 11）。其二，一致性抽查：随机抽 30000 个状态、各取一个真实相邻状态，验证 ${h(s) \le 1 + h(s')}$。前两者与线性冲突零违反，1.5 倍曼哈顿违反 7448 次（24.8%）。还有一个更隐蔽的案例放在下一节，因为它恰好构成一个典型错误。

单实例的细节更有体感。30 个实例中最难的一个 ${h^* = 28}$：${h_0}$ 展开 180184 个节点（全空间的 99.3%），错位砖 70751，曼哈顿 4991，线性冲突 2745；1.5 倍曼哈顿只展开 1248 个却返回 30 步的次优解；贪心展开 382 个，返回 60 步，比最优长一倍还多。展开数、解质量、可信度三笔账在同一个实例上全部对齐。

## $\rm \S \, 2.8$ h 从哪里来：松弛问题

启发函数不是拍脑袋凑的，它的合法来源有一个统一模板：**松弛问题（relaxed problem）**。把原问题的某条规则删掉，问题变简单，能直接算出精确最优代价；因为规则只删不加，任何原问题的解也是松弛问题的解，所以松弛问题的最优代价不超过原问题的最优代价。拿它当 ${h}$，可采纳性自动成立。

八数码的两个经典启发函数都是这么来的：

1. 允许一块砖瞬移到任意格子（无视空格与其他砖）：每块错位砖瞬移一次即到位，精确代价就是错位砖数。
2. 允许一块砖滑入相邻格但无视空格占位：每块砖独立直线走到位，精确代价就是曼哈顿距离。

拿 $\rm \S \, 2.2$ 的状态走一遍线性冲突的罚分账。第 1 行从左到右是 4、6、5，三块砖的目标都在本行，把它们的目标列号按当前位置排成一串是 0、2、1；最长严格递增子序列长 2（0 后面接 1 或接 2），于是至少 ${3 - 2 = 1}$ 块要出线，罚 2。第 0 行 2、1 的目标列号串是 1、0，递增子序列长只有 1，也罚 2。四步曼哈顿加两个罚分，正是 ${h = 8}$ 的来历。

曼哈顿比错位砖准，因为它的松弛保留的规则更多，下界更紧。线性冲突则再进一步：它不再对应一个松弛问题，而是在曼哈顿的基础上逐行逐列做附加推理（挡序的砖必须额外出线回线），由 Hansson、Mayer 与 Yung 在 1992 年证明其仍不超出真值。设计新启发函数的套路于是清晰：找一个能精确求解的松弛版本；想再加固，就做局部推理并单独证明下界，而不是凭直觉调大系数，原因见下一节的第一个错误。

## $\rm \S \, 2.9$ 两个典型错误与证据式排查

**错误一：把估计调大一点，「应该」还是下界。** 把曼哈顿乘 1.5，平均 ${h/h^*}$ 从 0.643 涨到 0.976，展开数全场最低，看上去全面胜出；但 30 个实例里有 1 个返回 30 步而真实最优 28 步。这种错误的可怕处在于「几乎全对」：不设对账组的话，测试全绿，bug 潜伏。排查手段本章已经用过两遍：找一个独立来源的真值（八数码全空间只有 181440 个状态，BFS 反扫一遍就拿到全部 ${h^*}$），然后做可采纳性抽查。38.2% 的违反率在这种审计下无处藏身。

**错误二：直觉上更「满」的公式更安全。** 线性冲突有个流行写法：同线挡序砖对每对罚 2。一行里三块砖全部逆序时它罚 ${2 \times 3 = 6}$，而真实额外代价只有 4（最长递增子序列长 1，移出 2 块，每块 2 步），凭空多算 2。实验里它的可采纳性抽查在 20000 个状态中抓到 1 次违反（最大超出量恰为 2），一致性抽查抓到 114 次（0.38%，最大单步降幅 3）。最阴险的是，30 个求解实例它仍然全部最优：错误没有当场发作。正确写法是按「必须移出线外的砖数」计罚，即每线罚 ${2 \times (k - \text{LIS})}$，这才是 Hansson 等人证明可采纳的版本。两个错误合起来是同一课：启发函数的正确性是数学性质，不是工程手感；每换一个公式，就重跑一遍抽查。

## $\rm \S \, 2.11$ 应用与辨析

1. 把曼哈顿距离乘 1.2 作为新启发函数。判断它是否可采纳，预测相对曼哈顿的展开数与解质量变化，并引用本章实验中 1.5 倍版本的实测证据支持你的预测。
2. 设想一个能精确计算 ${h^*}$ 的场景：这样的 ${h}$ 可采纳吗？一致吗？A* 会展开哪些节点？为什么实际中没人这么用？
3. 同学写了一个新的八数码启发函数，在 30 个测试实例上全部返回最优解，于是宣称「我的 ${h}$ 可采纳」。指出这个论证的漏洞，并给出一个能在几秒内跑完、可能戳穿它的检验流程。

## $\rm \S \, 2.12$ 答案

1. 定义：对所有状态 ${0 \le h(s) \le h^*(s)}$ 且 ${h(\text{goal}) = 0}$（$\rm \S \, 2.4$）。在定理 1 第 3 步：它把堆中路径节点 ${s_i}$ 的 ${f(s_i) = i + h(s_i)}$ 压到不超过真实剩余 ${h^*(s_i)}$，从而 ${f(s_i) \le C^*}$，保证最优路径的「前沿」永远先于次优目标项被弹出（$\rm \S \, 2.4$）。
2. 一致 ⇒ 可采纳（定理 2，沿最优路径逐边套三角不等式，$\rm \S \, 2.5$）；反向不通，反例是按 ${h^*}$ 奇偶切换「精确值/零」的函数，可采纳但在 ${h^*}$ 偶数与奇数相邻状态间击穿（$\rm \S \, 2.5$）。一致性额外买到：${f}$ 沿路径单调不减、无需重开、目标首次弹出即最优（定理 3，$\rm \S \, 2.5$）。
3. ${h \equiv 0}$ 时 ${f(n) = g(n) + 0 = g(n)}$，排序键与 UCS 完全相同，两者逐堆项一致（$\rm \S \, 2.3$）；实验也用它当对照（$\rm \S \, 2.7$ 表首行）。
4. 定义：${h_1, h_2}$ 都可采纳且处处 ${h_2 \ge h_1}$（$\rm \S \, 2.6$）。定理 4：${f_2 \ge f_1}$ 使 ${h_2}$ 的必然展开集是 ${h_1}$ 的子集。1.5 倍曼哈顿不可采纳，前提不成立，定理对它失去效力；它展开少是事实，但付出了次优解（$\rm \S \, 2.6$、$\rm \S \, 2.7$）。
5. 松弛问题：删掉原问题部分规则得到的更简单版本，其最优代价是原问题的下界（$\rm \S \, 2.8$）。因为原问题的每个解都是松弛问题的解，松弛最优代价不会超过原最优代价，直接拿它当 ${h}$ 就是可采纳的；错位砖与曼哈顿分别是「砖可瞬移」「砖可无视空格滑行」两个松弛的精确代价（$\rm \S \, 2.8$）。

**应用 1**：1.2 倍曼哈顿不可采纳（曼哈顿是紧下界，1.2 倍会在 ${h^* < 1.2 \cdot h_{\text{man}}}$ 的状态上超出，例如 ${h^* = 5}$、${h_{\text{man}} = 5}$ 时估 6）。预测：展开数进一步减少但出现次优解，且次优是潜伏的、多数实例仍最优。证据：1.5 倍版本展开 224.7 全场最低、30 例中 1 例次优、可采纳性抽查违反率 38.2%（$\rm \S \, 2.7$、$\rm \S \, 2.9$）。
**应用 2**：${h = h^*}$ 可采纳（等于真值）且一致（${h^*(s) \le c + h^*(s')}$ 正是最短路的定义）。此时 ${f}$ 沿最优路径恒等于 ${C^*}$，其余路径 ${f > C^*}$，A* 几乎只沿最优路径推进。但算出 ${h^*}$ 本身就是原问题，等于先解完再搜索；它的价值是理论基准，宣判一切真实启发函数的下界地位（$\rm \S \, 2.2$、$\rm \S \, 2.5$）。
**应用 3**：漏洞：可采纳性是对全部状态的性质，30 个实例只覆盖了空间的一亿分之一，且「返回最优解」与「${h}$ 不夸大」没有直接逻辑通道；$\rm \S \, 2.9$ 的成对计数线性冲突在 30 个实例上同样全最优，却在抽查中被抓到夸大。流程：从目标反扫全空间建距离表（八数码 181440 状态，BFS 约 0.3 秒），随机抽两万个状态验证 ${h(s) \le h^*(s)}$，再做 30000 对相邻状态的一致性抽查；两轮零违反才算过了体检，但仍只是「未发现反例」，不是证明（$\rm \S \, 2.7$、$\rm \S \, 2.9$）。
