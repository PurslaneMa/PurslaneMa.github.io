# $\rm Chapter \, 7$ 单片二阶逻辑与自动机：Büchi 与 Courcelle

第 6 章末尾留了一个预告：一阶逻辑的量词只能落在「点」上，而有些性质天生要谈「存在一个集合」。本章把量词升到集合，得到单片二阶逻辑（monadic second-order logic，MSO），然后展开本册最工整的一组重合：MSO 在字上恰好抓住正则语言（Büchi–Elgot–Trakhtenbrot 定理），在有界树宽的图上恰好抓住一批线性时间可判定的问题（Courcelle 定理），在无界图上则直接不可判定。自动机的状态、MSO 的集合量词、树上的动态规划，将被看成同一个机制的三张脸。

> **开始前自检**：本章假设你已经会：

> 1. □ FOL 的语法与语义：结构、关系符号、量词，${\mathcal M\vDash\varphi}$ 怎么读（本册第 6 章）；
> 2. □ DFA/NFA、正则语言与泵引理：状态是扫描时唯一被记住的东西（本册第 2 章）；

> 4. □ 树形 DP：以子树为子问题自底向上合并答案（竞赛通用）。

## $\rm \S \, 7.1$ 集合量词：从「点」升到「集合」

FOL 说不了连通性。直觉如下：一个 FOL 公式的量词嵌套层数是固定的，每层量词至多把视野往外推一步，所以公式的真值只由每个点周围常数步内的边决定；而「从 $s$ 出发有路到 $t$」可能要走任意多步。这是模型论的经典事实（可达性不是 FOL 可定义的），严格证明要用博弈式论证，本册不展开，但下面的例子会让「集合量词补上这一步」变得具体。

白话：MSO 不新造机器，只把量词的取值对象从「单个点」换成「一批点组成的集合」——像点名换成圈人，一句圈住所有从 1 出发能走到的地方。MSO 在 FOL 语法上只加两样东西：集合变元 $X,Y,\ldots$ 与原子公式 `X(x)`（读作「$x$ 属于 $X$」）；集合变元同样可被 $\exists/\forall$ 量化，但取值只能是论域的子集（「单片」指二阶变元全是一元关系，不允许二元关系变元）。语义照旧：结构里多解释几个集合变元，其余不变。

最小例：三个点的有向图 $1\to2\to3$。考虑公式

```text
∃S ( S(1) ∧ ¬S(3) ∧ ∀x∀y ( S(x) ∧ E(x,y) → S(y) ) )
```

读法：$S$ 含 1 不含 3，且对边封闭，顺着边走不出 $S$。脚本枚举两个结构上全部 $2^{3}$ 个子集：

| 结构 | 公式真值 | 满足公式的 $S$ | BFS：1 可达 3 |
| --- | --- | --- | --- |
| 边 {(1,2),(2,3)} | 假 | 无（含 1 的闭集被推着含 2、含 3） | 真 |
| 删去边 (2,3) | 真 | {1,2} | 假 |

这段可以笔算到底。结构 1 里含 1 的候选只有 {1}、{1,2}、{1,3}、{1,2,3}：{1} 与 {1,3} 在边 (1,2) 上漏了后继；{1,2} 在边 (2,3) 上漏了 3；{1,2,3} 违反 ¬S(3)。四个全不行，公式假。结构 2 里 {1,2} 通过：唯一边 (1,2) 两端都在，公式真。于是公式为真恰好当 3 从 1 不可达，「1 可达 3」就是这个公式的否定：一个 FOL 写不出、MSO 一行写完的性质。差别全在开头那个集合量词 `∃S`：它把「所有从 1 出发的走法」整体压进 $S$ 的封闭性条件里。

## $\rm \S \, 7.2$ 字上的 MSO＝正则语言

把字符串 $w$ 看成有穷结构：论域是位置 $0,\ldots,n-1$，关系只有序 $<$，再加一元谓词 `0(x)`、`1(x)` 表示该位置的字母。MSO 在这个结构上谈的全是「位置的集合」。Büchi–Elgot–Trakhtenbrot 定理：一个语言能被 MSO 句子定义，当且仅当它是正则语言（本册第 2 章意义上 DFA 可识别）。

这条定理的机制读法比陈述更有用：**集合量词就是在维护自动机状态**。`∃X` 枚举所有可能的集合，等价于自动机在扫描时猜一条状态路径；$X$ 在位置 $i$ 进、在位置 $i+1$ 出，对应一次状态转移。最小例：偶长度的串。公式

```text
∃X ( ∀x ( first(x) → X(x) ) ∧ ∀x ( last(x) → ¬X(x) )
      ∧ ∀x∀y ( succ(x,y) → ( X(x) ↔ ¬X(y) ) ) )
```

其中 `first(x)` 是 `¬∃y (y<x)`，`last(x)` 是 `¬∃y (x<y)`，`succ(x,y)` 是 `x<y ∧ ¬∃z (x<z ∧ z<y)` 的缩写。$X$ 从首位起每隔一个位置取一个：只有偶长度的串能让 $X$ 首位进、末位恰好不在。脚本在 30 条串（长 0–8）上枚举全部子集验证，与 `len(w)%2==0` 不一致 0 条。对应的 DFA 只有 2 个状态（奇/偶），$X$ 记录的正是「状态为偶的那些位置」，枚举 $X$ 就是枚举自动机的走法，公式可满足当且仅当存在一条接受路径。

再一个例子：倒数第三个字母是 0。公式

```text
∃x ( 0(x) ∧ ∃y∃z ( x<y ∧ y<z ∧ ∀w ( x<w → (w=y ∨ w=z) ) ) )
```

读法：存在一个 0 位置 $x$，其后恰好有两个位置。脚本在 46 条串上逐位置枚举验证，与直接判 `w[-3]=='0'` 不一致 0 条。对应的 DFA 有 8 个状态，用 3 个位记住最后三位，转移是左移一位、挤进新位，接受态是第三前位为 0 的那 4 个状态；脚本按这个位压状态逐步走，与直接判同样 0 不一致。把 DFA 在串 0101 上笔算一遍：

| 步 | 读入 | 状态（最近 3 位） |
| --- | --- | --- |
| 1 | 0 | —（不足 3 位） |
| 2 | 1 | 01 |
| 3 | 0 | 010 |
| 4 | 1 | 101 |

末态 101 的第三前位是 1，拒绝；直接判 `0101[-3]=='1'` 同样拒绝。「记住最后三位」就是集合量词扫描时随身携带的东西。

反方向同样成立：把 DFA 的接受历史编码成集合（「扫描到位置 $i$ 时处于状态 $q$」可以定义成一个集合），每个正则语言都能翻回 MSO。两边等价，不是单侧包含。

顺带看一眼代价：脚本逐串枚举集合 $X$ 是 $2^{n}$ 量级的：把「枚举所有集合」一次性做完，正是本册第 2 章子集构造在做的事（把 NFA 的状态幂集当 DFA 状态）。MSO 公式翻成自动机时状态数可能指数膨胀，与子集构造是同一笔账；这条定理谈的是「能不能」，不是「多便宜」。

**本节小结**：字结构上 MSO 与 DFA 说的是同一件事——枚举集合量词的取值就是自动机猜状态路径，于是 MSO 可定义与正则两边重合；代价是翻译时状态可能指数膨胀。

## $\rm \S \, 7.3$ 树可判定，网格不可判定

无穷世界里结论延续。Büchi 把字换成无穷串：MSO 可定义的无穷字语言恰是 $\omega$ 自动机可识别的；Rabin 定理搬到无穷树：树上 MSO 可定义的语言恰是树自动机可识别的。判定问题由此归到「自动机是否存在接受运行」，而后者是图搜索，可判定。于是 MSO 在无穷字与无穷树上仍是可判定的逻辑，这是自动机方法最深的收获之一，本册立牌子不展开。树守得住判定性，还是那句话在起作用：删掉一个根，子树互不相干，树自动机得以自底向上组合接受集。

边界出现在一般图上。把「给定 MSO 公式，问是否存在一个图满足它」当判定问题（MSO 可满足性），答案是不可判定，直觉三四行：网格图（每个点有向右、向下两条边）里，一行铺图灵机一条带上的一个格局（每格记一个带符号），一行压一行就是整台机器的计算历史；「机器接受」变成「存在一种合法铺法」，而铺法合法（相邻两行的符号转移符合机器规则、首行是初始格局、某行出现接受状态）全是 MSO 说得出的事。若能在图上判定 MSO 可满足性，就能判定停机问题。

这里要分辨两个问题。在一个给定的有穷图上检查公式真假（模型检查），有穷结构总能枚举集合，原则上可判定；不可判定的是可满足性：在「所有图」里找一个证人。第 8 章的主角正是前者；至于模型检查本身多贵，一般图上朴素枚举是指数，出路见下一节。

地图于是变成：字上可判定，树上可判定，网格上不可判定。字与树共享一个特征：删掉一个点，剩下互不相干的小块；网格与一般图没有。把「多小算不相干」定量化，就是下一节的主题。

## $\rm \S \, 7.4$ 有界树宽与 Courcelle 定理

树形 DP 为什么只在树上行？删掉一个点，树碎成互不相干的子树，子问题各自独立；一条环就把这破坏，子问题沿环互相缠绕。白话：树分解量的是「一张图离树有多远」——把顶点装进一串小袋子挂到树上，袋子越小，图越像树，DP 越省。定量化：**树分解（tree decomposition）**把图的顶点装进一列称为袋子的集合，袋子连成一棵树，要求每条边的两端点至少同在一袋，且含任一顶点的袋子构成连通子树；分解中最大袋子的点数减一，取所有分解的最小值，叫图的**树宽（treewidth）**。树与森林的树宽是 1，一条长环是 2，网格的树宽随边长增长，不可判定的那批结构正是树宽无界的。

> **竞赛连接**：树形 DP 就是在树宽 1 上跑：「以子树为子问题」是袋子互不相干的直接兑现；插头/轮廓线 DP 按一条窄袋子滚动记录状态，是「按袋子记 $2^{k}$ 量级配置」的手工版。

Courcelle 定理：固定 MSO 公式 $\varphi$ 与树宽界 $k$，判定 ${G\vDash\varphi}$ 的时间是 ${\rm O}(f(\varphi,k)\cdot n)$，输入规模 $n$ 上线性，指数只出现在同时依赖公式与树宽的常数 $f(\varphi,k)$ 里。一句话：**逻辑负责说什么，结构参数负责多贵**。

最小例：判定树上有大小至少 3 的独立集（两两无边、竞赛生已熟，不再注英文）。MSO 公式

```text
∃X ( ∃x∃y∃z ( X(x) ∧ X(y) ∧ X(z) ∧ x≠y ∧ y≠z ∧ x≠z )
      ∧ ∀u∀v ( ( X(u) ∧ X(v) ∧ u≠v ) → ¬E(u,v) ) )
```

朴素验证就是枚举：6 个点的图有 $2^{6}=64$ 个候选子集。树形 DP 换一条路：每个点记「取/不取」，自底向上合并，线性。分解也能笔算：取袋子 {0,1}、{1,2}、{1,3}、{3,4}、{3,5} 沿中心点 1、3 连成星形：每条边两端同袋，每点出现的袋子连通，最大袋子 2，故树宽恰为 1；DP 的「取/不取」两个槽位正好对着袋子里的两个点。脚本对拍：

| 方法 | 例树（6 点 5 边）最大独立集 | 60 棵随机树（2–9 点）不一致数 |
| --- | --- | --- |
| MSO 朴素枚举 $2^{n}$ 个子集 | 4（如 {0,2,4,5}） | — |
| 树形 DP | 4 | 0 |

适用条件要看牢：$\varphi$ 与 $k$ 都必须固定，$f(\varphi,k)$ 通常随二者指数增长，Courcelle 定理保证「参数之外线性」，不保证常数好看，实践中常数大到常被更朴素的 DP 击败。它真正的价值是把「把指数关进参数」变成定理；这笔账在复杂度语言里有正式名字，第 9 章再定价。

## $\rm \S \, 7.5$ 收束：同一个故事的三张脸

三个主角回答的是同一个问题：扫描一个结构、跨过一条割边时，需要随身携带多少信息？

1. 自动机的状态：字是一维的，割边只有一条，要带的只有常数个状态（偶长度带 2 个，倒数第三位带 8 个）；
2. MSO 的集合量词：`∃X` 枚举的集合就是状态路径，集合的进与出就是转移，Büchi–Elgot–Trakhtenbrot 定理是这句话的精确形式；
3. 树宽 DP 的子问题：树宽 $k$ 的图割开一条边只需带 $k$ 个边界点，边界上 $2^{k}$ 量级的配置就是 DP 状态。

结构从字到树到一般图，「要带的信息」从常数到袋子到没有小割，可判定性与代价跟着这个量走。本章脚本的分工也照着三张脸排：字上的例在验证「状态＝集合」，树上的例在验证「袋子＝DP 子问题」，两条都对上了，机制才算真的看清。第 8 章把这个视角转向另一类结构：随时间展开的系统。

## $\rm \S \, 7.8$ 本章自测答案

> 先闭卷作答上面两节，再核对。

### $\rm \S \, 7.8.1$ 关键概念回顾答案

1. FOL 量词层数固定，真值只由每点常数步内的邻居决定，而路可以任意长。MSO 补的是集合量词：`∃S` 一次把「所有走法」收进一个对边封闭的集合，可达性化为一行闭集公式的否定（§7.1）。
2. `∃X` 的每一种解释对应自动机的一条状态路径，$X$ 在相邻位置上的进与出对应一次转移。偶长度：$X$ 隔位取点、首位进末位出，恰是 2 状态 DFA 的奇偶翻转（§7.2）。
3. 字上 MSO 可定义的语言恰是正则语言。正向：MSO 公式翻成自动机（枚举集合＝猜状态路径）；反向：DFA 的接受历史可定义成集合，逐状态翻译回公式（§7.2）。
4. 树分解把顶点装进树形排列的袋子，每条边两端同袋、每点的袋子连通；树宽是最大袋子减一的最小值。树上删点碎成独立子树，DP 按子树合并，袋子大小 2 恰好够用（§7.4）。
5. 固定 MSO 公式 $\varphi$ 与树宽 $k$：判定 ${G\vDash\varphi}$ 可在 $f(\varphi,k)\cdot n$ 时间内完成，输入规模上线性；指数藏在只依赖 $\varphi,k$ 的常数里（§7.4）。

### $\rm \S \, 7.8.2$ 应用与辨析答案

1. 错。Büchi–Elgot–Trakhtenbrot 定理说两边重合：MSO 在字上定义的语言恰是正则语言，不存在「强出正则」的字语言；MSO 的优势出现在树与有界树宽图上（§7.2、§7.4）。
2. 树宽 3 的图对任何固定 MSO 公式都是线性时间；100 点网格的树宽随边长无界增长，定理不适用，只能退回朴素枚举，差别是「线性对指数」，而网格正是不可判定性证明用的形状（§7.3、§7.4）。
3. 集合量词要对 $2^{n}$ 个子集逐个枚举，两个集合量词就是 $2^{2n}$，公式固定省不掉这部分指数；只有树宽有界时 Courcelle 定理才把整体降到线性（§7.4）。
