# $\rm Chapter \, 2$ 特征标与正交关系

第 1 章把表示拆成了原子，但拆法是手工的：重数靠逐个凑，原子清单靠逐个验。本章给每个表示发一张**条形码**——特征标，一个把表示的维数与对称信息压缩成 $|G|$ 个复数的函数。本章两件大事：一是证明不同原子的条形码在群上**互相正交**（第一、第二正交关系），于是「数重数」从手工活降为算一个内积；二是把贯穿例子 $S_3$ 的特征标表**从零推演出来**，逐格验账。读完全章你会拥有表示论最常用的一张乘法口诀表。

> **开始前自检**：本章假设你已经会：
>
> 1. □ 第 1 章全部内容：表示、不可约、Maschke 定理与「$V \cong \bigoplus_i V_i^{\oplus m_i}$」的分解式，§2.3 的重数公式是对 §1.4 六问第 6 问的回答；
> 2. □ 迹的基本性质：$\mathrm{tr}(AB) = \mathrm{tr}(BA)$、迹在相似变换 $\mathrm{tr}(TAT^{-1}) = \mathrm{tr}(A)$ 下不变、分块对角矩阵的迹是对角块之和，§2.1 全部性质由此三条推出来；
> 3. □ 群的共轭类：$hgh^{-1}$ 与 $g$ 同类，$S_3$ 的三个类要能亲手分出来（本站群论与模论册），§2.2 与 §2.5 的「列」全靠它；
> 4. □ Hermite 内积与共轭对称：$\overline{\alpha \beta} = \bar{\alpha}\bar{\beta}$、酉矩阵特征值的模为 $1$，§2.1 的 $\chi(g^{-1}) = \overline{\chi(g)}$ 与 §2.3 的正交化都在这上面走。
>
> 其中第 2 条是本章的工作马——特征标的一切好性质都来自「迹对循环换位不眨眼」。

## $\rm \S \, 2.1$ 特征标的定义：把表示压缩成一行数

先说清特征标解决什么问题。§1.4 的不可约分解 $V \cong V_1^{\oplus m_1} \oplus \cdots \oplus V_r^{\oplus m_r}$ 里，重数 ${m_1, \ldots, m_r}$ 是我们真正想要的数，但 Maschke 定理只保证存在、不给出算法——它连「拆法唯一」都不承诺。想要算法，得先给每个表示找一个**不挑基的量**：换任何基都算出同一组数，这个量才可能是「表示本身的指纹」。矩阵的迹恰好天生如此。

定义来了。设 $\rho: G \to \mathrm{GL}(V)$ 是表示，$V$ 的**特征标（character）**是函数

$$
\chi_V: G \to \mathbb{C}, \qquad \chi_V(g) = \mathrm{tr}\,\rho(g)
$$

（读法：给每个群元素拍的那张矩阵求迹。$d$ 维表示的特征标开头一格 $\chi_V(e) = \mathrm{tr}\,I_d = d$——维数就写在条形码第一位。）

白话：**特征标是表示的条形码**——扫描器从 $|G|$ 维的矩阵群 $\rho(G)$ 里只读出 $|G|$ 个数，却指望凭这几个数认出整个表示。本章证明这扫描器惊人地好用：不可约表示的条形码两两正交，靠内积就能数出任何表示里每种原子出现几次。

五条基本性质，每条一行证明。设 $\rho$ 是 $V$ 的表示。

1. **等价表示同特征标**：$T\rho(g)T^{-1}$ 与 $\rho(g)$ 相似，迹不变。所以 $\chi_V$ 只依赖等价类——条形码认「表示」不认「照片角度」，这正是当初要的；
2. **类函数**：$\chi_V(hgh^{-1}) = \mathrm{tr}(\rho(h)\rho(g)\rho(h)^{-1}) = \mathrm{tr}(\rho(g)\rho(h)\rho(h)^{-1}) = \chi_V(g)$（读法：第一步用循环换位 $\mathrm{tr}(ABC) = \mathrm{tr}(BCA)$）。所以特征标在共轭类上取常值，是**类函数（class function）**——条形码天然按类折叠；
3. **共轭对称**：$\chi_V(g^{-1}) = \overline{\chi_V(g)}$。这条要费一点功夫：先把 $\rho$ 酉化——任取 $V$ 上的 Hermite 内积，定义 $\langle u, v \rangle' = \frac{1}{|G|}\sum_{g}\langle \rho(g)u, \rho(g)v \rangle$（读法：又是平均化，和 Maschke 同一个心法；平均后的内积满足 $\langle \rho(h)u, \rho(h)v \rangle' = \langle u, v \rangle'$，因为求和跑遍全群，换元 $g' = hg$ 不动平均值）。酉化后 $\rho(g)$ 都是酉矩阵，$\rho(g^{-1}) = \rho(g)^{*}$，特征值都在单位圆上且 $g^{-1}$ 的特征值是 $g$ 的特征值的倒数 $=$ 共轭，迹取共轭；
4. **循环换位**：$\chi_V(gh) = \chi_V(hg)$（还是 $\mathrm{tr}(AB) = \mathrm{tr}(BA)$）。特别地三个轮换平方 $\chi(g^2)$、$\chi(g^3)$ 都能用 $\chi$ 表出，后面算特征标值时顺手用；
5. **直和可加**：$\chi_{V \oplus W}(g) = \chi_V(g) + \chi_W(g)$（分块对角矩阵的迹是对角块之和）。这条是命根：**分解式两边取特征标，特征标就线性地记住了重数**。

性质 5 配上 §1.4 的贯穿例子立刻有产出。$S_3$ 排列表示的特征标是「不动点计数」：$\rho(\sigma)$ 是置换矩阵，对角线第 $i$ 位是 $1$ 当且仅当 $\sigma$ 固定 $i$，故 $\chi_{\mathrm{perm}}(\sigma) = \sigma$ 的不动点个数。分三类数：

1. $e$：三个不动点，$\chi = 3$；
2. 对换（如 $(1\,2)$）：恰固定 $3$，$\chi = 1$；
3. 三轮换（如 $(1\,2\,3)$）：没有不动点，$\chi = 0$。

由 §1.4 已证的 $\rho_{\mathrm{perm}} \cong V_1 \oplus V_3$（平凡 ⊕ 标准）与可加性，标准表示的特征标是减法：

$$
\chi_{\mathrm{std}} = \chi_{\mathrm{perm}} - \chi_{\mathrm{triv}} = (3, 1, 0) - (1, 1, 1) = (2, 0, -1)
$$

（读法：三个数分别是对三个共轭类的取值。$\chi_{\mathrm{std}}(e) = 2$ 复述了维数；对换取值 $0$ 与 §1.4 矩阵 $\rho(1\,2) = \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix}$ 的迹 $0$ 对上；三轮换取值 $-1$ 与 $\rho(1\,2\,3) = \begin{pmatrix} -1 & -1 \\ 1 & 0 \end{pmatrix}$ 的迹对上。）§1.4 用了半页矩阵运算才验出的数，特征标的减法一行给出——这就是条形码的效率。

**本节小结**：特征标 $\chi_V(g) = \mathrm{tr}\,\rho(g)$ 是不挑基的指纹：等价不变、按类取值、共轭对称、直和相加。$S_3$ 的三行条形码已经到手两行半（平凡、符号、标准）。下一节给类函数装上内积，让「条形码认原子」变成定理。

## $\rm \S \, 2.2$ 类函数空间与群上内积

定义。映射 $\alpha: G \to \mathbb{C}$ 叫**类函数**，若 $\alpha(hgh^{-1}) = \alpha(g)$ 对所有 ${g, h}$ 成立。全体类函数构成线性空间 $\mathcal{H}_G$（逐点加法与数乘），维数等于共轭类个数：类函数在每个类上取一个常值，各类互相独立，$\mathcal{H}_G \cong \mathbb{C}^{\#(\text{类})}$。$S_3$ 分三类

$$
C_1 = \{e\}, \qquad C_2 = \{(1\,2), (1\,3), (2\,3)\}, \qquad C_3 = \{(1\,2\,3), (1\,3\,2)\}
$$

（读法：对换互相共轭——手性相同；两个三轮换互相共轭——互为逆元也共轭，$h(1\,2\,3)h^{-1} = (1\,3\,2)$ 取 $h = (2\,3)$ 即得。）所以 $S_3$ 的类函数空间是三维的，特征标表将有 $3$ 列。

类函数上装内积：

$$
\langle \alpha, \beta \rangle = \frac{1}{|G|} \sum_{g \in G} \alpha(g)\,\overline{\beta(g)}
$$

（读法：在群上均匀随机抽一个 $g$，取 $\alpha(g)\overline{\beta(g)}$ 的期望。除以 $|G|$ 让常数函数的范数为 $1$。按类折叠后等价于加权平均 $\frac{1}{|G|}\sum_{k} |C_k|\,\alpha(C_k)\overline{\beta(C_k)}$，权重是类的大小。）

白话：接下来要证明一件近乎奇迹的事——**不可约表示的条形码在这个内积下两两正交**。条形码不是随便发的，它发下来就自带一套互检系统：拿 $\chi_V$ 与 $\chi_W$ 做一次内积，答案直接告诉你 $V$ 和 $W$ 是不是同一种原子。这件事的非平凡之处在于：内积只扫了 $|G|$ 个数，却要判定「两个矩阵群是否等价」这种全局问题。

**本节小结**：类函数空间维数＝共轭类个数（$S_3$：$3$），其上内积是群上的均匀平均。主角登场前的道具齐了，下一节推第一正交关系。

## $\rm \S \, 2.3$ 第一正交关系：重数从此只算内积

**定理（第一正交关系）**：设 ${V, W}$ 是有限群 $G$ 的两个不可约复表示，则

$$
\langle \chi_V, \chi_W \rangle =
\begin{cases}
1, & V \cong W \text{（等价）} \\
0, & V \not\cong W
\end{cases}
$$

证明给关键步骤，分三步；第 3 步引用 Schur 引理（陈述在此，证明在第 3 章 §3.1 付清）。

**第一步：平均化一个线性映射。** 任取线性映射 $A: W \to V$，定义

$$
T = \frac{1}{|G|} \sum_{g \in G} \rho_V(g)\,A\,\rho_W(g)^{-1}
$$

（读法：把 $A$ 在「群作用下」摇匀——与 Maschke 的投影平均同一心法，只是这次平均的对象是映射。）交换性验算与第 1 章一字不差：对任意 $h \in G$，$\rho_V(h)\,T\,\rho_W(h)^{-1} = \frac{1}{|G|}\sum_g \rho_V(hg)A\rho_W(hg)^{-1}$，换元 $k = hg$ 求和不变，得

$$
\rho_V(h)\,T = T\,\rho_W(h) \qquad \text{对所有 } h \in G
$$

（读法：$T$ 是 $W$ 与 $V$ 之间的「翻译官」——先翻译再作用等于先作用再翻译。这种映射叫**缠结算子（intertwiner）**，第 3 章的主角。）

**第二步：请出 Schur 引理。** ${V, W}$ 不可约，Schur 引理说：这样的 $T$ 若 $V \not\cong W$ 只能是 $0$；若 $V \cong W$ 则是纯量算子 $\lambda\,\mathrm{id}_V$，且 $\lambda = \mathrm{tr}(A)/d$（$d = \dim V$，对 $T$ 取迹：$\mathrm{tr}\,T = \frac{1}{|G|}\sum_g \mathrm{tr}(A) = \mathrm{tr}(A)$，而 $\mathrm{tr}(\lambda\,\mathrm{id}_V) = \lambda d$）。

**第三步：取 $A$ 为矩阵单位，挤出系数正交。** 选定 $V$ 的基与 $W$ 的基，令 $A = E_{ba}$（把 $W$ 的第 $a$ 个基向量送到 $V$ 的第 $b$ 个、其余全送零的矩阵单位）。$T = 0$ 时逐分量读出

$$
\frac{1}{|G|} \sum_{g \in G} \rho_V(g)_{ib}\,\rho_W(g^{-1})_{aj} = 0 \qquad (\text{一切 } i, a, b, j)
$$

$V \cong W$ 时 $T = (\mathrm{tr}(A)/d)\,\mathrm{id}_V = (1/d)\,\mathrm{id}_V$（$E_{ba}$ 的迹是 $\delta_{ab}$），逐分量读出

$$
\frac{1}{|G|} \sum_{g \in G} \rho_V(g)_{ib}\,\rho_W(g^{-1})_{aj} = \frac{\delta_{ab}\,\delta_{ij}}{d}
$$

（读法：矩阵系数的平方平均——每一个「像素位置」的矩阵系数都互相正交，就像标准正交基的分量表。注意 $\rho_W(g^{-1}) = \rho_W(g)^{*}$（酉化后），所以第二个因子其实是共轭。）特征标是系数的对角线和：$\chi_V(g) = \sum_i \rho_V(g)_{ii}$，而 $\overline{\chi_W(g)} = \sum_j \rho_W(g^{-1})_{jj}$。在系数正交式里取 $b = i$、$a = j$，再对 ${i, j}$ 求和：

$$
\langle \chi_V, \chi_W \rangle
= \sum_{i,j} \frac{1}{|G|} \sum_{g \in G} \rho_V(g)_{ii}\,\rho_W(g^{-1})_{jj}
= \sum_{i,j} \frac{\delta_{ij}}{d}
= \frac{d}{d} = 1
$$

（读法：等价情形每对指标贡献 $\delta_{ij}/d$，$d$ 对非零项合计 $1$；不等价情形系数正交的右边全是 $0$，逐对指标全灭。）证毕。

特征标正交立刻砸出两个日常武器：

1. **不可约判据**：$\chi_V$ 不可约（$V$ 不可约）当且仅当 $\langle \chi_V, \chi_V \rangle = 1$。第 1 章要摆六个矩阵找公共特征向量才能证的不可约性，现在一次内积解决；
2. **重数公式**：$V \cong \bigoplus_i V_i^{\oplus m_i}$ 时两边与 $\chi_j$ 取内积，正交性把其余项全灭，得

$$
m_j = \langle \chi_V, \chi_j \rangle
$$

（读法：§1.4 六问第 6 问的兑现——重数的指纹就是特征标，「数原子」=「做内积」，而且此式自动证明拆法唯一：$m_j$ 由 $\chi_V$ 完全决定。）

$S_3$ 验算两笔（数值由 §2.6 程序真算）：$\langle \chi_{\mathrm{std}}, \chi_{\mathrm{std}} \rangle = \frac{1}{6}\big(1 \cdot 2^2 + 3 \cdot 0^2 + 2 \cdot (-1)^2\big) = \frac{6}{6} = 1$——标准表示不可约，第 1 章 §1.4 的矩阵反证被一行内积复现；$\langle \chi_{\mathrm{perm}}, \chi_{\mathrm{std}} \rangle = \frac{1}{6}\big(1 \cdot 3 \cdot 2 + 3 \cdot 1 \cdot 0 + 2 \cdot 0 \cdot (-1)\big) = 1$——排列表示里标准表示恰好出现一次，与 $\rho_{\mathrm{perm}} \cong V_1 \oplus V_3$ 对账无误。

**本节小结**：第一正交关系 $\langle \chi_V, \chi_W \rangle = \delta_{VW}$ 的证明流水线是「平均化造缠结算子、Schur 引理定型、矩阵单位挤出系数正交」；两个推论（不可约判据、重数公式）把第 1 章的手工活全部自动化。下一节证明条形码系统还有第二层正交——这次是沿着「列」的方向。

## $\rm \S \, 2.4$ 第二正交关系：行正交免费送列正交

第一正交关系管「行」：固定两个不可约表示，沿着群元素求和。第二正交关系管「列」：固定两个共轭类，沿着不可约表示求和。

**定理（第二正交关系）**：设 ${\chi_1, \ldots, \chi_r}$ 是 $G$ 的全部不可约特征标，${C, C'}$ 是两个共轭类，则

$$
\sum_{i=1}^{r} \chi_i(C)\,\overline{\chi_i(C')} = \frac{|G|}{|C|}\,\delta_{C C'}
$$

（读法：左边是把特征标表竖着读、按列点乘；右边是「$|G|$ 除以列所在类的大小」——类越小列越重，恒等类（大小 $1$）最重，权重恰是 $|G|$。$\delta_{CC'}$ 指两个类相同。）

证明关键步骤是一段矩阵账。设 $X$ 是 $r \times r$ 的**特征标表**：第 $i$ 行第 $k$ 列填 $\chi_i(C_k)$（行跑不可约表示，列跑共轭类）。这里用到 $r$ 等于类的个数（第 3 章由正则表示证明，此处先记账），所以 $X$ 是方阵。令 $D = \mathrm{diag}(|C_1|, \ldots, |C_r|)$（类大小的对角阵）。第一正交关系按类折叠后（用 §2.2 末的加权形式）逐行读出

$$
\sum_{k} |C_k|\,\chi_i(C_k)\,\overline{\chi_j(C_k)} = |G|\,\delta_{ij}
$$

翻译成矩阵语言正是

$$
X\,D\,\overline{X^{\mathsf T}} = |G|\,I
$$

（读法：行向量与行向量在权重 $|C_k|$ 下正交——「行正交」就是第一正交关系的另一个名字。）由 $|C_k| \ge 1$ 知 $D$ 可逆，于是 $X$ 可逆，两边整理得

$$
\overline{X^{\mathsf T}}\,X = |G|\,D^{-1}
$$

（读法：从 $X D \overline{X^{\mathsf T}} = |G| I$ 出发：$D\overline{X^{\mathsf T}} = |G| X^{-1}$，再左乘 $X^{-1}$ 挪到右边即得。）逐列读出 $\sum_i \overline{\chi_i(C_k)}\,\chi_i(C_l) = |G|\,\delta_{kl}/|C_k|$——这就是第二正交关系。白话：**行正交免费送列正交**——有限维空间里「行向量组两两正交」与「列向量组带权正交」是同一张方阵可逆性的两种读法，方阵行满秩即列满秩，没有任何新分析，只是把同一个等式从另一侧展开。

$S_3$ 数值验账（三列各验一次，数值由 §2.6 程序真算）：

1. 恒等类 $C_1$：列向量 $(1, 1, 2)$，自点积 $1 + 1 + 4 = 6 = |G|/1$；
2. 对换类 $C_2$：列向量 $(1, -1, 0)$，自点积 $1 + 1 + 0 = 2 = |G|/3$；
3. 三轮换类 $C_3$：列向量 $(1, 1, -1)$，自点积 $1 + 1 + 1 = 3 = |G|/2$。

三笔全部落位。顺带 notice：第二正交关系在 $C = C'$ 时给出 $\sum_i |\chi_i(C)|^2 = |G|/|C|$——每个共轭类上的「特征标能量预算」恰好是 $|G|/|C|$，这是验任何新特征标表最快的列检。

**本节小结**：第二正交关系是第一正交关系的「转置读法」：特征标表作为带权正交的方阵，行正交与列正交互为表里。行管「分辨原子」，列管「约束单类取值」，两把尺子下一章合起来验表。下一节把 $S_3$ 的表从零推演到手。

## $\rm \S \, 2.5$ $S_3$ 特征标表完整推演

现在把口诀表整张造出来。推演四步，每一步只用已证的工具。

**第一步：分列。** 共轭类 §2.2 已分好：$C_1 = \{e\}$、$C_2 = \{(1\,2), (1\,3), (2\,3)\}$、$C_3 = \{(1\,2\,3), (1\,3\,2)\}$，大小依次为 $1$、$3$、$2$。特征标是类函数，表按类折叠成三列。

**第二步：数行。** 不可约表示的个数等于共轭类个数（陈述级：第 3 章正则表示的分解给出证明），所以表是 $3 \times 3$ 方阵，还缺三行中的第三行。

**第三步：填行。** 前两行是送分题：

1. **平凡行**：每个元素都拍 $(1)$，$\chi_1 = (1, 1, 1)$；
2. **符号行**：对换是奇置换取 $-1$，三轮换是偶置换取 $1$，$\chi_2 = (1, -1, 1)$；
3. **标准行**：§2.1 已经推好——$\chi_{\mathrm{perm}} = (3, 1, 0)$ 是不动点计数，减掉平凡行（§1.4 的分解 $\rho_{\mathrm{perm}} \cong V_1 \oplus V_3$）得 $\chi_{\mathrm{std}} = (2, 0, -1)$。

**第四步：验账。** 三道检查全部通过（每笔都由 §2.6 程序用 sympy 真算）：

1. **维数平方和**：$1^2 + 1^2 + 2^2 = 6 = |G|$。这不是巧合而是普适定理（第 3 章：正则表示分解使每种原子出现 $\dim$ 次）；$S_3$ 是它的最小非平凡实例；
2. **行正交**：三个行向量在权重 $(1, 3, 2)/6$ 下两两内积为单位阵。抽查标准行与符号行：$\frac{1}{6}\big(1 \cdot 2 \cdot 1 + 3 \cdot 0 \cdot (-1) + 2 \cdot (-1) \cdot 1\big) = \frac{2 - 2}{6} = 0$；
3. **列正交**：§2.4 三笔已验。

表格落定：

| | $e$（$1$ 个） | $(1\,2)$ 型（$3$ 个） | $(1\,2\,3)$ 型（$2$ 个） |
| --- | --- | --- | --- |
| 平凡 $\chi_1$ | $1$ | $1$ | $1$ |
| 符号 $\chi_2$ | $1$ | $-1$ | $1$ |
| 标准 $\chi_3$ | $2$ | $0$ | $-1$ |

（读法：行是条形码，列是「同一种对称性的三个切面」。对换列 $(1, -1, 0)$ 与三轮换列 $(1, 1, -1)$ 的样子，恰好编码了 $S_3$ 最深的结构事实——对换是反射、三轮换是旋转，符号特征标分得开反射、分不开旋转。）

这张表立刻能回答比第 1 章精细得多的问题。举例：$S_3$ 还有没有别的二维表示？任何二维表示的特征标 $\chi$ 是三行特征标的非负整系数组合 $\chi = m_1 \chi_1 + m_2 \chi_2 + m_3 \chi_3$（Maschke 保证完全可约），二维即 $m_1 + m_2 + 2m_3 = 2$，候选只有 $\chi_3$ 与 $\chi_1 \oplus \chi_2$（后者是 $\chi_1 + \chi_2 = (2, 0, 2)$，可约，正交判据 $\langle \chi, \chi \rangle = 2 \ne 1$ 当场识破）——**二维不可约表示本质上只有标准表示一种**。数原子、辨真伪、清点原子总数，一张表全包。

**本节小结**：$S_3$ 特征标表三步到手——分列（三类）、填行（平凡、符号、标准）、验账（平方和、行正交、列正交三关全过）。至此第 1 章的所有手工问题都有了机械答案。两处欠账（「不可约个数＝类数」与「平方和公式」）下一章由正则表示一并还清。

## $\rm \S \, 2.6$ 程序段：特征标表自动构建与三重验账

从群数据出发自动建表，把 §2.3–§2.5 的每笔账重算一遍（换任何群都能跑）：

```python
import sympy as sp
from sympy.combinatorics import SymmetricGroup

els = list(SymmetricGroup(3).generate_dimino())          # 0 起始索引

def fix(g):  return sum(1 for i in [0, 1, 2] if g(i) == i)
def cls(g):  return 'e' if g.is_identity else ('t' if g.order() == 2 else 'c')
classes = ['e', 't', 'c']                                 # e: 恒等, t: 对换, c: 三轮换
size = {c: sum(1 for g in els if cls(g) == c) for c in classes}

chi = {                                                   # 三个不可约特征标
    'trivial':  {g: 1                          for g in els},
    'sign':     {g: g.signature()              for g in els},
    'standard': {g: fix(g) - 1                 for g in els},   # 排列表示减平凡
}
rows = {n: [chi[n][[g for g in els if cls(g) == c][0]] for c in classes] for n in chi}
for n, r in rows.items(): print(n, r)

G = len(els)
# 行正交（第一正交关系）
for a in chi:
    for b in chi:
        s = sum(chi[a][g] * chi[b][g].conjugate() for g in els) / G
        assert s == (1 if a == b else 0), (a, b, s)
# 列正交（第二正交关系）
for c1 in classes:
    for c2 in classes:
        s = sum(rows[n][classes.index(c1)] * rows[n][classes.index(c2)].conjugate()
                for n in chi)
        assert s == (G / size[c1] if c1 == c2 else 0), (c1, c2, s)
# 维数平方和
print("|G| = sum d^2 =", sum(rows[n][0] ** 2 for n in chi), "==", G)
```

实跑输出（本章数值锚，照抄）：

```text
trivial [1, 1, 1]
sign [1, -1, 1]
standard [2, 0, -1]
|G| = sum d^2 = 6 == 6
```

读程序的三句话：特征标按「取每个类的代表元」折叠成行，类的大小只在列正交的权重里出现——两个正交关系的分工在代码里一目了然；`assert` 把九对行正交与九对列正交一次穷尽，任何一格错数字立刻报警；末行 $1 + 1 + 4 = 6$ 是维数平方和公式的最小实例，第 3 章会解释它为什么必须成立。

## $\rm \S \, 2.8$ 六问参考答案

1. 等价不变用相似不变性；类函数与循环换位用 $\mathrm{tr}(AB) = \mathrm{tr}(BA)$（循环换位）；直和可加用分块对角迹；共轭对称 $\chi(g^{-1}) = \overline{\chi(g)}$ 是唯一需要先酉化的一条——要 $\rho(g)$ 变成酉矩阵后 $g^{-1}$ 的矩阵才是共轭转置。（§2.1）
2. 平均化把「单个 $g$ 不保内积」升级成「全群一致保内积」：换元后 $\langle \rho(h)u, \rho(h)v \rangle'$ 的求和与原式逐项相同。与 Maschke 的平均是同一心法——对群摇匀取平均，把逐点的性质敲打成整体对称的性质。（§2.1、第 1 章 §1.3）
3. 平均化造缠结算子 $T$、Schur 引理定形（$0$ 或纯量）、取矩阵单位 $A = E_{ba}$ 把「$T$ 是什么」落到每一个矩阵分量上，得到矩阵系数的正交；特征标是系数的对角和，系数正交推出特征标正交。（§2.3）
4. Maschke 只说「存在某个拆法」；若两种拆法给出不同重数，同一 $\chi_V$ 会算出两个不同的 $\langle \chi_V, \chi_j \rangle$，矛盾——重数由特征标唯一决定，而特征标只依赖表示本身。（§2.3）
5. $D = \mathrm{diag}(|C_1|, \ldots, |C_r|)$，对角元是各类的大小。用到的方阵事实：$X D \overline{X^{\mathsf T}} = |G| I$ 蕴含 $X$ 可逆（$D$ 正定可逆），可逆方阵的「行带权正交」可以整理成「列带权正交」$\overline{X^{\mathsf T}} X = |G| D^{-1}$。（§2.4）
6. $(3, 1, 0) = \chi_{\mathrm{perm}}$：$m_{\mathrm{std}} = \langle \chi_{\mathrm{perm}}, \chi_{\mathrm{std}} \rangle = 1$、$m_{\mathrm{triv}} = 1$、$m_{\mathrm{sign}} = 0$，分解为平凡 ⊕ 标准。$(2, 0, 2)$：$\langle \chi, \chi \rangle = \frac{1}{6}(4 + 3 \cdot 0 + 2 \cdot 4) = 2 \ne 1$，一个内积断定可约（实为平凡 ⊕ 符号）。（§2.3、§2.5）
