# $\rm \S \, Chapter \, 4$ M/M/k 与排队网络

第 2 章把单窗口的世界解剖完了，但真实系统几乎从不只有一个窗口。第一条线是**横向的窗口池**：线程池里躺着一排随时干活的线程，数据库连接池攒着一把连接，呼叫中心坐着一排客服——顾客只排一条队，谁空出来谁接客。第二条线是**纵向的接力链**：一个请求先进网关、再进业务服务、再落数据库，前一站的离开就是后一站的到达。两条线在这一章汇合：窗口池问「开几个窗口才够用」（M/M/k 与 Erlang 公式），接力链问「整条链走下来总共多慢」（Burke 定理与 Jackson 网络）。工具还是第 2 章那本生灭账本，只是死率的形状变了，以及账本从一本变成了一排。

比喻先立在这：把 M/M/k 想成超市里**共享的一排收银台**——只开一条队，队头的人去往任何一台刚空出来的收银机；开得越多队伍消得越快，但每台收银机的利用率也被摊薄。排队网络则是一条**食堂动线**：打饭窗口出来端着盘子去打菜窗口，哪个环节挤，整条动线就堵在哪里。

## $\rm \S \, 4.1$ 动机：为什么不能拿 $k$ 个独立单窗口凑数

先拆穿一个诱惑：要 $k$ 个窗口，开 $k$ 家独立小店、每家接 $\frac{\lambda}{k}$ 的客流不就完了？第 2 章习题已经给过答案：$\lambda = 1.6$、$\mu = 1$ 时，两家独立 M/M/1 各接 $0.8$ 给 $W = 5$，而共享一条队的 M/M/2 给 $W = 2.78$——几乎砍半。原因在直觉上很清楚：分开排队时，一边的窗口空着、另一边的队还在排，**闲置无法共享**；只开一条队，任何一台空出来的机器都能接客。共享是有代价的红利，本章的任务就是把这份红利算成公式。另一头，接力链带来的问题是新的：即使每一站都各安其位，请求一站站传下去，端到端要多久？这需要先弄清「离开流长什么样」——它是第 4.6 节 Burke 定理的主角。

小结：本章两个问题——「多少窗口」与「链上多慢」——前者由生灭链直接解，后者要先回答「离开流是不是泊松」。

## $\rm \S \, 4.2$ M/M/k 的生灭链与平稳分布

白话先行：账本上记的还是「店里几个人」，但出口从一台变成了最多 $k$ 台同时开工——人越多，出口开得越多，直到 $k$ 台全忙后就封顶。

**定义 4.1（M/M/k 生灭链）**：泊松到达率 $\lambda$（§1.4），$k$ 个服务台、每台忙时率 $\mu$、一条共享队列。状态 $N(t)$ 为系统内人数（含在服者），率取

1. 生：$n \to n+1$，率 $\lambda_n = \lambda$，与 $n$ 无关；
2. 死：$n \to n-1$，率 $\mu_n = \min(n, k)\,\mu$（$n \ge 1$），$\mu_0 = 0$。

死率的出处是定理 1.2：$n \le k$ 时 $n$ 台全忙，「下一个离开」是 $n$ 个 $\mathrm{Exp}(\mu)$ 的最小值，率恰为 $n\mu$；$n > k$ 时只有 $k$ 台在干，率封顶在 $k\mu$。服务能力随人数线性爬坡、到 $k$ 封顶——这句话就是 $\min(n,k)\mu$ 的读法。两个记号贯穿全章：$a = \frac{\lambda}{\mu}$ 称**载荷**（offer 岀去的平均服务需求，单位「尔朗」，Erlang），$\rho = \frac{a}{k} = \frac{\lambda}{k\mu}$ 为**每台利用率**。稳定条件 $\rho < 1$（否则到达比全池消化还快，队列只进不出）。

**定理 4.1（M/M/k 的平稳分布）**：$\rho < 1$ 时，

$$
\pi_0 = \Biggl[ \sum_{n=0}^{k-1} \frac{(k\rho)^n}{n!} + \frac{(k\rho)^k}{k!\,(1-\rho)} \Biggr]^{-1}, \qquad \pi_n = \begin{cases} \pi_0\,\dfrac{(k\rho)^n}{n!}, & n \le k, \\[2mm] \pi_0\,\dfrac{(k\rho)^k}{k!}\,\rho^{\,n-k}, & n > k. \end{cases}
$$

**证明**。生灭结构与第 2 章完全同构，只是 $\mu_n$ 换了形状，逐字复用定理 2.1 的步骤。

1. **全局平衡**（$n \ge 1$）：$\pi_n(\lambda + \mu_n) = \lambda\pi_{n-1} + \mu_{n+1}\pi_{n+1}$；$n = 0$ 处 $\lambda\pi_0 = \mu\pi_1$。
2. **归纳加强成细节平衡**：设 $\lambda\pi_{n-1} = \mu_n\pi_n$，代入第 $n$ 层全局平衡得 $\pi_n\lambda + \pi_n\mu_n = \mu_n\pi_n + \mu_{n+1}\pi_{n+1}$，消去 $\mu_n\pi_n$ 得 $\lambda\pi_n = \mu_{n+1}\pi_{n+1}$——与定理 2.1 第 2 步逐字相同，因为那一步只用到方程的形状、没用 $\mu_n$ 的具体值。
3. **逐层递推**：$n+1 \le k$ 时 $\pi_{n+1} = \pi_n\,\frac{\lambda}{(n+1)\mu} = \pi_n\,\frac{a}{n+1}$，迭代出 $\pi_n = \pi_0\frac{a^n}{n!}$（$n \le k$）；$n \ge k$ 时 $\pi_{n+1} = \pi_n\rho$，几何衰减 $\pi_n = \pi_k\rho^{n-k}$（$n > k$）。
4. **归一化**：把两段求和，

$$
1 = \pi_0\sum_{n=0}^{k-1}\frac{(k\rho)^n}{n!} + \pi_0\,\frac{(k\rho)^k}{k!}\sum_{m \ge 0}\rho^m,
$$

   第二个和是几何级数，$\rho < 1$ 收敛于 $\frac{1}{1-\rho}$，解出 $\pi_0$；$\rho \ge 1$ 时发散，概率质量漏向无穷——第 2 章那只浴缸又回来了。∎

读法：$n \le k$ 段带阶乘分母，形状像泊松分布——人少时「全员上岗、无人排队」；$n \ge k$ 段切换成几何衰减——每多一个人就全是纯排队的人，越排越稀。两段在 $n = k$ 处接吻，交接棒的地方正是下一节 Erlang 公式的主场。

小结：死率封顶在 $k\mu$ 是相对 M/M/1 的唯一改动，细节平衡归纳原样走通，平稳分布在 $n = k$ 处从泊松形状切换成几何衰减。

## $\rm \S \, 4.3$ Erlang B：阻塞概率的全推导

白话先行：有些系统不给排队位——呼叫中心的中继线满了直接「线路忙」，连接池满了直接拒绝连接。顾客来了看到满座就走，这叫**丢客制**（M/M/k/k：第二个 k 表示容量封顶 $k$，无队列）。

**定理 4.2（Erlang B 公式）**：M/M/k/k 平稳运行（无条件，见下），阻塞概率 $B(k, a) = P(N = k)$ 为

$$
B(k, a) = \frac{a^k/k!}{\displaystyle\sum_{j=0}^{k} a^j/j!}.
$$

**证明**。丢客制下 $\mu_n = n\mu$ 对一切 $n \le k$ 成立，细节平衡递推 $\pi_{n+1} = \pi_n\frac{a}{n+1}$ 一直走到底，得 $\pi_n = \pi_0\frac{a^n}{n!}$（$n = 0, \ldots, k$）。归一化只在有限项上进行：$\pi_0 = \Bigl[\sum_{j=0}^{k} \frac{a^j}{j!}\Bigr]^{-1}$，故

$$
P(N = k) = \pi_0\,\frac{a^k}{k!} = \frac{a^k/k!}{\sum_{j=0}^{k} a^j/j!}. \qquad \blacksquare
$$

注意这里**没有** $\rho < 1$ 的条件：求和只有有限项，永远收敛。丢客制是「自带泄洪口」的系统——满员即拒，队列永不堆积，多来的载荷变成拒绝事件流走了。这就是电话网百年前选它做设计公式的原因（Erlang 1917 年的话务工程，亦见 Kleinrock《Queueing Systems Vol.1》第 3 章）。数值锚见 §4.8 的表：$\lambda = 8$、$\mu = 2$（$a = 4$）时 $B(4) = 0.31068$，四条中继线三成的呼叫会被拒。

闭式之外还有一条工程上更好用的**递推**：$B(0, a) = 1$，

$$
B(k, a) = \frac{a\,B(k-1, a)}{k + a\,B(k-1, a)}.
$$

**推导**。记 $S_k = \sum_{j=0}^{k} a^j/j!$，则 $B(k) = \frac{a^k/k!}{S_k}$。由 $\frac{a \cdot a^{k-1}}{(k-1)!} = k \cdot \frac{a^k}{k!}$ 得 $a\,B(k-1) = \frac{k\,(a^k/k!)}{S_{k-1}}$，于是

$$
\frac{a\,B(k-1)}{k + a\,B(k-1)} = \frac{k\,(a^k/k!)/S_{k-1}}{k\bigl[1 + (a^k/k!)/S_{k-1}\bigr]} = \frac{a^k/k!}{S_{k-1} + a^k/k!} = \frac{a^k/k!}{S_k} = B(k). \qquad \blacksquare
$$

小结：Erlang B 是丢客制下的 $\pi_k$，无稳定条件、自带递推；它是「满员即拒」世界的定价公式。

## $\rm \S \, 4.4$ Erlang C 与等待时间：$C(k,\rho)$ 与 $W_q$

白话先行：回到允许排队的 M/M/k。到达者最关心的第一个数不是「要等多久」而是「要不要等」——看到所有窗口都被占了才需要等。由 PASTA（§1.5），这个概率就是 $P(N \ge k)$。

**定理 4.3（Erlang C 公式）**：$\rho < 1$ 时，到达者需等待的概率为

$$
C(k, a) = P(N \ge k) = \frac{\dfrac{(k\rho)^k}{k!\,(1-\rho)}}{\displaystyle\sum_{n=0}^{k-1} \frac{(k\rho)^n}{n!} + \frac{(k\rho)^k}{k!\,(1-\rho)}}.
$$

**证明**。对几何衰减段求尾和：

$$
P(N \ge k) = \sum_{n=k}^{\infty} \pi_0\,\frac{(k\rho)^k}{k!}\,\rho^{n-k} = \pi_0\,\frac{(k\rho)^k}{k!}\sum_{m \ge 0}\rho^m = \pi_0\,\frac{(k\rho)^k}{k!\,(1-\rho)},
$$

代入定理 4.1 的 $\pi_0$ 即得。∎ 与 Erlang B 的关系式（同一 $a$、$k$ 下）一行代出：记 $T = \frac{a^k}{k!}$、$S = \sum_{j<k}\frac{a^j}{j!}$，则 $B = \frac{T}{S+T}$、$C = \frac{T}{S(1-\rho)+T}$；由 $S = \frac{T}{B} - T$ 代入化简得 $C = \frac{B}{1 - \rho\,(1 - B)}$，且 $\rho < 1$ 使分母小于 1，故恒有 $C > B$——肯排队的世界比拒绝的世界更容易撞上满座。

**定理 4.4（平均等待 $W_q = \dfrac{C(k,a)}{k\mu - \lambda}$）**。

**证明**。复用第 2 章 §2.4 的三块砖：PASTA、期望的线性性、几何求和。到达者看到 $n \ge k$ 时，$k$ 台全忙、队伍里有 $n - k$ 个前辈；他要等到第 $n - k + 1$ 个完成事件发生才能上台。队伍非空期间 $k$ 台全忙，完成是率 $k\mu$ 的泊松流（§1.4 普通性），故每个完成事件的间隔期望 $\frac{1}{k\mu}$，故 $E[W_q \mid \text{看到 } n] = \frac{n - k + 1}{k\mu}$。对所见队长取期望（PASTA 把它接到 $\pi$ 上），换元 $m = n - k$ 并用求和引理 $\sum_{m \ge 0}(m+1)\rho^m = \frac{1}{(1-\rho)^2}$：

$$
W_q = \sum_{n \ge k} \frac{n-k+1}{k\mu}\,\pi_n = \frac{\pi_0\,(k\rho)^k}{k!\,k\mu}\sum_{m \ge 0}(m+1)\,\rho^m = \frac{\pi_0\,(k\rho)^k}{k!\,k\mu\,(1-\rho)^2} = \frac{C(k,a)}{k\mu\,(1-\rho)} = \frac{C(k,a)}{k\mu - \lambda}. \qquad \blacksquare
$$

读法：分母 $k\mu - \lambda$ 是全池的**净消化速率**（$k$ 台合起来每单位时间比到达多啃掉几单）——和第 2 章 $W_q = \frac{\rho}{\mu-\lambda}$ 的分母读法一脉相承，只是从单台净速率换成了全池净速率。分子 $C$ 是「要等多久」问题的开关概率：先花 $C$ 的概率进等待通道，通道里的账由分母结。再往上的换算全部走 Little 定理（第 3 章）：$W = W_q + \frac{1}{\mu}$，$L = \lambda W$，$L_q = \lambda W_q$。等待时间的条件分布是 $\mathrm{Exp}(k\mu - \lambda)$，推导见 Kleinrock《Queueing Systems Vol.1》第 3 章（超出本章范围）。

小结：Erlang C 是几何尾和 $P(N \ge k)$，$W_q$ 的推导把第 2 章的三块砖原样搬进多窗口场景，分母从 $\mu - \lambda$ 换成 $k\mu - \lambda$。

## $\rm \S \, 4.5$ 无限窗口极限：M/M/∞

白话先行：把窗口数开到无穷会怎样？每位顾客一到就立刻上台，等待恒为零。听着像空想，其实很多真实系统就是这样：每请求一线程、缓存条目、内存页——「窗口」就是资源本身，来了就开新的。

**定理 4.5（M/M/∞ 的平稳分布）**：取 $\mu_n = n\mu$（$n$ 台同忙，率 $n\mu$，无封顶），则平稳分布存在且

$$
\pi_n = \mathrm{e}^{-a}\,\frac{a^n}{n!}, \qquad L = E[N] = a = \frac{\lambda}{\mu}, \qquad W = \frac{1}{\mu}, \qquad W_q \equiv 0.
$$

**证明**。细节平衡递推与丢客制同形：$\pi_{n+1} = \pi_n\frac{a}{n+1}$ 对一切 $n$ 成立，得 $\pi_n = \pi_0\frac{a^n}{n!}$。归一化用指数级数 $\sum_{n \ge 0}\frac{a^n}{n!} = \mathrm{e}^a$：$\pi_0 = \mathrm{e}^{-a}$，故 $\pi_n = \mathrm{e}^{-a}\frac{a^n}{n!}$——恰是参数 $a$ 的泊松分布。求 $L$ 复用第 1 章 §1.6 的换元：

$$
L = \sum_{n \ge 0} n\,\mathrm{e}^{-a}\frac{a^n}{n!} = \mathrm{e}^{-a}\,a \sum_{m \ge 0}\frac{a^m}{m!} = a,
$$

其中 $m = n-1$ 换元、$\frac{n}{n!} = \frac{1}{(n-1)!}$。$W_q = 0$ 平凡，$W = W_q + \frac{1}{\mu} = \frac{1}{\mu}$。∎

读法：$L = \frac{\lambda}{\mu}$ 与负载无关地成立——系统里平均人数就是「平均到达率 × 平均停留时间」，Little 定理的直觉形态；不管 $\lambda$ 多大，只要 $\mu$ 固定，店里平均就是 $a$ 个人、没人排队。这个极限是**容量规划的地板**：有限池 $k$ 相对它的额外等待全由 Erlang C 记账，$W_q = \frac{C}{k\mu-\lambda}$ 里的 $C$ 随 $k \to \infty$ 归零。

小结：M/M/∞ 是「无人等待」的基准世界，平稳分布恰是泊松分布，$L = \frac{\lambda}{\mu}$ 一行算尽。

## $\rm \S \, 4.6$ 排队网络 I：Burke 定理——泊松进去、泊松出来

白话先行：接力链的第一问是「离开流长什么样」。Burke 定理给了最理想的答案：稳定的 M/M/1（以及 M/M/k、M/M/∞），它的离开过程在平稳态下**仍是率 $\lambda$ 的泊松流**，且与任一时刻的队长独立。比喻：泊松进去、泊松出来——指数世界的进出是对称的。

**定理 4.6（Burke 定理，1956，陈述级）**：平稳态下，M/M/1 的离开过程是率 $\lambda$ 的泊松过程；且离开过程在时刻 $t$ 之后的部分与 $N(t)$ 独立。结论对 M/M/k 与 M/M/∞ 同样成立。

严格证明用可逆性（reversibility）——平稳的 M/M/1 在时间倒放看仍是 M/M/1，倒放的到达流就是正放的离开流——超出本章范围，见 Kleinrock《Queueing Systems Vol.1》第 4 章。但有一个反直觉点值得停下来：忙碌时段离开明明更密（$k$ 台全忙时完成率 $k\mu$），整体怎么还是泊松？读法：稳态下「离开密」的时段恰好被「系统空、离开稀」的时段配平，泊松性是全体时段混合后的账——就像第 1 章稀疏化定理里二项混合被泊松吸收，这里的混合也恰好归一。这一步是直觉不是证明；信任它到定理 4.7 为止，链上问题的入口就开了。

小结：Burke 定理说稳定的指数系统「泊松进去、泊松出来」，串联系统的每一站因此各自拿到泊松输入。

## $\rm \S \, 4.7$ 排队网络 II：Jackson 网络与乘积形式

白话先行：微服务链不是纯粹的直线串联——请求可能分流（网关按类型路由）、可能反馈（缓存未命中打回上游、失败重试）。开 Jackson 网络把这张图形式化。

**定义 4.2（开 Jackson 网络，陈述级）**：$m$ 个节点，节点 $j$ 有 $c_j$ 个服务台、每台率 $\mu_j$、一条共享队列。外部到达是各自独立的泊松流（率 $\lambda_j$）；顾客在一个节点服务完后以概率 $r_{ij}$ 转往节点 $i$、以概率 $1 - \sum_i r_{ij}$ 离开系统。各节点的**总到达率** $\gamma_j$ 由流量守恒方程（traffic equations）解出：$\gamma_j = \lambda_j + \sum_{i=1}^{m} \gamma_i\, r_{ij}$。

读法：节点 $j$ 的过路流量 = 外部新来的 + 各处转来的；反馈回环时这是线性方程组（$\gamma$ 两边都出现），解出来就是每站的真实负载。

**定理 4.7（Jackson 定理，1957，陈述级）**：若每个节点都满足 $\frac{\gamma_j}{c_j \mu_j} < 1$，则平稳分布是**乘积形式**：

$$
\pi(n_1, \ldots, n_m) = \prod_{j=1}^{m} \pi^{(j)}(n_j),
$$

其中 $\pi^{(j)}$ 是「到达率 $\gamma_j$ 的 M/M/$c_j$」的平稳分布（定理 4.1）。直觉：每条链各自像独立的 M/M/1——容量规划时对每个节点用 §4.4 的 Erlang C 公式（$\gamma_j$ 进、$\mu_j$ 出）就行，这是 Jackson 定理最值钱的用法。

**意义与陷阱**：乘积形式**不等于**独立泊松流。定理说的是同一时刻各节点人数的联合分布可拆成边缘之积；它**不**说「网络内部各条弧上的流是相互独立的泊松流」。反例就在反馈里：设单节点 M/M/1 以概率 $p$ 把服务完的顾客打回自己队尾，则流入该队的流 = 外部泊松流 + 自己的离开流回灌。由 Burke 定理离开流是泊松，但**这股合流不是泊松**——刚被服务完打回来的人和队长的起落强相关（服务完成的一瞬队列变短、同时可能冒出一个回头客），到达时刻不再是「完全随机的时间抽样」，§1.5 PASTA 的前提在内部弧上失守。所以：算各节点的平均负载与边缘分布，流量方程与乘积形式照样精确；但问「两个节点队长的瞬时联合」「某条内部弧上到达间隔的分布」时，不能把内部流当独立泊松流硬代——这类问题要超出本章范围的方法（时间可逆网络与乘积形式解的一般理论，见 Kleinrock Vol.1 第 4 章、Jackson 1957 原文）。

小结：Jackson 定理让每个节点各自按 Erlang 公式算账（乘积形式），但反馈弧上的流不是泊松——「边缘精确」与「内部流独立泊松」是两句话。

## $\rm \S \, 4.8$ 应用：线程池容量规划与微服务链的端到端延迟

1. **线程池容量规划**。任务到达 $\lambda = 8$ 每秒，单线程处理率 $\mu = 2$ 每秒（平均 $0.5$ 秒每任务），目标 $P(\text{等待}) \le 5\%$，求最小线程数 $k$。目标即 $C(k, 4) \le 0.05$。先看天真答案：$k = 4$ 时每线程恰好 $\rho = 1$——正好踩在刀刃上，队列无界增长（定理 4.1 第 4 步），完全不可用。查 Erlang 表（全部由 Python 按定理 4.2 递推与定理 4.3、4.4 的公式真算）：

2. **三级微服务链的端到端延迟**。请求率 $\lambda = 1$ 每秒，链上三级各是 M/M/1、每级 $\mu = 2.5$ 每秒。由 Burke 定理，第 1 级的离开是泊松流、作为第 2 级的到达；以此类推，每级都是到达率 $1$ 的 M/M/1。每级 $W_i = \frac{1}{\mu - \lambda} = \frac{1}{1.5} = 0.6667$ 秒，端到端 $W_{\text{总}} = W_1 + W_2 + W_3 = 3 \times \frac{1}{\mu - \lambda} = 2.0$ 秒。这里均值相加只靠期望的线性性（不需要各级独立），而「每级是 M/M/1」靠 Burke 定理。**模拟对照**（离散事件模拟，真跑）：手写事件循环，泊松到达（逆变换法）过三级 FIFO 队列，预热前 10% 不进统计；4 个独立种子各 $5 \times 10^5$ 位顾客，端到端 $W$ 依次为 1.9963、1.9996、1.9927、2.0027 秒，合并 1.9978 秒，相对理论 2.0 秒误差 $-0.11\%$——Burke 定理的账与模拟互相盖章。注意这只算了均值：方差与相关性是另一本账（超出本章范围）。
3. **与本站接口**：组合学册第 10 章（奇点摄动）管「训练系统的算力账」，本章管「服务系统的等待账」——前者算资源够不够快，后者算排队等不等得起。

小结：Erlang 表把 5% 目标翻译成 $k = 9$，Burke 定理把三级链的端到端账算成 2 秒并被模拟以千分之一误差确认。

## $\rm \S \, 4.11$ 本章自测答案

> 先闭卷作答 §4.9 与 §4.10，再核对。

### $\rm \S \, 4.11.1$ 关键概念回顾答案

1. $n \le k$ 时 $n$ 台同忙，「下一个离开」是 $n$ 个 $\mathrm{Exp}(\mu)$ 的最小值，由最小值性质（定理 1.2）率相加为 $n\mu$；$n > k$ 时只有 $k$ 台在忙，率封顶 $k\mu$。（§4.2）
2. $n \le k$ 段 $\pi_n = \pi_0\frac{(k\rho)^n}{n!}$ 带阶乘分母（泊松形状），$n > k$ 段按 $\rho$ 几何衰减（多出的全是排队者）。稳定条件 $\rho = \frac{\lambda}{k\mu} < 1$；$\rho \ge 1$ 时归一化里的几何级数发散，$\pi_0$ 解不出。（§4.2）
3. 求和只有有限项（$n = 0$ 到 $k$），永远收敛——拒绝机制是泄洪口，队列永不堆积。递推由 $a \cdot \frac{a^{k-1}}{(k-1)!} = k\frac{a^k}{k!}$ 这一阶乘关系代出：$B(k) = \frac{aB(k-1)}{k + aB(k-1)}$。（§4.3）
4. 记 $T = \frac{a^k}{k!}$、$S = \sum_{j<k}\frac{a^j}{j!}$，由 $B = \frac{T}{S+T}$ 解出 $S$ 代入 $C = \frac{T}{S(1-\rho)+T}$ 化简即得。$\rho < 1$ 使分母 $1 - \rho(1-B) < 1$，故 $C > B$：队列把人滞留得更久，满座被占得更狠。（§4.4）
5. 三块砖：PASTA（所见接到 $\pi$）、期望线性性（等 $n-k+1$ 个完成事件相加不需独立）、求和引理 $\sum(m+1)\rho^m = \frac{1}{(1-\rho)^2}$。$k\mu - \lambda$ 读作全池净消化速率。（§4.4）
6. 平稳态下离开过程是率 $\lambda$ 的泊松流、且与当前队长独立（M/M/1、M/M/k、M/M/∞ 皆然）。乘积形式只拆**同一时刻**各节点人数的联合分布；反馈弧上的合流与队长状态强相关（完成一瞬队列变短、回头客同时出现），不是泊松流，PASTA 在内部弧上失守。（§4.6–4.7）
