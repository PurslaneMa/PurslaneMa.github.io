# $\rm Chapter \, 3$ 拍卖与机制设计

第 1、2 章假设支付是公开知识。真实拍卖里不是：一件古董、一个广告位，愿意为它出多少钱只有你自己知道。一旦参与者持有私人信息，报出的数字就成了一种策略选择：报高报低各有利弊，规则设计得不好，大家就会谎报。本章的任务是把「规则」本身变成研究对象：机制由分配规则与支付规则组成，设计目标是让如实报告成为每个人的最优策略。主角是二价拍卖与其推广 VCG，它们给出本册第一个正面的设计成果。

> **开始前自检**：本章假设你已经会：
>
> 1. □ 占优与支配关系（本册第 1 章 §1.2；§3.2 的说真话证明是支配论证的一次应用）；
> 2. □ 单方偏离无利可图的检验方式（本册第 1 章 §1.3；§3.1 激励相容的定义）；
> 3. □ 枚举与排序求最优分配（竞赛通用；§3.4 的广告位分配）；
> 4. □ 「目标函数+约束」的优化语言（竞赛通用或本站《机器学习与凸优化》分册；§3.4 的福利最大化）。

## $\rm \S \, 3.1$ 从「算得对」到「说得真」

每个参与者对物品有一个自己的**估值（valuation）**：得到它对己值多少钱。估值是私人信息，机制设计者看不见，参与者却可以虚报。一个**机制（mechanism）**由两部分组成：分配规则（收到各方的报告后，决定谁得到什么）与支付规则（决定每人付多少钱）。注意输入的性质变了：第 1 章里参与者选的是「行动」，这里选的是「报告什么估值」，报告本身就是策略。

设计目标随之改变。算法设计追求算得准，机制设计追求**激励相容（incentive compatibility, IC）**：如实报告自己的估值是每个参与者的占优策略：不管别人怎么报，说真话都不吃亏。IC 的价值在设计侧：只要机制激励相容，设计者就知道收到的报告就是真值，只需在真值上优化分配，不必去预测千奇百怪的谎报行为。

先把「私人信息」落到具体场景：广告主知道自己一条点击值多少钱（转化率乘客单价），收藏家知道这幅画对自己值多少，承建商知道这项工程要花多少成本。设计者想要的是这些真值（分配只有对准真值才能高效），而拿到手里的只有各方自愿报出的数。机制设计的工作对象因此从「给定输入怎么算」变成「用什么规则让输入自己变真」：测量仪器（机制）本身会改变被测者的行为，这是一切与普通算法设计的分界。机制也不止拍卖一种：道路该收费还是排队、频谱给谁、公共项目修不修，凡「分配+支付」两件套齐全的场合都是机制。

## $\rm \S \, 3.2$ 二价拍卖：把诚实变成占优策略

**二价拍卖（second-price auction，又称 Vickrey auction）**拍卖单件物品：每人密封报一个价，报价最高者得，支付全场第二高的报价。设你的估值是 $v$，其他人的最高报价是 $s$，即你赢了就要付的数。你的效用是 $(v-s)\times[\text{赢}]$。逐情形比较「如实报 $v$」与任何偏离：

| 偏离 | 情形 | 结果 |
| --- | --- | --- |
| 报 $b>v$ | $s<v$ | 同样赢、同样付 $s$，效用不变 |
|  | $v<s<b$ | 赢了但要付 $s>v$，效用为负，如实报本可避免 |
|  | $s>b$ | 同样输，效用同为 $0$ |
| 报 $b<v$ | $s<b$ | 同样赢、同样付 $s$，效用不变 |
|  | $b<s<v$ | 输掉了本可赢的正效用 $v-s$ |
|  | $s>v$ | 同样输，效用同为 $0$ |

每种情形下如实报都不输给偏离（$s=v$ 的平局情形两报价结果相同），所以报 $v$ 占优。表里的六种情形覆盖了全部可能：偏离方向两种、$s$ 的落位各三种，交叉穷尽没有漏网。占优策略证明的完整性来自这种穷举，不来自直觉。机制的核心在支付规则：付第二价而不是自己的报价，赢家的支付与自己的报价无关，抬价只会平白增加「以超过估值的价格成交」的风险。注意 $s$ 的定义是「其他人的最高报价」而非「全场第二高的报价」。你就是最高者时两者相等，但证明里 $s$ 必须排除你自己的报价，否则报 $b>v$ 的情形分析会绕晕。规则的形式细节（密封出价还是公开轮流叫价）不影响这个论证：只要「赢家付第二高」成立，逐情形比较就成立。占优策略性质长在支付规则上，不长在拍卖流程上。

对比**一价拍卖（first-price auction）**：赢者付自己的报价。此时报 $v$ 的效用恒为 $0$，人人有压价动机；均衡里报价是估值的一个折扣（需要纳什均衡分析，本书不展开推导），而且折扣幅度依赖你对别人估值分布的信念——对手少了、对手更激进，折扣都得跟着变。二价把这份「猜」免除了，这正是占优策略比均衡强的地方，策略不依赖对对手的建模，换一批对手你的最优策略一字不改。也别把「二价更诚实」误读成「二价更赚钱」：在特定假设下两种拍卖的期望收入可以相等（收入等价，超出本书范围），二价的优势在策略的稳健，不在收入的多少。

顺带把两种「解」的强度排好：占优策略性质强于纳什均衡——前者对对手的任何行为成立，后者只要求彼此互为稳定反应。二价拍卖买到的是更强的那一档。这份溢价在 §3.5 之外的场景（合谋、重复交互）里会逐步显现。

## $\rm \S \, 3.3$ 显示原理：搜索空间塌缩

机制可以任意复杂：多轮报价、间接信号、保密规则。**显示原理（revelation principle）**一句话收束这种复杂：任何机制的任何均衡结果，都可以由一个「直接询问估值、且说真话构成均衡」的机制复制。复制的方式不难想：新机制让每个参与者一次性报告估值，内部替他按原机制的均衡策略去行动——均衡策略本来就是对报告的函数，原机制里你怎么玩，新机制里就替你怎么玩。于是设计者只需在「直接机制」里搜索，找的是一对分配规则与支付规则，不必发明博弈流程。本章接下来构造的就是这样的直接机制。

> **易混点**：显示原理塌缩的是「搜索空间」，不是说直接机制一定更好执行，间接机制有时沟通量更少、隐私更好。它给的是设计方法论：最优结果总能以直接机制的形式实现，找它就够了。

把直接机制写全：输入是 $n$ 份估值报告，输出是分配 $f(b)$ 与支付 $p(b)$，是纯函数、无多轮、无流程设计。本册此后说到「机制」，不特别说明时都指直接机制。

## $\rm \S \, 3.4$ VCG：按外部性收费

多个物品或多个位置、每人估值不同时，二价的直觉如何推广？先把估值模型说清：广告位的价值是「点击量 × 每次点击的价值」，前者由位置决定、后者是广告主的私人信息，广告主报告的正是这个每点击价值。**VCG 机制（Vickrey–Clarke–Groves mechanism）**给出一般答案。分配规则：选使报告的总福利最大的分配。支付规则：每人支付自己给别人造成的损失——具体地，

$$
p_i \;=\; W^{*}_{-i}\;-\;W_{-i}
$$

其中 $W^{*}_{-i}$ 是把 $i$ 拿走后、其余人能达到的最大总福利，$W_{-i}$ 是当前分配下其余人实际得到的总福利。你不为自己得到的付费，为你「占了位置导致别人少拿的」付费。

单物品时它退化为二价：赢家付的 $W^{*}_{-i}-W_{-i}$ 恰是第二高估值（没有你时它会被第二高的人拿走）。多物品看一个能手算的广告位例子：两个广告位，每日点击量 $10$ 与 $5$；三个广告主每次点击的价值 $A=4$、$B=3$、$C=1$。先把六种分配的总福利列全：

| 分配（位1, 位2） | 总福利 |
| --- | --- |
| A, B | $4\cdot 10+3\cdot 5=55$ |
| A, C | $4\cdot 10+1\cdot 5=45$ |
| B, A | $3\cdot 10+4\cdot 5=50$ |
| B, C | $3\cdot 10+1\cdot 5=35$ |
| C, A | $1\cdot 10+4\cdot 5=30$ |
| C, B | $1\cdot 10+3\cdot 5=25$ |

最优分配是 A 得位1、B 得位2，总福利 $55$。表里已经能看出位置的分量：谁拿位1 比谁拿位2 重得多：A、B 互换（第 3 行）福利立刻从 $55$ 掉到 $50$。按外部性算支付（全部枚举已用脚本核对）：1. A：没有 A 时其余人最优是 B 位1、C 位2，福利 $3\cdot 10+1\cdot 5=35$；有 A 时其余人得 $3\cdot 5=15$。付 $35-15=20$，效用 $40-20=20$；
2. B：没有 B 时其余人最优是 A 位1、C 位2，福利 $45$；有 B 时其余人得 $40$。付 $45-40=5$，效用 $15-5=10$；
3. C 未得物品：没有 C 时其余人的最优仍是 A 位1、B 位2，福利 $55$，与有 C 时完全相同，故付 $55-55=0$。

顺手核一遍「偏离无利可图」在这个实例上的样子：A 谎报 $5$/点击，排序不变、分配不变，支付按外部性结构算仍是 $20$，效用不变。A 谎报 $2$/点击，分配变为 B 位1、A 位2，A 付 $35-30=5$，效用 $4\cdot 5-5=15<20$。两头都不赚，直觉与 §3.2 的逐情形证明在此汇合。最后留一条界线：以上全部论证针对一次性拍卖；同样规则重复进行时，跨轮的声誉与报复会引入新的策略空间，真话不再逐轮占优。本册只处理一次性机制。

注意每单位点击的价格并不统一：A 付 $2$/点击、B 付 $1$/点击。位1 赢家的支付里含着「把位2 从 B 手里抢走」的外部性，这是多物品 VCG 与朴素「各自二价」的分界。把本节的成果打包成四条：

1. 分配福利最大：$55$，六种分配之首；
2. 说真话占优：向上谎报、向下谎报都不增收（本节两处抽核）；
3. 赢家效用非负（$20$、$10$、$0$）：没人被迫参与，这叫个人理性；
4. 收入 $25$：由估值结构决定，平台无法用规则参数直接调控。

第 3 条与第 2 条合起来才是完整的好机制：没人想撒谎，也没人想缺席。第 4 章会看到，近似一旦介入，这两条性质要一起重新挣得。

VCG 为什么激励相容？直觉一句话：你的支付只通过「你的到来挤掉了别人的什么」依赖分配，而外部性定价把你谎报能骗到的每一分好处，都精确地变成你账上多出来的支付。报高价挤掉别人，你付的就是被挤掉者的福利。完整证明需要逐条核对偏离方向，超出本书范围，但「算例里每个赢家的效用都是 $20$、$10$、$0$ 这样的非负数」与「报告真值时拿到的分配是全局最优」这两件事，就是第 4 章一切讨论的出发点。

顺带排除一个错误做法「每个位置各自二价」：位1 给报价最高者、收第二高的报价，位2 给次高者、收第三高的报价。放到上面的例子里：A 得位1、付 $9$/点击，总效用 $4\cdot 100-9\cdot 100=-500$，为负；位2 的 B 恰好付到自己的估值 $3$/点击，效用 $0$。位置之间的外部性没有进账单，报价与支付脱钩，参与者会被迫压价自保。朴素推广既不诚实也不高效，这正是必须用外部性定价的原因。

另有一条隐含的好性质：VCG 下赢家付的钱不会超过自己的估值（上例 $20\le 40$、$5\le 15$），所以参与拍卖永远不吃亏，没人需要被强迫进场。这个「自愿参与」约束在更一般的机制设计里叫个人理性，本册把它当背景假设使用。

## $\rm \S \, 3.5$ VCG 的代价

VCG 激励相容且福利最大，却不是免费午餐，三条代价都真实存在：

1. 收入不可控：总收入取决于估值结构，可能异常低，某些配置下甚至为 $0$。第 4 章同一实例上 VCG 收入 $550$，明显低于业界实际使用的 GSP 的 $950$——效率最高的机制未必是收入最高的机制；
2. 解释与预算成本：各赢家的单位价格互不相同（上例 $2$ 与 $1$），对广告主难以解释，「我为什么付这个价」需要一整套外部性叙事。预算约束也难以嵌入：预算花完的人退出博弈，IC 论证的前提就散了；
3. 计算代价：总福利最大的分配问题本身可能是 NP 难的，这正是第 4 章的主题。

工业界的广告拍卖因此没有直接用 VCG，而是用它砍掉解释成本后的近似品 GSP。但那份近似把「真话占优」也砍掉了。给 VCG 摆正位置：它是理论基准——证明了激励相容可达、给出福利上界与支付的构造方式；工程实践是在基准周围做减法，减掉什么、留下什么，是第 4 章的主题。

> **易混点**：「收入不可控」不是说 VCG 一定收入低，而是说收入由估值结构决定、平台无法用规则参数直接调控。同一个 VCG，估值拥挤时收入可观，估值拉开时收入萎缩。这与「效率最高」并不矛盾：效率分的是蛋糕，收入是蛋糕里归平台的那块。第 4 章的同一实例会把这句「不可控」变成具体数字：$550$ 对 $950$。

> **易混点**：分配规则「总福利最大」用的是各方报出的值。只有在激励相容的机制里，报告才等于真值，「效率」才有确定的含义；在一个会被人谎报的机制里谈「选了福利最大的分配」，那个「福利」本身已经是被操纵过的数。

## $\rm \S \, 3.8$ 本章自测答案

> 先闭卷作答上面两节，再核对。

### $\rm \S \, 3.8.1$ 关键概念回顾答案

1. 分配规则与支付规则；激励相容指如实报告估值是每个人的占优策略——不依赖对手行为的任何假设。（§3.1）
2. 报 $b>v$ 且 $s<v$、报 $b<v$ 且 $s<b$ 时，偏离与如实报的成交与支付完全相同——正是「支付与他人报价挂钩」使得这些偏离无差别；而抬价的新风险只出现在 $v<s<b$。（§3.2）
3. 任何机制的任何均衡结果都能由一个说真话的直接机制复制；搜索空间从「一切博弈流程」塌缩为「直接机制的分配规则与支付规则」。（§3.3）
4. $p_i=W^{*}_{-i}-W_{-i}$：$W^{*}_{-i}$ 是去掉 $i$ 后其余人的最大总福利，$W_{-i}$ 是当前分配下其余人的实际福利。单物品时去掉赢家后其余人的最优就是第二高者得物品，故赢家付第二高估值。（§3.4）
5. 收入不可控甚至可为 $0$；单位价格不统一带来解释与预算困难；福利最大化分配可能 NP 难。（§3.5）

### $\rm \S \, 3.8.2$ 应用与辨析答案

1. 报 $v$ 即便赢了效用也是 $0$，不如压价；均衡里人人按估值的折扣出价，折扣大小还依赖对对手的信念——这正是二价想免除的「猜」。（§3.2）
2. 赢家是估值 $7$ 者：没有他时物品归 $5$ 者、其余人福利 $5$；有他时其余人福利 $0$，支付 $5$。与二价规则（付第二高价 $5$）一致——VCG 是二价的推广。（§3.4）
3. 赢家付的是输家的报价，输家压到 $1$ 后赢家只需付 $1$，两人再私下分差价 $8$，双方都赚。占优策略性质只防「单方」偏离，不防结盟——防合谋是机制设计的另一条战线。（§3.2）

VCG 证明了一件事：让说真话成为占优策略是可以做到的，代价是每次分配都要解一个「总福利最大」的优化问题。单物品这不过是一次找最大值；物品一多、估值一复杂，这个问题就会撞上 NP 难。下一章处理计算复杂度与激励相容的正面冲突：近似求解会不会把「诚实」也解没了。
