# $\rm Chapter \, 2$ 浓度工具：从 Markov 到 Chernoff

上一章把期望算得清清楚楚，可「期望」只是平均值：一个期望 $nH_n$ 步的收集过程偶尔会跑上三倍长，一个期望 $W/2$ 的割偶尔会掉到很差。算法要在**单次调用**上可信，就必须把「偏离期望的概率」按死。浓度不等式（concentration inequalities）干的就是这件事——把「一堆独立噪声互相抵消」从直觉写成定量承诺，本章从最弱的 Markov 一路升级到 Chernoff，每条都给全证明，最后用真跑的数字对照每条的松紧。

> **开始前自检**：本章假设你已经会：
>
> 1. □ 第 1 章的指示变量与期望线性性 $\mathrm{E}[\sum X_i] = \sum \mathrm{E}[X_i]$，以及几何分布的期望 $1/p$。
> 2. □ 方差与独立性：独立时 $\mathrm{Var}(X+Y) = \mathrm{Var}X + \mathrm{Var}Y$；$\mathrm{Bern}(p)$ 的方差是 $p(1-p)$（本站概率论册第 2 章）。
> 3. □ 二项分布 $\mathrm{Bin}(n,p)$ 是 $n$ 个独立 $\mathrm{Bern}(p)$ 之和，$\mu = np$（概率论册第 2 章）。
> 4. □ 微积分基本功：$\ln(1+\delta)$ 的泰勒展开、$\mathrm{e}^x$ 求导，以及 $\mathrm{e}^x \ge 1 + x$。
>
> 第 2、3 条是本章的原材料，不熟先回概率论册补齐。

## $\rm \S \, 2.1$ 三个不等式速建：Markov、Chebyshev、Chernoff

先立最弱的一块砖，再逐级加固。**Markov 不等式**只用期望，问：非负随机变量取大值的概率能有多大？

**命题 2.1（Markov）**：$X \ge 0$，则对任意 $t > 0$，$\Pr[X \ge t] \le \mathrm{E}[X]/t$。

全证：在事件 $\{X \ge t\}$ 上有 $X \ge t \ge 0$，事件外指示变量为 $0$。用指示变量拆期望，

$$
\mathrm{E}[X] \ge \mathrm{E}\big[X\cdot\mathbf{1}_{\{X \ge t\}}\big] \ge \mathrm{E}\big[t\cdot\mathbf{1}_{\{X \ge t\}}\big] = t\,\Pr[X \ge t].
$$

读法：非负性保证「扔掉事件外的贡献」这一步不亏（扔掉的都是 $\ge 0$ 的东西），于是期望被事件内贡献托住，除 $t$ 即得。$\blacksquare$

**Chebyshev 不等式**把 Markov 用在平方量 $(X - \mathrm{E}[X])^2$ 上：想控制偏离，就先让它变成非负量。

**命题 2.2（Chebyshev）**：对任意 $t > 0$，$\Pr[|X - \mathrm{E}[X]| \ge t] \le \mathrm{Var}(X)/t^2$。

证明：对非负变量 $(X - \mathrm{E}[X])^2$ 用命题 2.1（阈值 $t^2$），左端事件恰是 $|X-\mathrm{E}[X]| \ge t$。$\blacksquare$

把 Chebyshev 用于 $\bar X = \frac1n\sum X_i$（独立、方差 $\sigma^2$）：$\mathrm{Var}(\bar X) = \sigma^2/n$，于是 $\Pr[|\bar X - \mu| \ge t] \le \frac{\sigma^2}{nt^2}$。这已经证出弱大数定律，但**尾巴太胖**：多项式 $1/t^2$ 只能按幂律收缩，而独立和的真尾巴是指数的。要指数尾巴，就把 Markov 用在 $\mathrm{e}^{\theta X}$ 上。

算一笔样本账看出两条尾巴的差距。要让 $\bar X$ 偏离均值超过 $0.01$ 的概率压到 $10^{-6}$（公平硬币，$\sigma^2 = \frac14$）：

1. 正态近似要求 $n \approx 5.6 \times 10^4$（$0.01$ 相当于 $4.75$ 个标准差）；
2. Chebyshev 要求 $\frac{1}{4n\,(0.01)^2} \le 10^{-6}$，即 $n \ge 2.5 \times 10^{10}$——多付约 $44$ 万倍。

差距不在常数，在结构：Chebyshev 只用方差，必须为「方差相同、但质量全堆在 $\pm t$ 处」的最坏分布买单；独立和的真尾巴是指数薄的，二阶矩天生压不出指数。比喻：用体温计量身高，仪器没错，量程不对。

**命题 2.3（Chernoff 上界）**：对任意 $\theta > 0$，

$$
\Pr[X \ge t] \le \mathrm{e}^{-\theta t}\,\mathrm{E}\big[\mathrm{e}^{\theta X}\big],\qquad \text{故}\qquad \Pr[X \ge t] \le \inf_{\theta > 0}\,\mathrm{e}^{-\theta t}\,\mathrm{E}\big[\mathrm{e}^{\theta X}\big].
$$

推导三步：$\theta > 0$ 时 $\mathrm{e}^{\theta x}$ 递增，事件改写为 $\{\mathrm{e}^{\theta X} \ge \mathrm{e}^{\theta t}\}$；对非负变量 $\mathrm{e}^{\theta X}$ 用 Markov；对**每个** $\theta$ 都成立，取下确界取最紧的。$\blacksquare$

把它兑现到独立伯努利和。设 $X_1, \ldots, X_n$ 独立同 $\mathrm{Bern}(p)$，$S = \sum_i X_i$，$\mu = np$，考察相对偏差 $S \ge (1+\delta)\mu$。

**第一步（MGF 因子化）**：独立性让期望拆成乘积，每个 $X_i$ 贡献 $\mathrm{e}^\theta$ 的概率是 $p$、贡献 $1$ 的概率是 $1-p$，

$$
\mathrm{E}\big[\mathrm{e}^{\theta S}\big] = \prod_{i=1}^n \mathrm{E}\big[\mathrm{e}^{\theta X_i}\big] = \big(1 - p + p\,\mathrm{e}^\theta\big)^n.
$$

**第二步（拧 $\theta$）**：每份变量摊到的指数是 $\varphi(\theta) = -\theta\,(1+\delta)p + \ln(1 - p + p\,\mathrm{e}^\theta)$（把 $t = (1+\delta)\mu$ 摊到 $n$ 份）。求导 $\varphi'(\theta) = -(1+\delta)p + \frac{p\,\mathrm{e}^\theta}{1-p+p\,\mathrm{e}^\theta}$，令它为零解出唯一驻点 $\mathrm{e}^{\theta^*} = \frac{(1+\delta)(1-p)}{1-(1+\delta)p}$。

**第三步（代回）**：把 $\theta^*$ 代回并整理，得到经典闭式

$$
\Pr[S \ge (1+\delta)\mu] \le \left(\frac{\mathrm{e}^{\delta}}{(1+\delta)^{1+\delta}}\right)^{\mu}.
$$

读法：右底数小于 $1$（因 $\ln(1+\delta) > \frac{\delta}{1+\delta}$），幂指数是 $\mu$，所以偏差越大、$\mu$ 越大，界就越指数地小。

**弱化版**：底数的对数 $\delta - (1+\delta)\ln(1+\delta)$ 不好看，算法分析里常换成只含 $\delta$ 的形式。可以证明对 $0 \le \delta \le 1$ 有 $\delta - (1+\delta)\ln(1+\delta) \le -\frac{\delta^2}{3}$（把左边看成 $\delta$ 的函数、检查它在 $0$ 处取值与导数的界即可），于是

$$
\Pr[S \ge (1+\delta)\mu] \le \mathrm{e}^{-\delta^2\mu/3},\qquad \text{更粗一档：}\quad \Pr[S \ge (1+\delta)\mu] \le \mathrm{e}^{-\delta^2 n/3}.
$$

读法：$\mathrm{e}^{-\delta^2\mu/3}$ 里 $\mu = n/2$（公平硬币），故 $\mathrm{e}^{-\delta^2 n/3}$ 是它的一个更松的抄法，算法分析里常直接用它做数值估算。双侧版本对 $-S$ 再用一次即可。

**本节小结**：Markov 供给两行母机、Chebyshev 是它的平方版（多项式尾巴）、Chernoff 把指数请回来（指数尾巴）。弱化版 $\mathrm{e}^{-\delta^2\mu/3}$ 是把 KL 型闭式折成只含偏差比例的一阶估计。

## $\rm \S \, 2.2$ 在算法分析中的用法：三个高概率承诺

浓度工具在算法里的通用句式是**高概率（with high probability，whp）**：某个坏事件发生的概率不超过 $n^{-c}$（$c$ 是任意常数）。下面三个是标准演练。

**(a) 随机化快排的递归深度高概率 $O(\log n)$。** 取一次随机主元，若它落在数组的中间一半（即划分后两段都 $\le \frac34 n$），称这一步**好**；好主元的概率是 $\frac12$。一条根到叶的路径上，只要攒够 $k$ 个好主元，子问题规模就从 $n$ 降到 $(\frac34)^k n$；令 $(\frac34)^k n \le 1$ 得 $k = \log_{4/3} n \approx 3.48\ln n$。走 $T = 4k$ 步还没触底，等于 ${4k}$ 次独立试验里好主元少于 $k$ 个（期望是 ${2k}$），这是概率 $\frac12$ 的独立和的下偏差。用弱化版 Chernoff（取 $\delta = \frac12$）：$\Pr[\text{好主元} < k] \le \mathrm{e}^{-k/12}$。要压到 $n^{-c}$，取 $k \gtrsim 12c\ln n$，于是**递归深度 $\le 4k = O(\log n)$ 以概率 $\ge 1 - n^{-c}$ 成立**。对照 $\S1.3$：期望比较次数 $2n\ln n$，而深度还额外有个高概率的 $O(\log n)$ 保证。深度的尾界可以钉成一行，$D$ 记递归深度：

$$
\Pr\big[D > 4k\big] \le \Pr\big[\text{好主元} < k \text{（共 } 4k \text{ 次）}\big] \le \mathrm{e}^{-k/12},\qquad k = \lceil 12c\ln n\rceil.
$$

严格化这一步要用一次联合界：递归树深度上限 $T$ 时根到叶的路径最多 $2^{T}$ 条，把单条路径的失败概率先压到 $2^{-T}n^{-c}$（指数里多留 $\ln 2$ 那一点），$2^{T}$ 条路径联合起来仍是 $n^{-c}$。这就是 $\S2.4$ 账本「指数多留一点」的具体还款，成本是常数因子 $12 \to 24$ 量级。

**(b) 哈希链长度高概率 $O(\log n/\log\log n)$。** 把 $n$ 个键散列进 $n$ 个桶，键之间各不相关，单个桶的长度 $X$ 近似 $\mathrm{Bin}(n, 1/n) \approx \mathrm{Poisson}(1)$。用上尾 Chernoff（$\mu = 1$，$\delta$ 较大时用 $\Pr[X \ge k] \le (\mathrm{e}/k)^k$）：某个固定桶长度 $\ge k$ 的概率 $\le (\mathrm{e}/k)^k$。对 $n$ 个桶取**联合界**（$\S2.4$），只要 $n\,(\mathrm{e}/k)^k \to 0$，就**所有**桶都短于 $k$。取 $k = \frac{c\ln n}{\ln\ln n}$：$\ln\big((\mathrm{e}/k)^k\big) = k(1 - \ln k) \approx -k\ln k \approx -\frac{c\ln n}{\ln\ln n}\cdot\ln\ln n = -c\ln n$，于是 $n\cdot(\mathrm{e}/k)^k \approx n^{1-c}$。所以最长链高概率不超过 $\frac{c\ln n}{\ln\ln n}$——比最坏情况的 $n$ 短了指数级。写成一行尾界（$X_i$ 是第 $i$ 桶长度）：

$$
\Pr\Big[\max_{1 \le i \le n} X_i \ge k\Big] \le n\,(\mathrm{e}/k)^k \le n^{1-c},\qquad k = \frac{c\ln n}{\ln\ln n}.
$$

**(c) 负载均衡：最大负载 $\approx \frac{\ln n}{\ln\ln n}$，两选一砍到 $\log\log n$。** 把 $n$ 个球独立均匀扔进 $n$ 个桶（单选一）。固定桶超过 $k$ 个球的概率 $\le (\mathrm{e}/k)^k$，取 $k = \frac{(1+o(1))\ln n}{\ln\ln n}$ 则由联合界得最大负载高概率为 $\Theta(\frac{\ln n}{\ln\ln n})$：桶数乘以单桶尾巴仍是 $o(1)$。**两选一（power of two choices）**：每个球先随机取两个桶，扔进当前较空的那个。一句话结论——最大负载降到 $\frac{\ln\ln n}{\ln 2} + O(1) = \log_2\log_2 n + O(1)$，指数塔少了一层。模拟（$n$ 个球 $n$ 个桶，固定种子）给：

| $n$ | 单选一最大负载 | 理论 $\ln n/\ln\ln n$ | 两选一最大负载 | 理论 $\log_2\log_2 n$ |
| --- | --- | --- | --- | --- |
| $10^4$ | $7$ | $4.15$ | $3$ | $3.73$ |
| $10^5$ | $8$ | $4.71$ | $4$ | $4.05$ |
| $10^6$ | $9$ | $5.26$ | $4$ | $4.32$ |

单选一的实测比渐近值偏高，是 $o(1)$ 修正项在中小 $n$ 的体现；两选一稳稳落在 $4$ 附近，比单选一低一大截。两句提醒：桶越满越少，最大负载就由「最贪的那个桶」决定，这正是联合界的用武之地。单桶尾巴的 $(\mathrm{e}/k)^k$ 从哪来？对 $\mathrm{Poisson}(1)$ 用 Chernoff，$\Pr[X \ge k] \le \frac{\mathrm{e}^{-1}\mathrm{e}^\theta}{(\mathrm{e}^\theta)^k}$，令 $\mathrm{e}^\theta = k$ 即得 $(\mathrm{e}/k)^k$——又一次「把 $\theta$ 拧到驻点」。

**本节小结**：三个承诺都用「Chernoff 压单点、联合界扫全部点」这一个套路——快排深度 $O(\log n)$、哈希链 $O(\log n/\log\log n)$、负载均衡 $\Theta(\ln n/\ln\ln n)$；两选一把负载的指数塔砍掉一层。

## $\rm \S \, 2.3$ 数值锚：界与真值的对照

$n = 100$ 公平硬币、$X \sim \mathrm{Bin}(100, \frac12)$，$\mu = 50$、标准差 $\sigma = \sqrt{100\cdot\frac14} = 5$。表里精确真值由二项尾概率逐项求和给出，三档界分别是紧 Chernoff、弱化版 $\mathrm{e}^{-\delta^2\mu/3}$、更粗的 $\mathrm{e}^{-\delta^2 n/3}$（$\delta = (k - 50)/50$）。

| $k$ | 偏离 | 精确真值 | 紧 Chernoff | $\mathrm{e}^{-\delta^2\mu/3}$ | $\mathrm{e}^{-\delta^2 n/3}$ |
| --- | --- | --- | --- | --- | --- |
| $55$ | $1\sigma$ | $1.84\times10^{-1}$ | $7.85\times10^{-1}$ | $8.47\times10^{-1}$ | $7.17\times10^{-1}$ |
| $60$ | $2\sigma$ | $2.84\times10^{-2}$ | $3.91\times10^{-1}$ | $5.13\times10^{-1}$ | $2.64\times10^{-1}$ |
| $65$ | $3\sigma$ | $1.76\times10^{-3}$ | $1.28\times10^{-1}$ | $2.23\times10^{-1}$ | $4.98\times10^{-2}$ |
| $70$ | $4\sigma$ | $3.93\times10^{-5}$ | $2.86\times10^{-2}$ | $6.95\times10^{-2}$ | $4.83\times10^{-3}$ |

读三件事。第一，**$\sigma$ 检查**：$X \ge 65$ 是偏离均值 $3\sigma = 15$ 处，精确概率 $1.76\times10^{-3}$，而 $\mathrm{e}^{-\delta^2 n/3}$ 给 $4.979\times10^{-2}$——同一档误差，界比真值大了一个半数量级，但已经是指数的形状；$X \ge 70$ 是 $4\sigma$，界 $4.83\times10^{-3}$ 与真值 $3.93\times10^{-5}$ 差两个数量级，仍在飞速收窄。第二，$\delta = 0.3$ 时 $\mathrm{e}^{-\delta^2 n/3} = \mathrm{e}^{-3} = 4.979\times10^{-2}$，$\delta = 0.1$ 时 $\mathrm{e}^{-\delta^2 n/3} = \mathrm{e}^{-1/3} = 7.165\times10^{-1}$——这两个正是本章要照抄的锚。第三，越靠近均值（$1\sigma$）界越松，因为 Chernoff 的指数是按「偏离比例」付账的，小幅偏离的单份代价小、乘以 $\mu$ 也压不下去；所以界在**深尾**才显出威力，浅尾处宁可贴个 $\sigma$ 或直接算精确值。

紧 Chernoff 与真值之间总差着 KL 型常数：真正的最优指数是 $\mu\,D(0.65\,\|\,0.5)$，其中 $D$ 是相对熵。$D(0.65\,\|\,0.5) = 0.65\ln\frac{0.65}{0.5} + 0.35\ln\frac{0.35}{0.5} \approx 0.0457$，$nD \approx 4.57$，故最优界 $\mathrm{e}^{-nD} \approx 1.03\times10^{-2}$，与真值 $1.76\times10^{-3}$ 只差约 $6$ 倍；本章用的 $\mathrm{e}^{-\delta^2 n/3} = 4.98\times10^{-2}$ 与它同量级。弱化版把 KL 换成 $\delta^2/3$，图的是「只含偏差比例、不必查表」，代价是常数上浮几倍——这是随机算法分析里最常做的取舍。把三档界的用途收在一处：

1. **紧 Chernoff**（含 KL）：要最优常数、能查表时用。
2. **弱化 $\mathrm{e}^{-\delta^2\mu/3}$**：只要偏差比例、算数最省，证明里最常引。
3. **粗化 $\mathrm{e}^{-\delta^2 n/3}$**：连 $\mu$ 都懒得写，口头估算用。

$$
\text{同一点 } X \ge 65:\quad \underbrace{1.76\times10^{-3}}_{\text{真值}} \;<\; \underbrace{1.03\times10^{-2}}_{nD} \;<\; \underbrace{4.98\times10^{-2}}_{\mathrm{e}^{-\delta^2 n/3}}.
$$

**本节小结**：三档界的松紧按「紧 Chernoff < 弱化 < 粗化」排序，但任何一档在深尾处都给出指数形状；浅尾别用 Chernoff 估算，直接看 $\sigma$。

## $\rm \S \, 2.4$ 「高概率」的记账纪律

随机算法报告结果时，「高概率」三个字必须能还原成一个数，否则等于没说。本站统一口径：

1. **高概率 = $1 - n^{-c}$**，$c$ 是**可以任意取大**的常数，$n$ 是输入规模。凡是写「whp」的地方，都要能说出「失败概率 $\le n^{-c}$，$c$ 取多大由后面几步决定」。
2. **联合界（union bound）**：$\Pr[\bigcup_i A_i] \le \sum_i \Pr[A_i]$。它粗糙但万用——把「所有点都好」拆成「每个点都好」，代价是概率相加。
3. **还款账本**：若有 $m$ 个坏事件、每个概率 $\le n^{-(c+1)}$，则联合界给总失败 $\le m\,n^{-(c+1)}$。只要 $m \le n$，就有 $m\,n^{-(c+1)} \le n^{-c}$，整体仍是 whp。所以**单个事件的指数里永远多留 $1$**，用来付「点太多」这笔联合界的利息。$\S2.2$ 的哈希链与负载均衡都是先压单点、再用这本账扫全场的。

账本实例：负载均衡里单桶长度 $\ge k$ 的概率是 $p_k = (\mathrm{e}/k)^k$，共 $n$ 个桶，联合界给「存在某个长桶」的概率 $\le n\,p_k$。要它 $\le n^{-c}$，只需 $p_k \le n^{-(c+1)}$——注意右端指数从 $-c$ 变成 $-(c+1)$，多出来的 $1$ 正是付给「$n$ 个桶」的利息。取 $k = \frac{(c+1)\ln n}{\ln\ln n}$ 代回 $(\mathrm{e}/k)^k$，用 $\S2.2(\mathrm{b})$ 的同款估算即得 $p_k \approx n^{-(c+1)}$，账平：

$$
m\,n^{-(c+1)} \;\le\; n\cdot n^{-(c+1)} \;=\; n^{-c}.
$$

一个常见错误是拿**期望**当**高概率**：$\mathrm{E}[X] = o(1)$ 只说「平均很少坏」，不说「几乎不坏」（$X$ 可以以极小概率取一个极大的值）。要 whp 就回到尾部概率，别拿平均值搪塞。

**本节小结**：whp 是可还原的 $1 - n^{-c}$；联合界把多点坏事件相加，代价用「多留一个指数单位」付清。期望小不等于概率小。

## $\rm \S \, 2.5$ 关键概念回顾

1. Markov 的两行证明里，「非负」和「指示变量」各用在哪一步？为什么 Chebyshev 要先平方再套 Markov？
2. Chernoff 方法的三步链（单调化、Markov、对 $\theta$ 取下确界）各换来什么？$\theta^*$ 由什么平衡决定？
3. 独立伯努利和的 MGF 因子化用在哪一步？紧 Chernoff 的底数 $\mathrm{e}^\delta/(1+\delta)^{1+\delta}$ 为什么小于 $1$？
4. 快排递归深度为什么要求「好主元」攒够 $k = \log_{4/3} n$ 个？$T = 4k$ 步的试验里好主元少于 $k$ 个的概率用哪条界压下？
5. 哈希链与负载均衡的两步套路是什么？为什么单点尾巴压到 $n^{-(c+1)}$ 就够了？
6. 「$\mathrm{E}[X] = o(1)$」与「$\Pr[X \ge 1] \le n^{-c}$」差在哪里？举一个前者成立而后者不成立的例子。

## $\rm \S \, 2.6$ 应用与辨析

1. 有同学说「Chebyshev 与 Chernoff 都给 $X$ 偏离均值的概率上界，Chebyshev 更一般所以更强」。指出错误。
2. 用弱化版 Chernoff 估 $n = 100$、$X \ge 55$（$1\sigma$）得到 $0.717$，某同学据此说「硬币几乎不会偏离 $\sigma$ 以上」。这话对吗？界在这里出了什么问题？
3. 哈希链分析里为什么对 $n$ 个桶取联合界、而不对键取？把「某个固定桶」的长度界直接说成「最长链」的界会漏掉什么？
4. 两选一把最大负载从 $\Theta(\ln n/\ln\ln n)$ 砍到 $\log_2\log_2 n$。为什么多看一眼第二个桶就能砍掉一层指数塔，而看更多桶收益锐减？
5. 若某算法的失败概率是 $n\cdot 2^{-n}$（$n$ 个事件各 $2^{-n}$），它算 whp 吗？若每个事件概率是 $2^{-n/2}$ 呢？用 $\S2.4$ 的账本判断。
6. 「Chernoff 界比真值大好几倍」是否说明界没用？结合 $\S2.3$ 的表，说明评价一条尾界「好不好」应该看什么。

## $\rm \S \, 2.7$ 本章自测答案

> 先闭卷作答 $\S2.5$ 与 $\S2.6$，再核对。

### $\rm \S \, 2.7.1$ 关键概念回顾答案

1. 非负性保证「扔掉事件外贡献」不亏；指示变量把事件折算成 $0/1$，让期望一拆两半。平方把双侧偏差折成非负量才能套 Markov，代价是只留二阶信息。（$\S2.1$）
2. 单调化无损地把事件等价改写；Markov 换来不等式；取 $\theta$ 下确界选出最紧的界。$\theta^*$ 由「线性惩罚 $-\theta t$」与「MGF 增长 $\ln M_X(\theta)$」的导数平衡决定。（$\S2.1$）
3. 因子化 $\mathrm{E}[\mathrm{e}^{\theta S}] = \prod \mathrm{E}[\mathrm{e}^{\theta X_i}]$ 用了完全独立。底数 $<1$ 因 $\ln(1+\delta) > \delta/(1+\delta)$，即 $\delta - (1+\delta)\ln(1+\delta) < 0$，故指数为负。（$\S2.1$）
4. 好主元使两段都 $\le\frac34 n$，$k$ 个好主元把规模压到 $(\frac34)^k n \le 1$。${4k}$ 次里好主元（期望 ${2k}$）少于 $k$ 是 $\frac12$ 独立和的下偏差，用弱化版 Chernoff 得 $\mathrm{e}^{-k/12}$ 量级，再取 $k \gtrsim 12c\ln n$ 压到 $n^{-c}$。（$\S2.2$）
5. 套路：Chernoff 压单点（固定桶／固定球）到 $n^{-(c+1)}$，联合界扫 $m \le n$ 个点，$m\,n^{-(c+1)} \le n^{-c}$。多留一个指数单位就是付联合界的利息。（$\S2.2$、$\S2.4$）
6. $\mathrm{E}[X] = o(1)$ 只控平均，允许小概率取极大值；whp 要求整个尾部 $\le n^{-c}$。例：$X = n^{c+1}$ 以概率 $n^{-(c+1)}$、否则 $0$，则 $\mathrm{E}[X] = 1$，而 $\Pr[X \ge 1] = n^{-(c+1)}$——要 whp 得指数够负。（$\S2.4$）

### $\rm \S \, 2.7.2$ 应用与辨析答案

1. 错。Chebyshev 只消化方差、给多项式尾巴 $1/t^2$；Chernoff 消化了「独立 + 有界」的完整结构、给指数尾巴。在 $X \ge 70$ 处 Chebyshev 界还停在 $0.25$ 量级，真值已是 $10^{-5}$——一般性换来的是松。（$\S2.3$）
2. 不对。$1\sigma$ 是**浅尾**，精确概率 $0.184$，Chernoff 界 $0.717$ 比它大近四倍，根本没在「压概率」；界只保证「不超过 $0.717$」，是个很松的上界。要估浅尾概率，用正态近似或直接算精确值。（$\S2.3$）
3. 因为要保证的是「所有桶都短」，坏事件发生在桶这一侧（共 $n$ 个），联合界扫 $n$ 个桶即可。只说「固定桶短于 $k$」漏掉了「哪个桶最长」的选择——$n$ 个桶里总有一个最长的，必须对所有桶联合，这就是 $\S2.2$ 里多出的那个 $\ln$ 因子来源。（$\S2.2$、$\S2.4$）
4. 单选一的瓶颈是「最贪的那个桶」反复被砸，需要 $\ln n/\ln\ln n$ 个球；两选一让一个球在「两个较空者里选更空」，等价于每次从两桶取 $\min$，极端尾部被削掉一层，最大负载变成 $\log\log n$。再看第三个桶只把常数再改一点，指数塔已到底，收益锐减。（$\S2.2$）
5. $n\cdot 2^{-n}$：单点 $2^{-n}$，$m = n$，总失败 $\le n\,2^{-n} \le n^{-c}$（对足够大 $n$），算 whp。$2^{-n/2}$：总失败 $\le n\,2^{-n/2}$，指数只到 $n/2$，仍是 $n^{-c}$ 量级，也算 whp（任何固定 $c$，取 $n$ 够大即可）。判断标准是「除以 $n$ 后指数还剩多少」。（$\S2.4$）
6. 不看「界／真值」的比值，看界本身的绝对量级与随规模的下降速度。深尾处真值 $10^{-3}\sim10^{-5}$、界 $10^{-1}\sim10^{-2}$，两者都小到实践上不会发生，且界随 $\delta$、$\mu$ 指数下降——这才是算法敢依赖的承诺；浅尾界 $0.7$ 虽比值小，却压不住概率、给不出「不会发生」的保证。分工：浅尾用正态近似估数值，深尾用 Chernoff 做担保。（$\S2.3$）

## $\rm \S \, 2.8$ 程序对账

下面一段把 §2.3 的对照表重算一遍：精确二项尾概率用整数组合数避免浮点误差，三档界按闭式算，最后一行顺带跑一次负载均衡模拟。

```python
import math, random
from math import comb, exp, log

def bin_tail(n, p, k):
    # 精确 P(X >= k)，X ~ Bin(n, p)，整数组合数保精度
    return sum(comb(n, i) * p**i * (1 - p)**(n - i) for i in range(k, n + 1))

def bounds(n, k):                            # 公平硬币，mu = n/2
    mu = n / 2.0
    d = (k - mu) / mu                        # 相对均值偏差
    strong = (exp(d) / (1 + d) ** (1 + d)) ** mu
    weak_mu = exp(-d * d * mu / 3)
    weak_n = exp(-d * d * n / 3)
    return strong, weak_mu, weak_n

for k in (55, 60, 65, 70):
    s, wm, wn = bounds(100, k)
    print(f"k={k}  exact={bin_tail(100,0.5,k):.3e}  strong={s:.3e}  weak(mu)={wm:.3e}  weak(n)={wn:.3e}")

print("eps=0.3 weak(n) =", exp(-0.3**2 * 100 / 3))   # 锚：4.979e-02
print("eps=0.1 weak(n) =", exp(-0.1**2 * 100 / 3))   # 锚：7.165e-01

def maxload(n, seed):                        # n 球 n 桶，单选一
    rng = random.Random(seed)
    b = [0] * n
    for _ in range(n):
        b[rng.randrange(n)] += 1
    return max(b)

for n in (10**4, 10**5, 10**6):
    print(f"n={n}  maxload={maxload(n,7)}  ln n/ln ln n={log(n)/log(log(n)):.2f}")
```

输出（本机实测）：

1. 对照表四行与 $\S2.3$ 逐位吻合，例如 `k=65  exact=1.759e-03  strong=1.283e-01  weak(mu)=2.231e-01  weak(n)=4.979e-02`。
2. 两个锚：`eps=0.3 weak(n) = 0.049787068367863944`（即 $4.979\times10^{-2}$），`eps=0.1 weak(n) = 0.7165313105737893`（即 $7.165\times10^{-1}$）。
3. 负载均衡 `n=10^6 maxload=9`、`ln n/ln ln n=5.26`——单选的实测比渐近略高，正是 $o(1)$ 修正项；换成两选一（$\S2.2$）同 $n$ 掉到 $4$。

**带走清单**：Markov 两行证明（非负＋指示变量）；Chebyshev 的平方化；Chernoff 三步链与独立和的 $\big(\mathrm{e}^\delta/(1+\delta)^{1+\delta}\big)^\mu$；弱化版 $\mathrm{e}^{-\delta^2\mu/3}$ 与粗化 $\mathrm{e}^{-\delta^2 n/3}$；快排深度、哈希链、负载均衡三个 whp 承诺；两选一砍一层指数塔；whp 的 $1-n^{-c}$ 口径与联合界账本。
