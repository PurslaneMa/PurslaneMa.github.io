# $\rm Chapter \, 2$ 函子：结构保持的映射

范畴立好了，下一步自然是**跨范畴映射**：把 $\mathcal{C}$ 里的对象与态射整体搬到 $\mathcal{D}$ 里去，而且要求「能接的箭头搬过去还能接、接的顺序不变」。这种映射叫**函子（functor）**，即范畴论的「结构保持同态」。CS 读者将当场认出老朋友：`List` 容器配 `map` 就是一个函子；「对容器里每个元素套一个函数」这件重复了无数遍的操作，本章给出它合法性的精确定义与两条公理，并展示公理如何直接兑现成性能事实（两次 `map` 合一次）。

> **开始前自检**：本章假设你已经会：
>
> 1. □ 范畴、态射、复合与三条公理（[第 1 章](01-范畴是什么.md) §1.2）；
> 2. □ 四个原型范畴：Set、路径、幺半群、偏序（[第 1 章](01-范畴是什么.md) §1.3），本章的例子全部取自它们；
> 3. □ 复合的顺序约定：$g\circ f$ 表示先 $f$ 后 $g$（[第 1 章](01-范畴是什么.md) §1.2），函子公理里最容易写反的地方；
> 4. □ 编程里 `map` 的直觉：对容器内每个元素套函数（不需要会任何函数式语言，§2.3.1 当场用伪代码）。

## $\rm \S \, 2.1$ 要解决的问题：「容器＋遍历」的重复劳动

写代码时同一个形状反复出现：数组套函数逐元素变换、可选值套函数（有值就变换、空就保持空）、树套函数递归变换……每次都重写一遍遍历骨架。更深的烦恼是：怎么确认自己写的「容器变换」没把结构弄坏（顺序乱了、嵌套丢了）？范畴论把这团经验压缩成一个定义：**函子＝对象层面的容器映射＋态射层面的逐元素变换，外加两条「不撕裂」公理**。定义一旦立住，「map 合法」的判定、「两次 map 合一次」的优化，全部变成公理的推论。

## $\rm \S \, 2.2$ 定义与两条公理

**函子（functor）** $F\colon\mathcal{C}\to\mathcal{D}$ 由两层映射组成：

1. **对象层**：每个 $\mathcal{C}$-对象 $A$ 映到 $\mathcal{D}$-对象 $F(A)$；
2. **态射层**：每条态射 $f\colon A\to B$ 映到态射 $F(f)\colon F(A)\to F(B)$（**两端必须配套**：源与目标被同一张对象映射搬过去）。

并满足两条公理：

1. **保恒等**：$F(\mathrm{id}_A)=\mathrm{id}_{F(A)}$，即「什么都不做」搬过去还是「什么都不做」；
2. **保复合**：$F(g\circ f)=F(g)\circ F(f)$，即「先 $f$ 后 $g$」搬过去后**仍是先 $f$ 的像后 $g$ 的像**，接线顺序不乱。

几何图景：函子把 $\mathcal{C}$ 的交换图**原样复印**到 $\mathcal{D}$（点对着点、箭头对着箭头、可接性保持）。为什么恰好这两条？回想第 1 章：范畴里唯一能对态射做的事就是「与恒等复合」「彼此复合」，公理说的正是**复合表在搬运后原样保留**，这是「保结构」在范畴语言里的全部含义：范畴没有别的结构可保。

## $\rm \S \, 2.3$ 例子

### $\rm \S \, 2.3.1$ List：容器函数式的原型函子

在 Set 上定义 $F$：对象层把集合 $A$ 映成「$A$ 中元素的有限列表」$[A]$；态射层把 $f\colon A\to B$ 映成 `map f`：

```text
map f []      = []                      -- 空表不动
map f (x:xs)  = f(x) : map f xs          -- 头部套 f，尾部递归
```

手算：$f$ 为「乘 $2$」，`map f [1,2,3] = [2,4,6]`。公理验证（各配一行伪代码事实）：

1. 保恒等：`map id xs = xs`（逐元素原样拷贝）；
2. 保复合：`map (g ∘ f) xs = map g (map f xs)`，即**两遍遍历等价一遍**。手算走一遍（$f$ 乘 $2$、$g$ 加 $1$、`xs=[1,2]`）：左边 `map (g∘f) [1,2] = [3,5]`；右边 `map g [2,4] = [3,5]` ✓。

第 2 条公理就是编译器「map 融合（fusion）」优化的正确性依据：性能事实从公理免费掉下来。

### $\rm \S \, 2.3.2$ Option：失败透明的函子

$F(A)=A$ 加一个「空」状态（记 `None`）：`map f None = None`，`map f (Some x) = Some (f x)`。公理立即可验（`None` 分支两条公理自动成立，`Some` 分支与 List 同理）。它的范畴论身份：**失败在结构里流动但不污染**：`map` 之后成功路径被变换、失败路径原样保留。第 6 章的单子会把「失败后中止整条链」补全，Option 是那一章的先遣队。

### $\rm \S \, 2.3.3$ 路径范畴之间：图的同态升级

设 $\mathcal{C}=\mathcal{D}=$ 路径范畴（第 1 章 §1.3.2）。函子＝**顶点映射＋边映射，并把路径映为路径的拼接**。最小手算：$G$ 有边 $e_1\colon A\to B$、$e_2\colon B\to C$；$H$ 有单边 $d\colon A'\to C'$。函子把 $A\mapsto A'$、$B\mapsto C'$、$C\mapsto C'$、$e_1\mapsto d$、$e_2\mapsto\mathrm{id}_{C'}$。检验保复合：$\mathcal{C}$ 里 $e_2\circ e_1$（$A$ 到 $C$ 的路径）必须映到 $F(e_2)\circ F(e_1)=\mathrm{id}_{C'}\circ d=d$ ✓，它自动是 $A'\to C'$ 的路径。公理逼着「路径的像＝像的拼接」，这正是图同态在带路径信息后的完整形态。

### $\rm \S \, 2.3.4$ 幺半群之间与两个平凡函子

单对象范畴（幺半群）之间的函子＝**保乘法与单位元的映射**（对象层只有一处，全部内容在态射层）：$F(a\cdot b)=F(a)\cdot F(b)$、$F(e)=e$。例：$(\mathbb{N},+,0)\to(\mathbb{N},\times,1)$ 把 $n$ 映到 $2^n$：$2^{a+b}=2^a\times2^b$ ✓。两个平凡但重要的函子：**恒等函子**（每个范畴到自己，原样搬运）与**常值函子**（一切对象映到固定的 $D$、一切态射映到 $\mathrm{id}_D$，即第 3 章自然变换的「极限锥」角色）。

## $\rm \S \, 2.4$ 反例：什么不是函子

公理可以坏。取 Set 上的候选 $F$：对象层照常（$F(A)=A$），态射层故意取「自复合」$F(f)=f\circ f$。保复合要求 $F(g\circ f)=F(g)\circ F(f)$，即

$$
(g\circ f)\circ(g\circ f) \;\overset{?}{=}\; (g\circ g)\circ(f\circ f)
$$

取 $\mathbb{N}$ 上 $f=$「加 $1$」、$g=$「乘 $3$」（这一族函数**不可交换**：先乘后加与先加后乘结果不同）。算两边：

$$
\text{左边：}(g\circ f)(x)=3(x+1)=3x+3,\quad F(g\circ f)(x)=3(3x+3)+3=9x+12
$$

$$
\text{右边：}F(g)\big(F(f)(x)\big)=g\big(g(f(f(x)))\big)=3\cdot3\cdot(x+2)=9x+18
$$

$9x+12\ne9x+18$，保复合失败，$F$ 不是函子。两点经验：其一，验公理别只盯保恒等，**保复合才是主战场**（恒等往往碰巧过）；其二，找反例要挑**不可交换**的函数族：对合（取反）与循环置换这类函数族里，两边常常碰巧相等，公理的失败被伪装起来。

## $\rm \S \, 2.5$ 公理的 CS 红利

1. **正确性**：自己写容器变换时，对照两条公理逐个验证，坏掉 `None` 分支的 `map`（保恒等失败）、不尊重嵌套顺序的变换（保复合失败）当场现形。
2. **性能**：保复合公理＝「$n$ 次 map 链可以融合成一次遍历」的免费正确性证明（§2.3.1）；
3. **词汇**：第 3 章的「函子之间的变换」、第 6 章的「单子」（自函子上的幺半群，本书用整章兑现这句黑话），全部踩在「函子」这块跳板上。

## $\rm \S \, 2.7$ 应用与辨析

1. 验证 Option 函子的两条公理（四个分支逐一核对）。
2. 判断是否为函子并说理：$F$ 把集合 $A$ 映到 $A\times A$、把 $f$ 映到 $f\times f$（逐分量作用）；再判断：把 $f\colon A\to B$ 映到「常函数 $B\to B\times B$，值为 $(b_0,b_0)$」的候选（需选定 $b_0\in B$，这条候选在「两端配套」上还剩什么问题？）。
3. 路径范畴函子里，若把一条边映到 $\mathrm{id}$，两条不同路径的像可能相同，这说明函子不保证什么？
4. 有人说：「保恒等可以由保复合推出，所以公理只要一条。」验证：把 $f=\mathrm{id}_A$ 代入保复合公理，能得到什么、不能得到什么（提示：得到的正是保恒等（对**像恒等**而言）；试试找出反例：所有态射映到 $\mathrm{id}_{F(B)}$ 的候选保复合吗？保恒等吗？）。

## $\rm \S \, 2.8$ 本章自测答案

> 先闭卷作答上面两节，再核对。

### $\rm \S \, 2.8.1$ 关键概念回顾答案

1. 对象层 $A\mapsto F(A)$ 与态射层 $f\mapsto F(f)$；配套指 $F(f)$ 的源/目标恰是 $F(A)/F(B)$，点与箭头用同一张地图搬。（§2.2）
2. $F(\mathrm{id}_A)=\mathrm{id}_{F(A)}$ 与 $F(g\circ f)=F(g)\circ F(f)$。因为范畴的全部结构就是复合表，两条公理说复合表原样搬运。（§2.2）
3. 保恒等↔`map id xs = xs`；保复合↔`map (g∘f) xs = map g (map f xs)`；红利是 map 融合（两遍变一遍）的正确性证明。（§2.3.1）
4. 保乘法与单位元：$F(ab)=F(a)F(b)$、$F(e)=e$；例 $n\mapsto2^n$ 把加法幺半群映入乘法幺半群。（§2.3.4）
5. 坏在保复合（$(g\circ f)$ 做两遍 ≠ 各做两遍再串联：$9x+12\ne9x+18$）；反例要避开对合与循环群这类可交换伪装者。（§2.4）

### $\rm \S \, 2.8.2$ 应用与辨析答案

1. `map id None = None`、`map id (Some x) = Some x`（保恒等）；`(g∘f)` 作用在 `None` 上为 `None`＝先 `map f` 再 `map g`；`Some x` 分支两边同为 `Some (g(f x))`（保复合）。（§2.3.2）
2. $f\times f$ 逐分量：保恒等（$\mathrm{id}\times\mathrm{id}=\mathrm{id}$）与保复合（$(g\circ f)\times(g\circ f)=(g\times g)\circ(f\times f)$，逐分量直验），是函子。常函数候选：对象层需要为每个 $B$ 挑定 $b_0$，这不是从 $B$ 内部结构来的（要全局选择函数，相当于额外的幂集层选择），且把不同态射全映到同一常函数后保复合退化为可验，真正的障碍是它在依赖「选定元素」这件外置信息，破坏了「映射由对象结构决定」的预期；作为函子定义仍可勉强成立（选好 $b_0(-)$ 的族），但它抹掉了全部态射信息，这是常值函子思路，不是「$f$ 的像」。（§2.2、§2.3）
3. 不保证**单射**：函子是「保结构」不是「保信息」，两条不同路径可以并成同一条像路径（如 §2.3.3 中 $e_2\circ e_1$ 与某条直接边若都映到 $d$）。区分「保持」（公理）与「反映射」（额外要求）。（§2.3.3）
4. 代 $f=\mathrm{id}_A$ 进保复合：$F(\mathrm{id}_A)=F(\mathrm{id}_A\circ\mathrm{id}_A)=F(\mathrm{id}_A)\circ F(\mathrm{id}_A)$，只推出 $F(\mathrm{id}_A)$ 幂等，推不出它等于 $\mathrm{id}_{F(A)}$。反例：把一切态射映到目标对象上的恒等（$F(f)=\mathrm{id}_{F(B)}$）保复合（两边都是 $\mathrm{id}$ 复合），但 $F(\mathrm{id}_A)=\mathrm{id}_{F(A)}$ 恰好成立。再改一版：映到某固定幂等态射（如投影）则保复合成立而保恒等失败。结论：两条公理独立，都要留。（§2.2）
