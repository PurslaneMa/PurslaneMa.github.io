# $\rm Chapter \, 4$ 重复博弈：合作的诞生

囚徒困境的均衡是互相背叛，蜈蚣博弈的均衡是立刻拿钱，可现实里合作遍地都是。上一章末尾留了线索：长链条顶不住逆向归纳，解法可能不在单局内部。本章把同一局博弈复制很多遍，看「明天还要见面」如何改变今天的算计，以及合作的理性地基究竟有多牢。

## $\rm \S \, 4.1$ 有限与无限重复、贴现因子

把一个**阶段博弈（stage game）**（比如囚徒困境）玩很多轮，每轮结束时双方可见全部历史，总支付按轮加总。**有限重复**是玩 $T$ 轮后强制散场；**无限重复**没有终点，未来的收益要打折：$t$ 轮后的 1 元只值今天的 $\delta^t$，$\delta\in(0,1)$ 是**贴现因子（discount factor）**。它有双重读法：主观上是耐心，客观上是「这关系明天还在的概率」。本章全部用贴现和 $\sum_t \delta^t u_t$ 计总账。

无限重复不是玄学：只要每轮有 $\delta$ 的概率继续、$1-\delta$ 的概率散伙，期望总账正是贴现和。$\delta$ 越接近 1，未来的分量越重，今天的动作越要顾忌明天的报复。

数字感先建立：$\delta=0.9$ 时 10 轮后的 1 元只值 $0.9^{10}\approx 0.349$ 元；$\delta=0.5$ 时只值不足一厘。本章一切结论都对 $\delta$ 敏感，末尾的表格会反复提醒这一点。计总账本章只用贴现和；机制设计文献常用的平均支付（除以 $\sum_t\delta^t$）只是换刻度，对「哪些组合是均衡」的判断与贴现和一致。

重复博弈里的「策略」也是 §3.1 说的全剧本：每个可能的历史对应一个行动；触发策略与 TFT 都是只认两三种历史的极简剧本，复杂剧本理论上有用武之地，实践里赢的常常是简单的。

## $\rm \S \, 4.2$ 触发策略与合作的条件

阶段博弈取经典配比：互相合作各得 $R=3$，单方背叛得诱惑 $T=5$、被背叛者得 $S=0$，互相背叛各得 $P=1$（满足 $T>R>P>S$）。**触发策略（trigger strategy）**：先合作；一旦对方背叛过，从此永远背叛。它把「合作」明码标价成一份永久惩罚合同。

在双方都执行触发策略的合作轨道上，每人贴现总收益是 $\dfrac{3}{1-\delta}$。单方面毁约能捞一次 $5$，之后对方永久背叛、自己只得 $1$，总账 $5+\dfrac{\delta}{1-\delta}$。合作不被背叛的条件：

$$
\frac{3}{1-\delta} \;\ge\; 5 + \frac{\delta}{1-\delta}
\quad\Longleftrightarrow\quad
3 \ge 5(1-\delta) + \delta
\quad\Longleftrightarrow\quad
\delta \ge \tfrac{1}{2}
$$

临界值 $\delta^*=\tfrac12$：未来至少要占一半权重，合作才经得起诱惑。

把配比换成一般的 ${T,R,P}$，同样的比较给出 $\tfrac{R}{1-\delta} \ge T + \tfrac{\delta P}{1-\delta}$，解出 $\delta^* = \tfrac{T-R}{T-P}$；经典配比下 $(5-3)/(5-1)=\tfrac12$，与上面一致。诱惑相对红利越大、或背叛的下场相对越轻，需要的耐心就越足。拿真实模拟核对：ALLD（永远背叛）对 TFT（以牙还牙：模仿对方上一轮的行动，首轮合作）打 100 轮，三种贴现率下的总收益（确定性模拟，无随机，复现只需同参数；Python 3.12 实测）：

```python
T, R, P, S = 5, 3, 1, 0
def duel(a, b, n, d):
    la, lb, ta = "C", "C", 0.0
    for t in range(n):
        xa = "D" if a == "ALLD" else lb
        xb = "D" if b == "ALLD" else la
        pa = T if (xa, xb) == ("D","C") else P if (xa, xb) == ("D","D") else R if xa == "C" else S
        ta += d ** t * pa
        la, lb = xa, xb
    return ta
```

| $\delta$ | ALLD 对 TFT | TFT 对 TFT | 判定 |
| --- | --- | --- | --- |
| $0.5$ | $6.0000$ | $6.0000$ | 打平，正是临界 $\delta^*=\tfrac12$ |
| $0.7$ | $7.3333$ | $10.0000$ | 背叛亏 $2.67$，合作合算 |
| $0.9$ | $13.9997$ | $29.9992$ | 背叛亏掉一半以上 |

（100 轮与无穷大的差别只剩 $\delta^{100}$ 量级的尾巴，$\delta=0.9$ 那行的 13.9997 就是 $14$ 减去它。）表里的数字也能闭式核对：ALLD 对 TFT 的总账是 $5+\sum_{t=1}^{99}\delta^t = 5+\tfrac{\delta-\delta^{100}}{1-\delta}$，TFT 对 TFT 是 $3\cdot\tfrac{1-\delta^{100}}{1-\delta}$。读表分三步：

1. 先看 $\delta=0.5$ 行：ALLD 总账与 TFT 对 TFT 打平在 $6$，正是手算的临界值，模拟与代数互相钉死；
2. 再看 $\delta$ 增大的方向：两笔总账都随 $\delta\to 1$ 无界增长，但主项差三倍（合作是 $\tfrac{3}{1-\delta}$，背叛是 $5+\tfrac{\delta}{1-\delta} = 4+\tfrac{1}{1-\delta}$），差距越拉越大；
3. 最后看 TFT 那半边：被剥削一次的代价是首轮 $S=0$ 加随后的互相背叛 $1$。TFT 自己亏，但它没有更好的选择：宽容度怎么定有权衡（§4.3）。

读法：$\delta$ 越大，背叛的一次性甜头越压不过失去未来的损失；ALLD 欺负 TFT 只能薅到第一轮的 $5$，之后自己也被拖进互相背叛的 $1$，损人不利己的部分由 TFT 的可激怒性补齐。

顺带分清两个问题：「什么组合是均衡」与「哪种策略在循环赛里得分高」。TFT 对 ALLD 就不是均衡组合：面对 TFT，背叛者改合作反而多拿（$\delta=0.7$ 时 $10$ 对 $7.33$），这对组合互不锁定；§4.2 的均衡是双方都执行触发策略。均衡分析回答稳定性，循环赛回答流行度，两件事别混。

## $\rm \S \, 4.3$ 以牙还牙与 Axelrod 竞赛

触发策略凶悍但僵硬：一次误会就永久开战。更人性的版本是**以牙还牙（tit-for-tat, TFT）**：只惩罚一轮，对方回头自己立刻回头。Axelrod 在 1980 年办了两届程序循环赛：各路博弈论学者提交策略程序两两互赛，第一届收到 14 份提交、第二届 62 份，冠军都是最短的 TFT，总共四行代码。它对善良策略几乎拿满合作红利，对算计者靠可激怒性止亏。

归纳 TFT 的特质：善良（先合作）、可激怒（立刻惩罚）、宽容（惩罚一轮就翻篇）、清晰（行为好预测，让对手算得清挑衅的下场）。后续研究补了边界：在动作有噪声的环境里 TFT 会因误判互相空转，更稳的变体（赢留输改）接管了这一场景。竞赛给的意义不在「TFT 万能」，而在一个事实：合作不需要中央设计，几个朴素性质就足以在一群自私策略中胜出。

Axelrod 把赛后分析写成《合作的进化》（1984）：四特质从此成为合作理论的入门词汇，「重复互动孕育合作」也由格言变成了可以算的命题。

## $\rm \S \, 4.4$ 无名氏定理与倒推崩溃

前两节都在算一份具体的惩罚合同，现在把镜头拉远：这种合同到底能撑起多大的合作空间？**无名氏定理（folk theorem）**：只要 $\delta$ 足够大，无限重复博弈可以支撑起一大片均衡收益：任何「可行且高于每人背叛底线」的收益向量，都能被某个触发式策略组合维持在均衡上。直觉是 §4.2 的推广：永久背叛的惩罚合同是万能威慑，合同里写多高的合作收益都执行得下去。定理的名字是诚实的：早在被形式化之前，折磨博弈论者的民间智慧已经知道它。它同时是一记警钟：均衡多到理论挑不出唯一答案，预言合作何时出现，得看合同写在收益集合的哪一格。

拿 §4.2 的配比看这片集合：阶段博弈的背叛底线是互相背叛的 $1$，折成总账 $\tfrac{1}{1-\delta}$；可行收益从合作红利 $\tfrac{3}{1-\delta}$ 到不对称合同下的极端分配都在框里，$\delta$ 够大时框内高于底线的每一格都有合同托底。均衡多，不是理论失效，是「合作有很多种分法」这件事第一次有了形式语言。

有限重复走相反的路：最后一条永合作不了，逆向归纳从尾巴倒推，囚徒困境的有限重复唯一均衡是轮轮背叛。连锁店悖论（Selten, 1978）把这记闷棍敲在更疼的地方：连锁店面对一串进入者，归纳说每一仗都该退让，现实里连锁店常常开战；实验里人类在有限重复囚徒困境中合作到接近尾声才散伙。

理论缺口至今没有公认答案，流行的修补是给「最后一轮」注入轻微不确定性：玩家不完全确信 $\delta<1$ 或对手的类型，倒推链在数学上依然自洽，在实践上失去着力点（Kreps、Milgrom、Roberts 与 Wilson 的声誉模型是这条线的严格版）。

民间合作靠的就是这两股力量：**未来的影子**（$\delta$ 的现实对应：熟人还要见面，陌生人之间 $\delta\approx 0$，所以陌生人社会靠制度补）与**声誉**（历史可见，一次背叛被所有未来对手看见，惩罚从单人触发升级成全网触发；计算经济学册 §1 末尾的机制视角在此落地）。平台评分系统是这两股力量的工程化：差评是全网可见的触发记录，账号长期有效抬高了 $\delta$。合作不是道德，是 $\delta$ 与可观测性的算术。

## $\rm \S \, 4.7$ 本章自测答案

> 先闭卷作答 §4.5 与 §4.6，再核对。

### $\rm \S \, 4.7.1$ 关键概念回顾答案

1. 耐心：主观贴现率；存续概率：每轮以 $\delta$ 概率继续时期望总账恰为贴现和。（§4.1）
2. 永久合作的总账 $\tfrac{3}{1-\delta}$ 对 背叛一次的总账 $5+\tfrac{\delta}{1-\delta}$；解出 $\delta\ge\tfrac12$。（§4.2）
3. $\delta=\tfrac12$ 时两笔总账相等，正是手算的临界值，理论与模拟互相钉死。ALLD 只薅到首轮 $5$，之后永久 $1$；对方 TFT 更惨（首轮 $0$），但 ALLD 自己也没占到长期便宜。（§4.2）
4. 惩罚有限、宽容、可恢复合作；噪声下误判会连锁反弹，需要更稳的变体。（§4.3）
5. 可行且高于背叛底线的收益向量（$\delta$ 足够大时）；警钟：均衡多到不唯一，理论不能预言具体落在哪个。（§4.4）
6. 同一台：逆向归纳从最后一轮倒推。实验反着走：人类合作到接近尾声，连锁店也常开战。（§4.4）

### $\rm \S \, 4.7.2$ 应用与辨析答案

1. 条件 $\tfrac{3}{1-\delta} \ge 4 + \tfrac{\delta}{1-\delta}$，即 $3 \ge 4-3\delta$，$\delta\ge\tfrac13$。诱惑越小，合作越便宜。（§4.2）
2. 「对 ALLD」是挑错对手：TFT 的价值在对付可合作的对手（对 TFT 得 $10$ 分，$\delta=0.7$）。ALLD 自己也亏：它若同样走合作轨道可得 $10$，背叛只换来 $7.33$，损人先损己。（§4.2）
3. 刷好评伪造的是声誉（可观测历史失真）；代练卖号破坏的是未来的影子（账号与「下次见面」脱钩，$\delta$ 被人为压低）。两者都是把 §4.4 的算术拆掉一角。（§4.4）
4. 关系破裂概率 $0.1$ 等价于有效贴现 $\delta' = 0.9\,\delta$，条件变为 $0.9\delta\ge\tfrac12$，即 $\delta\ge\tfrac59\approx 0.556$。名义耐心要打九折再过门槛。（§4.1、§4.2）
5. 几乎不动：各格只在末位多个 $\delta^{200}$ 量级的尾巴，比 $\delta^{100}$ 更小。有限轮数是无穷的数值近似，结论由 $\tfrac{1}{1-\delta}$ 的主项决定，这正是选 100 轮就够的原因。（§4.2）
