## $\rm \S \, 3.1$ 问题：正则数不了配对，文法来补

判 ${\{0^n1^n\}}$ 时，读到 1 必须知道「还欠多少个 0」。有穷状态存不下这个数（§2.3 已证等价类无穷），而配对恰恰有天然的次序结构：**最后欠下的最先还清**——这正是栈。给机器加栈之前，先从生成侧定义这类语言。**上下文无关文法**是四元组 ${G=(V,\Sigma,R,S)}$：变量集 $V$、终结符字母表 $\Sigma$、规则集 $R$（每条形如「变量 $\to$ 符号串」）、开始符号 ${S\in V}$。规则可以引用变量自身——递归是文法的引擎。

最小例：规则

```text
S -> 0 S 1 | ε
```

生成语言 ${\{0^n1^n:n\ge0\}}$：要 $n$ 层就展开 $n$ 次 `S -> 0S1`，最后用 `S -> ε` 收口。从 $S$ 出发反复把某个变量替换成其规则右部的过程叫**推导（derivation）**，写作 $S\Rightarrow0S1\Rightarrow00S11\Rightarrow00S1\;1\Rightarrow0011$（最后一步用了 $\varepsilon$）；每一步总替换**最左**变量的推导叫**最左推导（leftmost derivation）**。配对括号是同构的另一例：

```text
S -> ( S ) | S S | ε
```

串 `()(())` 可由此文法生成——生成侧一眼可见「嵌套」。

**本节小结**：本节把「配对」写成文法——变量递归引用自身，展开多少层就配多少对；下一个问题是怎么把「同一个串多种生成方式」这种隐患显式化。

## $\rm \S \, 3.2$ 推导树与歧义

推导过程画成树就是**推导树（derivation tree）**：变量是内部节点，其子节点按序是某次替换的右部；叶子从左到右拼出整串。一个串可能有多棵推导树——称该文法**歧义（ambiguous）**。经典翻车现场是表达式文法：

```text
E -> E + E | E * E | id
```

对串 `id+id*id` 手推两棵树（左树先按 `+` 分解，右树先按 `*` 分解）：

```text
树一: E -> E+E, 右子再展开 E*E        树二: E -> E*E, 左子再展开 E+E
          E                                     E
        / | \                                 / | \
       E  +  E                               E  *  E
       |    /|\                             /|\    |
      id   E * E                           E + E   id
           |   |                           |   |   |
           id  id                         id  id  id
读作 id+(id*id)                       读作 (id+id)*id
```

代入 `id`${=1,2,3}$：树一算出 $1+2\times3=7$，树二算出 $(1+2)\times3=9$。同一句话两种值，歧义不是审美问题而是正确性问题。消歧的标准手段是**分层文法**：

```text
E -> E + T | T          （表达式由若干项相加）
T -> T * F | F          （项由若干因子相乘）
F -> ( E ) | id         （因子是括号或原子）
```

每层只管一个优先级，`id+id*id` 的推导树唯一：`+` 在树根、`*` 在它右子树里。优先级与结合性不是求值代码里的魔法，而是文法分层方式——这是 §3.5 递归下降的地基。

**本节小结**：本节给推导画了树、给歧义验了尸：同一串两棵树就是两种求值；分层文法按优先级切层，树就唯一了。

## $\rm \S \, 3.3$ 下推自动机

### $\rm \S \, 3.3.1$ 定义与读法

**下推自动机**＝有穷自动机＋一条栈。转移读「当前状态、输入符号、栈顶」，做「压入／弹出／不动」并转到新状态；栈顶永远只看得见最后压入的符号。接受条件：读完输入且栈空（本书采用的约定）。非确定型 PDA（同一局面多种走法，任一路径接受即可）与 CFG 等价，且**比**确定型 PDA 更强——这与 DFA/NFA 能力相同形成对照；本册只用确定性场景。

### $\rm \S \, 3.3.2$ 一台判 ${0^n1^n}$ 的 PDA

只凭一步巧劲：读 0 压栈、读 1 弹栈。两个工作相位：相位 0（读 0 阶段）见 0 压 `X`，见 1 转相位 1；相位 1 见 1 弹 `X`，见 0 或栈已空再遇 1 则拒绝（无转移）。脚本模拟：

| 输入 | 判定 | 细节 |
| --- | --- | --- |
| ``（空） | 接受 | $n=0$，栈空 |
| `01` | 接受 | 压一个弹一个 |
| `0011` | 接受 | 轨迹见下 |
| `0101` | 拒绝 | 第 3 个字符是 0，相位 1 见 0 无转移 |
| `001` | 拒绝 | 读完后栈里剩一个 `X`（0 多） |
| `00111` | 拒绝 | 第 5 个字符是 1 时栈已空（1 多） |

`0011` 的完整轨迹：压得 `X`，压得 `XX`，弹出得 `X`，弹出得空——栈高先升后降、恰好归零。把 0 换成 `(`、1 换成 `)`，这台机器就是编译器里的括号检查器：配对即「压弹相抵、终点栈空」。

### $\rm \S \, 3.3.3$ CFG 与 PDA 等价

白话：这说的是「会写与会认是同一件事」——凡是用规则能生成出来的语言，恰好就是带着栈的机器能认的语言，两侧谁也不多谁也不少。

**定理**：语言 $L$ 可由 CFG 生成，当且仅当 $L$ 可由某台（非确定型）PDA 识别。方向直觉各一句：文法到自动机——把推导倒着看，非确定地猜「下一步展开哪条规则」，用栈存放待展开的部分；自动机到文法——把栈动作译成产生式，变量记「从状态 $p$ 弹净到状态 $q$ 能读出的串」。两个构造都不在本册展开，记住等价本身：生成侧（文法）与识别侧（机器）说的是同一类语言，之后按方便选用。

**本节小结**：本节从定义走到实例再到等价：PDA 用「压弹相抵」判配对，CFG 与 PDA 不过是同一类语言的两面。

## $\rm \S \, 3.4$ CFL 的边界

栈把 ${0^n1^n}$ 收进囊中，但栈自己也有天花板。**CFL 泵引理**：$L$ 是 CFL，则存在 $p$，任何 ${w\in L}$、${\lvert w\rvert\ge p}$ 可写成 $w=uvxyz$，满足 ${\lvert vxy\rvert\le p}$、${\lvert vy\rvert\ge1}$，且对一切 $i\ge0$，${uv^ixy^iz\in L}$。应用：${\{0^n1^n2^n\}}$ 不是 CFL。取 $w=0^p1^p2^p$；${\lvert vxy\rvert\le p}$ 迫使 $v$ 与 $y$ 合起来至多触及两种符号（三段各长 $p$，窗口 $p$ 装不下三种），泵动 $i$ 后至多两种符号的个数变化、至少一种不动（${v,y}$ 触不到它），三种个数无法保持相等——出 $L$。结论顺带成立：**任何 PDA 都判不了 ${0^n1^n2^n}$**，这不是技巧问题。

包含关系是一条严格链：正则语言 ⊊ CFL。左半：${0^n1^n}$ 是 CFL（§3.1 文法）却非正则（§2.2、§2.3）。闭性对比（对照第 2 章「正则对五运算全封闭」）：

| 运算 | 正则语言 | CFL |
| --- | --- | --- |
| 并 | 封闭 | 封闭 |
| 连接、星 | 封闭 | 封闭 |
| 补 | 封闭 | **不**封闭 |
| 交 | 封闭 | **不**封闭 |
| 与正则语言交 | 封闭 | 封闭 |

交不封闭的直接例证：${\{a^ib^jc^k:i=j\}}$ 与 ${\{a^ib^jc^k:j=k\}}$ 都是 CFL（各是一段配对拼上一段自由计数），其交恰为 ${\{a^nb^nc^n\}}$——刚被泵引理逐出 CFL。补不封闭由它反推：CFL 对并封闭，若再对补封闭，德摩根律将给出对交封闭，矛盾。最后一条「与正则语言交仍封闭」是实用工具：PDA 与 DFA 并行模拟、栈原样保留即可，于是可以用正则约束从 CFL 里筛子语言（第 7 章的 MSO 路线会反复用这种「机器组合」手法）。

**本节小结**：本节量出栈的天花板——CFL 泵引理把 ${0^n1^n2^n}$ 拒之门外，闭性表露出补与交两个破洞；机器的下一步升级因此有了明确方向。

## $\rm \S \, 3.5$ 竞赛／工程连接：递归下降解析

CFG 的最左推导可以直接翻译成递归函数：每个变量一个函数，按规则右部顺序消费输入。分层文法（§3.2）变成三层函数，四则运算（`+`、`*`、括号、正整数）的最小版：

```python
def calc(s):                     # 文法: E -> E+T | T ;  T -> T*F | F ;  F -> 数字 | (E)
    pos = 0
    def peek(): return s[pos] if pos < len(s) else ''
    def expr():                  # 对应变量 E：管 +
        nonlocal pos
        v = term()
        while peek() == '+':
            pos += 1; v += term()
        return v
    def term():                  # 对应变量 T：管 *
        nonlocal pos
        v = factor()
        while peek() == '*':
            pos += 1; v *= factor()
        return v
    def factor():                # 对应变量 F：数字或括号
        nonlocal pos
        if peek() == '(':
            pos += 1; v = expr()
            assert peek() == ')'; pos += 1
            return v
        v = 0
        while peek().isdigit():
            v = 10*v + int(peek()); pos += 1
        return v
    r = expr()
    assert pos == len(s)         # 整个串必须恰好被消费
    return r

print(calc('2+3*4'))     # 14
print(calc('(1+2)*3'))   # 9
print(calc('1+2+3*4+5')) # 20
```

把它存成 `calc.py` 后运行 `python calc.py`（任意装有 Python 的终端，无第三方依赖），三行输出与手算一致：`14`、`9`、`20`。读法对照：`expr` 调 `term` 就是 ${E\to E+T}$ 的最左推导，`while` 循环吃掉同一层余下的 `+`（左结合）；`factor` 里遇括号递回 `expr` 就是 $F\to(E)$——调用栈在替 PDA 的显式栈干活。优先级与括号的处理不靠特判，全部来自 §3.2 的文法分层；这套「文法即代码」的写法叫**递归下降解析（recursive descent parsing）**，是几乎所有手写解析器（含编译器前端）的骨架。

**本节小结**：本节把文法逐行翻译成递归函数——每个变量一个函数、调用栈顶替显式栈；§3.2 的分层文法在这里直接变成代码里的优先级结构。

## $\rm \S \, 3.8$ 本章自测答案

> 先闭卷作答上面两节，再核对。

### $\rm \S \, 3.8.1$ 关键概念回顾答案

1. ${G=(V,\Sigma,R,S)}$：变量集、终结符集、规则集、开始符号。括号文法 `S -> (S) | SS | ε`；一步推导：$S\Rightarrow(S)$。（§3.1）
2. 歧义＝存在某串有两棵不同推导树，求值会分裂（7 对 9）。分层文法让每层只负责一个优先级，`+` 必在根、`*` 必在其子层，树唯一。（§3.2）
3. 多一条后进先出的栈。相位 0 每读一个 0 压一个 `X`，相位 1 每读一个 1 弹一个，读毕栈空当且仅当两个计数相等——配对关系由栈的压弹次序天然保证。（§3.3.2）
4. CFL 版多一个 $y$、条件改为 ${\lvert vxy\rvert\le p}$、${\lvert vy\rvert\ge1}$（窗口盖住泵动部分）。关键一步：${\lvert vxy\rvert\le p}$ 使 ${v,y}$ 至多触及两种符号，泵动无法让三个计数同步。（§3.4）
5. 对补与交不封闭（例：两个 CFL 交出 ${0^n1^n2^n}$）；对并、连接、星、与正则交封闭。「交正则」让 PDA 与 DFA 并行模拟即可筛子语言，是给语言加约束而不破坏可识别性的标准手法。（§3.4）

### $\rm \S \, 3.8.2$ 应用与辨析答案

1. 错在机器能力层：§3.4 已证 ${0^n1^n2^n}$ 根本不是 CFL，任何 PDA（加一个计数器仍是 PDA 的变体——两个计数会互相盖住）都判不了；这不是实现技巧不足，而是「栈式存储」这一层的天花板，得换机器（第 4 章）。（§3.4）
2. 后一文法中每对括号由唯一一次 `S -> (S)S` 规则生成：外层括号唯一确定，剩余部分劈成「内层」与「右侧」也唯一，递归下去每棵推导树由串结构唯一决定；前一文法的 `S -> SS` 让劈分点可自由选择，产生歧义。（§3.2）
3. 对应 PDA 的栈：每个未返回的函数调用是一个待完成的展开目标，恰如栈中待处理的变量。非递归写法：自己维护一个符号栈，遇变量弹出并压入所选规则右部（逆序压）——这就是「文法到 PDA」构造的单机版。（§3.3.3、§3.5）

---

PDA 判 ${0^n1^n}$ 靠的是一步巧劲：0 的计数沉在栈底、1 的计数浮在栈顶，天然配成一对。${0^n1^n2^n}$ 要同时看住两个独立计数、且都要回头核对，栈一次只看得见栈顶，装不下（§3.4 已从语言层面判了死刑）。缺的是一种既能读也能写、不受后进先出约束、还要多长有多长的存储——把「存储」彻底放开，就得到全册主角：图灵机。
