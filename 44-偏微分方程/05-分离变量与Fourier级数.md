# $\rm Chapter \, 5$ 分离变量与 Fourier 级数

## $\rm \S \, 5.1$ 分离变量的机制

以带 Dirichlet 边界的杆上热方程为例：$u_t = u_{xx}$、$u(0, t) = u(L, t) = 0$、$u(x, 0) = f(x)$。猜解 $u(x, t) = X(x) T(t)$（时间和空间「各管各」）。代入：

$$
X T' = X'' T \implies \frac{T'}{T} = \frac{X''}{X} = -\lambda
$$

左边只含 $t$、右边只含 $x$，两边相等 ⟹ 两边都是同一个常数 $-\lambda$（**变量分离常数**）。于是：

1. 时间 ODE：$T' = -\lambda T \Rightarrow T = \mathrm{e}^{-\lambda t}$；
2. 空间 ODE：$X'' + \lambda X = 0$ 配边界 $X(0) = X(L) = 0$。

**读法**：一个 PDE 被拆成「一个一阶 ODE ＋ 一个特征值问题」——白话：把「时空合演」拆成「空间定形状、时间管伸缩」。

## $\rm \S \, 5.2$ 特征值问题与模

空间问题 $X'' + \lambda X = 0$、$X(0) = X(L) = 0$ 只有特定 $\lambda$ 才有非零解：$\lambda_n = (n\pi / L)^2$、$X_n = \sin(n\pi x / L)$，$n = 1, 2, \ldots$（$A\sin + B\cos$ 的一般解代边界：$B = 0$、$\sin(\sqrt\lambda L) = 0$）。每个 $(\lambda_n, X_n)$ 是一个**特征模**：

$$
u_n(x, t) = \mathrm{e}^{-\kappa \lambda_n t} \sin \frac{n\pi x}{L}
$$

**读法**：模是杆的「固有驻波」，衰减率 $\kappa \lambda_n \propto n^2$——**频率越高死得越快**（第 2 章 §2.5「高频先死」的定量版）。波动方程同款流程给 $u_{tt} = c^2 u_{xx}$ 的模 $u_n = \cos(c\sqrt{\lambda_n} t)\sin(\sqrt{\lambda_n} x)$——不衰减、只振荡（§3.3 对照表的又一格）。

## $\rm \S \, 5.3$ Fourier 拼装（本章主证）

一般初值 $f(x)$：按第 7 章展开 $f = \sum_n b_n \sin(n\pi x / L)$（系数 $b_n = \frac{2}{L}\int_0^L f \sin$），叠加（§1.3 许可证）：

$$
u(x, t) = \sum_{n=1}^{\infty} b_n\, \mathrm{e}^{-\kappa (n\pi/L)^2 t} \sin \frac{n\pi x}{L}
$$

**验证清单**（每条一句）：1. 逐项满足方程与边界（线性＋各模已验）；2. 初值：$t = 0$ 级数收敛到 $f$（Fourier 收敛定理）；3. 逐项求导合法性：$t > 0$ 时 $\mathrm{e}^{-\kappa \lambda_n t}$ 以 $e^{-c n^2}$ 级压住一切导数——**级数在 $t > 0$ 内绝对一致收敛且可任意次求导**（这就是「热方程瞬间无穷光滑」，§2.3 的级数版证据）。

**白话**：任意初始温度图样被拆成一把音叉（各频率驻波），每支音叉按自己的指数衰减率慢慢哑掉——高音先哑，最后只剩最低音（稳态）。

**完整例题**：初值 $f(x) = x$（锯齿）、区间 $[0, \pi]$、两端零温（Dirichlet）、$\kappa = 1$。系数全算：$b_n = \frac{2}{\pi}\int_0^\pi x\sin(nx)\,\mathrm{d}x$。分部积分取 $u = x$、$\mathrm{d}v = \sin(nx)\,\mathrm{d}x$（$\mathrm{d}u = \mathrm{d}x$、$v = -\frac{\cos(nx)}{n}$）：

$$
\int_0^\pi x\sin(nx)\,\mathrm{d}x = \Big[ -\frac{x\cos(nx)}{n} \Big]_0^\pi + \frac{1}{n}\int_0^\pi \cos(nx)\,\mathrm{d}x
$$

边界项在 $x = \pi$ 处给 $-\frac{\pi\cos(n\pi)}{n} = -\frac{\pi(-1)^n}{n}$、$x = 0$ 处为零；积分项 $\int_0^\pi \cos(nx)\,\mathrm{d}x = \frac{\sin(n\pi)}{n} = 0$。所以

$$
b_n = \frac{2}{\pi}\cdot\frac{\pi(-1)^{n+1}}{n} = \frac{2(-1)^{n+1}}{n}, \qquad u(x, t) = \sum_{n=1}^{\infty} \frac{2(-1)^{n+1}}{n}\, \mathrm{e}^{-n^2 t}\sin(nx)
$$

（$L = \pi$ 时 $\lambda_n = (n\pi/L)^2 = n^2$。）前三个系数 $b_1 = 2$、$b_2 = -1$、$b_3 = \frac{2}{3}$。**数值表**（前 3 项和 $S_3$ 与 30 项和 $S_{30}$ 对照，本机实跑）：

| --- | --- | --- | --- | --- |
| $0.1$ | $\pi/6$ | $0.523599$ | $+0.595370$ | $+0.523599$ |
| $0.1$ | $\pi/3$ | $1.047198$ | $+0.986710$ | $+1.047189$ |
| $0.1$ | $\pi/2$ | $1.570796$ | $+1.538628$ | $+1.569401$ |
| $0.1$ | $2\pi/3$ | $2.094395$ | $+2.147739$ | $+2.034073$ |
| $1$ | $\pi/6$ | $0.523599$ | $+0.352100$ | $+0.352100$ |

## $\rm \S \, 5.4$ 四类边界条件速查

同一流水线在别的边界条件下只有特征值表变化：

1. **两端 Dirichlet**：$\lambda_n = (n\pi/L)^2$，模 $\sin(n\pi x/L)$（§5.2）。
2. **两端 Neumann**（绝热）：$\lambda_n = (n\pi/L)^2$、$n = 0, 1, \ldots$，模 $\cos(n\pi x/L)$——多出零模 $\lambda_0 = 0$（常数解）：绝热杆的总热量守恒，长期归宿是「平均温度的常函数」。
3. **混合**（一端 Dirichlet 一端 Neumann）：$\lambda_n = ((n + \frac12)\pi / L)^2$，模 $\sin((n+\frac12)\pi x / L)$——半整数频率。
4. **周期边界**：$\lambda_n = (2\pi n / L)^2$，模 $\cos + \sin$ 成对——Fourier 级数的原装场景。

**读法**：边界条件决定的是「哪些频率被允许存在」——特征值表就是边界与波长的共振账。数值方法的稳定性分析（第 6 章 von Neumann）用的正是周期情形。

**三类边界的完整对照实验**（同一初值 $f(x) = x(1 - x)$、$L = 1$、$\kappa = 1$；系数用数值积分实算、$u(0.5, t)$ 取 60 项截断，本机实跑）。混合边界取一端零温一端绝热，模 $\sin(\mu_n x)$、$\mu_n = (n + \frac{1}{2})\pi$（$n = 0, 1, \ldots$）：

| 边界 | 前 3 个非零系数 | $\lambda_1$ | $u(0.5,\ 0.1)$ | $u(0.5,\ 1)$ | 长期归宿 |
| --- | --- | --- | --- | --- | --- |
| 两端 Dirichlet | $b_1 = 0.258012$、$b_3 = 0.009556$（$b_2 = 0$） | $\pi^2 = 9.87$ | $0.096162$ | $0.000013$ | $0$ |
| 两端 Neumann | $a_0 = 0.333333$、$a_2 = -0.101321$、$a_4 = -0.025330$（$a_1 = 0$） | $\pi^2$（首个非零模） | $0.168622$ | $0.166667$ | $\frac{a_0}{2} = \frac{1}{6}$ |
| 混合 | $c_0 = 0.221480$、$c_1 = 0.128287$、$c_2 = -0.024166$ | $(\pi/2)^2 = 2.47$ | $0.132247$ | $0.013281$ | $0$（最慢） |

三笔读数：1. **Neumann 不归零**——绝热杆热量无处可漏，长期冻结在平均温度 $\frac{1}{6}$（恰是初值的平均，$u(0.5, 1)$ 六位小数已站上 $0.166667$）；2. **混合边界衰减最慢**——基频 $(\pi/2)^2$ 只有 Dirichlet 的四分之一，$t = 1$ 时还剩 $0.013$ 没死透，$\mathrm{e}^{-\pi^2 t/4}$ 对 $\mathrm{e}^{-\pi^2 t}$ 的四倍差距全程在场；3. **Dirichlet 的偶数模全零**不是巧合：$f(x) = x(1-x)$ 关于中点 $x = \frac{1}{2}$ 对称，而偶数模 $\sin(2k\pi x)$ 关于中点反对称，积分为零——初值的对称性替你省了一半系数。三条演化同源同初值，唯一的差别是特征值表：口诀「边界条件决定哪些频率存活」到此有了实测账本。

## $\rm \S \, 5.5$ 与前三章的会师

1. **热方程卷积解**（§2.2）与级数解（§5.3）是同一解的两种写法：卷积核展开成模即得级数（有限区间上 Fourier 级数替代 Fourier 积分）。
2. **波动方程 d'Alembert**（§3.2）与级数解等价：$\sin(x \pm t)$ 的和差化积正是两条行波——三角恒等式把两种形态焊死。
3. **Laplace 圆盘解**（§4.5）就是「时间维度消失」的分离变量：$r^n$ 扮演了 $\mathrm{e}^{-\kappa\lambda t}$ 的压扁角色。

**读法**：分离变量不是一种技巧，是线性 PDE 的**通用语法**——原型方程的每个显式解都是它的某个化身。

**逐项求导合法性的定量演示**。§5.3 验证清单第 3 条说「$t > 0$ 可任意次求导」，这里把账摊开。用 §5.3 的锯齿级数（$\kappa = 1$）在 $x = \pi/3$ 处逐项列队：$u_{xx}$ 的第 $n$ 项是 $u$ 的第 $n$ 项乘 $-n^2$，所以二阶导数项 $= n^2 \times$ 原项。下表列项的绝对值（本机实跑；$x = \pi/3$ 处 $n$ 为 3 的倍数时 $\sin(n\pi/3) = 0$，整行归零）：

## $\rm \S \, 5.6$ 数值实验

杆长 $L = 1$、初值 $f(x) = x(1 - x)$（抛物线）：系数可手算 $b_n = \frac{4}{(n\pi)^3}(1 - (-1)^n)$（只有奇数模）。截断 $N = 20$、时刻 $t = 0.001, 0.01, 0.1$ 画剖面（纯 Python 30 行内）：$t = 0.001$ 已现光滑抛物拱的衰减版、$t = 0.1$ 只剩 $n = 1$ 模的半幅正弦拱（$b_1 \mathrm{e}^{-\kappa\pi^2 t} \approx$ 主导）——「高音先哑」的全过程可逐点对账。

**接口**：本章的模语言是全册的通用货币。向后——第 6 章的 von Neumann 稳定性分析（§6.3）就是把数值误差按本节的**周期模**展开、逐模追踪放大因子 $g(\theta)$：分离变量在那里变成审问数值格式的显微镜；§5.4 第 4 类边界（周期）正是它的载玻片。回望——§5.3 的 $\mathrm{e}^{-\kappa\lambda_n t}$ 与第 4 章 §4.5 的 $r^n$ 是同一个「高阶模压扁器」的抛物与椭圆两副面孔。

## $\rm \S \, 5.7$ 关键概念回顾

1. 分离常数 $-\lambda$ 为什么「必须是常数」？（§5.1）
2. 特征值问题 $\lambda_n = (n\pi/L)^2$ 怎么从边界条件里逼出来？（§5.2）
3. 模的衰减率与频率的什么关系？谁先死？（§5.2）
4. 级数解在 $t > 0$ 可任意求导的靠山？（§5.3）
5. Neumann 边界多出的零模对应什么物理？（§5.4）
6. d'Alembert 与级数解怎么焊死？（§5.5）
7. 重推 §5.3 例题：分部积分后边界项与积分项各剩什么？为什么 $x = \pi/2$ 处所有偶数模不贡献？（§5.3）
8. $f(x) = x(1 - x)$ 在绝热杆（Neumann）上的长期归宿是 $\frac{1}{6}$ 而不是 $0$——从哪个系数直接读出？物理上为什么必须如此？（§5.4）

## $\rm \S \, 5.8$ 本章自测答案

1. 左边只含 $t$、右边只含 $x$，恒等 ⟹ 都是常数（变量的函数等于另一变量的函数，只能是常数）。（§5.1）
2. 一般解代 $X(0) = X(L) = 0$：$B = 0$、$\sin(\sqrt\lambda L) = 0$ ⟹ $\sqrt\lambda L = n\pi$。（§5.2）
3. $\kappa \lambda_n \propto n^2$；高频先死。（§5.2）
4. $\mathrm{e}^{-\kappa\lambda_n t}$ 的 $e^{-cn^2}$ 级压制——绝对一致收敛。（§5.3）
5. 零模＝常数解＝守恒的平均温度（绝热不漏热）。（§5.4）
6. 三角和差化积把模叠加化成 $f(x \pm t)$ 行波。（§5.5）
7. 边界项剩 $-\frac{\pi(-1)^n}{n}$、积分项剩 $\frac{1}{n}\int_0^\pi \cos(nx)\,\mathrm{d}x = 0$，故 $b_n = \frac{2(-1)^{n+1}}{n}$。$x = \pi/2$ 处 $\sin(n\pi/2)$ 在偶数 $n$ 时为零——等价地说，$\sin({2k}x)$ 关于中点 $x = \pi/2$ 反对称（$\sin({2k}(\pi - x)) = -\sin({2k}x)$），该点天然是偶模的节。（§5.3）
8. 从 $a_0 = 2\int_0^1 x(1 - x)\,\mathrm{d}x = \frac{1}{3}$ 直接读出：长期归宿 $= \frac{a_0}{2} = \frac{1}{6}$，恰是初值的平均温度。物理上绝热杆总热量守恒、无处可漏，零模（常数解）不衰减，最后全场冻结在这个平均值上——Dirichlet 情形热量从零温端漏光才归零。（§5.4）
9. 绝热端要求 $\frac{\partial}{\partial x}\sin(\mu x)\big|_{x=1} = \mu\cos(\mu) = 0$，故 $\mu = (n + \frac{1}{2})\pi$；零温端要求 $\sin(\mu) = 0$，最短允许半波是 $\mu = \pi$。混合边界最短只装得下四分之一周期（$\mu_0 = \pi/2$），$\lambda_1 = (\pi/2)^2 = \pi^2/4$——边界松一端，基频矮四倍，衰减 $\mathrm{e}^{-\lambda_1 t}$ 随之慢四倍（§5.4 实验里 $t = 1$ 残留 $0.013$ 就是它）。（§5.4）
