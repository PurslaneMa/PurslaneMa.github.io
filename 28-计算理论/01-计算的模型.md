# $\rm Chapter \, 1$ 计算的模型：从 OJ 机器到图灵机

形式语言册在 fa2 阶段（§4–§5）讲过图灵机与停机问题：你知道它长什么样，也知道停机问题没有判定器。本章重走这段路，目的换了：把「计算」和「计算的代价」钉死到能证明定理的程度。第 3 章要定义复杂度类 $\mathrm{P}$ 与 $\mathrm{NP}$，而它们的全部结论都押在一句话上：换一台「合理」的机器，哪些问题能在多项式时间内解决，答案不变。这句话凭什么成立，是本章的主线。

> **开始前自检**：本章假设你已经会：
>
> 1. □ 说出图灵机的三件套：纸带、读写头、有穷状态，以及「格局」这个词（形式语言册 §4.2）；
> 2. □ 知道停机问题不可判定，对角化的套路是「假设判定器存在，构造一个自打脸的程序」（形式语言册 §5.2）；
> 3. □ 在 OJ 上交过题，对「$2^{20}$ 能跑、$2^{40}$ 跑不动」有手感（形式语言册 §9.2）；
> 4. □ 知道程序在内存里就是一段字节，既能被执行也能被当数据读写（计算机速通 §11）。

## $\rm \S \, 1.1$ 两台机器：评测机与纸带机

你在 OJ 上交的代码，跑在一台**随机访问机（Random Access Machine，RAM）**上：内存是一排编了号的字（word），第 3 章里说「$\mathrm{P}$ 是复杂度类」时假设的机器就是它。RAM 有两条对竞赛生来说天经地义的设定：

1. **随机访问**：读 `a[1000000]` 与读 `a[1]` 同样是一步，与下标大小无关；
2. **字运算 $O(1)$**：一次加法、一次比较、一次按位与，无论操作数多大都算一步（只要装得进一个字）。

图灵机（Turing machine）是另一副样子：一条无限长的纸带，一格一个符号；一个读写头，每步只能看当前格、改当前格、左移或右移一格；外加一个有穷状态寄存器。没有随机访问：想知道第 1000 格写了什么，头得真走过去。纸带、头、状态三件套在形式语言册 §4.2 有正式定义，本章直接用。

| | RAM（评测机） | 图灵机（纸带机） |
| --- | --- | --- |
| 内存 | 按字编号，随机访问 | 纸带顺序排列，只能逐格挪 |
| 一步的代价 | 读写下标、算术、跳转都是 $O(1)$ | 移一格是一步，够不着的地方要走过去 |
| 存程序 | 程序在内存里，也是数据 | 本章先让程序「住在」状态里，§1.4 再搬上纸带 |

两台机器的差距看着悬殊。结论先给出：它们的差距只有多项式量级，而复杂度类恰好对多项式量级的差异免疫。

## $\rm \S \, 1.2$ 手算一台图灵机：二进制加 1

先拿一个能整个算完的小例子，把「图灵机跑一步」的手感建立起来。任务：读入一个二进制串，末尾追加式地加 1。三个工作状态加一个停机状态就够：

1. $\mathrm{q_0}$（右扫描）：读到 0 或 1 就原样抄写、右移；读到空白说明到了串尾，左转一格进入 $\mathrm{q_1}$；
2. $\mathrm{q_1}$（左行进位）：读到 1 就改写成 0、继续左移（这是进位在传）；读到 0 就改写成 1、停机；读到空白（串顶到头了）就写入 1、停机。

下面是输入 `1011` 的完整格局序列，方括号标读写头位置与当前状态（Python 逐步模拟的输出，逻辑即上面两条）：

```text
[q0]1011B
1[q0]011B
10[q0]11B
101[q0]1B
1011[q0]B
101[q1]1B
10[q1]10B
1[q1]000B
1[H]100B
```

验算：${1011}_2 = 11$，加 1 得 ${1100}_2 = 12$，序列最后一行正是 `1100`。再试一个进位顶破串头的输入 `111`，模拟的最后三行是 `1[q1]10B`、`000[q1]B`、`[H]1000B`：$\mathrm{q_1}$ 走出纸带最左端，机器在头前面新开一格写 1，得到 ${1000}_2 = 8$，正确。

这台机器加一个 $n$ 位串用多少步？$\mathrm{q_0}$ 要走 $n$ 步到串尾，$\mathrm{q_1}$ 最坏从串尾走回串头，合计 $\Theta(n)$。它比 RAM 慢，但没有差一个数量级：RAM 上做同样的事也是 $\Theta(n)$。麻烦出在另一种程序上，下一节。

## $\rm \S \, 1.3$ 把 OJ 程序搬上纸带：模拟的代价

看一段最普通的 RAM 程序，$n$ 个 0/1 元素求和：

```python
s = 0
for i in range(n):
    s += a[i]          # s 是寄存器，a 是数组
```

RAM 上这是 $\Theta(n)$：每轮一次随机访问、一次寄存器加法。搬上单带图灵机要回答两个问题：$s$ 与数组放在哪；每轮实际走多少步。

### $\rm \S \, 1.3.1$ 膨胀发生在哪一步

寄存器 $s$ 没了，它必须住在纸带上；数组也住在纸带上，但两者的相对位置定死之后，读写头每轮都要在「下一个数组元素」和「$s$ 的格子」之间跑一个来回。布置成 `$ 1^s # d_1 d_2 … d_n`（$s$ 用一元笔画存，`#` 分隔），对最坏情形（全 1 数组）逐步模拟这个布局，实测步数如下（忠实模拟：位 0 无需访问寄存器，位 1 才走一趟；随机数据上另跑过一遍核对结果一致）：

| $n$ | RAM 步数（$\approx 4n$） | 图灵机步数 | 膨胀倍率 | $n$ 翻倍的增长 |
| --- | --- | --- | --- | --- |
| 4 | 18 | 52 | 2.9 倍 | |
| 8 | 34 | 168 | 4.9 倍 | 3.23 倍 |
| 16 | 66 | 592 | 9.0 倍 | 3.52 倍 |
| 32 | 130 | 2208 | 17.0 倍 | 3.73 倍 |

$n$ 每翻倍步数约乘 4，这正是 $\Theta(n^2)$ 的指纹：第 $i$ 轮的行程约 ${2i}$，总和 $\sum_{i=1}^{n} 2i = \Theta(n^2)$。线性程序在纸带上膨胀成了平方。

这不是坏消息，是定价。一般的定理（Hennie–Stearns 型的多带归单带结果）说：**任何 $T$ 步的 RAM 程序都能在 $O(T^2)$ 步内被图灵机模拟**。反过来图灵机当然也能被 RAM 模拟（RAM 是更强的机器，直接照搬即可，至多多项式开销）。两个方向都只差多项式，这叫两个模型**多项式等价（polynomially equivalent）**。

$$
\text{RAM 的 } T \text{ 步} \;\le\; \text{图灵机的 } O(T^2) \text{ 步} \;\le\; \text{RAM 的 } O(T^2) \text{ 步}
$$

往返一圈只丢多项式因子，这是等价陈述的精确形状。读法上留意两点：模拟是「逐条指令」的机械翻译，不需要任何聪明才智；指数 $T^2$ 里的平方不随程序而变，它是布局方式的账，不是问题的账。换更聪明的布局，某些程序能省一些（$\S 1.6$ 第 2 题就是让你试一种），但上限定理只承诺「存在一个平方级的通用模拟」，这已经够用了。

多项式等价还有另一半：多项式内部的高低起伏，复杂度类一概不理。一个旁证是**线性加速定理（linear speedup theorem）**：给图灵机多配常数条工作带（或加大字母表），任何 $\Theta(f(n))$ 的计算都能常数倍加速。所以「${2n}$ 步」和「$n$ 步」没有本质区别，多项式 $n^2$ 与 $n^3$ 之间也没有一道复杂度类想据此划界的墙。定理本身证明是折叠带子的技巧竞赛用不上，记住它的用途：它是「常数因子与多项式指数都无所谓」这条建模约定的机器背书。

## $\rm \S \, 1.4$ 通用图灵机：程序也是数据

还剩一块没搬上纸带：程序本身。$\S 1.2$ 的加 1 机器把程序「焊死」在状态寄存器里，一台机器只会一件事。**通用图灵机（universal Turing machine）** $U$ 改变这一点：纸带开头放一段机器 $\langle M \rangle$ 的编码（描述 $M$ 的状态与转移表），后面放 $M$ 的输入，$U$ 按编码逐条查表执行，行为与 $M$ 一模一样。$U$ 存在的理由很朴素：状态表本身是符号串，能编码，就能被另一台机器读取。

在 RAM 上这件事你每天都在做：操作系统把你的可执行文件当数据读进来，解释器把 `.py` 源码当数据逐行读。程序的「代码即数据」不是工程巧合，是计算模型与生俱来的性质。而且编码可以用自然数统一编号：每台图灵机领一个编号 $e$，于是「程序」和「输入」都成了数，这台机器对自身的操作（把自己当输入）就有了严格的写法 $M(\langle M \rangle)$。

编码还能再进一步：多个对象打包成一个。程序 $P$ 与输入 $x$ 可以编成有序对 $\langle P, x \rangle$（例如交错二者比特再加分隔符，或用质数配对函数），于是「停机问题以 $(P, x)$ 为输入」这样多参数的问题也落在单输入语言 $\{\langle P, x \rangle \mid P \text{ 在 } x \text{ 上停机}\}$ 的框架里。第 2 章的 K、Rice、归约全部在这个「一切皆串、串可编码一切」的约定下进行，届时不再重复交代。

这一步没有看起来那么无害。形式语言册 §5.2 的对角化论证里，那句「假设停机判定器存在，构造一个对自身行为唱反调的程序」之所以合法，靠的正是 $M(\langle M \rangle)$ 这个操作：程序拿到自己的描述当输入。下一章把这个「自引用」操作当成工具连用四次，它就是不可判定性地图上每条路的起点。届时请留意：构造里没有任何一步用到 $U$ 跑得多快，只用到它跑得完。快慢的账留给第 3 章，那里复杂度类正式登场。

3. 双带图灵机（一条只读输入带、一条工作带）给求和程序能省多少行程？为什么这类加速不改变「哪些问题多项式可解」？

## $\rm \S \, 1.7$ 本章自测答案

> 先闭卷作答 §1.5 与 §1.6，再核对。

### $\rm \S \, 1.7.1$ 关键概念回顾答案

1. 随机访问（下标不影响访存代价）与字运算 $O(1)$。图灵机只能逐格移动读写头，想知道远处格子必须真走过去。（§1.1）
2. ${0111}_2 + 1 = {1000}_2$。$\mathrm{q_0}$ 走到串尾后 $\mathrm{q_1}$ 从右向左把三个 1 全改成 0，走出左端新写一个 1。手算应得到与 $\S 1.2$ 的 `111` 情形同构的序列。（§1.2）
3. 膨胀在「寄存器访问」上：RAM 的一次寄存器加法是 $O(1)$，纸带上等于读写头在数组元素与累加器之间跑一趟 $\Theta(i)$ 的来回，$n$ 轮合计 $\Theta(n^2)$。（§1.3）
4. 两个方向的相互模拟都只有多项式开销：RAM 程序 $T$ 步可在 $O(T^2)$ 内被图灵机模拟，图灵机也能被 RAM 以多项式开销模拟。复杂度类以多项式为门槛，多项式开销跨不过这道门，所以模型的选择不影响类的成员资格。（§1.3）
5. 「常数因子无所谓」：多带（或扩字母表）能对任何 $\Theta(f(n))$ 计算做常数倍加速，所以常数因子不是复杂度类的分界。（§1.3）
6. 纸带开头是机器 $\langle M \rangle$ 的编码（状态与转移表），后面是 $M$ 的输入。停机问题的对角化论证里「程序把自己当输入」即 $M(\langle M \rangle)$，其严格意义由编码与 $U$ 提供。（§1.4）

### $\rm \S \, 1.7.2$ 应用与辨析答案

1. 能：无限大的字装得下 $2^{2^n}$，一次加法就「算完」了指数大的数。于是「多项式时间」覆盖的内容随模型畸变，门槛失去意义。这正是复杂度理论坚持「字长固定（如 $O(\log n)$ 位）、模型之间多项式等价」这类约束的原因。（§1.1、§1.3）
2. 还是 $\Theta(i)$：累加器在右侧，第 $i$ 轮读写头从左端第 $i$ 格走到右端 $s$ 再折回，行程同样约 $2(n-i)$ 量级；总代价仍是 $\Theta(n^2)$。搬布局躲不开平方，平方来自「寄存器与数据的距离」本身。（§1.3）
3. 输入带只读不动，工作带上无需反复回读输入，求和可以线性完成。但这类加速是常数到多项式内部的改进：不管省多少，「问题存在多项式算法」这一判定不变，所以复杂度类的成员不受影响。（§1.3）
4. 第一句对。$U$ 的模拟开销是多项式（对单带逐格模拟是平方级），但不保证恰好平方，可能有更大的多项式因子；「至多平方」是特定构造的产物，不是一般结论。（§1.3、§1.4）
5. 对应「把编号 $\langle M \rangle$ 写在 $M$ 自己的输入位置上」：有了机器编码，「程序对自身」从比喻变成一次普通的带符号输入操作。（§1.4）

模型钉死了：图灵机与 RAM 多项式等价，所以「多项式时间内可解」不挑机器。第 2 章先不问快慢，问一件更原始的事：有些问题根本算不出来，而证明这件事的每个武器（对角化、归约）都从本章末尾那个自引用操作里长出来。
