## $\rm \S \, 6.1$ 最短路径速览：三层算法一座塔

白话：从 $s$ 走到 $t$，怎么走最省？这个问题按「图带不带权」分成三层：无权图 BFS 一层一层剥；非负权图 Dijkstra 按距离从小到大收账；要**所有点对**的距离，Floyd–Warshall 用一张 DP 表兜底。三层共享同一个骨架——「已确定区域不断扩张，且扩张的顺序有讲究」。

1. **BFS（无权图）**：从源点出发逐层访问：先访问距离 0 的点，再距离 1 的，依此类推。队列保证层序不乱，$O(n + m)$ 内给出单源最短路（按边数计）。它与第 1 章 §1.4 的矩阵观点是同一件事：$(A^k)_{ij} > 0$ 当且仅当 $i$ 到 $j$ 存在长 $\le k$ 的途径——BFS 就是用队列把「最小的那个 $k$」找出来的动态版。
2. **Dijkstra（非负权图）**：维护每个点的试探距离 $\delta(v)$，每轮取出试探值最小的未定点 $u$，宣布它的距离定案，并用 $u$ 松弛邻居：$\delta(v) \leftarrow \min(\delta(v), \delta(u) + w(u, v))$。
3. **正确性（归纳关键步）**：断言「每轮取出的 $u$，其试探距离就是真实最短距离」。归纳假设已定案集合 $R$ 内的距离全对；考察取出的 $u$。任何 $s$ 到 $u$ 的路径必在某一步第一次离开 $R$，设离开时的边是 $x \to y$（$x \in R$、$y \notin R$）；这条路径的前缀长 $\ge \delta(x)$，于是路径全长 $\ge \delta(x) + w(x, y) \ge \delta(y) \ge \delta(u)$（$u$ 是试探值最小者）。而试探距离本身对应一条真实存在的路径，故 $\delta(u)$ 既不小于也不大于真实距离——定案无误。**非负权在哪一步用**：在 $\ge \delta(x) + w(x,y) \ge \delta(y)$ 这步；若有负边，前缀之后还可能越走越便宜，断言作废（负权要用 Bellman–Ford）。
4. **数值锚**（§6.8 实跑）：6 点经典图（$v_0$ 连 $v_1, v_2, v_5$ 权 ${7, 9, 14}$；$v_2$ 连 $v_5$ 权 2；等等），从 0 出发的距离向量是 $[0, 7, 9, 20, 20, 11]$——注意 $d(v_5) = 11$ 走的是 $0 \to 2 \to 5$（$9 + 2$）而非直达边 14，Dijkstra 的「绕路更短」在这个数上现形。
5. **Floyd–Warshall（全点对）**：定义 $d_k(i, j)$ 为「中间顶点只许用 $\{1, \ldots, k\}$」的最短距离，递推
$$
d_k(i, j) = \min\left(d_{k-1}(i, j),\ d_{k-1}(i, k) + d_{k-1}(k, j)\right).
$$
读法：第 $k$ 个顶点被解禁时，要么绕它更近（拆成 $i \to k$ 加 $k \to j$ 两段，各自仍是「只许用旧中间点」的最短路），要么不绕。三层循环 $O(n^3)$、空间 $O(n^2)$，稠密小图的全点对首选。
6. 三层的分工一句话：问单源且无权用 BFS，问单源带非负权用 Dijkstra（$O(m \log n)$），问全点对且图不大用 Floyd–Warshall。矩阵版也有一条暗线：把 $(\min, +)$ 当作「加法与乘法」 replacing 普通运算，$A$ 的 $(\min, +)$ 幂就编码最短路——BFS 的矩阵观点（普通乘法数走道）是这个代数的概率版兄弟。

**本节小结**：BFS 靠队列剥层（矩阵语言：$A^k$ 的支持集）、Dijkstra 靠「最小试探值定案」的归纳（非负权保证路径前缀不更便宜）、Floyd–Warshall 靠「中间点逐个解禁」的 DP；锚点 $[0, 7, 9, 20, 20, 11]$ 里藏着一条绕路更短的实例。

## $\rm \S \, 6.2$ 最大流与最小割：一对对偶的相遇

白话：把图想成管道网：$s$ 是水源、$t$ 是用户，每条管道有容量，问单位时间内最多能送多少水。答案有个惊人的对偶形式：**最大流等于最小割**——最贵的瓶颈（把顶点切成两半、跨半容量之和最小的那刀）恰好卡住水量的上限。这是图论里最重要的极小极大定理之一。

1. **定义（流与割）**：流 $f$ 给每条有向边赋值，要求 $0 \le f(e) \le c(e)$（容量限制）与每个中间顶点「流入 = 流出」（守恒）；流值 $|f|$ 是离开 $s$ 的净值。$s$-$t$ 割 $(S, \bar S)$ 要求 $s \in S$、$t \in \bar S$，容量 $c(S, \bar S)$ 是从 $S$ 指向 $\bar S$ 的边的容量和。
2. **弱对偶（一分钟）**：任何流值 $\le$ 任何割容量。流值 = 跨越割 $(S, \bar S)$ 的净流量（守恒保证中间顶点零贡献），而净流量至多 $c(S, \bar S)$。所以「最大流 $\le$ 最小割」是白给的；奇迹是反向也成立。
3. **定理（最大流最小割，Ford–Fulkerson, 1956）**：最大流值 = 最小割容量。
4. **证明关键步骤**。给定一个不能再增广的流 $f$：在**残量网络**（容量剩 $c - f$ 的正向边加可回退的反向边）里从 $s$ 出发，令 $S$ 为所有可达顶点。$t \notin S$（否则存在增广路径，与不能再增广矛盾），故 $(S, \bar S)$ 是割。逐条验账：$S$ 指向 $\bar S$ 的每条边必已**饱和**（否则残量边可达对面，$t$ 就进 $S$ 了），$\bar S$ 指向 $S$ 的每条边流量为零（否则反向残量边可达对面）。于是跨越割的净流量 = 全部饱和容量 = $c(S, \bar S)$ = 当前流值。结合弱对偶，三者同值，定理到手。读法：证明同时给了**算法**（不断找增广路径直到找不着）与**证书**（停机时的残量可达集就是最小割的 $S$ 侧）。
5. 复杂度与实现：增广路径每次至多推进 1，任意顺序可能不终止（无理容量）；**Edmonds–Karp** 规定每次走**边数最少**的增广路，$O(n m^2)$ 次内终止；更快的 Dinic 用分层网络做到 $O(n^2 m)$。实践里 BFS 版（Edmonds–Karp）简单可靠，是教学与中小规模的首选。
6. **数值锚**（§6.8 实跑）：6 点网络（源 $0$、汇 $5$，容量 $c(0,1) = 16$、$c(0,2) = 13$、$c(1,3) = 12$、$c(2,1) = 4$、$c(2,4) = 14$、$c(3,2) = 9$、$c(3,5) = 20$、$c(4,3) = 7$、$c(4,5) = 4$）：最大流值 **23**；残量可达集 $S = \{0, 1, 2, 4\}$；最小割边为 $(1, 3)$、$(4, 3)$、$(4, 5)$，容量 $12 + 7 + 4 = 23$——流与割在 23 处相遇，定理的教科书样本。
7. 与前章接一条线：第 4 章 §4.3 的电导率是「无向、按体积归一」的割；本节的 $s$-$t$ 割是「有向、带容量、端点指定」的割。前者有 Cheeger 谱近似（$\sqrt{2\nu_2}$ 因子内可解），后者有多项式精确算法——「割」这个对象横跨谱方法与组合优化两个世界，同一张图的两把手术刀。

**本节小结**：最大流最小割 = 弱对偶（白给）加增广停机时的残量可达集证书（定理）；Edmonds–Karp 用 BFS 选路保证 $O(nm^2)$；锚点：流值 23 与割 $\{12, 7, 4\}$ 的逐边相遇。

## $\rm \S \, 6.3$ 出口：图神经网络的信息传递视角

白话：前两节的算法有一个共同点——**每个顶点都在反复打听邻居的消息**：Dijkstra 的松弛是打听「经你过去要几步」，增广路径是打听「你还有多少余量」。图神经网络（GNN）把这个模式抽成唯一一条规则：每个顶点维护一个特征向量，每层把邻居的特征**聚合**进来、更新自己的。图上的学习，从此约化为信息传递。

1. **消息传递的一般形式**。第 $k$ 层的更新：
$$
h_v^{(k+1)} = \operatorname{UPDATE}\left(h_v^{(k)},\ \operatorname{AGGREGATE}\left(\left\{h_u^{(k)} : u \in N(v)\right\}\right)\right).
$$
UPDATE 与 AGGREGATE 换成具体函数，就得到各家模型。最经典的一支（GCN）取线性聚合：
$$
H^{(k+1)} = \sigma\left(P\, H^{(k)}\, W\right),
$$
其中 $P = D^{-1} A$ 是行随机的归一化邻接矩阵（按度平均邻居），$W$ 是可学习的权重，$\sigma$ 是逐点非线性。
2. **与第 4 章接通：一层 GCN = 一步平滑**。取 $W = I$、$\sigma$ 为恒等，$H^{(k+1)} = P H^{(k)}$ 恰是按邻居平均——即第 4 章 Laplacian 二次型「边两端差平方和」所惩罚的那个操作的反面：传播让相邻顶点的特征互相靠近。$P = D^{-1}A$ 与对称归一化 $\mathcal{N} = I - \frac{A}{d}$ 只差相似变换与平移（$P = I - D^{-1}L$），GCN 的层数就是平滑步数。
3. **与第 1 章接通：$k$ 层 = $k$ 步走道**。展开 $H^{(k)} = P^k H^{(0)} W^k$：顶点 $v$ 的第 $k$ 层特征是它在 $k$ 步随机游走可达范围内邻居特征的加权混合——权重正比于到达路径数（$A^k$ 的走道计数加了度归一）。GNN 的「感受野」就是第 1 章 §1.4 的 $A^k$ 支持集。
4. **数值锚：过平滑的全程录像**（§6.8 实跑）。玩具图：两个三角形，之间一条桥边 $0$-$3$；初始特征只有两个锚点：$v_0$ 带第 0 类标记、$v_4$ 带第 1 类标记（其余全零）。跑 ${P H}$ 五步：
$$
H^{(1)}:\ v_1, v_2 \text{ 各拿到 } 0.5 \text{ 的第 0 类信号},\quad
H^{(2)}:\ v_5 \text{ 也见到 } 0.17,
$$
信号一层层扩散；到第 5 步，两列取值为 $[0.21, 0.29, 0.29, 0.22, 0.14, 0.22]$ 附近，且两列越来越像。理论极限：$P^k H^{(0)} \to \mathbf{1} \pi^\top H^{(0)}$，其中 $\pi = d / \sum d = [0.214, 0.143, 0.143, 0.214, 0.143, 0.143]$（度比例分布）——两列最终**完全相同**，锚点的身份被冲掉。这就是**过平滑**：层数一多，所有顶点的特征塌缩到同一个向量，分类信息归零。真实 GNN 只敢叠两三层、加残差连接，根源在此。
5. **与第 2 章接通：表达能力的上限是一种着色**。1-WL 颜色精化算法反复执行「新颜色 $\leftarrow$ 哈希（旧颜色，邻居颜色的多重集）」，把顶点分到按结构等价的类里——它与消息传递网络的区别只在哈希函数可不可学；理论上 GNN 的判别力至多等于 1-WL：1-WL 分不开的图（如那对 3-正则双胞胎 $\rm K_{3,3}$ 与三棱柱，第 1 章 §1.3），任何标准消息传递 GNN 也分不开。第 2 章问「染色逼出什么秩序」，这里问「精化染色能认出什么结构」——同一本账的两个方向。
6. **与第 5 章接通：网络结构决定 GNN 好不好用**。ER 型图的度集中在均值附近，按度平均没有失真；无标度网络的枢纽顶点一次聚合吸进成千上万邻居的消息，普通顶点的信号被稀释——第 5 章 §5.3 的重尾（top-8 度 145 对均值 4）直接翻译成 GNN 的聚合偏斜。设计采样式邻居聚合（GraphSAGE 类）的动机，就是给重尾打补丁。

**本节小结**：消息传递 = GNN 的统一语法；GCN 一层是 Laplacian 平滑（第 4 章）、$k$ 层是 $k$ 步走道（第 1 章）；过平滑的录像（两列趋同于 $\pi = [0.214, 0.143, 0.143, 0.214, 0.143, 0.143]$）解释了为什么层数浅；1-WL 上限（第 2 章）与重尾聚合偏斜（第 5 章）是这套视角的两条边界。

## $\rm \S \, 6.4$ 收束：六章一张地图

白话：把全册的线索收进一张地图，每章各交出一件工具，本章各认领一次用途。

1. 第 1 章（图的基本量）交出**词汇**：度、连通、走道计数。本章的用途：$A^k$ 支持集是 GNN 感受野、BFS 是走道的动态版。
2. 第 2 章（着色与 Ramsey）交出**压力思维**：秩序躲不掉、染色记账结构。本章的用途：1-WL 精化是 GNN 表达能力的上限，$R(3,3) = 6$ 的鸽笼是「局部信息定全局」的最小样本。
3. 第 3 章（极图与 Turán）交出**边界思维**：禁令之下边数有天花板、极值构型均匀摊平。本章的用途：算法复杂度的下界论证、稀疏图上信息传递的物理极限，都是「结构约束决定可行域」的同类题。
4. 第 4 章（代数图论）交出**谱的显微镜**：Laplacian、代数连通度、Cheeger。本章的用途：GCN 是平滑算子的可学习版，最小割有谱近似。
5. 第 5 章（网络科学）交出**随机性**：相变、小世界、重尾。本章的用途：网络拓扑决定算法表现——最短路在 ER 上快（距离 $\ln n$ 级）、GNN 在无标度上聚合偏斜。
6. 图论至此给出一条完整的链：**对象（图）→ 量（度、谱、极值、随机性）→ 过程（算法、学习）**。所有「过程」都跑在量出的结构上；读懂量，才读得懂过程为什么快、为什么慢、为什么塌缩。

**本节小结**：六章一线——词汇、压力、边界、谱、随机、算法；信息传递是那条把五章量法全部接回一台机器的出口。

## $\rm \S \, 6.7$ 本章自测答案

> 先闭卷作答 §6.5 与 §6.6，再核对。

### $\rm \S \, 6.7.1$ 关键概念回顾答案

1. 断言：每轮取出的试探值最小者 $u$，试探距离即真实距离。归纳中考察首次离开已定案的边 $x \to y$：路径全长 $\ge \delta(x) + w(x, y) \ge \delta(y) \ge \delta(u)$，非负权保证「前缀之后不再变便宜」这一步；负权时路径后段可以拉低总长，不等式链断裂。（§6.1）
2. 解禁 $k$ = 允许路径经过顶点 $k$：比较「不经过」（$d_{k-1}(i,j)$）与「经过」（$d_{k-1}(i,k) + d_{k-1}(k,j)$）。经过情形拆成两段，$i \to k$ 段的最短路不需要再经过 $k$（否则可去掉来回），故中间点仍在 $\{1, \ldots, k-1\}$ 内。（§6.1）
3. 弱对偶：守恒使流值等于跨割净流量，容量限制使净流量 $\le c(S, \bar S)$。强对偶：停机时 $S$ 是残量网络中 $s$ 的可达集；$S \to \bar S$ 的边必饱和（否则可继续走到对面）、$\bar S \to S$ 的边流量必为零（否则反向残量可达对面），净流量恰等于割容量。（§6.2）
4. 每次选边数最少的增广路（BFS 距离意义），可证每条「饱和边」至多在两个相邻层次成为瓶颈，总增广次数 $O(nm)$、每次 $O(m)$；任意选路在无理容量下可能永不终止、有理容量下也可能指数次。（§6.2）
5. $k$ 层对应 $P^k$ 的 $k$ 步随机游走（第 1 章 $A^k$ 计走道的度归一版）与 $k$ 步 Laplacian 平滑（第 4 章二次型的反向操作）。极限 $\mathbf{1}\pi^\top H^{(0)}$，$\pi = d/\sum d$：每列塌缩到同一个度比例向量，所有顶点特征趋同，锚点是谁的信息在按度平均的反复混合中被冲掉。（§6.3）
6. GNN 的判别力至多等于 1-WL 颜色精化（聚合可看作可学习的哈希）；$\rm K_{3,3}$ 与三棱柱（1-WL 分不开、标准消息传递也分不开）是双双失手的证人。（§6.3）

### $\rm \S \, 6.7.2$ 应用与辨析答案

1. 不能保证。反例：边 $s \to t$ 权 $2$，边 $s \to x$ 权 $3$、$x \to t$ 权 $-2$（合计 1）。Dijkstra 先定案 $t$（试探值 2 最小），锁死 $d(t) = 2$；真实最短是 $s \to x \to t = 1$。错在「定案时认为后段不会再变便宜」，负边打破该假设。（§6.1）
2. 降为 2 后割 $(1,3), (4,3), (4,5)$ 容量 $12 + 2 + 4 = 18$，且源侧仍可达（${0,1,2}$ 到 4 的边 $(2,4)$ 容量 14 仍在割的 $S$ 侧内不发贡献），最大流值降为 18：验证守恒——$t$ 的入流只剩 $(3,5)$ 与 $(4,5)$，受 $(1,3)$ 的 12 与 $(4,3)$ 的 2 限制，$3$ 收至多 12、$4$ 收至多 14 中只能转发 2，合计 $12 + 2 + 4 = 18$。（§6.2）
3. 用过平滑录像：5 步后两列已接近同一向量，理论极限 $[0.214, 0.143, 0.143, 0.214, 0.143, 0.143]$ 两列完全相同——层数越多感受野越大没错，但特征同时塌缩到度比例常数，分类信息归零；现象名「过平滑」，机理是按度平均的反复混合是压缩映射、不动点对所有锚点一视同仁。（§6.3）
4. ER 图：度分布集中，$\pi$ 近似均匀向量，极限是「人人同一个近常数」——塌缩均匀但快慢由谱隙决定。BA 图：$\pi$ 被枢纽拉偏（枢纽分量接近 0.2 以上、多数顶点近乎 0），塌缩的极限严重偏向枢纽，普通顶点的信号在中间层就被枢纽稀释——重尾既改变塌缩速度也改变塌缩终点。（§5.3、§6.3）

## $\rm \S \, 6.8$ 可当场复跑的程序段

下面这段程序（numpy，全程确定性）把 §6.1–§6.3 的数值锚全部实算，输出与正文逐位一致：

```python
 # 第 6 章数值锚：Dijkstra / Edmonds-Karp / 信息传递 / 矩阵版 BFS
import numpy as np

 # --- Dijkstra：6 点经典带权图 ---
def dijkstra(nv, edges, s):
    adj = [[] for _ in range(nv)]
    for u, v, w in edges:
        adj[u].append((v, w)); adj[v].append((u, w))
    dist = [float('inf')] * nv; dist[s] = 0
    done = [False] * nv
    for _ in range(nv):
        u = min((d, i) for i, d in enumerate(dist) if not done[i])[1]
        done[u] = True
        for v, w in adj[u]:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
    return dist

w_edges = [(0, 1, 7), (0, 2, 9), (0, 5, 14), (1, 2, 10), (1, 3, 15),
           (2, 3, 11), (2, 5, 2), (3, 4, 6), (4, 5, 9)]
print("Dijkstra 距离", dijkstra(6, w_edges, 0))

 # --- Edmonds-Karp 最大流 ---
def edmonds_karp(nv, cap, s, t):
    res = [row[:] for row in cap]
    flow = 0
    while True:
        par = [-1] * nv; par[s] = s; q = [s]
        while q and par[t] == -1:
            u = q.pop(0)
            for v in range(nv):
                if par[v] == -1 and res[u][v] > 0:
                    par[v] = u; q.append(v)
        if par[t] == -1:
            break
        aug = float('inf'); v = t
        while v != s:
            u = par[v]; aug = min(aug, res[u][v]); v = u
        v = t
        while v != s:
            u = par[v]; res[u][v] -= aug; res[v][u] += aug; v = u
        flow += aug
    seen = {s}; q = [s]
    while q:
        u = q.pop()
        for v in range(nv):
            if res[u][v] > 0 and v not in seen:
                seen.add(v); q.append(v)
    cut = [(u, v, cap[u][v]) for u in range(nv) for v in range(nv)
           if cap[u][v] > 0 and u in seen and v not in seen]
    return flow, cut, sorted(seen)

cap = [[0] * 6 for _ in range(6)]
for u, v, c in [(0, 1, 16), (0, 2, 13), (1, 3, 12), (2, 1, 4), (2, 4, 14),
                (3, 2, 9), (3, 5, 20), (4, 3, 7), (4, 5, 4)]:
    cap[u][v] = c
fl, cut, side = edmonds_karp(6, cap, 0, 5)
print("最大流值", fl, "割边(带容量)", cut, "源侧 S", side)
print("割容量合计", sum(c for _, _, c in cut))

 # --- 信息传递：两个三角形 + 一条桥，P = D^{-1} A 的反复传播 ---
A = np.zeros((6, 6))
for i in range(3):
    for j in range(3):
        if i != j:
            A[i, j] = 1; A[i + 3, j + 3] = 1
A[0, 3] = A[3, 0] = 1
D = np.diag(A.sum(1))
P = np.linalg.inv(D) @ A
print("各点度", A.sum(1).astype(int).tolist())
X = np.zeros((6, 2)); X[0, 0] = 1; X[4, 1] = 1
H = X.copy()
for step in range(1, 6):
    H = P @ H
    print(f"传播 {step} 步", np.round(H, 2).tolist())
print("极限 pi = [d_i]/sum(d):", np.round(A.sum(1) / A.sum(), 3).tolist())

 # --- 矩阵版 BFS：P 的幂与首达 ---
Ab = np.zeros((5, 5))
for a, b in [(0, 1), (1, 2), (0, 2), (2, 3), (3, 4)]:
    Ab[a, b] = Ab[b, a] = 1
first = {}
Pm = np.eye(5)
for k in range(1, 6):
    Pm = Pm @ Ab
    for i in range(5):
        for j in range(5):
            if (i, j) not in first and Pm[i, j] > 0:
                first[(i, j)] = k
print("0 到 4 的首达步数", first[(0, 4)],
      " 0 到各点", [first[(0, j)] for j in range(5)])
```

## $\rm \S \, 6.9$ 带走清单

1. 最短路三层：BFS 剥层（$O(n + m)$）、Dijkstra 按「最小试探值定案」归纳（非负权用在「前缀之后不变便宜」）、Floyd–Warshall 按中间点解禁 DP（$O(n^3)$）；锚点 $[0, 7, 9, 20, 20, 11]$。
2. 最大流最小割：弱对偶白给、强对偶靠「停机时残量可达集 = 最小割 $S$ 侧、割边全饱和」的证书；Edmonds–Karp 按最少边数增广，$O(nm^2)$；锚点流值 23 = $12 + 7 + 4$。
3. 消息传递 $h_v^{(k+1)} = \operatorname{UPDATE}(h_v^{(k)}, \operatorname{AGGREGATE}(\{h_u^{(k)}\}))$ 是 GNN 的统一语法；GCN $= P H^{(k)} W$，$P = D^{-1} A$。
4. 两根接线：$k$ 层 GCN = $k$ 步随机游走（第 1 章 $A^k$）= $k$ 步 Laplacian 平滑（第 4 章）。
5. 过平滑：$P^k H^{(0)} \to \mathbf{1} \pi^\top H^{(0)}$，$\pi = d / \sum d$；玩具录像第 5 步两列趋同，极限 $[0.214, 0.143, 0.143, 0.214, 0.143, 0.143]$——层数一多身份归零，真实 GNN 只叠两三层。
6. 表达能力上限是 1-WL 精化（第 2 章着色思想），$\rm K_{3,3}$ 与三棱柱是标准消息传递也失手的证人；重尾网络（第 5 章 BA）的枢纽聚合偏斜是第二条边界。
