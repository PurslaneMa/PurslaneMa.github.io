# $\rm Chapter \, 5$ 局部差分隐私与随机化响应

前四章的所有机制都默认同一个角色在场：**可信的聚合者**。Laplace 机制也好、DP-SGD 也好，都是先让原始数据汇聚到一台服务器、再在出口加噪——数据在加噪之前是裸奔的。这一章掀掉这个角色：如果连聚合者也不能信，隐私必须从**每个人自己的硬币**开始。答案是局部差分隐私，而它的祖先——随机化响应——比差分隐私本身早了半个世纪：1965 年 Warner 为敏感问卷设计的掷硬币技巧，在数学上就是一台逐记录的 $\varepsilon$-DP 机器。本章把这台机器全证一遍，再用它回答一个定量问题：把信任从聚合者手里拿走，要付多少效用。

> **开始前自检**：本章假设你已经会：
>
> 1. □ $(\varepsilon,\delta)$-DP 的定义与「对每对相邻库、每个事件」的量词（[差分隐私册第 1 章](./01-邻接数据库与差分隐私.md)）——局部 DP 把这组量词下沉到**单条记录**，对照着读才看得清省了什么；
> 2. □ 后处理不变性（[差分隐私册第 3 章](./03-合成定理与后处理.md)）——聚合者收到噪声答案后的去偏校正，账单为零，靠的就是这条定理；
> 3. □ 期望的线性性与二项分布的方差（[概率论册第 4 章](../19-概率论/04-收敛与极限定理.md)）——去偏估计的偏差与方差计算全用得上；
> 4. □ 条件概率与全概率公式（[概率论册第 3 章](../19-概率论/03-多元随机变量与条件期望.md)）——主证的证明是一次两行展开；
> 5. □ 大数定律的直觉（[概率论册第 4 章](../19-概率论/04-收敛与极限定理.md)）——「$n$ 个人摊薄噪声」的速度由 $\sqrt{n}$ 决定，§5.3 的效用差距就刻在这里。

## $\rm \S \, 5.1$ 全局与局部：信任模型的两端

白话：全局 DP 是「把真数据交给一个可信托管人，他在出口加噪」；局部 DP 是「数据根本不出门——每个人在自己的设备上掷硬币，把已经加噪的答案交上去」。差别不在算法，在**谁拿着原始数据**。

场景化一点：输入法想学「哪张表情图用得多」。全局方案把每一次点击明文传到服务器，服务器在出口对统计结果加噪——用户只能相信服务器的机房、内网和员工都无懈可击；局部方案在手机上就掷硬币，上传的每一比特从出生起就带着噪声，服务器被黑、日志被 subpoena、员工越权，看到的都只是噪声化的答案。隐私保证的落点从「组织的操守」挪到了「数学的不等式」，这是两种模型真正的分水岭。

前四章的机制都属于全局（中央）差分隐私：机制 $M$ 以整个数据库 $D$ 为输入，加噪发生在聚合端。局部差分隐私（local DP，LDP）把这个前提砍掉——没有数据库这个概念了，只有一台**逐记录**工作的随机化器 $R$：

> **定义（$\varepsilon$-局部差分隐私）**：随机化器 $R$ 满足 $\varepsilon$-局部差分隐私，若对一切取值 ${x,x'}\in\mathcal{X}$ 与一切事件 $S\subseteq\mathrm{Range}(R)$ 有
>
> $$
> \Pr[R(x)\in S]\ \le\ \mathrm{e}^{\varepsilon}\,\Pr[R(x')\in S]
> $$

读法：量词从「每对相邻数据库」下沉到「每一对**取值**」——$x$ 与 ${x'}$ 是同一个人的真值两种可能，$\Pr$ 对随机化器自己的硬币取。注意 $\delta$ 没了：常见的 LDP 机制都是纯 DP（加性豁免在单记录层面很难给语义），这是局部模型少有的便宜。整条流水线是：每个人对真值 $x$ 跑 $R(x)$，把结果交给聚合者；聚合者只见噪声化的答案，对它们做的一切统计都是第 3 章意义上的后处理——免费，但也就是他能做的全部。

两种模型的对比，一张表看完：

1. **信任假设**：全局 DP 信任聚合者（至少信任他「拿真数据只跑机制」）；局部 DP 连这个也不需要——真值从未离开用户设备。
2. **噪声代价**：全局 DP 的噪声按「查询」加，一次 $\sigma=\Delta f\sqrt{2\ln(1.25/\delta)}/\varepsilon$；局部 DP 的噪声按「人」加，$n$ 个人每人自带一份，摊薄靠 $\sqrt{n}$——同样的精度，局部要贵得多（§5.3 定量）。
3. **典型用途**：全局 DP 用于人口普查、托管统计分析；局部 DP 用于浏览器遥测、输入法学习——凡是「数据一出门就不受你控制」的场景。

一个容易忽略的联接点：局部 DP 与全局 DP 不止是竞争对手——局部噪声化的数据汇到聚合者手里后，聚合者若另外掌握一个可信环境，还可以在此基础上再做一轮全局机制；而单看每一份上传，LDP 保证已经成立。信任谱系上，「纯全局 — 安全聚合＋全局 DP — 纯局部」是一条连续的光谱，工程按「最不可信的那一环」选点。

光谱中段值得单独点名：**安全聚合**（secure aggregation）用密码学的门限技术让服务器只能看到众人的**总和**、看不见任何单份上传——单份隐私由密码学管，总和层面再套全局 DP 管统计泄露。它是现代移动端训练（联邦学习，第 6 章出口处再会）的标准组合：密码学把「看见」缩到最小，差分隐私把「算出」管到最死。纯局部模型是光谱上最便宜（不需要任何密码学）、也最吵（噪声最大）的一端。

**本节小结**：局部 DP 把 DP 的量词从「相邻数据库」下沉到「每一对取值」，随机化器逐记录工作、通常是纯 DP；代价是噪声按人头加、效用靠 $\sqrt{n}$ 慢慢爬。

## $\rm \S \, 5.2$ 随机化响应（本章主证）

白话：1965 年，统计学家 Warner 面对一个调查困境——「你堕过胎吗」「你吸过毒吗」这类问题，受访者怕答案本身暴露自己，干脆撒谎或拒答。他的办法：**让回答者自己掷硬币**。正面，如实回答；反面，再掷一次，正面答「是」、反面答「否」。提问者拿到答案也不知道真假，但足够多的答案平均下来，真比例浮得出来。

把这个流程写成机器。设真值 $x\in\{0,1\}$，随机化响应（randomized response，RR）以参数 $p$ 工作：

$$
\Pr[R(x)=1]=p\cdot x+(1-p)(1-x)
$$

读法：$x=1$（真值「是」）时以 $p$ 如实输出 $1$、以 $1-p$ 翻转输出 $0$；$x=0$ 时对称。$p=1$ 退化为诚实回答（零隐私），$p=1/2$ 输出与真值无关的均匀硬币（最大隐私），中间是一条连续滑杆。Warner 的两次掷硬币恰好实现 $p=3/4$；工程上 $p$ 是自由参数。

> **命题（RR 是 $\varepsilon$-DP）**：RR 满足 $\varepsilon$-DP，其中 $\varepsilon=\ln\frac{p}{1-p}$；等价地，$p=\frac{\mathrm{e}^{\varepsilon}}{1+\mathrm{e}^{\varepsilon}}$。

证明两行。输出空间只有 $\{0,1\}$，逐点验两个事件。输出 $1$ 的条件概率：$x=1$ 时为 $p$，$x=0$ 时为 $1-p$；输出 $0$ 时对称。于是对任何事件 $S\subseteq\{0,1\}$（只有 $\{1\}$、$\{0\}$、全集三种非平凡情形）：

$$
\frac{\Pr[R(1)=1]}{\Pr[R(0)=1]}=\frac{p}{1-p}=\mathrm{e}^{\varepsilon},\qquad \frac{\Pr[R(1)=0]}{\Pr[R(0)=0]}=\frac{1-p}{p}=\mathrm{e}^{-\varepsilon}\le\mathrm{e}^{\varepsilon}
$$

读法：第一处是「真值是 $1$ 的人答『是』的概率」对「真值是 $0$ 的人答『是』的概率」之比——恰好 $\mathrm{e}^{\varepsilon}$；第二处方向反过来，比值 $\mathrm{e}^{-\varepsilon}$ 更小，不等式自动满足。全集是 $1=1$。单记录的似然比全程被封在 $\mathrm{e}^{\varepsilon}$ 内，按 LDP 的定义即证。$\blacksquare$

读这个证明要停一下的地方：**第 1 章 §1.4 说「确定性机制必败」，这里没有违反**——RR 的机制输出是随机的，且随机性直接长在记录上；两行的比值结构正是第 1 章 $(\varepsilon,\delta)$-DP 定义的逐点版本，只是「相邻数据库」缩成了「两个真值」。

> **易混点**：Warner 的原始问卷里 $p$ 不是自由参数而是流程的产物——掷两次硬币恰好给出 $p=3/4$，对应 $\varepsilon=\ln 3\approx 1.0986$，「问一次、掷两次」的固定价。现代 LDP 系统把它反过来用：先定隐私预算 $\varepsilon$，再反解 $p=\mathrm{e}^{\varepsilon}/(1+\mathrm{e}^{\varepsilon})$。另一个别搞混的对象：$p$ 在这里是**如实概率**，不是第 2 章 Gaussian 机制里的什么参数；两个 $p$ 毫无亲缘，只是撞了字母。

**准确率-隐私的定量滑杆。** 一个人的答案答对的概率是 $p$，所以单个答案的准确率就是 $p=\mathrm{e}^{\varepsilon}/(1+\mathrm{e}^{\varepsilon})$：$\varepsilon=0.5$ 时 $0.6225$，$\varepsilon=1$ 时 $0.7311$，$\varepsilon=2$ 时 $0.8808$。工程里还有个更常用的变体：不翻转，而是**均匀瞎猜**——以 $p$ 如实回答，以 $1-p$ 在 $\{0,1\}$ 里均匀乱答（答对算运气）。它的逐点概率是 $\Pr[R(x)=1]=p\cdot x+(1-p)/2$，同款两行证明给出**同一个** $\varepsilon=\ln\frac{1+p}{1-p}$（比值结构 $\frac{1+p}{1-p}$ 与翻转版一致）。答对概率变成

$$
\Pr[R(x)=x]=p+\frac{1-p}{2}=\frac{1+p}{2}
$$

读法：一半的「乱答」会撞对，所以准确率从 $p$ 抬高到 $(1+p)/2$。数值锚（实算）：

| $\varepsilon$ | $p=\mathrm{e}^{\varepsilon}/(1+\mathrm{e}^{\varepsilon})$ | 瞎猜版观测准确率 $(1+p)/2$ |
| --- | --- | --- |
| $0.5$ | $0.6225$ | $0.8112$ |
| $1$ | $0.7311$ | $0.8655$ |
| $2$ | $0.8808$ | $0.9404$ |

读法：$\varepsilon=0.5$ 时表面看 $81\%$ 的答案是对的——但这个「准确率」是**观测层面**的安慰剂：攻击者眼里，答案与真值的互信息仍由 $\varepsilon$ 钉死，$0.8112$ 的准确率与 $0.6225$ 的翻转版泄露得一样多。别被高分骗了，隐私在似然比里不在正确率里。

两个变体怎么选，一句话各给判据：翻转版的条件概率结构更干净（真值相同时输出分布不偏），理论分析常拿它当教具；瞎猜版在同样 $\varepsilon$ 下观测准确率更高、去偏后方差更小，是工程与本章实验的选择。两者相差的只是「说谎的方式」，似然比的骨架 $\frac{1+p}{1-p}$ 分毫不差——这也是「隐私在似然比里」最直接的一次演示。

**后处理去偏。** 单个答案无用，$n$ 个答案的**比例**才有用。设真实比例为 $p_0$，观测到「答 $1$」的比例 $\hat q$，瞎猜版下

$$
\mathbb{E}[\hat q]=p_0\cdot\frac{1+p}{2}+(1-p_0)\cdot\frac{1-p}{2}=\frac{1-p+2p_0p}{2}
$$

读法：全概率展开——真值为 $1$ 的人以 $(1+p)/2$ 答 $1$，真值为 $0$ 的人以 $(1-p)/2$ 答 $1$。解出 $p_0$，得校正因子：

$$
\hat p_0=\frac{2\hat q-1+p}{2p}
$$

读法：这是确定性映射——观测比例 $\hat q$ 减去「零真值时也有的底噪」$(1-p)/2$，再除以信号增益 $p$。分子里 $2\hat q-1$ 的读法：先把观测比例从 $[0,1]$ 平移到 $[-1,1]$，让「零信号」落在原点；$+p$ 是把底噪 $(1-p)/2$ 的两倍补回去；整个分子除以信号增益 ${2p}$，得到真比例的估计。按第 3 章 §3.1 后处理不变性，它**不加任何预算**：账单在每个人掷硬币那刻已结清。代价在方差：$\mathrm{Var}(\hat p_0)=\hat q(1-\hat q)/(np^2)$——信号被压小了 $p$ 倍，除回去时噪声放大 $1/p^2$ 倍；$\varepsilon$ 越小（$p$ 越接近 $1/2$），方差爆炸得越狠。这就是局部隐私的价签，§5.4 实测。

**本节小结**：RR 以 $p$ 如实、否则翻转（或瞎猜），两行比值证明 $\varepsilon=\ln\frac{p}{1-p}$；观测准确率 $(1+p)/2$ 是安慰剂，去偏估计 $\hat p_0=(2\hat q-1+p)/(2p)$ 免费但方差放大 $1/p^2$。

收尾前把机制往多值方向瞥一眼——真实遥测里的答案很少是二值的（emoji 有几千个）。$k$ 元直接编码（$k$-ary RR）：以 $\frac{\mathrm{e}^{\varepsilon}}{\mathrm{e}^{\varepsilon}+k-1}$ 发真值，否则在 $k$ 个取值里均匀乱发。证明骨架原封不动：任取两个真值，发某个特定值的条件概率之比被 $\mathrm{e}^{\varepsilon}$ 封住；去偏也照旧是「减底噪、除增益」的线性校正。二值 RR 是它 $k=2$ 的特例，RAPPOR 是它与布隆过滤器的合体——同一个 $\varepsilon$，一路沿用到底。

## $\rm \S \, 5.3$ 局部 DP 的现代应用与效用差距

随机化响应在 1965 年是问卷技巧，五十年后成了工业系统的核心部件，机制换了外壳、数学没换：

1. **Google RAPPOR**（Erlingsson et al., 2014）：Chrome 遥测统计用户改恶意设置的发生率——字符串没法直接掷硬币，先映到布隆过滤器、再对每一位做永久性随机化，等于「向量化的 RR」。
2. **Apple 输入法统计**（2016 起）：iOS 键盘统计 emoji 与热门词的使用频率，设备端对每个计数做 LDP 化再上传——Apple 公开的技术说明里 $\varepsilon$ 按功能分组取值，正是把滑杆按数据敏感度分别校准。
3. **规模化回归**：2017 年后 Google 的 Gboard、Microsoft 的遥测都把 LDP 用于高频聚合；国内大厂的输入法云同步也采用同类「端上加噪」架构。共同点：数据敏感、单体行为不可信、只需要**人群级**统计——LDP 的舒适区。

还有一个值得标注的理论地位：对二值取值，RR 不只是「一个」满足 $\varepsilon$-LDP 的机制，而是**最省方差**的那一个——Kairouz、Bonawitz 与 Rakhlin 在 2014 年证明，任何 $\varepsilon$-LDP 机制估计二值比例的方差都不低于 RR 的去偏方差。换句话说，§5.2 那笔 $1/p^2$ 的方差账不是实现不够好，是信息论的硬底价；多值情形的最优机制家族（直接编码、RAPPOR 的变体）也在这条线的延长线上。

舒适区之外要付价。定量地说效用差距：估计一个比例，**全局 DP** 对均值查询的敏感度是 $1/n$（替换型），噪声标准差按 $1/(\varepsilon n)$ 走；**局部 DP** 的去偏估计方差放大 $1/p^2$，标准差按 $1/(\varepsilon'\sqrt{n})$ 走（$\varepsilon'$ 是把 $p$ 折回 $\varepsilon$ 的常数）。两条标度一比：误差差约 $\sqrt{n}$ 倍，同样精度换算成样本量是**平方级**的差距。$n=10^4$ 时局部比全局的噪声大两个数量级——这就是「不信任聚合者」的市价。所以工程规律是：能信一次聚合者就用全局 DP（配合安全聚合等技术把「看见」缩到最小），实在不能信才上 LDP，并备好一个量级的样本。

**本节小结**：RAPPOR 与 Apple 遥测是 RR 的工业化身；局部模型的误差按 $1/(\varepsilon'\sqrt{n})$ 走、全局按 $1/(\varepsilon n)$ 走，差距约 $\sqrt{n}$ 倍——不信任的代价按样本量的平方计息。

最后澄清一个最容易混的边界：**本地化不等于匿名化**。用户上传的答案经过了随机化，但设备身份、IP、时间戳照样可能跟着走——LDP 只保证「这一比特答案对真值的似然比被封顶」，不承诺「上传者不可追踪」。第 1 章 §1.1 的教训在这里原样成立：保护范围由定义写死的那个对象决定，定义外的通道一概不管。

## $\rm \S \, 5.4$ 数值锚：$n=10000$ 人的去偏实验（程序实跑）

实验是 §5.8 程序的实跑输出。设定：$n=10000$ 人，真实比例 $p_0=0.6$，每人用瞎猜版 RR 上传一个比特；聚合者先看「答 $1$」的观测比例 $\hat q$，再按校正因子还原。固定种子，三档 $\varepsilon$：

| $\varepsilon$ | $p$ | 观测准确率（理论） | 观测准确率（实测） | 观测 $\hat q$ | 去偏 $\hat p_0$ | 偏差 $\hat p_0-p_0$ |
| --- | --- | --- | --- | --- | --- | --- |
| $0.5$ | $0.6225$ | $0.8112$ | $0.8171$ | $0.5588$ | $0.5945$ | $-0.0055$ |
| $1$ | $0.7311$ | $0.8655$ | $0.8679$ | $0.5742$ | $0.6015$ | $+0.0015$ |
| $2$ | $0.8808$ | $0.9404$ | $0.9404$ | $0.5855$ | $0.5971$ | $-0.0029$ |

读法分三层。第一层，**观测比例全体偏低**（$0.5588$ 到 $0.5855$，都在真值 $0.6$ 之下）：$(1-p)/2$ 的底噪把 $\hat q$ 拖向 $0.5$，$\varepsilon$ 越小拖得越狠——不做去偏直接上报 $\hat q$，$0.04$ 上下的系统偏差白送给读者。第二层，**去偏生效**：三个偏差都压在 $\pm 0.006$ 内。对照理论方差：$\varepsilon=0.5$ 时 $\mathrm{sd}(\hat p_0)=\sqrt{\hat q(1-\hat q)/n}/p\approx 0.0080$，偏差 $-0.0055$ 不到一个标准差；$\varepsilon=2$ 时 $\mathrm{sd}\approx 0.0056$，偏差 $-0.0029$ 同样在界内——观察到的偏差就是 $1/p^2$ 方差放大的正常抖动，不是系统误差。第三层，**准确率列是安慰剂**：观测准确率高达 $0.81$ 到 $0.94$ 且随 $\varepsilon$ 上升，但去偏前的信息量由 $\varepsilon$ 钉死——§5.2 的警告在数据里兑现。

> **易混点**：「偏差」（bias，估计量的系统偏移）与「标准差」（$\mathrm{sd}$，抽样抖动）是两个量。去偏估计在期望意义上**无偏**——表里的偏差是单次抽样的抖动，理论保证只有 $\pm 1$ 到 $2$ 个 $\mathrm{sd}$ 之内这一层；要是把表里 $-0.0055$ 读成「去偏也不准」，就把抖动当成了偏移。反过来，$\hat q$ 的 $-0.03$ 到 $-0.04$ 是真的偏差——它不随 $n$ 缩小，去偏是唯一出路。

顺带一题值得当场算：把 $n$ 乘 $4$，$\mathrm{sd}$ 减半——局部 DP 的效用靠 $\sqrt{n}$ 爬行，这就是 §5.3 「样本量平方级差距」的微观机制。

把全局 DP 拉进同一个问题里比价，差距立刻有形状。同一份数据（$n=10^4$ 条 $0$/$1$ 记录），聚合者若可信，直接对**均值**查询（替换型敏感度 $\Delta f=1/n$）上 Laplace 机制：$\varepsilon=0.5$ 时 $b=\Delta f/\varepsilon=2\times 10^{-4}$、标准差 $\sqrt{2}\,b\approx 2.8\times 10^{-4}$——对照局部 DP 去偏估计的 $0.0080$，差约 $28$ 倍；$\varepsilon=2$ 时全局标准差 $7\times 10^{-5}$ 对局部 $0.0056$，差约 $79$ 倍。$\sqrt{n}=100$ 是这些比值的量级骨架，常数随 $\varepsilon$ 缓慢变化。同一道题，信任模型换一档，效用塌一档。

**本节小结**：$n=10^4$ 实测——观测比例带 $0.03$ 到 $0.04$ 的向下偏差，去偏后压进 $\pm 0.006$（与 $1/p^2$ 方差理论吻合）；观测准确率 $0.81$ 到 $0.94$ 与隐私无关。

## $\rm \S \, 5.7$ 本章自测答案

> 先闭卷作答上面两节，再核对。

### $\rm \S \, 5.7.1$ 关键概念回顾答案

1. 量词从「每对相邻数据库 $D\sim D'$」下沉到「每一对取值 ${x,x'}$」——保护对象从库降为单条记录，随机化器逐条工作。LDP 机制通常纯 DP：单记录层面加性豁免没有自然的语义载体（没有「库里其他人」可以分摊），主流机制也用不上高斯的两面性。去偏不花预算：它是观测答案上的确定性映射，按第 3 章 §3.1 后处理不变性，隐私在掷硬币出口已结清。（§5.1、§5.2）

一个自测标准：如果只能带走本章一句话，带走「量词下沉」——全局模型里机制面对的是相邻库的差，局部模型里机制面对的是两个人的真值之别；前者允许噪声在库层面集中，后者注定噪声在人层面分散，效用差距的所有账都从这一个字眼里长出来。
2. $\Pr[R(x)=1]=p\cdot x+(1-p)(1-x)$（以 $p$ 如实、以 $1-p$ 翻转），$\varepsilon=\ln\frac{p}{1-p}$。证明：$\Pr[R(1)=1]/\Pr[R(0)=1]=p/(1-p)=\mathrm{e}^{\varepsilon}$，反向 $\Pr[R(1)=0]/\Pr[R(0)=0]=(1-p)/p=\mathrm{e}^{-\varepsilon}\le\mathrm{e}^{\varepsilon}$，两个单点事件封顶即一切事件封顶。瞎猜版答对概率：如实的 $p$ 加上乱答时撞对的 $(1-p)/2$，合计 $(1+p)/2$。（§5.2）
3. 全概率：$\mathbb{E}[\hat q]=(1-p+2p_0p)/2$，移项解出 $\hat p_0=(2\hat q-1+p)/(2p)$——减底噪 $(1-p)/2$、除信号增益 $p$。方差 $\hat q(1-\hat q)/(np^2)$，比直接观测真比例（方差 $p_0(1-p_0)/n$）放大 $1/p^2$ 量级；$\varepsilon\to 0$ 时 $p\to 1/2$，放大因子趋向 $4$ 的同时底噪拖拽最狠，实际更糟——这就是「最大隐私档位下统计几乎不可用」的定量形状。（§5.2）

### $\rm \S \, 5.7.2$ 应用与辨析答案

1. $\varepsilon=1$：$p=0.7311$，$\mathrm{sd}(\hat p_0)=\sqrt{\hat q(1-\hat q)/n}/p$；取 $n=10^4$、$\hat q\approx 0.46$（$10\%$ 真值经底噪拖向 $0.5$）得 $\mathrm{sd}\approx 0.0095$，对真值 $0.1$ 的相对误差约 $10\%$——量级勉强可用。真实比例 $1\%$ 时 $\hat q\approx 0.435$、$\mathrm{sd}$ 差不多仍是 $0.0095$，相对误差涨到 $95\%$——估计值 $0.1\pm 0.01$ 的抖动就能把 $1\%$ 淹没。结论：RR 适合估计**不稀有**的比例（大致 $\gtrsim 1/\sqrt{n}$），稀有事件的估计要靠「分桶＋更高 $\varepsilon$」或换全局 DP。（§5.2、§5.4）

补充一个实践直觉：稀有比例估计差，不是因为去偏公式错了，而是因为信号（$p_0$ 与 $1/2$ 的距离）天生就小、而噪声地板（$\mathrm{sd}$ 由 $\hat q$ 附近的二项方差决定）不跟着变小——信噪比崩了。任何「先加噪、再校正」的架构都逃不掉这条信噪比账，它与具体机制无关。
2. 错在「独立」：第二份答案与第一份共享同一个真值，聚合者把两个答案联看，对真值的似然比是单份的平方——$\varepsilon$ 翻倍（隐私账单从 $\varepsilon$ 变 $2\varepsilon$），换来的精度增益远抵不上（方差只降一半）。而对**这个人**的推断能力确实变强了：两份独立噪声同时指向同一真值的概率，比单份大得多。正确姿势是每人每真值只上传一份；要提精度，加人（$\sqrt{n}$）或调 $\varepsilon$，不加份。（§5.2）
3. 最坏情况口径下，合成按**全部查询**记账：一个功能花的 $\varepsilon$ 与其他功能花在同一个人身上的是累加的。分组是把总预算按敏感度切开分配——emoji 统计可以给宽松的 $\varepsilon$、浏览记录给严格的。共用一个最大 $\varepsilon$ 错在两处：低敏感功能白白享受高预算、拉高总账；而真正敏感的功能若预算不足，要么超支要么闭麦——分组至少让每一分预算花在被审计的用途上。分组之间照样要合成（同一个人的多个上传对同一个真值是多次查询），分组的正确读法是「先分账、再各自扣」，不是「各花各的、互不相干」。（§5.1）

## $\rm \S \, 5.8$ 可当场复跑的程序段

§5.4 表格的原始出处。纯标准库，`random.seed(11)` 固定种子：

```python
 # 随机化响应（瞎猜版）：观测、去偏与偏差（纯 Python）
import math, random

random.seed(11)
n, p0 = 10000, 0.6

print("eps   p(truth)  acc_th   acc_emp   obs_yes   debiased  bias")
for eps in (0.5, 1.0, 2.0):
    p = math.exp(eps) / (1.0 + math.exp(eps))     # 如实概率，eps = ln(p/(1-p))
    yes = acc = 0
    for _ in range(n):
        true = 1 if random.random() < p0 else 0
        ans = true if random.random() < p else random.randint(0, 1)
        yes += ans
        acc += (ans == true)
    q = yes / n
    phat = (2.0 * q - 1.0 + p) / (2.0 * p)        # 校正因子：减底噪、除增益
    print(f"{eps:<5} {p:.4f}    {(1.0+p)/2:.4f}   {acc/n:.4f}    {q:.4f}    {phat:.4f}   {phat-p0:+.4f}")
```

在本机（Python 3.12）输出：

```text
eps   p(truth)  acc_th   acc_emp   obs_yes   debiased  bias
0.5   0.6225    0.8112   0.8171    0.5588    0.5945   -0.0055
1.0   0.7311    0.8655   0.8679    0.5742    0.6015   +0.0015
2.0   0.8808    0.9404   0.9404    0.5855    0.5971   -0.0029
```

读法：程序主体是 §5.2 的逐行翻译——`ans = true if ... else random.randint(0, 1)` 是瞎猜版机制，`phat = (2*q - 1 + p)/(2*p)` 是校正因子。`acc_th` 列是理论观测准确率 $(1+p)/2$（§5.2 数值锚原样出现），`acc_emp` 列是 $n=10^4$ 次实测——两者差在 $0.006$ 以内，大数定律的现场办公。想换翻转版做对照，只需把 `else random.randint(0, 1)` 改成 `else 1 - true`，观测准确率会掉到 $p$ 列、去偏公式改成 $\hat p_0=(\hat q-(1-p))/(2p-1)$——§5.2 两变体同 $\varepsilon$ 的论断在代码里也只差一行。把 `p0` 换成任何想估的比例、`n` 调大调小，可以直接复现 §5.4 的三个读数层次。

**本节小结**：二十行程序同时担任机制演示（逐人掷硬币）、理论对账（准确率理论对实测）与工程模板（换 $p_0$、换 $n$ 即用）。

## $\rm \S \, 5.9$ 带走清单

1. 局部 DP：量词下沉到「每一对取值」，随机化器逐记录工作、通常纯 DP；聚合者只见噪声答案，其后一切加工免费（后处理不变性）。
2. RR 翻转版：$\Pr[R(x)=1]=px+(1-p)(1-x)$，$\varepsilon=\ln\frac{p}{1-p}$；两行比值证明，Warner 1965。
3. 瞎猜版变体：观测准确率 $(1+p)/2$——$\varepsilon=0.5/1/2$ 对应 $0.8112/0.8655/0.9404$；同一 $\varepsilon$，准确率是安慰剂，隐私在似然比里。
4. 去偏：$\hat p_0=(2\hat q-1+p)/(2p)$，免费（后处理）；方差放大 $1/p^2$，$\varepsilon$ 越小越狠。
5. 数值锚：$n=10^4$、$p_0=0.6$——观测 $\hat q$ 偏低 $0.014$ 到 $0.041$，去偏后偏差 $\pm 0.006$ 内且与 $\mathrm{sd}\approx\sqrt{\hat q(1-\hat q)/n}/p$ 吻合。
6. 效用差距：局部误差按 $1/(\varepsilon'\sqrt{n})$、全局按 $1/(\varepsilon n)$，差约 $\sqrt{n}$ 倍、样本量平方级；RAPPOR（布隆＋逐位随机化）与 Apple 遥测是工业化身。
