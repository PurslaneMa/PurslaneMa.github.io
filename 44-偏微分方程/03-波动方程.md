# $\rm Chapter \, 3$ 波动方程：d'Alembert 与能量法

波动方程是双曲型的原型：扰动以有限速度 $c$ 搬运，过去的信息永远在路上。它与热方程是性格的两个极端——一个抹平、一个搬运。本章推出方程、全证 d'Alembert 公式、用能量法钉死唯一性，最后把两章的性格对照表并排摆好。

## $\rm \S \, 3.1$ 弦振动方程的推导

张紧的弦（线密度 $\rho$、张力 $T$）做横振动，位移 $u(x, t)$。小振动假设下斜率 $u_x \ll 1$。取微元 $[x, x + \mathrm{d}x]$：竖向合力 $= T\, u_x\big|_{x+\mathrm{d}x} - T\, u_x\big|_x \approx T\, u_{xx}\, \mathrm{d}x$（张力沿弦向，竖向分量 $\approx T u_x$）。Newton 第二定律：$\rho\, \mathrm{d}x\, u_{tt} = T\, u_{xx}\, \mathrm{d}x$：

$$
u_{tt} = c^2\, u_{xx}, \qquad c = \sqrt{T/\rho}
$$

**读法**：$c$ 是波速——绷得越紧（$T$ 大）、弦越轻（$\rho$ 小），波跑得越快。与热方程对照：**二阶时间导**换掉了**一阶**，这一字之差改写了全部性格。

## $\rm \S \, 3.2$ d'Alembert 公式（本章主证）

**定理 3.1**（d'Alembert, 1747）。初值问题 $u_{tt} = c^2 u_{xx}$，$u(x, 0) = f(x)$、$u_t(x, 0) = g(x)$，在 $c$ 常数、全直线情形的解是

$$
u(x, t) = \frac{f(x + ct) + f(x - ct)}{2} + \frac{1}{2c} \int_{x - ct}^{x + ct} g(s)\, \mathrm{d}s
$$

**证明**（换元对角化，逐步写）。令 $\xi = x + ct$、$\eta = x - ct$，即 $x = \frac{\xi + \eta}{2}$、$t = \frac{\xi - \eta}{2c}$。链式法则：

$$
\partial_x = \partial_\xi + \partial_\eta, \qquad \partial_t = c\,(\partial_\xi - \partial_\eta)
$$

于是

$$
u_{tt} - c^2 u_{xx} = c^2\big[(\partial_\xi - \partial_\eta)^2 - (\partial_\xi + \partial_\eta)^2\big] u = -4c^2\, u_{\xi\eta}
$$

方程 $u_{tt} = c^2 u_{xx}$ 变成 $u_{\xi\eta} = 0$——**先对 $\eta$ 积分得 $u_\xi = \Phi(\xi)$，再对 $\xi$ 积分得 $u = F(\xi) + G(\eta)$**：通解是「右行波 $F(x + ct)$ ＋ 左行波 $G(x - ct)$」。代初值定 ${F, G}$：$t = 0$ 时 $F(x) + G(x) = f(x)$、$c(F'(x) - G'(x)) = g(x)$。第一式求导、联立第二式解出 $F'(x) = \frac{1}{2}f'(x) + \frac{g(x)}{2c}$、$G'(x) = \frac{1}{2}f'(x) - \frac{g(x)}{2c}$，积分并代入即得公式。$\blacksquare$

**数值锚**（本机实测）：$c = 1$、$f = \sin$、$g = 0$ 时 $u(1, 1) = \frac{\sin 2 + \sin 0}{2} = \cos 1 \cdot \sin 1 = 0.45464871341284085$——d'Alembert 与 $u = \cos t \sin x$（分离变量解）逐位一致。

**读法**：d'Alembert 把解拆成两列对开的行波，公式里的 $\frac{f(x \pm ct)}{2}$ 是「初值剖面的两半各跑各路」，积分项是「初速度的累积搬运」。通解都写出来了——这在 PDE 世界是稀罕待遇（第 1 章 §1.1 说过），归功于换元后 $u_{\xi\eta} = 0$ 的彻底退化：**双曲型的实特征线（$\xi, \eta$ 两族）把方程拆平了**——这正是 §1.2 判别式分类预言的事。

## $\rm \S \, 3.3$ 依赖域、影响区与两章对照表

d'Alembert 公式里，$u(x, t)$ 只依赖 $[x - ct,\ x + ct]$ 上的初值——这段区间叫点 $(x, t)$ 的**依赖域**；反过来，初值点 $s$ 的影响局限在锥形 $|x - s| \le ct$ 内——**影响区**。信息以有限速度 $c$ 搬运，锥外的事件与此刻此点无关。

与第 2 章并排摆好：

| | 热方程（抛物） | 波动方程（双曲） |
| --- | --- | --- |
| 时间导数 | 一阶 | 二阶 |
| 传播速度 | 无穷（§2.3 悖论） | 有限（$c$，锥形影响区） |
| 平滑性 | $t > 0$ 立刻无穷光滑（热核糊脸） | 初值多光滑解多光滑，不白送 |
| 最大值原理 | 成立（§2.4） | 不成立（内部可造新最值） |
| 长期归宿 | 边界撑起的稳态 | 能量守恒，永远振下去 |
| 可逆性 | 反向不适定（§1.4） | 时间反演对称（$t \mapsto -t$ 方程不变） |

**读法**：这张表是「扩散 vs 搬运」的全卷对照——从数值格式（第 6 章）到物理直觉，每一条都会回来。

## $\rm \S \, 3.4$ 能量法与唯一性（本章主证二）

定义能量

$$
E(t) = \frac{1}{2} \int_{\mathbb{R}} \big( u_t^2 + c^2 u_x^2 \big)\, \mathrm{d}x
$$

**定理 3.2**（能量守恒）。对衰减足够的解，$E(t) = E(0)$。

**证明**。求导并分部积分：

$$
E'(t) = \int (u_t u_{tt} + c^2 u_x u_{xt})\, \mathrm{d}x = \int u_t (u_{tt} - c^2 u_{xx})\, \mathrm{d}x + \Big[ c^2 u_t u_x \Big]_{-\infty}^{\infty} = 0
$$

（第一项用方程 $u_{tt} = c^2 u_{xx}$ 归零；边界项由衰减假设归零。）$\blacksquare$

**唯一性**（全证）。设 $u_1, u_2$ 同初值同方程，差 $w = u_1 - u_2$ 满足波动方程且初始能量 $E_w(0) = 0$（$w(x, 0) = 0 \Rightarrow w_x(x, 0) = 0$；$w_t(x, 0) = 0$）。由守恒 $E_w(t) = 0$ 对一切 $t$，而被积函数非负 ⟹ $w_t = w_x = 0$ 处处 ⟹ $w$ 常数 ⟹ 由 $w(x, 0) = 0$ 得 $w = 0$。$\blacksquare$

**读法**：能量法是双曲世界的「守恒式常识」——能量不生不灭，两个解的差没有能量，只能是零。注意它与热方程的唯一性证明（最大值原理，§2.4）气质完全不同：那边靠「常识压制」，这边靠「守恒清账」。连续依赖（适定性第三件）双曲侧要用能量不等式 $E(t) \le C E(0)$ 的变形，陈述级，标 Evans §2.4。

## $\rm \S \, 3.5$ 数值一瞥：CFL 的物理来源

显式差分格式（第 6 章细讲）里，波在一个时间步 $\Delta t$ 内跑过的距离 $c\, \Delta t$ 不能超过一个网格间距 $\Delta x$——否则数值信息来不及送达，格式必炸。这就是 **CFL 条件** $c\, \Delta t \le \Delta x$ 的物理读法：**数值依赖域必须罩住真实依赖域**。数值锚（第 6 章复用，本机已验）：放大因子 $g(\theta) = 1 - 4r \sin^2(\theta/2)$（$r = c^2 \Delta t^2 / \Delta x^2$），$r \le 1$ 时 $|g| \le 1$ 稳定，$r = 0.51$ 时 $\max|g| = 1.04$、$r = 0.6$ 时 $1.40$——越界即爆。

## $\rm \S \, 3.7$ 本章自测答案

1. 张力 $T$、线密度 $\rho$，$c$ 是波速。（§3.1）
2. 变成 $u_{\xi\eta} = 0$；通解 $F(x + ct) + G(x - ct)$——右行波＋左行波。（§3.2）
3. $\frac{f(x \pm ct)}{2}$ 搬运初值剖面，$\frac{1}{2c}\int g$ 搬运初速度的累积。（§3.2）
4. $u(x,t)$ 只依赖 $[x - ct, x + ct]$ 上的初值；初值点 $s$ 影响锥 $|x - s| \le ct$。热方程依赖域是全直线（无穷传播）。（§3.3）
5. $u_t^2$ 是动能密度、$c^2 u_x^2$ 是势能密度；守恒靠方程＋分部积分＋衰减边界项。（§3.4）
6. 数值依赖域必须罩住真实依赖域：$c\, \Delta t \le \Delta x$，否则格式不稳定。（§3.5）
