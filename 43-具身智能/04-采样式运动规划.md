# $\rm Chapter \, 4$ 采样式运动规划

前三章把「怎么动」拆成了三层：第 1 章给了描述刚体位姿的语言 $\mathrm{SE}(3)$，第 2 章回答「我在哪」（贝叶斯滤波把带噪声的传感器读数炼成状态估计），第 3 章回答「该施加什么力」（LQR 与 MPC 在动力学已知时算出最优控制序列）。但那三层都有一个没明说的前提：目标位形已经给定，而且默认存在一条过得去的路。这一章补上更前面的那一环——从「我在哪」到「我要去哪」之间，路本身得先被找出来。机械臂要从当前关节角摆到抓取位姿，中间隔着六个关节角的位形空间和一堆不能碰的障碍物；这条路几乎从来没有闭式解，只能在位形空间里现场搜。暴力的做法是铺网格再图搜索，而网格在高维按指数爆炸。采样式运动规划（sampling-based motion planning）的答案是：不在整个空间上铺砖，只撒一把随机样本，让连通性自己浮现出来。本章讲两个代表——PRM 与 RRT——然后把主要篇幅花在 RRT\* 上：一次改动极小的重接线（rewiring），为什么能把「快而次优」变成「越跑越接近最优」。

> 1. □ 正运动学是「关节角到位姿」的单向映射：位姿由关节角唯一决定，反之不然（$\S 1.2$）；
> 2. □ 自由度计数：$n$ 个关节的机械臂，其位形空间是 $n$ 维的（$\S 1.3$）；

## $\rm \S \, 4.1$ 规划在问什么：位形空间里的无碰撞通路

白话：运动规划问的是「从 A 到 B，有没有一条不撞墙的路」——但 A、B 和墙都要先说清楚住在哪个空间里。这个空间不是机器人身体所占的物理空间，而是位形空间（configuration space，记号 $\mathcal{C}$）：把机器人每一维自由度各取一个值，拼成一个向量。平面移动机器人的 $\mathcal{C}$ 是 $(x,y)$ 二维；六轴机械臂的 $\mathcal{C}$ 是六个关节角拼成的六维空间（转动关节的角度还要按 $2\pi$ 粘合周期性，此处不纠结）。规划的全部戏都在 $\mathcal{C}$ 里演。

$\mathcal{C}$ 与工作空间（workspace，身体所在的物理空间）的分工要掰清楚。工作空间里的障碍物是墙、桌子、人；把它们映射进 $\mathcal{C}$ 后变成 $\mathcal{C}$ 障碍（$\mathcal{C}$-obstacle）区域 $\mathcal{C}_{\mathrm{obs}}$——所有会撞的位形之并。映射是单向的：一个位形唯一确定身体占哪块物理空间，所以「位形 $\notin \mathcal{C}_{\mathrm{obs}}$」与「身体不撞任何东西」是同一句话的两种说法。反过来不成立：同一只手掌位置可以对应许多组关节角（冗余），所以在工作空间里规划根本没法给关节电机下指令。平面平移机器人是唯一能偷懒的：它的两个空间刚好重合。机械臂不行——六轴臂的工作空间是三维，位形空间是六维，在三维里画得通的通路换算回六维可能四分五裂。真正的地图是 $\mathcal{C}$；机械臂的地图，就是关节角空间。

于是规划问题的严格表述只有一行：给定 $q_{\mathrm{start}}, q_{\mathrm{goal}} \in \mathcal{C}_{\mathrm{free}} = \mathcal{C} \setminus \mathcal{C}_{\mathrm{obs}}$，找一条连续映射 $\sigma : [0,1] \to \mathcal{C}_{\mathrm{free}}$，满足 $\sigma(0) = q_{\mathrm{start}}$、$\sigma(1) = q_{\mathrm{goal}}$；若还要求 $\sigma$ 的长度（或更一般的代价泛函）最小，就是最优规划。读法：$\sigma$ 是一串无限密的位形序列，「不撞墙」被编码成值域落在 $\mathcal{C}_{\mathrm{free}}$ 里，「从 A 到 B」被编码成两个端点约束。

为什么需要采样？最朴素的算法是把 $\mathcal{C}$ 铺成每边 $k$ 格的网格再做图搜索。格点数是 $k^d$，$d$ 是维数：$d=2$ 时 $k=100$ 只有一万个格子；$d=6$ 时同样分辨率是一万亿个；$d=12$（双臂）直接超出任何内存的容量。这不是工程常数没调好，而是指数的数学本性——39 册 $\S 3.5$ 讲过近邻搜索在高维的塌缩，此处是同一诅咒撞上图搜索：格点数对维数指数增长，任何「先离散化再搜索」的方法都逃不掉这份账。还有一层更隐蔽的困难：即使格点数管得起，$k$ 有限意味着通路必须宽过格距才找得到，而门缝、缝隙的宽度是连续量，固定分辨率在它们面前永远可能恰好错过。所以路线只有一条：放弃穷举，靠随机采样「按需」探索空间。这就是本章的主角。

本节小结：规划问题在位形空间 $\mathcal{C}$ 里陈述（A 到 B 的无碰撞连续通路），工作空间只是身体的家；网格离散化在高维按 $k^d$ 爆炸，逼出了采样式方法。

## $\rm \S \, 4.2$ 概率路线图 PRM：先修路网，再查导航

白话：概率路线图（probabilistic roadmap，PRM；Kavraki, Švestka, Latombe & Overmars 1996，LaValle 2006 $\S 5.6$）的思路像修公路网——规划不止单次、查询成千上万次时，先花一大笔钱把路网修好存起来，之后每次出行只查图。它是「多次查询」（multiple-query）方法的代表。

PRM 分两个阶段。1. **学习阶段**：在 $\mathcal{C}_{\mathrm{free}}$ 里独立均匀撒 $N$ 个样本（落进 $\mathcal{C}_{\mathrm{obs}}$ 的丢弃），每个样本与近邻试连直边，边通过碰撞检查（机械臂上就是把沿边的位形离散化、逐个送进正运动学查碰撞）就保留；样本与合法边构成一个图 $G$，即路线图，存下来复用。2. **查询阶段**：来了一对新的起终点，先用短边把它们各自接进 $G$（接不上就补采样），然后在 $G$ 上跑 Dijkstra 或 A\*，输出的图路径换算回 $\mathcal{C}$ 里的折线就是解。

这套方法成立，靠一个概率保证：采样越密，路线图越能忠实反映 $\mathcal{C}_{\mathrm{free}}$ 的连通结构。直觉版论证：$\mathcal{C}_{\mathrm{free}}$ 里任何一条够宽的通路 $\sigma$ 都带着一个正体积的「管道」邻域；$N$ 个独立均匀样本全躲开这条管道的概率是 $\left(1 - \mu(V)/\mu(\mathcal{C})\right)^{N}$，随 $N$ 指数衰减到零（$\mu$ 是体积测度，$V$ 是管道的体积）。读法：只要通路是「胖」的，撒点总会掉进管道里几个，掉进去的样本经近邻相连，就把通路离散化地重建出来。所以 PRM 是概率完备（probabilistically complete）的：若解存在且不太瘦，$N \to \infty$ 时找到解的概率趋于 1。注意措辞——「瘦到零宽」的通路（精确穿过缝隙的解）不在保证范围内，这是所有采样方法的共同软肋。

PRM 与本章后半主角的分野在「图 vs 树」：PRM 建无向图、一次投入长期复用；RRT 建有向树、单次查询现场生长。当规划是一次性的（机械臂抓一下放一下，路径每次都不同），学习阶段的固定开销摊不薄，单查询的树方法更划算——这正是 RRT 登场的舞台。

本节小结：PRM 学习阶段撒点建图、查询阶段图上找路；连通性由「样本密度足够则胖通路必被穿过」的概率论证兜底；一次性查询的场景轮到树方法。

## $\rm \S \, 4.3$ RRT：两行算法与 Voronoi 偏置

白话：快速探索随机树（rapidly-exploring random tree，RRT）是一棵从起点往外疯长的树，每一步只做两件事——在空间里随机撒一个点，找到树上离它最近的已有顶点，朝它挪一小步。就这两行，树却自己学会了「往没去过的地方长」。

先把算法写下来（LaValle 1998 的技术报告首次提出，教科书版见 LaValle 2006 $\S 5.5$）。维护树 $T = (V, E)$，根为 $q_{\mathrm{start}}$，步长上限 $\eta$；每轮迭代：

1. 撒随机样本 $s \sim \mathrm{Unif}(\mathcal{C})$；
2. 找最近邻 $v = \operatorname*{arg\,min}_{u \in V} \lVert u - s \rVert$，取新点 $v_{\mathrm{new}} = v + \min(\eta, \lVert s - v \rVert) \cdot \dfrac{s - v}{\lVert s - v \rVert}$；
3. 若边 $(v, v_{\mathrm{new}})$ 不撞障碍，把 $v_{\mathrm{new}}$ 与这条边加进树。

第 2 行是全部魔法所在：$s$ 只是诱饵，真正入树的是从最近顶点 $v$ 朝 $s$ 方向走的一小步——$s$ 本身从不入树。

为什么这棵树偏爱空旷地带？答案是 Voronoi 偏置（Voronoi bias）。把空间剖成 $|V|$ 个 Voronoi 区域：顶点 $u$ 的区域是所有「离 $u$ 比离其他任何顶点都近」的点之并。第 2 步的最近邻查询，等价于问「随机点 $s$ 落在哪个顶点的 Voronoi 区域里」——回答是：$s$ 所在区域的那个顶点被选中、朝 $s$ 长一步。于是每个顶点每轮被选中的概率，恰好等于它的 Voronoi 区域占总面积的份额。现在看生长的动力学：一个顶点周围同类顶点越稀少，它的 Voronoi 区域越大，被选中的概率越高，树就越往那扩张。未开发的空旷地界上顶点稀疏、单个顶点坐拥大片区域，概率自动把新枝导向那里；挤挤挨挨的旧地盘上每个顶点的份额被摊薄，几乎不再被眷顾。这就是「快速探索」四个字的机制内核：探索的优先级不靠任何启发式表，而是 Voronoi 面积的份额自己算出来的——密度低处自动权重高，像水往低处流。这个偏置还自带刹车：新顶点落进空地，就把原来的大区切走一块，哪里最空、哪里被切得最快；空地填满后各区面积趋于均匀，偏置自然消退，树从「向外探索」转入「均匀加密」。对照组最能说明问题：若改成「随机挑一个顶点、朝随机方向走一步」，每个顶点被选中的概率都是 $1/n$，与它周围空不空毫无关系，而大多数顶点挤在根附近，树就长成原地打转的一丛灌木。$\S 4.5$ 表二把两者的差距量成了一个数量级。

代价是「快而次优」。RRT 的保证只有一条：概率完备——若解存在，找到解的概率随迭代数趋于 1（LaValle & Kuffner 2001）。它对解的质量一言不发，而且机制本身就在跟最优性作对：树一旦到达目标，第一次找到的通路就被冻结了——之后的随机点大多被 Voronoi 份额送往未开发区域，已有的树枝几乎不再被触碰，没有任何机制回头缩短它。新顶点偶尔落进目标邻域，它的祖先链同样是一串「当时谁最近」的偶然决定，曲折程度并不更好。Karaman 与 Frazzoli（2011）把这件事证成了定理：RRT 的最优代价几乎必然收敛到一个严格大于最优值的数。$\S 4.5$ 的实验会把这个「平台期」直接量出来。要打破冻结，得让树在长新枝的同时允许动旧枝——这正是 RRT\* 做的事。

本节小结：RRT = 最近邻加步进的两行循环；最近邻查询使每个顶点的被选概率等于其 Voronoi 份额，稀疏处自动获得高权重，树冠线性铺开；机制保证快（概率完备），但旧枝冻结、次优。

## $\rm \S \, 4.4$ RRT\*：重接线与渐近最优

白话：RRT\* 与 RRT 的唯一区别是，新枝接入时不只问「谁离我最近」，而是问「邻居里谁让我最便宜」，并且反过来检查「我能不能当邻居们的便宜爹」。前者叫选父（choose parent），后者叫重接线（rewire）。两处小改，让树从一坨乱毛线逐渐梳成近似最短路径树。

先补一个概念。树上从根到 $v$ 的路径长度记 $c(v)$（代价，二维取欧氏长度）。RRT 里 $c(v_{\mathrm{new}}) = c(v) + \lVert v_{\mathrm{new}} - v \rVert$ 被父节点锁死；RRT\* 在同一轮迭代里多做两个局部优化：

1. **选父**：新点 $v_{\mathrm{new}}$ 生成后，在半径 $r_n$ 的邻域 $X_{\mathrm{near}} = \{u \in V : \lVert u - v_{\mathrm{new}} \rVert \le r_n\}$ 内挑 $\operatorname*{arg\,min}_{u} \left[ c(u) + \lVert u - v_{\mathrm{new}} \rVert \right]$ 当父亲，而不是无脑认最近邻；
2. **重接线**：把 $v_{\mathrm{new}}$ 挂上之后，对每个邻居 $u$ 检查 $c(v_{\mathrm{new}}) + \lVert v_{\mathrm{new}} - u \rVert < c(u)$ 是否成立；成立就把 $u$ 的父亲改成 $v_{\mathrm{new}}$（$u$ 的整条子树跟着搬家，不会成环——$v_{\mathrm{new}}$ 是本轮新生的点，不可能是 $u$ 的祖先），不成立则不动。

两个动作都是「三角不等式套利」：三点之间，两段折线若比现有一段直线加子路径便宜，就换。选父让新枝从最便宜的邻居接入，重接线让老枝跟着新枝沾光；每轮迭代都在局部做无后效的贪心改善，而这些局部改善叠加的效果，是整棵树随样本增长逐步逼近「以起点为根、在 $\mathcal{C}_{\mathrm{free}}$ 里取道最短」的最优树。打个比方：RRT 长成一片「谁先到谁占坑」的原始丛林，枝杈路线是历史的偶然；RRT\* 每来一个新样本就把周围一圈枝杈重新梳理一遍，偶然性被一遍遍熨平。$\S 4.5$ 实验里 RRT\* 的路径长度随 $n$ 持续下降、RRT 早早躺平，就是这两行代码的账面效果。

为什么重接线让树越来越像最优树？先换一个看法。把「两点相距不超过 $r_n$ 且连线无碰撞就连边」得到的图记作随机几何图 $G_n$，它的单源最短路树就是此刻能指望的最好的树。最短路算法（Dijkstra、Bellman–Ford）只靠一个动作：松弛（relaxation），即检查「经 $u$ 到 $w$ 是否比 $w$ 现在的代价便宜」，便宜就改。对照着读：选父是对 $v_{\mathrm{new}}$ 的全部入边做松弛，重接线是对它的全部出边做松弛。所以 RRT\* 是在随机几何图上「边建图边跑」的增量最短路，每条边在它较年轻的端点出生那一刻被双向松弛一次。差别在于它只松弛这一轮，不像 Dijkstra 那样把改善一路传遍全图：$u$ 改认新父后整棵子树的代价同步下调（代码里那段栈循环），但 $u$ 的其他邻居不会被再查一遍。所以是「越来越像」而不是「就是」；好在每个已有顶点的代价只降不升，树不会来回抖动。

Karaman 与 Frazzoli 2011（International Journal of Robotics Research 30 卷 7 期，«Sampling-based Algorithms for Optimal Motion Planning»）证明的渐近最优性（asymptotic optimality）说：几乎必然地，RRT\* 返回解的代价收敛到最优代价 $c^{*}$，

$$
\Pr\!\left[\lim_{n \to \infty} c_n = c^{*}\right] = 1
$$

读法：$c_n$ 是有 $n$ 个顶点时树上经目标邻域的最好代价，$c^{*}$ 是 $\mathcal{C}_{\mathrm{free}}$ 里真最短路的代价；「几乎必然」（almost surely）是概率论里的强说法——不收敛这一事件的概率为零，不是「大概率收敛」。它只说极限，不说速度。

最优性从哪来？用「一串小球」的论证看主干：

1. 取最优路径 $\sigma^{*}$，假设它能被稍胖一点的无碰撞路径以任意小的代价差逼近（KF 2011 称为鲁棒最优；本章实验里贴着墙角的最短折线就属于这类）；
2. 沿 $\sigma^{*}$ 摆一串半径与 $r_n$ 成比例的小球，相邻球心足够近，保证前一个球里任一点与后一个球里任一点相距不超过 $r_n$；
3. 若每个球里都至少有一个顶点，这些顶点依次互为邻居，松弛动作保证树上代价不超过沿它们跳跃的折线长；球越小折线越贴 $\sigma^{*}$，$r_n \to 0$ 时折线长趋于 $c^{*}$；
4. 剩下只有一个问题：每个球都非空的概率。半径公式就是为这一步定制的。

（严格证明还要处理「只松弛一轮」带来的代价过期，KF 2011 正文为此花了大量篇幅，这里只讲主干。）RRT\* 取

$$
r_n = \min\left\{ \gamma \left( \frac{\log n}{n} \right)^{1/d},\ \eta \right\},\qquad \gamma > 2\left(1+\frac{1}{d}\right)^{1/d}\left(\frac{\mu(\mathcal{C}_{\mathrm{free}})}{\zeta_d}\right)^{1/d}
$$

读法：$n$ 是当前顶点数，$d$ 是位形空间维数，$\eta$ 是步长上限（早期半径不超过一步），$\zeta_d$ 是 $d$ 维单位球的体积（$\zeta_2 = \pi$），$\mu(\mathcal{C}_{\mathrm{free}})$ 是自由空间体积；$\gamma$ 的下界是 KF 2011 给出的门槛。拿第 4 步来读它：单个小球体积正比于 $r_n^d$，$n$ 个均匀样本全躲开它的概率约为 $\exp(-c\, n r_n^d)$（$c$ 是与球的相对大小有关的常数），代入 $r_n^d = \gamma^d \log n / n$ 得 $n^{-c\gamma^d}$。沿路径要摆的球数约正比于 $1/r_n$，只是多项式级增长；$\gamma$ 够大时 $n^{-c\gamma^d}$ 衰减得比球数增长快，联合界（union bound）给出「至少一个球空着」的概率趋于零。于是两个因子各有分工：$(1/n)^{1/d}$ 是几何项，$n$ 个样本撒在 $d$ 维空间里，近邻间距的典型尺度就是 $n^{-1/d}$；$\log n$ 是保险，若半径只取 $n^{-1/d}$，每个球里的期望样本数是常数，空球概率不随 $n$ 下降而球数还在涨，链条迟早断在某处。换成邻居数读更直观：

$$
\mathbb{E}\,\lvert X_{\mathrm{near}}\rvert \approx n \cdot \frac{\zeta_d\, r_n^{d}}{\mu(\mathcal{C}_{\mathrm{free}})} = \frac{\gamma^{d}\zeta_d}{\mu(\mathcal{C}_{\mathrm{free}})}\log n
$$

读法：球体积占自由空间的比例乘上 $n$，就是球里的期望样本数。$\gamma$ 恰取下界时系数等于 $2^d(1+1/d)$，二维即 $6\log n$——本章实验在 $n = 8000$ 时约 54 个（不计边界与障碍的折损）。三种取法一对照：常数个邻居，链条会断，收敛到次优；$\log n$ 个邻居，每轮 $O(\log n)$ 次检查，全程 $O(n\log n)$，与 RRT 同一量级；$\Theta(n)$ 个邻居，正确但每步扫全树，全程 $O(n^2)$。指数上的 $1/d$ 又是维数诅咒的回音：维数越高，要装下同样多的邻居，$\gamma$ 越大、半径收缩越慢。

Informed RRT\*（Gammell, Srinivasa & Barfoot 2014）一句话：找到代价为 $c_{\mathrm{best}}$ 的第一条通路后，能改进它的点必满足 ${\lVert x - q_{\mathrm{start}} Vert + \lVert x - q_{\mathrm{goal}} Vert \le c_{\mathrm{best}}}$，即落在以起终点为焦点的椭球里，于是只在椭球内采样——机制原封不动，只是同样的收敛游戏在更小的有效体积里跑，收敛显著加速。

本节小结：RRT\* = RRT ＋选父＋重接线，两处三角不等式套利让总代价单调下降；RRT\* 是随机几何图上只松弛一轮的增量最短路；沿最优路径的小球链全部非空，就有贴近最优的折线可走，而 $\gamma(\log n/n)^{1/d}$ 正是让小球链几乎必然非空、邻居数又只涨到 $\log n$ 的半径。

## $\rm \S \, 4.5$ 数值实证：mini-RRT 与 mini-RRT\* 对账

纸上谈兵到此为止，把两行算法真的跑起来。实验设置：$10 \times 10$ 的二维方形世界，两堵矩形墙 $\mathcal{O}_1 = [-1,7] \times [3,4]$（从左墙伸出，缺口在右）、$\mathcal{O}_2 = [3,11] \times [6,7]$（从右墙伸出，缺口在左），墙体故意伸出边界，杜绝贴着场地边缘漏缝，起点 $(1,1)$、终点 $(9,9)$，步长 $\eta = 1$，目标半径 $0.5$。真最短路可手算：绕 $\mathcal{O}_1$ 右下角 $(7,3)$ 与右上角 $(7,4)$、再绕 $\mathcal{O}_2$ 左下角 $(3,6)$ 与左上角 $(3,7)$ 的折线，长度 $\sqrt{40} + 1 + \sqrt{20} + 1 + \sqrt{40} \approx 19.121$。代码在 $\S 4.8$，纯 Python 标准库、固定种子、单文件可复跑；RRT\* 的 $\gamma$ 取 Karaman–Frazzoli 二维下界 $2\sqrt{1.5}\sqrt{86/\pi} \approx 12.82$（自由空间面积 86）；半径在 $n$ 约 1160 之前被 $\eta = 1$ 封顶，$n = 8000$ 时缩到约 0.43。

先看单种子（seed $=0$）的路径长度账（每个 $n$ 处：树上经目标邻域的最优代价）：

| 2000 | 21.894 | 19.768 |

表读法一：RRT 在 $n = 500$ 后纹丝不动（平台期——旧枝冻结，机制如 $\S 4.3$ 所言），停在比最优差约 15% 的位置；RRT\* 每一档都在降，$n = 8000$ 时距最优只差 1.9%，且没有停下来的迹象。这就是「渐近最优」四个字的数值形状：不是某个神秘的 $n$ 之后突然变优，而是持续、单调、越改越细的下降。顺带一提，同种子下两棵树的首达时刻都是 $n = 151$ 并非巧合：这份实现里碰撞检查用最近邻 $v$ 而非选出的父节点，故两树接受的新点序列完全相同——唯一的差别是接线方式，这恰好把「重接线」的净效应隔离了出来。

表读法二（多种子）：换 20 个种子各跑一遍取均值，结论更干净。RRT 的路径长从 $n = 250$ 的 27.9 到 $n = 8000$ 的 27.5——四位数不动，且均值比单种子差得多，因为不同种子的 RRT 冻结在不同的次优值上，平均掉了单次的侥幸；RRT\* 从 23.6 一路降到 19.4，标准差从 1.9 收到 0.06——随机性被渐近最优性活活磨平，20 个种子在 $n = 8000$ 的终值全部挤在 19.3 到 19.6 之间。

第二件事是把 Voronoi 偏置本身量出来（采样偏置的实算演示）。在无障碍空场地、根在中心、步长 0.5 的条件下生长树，统计三个量：新枝「背离根方向」的比例、树冠最大半径、树顶点覆盖的单位方格比例；再独立撒两万个均匀点，统计「被选为最近邻」次数最多的前 10% 顶点吃掉多少份额。20 个种子的均值：

表读法：朴素对照（随机挑顶点、随机方向走一步，无 Voronoi 机制）在同样本数下只覆盖 17.0% 的方格，对 RRT 的 87.4%；树冠半径 2.7 对 6.5——同样的随机预算，「朝大 Voronoi 区域长」的偏置把探索效率抬了一个数量级。前 10% 顶点的份额分布也一致：朴素树的份额高度集中在根部（前 10% 顶点吃掉 92.9% 的采样召唤、平均离根仅 1.75，树长成一丛灌木），RRT 的份额分散在树冠外缘（只吃 28.4%、平均离根 4.36，树长成一张网）。「被随机点召唤的概率正比于 Voronoi 面积」从机制变成了可测的分布差异。

本节小结：固定种子的对账实验把三句话钉死——RRT 有平台期（$n \ge 500$ 后 21.894 纹丝不动）、RRT\* 持续下降（21.9 到 19.5）、偏置本身可测（覆盖率高一个数量级、Voronoi 份额向外缘转移）。

## $\rm \S \, 4.6$ 出口：往动力学与学习两个方向走

本章的 $\sigma$ 是纯几何的：不控制，无惯性。真机器人走一条几何最短的折线，速度、加速度、力矩全是「未定义」。kinodynamic 规划把采样对象换成扩大的状态空间：树的节点是状态 $(q, \dot{q})$，边是有限时长的控制输入积分出的轨迹段，碰撞与动力学约束在采样时就一并检查（LaValle 2006 第 14 章「微分约束下的采样式规划」；渐近最优版本见 Webb & van den Berg 2013 的 kinodynamic RRT\*）。它与第 3 章 MPC 是互补路线——采样规划给全局拓扑、MPC 精修局部，两层常叠着用。

另一头是学习。近年的做法是用网络学一个采样分布 $p_\theta(s)$ 替换均匀采样，让树别把预算浪费在显然无用的区域（代表工作：Ichter et al. 2018 用「临界区域」标注训练采样网络）。与规划的关系一句话：**学习给先验、规划保安全**——网络把「哪里可能有解」的猜测注入采样分布以加速，而碰撞检查与渐近最优的机制原封不动地留在规划器里；猜测错了不损完备性，最多少快。

本节小结：把状态空间换成 $(q, \dot{q})$ 就是 kinodynamic 规划，采样框架原样适用；学习改采样分布、规划器保留完备与最优的底盘，两者是先验与保障的分工。

## $\rm \S \, 4.8$ 可当场复跑的验证段

复跑脚本（Python 3 标准库，固定种子确定性可复现；碰撞检测用 Liang–Barsky 线段-矩形判据；`plan` 返回值的首个元素即首次到达目标的顶点数）：

```python
import math, random, heapq
d = math.dist
OBS = [(-1, 3, 7, 4), (3, 6, 11, 7)]  # 两堵墙 (xmin,ymin,xmax,ymax)
START, GOAL, GR, ETA = (1.0, 1.0), (9.0, 9.0), 0.5, 1.0

def hits(a, b, r):  # Liang-Barsky：线段是否穿过矩形内部（擦边不算）
    x0, y0, x1, y1 = r; t0, t1 = 0.0, 1.0
    dx, dy = b[0] - a[0], b[1] - a[1]
    for p, q in ((-dx, a[0]-x0), (dx, x1-a[0]), (-dy, a[1]-y0), (dy, y1-a[1])):
        if p == 0:
            if q <= 0: return False
        elif p < 0: t0 = max(t0, q/p)
        else: t1 = min(t1, q/p)
    return t0 < t1

def free(a, b, obs=OBS):
    return all(0 <= c <= 10 for c in b) and not any(hits(a, b, r) for r in obs)

def optimum():  # 可视图 + Dijkstra：真最短路，供对照
    P = [START, GOAL] + [(x, y) for r in OBS for x in r[0::2] for y in r[1::2]]
    best, pq = {0: 0.0}, [(0.0, 0)]
    while pq:
        c, i = heapq.heappop(pq)
        if i == 1: return c
        for j, q in enumerate(P):
            if j != i and free(P[i], q) and c + d(P[i], q) < best.get(j, 1e9):
                best[j] = c + d(P[i], q); heapq.heappush(pq, (best[j], j))

def plan(nmax, star, seed, marks, root=START, eta=ETA, obs=OBS):
    rng = random.Random(seed)
    V, par, cost, kids = [root], [0], [0.0], [[]]
    gamma = 2 * 1.5**0.5 * (86 / math.pi)**0.5  # Karaman-Frazzoli 二维下界
    first, out = None, {}
    while len(V) < nmax:
        s = (rng.uniform(0, 10), rng.uniform(0, 10))          # 1. 撒样本
        i = min(range(len(V)), key=lambda k: d(V[k], s))       # 2. 最近邻
        L = d(V[i], s)
        if L == 0: continue
        new = s if L <= eta else (V[i][0] + eta*(s[0]-V[i][0])/L,
                                  V[i][1] + eta*(s[1]-V[i][1])/L)  # 步进
        if not free(V[i], new, obs): continue
        p, c, X = i, cost[i] + d(V[i], new), []
        if star:
            n = len(V)
            r = min(gamma * (math.log(n)/n)**0.5, eta) if n > 1 else eta
            X = [k for k in range(n) if d(V[k], new) <= r and free(V[k], new, obs)]
            for k in X:  # 选父：邻域里让 new 最便宜的那个
                if cost[k] + d(V[k], new) < c: p, c = k, cost[k] + d(V[k], new)
        V.append(new); par.append(p); cost.append(c); kids.append([]); m = len(V)-1
        kids[p].append(m)
        for k in X:  # 重接线：经 new 更便宜就改认 new 为父
            nc = c + d(new, V[k])
            if nc < cost[k] - 1e-12:
                kids[par[k]].remove(k); par[k] = m; kids[m].append(k)
                delta, st = cost[k] - nc, [k]
                while st:  # 子孙的代价一并下调
                    u = st.pop(); cost[u] -= delta; st.extend(kids[u])
        if first is None and d(new, GOAL) <= GR: first = len(V)
        if len(V) in marks:
            g = [cost[k] + d(V[k], GOAL) for k in range(len(V)) if d(V[k], GOAL) <= GR]
            out[len(V)] = round(min(g), 3) if g else None
    return first, out, V, par

if __name__ == "__main__":
    print("optimum %.3f" % optimum())
    marks = (250, 500, 1000, 2000, 4000, 8000)
    for star in (False, True):
        f, o, _, _ = plan(8000, star, 0, marks)
        print("RRT*" if star else "RRT", "first hit at n =", f, o)
```

运行 `python mini_rrt.py` 应输出 `optimum 19.121`，RRT 与 RRT\* 的首达 $n$ 均为 151，且各档路径长与 $\S 4.5$ 表一逐格一致（seed $=0$ 的确定性结果）。进一步的验证动作：

1. 把 `marks` 各档的输出画成曲线：RRT 自 $n = 500$ 起恒为 21.894，RRT\* 单调降至 19.476。
2. 把 seed 换成 1 到 19 各跑一遍：RRT 的终值各不相同（不同种子冻结在不同次优值），RRT\* 的终值全部挤在 19.3 到 19.6 之间——渐近最优性的另一种肉眼可见。
3. 把 `ETA` 从 1.0 降到 0.3：两树首达 $n$ 都显著变大（步长小则绕障精细但探索慢），RRT\* 终值略降、RRT 终值几乎不变——平台期是机制问题，不是步长问题。
4. 删掉一堵墙（`OBS` 去掉一项）重跑：`optimum` 变小，RRT\* 在更小的 $n$ 就贴近新最优；手算剩下那堵墙的绕行折线长，核对 `optimum` 输出。

收束一下：采样式规划的全部魔力来自一个分工——随机性负责「不遗漏」（撒点终会落进任何胖通路），确定性机制负责「有方向」（Voronoi 偏置导向空旷处、重接线导向便宜处）。PRM 把这两样铸成可复用的路网，RRT 铸成单次查询的疯长树，RRT\* 再给树加上「回头改错」的能力，快与最优从此不必二选一。下一章把这些几何层面的路交给真实动力学去执行：接触怎么建模、全身控制怎么把规划器的折线变成电机的指令。
