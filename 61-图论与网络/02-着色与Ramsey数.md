# $\rm Chapter \, 2$ 着色与 Ramsey 数：压力之下的必然秩序

给系统加压，秩序反而显形——这是 Ramsey 理论的核心体验。顶点着色问的是「最少几种颜色能避免所有冲突」；而 Ramsey 数问的是反方向的问题：「人多到什么程度，无论关系怎么排布，某种秩序都躲不掉」。本章的主证是两者交汇处最小也最漂亮的定理 $R(3,3) = 6$：六个点两两连边、每条边染红或蓝，单色三角形必然出现。它小到可以暴力验证（三万多种染色，程序几秒扫完），又大到能长出 Schur 定理、van der Waerden 定理这样横跨数论与组合的分支。

> **开始前自检**：本章假设你已经会：
>
> 1. □ 鸽笼原理：$n + 1$ 个物件放进 $n$ 个抽屉，必有抽屉装至少两个。
> 2. □ 组合学册第 1—2 章的基本计数：$\binom{n}{k}$、乘法原理、Pascal 恒等式。
> 3. □ 本册第 1 章的词汇：二部图（§1.3 的 $\rm K_{3,3}$）、圈与围长、Petersen 图的色数 3（§1.5 数值锚）。
>
> 互文提示：第 3 章会反复借用本章的色数 $\chi$——Erdős–Stone 定理说，图的渐近极值由色数决定。

## $\rm \S \, 2.1$ 色数与着色多项式：冲突的最小配色方案

白话：排考试时间表，有冲突的科目不能同时考——最少分成几场？把科目当顶点、冲突当边，答案就是色数。

1. **定义（色数）**：图 $G$ 的合法着色是从 $V(G)$ 到颜色集的映射，要求每条边的两端异色。色数 $\chi(G)$ 是合法着色所需的最少颜色数。
2. 着色是「冲突回避」的通用模型：寄存器分配（同时活跃的变量不能共用寄存器）、频率规划、地图染色，全都翻译成色数。冲突图越密，$\chi$ 越大。

先在圈上练手，圈是后面所有论证的试金石。

1. **命题**：$n \ge 3$ 时，$\chi(C_n) = 2$ 若 $n$ 为偶数，$\chi(C_n) = 3$ 若 $n$ 为奇数。
2. 偶圈用 2 色：沿圈交替涂两色，偶数长度让转一圈刚好对上。奇圈 2 色必败：假设合法 2-着色存在，从任一点出发沿圈走，相邻必须异色、只有两色可用，于是颜色被强制逐步交替；走奇数步回到起点的前一站时，那一点的颜色与起点相同——而它们相邻，矛盾。3 色可行：给 $v_1$ 涂色 1，$v_2$ 到 $v_{n-1}$ 这段偶数……不对，是奇数个点的路径交替涂色 2 与 3（末端落在色 2），最后 $v_n$ 与色 1、色 2 都相邻，涂色 3。
3. 修正读法：$n$ 为奇数时 $v_2, \ldots, v_{n-1}$ 共 $n - 2$ 个点（奇数个），交替涂 2、3 后末端 $v_{n-1}$ 落在色 2；$v_n$ 只需避开色 1 与色 2，涂色 3。全程合法。
4. 顺带记住圈的着色多项式通式（陈述级，第 5 章 Erdős–Gallai 语境下再用）：$P_{C_n}(q) = (q-1)^n + (-1)^n (q-1)$。读法：先按路径染 $(q-1)^n$ 种，再修正首尾「被迫同色/被迫异色」的两类漏账，修正项按 $n$ 的奇偶变号——$n = 4$ 时它就是上一段手算的答案。

色数的下界来自团，上界来自贪心，两条夹住它。

1. **命题（$\chi \ge \omega$）**：$\chi(G)$ 不小于团数 $\omega(G)$（最大团——两两相邻的顶点集——的大小）。证明：团内任意两点相邻，合法着色下它们必须异色，故团内点两两异色，$\omega(G)$ 个点吃掉 $\omega(G)$ 种颜色。
2. **命题（贪心 $\chi \le \Delta + 1$）**：证明：把顶点任意排成 $v_1, \ldots, v_n$，依次着色；给 $v_i$ 上色时它至多 $\Delta$ 个已着色邻居，至多禁掉 $\Delta$ 种颜色，而调色盘有 $\Delta + 1$ 种，总有一款可用。
3. **Brooks 定理**（陈述级，出处 Brooks 1941）：连通图 $G$ 若既不是完全图 $K_{\Delta+1}$ 也不是奇圈，则 $\chi(G) \le \Delta(G)$。两个例外各自卡在 inequalities 的边界：$K_{\Delta+1}$ 有 $\chi = \Delta + 1$，比上界多一；奇圈 $\Delta = 2$ 而 $\chi = 3$。Petersen 图（$\Delta = 3$、$\chi = 3$、非完全图）是 Brooks 不等式取等的干净样本。
4. $\chi$ 与 $\omega$ 可以脱钩到什么程度？Erdős（1959，概率构造，方法见概率论册第 18 章）证明：存在色数任意大而无三角形的图——$\chi - \omega$ 没有上界。小样先尝一口：Petersen 图 $\omega = 2$ 而 $\chi = 3$。

白话：着色多项式把「有多少种着色方案」本身当成研究对象——它不再问最少几色，而是问给定 $q$ 色调色盘时方案数是多少，把色数收编为多项式的第一个正整数点。

1. **定义（着色多项式）**：$P_G(q)$ 表示用 $q$ 种颜色给 $G$ 合法着色的方案数。它是 $q$ 的多项式（可由删边—缩边递推证得，此处从略），且
$$
\chi(G) = \min\{q : P_G(q) > 0\}.
$$
2. 在 $C_4$ 上全程手算。给四个顶点沿圈编号 $v_1, v_2, v_3, v_4$，逐个着色并按「$v_1$ 与 $v_3$ 是否同色」分支：$v_1$ 有 $q$ 种；$v_2$ 避开 $v_1$，$q - 1$ 种；$v_3$ 避开 $v_2$，$q - 1$ 种；$v_4$ 同时避开 $v_3$ 与 $v_1$，两种情形——若 $v_1 = v_3$，$v_4$ 有 $q - 1$ 种；若 $v_1 \ne v_3$，有 $q - 2$ 种。合并：
$$
P_{C_4}(q) = q(q-1)^2 + q(q-1)(q-2)^2 = q(q-1)\left[(q-1) + (q-2)^2\right] = q(q-1)(q^2 - 3q + 3).
$$
3. 读法：第一分支是「对角同色」（$q(q-1)$ 种摆法、$v_4$ 剩 $q-1$ 色），第二分支是「对角异色」（$q(q-1)(q-2)$ 种摆法、$v_4$ 剩 $q-2$ 色）。展开可对账：$q(q-1)(q^2 - 3q + 3) = (q-1)^4 + (q-1)$——圈公式 $P_{C_n}(q) = (q-1)^n + (-1)^n (q-1)$ 在 $n = 4$ 的特例。
4. 数值锚（程序实跑照抄）：$q = 2, 3, 4, 5, 6, 7$ 时 $P_{C_4}(q) = 2, 18, 84, 260, 630, 1302$。代入 $q = 2$ 得 $2$：$C_4$ 恰有两种 2-着色（两色交替、起点二选一）——这也当场验证了 $\chi(C_4) = 2$。

**本节小结**：色数被团数压在下界、被 $\Delta + 1$ 压在上界，Brooks 把上界收到 $\Delta$（完全图与奇圈除外）；着色多项式把方案数写成 $q$ 的多项式，$C_4$ 的逐位手算给出本章第一个数值锚。

## $\rm \S \, 2.2$ 本章主证：$R(3,3) = 6$

白话：六个人里，必有三人互相都认识，或三人互相都不认识。把「认识」染红、「不认识」染蓝，这就是完全图的边二染色问题——而它躲不掉单色三角形。

1. **定义（Ramsey 数 $R(3,3)$）**：最小的 $n$，使得 $K_n$ 的任何红蓝二染色都含红色三角形或蓝色三角形。
2. **上界 $R(3,3) \le 6$，逐步走**：任取 $K_6$ 的一个二染色与一个顶点 $v$。$v$ 恰有 5 条关联边，染两色，鸽笼原理（$5 = 2 + 2 + 1$）保证其中至少 3 条同色，不妨设红边 ${v, a}$、${v, b}$、${v, c}$。再看 ${a, b, c}$ 三点之间的三条边：只要有一条是红，比如 ${a, b}$，则三点组 ${v, a, b}$ 三边全红，红色三角形到手；若三条全是蓝，则 ${a, b, c}$ 三边全蓝，蓝色三角形到手。两条路必走一条，$K_6$ 逃不掉。读法：证明只动了一次鸽笼、一次三分支讨论，却把 $2^{15} = 32768$ 种染色的无限重复劳动一次收编——这就是「结构性证明」省力的方式。
3. **下界 $R(3,3) > 5$，把幸存染色完整摆出**：给 $K_5$ 的边染色——红边取五边形 ${12, 23, 34, 45, 51}$，蓝边取剩下五条 ${13, 35, 52, 24, 41}$。逐一验证：红图就是 $C_5$，围长 5，无三角形；蓝边也构成一个圈 $1 \to 3 \to 5 \to 2 \to 4 \to 1$（五个点每点恰好两条蓝边，连成单个五边形），同样无三角形。两种颜色都干净，$K_5$ 躲过去了。

两条合起来：$R(3,3) = 6$。但下界的染色是否唯一？把 1024 种染色全部扫一遍（§2.8 程序），幸存者恰有 12 种，它们长一个样——值得解剖：

1. 设某染色红图 $R$ 与蓝图 $B$ 都无三角形。借用第 3 章 Mantel 定理的 $r = 2$ 特例（5 顶点无三角形至多 $\lfloor 25/4 \rfloor = 6$ 条边，先当已知用）：$e(R) \le 6$ 且 $e(B) \le 6$，而 $e(R) + e(B) = 10$，故 $4 \le e(R) \le 6$。
2. $e(R) = 6$：五点无三角形取满 6 条边的图只有 $K_{2,3}$（Mantel 等号情形），其补图是 $K_2 \cup K_3$，含三角形——蓝图爆雷，出局。
3. $e(R) = 4$：对称，蓝图有 6 条边，同样出局。
4. $e(R) = 5$：红蓝各 5 条、都无三角形。五点 5 边的无三角形图逐一过堂：$C_4$ 加悬挂点——补图含三角形，出局；$K_{2,3}$ 缺一条边——补图含三角形，出局；只有红恰为 $C_5$ 时，补图是五角星（仍是一个 5-圈），两清。
5. 于是幸存者必是「红一个五边形、蓝一个五角星」。$K_5$ 中五边形有 $5!/10 = 12$ 个，与程序数出的 12 逐位吻合——所谓 12 种「不同」染色，只是同一构型的 12 个摆放位置。

程序还给出了另一半锚：$K_6$ 的 $2^{15} = 32768$ 种二染色中，无单色三角形的幸存者是 0 种——与证明一致，一个都没漏。

**本节小结**：$R(3,3) = 6$ 由两个方向拼成：鸽笼加一次分支讨论把 6 压成上界，五边形染色把 5 顶成下界；暴力扫描与 12 个幸存者（全是五边形构型）把证明的两端都钉了锚。

## $\rm \S \, 2.3$ Ramsey 定理的一般形式：必然性的机械制造

白话：三角形只是热身。任意指定两种「秩序」——红边里找 $K_k$、蓝边里找 $K_l$——只要点够多，总有一样躲不掉；而且「够多」可以具体算出来。

1. **定义（Ramsey 数 $R(k, l)$）**：最小的 $n$，使得 $K_n$ 的任何红蓝二染色含红色 $K_k$ 或蓝色 $K_l$。约定 $R(1, l) = R(k, 1) = 1$（单点既是红 $K_1$ 又是蓝 $K_1$）。
2. **定理（递归上界）**：对 $k, l \ge 2$，
$$
R(k, l) \le R(k-1, l) + R(k, l-1).
$$
3. 证明：令 $N = R(k-1, l) + R(k, l-1)$，任取 $K_N$ 的红蓝二染色与顶点 $v$。$v$ 有 $N - 1$ 个邻居；红色邻居集 $A$ 与蓝色邻居集 $B$ 满足 $|A| + |B| = N - 1$。两种情形：
4. 若 $|A| \ge R(k-1, l)$：把 $A$ 看成诱导二染色图，其中或含红 $K_{k-1}$——加上 $v$（$v$ 到 $A$ 全是红边）凑成红 $K_k$——或含蓝 $K_l$，两种都达标。
5. 否则 $|A| \le R(k-1, l) - 1$，于是
$$
|B| \ge (N - 1) - (R(k-1, l) - 1) = R(k, l - 1),
$$
对 $B$ 同样处理：红 $K_k$ 直接到手，或蓝 $K_{l-1}$ 加 $v$（$v$ 到 $B$ 全是蓝边）凑成蓝 $K_l$。证毕。
6. **推论（有限性）**：一切 $R(k, l)$ 有限，且 $R(k, l) \le \binom{k + l - 2}{k - 1}$。证明：对 $k + l$ 归纳，递归式与 Pascal 恒等式 $\binom{k+l-2}{k-1} = \binom{k+l-3}{k-2} + \binom{k+l-3}{k-1}$ 逐项咬合，边界 $R(1, l) = 1 = \binom{l-1}{0}$ 对上。

这个递归给的是上界，真实值往往小得多。已知 Ramsey 数一小段（截至 2024 年）：

1. $R(3,3) = 6$，$R(3,4) = 9$，$R(3,5) = 14$，$R(3,6) = 18$，$R(3,7) = 23$，$R(3,8) = 28$。
2. $R(4,4) = 18$，$R(4,5) = 25$。
3. $R(5,5)$ 至今未知，只知道 $43 \le R(5,5) \le 48$。Erdős 的比喻流传很广：外星人进驻地球、威胁一年内算不出 $R(5,5)$ 就毁灭地球，那值得调集全部计算机算；若改问 $R(6,6)$，该直接开战。

**本节小结**：递归 $R(k,l) \le R(k-1,l) + R(k,l-1)$ 用「盯住一个顶点、两个邻居集互相兜底」把存在性变成双重归纳，有限性与二项式上界一次到位；已知值表显示真实 Ramsey 数远小于上界——确定精确值是组合学的硬骨头。

## $\rm \S \, 2.4$ 应用：Schur 定理与 van der Waerden 定理

白话：Ramsey 的两边不只有「三角形」这一种秩序。把染色对象从边换成数字，同样躲不掉的单色结构接连出现——整数的加法与等差。

1. **Schur 定理**（1916）：把正整数任意有限染色，必存在同色的 ${x, y, z}$（$x$ 与 $y$ 允许相同）满足 $x + y = z$。
2. 它是 Ramsey 定理的直接推论，机制一句话：取足够大的 $n$，给 $K_n$ 的边 ${i, j}$ 染「$|i - j|$ 的颜色」（$|i-j| \le n$，颜色有定义）；Ramsey 给出单色三角形 $i < j < k$，于是
$$
|i - j| + |j - k| = |k - i|,
$$
三个数同色——一个单色的加法等式到手。
3. 定量版本用 Schur 数说话：$S(r)$ 是最大的 $n$ 使 $\{1, \ldots, n\}$ 可 $r$ 染色且避开单色和。已知 $S(1) = 1$，$S(2) = 4$，$S(3) = 13$，$S(4) = 44$，$S(5) = 160$（2017 年由计算机搜索确定）。
4. $S(2) = 4$ 的数值锚（§2.8 程序实跑）值得亲手摸一遍：$\{1, \ldots, 4\}$ 的 16 种二染色中恰 2 种合法，且互为换色——红 $\{1, 4\}$、蓝 $\{2, 3\}$。逐条核对三条嫌疑和式：$1 + 1 = 2$ 的三数 ${1, 1, 2}$ 是红蓝蓝，非单色；$1 + 3 = 4$ 是红蓝红；$2 + 2 = 4$ 是蓝蓝红。全部排除。反方向看 5 个数为什么装不下：合法染色里 ${1, 2}$ 必须异色（否则 $1 + 1 = 2$），${2, 4}$ 必须异色（否则 $2 + 2 = 4$），于是 $1$ 与 $4$ 同色；再看 $3$——它与 $1$ 同色则 $1 + 3 = 4$ 三数全红；与 $2$ 同色则 $2 + 3 = 5$ 逼 $5$ 取红，而 $1 + 4 = 5$ 三数全红。两条路都爆，程序一锤定音：32 种染色 0 种合法。
5. **van der Waerden 定理**（1927）：把足够长的整数区间任意有限染色，必存在单色等差数列。等差数列 $a, a + d, \ldots$ 的出现比「和式」更难躲：双色的临界值 $W(2, 3) = 9$、$W(2, 4) = 35$、$W(2, 5) = 178$、$W(2, 6) = 1132$，三色的 $W(3, 3) = 27$、$W(3, 4) = 293$。$W(2,3) = 9$ 的数值锚（§2.8 程序实跑）：$\{1, \ldots, 8\}$ 的 256 种二染色中恰 6 种不含单色 3-项等差，$\{1, \ldots, 9\}$ 的 512 种中 0 种——同一个 9，等差比三角形更会藏也更躲不开。
**本节小结**：Schur 定理把 Ramsey 搬进整数加法——边染色按差值编码，单色三角形翻译成同色和式；van der Waerden 把它搬进等差，临界值 $W(2,3) = 9$ 与 $R(3,3) = 6$ 一小一大，都是「压力必出秩序」的定量刻画。

### $\rm \S \, 2.7.1$ 关键概念回顾答案

1. 团内两点必相邻、合法着色必异色，$\omega$ 个点吃掉 $\omega$ 种颜色。例外一：$K_{\Delta+1}$ 本身 $\chi = \Delta + 1$，比 $\Delta$ 多一；例外二：奇圈 $\Delta = 2$ 而 $\chi = 3$，2 色被交替强制锁死。（§2.1）
2. 鸽笼用在顶点 $v$ 的 5 条关联边：两色中必有一色占至少 3 条。幸存染色是红五边形加蓝五角星——红图 $C_5$、蓝图也是 5-圈，围长都是 5。（§2.2）
3. 全是「红 $C_5$ + 蓝 $C_5$（五角星）」构型；$K_5$ 中五边形有 $5!/10 = 12$ 个，每个五边形唯一确定其对偶（补图），故恰 12 种。（§2.2）
4. $A$ 是 $v$ 的红邻居集、$B$ 是蓝邻居集，$|A| + |B| = N - 1$。$A$ 够大就用 $R(k-1,l)$ 兜底（红 $K_{k-1}$ 加 $v$ 成红 $K_k$，或蓝 $K_l$）；$A$ 不够大则 $B$ 自动够大、用 $R(k,l-1)$ 兜底。（§2.3）
5. 边 ${i, j}$ 染 $|i - j|$ 的颜色；单色三角形 $i < j < k$ 给出 $|i-j| + |j-k| = |k-i|$，三个距离同色。（§2.4）
6. 方案数恰为 2 说明 2-着色存在且唯一到全局换色——即 $C_4$ 连通且是二部图，$\chi(C_4) = 2$；两种方案互为颜色对调，对应二部图划分的唯一性（连通情形）。（§2.1）

### $\rm \S \, 2.7.2$ 应用与辨析答案

1. 不对。正确说法是「必有 3 人互相认识，或 3 人互相都不认识」——两个结论是「或」不是「且」。反例即 $R(3,3) > 5$ 的五边形染色：5 人围成环互为熟人、环上不相邻的全是陌生人，既无红色三角也无蓝色三角；6 人时 $R(3,3) = 6$ 兜底。（§2.2）
2. 奇圈正是 Brooks 的第二个例外：$\Delta = 2$、$\chi = 3$、既非完全图（3 个点的奇圈 $C_3$ 就是 $K_3$——所以定理把 $n \ge 5$ 的奇圈单独点名）也非「$\chi \le \Delta$ 能容纳」的图。偶圈 $\chi = 2 = \Delta$，恰好在 Brooks 界内取等，不是例外。（§2.1）
3. 不能直接出来。和式来自三角形的距离关系：三边 $|i-j|$、$|j-k|$、$|k-i|$ 自动满足两短边之和等于长边；四边形的四条距离没有这种恒等式，单色四边形给不出 $x + y = z$ 的三元组。Schur 的编码精心挑了三角形，正因为它带加法结构。（§2.4）
4. 断掉在「上界松」：$\chi \le \Delta + 1 = 4$ 只说 4 色够用，完全不排除 2 色就够、也不保证 2 色够。真正的判定要回到定义去验：Petersen 图含奇圈（五边形），2-染色被交替性排除；程序实跑 2 染色方案 0 种、3 染色 120 种，$\chi = 3$ 是数出来的。（§2.1、§1.5）

## $\rm \S \, 2.8$ 可当场复跑的程序段

下面这段纯 Python 把 §2.2 与 §2.4 的暴力锚全部实算，输出与正文逐位一致：

```python
 # R(3,3) 暴力验证 + Schur 数 S(2)（纯 Python）
import itertools

def has_mono_triangle(nv, color):
    # color: 边 (a, b)（a < b）-> 0/1
    for tri in itertools.combinations(range(nv), 3):
        es = [tuple(sorted(e)) for e in itertools.combinations(tri, 2)]
        if len({color[e] for e in es}) == 1:
            return True
    return False

K5 = list(itertools.combinations(range(5), 2))
surv = 0
for bits in itertools.product((0, 1), repeat=len(K5)):
    if not has_mono_triangle(5, dict(zip(K5, bits))):
        surv += 1
print("K5：共", 2 ** len(K5), "种二染色，无单色三角形的有", surv, "种")

K6 = list(itertools.combinations(range(6), 2))
surv = 0
for bits in itertools.product((0, 1), repeat=len(K6)):
    if not has_mono_triangle(6, dict(zip(K6, bits))):
        surv += 1
print("K6：共", 2 ** len(K6), "种二染色，无单色三角形的有", surv, "种")

 # Schur：给 {1, ..., n} 染两色，能否避开单色的 x + y = z
def schur_free(color, nv):
    for x in range(1, nv + 1):
        for y in range(1, nv + 1 - x):
            if color[x - 1] == color[y - 1] == color[x + y - 1]:
                return False
    return True

for nv in (4, 5):
    good = sum(schur_free(c, nv) for c in itertools.product((0, 1), repeat=nv))
    print(f"{{1, ..., {nv}}} 的无单色和二染色数：{good}")

 # van der Waerden W(2,3)=9 抽验：单色 3 项等差
def has_ap(color):
    L = len(color)
    return any(color[a] == color[a + d] == color[a + 2 * d]
               for a in range(L) for d in range(1, (L - 1 - a) // 2 + 1))

for nv in (8, 9):
    free = sum(1 for c in itertools.product((0, 1), repeat=nv) if not has_ap(c))
    print(f"{{1, ..., {nv}}} 的无单色等差二染色数：{free}")
```

{1, ..., 5} 的无单色和二染色数：0
{1, ..., 8} 的无单色等差二染色数：6

读法：前两行钉死 $R(3,3) = 6$ 的两端（12 个幸存者全是五边形构型，0 个幸存者验证鸽笼证明无死角）；中间两行给出 $S(2) = 4$（唯一构型红 $\{1,4\}$、蓝 $\{2,3\}$ 的两个换色版）；末两行给出 $W(2,3) = 9$。三个「从有到无」的断崖——12 到 0、2 到 0、6 到 0——就是 Ramsey 现象的数值形状。

## $\rm \S \, 2.9$ 带走清单

1. $\chi(G) \ge \omega(G)$ 恒真；贪心给 $\chi \le \Delta + 1$；Brooks 定理：除 $K_{\Delta+1}$ 与奇圈外 $\chi \le \Delta$。$\chi$ 与 $\omega$ 可脱钩任意远（Erdős 概率构造）。
2. $\chi(C_n) = 2$（偶圈）/ $3$（奇圈）；$P_{C_4}(q) = (q-1)^4 + (q-1) = q(q-1)(q^2 - 3q + 3)$，$P(2) = 2$，$q = 2$ 至 $7$ 依次为 ${2, 18, 84, 260, 630, 1302}$。
3. $R(3,3) = 6$：上界靠鸽笼（一点 5 边必 3 同色，对面三点内必同色边），下界靠红五边形蓝五角星；暴力锚 $1024$ 中幸存 $12$、$32768$ 中幸存 $0$。
4. $R(k,l) \le R(k-1,l) + R(k,l-1)$，双重归纳得有限性与 $R(k,l) \le \binom{k+l-2}{k-1}$；已知值 $R(3,4)=9$、$R(3,5)=14$、$R(4,4)=18$、$R(4,5)=25$，$R(5,5) \in [43, 48]$ 未知。
5. Schur 定理：有限染色必现同色和 $x + y = z$（Ramsey 化：边染差值、单色三角给和式）；$S(2) = 4$，锚为 16 中 2、32 中 0。
6. van der Waerden 定理：有限染色必现单色等差；$W(2,3) = 9$，锚为 256 中 6、512 中 0。
