# $\rm Chapter \, 1$ 熵：不确定性与编码下界

概率论册第 15 章用一章的篇幅从概率视角速览了熵、互信息与信道容量——那是一张俯瞰图。本册把那一章展开成一册，每个定理都给全证、每个数都实跑。分工说清楚：概率论册管「熵是一个期望」，本册管「熵为什么是压缩的极限」。本章就从这个问题入手：一个随机源每个符号平均至少要花几个比特才能无损记下来？答案是熵，而且差不到一个比特——这就是 Shannon 信源编码定理的第一版，本章主证。路线：自信息与熵的定义（§1.1）、熵的代数性质（§1.2）、Kraft 不等式与它的逆（§1.3，前缀码的全部几何）、信源编码定理第一版（§1.4，下界用 Jensen、上界用舍入构造）、Huffman 算法（§1.5，把上界真正造出来），末尾用一个四符号分布把熵、码长、Kraft 和对账到小数点后六位。

## $\rm \S \, 1.1$ 不确定性的度量：自信息与熵

**白话**：一条消息越出人意料，它带来的信息越多——「明天太阳升起」不值一提，「明天下雪」在七月就值得登报。信息论把「意外程度」量化成一个数，再把它对所有可能的消息取平均，就是熵。熵读作「这个源平均每个符号有多意外」，而本章末尾会证明：它恰好是「最优编码下每个符号的平均位数」。

**定义 1.1**（自信息）。设离散随机变量 $X$ 取值于有限字母表 $\mathcal{X}$，概率质量函数 $p(x)$。事件 ${X = x}$ 的**自信息（self-information）**定义为

$$
I(x) \;=\; -\log_2 p(x) \;=\; \log_2 \frac{1}{p(x)}
$$

**为什么是对数**（读法）。对「意外度」提三条朴素要求：随概率单调递减（越少见越意外）、连续（概率微调则意外度微调）、独立事件的意外度相加（两件互不相干的事一起发生，意外度应该是两者之和，而它们的概率是乘积）。要求「乘积变加法」，唯一的连续单调解就是对数；取负号让它非负。底数只决定单位：底 2 读**比特（bit）**，底 $e$ 读**纳特（nat）**，换算 ${1\ \text{nat} = 1/\ln 2 = 1.442695\ \text{bit}}$。本册全程用底 2，因为我们的目标是「数位数」。两个锚：${p = 1}$ 时 ${I = 0}$（必然事件无信息），${p = 1/2}$ 时 ${I = 1}$（一次公平硬币恰是一比特）。

**定义 1.2**（熵）。$X$ 的**熵（entropy）**是自信息的期望：

$$
H(X) \;=\; \mathrm{E}\big[-\log_2 p(X)\big] \;=\; -\sum_{x \in \mathcal{X}} p(x) \log_2 p(x)
$$

约定 ${0 \log_2 0 = 0}$（由 ${t \log t \to 0}$ 当 ${t \to 0^+}$ 连续补上）。熵是分布的函数，不是取值的函数——把 $\mathcal{X}$ 的符号换个名字，熵一个数都不变；所以也常写成 ${H(p_1, \ldots, p_m)}$。

**二值熵**：两点分布 ${(p, 1-p)}$ 的熵记 ${H_b(p) = -p \log_2 p - (1-p) \log_2 (1-p)}$，是全册最常手算的量。三个数值锚（本机实测）：

1. ${H(0.5, 0.5) = 1}$ 比特——公平硬币，一次抛掷恰好一比特；
2. 均匀六面骰 ${H = \log_2 6 = 2.584963}$ 比特——六个等可能结果，不是整数比特，这正是本章要解释的现象（§1.4：单个符号编码总要多付「舍入税」）；
3. ${H(0.9, 0.1) = 0.468996}$ 比特——「九成确定」仍有近半比特不确定性；第 3 章会把这个 0.9 的源一路算到块编码。

**本节小结**：自信息 ${-\log_2 p}$ 是「乘变加」逼出来的唯一形状；熵＝自信息的期望，单位由对数底决定；熵只看分布不看标签。

## $\rm \S \, 1.2$ 熵的代数性质

**白话**：熵作为一个函数有几条像「加减法」一样顺手的规则——它非负，它有上界（最均匀最不确定），两个变量一起的熵可以拆成「先看一个、再在它的条件下看另一个」，而知道了别的事情只会让不确定性减少不会增加。前三条本节证全，最后一条留到第 2 章。

**定理 1.1**（非负与上界）。${0 \le H(X) \le \log_2 |\mathcal{X}|}$。左边取等当且仅当 $X$ 几乎必然等于某一个值；右边取等当且仅当 $X$ 在 $\mathcal{X}$ 上均匀。

**证明**。非负：每一项 ${-p(x) \log_2 p(x) \ge 0}$，因为 ${p \in (0, 1]}$ 时 ${\log_2 p \le 0}$；和为零当且仅当每项为零，即每个 $p(x)$ 是 0 或 1，只能恰有一个 1。上界用 Jensen：$\log_2$ 在 ${(0, \infty)}$ 上凹，对随机变量 ${Z = 1/p(X)}$ 有

$$
H(X) \;=\; \mathrm{E}\big[\log_2 Z\big] \;\le\; \log_2 \mathrm{E}[Z] \;=\; \log_2 \sum_{x:\, p(x) > 0} p(x) \cdot \frac{1}{p(x)} \;=\; \log_2 |\operatorname{supp} p| \;\le\; \log_2 |\mathcal{X}|
$$

Jensen 取等当且仅当 $Z$ 几乎必然为常数，即 $p(x)$ 在支撑上处处相等——均匀。$\blacksquare$

**读法**：这是本章第一次用 Jensen，模式是「把 $\sum p \cdot (\ldots)$ 看成期望、把 $\log$ 提到外面」；§1.4 的下界证明是同一套路的第二次使用，到时候请回看这一段。

**定义 1.3**（联合熵与条件熵）。两个变量 ${(X, Y)}$ 的**联合熵（joint entropy）**就是把对 $(X, Y)$ 当一个变量算熵：${H(X, Y) = -\sum_{x, y} p(x, y) \log_2 p(x, y)}$。**条件熵（conditional entropy）**定义为

$$
H(Y \mid X) \;=\; \sum_{x} p(x)\, H(Y \mid X = x) \;=\; -\sum_{x, y} p(x, y) \log_2 p(y \mid x)
$$

读作「知道 $X$ 以后，$Y$ 平均还剩多少不确定性」。注意它是一个**数**，已经对 $X$ 取过平均；随 $x$ 变化的是 ${H(Y \mid X = x)}$，那是条件分布 ${p(\cdot \mid x)}$ 自己的熵。

**定理 1.2**（链式法则）。${H(X, Y) = H(X) + H(Y \mid X)}$。

**证明**。逐点用 ${p(x, y) = p(x)\, p(y \mid x)}$ 取对数：

$$
\begin{aligned}
H(X, Y) &= -\sum_{x, y} p(x, y) \big[\log_2 p(x) + \log_2 p(y \mid x)\big] \\
&= -\sum_{x} \Big(\sum_{y} p(x, y)\Big) \log_2 p(x) \;-\; \sum_{x, y} p(x, y) \log_2 p(y \mid x) \\
&= H(X) + H(Y \mid X)
\end{aligned}
$$

第二行到第三行：括号里对 $y$ 求和得到边缘 $p(x)$，第一项变成 $H(X)$；第二项正是定义 1.3。$\blacksquare$

**读法**：链式法则说「一起看 $(X, Y)$ 的不确定性」＝「先看 $X$」＋「在 $X$ 已知下再看 $Y$」——这和概率的乘法公式 ${p(x, y) = p(x)\, p(y \mid x)}$ 是同一句话取了对数。对称地也有 ${H(X, Y) = H(Y) + H(X \mid Y)}$。连续用就是 ${H(X_1, \ldots, X_n) = \sum_i H(X_i \mid X_1, \ldots, X_{i-1})}$。

**定理 1.3**（条件化不增熵，陈述级）。${H(Y \mid X) \le H(Y)}$，取等当且仅当 $X$ 与 $Y$ 独立。

**读法**：「多知道一件事，平均不会更糊涂」。注意是「平均」——某个具体的 ${X = x}$ 可以让 $Y$ 更不确定（${H(Y \mid X = x) > H(Y)}$ 完全可能），但对 $x$ 取平均后不会。证明要用到互信息非负，那是第 2 章 §2.3 的事；本章先当工具用。推论：独立时 ${H(X, Y) = H(X) + H(Y)}$，一般情形 ${H(X, Y) \le H(X) + H(Y)}$——熵的次可加性。

**本节小结**：非负、均匀封顶（Jensen 一次）、链式法则（乘法公式取对数）、条件化不增（留第 2 章）。接下来把「熵」和「编码」接上，先得把「码」说清楚。

## $\rm \S \, 1.3$ 前缀码与 Kraft 不等式

**白话**：给每个符号分配一串 0/1 作为它的「名字」，要求把名字连着写成一长串时能无歧义地切回去。最省事的办法是规定任何名字都不是另一个名字的开头——这样读到一个完整名字就能立刻切断，不必往后看。这种码叫前缀码。Kraft 不等式回答：一组码长能不能被一个前缀码实现？答案是一条干净的数值判据。

**定义 1.4**（码与前缀码）。一个（二元）**码（code）**是映射 ${C: \mathcal{X} \to \{0, 1\}^*}$，${C(x)}$ 叫 $x$ 的**码字（codeword）**，长度记 ${l(x)}$。码是**前缀码（prefix code）**（又叫即时码），若没有任何码字是另一个码字的前缀。平均码长 ${L(C) = \mathrm{E}[l(X)] = \sum_x p(x)\, l(x)}$。

前缀码可以画成一棵二叉树：从根出发，0 向左、1 向右，每个码字是一条从根到某节点的路径，前缀自由恰好说「码字节点互不为祖先」，于是可以把所有码字放在叶子上（内部节点上的码字可以下移到叶子而不破坏前缀性）。

**定理 1.4**（Kraft 不等式，1949）。任何二元前缀码的码长 ${l_1, \ldots, l_m}$ 满足

$$
\sum_{i=1}^{m} 2^{-l_i} \;\le\; 1
$$

**证明**（区间切分）。把码字 ${c = c_1 c_2 \cdots c_l}$ 对应到单位区间里的二进制小数区间

$$
J(c) \;=\; \Big[\, 0.c_1 c_2 \cdots c_l,\ \ 0.c_1 c_2 \cdots c_l + 2^{-l} \,\Big) \;\subset\; [0, 1)
$$

这是长度 $2^{-l}$ 的二进区间（dyadic interval）；在树的语言里，深度 $l$ 的节点恰好对应一个长 $2^{-l}$ 的区间，其左右孩子把它对半切开。关键观察：**$c$ 是 ${c'}$ 的前缀当且仅当 ${J(c') \subseteq J(c)}$**——前缀意味着 ${c'}$ 的小数展开以 $c$ 的展开开头，于是落在 $J(c)$ 内；反过来两个二进区间要么不相交要么嵌套（树上两个节点要么无祖先关系要么一个是另一个的祖先），嵌套就是前缀。所以前缀自由等价于 $m$ 个区间 ${J(c_i)}$ 两两不交。不交的子区间总长不超过 $[0, 1)$ 的长，即 ${\sum_i 2^{-l_i} \le 1}$。$\blacksquare$

**读法**：每个码字在 $[0, 1)$ 上「圈地」$2^{-l_i}$，长码字圈小地、短码字圈大地；前缀自由＝地块不重叠；总地只有 1。这就是为什么不能既有太多短码字又前缀自由——短码字太贪地。取等当且仅当地块铺满 $[0, 1)$，树的语言是「每个内部节点都有两个孩子」。

**定理 1.5**（Kraft 的逆）。若正整数 ${l_1 \le l_2 \le \cdots \le l_m}$ 满足 ${\sum_i 2^{-l_i} \le 1}$，则存在以它们为码长的前缀码。

**证明**（构造）。令 ${s_1 = 0}$，${s_i = \sum_{j < i} 2^{-l_j}}$（前 ${i-1}$ 块地的累计长度）。取 $c_i$ 为 $s_i$ 的二进制展开的前 $l_i$ 位。要验证两件事：

1. $c_i$ 精确代表 $s_i$（不需要第 $l_i$ 位之后的位）：因为 ${l_j \le l_i}$ 对所有 ${j < i}$ 成立，每个 $2^{-l_j}$ 都是 $2^{-l_i}$ 的整数倍，和 $s_i$ 也是；于是 $s_i$ 的二进制展开在第 $l_i$ 位之后全为零。
2. 前缀自由：$J(c_i)$ 恰是 ${[s_i, s_i + 2^{-l_i})}$，而 ${s_{i+1} = s_i + 2^{-l_i}}$，所以这些区间首尾相接、两两不交，且由 ${s_m + 2^{-l_m} = \sum_i 2^{-l_i} \le 1}$ 全部落在 $[0, 1)$ 内；由定理 1.4 证明中的等价性，不交即前缀自由。$\blacksquare$

**在一组码长上走一遍**：码长 ${\{1, 2, 3, 3\}}$，Kraft 和 ${1/2 + 1/4 + 1/8 + 1/8 = 1}$。累计 ${s = 0,\ 1/2,\ 3/4,\ 7/8}$，二进制 ${0.0,\ 0.10,\ 0.110,\ 0.111}$，截前 ${l_i}$ 位得码字 ${0,\ 10,\ 110,\ 111}$——正是一条「梳子」形的树。§1.5 的 Huffman 锚例码长 ${\{1, 2, 3, 3\}}$ 也是这组。

**McMillan 推广**（陈述级）：把「前缀码」放宽到「唯一可译码」（任何码字串只有一种切法），Kraft 不等式依然成立（Cover–Thomas《Elements of Information Theory》定理 5.5.1）。配合定理 1.5，这意味着**放弃即时性换不来更短的码长**——任何唯一可译码的码长表都能被某个前缀码照搬。所以本册后面只谈前缀码，不吃亏。

**本节小结**：前缀码＝树上叶子＝单位区间上不重叠的二进地块；Kraft 不等式是「总地只有 1」；逆命题靠「按长度排序、首尾相接地圈」构造出来。有了「哪些码长可行」的判据，才能问「可行码长里最短的平均有多长」。

## $\rm \S \, 1.4$ 信源编码定理第一版：${H \le L < H + 1}$（本章主证）

**白话**：Kraft 把前缀码的码长集合刻画成了一个凸区域，平均码长是这个区域上的线性函数，于是「最优码长」是一个带约束的最小化问题。它的答案出奇干净：最小值不小于熵，而且用「把 ${\log_2 (1/p)}$ 向上取整」这一个粗暴动作就能逼到熵加一以内。

**定理 1.6**（Shannon，1948；信源编码定理第一版）。设 $X$ 的分布为 $p$，熵 $H(X)$。

1. **下界**：任何前缀码的平均码长满足 ${L \ge H(X)}$，取等当且仅当 ${l(x) = -\log_2 p(x)}$ 对所有 $x$ 成立（即 $p$ 是**二进分布**，每个 $p(x)$ 是 2 的整数次幂）。
2. **上界**：存在前缀码使 ${L < H(X) + 1}$。

**证明（下界）**。设码长 ${l_i = l(x_i)}$，${p_i = p(x_i)}$，${q_i = 2^{-l_i}}$。由 Kraft，${\sum_i q_i \le 1}$。计算

$$
\begin{aligned}
L - H(X) &= \sum_i p_i l_i + \sum_i p_i \log_2 p_i
= \sum_i p_i \log_2 \frac{p_i}{2^{-l_i}}
= -\sum_i p_i \log_2 \frac{q_i}{p_i} \\
&\ge -\log_2 \Big( \sum_i p_i \cdot \frac{q_i}{p_i} \Big)
= -\log_2 \sum_i q_i
\;\ge\; -\log_2 1 \;=\; 0
\end{aligned}
$$

第一行是代数整理（把 $l_i$ 写成 ${-\log_2 2^{-l_i}}$ 合并到一个对数里）；第二行第一个不等号是 Jensen（$\log_2$ 凹，${\mathrm{E}[\log_2 Z] \le \log_2 \mathrm{E}[Z]}$，这里 ${Z = q_i / p_i}$ 以概率 $p_i$ 取值）；第二个不等号是 Kraft。取等条件：Jensen 取等要求 ${q_i / p_i}$ 为常数，Kraft 取等要求 ${\sum q_i = 1}$，两者合起来就是 ${q_i = p_i}$，即 ${l_i = -\log_2 p_i}$。$\blacksquare$

**读法**：这行证明的灵魂是把「码长表」${\{2^{-l_i}\}}$ 看成一个（亏损的）概率分布 $q$，然后 ${L - H}$ 就是 $p$ 相对于 $q$ 的「偏离」；第 2 章会给这个偏离起名 KL 散度并证它非负——本章只借了它的 Jensen 内核。白话地说：**用错了分布编码（按 $q$ 分码长而真实是 $p$），每符号多付的位数恰是 $p$ 到 $q$ 的 KL 距离**。

**证明（上界）**。取 **Shannon–Fano 码长** ${l_i = \lceil \log_2 (1/p_i) \rceil}$（向上取整）。先验 Kraft：

$$
\sum_i 2^{-l_i} \;\le\; \sum_i 2^{-\log_2 (1/p_i)} \;=\; \sum_i p_i \;=\; 1
$$

（取整向上使指数 ${-l_i \le -\log_2 (1/p_i)}$）。由定理 1.5，存在前缀码实现这组码长。再算平均：

$$
L \;=\; \sum_i p_i \Big\lceil \log_2 \frac{1}{p_i} \Big\rceil \;<\; \sum_i p_i \Big( \log_2 \frac{1}{p_i} + 1 \Big) \;=\; H(X) + 1
$$

用了 ${\lceil t \rceil < t + 1}$。$\blacksquare$

**读法**：那个「$+1$」是**舍入税**——理想码长 ${\log_2 (1/p_i)}$ 一般不是整数，而码长必须是整数，每个符号最多亏一位。六面骰的 ${\log_2 6 = 2.585}$ 就是这样：单个符号编码至少 3 位，亏 0.415。第 3 章的块编码把 $n$ 个符号打包、把这一位的税摊到 $n$ 个符号上，税率降到 $1/n$，这正是「熵＝每符号极限位数」的严格含义。

**定理读作一句话**：最优前缀码的平均码长 $L^*$ 被夹在 ${[H, H + 1)}$ 里。下界对所有码成立（是一条极限），上界由一个具体构造达到（是一条可行性）。

**本节小结**：下界＝Kraft＋Jensen（码长表当分布、偏离非负），上界＝Shannon–Fano 取整＋Kraft 逆。熵是编码位数的极限这件事，到此有了第一个严格版本，余量一比特。

## $\rm \S \, 1.5$ Huffman 构造：把上界真正造出来

**白话**：Shannon–Fano 保证了「$H + 1$ 以内」，但它只是「可行」不是「最优」。最优前缀码有一个贪心算法：反复把两个最不常见的符号捆成一个「合成符号」，直到只剩一个，再把捆的过程倒放成一棵树。它的直觉是「最不常见的两个符号活该用最长的码，而且码长可以相同、只差最后一位」。

**算法 1.1**（Huffman，1952）。输入字母表 $\mathcal{X}$ 与概率 $p$：

1. 把每个符号作为一棵单节点树，权重为它的概率，放进一个按权重排序的集合。
2. 取出权重最小的两棵树 $T_1$、$T_2$（${w(T_1) \le w(T_2)}$），新建一个根，$T_1$ 挂在 0 边、$T_2$ 挂在 1 边，权重 ${w(T_1) + w(T_2)}$，放回集合。
3. 重复第 2 步直到集合只剩一棵树；每个符号的码字＝从根到它的叶子沿途读下的 0/1 串。

**定理 1.7**（Huffman 最优性，陈述级）。Huffman 码在所有前缀码中平均码长最小。

**证明思路**（Cover–Thomas 定理 5.8.1，两步）：第一步，任何最优码里两个最小概率的符号可以安排成同深度的兄弟叶子（否则把它们与最深层的叶子交换不会增加平均码长）；第二步，把这两个符号捆成一个符号后，原问题的最优码与缩小后问题的最优码只差一个固定常数（捆成符号的概率），于是归纳到 ${m - 1}$ 个符号。两步合起来，每一次「捆最小两个」都不损失最优性。

**在锚例上走一遍**：分布 ${\{a: 0.4,\ b: 0.35,\ c: 0.15,\ d: 0.1\}}$。

1. 最小两个：$d$（0.1）与 $c$（0.15），捆成 $dc$（0.25），$d$ 挂 0、$c$ 挂 1。集合变 ${\{a: 0.4,\ b: 0.35,\ dc: 0.25\}}$。
2. 最小两个：$dc$（0.25）与 $b$（0.35），捆成 $dcb$（0.60），$dc$ 挂 0、$b$ 挂 1。集合变 ${\{a: 0.4,\ dcb: 0.60\}}$。
3. 最后：$a$（0.4）与 $dcb$（0.60），$a$ 挂 0、$dcb$ 挂 1。根权重 1.0。

倒放成树、读码字：${a = 0}$，${b = 11}$，${c = 101}$，${d = 100}$。三项对账（本机实测）：

1. 平均码长 ${L = 0.4 \times 1 + 0.35 \times 2 + 0.15 \times 3 + 0.1 \times 3 = 1.85}$；
2. 熵 ${H = 1.801609}$，于是 ${1.801609 \le 1.85 < 2.801609}$，定理 1.6 两端都对；
3. Kraft 和 ${2^{-1} + 2^{-2} + 2^{-3} + 2^{-3} = 1}$，恰好取等——Huffman 树每个内部节点都有两个孩子，地块铺满 $[0, 1)$。

**读法**：$L - H = 0.048391$ 比特，远小于 1——Huffman 的实际余量通常比定理 1.6 的「$+1$」小得多；但余量不会为零，因为 ${\log_2 (1/0.4) = 1.321928}$ 不是整数，$a$ 用 1 位「占了便宜」、$c$ 用 3 位「吃了亏」（理想 2.736966），两边抵不平。对比 Shannon–Fano 码长 ${\lceil 1.32 \rceil, \lceil 1.51 \rceil, \lceil 2.74 \rceil, \lceil 3.32 \rceil = 2, 2, 3, 4}$，平均 ${2.35}$——比 Huffman 的 1.85 差 0.5 位，这就是「可行」与「最优」的距离。

**三个实现提醒**（OI 现场）：

1. 用小根堆维护集合，总复杂度 ${O(m \log m)}$；权重相等时合并顺序不唯一，不同的平局处理给出不同的码表，但平均码长相同。
2. 平均码长可以不建树直接算：每次合并时把新权重累加进一个总和，最后的总和就是 $L$（每个叶子的权重恰好被加了「深度」次）。§1.6 的程序段两种都算、互相校验。
3. 频率是整数时全程用整数避免浮点比较；$k$ 元 Huffman（每次捆 $k$ 个）要先补虚拟零权符号使 ${(m - 1) \bmod (k - 1) = 0}$，否则根的孩子不满。

**本节小结**：Huffman 用「捆最小两个」贪心造出最优前缀码；锚例上 ${H = 1.801609 \le L = 1.85}$、Kraft 和恰 1。定理 1.6 的上界由它兑现，且通常远优于「$+1$」。

## $\rm \S \, 1.6$ 程序段：Huffman 构建与熵对账

程序（纯 Python，堆实现，断言 §1.5 的三项对账）。两条独立路径算 $L$：一条按码字长度加权，一条按合并时累加权重。两者相等是对「每个叶子的权重被加了深度次」的直接验证：

```python
import heapq
from math import log2

P = {"a": 0.4, "b": 0.35, "c": 0.15, "d": 0.1}

def entropy(p):
    return -sum(v * log2(v) for v in p.values() if v > 0)

def huffman(p):
    # 堆元素 (权重, 序号, 节点)；序号只为打破平局、保证确定性
    heap = [(w, i, (sym,)) for i, (sym, w) in enumerate(p.items())]
    heapq.heapify(heap)
    nxt = len(heap)
    merged_total = 0.0
    while len(heap) > 1:
        w1, _, t1 = heapq.heappop(heap)   # 较轻的挂 0
        w2, _, t2 = heapq.heappop(heap)   # 较重的挂 1
        merged_total += w1 + w2
        heapq.heappush(heap, (w1 + w2, nxt, (t1, t2)))
        nxt += 1
    root = heap[0][2]
    codes = {}
    def walk(node, prefix):
        if len(node) == 1 and isinstance(node[0], str):
            codes[node[0]] = prefix or "0"
        else:
            walk(node[0], prefix + "0")
            walk(node[1], prefix + "1")
    walk(root, "")
    return codes, merged_total

codes, L_by_merge = huffman(P)
L_by_len = sum(P[s] * len(c) for s, c in codes.items())
kraft = sum(2.0 ** (-len(c)) for c in codes.values())
H = entropy(P)
print("codes =", codes)
print("L(len) = %.6f  L(merge) = %.6f  H = %.6f  Kraft = %.6f"
      % (L_by_len, L_by_merge, H, kraft))
assert codes == {"a": "0", "b": "11", "c": "101", "d": "100"}
assert abs(L_by_len - 1.85) < 1e-12 and abs(L_by_merge - 1.85) < 1e-12
assert H <= L_by_len < H + 1 and abs(kraft - 1.0) < 1e-12
# 前缀自由性：任何码字不是另一个的前缀
ws = list(codes.values())
assert not any(u != v and v.startswith(u) for u in ws for v in ws)
```

实跑输出：

```text
codes = {'a': '0', 'd': '100', 'c': '101', 'b': '11'}
L(len) = 1.850000  L(merge) = 1.850000  H = 1.801609  Kraft = 1.000000
```

读这段代码核对三件事：

1. `heappop` 两次的顺序决定了 0/1 的分配——较轻的先出堆、挂 0，这是 §1.5 走法里「$d$ 挂 0、$c$ 挂 1」的代码对应；换成较重挂 0 会得到 ${a = 1,\ b = 00,\ \ldots}$，码长表不变。
2. `merged_total` 与 `L_by_len` 相等验证了 §1.5 实现提醒 2；
3. 最后一行断言是定义 1.4 的直接检查——前缀自由不是「看起来对」，是逐对核过的。

**换一个分布自己跑**：把 `P` 换成六面骰均匀 ${\{1/6\} \times 6}$，Huffman 给出两个 2 位码和四个 3 位码，${L = 2.666667}$，${H = 2.584963}$——余量 0.081704，仍小于 1 但不为零。换成二进分布 ${\{1/2, 1/4, 1/8, 1/8\}}$，${L = H = 1.75}$，余量恰为零，这就是定理 1.6 的取等条件现身。

## $\rm \S \, 1.7$ 关键概念回顾

1. 自信息 ${-\log_2 p}$ 的三条设计要求各是什么？哪一条逼出了对数？（§1.1）
2. ${H(X) \le \log_2 |\mathcal{X}|}$ 的 Jensen 证明把哪个量当成了随机变量？取等条件是什么？（§1.2）
3. 链式法则 ${H(X, Y) = H(X) + H(Y \mid X)}$ 对应概率论里的哪条公式？（§1.2）
4. Kraft 不等式的区间证明里，「前缀」翻译成了区间的什么关系？逆命题的构造为什么要先按长度排序？（§1.3）
5. ${L \ge H}$ 的证明把码长表 ${\{2^{-l_i}\}}$ 看成了什么？两个不等号各来自哪里？（§1.4）
6. Shannon–Fano 码长怎么取？「$+1$」的来源是什么，第 3 章用什么办法消掉它？（§1.4）

## $\rm \S \, 1.8$ 本章自测答案

1. 随概率单调递减、连续、独立事件可加；「可加」要求把概率的乘积变成和，唯一解是对数。（§1.1）
2. 把 ${Z = 1/p(X)}$ 当随机变量，${H = \mathrm{E}[\log_2 Z] \le \log_2 \mathrm{E}[Z] = \log_2 |\operatorname{supp} p|}$；取等当且仅当 $Z$ 为常数，即均匀。（§1.2）
3. 乘法公式 ${p(x, y) = p(x)\, p(y \mid x)}$ 取对数后对联合分布求期望。（§1.2）
4. 「$c$ 是 ${c'}$ 的前缀」翻译成「${J(c') \subseteq J(c)}$」，前缀自由＝区间两两不交，总长 ${\le 1}$；排序保证累计和 $s_i$ 是 $2^{-l_i}$ 的整数倍，截前 $l_i$ 位不丢信息。（§1.3）
5. 看成一个亏损分布 $q$（${\sum q_i \le 1}$）；第一个不等号是 Jensen（$\log$ 凹），第二个是 Kraft。（§1.4）
6. ${l_i = \lceil \log_2 (1/p_i) \rceil}$；来自向上取整每符号最多亏 1 位；第 3 章把 $n$ 个符号打包编码，税摊成 $1/n$。（§1.4）

**带走清单**：自信息 ${-\log_2 p}$ 由「乘变加」唯一确定；熵＝其期望，${0 \le H \le \log_2 |\mathcal{X}|}$；链式法则；前缀码＝树叶＝不重叠二进地块，Kraft ${\sum 2^{-l_i} \le 1}$ 及其逆（排序圈地构造）；信源编码定理第一版 ${H \le L^* < H + 1}$（下界 Kraft＋Jensen、上界 Shannon–Fano 取整）；Huffman 贪心＝最优前缀码；锚 ${\{0.4, 0.35, 0.15, 0.1\}}$：码 ${\{0, 11, 101, 100\}}$、${L = 1.85}$、${H = 1.801609}$、Kraft 和 1。
