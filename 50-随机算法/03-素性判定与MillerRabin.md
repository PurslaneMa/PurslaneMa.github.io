# $\rm Chapter \, 3$ 素性判定与 Miller–Rabin

要判定 $10^{18}$ 附近的数是不是素数，试除法要除到 $10^9$——天文数字次除法，一秒都活不下来。可如果允许掷硬币，同一件事几十行代码、几十次模幂就做完了，还把错误概率压到比宇宙寿命里出错一次还小。素性判定是随机算法最漂亮的战例：它不靠「碰运气」而是靠数论结构，把「合数总有办法露馅」这句直觉拧成一个 $1/4$ 的定量界。本章从费马小定理出发，踩过伪素数与 Carmichael 数的两个坑，落到 Miller–Rabin 的完整证明，最后看它怎么变成 RSA 生成长素数的接口。

> **开始前自检**：本章假设你已经会：
>
> 1. □ 模运算与费马小定理：$p$ 素数、$\gcd(a,p)=1$ 时 $a^{p-1} \equiv 1 \pmod p$（本站数论册第 1 章）。
> 2. □ 中国剩余定理与乘法群 $(\mathbb{Z}/n\mathbb{Z})^*$：$n = \prod p_i^{e_i}$ 时它同构于各 $(\mathbb{Z}/p_i^{e_i}\mathbb{Z})^*$ 的直积（数论册第 1 章）。
> 3. □ 快速幂：$a^b \bmod n$ 在 $O(\log b)$ 次模乘内算完（任意算法入门材料）。
> 4. □ 第 2 章的高概率口径与联合界，以及第 1 章「重复取多数票把错误率自放大」的算术。
>
> 第 1、2 条是本章的脚手架，不熟先回数论册补齐。

## $\rm \S \, 3.1$ 从试除到 Fermat 测试

试除法的账很清楚：判 $n$ 素性要试到 $\sqrt n$ 个候选因子，$n = 10^{18}$ 时是 $10^9$ 次除法，单机跑不动，更别说 RSA 用的 $2048$ 位整数。要绕开它，得换一个**不去找因子**的判据。

**费马小定理**给了第一块砖：$p$ 素数、$\gcd(a,p)=1$，则 $a^{p-1} \equiv 1 \pmod p$。逆否一下就是判据：**若存在 $a$ 使 $a^{n-1} \not\equiv 1 \pmod n$，则 $n$ 必是合数**，且 $a$ 称为 $n$ 的一个**证人（witness）**。取 $a = 2$、快速幂算 $2^{n-1} \bmod n$，$O(\log n)$ 次模乘就出结果，比试除快得离谱。

$$
p \text{ 素数},\ \gcd(a,p)=1 \ \Longrightarrow\ a^{p-1} \equiv 1 \pmod p;\qquad \text{逆否：}\ \exists a,\ a^{n-1} \not\equiv 1 \pmod n \ \Longrightarrow\ n \text{ 合数}.
$$

问题在于**逆命题不成立**：费马测试只能「有时报合数」，从不保证「报素数」就是素数。合数里有一部分能蒙混过关：

**例题 3.1（基 2 的伪素数 341）**：$341 = 11 \times 31$ 是合数，却满足 $2^{340} \equiv 1 \pmod{341}$。验算用费马小定理对两个因子分别看：$2^{10} \equiv 1 \pmod{11}$（$2^{10} = 1024 = 93\cdot11 + 1$）且 $10 \mid 340$，故 $2^{340}\equiv1\pmod{11}$；再看模 $31$，$2^5 = 32 \equiv 1 \pmod{31}$，故 $2^{340} = (2^5)^{68}\equiv1\pmod{31}$。两式由中国剩余定理合并，得 $2^{340}\equiv1\pmod{341}$。**所以 $341$ 骗过了基 2 的费马测试**，这类合数叫**基 $a$ 的费马伪素数（Fermat pseudoprime）**。

伪素数并不稀少（$10^9$ 以内基 2 的伪素数有上万个），单靠随机换基也不行——因为存在一类合数，**对所有**与它互素的基都能骗过费马测试。

顺带记住伪素数的一个用途：它是判素算法测试集的**天然靶子**——任何新写的判素实现，都要先在已知伪素数上不翻车（$341$、$2047$、$3215031751$ 这类数是后面验收实现的固定样本）。

**本节小结**：费马小定理给出 $O(\log n)$ 的判据，但逆命题有漏洞（$341$）；漏洞的极端形态是下一节的 Carmichael 数。

## $\rm \S \, 3.2$ Carmichael 数与更强的测试

**Carmichael 数**是最坏的一类合数：$n$ 合数，但对**一切**满足 $\gcd(a,n)=1$ 的基 $a$ 都有 $a^{n-1}\equiv1\pmod n$。费马测试对它们彻底失效，无论换多少个基。

**例题 3.2（最小的 Carmichael 数 561）**：$561 = 3 \times 11 \times 17$。逐个验证「$p - 1 \mid 560$」：$3-1=2 \mid 560$、$11-1=10 \mid 560$、$17-1=16 \mid 560$。这三条正是 **Korselt 判据**——$n$ 平方自由、且对每个素因子 $p$ 有 $p-1 \mid n-1$，等价于 $n$ 是 Carmichael 数。于是对任意 $\gcd(a,561)=1$：模 $3$ 时 $a^2\equiv1 \Rightarrow a^{560}=(a^2)^{280}\equiv1$；模 $11$ 时 $a^{10}\equiv1 \Rightarrow a^{560}=(a^{10})^{56}\equiv1$；模 $17$ 时 $a^{16}\equiv1 \Rightarrow a^{560}=(a^{16})^{35}\equiv1$。三个同余由中国剩余定理合并，$a^{560}\equiv1\pmod{561}$。**任何基都骗得过费马测试**（$561$ 的 $319$ 个互素基全是骗子）。

$$
n \text{ 是 Carmichael 数} \iff n = p_1 p_2 \cdots p_k \text{（平方自由）且 } p_i - 1 \mid n - 1 \ (\forall i).
$$

出路是加一道**平方根**的检查。观察费马小定理的证明路径：$a^{n-1}\equiv1$ 时，若 $n$ 素数，则 $a^{(n-1)/2}$ 只能取 $\pm1$（因 $x^2\equiv1$ 在**域**里只有两个解）。把这个性质递归地用下去，就是**强伪素数测试**：

**定义 3.3（强伪素数）**：写 $n - 1 = 2^s d$（$d$ 奇）。基 $a$ 判 $n$ 为合数，若 $a^d \not\equiv 1$ 且对一切 $0 \le r < s$ 有 $a^{2^r d} \not\equiv -1 \pmod n$；否则称 $n$ 是**基 $a$ 的强伪素数（strong pseudoprime）**。这套判据就是 Miller–Rabin 测试。

白话：把 $a^{n-1}$ 的开方过程摊成一条链 $a^d, a^{2d}, a^{4d}, \ldots, a^{n-1}$，若 $n$ 素数，这条链末端是 $1$、且**首次出现的 $1$ 的前一项必须是 $-1$**（否则就撞上了一个非平凡的平方根）——强测试就是沿链检查这一步。

$$
a^d \ \longrightarrow\ a^{2d} \ \longrightarrow\ a^{4d} \ \longrightarrow\ \cdots\ \longrightarrow\ a^{2^s d} = a^{n-1} \equiv 1 \pmod n.
$$

**本节小结**：Carmichael 数（$561$）让费马测试对任何基都失效；补救办法是沿「平方链」检查 $-1$，得到强伪素数判据，即 Miller–Rabin。

## $\rm \S \, 3.3$ Miller–Rabin 全证（本章主证）

**算法（Miller–Rabin）**：输入奇数 $n > 2$、重复次数 $k$。
1. 写 $n - 1 = 2^s d$，$d$ 奇。
2. 随机取 $a \in \{2, \ldots, n-2\}$，算 $x = a^d \bmod n$。
3. 若 $x = 1$ 或 $x = n-1$，本基通过，换下一个基。
4. 否则做 $s - 1$ 次 $x \leftarrow x^2 \bmod n$，每次检查是否 $= n-1$；命中则通过，始终不中则**判 $n$ 合数**。
5. $k$ 个基全通过则报「素数」。

正确性一侧是干净的：**若 $n$ 素数，任何基都不会误判**（链上不会出现非平凡的 $1$ 的平方根）。所以 Miller–Rabin 是单边错误，落在 $\mathrm{co\text{-}RP}$ 里（第 1 章 §1.5）。要证明的另一侧是错误率。

**定理 3.4（Monier–Rabin）**：$n$ 为奇合数时，使 Miller–Rabin 接受的基 $a \in \{2, \ldots, n-2\}$ 至多占总数的 $\frac14$。

证明分四步，核心是「有限阿贝尔群上 $1$ 的平方根至多两个（真正素数时），合数时多出来的非平凡平方根正是证人」。

**第一步（骗子都在一个子群里）。** 记 $G = (\mathbb{Z}/n\mathbb{Z})^*$、$|G| = \varphi(n)$。骗子基必过费马检验，即 $a^{n-1} \equiv 1 \pmod n$，故骗子集 $L$ 落在

$$
H = \{\, a \in G : a^{n-1} = 1 \,\}
$$

里。$H$ 是同态 $a \mapsto a^{n-1}$ 的核，因而是 $G$ 的子群。这一步把「全空间」压进一个子群，是全部计数的地基。

**第二步（平方链与 $1$ 的平方根）。** 对 $a \in G$，若 $a^{n-1} \neq 1$，$a$ 是费马证人、自然是 MR 证人。故只需数 $H$ 内的骗子。对 $a \in H$，定义 $j(a) = \min\{ j \ge 0 : a^{2^j d} = 1 \}$（存在，$\le s$）。若 $j(a) = 0$，链的第一步就是 $1$，MR 通过——这是骗子的一种。若 $j(a) \ge 1$，则 $u = a^{2^{j(a)-1} d}$ 是 $1$ 的平方根（$u^2 = a^{2^{j(a)}d} = 1$），MR 通过当且仅当 $u = -1$。所以

$$
L = \{\, a \in H : j(a) = 0 \text{ 或 } a^{2^{j(a)-1}d} = -1 \,\}.
$$

读法：MR 能抓住的，正是那些「链首次回到 $1$ 之前撞上了非平凡平方根」的基；抓不住的是「回到 $1$ 之前只经过 $\pm1$」的基。**这就是强测试比费马测试多的那件武器。**

**第三步（合数里非平凡平方根足够多）。** $x^2 \equiv 1 \pmod n$ 的解数恰好是 $2^{\omega(n)}$，其中 $\omega(n)$ 是 $n$ 的不同素因子个数：由中国剩余定理，模每个素幂 $p_i^{e_i}$ 时 $x = \pm1$，各二选一。当 $n$ 不是素幂（合数必满足，除非 $n = p^e$）时 $\omega(n) \ge 2$，解数 $\ge 4$，于是除 $x = \pm1$ 外还有**非平凡平方根**。这些非平凡平方根散布在 $G$ 里，一旦链经过它们，MR 立刻判合数。

**第四步（计数 $|L| \le \varphi(n)/4$）。** 精确计数归 Monier（1980）与 Rabin（1980）：在 $H$ 内部，第二步那条链「首次回 $1$ 的前一项」均匀地落在一组平方根上，第三步的非平凡平方根使得「只经过 $\pm1$」的 $a$ 至多占 $H$ 的一半；若 $H \neq G$（$n$ 非 Carmichael），第一步已先砍掉至少一半，两者相乘得 $|L| \le \varphi(n)/4$。代入 $|L|/(n-1) \le \varphi(n)/(4(n-1)) \le \frac14$，定理成立。$\blacksquare$

**错误概率的乘法。** 独立取 $k$ 个随机基，全部是骗子的概率 $\le 4^{-k}$。取 $k = 20$ 得 $4^{-20} \approx 9.1 \times 10^{-13}$，取 $k = 40$ 得 $4^{-40} \approx 8.3 \times 10^{-25}$——比宇宙寿命里出错一次还小得多。与第 1 章「单边错误重复取或」不同，这里每次重复是独立的、取**与**（全通过才报素数），错误率按 $4^{-k}$ 下降。

$$
\Pr[\text{MR 误判}] \le \left(\frac14\right)^k = 4^{-k}:\qquad k = 20 \Rightarrow 9.1\times10^{-13},\qquad k = 40 \Rightarrow 8.3\times10^{-25}.
$$

**本节小结**：MR 的证明路线是「骗子落进子群 $H$」→「链检查等价于检测非平凡平方根」→「合数有 $\ge 4$ 个 $1$ 的平方根」→「Monier 计数给 $\le \varphi(n)/4$」；重复 $k$ 次错误率 $4^{-k}$。

## $\rm \S \, 3.4$ 数值锚：强伪素数、骗子率与确定性基组

**基 2 的强伪素数表**（程序实算，判据用定义 3.3，$< 4000$ 全扫）：

| 强伪素数 $n$ | 分解 | 为何骗过基 2 |
| --- | --- | --- |
| $2047$ | $23 \times 89$ | $n-1 = 2\cdot1023$，$2^{1023} \equiv -1 \pmod{2047}$，链首项即 $-1$ |
| $3277$ | $29 \times 113$ | $n-1 = 4\cdot819$，链上某步首达 $-1$ |

$<4000$ 的基 2 强伪素数**恰为 $\{2047, 3277\}$**（$2047 = 23\times89$、$3277 = 29\times113$），比同范围的费马伪素数少得多——强测试确实更严。

**骗子基的比例实测**。对 $<2\times10^4$ 的全部奇合数，统计「使 MR 接受的基占全部基的比例」：平均只有 $0.0025$（远低于 $1/4$ 的上界），最大值出现在 $n = 12403 = 79 \times 157$ 处，达到 $0.2452$——几乎顶到 $\frac14$ 的理论上界，说明这条界**是紧的**，不是宽松的估计。对 $<2\times10^5$ 的奇合数，单基 $2$ 的骗子比例只有 $0.00023$，单基 $3$ 是 $0.00037$：典型情形下单个基的错误率比 $1/4$ 小两三个数量级，$1/4$ 是最坏情形的兜底。

**确定性基组**一句话：对 $n < 3\,317\,044\,064\,679\,887\,385\,961\,981 \approx 3.3\times10^{24}$，依次用基 $\{2,3,5,7,11,13,17\}$ 这 $7$ 个做 MR，**全通过当且仅当 $n$ 素数**，不必用随机性（Jaeschke 1993；Sorenson–Webster 2015）。$64$ 位整数只在前几个基上就够，这也是竞赛与工程里最常见的写法。

$$
n \text{ 合数} \ \Longrightarrow\ \exists\, a \in \{2,3,5,7,11,13,17\} \text{ 使 MR 判 } n \text{ 合数},\qquad n < 3.3\times10^{24}.
$$

**本节小结**：$<4000$ 的基 2 强伪素数只有 ${2047, 3277}$；骗子率平均远低于 $1/4$、最坏可达 $0.2452$ 说明界紧；小范围可用 $7$ 个确定性基省掉随机性。

## $\rm \S \, 3.5$ 从素性到构造：随机生成大素数

有了快速判素，就能反过来**造**素数：RSA 需要生成 $1024$ 位或 $2048$ 位的随机大素数。

做法直接：反复取随机奇数 $N$（首尾位钉成 $1$），对每个候选做 MR，第一个通过的就是素数。代价由**素数密度**决定：$N$ 附近素数的比例约 $\frac{1}{\ln N}$，所以期望试约 $\ln N$ 个候选。$N \approx 2^{2048}$ 时 $\ln N \approx 2048 \ln 2 \approx 1419.4$，即平均试一千四百多个奇数——每个候选只用几次模幂，秒级完成。

$$
\Pr[N \text{ 素} \mid N \text{ 随机奇}] \approx \frac{2}{\ln N},\qquad \mathbb{E}[\text{试次数}] \approx \frac{\ln N}{2} \approx 710.
$$

读法：钉掉偶数和 $5$ 的倍数后，期望试次数再降常数倍；关键是「期望试 $\ln N$ 个」这条账，它让「随机撞出一个大素数」从异想天开变成一个多项式时间的常规操作。这就是 RSA 的随机算法接口：**素性判定（Monte Carlo）＋ 随机搜索（Las Vegas，一定找到）**，接口的另一端在密码学册第 6 章展开。

生成算法的骨架也顺手写清：反复取随机奇数 $N$（首位钉成 $1$、末位避开 $5$），跑 $k$ 轮 MR，全通过就输出、否则换下一个。这是标准的 Las Vegas 外壳——输出一定是素数（MR 对素数零误判），期望代价 $\Theta(\ln N)$ 个候选、每个候选 $O(k\log N)$ 次模乘。

**本节小结**：随机生成大素数 = 随机取奇候选 + MR 判素，期望试 $\ln N$ 个；素数密度 $1/\ln N$ 是把「构造」压成多项式时间的那条账。

## $\rm \S \, 3.7$ 应用与辨析

1. 有同学说「费马测试对基 $2$ 失败，那我随机多换几个基就好了」。用 Carmichael 数 $561$ 说明这个策略为何无效。
2. 判定 $n = 9$ 的素性：写出 $n-1 = 2^3\cdot1$，列出所有基 $a \in \{2,\ldots,7\}$ 的平方链，指出哪些是骗子、哪些是证人，并核对骗子比例不超过 $1/4$。
3. 某同学把 Miller–Rabin 的「$s-1$ 次平方」写成「$s$ 次平方」，即多检查一步 $x^2 = a^{2^s d} = a^{n-1}$。这会不会引入错误？为什么。
4. 用 $7$ 个确定性基 $\{2,3,5,7,11,13,17\}$ 判素，为什么在 $n < 3.3\times10^{24}$ 上是**确定**正确的、而在更大范围只能当高概率使用？
5. 生成 $2048$ 位素数时，把候选限制成「末位是 $1$ 或 $3$ 或 $7$ 或 $9$」（跳过偶数与 $5$ 的倍数）后，期望试次数大约变多少？说明这条优化的来源。
6. 若把 MR 的随机基改成「只取前几个小素数 $2,3,5,7,\ldots$」，对 $n < 3.3\times10^{24}$ 有什么好处与风险？对更大的 $n$ 呢？

## $\rm \S \, 3.8$ 本章自测答案

> 先闭卷作答 $\S3.6$ 与 $\S3.7$，再核对。

### $\rm \S \, 3.8.1$ 关键概念回顾答案

1. 费马小定理断言素数必过 $a^{n-1}\equiv1$，逆否给出「有基不过 ⇒ 合数」。逆命题失效处是费马伪素数：合数也能通过，$341 = 11\times31$ 是基 $2$ 的反例。（$\S3.1$）
2. Korselt：$n$ 平方自由且每个素因子 $p$ 满足 $p-1 \mid n-1$。$561$ 的 ${2,10,16}$ 都整除 $560$，故成立。Carmichael 数对每个互素基都过费马检验，因为针对每个 $p_i$ 的阶都整除 $n-1$、再由中国剩余定理合并。（$\S3.2$）
3. 平方链检查「$a^{n-1}$ 的开方过程中是否撞上非平凡的 $1$ 的平方根」。素数域里 $x^2\equiv1$ 只有 $\pm1$，故链首达 $1$ 前一步必是 $-1$；合数有非平凡平方根，链一旦经过就被判合数。（$\S3.2$、$\S3.3$）
4. 四步：骗子落进子群 $H$；链检查等价于检测非平凡平方根；合数解数 $2^{\omega(n)}\ge4$；Monier 计数得 $\le\varphi(n)/4$。$x^2\equiv1$ 有 $2^{\omega(n)}$ 个解，非平凡解正是证人来源。（$\S3.3$）
5. 因为存在 $n = 12403 = 79\times157$ 使骗子率 $0.2452$，几乎顶到 $1/4$，说明界紧、不能再改进。（$\S3.3$、$\S3.4$）
6. 独立取 $k$ 个基、要求全通过，故「全骗」概率 $\le(1/4)^k = 4^{-k}$。与「取或」不同：取或放大另一侧错误，取与（全通过）把单基错误率乘起来，指数级下降。（$\S3.3$）

### $\rm \S \, 3.8.2$ 应用与辨析答案

1. 无效。$561$ 是 Carmichael 数，对**一切** $\gcd(a,561)=1$ 的基都有 $a^{560}\equiv1$，换多少随机基都骗得过。必须升级到强测试（平方链），$561$ 在基 $2$ 下链首项 $2^{280}\neq\pm1$，被 MR 判合数。（$\S3.2$、$\S3.3$）
2. $n=9$，$n-1=8=2^3\cdot1$，$s=3$、$d=1$。基 $2$：$2^1=2$，平方得 $4$，再平方得 $7$（$16\bmod9$），链 $2\to4\to7$，无 $-1$、无 $1$，$2$ 是证人。基 $8$：$8\equiv-1$，$8^1 = -1$，链首即 $-1$，$8$ 是骗子（这正是 $x^2\equiv1\pmod9$ 的非平凡平方根 $8\equiv-1\bmod9$ 的镜像）。基 $4$：$4^1=4$，$4^2=7$，$4^4=4$，无 $-1$，证人。骗子只有 $a=8$ 一个，$1/(9-2) = 0.14 < 1/4$。（$\S3.3$）
3. 不会引入错误。第 $s$ 步的 $x^2 = a^{2^s d} = a^{n-1}$，若前面都没到 $-1$，这一步到 $a^{n-1}$：$n$ 素数时 $a^{n-1}=1$，此时多检查的 $x=n-1$ 不成立、$x=1$ 也不是刚刚到达，判合数的逻辑不受影响；但$n$ 合数时 $a^{n-1}$ 可能是 $1$（费马骗子），把它当 $-1$ 才是错的。所以多检查一步不改变正确性，只是**浪费**——MR 的标准写法只查 $s-1$ 步，终点 $a^{n-1}$ 由费马检验负责。（$\S3.3$）
4. 因为 $3.3\times10^{24}$ 是**已被穷举验证**的界：Jaeschke 与 Sorenson–Webster 证明了不存在小于该界的、同时骗过这 $7$ 个基的合数（否则就找到反例）。超出该界，$\{2,3,5,7,11,13,17\}$ 不再是充分集，理论上可能有合数全骗过——只能退回高概率口径。（$\S3.4$）
5. 跳过偶数与 $5$ 的倍数，候选密度从「所有奇数」降到 $4/10$... 确切说，末位限定为 $\{1,3,7,9\}$ 后候选只剩 $4/10 = 2/5$，期望试次数从 $\ln N/2$ 再降约 $10/4 = 2.5$ 倍（等价于对 $\gcd(N,10)=1$ 分层抽样）。来源是素数除了 ${2,5}$ 外末位只能是 ${1,3,7,9}$，把明显非素的候选提前剔掉。（$\S3.5$）
6. 好处：在 $3.3\times10^{24}$ 以内这组基是确定充分的，省掉随机数生成、结果可复现。风险：这组基的充分性是**被穷举验证的有限事实**，不是定理；对更大的 $n$ 存在骗过前若干素基的合数，例如 $3215031751 = 151\times751\times28351$ 是首个骗过基 ${2,3,5,7}$ 的强伪素数。做法是：小范围用固定基换确定与速度，大范围用随机基换正确性保证。（$\S3.4$）

## $\rm \S \, 3.9$ 程序对账

下面一段给出完整的 Miller–Rabin 实现，并重算 §3.4 的强伪素数表与骗子率，全部本机实测。

```python
import math

def is_prime_trivial(n):                     # 试除，小范围当真值用
    if n < 2: return False
    if n % 2 == 0: return n == 2
    i = 3
    while i * i <= n:
        if n % i == 0: return False
        i += 2
    return True

def is_strong_pseudoprime(n, a):             # n 奇合数、基 a：True 表示骗过 MR
    if n % 2 == 0: return False
    d = n - 1; s = 0
    while d % 2 == 0:
        d //= 2; s += 1
    x = pow(a, d, n)                         # 链首项
    if x == 1 or x == n - 1: return True
    for _ in range(s - 1):                   # 沿平方链找 -1
        x = x * x % n
        if x == n - 1: return True
    return False

def miller_rabin(n, bases):                  # bases 给定则确定；全过报素数
    if n < 2: return False
    for p in (2, 3, 5, 7):
        if n % p == 0: return n == p
    for a in bases:
        if not is_strong_pseudoprime(n, a):
            return False
    return True

    # 基 2 的强伪素数 < 4000：应为 {2047, 3277}
sps = [n for n in range(3, 4000, 2) if not is_prime_trivial(n) and is_strong_pseudoprime(n, 2)]
print("base-2 strong pseudoprimes < 4000:", sps)
print("2047 = 23*89 ?", 2047 == 23 * 89, " 3277 = 29*113 ?", 3277 == 29 * 113)
print("341 Fermat-pseudoprime base2 ?", pow(2, 340, 341) == 1, " 341 = 11*31 ?", 341 == 11 * 31)
print("561 Fermat-pseudoprime base2 ?", pow(2, 560, 561) == 1, " 561 strong ?", is_strong_pseudoprime(561, 2))

    # 骗子基的比例：奇合数 < 2e4，MR 接受比例的最大值与均值
def liar_frac(n):
    return sum(1 for a in range(2, n) if is_strong_pseudoprime(n, a)) / (n - 2)

mean = 0.0; cnt = 0; best_f = 0.0; best_n = 0
for n in range(9, 20000, 2):                 # 记录 n，别用"下标推 n"（中间跳过了素数）
    if is_prime_trivial(n):
        continue
    f = liar_frac(n)
    mean += f; cnt += 1
    if f > best_f:
        best_f, best_n = f, n
print(f"liar frac: mean={mean/cnt:.5f}  max={best_f:.4f}  at n={best_n}")
print("deterministic check 2..17:", miller_rabin(12403, [2,3,5,7,11,13,17]))  # 12403=79*157 应为 False
```

输出（本机实测）：

1. `base-2 strong pseudoprimes < 4000: [2047, 3277]`，两个分解等式均为 `True`——与 §3.4 的表逐项对上。
2. `341 Fermat-pseudoprime base2 ? True`、`561 Fermat-pseudoprime base2 ? True`、`561 strong ? False`——费马测试放过 $341$ 与 $561$，而强测试把 $561$ 抓住。
3. `liar frac: mean=0.00247 max=0.2452 at n=12403`——平均骗子率 $0.25\%$，最坏 $0.2452$，几乎顶到 $1/4$ 的上界。
4. `deterministic check 2..17: False`——$12403 = 79\times157$ 被 7 个确定性基判为合数。

**带走清单**：费马小定理判据与 $341$ 这个基 2 伪素数反例；Carmichael 数 $561$ 与 Korselt 判据；强伪素数定义的平方链判据；Miller–Rabin 的四步证明（子群 $H$、非平凡平方根、$|\{x : x^2=1\}| = 2^{\omega(n)}$、Monier 计数 $\le\varphi(n)/4$）；错误率 $4^{-k}$ 与 $\mathrm{co\text{-}RP}$；基 2 强伪素数 $\{2047, 3277\}$、最坏骗子率 $0.2452$（$12403 = 79\times157$）；$7$ 个确定性基到 $3.3\times10^{24}$；随机生成大素数的密度账 $\mathbb{E}[\text{试}] \approx \frac{\ln N}{2}$。
