# $\rm Chapter \, 6$ 筛法与圆法

第 5 章用 Dirichlet 特征把素数按余类分账，靠的是乘法世界的谐波。但数论里最著名的两个未解问题——孪生素数猜想与哥德巴赫猜想——都是**加法**条件：$p$ 与 $p + 2$ 同时是素数，$N$ 是三个素数之和。加法条件与乘法结构天然相克（§5.1 已见过一次：余 3 的素数集合对乘法不封闭；这次连「按余类分账」都无从下手，因为条件根本不是同余式）。本章介绍解析数论的另外两台发动机：**筛法**（sieve）回答「满足联合整除条件的数至多有多少」，策略是「先把全部算入、再按整除性扣除」；**圆法**（circle method）回答「加法方程的素数解有多少组」，策略是用傅里叶正交性把方程变成一个积分。两台机器共享同一个哲学：**放弃对单个素数的精确记账，换取对整体计数的控制**。本章完整走筛法三级火箭——Legendre 容斥的破产、Brun 截断、Selberg 二次型——直到孪生素数上界（与猜想密度差 8 倍），再完整计算圆法的主弧、说明次弧的困难与 Helfgott 的收官。范围外声明共四处，均标明出处。

> **开始前自检**：本章假设你已经会：
>
> 1. □ 复数的单位圆记号 $\mathrm{e}(t) = \mathrm{e}^{2\pi i t}$、模长、以及有限几何级数求和 $\sum_{n \le N} x^n = \frac{x^{N+1} - x}{x - 1}$（$x \ne 1$）。
> 2. □ Cauchy–Schwarz 不等式 $\left(\sum_k a_k b_k\right)^2 \le \left(\sum_k a_k^2\right)\left(\sum_k b_k^2\right)$，以及「配方法证非负二次型下界」的操作。
> 3. □ 素数定理的陈述 $\pi(x) \sim \dfrac{x}{\ln x}$（第 4 章）与 Dirichlet 定理的陈述（第 5 章）；$O$、$o$、$\ll$ 记号。
> 4. □ Möbius 函数 $\mu$ 与恒等式 $\sum_{d \mid n} \mu(d) = [n = 1]$——本章 §6.2 当场给出定义与证明，无需预备。

## $\rm \S \, 6.1$ 动机：当记账遇到加法

先写下两个猜想的精确形状。**孪生素数猜想**：$\pi_2(x) := \#\{p \le x : p + 2 \text{ 为素数}\}$ 满足

$$
\pi_2(x) \sim 2 C_2 \frac{x}{\ln^2 x}, \qquad C_2 := \prod_{p > 2} \left(1 - \frac{1}{(p-1)^2}\right) \approx 0.66016 ,
$$

$C_2$ 称**孪生素数常数**（收敛极慢，数值取自标准表）。**弱哥德巴赫（三素数）猜想**：每个奇数 $N \ge 7$ 都能写成三个素数之和。第 4、5 章的机器为什么管不了它们？素数定理数的是「一个整除性条件」（$n$ 没有非平凡因子），Dirichlet 定理数的是「一个同余条件」（$p \equiv a \pmod q$）——都是**单个**乘法世界里的筛选。孪生素数是**两个素性条件的联合分布**，哥德巴赫是**三个素性条件的加法耦合**：方程 $p_1 + p_2 + p_3 = N$ 把三个乘法对象用加法锁死，Euler 乘积的逐项对账机制（第 3 章 §3.1、第 5 章 §5.3）在这里没有对应物。

打个比方。筛法像清点会场：不数人头，而是先按「票面规则」放行全部候选，再把不合格的按整除性逐层抽走——精确抽完太贵，学问在于「抽到第几层停、停的时候账还剩多少可信」。圆法像分光计：把「哪些三元组相加等于 $N$」翻译成频率的干涉——把每个候选 $n$ 挂上一个相位 $\mathrm{e}(n\alpha)$，只有恰好共振的组合在积分中幸存。两台机器都只能拿「主项对、误差可控」的近似账。

**本节小结**：本节摆出两座山——孪生素数与弱哥德巴赫——并指出第 4、5 章的乘法机器为何够不着：加法条件把独立的乘法对象锁死，逐项对账无从展开；接下来筛法用容斥扣除接联合整除条件，圆法用正交性积分接加法方程。

## $\rm \S \, 6.2$ Eratosthenes–Legendre 筛：容斥的精确代价

白话：筛法先把「候选名单」连同权重一起端上桌（数列 $a(n)$），再问一个问题——把被小素数整除的候选全部扣掉后，桌上还剩多少权重；一切化为对这份名单的容斥记账。

**筛法的一般设置**。设 $a(n) \ge 0$ 是有限支撑的实数列，记 $A_d = \sum_{d \mid n} a(n)$（对 $n$ 求和），并假设有主项分解 $A_d = f(d) X + R_d$（$f(1) = 1$、$f$ 乘性、$0 \le f(p) < 1$），$X$ 是问题的「尺寸」、$R_d$ 是余项。对 $z \ge 2$ 记 $\mathcal{P} = \{p : p \le z\}$ 与 $P(z) = \prod_{p \le z} p$，定义**筛函数**

$$
S(A, \mathcal{P}, z) = \sum_{(n, P(z)) = 1} a(n),
$$

即 $a(n)$ 中不被任何 $p \le z$ 整除者的总权重。Möbius 函数定义：$\mu(d) = (-1)^{\omega(d)}$（$d$ 无平方因子，$\omega(d)$ 为不同素因子个数），否则 $\mu(d) = 0$。它的定义性恒等式 $\sum_{d \mid n} \mu(d) = [n = 1]$ 证明一行：两边对 $n$ 都是乘性的，对素数幂 $p^k$ 直接验算 $\sum_{d \mid p^k} \mu(d) = 1 + (-1) = 0$（$k \ge 1$），故乘积在 $n > 1$ 时为 $0$、$n = 1$ 时为 $1$。于是「不被任何 $p \le z$ 整除」可写成容斥：

$$
[(n, P(z)) = 1] = \sum_{d \mid (n, P(z))} \mu(d) .
$$

对 $n$ 求和并代入主项分解：

$$
S(A, \mathcal{P}, z) = \sum_{d \mid P(z)} \mu(d) A_d = X \sum_{d \mid P(z)} \frac{\mu(d) f(d)}{d} + \sum_{d \mid P(z)} \mu(d) R_d = X \prod_{p \le z} \left(1 - f(p)\right) + E ,
$$

其中 $E = \sum_{d \mid P(z)} \mu(d) R_d$。**Legendre 筛就是这条恒等式**；它的生死全在误差 $E$。

**例一：等差数列中的素数**。$a(n) = 1$（$n \le x$，$n \equiv a \pmod q$，$\gcd(a,q) = 1$），其余为 $0$。对 $d \mid P(z)$（$d$ 与 $q$ 互素），条件「$n \equiv a \pmod q$ 且 $d \mid n$」由 CRT 给出模 $qd$ 的唯一剩余类，故 $A_d = \dfrac{x}{qd} + O(1)$，即 $f(d) = 1/d$（$X = x/q$）且 $|R_d| \le 1$，误差合计 $|E| \le \sum_{d \mid P(z)} 1 = 2^{\pi(z)}$。要数素数必须筛到 $z = \sqrt{x}$（合数 $n \le x$ 必有因子 $\le \sqrt{x}$；$p \mid q$ 的素数自动不整除 $n \equiv a$），此时 $2^{\pi(\sqrt{x})} = \mathrm{e}^{(2\ln 2 + o(1))\sqrt{x}/\ln x}$——比 $x$ 的任何次幂都大。取 $x = 10^4$ 验算量级：$z = 100$，$2^{25} \approx 3.4 \times 10^7$，而主项不过 $10^4$ 量级。**误差税碾碎主项，Legendre 容斥对 $\pi(x)$ 毫无用处。**

**例二：孪生素数**。$a(n) = \#\{m \le x : n = m(m+2)\}$，即 $A$ 是乘积 $m(m+2)$ 的清单；$m$ 与 $m+2$ 都是素数当且仅当 $m(m+2)$ 无素因子 $\le \sqrt{x+2}$（若 $m$ 合数，最小因子 $\le \sqrt m \le \sqrt x$；若 $m+2$ 合数，$m + 2 = p_1 p_2$ 时小因子 $\le \sqrt{x+2}$，而两个都 $> \sqrt x$ 的因子乘积超过 $x + 2$）。对 $d \mid P(z)$，条件 $d \mid m(m+2)$ 逐素因子分解：对奇素数 $p$，$m \equiv 0$ 或 $-2 \pmod p$，两个类；对 $p = 2$，$m \equiv 0 \pmod 2$ 一个类（$m$ 与 $m+2$ 同奇偶）。记类数函数 $\rho$：$\rho(2) = 1$、$\rho(p) = 2$（$p > 2$），乘性，则 $A_d = \rho(d) \dfrac{x}{d} + O(\rho(d))$（$\rho(d)$ 个剩余类、每类贡献 $x/d + O(1)$）。代入恒等式：

$$
S(A, \mathcal{P}, z) = x \prod_{p \le z} \left(1 - \frac{\rho(p)}{p}\right) + E, \qquad |E| \le \sum_{d \mid P(z)} \rho(d) = \prod_{p \le z} (1 + \rho(p)) = 2 \cdot 3^{\pi(z) - 1} .
$$

末一等式用乘性：$\sum_{d \mid P(z)} \rho(d) = \prod_{p \le z}(1 + \rho(p))$。**这正是误差的 $3^{\omega}$ 级爆炸机制：每纳入一个新素因子 $p$，容斥项的个数乘 $1 + \rho(p) = 3$，误差税相应从 $3^{\pi(z)}$ 跳到 $3\,3^{\pi(z)}$**。取 $z = \sqrt{x}$：$3^{\pi(\sqrt x)} = \mathrm{e}^{(2\ln 3 + o(1))\sqrt{x}/\ln x}$，同样超过 $x$ 的任何幂（$x = 10^4$ 时 $3^{25} \approx 8.5 \times 10^{11}$）。

主项倒是有形状的。由 Mertens 乘积 $\prod_{p \le z}(1 - 1/p) \sim \mathrm{e}^{-\gamma}/\ln z$（Mertens 1874；由 PNT 对 $\sum_{p \le y} \ln p / p \sim \ln y$ 做两次部分求和可得 $\sum_{p \le y} 1/p = \ln\ln y + M + o(1)$，乘积常数 $\mathrm{e}^{-\gamma}$ 的确定是 Mertens 的定理，超出本章范围），以及拆出的局部比 $\left(1 - \frac{2}{p}\right)\left(1 - \frac1p\right)^{-2} = \frac{p(p-2)}{(p-1)^2}$，得

$$
\prod_{p \le z} \left(1 - \frac{\rho(p)}{p}\right) \sim \frac{C_2\, \mathrm{e}^{-2\gamma}}{2 \ln^2 z} \sim 2 C_2 \mathrm{e}^{-2\gamma} \frac{1}{\ln^2 x} \qquad (z = \sqrt x),
$$

即主项 $\approx 0.416\, x/\ln^2 x$，比猜想主项 $2C_2 x/\ln^2 x \approx 1.32\, x/\ln^2 x$ 小 $\mathrm{e}^{2\gamma} \approx 3.17$ 倍——但常数层面的讨论毫无意义，因为误差无限大。结论：**Legendre 容斥给出正确的形状、不可行的账本；需要一种「少付误差税」的扣除方式**。

**本节小结**：本节搭好筛法的通用账本——主项 $X\prod_{p\le z}(1-f(p))$ 加误差 $E$——并在素数与孪生两个实例上看到同一死因：每纳入一个素因子，容斥项翻倍或三倍，误差税指数式爆炸碾碎主项；解药是下一节把容斥半途截断。

## $\rm \S \, 6.3$ Brun 纯筛：把容斥截断

Brun 1919 年的想法：完整容斥要对每个 $d \mid P(z)$ 付一次余项税，那就**只容斥到深度 $r$**——丢掉 $\omega(d) > r$ 的项。丢项破坏精确性，但 Bonferroni 不等式保证丢剩的部分仍以确定的方向夹住真值。

**引理 6.1（Bonferroni）**：设 $E_1, \ldots, E_k$ 为事件，$m$ 为其中发生者的个数。则对 $r \ge 0$，

$$
\sum_{\substack{S \subseteq \{1,\ldots,k\} \\ |S| \le r}} (-1)^{|S|} \left[\bigcap_{i \in S} E_i\right] = \begin{cases} 1, & m = 0, \\ (-1)^r \dbinom{m-1}{r}, & r < m, \\ 0, & r \ge m \ge 1 . \end{cases}
$$

**证明**：左端只依赖发生的那些事件：每个发生的事件子集 $S$（$|S| \le r$）贡献一次，故左端 $= \sum_{j=0}^{\min(r,m)} (-1)^j \binom{m}{j}$。对 $r$ 用 Pascal 恒等式 $\binom{m}{j} = \binom{m-1}{j} + \binom{m-1}{j-1}$ 归纳（相邻两项伸缩相消），得交错和 $\sum_{j=0}^{r}(-1)^j\binom{m}{j} = (-1)^r \binom{m-1}{r}$（$r < m$）；$r \ge m$ 时是完整的 $(1-1)^m = 0$。∎

于是**偶数层截断给上界、奇数层给下界**。对筛问题取事件 $E_p = \{p \mid n(n+2)\}$，定义截断和 $S_r = \sum_{d \mid P(z),\, \omega(d) \le r} \mu(d) A_d$：$r$ 偶时 $S(A,\mathcal{P},z) \le S_r$，$r$ 奇时反向。以下只做上界（$r$ 偶）。

**主项分析**。记 $w(d) = \rho(d)/d$，$E_k = \sum_{\omega(d) = k,\, d \mid P(z)} w(d)$，则完整容斥的主项是 $\sum_{k \ge 0}(-1)^k E_k = \prod_{p \le z}(1 - w(p))$（有限乘积的展开，精确恒等式），截断后

$$
\sum_{k \le r} (-1)^k E_k = \prod_{p \le z}\left(1 - w(p)\right) + \text{尾部}.
$$

两条控制：（1）**排序注入**：每个 $k$ 元无序素数组有 ${k!}$ 种排序，故 $k!\,E_k \le \left(\sum_{p \le z} w(p)\right)^k$，记 $\sigma := \sum_{p \le z} \rho(p)/p = \frac12 + 2\sum_{3 \le p \le z} \frac1p = 2\ln\ln z + O(1)$，得 $E_k \le \sigma^k/k!$。（2）**相邻递减**：$E_k = \frac1k \sum_{\omega(d') = k-1} w(d') \sum_{p \le z,\, p \nmid d'} w(p) \le \frac{\sigma}{k} E_{k-1}$（把每个 $k$ 元组按删去一个元素分组），故 $k > \sigma$ 后 $E_k$ 递减，尾部绝对值 $\le 2E_{r+1} \le 2\left(\frac{e\sigma}{r+1}\right)^{r+1}$（几何级数求和，配合 Stirling 下界 $(r+1)! \ge \left(\frac{r+1}{e}\right)^{r+1}$；需 $r + 2 > 2\sigma$）。**误差税**：$\sum_{\omega(d) \le r, \, d \mid P(z)} \rho(d) \le \sum_{k \le r} 2^k \binom{\pi(z)}{k} \le r \left(\frac{2 e\, \pi(z)}{r}\right)^{r}$（项在 $k \le r$ 段递增，$r \ll \pi(z)$）。

**联立定参**。取 $s = r = 12\lceil \ln\ln x \rceil$（$r$ 偶化）与 $z = x^{1/s}$，此时 $\ln z = \frac{\ln x}{s}$。

1. 尾部：$\sigma \le 2\ln\ln x + 2$，$\dfrac{e\sigma}{r+1} \le \dfrac{2e\ln\ln x(1 + o(1))}{12 \ln\ln x} \le \dfrac12$（$x$ 充分大），尾部 $\le 2 \cdot 2^{-12\ln\ln x} = 2(\ln x)^{-12\ln 2} = o(\ln^{-3} x)$。
2. 误差税：$\pi(z) \sim \dfrac{s\, x^{1/s}}{\ln x}$，对数的指数为 $r\left(\ln \frac{2e\,\pi(z)}{r}\right) = \ln x + r\left(1 + \ln 2 - \ln\ln x\right) + O(\ln\ln x) \le \ln x - 12(\ln\ln x)^2 + O(\ln\ln x)$，故税 $\ll x\,(\ln x)^{-12\ln\ln x + O(1)} = o(x/\ln^3 x)$。
3. 主项：$\prod_{p \le z}(1 - w(p)) \le \mathrm{e}^{-\sigma} \ll (\ln z)^{-2} = \dfrac{s^2}{\ln^2 x} \ll \dfrac{(\ln\ln x)^2}{\ln^2 x}$。

三项合并（除以 $\ln^2 x$ 后税与尾部都可吸收）：

**定理 6.2（Brun，1919）**：$\displaystyle \pi_2(x) \ll \frac{x\,(\ln\ln x)^2}{\ln^2 x}$。

**本节小结**：本节用 Bonferroni 截断把容斥砍到深度 $r$，尾部与误差税在 $r \sim z$ 的对数刻度上被同时压小，抢到 $x/\ln^2 x$ 的量级、付出 $(\ln\ln x)^2$ 折损——下节的 Selberg 筛将换一种收税方式消掉折损。

常数难看且 $x_0$ 巨大，但两点是结构性的：**量级 $x/\ln^2 x$ 抢到了**（孪生素数若无穷，密度确实应是这个量级），代价是 $(\ln\ln x)^2$ 的折损——它来自把 $z$ 压到 $x^{1/s}$：误差税随 $z$ 指数式爆炸，逼 $s \sim \ln\ln x$，而主项里 $1/\ln^2 z = s^2/\ln^2 x$ 又把折损吃回来。另一个结构事实是**只有上界**：奇数层截断虽给下界，但主项 $\prod(1 - w(p)) \approx 1/\ln^2 z$ 本身趋于 0，截断和会变负——完整容斥的「相消」正是孪生素数的全部算术内容，截断保不住它的符号。完整现代处理见 Halberstam–Richert《Sieve Methods》与 Greaves《Sieves in Number Theory and Applications》的纯筛章节。

## $\rm \S \, 6.4$ Selberg 上界筛：$\Lambda^2$ 二次型

Selberg 1947 年的换轨：不再逼近 $\mu$，而是**自己造一个恒为非负的上核**。取实数权重 $\lambda_d$（$\lambda_1 = 1$，支撑在平方因子 free 的 $d \le D$、$d \mid P(z)$ 上），逐点比较 $[(n, P(z)) = 1] \le \left(\sum_{d \mid n,\ d \le D} \lambda_d\right)^2$：若 $(n, P(z)) = 1$，内和只有 $d = 1$ 一项，右边 $= \lambda_1^2 = 1$，取等；否则左边为 $0$、右边 $\ge 0$。求和并用主项分解（本节推导与 Vaughan 的 Selberg 筛讲义逐平行，记号沿用 §6.2）：

$$
S(A, \mathcal{P}, z) \le \sum_{n} a(n) \left(\sum_{d \mid n} \lambda_d\right)^2 = \sum_{d, e \le D} \lambda_d \lambda_e A_{[d,e]} = X \, M(\lambda) + R(\lambda),
$$

其中 $M(\lambda) = \sum_{d,e} \lambda_d \lambda_e f([d,e])$，$R(\lambda) = \sum_{d,e} \lambda_d \lambda_e R_{[d,e]}$（$[d, e]$ 读作 $d$ 与 $e$ 的最小公倍数，同时被 $d$、$e$ 整除的最小者，对照「$d \mid n$ 且 $e \mid n$ 合起来就是 $[d,e] \mid n$」）。现在**把二次型对角化**，三步。

**第一步（去 lcm）**：写 $(d,e) = m$、$d = qm$、$e = rm$、$(q,r) = 1$。由乘性（平方因子 free 下 $[d,e] = qrm$ 的素因子分属 ${q, r, m}$）：$f([d,e]) = f(qm)f(rm)/f(m)$，故 $M = \sum_m f(m)^{-1} \sum_{(q,r)=1} \lambda_{qm}\lambda_{rm} f(qm) f(rm)$。互素条件用 $\mu$ 摘除（$\sum_{(q,r)=1} B_q C_r = \sum_l \mu(l) \left(\sum_q B_{ql}\right)\left(\sum_r C_{rl}\right)$），得 $M = \sum_m f(m)^{-1} \sum_l \mu(l) \left(\sum_d \lambda_{dlm} f(dlm)\right)^2$。**第二步（收集 $lm = n$）**：$\sum_{lm = n} f(m)^{-1}\mu(l) = \prod_{p \mid n} \dfrac{1 - f(p)}{f(p)}$（两边乘性；单素数验算：$1/f(p) - 1 = (1-f(p))/f(p)$），记其倒数为 $g$：

$$
g(n) = \prod_{p \mid n} \frac{f(p)}{1 - f(p)}, \qquad M = \sum_n g(n)^{-1} \left(\sum_d \lambda_{dn} f(dn)\right)^2 .
$$

读法：第一式定义对角权重 $g$（把每层的 $f$ 与 $\mu$ 的账折进一个乘积），第二式把二次型化成只含 $\omega$ 的平方和——配方所需的全部原料就此到齐。

**第三步（换变量并配方）**：令 $\omega_n = \sum_d \lambda_{dn} f(dn)$。$\lambda \mapsto \omega$ 是上三角可逆变换，反演为 $\lambda_m f(m) = \sum_n \omega_{nm} \mu(n)$（验证：右边 $= \sum_{q} \lambda_{qm} f(qm) \sum_{n \mid q} \mu(n) = \lambda_m f(m)$）。约束 $\lambda_1 = 1$ 即

$$
\sum_n \omega_n \mu(n) = 1 .
$$

记 $G = \sum_{n \le D} g(n)$、$\Lambda = 1/G$，配方：

$$
M = \sum_n \frac{\left(\omega_n - \Lambda \mu(n) g(n)\right)^2}{g(n)} + 2\Lambda - \Lambda^2 G \ge 2\Lambda - \Lambda = \frac1G ,
$$

（展开用了 $\sum_n \omega_n \mu(n) = 1$ 与 $\Lambda^2 G = \Lambda$；$g(n) > 0$ 因 $f(p) < 1$）。取等当 $\omega_n = \Lambda \mu(n) g(n)$。于是：

**定理 6.3（Selberg 上界筛）**：在 §6.2 的设置下，存在支撑在 $d \le D$ 的权重使

$$
S(A, \mathcal{P}, z) \le \frac{X}{G} + R, \qquad G = \sum_{d \le D,\ d \mid P(z)} \prod_{p \mid d} \frac{f(p)}{1 - f(p)} .
$$

**余项的控制**：最优权重满足 $| \lambda_m | \le 1$。证明：由取等的 $\omega$ 反推 $\lambda_m = \Lambda \mu(m) \frac{g(m)}{f(m)} \sum_{n:\, nm \le D} g(n)$，而 $\frac{g(m)}{f(m)} = \prod_{p \mid m}(1 - f(p))^{-1} = \prod_{p \mid m}(1 + g(p)) = \sum_{d \mid m} g(d)$，故 $|\lambda_m| \le \Lambda \sum_{d \mid m} g(d) \sum_{n:\, nd \le D,\, (n, m/d) = 1} g(n) = \Lambda \sum_{d \mid m} \sum_{k \le D,\, (k,m) = d} g(k) = \Lambda \sum_{k \le D} g(k) = 1$（换元 $k = nd$：$k \le D$、$d \mid k$ 且 $k/d \le D$，$(k,m) = d$；最后一步把 $k$ 按 $(k,m)$ 分层）。对孪生问题 $|R_{[d,e]}| \le \rho([d,e]) = \rho(d)\rho(e)/\rho((d,e)) \le \rho(d)\rho(e)$，故 $|R| \le \left(\sum_{d \le D} \mu^2(d) \rho(d)\right)^2 \le \left(\sum_{d \le D} 2^{\omega(d)}\right)^2 \ll D^2 \ln^2 D$（末一步：$2^{\omega(n)} = \sum_{d \mid n} \mu^2(d)$，交换求和后乘 $\sum_{d \le D} \mu^2(d)/d \ll \ln D$）。取 $D = \sqrt{x}/\ln^3 x$：$|R| = o(x/\ln^2 x)$。

**主项常数**。孪生问题 $f(p) = \rho(p)/p$ 给 $g(2) = 1$、$g(p) = \frac{2}{p-2}$（$p > 2$）；$z = \sqrt x \ge D$ 使 $d \mid P(z)$ 无额外限制。$G(D) = \sum_{d \le D} \mu^2(d) g(d)$ 的渐近用 Dirichlet 级数读出：$\sum_d g(d) d^{-s} = \prod_p (1 + g(p) p^{-s}) = \zeta(1+s)^2 H(s)$，而单素数因子给出 $(1 + g(p))(1 - 1/p)^2 = \frac{(p-1)^2}{p(p-2)} = \left(1 - \frac{1}{(p-1)^2}\right)^{-1}$（$p > 2$）、$(1 + g(2))(1/2)^2 = \frac12$，故 $H(0) = \frac12 \prod_{p > 2}\left(1 - \frac{1}{(p-1)^2}\right)^{-1} = \frac{1}{2C_2}$；由标准 Tauberian 定理（Karamata；超出本章范围，出处：Tenenbaum《Introduction to Analytic and Probabilistic Number Theory》或 Halberstam–Richert《Sieve Methods》）得 $G(D) \sim \frac{(\ln D)^2}{4 C_2}$。代入 $D = \sqrt x/\ln^3 x$（$\ln D = \frac12 \ln x + o(\ln x)$）：

**定理 6.4（Selberg）**：$\displaystyle \pi_2(x) \le S(A, \mathcal{P}, \sqrt x) \le \frac{16 C_2\, x}{\ln^2 x}\,(1 + o(1)) + o\!\left(\frac{x}{\ln^2 x}\right) = \{16 C_2 + o(1)\}\frac{x}{\ln^2 x}.$

**口径警告**：猜想主项是 $2C_2 x/\ln^2 x$，上界是它的 $8$ 倍；不少文献把奇异级数 $2C_2 \approx 1.32$ 整体称作「孪生素数常数」并把同一结果写作 $8 C_2 x/\ln^2 x$——读文献先查常数定义，本文全程用 $C_2 = 0.66016$。上界大于猜想当然不构成怀疑：筛法给出的是「至多」，且常数 8 是 $\Lambda^2$ 方法的固有折损（后续改进把倍数往下压，见 Halberstam–Richert 与 Greaves 书中的加权筛章节；陈景润 1973 的「素数 + 至多两素因子之积」也是这一族的加权筛，出处：Chen, Sci. Sinica 16 (1973)）。

**为什么 $\Lambda^2$ 更聪明**。对比 §6.3：Brun 的误差税 $\sum_{d \mid P(z)} \rho(d)$ 对**每一个** $d \mid P(z)$ 收税，$z$ 越大税越重，被迫把 $z$ 压小；Selberg 的余项只对 $d, e \le D$ 收税且 $|\lambda_d| \le 1$，**权重支撑与 $z$ 解耦**——$z$ 可以一路推到 $\sqrt x$，主项里不再有 $s^2$ 折损。**维数直觉**：称 $\sum_{p \le y} f(p) \ln p \approx \kappa \ln y$ 的筛问题为 $\kappa$ 维（孪生问题 $\kappa = 2$：每个素因子封两个剩余类；素数本身 $\kappa = 1$），则 $G(D)$ 增长如 $(\ln D)^\kappa$，主项是 $x/\ln^\kappa D$；维数越高，$g(d)$ 越大、余项税里的组合爆炸越猛，筛越弱——同一台机器上，一维的素数问题还能顺带给出 Brun–Titchmarsh 型上界 $\pi(x + y) - \pi(y) \lesssim 2x/\ln x$（取 $f = 1/d$、$G = \sum_{d \le D} \mu^2(d)/\varphi(d) \sim \ln D$；完整推导见 Montgomery–Vaughan《Multiplicative Number Theory I》与 Vaughan 的 Selberg 筛讲义）。

**现状一句**：张益唐（Ann. of Math. 179 (2014) 1121–1174）证明存在绝对常数 $B$ 使 $p_{k+1} - p_k \le B$ 无穷多次（初值 $7 \times 10^7$），Maynard（Ann. of Math. 181 (2015) 383–413）的多元筛与 Polymath8b 合作项目把纪录压到 $B = 246$；但 $B = 2$（孪生素数）仍卡在奇偶性屏障——Selberg 早已指出，纯筛的权重分不清「素数」与「奇数个素因子之积」（现代讨论见 Greaves 书第 1 章）。

**本节小结**：本节把筛核从「逼近 $\mu$」换成「自造非负二次型」，经去 lcm—收集—配方三步得 $S \le X/G + R$：余项只对 $d, e \le D$ 收税、与 $z$ 解耦，孪生上界推进到 $16C_2\, x/\ln^2 x$，但奇偶性屏障宣告纯筛止步于此。

## $\rm \S \, 6.5$ 圆法：正交性把加法变成积分

转向加法侧。记 $\mathrm{e}(t) = \mathrm{e}^{2 \pi i t}$（读作「$t$ 圈的相位」，对照单位圆上转过 $2\pi t$ 角度的点；整数 $m$ 处恰好转整数圈，$\mathrm{e}(m) = 1$），素数的相位和

$$
S(\alpha) = \sum_{n \le N} \Lambda(n)\, \mathrm{e}(n\alpha), \qquad \Lambda(n) = \begin{cases} \ln p, & n = p^k, \\ 0, & \text{其余}, \end{cases}
$$

（von Mangoldt 加权：素数幂的总贡献 $\ll \sqrt N \ln^2 N$，对下面的主项 $N^2$ 可忽略，用它换来与 PNT 无缝对接）。**正交性引理**：对整数 $m$，$\displaystyle \int_0^1 \mathrm{e}(m\alpha)\,\mathrm{d}\alpha = [m = 0]$。证明：$m = 0$ 时被积函数恒 1；$m \ne 0$ 时 $\int_0^1 \mathrm{e}(m\alpha)\,\mathrm{d}\alpha = \frac{\mathrm{e}(m) - 1}{2\pi i m} = 0$（$\mathrm{e}(m) = 1$）。∎

把「$N = p_1 + p_2 + p_3$ 的加权表示数」

$$
J(N) = \sum_{\substack{p_1, p_2, p_3 \le N \\ p_1 + p_2 + p_3 = N}} \ln p_1 \ln p_2 \ln p_3
$$

写成积分：展开 $S(\alpha)^3 \mathrm{e}(-N\alpha) = \sum_{n_1, n_2, n_3} \Lambda(n_1)\Lambda(n_2)\Lambda(n_3)\, \mathrm{e}((n_1 + n_2 + n_3 - N)\alpha)$，逐项积分，正交性恰好筛出 $n_1 + n_2 + n_3 = N$：

$$
J(N) = \int_0^1 S(\alpha)^3\, \mathrm{e}(-N\alpha)\, \mathrm{d}\alpha .
$$

**圆法的问题变成分析 $S(\alpha)$ 作为 $\alpha$ 的函数在哪里大、在哪里小**。$S(\alpha)$ 是一列单位圆上的相位按素数分布加权叠加：当 $\alpha$ 靠近某个分母小的分数 $a/q$ 时，素数在各剩余类里的分布使大量相位相干叠加（合唱里同相的声部）；$\alpha$ 远离所有小分母分数时相位互相抵消。这引出**主弧/次弧划分**：取 $L = (\ln N)^B$（$B$ 充分大），主弧

$$
\mathfrak{M} = \bigcup_{q \le L} \bigcup_{(a, q) = 1} \left[\frac{a}{q} - \frac{1}{qQ},\ \frac{a}{q} + \frac{1}{qQ}\right], \qquad Q = \frac{N}{(\ln N)^B},
$$

（宽度小于相邻分数间距 $1/L^2$，互不重叠），$[0,1]$ 的剩余部分称**次弧** $\mathfrak{m}$。

**本节小结**：本节用正交性把三素数表示数改写成 $J(N) = \int_0^1 S^3 \mathrm{e}(-N\alpha)\,\mathrm{d}\alpha$，并把积分区间划成「相位相干的主弧」与「相位抵消的次弧」——接下来两节分别算主弧、压次弧。

## $\rm \S \, 6.6$ 主弧：从几何级数到奇异级数

**主弧近似**。设 $\alpha = a/q + \beta \in \mathfrak{M}(a,q)$，$(a,q) = 1$，$|\beta| \le 1/(qQ)$。按剩余类分组：$S(\alpha) = \sum_{r \bmod q} \mathrm{e}(ra/q) \sum_{n \le N,\, n \equiv r \, (q)} \Lambda(n)\, \mathrm{e}(n\beta)$。对 $(r, q) = 1$：素数在类 $r$ 中的均匀性（PNT 的等差版；主弧上的一致版本由 Siegel–Walfisz 定理保证，超出本章范围，出处：Davenport《Multiplicative Number Theory》）加部分求和给出内和 $= \frac{1}{\varphi(q)} \sum_{n \le N} \mathrm{e}(n\beta) + \text{小误差}$；$(r,q) > 1$ 的类只含素数幂，贡献 $\ll \sqrt N \ln^2 N$。于是

$$
S(\alpha) \approx \frac{\mu(q)}{\varphi(q)}\, V(\beta), \qquad V(\beta) = \sum_{n \le N} \mathrm{e}(n\beta),
$$

其中用了 Ramanujan 和 $c_q(a) := \sum_{(r,q)=1} \mathrm{e}(ra/q)$ 在 $(a,q)=1$ 时的取值：$r \mapsto ar$ 置换单位类，故 $c_q(a) = c_q(1)$；而 $[q = 1] = \sum_{r=1}^q \mathrm{e}(r/q) = \sum_{m \mid q} c_m(1)$（按 $\gcd(r, q)$ 分层），Möbius 反演给 $c_q(1) = \mu(q)$。

**几何级数的三重积分**。$V(\beta)$ 是有限几何级数（自检第 1 条），且 $\int_0^1 V(\beta)^3 \mathrm{e}(-N\beta)\,\mathrm{d}\beta$ 恰好清点整数解：按正交性逐项展开，

$$
\int_0^1 V(\beta)^3 \mathrm{e}(-N\beta)\,\mathrm{d}\beta = \#\{(n_1, n_2, n_3) \in [1, N]^3 : n_1 + n_2 + n_3 = N\} = \binom{N-1}{2} = \frac{N^2}{2} + O(N),
$$

（隔板计数：$N$ 分成三个正整数部分的方式数）。主弧上把 $S$ 换成近似并合成所有 $q \le L$、$(a,q)=1$：

$$
J(N) = \frac{N^2}{2} \sum_{q \le L} \left(\frac{\mu(q)}{\varphi(q)}\right)^3 \sum_{(a,q)=1} \mathrm{e}(-Na/q) + o(N^2) = \frac{N^2}{2} \sum_{q \le L} \left(\frac{\mu(q)}{\varphi(q)}\right)^3 c_q(-N) + o(N^2),
$$

（换 $q$ 求和时 $V$ 的积分对所有 $(a,q)$ 相同；近似带来的误差逐项吸收进 $o(N^2)$，严格簿记超出本章范围，出处：Vaughan《The Hardy–Littlewood Method》第 3 章）。

**奇异级数**。令 $L \to \infty$，定义

$$
\mathfrak{S}(N) = \sum_{q=1}^{\infty} \left(\frac{\mu(q)}{\varphi(q)}\right)^3 c_q(-N) .
$$

**绝对收敛**：$\mu(q)^3 = 0$ 除非 $q$ 平方因子 free，而 $|c_q(-N)| \le (q, N)\,\tau(q,N)$（由 $c_q(a) = \sum_{d \mid (q,a)} d\, \mu(q/d)$），故级数被乘性优控 $\prod_p \left(1 + \frac{2p}{\varphi(p)^3}\right) < \infty$ 压住。**Euler 乘积**：$q \mapsto c_q(-N)$ 乘性（CRT：模 $q_1 q_2$ 的单位类一一对应于单位类对，且 $\mathrm{e}(ra/q_1q_2) = \mathrm{e}(r_1 a/q_1)\,\mathrm{e}(r_2 a/q_2)$），逐素因子分解，注意 $\mu(p)^3 = \mu(p) = -1$ 使 $q$ 只取一次方：

1. $p \nmid N$：$c_p(-N) = \sum_{r=1}^{p-1} \mathrm{e}(-Nr/p) = -1$（非平凡 $p$ 次单位根之和），局部因子 $1 + \dfrac{(-1)(-1)}{(p-1)^3} = 1 + \dfrac{1}{(p-1)^3}$；
2. $p \mid N$：每项 $\mathrm{e}(-Nr/p) = 1$，$c_p(-N) = p - 1$，局部因子 $1 + \dfrac{(-1)(p-1)}{(p-1)^3} = 1 - \dfrac{1}{(p-1)^2}$。

$$
\mathfrak{S}(N) = \prod_{p \nmid N} \left(1 + \frac{1}{(p-1)^3}\right) \prod_{p \mid N} \left(1 - \frac{1}{(p-1)^2}\right) .
$$

**它为什么是「算术密度」**：主项 $\frac{N^2}{2}$ 数的是**全部**整数三元组；每个素数 $p$ 提供一个独立的局部修正因子，衡量「模 $p$ 的约束让素数三元组比整数三元组更稀还是更密」。以 $p = 3$ 看机制（素数 $> 3$ 只占剩余类 ${1, 2}$）：单位三元组中和为 $0$ 的比例是 $\frac{(p-1)(p-2)}{(p-1)^3} = \frac{p-2}{(p-1)^2}$，和为非零的比例是 $\frac{p^2 - 3p + 3}{(p-1)^2}$——恒有 $p - 2 < p^2 - 3p + 3$，**目标剩余为 0（即 $p \mid N$）时素数三元组局部更稀**，对应 $p \mid N$ 的因子 $1 - \frac{1}{(p-1)^2} < 1$；$p = 3$ 处对比最悬殊（$\frac34$ 对 $\frac98$，比值 $\frac23$）。数值验收（§6.8）：$\mathfrak{S}(10001) = 2.3004$（$10001 = 73 \times 137$，与 3 互素）对 $\mathfrak{S}(9999) = 1.5174$（$3 \mid 9999$），差别几乎全部来自 3。合起来：

**命题 6.5（三素数主项）**：$\displaystyle J(N) = \frac{N^2}{2}\, \mathfrak{S}(N)\,(1 + o(1)) \qquad (N \to \infty,\ N \text{ 奇}) .$

注意 $\mathfrak{S}(N)$ 有下界：$3 \mid N$ 时乘上 $\frac34 \prod_{p > 3}(1 + \frac{1}{(p-1)^3})^{-1}\cdot \prod$ 型修正仍 $\ge \mathfrak{c} > 0$（逐因子估计），主项永远不塌。

**本节小结**：本节在主弧上完成全套计算：均匀性给 $\frac{\mu(q)}{\varphi(q)}V(\beta)$、几何级数的重积分给主项 $\frac{N^2}{2}$、奇异级数把每个素数的局部密度修正乘成一枚算术因子 $\mathfrak{S}(N)$——三素数主项成立，只欠次弧证明可忽略。

## $\rm \S \, 6.7$ 次弧、三素数定理与二元卡点

主弧之外，$[0,1]$ 的其余部分必须被证明「什么都贡献不了」。圆法的标准记账 $\left|\int_{\mathfrak{m}} S(\alpha)^3 \mathrm{e}(-N\alpha)\,\mathrm{d}\alpha\right| \le \sup_{\alpha \in \mathfrak{m}} |S(\alpha)| \cdot \int_0^1 |S(\alpha)|^2\,\mathrm{d}\alpha$，而右边的 $L^2$ 质量由正交性**精确**算出：$\int_0^1 |S(\alpha)|^2 \mathrm{d}\alpha = \sum_{n \le N} \Lambda(n)^2 \ll N \ln N$（$|\mathrm{e}| = 1$，交叉项全灭）。所以三素数的次弧只需要**逐点小**：

**定理 6.6（Vinogradov 次弧界，1937）**：对任意 $A > 0$，存在 $B = B(A)$，使对次弧 $\mathfrak{m}$ 上的一切 $\alpha$ 有 $\displaystyle |S(\alpha)| \ll N\,(\ln N)^{-A}$。

证明的引擎是 **Vaughan 恒等式**：把 $\Lambda$ 分解成「短区间素数和 × 倍数和」（Type I）与「双线性型」（Type II）的有限和，前者用几何级数型界、后者用 Weyl 差分与 Cauchy–Schwarz，配合主弧附近的排除，把 $|S|$ 压到 $N/\ln^A N$。完整证明（约需一章）超出本章范围；出处：Vaughan《The Hardy–Littlewood Method》第 2 版第 3 章（Vaughan 恒等式为其中引理 3.1）。取 $A = 3$：次弧贡献 $\ll N(\ln N)^{-3} \cdot N\ln N = o(N^2)$，被主项 $\frac{N^2}{2}\mathfrak{S}(N) \gg N^2$ 碾过。于是：

**定理 6.7（Vinogradov，1937）**：存在 $N_0$，使一切奇数 $N \ge N_0$ 都是三个素数之和。

Vinogradov 的证明给不出有效的 $N_0$（依赖 Siegel 零点的无效常数）；后续工作给出有效界限并逐步压小。**收官是 Helfgott（2013）**：他把次弧估计做成**完全有效**的形式，证明解析部分覆盖 $N \gtrsim 10^{27}$；以下区间 $7 \le N \le 8.8 \times 10^{30}$ 由 Helfgott–Platt 的严格机器验证覆盖（对每个奇数显式构造三素数表示，配合 Platt 对 Dirichlet L 函数前 $3 \times 10^{10}$ 高度零点的严格验证）。两段拼合，弱哥德巴赫完整解决。出处：Helfgott, arXiv:1305.2897（主弧与次弧的显式估计）、arXiv:1312.7748（收官宣布）；Platt, arXiv:1305.3062（L 函数零点计算）。**分区验证 + 机器辅助**是这个证明的标志性结构——解析方法负责无穷远、计算机负责有限段，接缝处用有效常数缝合。

**二元哥德巴赫为什么卡住**。同样的积分 $J_2(N) = \int_0^1 S(\alpha)^2 \mathrm{e}(-N\alpha)\,\mathrm{d}\alpha$（偶数 $N = p_1 + p_2$ 的加权表示数）主弧照样给主项 $\approx N\, \mathfrak{S}_2(N)$（$\mathfrak{S}_2$ 是二元奇异级数，量级 1 的算术因子）。但次弧的账彻底变脸：$L^2$ 质量 $\int_0^1 |S|^2 \approx N \ln N$ **与主项 $N$ 同级甚至更大**——「sup 乘 $L^2$ 质量」的降价策略彻底失效，因为次弧本身就有 $N \ln N$ 的质量躺在那里。要前进必须直接估计次弧上的 $\int_{\mathfrak{m}} S^2 \mathrm{e}(-N\alpha)$，即精确控制相位和 $S$ 在次弧上的**分布**而非只控制其上确界；经 Vaughan 恒等式拆出的 Type I/II 双线和，需要素数在模 $q$ 余类中分布的「水平」超过 Bombieri–Vinogradov 定理的 $1/2$ 屏障，而现有的全部技术（包括筛法加权）都撞在同一堵墙上——这堵墙与 §6.4 的奇偶性屏障是同一现象的圆法面相（陈述级；出处：Vaughan《The Hardy–Littlewood Method》第 3 章的讨论与 Halberstam–Richert《Sieve Methods》关于屏障的导论）。三素数与二素数的分界不在「主项对不对」，而在**级配**：$N^2$ 的主项压得住 $o(N^2)$ 的次弧，$N$ 的主项压不住 $N\ln N$ 的次弧。

**本节小结**：本节用「sup × $L^2$ 质量」的降价策略配合 Vaughan 恒等式压住次弧，经 Helfgott 的有效估计与机器验证收官三素数定理；同一招搬到二元时次弧质量反超主项，卡点与上一节的奇偶性屏障是同一堵墙的两个面。

## $\rm \S \, 6.8$ 数值验收

以下数字全部由程序实算（写作前跑通；筛法打表、奇异级数按定义逐素数乘），读者可复核。

1. **孪生素数对计数与 Hardy–Littlewood 预测**（$\pi_2(x)$：两成员都 $\le x$ 的孪生素数对；预测 $2C_2 x/\ln^2 x$，$C_2 = 0.6601618$）：

$$
\pi_2(10^4) = 205 \ \ \text{对预测} \ 155.6 \ \ (\text{比} \ 1.317), \qquad \pi_2(10^5) = 1224 \ \ \text{对预测} \ 996.1 \ \ (\text{比} \ 1.229).
$$

比值随 $x$ 缓慢降到 1——预测的常数与量级都对，收敛慢是 $\ln$ 尺度的常态。小锚点：$10^2$ 以下恰 8 对：$(3,5), (5,7), (11,13), (17,19), (29,31), (41,43), (59,61), (71,73)$。

2. **三素数穷举**：区间 $[7, 10^4)$ 内全部 $4997$ 个奇数都被程序确认可写成三素数之和（对每个 $N$ 枚举 $p_1 \le p_2 \le p_3$），失败计数为 0——弱哥德巴赫在小范围内无例外（Helfgott–Platt 把同一验证做到了 $8.8 \times 10^{30}$）。

3. **加权表示数对主项**（$J(N) = \sum_{p_1+p_2+p_3=N} \ln p_1 \ln p_2 \ln p_3$ 对 $\frac{N^2}{2}\mathfrak{S}(N)$）：

$N = 9999$：$72\,178\,556$ 对 $75\,833\,045$（比 $0.952$）；$N = 10001$：$110\,447\,536$ 对 $115\,042\,316$（比 $0.960$）；$N = 5001$：$17\,911\,928$ 对 $19\,182\,343$（比 $0.934$）——命题 6.5 的主项在 $N \sim 10^4$ 已到位到百分之几，且 $\mathfrak{S}(9999) = 1.5174 < \mathfrak{S}(10001) = 2.3004$ 清晰展示 $3 \mid N$ 的压低效应。

## $\rm \S \, 6.11$ 本章自测答案

> 先闭卷作答 §6.9 与 §6.10，再核对。

### $\rm \S \, 6.11.1$ 关键概念回顾答案

1. $\sum_{d \mid n} \mu(d) = [n = 1]$；对每个候选 $n$，恒等式 $[(n, P(z)) = 1] = \sum_{d \mid (n, P(z))} \mu(d)$ 把「无小素因子」翻译成对 $d \mid P(z)$ 的容斥和，交换求和后每项配 $A_d$。（§6.2）
2. $\rho(2) = 1$、$\rho(p) = 2$ 使 $\sum_{d \mid P(z)} \rho(d) = \prod_{p \le z}(1 + \rho(p)) = 2 \cdot 3^{\pi(z)-1}$：每新增一个素因子，容斥项集合按「含/不含该因子」分裂且含者权重乘 $\rho(p) = 2$，总税乘 $3$；$z = \sqrt x$ 时这是 $\mathrm{e}^{(2\ln 3)\sqrt x/\ln x}$ 级，超过 $x$ 的任何幂。（§6.2）
3. 截断和 $\sum_{|S| \le r} (-1)^{|S|}[\cap E_i] = (-1)^r \binom{m-1}{r}$（$r < m$），符号由 $r$ 的奇偶决定，故偶层 $\ge$ 真值、奇层 $\le$。尾部由 $E_k \le \sigma^k/k!$ 与相邻递减 $E_k \le \frac{\sigma}{k}E_{k-1}$ 控制（$E_{r+1} \le (e\sigma/(r+1))^{r+1}$，需 $r \gg \sigma$）；误差税 $\approx (2e\pi(z)/r)^r$ 随 $z$（即 $\pi(z)$）猛涨。压尾部要 $r$ 大，压税要 $z$ 小、$r$ 小于 $\pi(z)$ 的对数刻度——两个条件挤在同一对 $(r, z)$ 上，$r \sim s \sim \ln\ln x$、$z = x^{1/s}$ 是可行解，代价是主项的 $s^2 = (\ln\ln x)^2$ 折损。（§6.3）
4. 去 lcm 把 $f([d,e])$ 分裂成 $f(qm)f(rm)/f(m)$ 并用 $\mu$ 摘除互素条件；收集 $lm = n$ 造出对角权重 $g(n) = \prod f/(1-f)$；配方在约束 $\sum \omega_n \mu(n) = 1$ 下给出下界 $M \ge 1/G$。单素数恒等式 $(1 + g(p))(1 - 1/p)^2 = (1 - \frac{1}{(p-1)^2})^{-1}$（$p > 2$）把 $H(0)$ 化为 $\frac{1}{2C_2}$，Tauberian 定理给 $G(D) \sim (\ln D)^2/(4C_2)$。$|\lambda_d| \le 1$ 使余项 $|R| \le (\sum_{d \le D} 2^{\omega(d)})^2 \ll D^2\ln^2 D$，从而 $D$ 可取 $\sqrt x/\ln^3 x$。（§6.4）
5. 正交性引理 $\int_0^1 \mathrm{e}(m\alpha)\,\mathrm{d}\alpha = [m = 0]$ 把 $S^3\mathrm{e}(-N\alpha)$ 的积分逐项筛成 $n_1 + n_2 + n_3 = N$。主弧近似的两个成分：等差数列中素数的均匀性给出每类 $\frac{1}{\varphi(q)} V(\beta)$；$\sum_{(r,q)=1} \mathrm{e}(ra/q) = c_q(a) = \mu(q)$（$r \mapsto ar$ 置换单位类 + Möbius 反演）把 $\varphi(q)$ 个类聚成系数 $\frac{\mu(q)}{\varphi(q)}$。（§6.5、§6.6）
6. $p \nmid N$ 时目标剩余非零，$c_p(-N) = -1$，因子 $1 + \frac{1}{(p-1)^3} > 1$；$p \mid N$ 时目标为 0，单位三元组中和为 0 的比例 $\frac{p-2}{(p-1)^2}$ 低于非零情形，因子 $1 - \frac{1}{(p-1)^2} < 1$——每个素数一个独立的局部密度修正。级配：三素数次弧只需逐点上界（$L^2$ 质量 $N\ln N$ 乘 $N/\ln^A N$ 的 sup 是 $o(N^2)$，压得住 $N^2$ 主项）；二素数主项 $N$ 与次弧质量 $N \ln N$ 同级，必须直接控制次弧分布，撞上 Type I/II 与分布水平 $1/2$ 屏障。（§6.6、§6.7）

### $\rm \S \, 6.11.2$ 应用与辨析答案

1. 容斥：$30 - \lfloor 30/2 \rfloor - \lfloor 30/3 \rfloor + \lfloor 30/6 \rfloor = 30 - 15 - 10 + 5 = 10$。局部密度：每类贡献 $30 \cdot (1 - \frac12)(1 - \frac13) = 10$，一致。这里是 $\rho(2) = \rho(3) = 1$ 的单类情形，主项与精确值只差 $\lfloor \cdot \rfloor$ 的取整误差。（§6.2）
2. 错误一：比较对象错位——Legendre 主项是「独立乘积概率」的近似，它漏掉的正是各素数条件之间的相关性，Hardy–Littlewood 猜想的常数 $2C_2$ 已经用奇异级数把相关性算清（$\prod \frac{p(p-2)}{(p-1)^2}$ 修正），两者相差 $\mathrm{e}^{2\gamma}$ 是 Mertens 乘积与「真密度」的已知系统差，不是猜想的矛盾。错误二：Legendre 筛的误差项超过任何幂，主项常数在账本上根本不可读——一个被无穷大误差淹没的数字不能用来反驳任何命题。（§6.2）
3. Brun 的误差税 $\sum_{d \mid P(z)} \rho(d)$ 对 $P(z)$ 的**每个**因子收税，$z$ 增大时按 $3^{\pi(z)}$ 爆炸，故 $z$ 必须压到 $x^{1/s}$、$s \sim \ln\ln x$；Selberg 的余项只对 $d, e \le D$ 的对子收税且 $|\lambda_d| \le 1$，税 $\ll D^2 \ln^2 D$ 与 $z$ 无关，于是 $z$ 可停在 $\sqrt x$ 而主项常数不受折损。（§6.3、§6.4）
4. 文献乙的 $16C_2$ 用 $C_2 = 0.66016$（本文口径），文献甲的「8 倍」相对奇异级数 $\mathfrak{S}_2 = 2C_2 = 1.3203$；$16C_2 = 8 \times (2C_2)$，同一结果。换算规则：先查该文献里 Hardy–Littlewood 预测写成 $C \cdot x/\ln^2 x$ 的 $C$ 是 $C_2$ 还是 $2C_2$，再对齐。（§6.4）
5. 方向错误：弱哥德巴赫（奇数 $=$ 三素数）不蕴含二元（偶数 $=$ 两素数）——三元表示里三、两个偶素数的组合无法拆出一个确定的二元分解；逻辑上强蕴含弱（$N$ 奇时 $N - 3$ 为偶、若 $N - 3$ 可写成两素数之和即得三元表示），而已被证明的是弱的那头。圆法层面的实质障碍：把弱哥德巴赫的论证搬到二元，主项从 $\frac{N^2}{2}\mathfrak{S}(N)$ 掉到 $\approx N\mathfrak{S}_2(N)$，与次弧 $L^2$ 质量 $N\ln N$ 同级，「主弧算主项、次弧当误差」的分工失效，需要目前不可得的次弧分布控制（§6.7 的 Type I/II 与 $1/2$ 屏障）。（§6.7）
