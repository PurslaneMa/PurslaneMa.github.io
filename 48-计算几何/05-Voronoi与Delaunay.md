## $\rm \S \, 5.1$ Voronoi 图：最近点的管辖分区

给定点集 $P = \{p_1, \ldots, p_n\}$，点 $p_i$ 的 **Voronoi 格**：

$$
V_i = \{\, x : |x - p_i| \le |x - p_j| \ \forall j \ne i \,\}
$$

**关键观察（本章一切性质的源头）**：$|x - p_i| \le |x - p_j|$ 等价于 $x$ 落在 $p_i p_j$ 垂直平分线靠近 $p_i$ 的一侧——是一个**半平面**。于是

$$
V_i = \bigcap_{j \ne i} H_{ij}, \qquad H_{ij} = \{x : (x - \tfrac{p_i + p_j}{2}) \cdot (p_j - p_i) \le 0\}
$$

**n−1 个半平面的交**。由第 1 章（凸集）知：Voronoi 格是**凸多边形**（可能无界）。**白话**：每个点一块「势力范围」，边界上的居民到两个点的距离相等——像两张纸的褶皱。

**复杂度**：Voronoi 图（作为平面图）顶点数 ≤ 2n − 5、边数 ≤ 3n − 6（欧拉公式实算：$V - E + F = 2$ 且每面至少 3 边——第 1 章 §1.5 的锚在这里第二次出场）。

**完整小例（3 个点的 Voronoi，逐边手算）**：取 $P_1 = (0,0)$、$P_2 = (4,0)$、$P_3 = (0,4)$。逐条写垂直平分线——用 $H_{ij}$ 的定义式：过中点、法向 $p_j - p_i$：

1. $P_1 P_2$：中点 (2,0)，法向 (4,0)，不等式 $4(x-2) \le 0$，平分线 x = 2，$P_1$ 侧 x ≤ 2；
2. $P_1 P_3$：中点 (0,2)，法向 (0,4)，不等式 $4(y-2) \le 0$，平分线 y = 2，$P_1$ 侧 y ≤ 2；
3. $P_2 P_3$：中点 (2,2)，法向 (−4,4)，不等式 $-4(x-2) + 4(y-2) \le 0$，即 y ≤ x——验证 $P_2 = (4,0)$ 在内：$0 \le 4$ ✓。

三个格全是两条半平面的交：

$$
V_1 = \{x \le 2\} \cap \{y \le 2\}, \qquad V_2 = \{x \ge 2\} \cap \{y \le x\}, \qquad V_3 = \{y \ge 2\} \cap \{y \ge x\}
$$

读法：三格全部无界（三点的凸包是三角形，格伸向无穷），公共边界恰好落在三条平分线上；三条平分线两两求交全交在同一点 (2,2)——它到三点距离平方都是 $4 + 4 = 8$，是不共线三点唯一的等距点（外心），即本图唯一的 Voronoi 顶点。程序实跑核对（平分线方程、等距性、归属采样）：

```text
平分线 P1P2: 4x + 0y = 8 (即 x = 2)
平分线 P1P3: 0x + 4y = 8 (即 y = 2)
平分线 P2P3: -4x + 4y = 0 (即 y = x)
(2,2) 到三点距离平方: [8, 8, 8]
采样: (-1,0) 属 P1 格; (3,0) 属 P2 格; (0,3) 属 P3 格
```

## $\rm \S \, 5.2$ Delaunay 三角剖分：对偶的双胞胎

两个点 $p_i, p_j$ 连一条边，当且仅当它们的 Voronoi 格共享一条边——这张图叫 **Delaunay 图**（通常就是三角剖分）。

**对偶性（陈述级＋为什么）**：Voronoi 顶点 = 到三个点等距的圆心 ⟹ 它所在的三格两两相邻 ⟹ 三个点两两连边构成 Delaunay 三角形；反之 Delaunay 边 ⟺ 分割穴的 Voronoi 边。两个图互为对偶（Voronoi 的面 ↔ Delaunay 的顶点，边 ↔ 边，顶点 ↔ 面）。

**三条立刻的性质**：

1. Delaunay 图是平面图（边不相交——因为对应的 Voronoi 边不相交）；
2. 若 $P$ 无四点共圆，Delaunay 是**唯一的三角剖分**（退化时需一致化打破对称，工程上按随机抖动处理）；
3. 外边界给凸包：Delaunay 剖分恰以凸包为外壳（第 2 章的回扣）。

## $\rm \S \, 5.3$ 空圆性质（本章主证）

**定理 5.1**。$\triangle abc$ 是 Delaunay 三角形 ⟺ 其外接圆内不含任何输入点（空圆性质）。

**证明**。设 $O$ 为 $abc$ 的外心（三格外接点）。(⇐) 若外接圆内无点，则 $O$ 到 ${a, b, c}$ 最近 ⟹ $O$ 是 Voronoi 顶点（三格交会点）⟹ $abc$ 是 Delaunay 三角形。(⇒) 若 $abc$ 是 Delaunay 三角形、$O$ 是三格外接顶点，则 $|Oa| = |Ob| = |Oc| \le |Oq|$ 对一切 $q \in P$（$O$ 在 $a$ 的 Voronoi 格里即得）——即外接圆内（半径 $|Oa|$ 内）无点。$\blacksquare$

**等价刻画**：「Delaunay = 所有三角剖分中**最大化最小角**的那个」——空圆性质与最大最小角是同一件事的两个侧面（陈述级，出处 de Berg 第 9 章）。**读法**：空圆性质是**局部判据**——判断三角剖分是不是 Delaunay，只需逐三角形查空圆；而「最小角最大」是全局最优性陈述。局部⟺全局正是 Delaunay 的魅力。

**完整验证例（4 个固定点的两种剖分，实跑照抄）**：A(0,0)、B(4,0)、C(5,3)、D(0,3) 构成凸四边形，两条对角线给出两个候选：T1 连 AC（三角形 ABC、ACD），T2 连 BD（三角形 ABD、BCD）。逐三角形查空圆：

1. T1 的三角形 ABC：AB 的中垂线 x = 2；AC 的中点 (5/2, 3/2)、斜率 3/5，中垂线斜率 −5/3，代入 x = 2 得 y = 3/2 + 5/6 = 7/3——外心 (2, 7/3)，半径平方 $r^2 = 4 + 49/9 = 85/9$。查 D=(0,3)：距离平方 $4 + 4/9 = 40/9 < 85/9$，**D 在圆内，T1 违背空圆，不是 Delaunay**；
2. T2 的三角形 ABD：∠A 是直角，外心取斜边 BD 中点 (2, 3/2)，$r^2 = 25/4$。查 C=(5,3)：距离平方 $9 + 9/4 = 45/4 > 25/4$，圆外 ✓；
3. T2 的三角形 BCD：CD 的中垂线 x = 5/2；BC 的中点 (9/2, 3/2)、斜率 3，中垂线斜率 −1/3，代入得 y = 3/2 + 2/3 = 13/6——外心 (5/2, 13/6)，$r^2 = 9/4 + 169/36 = 125/18$。查 A=(0,0)：$25/4 + 169/36 = 197/18 > 125/18$，圆外 ✓。

```text
T1 外接圆 ABC: 圆心 (2.0000, 2.3333) 半径^2 = 9.4444 ; D 距离^2 = 4.4444  -> 在圆内
T2 外接圆 ABD: 圆心 (2.0000, 1.5000) 半径^2 = 6.2500 ; C 距离^2 = 11.2500 -> 不在圆内
T2 外接圆 BCD: 圆心 (2.5000, 2.1667) 半径^2 = 6.9444 ; A 距离^2 = 10.9444 -> 不在圆内
```

读法：T1 的违例不是压线——D 离圆心约 2.11 而半径约 3.07，差得很富余，空圆检查不需要 eps 级分辨率就能裁决。对偶地，T1 里那条违约的对角线 AC 正是 §5.4 随机增量要翻掉（flip）的边：翻边判据就是这段外接圆计算。

## $\rm \S \, 5.4$ 构造路线

1. **Fortune 扫描线**（1986）：Voronoi 的海滩线扫掠，O(n log n)——理论最优、实现凶险（退化族与扫描线的复合沼泽）。
2. **随机增量 Delaunay**（Guibas–Stolfi）：每次插点——定位、分裂、**翻边**（非法边当且仅当违背空圆：flip 检查 O(1)）；期望 O(n log n)，实现友好。
3. **分治 O(n log n)**：经典教科书路线。
4. **OI 实用口径**：n ≤ 2000 时 O(n²) 暴力足够——对每个点算 n−1 个半平面交，或直接暴力空圆检查。写题时先问 n。

**最大化最小角的数值演示**（§5.3 的同一份四边形，实跑照抄）：两种切法各出 6 个角，比角用 tan 不调反三角——角 aob 的 tan = |叉积|/点积，锐角范围内 tan 单调，比 tan 即比角（第 1 章「全程不开方」口径的表亲）：

| 剖分 | 六个角（度） | 最小角 | 最小角的 tan |
| --- | --- | --- | --- |
| T1（连 AC） | 30.96, 108.43, 40.60, 59.04, 30.96, 90.00 | 30.96° | 3/5 = 0.60 |
| T2（连 BD） | 90.00, 36.87, 53.13, 71.57, 71.57, 36.87 | 36.87° | 3/4 = 0.75 |

两枚最小角的 tan 手算：T1 的担当角在 A，两边 AB、AC 的叉积绝对值 $|4 \cdot 3 - 0 \cdot 5| = 12$、点积 $4 \cdot 5 + 0 \cdot 3 = 20$，tan = 12/20 = 3/5；T2 的担当角在 B，两边 BA、BD 的叉积绝对值 $|(-4) \cdot 3 - 0 \cdot (-4)| = 12$、点积 $(-4)(-4) + 0 \cdot 3 = 16$，tan = 12/16 = 3/4。$0.60 < 0.75$，T2 更平——与「T2 才是 Delaunay」（§5.3 逐圆验过）互相咬合：同一份数据，空圆性质与最大最小角给出同一裁决。

## $\rm \S \, 5.5$ 数值实验

固定 10 个整数点（seed 2026），三份账对验：

1. **暴力 Voronoi**：网格采样逐点找最近点，画出的分区与「半平面交通用」一致（采样分辨率 0.1）；
2. **空圆逐边检查**：对暴力构造的 Delaunay 边集，逐三角形验证外接圆内无点——全过；
3. **欧拉对账**：剖分的 $V - E + F = 2$（含外域）逐数对上（第 1 章锚第三次出场）。

程序段给完整可跑版（约 50 行：暴力最近点 + 空圆检查）。

```python
import random
from collections import Counter

def circumcenter(a, b, c):                     # 外接圆圆心与半径平方; 共线返回 None
    d = 2*(a[0]*(b[1]-c[1]) + b[0]*(c[1]-a[1]) + c[0]*(a[1]-b[1]))
    if d == 0: return None
    sa, sb, sc = a[0]**2+a[1]**2, b[0]**2+b[1]**2, c[0]**2+c[1]**2
    ux = (sa*(b[1]-c[1]) + sb*(c[1]-a[1]) + sc*(a[1]-b[1])) / d
    uy = (sa*(c[0]-b[0]) + sb*(a[0]-c[0]) + sc*(b[0]-a[0])) / d
    return (ux, uy, (a[0]-ux)**2 + (a[1]-uy)**2)

random.seed(2026)
P = sorted(set((random.randint(0, 30), random.randint(0, 30)) for _ in range(10)))
n = len(P)
tris = []                                      # 空圆检查: C(n,3) 个三元组全查
for i in range(n):
    for j in range(i+1, n):
        for k in range(j+1, n):
            cc = circumcenter(P[i], P[j], P[k])
            if cc and all((P[l][0]-cc[0])**2 + (P[l][1]-cc[1])**2 >= cc[2]
                          for l in range(n) if l not in (i, j, k)):
                tris.append((i, j, k))
cnt = Counter()
for i, j, k in tris:
    for e in ((i, j), (j, k), (i, k)): cnt[(min(e), max(e))] += 1
E, interior = len(cnt), {e for e in cnt if cnt[e] == 2}
print("T=%d V=%d E=%d F=%d V-E+F=%d 内部边=%d" % (
    len(tris), n, E, len(tris)+1, n-E+len(tris)+1, len(interior)))
lo, hi, step = (2, 9), (28, 31), 0.1           # 采样窗口罩住全部点
nx, ny = int((hi[0]-lo[0])/step)+1, int((hi[1]-lo[1])/step)+1
own = [[min(range(n), key=lambda i: (lo[0]+c*step-P[i][0])**2 + (lo[1]+r*step-P[i][1])**2)
        for c in range(nx)] for r in range(ny)]
adj = set()
for r in range(ny):
    for c in range(nx):
        if c+1 < nx and own[r][c] != own[r][c+1]:
            adj.add((min(own[r][c], own[r][c+1]), max(own[r][c], own[r][c+1])))
        if r+1 < ny and own[r][c] != own[r+1][c]:
            adj.add((min(own[r][c], own[r+1][c]), max(own[r][c], own[r+1][c])))
print("采样邻接 %d 对; 内部边全部命中: %s" % (len(adj), interior <= adj))
print("多出的邻接对(凸包边的对偶射线被窗口截断):", sorted(adj - interior))
```

在我机器上的输出：

```text
T=12 V=10 E=21 F=13 V-E+F=2 内部边=15
采样邻接 20 对; 内部边全部命中: True
多出的邻接对(凸包边的对偶射线被窗口截断): [(0, 1), (0, 5), (4, 9), (5, 8), (8, 9)]
```

读法分三笔：1. **空圆账**——12 个三元组的外接圆内无任何其他点，它们就是全部 Delaunay 三角形；数目自洽：$T = 2n - 2 - h = 12$、$E = 3n - 3 - h = 21$（凸包 $h = 6$ 个顶点，边出现次数 15 条 ×2 ＋ 6 条 ×1，凸包边只属一个三角形）。2. **欧拉账**——$V - E + F = 10 - 21 + 13 = 2$，§5.5 第 3 条的账在程序里逐数兑现（第 1 章 §1.5）。3. **对偶账**——15 条内部边全部以「相邻采样格归属不同点」现身；多出的 5 对是凸包边的对偶：它们的 Voronoi 边界是伸向无穷的**射线**，被窗口边框截断后看起来像普通邻接。凸包边 (1,4) 的对偶射线整段在窗外（它从三角形 ${1, 2, 4}$ 的外心出发——中垂线 x = 5 与 9x + 2y = 161.5 交于 (5, 58.25)），采样完全照不见。「无界格要特殊处理」说的就是这 6 条射线：有界采样照不全，是原理不是 bug。

## $\rm \S \, 5.6$ 应用一瞥

1. **最近邻查询**：在 Voronoi 图上游走（每次跨边到邻居），期望 O(√n)（Kibriya 等的实用算法）。
2. **自然邻域插值**：地形/气象插值用 Voronoi 面积权重（Sibson 插值一句话）。
3. **机器人路径规划**：Voronoi 图是「离所有障碍最远的通道骨架」——沿边走的路径最大化安全距离（接 EB04 运动规划的接口）。
4. **生物作息**：从蚊虫领地到神经元感受野（Voronoi 模型的现实版）。

**接口两句**：向前——最近邻查询的工程化由第 6 章 §6.2 的 kd 树接管（Voronoi 游走的期望 $O(\sqrt{n})$ 与 kd 树的平均 $O(\log n)$ 是同一问题的两种「组织」，一个按管辖分区走、一个按空间划分走），构造时的退化警惕则全盘继承第 4 章 §4.3 的清单；向后——EB04 运动规划直接住在第 3 条上：Voronoi 图当最大间隙路图、Delaunay 三角网当地形插值与碰撞检查的底座，两边的接口都从本章的定义式长出来。

## $\rm \S \, 5.8$ 本章自测答案

1. 定义式展开成 n−1 个线性不等式（半平面交），凸性来自半平面。（§5.1）
2. n−1 个；Voronoi 图整体 V ≤ 2n−5、E ≤ 3n−6。（§5.1）
3. 面↔顶点、边↔边、顶点↔面。（§5.2）
4. 外心最近 ⟹ Voronoi 顶点 ⟹ 三格相邻；反向由「$O$ 在 $a$ 格内」读距离不等式。（§5.3）
5. 局部＝逐三角形空圆检查；全局＝最小角最大。（§5.3）
6. 新点插入可能造出违空圆的边，flip 修正；判据＝对边两三角形四点共圆测试。（§5.4）
7. 推导：三条平分线两两求交都得 (2,2)——它到三点距离平方都是 $4 + 4 = 8$。不共线三点的等距点唯一（外心到三点等距，必在第三条中垂线上），三线共点是必然不是巧合；这个交点就是 Voronoi 顶点，三格在此交会、各自沿一条平分线伸向无穷。（§5.1）
8. 定理 5.1 是双向的当且仅当：剖分的每个三角形外接圆空 ⟺ 每个三角形是 Delaunay 三角形 ⟺ 剖分是 Delaunay 剖分。「最小角最大」不必直接验——它是空圆性质的全局侧面（§5.3 的等价刻画），局部判据逐个过完，全局结论自动到手。§5.3 的四点例是全套流程的缩样：查出 ABC 的外接圆含 D，一票否决 T1。（§5.3）
9. 锐角场合（点积为正）tan 在 $(0, \pi/2)$ 单调递增，比 tan 即比角；tan 只用乘加减（叉积、点积在整数坐标下可精确算），不开方不反解——第 1 章平方距离口径的直系表亲。失效场合：角非锐角（点积为负，tan 变号或发散，须先按象限分类再比）；角退化（叉积为零，0° 或 180°）。（§5.4）
