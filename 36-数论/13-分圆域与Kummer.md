## $\rm \S \, 13.1$ 动机：把 Fermat 搬进分圆域

$p$ 为奇素数，$x^p + y^p = z^p$ 两边在 $\mathbb{Z}[\zeta_p]$ 里看。令 $\zeta = \zeta_p$，$x^p + y^p = \prod_{j=0}^{p-1} (x + \zeta^j y)$——左边一个整数裂成 $p$ 个分圆整数的乘积。**白话**：Fermat 方程在整数世界里是一块顽石，搬进 $\mathbb{Q}(\zeta_p)$ 后碎成 $p$ 片，每片是一个线性因子；如果这些因子两两「基本互素」，就能逐片强约束——每片各自是 $p$ 次幂的理想倍。Kummer 一开始以为 $\mathbb{Z}[\zeta_p]$ 也像 $\mathbb{Z}$ 一样唯一分解，1847 年被 Cauchy/Liouville 的反例打醒（$p = 23$ 时失效），随即发明理想论补锅——第 8 章那套机器的诞生动机之一就在这里。

## $\rm \S \, 13.2$ 分圆整数的算术

1. **整环与判别式**：$\mathcal{O}_{\mathbb{Q}(\zeta_p)} = \mathbb{Z}[\zeta]$（$p$ 素时无整基修正），判别式 $D = (-1)^{(p-1)/2} p^{p-2}$——**只含 $p$ 的幂**，所以 $p$ 是唯一的分歧素数（第 8 章判别式账的直接推论：分歧只发生在 $p \mid D$ 处）。 moreover $(p) = (1 - \zeta)^{p-1} \cdot \text{unit}$，即 $p$ 完全分歧成 $p$ 个共轭素理想，全部由单个素理想 $(1-\zeta)$ 生成——「$1-\zeta$」这把小钥匙会在 §13.4 反复出现。
2. **单位**：Dirichlet 单位定理给单位秩 $\frac{p-3}{2}$（实子域贡献），加上 $\pm\zeta^j$ 的单位根——单位群比 $\mathbb{Z}$ 丰富得多，这恰是 §13.4 证明的难点来源。
3. **类数**：$h_p = |\mathrm{Cl}(\mathbb{Q}(\zeta_p))|$。Kummer 证明 $h_p$ 有「正负两半」$h_p = h_p^+ h_p^-$（正半来自实子域、负半来自复特征的部分 Jacobi 和行列式），且 $p \mid h_p \iff p \mid h_p^-$——负半可计算，这是判据可行性的根。

## $\rm \S \, 13.3$ Kummer 判据：Bernoulli 分子说了算

**定义**：$p$ **正则**（regular），若 $p$ 不整除 $h_p$；否则非正则（irregular）。Kummer 的等价刻画（1850—1857，本章主证线；全证见 Washington《Introduction to Cyclotomic Fields》第 5、9 章，此处给骨架）：

$$
p \text{ 正则} \iff p \nmid \mathrm{num}(B_k) \quad \text{对全部偶数 } 2 \le k \le p - 3
$$

其中 $B_k$ 是 Bernoulli 数（$\mathrm{num}(B_k)$ 为写成分数后最简分子的绝对值）。骨架三步：1. 负半类数 $h_p^-$ 是若干广义 Bernoulli 值 $B_{1,\chi}$ 的乘积（解析类数公式——第 13 章的机器——在分圆域的相对化）；2. $p \mid h_p^- \iff$ 某个 $B_{1,\chi} \equiv 0 \pmod p$；3. Herbrand 类 Bernoulli 平移恒等式把 $B_{1,\chi}$ 的零性翻译成普通 $B_k$ 分子的整除性。**程序判据**一行：`bernoulli(k).p % p == 0`（sympy 的 `bernoulli(k).p` 取分子），对 $k$ 取偶数 $2, 4, \ldots, p-3$ 逐个测。

**读法**：判据把「类群这种看不见的结构」完全翻译成「一列既定有理数的分子」——这正是 Kummer 留给计算数论的遗产：结构问题 ⟶ 数值审计。

**程序实现与 $p < 250$ 全表（本机 sympy 实测）。** 判据逐素数、逐偶指数地测分子整除：

```python
from sympy import bernoulli, primerange

def irregular_pairs(p):
    # Kummer 判据: 偶数 k, 2 <= k <= p-3, p 整除 num(B_k)
    return [k for k in range(2, p - 2, 2) if bernoulli(k).p % p == 0]

table = [(p, irregular_pairs(p)) for p in primerange(3, 250)]
for p, ks in table:
    if ks:
        print(f"p = {p}: k = {ks}" + ("   <- 双 pair" if len(ks) > 1 else ""))
print("p < 250 非正则素数个数:", sum(1 for _, ks in table if ks))
B32 = bernoulli(32)
print("num(B_32) =", abs(B32.p), f"({len(str(abs(B32.p)))} 位), 37 整除它:", B32.p % 37 == 0)
```

运行方法：存成 `.py` 后 `python 文件名.py`。本机实测输出：

```text
p = 37: k = [32]
p = 59: k = [44]
p = 67: k = [58]
p = 101: k = [68]
p = 103: k = [24]
p = 131: k = [22]
p = 149: k = [130]
p = 157: k = [62, 110]   <- 双 pair
p = 233: k = [84]
p < 250 非正则素数个数: 9
num(B_32) = 7709321041217 (13 位), 37 整除它: True
```

程序读法：`range(2, p - 2, 2)` 就是窗口 $2 \le k \le p - 3$ 的代码形态（$p$ 奇，右端开区间卡在 $p - 3$）；`bernoulli(k).p` 取最简分数的分子（sympy 精确有理数，无浮点污染）。表与 §13.5 的清单完全一致，另附分子本身：$37 \mid \mathrm{num}(B_{32})$，而 $\mathrm{num}(B_{32}) = 7709321041217$ 只有 13 位——判据的可行性全靠 Bernoulli 分子的精确可计算性，没有这一层，「$p$ 整除类数」在 $p = 37$ 的时代根本无法检验。

## $\rm \S \, 13.4$ FLT 第一种情形：证明骨架

**定理**（Kummer）：$p$ 正则时，$x^p + y^p = z^p$ 无满足 $p \nmid xyz$ 的正整数解（第一种情形）。骨架三步（全证超出本章，标 Washington 第 9 章）：

1. **理想分解与互素**：在 $\mathbb{Z}[\zeta]$ 中 $x^p + y^p = \prod (x + \zeta^j y)$；$p \nmid xyz$ 加 $p$ 唯一分歧的事实，推出各因子两两仅可能共享 $(1-\zeta)$ 的固定小幂——整理后每个因子都与 $p$ 次幂理想相伴。
2. **Kummer 引理**：若理想 $(1-\zeta)^{2-2p}$ 整除某个主理想 $(\alpha)$ 且 $\alpha$ 与某整数模 $(1-\zeta)^2$ 同余，则 $\alpha$ 模 $p$ 后退化为普通整数——这一步把「分圆世界的幂理想」摁回「整数世界的幂」。
3. **单位的抵抗**：把两份表达对账，得 $(a+b\zeta)^p$ 型恒等式；比较 $\zeta$ 系数并把单位吸收进 $p$ 次幂，最终落到「$p \mid B_{p-1-f}$ 对某个偶 $f$」的矛盾——单位群的 $p$ 部分与「$p \nmid h_p$」（正则性）在此正面交锋，正则性恰保证单位不提供逃生门。

「第二种情形」（$p \mid xyz$）的困难在因子们不再互素、$(1-\zeta)$ 的幂次纠缠——Kummer 时代只部分解决，完整处理要到 20 世纪（Vandiver 的补丁，且仍有条件性争议）。**历史注记**：Kummer 曾宣称判据对一切 $p$ 成立，1847 年后被自己算出的 $p = 37$ 反例打脸——第一个非正则素数，恰好是 §13.5 程序吐出的第一个。

**数值侧的判据可信度检查（不是证明）。** 定理说「正则 ⟹ 情形 I 无解」，这条蕴涵本身可以拿暴力扫描垫个数值地板——对最小的两个正则素数 $p = 3, 5$，在 $1 \le x, y, z \le 30$ 的盒子里清点：

```python
def flt_case1(p, B=30):
    # 情形 I: p 不整除 xyz; 三重循环里凡是 x, y, z 含 p 的直接跳过
    hits = []
    checked = 0
    for x in range(1, B + 1):
        for y in range(1, B + 1):
            for z in range(1, B + 1):
                if p in (x, y, z):
                    continue
                checked += 1
                if x ** p + y ** p == z ** p:
                    hits.append((x, y, z))
    return checked, hits

for p in (3, 5):
    checked, hits = flt_case1(p)
    print(f"p = {p}: 扫描 {checked} 组情形 I 三元组, 命中 {len(hits)} 个")
miss = min(abs(x ** 3 + y ** 3 - z ** 3)
           for x in range(1, 31) for y in range(1, 31) for z in range(1, 31)
           if 3 not in (x, y, z))
print(f"p = 3 的最近擦边距离 = {miss} (如 1^3 + 2^3 = 9, 离 2^3 = 8 只差 1)")
```

本机实测输出：

```text
p = 3: 扫描 24389 组情形 I 三元组, 命中 0 个
p = 5: 扫描 24389 组情形 I 三元组, 命中 0 个
p = 3 的最近擦边距离 = 1 (如 1^3 + 2^3 = 9, 离 2^3 = 8 只差 1)
```

**读法**：两件事分清楚。零命中什么也没证明——反例可以在任何有限盒外，Kummer 定理的重担全在理想论上；扫描的作用是给「判据可信」装数值地板。而最近擦边才真正有信息量：$1^3 + 2^3 = 9$ 与 $2^3 = 8$ 只差 $1$，方程可以贴到无限近而不重合——FLT 不是「碰巧没有解」，是整数结构在深层挡住了它，这正是需要分圆域这种重型机器的原因。

## $\rm \S \, 13.5$ 实算：非正则素数全表（本机 sympy 实测）

判据 `bernoulli(k).p % p == 0`（$k$ 偶、$2 \le k \le p-3$）逐素数扫描：

1. **$p < 100$：非正则素数恰为三个**——$37 \mid \mathrm{num}(B_{32})$、$59 \mid \mathrm{num}(B_{44})$、$67 \mid \mathrm{num}(B_{58})$；其余 21 个素数（3 到 97）全部正则。
2. **延展到 250**：$101[B_{68}]$、$103[B_{24}]$、$131[B_{22}]$、$149[B_{130}]$、$157[B_{62}, B_{110}]$（双 pair！）、$233[B_{84}]$——合计 9 个非正则，密度约 $9/53 \approx 17\%$，与启发式密度 $1 - \mathrm{e}^{-1/2} \approx 39\%$ 的低阶偏差（每素数平均 $\frac12$ 个 pair、泊松近似在小区间偏高）方向一致。
3. **pair 的多寡**：157 有两组 $(B_{62}, B_{110})$；非正则性可以「多重」，而判据只要命中一次即判负。
4. **首个反例的分量**：$B_{32}$ 的分子是 13 位大整数（$7709321041217$，见 §13.3 程序输出）——判据的可行性全靠 Bernoulli 分子的可计算性（sympy 精确有理数），没有这一层，「p 整除类数」的结构判据在 $p = 37$ 时代根本无法检验。

**pair 的完整含义**。表里的记号如 $157[B_{62}, B_{110}]$ 值得拆开讲清楚。一个 **irregular pair** 是二元组 $(p, k)$：$k$ 偶、$2 \le k \le p - 3$、$p \mid \mathrm{num}(B_k)$。「指数配对」的机制藏在 Herbrand 定理里：类群负部的每个奇指标 $i$（特征 $\omega^i$）的分量为非平凡 $\iff$ $p \mid \mathrm{num}(B_{p-i})$——偶 Bernoulli 指数 $k$ 通过 $i = p - k$ 与奇特征指标绑成一对，pair 指的就是这根「$k$ 配 $p - k$」的耦合。157 有两组：$k = 62$（配 $i = 95$）与 $k = 110$（配 $i = 47$）。**为什么两组仍只算一个非正则素数**：判据的布尔性——「$p$ 非正则」$\iff$ 「存在某个 $k$ 命中」是一次 OR，命中一次与命中两次的真值相同，非正则素数表里 157 只出现一次；但多出的命中不浪费——Herbrand–Ribet 定理说每个 pair 对应类群负部一个独立的 $\mathbb{Z}/p$ 分量，157 的类群负部因此有两个这样的分量（非正则性指标 $\mathrm{ii}(157) = 2$）。判据只回答「有没有」，分量的个数要靠逐 $k$ 清点 pair 来读。

## $\rm \S \, 13.6$ 出口

1. **Vandiver 猜想**（陈述级）：$p \nmid h_p^+$（正半）。迄今验证到亿级素数无一反例，FLT 情形 II 的现代证明路线押在它身上。
2. **p-adic 方向**（各一句）：p-adic L 函数把 $L(1, \chi)$ 解析延拓到 $p$-adic 世界；Iwasawa 理论用 $\mathbb{Z}_p$-扩张上的模结构给 $h_p$ 的 $p$-部分开出了「主理想定理的渐近版」——Herbrand–Ribet 定理（类群的 $\zeta^k$-分量的结构由 $B_{p-k}$ 分子裁决）是判据的现代深化。
3. **终点回扣**：FLT 的最终证明（Wiles, 1995）走椭圆曲线与模形式，与 Kummer 线在「理想类群控制算术」的精神上同源；椭圆曲线是下一条大支流，第 15 章收束地图登记位置。
4. **接口回扣**：判据骨架第 1 步（$h_p^-$ 是广义 Bernoulli 值的乘积）是第 12 章 §12.3 解析类数公式在分圆域的相对化；「唯一分解失效由理想论补锅」正是第 8 章 §8.6—8.8 那套机器的诞生现场——Kummer 发明理想论的动机清单第一条就是本章的 FLT。两条线的分工与汇合登记在第 15 章收束地图。

## $\rm \S \, 13.8$ 本章自测答案

1. 裂成 $\prod_{j=0}^{p-1}(x + \zeta^j y)$；因子逐片受理想约束，唯一分解失效由理想论补锅。（§13.1）
2. $D = (-1)^{(p-1)/2} p^{p-2}$ 只含 $p$；$p$ 完全分歧，$(p) = (1-\zeta)^{p-1} \times$unit。（§13.2）
3. 正则 $= p \nmid h_p$；等价于 $p$ 不整除任何 $\mathrm{num}(B_k)$（偶 $k$、$2 \le k \le p-3$）。（§13.3）
4. 第 2 步——$h_p^-$ 是广义 Bernoulli 值的乘积，解析类数公式的相对化。（§13.3）
5. 第 3 步单位吸收：正则性保证单位群不提供 $(a+b\zeta)^p$ 恒等式的逃生门。（§13.4）
6. 它是第一个非正则素数（$37 \mid \mathrm{num}(B_{32})$），推翻了 Kummer「判据恒真」的最初宣称。（§13.5）
7. Herbrand 定理把每个偶指数 $k$ 连到类群负部的 $\omega^{p-k}$ 分量，奇指标 $i$ 的范围是 $3 \le i \le p - 2$，对应 $k = p - i$ 跑遍 $2$ 到 $p - 3$；$k = p - 1$（即 $i = 0$，平凡特征）落在正半类数那一侧，审计的是 $h_p^+$ 的账——那是 §13.6 出口 1 里 Vandiver 猜想的地盘，不属于 Kummer 判据。（§13.3）
8. 窗口 $2 \le k \le 56$ 的偶数共 28 个，逐个测 $\mathrm{num}(B_k) \bmod 59$，恰在 $k = 44$ 命中（$59 \mid \mathrm{num}(B_{44})$）——59 非正则，且是 $p < 100$ 的三个非正则素数（37、59、67）之二。（§13.3）
9. 窗口为空 ⟹ 「对所有 $k$ 都不整除」真空成立 ⟹ 3 正则（事实上 $h(\mathbb{Q}(\zeta_3)) = h(\mathbb{Q}(\sqrt{-3})) = 1$，回扣第 12 章 $D = -3$ 的账）。扫描替代不了定理：它只在 $x, y, z \le 30$ 的盒子里清点，反例可以在盒外任何地方；它的角色是给「正则 ⟹ 情形 I」这条已证的蕴涵做数值地板，证明的重担在理想论。（§13.4）

**带走清单**：$x^p+y^p$ 的分圆分解；判别式 $p^{p-2}$ 与完全分歧的 $(1-\zeta)$ 账；Kummer 判据的一行程序实现与 $p<250$ 全表（9 个、含 157 双 pair、pair 的 $k \leftrightarrow p-k$ 耦合）；FLT 情形 I 骨架、情形 II 的难点与数值可信度扫描；Vandiver/Iwasawa/Wiles 三个出口的分工；与第 8 章、第 12 章、第 15 章的接口。
