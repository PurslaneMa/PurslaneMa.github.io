# $\rm Chapter \, 6$ 单子：让「装饰过的函数」重新接成管道

「单子不过是自函子范畴里的幺半群」，这句被引用到烂的话在本章结束时逐词兑现。先说它解决的问题：**副作用把函数复合弄断了**。第 1 章的类型范畴里，$f\colon A\to B$ 与 $g\colon B\to C$ 复合天经地义；可现实程序返回的是「装饰过的值」：可能失败的 $A\to$ `Option<B>`、可能多值的 $A\to$ `List<B>`、异步的 $A\to$ `Future<B>`。$g$ 想吃的是裸 $B$，接不上 $f$ 的输出，管道断了。**单子（monad）**＝一套让装饰函数重新复合的代数：一个装饰方案＋「注入」与「展平」两个操作＋三条律。它同时是本书前五章的总装车间：函子（第 2 章）给装饰方案、自然变换（第 3 章）给两个操作、幺半群（第 1 章 §1.3.3）给三条律的名字。

## $\rm \S \, 6.1$ 要解决的问题：复合断了

看失败传播：`parse: String -> Option<Int>`、`sqrt: Int -> Option<Float>`（负数失败）。想串成「解析再开方」，普通复合 `sqrt ∘ parse` 根本类型不合——`sqrt` 要 `Int`，`parse` 给的是 `Option<Int>`。每个语言各自发明补丁：判空层层嵌套（`if x is None: return None` 写八遍）、异常、回调地狱，补丁的共同形状没人说破。范畴论说破：装饰函数之间有一套**自带的复合**，只要装饰方案满足三条律；满足的那一天，「失败传播」「多值枚举」「异步串行」全部变成同一个复合的实例。

## $\rm \S \, 6.2$ 定义：一个函子、两个操作、三条律

**单子（monad）**（CS 友好的 Kleisli 版）＝一个自函子 $T$ 配两个自然变换：

1. **unit**（注入）：$\eta_A\colon A\to T(A)$，把裸值装进装饰（`Some x`、`[x]`）；
2. **bind**（装饰复合）：对每个 $f\colon A\to T(B)$ 给出 $f^{*}\colon T(A)\to T(B)$，把「装饰函数」提升为「装饰值之间的函数」（先拆装饰、执行、再合装饰）。

三条律（对一切适用的 ${f,g}$、一切 $x$）：

1. 左单位：$\eta^{*}\circ\eta=\mathrm{id}$，先注入再执行等于原函数；
2. 右单位：$\eta^{*}=\mathrm{id}$ 对 $f=\eta$ 成立时（即 $\eta^{*}\colon T(A)\to T(A)$ 是恒等），即注入了又立刻展平，等于什么都没做；
3. 结合：$(g^{*}\circ f)^{*}=g^{*}\circ f^{*}$。**装饰函数的复合满足结合律**，管道可以任意加括号。

三条律合起来的宣言：**Kleisli 复合（$g\circ_{T}f:=g^{*}\circ f$）构成一个真正的范畴**（第 1 章公理逐条对应：unit 态射是 $\eta$，结合律是律 3）。这个范畴叫 **Kleisli 范畴**：对象照旧，态射从 $A\to B$ 换成 $A\to T(B)$。

### $\rm \S \, 6.2.1$ Option 手算

`Some x >>= f = f x`；`None >>= f = None`。三律验：左单位 `Some x >>= f = f x` ✓；右单位 `x >>= Some = x`（`Some` 分支还原、`None` 保持 `None`）✓；结合律按分支展开即 `None` 传染性的一致性 ✓。于是 `parse` 接 `sqrt`：

```text
parse_then_sqrt s = parse s >>= sqrt
```

失败自动传播。§6.1 的层层判空被两行定义吃掉。

### $\rm \S \, 6.2.2$ List 手算

`xs >>= f = concat(map f xs)`：每个元素产生一列分支，全部摊平。例：`[1,2] >>= (x -> [x, -x]) = [1,-1,2,-2]`。三律验（抽查结合律）：`([1,2] >>= f) >>= g` 与 `[1,2] >>= (x -> f(x) >>= g)` 都等于按树状展开后先序摊平的结果。这是**非确定性计算**的代数：一条 Kleisli 态射是「一个输入出多种可能」，复合＝分支树展开。竞赛生的回溯搜索、正则匹配的 NFA 走法，全是 List 单子管道。

## $\rm \S \, 6.3$ 黑话兑现：幺半群视角

「自函子范畴里的幺半群」逐词翻译。**自函子范畴**：对象＝自函子（List、Option……），态射＝自然变换（第 3 章末尾预告的「函子范畴」 restrict 到自己身上）。取定一个自函子 $T$，「幺半群」需要：

1. 一个**乘法**：$\mu\colon T\circ T\Rightarrow T$（双层装饰压平：`join`）；
2. 一个**单位元**：$\eta\colon \mathrm{Id}\Rightarrow T$（unit）；
3. 幺半群律：$\mu\circ T\eta=\mu\circ\eta T=\mathrm{id}$（右/左单位）、$\mu\circ T\mu=\mu\circ\mu T$（结合）。

（$T\eta$、$\eta T$ 是 unit 与 $T$ 的两种「Functor 作用复合」：左侧「先装再压」与右侧「先压再装」，方形图各画一张即第 3 章的自然性练习。）bind 与 join 可以互相同化：$f^{*}=\mu\circ T(f)$，三条律逐字变回幺半群律。**Mac Lane 那句话的全部内容：单子律＝幺半群律在「函子层」的重放**。第 1 章「幺半群是单对象范畴」在此合龙：单子是「幺半群」这个形状在自函子范畴里的再次实例化。名称恐惧症到此可以卸载：你不是在学新对象，是在第三次见老朋友。

## $\rm \S \, 6.4$ Kleisli 日常：三个单子、一种读法

1. **Option**（§6.2.1）：失败传播，错误处理的代数；
2. **List**（§6.2.2）：非确定分支，搜索与枚举的代数；
3. **Future/Promise**：`f: A -> Future<B>` 与 `g: B -> Future<C>` 用 bind 串联＝**异步串行**（后一步吃前一步的完成值）。律保证「回调怎么分层组队」结果一致，异步地狱的代数出口。

工程惯例 `do`-记号（或 async/await）只是 Kleisli 管道的语法糖：`x <- parse s; y <- sqrt x` 逐行脱糖成 bind 串联。**单子的实用判断题**：什么时候**不是**单子？两条操作或三条律坏一条——例如「装饰」是「绝对时间戳」的函子，unit 无法给出：注入一个值总得选时间戳，却没有自然选择，律也无从谈起：不是所有容器都配单子化，律正是资格审查。

> **类比**：单子像「快递管道系统」：unit 是打包，bind 是「拆包、处理、重新打包」的标准流水线，三条律保证流水线怎么分组作业结果一致。Option 的流水线遇到坏件自动终止，List 的流水线把一个包裹拆成多个继续送，Future 的流水线到货才开工。同一条作业规程，三种货品。

## $\rm \S \, 6.6$ 应用与辨析

1. 用 bind 语言验证 List 单子的右单位律 `xs >>= (x -> [x]) = xs`，并举一个「非自然」的装饰方案（如「以绝对时间戳装饰」）说明 unit 为什么给不出。
2. 把「读文件→解析→入库」三个可能失败的步骤写成 Option 单子的 Kleisli 管道（伪代码），并指出失败在第几步被短路、由哪条律保证「短路点之后不再执行」。
3. 同学说：「单子就是容器。」用三条律反驳：给一个容器形状（如「集合 + 任意选一个代表」的操作）它有 map 却凑不出满足律的 unit/bind。缺的是**律**，不是形状。

## $\rm \S \, 6.7$ 本章自测答案

> 先闭卷作答上面两节，再核对。

### $\rm \S \, 6.7.1$ 关键概念回顾答案

1. 自函子 $T$＋unit $\eta\colon A\to T(A)$＋bind $f^{*}\colon T(A)\to T(B)$；三律＝左单位、右单位、结合；修好「装饰函数的复合」。（§6.2）
2. `Some x >>= f = f x`、`None >>= f = None`；左单位 `Some x >>= f = f x`、右单位 `x >>= Some = x`。（§6.2.1）
3. `xs >>= f = concat(map f xs)`；非确定/分支计算（搜索、枚举）。（§6.2.2）
4. 对象＝自函子、乘法＝$\mu\colon T\circ T\Rightarrow T$（join）、单位＝$\eta$；幺半群律（单位、结合）＝单子律的 join 形式。（§6.3）
5. 对象照旧、态射 $A\to T(B)$；`do` 每行脱糖为一次 bind 串联。（§6.2、§6.4）

### $\rm \S \, 6.7.2$ 应用与辨析答案

1. `concat(map (x->[x]) xs) = concat(map (x->[x]) xs)` 逐元素 `[x]` 摊回 `x`，得 `xs` ✓。反例：「带绝对时间戳的值」需要 unit 为每个裸值**选**时间戳，却没有自然选择（任何选择都依赖外部时钟，第 3 章自然性检验直接绞杀），故该装饰连单子的资格都没有。（§6.2、§6.3）
2. `read_file(path) >>= parse >>= save`；失败（返回 `None`）的步骤之后，bind 的 `None` 分支直接返回 `None`。「短路」由 Option 的 bind 定义保证，而「定义合法（不漏分支、不多执行）」由三律背书：结合律保证三步管道无论怎么加括号，短路行为一致。（§6.2.1、§6.4）
3. 「以集合为代表选取」的 bind：`xs >>= f` 需要对每个 `f(x)` 的结果集合「选一个代表」再合。选择不自然（依赖枚举顺序），律无从满足。单子的资格是代数资格（有 unit、有满足律的 bind），不是「装得下东西」的形状资格。（§6.2）
