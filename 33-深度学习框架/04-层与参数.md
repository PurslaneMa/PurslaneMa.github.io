# $\rm Chapter \, 4$ 层与参数：Module 系统

## $\rm \S \, 4.1$ 从算子到层：Linear、ReLU、Sigmoid

层是「前向 + 反向」一对方法，反向的签名统一：收上游梯度 ${g=\partial L/\partial(\text{输出})}$，返回 ${\partial L/\partial(\text{输入})}$。三个基本层各 5 行：

```python
class Linear:
    def forward(self, x):
        self.x = x                      # 反向要用
        return x @ self.W + self.b
    def backward(self, g):
        self.gradW += self.x.T @ g      # dL/dW
        self.gradb += g.sum(axis=0)     # dL/db
        return g @ self.W.T             # dL/dx，传给下一层

class ReLU:
    def forward(self, x):
        self.mask = (x > 0)
        return x * self.mask
    def backward(self, g):
        return g * self.mask

class Sigmoid:
    def forward(self, x):
        self.y = 1 / (1 + np.exp(-x))
        return self.y
    def backward(self, g):
        return g * self.y * (1 - self.y)
```

每一层在反向时缺一点前向的信息，缺什么就要存什么：

| 层 | 前向保存 | 反向公式 | 保存的原因 |
| --- | --- | --- | --- |
| Linear | 输入 ${x}$ | ${\partial L/\partial W=x^{\top}g}$ | 公式里只有 ${g}$ 推不出 ${x}$ |
| ReLU | 掩码 ${x>0}$ | 逐元素 ${g\odot\mathrm{mask}}$ | 导数取 0 或 1，由前向输入决定 |
| Sigmoid | 输出 ${y}$ | ${g\odot y(1-y)}$ | 导数用输出表出最省，不必存 ${x}$ |

第 3 章的闭包是「把回传规则记在每个数上」；层是「把同类数的回传规则合成一个矩阵公式」。`gradW +=` 沿用了 §3.2 的累积规则：同一参数被多个样本共同使用，贡献求和。

## $\rm \S \, 4.2$ 迷你 Module 与两层 MLP

层有了，还需要一个容器：统一「调用」（像函数一样 `net(x)`）、统一「报参数」、统一「清梯度」。25 行的迷你 Module：

```python
class Module:
    def __call__(self, x):              # net(x) 等价于 net.forward(x)
        return self.forward(x)
    def parameters(self):
        ps = []
        for name, v in self.__dict__.items():
            if isinstance(v, Module):   # 子层或子网络都算
                ps += [f"{name}.{q}" for q in v.parameters()]
        return ps
    def zero_grad(self):
        for v in self.__dict__.values():
            if isinstance(v, Module):
                v.zero_grad()
    def forward(self, x):
        raise NotImplementedError

class MLP(Module):
    def __init__(self, W1, b1, W2, b2):
        self.l1 = Linear(W1, b1)
        self.a1 = ReLU()
        self.l2 = Linear(W2, b2)
    def forward(self, x):
        return self.l2(self.a1(self.l1(x)))
```

`MLP` 实例的 `parameters()` 返回 `['l1.W', 'l1.b', 'l2.W', 'l2.b']`（ReLU 无参数，自动跳过）。

## $\rm \S \, 4.3$ 参数管理：名字与递归收集

`parameters()` 返回的是**带名字**的参数表，名字不是装饰：

1. 保存与恢复：checkpoint 里的参数按名字存取（PyTorch 的 `state_dict` 键就是这套名字），换台机器续训靠它对号入座；
2. 调试：梯度爆炸时，`l2.W` 比「第 10086 个数」有用得多；
3. 递归收集：`isinstance(v, Module)` 让嵌套网络自动展开，Module 里放 Module，名字用点号串起来，`net.encoder.l1.W` 这类路径就是这么来的。

`zero_grad()` 也值得一句：第 3 章说梯度要累积（`+=`），那是**同一次反向传播之内**的多路径求和；跨训练步的旧梯度必须清掉。忘记 `zero_grad()` 是常见 bug：优化器拿到的梯度悄悄混着上一步的旧账。PyTorch 里 `optimizer.zero_grad()` 每步必调，同一枚硬币的两面。

## $\rm \S \, 4.4$ PyTorch 对照与初始化

对照实验：${3\to5\to2}$ 的两层 MLP，4 个样本，MSE 损失，两边用同一份权重与输入（float64）：

| 量 | 迷你（NumPy） | torch.nn | 最大差 |
| --- | --- | --- | --- |
| 损失 | 11.777685821502 | 11.777685821502 | ${1.8\times10^{-15}}$ |
| 前向输出 | 同上逐数 | 同上逐数 | ${8.9\times10^{-16}}$ |
| ${W_1}$ 梯度 | ${(3,5)}$ | ${(3,5)}$ | ${1.8\times10^{-15}}$ |
| ${b_1}$ 梯度 | ${(5,)}$ | ${(5,)}$ | ${8.9\times10^{-16}}$ |
| ${W_2}$ 梯度 | ${(5,2)}$ | ${(5,2)}$ | ${1.8\times10^{-15}}$ |
| ${b_2}$ 梯度 | ${(2,)}$ | ${(2,)}$ | ${4.4\times10^{-16}}$ |

验证环境：WSL Ubuntu，PyTorch 2.14.1+cpu，float64。手写层的矩阵公式与 `nn.Linear` 加 `nn.ReLU` 在机器精度上逐数一致。

最后是初始化。偏置可以设零（它不参与层内对称）；权重全零不行，真跑两段小实验：

1. **全零权重**：输入 ${(2,1)}$ 过 Linear(全零) 得前向值 ${(0,0)}$，ReLU 掩码全假，反传后 `gradW` 全零：参数永不更新，网络学不动；
2. **两列相同**：权重两列初始化成一样（前向值 ${(3,3)}$），反传后 `gradW` 是 `[[2, 2], [1, 1]]`，两列永远相同：两个「不同」的隐层单元步调一致，整层退化成一个单元。

第二条正是深度学习分册 §7.4.1 用归纳法证明的对称性：梯度下降只会**保持**初始对称，打破对称的唯一机会是初始化那一刻，所以权重必须随机。本册的贡献是把证明跑成了代码。

## $\rm \S \, 4.7$ 本章自测答案

### $\rm \S \, 4.7.1$ 关键概念回顾答案

1. 收上游梯度 ${g}$、返回对输入的梯度，中途顺手算出参数梯度；Value 闭包把规则记在每个标量上，层把同类标量的规则合并成矩阵公式。（§4.1）
2. Linear 存输入 ${x}$，ReLU 存掩码，Sigmoid 存输出；Sigmoid 的导数 ${y(1-y)}$ 可由输出直接算出，存 ${y}$ 比存 ${x}$ 省一次指数。（§4.1）
3. 保存 checkpoint、定位调试都靠名字对号；递归收集靠 `isinstance(v, Module)`。（§4.3）
4. 跨步旧梯度混入本步更新；不矛盾：`+=` 是一次反向内多路径求和，`zero_grad` 是跨步清账。（§4.3）
5. 全零时前向输出零、ReLU 掩码全假，参数梯度为零，无更新；两列相同时两单元梯度恒同，整层退化成一个单元，这是对称性保持。（§4.4）

### $\rm \S \, 4.7.2$ 应用与辨析答案

1. 每过一层梯度至少乘 0.25，${k}$ 层后衰减到 ${4^{-k}}$ 以下，深网络梯度消失；这正是 Sigmoid 让位给 ReLU/tanh 的原因。（§4.1）
2. 紧跟 BatchNorm 时平移会被归一化吸掉，偏置冗余可去。（§4.4）
3. 落到 float32 机器精度即 ${10^{-7}}$ 量级，仍是「逐数一致」，只是基线变宽。（§4.4）
4. 不会变（`None` 不是 Module，跳过）；`forward` 在 `self.a1(...)` 处抛 `TypeError: 'NoneType' object is not callable`。（§4.2）
5. 对每个名字按点号拆路径、递归找到持有者，把其 `gradW/gradb` 数组原地清零。（§4.3）
