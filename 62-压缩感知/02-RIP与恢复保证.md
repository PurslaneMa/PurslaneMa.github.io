# $\rm Chapter \, 2$ RIP 与恢复保证

## $\rm \S \, 2.1$ 相干性：最容易算的不变量

白话：想知道测量矩阵好不好，最省事是看有没有哪两列长得太像——这就是相干性。它好算，但只看最坏的一对列，恢复条件悲观得离谱；本节先立起来，再用真算的账看清悲观在哪。

设 $A \in \mathrm{R}^{m \times n}$ 的列都已归一化（$\|a_j\|_2 = 1$）。定义**互相干性**（mutual coherence）：

$$
\mu(A) = \max_{i \neq j} \left| \langle a_i, a_j \rangle \right|
$$

读法：$\mu(A)$ 是最不像的两个列向量之间内积的绝对值的最大值——列两两正交时为 0，有完全相同的两列时为 1。它是全矩阵「最大相似度」的单一刻度。相干性能对全矩阵说的第一件事是它的下界，**Welch 界**：

$$
\mu(A) \;\ge\; \sqrt{\frac{n - m}{m (n - 1)}}
$$

读法：$n$ 列单位向量挤在 $m$ 维空间里，两两夹角不可能都开得很大——列越多、空间越小，相干性的下限越高。证明只用到一步迹不等式：记 Gram 矩阵 $G = A^{\mathsf T} A$（对角线全是 1，秩至多 $m$），则

$$
\|G\|_{\mathrm{F}}^2 = \sum_{i, j} G_{ij}^2 \;\ge\; \frac{(\operatorname{tr} G)^2}{\operatorname{rank}(G)} = \frac{n^2}{m}
$$

读法：固定迹与秩时 Frobenius 范数平方的下界（Cauchy–Schwarz，奇异值语言见 [HP 册第 5 章](../39-高维概率与矩阵分析/05-矩阵分析函数与微积分.md)）。而 $\|G\|_{\mathrm{F}}^2 = n + 2 \sum_{i<j} G_{ij}^2 \le n + n(n-1) \mu^2$，两头一夹就是 Welch 界。∎

真算一笔：$m = 28$、$n = 64$ 的高斯矩阵（列归一化），200 次试验 $\mu$ 平均 $0.6228$（范围 $0.5091 \sim 0.7387$），Welch 界只有 $0.1429$——随机矩阵离「最均匀的摆放」还差得远，但已经够用，本节结尾算这笔账。

相干性真正有用的地方是管** spark**：一个矩阵所有线性相关列族中，最小的列数叫 spark($A$)。它是欠定方程解唯一性的总开关。

**定理（spark 与唯一恢复）**：若 $\operatorname{spark}(A) > 2k$，则 $Ax = y$ 的任意 $k$-稀疏解是唯一的稀疏解，从而 $\min \|x\|_0 \;\text{s.t.}\; Ax = y$ 的解恰好就是它。

证明：设 $x_1, x_2$ 都是 $k$-稀疏解，$h = x_1 - x_2$ 至多 ${2k}$-稀疏且 $Ah = 0$，即 $A$ 有一个支撑不超过 ${2k}$ 的零空间向量——这要求 ${2k}$ 列线性相关，与 $\operatorname{spark}(A) > 2k$ 矛盾。∎

而 spark 有两个现成的刻度：其一，$m + 1$ 列向量必线性相关，故 $\operatorname{spark}(A) \le m + 1$——所以 $m \ge 2k$ 是唯一性的必要量级；其二，spark 可以从相干性读出来。

**命题（Gershgorin 下界）**：$\operatorname{spark}(A) \ge 1 + 1/\mu(A)$。

证明：Gershgorin 圆定理说任一方阵的特征值都落在以对角元为圆心、该行非对角元绝对值之和为半径的圆盘里。取 $G = A^{\mathsf T} A$ 的任意 $k \times k$ 主子矩阵（对角元 1，非对角元绝对值 $\le \mu$）：$k < 1 + 1/\mu$ 时每行严格对角占优，0 落不进半径 $< 1$ 的圆盘，故可逆——任意 $k < 1 + 1/\mu$ 列线性无关。∎

真算一笔：$m = 5$、$n = 10$ 的高斯矩阵，200 次试验里全部 $\binom{10}{5} = 252$ 个五列子集都满秩（5 列一般位置下无关、6 列在 $\mathrm{R}^5$ 里自动相关），故 $\operatorname{spark} = 6 = m + 1$；平均 $\bar\mu = 0.895$，下界 $1/\bar\mu + 1 = 2.12$——界成立但很松，$m$ 小时随机列本来就挤。

spark 管 $\ell_0$，相干性还管算法：第 3 章证明 Tropp 条件 $\mu < 1/(2k-1)$ 时 OMP 对一切 $k$-稀疏信号精确恢复。只算账：$n = 64$、$k = 6$ 要求 $\mu < 1/11 = 0.0909$，而实测 $m = 28$ 时 $0.623$、$m = 64$ 时 $0.395$、$m = 200$ 时 $0.247$、$m = 1000$ 时 $0.131$——测到 $m = 1000$（早超过 $n = 64$，采样定理都满足了）还差一个数量级。**相干性判据在典型配置下无解**，可第 1 章同一配置 $m = 28$ 就有 $95\%$ 成功率。差距来源：$\mu$ 用「最坏的一对列」给全体稀疏信号定罪，而成功机理是绝大多数列组合都良好——这正是 RIP 要形式化的东西。

**本节小结**：相干性 $\mu$ 是最坏列对的相似度，Welch 界 $\sqrt{(n-m)/m(n-1)}$ 管它的下限；spark $\ge 1 + 1/\mu$（Gershgorin）加 spark $> 2k$ 给 $\ell_0$ 唯一恢复。但相干性判据悲观到无解：$n = 64$、$k = 6$ 要求 $\mu < 0.0909$，实测 $m = 1000$ 都到不了，而 $m = 28$ 实验成功率 $95\%$——下一节换一个「对全部稀疏子集同时」刻度的量。

## $\rm \S \, 2.2$ 约束等距性质（RIP）

白话：相干性只看最坏的一对列，RIP 看所有 $s$ 列的组合——要求矩阵把任何 $s$-稀疏向量的长度都几乎原样保留。它难算，但它给的恢复条件才是真正够用的。

**定义（约束等距性质）**：称 $A \in \mathrm{R}^{m \times n}$ 满足阶为 $s$、常数为 $\delta_s$ 的约束等距性质，若 $\delta_s$ 是使

$$
(1 - \delta_s) \|x\|_2^2 \;\le\; \|A x\|_2^2 \;\le\; (1 + \delta_s) \|x\|_2^2 \qquad \text{对一切 } \|x\|_0 \le s
$$

成立的最小非负数。

读法：量词只在 $s$-稀疏世界里（全空间等距要 $m \ge n$，就没有压缩了）；不等式说任何 $s$-稀疏信号的能量被保持在真值 $1 \pm \delta_s$ 倍内，$\delta_s$ 取的是最优常数。**两个不同的 $s$-稀疏信号不会撞在一起**：$A x_1 = A x_2$ 给出非零的 $s$-稀疏零空间向量，与下界矛盾——「不同的稀疏信号给出不同的测量」被下半段精确表达。

RIP 有一个完全可计算的刻画，把每列子矩阵的奇异值拉出来即可：

$$
\delta_s = \max_{|T| \le s} \; \max\!\left( \sigma_{\max}^2(A_T) - 1, \; 1 - \sigma_{\min}^2(A_T) \right)
$$

读法：$A_T$ 是抽出列指标集 $T$ 得到的 $m \times |T|$ 子矩阵（$|T| \le s$）；$\sigma_{\max}$、$\sigma_{\min}$ 是它的最大、最小奇异值（语言见 [HP 册第 5 章](../39-高维概率与矩阵分析/05-矩阵分析函数与微积分.md)）。对支撑在 $T$ 里的 $x$，$\|Ax\|_2^2$ 在 $x$ 的单位球上正好张满区间 $[\sigma_{\min}^2, \sigma_{\max}^2]$，所以保距等价于每个子矩阵的奇异值平方都挤在 $1$ 附近。RIP 不是新发明，它就是「所有 $s$ 列子矩阵同时良态」的奇异值条件。

相干性给 RIP 一个免费的上界：$\delta_s \le (s-1)\mu$。证明：对支撑在 $T$（$|T| \le s$）的单位向量 $x$，

$$
\left| \|Ax\|_2^2 - 1 \right| = \left| \sum_{i \neq j \in T} x_i x_j \langle a_i, a_j \rangle \right| \le \mu \left( \left(\textstyle\sum_{i \in T} |x_i|\right)^2 - \sum_{i \in T} x_i^2 \right) \le \mu (s - 1) \|x\|_2^2
$$

读法：对角项 $i = j$ 正好凑出 $\|x\|_2^2 = 1$，非对角项用 $|\langle a_i, a_j\rangle| \le \mu$ 与 $\sum_{i \neq j} |x_i| |x_j| \le (s-1)\|x\|_2^2$ 收口。∎ 这个界不算太松（$\mu = 0.62$ 推 $\delta_2 \le 0.62$，实测 $0.605$），但推 $\delta_6 \le 5 \times 0.62 = 3.1$ 已完全没用；反过来 RIP 也推不出小相干性——$\delta_2 < 1$ 只说没有两列平行。

真算一笔（本章程序段可复现）：$n = 64$ 的高斯矩阵，$\delta_2$、$\delta_3$ 对全部列组合精确枚举、10 次试验平均：

| $m$ | $\delta_2$ | $\delta_3$ |
| --- | --- | --- |
| 28 | 0.605 | 1.025 |
| 32 | 0.582 | 0.914 |
| 40 | 0.562 | 0.904 |
| 48 | 0.503 | 0.775 |
| 56 | 0.470 | 0.742 |

读法：$\delta_2$ 按 $m^{-1/2}$ 下降（测量 $28 \to 56$，比值 $0.78 \approx 1/\sqrt{2}$）；$\delta_3$ 在 $m = 28$ 超过 1——存在拉伸到 2 倍以上的三列组合，RIP 只在 $s$ 不大、$m$ 足够时成立。对比造坏的矩阵 $A = [I_m, I_m]/\sqrt{2}$：相同两列 $\sigma_{\min}^2 = 0$，$\delta_2 = 1$ 精确成立；$k = 2$ 的 OMP 恢复 200 次全灭，同尺寸高斯 $200/200$——RIP 的差距就是成功率的差距。

RIP 还给第 1 章的测量方程一个稳定的误差合同：对任意两个至多 $s$-稀疏的 ${x, x'}$，

$$
\|A(x - x')\|_2 \;\le\; \sqrt{1 + \delta_s}\, \|x - x'\|_2
$$

读法：$x - x'$ 至多 $s$-稀疏，直接套上半段。§2.4 的鲁棒恢复定理说明这份合同反方向（测量误差到信号误差）也能签。

**本节小结**：RIP = 全部 $s$ 列子矩阵的奇异值平方挤在 $1 \pm \delta_s$ 内，$\delta_s \le (s-1)\mu$ 但远强于相干性；真算表显示高斯矩阵 $\delta_2 \sim m^{-1/2}$、重复列矩阵 $\delta_2 = 1$ 且恢复全灭。下一节解释为什么随机矩阵天生就有小 $\delta_s$。

## $\rm \S \, 2.3$ 随机矩阵以高概率满足 RIP

白话：让测量矩阵的元素随机抽样，$s$ 列子矩阵的奇异值就会自动挤到 1 附近——这不是巧合，是高维随机行为的常态；确定性构造至今远远落后。

**定理（随机矩阵的 RIP）**：设 $A$ 的元素独立同分布、亚高斯（高斯、$\pm 1$ Bernoulli 都算），按 $1/\sqrt{m}$ 缩放，则存在只依赖亚高斯矩的常数 $C, c > 0$，当

$$
m \;\ge\; C \delta_s^{-2} \left( s \log \frac{n}{s} + \log \frac{1}{\eta} \right)
$$

时，$A$ 以至少 $1 - \eta$ 的概率满足阶 $s$、常数 $\delta_s$ 的 RIP。

读法：$\binom{n}{s} \approx (en/s)^s$ 个支撑子空间各自集中，union bound 要求失败概率压到 $\binom{n}{s}^{-1}$ 以下，恰好消耗 $s \log(n/s)$ 量级的测量——单个子矩阵 $\|A_T^{\mathsf T} A_T - I\|$ 偏离 $t$ 的概率按 $e^{-cmt^2}$ 衰减，机器在 [HP 册第 1 章](../39-高维概率与矩阵分析/01-集中不等式.md)与 [HP 册第 11 章](../39-高维概率与矩阵分析/11-矩阵集中不等式.md)；$\log(1/\eta)$ 是失败概率再压一档的代价。

这解释了第 1 章数值锚：$m = 28 \sim 32$ 是 $k \log(n/k) \approx 20.5$ 的常数倍，RIP 高概率成立，恢复定理接手，成功率冲到 $95\% \sim 99\%$。

但同一张表里藏着必须诚实面对的裂缝：按 $m^{-1/2}$ 外推，$\delta_2$ 降到 $\sqrt{2}-1 \approx 0.414$ 需 $m \approx 60$、降到定理阈值 $1 - 1/\sqrt{2} \approx 0.293$ 需 $m \approx 120$——**超过 $n = 64$，即全采样**。把恢复定理的充分条件当设计依据，压缩感知永远不划算；可实验里 $m = 28$ 就是 $95\%$ 成功。这不是悖论：RIP 定理给的是**对一切稀疏信号都成立的保证**，常数与阈值是为全称量词付的保险费；实际失效边界由第 4 章的相位跃迁刻画，远比充分条件乐观。定理管兜底，相变管预期——本册往后始终区分这两层。

定理只用了元素的亚高斯性，所以高斯与 $\pm 1$ Bernoulli 矩阵同等待遇；把 $n \times n$ 正交矩阵（傅里叶、DCT）随机抽 $m$ 行，只要与稀疏基不相干，也满足同阶 RIP——这个「亚采样正交矩阵」版本在应用里最重要（MRI 正是随机抽傅里叶行，第 4、5 章展开）。反方向消息差得多：确定性构造（有限域类）至今仍是 $s^2$ 量级的测量数而非 $s \log n$ 量级——「随机性换测量数」没有已知的确定性替代品。

**本节小结**：亚高斯随机矩阵以 $1 - \eta$ 概率满足 RIP，测量数 $m \ge C\delta_s^{-2}(s\log(n/s) + \log(1/\eta))$——组合数 $\binom{n}{s}$ 通过 union bound 变成 $\log$ 因子；亚采样正交矩阵同样有效，确定性构造落后一个量级。充分条件的常数与实际成功率之间的裂缝由相位跃迁理论（第 4 章）补上。

## $\rm \S \, 2.4$ 精确恢复定理与测量数下界（本章主证）

白话：本节证全册核心定理——$\delta_{2s}$ 足够小时基追踪的解恰是真稀疏信号；发动机是零空间向量的「头尾」性质，最后用计数论证说明 $s \log(n/s)$ 省不掉。

证明的枢纽是**零空间性质**（null space property, NSP）：称 $A$ 满足阶 $s$、常数 $\rho < 1$ 的 NSP，若对 $A$ 的每个零空间向量 $h \ne 0$，用 $h_T$ 记 $h$ 绝对值最大的 $s$ 个坐标、$h_{T^c}$ 记其余，都有

$$
\|h_{T^c}\|_1 \;\le\; \rho\, \|h_T\|_1
$$

读法：零空间里任何非零向量，「头部以外」的质量都压不到头部的 $\rho$ 倍——零空间向量被迫摊平，任何 $s$ 个坐标装不下它的主体。标准刻画（Foucart–Rauhut 教材第 4 章；Candès 2008）：**$A$ 用 $\ell_1$ 精确恢复一切 $s$-稀疏信号，当且仅当它满足阶 $s$ 的 NSP**。本节的任务是把 RIP 压成 NSP。

**定理（本章主定理）**：若 $A$ 满足 $\delta_{2s} < \sqrt{2} - 1$，则对每个 $s$-稀疏的 $x_0$ 与 $y = Ax_0$，基追踪 $(P_1)$ 的唯一最优解是 $x^* = x_0$。

证明给关键步骤。设 $h = x^* - x_0 \in \operatorname{null}(A)$，$T_0 = \operatorname{supp}(x_0)$。

1. **头尾不等式（$\ell_1$ 最优性）**。$x^*$ 最优给出 $\|x_0\|_1 \ge \|x^*\|_1 = \|x_0 + h\|_1$。把 $x_0 + h$ 按 $T_0$ 内外拆开、用三角不等式：

$$
\|x_0\|_1 \;\ge\; \|x_0 + h_{T_0}\|_1 + \|h_{T_0^c}\|_1 \;\ge\; \|x_0\|_1 - \|h_{T_0}\|_1 + \|h_{T_0^c}\|_1
$$

移项得 $\|h_{T_0^c}\|_1 \le \|h_{T_0}\|_1$：最优解逼着 $h$ 的质量大头放在真信号的支撑上。

2. **半块分拆（机关所在）**。把 $h_{T_0^c}$ 按绝对值从大到小切成大小 $s/2$ 的块 $T_1, T_2, \ldots$（$s$ 取偶数）。半块机关：让每处相关性的支撑并集都 $\le {2s}$，$\delta_{2s}$（而非 $\delta_{3s}$）才够用。由排序，$\|h_{T_{j+1}}\|_2 \le \|h_{T_j}\|_2$。

3. **相关性引理（极化）**。对支撑不相交的 ${u, v}$（$|{\rm supp}(u) \cup {\rm supp}(v)| \le 2s$），

$$
\left| \langle A u, A v \rangle \right| \;\le\; \delta_{2s} \|u\|_2 \|v\|_2
$$

证明：$\langle Au, Av \rangle = \tfrac{1}{4}\left( \|A(u+v)\|_2^2 - \|A(u-v)\|_2^2 \right)$，$u \pm v$ 的支撑都在并集里、至多 ${2s}$-稀疏，对两项分别用 RIP 的上下界即得。∎

4. **收口**。令 $u = h_{T_0} + h_{T_1}$（支撑 $1.5s \le 2s$，且 $u \in \operatorname{null}(A)$）。从 $Au = 0$ 出发：

$$
0 = \|A u\|_2^2 = \langle A u, A u \rangle = \langle A u, A h \rangle = \left\langle A u,\; A \sum_{j \ge 2} h_{T_j} \right\rangle
$$

读法：尾部逐块用第 3 步引理（每块 $s/2$，与 $u$ 的并集 ${2s}$）：

$$
(1 - \delta_{2s}) \|u\|_2^2 \;\le\; \|Au\|_2^2 \;\le\; \delta_{2s} \|u\|_2 \left( \|h_{T_2}\|_2 + \sum_{j \ge 3} \|h_{T_j}\|_2 \right)
$$

读法：右边括号逐项压：$\|h_{T_2}\|_2 \le \|h_{T_1}\|_2 \le \|u\|_2$（块衰减加三角不等式）；尾部和用 $\|h_{T_j}\|_2 \le \sqrt{2/s}\,\|h_{T_j}\|_1$（块大小 $s/2$）加头尾不等式：

$$
\sum_{j \ge 3} \|h_{T_j}\|_2 \;\le\; \sqrt{\tfrac{2}{s}} \sum_{j \ge 3} \|h_{T_j}\|_1 \;\le\; \sqrt{\tfrac{2}{s}}\, \|h_{T_0^c}\|_1 \;\le\; \sqrt{\tfrac{2}{s}}\, \|h_{T_0}\|_1 \;\le\; \sqrt{2}\, \|h_{T_0}\|_2 \;\le\; \sqrt{2}\, \|u\|_2
$$

读法：末步是第 1 章的 $\|h_{T_0}\|_1 \le \sqrt{s}\,\|h_{T_0}\|_2$。括号至多 $(1 + \sqrt{2})\|u\|_2$，于是

$$
(1 - \delta_{2s}) \|u\|_2^2 \;\le\; (1 + \sqrt{2})\, \delta_{2s} \|u\|_2^2
$$

只要 $1 - \delta_{2s} > (1+\sqrt{2})\delta_{2s}$，即 $\delta_{2s} < 1/(2 + \sqrt{2}) = 1 - 1/\sqrt{2} \approx 0.293$，就有 $\|u\|_2 = 0$，即 $h_{T_0} = h_{T_1} = 0$。代回第 1 步：$\|h_{T_0^c}\|_1 \le \|h_{T_0}\|_1 = 0$，全部 $h = 0$。∎

这份自足证明的阈值是 $0.293$；Candès（2008）用更细的配对记账（尾块两两捆成 ${2s}$-稀疏向量、建立几何衰减）把阈值推到 $\sqrt{2} - 1 \approx 0.414$，即定理陈述里的常数。两者都是充分条件，真实边界（第 4 章的相位跃迁）乐观得多。

有噪声与可压缩信号时，同一套机器给出鲁棒版（Candès 2008）：$\delta_{2s} < \sqrt{2} - 1$、$\|e\|_2 \le \varepsilon$、$x_0$ 的最佳 $s$ 项逼近误差 $\sigma_s(x_0) = \inf\{\|x_0 - z\|_2 : \|z\|_0 \le s\}$ 时，约束版 $\min \|x\|_1 \;\text{s.t.}\; \|Ax - y\|_2 \le \varepsilon$ 给出

$$
\|x^* - x_0\|_2 \;\le\; C_0 \frac{\sigma_s(x_0)}{\sqrt{s}} + C_1 \frac{\varepsilon}{\sqrt{s}}
$$

读法：$C_0, C_1$ 只依赖 $\delta_{2s}$；第一项是信号不完全稀疏的代价（带 $\sqrt{s}$ 增益），第二项是噪声的代价。恢复从「精确」升级成「稳定」。

最后是测量数的下界：$s \log(n/s)$ 不是定理的松懈，是本质。

**命题（计数下界）**：若 $A$ 对一切 $s$-稀疏向量单射，则 $m \ge c\, s \log(n/s)$，$c$ 为绝对常数。

证明概要（体积计数）：$s$-稀疏单位向量是 $\binom{n}{s}$ 个 $s$ 维子空间球面的并，单射性要求它们的像互不粘连；每个子空间取 $\tau$-网、数 $\mathrm{R}^m$ 里固定间隔的球至多 $(C/\tau)^m$ 个，两边一数 $\binom{n}{s} \tau^{-s} \le (C/\tau)^m$，小 $\tau$ 下化简出 $m \ge c\, s \log(n/s)$。∎ 读法：$\binom{n}{s} \ge (n/s)^s$ 个支撑各有 $s$ 个自由度要在 $m$ 个测量里安家，支撑数目贡献 $\log$ 因子——与[编码理论册第 1 章](../49-编码理论/01-纠错的账.md)「描述项数付 $\log$ 空间」同一条原理。真算钉个数：$\log_2 \binom{64}{6} = 26.2$、$s \log_2(n/s) = 20.5$，而第 1 章实测 $m^* \approx 28 \sim 32$——实测边界紧贴下界，上界（§2.3 的 $C s \log(n/s)$）与下界只差常数，测量数的阶已到头。

**本节小结**：NSP（零空间向量头部以外质量 $\le \rho$ 倍）是 $\ell_1$ 精确恢复的充要刻画；RIP 压成 NSP 的证明四步——头尾不等式、半块分拆、极化相关性引理、$(1-\delta) > (1+\sqrt{2})\delta$ 收口——给出阈值 $1 - 1/\sqrt{2}$，配对记账改进到 $\sqrt{2}-1$；鲁棒版把噪声与可压缩误差按 $1/\sqrt{s}$ 折进恢复误差；计数下界 $m \ge c\, s\log(n/s)$ 与上界只差常数。下一章把主角换成算法：同样的恢复保证，贪婪算法怎么拿。

## $\rm \S \, 2.7$ 本章自测答案

> 先闭卷作答上面两节，再核对。

### $\rm \S \, 2.7.1$ 关键概念回顾答案

1. RIP：对一切 $\|x\|_0 \le s$ 有 $(1-\delta_s)\|x\|_2^2 \le \|Ax\|_2^2 \le (1+\delta_s)\|x\|_2^2$。固定支撑后 $\|Ax\|_2^2$ 在单位球上张满 $[\sigma_{\min}^2(A_T), \sigma_{\max}^2(A_T)]$，全体 $|T| \le s$ 取最大即得奇异值刻画。$\delta_s \le (s-1)\mu$ 说明 RIP 条件更易满足，但 $\delta_2 < 1$ 与小 $\mu$ 互不推出。（§2.1、§2.2）
2. $\operatorname{spark}(A) > {2k}$ 时两个 $k$-稀疏解之差是 ${2k}$-稀疏的零空间向量，与 spark 定义矛盾，故唯一。Gershgorin：$G = A^{\mathsf T}A$ 的 $k \times k$ 主子矩阵在 $1 - (k-1)\mu > 0$ 时对角占优可逆，故 $k < 1 + 1/\mu$ 列无关，$\operatorname{spark} \ge 1 + 1/\mu$。（§2.1）
3. 四步：(1) $\ell_1$ 最优性给头尾不等式 $\|h_{T_0^c}\|_1 \le \|h_{T_0}\|_1$；(2) 尾部切 $s/2$ 半块、块衰减；(3) 极化引理把不相交支撑的相关性压到 $\delta_{2s}\|u\|_2\|v\|_2$；(4) 对 $u = h_{T_0} + h_{T_1}$ 展开 $\|Au\|_2^2 = 0$，尾部受控后 $(1-\delta_{2s}) \le (1+\sqrt{2})\delta_{2s}$ 与 $\delta_{2s} < 1-1/\sqrt{2}$ 矛盾逼出 $u = 0$，头尾不等式收尾全零。半块机关：让所有相关性估计的支撑并集 $\le {2s}$，$\delta_{2s}$ 才够用。$\log(n/s)$ 来自 $\binom{n}{s} \approx (en/s)^s$ 个子空间的 union bound（下界）与逐子空间集中（上界）。（§2.4）

### $\rm \S \, 2.7.2$ 应用与辨析答案

1. 阈值 $\mu < 1/(2k-1) = 1/15 \approx 0.0667$。高斯 $m \times 256$ 矩阵的最坏内积量级 $\mu \approx \sqrt{2\log n / m}$，压到 $0.0667$ 需 $m \approx 2 \times 5.55 / 0.00445 \approx 2500 \gg 256$。$n = 256$、$k = 8$ 在 $m$ 为几十时实验上就基本成功，相干性判据却要远超全采样的测量数才给保证——拿它做设计依据等于放弃压缩。（§2.1）
2. $\delta_3(m) \approx 1.025\sqrt{28/m}$，降到 $0.5$ 需 $m \approx 28 \times (1.025/0.5)^2 \approx 117 > 64$；即便开满 $m = n = 64$（外推 $\delta_3 \approx 0.68$），充分条件阈值也够不着——RIP 常数是「对一切信号兜底」的保险费，不是单次实验的失效边界，实际边界宽得多（第 4 章）。（§2.2、§2.3）
3. $[I_m, I_m]/\sqrt{2}$：两列完全相同，那对列的 $\sigma_{\min} = 0$，$\delta_2 = 1$（§2.2 真算）。换成 $[I_m, R]$：单位列与随机单位列的内积量级 $\sqrt{\log m / m}$，趋于 0，$\delta_2$ 接近单位阵本身的 $\delta_2 \approx 0$ 量级。差别：结构化重复复制同一方向、留下完全盲区；随机扩展的方向撒得近似均匀，固定方向撞上的概率随 $m$ 消失。（§2.2、§2.3）

## $\rm \S \, 2.8$ 可当场复跑的程序段

下面这段 Python（只需 NumPy）把本章的数钉死，种子固定。

```python
 # RIP 与相干性数值锚（n=64；delta 枚举全部 s 列子集）
import numpy as np
from itertools import combinations

rng = np.random.default_rng(20261105)

def make_A(m, n):
    A = rng.standard_normal((m, n))
    A /= np.linalg.norm(A, axis=0)
    return A

def rip_delta(A, s):
    lo, hi = np.inf, -np.inf
    for T in combinations(range(A.shape[1]), s):
        sv = np.linalg.svd(A[:, T], compute_uv=False)
        lo = min(lo, sv[-1] ** 2); hi = max(hi, sv[0] ** 2)
    return max(abs(hi - 1), abs(1 - lo))

mus = []
for _ in range(200):
    A = make_A(28, 64)
    G = A.T @ A; np.fill_diagonal(G, 0)
    mus.append(np.abs(G).max())
print(f"mu(28x64): {np.mean(mus):.4f} ({np.min(mus):.3f}~{np.max(mus):.3f})",
      f"Welch {np.sqrt(36 / (28 * 63)):.4f}")
for mm in (64, 200, 1000):
    A = make_A(mm, 64)
    G = A.T @ A; np.fill_diagonal(G, 0)
    print(f"mu m={mm}: {np.abs(G).max():.4f}")
for m in (28, 32, 40, 48, 56):
    d2, d3 = [], []
    for _ in range(10):
        A = make_A(m, 64)
        d2.append(rip_delta(A, 2)); d3.append(rip_delta(A, 3))
    print(f"m={m}: delta_2={np.mean(d2):.3f}, delta_3={np.mean(d3):.3f}")

ok, mus = True, []
for _ in range(200):
    A = make_A(5, 10)
    for T in combinations(range(10), 5):
        ok &= np.linalg.matrix_rank(A[:, T]) == 5
    G = A.T @ A; np.fill_diagonal(G, 0)
    mus.append(np.abs(G).max())
print(f"spark full-rank: {ok}, mu={np.mean(mus):.4f}, 1/mu+1={1/np.mean(mus) + 1:.2f}")

def omp(A, y, k):
    T, r = [], y.copy()
    for _ in range(k):
        T.append(int(np.argmax(np.abs(A.T @ r))))
        As = A[:, T]
        c, *_ = np.linalg.lstsq(As, y, rcond=None)
        r = y - As @ c
    return sorted(T)

Abad = np.hstack([np.eye(28), np.eye(28)]) / np.sqrt(2)
hits = 0
for _ in range(200):
    i = int(rng.integers(28)); idx = [i, i + 28]
    x = np.zeros(56); x[idx] = rng.standard_normal(2)
    hits += omp(Abad, Abad @ x, 2) == sorted(idx)
print(f"OMP on duplicated-identity: {hits}/200")
```

## $\rm \S \, 2.9$ 带走清单

1. 相干性 $\mu(A) = \max_{i \neq j} |\langle a_i, a_j \rangle|$ 好算但悲观：Welch 界 $\sqrt{(n-m)/m(n-1)}$；spark $\ge 1 + 1/\mu$（Gershgorin）；$n = 64$、$k = 6$ 的相干性判据要求 $\mu < 0.0909$，实测 $m = 1000$ 都达不到。
2. RIP：$(1-\delta_s)\|x\|_2^2 \le \|Ax\|_2^2 \le (1+\delta_s)\|x\|_2^2$ 对一切 $\|x\|_0 \le s$；等价于全部 $s$ 列子矩阵奇异值平方在 $1 \pm \delta_s$ 内；$\delta_s \le (s-1)\mu$。真算：$n = 64$ 高斯 $\delta_2$ 从 $m = 28$ 的 $0.605$ 降到 $m = 56$ 的 $0.470$（$m^{-1/2}$ 律）。
3. 亚高斯随机矩阵以 $1 - \eta$ 概率满足 RIP，测量数 $m \ge C\delta_s^{-2}(s\log(n/s) + \log(1/\eta))$：$\binom{n}{s}$ 个子空间 union bound 付 $s\log(n/s)$；亚采样正交矩阵同阶有效，确定性构造落后。
4. 主定理：$\delta_{2s} < \sqrt{2}-1$ 时基追踪对一切 $s$-稀疏信号精确恢复（NSP 充要；自足证明到阈值 $1 - 1/\sqrt{2}$，机关是半块分拆）；鲁棒版误差 $\le C_0\sigma_s(x_0)/\sqrt{s} + C_1\varepsilon/\sqrt{s}$。
5. 测量数下界 $m \ge c\,s\log(n/s)$（计数论证）：上界下界只差常数，$\log$ 因子省不掉；真算 $\log_2\binom{64}{6} = 26.2$ 对实测 $m^* \approx 28 \sim 32$。
6. 充分条件与实际成功率的裂缝（$m = 28$ 成功率 $95\%$ 而 $\delta_2$ 阈值要求 $m \approx 60^+$）由相位跃迁理论解释——定理管兜底，相变管预期，第 4 章展开。
