# $\rm Chapter \, 9$ 局部域与局部-全局

第 8 章的理想账本在一处细节上值得驻足：同一个环 $\mathbb{Z}[\sqrt{-5}]$ 里，$(2) = \mathfrak{p}_2^2$ 在素数 2 处「平方坍缩」，$(3) = \mathfrak{p}_3\mathfrak{p}_3'$ 在素数 3 处正常分裂——素理想的分解剧本逐素数各不相同。「某个素数处发生了什么」是一个局部问题，而处理局部问题的标准分析动作是：对准它、放大它、把它的世界完整造出来。本章就给每个素数 $p$ 配一台这样的放大镜：换掉「大小」这把尺子，改用「被 $p$ 整除得多深」来量距离，把 $\mathbb{Q}$ 完备成一个专门研究 $p$ 的完备数域 $\mathbb{Q}_p$——正如实数 $\mathbb{R}$ 是 $\mathbb{Q}$ 对普通距离的完备化。在新世界里，模 $p$ 的同余解会自动逐位抬升成真解（Hensel 引理），而「把每个素数处的局部信息拼回全局」的原理将在二次型上第一次完整兑现（Hasse–Minkowski）：$x^2+y^2=n$ 有没有有理解，由一组逐素数的局部检查完全判定。路线：p-adic 绝对值与超度量（§9.2）、Ostrowski 定理（§9.3）、$\mathbb{Q}_p$ 的构造与展开（§9.4）、Hensel 引理（§9.5）、两平方和的高斯整数证明（§9.6）、局部-全局原理与 $x^2+y^2=n$ 的完整判据（§9.7）。每个证明完整；Hasse–Minkowski 的完整证明与重根情形的 Hensel 引理超出本章范围，按站点惯例标注出处。

## $\rm \S \, 9.1$ 动机：把一个素数放大成整个世界

实数 $\mathbb{R}$ 是怎么来的？$\mathbb{Q}$ 对普通距离 $|x-y|$ 有「洞」（$\sqrt2$ 的位置没有有理数），柯西序列把它们填满。这个动作有两半：一把**尺子**（绝对值，定义 9.1）加上一次**完备化**（定义 9.5）。第 3、4 章的极限、级数、积分全部住在 $\mathbb{R}$ 这个完备世界里——尺子决定了分析。

第 8 章的账本指出：素数 world 里的「局部剧本」各不相同——$2$ 分歧、$3$ 分裂（§8.6）。想研究「在 $p$ 处的行为」，就应该有一把只感知 $p$ 的尺子：两个数算得「近」，当它们的差被 $p$ 的高次幂整除。$7 \mid (x-y)$ 比 $7 \nmid (x-y)$ 近，$49 \mid (x-y)$ 更近——**p-adic 距离就是「被 $p$ 整除得多深」的倒数**。放大镜对准素数 $p$ 之后，原本的「大小」消失，整座算术世界以 $p$ 为中心重组；把 $\mathbb{Q}$ 对这把新尺子完备化，得到的世界记作 $\mathbb{Q}_p$。$\mathbb{R}$ 与各 $\mathbb{Q}_p$ 统称**局部域**（local field）：它们都是 $\mathbb{Q}$ 对某把绝对值尺子的完备化，分析性质与 $\mathbb{R}$ 同级（完备、可做极限与级数），代数性格却逐把尺子不同。

本章的终点是一条原理：**$x^2+y^2=n$ 有没有有理解，等价于它在 $\mathbb{R}$ 与每个 $\mathbb{Q}_p$ 里都有解**。全局问题被拆成一组局部检查——而这套检查最终读出的判据，恰是 Fermat 两平方和定理（§9.6 用高斯整数独立证出的那一条）。

## $\rm \S \, 9.2$ p-adic 绝对值：另一种「大小」

**定义 9.1（绝对值）**：$\mathbb{Q}$ 上的绝对值是函数 $|\cdot| : \mathbb{Q} \to \mathbb{R}_{\ge 0}$，满足：

1. $|x| \ge 0$，且 $|x| = 0 \iff x = 0$；
2. $|xy| = |x|\,|y|$；
3. $|x+y| \le |x| + |y|$（三角不等式）。

称它**非平凡**，若某个 $x$ 有 $|x| \ne 1$。普通绝对值记 $|\cdot|_\infty$。两条绝对值称**等价**，若一条是另一条的幂 $|\cdot|^c$（$c > 0$）——它们给出同一个柯西收敛理论。

**定义 9.2（p-adic 绝对值）**：对 $x \in \mathbb{Q}^\times$，写 $x = p^a \frac{m}{n}$（$a \in \mathbb{Z}$，$p \nmid mn$；存在性由算术基本定理，唯一性由既约性），令 $v_p(x) = a$；再令 $v_p(0) = +\infty$。定义

$$
|x|_p = p^{-v_p(x)}, \qquad |0|_p = 0 .
$$

读法：$x$ 被 $p$ 整除得越深，$|x|_p$ 越小；$p$ 不整除的数 $|x|_p = 1$。例如 $|6|_3 = \frac13$、$|9|_3 = \frac19$、$|2|_3 = 1$、$|\frac{1}{3}|_3 = 3$。

**命题 9.3（三公理验证）**：$|\cdot|_p$ 是非平凡绝对值，且三角不等式有强版本：

$$
|x+y|_p \le \max\bigl(|x|_p, |y|_p\bigr),
$$

强三角不等式又称**超度量不等式**（ultrametric inequality）。

证：

1. **正性**：$x \ne 0$ 时 $v_p(x)$ 有限，$p^{-v_p(x)} > 0$；$|0|_p = 0$ 是约定。
2. **乘性**：设 $x = p^a\frac{m}{n}$、$y = p^b\frac{m'}{n'}$（各分子分母均不被 $p$ 整除）。则 $xy = p^{a+b}\frac{mm'}{nn'}$，而 $p \nmid mm'nn'$，故 $v_p(xy) = a + b = v_p(x) + v_p(y)$，两边取 $p$ 的负幂即得。
3. **强三角**：不妨 $v_p(x) = a \le b = v_p(y)$（否则对换），写 $x = p^a\frac{m}{n}$、$y = p^b\frac{m'}{n'}$。通分相加：

$$
x + y = p^a \cdot \frac{mn' + p^{b-a}m'n}{nn'} .
$$

   若 $a < b$：括号里第一项 ${mn'}$ 不被 $p$ 整除（$p \nmid m$、$p \nmid n'$），第二项被 $p$ 整除（$b - a \ge 1$），所以和 $\equiv mn' \not\equiv 0 \pmod p$，于是 $v_p(x+y) = a = \min(v_p(x), v_p(y))$，即 $|x+y|_p = \max(|x|_p, |y|_p)$。若 $a = b$：括号是整数，故 $v_p(x+y) \ge a$，即 $|x+y|_p \le p^{-a} = \max$。合并两种情形，强三角成立；非平凡性显然（$|p|_p = \frac1p \ne 1$）。$\blacksquare$

$|x|_p \ne |y|_p$ 时强三角取**等号**（推导的第一种情形）——这句话有一个精确的几何名字。

**命题 9.4（超度量的几何与收敛）**：

1. **所有三角形等腰**：三边 $|x|_p$、$|y|_p$、$|x+y|_p$ 中，只要两边不等，就有 $|x+y|_p = \max(|x|_p, |y|_p)$——最长边恰出现两次，底边（第三边）不长于两腰。普通几何允许三边互异的三角形，超度量世界禁止。
2. **柯西 ⟺ 相邻差趋零**：序列 $(a_n)$ 是 $|\cdot|_p$-柯西序列（$\forall \varepsilon > 0\ \exists N:\ |a_m - a_n|_p < \varepsilon$ 对 $m, n \ge N$）当且仅当 $|a_{n+1} - a_n|_p \to 0$。（$\Rightarrow$ 取 $m = n+1$；$\Leftarrow$ 用望远镜 $a_m - a_n = \sum_{k=n+1}^{m}(a_k - a_{k-1})$ 与超度量：$|a_m - a_n|_p \le \max_{n < k \le m} |a_k - a_{k-1}|_p$。）在 $|\cdot|_\infty$ 下这条不成立：调和级数部分和的相邻差 $\frac{1}{n+1} \to 0$ 却不是柯西序列。
3. **级数判据**：$\sum_k a_k$ 在 $|\cdot|_p$ 下收敛 $\iff$ 通项 $a_k \to 0$（第 2 条用于部分和序列）。于是 $1 + 2 + 4 + 8 + \cdots$ 在 $\mathbb{Q}_2$ 中收敛：通项 $|2^k|_2 = 2^{-k} \to 0$。它的和将在 §9.4 算出：$-1$。

数值锚：$|3+6|_3 = |9|_3 = \frac19 < \frac13 = \max(|3|_3, |6|_3)$——和被 $p$ 整除得比每一项都深，这正是「靠近即整除」的现场；$|2+2|_3 = |4|_3 = 1 = \max(1,1)$，等腰成立。

## $\rm \S \, 9.3$ Ostrowski 定理：$\mathbb{Q}$ 上绝对值的完整清单

换尺子之前先问：一共有几把尺子？答案是惊人的少。

**定理 9.5（Ostrowski 定理）**：$\mathbb{Q}$ 上任何非平凡绝对值都等价于 $|\cdot|_\infty$，或等价于某个 $|\cdot|_p$。

证：称绝对值**阿基米德**，若某个正整数 $n$ 满足 $|n| > 1$；否则（一切正整数 $|n| \le 1$）称**非阿基米德**。二分讨论。预备事实：$|1| = |1|^2$ 且非平凡，故 $|1| = 1$；对正整数 $a$，$|a| = |1 + \cdots + 1| \le a$（普通三角不等式）。

**情形 A（阿基米德）**：

1. **一切 $m \ge 2$ 都有 $|m| > 1$**。反设某 $m \ge 2$ 有 $|m| \le 1$。把 $n^k$ 按 $m$ 进制展开：$n^k = \sum_{j \le L} a_j m^j$，$0 \le a_j \le m - 1$，$L \le k \log_m n$。取绝对值：$|n|^k \le \sum_j |a_j|\,|m|^j \le (L+1)(m-1) \le (k \log_m n + 1)(m-1)$（用到 $|a_j| \le a_j$ 与 $|m|^j \le 1$）。开 $k$ 次根令 $k \to \infty$：$|n| \le 1$，与情形 A 的前提矛盾。
2. **base-$n$ 展开不等式**：固定 $n \ge 2$，把 $m^k$ 按 $n$ 进制展开：$m^k = \sum_{j \le L} a_j n^j$，$|a_j| \le a_j \le n-1$。由 $|n| > 1$ 得 $|n|^j \le |n|^L$，于是

$$
|m|^k = |m^k| \le \sum_{j \le L} |a_j|\,|n|^j \le (L+1)(n-1)\,|n|^L \le (k \log_n m + 1)(n-1)\,|n|^{k \log_n m}.
$$

   开 $k$ 次根、令 $k \to \infty$（前两个因子趋 1）：$|m| \le |n|^{\log_n m}$。
3. **指数合并**：把上式对换 ${m, n}$（两者都 $> 1$，第 1 步保证）得 $|n| \le |m|^{\log_m n}$；代入并升幂（指数 $\log_n m > 0$）：$|m| \le |n|^{\log_n m} \le \bigl(|m|^{\log_m n}\bigr)^{\log_n m} = |m|$。全程取等，故对一切 $m, n \ge 2$：$|m| = |n|^{\log_n m}$，即 $\frac{\ln |m|}{\ln m} = \frac{\ln|n|}{\ln n} =: c$ 与取值无关，$c > 0$。所以 $|x| = |x|_\infty^c$ 对一切 $x \in \mathbb{Q}$ 成立（正整数的等式按素数分解延拓，负号由 $|-x| = |x|$ 兜底）。

**情形 B（非阿基米德）**：

1. **强三角成立**：对 $x, y \in \mathbb{Q}$ 与 $N \ge 1$，二项式展开 $(x+y)^N = \sum_k \binom{N}{k} x^k y^{N-k}$。每个 $\binom{N}{k}$ 是正整数，情形 B 假设给 $\bigl|\binom{N}{k}\bigr| \le 1$，于是 $|x+y|^N \le \sum_k |x|^k |y|^{N-k} \le (N+1)\max(|x|,|y|)^N$。开 $N$ 次根、令 $N \to \infty$：$|x+y| \le \max(|x|, |y|)$。
2. **找 $p$**：非平凡保证某正整数 $|n| \ne 1$，又 $\le 1$，故 $< 1$。取 $p$ 为**最小的**满足 $|p| < 1$ 的正整数。$p$ 是素数：若 $p = ab$（$1 \le a, b < p$），由最小性 $|a| = |b| = 1$，则 $|p| = 1$，矛盾。
3. **与 $p$ 互素的整数绝对值为 1**：设 $\gcd(m, p) = 1$，Bézout 给 $mu + pv = 1$。用强三角：$1 = |mu + pv| \le \max(|m||u|, |p||v|) \le \max(|m|, |p|)$（整数 ${u, v}$ 有 $|u|, |v| \le 1$，而 $|p| < 1$）。右边 $\ge 1$ 逼出 $|m| = 1$。
4. **收口**：对 $m = p^a m'$（$p \nmid m'$）：$|m| = |p|^a$；对 $x = \pm p^a \frac{m'}{n'}$：$|x| = |p|^{v_p(x)} = |x|_p^{c}$，其中 $c = -\frac{\ln|p|}{\ln p} > 0$。等价于 $|\cdot|_p$。$\blacksquare$

出处：完整证明见 Gouvêa《p-adic Numbers》第 3 章。定理的读法：**素数集合加上无穷远点，是 $\mathbb{Q}$ 的全部「坐标系」**。第 8 章的每个素理想 $\mathfrak{p} \supseteq (p)$ 恰对应一把尺子 $|\cdot|_p$——「在 $\mathfrak{p}$ 处局部化」这句代数话，在分析侧的化身就是换用这把尺子。

## $\rm \S \, 9.4$ $\mathbb{Q}_p$ 的构造：完备化与 p-adic 展开

**定义 9.6（$\mathbb{Q}_p$ 与 $\mathbb{Z}_p$）**：$(\mathbb{Q}, |\cdot|_p)$ 的柯西序列 $(a_n)$ 称**零序列**，若 $|a_n|_p \to 0$。两条柯西序列**等价**，若逐项相减是零序列。等价类的集合记 $\mathbb{Q}_p$，加法与乘法逐项定义（标准的良定义验证：等价类的和差不依赖代表元选取）；$\mathbb{Q}$ 经常值序列嵌入 $\mathbb{Q}_p$。$|x|_p := \lim_n |a_n|_p$（实数中柯西故收敛；等价序列的极限相同）。$\mathbb{Q}_p$ 对这套运算与赋值构成域：非零元素的逆由「$|x|_p > 0$ 时 $|a_n|_p$ 最终一致远离 0，取 $(1/a_n)$」给出。$\mathbb{Q}_p$ 是完备的：任何柯西序列收敛（对角线法，标准完备化构造，细节见 Gouvêa《p-adic Numbers》第 3 章、Serre《A Course in Arithmetic》第 II 章）。子集

$$
\mathbb{Z}_p = \{x \in \mathbb{Q}_p : |x|_p \le 1\}
$$

称 **p-adic 整数**。它是子环：$|xy|_p \le 1$ 平凡，$|x+y|_p \le \max \le 1$ 用超度量。单位恰是 $|x|_p = 1$ 的元素；$p\mathbb{Z}_p = \{|x|_p < 1\}$ 是理想（事实上是唯一的极大理想，因为 $|x|_p = 1$ 的元素都可逆），商环 $\mathbb{Z}_p/p\mathbb{Z}_p \cong \mathbb{F}_p$。对整数 ${a, b}$ 有词典：$|a - b|_p \le p^{-k} \iff p^k \mid a - b$——**同余是 p-adic 距离的代数影子**；中国剩余定理 $\mathbb{Z}/N\mathbb{Z} \cong \prod_{p^k \parallel N} \mathbb{Z}/p^k\mathbb{Z}$ 则说：有限同余世界是各 $\mathbb{Q}_p$ 世界的有限切片。

**引理 9.7（$\mathbb{Z}$ 稠密于 $\mathbb{Z}_p$）**：对任意 $x \in \mathbb{Z}_p$ 与 $k \ge 1$，存在 $a \in \mathbb{Z}$ 使 $|x - a|_p \le p^{-k}$。

证：取柯西代表 $(a_n) \subset \mathbb{Q}$，取 $n$ 使 $|x - a_n|_p < 1$ 且 $|a_n - a_n|_p$ 稳定，则 $|a_n|_p \le \max(|x|_p, |x - a_n|_p) \le 1$。写既约 $a_n = \frac{b}{c}$：$v_p(b) \ge v_p(c)$，而既约给 $\min(v_p(b), v_p(c)) = 0$，故 $v_p(c) = 0$，$p \nmid c$，$c$ 在模 $p^{k+1}$ 意义下可逆。取 $a \equiv b\,c^{-1} \pmod{p^{k+1}}$（$a \in \mathbb{Z}$）：$|a - \tfrac{b}{c}|_p = \frac{|ac - b|_p}{|c|_p} = |ac - b|_p \le p^{-k-1}$（$|c|_p = 1$），三角不等式收尾：$|x - a|_p \le \max(|x - a_n|_p, |a_n - a|_p) \le p^{-k}$。$\blacksquare$

**命题 9.8（p-adic 展开）**：每个 $x \in \mathbb{Z}_p$ 有唯一展开

$$
x = a_0 + a_1 p + a_2 p^2 + \cdots, \qquad a_k \in \{0, 1, \ldots, p-1\},
$$

且部分和 $s_N = \sum_{k < N} a_k p^k \in \mathbb{Z}$ 满足 $|x - s_N|_p \le p^{-N}$。

证：**构造**（逐位剥皮）：$a_0$ 取 $x \bmod p$ 的代表——由引理 9.7 取 $a \equiv x \pmod p$ 意义下的整数逼近，不同逼近模 $p$ 同余，$a_0$ 良定义且 $0 \le a_0 \le p-1$。令 $x_1 = \frac{x - a_0}{p}$：$|x - a_0|_p \le \frac1p$ 故 $x_1 \in \mathbb{Z}_p$。对 $x_1$ 重复得 $a_1, a_2, \ldots$。**收敛**：$x - s_N = p^N x_N$（$x_N$ 是第 $N$ 次剥皮后的余量），故 $|x - s_N|_p \le p^{-N} \to 0$。**唯一性**：若 $\sum a_k p^k = \sum b_k p^k$ 且 $j$ 是首个 $a_j \ne b_j$ 的下标，则差 $= (a_j - b_j)p^j + (\text{被 } p^{j+1} \text{ 整除的项})$；$a_j - b_j \not\equiv 0 \pmod p$ 而其余项 $\equiv 0$，故差 $\not\equiv 0 \pmod{p^{j+1}}$，特别非零，矛盾。$\blacksquare$

$\mathbb{Q}_p$ 的全部元素：$x = p^{-m}(a_0 + a_1 p + \cdots)$（$m$ 有限，是「小数点」向左挪有限位），即**有限个负位加无限个非负位**。与十进制对比：十进制展开向越来越小的实数尺度走（小数点右侧），p-adic 展开向被 $p$ 整除得越来越深的方向走（无限向左延伸）；负数不需要负号——它们有自己的展开。

数值锚（python 逐位真算复核）：

1. $\frac13 \in \mathbb{Z}_7$（$|\frac13|_7 = 1$）：

$$
\frac13 = 5 + 4 \cdot 7 + 4 \cdot 7^2 + 4 \cdot 7^3 + \cdots
$$

   截断验证：$5$、$5 + 28 = 33$、$5 + 28 + 196 = 229$、$1601$；$3 \times 229 = 687 = 2 \times 343 + 1$，$3 \times 1601 = 4803 = 2 \times 2401 + 1$，均 $\equiv 1$。几何级数验算：$5 + 4 \cdot 7(1 + 7 + 7^2 + \cdots) = 5 + \frac{28}{1 - 7} = 5 - \frac{14}{3} = \frac13$。
2. $-1 = (p-1)(1 + p + p^2 + \cdots)$：因 $(1 - p)(1 + p + \cdots + p^N) = 1 - p^{N+1} \to 1$（$|p^{N+1}|_p \to 0$），故 $(p-1)\sum_k p^k = -1$。$p = 7$ 的截断验算：$6 \times (1 + 7 + 49) = 342 = 343 - 1 \equiv -1 \pmod{343}$。于是在 $\mathbb{Q}_2$ 里 $1 + 2 + 4 + 8 + \cdots = -1$——命题 9.4.3 的收敛有了归宿。

## $\rm \S \, 9.5$ Hensel 引理：同余解逐位抬升成真解

模 $p$ 有解的方程，在 $\mathbb{Z}/p^2$、$\mathbb{Z}/p^3$、……里还有解吗？第 8 章的语言里，这是商环 $\mathbb{Z}_p/p^k\mathbb{Z}_p$ 的逐层相容问题。Hensel 引理说：只要模 $p$ 的根是**单根**，它就自动长成 $\mathbb{Z}_p$ 里的真根——牛顿迭代在新世界里永不停机。

**定理 9.9（Hensel 引理，单根版）**：设 $f \in \mathbb{Z}_p[x]$，$a_0 \in \mathbb{Z}_p$ 满足

$$
f(a_0) \equiv 0 \pmod p, \qquad f'(a_0) \not\equiv 0 \pmod p .
$$

则存在唯一 $a \in \mathbb{Z}_p$ 使 $f(a) = 0$ 且 $a \equiv a_0 \pmod p$。且可取序列 $a_k$ 满足 $a_k \equiv a_{k+1} \pmod{p^{k+1}}$、$f(a_k) \equiv 0 \pmod{p^{k+1}}$，递推为

$$
a_{k+1} = a_k - \frac{f(a_k)}{f'(a_k)} .
$$

证：分四步。**第 0 步（泰勒展开）**：多项式有恒等式 $f(x + h) = f(x) + h f'(x) + h^2 G(x, h)$，其中 $G \in \mathbb{Z}_p[x, h]$（对每个单项 $c_i x^i$ 用 $(x+h)^i = \sum_j \binom{i}{j} x^{i-j} h^j$ 逐项收集，$j \ge 2$ 的都归 $h^2 G$）。系数在 $\mathbb{Z}_p$ 中，故 $a_k \in \mathbb{Z}_p$、$h \in \mathbb{Z}_p$ 时 $|G(a_k, h)|_p \le 1$。

1. **归纳构造**：设 $a_k \in \mathbb{Z}_p$ 满足 $f(a_k) \equiv 0 \pmod{p^{k+1}}$ 且 $a_k \equiv a_0 \pmod p$，要造 $a_{k+1} = a_k + t\,p^{k+1}$（$t \in \{0, \ldots, p-1\}$ 待定）使 $f(a_{k+1}) \equiv 0 \pmod{p^{k+2}}$。代入泰勒展开：

$$
f(a_{k+1}) = f(a_k) + t\,p^{k+1} f'(a_k) + t^2 p^{2k+2} G(a_k, t p^{k+1}) .
$$

   末项的赋值 $\ge 2k + 2 \ge k + 2$（$k \ge 0$），模 $p^{k+2}$ 消失。写 $f(a_k) = p^{k+1} u_k$（$u_k \in \mathbb{Z}_p$，由假设），则要求化为

$$
u_k + t\, f'(a_k) \equiv 0 \pmod p .
$$

   由 $a_k \equiv a_0 \pmod p$ 与系数整性，$f'(a_k) \equiv f'(a_0) \not\equiv 0 \pmod p$，故 $f'(a_k)$ 模 $p$ 可逆，$t \equiv -u_k \bigl(f'(a_k)\bigr)^{-1} \pmod p$ 存在且**模 $p$ 唯一**。归纳起步 $k = 0$ 即假设本身。
2. **收敛**：$|a_{k+1} - a_k|_p \le p^{-(k+1)} \to 0$，由命题 9.4.2（望远镜＋超度量）序列是柯西的；$\mathbb{Q}_p$ 完备，极限 $a \in \mathbb{Q}_p$ 存在，且 $|a|_p \le \max(|a_k|_p, |a - a_k|_p) \le 1$ 对大 $k$ 成立，故 $a \in \mathbb{Z}_p$，且 $a \equiv a_k \pmod{p^{k+1}}$，特别 $a \equiv a_0 \pmod p$。
3. **$f(a) = 0$**：多项式对超度量距离连续（$|f(a) - f(a_k)|_p \le \max_i |c_i|_p\,|a - a_k|_p \le |a - a_k|_p \to 0$），而 $|f(a_k)|_p \le p^{-(k+1)} \to 0$，故 $f(a) = 0$。
4. **唯一性**：设 $a \equiv b \equiv a_0 \pmod p$、$f(a) = f(b) = 0$。恒等式 $x^i - y^i = (x - y)(x^{i-1} + x^{i-2}y + \cdots + y^{i-1})$ 逐项求和给

$$
f(x) - f(y) = (x - y)\, H(x, y), \qquad H(x,y) = \sum_{i \ge 1} c_i \sum_{j=0}^{i-1} x^{i-1-j} y^j .
$$

   代入 $x \equiv y \equiv a_0 \pmod p$：内和 $\equiv i\, a_0^{i-1} \pmod p$，故 $H(a, b) \equiv f'(a_0) \not\equiv 0 \pmod p$，$H(a,b) \ne 0$。$0 = f(a) - f(b) = (a - b) H(a, b)$ 在域 $\mathbb{Q}_p$ 中成立而无零因子，逼出 $a = b$。$\blacksquare$

递推式 $a_{k+1} = a_k - \frac{f(a_k)}{f'(a_k)}$ 正是牛顿迭代：$f'(a_k)$ 是 $\mathbb{Z}_p$ 的单位（$|f'(a_k)|_p = 1$），除法在 $\mathbb{Z}_p$ 内合法，且与第 1 步的 $t$ 公式逐层一致。条件 $f'(a_0) \not\equiv 0 \pmod p$ 不可去掉：$f(x) = x^2 - p$ 在模 $p$ 下有根 $0$，但 $f'(0) = 0$，而 $x^2 = p$ 在 $\mathbb{Q}_p$ 中无解（平方的赋值必为偶数，$v_p(p) = 1$）——重根情形称**分歧**（与第 8 章同一个词，那里 $2 \mid \Delta_K$ 的素数平方坍缩，这里导数在模 $p$ 下坍缩为零）。一般的重根提升判据超出本章范围，见 Gouvêa《p-adic Numbers》第 3 章。

**例（$\sqrt2$ 存在于 $\mathbb{Q}_7$，数值锚逐位真算）**：$2$ 是模 7 的平方剩余：$3^2 = 9 \equiv 2 \pmod 7$。取 $f(x) = x^2 - 2$、$a_0 = 3$，$f'(3) = 6 \not\equiv 0 \pmod 7$，Hensel 适用。逐层抬升：

1. 模 $49$：$a_1 = 10$，$10^2 = 100 = 2 \times 49 + 2$；
2. 模 $343$：$a_2 = 108$，$108^2 = 11664 = 34 \times 343 + 2$；
3. 模 $2401$：$a_3 = 2166$，$2166^2 = 4691556 = 1954 \times 2401 + 2$。

于是 $\sqrt2 = 3 + 1 \cdot 7 + 2 \cdot 7^2 + 6 \cdot 7^3 + \cdots$（$2166 = 3 + 7 + 98 + 2058$）。另一支从模 7 的根 $4$ 出发，抬到 $-\sqrt2 \equiv 235 \pmod{2401}$（$235 = 4 + 5 \cdot 7 + 3 \cdot 49$，$235^2 = 55225 = 23 \times 2401 + 2$）。每一层都只是解一个模 $p$ 的线性方程——「先猜末位，再解下一层」，无穷精度的平方根被有限步的思考逐位买下。

## $\rm \S \, 9.6$ $-1$ 的平方根与 Fermat 两平方和定理

**定理 9.10（$-1$ 在 $\mathbb{Q}_p$ 中可开方的判据）**：设 $p$ 为奇素数。则 $-1$ 在 $\mathbb{Q}_p$ 中有平方根 $\iff p \equiv 1 \pmod 4$。

证：**引理（欧拉判据，Euler's criterion）**：对 $a \in \mathbb{F}_p^\times$，$a^{\frac{p-1}{2}} \equiv 1 \pmod p \iff a$ 是模 $p$ 的平方剩余（quadratic residue）。证：取原根 $g$（$\mathbb{F}_p^\times$ 循环，数论册第 1 章），写 $a \equiv g^k$。$a$ 是平方剩余 $\iff k$ 为偶（平方恰是偶次幂 $g^{2j}$；若 $g^k = g^{2j}$ 则 $k \equiv 2j \pmod{p-1}$，$p - 1$ 为偶，$k$ 偶）。令 $w = g^{\frac{p-1}{2}}$：$w^2 = g^{p-1} \equiv 1$ 而 $w \ne 1$（$g$ 的阶是 $p-1$），故 $w \equiv -1$；于是 $a^{\frac{p-1}{2}} = w^k = (-1)^k$。$\square$

（$\Rightarrow$）设 $x^2 = -1$ 于 $\mathbb{Q}_p$。取范数：$|x|_p^2 = |-1|_p = 1$，故 $|x|_p = 1$，$x \in \mathbb{Z}_p$；又 $x \notin p\mathbb{Z}_p$（否则 $|x^2|_p \le p^{-2} < 1 = |-1|_p$）。模 $p$ 约化：$\bar{x}^2 = -1$ 于 $\mathbb{F}_p$，$\bar{x} \ne 0$。于是 $\{1, \bar{x}, \bar{x}^2, \bar{x}^3\} = \{1, \bar{x}, -1, -\bar{x}\}$ 是 $\mathbb{F}_p^\times$ 的 4 阶子群，拉格朗日定理给 $4 \mid p - 1$，即 $p \equiv 1 \pmod 4$。

（$\Leftarrow$）设 $p \equiv 1 \pmod 4$，即 $\frac{p-1}{2}$ 偶。欧拉判据取 $a = -1$：$(-1)^{\frac{p-1}{2}} \equiv 1$，故存在 $x_0$ 使 $x_0^2 \equiv -1 \pmod p$（且 $x_0 \not\equiv 0$）。对 $f(X) = X^2 + 1$ 用 Hensel：$f(x_0) \equiv 0$、$f'(x_0) = 2x_0 \not\equiv 0 \pmod p$，得 $x \in \mathbb{Z}_p$、$x^2 = -1$。$\blacksquare$

数值锚（python 真算）：$p = 5$：$2^2 = 4 \equiv -1 \pmod 5$；Hensel 抬升 $2 \to 7$（$7^2 = 49 \equiv -1 \pmod{25}$）$\to 57$（$57^2 + 1 = 3250 = 26 \times 125$），即 $\sqrt{-1} = 2 + 1 \cdot 5 + 2 \cdot 5^2 + \cdots \in \mathbb{Z}_5$。$p = 7$：欧拉判据给 $(-1)^3 \equiv -1 \pmod 7$，故 $-1$ 不是模 7 平方剩余（平方枚举 $\{0, 1, 2, 4\}$），在 $\mathbb{Q}_7$ 中**不可**开方。防误读一处：$6^2 = 36 \equiv 1 \pmod 7$，所以 $\pm 6$ 是 $1$ 的平方根而非 $-1$ 的；在 $\mathbb{Z}_p$（$p$ 奇）中 $x^2 = 1$ 恰有两根 $\pm 1$，这正是 Hensel 唯一性（$f'(±1) = \pm 2 \not\equiv 0$）。

**高斯整数工具箱。** $\mathbb{Z}[i] = \{a + bi : a, b \in \mathbb{Z}\}$，**高斯整数**（Gaussian integer）；共轭 $\overline{a+bi} = a - bi$ 保持乘法（$(zw)^- = \bar z \bar w$ 直接展开可验），**范数** $N(z) = z\bar z = a^2 + b^2$ 故乘性 $N(zw) = N(z)N(w)$；单位是 $N = 1$ 的元素：$a^2 + b^2 = 1$ 只有 $\pm 1, \pm i$。

1. **带余除法**：$z, w \in \mathbb{Z}[i]$、$w \ne 0$。商 $z/w = u + vi \in \mathbb{C}$（$u, v \in \mathbb{Q}$），取整数 ${m, n}$ 使 $|u - m| \le \frac12$、$|v - n| \le \frac12$，令 $q = m + ni$、$r = z - qw$。则 $r = \bigl((u-m) + (v-n)i\bigr) w$，$N(r) = N\bigl((u-m) + (v-n)i\bigr) N(w) \le \bigl(\frac14 + \frac14\bigr) N(w) = \frac12 N(w) < N(w)$。
2. **$\mathbb{Z}[i]$ 是 UFD**：带余除法给出欧几里得赋值，故每个非零理想由其中范数最小的元素生成（对 $z \in I$ 作带余除法 $z = qw + r$，$r \in I$ 且 $N(r) < N(w)$ 逼出 $r = 0$），是主理想环；主理想环是 UFD——存在性靠范数下降逼出不可约分解，唯一性靠 Bézout 恒等式证明「不可约 ⟹ 素元」，与第 8 章定理 8.19 中段的论证逐字同型，不赘述。

**定理 9.11（Fermat 两平方和定理）**：设 $n \ge 1$。则 $n = x^2 + y^2$ 有整数解 $\iff$ 在 $n$ 的素数分解中，每个 $p \equiv 3 \pmod 4$ 的素数幂次为偶。

证：关键在 $\mathbb{Z}[i]$ 中给素数分类。

1. **$p \equiv 3 \pmod 4$ 在 $\mathbb{Z}[i]$ 中仍是素元**：若 $p = zw$ 且 ${z, w}$ 都非单位，则 $N(z) N(w) = N(p) = p^2$，两个都 $> 1$ 的因子只能各为 $p$，即 $z = a + bi$、$a^2 + b^2 = p$。但平方在模 4 下是 $\{0, 1\}$，$a^2 + b^2 \in \{0, 1, 2\} \pmod 4$，与 $p \equiv 3 \pmod 4$ 矛盾。
2. **$p \equiv 1 \pmod 4$ 在 $\mathbb{Z}[i]$ 中劈开**：由定理 9.10 的证明（欧拉判据一步即可），存在 $x_0$ 使 $x_0^2 \equiv -1 \pmod p$。于是 $p \mid x_0^2 + 1 = (x_0 + i)(x_0 - i)$。但 $p$ 不整除任一因子：$x_0 + i = p(a + bi)$ 会逼出 $1 = pb$，不可能。由 UFD 的欧几里得引理（素元性），$p$ 不是素元，又 $\mathbb{Z}[i]$ 是 UFD（不可约 ⟺ 素元），故 $p$ 可约：$p = zw$ 非平凡，第 1 条的范数论证给出 $N(z) = p$，即

$$
p = a^2 + b^2 \qquad (p \equiv 1 \pmod 4).
$$

3. **合成与分解**：$n = x^2 + y^2 \iff n = N(x + iy) \iff$ 存在 $z \in \mathbb{Z}[i]$ 使 $N(z) = n$。把 $n$ 写成 $n = 2^a \prod_{p \equiv 1 (4)} p^{e_p} \prod_{p \equiv 3 (4)} p^{f_p}$。每个 $p \equiv 1 \pmod 4$ 在 $\mathbb{Z}[i]$ 中劈成 $p = \pi_p \bar\pi_p$（$N(\pi_p) = p$，$\pi_p$ 与 $\bar\pi_p$ 不相伴——若相伴则 $p = N(\pi_p) \in \{2a^2, a^2 + a^2 = 2a^2\}$ 型或 $b = 0$，逐一排除）。于是：

   （$\Leftarrow$）判据成立即诸 $f_p$ 偶，令 $z = (1+i)^a \prod_p \pi_p^{e_p} \prod_{p \equiv 3 (4)} p^{f_p / 2}$，则 $N(z) = 2^a \prod p^{e_p} \prod p^{f_p} = n$，$z = x + iy$ 给出表示。$2 = N(1 + i) = 1^2 + 1^2$ 兜住因子 2。

   （$\Rightarrow$）设 $n = N(z) = z\bar z$。对 $p \equiv 3 \pmod 4$：$p$ 在 $\mathbb{Z}[i]$ 中是素元且实值（$\bar p = p$），故 $v_p(n) = v_p(z) + v_p(\bar z) = v_p(z) + v_p(z) = 2 v_p(z)$（共轭是保持 $p$ 的环自同构，赋值不变），为偶数。$\blacksquare$

判据的「表示」可以不唯一：$85 = 5 \times 17$，$5 = (2+i)(2-i)$、$17 = (4+i)(4-i)$，两种配对方向给出 $z = (2+i)(4+i) = 7 + 6i$（$85 = 49 + 36$）与 $z = (2+i)(4-i) = 9 + 2i$（$85 = 81 + 4$）——每个 $\equiv 1 \pmod 4$ 的素因子都贡献一次选边机会。

## $\rm \S \, 9.7$ Hasse–Minkowski：局部信息拼成全局

现在问本章的元问题：$x^2 + y^2 = n$（$n \in \mathbb{Q}$，$n \ne 0$）在 $\mathbb{Q}$ 中有解吗？把问题局部化：它在 $\mathbb{R}$ 中有解吗？在每个 $\mathbb{Q}_p$ 中有解吗？后者显然必要（$\mathbb{Q}$ 嵌入每个局部域，全局解映成局部解）；深刻的是**充分性**。

**定理 9.12（Hasse–Minkowski 定理）**：设 $Q(X_1, \ldots, X_m)$ 是有理系数二次型。则 $Q = 0$ 在 $\mathbb{Q}$ 中有非平凡解 $\iff$ $Q = 0$ 在 $\mathbb{R}$ 与每个 $\mathbb{Q}_p$ 中都有非平凡解。

这是数论第一条完整的局部-全局定理，且对一切变元数 $m$ 成立。完整证明需要 Hilbert 符号 $(a, b)_p$ 的乘积公式（「所有局部符号相乘为 1」——这正是「局部数据可以粘合」的代数化身），超出本章范围：全证见 Serre《A Course in Arithmetic》第 IV 章（关键新部件是三变元情形），局部二次型分类见 Cassels《Local Fields》。

**齐次化换算**：对 $x^2 + y^2 = n$ 用型 $Q = X^2 + Y^2 - nZ^2$。全局解 ${x, y}$ 给非平凡零点 $(x, y, 1)$。反向：非平凡零点若 $Z \ne 0$，除以 $Z^2$ 得原方程的解；若 $Z = 0$，则 $X^2 + Y^2 = 0$ 非平凡，即 $-1$ 在该域是平方。在 $\mathbb{R}$、$\mathbb{Q}_2$ 与 $p \equiv 3 \pmod 4$ 的 $\mathbb{Q}_p$ 中这不可能（$\mathbb{R}$ 显然；后两者由定理 9.10 与下文引理 9.13 的模 8 论证），故零点必有 $Z \ne 0$；在 $p \equiv 1 \pmod 4$ 处 $-1$ 是平方，原方程的显式解见下面第 2 条。两头接通。

**定理 9.13（$x^2 + y^2 = n$ 的完整判据）**：$x^2 + y^2 = n$ 在 $\mathbb{Q}$ 中有解 $\iff$ $n > 0$，且对每个 $p \equiv 3 \pmod 4$，$v_p(n)$ 为偶数。

证：（$\Rightarrow$）设 $x, y \in \mathbb{Q}$、$x^2 + y^2 = n$，$p \equiv 3 \pmod 4$。记 $m = \min(v_p(x), v_p(y))$，提公因子 $p^m$ 归到至少一个单位。三种情形：若 $v_p(x) \ne v_p(y)$，超度量等号情形给 $v_p(n) = 2\min(v_p(x), v_p(y))$，偶；若 $v_p(x) = v_p(y) = m$ 且约化后两单位 $\frac{x}{p^m}, \frac{y}{p^m}$ 都 $\not\equiv 0 \pmod p$：若 $p \mid x'^2 + y'^2$ 则 $\bigl(x' y'^{-1}\bigr)^2 \equiv -1 \pmod p$，与 $p \equiv 3 \pmod 4$ 无平方根（定理 9.10）矛盾，故 $v_p(n) = 2m$，偶；若某个约化后 $\equiv 0$，则另一方是单位，同第一种情形。$n > 0$ 显然。

（$\Leftarrow$）逐局部验证，然后由 Hasse–Minkowski 收口。

1. **实局部**：$n > 0$，$x = \sqrt{n}$、$y = 0$。
2. **$p \equiv 1 \pmod 4$**：$-1$ 在 $\mathbb{Q}_p$ 有平方根 $i$（定理 9.10）。取 $x = \frac{n+1}{2}$、$y = \frac{n-1}{2i}$（2 与 $i$ 在 $p$ 奇时可逆）：$(x + iy)(x - iy) = n \cdot 1 = n$，即 $x^2 + y^2 = n$。
3. **$p = 2$**：

   **引理 9.14（2-adic 平方判据）**：奇数 $u \in \mathbb{Z}_2$ 是 $\mathbb{Z}_2$ 的平方 $\iff u \equiv 1 \pmod 8$。（$\Rightarrow$）奇数平方 $\equiv 1 \pmod 8$：$(2k+1)^2 = 4k(k+1) + 1$，$k(k+1)$ 偶。（$\Leftarrow$）牛顿迭代 $x_{n+1} = \frac{1}{2}\bigl(x_n + u\,x_n^{-1}\bigr)$，$x_0 = 1$。归纳设 $2^s \mid x_n^2 - u$（$s \ge 3$）：则 $x_n^2 + u = (x_n^2 - u) + 2u$ 是偶数与偶数之和，$v_2 \ge 1$，故 $x_{n+1} \in \mathbb{Z}_2$ 且 $x_{n+1}$ 为奇；误差满足恒等式 $x_{n+1}^2 - u = \frac{(x_n^2 - u)^2}{4 x_n^2}$（直接展开验证），赋值 $2s - 2 \ge s + 1$（$s \ge 3$），严格翻倍增长。误差趋零，极限 $x \in \mathbb{Z}_2$ 满足 $x^2 = u$。$\square$

   由判据的奇素数条件，$n = 2^v \cdot u$ 的奇部 $u$ 的每个 $\equiv 3 \pmod 4$ 素因子都是偶次幂，故 $u \equiv 1 \pmod 4$（$\equiv 1 \pmod 4$ 的素因子贡献 $1$，$\equiv 3 \pmod 4$ 素因子的偶次幂贡献 $1$）。令 $t$ 为 $2u - 1$ 的平方根——$2u - 1 \equiv 1 \pmod 8$，由引理 9.14 存在。两个恒等式：$1 + t^2 = 2u$，$4u = (1+t)^2 + (1-t)^2$（展开即验）。于是：$v = 2k$ 偶时 $n = 2^{2k} u = \bigl(2^{k-1}(1+t)\bigr)^2 + \bigl(2^{k-1}(1-t)\bigr)^2$（$v = 0$ 时取 $\bigl(\frac{1+t}{2}\bigr)^2 + \bigl(\frac{1-t}{2}\bigr)^2$，$t$ 奇保证两系数都是 2-adic 整数）；$v = 2k+1$ 奇时 $n = 2^{2k} (2u) = (2^k)^2 + (2^k t)^2$。各情形 $x, y \in \mathbb{Z}_2 \subset \mathbb{Q}_2$。
4. **$p \equiv 3 \pmod 4$**：写 $n = p^{2m} u$，$u \in \mathbb{Z}_p^\times$。先证 $u$ 是 $\mathbb{Z}_p$ 中两平方和：令 $c = u \bmod p \in \mathbb{F}_p^\times$。平方集合 $A = \{a^2 : a \in \mathbb{F}_p\}$ 有 $\frac{p+1}{2}$ 个元素（$a^2 = (-a)^2$ 配对），对集合 $c - A$ 用鸽笼原理：$|A| + |c - A| = p + 1 > p$，两者相交，故 $c = a_0^2 + b_0^2$。若 $c$ 本身是平方剩余，取 $y_0$：$y_0^2 \equiv u \pmod p$，对 $Y^2 - u$ 用 Hensel（导数 $2y_0 \not\equiv 0$）得 $y^2 = u$，解 $(0, y)$；否则 $a_0, b_0$ 都 $\not\equiv 0$，固定 $y = b_0 \in \mathbb{Z}_p$，对 $X^2 + b_0^2 - u$ 用 Hensel（在 $x_0 = a_0$ 处导数 $2a_0 \not\equiv 0$）得 $x^2 + b_0^2 = u$。缩放：$n = (p^m x)^2 + (p^m y)^2$。

五个局部全部就位，Hasse–Minkowski（定理 9.12）给出全局解。$\blacksquare$

实践中只需检查**有限多个**局部：$p \nmid 2n$ 时 $v_p(n) = 0$ 自动为偶；实数查一次；剩下的只是 $2$ 与 $n$ 的素因子。数值锚（python 穷举 $1$ 到 $100$ 并用 sympy 分解复核）：恰有 **43** 个正整数是两平方和，与判据完全吻合。可表示的如 $97 = 81 + 16$、$90 = 81 + 9$、$98 = 49 + 49$、$45 = 36 + 9$；不可表示的开头是 $3, 6, 7, 11, 12, 14, 15, 19, 21, 22, 23, \ldots$——逐一对应某个 $\equiv 3 \pmod 4$ 素因子的奇次幂（$3$、$6$ 的 $v_3 = 1$，$7$ 的 $v_7 = 1$，等等）。

**为什么「局部信息拼成全局」是深刻的**：

1. 有理解的搜索是无限的、无结构的；局部检查是有限的、可计算的——每个 $\mathbb{Q}_p$ 检查最终化归为「模 $p$ 有没有单根近似」，由 Hensel 逐位买断无穷精度。
2. 这个原理不是普适的：二次型是幸运的例外。次数 $\ge 3$ 的方程立刻失守——Selmer 曲线 $3x^3 + 4y^3 + 5z^3 = 0$ 在每个 $\mathbb{Q}_p$ 与 $\mathbb{R}$ 中都有非平凡解，却在 $\mathbb{Q}$ 上没有任何非平凡解（Selmer 1951 原文；现代讲述见 Silverman–Tate《Rational Points on Elliptic Curves》）。局部验证本身超出本章范围。
3. 失效的差距本身成为不变量：椭圆曲线的 Tate–Shafarevich 群 $\Sha$ 收容「局部处处有点、全局无点」的对象，BSD 猜想把它的阶写进 $L$ 函数的秩公式——「粘合亏损」是深度算术信息，不是理论缺陷。

## $\rm \S \, 9.10$ 本章自测答案

> 先闭卷作答 §9.8 与 §9.9，再核对。

### $\rm \S \, 9.10.1$ 关键概念回顾答案

1. $v_p(x)$ 是分解中 $p$ 的幂次，$|x|_p = p^{-v_p(x)}$。乘性用 $v_p(xy) = v_p(x) + v_p(y)$（分解唯一性）；强三角通分后看括号 $mn' + p^{b-a}m'n$：$a < b$ 时模 $p$ 非零（既约性保证 $p \nmid mn'$），严格情形取等。等号性质称所有三角形等腰——最长边出现两次。（§9.2）
2. 望远镜 $a_m - a_n = \sum (a_k - a_{k-1})$ 加超度量 $|\sum| \le \max$；级数判据用于部分和。调和级数的相邻差趋零但部分和无界，显示这条在 $|\cdot|_\infty$ 下不成立。（§9.2）
3. 阿基米德情形：base-$n$ 展开给 $|m| \le |n|^{\log_n m}$，对换取等式，指数 $\frac{\ln|m|}{\ln m}$ 与取值无关；非阿基米德情形：二项式系数 $|\cdot| \le 1$ 给强三角，最小性选出素数 $p$，Bézout 给互素整数 $|\cdot| = 1$，收口 $|x| = |p|^{v_p(x)}$。即除 $|\cdot|_\infty$ 与诸 $|\cdot|_p$（的幂）外无其他尺子。（§9.3）
4. 柯西序列等价类；$\sum a_k p^k$（$0 \le a_k < p$）；「模 $p^k$ 逐层相容的答案」。稠密性证明的关键：$|b/c|_p \le 1$ 且既约逼出 $p \nmid c$（否则 ${b, c}$ 都被 $p$ 整除），于是 $c$ 模 $p^k$ 可逆、整数逼近 $b c^{-1}$ 可造。（§9.4）
5. 条件：$f(a_0) \equiv 0$、$f'(a_0) \not\equiv 0 \pmod p$。迭代 $a_{k+1} = a_k - f(a_k)/f'(a_k)$ 是牛顿迭代，$f'(a_k)$ 是单位。唯一性靠 $f(x) - f(y) = (x-y)H(x,y)$ 与 $H \equiv f'(a_0) \not\equiv 0 \pmod p$、域无零因子。$x^2 = p$：模 $p$ 根 $0$ 是重根（$f'(0) = 0$），且 $v_p(p) = 1$ 奇数与「平方赋值为偶」矛盾，无解。（§9.5）
6. 证明链：$x^2 = -1 \Rightarrow$ 模 $p$ 得 4 阶子群 $\Rightarrow$ 拉格朗日 $4 \mid p-1$；反向用欧拉判据（原根）+ Hensel。高斯整数证明：$p \equiv 3 \pmod 4$ 素元性靠 $a^2 + b^2 = p$ 模 4 无解；$p \equiv 1 \pmod 4$ 劈开靠欧拉判据给 $x_0^2 \equiv -1$、$p \mid (x_0+i)(x_0-i)$ 而不整除因子、UFD 逼出 $N(z) = p$。$85$ 的两种表示来自 $5 = (2+i)(2-i)$、$17 = (4+i)(4-i)$ 的两种配对。（§9.6）
7. 二次型 $Q = 0$ 全局有非平凡解 ⟺ 处处局部有。清单四项：实（$n > 0$）、$p \equiv 1 \pmod 4$（$i \in \mathbb{Q}_p$ 显式解）、$p = 2$（2-adic 平方判据＋恒等式）、$p \equiv 3 \pmod 4$（鸽笼＋Hensel）；必要性由赋值三分情形直接证。Selmer 反例否定了「局部充分性」对高次方程的期待，留下的差距由 $\Sha$ 测量。（§9.7）

### $\rm \S \, 9.10.2$ 应用与辨析答案

1. $\frac23 = 4 + 1 \cdot 5 + 3 \cdot 5^2 + \cdots$。验证：$3 \times 4 = 12 \equiv 2 \pmod 5$；$3 \times 9 = 27 \equiv 2 \pmod{25}$；$3 \times 84 = 252 = 2 \times 125 + 2$。（§9.4）
2. 抬升到 $x \equiv 235 \pmod{343}$：$235 = 4 + 5 \cdot 7 + 3 \cdot 7^2$，$235^2 = 55225 = 161 \times 343 + 2$。（§9.5；对称地它是 $-\sqrt2$ 的截断。）
3. 两处错误。条件错误：$f'(0) = 0 \equiv 0 \pmod p$，Hensel 的单根条件不满足。结论错误：$x^2 = p$ 在 $\mathbb{Q}_p$ 无解，因为 $v_p(x^2) = 2 v_p(x)$ 必为偶数而 $v_p(p) = 1$——重根情形不仅方法失效，结论本身为假。（§9.5）
4. $45 = 9 \times 5 = 36 + 9$ 可表示（$v_3 = 2$ 偶、$5 \equiv 1 \pmod 4$）；$77 = 7 \times 11$ 不可表示（$v_7 = v_{11} = 1$ 都是 $\equiv 3 \pmod 4$ 素因子的奇次幂）；$98 = 2 \times 7^2 = 49 + 49$ 可表示（$7$ 的幂次为偶）。（§9.7）
5. Hasse–Minkowski 只对二次型成立，Selmer 曲线是三次型——「处处局部有解 ⟹ 全局有解」在次数 3 没有保证。这段推理把一条被证明只覆盖二次型的定理当成了普适原理，而 Selmer 曲线正是它失效的名场面。（§9.7）
