## $\rm \S \, 21.1$ 造表五件套与总流程

白话：造特征标表像破一笔互相咬合的填字账——单看一格无从下手，但约束够多时每个格子都被钉死。本章反复使用的约束恰好五件，先列清单再给流程。

1. **行正交**（第 11 章推论 11.12）：$\langle \chi_i, \chi_j \rangle = \delta_{ij}$——行与行不许雷同；
2. **列正交**（第 11 章 §11.4 陈述段「不可约特征标是类函数空间的正交基」的推论，第 19 章锚一已反复使用）：$\sum_i |\chi_i(g)|^2 = |C_G(g)|$——一列的平方和恰是中心化子的阶，这是「猜一格、验一格」的验收器；
3. **度数方程**（第 11 章推论 11.15）：$\sum_i d_i^2 = |G|$，$d_i = \chi_i(1)$——第一列自带一条硬方程；
4. **商映射拉回**：$N \trianglelefteq G$ 时，$G/N$ 的不可约特征标 $\psi$ 沿 $\pi: G \to G/N$ 拉回成 $\psi \circ \pi$，给出 $G$ 的含 $N$ 于核中的不可约特征标——大群的表可以借小群的表填行；
5. **诱导与 sign 张量**（第 20 章命题 20.6、定理 20.8）：$\mathrm{Ind}_H^G$ 按分部账本造行，Frobenius 互反读分解；一维特征标 $\varepsilon$ 与表示的张量 $\chi \otimes \varepsilon$ 保不可约（$|\varepsilon(g)| = 1$ 使 $\langle \chi \otimes \varepsilon, \chi \otimes \varepsilon \rangle = \langle \chi, \chi \rangle$）——一行算完，同维数的孪生行免费再得。

两条正交关系按类加权后的工作形态是

$$
\frac{1}{|G|}\sum_k |C_k|\,\chi_i(c_k)\overline{\chi_j(c_k)} \;=\; \delta_{ij},
\qquad\qquad
\sum_i |\chi_i(c_k)|^2 \;=\; |C_G(c_k)|.
$$

读法：第一条管行——对全部群元素的平均按类归并成「类大小加权」的和；第二条管列——一列的平方和恰是该类中心化子的阶，而类大小与中心化子阶由轨道-稳定子（第 3 章定理 3.5）互为倒数：$|C_k| = |G|/|C_G(c_k)|$。两条配套的计数事实贯穿全章：**类数等于不可约个数**（第 11 章 §11.4，类函数空间的维数），它定表的形状；类大小公式（刚引的轨道-稳定子）把类账与中心化子焊在一起。总流程一句话：**先数共轭类定表的形状（类数给行数，度数方程钉住第一列），再用五件套把其余格子一格一格钉死，最后用列正交整表验收。**本节小结：五件套就是全部武器，下面两节是两场完整的实战，每件武器都会开火多次。

## $\rm \S \, 21.2$ $S_4$ 全表逐步构造

白话：$S_4$ 是四件东西的置换群，元素按循环型分家——共轭保持循环型（第 3 章引理 3.7），且同循环型可互达，所以类 $=$ 循环型。五档循环型给出五个类，逐档把类大小与中心化子一起算清。

1. **单位元**：类大小 $1$，中心化子 $S_4$ 全体，$24$。
2. **对换**（$g = (12)$）：$\tau g \tau^{-1} = (\tau(1)\,\tau(2))$，它等于 $(12)$ 当且仅当 $\tau$ 把集合 $\{1, 2\}$ 整体保持：$\tau$ 在 $\{1,2\}$ 上有 $2$ 种、在 $\{3,4\}$ 上有 $2$ 种，$|C_{S_4}(g)| = 2 \cdot 2 = 4$，类大小 $24/4 = 6$（与「四点选两点」$= 6$ 对上）。
3. **双对换**（$g = (12)(34)$）：全体双对换恰 $3$ 条（把四点分成两对有 $3$ 种分法），且彼此共轭——$\tau = (23)$ 把 $(12)(34)$ 送去 $(\tau(1)\,\tau(2))(\tau(3)\,\tau(4)) = (13)(24)$。故类大小 $= 3$，中心化子阶 $24/3 = 8$；交叉验证：$V_4 = \{e, (12)(34), (13)(24), (14)(23)\}$ 是阿贝尔群，整个落在中心化子里已是 $4$ 个，再加 $(12)$（它与 $(12)(34)$ 可交换：两条不交循环）凑足 $8$。
4. **三循环**（$g = (123)$）：$\tau g \tau^{-1} = (\tau(1)\,\tau(2)\,\tau(3))$ 等于 $g$ 当且仅当 $(\tau(1), \tau(2), \tau(3))$ 是 $(1,2,3)$ 的循环轮换且 $\tau(4) = 4$，共 $3$ 种，中心化子阶 $3 = \langle (123) \rangle$，类大小 $24/3 = 8$；直接计数：选三个点 $4$ 种、循环方向 $2$ 种，恰 $8$ 条，两账对平。
5. **4-循环**（$g = (1234)$）：直接计数 $4!/4 = 6$（每个 4-循环有 $4$ 种等价写法），反推中心化子 $|C| = 24/6 = 4$；验证：$g$ 在四点上传递，若 $\tau g = g\tau$，则 $\tau(g^k(1)) = g^k \tau(1)$ 对一切 $k$ 成立——$\tau$ 由 $\tau(1)$ 的取值唯一决定且必为 $g^k$ 之形，故 $C = \langle g \rangle$ 恰 $4$ 阶。

类账合计 $1 + 6 + 3 + 8 + 6 = 24$ ✓，五个类给五条不可约。度数方程与它的解：

$$
d_1^2 + d_2^2 + d_3^2 + d_4^2 + d_5^2 \;=\; 24, \qquad d_i \ge 1\ \text{整数}.
$$

读法：五个正整数的平方凑 $24$，平方池只有 $\{1, 4, 9, 16\}$。逐档排查：若某 $d = 4$，其余四个正平方要凑 $8$，但 $4+1+1+1 = 7$、$1+1+1+1 = 4$、$4+4+1+1 = 10$——夹不住，$16$ 出局；于是平方全在 $\{1, 4, 9\}$ 里。三个 $9$ 超支（$27 > 24$）；两个 $9$：剩三项凑 $6 = 4 + 1 + 1$ ✓；恰一个 $9$：剩四项（各 $\le 4$）凑 $15$，但 $15$ 为奇数需要奇数个 $1$，逐试 $4+4+4+1 = 13$、$4+4+1+1 = 10$ 全落空；零个 $9$：至多 $4 \cdot 5 = 20 < 24$。**唯一解** $\{1, 1, 1, 4, 9\}$，即维数 $\{1, 1, 2, 3, 3\}$。旁证：$S_4$ 的换位子群是 $A_4$（第 4 章例 4.18），交换化 $S_4/A_4 \cong \mathbb{Z}_2$ 恰给两条一维——与解里的两个 $d = 1$ 对上。

平凡行 $\chi_1 = [1, 1, 1, 1, 1]$ 与符号行 $\chi_2 = [1, -1, 1, 1, -1]$ 立刻写下：对换与 4-循环是奇置换（$4$-循环拆成 $3$ 个对换），单位元、双对换、三循环是偶置换。下一条是三维标准行。置换表示 $\mathbb{C}^4$（按坐标置换作用）的特征标是不动点数——置换矩阵每行恰一个 $1$，迹就是纹丝不动的坐标个数。它分解为

$$
\mathbb{C}^4 \;=\; \mathbb{C}\,(1, 1, 1, 1) \;\oplus\; \{x \in \mathbb{C}^4 : x_1 + x_2 + x_3 + x_4 = 0\},
$$

读法：左边是全等向量线，右边是和零超平面；置换坐标作用把全等向量送回全等向量、保住坐标和，两条都是子表示，维数 $1 + 3 = 4$。故 $\chi_{\mathrm{std}}(g) = \mathrm{fix}(g) - 1$：五类的不动点数 ${4, 2, 0, 1, 0}$ 给行 $[3, 1, -1, 0, -1]$。当场验收：$\langle \chi_{\mathrm{std}}, \chi_{\mathrm{std}} \rangle = \frac{1}{24}(1 \cdot 9 + 6 \cdot 1 + 3 \cdot 1 + 8 \cdot 0 + 6 \cdot 1) = 1$，不可约。第五行免费用张量拿走：$\chi_5 = \chi_{\mathrm{std}} \otimes \mathrm{sign}$ 不可约（五件套第 5 件），逐列乘 $\pm 1$ 得 $[3, -1, -1, 0, 1]$，与 $\chi_4$ 在对换列分道（$1$ 对 $-1$），是不同的行。

剩下的二维行走商映射拉回，分四步全证。

1. **$V_4$ 正规**：共轭把双对换送去双对换（$(\tau(1)\,\tau(2))(\tau(3)\,\tau(4))$ 仍是两条不交对换之积），而 $V_4$ 恰是「单位元加全体双对换」，这个集合被共轭整体保持——$V_4 \trianglelefteq S_4$。
2. **$S_4/V_4 \cong S_3$**：考虑共轭作用 $\varphi: S_4 \to S_3$（作用于三元集 $\{d_1, d_2, d_3\} = V_4 \setminus \{e\}$，$d_1 = (12)(34)$、$d_2 = (13)(24)$、$d_3 = (14)(23)$）。像里有 2 阶元也有 3 阶元：$(12)$ 固定 $d_1$（它与 $d_1$ 可交换）、把 $d_2$ 送去 $(\tau(1)\,\tau(3))(\tau(2)\,\tau(4)) = (23)(14) = d_3$——是个对换；$(123)$ 逐条共轭给 $d_1 \mapsto d_3$、$d_3 \mapsto d_2$、$d_2 \mapsto d_1$——是个三循环。对换与三循环在 $S_3$ 里生成全群，故 $|\varphi(S_4)| = 6$，$|\ker \varphi| = 24/6 = 4$；而 $V_4$ 阿贝尔、共轭作用平凡，$V_4 \subseteq \ker \varphi$，两边都是 4 阶——$\ker \varphi = V_4$，$S_4/V_4 \cong S_3$。
3. **商群里的类位置**：$S_3$ 的三个类恰是 $\{e\}$、三个 2 阶元、两个 3 阶元，所以只需读陪集的阶。$e$ 与三条双对换落在 $V_4$ 里，陪集是单位元；$(12)^2 = e \in V_4$ 而 $(12) \notin V_4$，陪集阶 $2$；$(1234)^2 = (13)(24) \in V_4$ 而 $(1234) \notin V_4$（奇置换，$V_4$ 全偶），陪集阶 $2$——**这就是「4-循环在商群里是对换」的精确含义**，再配一条显式验证：$(1234)$ 共轭作用固定 $d_2$（$d_2$ 就是它的平方，当然交换）、互换 $d_1$ 与 $d_3$，正是对换的动作；$(123)^3 = e \in V_4$ 而 $(123)$、$(123)^2$ 都不在 $V_4$，陪集阶 $3$。
4. **拉回与认领**：沿商映射拉回 $S_3$ 的二维标准特征标（例 11.17 的 $(2, 0, -1)$）：单位元陪集取 $2$、对换类陪集取 $0$、三循环类陪集取 $-1$，行 $[2, 0, 2, -1, 0]$。不可约性：拉回表示里 $V_4$ 逐元素作用为恒等，子空间在 $S_4$ 下稳定当且仅当在 $S_4/V_4$ 下稳定——$S_3$ 二维不可约给拉回不可约；度数 $2$ 在 $\{1, 1, 2, 3, 3\}$ 中唯一，不必再与其他行区分。

整张表落定：

| 类（大小） | $\{e\}\,(1)$ | $(12)\,(6)$ | $(12)(34)\,(3)$ | $(123)\,(8)$ | $(1234)\,(6)$ |
| --- | --- | --- | --- | --- | --- |
| 平凡 $\chi_1$ | $1$ | $1$ | $1$ | $1$ | $1$ |
| 符号 $\chi_2$ | $1$ | $-1$ | $1$ | $1$ | $-1$ |
| 二维（拉回）$\chi_3$ | $2$ | $0$ | $2$ | $-1$ | $0$ |
| 标准 $\chi_4$ | $3$ | $1$ | $-1$ | $0$ | $-1$ |
| 标准$\otimes$符号 $\chi_5$ | $3$ | $-1$ | $-1$ | $0$ | $1$ |

读两条隐藏的账。其一，第五行就是第二行与第四行的逐列乘积——「张 sign」在表上是一列一列乘出来的。其二，正则特征标的分解

$$
\chi_{\mathrm{reg}} \;=\; \chi_1 + \chi_2 + 2\chi_3 + 3\chi_4 + 3\chi_5
$$

读法：第一列读出 $1 + 1 + 4 + 9 + 9 = 24 = |S_4|$；其余四列逐类代入全归零（对换列 $1 - 1 + 0 + 3 - 3 = 0$，双对换列 $1 + 1 + 4 - 3 - 3 = 0$，三循环列 $1 + 1 - 2 = 0$，4-循环列 $1 - 1 - 3 + 3 = 0$）——第 11 章定理 11.13 的「非单位元处一分不剩」逐类兑现，给全表又盖一枚验收章。列正交整表验收（各类中心化子阶 $[24, 4, 8, 3, 4]$，正是类账步骤反推的账）：单位元列 $1 + 1 + 4 + 9 + 9 = 24$；对换列 $1 + 1 + 0 + 1 + 1 = 4$；双对换列 $1 + 1 + 4 + 1 + 1 = 8$；三循环列 $1 + 1 + 1 + 0 + 0 = 3$；4-循环列 $1 + 1 + 0 + 1 + 1 = 4$——五列逐列咬合，填错一格当场报警。本节小结：类账定形状、度数方程定第一列、不动点数与 sign 张量送两条三维行、商拉回送二维行，列正交与正则零账把全表焊死。

## $\rm \S \, 21.3$ $A_5$ 全表

白话：$A_5$ 是五点的偶置换群，阶 $60$，单（第 4 章定理 4.12）。单性在造表里的用法只有一处，却致命：它封死了一维表示的来源。其余全靠算术与诱导。

**类账**：偶置换的循环型三档——双对换、三循环、五循环。

1. **双对换** $15$ 条（选四个点 $5$ 种、两两配对 $3$ 种）：$C_{S_5}(g) \cong D_8$ 阶 $8$（保持 $\{1,2\}$ 与 $\{3,4\}$ 两对、可整体换序），其中偶元素恰是 $V_4$ 阶 $4$，故 $|C_{A_5}(g)| = 4$、类大小 $60/4 = 15$ ✓。
2. **三循环** $20$ 条（$\binom{5}{3} \cdot 2$）：$C_{S_5}((123)) = \langle (123) \rangle \times \langle (45) \rangle$ 阶 $6$ 含奇元素 $(45)$，偶部分恰 $\langle (123) \rangle$ 阶 $3$，类大小 $60/3 = 20$ ✓。
3. **五循环** $24$ 条：$C_{S_5}(\sigma) = \langle \sigma \rangle$ 阶 $5$（$\sigma$ 传递，交换 $\sigma$ 的 $\tau$ 由 $\tau(1)$ 唯一决定），**全在 $A_5$ 里**——这里触发分裂判据。

> **分裂判据**：把 $g$ 共轭成固定 ${g'}$ 的 $S_5$-元素集合是「某个共轭子乘 $C_{S_5}(g)$」的陪集。若 $C_{S_5}(g)$ 含奇元素，每个共轭子都有奇偶两种取法，$A_5$-共轭与 $S_5$-共轭重合，类不分裂；若 $C_{S_5}(g) \subseteq A_5$，每个陪集奇偶一致，$S_5$-类按共轭子奇偶对半裂成两个 $A_5$-类。

于是 $24$ 条五循环裂成两类，各 $60/5 = 12$ 条。定案成员：$\sigma^{-1}$ 落在 $\sigma$ 所在的一类（记 ${5A}$）——偶共轭子 $(25)(34)$ 给 $\tau\sigma\tau^{-1} = (\tau(1)\,\tau(2)\,\tau(3)\,\tau(4)\,\tau(5)) = (1\,5\,4\,3\,2) = \sigma^{-1}$；$\sigma^2$ 落在另一类（记 ${5B}$）——把 $\sigma$ 的循环标记 $(1,2,3,4,5)$ 送到 $\sigma^2$ 的 $(1,3,5,2,4)$ 的置换是 $1 \mapsto 1,\ 2 \mapsto 3,\ 3 \mapsto 5,\ 4 \mapsto 2,\ 5 \mapsto 4$，即 $(2\,3\,5\,4)$，奇，而共轭子陪集奇偶一致（中心化子全偶），故全部共轭子皆奇，$\sigma^2$ 不在 ${5A}$。

> **辨析（一条现成的陷阱）**：$(13542)$ 长得像「另一条五循环」，其实与 $(12345)$ **同类**——偶置换 $(235)$ 把 $(12345)$ 共轭成 $(\tau(1)\,\tau(2)\,\tau(3)\,\tau(4)\,\tau(5)) = (1\,3\,5\,4\,2)$。「换个写法」不等于「换类」；分裂的裁决者是共轭子的奇偶，不是肉眼。${5B}$ 的干净代表是 $\sigma^2 = (13524)$。程序裁决见 §21.7。

类账 $1 + 15 + 20 + 12 + 12 = 60$ ✓，五个类给五条不可约。**度数方程**分两头上演。反方向（天真开局破产）：若像 $S_3$、$S_4$ 那样用符号特征标白拿第二条一维、再补一条二维，剩两条平方和为 $60 - 1 - 1 - 4 = 54$；两个平方凑 $54$，在 $\{4, 9, 16, 25, 36, 49\}$ 里逐对清点：$49 + 4 = 53$、$49 + 9 = 58$、$36 + 16 = 52$、$25 + 25 = 50$——全部落空，此开局推不动。而第二条一维本就被单性封死：一维表示的核是正规子群，$A_5$ 单给核为 $\{e\}$ 或全群；核为 $\{e\}$ 则 $A_5$ 同构于 $\mathbb{C}^{\times}$ 的子群而交换，矛盾——故只有平凡一条一维。正方向（清点定案）：除平凡外恰四条，

$$
d_2^2 + d_3^2 + d_4^2 + d_5^2 \;=\; 59, \qquad d_i \ge 2.
$$

读法：四个 $\ge 2$ 的整数的平方凑 $59$，按最大项分档。含 $49$，其余三项至少 $4 + 4 + 4 = 12$，超支；含 $36$，其余三项凑 $23$，在 $\{4, 9, 16, 25\}$ 里三三清点（$4+4+16 = 24$、$4+9+9 = 22$、$4+4+9 = 17$、$9+9+9 = 27$）无 $23$；最大项 $25$，其余凑 $34$，唯一命中 $16 + 9 + 9$（对照 $25+4+4 = 33$、$16+16+4 = 36$）；全无 $25$ 以上则至多 $16 \cdot 4 = 64$，但 $16 \cdot 3 + 9 = 57$、$16 \cdot 2 + 9 \cdot 2 = 50$ 等全部错过 $59$。**唯一解** $\{9, 9, 16, 25\}$，即维数 ${3, 3, 4, 5}$；注意清点里从未出现 $4$，$d = 2$ 被算术顺带排除，与反方向遥相印证。$\sum d_i^2 = 1 + 9 + 9 + 16 + 25 = 60$ ✓。

平凡行照抄。**四维行**：$S_5$ 的标准表示（五点置换表示去掉全等向量线）限制到 $A_5$，特征标仍是「五点不动点数减一」：五类的不动点数 ${5, 1, 2, 0, 0}$ 给行 $[4, 0, 1, -1, -1]$；验收 $\langle \chi_4, \chi_4 \rangle = \frac{1}{60}(16 + 0 + 20 + 12 + 12) = 1$，限制后仍不可约。**五维行**：$24$ 条五循环每条生成一个五阶子群（含四条非单位元），故 Sylow-5 子群恰 $24/4 = 6$ 个，$A_5$ 共轭作用传递（Sylow 第二定理），取 $N = N_{A_5}(\langle \sigma \rangle)$，轨道-稳定子给 $|N| = 60/6 = 10$。$N$ 的形状：对合 $\tau = (25)(34)$ 共轭 $\sigma$ 到 $\sigma^{-1}$（上段算过），故 $\tau \in N$，$\langle \sigma, \tau \rangle \subseteq N$ 已有 $5 + 5 = 10$ 个元素（$\tau \notin \langle \sigma \rangle$），恰是 $N$，同构 $D_{10}$——$\langle \sigma \rangle$ 的四个 5 阶元加五个对合。置 $\pi = \mathrm{Ind}_N^{A_5} \mathbf{1}_N$，用第 20 章命题 20.6 逐类清点（$x^{-1}gx \in N$ 的 $x$ 按「$N$ 里与 $g$ 同类的元素」分摊，每个被 $|C_{A_5}(g)|$ 个 $x$ 击中）：$e$ 列 $60/10 = 6$；${2A}$ 列 $N \cap {2A}$ 是五个对合（对合全是双对换、全体同类），$5 \cdot 4/10 = 2$；${3A}$ 列 $N$ 无三阶元（Lagrange），$0$；${5A}$ 列 $N \cap {5A} = \{\sigma, \sigma^{-1}\}$（$\sigma^2, \sigma^3$ 在另一类），$2 \cdot 5/10 = 1$，${5B}$ 同理 $1$。置 $\chi_5 = \pi - \mathbf{1}$，行 $[5, 1, -1, 0, 0]$；验收 $\langle \chi_5, \chi_5 \rangle = \frac{1}{60}(25 + 15 + 20) = 1$，而虚拟特征标内积为一只能是 $\pm$ 一条不可约（正交基下系数平方和为一），$\chi_5(e) = 5 > 0$ 排除负号——真不可约特征标。

**两条三维行**是本章的压轴。取 $C_5 = \langle \sigma \rangle$ 与它的忠实一维特征标 $\psi(\sigma) = \zeta$（$\zeta = \mathrm{e}^{2\pi i/5}$），令 $W = \mathrm{Ind}_{C_5}^{A_5} \psi$，维数 $60/5 = 12$。命题 20.6 的求和只收「$x^{-1}gx \in \langle \sigma \rangle$」的 $x$，而这等价于 $x \in N$（$x^{-1} \langle \sigma \rangle x = \langle x^{-1}\sigma x \rangle = \langle \sigma \rangle$）。$N$ 里 $\langle \sigma \rangle$ 的五个元素把 $\sigma$ 送去 $\sigma$（阿贝尔），五个对合把它送去 $\sigma^{-1}$（对合在 $\langle \sigma \rangle$ 上的自同构非平凡——否则它落入中心化子 $C_{A_5}(\sigma) = \langle \sigma \rangle$，而那里没有对合——故必为二阶自同构即逆转）。故

$$
\chi_W(\sigma) = \zeta + \zeta^{-1}, \qquad \chi_W(\sigma^2) = \zeta^2 + \zeta^{-2}, \qquad \chi_W = [12,\ 0,\ 0,\ \zeta + \zeta^{-1},\ \zeta^2 + \zeta^{-2}],
$$

读法：非 5-循环的类上无人入选，值为零；两个 5-循环类各被 $N$ 的十个元素扫一遍、按 $\psi$ 的取值平均。记 $u = \zeta + \zeta^{-1}$、$v = \zeta^2 + \zeta^{-2}$：由 $1 + \zeta + \zeta^2 + \zeta^3 + \zeta^4 = 0$ 取实部得 $1 + u + v = 0$，而 $v = u^2 - 2$，代入得 $u^2 + u - 1 = 0$，正根（$u = 2\cos 72^{\circ} > 0$）为 $u = \frac{\sqrt{5} - 1}{2} = \frac{1}{\varphi}$，于是 $v = -\varphi$。几何读法同一条账：$A_5$ 是正二十面体的旋转群，六条五重轴恰是六个 Sylow-5 子群；绕轴转 $72^{\circ}$ 的三维旋转矩阵特征值为 $1, \zeta^{\pm 1}$，迹 $1 + u = \varphi$；转 $144^{\circ}$ 特征值 $1, \zeta^{\pm 2}$，迹 $1 + v = -\frac{1}{\varphi}$——而且同一条轴上 $\pm 72^{\circ}$ 与 $\pm 144^{\circ}$ 互相共轭不到（共轭把轴送到轴、转角不动），这正是 ${5A}$ 与 ${5B}$ 分裂的几何版。现在扣账：$\chi_{3a} := \chi_W - \chi_4 - \chi_5$ 逐类相减得 $[3, -1, 0, \frac{1}{\varphi} + 1, 1 - \varphi] = [3, -1, 0, \varphi, -\frac{1}{\varphi}]$（用了 $\varphi = 1 + \frac{1}{\varphi}$ 与 $1 - \varphi = -\frac{1}{\varphi}$）。验收：$\langle \chi_{3a}, \chi_{3a} \rangle = \frac{1}{60}\big(9 + 15 + 12(\varphi^2 + \varphi^{-2})\big)$，而 $\varphi^2 + \varphi^{-2} = 3$（下段证），故 $\frac{9 + 15 + 36}{60} = 1$——同「虚拟、内积一、首项为正」的三步论证，$\chi_{3a}$ 是真不可约特征标。孪生行免费再得：取奇置换 $h = (12) \in S_5$，置 $\chi_{3b}(g) = \chi_{3a}(hgh^{-1})$，这是表示 $\rho^h(g) = \rho(h^{-1}gh)$ 的特征标；奇共轭交换 ${5A}$ 与 ${5B}$（$(12)\sigma(12)$ 的共轭子含奇元 $(12)$，共轭子奇偶一致，故它不在 ${5A}$），行变 $[3, -1, 0, -\frac{1}{\varphi}, \varphi]$，内积与 $\chi_{3a}$ 相同（换共轭是等距），且在 ${5A}$ 列取值不同——是不同的行。这对孪生的差别就是嵌入 $A_5 \subset S_5$ 的扭曲，与 $S_6$ 外自同构那种成对现象无关（陈述级；James–Liebeck 书中沿此路线构造）。五条行到齐，度数 ${1, 3, 3, 4, 5}$ 与度数方程的解逐位吻合——完备性当场对账：

| 类（大小） | $\{e\}\,(1)$ | $(12)(34)\,(15)$ | $(123)\,(20)$ | $(12345)\,(12)$ | $(13524)\,(12)$ |
| --- | --- | --- | --- | --- | --- |
| $\chi_1$ | $1$ | $1$ | $1$ | $1$ | $1$ |
| $\chi_{3a}$ | $3$ | $-1$ | $0$ | $\varphi$ | $-\frac{1}{\varphi}$ |

**精确验算**。$\varphi = \frac{1 + \sqrt{5}}{2}$ 满足 $\varphi^2 = \varphi + 1$（展开即得），倒数为 $\frac{1}{\varphi} = \varphi - 1$（$\varphi(\varphi - 1) = \varphi^2 - \varphi = 1$），平方倒数 $\frac{1}{\varphi^2} = (\varphi - 1)^2 = \varphi^2 - 2\varphi + 1 = 2 - \varphi$。两条主恒等式随之而来：

$$
\varphi - \frac{1}{\varphi} \;=\; 1, \qquad \varphi^2 + \frac{1}{\varphi^2} \;=\; (\varphi + 1) + (2 - \varphi) \;=\; 3.
$$

读法：这两条恒等式就是让根号 5 全部对消的账本——所有含 $\varphi$ 的内积摊开都是 $a + b\sqrt{5}$ 的形状，账本保证 $b$ 位清零、$a$ 位落成整数。行范数逐行验到 $1$：$\chi_1$ 行 $\frac{1 + 15 + 20 + 12 + 12}{60}$；${3a}$、${3b}$ 行 $\frac{9 + 15 + 12 \cdot 3}{60}$；$\chi_4$ 行 $\frac{16 + 20 + 12 + 12}{60}$；$\chi_5$ 行 $\frac{25 + 15 + 20}{60}$。两两正交十对全验。含 $\varphi$ 的四对细算：$\chi_1 \cdot \chi_{3a}$ 为 $3 - 15 + 12(\varphi - \frac{1}{\varphi}) = -12 + 12 = 0$（$\chi_1 \cdot \chi_{3b}$ 同理）；$\chi_{3a} \cdot \chi_{3b}$ 为 $9 + 15 - 12 - 12 = 0$（两个五循环列各贡献 $\varphi \cdot (-\frac{1}{\varphi}) \cdot 12 = -12$）；$\chi_{3a} \cdot \chi_4$ 为 $12 - 12\varphi + \frac{12}{\varphi} = 12 - 12 = 0$（$\chi_{3b} \cdot \chi_4$ 同理）。纯整数六对一句带过：$4 + 20 - 12 - 12 = 0$、$5 + 15 - 20 = 0$、$15 - 15 = 0$、$15 - 15 = 0$、$20 - 20 = 0$。正则零账也随手兑现：$\chi_{\mathrm{reg}} = \chi_1 + 3\chi_{3a} + 3\chi_{3b} + 4\chi_4 + 5\chi_5$，第一列 $1 + 9 + 9 + 16 + 25 = 60$，其余四列靠两条恒等式归零（${5A}$ 列 $1 - 4 + 3(\varphi - \frac{1}{\varphi}) = 0$）。列正交收尾（中心化子阶 $[60, 4, 3, 5, 5]$，正是类账步骤里算出的）：单位元列 $1 + 9 + 9 + 16 + 25 = 60$；双对换列 $1 + 1 + 1 + 0 + 1 = 4$；三循环列 $1 + 0 + 0 + 1 + 1 = 3$；两个五循环列各 $1 + \varphi^2 + \frac{1}{\varphi^2} + 1 + 0 = 2 + 3 = 5$。本节小结：单性封死一维、算术解出 $\{1, 3, 3, 4, 5\}$、诱导账一次掏出两条三维行、黄金比例的账本把根号 5 全部对消——$A_5$ 的表与 $S_4$ 的表在同一套流程下验收合格。

## $\rm \S \, 21.4$ 程序怎么算特征标表：Dixon 一瞥

白话：本章两张表是手工刺绣，GAP 一秒钟织完——机器没有魔法，它解的是同一个方程组，只是把「猜」换成了系统性的枚举。机器的三个部件，三段说完。

1. **原料**：共轭类清点，外加幂映射表——每个 $g$ 的各次幂 $g^k$ 落在哪个类。这是唯一「群论」的部分，剩下的全是解方程。
2. **方程组**：行正交、列正交、度数方程、整性（特征标值是代数整数，第 19 章推论 19.6；有理值必为整数）、Galois 结构——若 $\chi(g) = \sum_j \lambda_j$（特征值之和），则 $\chi(g^k) = \sum_j \lambda_j^k$，幂映射表把同一行在不同类上的值锁在一起。表由此变成有限个未知量的多项式方程组。
3. **Dixon 的降格**（1967，陈述级）：把复数域的问题模素数 $p$ 打碎——特征 $p$ 下 Maschke 失效，表示反而更「碎」、更小，Brauer 特征标只看 $p$-正则类；对几个素数各解一遍模问题，再升格拼回复特征标。完整证明超出本章范围，出处 Serre 第三部分；James–Liebeck 第 30 章有可逐步跟做的算法叙述。

GAP 一句话：`CharacterTable("A5"); Display(last);` 秒回 §21.3 的表（GAP 的类名 5A、5B 对应本书的 $(12345)$、$(13524)$）。为什么「猜一格验一格」的暴力可行：列正交是逐列的硬约束——$n - 1$ 行已知时，最后一行在每列的模长被钉死，行正交与整性再钉住相位与符号；本章的手工流程反复兑现这一点（$A_5$ 的两条三维行被 $\chi_W - \chi_4 - \chi_5$ 一步钉死，$S_4$ 的二维行被度数唯一性认领）。格子不是自由变量，是指纹上互相咬合的纹线。本节小结：机器造表 $=$ 类清点 $+$ 正交方程组 $+$ 模 $p$ 降格；手工造表是同一方程组的「人肉 Dixon」。

## $\rm \S \, 21.5$ 应用：从特征标表读 Galois 群

白话：指纹比喻在这里兑现成字面用法——四次方程的 Galois 群就藏在 $S_4$ 的表里，读表的顺序就是判定的流程。设 $f \in \mathbb{Q}[x]$ 不可约四次，$G = \mathrm{Gal}(L/\mathbb{Q})$ 作用于四根，是 $S_4$ 的传递子群；$S_4$ 的传递子群恰五个：$S_4, A_4, D_4, C_4, V_4$（阶 ${24, 12, 8, 4, 4}$，陈述级）。判定就是在这五个里点名，三件判据全在表上。

1. **sign 行读判别式**：$\delta = \prod_{i<j}(r_i - r_j)$ 满足 $\sigma(\delta) = \mathrm{sign}(\sigma)\,\delta$，而 $\mathrm{disc}(f) = \delta^2$。判别式是有理平方 $\iff$ $\delta \in \mathbb{Q}$（$\delta \in L$，被 $G$ 整体固定才落回 $\mathbb{Q}$，第 13 章固定域对应）$\iff$ $G$ 上符号行全取 $1$ $\iff$ $G \in \{A_4, V_4\}$。
2. **二维行读预解式**：预解三次式的三条根是

$$
\theta_1 = (r_1 + r_2)(r_3 + r_4), \qquad \theta_2 = (r_1 + r_3)(r_2 + r_4), \qquad \theta_3 = (r_1 + r_4)(r_2 + r_3),
$$

读法：每个 $\theta$ 对应四根的一种两两配对，恰是 §21.2 步骤 2 的三元集 $\{d_1, d_2, d_3\}$——$G$ 置换这三条 $\theta$，固定其一 $\iff$ $G$ 落进配对稳定子（$D_4$ 型，阶 $8$）$\iff$ 预解式在 $\mathbb{Q}$ 有根。表的语言：$G$ 在配对上的置换特征标就是「平凡加二维行限制到 $G$」。
3. **三维行管收口**：三元指纹 $(\mathrm{sign}, \chi_2, \chi_4)$ 按类取值——

$$
(1, 2, 3),\quad (-1, 0, 1),\quad (1, 2, -1),\quad (-1, 0, -1),\quad (1, -1, 0),
$$

读法：五条互不相同——指纹把 $S_4$ 的五个类一一分开。数清 $G$ 里各指纹的个数就数清了循环型普查，而普查数据由模 $p$ 分解型定理（第 14 章）供给；对换个数区分 $D_4$（两个）与 $C_4$（零个），4-循环个数把 $C_4$ 与 $V_4$ 分开。

| 群 | 判别式平方 | 预解式有 $\mathbb{Q}$ 根 | 对换个数 | 4-循环个数 |
| --- | --- | --- | --- | --- |
| $S_4$ | 否 | 否 | $6$ | $6$ |
| $A_4$ | 是 | 否 | $0$ | $0$ |
| $D_4$ | 否 | 是 | $2$ | $2$ |
| $C_4$ | 否 | 是 | $0$ | $2$ |
| $V_4$ | 是 | 是（全裂） | $0$ | $0$ |

实战对账（第 14 章的 $x^4 - x - 1$）：判别式 $-283$ 是素数、非平方——sign 行判它不落 $\{A_4, V_4\}$；预解式 $x^3 + 4x - 1$ 无有理根（$\pm 1$ 代入得 $4, -6$）、不可约——二维行判它不落 $\{D_4, C_4, V_4\}$；两头一夹 $G = S_4$，与第 14 章 sympy `galois_group` 的真算一致。第 14 章的分解型定理负责供数据，本章的表负责解释为什么这些数据恰好点名。

指纹不唯一的边界也要说清。反例一（陈述级）：$D_8$ 与 $Q_8$——同阶 $8$、都是五个类（大小 ${1, 1, 2, 2, 2}$）、都是四条一维加一条二维（二维取值 $[2, -2, 0, 0, 0]$）——两张表逐格相同（$D_8$ 的表见例 11.18；$Q_8$ 的四条一维沿商 $Q_8/\{\pm 1\} \cong \mathbb{Z}_2 \times \mathbb{Z}_2$ 拉回，二维由 Pauli 型矩阵给出；出处 Serre §5.7 习题）。反例二（陈述级）：奇素数 $p$ 的两个 $p^3$ 阶非交换群（Heisenberg 群与 exponent-$p^2$ 的姊妹）也同表——$D_8$ 对 $Q_8$ 是 $p = 2$ 的特例。读法：表「看不见」的东西包括元素的阶与幂映射——在表上补一行幂映射数据（§21.4 的原料）就能分开 $D_8$ 与 $Q_8$（$r^2$ 与 $-1$ 的幂行为不同）。指纹不唯一不推翻指纹学，只是划清它的管辖边界。本节小结：判别式走 sign 行、预解式走二维行、指纹普查靠三维行收口，四次方程的群在五个传递子群里点名入座；而同表反例提醒我们表并非群的全部信息。

## $\rm \S \, 21.7$ 可当场复跑的验证

下面一段纯标准库 Python 把本章三条验收一次跑完：度数方程、全部二十五对行正交、五列平方和对照中心化子阶。$A_5$ 的无理值记作数对 $(a, b) = a + b\sqrt{5}$，系数用分数精确算——正交验算的「对消」是恒等式，不是数值巧合。

```python
# 特征标表全表验算：S4 与 A5（纯标准库，不依赖 sympy）
from fractions import Fraction as F

def mul(u, v):                        # (a1+b1*sqrt5)*(a2+b2*sqrt5)
    return (u[0]*v[0] + 5*u[1]*v[1], u[0]*v[1] + u[1]*v[0])
def I(x):     return (F(x), F(0))     # 整数值
PHI  = (F(1, 2),  F(1, 2))            #  phi   = (1+sqrt5)/2
MPHI = (F(1, 2), -F(1, 2))            # -1/phi = (1-sqrt5)/2

def inner(r1, r2, sizes, n):          # 表值全为实数，逐类直接相乘
    sa = sb = F(0)
    for a, b, c in zip(r1, r2, sizes):
        p = mul(a, b); sa += c * p[0]; sb += c * p[1]
    return sa / n, sb / n             # n = |G|；sqrt5 系数必须对消成 0

def audit(name, n, sizes, cent, rows):
    assert sum(mul(r[0], r[0])[0] for r in rows) == n, "degree"
    for i, r1 in enumerate(rows):
        for j, r2 in enumerate(rows):
            want = (F(1), F(0)) if i == j else (F(0), F(0))
            assert inner(r1, r2, sizes, n) == want, f"row {i},{j}"
    for k in range(len(sizes)):       # 列正交：平方和 = 中心化子阶
        assert sum(mul(r[k], r[k])[0] for r in rows) == cent[k], f"col {k}"
    print(name, "rows", len(rows), "classes", len(sizes), "all OK")

S4 = [
    [I(1),  I(1),  I(1),  I(1),  I(1)],   # 平凡
    [I(1),  I(-1), I(1),  I(1),  I(-1)],  # 符号
    [I(2),  I(0),  I(2),  I(-1), I(0)],   # 二维（S4/V4 = S3 拉回）
    [I(3),  I(1),  I(-1), I(0),  I(-1)],  # 三维标准 = 不动点数 - 1
    [I(3),  I(-1), I(-1), I(0),  I(1)],   # 标准 (x) 符号
]
audit("S4", 24, [1, 6, 3, 8, 6], [24, 4, 8, 3, 4], S4)
```
