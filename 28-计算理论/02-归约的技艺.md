# $\rm Chapter \, 2$ 归约的技艺：不可判定性的地图

第 1 章末尾留下的自引用操作，本章要连用四次。目标是一张地图：停机问题不可判定之后，还有成千上万个问题同样不可判定，它们不是各自独立被证明的，而是全部靠一台机器搬运过去。这台机器叫归约。学完本章你应当能自己把「某问题不可判定」这句话拆成两半：一个已知的不可判定源点，加一条明确写出的构造。

> **开始前自检**：本章假设你已经会：
>
> 1. □ 会陈述停机问题：不存在程序，对任意输入程序对 $(P, x)$ 判定 $P$ 是否停机（形式语言册 §5.2）；
> 2. □ 理解对角化的构造套路：假设判定器存在，用它造一个在关键点上唱反调的程序（形式语言册 §5.2）；
> 3. □ 知道「程序当数据」：机器编码 $\langle M \rangle$ 可以作为输入喂给程序，包括喂给它自己（§1.4）；
> 4. □ 见过 $\{a^n b^n\}$ 之类的上下文无关语言，知道下推自动机判定不了更强的语言（形式语言册 §3）。

## $\rm \S \, 2.1$ 归约：把困难搬运过去

**归约（reduction）**写成 $A \le B$，读作「$A$ 不难于 $B$」，意思是：假如手里有一个 $B$ 的判定器，就能造出 $A$ 的判定器。构造必须是一段明确写出的程序 $f$：把 $A$ 的实例转成 $B$ 的实例，使得二者的答案一致。此时若 $B$ 可判定，则「输入转 $f$，交给 $B$ 判定器」就是 $A$ 的判定器；于是 $A$ 可判定而 $B$ 不可判定是不可能的组合。用它证不可判定的方向是：找一个**已知**不可判定的 $A$，证明 $A \le B$，则 $B$ 不可判定。

方向记反是常见错误。$A \le B$ 里吃亏的是 $A$：$B$ 的判定器白送，$A$ 才能得救。所以「已知难的最难」的直觉要用对：停机 $\le B$ 说明 $B$ 至少和停机一样难。整章的地图都按这个方向画。

归约还有一个经常被忽略的约束：转换 $f$ 本身必须是**可计算的**。否则「用 $B$ 判定器造 $A$ 判定器」无从谈起，因为那段转换程序根本写不出来。可计算性的门槛极低（不设时间上限），但它把「数学上存在对应」与「构造上可执行」分开了。

**本节小结**：本节立好了搬运工具：$A \le B$ 的方向是「$B$ 的判定器白送，$A$ 得救」，且 $f$ 本身必须可计算；下一节先磨一个足够硬的源点，再开搬。

## $\rm \S \, 2.2$ K 语言：自我否定的对角线

先把源点磨亮。定义 **K 语言**。白话：K 收录的是那些「喂给自己的编号、反而不停机」的程序——编号既是程序又是输入，对角线正好踩在这个位置：

$$
K = \{ e \mid \text{第 } e \text{ 号程序在输入 } e \text{ 上不停机} \}
$$

K 的定义里只有自引用，没有别的材料。证明 $K$ 不可判定用对角化：假设 $D$ 判定 $K$，构造程序 $N$：读入 $e$，问 $D(e)$，答「不停机」就立刻停机，答「停机」就原地死循环。$N$ 是合法程序（$D$ 的存在是假设，但构造里调用它的代码合法）。把 $N$ 自己的编号喂给它：$N(\langle N \rangle)$ 停机 $\iff$ $D(\langle N \rangle)$ 判「不停机」$\iff$ $N(\langle N \rangle)$ 不停机。两边等价推出矛盾，假设作废。这个形状你已见过（形式语言册 §5.2），本章要把它用熟。

对角化之后，归约立刻接手。用 K 造停机问题的判定器：给定 $(P, x)$，构造程序 $Q$，它无视自己的输入、一门心思执行 $P(x)$，然后**假设层**的代码长这样（Python）：

```python
def HALT_decider(P, x):              # 假设 K_decider 存在
    Q = Prog('Q', lambda inp: P.fn(x))   # 无视输入, 只做 P(x)
    return not K_decider(Q)          # Q 不停在<Q>上 <=> P 不停在 x 上
```

构造的核心是一条对角不变量：$Q$ 停在自己的编码上，当且仅当 $P$ 停在 $x$ 上（$Q$ 根本不看输入，两者是同一件事）。于是 `K_decider(Q)` 回答「$Q$ 不停在 $\langle Q \rangle$ 上」，取反即得 $P$ 停在 $x$ 上。K 判定器存在推出停机判定器存在，与源点矛盾，K 不可判定。

这条构造不依赖任何语义假设，可以放进一个「玩具世界」实测：玩具世界里只有 3 台行为已知的机器，K 判定器按定义兑现。对全部 $(P, x)$ 组合跑一遍，构造出的停机判定器 6 次判定与真值全部一致：

| 程序 | 输入 | 真值（$P(x)$ 停机？） | 构造判定器输出 |
| --- | --- | --- | --- |
| $M_1$（永远停） | 空串 | 是 | 是 |
| $M_1$ | `a` | 是 | 是 |
| $M_2$（永远不停） | 空串 | 否 | 否 |
| $M_2$ | `a` | 否 | 否 |
| $M_3$（空串停，其余循环） | 空串 | 是 | 是 |
| $M_3$ | `a` | 否 | 否 |

玩具世界当然证明不了现实里 $K$ 可判定，它核对的是**构造的逻辑管道**：只要 K 判定器存在，管道就通。注意 $M_3$ 那两行：管道必须对「行为依赖输入」的程序也正确，而构造里 $Q$ 恰好把 $P$ 的输入焊死成 $x$，这种不对称被原样搬进对角线。

**本节小结**：本节磨出了源点 K：对角化直接判它不可判定，又用「K 判定器造停机判定器」演示了归约管道的用法；下一节把这条管道批量复制。

## $\rm \S \, 2.3$ Rice 定理：给语义性质判死刑

源点一个就够搬一辈子。**Rice 定理（Rice's theorem）**把搬运动作批量完成：对程序语义性质的任何非平凡提问都不可判定。

表述前先分清两类性质。**语法性质**只看代码长什么样：程序里有没有 while、长度是否超过 100 行。**语义性质**只看行为不看长相：是否停机、输出是否为 42、接受的语言是否正则。Rice 定理断言：设 $\mathcal{P}$（花体 P，读作「性质 $\mathcal{P}$」，代表某个具体的语义性质）是程序的一个语义性质，且非平凡（有的程序有这性质，有的没有），则 $\{\langle M \rangle \mid M \text{ 有性质 } \mathcal{P}\}$ 不可判定。

证明草图是 $\S 2.2$ 管道的复用，先看主情形。设 $\mathcal{P}$ 非平凡，且「原地空转、什么也不做」的程序**没有**性质 $\mathcal{P}$（比如「会停机」类性质）。取一个有 $\mathcal{P}$ 的程序 $A$，对任意 $(P, x)$ 构造程序 $N$：先模拟 $P(x)$，若停机就转去执行 $A$。于是 $P(x)$ 停时 $N$ 与 $A$ 行为一致、有 $\mathcal{P}$；$P(x)$ 不停时 $N$ 一直空在模拟里、没有 $\mathcal{P}$。即 $N$ 有 $\mathcal{P}$ 当且仅当 $P(x)$ 停机，若 $\mathcal{P}$ 可判定就造出了停机判定器，矛盾。若空转程序反而有 $\mathcal{P}$（比如「不死循环」类性质），把 $A$ 换成**没有** $\mathcal{P}$ 的程序做同样构造，得到 $N$ 有 $\mathcal{P}$ 当且仅当 $P(x)$ 不停机，归约到 $\S 2.2$ 的 K（同样不可判定）。两个方向至少一个成立，构造的管道与 $\S 2.2$ 相同，只多包了一层「先模拟 $P(x)$」。

两个应用，都是竞赛或工程里真实想过的问题：

1. 「这段程序会不会死循环」：死循环与否是纯语义性质，非平凡（`while(1);` 死循环，`print(1);` 不会）。Rice 定理说任何测试工具都给不出完备答案，只能近似；
2. 「这段程序会不会输出 42」：同样是语义性质，同样非平凡。连「输出是否等于某个常数」都不存在判定器。

Rice 定理的适用边界也要记：它只管语义性质。语法性质（代码里有没有某条指令）当然可判定，扫描文本即可；带时间上限的提问（$P$ 在 $10^6$ 步内是否停机）也躲开了语义性质的定义，直接模拟就能判。Rice 定理杀死的是「就行为论行为、无任何资源限制」的提问。顺带一提，Rice 定理还有一个常被当成独立定理的推论：判定两段程序是否**行为等价**也是语义性质、非平凡，同样不可判定，重构与编译器优化里的「改动前后行为一致」只能靠测试逼近，没有一锤定音的检查器。

**本节小结**：本节把归约管道升级成批发：任何非平凡语义性质都不可判定；边界也要记牢，带语法特征或资源上限的提问不在射程内。

## $\rm \S \, 2.4$ PCP 与第十问题：地图的边疆

源点不必只有停机问题一个。**波斯特对应问题（Post Correspondence Problem，PCP）**给定一组骨牌，每张牌上半与下半各印一个串，问能否取一个可重复的序列，让上串连写与下串连写完全相同。两块牌的最小实例，取 $X = (\text{上}1,\ \text{下}11)$、$Y = (\text{上}11,\ \text{下}1)$，暴力搜索到长度 4，找到 8 个解，最短的解长 2：序列 ${XY}$ 上串 $1{+}11 = 111$，下串 $11{+}1 = 111$，相同；序列 ${YX}$ 同理（长度 1 无解，程序同时核对了这点）：

```python
doms = [('1', '11'), ('11', '1')]     # (上串, 下串)
top = ''.join(doms[i][0] for i in seq)   # seq 是牌号序列
bot = ''.join(doms[i][1] for i in seq)   # 解存在 <=> 存在 seq 使 top == bot
```

换个实例：$X = (1, 111)$、$Y = (10011, 0)$，这是 Post 的经典无解对。长度账先给一道紧箍咒：每张 $X$ 让上串比下串短 2，每张 $Y$ 让上串比下串长 4，解存在要求两种牌严格按 ${2:1}$ 取用；再加内容约束，0 只能经 $Y$ 进入上下两半，而 $Y$ 上串里 0 后面跟着 011、下串里 0 后面什么都没有，位置永远错位。两条约束合起来把所有候选序列堵死（严格证明超出本章，这里只取它的地图位置）：PCP 一般情形不可判定，归约自停机问题，构造较长。它的价值在形态：一个纯组合问题，与程序毫无字面联系，照样不可判定。

再远一站。希尔伯特第十问题问：能否给出算法，判定任意整系数多项式方程（**丢番图方程（Diophantine equation）**）是否有整数解。1970 年 Matiyasevich 补齐最后一步（在 Davis、Putnam、Robinson 的框架上），答案是「否」：这样的一步通用算法不存在。只述史不展开：它的证明把整系数多项式锻造成一台图灵机，可判定性被归约链从停机问题一路传了过来。

到此把本章的地图正式画出来，全部节点与搬运路径：

1. 停机问题：不可判定（源点，形式语言册 §5.2）；
2. K 语言：不可判定（对角化直接证，§2.2）；
3. 一切非平凡语义性质：不可判定（Rice 定理批量搬运，§2.3）；
4. PCP：不可判定（归约自停机问题，§2.4）；
5. 丢番图方程：无通用判定算法（Matiyasevich，§2.4）。

每个节点的证明都拆成「上游节点 + 一段可计算构造」，地图因此可以继续往下游画：你遇到任何一个新问题，先问它像不像这条链上的某个节点。

这张地图有一条暗线贯穿：对角化。康托尔 1891 年用「第 $n$ 个集合在第 $n$ 位上唱反调」证明实数不可数；哥德尔 1931 年让命题谈论自身的可证性；图灵 1936 年让程序对自身的停机行为唱反调。三件事同一个骨架：编号一切对象，在编号等于内容的位置上做反向构造。第 3 章时间层次定理的证明会再演一遍这个骨架，只是这次唱反调的不是「是否停机」，而是「是否够快」。

## $\rm \S \, 2.6$ 应用与辨析

1. 有人声称：「我证明了 $A \le B$ 且 $A$ 不可判定，所以 $B$ 可判定时 $A$ 的判定器可以从 $B$ 搬运过来。」这段话哪里接反了？
2. 「程序是否在 1 秒内停机」可判定吗？它怎么躲开 Rice 定理？
3. 假设某语义性质 $\mathcal{P}$ 只有唯一一个程序具有（其余都没有）。Rice 定理还适用吗？
4. PCP 的可判定性对「牌数」敏感吗？两块牌、三块牌分别是什么局面？
5. K 语言与停机问题都不含「否定」，为什么 K 的对角化里出现了自我否定，而停机问题版本出现的是自我指涉？

## $\rm \S \, 2.7$ 本章自测答案

> 先闭卷作答 §2.5 与 §2.6，再核对。

### $\rm \S \, 2.7.1$ 关键概念回顾答案

1. 存在可计算映射 $f$，使实例 $w \in A$ 当且仅当 $f(w) \in B$；等价地，有 $B$ 的判定器就能造 $A$ 的判定器。证 $B$ 不可判定要选已知不可判定的 $A$（如停机问题或 K）并证 $A \le B$。（§2.1）
2. $Q$ 无视自己的输入，行为就是把 $P$ 跑在 $x$ 上：$Q(\langle Q \rangle)$ 执行的是 $P(x)$，无论输入是什么。停与不停只由 $P(x)$ 决定。（§2.2）
3. 语法性质如「代码里是否出现 `goto`」；语义性质如「是否停机」「接受的语言是否正则」。Rice 定理杀的是非平凡的语义性质。（§2.3）
4. $P(x)$ 不停：$N$ 一直停在模拟里，谈不上性质 $\mathcal{P}$（视取的性质方向而定，构造保证 $N$ 无 $\mathcal{P}$）；$P(x)$ 停：$N$ 转而执行 $A$，与 $A$ 行为一致，有 $\mathcal{P}$。所以「$N$ 有 $\mathcal{P}$」等价于「$P(x)$ 停机」。（§2.3）
5. 长度 2 的解 ${XY}$ 或 ${YX}$，连写串都是 $111$；长度 1 无解。（§2.4）
6. 康托尔：第 $n$ 个实数在小数展开第 $n$ 位；哥德尔：编号 $\langle p \rangle$ 被命题 $p$ 自己谈论；图灵：程序以自己的编码 $\langle N \rangle$ 为输入。（§2.4）

### $\rm \S \, 2.7.2$ 应用与辨析答案

1. 方向接反了。$A \le B$ 保证的是「$B$ 可判定 $\Rightarrow$ $A$ 可判定」；$A$ 不可判定时正确的推论是 $B$ 必不可判定，而不是 $B$ 可判定。（§2.1）
2. 可判定：直接模拟 $10^9$ 步，停了答「是」，没停答「否」。它带资源上限，超时即有确定答案，不问「最终行为」，所以躲开了 Rice 定理的「无限制语义性质」前提。（§2.3）
3. 适用。「非平凡」只要求有的程序有、有的程序没有；哪怕满足者唯一，仍是语义性质、仍非平凡。Rice 定理不看性质集有多大。（§2.3）
4. 敏感。两块牌时是可判定的（可穷举的组合有限）；一般牌数下不可判定。题目规模在这类问题里直接决定可判定性，而不只是决定快慢。（§2.4）
5. K 问的是「不停机」，判定器答反方向，构造 $N$ 才能在「答不停」时选择停机，制造自我否定；停机问题问「停机」，$N$ 对自身的行为直接构成矛盾，不需要先取反。两版论证同源，取反位置不同。（§2.2）
