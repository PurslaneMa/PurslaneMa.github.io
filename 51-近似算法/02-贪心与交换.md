# $\rm Chapter \, 2$ 贪心与交换：从匹配下界到 LPT

第 1 章把「证什么」立住了：造一个不超过 $\mathrm{OPT}$ 的下界证书 $\mathrm{LB}$。本章开始造。三件兵器里的第一件——**对立面证明**——有两条最朴素的路。一条是**贪心**：不回头，每步选局部最好的，赌整体不会太差。另一条是**交换**：拿算法解与最优解摆在一起，找到第一个分歧，局部改一步而不变坏，一步步把算法解「推」到最优解。本章四个主证——顶点覆盖、集合覆盖、LPT 调度、对称差上界——全是这两条路的样本；第 3 章才换用 LP 这把斤两。

## $\rm \S \, 2.1$ 顶点覆盖的 2-近似：匹配当下界

**白话**：顶点覆盖是「选最少的点，把每条边的两端至少按住一头」。贪心做法简单到近乎鲁莽——随便挑一条还没被按住的边，把它的两个端点都收进来，重复。它可能选多了，但绝不会选到最优的两倍以上，而且证明只有三行。

**定义**（顶点覆盖）。无向图 $G = (V, E)$，$C \subseteq V$ 是顶点覆盖，若每条边 $(u, v)$ 至少有一端落在 $C$（$u \in C$ 或 $v \in C$）。最小顶点覆盖问题求 $|C|$ 最小的覆盖，记最优值 $\mathrm{OPT}$。判定「是否存在大小 $\le k$ 的覆盖」是 NP 完全的，所以退而求近似。

**算法**（极大匹配法）。从 $E$ 里反复取一条两端都还没被选中的边 $(u, v)$，把 ${u, v}$ 都放进 $C$。直到没有这样的边为止。记算法取过的边集为 $M$。

**定理 2.1**（$2$-近似，全证）。算法输出的 $C$ 满足 $|C| = 2\,|M| \le 2\,\mathrm{OPT}$。

**证明**。三笔账，一笔一行：

1. **$M$ 是匹配**。每次取的边，两端此前都没被选、以后也不会再被选（进了 $C$ 就不再作为端点），所以新边与已取边不共享端点——$M$ 是一组互不相交的边。
2. **$C$ 是覆盖**。算法直到「没有两端都未覆盖的边」才停，即每条边至少一端已进 $C$——$C$ 合法。
3. **$|C| = 2|M| \le 2\,\mathrm{OPT}$**。前一个等式从构造来（每条选中边贡献两个端点）。后一个不等式：任取一个最优覆盖 $C^*$，它必须盖住 $M$ 的每一条边；而 $M$ 的边互不相交，一个点至多属于一条 $M$ 的边，故盖住 $|M|$ 条互不相交的边至少要点 $|M|$ 个。于是 $|C^*| \ge |M|$，即 $\mathrm{OPT} \ge |M|$。

把两半合起来：$|C| = 2|M| \le 2\,\mathrm{OPT}$。$\blacksquare$

**读法**：下界证书在第 3 步——$|M|$ 就是那个 $\mathrm{LB}$。它是「对立面证明」的标准形态：$M$ 是一组**互相独立的障碍**，每个障碍都要花掉最优解的一个点，于是障碍数成了 $\mathrm{OPT}$ 的地板。避开「对立面」这个词的说法是：**极大匹配把问题切成 $|M|$ 块，块之间没有共享的点可用**。第 2.4 节的对称差会把这套直觉一般化。

**算法选哪个极大匹配无所谓**。证明从头到尾没用到「边按什么顺序取」——任取一个极大匹配（无法再加边的匹配），结论都成立：$|C| = 2|M| \le 2\,\mathrm{OPT}$。这是好事，也是提醒：保证来自**极大性**这条结构性质，不来自任何择边技巧；想改进比值得换整个框架（第 3 章），而不是换取边顺序。$K_{n,n}$ 上不管怎么取，比值都逼近 $2$，正是这条「结构决定比值」的现场。

**数值锚（本机实测，蝴蝶结）**：5 个点、6 条边——两个三角形共用一个点（边集 $(0, 1), (1, 2), (0, 2), (2, 3), (3, 4), (2, 4)$），记共用点为 $2$。贪心按边序取 $(0, 1)$、$(2, 3)$，得覆盖 $\{0, 1, 2, 3\}$，$|C| = 4$；暴力枚举得 $\mathrm{OPT} = 3$（例如 $\{0, 2, 3\}$）。比值 $4/3 \approx 1.333$，与定理的上界 $2$ 差得远——但定理必须对**所有**图成立，这个例子只是实况。

**紧例（比值逼近 2）**：完全二分图 $K_{n,n}$，左、右各 $n$ 个点、所有 $n^2$ 条边都连通。最优覆盖恰是左侧全部 $n$ 个点（或右侧全部），$\mathrm{OPT} = n$。贪心只要先取到一条边，比如某个左点与某个右点，它就吃掉了 $2$ 个点，最终 $|C| = 2n$——比值 $2n/n = 2$。所以 $2$ 这个常数是**紧**的，$1/2$ 的保证没法靠小修小补提到 $2$ 以下太多。

**该知道的边界**：$2$ 不是随便的常数。已知（Dinur–Safra 2005 一脉的不可近似性）把顶点覆盖压到 $2 - \varepsilon$ 会让 $\mathrm{NP}$ 塌缩到随机多项式时间，所以任何 $1.99$-近似都必须用新的数学。目前实用上最好的保证是 $2 - \Theta(1/\sqrt{\log n})$，离开 $2$ 一点点，代价是巨大的。第 3 章会用 LP 松弛再给一个 $2$-近似——同一常数，不同兵器。

**本节小结**：极大匹配同时给出一个可行覆盖（代价 $2|M|$）和一个下界证书（$\mathrm{OPT} \ge |M|$），两头一夹得 $2$-近似；$K_{n,n}$ 证明 $2$ 是紧的。

## $\rm \S \, 2.2$ 集合覆盖贪心：调和级数记账

**白话**：集合覆盖是「用最少的几袋子东西，把一张清单上的元素全盖住」。贪心每步都是选「还能新盖最多元素」的那袋子。它可能略亏，但亏得有限——亏掉的是个调和级数，也就是一个对数。

**定义**（集合覆盖）。全集 $U$（$|U| = n$）与集合族 $\mathcal{F} \subseteq 2^{U}$，选最少的集合 $S_1, \dots, S_g \in \mathcal{F}$ 使 $\bigcup_i S_i = U$，记最优值 $\mathrm{OPT} = k$。它是顶点覆盖的推广（每条边一个元素、每个点一个集合）。

**算法**（贪心）。维护已覆盖集 $\mathrm{cov}$；每步选使 $|S \setminus \mathrm{cov}|$ 最大的 $S$，更新 $\mathrm{cov}$，直到 $\mathrm{cov} = U$。

**定理 2.2**（$(H_n + 0) \le (\ln n + 1)$-近似，全证）。贪心用集合数 $g$ 满足 $g \le H_n \cdot k \le (\ln n + 1)\,k$，其中 $H_n = 1 + 1/2 + \cdots + 1/n$，$\mathrm{OPT} = k$。

**证明（逐元素摊账）**。设 $r_t$ 为第 $t$ 步之前尚未覆盖的元素数，$c_t$ 为第 $t$ 步贪心新盖住的元素数。关键观察：**剩下这 $r_t$ 个元素，仍能被 $\mathrm{OPT}$ 的那个最优解覆盖**——把 $k$ 个最优集合里与剩余元素相交的那些拿出来，它们的并集恰是剩余元素（因为最优解覆盖全 $U$）。所以它们的平均覆盖量 $\ge r_t / k$，贪心挑的那个（最大者）至少盖 $c_t \ge r_t / k$。

现在给元素记账：一个元素在它**被覆盖的那一步**记上一笔 $1 / c_t$。一步里 $c_t$ 个元素各记 $1/c_t$，这一步的总账恰是 $1$——于是全部元素的总账等于步数 $g$（每步一个集合）。

另一侧，按元素单独估这笔账的上界。把元素按覆盖顺序编号 $e_1, \dots, e_n$：$e_i$ 被覆盖时，它和它之后的 $n - i + 1$ 个元素都还没被覆盖，故 $r_t \ge n - i + 1$，于是那一笔

$$
\frac{1}{c_t} \;\le\; \frac{1}{r_t / k} \;=\; \frac{k}{r_t} \;\le\; \frac{k}{\,n - i + 1\,}
$$

对所有元素求和：

$$
g \;=\; \sum_{i=1}^{n} \frac{1}{c_{t(e_i)}} \;\le\; \sum_{i=1}^{n} \frac{k}{n - i + 1} \;=\; k \sum_{j=1}^{n} \frac{1}{j} \;=\; k\,H_n
$$

末一步只是把下标 $j = n - i + 1$ 重排。再用 $H_n \le \ln n + 1$（把和看成 $\int_1^n \frac{dx}{x}$ 的阶梯近似）得 $g \le (\ln n + 1)\,k$。$\blacksquare$

**读法**：证明的骨架是「**每步至少盖掉剩余部分的 $1/k$**」——剩余问题本身也是个集合覆盖，规模缩到 $r_t$，最优仍不超过 $k$，所以贪心的那一步不会太亏。调和级数 $H_n$ 的出现，正是「每步以固定比例缩小剩余」这种几何收缩的累账。

**数值锚（本机实测，六元素三集合）**：$U = \{1, \dots, 6\}$，$\mathcal{F} = \{\{1, 2, 3\}, \{3, 4, 5\}, \{5, 6, 1\}\}$。贪心按次序取三个集合，$g = 3$；暴力枚举最优也是 $3$（任两个集合的并都漏掉一个元素）。比值 $1$；这个实例太规整，体现不出对数，但它把「贪心的选取与摊账」走了一遍。

**两个常用变体**（同一套摊账，改一两处即可）：

1. **加权集合覆盖**：每个集合带代价 $c_S$，贪心改选「单位代价新盖最多」的集合，比值仍是 $H_n$ 量级——摊账里把「1」换成「$c_S$」再逐项比即可。
2. **部分覆盖**：只需盖住至少 $t$ 个元素而非全部，贪心前 $t$ 步的记账一字不改，界照旧——因为摊账用的是「剩余元素」，不关心还剩多少。

**紧例（对数是真的）**：构造 $U$ 自上而下规模减半能逼出 $g \approx \ln n$ 的比值（教科书标准例）：上层放一个「大集合」盖住一半元素，下面几层各盖住剩余的一半，且每层的集合互相错位，逼贪心每步只能盖掉当前剩余的固定比例，累出来就是 $H_n$。这说明那道界不是虚设。集合覆盖的不可近似性也恰好卡在对数附近——把保证压到 $(1 - \varepsilon)\ln n$ 会让 $\mathrm{NP}$ 进 $O(n^{\mathrm{poly}\log n})$。对数就是它的天花板，这与第 1 章谱系里它落在 **log-APX** 一档完全对应。

**本节小结**：集合覆盖贪心每步盖掉剩余部分的 $1/k$，几何收缩累出一个调和级数 $H_n \le \ln n + 1$；这一档保证在对数，且本质上紧。

## $\rm \S \, 2.3$ 调度与交换论证（本章主证）

**白话**：$m$ 台机器、$n$ 个作业，每个作业有加工时间，把它们分给机器，让最晚收工的那台尽量早收工——这条「最晚收工时刻」叫**最大完工时间**（makespan）。LPT 贪心只有一句话：作业按时间从大到小排，逐个丢给当前最空的机器。

**定义**（最小化最大完工时间）。$n$ 个作业，加工时间 $p_1, \dots, p_n > 0$，$m$ 台机器（并行、同速）。一个排程把每个作业指给一台机器；某机器的负载是分给它的作业时间之和；makespan 是最大负载。记 $P = \sum_i p_i$，最优 makespan 为 $\mathrm{OPT}$。立刻有 $\mathrm{OPT} \ge P/m$（总工作量摊到 $m$ 台）与 $\mathrm{OPT} \ge p_1$（最大的作业总得占这么多）。

**算法**（LPT，Longest Processing Time first）。排序 $p_1 \ge p_2 \ge \cdots \ge p_n$，依次把 $p_i$ 指派给当前负载最小的机器。

**定理 2.3**（Graham 1969，$4/3 - 1/(3m)$-近似，全证）。LPT 的 makespan $L$ 满足

$$
L \;\le\; \left(\frac{4}{3} - \frac{1}{3m}\right)\mathrm{OPT}
$$

**证明（临界作业 + 两情形）**。设 $p_j$ 是使得某台机器达到负载 $L$ 的**临界作业**——它是最后放到那台机器上的，且该机器此前负载为 $L - p_j$。因为 LPT 把 $p_j$ 放到了当前最空的机器，**放 $p_j$ 之前每台机器的负载都 $\ge L - p_j$**，否则 $p_j$ 会去那台更空的机器。于是

$$
P \;\ge\; m\,(L - p_j) + p_j \;=\; m L - (m - 1)\,p_j
$$

移项得 LPT 的基本不等式

$$
L \;\le\; \frac{P}{m} + \Big(1 - \frac{1}{m}\Big) p_j
$$

下面分两种情形，把 $p_j$ 与 $\mathrm{OPT}$ 的大小关系代进去。

1. **情形 A：$p_j \le \mathrm{OPT}/3$**。由 $\mathrm{OPT} \ge P/m$，代入基本不等式：

$$
L \;\le\; \mathrm{OPT} + \Big(1 - \frac{1}{m}\Big)\frac{\mathrm{OPT}}{3} \;=\; \Big(\frac{4}{3} - \frac{1}{3m}\Big)\mathrm{OPT}
$$

2. **情形 B：$p_j > \mathrm{OPT}/3$**。此时所有作业 $p_i \ge p_j > \mathrm{OPT}/3$。在最优排程里，一台机器至多放 2 个作业（3 个之和就超过 $\mathrm{OPT}$ 了），故作业数 $n \le 2m$。作业数不超过机器数的两倍时，LPT **就是最优**：排序后最大的 $m$ 个作业各占一台机器，后续每个作业都被配到恰好能放下它的最空机器，与最优排程逐对一致（标准结论，标 Graham 原文）。于是 $L = \mathrm{OPT}$，当然满足要证的上界。

两情形合并即得 $L \le (4/3 - 1/(3m))\,\mathrm{OPT}$。$\blacksquare$

**交换论证方法论（本章要带走的手艺）**。定理 2.3 的手法叫**临界元素分析**，它是交换论证的近亲。把交换论证的通用模板摆出来：

1. 拿一个**最优解** $Y$ 和算法解 $X$，摆在同一边。
2. 若 $X = Y$ 结束；否则找**第一个分歧处**——某个元素/作业/点在 $X$、$Y$ 里被分到了不同的位置。
3. 在分歧处做一个**局部交换**：把 $Y$ 改一步，让它向 $X$ 靠近。
4. 证明交换后 $Y$ 仍可行、且代价**不变差**（这是全部难度的所在）。
5. 交换次数有限，最终 $X$ 被证明不劣于 $Y$，比值到手。

白话：**与其一次性证明贪心好，不如让最优解一步步向贪心解靠拢，每靠一步都不吃亏**。顶点覆盖的证明其实也藏着一个交换：把最优覆盖里「覆盖多条匹配边」的点与贪心解对齐。第 2.1、2.2 的证明都是这套模板的具体化，只是改造成了「直接数账」的手法。LPT 没有显式交换，但它同样在比较 $X$ 与 $Y$（临界作业使 $X$ 的负载被 $Y$ 的负载上下夹住），精神一致。

**第四步是全部难点**。前四步里，第一到第三步是体力活；真正要动脑的是第四步——交换后凭什么不劣？这一步往往依赖问题的**交换闭包**性质（把某个对象挪一挪，可行性还在），而不同问题的闭包形态各异。所以交换论证不是一条能套任何问题的公式，而是一套**提问方式**：先问「我的解与最优解第一个分歧在哪」，再问「在那里能不能顺手改一步」。养成这两个习惯，多数贪心分析的入口就打开了。

**它和临界元素的区别**。交换论证沿着「分歧」走，是**构造性**的——最后真的把 $Y$ 改造成 $X$；临界元素分析（LPT）走的是**比较性**的——不改造解，只在同一个作业 $p_j$ 上把两解的负载做不等式夹逼。两者都能收尾，选择哪条看问题的结构：解与解之间容易「挪」，用交换；有天然的「最后一步」或「关键元素」，用临界分析。

**数值锚（本机实测，紧实例）**：$m = 2$，作业时间 $(3, 3, 2, 2, 2)$，$P = 12$。LPT 排序后依次落位，得负载 $(7, 5)$，$L = 7$；暴力枚举最优是 $(6, 6)$，$\mathrm{OPT} = 6$。比值 $7/6 \approx 1.1667$，恰等于上界 $4/3 - 1/(3 \cdot 2) = 7/6$——**这个实例把界踩到了等号**，说明定理的常数不能随便改小。

**顺带一句对照**：如果连排序都省掉、任意顺序把作业丢给最空的机器（叫 list scheduling），比值只能到 $2 - 1/m$；仅仅加上「先做大作业」这一步，就把 $2$ 附近压到了 $1.33$ 附近。可见贪心的力量常藏在排序与优先级里，而不在「贪」字上。这也是第 2.1、2.2 里「按什么贪」比「贪不贪」更要紧的原因。

**本节小结**：LPT 的界 $4/3 - 1/(3m)$ 由「临界作业 + 两情形」得到；交换论证是它背后的通用手艺——第一个分歧处局部交换、不变坏、迭代收敛。这套模板下一节正式登场。

## $\rm \S \, 2.4$ 对称差上界：交替路径

**白话**：要比较「算法的解」与「最优解」，最通用的工具是把它们**叠加**起来看差异——只属于一边的集合叫对称差。对称差的结构极整齐：它是一堆交替的路径和圈。沿着这些路径数一数，比值自然浮出来。

**定义**（对称差）。两个解 ${X, Y}$，对称差 $X \mathbin{\triangle} Y = (X \setminus Y) \cup (Y \setminus X)$——恰被一个解包含的元素/边的集合。

**结构引理**（全证，三步）。设 ${X, Y}$ 是同一个匹配问题的两个匹配，则 $X \mathbin{\triangle} Y$ 分解为若干**互不相交的交替路径与交替圈**。

**证明**。看任意点 $v$ 在 $X \mathbin{\triangle} Y$ 里的度数：它至多在 $X$ 里连一条边、在 $Y$ 里连一条边，故度 $\le 2$（若在某解里不出现，度数更小）。度数处处 $\le 2$ 的图，每个连通块只能是**路径**或**圈**。再逐块看边的归属：路径/圈上的边在 $X$、$Y$ 之间交替出现（若同一解的两条边在块上相邻，它们就共享一个点、与「匹配」矛盾）。故块是交替的。$\blacksquare$

**它怎么给你比值**。Berge 定理（离散优化册第 5 章）就是这条引理的直接推论：若 $|Y| > |X|$，交替块里必有一条「$Y$ 边多于 $X$ 边」的路径，而这条路径恰是 $X$ 的一条增广路——沿着它翻转就变大。同一招用在本章的覆盖类问题上：

1. **顶点覆盖**：$X$ 是贪心覆盖、$Y$ 是最优覆盖。对称差里每个点的度数也 $\le 2$，交替路径/圈数一数，就能把「$|X|$ 比 $|Y|$ 多多少」摊到每条路径上——每条路径上两解的边数差至多 1，总差被路径数控制。
2. **极大匹配下界（§2.1 的第 3 步）**：把它读成对称差语言——$M$（贪心匹配）与 $C^*$（最优覆盖）虽不同类型，但「一条 $M$ 边最多被一个 $C^*$ 点覆盖」正是「$M$ 边在 $C^*$ 视角下无共享」的对称差读数。

这套账的**通用算式**是：把 $|X \setminus Y|$ 沿每个交替块分别数，块内两解的计数差被块长整除；把所有块的差加起来就是 $|X| - |Y|$ 的量级，于是比值被「块结构」框住。第 2.1 节的 $|C| = 2|M|$、Berge 定理的增广路、乃至后面第 3 章 LP 舍入的逐项核对，用的都是同一本账——只是记账对象从边换成了变量。

**读法**：对称差上界是**对立面证明的一般形状**。凡是「选一批互不相交的对象当障碍」的证明（匹配、覆盖、装箱、顶点删除），背后都能翻成一句「算法解与最优解的对称差被交替结构限制」。学会这一句，很多比值证明就不再是从零构造。

**本节小结**：对称差把两个解的差异拆成交替路径与圈（度数 $\le 2$ 的直接后果）；Berge 定理与本章两个下界都是它的一行读数——这是对立面证明的通用外观。

## $\rm \S \, 2.5$ 数值锚与程序段

三组锚，一段程序全算（本机实测）：

1. 顶点覆盖（§2.1）：蝴蝶结，贪心覆盖 $\{0, 1, 2, 3\}$、$4$ 个点，最优 $3$ 个点，比值 $1.3333$。
2. 集合覆盖（§2.2）：六元素三集合，贪心 $3$ 个集合，最优也是 $3$。
3. LPT 调度（§2.3）：$m = 2$、作业 $(3, 3, 2, 2, 2)$，LPT $= 7$、最优 $= 6$、上界 $1.1667$。

```python
import itertools
E = [(0, 1), (1, 2), (0, 2), (2, 3), (3, 4), (2, 4)]   # 蝴蝶结：两三角形共点 2
n = 5
used, match = set(), []
for (u, v) in sorted(E):
    if u not in used and v not in used:
        match.append((u, v))
        used.add(u)
        used.add(v)
opt_vc = min(k for k in range(n + 1)
             if any(all(u in S or v in S for (u, v) in E)
                    for S in itertools.combinations(range(n), k)))
print("cover =", sorted(used), "size =", len(used), "| optVC =", opt_vc,
      "| ratio =", round(len(used) / opt_vc, 4))

U = {1, 2, 3, 4, 5, 6}
SETS = [{1, 2, 3}, {3, 4, 5}, {5, 6, 1}]
covered, chosen = set(), []
while covered != U:
    i = max(range(len(SETS)), key=lambda i: (len(SETS[i] - covered), -i))
    chosen.append(i)
    covered |= SETS[i]
opt_sc = min(k for k in range(1, len(SETS) + 1)
             if any(set().union(*[SETS[i] for i in c]) == U
                    for c in itertools.combinations(range(len(SETS)), k)))
print("greedy sets =", chosen, "size =", len(chosen), "| optSC =", opt_sc)


def lpt(m, jobs):
    loads = [0] * m
    for p in sorted(jobs, reverse=True):
        loads[loads.index(min(loads))] += p
    return max(loads)


jobs = [3, 3, 2, 2, 2]
opt_ms = min(max(sum(p for p, a in zip(jobs, ass) if a == k) for k in range(2))
             for ass in itertools.product(range(2), repeat=5))
print("LPT =", lpt(2, jobs), "| OPT =", opt_ms,
      "| bound =", round(4 / 3 - 1 / 6, 4))
assert len(used) == 4 and opt_vc == 3 and len(chosen) == 3 and opt_sc == 3
assert lpt(2, jobs) == 7 and opt_ms == 6
```

实跑输出 `cover = [0, 1, 2, 3] size = 4 | optVC = 3 | ratio = 1.3333`、`greedy sets = [0, 1, 2] size = 3 | optSC = 3`、`LPT = 7 | OPT = 6 | bound = 1.1667`。读代码对照三处：顶点覆盖段里 `used` 就是算法输出的 $C$、`match` 是下界证书 $M$；集合覆盖段的 `while` 每轮取「新盖最多」的集合，正是 §2.2 的贪心；`lpt` 每次 `index(min(loads))` 找最空机器，`opt_ms` 用暴力枚举给最优值——三条锚与三个定理逐一对上。

**本节小结**：三组锚把本章三个定理各点验一次；代码与证明的结构一一对应（`used` = $C$、`min` 下界 = $|M|$、`index(min)` = LPT 选机）。

## $\rm \S \, 2.6$ 关键概念回顾

1. 顶点覆盖 $2$-近似里，$M$ 的「互不相交」为什么让 $\mathrm{OPT} \ge |M|$？下界证书是谁？（§2.1）
2. $K_{n,n}$ 为什么能把比值逼到 $2$？压到 $2 - \varepsilon$ 会付出什么代价？（§2.1）
3. 集合覆盖贪心的「逐元素摊账」中，为什么每步至少盖掉剩余部分的 $1/\mathrm{OPT}$？（§2.2）
4. LPT 定理证明的**临界作业** $p_j$ 为何满足「放它之前每台机器负载都 $\ge L - p_j$」？两个情形为什么要分开？（§2.3）
5. 交换论证的通用模板五步是什么？（§2.3）
6. 对称差的结构引理凭什么说「度数处处 $\le 2$」？它和 Berge 定理、极大匹配下界的关系？（§2.4）

## $\rm \S \, 2.7$ 本章自测答案

1. $M$ 的每条边都要被最优覆盖盖住，而互不相交使一个点至多盖一条，故 $|C^*| \ge |M|$；下界证书就是 $|M|$。（§2.1）
2. $K_{n,n}$ 上 $\mathrm{OPT} = n$、贪心给 ${2n}$，比值 $2$。压到 $2 - \varepsilon$ 会让 $\mathrm{NP}$ 塌缩到随机多项式时间，现有技术做不到。（§2.1）
3. 剩余的 $r_t$ 个元素仍能被最优解的 $k$ 个集合覆盖，平均每个盖 $r_t/k$，贪心挑最大的故至少 $r_t/k$。（§2.2）
4. LPT 总把作业放到当前最空的机器，$p_j$ 落到那台机器说明别处都不更空；情形 A 用 $\mathrm{OPT} \ge P/m$ 收口，情形 B 中每台机器至多 2 个作业、LPT 恰最优——两情形覆盖 $p_j$ 的所有可能。（§2.3）
5. 取最优解与算法解摆一起、找第一分歧、局部交换、证不变差、有限步收敛。关键在第四步「不变差」。（§2.3）
6. 每个点至多在 $X$ 连一条、$Y$ 连一条边，故度数 $\le 2$，连通块只能是交替路径或圈；$|Y| > |X|$ 时必有一条 $Y$ 边更多的交替路，即 $X$ 的增广路（Berge）；§2.1 第 3 步是同一读数。（§2.4）

**带走清单**：极大匹配当众下界（$|C| = 2|M| \le 2\,\mathrm{OPT}$）与 $K_{n,n}$ 紧例；集合覆盖贪心的调和级数摊账（$H_n \le \ln n + 1$）；LPT 的临界作业两情形与紧实例 $7/6$；交换论证五步模板；对称差的结构引理与「度数 $\le 2$」；三组实算锚（$4/3$、$3 = 3$、$7/6$）。
