# $\rm Appendix \, A$ 常用命令速查

> 本附录按章节顺序汇总正文中实际出现并解释过的命令。它不是命令字典——每条命令的作用、为什么存在、失败时说明什么，都以各章正文为准。这里只做快速定位：读到某条命令想不起它干什么，回来查这一行即可。

## 使用约定

1. **平台标注**：`（PowerShell）` 表示 Windows PowerShell 写法；`（Bash）` 表示 Linux/macOS 的 Bash/Zsh 写法；`（通用）` 表示两平台写法相同或工具自带。
2. **⚠️ 危险命令**：会删除、覆盖或不可恢复地修改文件/数据的命令。执行前先确认对象（先 `ls` 或 `Get-ChildItem` 看看匹配了什么），并优先使用可恢复的替代方案（正文原则：Git 撤销先讲可恢复方案；数据库修改先 `SELECT` 验证）。
3. **命令中的占位符**：`<container>`、`PID`、`alice@server` 等尖括号或大写单词表示你需要替换成实际的值。
4. **重定向与编码**：两平台的 `>` 都会覆盖目标文件；但 Windows PowerShell 5.1 的 `>` 默认写成 UTF-16，凡是给别的工具读的文本（`requirements.txt`、`.gitignore`、`backup.sql`）都会被下游读错（文件里出现 `42 00` 这样的零字节就是它）——小文件直接用编辑器建（`.gitignore` 见第 19 章），必须重定向时用 `| Out-File -Encoding utf8`（5.1 会带 UTF-8 BOM）或 `| Set-Content -Encoding utf8`；PowerShell 7+ 的 `>` 默认 UTF-8，没有这个问题（详见第 2 章）。
5. **平台与版本差异**：Bash 专属写法和需要 PowerShell 7+ 的写法都会在条目里说明；只标“通用”的表示两平台、5.1 与 7+ 都可用。
6. 全部命令均来自各章正文的代码块和行内代码，没有额外补充。正文中标记为反例的写法（如把 API Key 写进命令行）在本附录中标明“反例，勿用”。

## $\rm \S \, A.1$ 第 1 章：计算机、程序与开发全景

1. `Get-Location` — 显示当前工作目录（PowerShell）
2. `pwd` — 显示当前工作目录（Bash）
3. `Get-ChildItem` — 列出当前目录内容（PowerShell）
4. `ls` — 列出当前目录内容（Bash）
5. `g++ main.cpp -std=c++17 -Wall -Wextra -o sum` — 编译 C++ 源文件：`-std` 选语言标准，`-Wall -Wextra` 开警告，`-o` 指定输出文件名（通用，需已安装 g++）
6. `./sum.exe` — 运行当前目录中的编译产物，Windows 可执行文件需带 `.exe` 扩展名（PowerShell）
7. `./sum` — 运行当前目录中的编译产物（Bash）
8. `$LASTEXITCODE` — 查看上一条原生程序命令的退出码，`0` 表示成功（PowerShell）
9. `echo $?` — 查看上一条命令的退出码（Bash）
10. `show-args "my papers.txt" --limit 10` — 带空格参数运行程序：含空格的部分必须加引号（通用）

## $\rm \S \, A.2$ 第 2 章：终端、Shell 与命令行

1. `Get-Location` / `pwd` — 查看当前工作目录（PowerShell / Bash）
2. `Get-ChildItem` / `ls` — 列出当前目录内容（PowerShell / Bash）
3. `echo hello` — 让 Shell 打印文字；`echo "..." > file.txt` 可生成小文件（通用）
4. `Get-Content file` / `cat file` — 查看文本文件内容，适合小文件（PowerShell / Bash）
5. `Set-Location D:\projects` — 切换目录（PowerShell）
6. `cd D:\projects` — 切换目录，`Set-Location` 的常用别名（PowerShell）
7. `cd /home/alice/projects` — 切换目录；`cd ~` 回主目录（Bash）
8. `Get-Command python` — 查看输入的命令名实际解析到哪个可执行文件（PowerShell）
9. `command -v python` — 同上（Bash）
10. `./app.exe` / `./app` — 显式运行当前目录中的程序；多数 Shell 不默认在当前目录找命令（PowerShell / Bash）
11. ⚠️ `program > output.txt` — 把程序的标准输出写入文件，**会覆盖已有内容**（通用）
12. `program >> output.txt` — 把标准输出追加到文件末尾（通用）
13. `program < input.txt` — 从文件提供标准输入（Bash）
14. `Get-Content input.txt | ./program.exe` — PowerShell 给原生程序喂输入的可靠写法（PowerShell）
15. `producer | consumer` — 管道：左侧程序的输出接到右侧程序的输入（通用）
16. `Get-Process | Where-Object { $_.CPU -gt 10 }` — 按属性筛选对象管道（PowerShell）
17. `ps aux | grep python` — 文本管道：查找名字含 python 的进程（Bash）
18. `$LASTEXITCODE` / `echo $?` — 查看退出码（PowerShell / Bash）
19. `$env:PATH` — 查看单个环境变量（PowerShell）
20. `echo "$PATH"` — 查看环境变量，**必须加引号**避免被再次分词（Bash）
21. `$env:APP_ENV = 'development'` — 设置环境变量，只影响当前会话（PowerShell）
22. `export APP_ENV=development` — 同上（Bash）
23. `git log --oneline --max-count 5` — 命令结构示范：程序 `git` + 子命令 `log` + 选项（通用）

## $\rm \S \, A.3$ 第 3 章：文件系统、路径与权限

**路径验证与隐藏文件**

1. `Get-Location` / `pwd` — 当前目录（PowerShell / Bash）
2. `Test-Path "C:\Users\Alice\projects\data\papers.json"` — 路径是否存在，返回 True/False（PowerShell）
3. `ls /home/alice/projects/data/papers.json` — 文件存在则显示文件名，不存在报错（Bash）
4. `ls` / `ls -a` / `ls -A` — 普通列出 / 含 `.` `..` 全部列出 / 含隐藏文件但不含 `.` `..`（Bash）
5. `Get-ChildItem -Hidden` — 只查看隐藏项目（PowerShell）
6. `Get-ChildItem -Force` — 同时显示隐藏和非隐藏（PowerShell）
7. `Get-ChildItem *.cpp` — 当前目录下所有 `.cpp` 文件（PowerShell）
8. `Get-ChildItem -Recurse *.cpp` — 含子目录递归（PowerShell）
9. `ls *.cpp` — 当前目录下所有 `.cpp` 文件（Bash）
10. `find . -name "*.cpp"` — 递归查找，比通配符更可靠（Bash）
11. ⚠️ `rm *.log` — 删除当前目录下所有 `.log` 文件；先 `ls *.log` 确认匹配了什么再执行（Bash）
12. ⚠️ `rm -r test_*` — 递归删除所有以 `test_` 开头的目录及其内容（Bash）

**符号链接**

1. `New-Item -ItemType SymbolicLink -Path link_name -Target target_path` — 创建符号链接；Windows 上通常需要管理员权限或已开启“开发者模式”，否则报权限错误（PowerShell）
2. `ln -s target_path link_name` — 创建符号链接，注意参数顺序（Bash）
3. `Get-Item link_name | Select-Object Target` — 查看链接指向哪里（PowerShell）
4. `ls -l link_name` — 输出 `link_name -> target_path`（Bash）

**权限**

1. `whoami` — 当前用户名，排障第一步（通用）
2. `ls -l target` — 查看权限、硬链接数、所有者、组（Bash）
3. `stat target` — 更详细的权限信息：inode、块数、时间戳（Bash）
4. `namei -l /a/b/c/d/file` — 逐级解析路径每一层目录的权限，找出深层路径在哪一层被拦（Bash）
5. `Get-Acl target | Format-List` — 查看文件权限（PowerShell）
6. `chmod u+x script.sh` — 给 owner 加执行权限（Bash）
7. `chmod g-w data.txt` — 去掉 group 的写权限（Bash）
8. `chmod o-rwx secret.key` — 去掉 others 的全部权限（Bash）
9. `chmod 755 script.sh` — 数字模式：owner 全权限，group/others 读+执行（Bash）
10. `chmod 600 ~/.ssh/id_rsa` — 敏感文件仅所有者可读写（Bash）
11. `chown alice:staff file.txt` — 修改文件所有者与组，通常需要管理员权限（Bash）
12. `Format-Hex file.txt | Select-Object -First 2` — 查看文件开头的十六进制字节，`0D 0A` 连续出现即 CRLF（5.1/7+ 通用）。不要写 `Get-Content -AsByteStream`——那是 PowerShell 6+ 才有的参数，5.1 会报“找不到与参数名称匹配的参数”（PowerShell）

## $\rm \S \, A.5$ 第 5 章：编辑器、IDE 与调试器

1. `code D:\projects\paper-manager` — 用 VS Code 打开项目目录；示例是 Windows 路径，Bash 下换成 `code ~/paper-manager`（VS Code 命令行，两平台都有）
2. `g++ -g -std=c++17 -Wall -Wextra sum_array.cpp -o sum_array` — `-g` 把源码行号和变量名嵌入可执行文件，调试前必须加（通用）
3. `gdb ./sum_array` — 启动 GDB 调试器（Linux/macOS）
4. gdb 内部命令：`break sum` 设断点、`run` 运行、`print n` 查看变量、`step` 单步进入函数、`next` 单步跳过函数、`continue` 继续到下一断点、`backtrace` 查看调用栈、`quit` 退出（Linux/macOS）
5. `g++ -fsanitize=address -g program.cpp -o program` — AddressSanitizer：运行时检测越界、use-after-free、内存泄漏（通用，g++/clang++）
6. `g++ -fsanitize=undefined -g program.cpp -o program` — UBSan：检测整数溢出、空指针解引用（通用）
7. `g++ -fsanitize=thread -g program.cpp -o program` — ThreadSanitizer：检测数据竞争（通用）
8. `valgrind --leak-check=full ./program` — 不重新编译即可检测内存泄漏和未初始化值（Linux）

## $\rm \S \, A.6$ 第 6 章：文本、编码、压缩包与数据格式

**编码与换行**

1. `Format-Hex unknown.file | Select-Object -First 2` — 查看文件开头字节，判断文本还是二进制（5.1/7+ 通用；7+ 可用 `-Count 16`，5.1 没有该参数，且大文件不要直接跑——它会一直打到文件结尾）（PowerShell）
2. `file unknown.file` — 自动判断文件类型与编码，输出如 `ASCII text`、`UTF-8 Unicode text`、`PNG image data`（Bash）
3. `cat -A file.txt` — 显示行尾符号：`^M$` 是 CRLF，只有 `$` 是 LF（Bash）
4. ⚠️ `dos2unix file.txt` — 原地把 CRLF 换成 LF，**直接改写文件**（Bash）
5. ⚠️ `unix2dos file.txt` — 原地把 LF 换成 CRLF（Bash）

**压缩包**

1. `tar -xzvf archive.tar.gz` — 解压 `.tar.gz`：`x` 解包、`z` 自动处理 gzip、`v` 显示过程、`f` 指定文件（通用，Windows 10 1803+ 自带 tar）
2. `tar -czvf archive.tar.gz folder/` — 打包并压缩目录（通用）
3. `Compress-Archive -Path folder -DestinationPath archive.zip` — 打 ZIP 包（PowerShell）
4. `Expand-Archive -Path archive.zip -DestinationPath output` — 解 ZIP（PowerShell）

**搜索与校验**

1. `grep -E '20(1[7-9])\b' papers.txt` — 用正则 `-E` 搜索文本（Bash）
2. `sha256sum file.tar.gz` — 计算 SHA-256 哈希，校验文件完整性（Bash）
3. `md5sum file.tar.gz` — 计算 MD5 哈希（Bash）
4. `Get-FileHash file.tar.gz` — 默认 SHA256（PowerShell）
5. `Get-FileHash file.tar.gz -Algorithm MD5` — 指定算法（PowerShell）

## $\rm \S \, A.7$ 第 7 章：开发者命令行工具箱

**查看与搜索**

1. `less huge_papers.json` — 分页查看大文件：空格翻页、`/` 搜索、`q` 退出（Bash）
2. `Get-Content huge_papers.json | Out-Host -Paging` — 分页查看（PowerShell）
3. `more huge_papers.json` — 分页查看（PowerShell）
4. `head -n 10 papers.csv` — 前 10 行（Bash）
5. `tail -n 10 papers.csv` — 最后 10 行（Bash）
6. `tail -f server.log` — 实时追踪文件末尾新增内容（Bash）
7. `Get-Content papers.csv -Head 10` — 前 10 行（PowerShell）
8. `Get-Content papers.csv -Tail 10` — 最后 10 行（PowerShell）
9. `Get-Content server.log -Tail 10 -Wait` — 类似 `tail -f` 实时追踪（PowerShell）
10. `grep -r "connectTimeout" src/` — 递归搜索目录内容（Bash）
11. `grep -rn --include="*.cpp" "TODO" src/` — 带行号、限定文件类型（Bash）
12. `rg "connectTimeout" src/` — ripgrep：更快，默认递归、忽略 `.git` 和二进制（Bash）
13. `rg -l "connectTimeout" src/` — 只列出文件名（Bash）
14. `Select-String -Path "src\*.cpp" -Pattern "connectTimeout"` — 搜索文件内容（PowerShell）
15. `Get-ChildItem src -Recurse -Filter *.cpp | Select-String "connectTimeout"` — 递归搜索文件内容；`Select-String` 自身没有 `-Recurse` 参数，写上去会报“找不到与参数名称匹配的参数”（PowerShell）

**比较**

1. `diff old_version.cpp new_version.cpp` — 逐行比较两个文件（Bash）
2. `diff -u old_version.cpp new_version.cpp` — unified 格式，更易读（Bash）
3. `Compare-Object (Get-Content old.cpp) (Get-Content new.cpp)` — 比较两个文本文件（PowerShell）

**JSON 处理**

1. `cat papers.json | jq '.title'` — 提取 title 字段（Bash）
2. `cat papers.json | jq '.[] | {title, year}'` — 提取多个字段（Bash）
3. `cat papers.json | jq '.[] | select(.year > 2020)'` — 筛选（Bash）
4. `$papers = Get-Content papers.json | ConvertFrom-Json` — 解析 JSON 为对象（PowerShell）
5. `$papers | Select-Object title, year` — 选择字段（PowerShell）
6. `$papers | Where-Object { $_.year -gt 2020 }` — 筛选（PowerShell）

**打包、压缩、校验（速查集合）**

1. `tar -czvf archive.tar.gz folder/` — 创建 `.tar.gz`（Bash）
2. `zip -r archive.zip folder/` — 创建 ZIP（Bash）
3. `tar -tzvf archive.tar.gz` — 查看压缩包内容不解压（Bash）
4. `unzip -l archive.zip` — 查看 ZIP 内容（Bash）
5. `tar -xzvf archive.tar.gz` / `unzip archive.zip` — 解压（Bash）
6. `sha256sum downloaded_file.tar.gz` — 校验下载文件（Bash）
7. `Get-FileHash downloaded_file.tar.gz` — 校验下载文件（PowerShell）

**HTTP 与连通性**

1. `curl https://api.github.com/repos/torvalds/linux` — GET 请求，显示响应体（Bash，或 Git Bash）
2. `curl -i https://api.github.com` — 连响应头一起显示（Bash）
3. `curl -I https://example.com` — 只显示响应头（Bash）
4. `curl "https://api.example.com/search?q=transformer&limit=10"` — 带查询参数的 GET（Bash）
5. `curl -X POST https://api.example.com/papers -H "Content-Type: application/json" -d '{"title":"My Paper","year":2024}'` — POST JSON：`-X` 方法、`-H` 请求头、`-d` 数据（Bash）
6. `curl -O https://example.com/data.tar.gz` — 下载文件并保留远程文件名（Bash）
7. `curl -s https://api.example.com/data | jq '.results'` — 静默模式配合管道（Bash）
8. `Invoke-RestMethod https://api.github.com/repos/torvalds/linux` — PowerShell 中调用 REST API（PowerShell；注意 PowerShell 里 `curl` 是 `Invoke-WebRequest` 的别名，参数不同）
9. `nslookup api.example.com` — DNS 解析，查域名对应 IP（通用）
10. `ping api.example.com` — ICMP 连通性探测；部分服务器禁 ping 但服务正常（通用）
11. `nc -zv api.example.com 443` — 测试 TCP 端口是否开放（Bash）
12. `Test-NetConnection api.example.com -Port 443` — 同上（PowerShell）

**端口与进程**

1. `lsof -i :8080` — 列出监听 8080 端口的进程（Bash/Linux）
2. `ss -tlnp | grep 8080` — 更轻量的端口占用查询（Bash/Linux）
3. `ps -p PID -o pid,user,comm,args` — 按 PID 查看进程详情（Bash）
4. `Get-NetTCPConnection -LocalPort 8080` — 查端口占用，`OwningProcess` 列是 PID（PowerShell）
5. `Get-Process -Id PID` — 按 PID 查进程（PowerShell）
6. `ps aux | grep python` — 查找名字含 python 的进程（Bash）
7. `top` — 实时资源监控，`q` 退出（Bash/Linux）
8. `htop` — top 的增强版，需额外安装（Bash/Linux）
9. `Get-Process python` — 查看 Python 进程（PowerShell）
10. `Get-Process | Sort-Object CPU -Descending | Select-Object -First 10` — CPU 占用前十（PowerShell）

**磁盘**

1. `df -h` — 各分区使用情况（Bash）
2. `df -i` — inode 使用情况；磁盘有空间却报 No space left 时查它（Bash）
3. `du -sh folder/` — 某个目录的总大小（Bash）
4. `du -sh * | sort -hr` — 当前目录各项按大小降序（Bash）
5. `Get-PSDrive -PSProvider FileSystem` — 类似 `df`（PowerShell）
6. `Get-ChildItem folder -Recurse | Measure-Object -Property Length -Sum` — 类似 `du`（PowerShell）

**版本与路径**

1. `which python` — 可执行文件路径（Bash）
2. `python --version` — 版本号（通用）
3. `python -c "import sys; print(sys.executable)"` — Python 自身完整路径，最可靠（通用）
4. `Get-Command python | Select-Object Source` — 可执行文件路径（PowerShell）

**陌生工具探索与临时服务**

1. `tool --help`（或 `-h`、`-?`）— 看用法；`tool --version` 确认版本（通用）
2. `mkdir /tmp/tool-test && cd /tmp/tool-test` — 在临时目录做只读实验（Bash）
3. `python -m http.server 9999` — 当前目录起一个临时 HTTP 服务，用于验证端口/进程工具（通用）

## $\rm \S \, A.9$ 第 9 章：软件、运行时、SDK 与包管理器

**诊断调用的是哪个版本**

1. `Get-Command python | Select-Object Source` — 输入命令名实际解析到哪里（PowerShell）
2. `command -v python` — 同上（Bash）
3. `python --version` — 版本号（通用）
4. `python -c "import sys; print(sys.executable)"` — Python 自己的完整路径（通用）
5. `command -v pip` — 查看 pip 和 python 是否在同一路径下（Bash）
6. `python -m pip install numpy` — 通过 python 调用 pip，保证 pip 与 python 一致（通用）

**Python 虚拟环境（venv）**

1. `python -m venv venv` — 在 `venv/` 目录创建虚拟环境（通用）
2. `source venv/bin/activate` — 激活（Bash）
3. `venv\Scripts\Activate.ps1` — 激活（PowerShell；若报“禁止运行脚本”，是执行策略拦住的，见第 9 章 §9.3.5 的处理与其恢复方法）
4. `pip install requests` — 激活后安装包，只进入当前 venv（通用）
5. ⚠️ `pip freeze > requirements.txt` — 导出依赖清单，**覆盖目标文件**（通用）
6. `pip install -r requirements.txt` — 按清单重建环境（通用）
7. `pip install --upgrade numpy` — 升级单个包（通用）
8. ⚠️ `pip uninstall numpy` — 卸载包；不会清理缓存，也不检查其他包的隐性依赖（通用）
9. `pip install requests`（未激活 venv 时）— 装进系统 Python 的 site-packages，影响全局（通用，属“全局安装”反例场景）

**Node.js / npm**

1. `npm init -y` — 生成默认 `package.json`（通用）
2. `npm install express` — 安装依赖并写入 `package.json`（通用）
3. `npm install` — 按 `package-lock.json` 安装精确版本，新机器重建环境用（通用）
4. `node -e "console.log(require('./package.json').name)"` — 用 Node 求值一段代码验证环境（通用）

**Windows 系统级安装（winget）**

1. `winget install Python.Python.3.12` — 安装 Python 3.12（Windows）
2. `winget install OpenJS.NodeJS` — 安装 Node.js（Windows）

## $\rm \S \, A.10$ 第 10 章：计算机硬件速通

1. `lscpu` — CPU 架构信息（Linux）
2. `cat /proc/cpuinfo | head -20` — 每个逻辑 CPU 的详细信息（Linux）
3. `getconf -a | grep CACHE` — 缓存大小（Linux）
4. `Get-CimInstance Win32_Processor | Select-Object Name, NumberOfCores, MaxClockSpeed` — CPU 信息（Windows PowerShell）

1. ⚠️ `git restore parser.cpp` — 用暂存区的内容覆盖工作区文件（默认来源是暂存区，不是上次提交）：未 `git add` 过的修改就此丢失、无法找回（通用；想整体退回上次提交要先确认暂存区干净，细节见附录 E）
2. `git restore --staged parser.cpp` — 从暂存区移除（相当于取消 `git add`），修改保留在工作区（通用）
3. `git revert HEAD` — 撤销最近一次提交：创建新提交还原内容，历史不被删除，安全（通用）
4. `git revert abc1234` — 撤销指定提交（通用）
5. `git reset --soft HEAD~1` — 撤销最近提交，修改保留在暂存区（通用）
6. `git reset --mixed HEAD~1` — 撤销最近提交，修改保留在工作区（默认模式）（通用）
7. ⚠️ `git reset --hard HEAD~1` — 丢弃最近一次提交，并清空工作区（未提交的修改无法找回）；被丢弃的**提交**在 `git reflog` 过期或被 GC 清理前仍可用 reflog 找回（通用，见附录 E）
8. `git stash` — 临时保存未提交的修改，恢复干净状态（通用）
9. `git stash pop` — 恢复之前保存的修改（通用）

**历史考古**

1. `git blame parser.cpp` — 每一行最后是谁、在哪个提交中修改（通用）
2. `git show abc1234` — 查看特定提交的完整修改（通用）
3. `git diff main..add-csv-import` — 两个分支的全部差异（通用）
4. `git diff --name-only main..` — 只看改了哪些文件（通用）
5. `git branch -d feature-name` — 删除已合并的分支；未合并的分支会被拒绝（通用）

10. `docker compose build` / `docker compose up -d` / `docker compose ps` / `docker compose logs -f backend` — 贯穿项目容器化阶段的完整命令序列（通用，见 A.30）
11. `docker cp` — 容器与宿主机之间复制文件；正文复盘指出备份数据应优先 volume 映射而非 `docker cp`（通用，见 A.30）
12. `curl http://127.0.0.1:5000/api/papers` — 本地验收 API 返回 JSON（Bash，见 A.23）
13. `nslookup papers.example.com` — 部署后验证域名解析（通用，见 A.24）
14. `sudo journalctl -u paper-api -f` — 部署后实时跟踪服务日志（Linux，见 A.13）
15. `tail -f /home/deploy/paper-manager/logs/api.log` — 应用自有日志文件（Bash，见 A.7）

## 危险命令总览

执行前确认对象、优先可恢复方案。全部危险命令按章节列出：

**删除/覆盖文件**

1. ⚠️ `program > output.txt` — 重定向覆盖（A.2）
2. ⚠️ `pip freeze > requirements.txt` / `sqlite3 papers.db .dump > backup.sql` / `pg_dump paperdb > backup.sql` / `echo "..." > .gitignore` — 各类覆盖式重定向（A.9、A.27、A.19）
3. ⚠️ `rm *.log` / `rm -r test_*` / `rm -rf cpp-parser/build` — 删除文件与目录（A.3、A.21）
4. ⚠️ `dos2unix` / `unix2dos` — 原地改写文件（A.6）

**卸载/删除软件与容器**

1. ⚠️ `pip uninstall`、`sudo apt remove/purge/autoremove`、`winget uninstall`（A.9、A.13）
2. ⚠️ `docker rm` / `docker rmi` / `docker compose down` / `docker compose down -v`（A.30）

**不可恢复的版本与进程操作**

1. ⚠️ `git restore <file>`、`git reset --hard` — 丢弃未提交的修改（无法找回）；`reset --hard` 丢掉的**提交**在 reflog 过期/GC 之前仍可找回（A.19、附录 E）
2. ⚠️ `kill -9 PID` — 强制终止，进程无法保存现场（A.11）
3. ⚠️ `dd if=/dev/zero of=...` — 覆盖目标区域，只在临时环境演练（A.13）

**修改系统状态**

1. ⚠️ `sudo make install` — 写系统目录（A.13）
2. ⚠️ `ssh-copy-id` — 修改远程服务器的认证文件（A.14）
3. ⚠️ `chown`、`sudo systemctl edit`、`sudo certbot` — 修改所有权/系统配置，先说明影响与恢复方式再执行（A.3、A.13、A.31）
