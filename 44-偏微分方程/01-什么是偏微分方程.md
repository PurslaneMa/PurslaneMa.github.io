# $\rm Chapter \, 1$ 什么是偏微分方程：三原型与分类

常微分方程（连续数学册第 9 章）问的是「这条曲线长什么样」；偏微分方程问的是「这张曲面、这场时空演化长什么样」。一个未知函数、两个以上自变量、方程里出现偏导数——就这一句话的差别，让解的存在、唯一、稳定性和求法全部换血。本章立好全册的地图：三个原型方程（热、波、Laplace）、按判别式的三分类、线性叠加原理、边界条件三型。后面五章全是这张地图上的深耕。

## $\rm \S \, 1.1$ 从 ODE 到 PDE：解的概念升级

ODE $y'(x) = f(x, y)$ 的解是一个函数 $y(x)$——一条曲线。PDE 的解是一个**多变量函数**。例：

$$
\frac{\partial u}{\partial t} = \frac{\partial^2 u}{\partial x^2}
$$

读法：$u(x, t)$ 是「位置 $x$ 处、时刻 $t$ 的温度」，左边是温度的时间变化率，右边是温度剖面的二阶空间导。这个方程叫**热方程**，解 $u(x, t)$ 是一整个时空曲面。三个立刻能体会的升级：

1. **初始数据是函数**：ODE 给一个初值 $y(x_0) = y_0$（一个数）；PDE 要给整条初始剖面 $u(x, 0) = u_0(x)$（一个函数）。
2. **解空间无穷维**：ODE 的解由有限个常数参数化；PDE 的解由一个任意函数参数化——这才是 Fourier 级数登场的根本原因（第 5 章）。
3. **「一般解」几乎不存在**：ODE 有通解概念；PDE 极少数才有闭式通解（波动方程算一个，第 3 章）。方法论从「找通解」转向「针对原型逐个击破＋数值」（第 6 章）。

**本节小结**：PDE 的解是时空曲面；数据是函数；一般解不存在——这三件事决定了全册的打法。

## $\rm \S \, 1.2$ 三原型与判别式分类

全册的三个主角，物理身份一句话各领走：

1. **热方程**（抛物型）：$u_t = \kappa\, u_{xx}$——扩散，温度趋于均匀，未来被「抹平」。
2. **波动方程**（双曲型）：$u_{tt} = c^2\, u_{xx}$——振动，扰动以速度 $c$ 传播，过去的信息永远在路上。
3. **Laplace 方程**（椭圆型）：$u_{xx} + u_{yy} = 0$——稳态，边界决定一切，体内处处「最平滑」（第 4 章）。

二阶线性 PDE 的一般形：

$$
A u_{xx} + 2B u_{xy} + C u_{yy} + \text{低阶项} = 0
$$

按判别式 $\Delta = B^2 - AC$ 分类：$\Delta < 0$ **椭圆**、$\Delta = 0$ **抛物**、$\Delta > 0$ **双曲**。

**为什么这个判别式说了算**（读法）：二阶主部像一张二次型 $A\,p^2 + 2B\,pq + C\,q^2$（${p, q}$ 是对偶频率变量，第 5 章 Fourier 变换的视角）。二次型的惯性定理把对称矩阵 $\begin{pmatrix} A & B \\ B & C \end{pmatrix}$ 分成正定/退化/不定三档，而「不定 ⟺ $\Delta > 0$」——双曲型的特征方向是**实**的（两族实特征线，第 3 章 d'Alembert 换元 $\xi = x + ct, \eta = x - ct$ 就是沿特征线切开），椭圆型的特征方向是复的（没有实传播方向——稳态没有「时间」）。分类不是贴标签，是**方程里有没有「传播」这回事**的代数判据。

混合型也真实存在：Tricomi 方程 $u_{yy} + x\, u_{xx} = 0$ 在 $x > 0$ 椭圆、$x < 0$ 双曲——跨音速空气动力学里的常客（亚音速区椭圆、超音速区双曲），一句话存档即可。

**分类练习：三个方程当场算**（系数一律按本章约定 $A u_{xx} + 2B u_{xy} + C u_{yy}$ 读，交叉项带 2）：

1. $u_{xx} + 2u_{xy} + u_{yy} = 0$：$A = 1$、$B = 1$、$C = 1$，$\Delta = 1 - 1 = 0$，**抛物**。左端其实是一个平方：$(\partial_x + \partial_y)^2 u = 0$——方程只「看得见」一个方向，沿 $x - y$ 的二阶导根本不出现。这正是一维热方程转了个角度：扩散型退化，一个实特征方向。
2. $u_{xx} - 4u_{xy} + u_{yy} = 0$：$A = 1$、$B = -2$、$C = 1$，$\Delta = 4 - 1 = 3 > 0$，**双曲**。二阶主部能因子分解成 $(\partial_x - (2 - \sqrt{3})\,\partial_y)(\partial_x - (2 + \sqrt{3})\,\partial_y)u = 0$——两个实因子对应两族实特征线，两列对开的行波在这里有了代数户口。物理直觉：一根各向异性绷紧的弦上的振动。
3. $3u_{xx} + u_{yy} = 0$：$A = 3$、$B = 0$、$C = 1$，$\Delta = 0 - 3 = -3 < 0$，**椭圆**。两个二阶导同号、没有实因子；坐标拉伸 $x' = x/\sqrt{3}$ 就把它归一成 Laplace 方程。物理直觉：稳态温度场，没有「传播」这回事。

记号提醒：有的书把一般形写成 $A u_{xx} + B u_{xy} + C u_{yy}$、判别式用 $B^2 - 4AC$——上面第 2 个方程在那套记号下是 $\Delta = 16 - 4 = 12$，双曲的结论不变；两套约定差一个因子 2 的记账方式，分类永远一致，本书从头到尾用带 2 的这版本。

**著名 PDE 一览表**（每行一个户口）：

| 方程 | 类型 | 物理 | 本册哪章 |
| --- | --- | --- | --- |
| $u_t = \kappa\, u_{xx}$ | 抛物 | 扩散、抹平 | 第 2 章 |
| $u_{tt} = c^2\, u_{xx}$ | 双曲 | 振动、有限速传播 | 第 3 章 |
| $u_{xx} + u_{yy} = 0$ | 椭圆 | 稳态、边界决定一切 | 第 4 章 |
| $u_t + (u \cdot \nabla) u = -\nabla p + \nu \Delta u$ | 抛物骨架＋非线性一阶项 | 流体动量输运（Navier–Stokes） | 不在本册：非线性项 $(u \cdot \nabla) u$ 撕掉叠加原理（§1.3），整套线性方法失效 |
| $\mathrm{i}\hbar\, \psi_t = -\frac{\hbar^2}{2m} \Delta \psi$ | 色散型（复系数，三类之外） | 量子波函数演化 | 不在本册：见 14-量子力学册 |

**本节小结**：三原型各管一种物理行为；判别式读的是二阶主部二次型；分类的实质是「有没有实传播方向」。

## $\rm \S \, 1.3$ 线性与叠加原理

算子 $L$ 线性：$L(\alpha u + \beta v) = \alpha L(u) + \beta L(v)$。线性 PDE 即 $L(u) = f$，$f = 0$ 称齐次。**叠加原理**：

1. 齐次方程的任意多个解线性组合仍是解；
2. 非齐次方程 $L(u) = f$ 的解 $=$ 一个特解 $+$ 齐次方程的任意解。

**为什么它是全册的许可证**（读法）：把复杂初始数据用 Fourier 级数拆成简谐波（第 5 章），每个简谐波各自解一个 ODE（时间部分），再把结果加回去——整个「分离变量」流程的合法性全押在叠加原理上。非线性 PDE（如 $u\, u_x + u_t = 0$ 的交通流方程）没有这张许可证，方法学整个不同——本册只走线性世界，出口处一句话登记非线性。

**本节小结**：线性 ⟹ 拆解-分别求解-拼回；这是分离变量的合法性证书。

## $\rm \S \, 1.4$ 定解条件：边界条件三型与适定性

PDE 只给「内部规律」，一条时空曲面要钉死还需要**定解条件**。时间方向给初条件（$u(x, 0) = u_0(x)$）；空间方向给**边界条件**，三型：

1. **Dirichlet**（第一类）：边界上给定 $u$ 的值——「边缘温度钉在零度」。
2. **Neumann**（第二类）：边界上给定法向导数 $\partial u/\partial n$——「边缘热流给定」；特别的 $\partial u / \partial n = 0$ 叫绝热（ insulated）。
3. **Robin**（第三类）：线性组合 $\alpha u + \beta \partial u / \partial n$ 给定——「按 Newton 冷却律与环境换热」。

**适定性**（Hadamard, 1902）三要件：解**存在**、解**唯一**、解**连续依赖**于数据（数据动一点，解只动一点）。第三条最容易被忽略也最要命：反向热方程（从 $t = 1$ 的温度剖面倒推 $t = 0$）存在且唯一——热方程正向是压缩、反向是放大——但高频误差指数爆炸，**不适定**，物理上不可实现。适定性不是学究气，是「这问题该不该交给计算机」的准入证（第 6 章数值格式的稳定性正是它的离散版）。

**分类有五行计算器，适定性没有**——这件事本身就有信息量。程序段（可当场复跑）：

```python
def classify(A, B, C):          # 方程 A u_xx + 2B u_xy + C u_yy = 0
    d = B*B - A*C
    return "椭圆" if d < 0 else ("抛物" if d == 0 else "双曲")

print(classify(1, 0, 0), classify(-1, 0, 1), classify(3, 0, 1))
```

实跑输出：`抛物 双曲 椭圆`（依次是热方程、波动方程、$3u_{xx} + u_{yy} = 0$）。分类是代数，五行就完事；适定性却要看方程**和定解条件的搭配**，没有一行的判别式。辛普森悖论式的演示：同一个 Laplace 算子，切法定解条件的方式一换，结论整个翻转——边界上只给 $u$（Dirichlet 问题）适定；边界上同时给 $u$ 与 $\partial u / \partial n$（Cauchy 型数据）立刻不适定。后者的小账本：给边界数据 $u_y(x, 0) = \frac{1}{n} \sin(nx)$（幅度随 $n \to \infty$ 趋零），对应的调和函数是 $u_n = \frac{1}{n^2} \sin(nx) \sinh(ny)$（逐项验证：$u_{xx} + u_{yy} = -\sin(nx)\sinh(ny) + \sin(nx)\sinh(ny) = 0$），它在 $y = 1$ 处取值 $\frac{\sinh n}{n^2} \to \infty$——数据动一点点，解炸上天，连续依赖死得干净利落。

**本节小结**：初条件管时间、边界条件管空间（三型各有物理身份）；适定性三要件里「连续依赖」是数值时代的隐形主菜。

## $\rm \S \, 1.5$ 全册地图与读法

1. 第 2 章**热方程**：热核 $G(x,t)$ 显式解全推导、最大值原理、无穷传播悖论——抛物型的温柔与诡异。
2. 第 3 章**波动方程**：d'Alembert 公式全推导、能量法守恒、有限传播速度——双曲型的刚性。
3. 第 4 章**Laplace 方程**：调和函数、均值性质、极值原理——椭圆型的优雅。
4. 第 5 章**分离变量**：把第 2—4 章的特解统一在 Fourier 级数的框架下——方法论的汇合点。
5. 第 6 章**数值 PDE**：有限差分、von Neumann 稳定性、CFL 条件——前三章理论在计算机上的回声。

读法建议：第 2、3 章对照读（一个是「抹平」、一个是「搬运」，对照表在 §3.3）；第 4、5 章对照读（椭圆型方程在 Fourier 语言里就是「没有时间部分」）。

## $\rm \S \, 1.7$ 本章自测答案

1. 解是时空曲面不是曲线；初始数据是函数不是数；一般解几乎不存在。（§1.1）
2. 热 $u_t = \kappa u_{xx}$ 抹平、波 $u_{tt} = c^2 u_{xx}$ 传播、Laplace $u_{xx} + u_{yy} = 0$ 稳态。（§1.2）
3. 二阶主部二次型的惯性——实特征方向有（双曲）还是没有（椭圆），即「传播」存在与否。（§1.2）
4. 把一般数据拆成简谐波、分别求解再拼回——线性叠加是这整套流程的合法性来源。（§1.3）
5. Dirichlet 给温度、Neumann 给热流、Robin 给换热律。（§1.4）
6. 存在、唯一、连续依赖；反向热方程解存在唯一但高频误差指数放大，坏在连续依赖。（§1.4）
7. $A = 1$、$B = 1$、$C = 2$，$\Delta = 1 - 2 = -2 < 0$，椭圆。要看的其实是对称矩阵 $\begin{pmatrix} 1 & 1 \\ 1 & 2 \end{pmatrix}$：特征多项式 $\lambda^2 - 3\lambda + 1 = 0$，两个特征值 $\frac{3 \pm \sqrt{5}}{2}$ 全为正，二次型正定。正交旋转是坐标变换，不改特征值的符号、只改它们的大小——$\Delta$ 的符号（从而类型）是旋转不变量。这也是「椭圆型没有实特征方向」与坐标系怎么摆无关的原因。（§1.2）
8. 先判型：$A = 0$、$B = \frac{1}{2}$、$C = 0$，$\Delta = \frac{1}{4} > 0$，双曲。求解分两步：$u_{xy} = \partial_y (u_x) = 0$ 说明 $u_x$ 不依赖 $y$，记 $u_x = \Phi(x)$；再对 $x$ 积分得 $u = F(x) + G(y)$。两个任意函数，一个挂在 $x$ = 常数族、一个挂在 $y$ = 常数族——恰是两族特征线，各驮一个。这正是第 3 章 d'Alembert 通解 $F(x + ct) + G(x - ct)$ 的零成本预演：换元后的波动方程就是 $u_{\xi\eta} = 0$（§3.2），两族特征线只是换了个名字。（§1.2、§1.3）

**与相邻章的接口**：回扣一侧——判别式的二次型读法（§1.2）用的是连续数学册第 5 章的 Hessian 语言；§1.3 许给 Fourier 级数的承诺由第 5 章 §5.3 兑现。出口一侧——第 4 章 §4.3 的均值性质把「椭圆 $=$ 体内处处最平滑」做成定理，§4.4 的极值原理是 §1.4 适定性在椭圆侧的化身；第 6 章 §6.3 的 von Neumann 分析把「连续依赖」翻成离散版：格式稳定，说的正是数值解连续依赖初始数据。
