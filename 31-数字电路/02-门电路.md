# $\rm Chapter \, 2$ 门电路：CMOS 如何用晶体管搭逻辑

上一章得到了三种开关：导线、见 1 就通的 NMOS、见 0 就通的 PMOS，以及「串联是与、并联是或」的接线规律。本章把开关装配成逻辑门。做法不是随手一接，而是一套纪律：每个输出在任何时刻要么紧接电源（读作 1）、要么紧接地面（读作 0），绝不悬空、绝不短路。遵守这套纪律的工艺叫 CMOS，今天几乎所有数字芯片都由它构成。

> **开始前自检**：本章假设你已经会：
>
> 1. □ NMOS 栅 1 导通、PMOS 栅 0 导通（§1.3）；
> 2. □ NMOS 传 1 打折、PMOS 传 0 打折（§1.3）；
> 3. □ 动态功耗公式 $P = C V^2 f$（计算机系统结构册 §1.2）；
> 4. □ 德摩根律与真值表枚举（竞赛通用）。

## $\rm \S \, 2.1$ CMOS：互补的上拉与下拉

CMOS 电路里，输出节点被两套开关网络夹在中间：上面经 PMOS 网络接电源 $V_{DD}$，下面经 NMOS 网络接地。两条纪律管住一切：

1. 上拉网络与下拉网络逻辑互补：任何输入组合下，恰好一个网络导通。导通的那个决定输出，另一个彻底断开；
2. 上拉只用 P 管，下拉只用 N 管。原因在 §1.3 的债里：NMOS 传 0 不打折，PMOS 传 1 不打折，各干各的拿手活。

名字里的 C 就来自这条纪律：CMOS 即互补 MOS（complementary MOS），P 网络与 N 网络像阴阳两半，逻辑上互为反面。门级仿真的核心由此只要几行：

```python
pull_up = lambda a, b: (a == 0) or (b == 0)   # NAND 上拉: 两只 P 管并联
pull_dn = lambda a, b: a and b                # NAND 下拉: 两只 N 管串联
out = 1 if (pull_up(a, b) and not pull_dn(a, b)) else 0
```


最简单的门是反相器，两只管：输入 $a$ 接一只 PMOS（上拉）和一只 NMOS（下拉）的栅极。$a = 0$ 时 PMOS 通，输出 1；$a = 1$ 时 NMOS 通，输出 0。NAND 用四只管：下拉是两只 NMOS 串联（$a$ 与 $b$ 都为 1 才通到地），上拉是两只 PMOS 并联（$a$ 或 $b$ 有 0 就通到电源）。按对偶规则把下拉网络反写（串换并、N 换 P）就得到上拉。NOR 同样四只管，连接方式与 NAND 互为镜像：上拉是两只 PMOS 串联，下拉是两只 NMOS 并联。Python 实跑核对（枚举输入，输出电平由「哪套网络导通」决定，上下拉同时导通记为冲突，都不导通记为悬空）：

| 门 | $a$ | $b$ | 上拉导通 | 下拉导通 | 输出 | 期望 |
| --- | --- | --- | --- | --- | --- | --- |
| NAND | 0 | 0 | 是 | 否 | 1 | 1 |
| NAND | 0 | 1 | 是 | 否 | 1 | 1 |
| NAND | 1 | 0 | 是 | 否 | 1 | 1 |
| NAND | 1 | 1 | 否 | 是 | 0 | 0 |

NOT（2 组输入）、NAND（4 组）、NOR（4 组）三只门全部枚举通过，且每个输入组合下上下拉严格互补，无一冲突、无一悬空。NOR 的晶体管级连接值得单看一眼，它与 NAND 互为镜像：

| 门 | $a$ | $b$ | 上拉导通 | 下拉导通 | 输出 | 期望 |
| --- | --- | --- | --- | --- | --- | --- |
| NOR | 0 | 0 | 是 | 否 | 1 | 1 |
| NOR | 0 | 1 | 否 | 是 | 0 | 0 |
| NOR | 1 | 0 | 否 | 是 | 0 | 0 |
| NOR | 1 | 1 | 否 | 是 | 0 | 0 |

上拉两只 PMOS 串联：只有 $a = b = 0$ 时才通到电源。悬空与冲突不是多余的分类：悬空是三态门（§2.4）的正常状态，冲突则是布线错误，真跑的仿真器把两者单独记，正文的门永远不出现这两种值。

**本节小结**：这一节定了 CMOS 的两条纪律（上下拉互补、P 上 N 下），并用它装配了 NOT、NAND、NOR 三只门。下一节解释为什么工厂只批量生产其中两只。

## $\rm \S \, 2.2$ 为什么积木是 NAND 与 NOR

NAND 有一条别的门没有的本领：它是天生的反相器。把两输入接在一起，$\text{NAND}(a, a) = \lnot a$。于是任何「与或」表达式都能用两级 NAND 搭出来。Python 实跑核对（先手算 $a=b=c=d=1$：内层两只输出 0、0，外层 NAND 得 1，右端亦为 1）：

```python
nand = lambda a, b: 1 - (a & b)
sop  = lambda a, b, c, d: nand(nand(a, b), nand(c, d))
# 穷举 16 组输入: sop(a,b,c,d) == (a&b) | (c&d)，全等
```

实跑结论：$\text{NAND}(\text{NAND}(a,b), \text{NAND}(c,d)) \equiv (a \land b) \lor (c \land d)$，16 组全等；NAND 接一只反相器得 AND，4 组全等；德摩根律的电路版也成立：$\text{NOR}(a, b) = \lnot a \land \lnot b$，即两个自反相 NAND（$\text{NAND}(a,a)$、$\text{NAND}(b,b)$）加一级与，4 组全等。两级 NAND 网络就能覆盖一切逻辑，这是「积木」资格的一半。

另一半是物理账。NAND 与 NOR 都是 4 管，但代价分布不同：NAND 的两只 PMOS 并联、两只 NMOS 串联；NOR 正相反。PMOS 弱（空穴迁移率约为电子的一半，§1.3），串联让弱者更弱，所以让 PMOS 并联的 NAND 天然占优。工程结论：标准单元库里 NAND 是最便宜的积木，NOR 次之，更复杂的门（如下拉 $a$ 串 $b$ 再并 $c$ 的 AOI 门）按需备用。第 3 章化简逻辑时，「偏爱 NAND」会直接决定电路形态。

门数为什么值得斤斤计较？§1.4 的两笔账在这里接上：每只晶体管占约 $0.005\,\mu\text{m}^2$ 的硅，乘上良率折扣才是真金白银。化简逻辑不是美学追求，是让同样的 die 塞下更多功能的经济学。

**本节小结**：这一节回答「积木为什么是 NAND 与 NOR」：逻辑上两级 NAND 覆盖一切与或式，物理上 NAND 让弱的 PMOS 并联不吃亏。积木选定了，下一节算用它们的电费。

## $\rm \S \, 2.3$ 功耗：静态与动态

CMOS 的招牌是静态功耗近似为零：稳态下上下拉恰好一通一断，电源到地之间没有通路，只剩微弱的漏电流。这是它淘汰掉一切「要靠持续拉电流表示电平」的旧工艺的原因。

功耗发生在翻转的瞬间。输出从 0 变 1，上拉网络给负载电容 $C$ 充电；从 1 变 0，这份电荷经下拉网络放掉。每次充放电从电源取走 $C V_{DD}^2$ 的能量，每秒翻转 $f$ 次就得到：

$$
P = C \cdot V_{DD}^2 \cdot f
$$

与计算机系统结构册 §1.2 的功耗墙是同一条公式：那一节说「电压降到 1 V 附近后降不动了」，电路层面的原因就在 $V^2$ 这个平方项。手算一笔账：一只负载 $50\,\text{fF}$ 的门，$V = 1\,\text{V}$、$f = 3\,\text{GHz}$，$P = 50 \times 10^{-15} \times 3 \times 10^9 = 0.15\,\text{mW}$。十亿只门若同时这样翻转就是 150 kW，芯片早就烧了；现实是任一时刻只有百分之几的门在翻转，功耗预算实际是「允许多少门同时翻转」的配额制。设计者在 §1.2 见过的每瓦性能，从这里开始就有了晶体管级的含义。

> **账本**：静态功耗是「养门」的钱，CMOS 几乎为零；动态功耗是「干活」的钱，按翻转次数计费。芯片的功耗预算在两者之间分配，第 5 章的时钟会把「计费周期」固定下来。

**本节小结**：这一节把功耗拆成两笔：CMOS 靠互补纪律几乎免掉静态账，动态账由 $P = C V^2 f$ 计费，而 $V^2$ 的平方正是 §1.2 功耗墙的电路层根源。下一节看 0/1 两值买来的另一件商品：抗噪。

## $\rm \S \, 2.4$ 噪声容限与三态门

把电压连续谱压成 0/1 两值，换来的是抗噪能力。约定 0.3 V 以下读 0、0.7 V 以上读 1，中间是未定区（1 V 供电的简化口径）。Python 实跑枚举一组受损电平，看门如何处置：

| 输入电平 | 读作 | 反相器输出 |
| --- | --- | --- |
| 0.00 | 0 | 1.0 |
| 0.25 | 0 | 1.0 |
| 0.50 | ? | 未定 |
| 0.75 | 1 | 0.0 |
| 1.00 | 1 | 0.0 |

0.25 这样的受损电平照样读 0，反相器输出的是满幅的 1.0：噪声在每一级被「重新整形」，不逐级累积。这是数字电路与模拟电路的分水岭：模拟信号过十级放大器，噪声也被放大十级；数字信号过一百级门，误差到不了第二级。未定区也不浪费：0.5 V 读不出来，正是第 5 章锁存器「禁止态」的伏笔。

门还有一个不常提的第三态。三态门（tri-state gate）加一根使能线：使能有效时输出等于输入，无效时输出进入高阻态 Z，相当于从电路里拔掉。把多个三态门的输出并接成一条总线（bus），同一时刻至多一个门使能，大家分时发言。配套的小器件是传输门（transmission gate）：一只 NMOS 与一只 PMOS 并联，NMOS 传 0、PMOS 传 1，§1.3 的打折债由此清偿；使能为 1 时双向导通。实跑核对：使能枚举两组，导通条件 $en = 1$ 成立。

**本节小结**：这一节先看 0/1 两值的抗噪红利——每级门把受损电平重新整形、误差不累积；再补上第三态 Z 与传输门，把 §1.3 欠的「打折债」清了。到此门电路的工具箱齐了，下一章开始用门搭能算数的电路。

## $\rm \S \, 2.7$ 本章自测答案

> 先闭卷作答 §2.5 与 §2.6，再核对。

### $\rm \S \, 2.7.1$ 关键概念回顾答案

1. 任何输入下上下拉恰好一通一断；上拉用 P 管、下拉用 N 管。病态输出：悬空 Z（三态门的正常状态）、冲突（布线错误）。（§2.1、§2.4）
2. 下拉两只 NMOS 串联，上拉两只 PMOS 并联。对偶规则：把下拉网络串换并、N 换 P，就得到逻辑互补的上拉。（§2.1）
3. NAND 自反相（NAND$(a,a) = \lnot a$），两级 NAND 即与或。形式：NAND(NAND$(a,b)$, NAND$(c,d)$)，16 组输入实跑全等。（§2.2）
4. PMOS 弱（空穴迁移率约为电子一半）；串联使弱者更弱。NAND 让 PMOS 并联、把串联的活交给较强的 NMOS，所以占优。（§2.2）
5. $C$ 是输出节点的负载电容，$V$ 是供电电压，$f$ 是翻转频率。稳态下电源到地无通路，只剩漏电。（§2.3）
6. 门把受损电平重新整形为满幅输出：0.25 V 读作 0 后，输出是干净的 1.0。每级都是再生的起点。（§2.4）

### $\rm \S \, 2.7.2$ 应用与辨析答案

1. $a = 0$ 时 N 管截止、P 管（栅 0 导通）把输出接地：输出恒 0；$a = 1$ 时 P 管截止、N 管把输出接电源：恒 1。输入与输出永远同相，「反相器」变成「同相器」，说明互补不只是防短路，还定极性。（§2.1）
2. 冲突。输出 1 的门经 PMOS 接电源、输出 0 的门经 NMOS 接地，电源到地出现低阻通路，大电流烧管或至少电平非法；这正是「同一时刻至多一个使能」的纪律来源。（§2.4）
3. 频率项：$3/2 = 1.5$，涨 50%；电压项：$(0.9/1)^2 = 0.81$，降 19%。合并 $1.5 \times 0.81 = 1.215$，净涨约 22%。平方项吃掉了频率账的一部分。（§2.3）
4. 该工艺稳态下要持续取电流维持电平，功耗正比于门数而不随翻转归零；CMOS 稳态无通路，静态功耗只剩漏电，集成度才能上规模。（§2.3）
5. 单用 NMOS 传 1 会打折（$V_{DD} - V_{th}$），单用 PMOS 传 0 会打折；并联后 0 与 1 各由不打折的那只管承载，满幅传输且双向导通。（§2.4）
