## $\rm \S \, 6.1$ 从叉积到谓词：分支树的地基

竞赛代码里 `cross(b-a, c-a) > 0` 写起来理直气壮，前提只有一条：坐标是整数，叉积精确，符号就是真符号。OJ 题目把这条前提免费送给你，真实系统不送。CAD 与碰撞检测的输入来自测量、建模或浮点运算本身，「恰好共线」「恰好共面」不是构造出来才出现的小概率退化，而是大量出现在构造边界上——两条边共享端点、网格沿对齐线切分、模型镜像拼接，全都把共线情形摆在算法必须作答的位置上。

先给这类函数一个名字。**谓词（predicate）**是返回值只有「正、零、负」三档的函数，它的全部信息就在符号里，数值大小不作数。几何里最基本的一条是**方向谓词（orientation predicate）**：$\operatorname{orient}(a,b,c)$ 返回叉积 $(b-a)\times(c-a)$ 的符号，回答「$c$ 在有向直线 $ab$ 的哪一侧」。凸包的每一次转向比较、扫描线的每一个事件、第 5 章求交的每一步判号，脚下踩的都是它。

谓词错一档，后果不是差一点，而是分支树塌方：凸包把凹点当凸点收进去，自交的多边形从此失去一切几何保证；扫描线事件顺序错一格，求交结果整段漏掉；求交判号错一次，一条本该命中的光线穿墙而过。这就是为什么工业几何库把「谓词永远给对符号」当作第一公理来经营——本章余下三节分别讲判交的严格分类、误差从哪来、以及应对的三级阶梯。

## $\rm \S \, 6.2$ 线段相交判定的严格版

竞赛版判交通常只写「两次跨立」，共线情形靠手感补丁。严格版把全部情形收进四个方向谓词：对线段 $ab$ 与 $cd$，记 $d_1=\operatorname{orient}(a,b,c)$、$d_2=\operatorname{orient}(a,b,d)$、$d_3=\operatorname{orient}(c,d,a)$、$d_4=\operatorname{orient}(c,d,b)$。$d_1d_2<0$ 表示 ${c,d}$ 严格分居直线 $ab$ 两侧（**跨立实验（straddling test）**），$d_3d_4<0$ 反向同理。四条共线补判各配一个「端点落框」检查：

```cpp
bool onSeg(P a, P b, P c) {              // 已知 c 在直线 ab 上：是否落在线段 ab 内
    return min(a.x,b.x) <= c.x && c.x <= max(a.x,b.x)
        && min(a.y,b.y) <= c.y && c.y <= max(a.y,b.y);
}
bool intersect(P a, P b, P c, P d) {     // 整数坐标下精确
    long long d1 = cross(b-a, c-a), d2 = cross(b-a, d-a);
    long long d3 = cross(d-c, a-c), d4 = cross(d-c, b-c);
    if (((d1>0&&d2<0)||(d1<0&&d2>0)) && ((d3>0&&d4<0)||(d3<0&&d4>0)))
        return true;                     // 双向严格跨立：规范相交
    if (d1==0 && onSeg(a,b,c)) return true;
    if (d2==0 && onSeg(a,b,d)) return true;
    if (d3==0 && onSeg(c,d,a)) return true;
    if (d4==0 && onSeg(c,d,b)) return true;
    return false;
}
```

九种符号组合的结局全部列得出来，一张表收干净：

| | $d_3d_4<0$ | $d_3d_4=0$ | $d_3d_4>0$ |
| --- | --- | --- | --- |
| $d_1d_2<0$ | 相交：交点在两线段内部 | 相交：触在 $ab$ 的一个端点 | 不相交 |
| $d_1d_2=0$ | 相交：触在 $cd$ 的一个端点 | 四点共线或端点接触：由四个 onSeg 分支定 | 不相交 |
| $d_1d_2>0$ | 不相交 | 不相交 | 不相交 |

读表的两个非平凡格子的道理各一句。$d_1d_2<0$ 且 $d_3d_4=0$：$cd$ 严格跨过直线 $ab$，而 $a$ 或 $b$ 落在直线 $cd$ 上——两直线交点唯一，所以那个端点就是交点，且严格落在 $cd$ 内部。$d_1d_2=0$ 且 $d_3d_4=0$：要么四点共线（相交判定化为一维区间重叠，onSeg 分支恰好覆盖），要么两直线只共享一个点，同样落进 onSeg 分支。注意这张表和这段代码只在符号可信时成立——整数坐标给出可信的符号，浮点坐标给不出，这正是下一节的主题。

## $\rm \S \, 6.3$ 浮点误差从哪来

把方向谓词喂给 double，三处误差接力。第一处是入口：坐标按「最近可表示数」舍入，$10^4$ 量级的坐标一步就带进约 $\mathrm{ulp}(10^4)\approx1.8\times10^{-12}$ 的偏差。第二处是乘法：$(b_x-a_x)(c_y-a_y)$ 与 $(b_y-a_y)(c_x-a_x)$ 各是 $10^8$ 量级的乘积，每个乘积再舍入一次，偏差约达 $\mathrm{ulp}(2\times10^8)\approx3\times10^{-8}$。第三处是相减：两个相近数相减本身精确（比值不超过 2 的浮点数相减可精确表示），但**灾难性消去（catastrophic cancellation）**的真意在这里——减法不制造新误差，它把前两处埋进乘积的旧误差原样暴露成结果的主体。本站连续数学分册第 1 章讲过 ulp 随量级增长与结合律失效，这里是它们最直接的几何后果：乘积 $2\times10^8$ 有 16 位有效数字，真实答案 $10^{-8}$ 量级，等于要求保住第 16 位之后的数字。

下面是可以当场复现的失败构造。三点几乎落在 $y=x+0.1$ 上，$C$ 沿法向只抬高 $\delta$，真实叉积用 Fraction 按十进制原样精确计算，double 按竞赛写法计算：

```python
from decimal import Decimal
from fractions import Fraction

A = (Decimal("10000.1"), Decimal("10000.2"))
B = (Decimal("20000.3"), Decimal("20000.4"))          # 直线 y = x + 0.1
C = (Decimal("30000.5"), Decimal("30000.6") + Decimal("2e-12"))

def cross(pts):
    (ax, ay), (bx, by), (cx, cy) = pts
    return (bx - ax) * (cy - ay) - (by - ay) * (cx - ax)

t = cross([(Fraction(x), Fraction(y)) for x, y in (A, B, C)])
v = cross([(float(x), float(y)) for x, y in (A, B, C)])
print(float(t), v)   # 输出 +2.00004e-08 -5.960464e-08：符号相反
```

| 抬高量 $\delta$ | 真实叉积（Fraction） | double 叉积 | 真实符号 | double 符号 |
| --- | --- | --- | --- | --- |
| $0$（恰好共线） | $0$ | $-8.9407\times10^{-8}$ | $0$（在线上） | $-$（右侧） |
| $2\times10^{-12}$ | $+2.00004\times10^{-8}$ | $-5.9605\times10^{-8}$ | $+$（左） | $-$（右） |
| $1\times10^{-6}$ | $+1.00002\times10^{-2}$ | $+1.000011\times10^{-2}$ | $+$（左） | $+$（左） |

读这张表抓三个事实。第一行：十进制下精确共线的三点，double 说「右侧」——方向谓词在最常见的构造边界上直接失守。第二行：真实答案 $2\times10^{-8}$，double 给 $-5.96\times10^{-8}$，符号完全由舍入噪声决定；而且算出的两个值 $-8.9407\times10^{-8}$ 与 $-5.9605\times10^{-8}$ 恰是 $\mathrm{ulp}(2\times10^8)=2.98\times10^{-8}$ 的 3 倍与 2 倍——结果被钉死在浮点格点上，噪声不是随机小数而是 ulp 的整数倍。第三行：$\delta$ 抬到 $10^{-6}$ 后信号盖过噪声，double 判对——判号的可信边界就在「真实叉积与乘积的 ulp 谁大」这条线上，而写代码时你不知道自己在线的哪一侧。

## $\rm \S \, 6.4$ 应对阶梯：从容差到精确谓词

**第一级：容差（tolerance）。** 把「等于零」换成「绝对值小于 $\varepsilon$」，是渲染、碰撞这类容忍近似误差的场景最常见的选择。先看它防住了什么、又放进了什么。同一类勘测数据分别用米和毫米记录，三个场景全部真实共线或真实偏移，double 判号与两档 $\varepsilon$ 的判定如下（均已实跑验证）：

| 场景 | 真实叉积 | double 叉积 | $\varepsilon=10^{-5}$ | $\varepsilon=10^{-2}$ |
| --- | --- | --- | --- | --- |
| S1：米制，三点精确共线 | $0$ | $-8.94\times10^{-8}$ | 共线 ✓ | 共线 ✓ |
| S2：毫米坐标，三点精确共线 | $0$ | $-9.38\times10^{-2}$ | 判出方位 ✗ | 判出方位 ✗ |
| S3：1 米线段旁 1 毫米的真偏移 | $10^{-3}$ | $1.000\times10^{-3}$ | 有方位 ✓ | 共线 ✗ |

不存在让三行全对的 $\varepsilon$：救 S2 需要 $\varepsilon>9.4\times10^{-2}$，救 S3 需要 $\varepsilon\le10^{-3}$，两头不可兼得。原因在结构而不在调参：叉积随线段长度缩放，毫米坐标把舍入噪声放大了六个数量级，而 1 毫米的真偏移在 1 米线段上只产生 $10^{-3}$ 的叉积——同一个 $\varepsilon$ 面对的两种「小」相差九个数量级。容差把一个数学事实（是否为零）换成了一个押注尺度的工程猜测，尺度的下限与上限都不由你控制。

**第二级：整型化。** 输入本来就是整数（或可无损放大量级）时，一切判号在整数域精确，这是竞赛的标准做法，也是它真正适用的唯一场景。精度换来的是溢出要自己数：坐标绝对值不超过 $10^9$ 时，坐标差不超过 $2\times10^9$，单个乘积不超过 $4\times10^{18}$，叉积绝对值不超过 $8\times10^{18}$；$2^{63}-1=9.223\times10^{18}$，`long long` 恰好装得下，余量约 13.3%。边界可以精确算出：坐标不超过 $2^{30}-1=1073741823$ 时叉积必不溢出，再大 1 就可能溢。写法上把差先算成 64 位再相乘：

```cpp
long long d = (long long)(b.x-a.x)*(c.y-a.y)
            - (long long)(b.y-a.y)*(c.x-a.x);
```

坐标超过 $2^{30}-1$ 时换 `__int128`，或直接用 Python 的任意精度整数做离线验证。注意两级前提：输入必须真是整数网格上的点，且上界已知——浮点输入硬取整只是把误差从判号搬进坐标本身。

**第三级：自适应精确谓词（adaptive exact predicate）。** Shewchuk 的 orient2d 给出工业级的答案：先用 double 算叉积，同时用浮点误差界理论算出一个由各乘积绝对值累成的「误差预算」$B$；若 $\lvert \mathrm{det}\rvert>B$，符号必定正确，直接返回；否则进入**扩展算术（expansion arithmetic）**——two-product 把每个乘法拆成和恰好等于原式的两个浮点数，逐级累加保住全部有效位，重算出精确符号。绝大多数输入走快路径，代价与普通 double 几乎相同；只有真正逼近退化的输入才触发慢路径，而慢路径给出的符号永远正确。CGAL 等工业几何库把这套谓词当作立身之本：谓词从此不会判错，最多判得慢一点。

## $\rm \S \, 6.5$ 接口：光线-三角形求交里的判号

第 5 章的 Möller–Trumbore 求交是一条判号链：$\lvert\mathrm{det}\rvert$ 过小判平行，${u,v}$ 落在 ${[0,1]}$ 判命中影子，$t\ge t_{\min}$ 判在正前方。这条链在近退化输入下的每一环都会踩到 §6.3 的坑。薄片三角形（sliver，三个顶点近共线的三角形）的真实 $\mathrm{det}$ 本身就在噪声量级，该命不该命全由舍入决定；光线恰好穿过两个三角形的共享边时，边界值 $u=0$ 或 $v=1$ 被 $\pm$ 噪声随机推过线，两个三角形都记命中或都不记，阴影里出现针孔或重影；掠射角下 $t$ 的相对误差被放大，深度图出现条纹。

工程对策分两档。渲染档用一致性偏移：同一条光线对相邻三角形用同一套 $\varepsilon$ 策略，让「判错」至少判得一致，避免针孔。严格档回到第三级谓词：把判号链的每个比较换成精确谓词，生产渲染器与 CGAL 的共同选择。第 5 章说「严格讨论留给第 6 章」，欠的就是这一句：没有可靠谓词，路径追踪在退化网格上不是慢，是错。

## $\rm \S \, 6.8$ 本章自测答案

> 先闭卷作答上面两节，再核对。

### $\rm \S \, 6.8.1$ 关键概念回顾答案

1. 谓词是只返回正、零、负三档符号的函数。上游算法（凸包、扫描线、求交）是由谓词驱动的分支树，一个谓词错档，分支走向改变，后续所有建立在「凸包不自交」「事件有序」上的保证一并失效，所以是塌方而不是误差累积。（§6.1）
2. $d_1,d_2$ 看 ${c,d}$ 相对直线 $ab$，$d_3,d_4$ 看 ${a,b}$ 相对直线 $cd$。$d_1d_2<0$ 说明 $cd$ 严格跨过直线 $ab$，$d_3d_4=0$ 说明 $a$ 或 $b$ 在直线 $cd$ 上；两直线交点唯一，故该端点就是交点，且严格落在 $cd$ 内部。（§6.2）
3. 入口坐标舍入、乘积舍入、相减暴露。两相近数相减按浮点规则本身精确，但它减掉的是两个各自带噪的乘积，真实信息在乘法那一步已经丢失；消去只是把丢失显形，所以名字叫「灾难性」而责任不在减法。（§6.3）
4. 容差前提是场景容忍近似误差，代价是押注尺度（S2、S3 不可兼得）；整型化前提是输入本为整数且上界已知，代价是溢出需自己数（坐标上限 $2^{30}-1$）；自适应谓词前提是接受实现复杂度，代价仅是退化输入上的慢路径。$\varepsilon$ 无解是因为 S2 的噪声 $9.4\times10^{-2}$ 与 S3 的信号 $10^{-3}$ 要求互相矛盾的上下界。（§6.4）
5. 先算 double 近似值与误差预算 $B$；$\lvert\mathrm{det}\rvert>B$ 时符号必有保证、立即返回，否则用扩展算术精确重算。$B$ 由各乘积绝对值按浮点误差界累出。（§6.4）

### $\rm \S \, 6.8.2$ 应用与辨析答案

1. 乘积 $10^8$ 量级、答案 $10^{-8}$ 量级时符号由舍入噪声决定（§6.3 表第二行），近共线的相邻点偶发触发，故对拍全过而真实数据偶发自交。浮点输入且要求正确时，适合第三级自适应精确谓词；若只是渲染且容忍近似，可退一级用容差并接受其失效模式。（§6.3、§6.4）
2. 装得下，但余量已收窄。坐标 $10^8$ 时差不超过 $2\times10^8$，叉积不超过 $8\times(2\times10^8)^2=3.2\times10^{17}$，仍在 $2^{63}-1\approx9.2\times10^{18}$ 内，约有 28 倍余量；精确界限是坐标不超过 $2^{30}-1=1073741823$，$10^8$ 距它还有一个数量级，再往上放大数据就必须换 `__int128`。（§6.4）
3. 光线过共享边时 $u=0$ 或 $v=1$ 的边界判号被噪声随机推过线，两三角形都记或都不记命中。渲染档：对同一条光线统一 $\varepsilon$ 与偏移策略，使相邻三角形判得一致；严格档：把边界判号换成精确谓词，符号不再漂移。（§6.5）
