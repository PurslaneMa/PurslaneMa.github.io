本博客提供一个本地图形化后台：

```text
http://localhost:4000/admin
```

常用操作：

- `文章`：查看、编辑已有文章。
- `新建文章`：创建新的 Markdown 文章。
- `页面`：管理关于页、搜索页等独立页面。
- `设置`：调整后台编辑器设置。
- `发布`：本地生成或部署相关操作；正式发布建议通过 Git 推送到 GitHub 后由 GitHub Actions 自动部署。

文章源码位置：

```text
D:\AI\github-blog\source\_posts
```

站点配置：

```text
D:\AI\github-blog\_config.yml
D:\AI\github-blog\_config.next.yml
```
