# $\rm Chapter \, 8$ 博弈的计算：PPAD 与相关均衡

纳什定理（本册 §1.4）说均衡存在，存在不等于找得到。把「找一个纳什均衡」当算法问题来定价，答案是复杂度类地图上的第三个台阶：既非 P 也非 NP，而是 PPAD。本章四步：两人博弈的专门算法一句话带过；用端点引理拆开 PPAD 的奇偶内核；引入比纳什均衡更好算的相关均衡；最后把零和与一般和的计算难度摆进一张对照表。

> **开始前自检**：本章假设你已经会：
>
> 1. □ NP 完全与「解存在但难找」的分界（计算机速通 §N 或本站计算理论册 §3–§4；§8.2 全文对比它）；
> 2. □ 图的度数：出边数与入边数（竞赛通用；§8.2 的端点引理只用到这个）；
> 3. □ 线性规划与单纯形法的名字（本册 §2.2 把零和博弈写成 LP；§8.3 的相关均衡同样是一个 LP）；
> 4. □ 混合策略与等利润法（本册 §1.4；§8.3 的手算例子用它核对）。

## $\rm \S \, 8.1$ 从存在到找到：Lemke–Howson 一句话

**Lemke–Howson 算法**（1964）：与单纯形法同族的转轴算法，在两人博弈上从一个人工起点出发沿一条「路径」追踪，终点必是一个纳什均衡。它是两人情形的专门利器，实践中常常很快，但最坏情形要走指数多步；而且它只管两人，三人及以上连这样的路径结构都没有。一般情形怎么办，要等 §8.2 的复杂度语言。

为什么路径的终点一定是均衡？把「双方各自的最佳应对可行域」想成两张加密的图，Lemke–Howson 沿着「有一个人不满足」的缺口往前走，每步修好一个人的约束、弄坏另一个人的，直到两边同时修好：那个自锁的点就是均衡。这个「沿着缺口走」的几何直觉在第 1 章的不动点证明里有它的兄弟，把它翻译成图论语言就是下一节的端点引理。

## $\rm \S \, 8.2$ PPAD：端点引理与第三个台阶

PPAD 的定义核心是一张图上两行的奇偶账。**端点引理**：设有向图上每个节点的出度与入度都不超过 1（这样的图必是若干条不相交的路径与环的拼盘），则「出度与入度不等」的节点（端点：只有出边的源头、只有入边的汇）必成对出现，每条路径一头一尾。手算小例：路径 $0\to 1\to 2$、路径 $3\to 4$、环 $5\rightleftharpoons 6$，各节点（出，入）依次为 ${(1,0),(1,1),(0,1),(1,0),(0,1),(1,1),(1,1)}$：源头恰两个（0 与 3），汇恰两个（2 与 4），环贡献零个端点，数目永远成对。证明只需要一笔账：把「出度减入度」对全图求和，每条边给尾加一、给头减一，总和恒为零；环上节点各自抵消，剩下的贡献全来自端点，故源与汇的数目相等。

**PPAD（Polynomial Parity Arguments on Directed graphs）**类把这句话变成搜索问题：给你一个指数大的**隐式图**（不给全图，给一个函数：输入节点、输出它的出边邻居），再给你其中一个端点，要你找出另一个端点。隐式图是关键：全图大到存不下，但局部可查，这正是纳什均衡搜索的形状。纳什定理的不动点证明可以改写成这种奇偶论证（计算经济学册 §7.2 的 Lemke–Howson 路径正是它的具象），于是「纳什均衡存在」翻译成「端点搜索有解」。**纳什均衡的计算是 PPAD 完全的**：两人情形归功 Chen–Deng（2006），多人情形归功 Daskalakis–Goldberg–Papadimitriou（2006/2009）。与 NP 的分工要背下来：

1. NP 的难建立在「可能根本没有解」上：SAT 的无解实例让验证者无从下手；
2. PPAD 的实例**保证有解**（端点成对、均衡存在），难在从指数大的空间里把它揪出来；
3. 两者一般认为互不包含，但都未证明，PPAD 常被读作「介于 P 与 NP 之间的第三个台阶」；完整类地图见本站计算理论册 §3、形式语言与自动机册 §9。

工程读法与 NP-hard 相同：别指望多项式算法通吃纳什均衡，例外情形（零和的 LP、势博弈的最佳响应必停机，见计算经济学册 §7.3）才是设计系统时该优先的结构。

## $\rm \S \, 8.3$ 相关均衡：信号装置下的无偏离

**相关均衡（correlated equilibrium, Aumann 1974）**在玩家之外放一台**信号装置（signaling device）**：它按公开分布 $p(a_1,\dots,a_n)$ 抽一个行动组合，私下告诉每人「你该出什么」。分布 $p$ 是相关均衡，当且仅当没有任何人在收到建议后想违抗：对玩家 $i$ 的每个行动 $a_i$ 与每个偏离目标 ${a_i'}$，

$$
\sum_{a_{-i}} p(a_i, a_{-i})\,\bigl[\,u_i(a_i, a_{-i}) - u_i({a_i'}, a_{-i})\,\bigr] \;\ge\; 0
$$

逐符号读：求和跑遍别人的行动；左边第一项是「服从建议」的期望支付，第二项是「违抗一次」的期望支付；不等式要求违抗无利可图。这组约束对 $p$ **线性**，所以相关均衡集是线性不等式组定义的多面体：找一个相关均衡是 LP，多项式时间。纳什均衡是它的特例（$p$ 取均衡策略的乘积分布），所以相关均衡更弱、集合更大、也更好算。

换个读法：把每个行动组合 $a$ 看成一个「事件」，事件发生的概率是 $p(a)$；约束说的是**每个被推荐行动的事件里，推荐都是对当事人条件期望的最优**。信号装置像一位有威信的调度员：只要每次广播都经得起被点名者的账本检验，威信就自动维持。若有额外目标（比如最大化总福利），直接在这组线性约束上加线性目标：

$$
\max_{p} \; \sum_{a} p(a)igl[u_1(a) + u_2(a)igr]
\quad 	ext{s.t.} \quad
	ext{无偏离约束},\; p \ge 0,\; \sum_a p(a) = 1
$$

线性目标加线性约束，最优解落在多面体的某个顶点上：相关均衡的「最好一个」同样是多项式的。

手算例子用性别战（本册 §1.4 的 ${(2,1)}$、${(0,0)}$、${(0,0)}$、${(1,2)}$ 矩阵）。信号装置掷均匀硬币：正面推荐（歌剧，歌剧）、反面推荐（足球，足球），$p=(\tfrac12,0,0,\tfrac12)$。四个偏离约束逐一验：收到「歌剧」的一方知道对方也收到歌剧，偏离到足球得 $0 < 2$（列方偏离得 $0<1$），不动；收到「足球」同理反向。四个约束全部严格通过：协调失败的博弈被一枚硬币治好了，这枚硬币就是「共同知识的相关信号」。再验一个不在集合里的点：均匀分布 $p=(\tfrac14,\tfrac14,\tfrac14,\tfrac14)$ 的四个约束值为 ${(0.25,-0.25,-0.25,0.25)}$，中间两个为负（被推荐去歌剧的人有一半概率撞上对方去足球），不是相关均衡。

## $\rm \S \, 8.4$ 数值实验与难度对照表

枚举相关分布验证多面体形状（纯 Python 3.12 实测，单纯形上步长 $\tfrac1{40}$ 的网格共 12341 个点，逐点检验四个偏离约束，过程确定性）：

```python
def ce_ok(U1, U2, p):            # 2x2 博弈，p=(p00,p01,p10,p11)
    p00, p01, p10, p11 = p
    row0 = p00*(U1[0][0]-U1[1][0]) + p01*(U1[0][1]-U1[1][1])
    row1 = p10*(U1[1][0]-U1[0][0]) + p11*(U1[1][1]-U1[0][1])
    col0 = p00*(U2[0][0]-U2[0][1]) + p10*(U2[1][0]-U2[1][1])
    col1 = p01*(U2[0][1]-U2[0][0]) + p11*(U2[1][1]-U2[1][0])
    return min(row0, row1, col0, col1) >= -1e-12
```

三个博弈各跑一遍网格，读数如下：

```text
BoS           feasible 1938 / 12341   含内部点，三维实心多面体
MatchPennies  feasible    1 / 12341   收缩成单点（均匀分布）
Degenerate    feasible   41 / 12341   全部落在 p10=p11=0 的线段上
```

1. 性别战：可行点 1938 个。点 ${(0.40,\,0.30,\,0.05,\,0.25)}$ 四个约束值 ${(0.50,\,0.15,\,0.30,\,0.20)}$ 全部严格为正：它周围一小圈都在集合内，集合是（三维）实心多面体；混合均衡的乘积分布 ${(2/9,\,4/9,\,1/9,\,2/9)}$ 恰在边界上（四约束全为零），§8.3 的硬币点也在其中，两个纯均衡之间的整条 ${(t,0,0,1-t)}$ 线段（网格上 41 个点全部可行）是其一维骨架；
2. 匹配便士：可行点 1 个，就是均匀分布：偏差约束把四面体压成一点，纳什均衡与相关均衡重合；
3. 退化实验（行方对「歌剧」严格占优、列方在行方去歌剧时恰好无差异）：可行点 41 个，全部落在 ${p_{10}=p_{11}=0}$ 的线段上：集合收缩成一维。多面体的维数随支付的退化程度走，无差异一格，维数掉一层。

| 博弈类型 | 均衡计算 | 用什么算 | 结构原因 |
| --- | --- | --- | --- |
| 零和（§2） | 多项式，LP | 线性规划对偶 | minimax 定理，利益完全对立 |
| 势博弈 | 多项式级，局部搜索必停 | 最佳响应动态 | 存在势函数严格下降 |
| 一般和两人 | PPAD 完全 | Lemke–Howson 最坏指数 | 端点引理只保存在性 |
| 相关均衡 | 多项式，LP | 一组线性无偏离约束 | 约束对分布线性 |

对照表的读法自下而上：相关均衡比纳什均衡「弱一档」却「好算一整档」，这不是巧合而是本章的中心命题：解概念放宽一点，约束从非线性（最佳应对是分段函数）回到线性，计算难度随之塌回 P。零和是最早的特例（§2），势博弈是结构特例（计算经济学册 §7.3），一般和纳什均衡卡在 PPAD 是常态而非缺陷：存在性由奇偶保证，可计算性没有同样的幸运。

## $\rm \S \, 8.5$ 关键概念回顾

1. 端点引理里「环不贡献端点」为什么重要？若图中全是环，搜索问题的答案是什么？
2. PPAD 完全与 NP 完全在「验证解」这一步有何不同？给纳什均衡写一个多项式时间的验证者可行吗？
3. 相关均衡约束里为什么对每个 $(a_i, {a_i'})$ 都要一条不等式，只查「最想偏离的一次」不够吗？
4. 性别战的硬币分布 ${(1/2,0,0,1/2)}$ 与两个纯均衡的凸组合 ${(t,0,0,1-t)}$：$t$ 取哪些值仍是相关均衡？
5. 零和博弈的纳什均衡集是乘积结构（两套安全策略各自任意混），这对「相关均衡集的维数」意味着什么？
6. 隐式图「不给全图、给邻居函数」对应搜索问题的什么约束？为什么这与纳什均衡搜索的形状相符？

## $\rm \S \, 8.6$ 应用与辨析

1. 交通调度台广播「路口 A 走高速、路口 B 走辅路」式的随机指令，司机服从。把该系统写成信号装置模型，并说明它比「各自设导航」多解决了什么。
2. 拍卖平台可以在竞价前公布一个相关信号。解释为什么这类信号能抬升卖家收入而不违反任何玩家的无偏离约束。
3. 蜈蚣博弈（§3.3）的逆向归纳均衡是 PPAD 意义上的难，还是另一种难？
4. 某游戏 AI 用迭代逼近纳什均衡总是震荡不收敛。参照 §8.4 对照表，给出两个可能的结构原因与两条对应的改造方向。
5. 相关均衡 LP 的最优目标值选「最大化总福利」时，解出的分布可能严格优于一切纳什均衡的福利。用性别战的硬币分布算一下总福利并与两个纯均衡比较。

## $\rm \S \, 8.7$ 本章自测答案

> 先闭卷作答 §8.5 与 §8.6，再核对。

### $\rm \S \, 8.7.1$ 关键概念回顾答案

1. 环上每个节点出度与入度恰为 1，不出端点；若给出的隐式图全是环，则任何节点都「出度等于入度」，搜索问题没有合法答案，这正是题目保证至少给一个端点的原因。（§8.2）
2. NP 的证书是解本身，多项式时间可验证；PPAD 的证书同样可以是「另一端点及路径」，验证也是多项式的。给纳什均衡写验证者可行：策略组合配上每人无单方偏离的逐项检验。差别不在验证而在存在性的来源：纳什均衡由奇偶论证保证存在，SAT 无解时验证无从谈起，PPAD 完全刻画的正是这种「保证有解却难找」的难度。（§8.2）
3. 信号装置是私下告知：别人收到什么建议我不知道，我的偏离动机要对「我的建议」条件化，每个可能的建议都对应一个独立局面，漏查任何一个都可能在那个局面留出违背的口子。（§8.3）
4. 一切 $t\in[0,1]$：被推荐「歌剧」时对方必是歌剧（${p_{01}=p_{10}=0}$ 截断了坏消息），偏离得 0 严格小于服从；$t=0$ 与 $t=1$ 退化为纯均衡本身。（§8.3、§8.4）
5. 乘积结构使任何乘积分布都是可行点，零和的均衡集若非单点则已含连续族；相关均衡集只会更大（乘积分布满足无偏离约束），维数不低于乘积结构给出的自由度。（§8.4）


6. 隐式图把「存不下」与「查得到」分开：全图指数大，但任一节点的出边可局部查询。纳什均衡正是这个形状：策略组合空间指数大，而任一组合「有无人想偏离」可局部检验，存在性定理再保证端点成对，于是搜索问题落进 PPAD 的模板。（§8.2）
### $\rm \S \, 8.7.2$ 应用与辨析答案

1. 调度台按相关分布私下建议各路口，司机间服从同一枚硬币：无偏离约束保证没人有动机违抗。它解决了「各自设导航」时协调到坏均衡的问题：导航是独立的随机化（乘积分布），调度台能产生相关的推荐，把概率质量挪到总代价低的组合上。（§8.3）
2. 公布信号让 bidder 的行动相关化，卖家可以把质量放在竞争激烈的实现上；每个 bidder 的无偏离约束仍在（信号只是信息，偏离的期望按条件概率重算过）。这正是相关性拍卖（提示：计算经济学册 §4 的关联机制）的入口。（§8.3）
3. 蜈蚣博弈是完美信息动态博弈，逆向归纳沿树一遍即得均衡，是多项式时间；它的难（§3.3 的实验裂缝）是行为与理论的偏差，不是计算复杂度。PPAD 难属于一般和同时行动的均衡搜索。（§8.2）
4. 原因一：博弈是一般和且非势博弈，最佳响应动态没有停机保证（对照表第三行）；原因二：迭代对象是混合策略的乘积族，而真均衡可能在相关均衡集的边界上。改造：换成零和近似（对手建模为最小化我方收益）走 LP；或改为学习动态，收敛到粗相关均衡即够用（计算经济学册 §7.4）。（§8.4）
5. 硬币分布 ${(1/2,0,0,1/2)}$ 的总福利 $\tfrac12\cdot 3 + \tfrac12\cdot 3 = 3$；两个纯均衡福利各为 3，混合纳什均衡（§1.4，两人各得 $\tfrac23$）福利 $2\times\tfrac23 = \tfrac43 \approx 1.33$。相关均衡把福利从协调失败里捞回来，顶到纯均衡水平且人人比混合均衡好。（§8.3）
