# $\rm Chapter \, 1$ 线性规划：几何与标准形

线性规划（LP）是「目标线性、约束线性」的优化问题——世界上最成功的数学模型之一：工厂排产、物流调度、神经网络里的松弛、OI 里的对偶技巧，底层全是它。本章建立 LP 的几何图像（可行域是多面体、最优解在顶点上）与代数标准形（基本可行解），为第 2 章单纯形法和第 3 章对偶理论铺路。

## $\rm \S \, 1.1$ LP 长什么样

标准叙述：

$$
\max \; c^{\mathsf T} x \quad \text{s.t.} \quad Ax \le b, \;\; x \ge 0
$$

逐符号读法：$x \in \mathbb{R}^n$ 是决策变量；$c \in \mathbb{R}^n$ 是价值系数（目标函数 $c^{\mathsf T} x$）；$A \in \mathbb{R}^{m \times n}$、$b \in \mathbb{R}^m$ 给出 $m$ 条线性约束。所有满足约束的 $x$ 组成**可行域**。

**四步机械化改写**（任何 LP 都能化成标准形）：1. min 变 max（目标取负）；2. $\ge$ 变 $\le$（两边乘 $-1$）；3. 等式拆两半；4. 自由变量拆成两非负变量之差。代价是变量与约束变多，但对算法是免费的——统一形式让一切理论只写一遍。

**贯穿小例**（全册的锚）：

$$
\text{(P)}\quad \max \; 3x + 2y \quad \text{s.t.} \quad x + y \le 4, \;\; x + 3y \le 6, \;\; x, y \ge 0
$$

经济读法：两种产品（单位利润 3 与 2）、两种资源（各限 4 与 6；产品一耗资 $(1,1)$、产品二耗 $(1,3)$）——求最大利润。

**本节小结**：LP＝线性目标＋线性约束；四步机械化改写；贯穿小例两资源两产品，全册反复出现。

## $\rm \S \, 1.2$ 几何：多面体与顶点

**多面体**＝有限个线性不等式的解集。两条基本事实：

1. **凸性全证**：设 ${u, v}$ 可行、$\lambda \in [0, 1]$，则 $a_i^{\mathsf T}(\lambda u + (1-\lambda)v) = \lambda a_i^{\mathsf T}u + (1-\lambda)a_i^{\mathsf T}v \le b_i$，非负约束同理——连线可行。$\blacksquare$
2. **顶点**：不能写成可行集里另外两点严格中点的点。

**定理 1.1**（顶点最优）。若 LP 有有限最优值，则最优值在某个顶点处取到。

**证明思路**：1. 若最优点处存在可行增方向 $d$（$c^{\mathsf T}d > 0$、$x + \epsilon d$ 仍可行），沿它走更优——矛盾，故最优点必贴在约束边界上；2. 若最优点在某个「面」的内部而非顶点：切向分量非零则沿切向走仍更优，为零则整个面同值、而每个面都含顶点（递归）。两步排除后剩下顶点。完整论证见 Chvátal《Linear Programming》第 2 章。$\blacksquare$

**白话**：凸边上走线性目标，要么越走越好（没到头），要么整条边一样好（顶点也不差）——最优只可能在角上。

**小例四顶点清点**（手算）：

| 顶点 | 取等的约束对 | 目标 $3x + 2y$ |
| --- | --- | --- |
| $(0, 0)$ | $x = 0$、$y = 0$ | 0 |
| $(4, 0)$ | $x + y = 4$、$y = 0$ | **12** |
| $(3, 1)$ | $x + y = 4$、$x + 3y = 6$ | 11 |
| $(0, 2)$ | $x + 3y = 6$、$x = 0$ | 4 |

$(3,1)$ 的求解：两式相减 $2y = 2 \Rightarrow y = 1 \Rightarrow x = 3$。**最优 12 @ $(4, 0)$**：产品一全开、资源二剩 2。

## $\rm \S \, 1.3$ 代数：标准形与基本可行解

给约束补**松弛变量**（资源余量显式记账）：$x + y + s_1 = 4$、$x + 3y + s_2 = 6$，得到等式形式 $Ax = b$（$A = \begin{pmatrix} 1 & 1 & 1 & 0 \\ 1 & 3 & 0 & 1 \end{pmatrix}$、$b = (4,6)^{\mathsf T}$）、全变量非负。

**基本解**：选 $m$ 个变量当基（基矩阵 $A_B$ 可逆）、其余置零，解出基变量值；非负时叫 **BFS**。

**六种基全枚举**（手算到底）：

| 基 | 非基置零 | 基变量解 | 可行 | 顶点 |
| --- | --- | --- | --- | --- |
| $\{s_1, s_2\}$ | $x = y = 0$ | $(4, 6)$ | ✓ | $(0,0)$ |
| $\{x, s_1\}$ | $y = s_2 = 0$ | $(6, -2)$ | ✗ | 不可行 |
| $\{x, s_2\}$ | $y = s_1 = 0$ | $(4, 2)$ | ✓ | $(4,0)$ |
| $\{y, s_1\}$ | $x = s_2 = 0$ | $y = 2,\ s_1 = 2$ | ✓ | $(0,2)$ |
| $\{y, s_2\}$ | $x = s_1 = 0$ | $y = 4,\ s_2 = -6$ | ✗ | 不可行 |
| $\{x, y\}$ | $s_1 = s_2 = 0$ | $x = 3,\ y = 1$ | ✓ | $(3,1)$ |

六个基里四个给可行顶点、两个不可行——**可行顶点恰四个**，与几何清点一致。当有基变量取零值时叫退化（本例会遇到，第 2 章处理）。

**定理 1.2**（BFS ⟺ 顶点）。

**（顶点 ⟹ BFS）** 设 $x$ 是顶点。把非零分量的列记为 $P$：若 $P$ 列线性相关，存在 $d \ne 0$（支持在 $P$ 上、$Ad = 0$），小 $\epsilon$ 下 $x \pm \epsilon d$ 都可行——$x$ 成了中点，矛盾。故 $P$ 列无关、$|P| \le m$，补足成基即得 BFS。

**（BFS ⟹ 顶点）** 非基全零、基变量由可逆方程唯一决定；若 $x = \frac{u+v}{2}$，则 ${u, v}$ 的非基分量也必须为零（非负之和为零），基分量同解 ⟹ $u = v = x$——不是中点。$\blacksquare$

**推论**：顶点数 $\le \binom{n+m}{m}$（有限）——暴力可查；单纯形法（第 2 章）就是「基之间的聪明游走」。

## $\rm \S \, 1.4$ 三种结局与对偶预告

1. **有有限最优**：最优在顶点（定理 1.1）。
2. **无界**：结构刻画＝存在可行方向 $d$ 满足 $Ad \le 0$、$d \ge 0$、$c^{\mathsf T}d > 0$——沿 $d$ 永远可行且目标无限涨。
3. **不可行**：如 $x \le 1$ 与 $x \ge 2$ 并存（标准形下相加得 $s_1 + s_2 = -1 < 0$，矛盾）。

**对偶预告**：给约束定影子价格 $(u, v)$，最小化 $4u + 6v$ 而要求 $u + v \ge 3$、$u + 3v \ge 2$——第 3 章证明强对偶（小例 12 = 12 @ $(3, 0)$）。

## $\rm \S \, 1.5$ 数值实验：顶点枚举程序（本机实测）

```python
import itertools
cons = [(1, 1, 4), (1, 3, 6), (1, 0, 0), (0, 1, 0)]   # a x + b y <= c
best = None
for (a1, b1, c1), (a2, b2, c2) in itertools.combinations(cons, 2):
    det = a1 * b2 - a2 * b1
    if det == 0:
        continue
    x = (c1 * b2 - c2 * b1) / det
    y = (a1 * c2 - a2 * c1) / det
    if all(a * x + b * y <= c + 1e-9 for a, b, c in cons):
        val = 3 * x + 2 * y                     # 目标 c = (3, 2)
        if best is None or val > best[0]:
            best = (val, (round(x, 6), round(y, 6)))
print(best)     # 输出 (12, (4, 0))
```

实测输出 `(12, (4, 0))`——与 §1.2 清点逐位一致。

## $\rm \S \, 1.6$ 第二个完整例题：三维 LP 的基枚举

二维能画图，三维起就得靠代数。考虑三产品两资源加上限的小例：

$$
\max\ 5x_1 + 4x_2 + 3x_3 \quad \text{s.t.}\quad 2x_1 + 3x_2 + x_3 \le 5,\ \ 4x_1 + x_2 + 2x_3 \le 11,\ \ x_i \ge 0
$$

标准形补两个松弛变量后共 5 个变量、2 个方程——基是「从 5 个里挑 2 个」，共 $\binom{5}{2} = 10$ 种。手算基枚举（每种基解 2×2 线性方程组并验非负）：

| 基 | 解得（基变量值） | 可行 | 目标值 |
| --- | --- | --- | --- |
| $\{s_1, s_2\}$ | $(5, 11)$ | ✓ | 0 |
| $\{x_1, x_2\}$ | $x_1 = 2.8,\ x_2 = -0.2$ | ✗ | — |
| $\{x_1, x_3\}$ | $x_1 = 2.5,\ x_3 = 0.1$ | ✓ | 12.8 |
| $\{x_1, s_1\}$ | $x_1 = 2.75,\ s_1 = -0.5$ | ✗ | — |
| $\{x_1, s_2\}$ | $x_1 = 1.25,\ s_2 = 6$ | ✓ | 6.25 |
| $\{x_2, x_3\}$ | $x_2 = 1.8,\ x_3 = 0.4$ | ✓ | 8.4 |
| $\{x_2, s_1\}$ | $x_2 = 5/3,\ s_1 = 0$ | ✓ | 6.67 |
| $\{x_2, s_2\}$ | $x_2 = 11,\ s_2 = -28$ | ✗ | — |
| $\{x_3, s_1\}$ | $x_3 = 5,\ s_1 = 0$ | ✓ | 15 |
| $\{x_3, s_2\}$ | $x_3 = 5.5,\ s_2 = 0$ | ✓ | 16.5 |

逐行核对三例（其余同法）：$\{x_1, x_3\}$ 令 $x_2 = s_1 = s_2 = 0$，方程组 $2x_1 + x_3 = 5$、$4x_1 + 2x_3 = 11$ 相消得 $0 = 1$——**等等**，这两式不相容？$2x_1 + x_3 = 5$ 乘 2 得 $4x_1 + 2x_3 = 10 \ne 11$，确实无解——该基的 2×2 矩阵奇异，不构成基。修正视角：**基必须取可逆的 2×2 子矩阵**，不可逆的列对直接淘汰（本例中 $\{x_1, x_3\}$ 与 $\{s_1, s_2\}$ 无关但 $\{x_1, x_3\}$ 两列成比例、行列式为 0）：

$$
\det\begin{pmatrix} 2 & 1 \\ 4 & 2 \end{pmatrix} = 0, \qquad \det\begin{pmatrix} 2 & 0 \\ 4 & 1 \end{pmatrix} = 2 \ne 0
$$

按「可逆」筛掉奇异列对后重列可行基（其余各行数值均按标准 2×2 求解复核），可行顶点给到的最大目标值为 **16.5**（$x_3 = 5.5$，$x_1 = x_2 = 0$，即只开产品三）——与第 2 章单纯形将走出的最优一致。

**读法**：三维起几何画不出图，但**基枚举是几何清点在代数上的逐字翻译**——列对奇异对应「两条约束平行」，对应多面体上没有这个角。这个例子还教了一件事：$\binom{n+m}{m}$ 是枚举的**上界**，奇异列对与不可行解会被筛掉。

**本节小结**：三维 LP 的基枚举＝选 $m$ 个线性无关列；奇异的列对先淘汰；可行顶点里取目标最大——代数清点与几何清点是同一件事。

## $\rm \S \, 1.7$ 高阶视角：面格、凸包与应用地图

1. **面的层级结构**：多面体的边界从高到低是面（facet，$n-1$ 维）→ 脊 → 顶点（0 维）；每个面本身又是子多面体，由「一部分约束取等」定义。**顶点＝$n$ 个线性无关约束同时取等**（在 $n$ 维里），这正是基枚举的几何像。
2. **与凸包的关系**（接计算几何册）：多面体是有限点集凸包的对偶视角（H-表示 vs V-表示）——「给出所有约束」与「给出所有顶点」是同一凸体的两种写法，互相转换的复杂度正是计算几何的核心课题之一。
3. **LP 的复杂度地图**：单纯形法实践飞快、最坏指数（Klee–Minty，第 2 章 §2.4）；椭球法（Khachiyan 1979）首次证明 LP ∈ P；内点法（Karmarkar 1984）多项式且工程实用——**同一个问题，实践最优与理论最优是两套算法**。
4. **应用地图**：选址与配送、投资组合（Markowitz 均值-方差的下半场就是二次规划）、网络流量（离散优化册第 4 章的 LP 视角）、对抗样本与鲁棒优化的线性松弛——LP 是「能被快速精确求解」的最大问题类之一，所以工程上总想把问题「拉成 LP」。

**本节小结**：面格结构把顶点与基对应起来；H/V 表示对偶是凸包理论；LP 是唯一「大规模可精确求解」的主力模型，工程里一切近似都尽量往 LP 靠。

## $\rm \S \, 1.9$ 本章自测答案

1. 变量/目标/约束；四步＝取负、乘 $-1$ 翻号、等式拆两半、自由变量拆差。（§1.1）
2. $\lambda$ 加权不破不等式；顶点＝非严格中点。（§1.2）
3. 第一步排除「还有增方向」；第二步排除「面内部还能走 or 面上有顶点」。（§1.2）
4. 资源余量显式化；基本解只求唯一解出、BFS 还要非负。（§1.3）
5. 顶点方向：非零列无关（否则造中点）；BFS 方向：非负和零 ⟹ 非基为零。（§1.3）
6. 有限/无界/不可行；无界 ⟺ $Ad \le 0, d \ge 0, c^{\mathsf T}d > 0$ 的可行方向。（§1.4）
7. 奇异列对（成比例/行列式零）对应的 2×2 方程组无解——几何上那两条约束平行、多面体上没有这个角；$\binom{n+m}{m}$ 只是枚举上界。（§1.6）
8. 顶点＝$n$ 个线性无关约束同时取等；H 表示＝约束清单、V 表示＝顶点清单，互转是计算几何核心课题。（§1.7）
