## $\rm \S \, 5.1$ 曲率从哪来：度量的二阶信息

第 4 章末说过：测地法坐标下一阶项消失、**二阶项才是曲率**。精确化：Gauss 曲率 $K$ 是「度量对欧氏的偏离速度」——在测地法坐标下 $g_{ij} = \delta_{ij} - \frac{K}{3}(x^i x^j \text{ 的迹修正}) + \cdots$，具体地 $g_{11} = 1 - \frac{K}{3} y^2 + \cdots$（$y$ 是切向偏移）：半径 $r$ 的测地圆周长

$$
C(r) = 2\pi r\, \Big(1 - \frac{K r^2}{6} + \cdots\Big)
$$

**读法**：站在弯曲世界量「半径 $r$ 的圆」，周长不再 $2\pi r$——正曲率（球面）周长偏小、负曲率（鞍面）偏大。**这一式子是「住在曲面里的二维生物不开口就能测出曲率」的全部依据**——曲率是内禀的，这是本章主定理的序曲。

## $\rm \S \, 5.2$ 三张标准面孔

1. **球面**（半径 $R$）：$K = 1/R^2 > 0$——测地线（大圆）汇聚，三角形内角和 $> \pi$（第 4 章 §4.3 的大圆三边上可实算：正三角形的内角和 $= \pi + 3\arccos(-\frac13) \times$ 归一化因子；具体：单位球正八面体面三角内角和 $\frac{3\pi}{2}$，球面角盈 $\frac{\pi}{2}$ 恰等于面积 $A$，即 **Gauss–Bonnet 特例** $A = \sum\alpha_i - \pi$）。
2. **平面**：$K = 0$——欧氏几何，内角和 $= \pi$。
3. **伪球/双曲面**：$K < 0$——测地线发散，内角和 $< \pi$，双曲几何的舞台。

**球面角盈锚**（可实算）：单位球上顶点 $(1,0,0), (0,1,0), (0,0,1)$ 的测地三角形，三边都是 $\frac{\pi}{2}$、三个内角都是 $\frac{\pi}{2}$——内角和 $\frac{3\pi}{2} = \pi + \frac{\pi}{2}$，角盈 $\frac{\pi}{2}$；而 Gauss–Bonnet 说角盈 ${= }$ 面积，这个三角形面积恰是球面的 $\frac18 = \frac{4\pi/8}{} = \frac{\pi}{2}$ ✓——两账全对上（本机用大圆距公式逐边验证）。

**例题全算：八分球三角形三内角逐个算**。上面那笔「角盈账」值得把每个内角的算法拆开——顶点处的角不量弦、量**切向量**。顶点 $A = (1, 0, 0)$、$B = (0, 1, 0)$、$C = (0, 0, 1)$；三边都是大圆弧（第 4 章 §4.3 的定理保证它们是测地线），边长用大圆距公式：三对顶点两两正交，$d(A,B) = d(B,C) = d(C,A) = \arccos 0 = \frac{\pi}{2}$。内角的算法：大圆弧在端点 $p$ 处朝 $q$ 的切向量，是把弦方向投影到切平面再归一化——$t = \frac{q - (p \cdot q)\,p}{|q - (p \cdot q)\,p|}$（切平面方程 $v^{\mathsf T}p = 0$ 见第 2 章 §2.2）。三个顶点逐个算：

1. 在 $A$：边 ${AB}$ 的切向 $t_{AB} = \frac{B - 0 \cdot A}{1} = (0, 1, 0)$，边 ${AC}$ 的切向 $t_{AC} = (0, 0, 1)$，夹角 $= \arccos(t_{AB} \cdot t_{AC}) = \arccos 0 = \frac{\pi}{2}$；
2. 在 $B$：$t_{BA} = (1, 0, 0)$、$t_{BC} = (0, 0, 1)$，夹角 $\frac{\pi}{2}$；
3. 在 $C$：$t_{CA} = (1, 0, 0)$、$t_{CB} = (0, 1, 0)$，夹角 $\frac{\pi}{2}$。

（实跑照抄：三个 $\arccos$ 输出全是 $1.570796$，即 $\frac{\pi}{2}$ 到小数点后六位；代码在本章 §5.6。）内角和 $\frac{3\pi}{2} = \pi + \frac{\pi}{2}$，角盈 $\frac{\pi}{2}$。**Gauss–Bonnet 对账**：这个三角形围住的是第一卦限——三个坐标面从球面切出的 $\frac18$，面积 $\frac18 \times 4\pi = \frac{\pi}{2}$，与角盈逐位相等（$1.570796$ 对 $1.570796$）。球面版 Gauss–Bonnet $A = \sum\alpha_i - \pi$（$K = 1$ 特例）两笔账全对上——下一节会看到这笔账为什么必须对。

## $\rm \S \, 5.3$ 绝妙定理（本章主证）

**定理 5.1**（Gauss, Theorema Egregium, 1827）。曲面的 Gauss 曲率 $K$ 在等距变形下不变——它只依赖第一基本形式（度量 $g$），不依赖曲面嵌在 $\mathbb{R}^3$ 里的姿势。

**证明思路**（核心账目，全证标 do Carmo §4.3）。$K$ 的内蕴公式：$K = \frac{R_{1212}}{\det g}$，其中 Riemann 曲率张量 $R$ 完全由 $\Gamma^k_{ij}$ 与其导数构成，而 $\Gamma$ 由度量 $g$ 的一阶导数算出（第 4 章 §4.2 公式）——**链条 $K \leftarrow R \leftarrow \Gamma \leftarrow g$ 不经任何外部信息**。等距变形保度量 $g$ ⟹ 保整条链 ⟹ 保 $K$。Gauss 的原始证明走 $K = \frac{LN - M^2}{EG - F^2}$ 并验证分子可由 ${E, F, G}$ 及其导数表出（极繁）；现代式就是上面的张量链。$\blacksquare$

**绝妙在哪**：平面卷成圆柱——弯曲了！但 $K$ 仍是 0（圆柱面可展开贴平平面：第一基本形式不变）。**内禀 vs 外禀**的区分就此立起：卷尺的弯是外禀的（你看得见），纸面的弯若能展开贴平就是内禀平坦。广义相对论的数学基石「时空曲率是四维流形的内禀性质」用的正是同一条链——引力不是嵌在更高维里的弯曲，是度量的内禀账。

**白话**：住在曲面上的二维生物不开口（不需要第三维）就能量出曲率——量测地三角形内角和、量圆周长与半径的偏差即可；而一张纸卷成筒，纸上居民毫无察觉。

**圆柱面的完整数值验证**。「纸卷成筒」落到实处，就是把第一基本形式 ${E, F, G}$ 摆出来算。圆柱 $x^2 + y^2 = 1$ 参数化 $X(u, v) = (\cos u, \sin u, v)$，两个坐标切向量 $X_u = (-\sin u, \cos u, 0)$、$X_v = (0, 0, 1)$。在 $(u, v) = (0.7, 1.3)$ 处实算（任意点同值——三个内积里出现的 $\sin^2 u + \cos^2 u$ 与参数无关）：

$$
E = X_u \cdot X_u = \sin^2 u + \cos^2 u = 1, \qquad F = X_u \cdot X_v = 0, \qquad G = X_v \cdot X_v = 1
$$

实跑输出 $E = 1.000000$、$F = 0.000000$、$G = 1.000000$——与平面直角坐标 $(u, v) \mapsto (u, v)$ 的第一基本形式**恒等**：映射 $(\cos u, \sin u, v) \leftrightarrow (u, v)$ 就是「展开」这个动作本身，两张曲面度量完全相同，度量决定 $K$（绝妙定理的链条），平面 $K = 0$ 故圆柱 $K = 0$。卷出来的弯全记在第二基本形式（法向量怎么摆）里——外禀的弯、内禀的平。

**对照组：球面为什么展不平**。同一套算法上球面（第 4 章 §4.1 的参数化）：$X_\theta = (\cos\theta\cos\varphi,\ \cos\theta\sin\varphi,\ -\sin\theta)$、$X_\varphi = (-\sin\theta\sin\varphi,\ \sin\theta\cos\varphi,\ 0)$，算得 $E = 1$、$F = 0$、$G = \sin^2\theta$。实跑三个纬度：$\theta = \frac{\pi}{6}$ 处 $G = 0.250000$、$\theta = \frac{\pi}{4}$ 处 $G = 0.500000$、$\theta = \frac{\pi}{2}$ 处 $G = 1.000000$——$G$ 随纬度变。这个 $\sin^2\theta$（第 4 章的老朋友）就是展不平的数值化：等距展开要求同一个点在两张曲面上的 $G$ 取同值，而平面的 $G$ 是常数、球面的不是，矛盾。绝妙定理把这句升级为定理：无论用什么参数化、什么展开方案，$K = 1$ 搬不走。

## $\rm \S \, 5.4$ Gauss–Bonnet（陈述级）

紧致曲面 $\Sigma$：

$$
\int_\Sigma K\, \mathrm{d}A = 2\pi\, \chi(\Sigma), \qquad \chi = 2 - 2g_{\text{洞}}
$$

球面（$g = 0$）：$\int K = 4\pi R^2 \cdot \frac{1}{R^2} = 4\pi = 2\pi \cdot 2$ ✓；环面（$g = 1$）：$\chi = 0$，总曲率积分为零（正面凸、内圈负，正好抵消）。**读法**：曲率是局部账，拓扑是全局账，Gauss–Bonnet 说「全局账是局部账的总和」——局部微分几何与全局拓扑的第一座桥，现代指标定理（Chern 类等）的直系祖先。陈述级，标 do Carmo §5.4。

**第二个实例：环面上正负曲率如何对账**。「正好抵消」值得实算一遍。环面参数化 $X(\theta, \varphi) = ((R + r\cos\theta)\cos\varphi,\ (R + r\cos\theta)\sin\varphi,\ r\sin\theta)$（$R$ 中心圆半径、$r$ 管半径，$R > r$），Gauss 曲率有现成公式 $K = \frac{\cos\theta}{r(R + r\cos\theta)}$——一句话读它：分子 $\cos\theta$ 在外圈（$\theta = 0$，离轴最远、凸出来）为正、内圈（$\theta = \pi$，凹进去）为负，分母 $r(R + r\cos\theta)$ 恒正，符号全由内外圈定。取 $R = 2$、$r = 0.5$ 实算三个点：外圈 $K = \frac{1}{0.5 \times 2.5} = 0.800000$，管顶（$\theta = \frac{\pi}{2}$）$K = 0$，内圈 $K = \frac{-1}{0.5 \times 1.5} = -1.333333$。沿整个环面积分（$800 \times 800$ 网格、矩形法，代码见 §5.6）：$\int K\,\mathrm{d}A = 8.98 \times 10^{-16} \approx 0$——正负两本账精确相消。对照组：同法积分球面得 $12.566354$，对照 $4\pi = 12.566371$（网格误差 $10^{-5}$ 量级）。**白话**：甜甜圈外侧像球面（凸）、内侧像鞍面（凹），两种几何共处一个流形，总价为零是拓扑（一个洞，$\chi = 0$）规定的——几何在替拓扑还账。

## $\rm \S \, 5.5$ 高维一瞥（各一句）

1. **Riemann 曲率张量**：$n$ 维的曲率不是一个数，是 $(0,4)$ 张量 $R_{ijkl}$——20 个独立分量（$n = 4$）；截面曲率 $K(\sigma)$ 是二维切平面方向的 $K$ 推广。
2. **Ricci 与 Einstein**：$R_{ij}$（缩并）出现在 Einstein 场方程 $G_{\mu\nu} = 8\pi T_{\mu\nu}$——「物质决定几何」。
3. **常曲率空间**：$K$ 恒定的三类模型（球面/欧氏/双曲）是宇宙学的三选一。

## $\rm \S \, 5.6$ 数值实验

1. 球面角盈锚复算：三顶点两两 $\arccos$ 距离全 $\frac{\pi}{2}$、内角全 $\frac{\pi}{2}$（每条边上的切向夹角用 $\mathbb{R}^3$ 投影到切平面计算）——角盈 $\frac{\pi}{2}$ ＝ 面积 $\frac{\pi}{2}$，Gauss–Bonnet 特例两账对齐。
2. 半径 $r$ 测地圆周长表：$C(r) = 2\pi\sin r$（球面解析）对 $2\pi r$ 的偏差 $\frac{C}{2\pi r} = \frac{\sin r}{r} \approx 1 - \frac{r^2}{6}$——与 §5.1 展开系数 $-\frac{K}{6} = -\frac16$（$K = 1$）逐位吻合。
3. **可跑实验段**（纯 Python、纯 NumPy）——把本章三笔新账一次算全：

```python
import numpy as np

V = [np.array(c, dtype=float) for c in [(1,0,0), (0,1,0), (0,0,1)]]
# (1) 八分球三角形：内角 = 端点切向量投影到切平面后的夹角
for i in range(3):
    p, q, r = V[i], V[(i+1) % 3], V[(i+2) % 3]
    tq = q - (p @ q) * p; tq /= np.linalg.norm(tq)
    tr = r - (p @ r) * p; tr /= np.linalg.norm(tr)
    print(f"angle at vertex {i+1}: {np.arccos(np.clip(tq @ tr, -1.0, 1.0)):.6f}")

# (2) 第一基本形式：圆柱 vs 球面
u0 = 0.7
Xu = np.array([-np.sin(u0), np.cos(u0), 0.0]); Xv = np.array([0.0, 0.0, 1.0])
print(f"cylinder: E={Xu @ Xu:.6f} F={Xu @ Xv:.6f} G={Xv @ Xv:.6f}")
for th in (np.pi/6, np.pi/4, np.pi/2):
    Xt = np.array([np.cos(th), 0.0, -np.sin(th)])
    Xp = np.array([0.0, np.sin(th), 0.0])
    print(f"sphere theta={th:.4f}: E={Xt @ Xt:.6f} F={Xt @ Xp:.6f} G={Xp @ Xp:.6f}")

# (3) 环面 K 积分（R=2, r=0.5，矩形法）
R, r, n = 2.0, 0.5, 800
g = np.linspace(0.0, 2.0*np.pi, n, endpoint=False)
TH, _ = np.meshgrid(g, g, indexing='ij')
K = np.cos(TH) / (r * (R + r*np.cos(TH)))
J = r * (R + r*np.cos(TH))
print(f"torus int K dA = {np.sum(K*J) * (2*np.pi/n)**2:.3e}")
```

**读法**：三段输出分别兑现 §5.2（三内角全 $\frac{\pi}{2}$）、§5.3（圆柱 ${E, F, G}$ 与平面恒等、球面 $G = \sin^2\theta$ 随纬度变）、§5.4（环面总曲率积分 $10^{-16}$ 级为零）——正文里的每笔账都能一键复算。

## $\rm \S \, 5.8$ 本章自测答案

1. $C(r) = 2\pi r(1 - \frac{K r^2}{6} + \cdots)$——不开口即可测 $K$。（§5.1）
2. 球 $K > 0$ 内角和 $> \pi$；平面 $= \pi$；双曲 $< \pi$。（§5.2）
3. $K$ 由 $R$ 算、$R$ 由 $\Gamma$ 算、$\Gamma$ 由度量一阶导算——全程内蕴。（§5.3）
4. 圆柱可展开贴平、第一基本形式不变，$K$ 是内禀量故仍为 0。（§5.3）
5. 局部曲率积分 ⟺ 全局拓扑示性数（$\int K = 2\pi\chi$）。（§5.4）
6. 角盈 $\frac{\pi}{2}$ 与面积 $\frac{\pi}{2}$ 相等；周长偏差 $\frac{\sin r}{r} \approx 1 - \frac{r^2}{6}$ 与 $K = 1$ 吻合。（§5.6）
7. 把弦方向投影到切平面再归一化：$t = \frac{q - (p \cdot q)\,p}{|q - (p \cdot q)\,p|}$；在 $(1,0,0)$ 处两条边的切向是 $(0, 1, 0)$ 与 $(0, 0, 1)$，夹角 $\arccos 0 = \frac{\pi}{2}$。（§5.2）
8. 差在 $G$：圆柱 $G = 1$ 恒定（与平面恒等），球面 $G = \sin^2\theta$ 随纬度变（$\frac{\pi}{6}$ 处 $0.25$、赤道 $1$）。等距展开要求 $G$ 在两张曲面取同值，常数对变数即矛盾——任何展开方案都封死。（§5.3）
9. 外圈 $K = \frac{1}{r(R + r)} > 0$、内圈 $K = \frac{-1}{r(R - r)} < 0$（$R = 2$、$r = 0.5$ 时 $0.8$ 与 $-1.333333$）；总积分 $= 2\pi\chi = 0$ 由环面的拓扑（一个洞）规定，内外圈正负相消是几何在替拓扑还账。（§5.4）
