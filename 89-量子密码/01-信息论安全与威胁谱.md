密码学的每一份安全承诺都在回答同一件事：对手拿到密文之后，哪些路是通的，哪些路是死的。两条路走法不同，代价也不同：一条说「路根本不存在，你花无限时间也走不通」，另一条说「路存在，但走完要一亿年」。本册的起点是把这两条路钉成两个严格口径，算清各自的代价，然后回答一个问题：当量子技术同时带来「能现场长密钥的信道」和「能撕碎公钥密码的算法」时，整个密码体系的信任应该放在哪里。全册的心智模型一句话：**信任从假设变成物理，但物理设备本身又成了新的假设**。这句话每一章都会往前推一格，本章先给它落第一个人能摸到的形状。

## $\rm \S \, 1.1$ 问题：信任的存放位置

两种安全承诺可以用两个保险柜来建立直觉。第一种保险柜的墙里没有任何暗道，锁芯与门板之间也不存在可以撬动的缝隙：它对攻击者的承诺不依赖「贼力气多大」，哪怕给贼无限时间和无限工具，他能做的也只剩盲猜。第二种保险柜是一把非常结实的普通锁：贼确实能撬开，但按已知的撬法得花一百年，而你的假设是贼不会活那么久。前者对应**信息论安全（information-theoretic security）**，后者对应**计算安全（computational security）**；两种口径在密码学册 §1.3 与 §1.5 都已登过场，本章要把它们放进同一个坐标系里算账。

直觉落到定义时有一个必须说清的边界：第二种保险柜的「一百年」不是数学定理，是经验事实。撬法（算法）的进步、贼的装备（算力）升级、锁匠手册（密码分析）的新发现，任何一项都可能把一百年压成一个月。而第一种保险柜免于此难的原因不是「贼弱」，是承诺里根本没有贼的位置：它的安全证明是一段不含算力变量的概率推导。这个差别决定了两者各自怕什么：前者怕物理前提被违反，后者怕数学与算力的进步。本册后面所有章节，都在围着这一对「怕」打转。

量子技术对这对「怕」各补了一块砖。补在信息论一侧：量子密钥分发（quantum key distribution，QKD）能在两台设备之间现场产出真随机的共享密钥，且窃听会留指纹（量子通信册 §2.3），这正好补上 OTP 最痛的「海量真随机密钥怎么送到」的缺口。补在计算安全一侧的对立面：Shor 算法让量子计算机多项式时间解分解与离散对数，公钥密码的「难题」从经验事实变成已知可破（量子通信册 §8.1）。一边供给，一边威胁，两块砖合起来就是本册的存在理由。

## $\rm \S \, 1.2$ 两种「破不动」：口径与代价

### $\rm \S \, 1.2.1$ 信息论安全：把成功概率压回先验

两消息博弈是最小化的检验场景：消息空间里有两个候选明文 $m_0$ 与 $m_1$，各以二分之一概率出现；对手知道这两个候选，拿到密文 $C$ 后必须猜是哪一个。信息论安全要求：这个命中率不高于盲猜，且**不论对手的计算能力、可用时间与存储有多夸张**。用 OTP 检验这一条只要两步。加密为 ${C = M \oplus K}$，密钥 $K$ 均匀且与消息独立。固定任一密文 ${c \in \{0,1\}^n}$，映射 ${k \mapsto k \oplus c}$ 是 $\{0,1\}^n$ 上的双射，所以每个候选明文恰好对应一个解释它的密钥：

$$
\Pr[C = c \mid M = m_i] = \Pr[K = m_i \oplus c] = 2^{-n}, \qquad i = 0, 1
$$

这个条件概率与 $i$ 无关，贝叶斯公式立刻给出后验等于先验：密文没有改变对手对消息的任何判断。注意证明里出现的每个量都是概率分布，没有一项叫「攻击者的操作数」，这就是「算力买不到进展」在数学上的形状，也是密码学册 §1.3 那两行证明的全部内容。

选两消息博弈做检验场景而非直接写「互信息为零」，是因为前者可操作：它把「对手拿到了什么」全部摆上台面（两个候选加一条密文），把「对手要交出什么」也钉死（一个猜测），于是任何攻击策略都被折算成一个命中率数字。互信息为零与命中率恒为二分之一可以互相推出，但命中率口径有一个实战优势：它对部分泄密给出连续的读数，泄一点密命中率就离开二分之一一点，第 2 章的安全证明算「密钥率还剩多少」时用的正是这种连续记账。

安全从不免费。Shannon 定理（陈述级见密码学册 §1.3）钉死了价签：任何完美保密方案必有密钥空间不小于消息空间，${|K| \ge |M|}$。OTP 取到等号，于是它的密钥经济形态是**消耗品**：加密 $n$ 比特报文，就永久烧掉 $n$ 比特真随机密钥，密钥与报文逐比特同步消失，一分一毫都不许省、不许重用、不许由伪随机过程生成（伪随机会把两行证明的前提「$K$ 均匀」直接抽掉，见密码学册 §1.3 末尾的警告）。信息论安全的花销模式因此像火箭燃料：烧一次，带一程。

### $\rm \S \, 1.2.2$ 计算安全：把成功概率压进多项式时间够不着的地方

计算安全换了一种承诺：不说「不可能」，说「代价」。口径是：取安全参数 $n$（对 AES-128 即 ${n = 128}$），任何计算量在 $n$ 的多项式以内的攻击，其成功概率都可忽略地小。这个定义自带两条前提，两条都不是定理。第一，背后那道难题真的难：离散对数与整数分解的「难」是几十年没人找到有效算法的经验事实，Shor 算法一出，这条前提对公钥密码就地崩塌（量子通信册 §8.1）。第二，攻击者的算力有物理上限，$2^{128}$ 次操作的换算见密码学册 §1.5，实测段 D 还会复算一遍。

两种口径放进同一张表，差别就一目了然。

| 比较维度 | 信息论安全（OTP） | 计算安全（AES-128） |
| --- | --- | --- |
| 对手算力 | 无限制，含未来任意算力 | 限定在多项式时间以内 |
| 核心前提 | 密钥真随机、只用一次、逐比特同步消耗 | 底层难题难 + 算力物理上限（都是经验事实） |
| 证明形式 | 概率恒等式，证明里无算力变量 | 归约到难题；难题崩塌则证明失效 |
| 密钥代价 | 与报文等长，烧完即弃 | 固定 128 位，可长期重用 |
| 典型失效方式 | 密钥重用、密钥可预测 | 数学进步（Shor）、算力跃升 |

参数 $n$ 取多大是工程折衷，不是道德判断。上世纪九十年代 $56$ 位密钥还能撑住，因为穷举 $2^{56}$ 次操作在当年硬件上要跑数年；今天这个数几小时就能走完，于是业界把对称密钥的基线抬到 $128$ 位，对 ${2^{128}}$ 次操作再叠加「硬件每年还在变快」的余量。安全参数的历史是一部不断向上修订的历史，这正是计算安全口径的代价之一：承诺的有效期依附在算力曲线上，曲线动，承诺就得重签。信息论侧没有这条曲线，代价表上写的是另一种货币（密钥管理），两种货币不可通约，但都得付清。

表里最后一行值得多看一眼：OTP 的失效不看对手脸色的原因，是它把全部信任压在了自己那侧的操作纪律上。这也是本册心智模型的第一次显形：信息论方案把「对手很弱」这个假设换成了「密钥管理不出错」这个假设，假设没有被消灭，只是被搬了家。

### $\rm \S \, 1.2.3$ 穷举为什么对两者意义不同

把「穷举全部密钥」这件武器分别打在两种方案上，发生的不是「一个破得动、一个破不动」，而是两棵形状完全不同的博弈树。对密钥重用的分组密码，攻击有**验证预言机（verification oracle）**：一把候选密钥 $k$ 要同时解释全部密文块，任何一段已知明文（文件头、协议常量、可打印文本）都能充当裁判，穷举每试一个 $k$ 就把幸存者集合剪小一圈，进展单调积累，走完全程必然锁定唯一真钥。对 OTP，密钥只服务一个块就销毁：候选密钥 $k$ 只需解释 ${k \oplus c}$ 这一个值，每个候选都自洽，穷举走完全程得到的候选集恰好是整个明文空间，正确明文混在其中位置均匀，穷举完成时的成功率仍是先验 $2^{-n}$，与穷举开始前一字不差。

形式化地讲：给定密文 $c$，候选明文集为

$$
\{\, k \oplus c \mid k \in \{0,1\}^n \,\} = \{0,1\}^n
$$

双射把这个集合撑满整个消息空间，而没有任何约束去区分其中哪个 $m$ 更「像」正确答案；分组密码那边，已知明文对 ${(m^*, c^*)}$ 给出硬约束 ${E_k(m^*) = c^*}$，随机双射下期望只有一把密钥满足。一棵是越走越窄的剪枝树，一棵是处处等权的平权树：前者只需要祈祷难题够难，后者根本不需要树。

## $\rm \S \, 1.3$ 实测：同一笔穷举预算下的两种博弈树

上面的论证全部可以按字面跑出来。 AES-128 本身没法进实验：$2^{128}$ 次穷举超出任何真实算力，直接演示只会沦为口号。改用可控的玩具尺寸（$16$ 位块、$16$ 位密钥），穷举全程能在一秒内走完，两种博弈树的形状因此都能被肉眼看到；尺寸缩小不影响结论，因为 §1.2.3 的双射论证对任意 $n$ 成立，玩具只是把任意 $n$ 代了一个看得见的值。实验环境：WSL（Ubuntu）`python3` + NumPy，固定种子 `20261111`，脚本与完整输出存放在 `C:\Users\20811\Desktop\26Fall\_uni5_work\expQX01\`（`exp1.py` 与 `result.txt`，全程 9 秒）。脚本分四段：A 段做 OTP 两消息博弈的蒙特卡洛，B 段对两种方案施加完全相同的穷举预算（$2^{16}$ 把密钥全试），C 段算 §1.4 的 gap 模型账，D 段复算 $2^{128}$ 的量级账。核心代码如下：

```python
import numpy as np
rng = np.random.default_rng(20261111)

# A. OTP 两消息博弈：命中 p 率应停在 0.5，与算力无关
N = 400000
m0, m1 = rng.integers(0, 256, N), rng.integers(0, 256, N)
b, k = rng.integers(0, 2, N), rng.integers(0, 256, N)
c = np.where(b == 0, m0, m1) ^ k          # 密文
hit = np.mean(rng.integers(0, 2, N) == b)  # 任何策略的命中率

# B. 同一笔穷举预算：玩具分组密码（密钥重用） vs OTP
a = 2654435761 % (1 << 16)                 # 奇常数，模 2^16 乘法是双射
E = lambda kk, m: (a * (m ^ kk)) % (1 << 16)
kp_pairs = [(0x1234, E(0xBEEF, 0x1234)),   # 已知明文对（文件头场景）
            (0x5678, E(0xBEEF, 0x5678))]
surv = [kk for kk in range(1 << 16)
        if all(E(kk, mm) == cc for mm, cc in kp_pairs)]  # 验证预言机剪枝
otp_cands = {0x11EF ^ kk for kk in range(1 << 16)}       # OTP 穷举候选集
```

运行后 `result.txt` 的 A、B、D 三段输出如下（C 段留给 §1.4）：

N=400000  Eve 命中率 = 0.4995（理论 0.5，偏差 0.0005）

正确明文 m=23 混在其中，位置 24/256，无任何识别线索。

三段输出各钉死一个论断。读输出前先交代方法上的一件事：A 段的 Eve 用「随机猜」出场，这看似放水，实为按定义出牌——两消息博弈的最优策略就是二分之一随机猜，任何「聪明」策略都无法超越它，A 段随后在自测第 4 题里让你亲手验证这一点。A 段：四十万轮博弈里命中率 $0.4995$，与盲猜的偏差 $0.0005$ 落在二项分布的正常涨落内（${N = 4 \times 10^5}$ 时标准差约 $0.0008$），完美保密按字面兑现。B 段：同一笔 $2^{16}$ 次试验的预算，重用密钥的玩具分组密码被唯一锁定，OTP 侧得到 $65536$ 个互不相同的候选明文、零进展，「穷举」这个动作本身在两种方案里根本不是同一个动作。D 段：计算安全那侧的 $2^{128}$ 折算成一亿亿次每秒的机器也要 $10^{22}$ 年量级，而量子侧 Grover 只把对称强度砍半到 $2^{64}$（量子通信册 §8.1 的口径）；注意这是**量级换算账**而非实测穷举，$2^{128}$ 次操作没有真跑，跑的是换算公式。

这个对照实验的结论值得单独一句：信息论安全与计算安全的差别，不在「谁更难破」，在「穷举有没有意义」：前者里穷举是一件逻辑上无效的事，后者里穷举是一件工程上无效的事。逻辑无效不依赖任何关于算力的假设，这正是量子时代还愿意多看 OTP 一眼的全部理由；而它的价格标签，下一节直接开票。

> 竞赛生迁移提示：两棵博弈树的对比在算法竞赛里有现成的对应物。计算安全的穷举像带剪枝的搜索，每步都有可验证的进度量（幸存候选数），评测器（已知明文）始终在线；信息论安全的穷举像在一棵所有叶子等值的树上搜索，没有评测信号，搜索等于随机游走。凡是「验证比求解容易」的问题（SAT、碰撞），穷举都有支点；OTP 的保密性恰恰把验证的支点抽掉了。

## $\rm \S \, 1.4$ QKD 在密钥体系里的位置：分发层，不是加密层

### $\rm \S \, 1.4.1$ 密钥体系的三层

对称密钥的一生分三段：生成、分发、使用。生成段要的是真随机（量子随机数发生器在第 5 章，伪随机会抽掉 OTP 的证明前提）；分发段要把密钥安全送到对端，候选方案有预共享（人工护送）、公钥交换（密码学册 §5.1，Shor 之后算力前提受损）与 QKD；使用段才是加密本身，交给 AES 这类分组密码（密码学册 §2）或 OTP。三层各司其职，混淆层次是新手最常见的误读。

```mermaid
flowchart LR
    G["生成层<br/>真随机源（QRNG，第 5 章）"] --> D["分发层<br/>预共享 / 公钥交换 / QKD（本册主角）"]
    D --> U["使用层<br/>AES（计算安全）或 OTP（信息论安全）"]
```

生成层常被跳过，却是三层里最容易被假货占据的一层：市面上的「随机数」绝大多数来自伪随机过程（密码学册 §2.3 讲 nonce 重用时埋过同一性质的雷），它们的输出对人类够随机，对信息论安全的证明却一文不值——证明前提写的是「$K$ 均匀」，伪随机的输出分布离均匀有距离，哪怕距离小到测不出。硬件真随机源用物理过程（热噪声、光子的分束）造比特，本册第 5 章讨论怎么验证它的均匀性；QKD 产出的密钥经隐私放大后同样满足这个前提，这是它在 §1.4.2 的账里能配额给 OTP 的资格证明。

分发层的三个候选各有各的账。预共享最古老：密钥由人工或加密信道预先送达，安全但扩张不动，一百个节点两两预共享要管近五千条密钥；公钥交换把分发问题交给数学难题，代价是 §1.2.2 说的「承诺有效期依附算力曲线」；QKD 把它交给物理，代价换成光纤、专用设备与距离。三个候选不是竞争关系，现实系统按场景混用，第 6 章收束时会回到这张分工表。

QKD 只替换分发层：它产出的仍是普通对称密钥比特串，报文加密照旧走经典算法。所以「量子加密通信」这个流行说法在字面上不成立：报文全程由经典密码加密，量子物理接管的是「密钥从哪来」这一段。这个层次定位决定了后文全部账目的记法：QKD 的产出是**密钥率**（每秒多少比特），而 OTP 与 AES 的需求是**密钥消耗率**，两者的差就是本节的账。

### $\rm \S \, 1.4.2$ gap 模型账：OTP 的消耗 vs QKD 的供给

Shannon 定理的价签先折算成消耗侧的数：OTP 加密 $1$ GB 视频需要 ${8 \times 10^9}$ 比特真随机密钥，用一次即焚。供给侧，QKD 的密钥率在现实里是一个被多重因子层层削减的量，简化模型（标注：**模型推演非实测**，参数取文献常见量级，账目结构与量子通信册 §2.6、§6.4 一致）为：

$$
R_{\text{key}} \;=\; R_{\text{p}} \cdot \mu \cdot \eta_{\text{d}} \cdot T(L) \cdot \tfrac{1}{2} \cdot \bigl(1 - 2\,h(q)\bigr)
$$

逐符号读：$R_{\text{p}}$ 是发送端脉冲率；$\mu$ 是每脉冲平均光子数（弱相干光源的泊松账，量子通信册 §6.1）；$\eta_{\text{d}}$ 是探测器效率；$T(L) = 10^{-\alpha L / 10}$ 是长度 $L$、衰减 $\alpha$ dB/km 的光纤透过率；$\tfrac{1}{2}$ 是 BB84 基筛选的保留比例（量子通信册 §2.2）；${1 - 2h(q)}$ 是纠错与隐私放大后的安全率因子，其中 $h$ 是二元熵函数、$q$ 是误码率（量子通信册 §2.6 的账）。代入一组文献量级参数：$50$ km 光纤（${\alpha = 0.2}$，${T = 0.100}$）、${R_{\text{p}} = 10^8}$ 脉冲/秒、${\mu = 0.5}$、${\eta_{\text{d}} = 0.6}$、${q = 0.02}$，安全率因子 ${1 - 2h(0.02) = 0.7171}$，模型给出：

$$
R_{\text{key}} \approx 1.08 \times 10^{6} \ \text{bit/s} \;\approx\; 1.08 \ \text{Mbit/s}
$$

`result.txt` 的 C 段把这本账连同两个消耗场景一起算完：

```text
== C. gap 模型账：OTP 密钥消耗 vs QKD 密钥率（模型推演，参数为文献量级） ==
参数：50 km 光纤（透过率 0.100）、脉冲率 1.0e+08/s、mu=0.5、eta_d=0.6、
      筛选 0.5、QBER=0.02、PA 因子 0.7171
模型密钥率 ≈ 1.076e+06 bit/s ≈ 1.08 Mbit/s
OTP 加密 1 GB：密钥需求 8.0e+09 bit → QKD 连续产钥 7437 s ≈ 2.07 小时
AES-128 会话密钥：只需 128 bit → 0.12 ms 的 QKD 产量
gap 比 = 6.250e+07
```

读法分两行。第一行，OTP 消耗：加密这 $1$ GB 视频，QKD 要满负荷连续产钥 $2.07$ 小时，且这批密钥随视频播放一次性蒸发，想再加密一遍就得再攒两小时。第二行，AES 消耗：$128$ 位的会话密钥只等价于 $0.12$ 毫秒的 QKD 产量，一把钥匙护住整个会话。两行的比值 $6.25 \times 10^7$ 就是「逐比特消耗」与「固定密钥重用」之间的经济鸿沟，源头正是 §1.2 表格里那一行「密钥代价」。还要注明账本的偏乐观处：模型未计诱骗态、有限码长（第 2 章）与设备开销，真实系统密钥率通常再低一到两个数量级，鸿沟只朝更宽的方向走。距离在这个模型里是指数杀手：$T(L) = 10^{-\alpha L/10}$ 把密钥率随光纤长度指数压低，$50$ km 到 $100$ km 就再砍一个因子 $10$，这正是量子通信册 §6.4 那本「密钥率-距离」账的简化版，也是远距离要靠中继与可信节点（量子通信册 §7）的账面原因。

于是工程结论自然成形：QKD 供不起「对海量数据逐比特 OTP」，现实组合是 QKD 持续产出新鲜密钥、定期刷新 AES 的会话密钥，保密强度回落到计算安全那一档，但「密钥新鲜且窃听留痕」由物理层担保。完整的组合策略账（什么场景用哪档、为什么不是二选一）在第 6 章收束；OTP 配 QKD 的真实现场是短报文高价值链路，例如政府专线上的指令级通信。

## $\rm \S \, 1.5$ 威胁谱：从「算法被破」到「物理被听」

威胁建模五问（安全册 §1.5）里的第二问「攻击者是谁」，在传统密码教材里几乎只用算力一个轴回答：手里有几台机器、能跑多少次操作。本章前四节也在这个轴上：信息论安全把这一轴彻底封死（算力买不到进展），计算安全把这一轴拉到 ${2^{128}}$（工程上够不着）。QKD 加入后，能力轴多出一条物理分支，威胁谱从一维变两维。

先排经典一维的谱，由内向外：数学弱点（难题被解，Shor 之于 RSA/DH，见量子通信册 §8.1）；实现弱点与侧信道（算法没错，错的拿法让密钥漏出来，安全册 §5 有一整章实账）；密钥管理失败（密钥存哪、怎么轮换、谁有副本，即五问里的资产与入口问题）。这三级共享一个特征：攻击面都在**数学与代码**里，物理定律不管这些事。

QKD 把第四级搬进了**物理**：对量子信道的直接截听。不可克隆定理保证窃听者无法复制量子态，测量扰动保证截听会以误码率的形式留指纹（量子通信册 §1.3、§2.3），所以经典意义上「无声无息抄走密钥」的路在物理上被堵住。但按本章心智模型的预言，堵住旧门的地方必开新门：物理设备自己成了攻击面。光源不是理想的单光子枪（泊松账，量子通信册 §6.1），探测器可以被强光致盲后谎报结果（第 3 章定性展开）；对手不再正面攻击量子态，转而欺骗「替你观察量子态的仪器」。

时间轴上的威胁还要单独记一笔。公钥侧的「先存后解」（harvest now, decrypt later）对手今天就在收集密文，等量子计算机成熟再回头解：数据寿命超过量子机到来时间的业务，现在就已经暴露在 Shor 的威胁下，哪怕攻击发生在十年后。这条时间账把「量子威胁还很远」的直觉直接作废，也是量子通信册 §8.1 与后量子密码并列存在的理由；对称侧没有对应问题，AES 密文先存后解只会面对 Grover 的平方加速，账面上安全得多。

把 Eve 的能力按档排开，本册的章节路线恰好是这张谱的推进表：

1. **被动窃听**：只听不做，经典信道旁听、量子信道被动测量；
2. **主动截听**：截听重发与干扰，留指纹但敢于承受被抓的概率（量子通信册 §1.4）；
3. **有量子存储的对手**：先存后测，等基协商完再选测量方式，BB84 的安全证明必须覆盖它（第 2 章）；
4. **控制设备的对手**：绕过物理定律正面，从实现缺陷下手（探测器致盲等，第 3 章）。

读这张表要两维一起读，不是只看档次高低。同一档对手打在两种方案上，结局完全不同：第 3 档的量子存储对手对 AES 无所增益（穷举还是买不到进展），对 BB84 却是致命的——他可以避开测量扰动的抓捕逻辑，这正是 BB84 早期「证明覆盖不到存储型对手」争议的来源，也是第 2 章安全证明要补的第一个缺口。威胁建模五问里「攻击者是谁」一问的答案，从此要写成二维坐标：算力轴一格、物理轴一格，缺一格就是建模漏洞。

第 2 章的安全证明对付第 1–3 档；第 3 章的 MDI 协议干脆把中间站设为不可信，把第 4 档的一半剪出证明范围；第 4 章的设备无关方案连设备都不信，用贝尔违背当安全证书。每一章都在把信任往上一层搬，没有一章宣布消灭假设：信任从假设变成物理，而物理设备本身又成了新的假设，这句话到第 4 章会显出它全部的重量。

## $\rm \S \, 1.8$ 本章自测答案

1. 定义：对手知道 $m_0, m_1$ 并拿到密文 $C$ 后，猜对发送的是哪一个的概率恒为 $\tfrac{1}{2}$，与算力无关。证明差别：信息论安全的证明（${\Pr[C=c \mid M=m_i] = 2^{-n}}$ 对两个 $i$ 相等）里每个量都是概率，没有「攻击操作数」这一项；计算安全的证明是归约到难题，攻击者操作数出现在定义的每一行（多项式时间以内），难题崩塌或算力跃升都直接改写结论。（§1.2.1、§1.2.2）
2. 双射论证：给定密文 $c$，映射 ${k \mapsto k \oplus c}$ 把全部 $2^n$ 个密钥映成整个明文空间，每个候选明文恰有一个自洽密钥，没有任何约束可区分它们；重用密钥的分组密码则受已知明文约束 ${E_k(m^*) = c^*}$ 剪枝，期望仅一把密钥幸存。实测：B 段 $65536$ 次试验后，玩具分组密码幸存 $1$ 个、OTP 幸存 $65536$ 个候选明文。（§1.2.3、§1.3）
3. 替换的是**分发**层；错在「加密」两个字：报文全程由经典算法（AES 或 OTP）加密，QKD 只负责把密钥现场送到对端。若厂商连「使用层也换了」一起宣称，则要么指 OTP（受 §1.4.2 消耗账约束），要么是无定义的营销词。（§1.4.1）
4. 不变，三种策略的命中率都停在 $\tfrac{1}{2}$（偏差只在二项涨落内）。信息论安全对所有攻击策略一视同仁：后验等于先验意味着「聪明」在密文上找不到任何着力点，这也是定义要写成「对所有策略的上界」而非「对已知策略」的原因。（§1.2.1、§1.3）
4. Shannon 定理：完美保密必有 ${|K| \ge |M|}$，OTP 取等号，所以「密钥与报文逐比特等长」不是实现不够好，而是下界本身；由此密钥经济形态是消耗品，加密 $n$ 比特烧掉 $n$ 比特真随机密钥，与火箭燃料同款账。（§1.2.1）
5. 公式见 §1.4.2；$T(L)$、$\eta_{\text{d}}$ 与 $\tfrac{1}{2}$（筛选损耗）属物理层，$\mu$ 一半物理一半安全（多光子泄漏，量子通信册 §6.2），$1 - 2h(q)$ 属信息安全账（纠错泄漏加隐私放大）。模型密钥率 $1.08$ Mbit/s 对 OTP 的 $8 \times 10^9$ bit/GB 需求，缺口表现为 $2.07$ 小时每 GB；对 AES 的 $128$ bit 需求，缺口消失（$0.12$ ms）。（§1.4.2）

答案里出现 ${10^{22}}$ 年、$2.07$ 小时、${6.25 \times 10^7}$ 这些数，它们的出处分别是 §1.3 的 D 段换算账与 §1.4.2 的模型账，参数全部在 `expQX01/exp1.py` 里可复算。下一章进入本册的技术纵深：这些账目背后的安全证明怎么写：Eve 被允许持有量子存储后，BB84 的密钥率如何从一条 CSS 码的纠错恒等式里长出来，以及为什么块长一短，证明的结论就要打折。
