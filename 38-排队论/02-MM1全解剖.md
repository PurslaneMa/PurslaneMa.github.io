# $\rm \S \, Chapter \, 2$ M/M/1 全解剖

第 1 章把「人什么时候来」彻底解决了：到达间隔独立同指数、计数泊松、拆合免费。现在补上另一半——来了之后要待多久。本章处理整个排队论里最简单的非线性随机系统：一个服务台、泊松到达、指数服务。它简单到能用纸笔把每一个稳态量都写成闭式，又丰富到足以校准你日后对一切排队现象的直觉——所以它是排队论的果蝇：繁殖快、结构清楚，所有新想法先拿它试。本章的路线是四步：先立账本（生灭过程），再读出平稳分布（几何分布），然后从两个视角各算一遍性能量（时间平均与到达平均），最后把两套答案对账——对账的那一行等式就是 Little 定理的预告。

比喻先立在这：把整个系统想成一家只有一个厨师的小店，账本上只记一个数——店里现在几个人。来一位客人记一笔进账（生），做完一单记一笔出账（死）。本章全部内容就是读这本一进一出的账：翻到任意一页时各数字出现的频率（平稳分布），以及据此算出的平均人数与平均停留时间。

> **开始前自检**：本章假设你已经会：
>
> 1. □ 指数分布的无记忆性 $P(X > s + t \mid X > s) = P(X > t)$（§1.2）。
> 2. □ 泊松过程的普通性 $P(N(h) = 1) = \lambda h + o(h)$ 与独立增量（§1.4）。
> 3. □ PASTA：泊松到达者所见等于时间平均（§1.5，陈述级）。
> 4. □ 几何级数 $\sum_{n \ge 0} x^n = \frac{1}{1-x}$（$\lvert x \rvert < 1$），以及逐项求导。
> 5. □ 期望的线性性：$E[X + Y] = E[X] + E[Y]$ 不需要独立性。
>
> 其中第 1、3 条是本章的两块主砖，不熟先回第 1 章补齐。

## $\rm \S \, 2.1$ 动机：为什么拿 M/M/1 当校准器

先用肯德尔记号（Kendall notation）给系统起名字：$A/B/c$，三个槽位依次是到达间隔分布、服务时间分布、服务台数；记号 M 是 Markov 的缩写，意思是「无记忆」。于是 M/M/1 读作：泊松到达、指数服务、单服务台。参数就两个：到达率 $\lambda$（每单位时间来几个人）与服务率 $\mu$（忙时每单位时间做完几单），对应平均间隔 $\frac{1}{\lambda}$ 与平均服务时间 $\frac{1}{\mu}$。

它凭什么当「果蝇」？两条。第一，它是唯一一个全部稳态量都有闭式答案的非平凡排队系统——后面的 M/M/k、M/G/1、排队网络，每推进一步都要回头跟 M/M/1 的答案对表。第二，也是更值钱的一条：它校准直觉。先自测一下：一家理发店，客人到达强度是师傅能力的九成（$\rho = 0.9$），店里平均几个人？多数人的直觉是「两三个」。正确答案是 9 个。$\rho = 0.99$ 呢？99 个。队长不是随利用率线性增长，而是按 $\frac{1}{1-\rho}$ 爆炸——这一条曲线是全部容量规划常识的源头，本章把它从账本里一步步算出来。

小结：M/M/1 = 泊松到达＋指数服务＋单台，两个参数 $\lambda$ 与 $\mu$；它的价值不在真实（现实很少这么规矩），而在它是唯一能全闭式求解的校准器。

## $\rm \S \, 2.2$ 生灭过程：一进一出的账本

白话先行：要问「稳态下店里人数的分布」，得先说清人数怎么随时间跳。无记忆性保证：无论现在几个人、已经营业多久，下一跳只有两种可能——新客到达（率 $\lambda$），或正在服务的那单完成（率 $\mu$，仅当有人在做）。状态就是这一个数。

**定义 2.1（生灭过程，birth–death process）**：以队长 $N(t)$（系统内人数，含正在被服务的）为状态的连续时间马尔可夫链，在状态 $n$ 处：

1. 生：$n \to n+1$，率 $\lambda_n = \lambda$，与 $n$ 无关；
2. 死：$n \to n-1$，率 $\mu_n = \mu$（$n \ge 1$），$\mu_0 = 0$（没人可服务）。

两条率各有出处。生率来自第 1 章：到达是泊松流，普通性给出 $P(N(h) = 1) = \lambda h + o(h)$，且独立增量使这条率不因店里人多而改变（§1.4）。死率来自无记忆性：只要台子忙，「下一单何时做完」是重新起算的 $\mathrm{Exp}(\mu)$，瞬时完成率恒为 $\mu$——服务进度不积累，做了多久都白搭（§1.2 的微分读法）。M/M/1 里两个 M 的来历就在这：到达无记忆，服务也无记忆。

白话先行：平稳分布问的是「店开了很久之后，翻到账本任意一页，看到 $n$ 个人的频率」。这是本章的核心对象。

**定义 2.2（平稳分布，stationary distribution）**：概率分布 $\{\pi_n\}_{n \ge 0}$ 称为平稳分布，若初始分布取 $\pi$ 时，对一切 $t$ 与 $n$ 有 $P(N(t) = n) = \pi_n$——概率不再随时间流动。

**定理 2.1（M/M/1 的平稳分布）**：M/M/1 存在平稳分布当且仅当 $\rho = \frac{\lambda}{\mu} < 1$，且此时

$$
\pi_n = (1 - \rho)\,\rho^n, \qquad n = 0, 1, 2, \ldots
$$

**证明**。分四步，每步的账都摊开。

1. **列全局平衡方程**。稳态的含义是每个状态的人数占比不变，于是对每个 $n$，「流出状态 $n$ 的频率」必须等于「流入的频率」。流出：处于状态 $n$ 的时间占比是 $\pi_n$，而处于 $n$ 时下一跳以率 $\lambda + \mu$ 发生（$n \ge 1$ 时生死两条路都开着），故流出率为 $\pi_n(\lambda + \mu)$。流入：从 $n-1$ 生一个（占比 $\pi_{n-1}$、生率 $\lambda$）或从 $n+1$ 死一个（占比 $\pi_{n+1}$、死率 $\mu$），合计 $\lambda\pi_{n-1} + \mu\pi_{n+1}$。于是对 $n \ge 1$：

$$
\pi_n(\lambda + \mu) = \lambda\pi_{n-1} + \mu\pi_{n+1},
$$

   而 $n = 0$ 处没有死路，流出只有 $\lambda\pi_0$，流入只有 $\mu\pi_1$，即 $\lambda\pi_0 = \mu\pi_1$。这组方程和第 1 章泊松分布的微分方程组（§1.4 定理 1.3）是同一件事的稳态版：人数在指标 $n$ 上像水在阶梯间流动。
2. **归纳出细节平衡**。白话：全局平衡说「每行收支相抵」，我们断言更强的账目——相邻两层之间那道墙上，向上穿过的频率恰好等于向下的频率，即 $\lambda\pi_n = \mu\pi_{n+1}$ 对每个 $n$ 成立（这叫细节平衡，detailed balance）。归纳：$n = 0$ 的方程 $\lambda\pi_0 = \mu\pi_1$ 本身就是细节平衡。设 $\lambda\pi_{n-1} = \mu\pi_n$ 已成立，代入 $n$ 的全局平衡式右端第一项：

$$
\pi_n\lambda + \pi_n\mu = \mu\pi_n + \mu\pi_{n+1},
$$

   两边消去 $\mu\pi_n$，得 $\lambda\pi_n = \mu\pi_{n+1}$。归纳完成。这行等式在说：从 $n$ 升到 $n+1$ 的每一次，平均而言都有一次从 $n+1$ 降回 $n$ 与之配对——账本上相邻两行之间永远不打架。
3. **逐层递推**。由细节平衡，$\pi_{n+1} = \frac{\lambda}{\mu}\pi_n = \rho\,\pi_n$，迭代得 $\pi_n = \rho^n\pi_0$。
4. **归一化的账与稳定性条件**。全体概率求和必须等于 1：$\sum_{n \ge 0}\pi_n = \pi_0\sum_{n \ge 0}\rho^n$。几何级数当 $\lvert \rho \rvert < 1$ 收敛于 $\frac{1}{1-\rho}$，当 $\rho \ge 1$ 发散。所以 $\rho < 1$ 时 $\pi_0 \cdot \frac{1}{1-\rho} = 1$，即 $\pi_0 = 1-\rho$；$\rho \ge 1$ 时级数发散，不存在可归一化的解——平稳分布根本不存在，队长的概率质量一路漏向无穷：账本只进不出地堆积，像一只只进水不放水的浴缸。∎

读法与校准：$\pi_n = (1-\rho)\rho^n$ 是几何分布（geometric distribution）——第 1 章说过它是指数分布的离散表亲（§1.2），「越往后排人越少」按 $\rho$ 的幂衰减。两个立即可用的读数：$\pi_0 = 1-\rho$ 是台子空闲的时间占比；系统非空的概率 $1-\pi_0 = \rho$ 是台忙的时间占比。所以 $\rho = \frac{\lambda}{\mu}$ 身兼两职：它既是「每个平均服务时间里来几位客人」，又是「台子忙的时间占比」——后者正是利用率（utilization）这个名字的来源。

小结：生灭链的账本只有生 $\lambda$ 与死 $\mu$ 两笔；全局平衡经归纳加强成细节平衡，逐层递推出 $\pi_n = (1-\rho)\rho^n$，而「几何级数收敛」与「队列不漂移」是同一件事 $\rho < 1$ 的两张脸。

## $\rm \S \, 2.3$ 时间平均视角：$L$ 与 $L_q$

白话先行：平稳分布在手，「平均几个人」就是按 $\pi$ 求期望，剩下的活只有几何级数求和。记 $L = E[N]$（平均队长，含正在服务的那位）。

**定理 2.2（性能量全套）**：$\rho < 1$ 时，

$$
L = \frac{\rho}{1-\rho}, \qquad L_q = \frac{\rho^2}{1-\rho}, \qquad W = \frac{1}{\mu - \lambda}, \qquad W_q = \frac{\rho}{\mu - \lambda}.
$$

本节证前两个（时间平均量），后两个（每个顾客亲历的时间）留给下一节从到达者视角推。

**$L$ 的推导**。按定义求和，先用一个求和引理：对 $\lvert x \rvert < 1$，对几何级数 $\sum_{n \ge 0} x^n = \frac{1}{1-x}$ 两边逐项求导（收敛域内部允许），得 $\sum_{n \ge 1} n\,x^{n-1} = \frac{1}{(1-x)^2}$，乘 $x$ 得

$$
\sum_{n \ge 1} n\,x^n = \frac{x}{(1-x)^2}.
$$

于是

$$
L = \sum_{n \ge 0} n\,(1-\rho)\rho^n = (1-\rho)\cdot\frac{\rho}{(1-\rho)^2} = \frac{\rho}{1-\rho}.
$$

读法：分子 $\rho$ 是已占用的强度，分母 $1-\rho$ 是剩余的容量——队长等于「已用比余量」。校准：$\rho = 0.9$ 给 $L = 9$，$\rho = 0.99$ 给 99，§2.1 的直觉冲击现在有了出处。

**$L_q$ 的推导**。队列长（只数排队等候的）与队长（含在服的）只差一个 0/1 指示：台子忙不忙。忙的概率是 $1-\pi_0 = \rho$，所以

$$
L_q = \sum_{n \ge 1} (n-1)\,(1-\rho)\rho^n = L - (1 - \pi_0) = \frac{\rho}{1-\rho} - \rho = \frac{\rho^2}{1-\rho}.
$$

读法：队伍比全队少的那个数恰是利用率 $\rho$——正在被服务的那位不该算进「排队的人」里。校准：$\rho = 0.9$ 给 $L_q = 8.1$，与 $L = 9$ 只差 0.9（那位在服的顾客）。

小结：$L$ 与 $L_q$ 都由几何级数求和一步得出，差值 $L - L_q = \rho$ 恰好是台子忙的时间占比。

## $\rm \S \, 2.4$ 到达者视角：$W$ 与 $W_q$

白话先行：$L$ 站在店门口数人，是时间的平均；顾客关心的却是「我进去要待多久」。换视角：跟着一位到达者走一遍，用三块现成的砖拼出答案。

1. **PASTA**（§1.5 回收）：泊松到达者看到的队长分布就是平稳分布 $\pi$——到达时刻是完全随机的时间抽样，不挑人多的时候。且到达者看的是「自己进门之前」的店，不把自己数进去。
2. **剩余服务时间**（§1.2 回收）：到达撞上台子忙时，在服那位已经做了多久与你无关——无记忆性使它的剩余时间仍是 $\mathrm{Exp}(\mu)$，均值 $\frac{1}{\mu}$，一个完整的「平均服务时间」。
3. **期望的线性性**：等待是前面每个人各一段服务时间的和，求期望只需要相加，不需要独立（自检第 5 条）。

设到达者看到 $n$ 个人（含在服者）。排队时间是 $n-1$ 位排队者各一段完整服务，加在服者的一段剩余，共 $n$ 段、每段期望 $\frac{1}{\mu}$；再加自己的服务 $\frac{1}{\mu}$ 才离开系统。于是

$$
E[W_q \mid \text{看到 } n] = \frac{n}{\mu}, \qquad E[W \mid \text{看到 } n] = \frac{n+1}{\mu}.
$$

对看到的队长取期望（由 PASTA，其期望就是 $L$）：

$$
W_q = \frac{L}{\mu} = \frac{\rho}{(1-\rho)\,\mu} = \frac{\rho}{\mu - \lambda}, \qquad W = \frac{L + 1}{\mu} = \frac{1}{(1-\rho)\,\mu} = \frac{1}{\mu - \lambda}.
$$

定理 2.2 全部得证，且没有一步用几何级数以外的重机器。读法：分母 $\mu - \lambda$ 是净消化速率——服务比到达每单位时间多啃掉几单；平均系统时间就是净速率的倒数。校准：$\mu = 1$、$\rho = 0.9$ 时 $W = 10$，是平均服务时间的 10 倍——你自己的服务只占其中的 1，其余 9 全是排队。自检：$W - W_q = \frac{1-\rho}{\mu-\lambda} = \frac{1}{\mu}$，恰为自己的服务时间，账目吻合。

小结：$W$ 与 $W_q$ 不另起炉灶，靠 PASTA 把到达者所见接到 $\pi$ 上、靠无记忆把剩余服务折成 $\frac{1}{\mu}$，四件性能量至此全部闭式。

## $\rm \S \, 2.5$ Little 定理预演：对账

白话先行：现在手里有两套独立算出的答案——时间平均（$L$、$L_q$）与到达平均（$W$、$W_q$），把它们对起来看。

代数只有三行：

$$
\lambda W = \frac{\lambda}{\mu - \lambda} = \frac{\lambda/\mu}{1 - \lambda/\mu} = \frac{\rho}{1-\rho} = L,
$$

$$
\lambda W_q = \frac{\lambda\rho}{\mu - \lambda} = \rho\cdot\frac{\rho}{1-\rho} = \frac{\rho^2}{1-\rho} = L_q,
$$

加上上一节已验的 $W = W_q + \frac{1}{\mu}$，三行全中。读法：$\lambda W = L$ 说的是「店里有几个人 = 每分钟进来几个 × 每人待多久」——流量、存量与停留时间的恒等式，和「水库蓄水量 = 入流 × 停留时间」是同一句话。

这不是 M/M/1 的巧合，而是 Little 定理（Little's law）$L = \lambda W$ 的首次现身。第 3 章将证明：它几乎不需要任何假设——到达不必泊松、服务不必指数、台数不限，只要系统稳态且流量守恒，恒等式就成立。M/M/1 的价值在于它是唯一能显式算出等式两端的最简模型：我们先在这里亲眼看到定理成立，第 3 章再回答「为什么总是这样」。要交代的账目：上面 $W$ 的推导动用过一次 PASTA，所以这次对账还不是「一般版本的证据」；第 3 章的一般证明会把它绕开。

小结：两套独立推导的量被 $\lambda W = L$、$\lambda W_q = L_q$ 精确锁死——Little 定理的预告片放完，正片在第 3 章。

## $\rm \S \, 2.6$ 数值锚：闭式表、模拟对照与 $\rho \to 1$

**闭式总表**（取 $\mu = 1$，时间以平均服务时间为单位，$\lambda = \rho$；数值均由 Python 直接计算）：

| $\rho$ | $L$ | $W$ | $W_q$ | $L_q$ |
| --- | --- | --- | --- | --- |
| 0.5 | 1 | 2 | 1 | 0.5 |
| 0.8 | 4 | 5 | 4 | 3.2 |
| 0.9 | 9 | 10 | 9 | 8.1 |
| 0.95 | 19 | 20 | 19 | 18.05 |
| 0.99 | 99 | 100 | 99 | 98.01 |

读表三句话：1. $L$ 与 $W_q$ 数值相同是 $\mu = 1$ 这个单位选择的巧合（一般关系是 $W_q = \frac{L}{\mu}$）。2. $W$ 的膨胀节奏：$\rho$ 从 0.5 到 0.8 翻 2.5 倍，从 0.95 到 0.99 直接翻 5 倍。3. 最后一行就是临界恶化的样子：$\rho = 0.99$ 时在系统里平均要耗 100 个平均服务时间，而其中 99 个在排队。

**模拟对照**（全部真跑）：手写事件循环——到达与离开各持一个钟，每次推进到更早的那只，指数间隔用逆变换法生成。每个种子服务 $10^6$ 位顾客（约 $2 \times 10^6$ 个事件），预热期（前 10% 事件）不进统计；$\rho = 0.9$ 处合并 24 个独立种子。结果：

| 量 | 理论 | 模拟（合并） | 相对误差 |
| --- | --- | --- | --- |
| $L$ | 9 | 9.043 | +0.47% |
| $W$ | 10 | 10.044 | +0.45% |
| $W_q$ | 9 | 9.044 | +0.49% |
| $L_q$ | 8.1 | 8.142 | +0.52% |

四个量全部落在 1% 以内，闭式解与模拟互相盖章。（诚实备注：$\rho = 0.9$ 时单个种子的波动就有约 $\pm 2\%$——队长起伏的相关时间约 380 个服务时间，一个种子只覆盖几千个独立起伏，所以必须多种子合并；这句备注正是下一段的主角。）

**$\rho = 0.99$ 的临界恶化演示**：闭式解说 $W = 100$。模拟同一套循环跑 5 个种子，单种子 $W$ 分别为 83.6、72.1、105.8、118.3、80.0，合并 92.0——系统性偏低且种子间散布达 71 到 118。为什么模拟在 $\rho = 0.99$ 处失灵？M/M/1 队长起伏的自相关时间约为 $\frac{1}{(\sqrt{\mu} - \sqrt{\lambda})^2}$ 个服务时间（生灭链最慢衰减率的倒数，超出本章范围，见 Kleinrock《Queueing Systems Vol.1》第 2 章）：$\rho = 0.9$ 时约 380，$\rho = 0.99$ 时约 $4 \times 10^4$——同样的运行长度，能采到的独立起伏从几千个跌到几十个。临界恶化有第二张脸：$\rho \to 1$ 不只让队伍爆炸，还让系统变得极难测量，你自己做实验时也会撞上它。比喻归位：恰好吃满的餐厅，不仅每分钟都在崩溃边缘，而且你连「它到底多接近崩溃」都要观察很久才说得准。

小结：闭式表给出了校准曲线，24 种子模拟以小于 1% 的误差盖章，而 $\rho = 0.99$ 的模拟失灵本身成了临界恶化的又一课。

## $\rm \S \, 2.7$ 关键概念回顾

1. 为什么 M/M/1 的状态过程是生灭链？生率与死率各是什么、各从第 1 章的哪条性质来？
2. 全局平衡方程与细节平衡方程是什么关系？归纳证明的第二步代入了什么、消去了什么？
3. $\rho < 1$ 同时是哪两件事的条件？$\rho \ge 1$ 时归一化在哪一步失败？
4. $L$ 与 $L_q$ 的差为什么恰是 $\rho$？「排队的人」和「在系统里的人」差的是谁？
5. 从到达者视角推 $W$ 用了哪三块砖？每块各回收第 1 章的哪一节？
6. Little 定理在 M/M/1 里验证了哪三条关系？为什么这次对账还不算一般证明？

## $\rm \S \, 2.8$ 应用与辨析

1. 请求到达率 $\lambda = 4$ 每秒，服务器处理率 $\mu = 5$ 每秒。求 $L$、$W$、$W_q$、$L_q$、$\pi_0$，以及到达者看到至少 3 个请求在系统中的概率。
2. 诊所的服务平均 1 分钟一位（$\mu = 1$ 每分钟）。要让平均排队时间 $W_q$ 不超过 1 分钟，到达率 $\lambda$ 最多是多少？再问：要让平均系统时间 $W$ 不超过 1 分钟呢？
3. 同一系统 $\mu = 1$、$\lambda = 0.9$（$W = 10$）。两个改进方案：「处理率提高 10%」（$\mu \to 1.1$）与「到达率压降 10%」（$\lambda \to 0.81$），分别算改进后的 $W$ 并解释差异。
4. 一个窗口排队（$L$ 与 $W$ 已知）与两个窗口共用一条队，哪个好？用 $\lambda = 1.6$、$\mu = 1$ 给出数字对比：两个独立 M/M/1 各接 $\lambda/2$，对照 M/M/2 的精确值。
5. 有同学说：「模拟 $\rho = 0.99$ 的 M/M/1，跑 $10^6$ 个事件就够了，反正误差总是 1% 以内。」指出错误并给出定量依据。

## $\rm \S \, 2.9$ 本章自测答案

> 先闭卷作答 §2.7 与 §2.8，再核对。

### $\rm \S \, 2.9.1$ 关键概念回顾答案

1. 状态取队长 $N(t)$；生率 $\lambda$ 来自泊松流的普通性与独立增量（§1.4），与状态无关；死率 $\mu$ 来自服务的无记忆性（§1.2）——忙时任一瞬间的完成率恒为 $\mu$，与已服务多久无关；$\mu_0 = 0$ 因为空店无单可做。两个 M 都是「无记忆」。
2. 全局平衡是「每个状态流入率 = 流出率」；细节平衡更强：「相邻两层之间那道墙向上与向下的流率相等」。归纳第二步把假设 $\lambda\pi_{n-1} = \mu\pi_n$ 代入 $n$ 层的全局平衡式，两边消去 $\mu\pi_n$ 得 $\lambda\pi_n = \mu\pi_{n+1}$。（§2.2）
3. $\rho < 1$ 既是几何级数 $\sum\rho^n$ 收敛的条件（归一化可行），也是队列不漂移的条件（平稳分布存在）。$\rho \ge 1$ 时求和发散，$\pi_0$ 解不出来——概率质量漏向无穷。（§2.2）
4. 差是「正在被服务」的 0/1 指示的期望，即台忙概率 $1-\pi_0 = \rho$：「在系统里」比「在排队」多出在服的那一位。（§2.3）
5. 三块砖：PASTA（所见分布 = $\pi$，§1.5）、剩余服务时间仍 $\mathrm{Exp}(\mu)$（无记忆，§1.2）、期望的线性性（自检第 5 条，不需独立）。（§2.4）
6. 三条：$\lambda W = L$、$\lambda W_q = L_q$、$W = W_q + \frac{1}{\mu}$。这次对账中 $W$ 的推导动用了 PASTA，依赖泊松到达，所以只是定理在特例上的验证；一般证明（几乎无假设）在第 3 章。（§2.5）

### $\rm \S \, 2.9.2$ 应用与辨析答案

1. $\rho = 0.8$：$L = 4$，$W = \frac{1}{5-4} = 1$ 秒，$W_q = 0.8$ 秒，$L_q = 3.2$，$\pi_0 = 0.2$。尾概率用几何分布求和：$P(N \ge 3) = \sum_{n \ge 3}(1-\rho)\rho^n = \rho^3 = 0.512$——九成的负载下，到达者有超过一半的概率撞上 3 个以上的请求。（§2.2–2.3）
2. $W_q = \frac{\rho}{\mu(1-\rho)} \le 1$ 解出 $\rho \le \frac{1}{2}$，即 $\lambda \le 0.5$ 每分钟（核对：$\rho = 0.5$ 时 $W_q = 1$）。$W \le 1$ 分钟则无解：$W = \frac{1}{\mu-\lambda} \ge \frac{1}{\mu} = 1$ 分钟，等号只在 $\lambda = 0$ 时成立——平均系统时间的下界是你自己的服务时间，想突破它只能加快服务。（§2.4）
3. 处理率 +10%：$W = \frac{1}{1.1-0.9} = 5$，砍半。到达率 −10%：$W = \frac{1}{1-0.81} \approx 5.26$，略逊。原因：$W = \frac{1}{\mu-\lambda}$ 只看差值，服务端 +0.1 把差从 0.1 抬到 0.2（翻倍），到达端 −0.09 只抬到 0.19。高负载时改进要砸在瓶颈端——差值小，同幅度的拨动在分子上效果被放大。（§2.4）
4. 两个独立 M/M/1 各接 $\lambda/2 = 0.8$：每队 $W = \frac{1}{1-0.8} = 5$。M/M/2（精确值，由生灭链平稳分布算出）：$L = 4.44$、$W = 2.78$、$W_q = 1.78$、到达需等待的概率 0.711——系统时间几乎砍半。方向性解释：分开排队时，一条队空着台子闲、另一条队还在排，闲置不被共享；共用一条队后任何空闲窗口都能接客。M/M/2 的闭式推导（Erlang C 公式）超出本章范围，见 Kleinrock《Queueing Systems Vol.1》第 3 章。（§2.2）
5. 错。误差不是自动 1%：单种子波动由队长起伏的相关时间决定，约为 $\frac{1}{(\sqrt{\mu}-\sqrt{\lambda})^2}$ 个服务时间——$\rho = 0.9$ 时约 380，$\rho = 0.99$ 时约 $4 \times 10^4$。$10^6$ 个事件在 $\rho = 0.99$ 处只覆盖几十个独立起伏，实测 5 个种子的 $W$ 散布在 72 到 118 之间（理论值 100）。要压进 1%，事件数需再涨几个量级。（§2.6）

---

M/M/1 到此全解剖完毕：账本（生灭链）、账目（细节平衡）、四个稳态量的闭式解、两套视角的对账。但我们心里清楚，这一章动用了一件奢侈品——PASTA，它只在泊松到达时成立；而且 $W$ 是绕道 $L$ 才算出来的。有没有一条不挑到达过程、不挑服务分布、连「到达者所见」都不需要的普适关系，直接把「平均几人」和「平均待多久」锁死？有，它就是刚才对账对出来的 $\lambda W = L$：Little 定理。第 3 章给它一般证明，并看这条一行等式如何成为系统设计里最便宜的会计。
