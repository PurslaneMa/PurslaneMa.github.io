# $\rm Chapter \, 2$ 凸包：Andrew 与 Graham

地基（第 1 章）打好了，本册盖的第一座主体建筑是凸包——点集的「外轮廓」。它值得用一整章郑重其事：一方面它是 OI 的万金油，直接出题（求周长面积、最小外接、直径）与间接出题（作为直径、最小矩形、二维 LP 的前置结构）都常考；另一方面它的主算法 Andrew 单调链只有十几行，却把这十几行**每一行都证到脚下**的完整正确性论证，教科书常常跳步。本章的主证就是那套全证：排序、双链、弹出条件的几何读法、以及「被弹出的点为什么永不再入」的排序论证。Graham（1972）的极角扫描是历史起点，Andrew（1979）的单调链用一次字典序排序把它改造成更好写的版本——本章主讲后者，前者在 §2.2 给出一句定位。

> 4. □ 鞋带公式（第 1 章 §1.4；§2.4 用它验收凸包面积）。

## $\rm \S \, 2.1$ 凸包的定义与性质

白话：把所有钉子按在板上，拿一根橡皮筋撑到最紧松手，橡皮筋的形状就是凸包。它是「恰好围住所有点的最紧凸边界」，一切的「最紧」都该被问一句精确含义，于是有定义。

**定义（凸包）**：点集 $S$ 的凸包 $\operatorname{conv}(S)$ 定义为所有包含 $S$ 的凸集的交。平面情形它是一个凸多边形，其**顶点**恰是 $S$ 中那些不能表示成其余点凸组合的点——直观说，就是橡皮筋真正绷到的那些钉子。

两条立刻能用、本章反复依赖的性质：

1. **顶点数不超过输入数**：顶点是输入点的子集，$h \le n$，其中 $h$ 记凸包顶点数。这条看似废话的性质是复杂度分析的支点——很多凸包上的算法（包括第 3 章的旋转卡壳）开销按 $h$ 而不是按 $n$ 记。
2. **凸包唯一**：交的定义天然唯一；更重要的是，任何「含全部输入点的凸多边形、且顶点取自输入点」的实现都是它（§2.2 末尾用一行包含论证兑现）。所以算法比赛只需要比「谁写得对」，不存在「两个都对但答案不同」。

构造算法的谱系一句话定位：**Jarvis 礼物包装（gift wrapping）** 沿着边界走，每步在全部点里扫出当前方向上「最外」的那个点，单步 $O(n)$、共 $h$ 步，总 $O(nh)$——好想好写，但 $h \to n$（全部点都在凸包上）时退化为平方；本章主证的主角 **Andrew 单调链** 以一次排序换掉这个退化，做到 $O(n \log n)$，且是本章的下界（§2.3）能证到的极限。

实践里 $h$ 往往远小于 $n$：随机均匀点集的凸包顶点数期望只有 $O(\log n)$ 量级，网格化、圆周分布才会把 $h$ 顶到 $n$——所以「先建包、再在包上做 $h$ 量级的事」是许多几何题的提速骨架，而不是保守优化。凸性值得当作全部保护的来源还有一层：凸集对线段封闭，凸包上的任何局部最优自动是全局最优——第 3 章的单峰性、LP 的顶点定理，都是这一句话在不同名字下的重演。

**本节小结**：凸包 = 最紧凸边界 = 顶点数 $h \le n$ 的唯一凸多边形；Jarvis $O(nh)$ 给直觉，Andrew $O(n \log n)$ 给实现，下一节把后者证全。

## $\rm \S \, 2.2$ Andrew 单调链：主证全证

白话：把点从左到右排成一列，从左往右扫一遍维护「到目前为止的**下**边界」，再从右往左扫一遍维护「**上**边界」，两段拼起来就是凸包。下边界用栈维护：新点来了，把「挡路」的旧点弹掉。

**实现**（去重、两链拼接都做实，可直接提交）：

```cpp
vector<P> convex_hull(vector<P> pts) {
    sort(pts.begin(), pts.end());                     // 字典序: 先 x 后 y
    pts.erase(unique(pts.begin(), pts.end()), pts.end());   // 去重: 重复点是退化源
    int n = pts.size();
    if (n <= 2) return pts;                           // 0/1/2 点: 本身即答案
    vector<P> lo, up;                                 // 下链 / 上链
    for (int i = 0; i < n; i++) {                     // 下链: 从最左到最右
        while (lo.size() >= 2 && cross(lo[lo.size()-2], lo.back(), pts[i]) <= 0)
            lo.pop_back();                            // 不左转(右转或共线)就弹
        lo.push_back(pts[i]);
    }
    for (int i = n - 1; i >= 0; i--) {                // 上链: 反向再扫一遍
        while (up.size() >= 2 && cross(up[up.size()-2], up.back(), pts[i]) <= 0)
            up.pop_back();
        up.push_back(pts[i]);
    }
    lo.pop_back(); up.pop_back();                     // 各去掉收尾的最右/最左点
    lo.insert(lo.end(), up.begin(), up.end());        // 拼接: 逆时针整圈
    return lo;
}
```

弹出条件 `cross <= 0` 的几何读法：链上最后两点与新点**不构成左转**（右转或三点共线）时，中间那个点是「凹」的或「平」的，不配当凸包顶点，弹。取 $\le$ 而不是 $<$，弹掉的还包括共线的中点——这是「只要极点、不收边上共线点」的口径；若题目要求把共线点全收进边界，把条件放宽成 `cross < 0` 即可，正确性论证逐字不变。重复点必须去重：两个相同点会让叉积恒为零、把边界点误弹（这也是 §2.4 锚点数据里真实发生的）。

在锚点数据（§2.4 的 seed = 11，去重 28 点）上把下链的前半程走一遍，三个现场细节全部冒头：

1. 处理 $(1,19)$（与前点 $(1,1)$ 同 $x$）：$\operatorname{cross}((0,2),(1,1),(1,19)) = 18 > 0$，左转成立，链沿竖直边爬升——同 $x$ 批不是人为构造，锚点数据第一批就出现；
2. 处理 $(6,16)$：$\operatorname{cross}((6,5),(6,7),(6,16)) = 0$，共线中点 $(6,7)$ 被 $\le$ 弹出——极点口径在真实数据上开火，而不是只在教科书里开火；
3. 处理 $(8,10)$：一口气弹出 $(7,20)$（叉积 $-4$）与 $(7,16)$（叉积 $-17$），随后对 $(6,5)$ 左转成立——一步入栈、两步出栈，§2.3 摊还账本的原始素材。

后半程继续吸收、弹出，终局下链为 $(0,2),(1,1),(19,0),(20,5),(20,19)$——末段 $(20,5) 	o (20,19)$ 正是同 $x$ 批的竖直收尾；上链对称地从 $(20,19)$ 走回 $(1,19)$，两链各去收尾点拼接，恰好得到 §2.4 表格里的 8 个顶点。

**定理（正确性）**：设输入去重后按字典序处理，则下链终局恰为点集的下凸包（从最左点到最右点、沿下方的顶点序列），上链对称，拼接恰为凸包顶点的逆时针序。

证明分四步，每步独立可查。

**第一步（弹出即永别）。** 每个点按排序恰被处理一次，处理时恰入栈一次；出栈之后没有任何代码路径会再把它压回来——它不会被第二次处理。这就是「被弹出的点永不再入」的全部内容：**排序让每点只发一张入场券**，弹出是单程票。

**第二步（链是凸的）。** 算法终止时链上相邻三点全部满足弹出条件的否定，即严格左转；又因按字典序处理且已去重，链上每条边指向 $x$ 严格增大的一侧（同 $x$ 批内部是竖直边，见第四步的补证）。左转加 $x$ 单调，等价于**链的斜率自左向右严格递增**——这正是「凸」的解析定义。

**第三步（覆盖边引理：弹出的点从此在链下）。** 设点 $w$ 在新点 $p$ 到来时被弹出，弹出的瞬间栈顶为 $s$，弹出条件是 $\operatorname{cross}(s, w, p) \le 0$。由 $s.x \le w.x \le p.x$（栈按 $x$ 递增、新点 $x$ 最大）与上式的符号翻转（$w$ 在直线 $sp$ 的右侧即下方或线上），$w$ 从此被一条**覆盖边**——$x$ 区间罩住 ${w.x}$、且 $w$ 在其下方或线上的链边——收编。关键事实：覆盖边会更新，但支配关系永不丢失。设当前覆盖边为 $(u, v)$，此后链尾每次被替换：

1. $v$ 被新点 ${p'}$ 弹出，新边 $(u, p')$：$u.x \le w.x \le v.x \le p'.x$，覆盖保持；支配性用「差函数过零定号」。两条直线同过 $u$，差沿 $x$ 是一次函数、在 $u_x$ 处为零，而它在 ${v.x}$ 处的取值由弹出条件 $\operatorname{cross}(u, v, p') \le 0$ 保证非负：

$$
\ell_{(u,p')}(x) - \ell_{(u,v)}(x) \;=\; \lambda\,(x - u_x), \qquad \lambda \;\ge\; 0,
$$

读法：一次函数两端定号即可整段定号——$\lambda \ge 0$ 且 $x \ge u_x$，故整条右半线上 $w$ 都在这条新边的下方或线上；${w.x}$ 落在其中；
2. $u$ 被新点 ${p'}$ 弹出，新边 $(u', p')$：此时 $u$ 在直线 ${u'p'}$ 的下方或线上（弹出条件），而直线 ${up'}$ 与 ${u'p'}$ 同过 ${p'}$，差在 ${p'.x}$ 处为零：

$$
\ell_{(u',p')}(x) - \ell_{(u,p')}(x) \;=\; \mu\,(x - {p'.x}), \qquad \mu \;\le\; 0,
$$

读法：${u.x}$ 处的弹出条件把差定号为非负，$x \le {p'.x}$ 与 $\mu \le 0$ 同号相乘，整条左半线差非负——${w.x}$ 仍在其中。

两条线性函数论证首尾相接，$w$ 在**每一条**后续覆盖边的下方或线上；覆盖边序列随链稳定而稳定，终局链中罩住 ${w.x}$ 的那条边（必存在：终局链从最左点连到最右点）也不例外。同理核验仍在栈中的点：对保留旧边用第二、一步的归纳，对新边 $(s, p)$，链凸加左转条件给出 $\operatorname{slope}(s,p) > \operatorname{slope}(z,s)$（$z$ 为任意更靠左的栈点或更早弹出的点，斜率递增链的弦斜率不超过右端边斜率），立即 $\operatorname{cross}(s,p,z) \ge 0$。

**第四步（同 $x$ 批与拼接）。** 同 $x$ 的点按 $y$ 序连续处理，批内竖直边的相邻三点半积展开后恰为 $(b_x - a_x)(c_y - b_y) \ge 0$ 的直接验证（或整体把坐标系旋转一个一般角度，叉积不变，化归 $x$ 互异的情形，两种收法任选其一即完整）。下链终局从最左点走到最右点、上链反向对称，各去掉收尾重复端点后拼接成逆时针闭圈；这个闭圈的每条边都有全体输入点在其上方或左侧（第一至三步），所以它是**含全部输入点的凸多边形，且顶点取自输入点**。于是用 §2.1 的唯一性话术收尾：记闭圈为 $Q$，$Q$ 凸且含 $S$，故 $\operatorname{conv}(S) \subseteq Q$；又 $Q$ 的顶点全在 $S$ 中，凸集由其顶点的凸组合张成，故 $Q = \operatorname{conv}(\text{顶点}) \subseteq \operatorname{conv}(S)$。两个包含合起来，$Q = \operatorname{conv}(S)$——输出恰是凸包，连同唯一性一并证完。∎

读法：这四步里真正干活的只有两件武器——排序给「每点一张入场券」（第一步），线性差函数给「弹出后支配关系不丢」（第三步）；第二、四步是把几何翻译成代数的簿记。整个证明没有出现一次角度与弧度，「凸」从头到尾只是叉积不等式——这正是第 1 章「多项式优于超越函数」纪律的兑现。历史上 Graham 1972 的极角扫描以某极点为基准按极角排序，极点选取与极角比较都要额外小心；Andrew 1979 的单调链换成字典序排序、双链各扫一遍，不需要极点、不需要三角函数，所以成为竞赛的标准写法。

**本节小结**：单调链 = 字典序排序加双链扫描，弹出条件「不左转就弹」；正确性 = 一张入场券（排序）加一条不丢的支配链（线性差函数），拼接与唯一性一包含论证收口。

## $\rm \S \, 2.3$ 复杂度：摊还 $O(n)$ 与排序下界

链扫描本身的账很好算，摊开写清楚：每个点恰入栈一次（入场券只有一张）；循环里弹出的每个点都曾入栈，且弹出后永不再入，故出栈总次数 $\le$ 入栈总次数 $= n$，两链合计栈操作 $O(n)$。单次循环里「一步弹两个」（§2.2 锚点数据的 $(8,10)$ 就弹了两个）不怕——贵的步骤由全体便宜步骤摊平，均摊每点常数，与扫描线均摊、并查集路径压缩同属一族。主导项是排序的 $O(n \log n)$，总复杂度 $O(n \log n)$。

这不是实现选择的偶然，而是问题本身的下限。陈述级论证（细节见 Preparata 与 Shamos《Computational Geometry》1985 年版第 3 章）：若凸包能 $o(n \log n)$ 求出，排序也能。把待排序的实数映到抛物线上：

$$
x_i \;\longmapsto\; \bigl(x_i,\ x_i^2\bigr), \qquad \operatorname{conv}\bigl\{(x_i,\ x_i^2)\bigr\} \text{ 的顶点沿链读出} \;=\; \{x_i\} \text{ 升序},
$$

读法：抛物线是严格凸的，全部点都是极点，凸包一个都不丢；凸包顶点沿链的顺序就是 $x$ 的顺序，按比较型模型读出凸包即读出排序。排序需要 $\Omega(n \log n)$ 次比较，凸包因此也是。所以 $O(n \log n)$ 不是「目前最快」，是**到此为止**；想更快只能换模型（如整数坐标的栅格技巧），那是另一场比赛。

**本节小结**：摊还让链扫描 $O(n)$，排序钉死 $O(n \log n)$，抛物线归约证明这个界不可再压——Andrew 恰好踩在下界上。

## $\rm \S \, 2.4$ 数值锚：seed = 11 的三十个点

以下锚点全部实测（§2.7 程序段可复跑）。取 `random.seed(11)` 生成的 30 个 $[0,20]^2$ 整数随机点：$(14,17),(14,14),(16,18),(6,5),(16,15),(20,19),(5,3),(14,9),(4,2),\cdots$。注意数据里 $(19,0)$ 与 $(20,19)$ 各出现两次——去重不是洁癖，它在锚点数据上真实触发，去重后 28 点。

算法结果：

| 项目 | 实测值 |
| --- | --- |
| 去重后点数 | $28$ |
| 凸包顶点数 $h$ | $8$ |
| 下链（左 → 右，含竖直收尾） | $(0,2),(1,1),(19,0),(20,5),(20,19)$ |
| 上链（右 → 左） | $(20,19),(17,20),(7,20),(1,19),(0,2)$ |
| 顶点（逆时针，两链各去收尾点拼接） | $(0,2),(1,1),(19,0),(20,5),(20,19),(17,20),(7,20),(1,19)$ |
| 鞋带面积（第 1 章 §1.4） | $373$ |

交叉验收：对每个输入点 $v$ 用「三角形覆盖」暴力重判——$v$ 是凸包顶点当且仅当 $v$ 不落在任何三个**其他**点构成的三角形内或边上（跳过零面积的退化三角形，否则共线三点组成的「扁三角形」会误判覆盖）。28 点的暴力顶点集与 Andrew 输出**逐点一致**，8 顶点无出入。这条暴力的定位与第 1 章 §1.3 的四案例一样：小规模对拍器，定算法对错。注意暴力的规模是 $O(n^4)$ 级（每点 × 三角形数），28 点能跑、30 万点想都别想——对拍器与正式算法在规模上的分工，本身就是一条工程纪律。

**本节小结**：锚点数据含重复点（去重真实触发），Andrew 与三角形覆盖暴力在 8 个顶点上完全一致，面积 373 留给第 3 章复用。

## $\rm \S \, 2.5$ 凸包的应用一瞥

1. **两点最远距离在凸包顶点上取到**：平面上 $n$ 个点的直径（最远点对）必是凸包的对踵点对——直觉上橡皮筋绷得最开的两端一定是钉子；证明与据此设计的 $O(h)$ 旋转卡壳是第 3 章的主证。没有凸包，直径要 $O(n^2)$ 暴力；有了凸包且 $h \ll n$，先建包再卡壳是标准两步。预告一个可当场复验的数：§2.4 锚点数据的直径平方为 $689$，最远点对是 $((0,2),(20,19))$——凸包左下角与右上角，第 3 章的卡壳程序与 $O(n^2)$ 暴力会对出同一个数。
2. **凸包与线性规划可行域**：线性目标 $c \cdot x$ 在凸多边形上取最大必在顶点取到（线性函数沿凸边界的单峰性，第 3 章 §3.1 会把这条性质证全），而二维 LP 的可行域顶点正是约束半平面交「凸包对偶」出的极点——离散优化册第 1 章讲 LP 几何时说的「最优解在顶点上」，与本册的凸包是同一枚硬币的两面。反过来，半平面交的极点算法与单调链共享同一套弹栈骨架——把「点」换成「半平面」、弹出条件换成「不满足约束」，读者会在第 4 章认出同一个循环。
3. **更多 OI 常客**：最小外接矩形与最小外接圆（第 3 章 §3.3、§3.5）、凸包周长（顶点相邻距离求和）、以及「动态加点的离线重扫」——点集会增删时用平衡树维护两条链，是单调链思想的结构化版本。

**本节小结**：直径、LP 顶点、外接形状——凸包是这些问题的公共前缀；第 3 章顺着第一条走到旋转卡壳。

## $\rm \S \, 2.6$ 六问与答

1. 凸包顶点数 $h$ 与输入数 $n$ 的关系？这条性质在哪两个算法的复杂度里登场？（答：$h \le n$，顶点是输入点子集；Jarvis 的 $O(nh)$ 与旋转卡壳的 $O(h)$ 都按它记账。）
2. 弹出条件 `cross <= 0` 里等号的几何含义？想保留边界上的共线点改哪里？（答：等号把「三点共线」也弹掉，即只要极点的口径；保留共线点改成 `cross < 0`，论证不变。）
3. 「被弹出的点永不再入」的论证靠什么？（答：排序——每点恰处理一次、恰入栈一次，弹出后没有代码路径再压回；不是栈的性质，是入场券只有一张。）
4. 重复输入点为什么必须去重？（答：相同点使叉积恒为零，按「不左转就弹」会把边界点误弹；锚点数据里 $(19,0)$、$(20,19)$ 各重复两次，真实触发。）
5. $O(n \log n)$ 下界的归约怎么构造？（答：$(x_i, x_i^2)$ 抛物线点集的凸包顶点沿链读出即 $x$ 排序；比较型模型下排序 $\Omega(n \log n)$，凸包同界。）
6. 为什么任何「含全部点的凸多边形且顶点取自输入」的实现都等于凸包本身？（答：双向包含——它含 $S$ 故 $\operatorname{conv}(S) \subseteq Q$；顶点属于 $S$ 故 $Q \subseteq \operatorname{conv}(S)$。）

## $\rm \S \, 2.7$ 程序段：Andrew 对账暴力

纯 Python。生成 seed = 11 的锚点数据，跑 Andrew（与 §2.2 的 C++ 逐行对应），再用三角形覆盖暴力对账，并打印凸包面积。

```python
import random

def cross(o, a, b):
    return (a[0]-o[0])*(b[1]-o[1]) - (a[1]-o[1])*(b[0]-o[0])

def hull_andrew(points):
    pts = sorted(set(points))                       # 去重 + 字典序
    if len(pts) <= 2:
        return pts
    def chain(seq):
        st = []
        for q in seq:
            while len(st) >= 2 and cross(st[-2], st[-1], q) <= 0:
                st.pop()                            # 不左转就弹
            st.append(q)
        return st
    lo = chain(pts)                                 # 下链: 左 -> 右
    up = chain(pts[::-1])                           # 上链: 右 -> 左
    return lo[:-1] + up[:-1]                        # 拼接: 逆时针整圈

def hull_brute(points):
    S = sorted(set(points))                         # v 是顶点 <=> v 不在任何
    def in_tri(a, b, c, q):                         # 其他三点三角形内/边上
        if cross(a, b, c) == 0:
            return False                            # 零面积三角形无裁决权
        d = [cross(a,b,q), cross(b,c,q), cross(c,a,q)]
        return all(x >= 0 for x in d) or all(x <= 0 for x in d)
    out = set()
    for v in S:
        rest = [p for p in S if p != v]
        covered = any(in_tri(rest[i], rest[j], rest[k], v)
                      for i in range(len(rest))
                      for j in range(i+1, len(rest))
                      for k in range(j+1, len(rest)))
        if not covered:
            out.add(v)
    return out

random.seed(11)
pts = [(random.randint(0, 20), random.randint(0, 20)) for _ in range(30)]
uniq = sorted(set(pts))
H = hull_andrew(pts)
B = hull_brute(pts)
print("n =", len(pts), " uniq =", len(uniq), " dup pairs =", len(pts) - len(uniq))
print("hull size:", len(H))
print("hull:", H)
print("brute identical:", set(H) == B)
A = sum(H[i][0]*H[(i+1) % len(H)][1] - H[(i+1) % len(H)][0]*H[i][1] for i in range(len(H)))
print("area:", A // 2)
 # 退化四连: 同 x 竖直批 / 全共线 / 重复点 / 单点
print(hull_andrew([(0,1),(5,0),(5,10)]))
print(hull_andrew([(0,0),(1,1),(2,2),(3,3)]))
print(hull_andrew([(0,0),(2,0),(1,1),(2,0),(0,0)]))
print(hull_andrew([(7,7)]))
```

## $\rm \S \, 2.8$ 带走清单

1. 凸包唯一、顶点数 $h \le n$；「含全部输入点的凸多边形且顶点取自输入」的实现都恰是它（双向包含一行）。
2. Andrew 单调链：字典序排序 + 去重 + 下上两链各扫一遍；弹出条件 $\operatorname{cross} \le 0$ = 「不左转就弹」，$\le$ 与 $<$ 之分是极点口径与收共线点口径之分。
3. 正确性四步：排序给「每点一张入场券」（弹出即永别）；左转 + $x$ 单调给链凸性；线性差函数给覆盖边支配不丢；拼接加双向包含收口。
4. 复杂度 $O(n \log n)$：链扫描摊还 $O(n)$，排序主导；抛物线归约 $(x_i, x_i^2)$ 证明比较型模型下无更快的可能。
5. 锚点：seed = 11 的 30 点去重 28，凸包 8 顶点 $(0,2),(1,1),(19,0),(20,5),(20,19),(17,20),(7,20),(1,19)$，面积 373，与三角形覆盖暴力完全一致。
6. 凸包是直径、最小外接矩形、二维 LP 顶点的公共前缀——下一章从直径开始把度量做全。
