## $\rm \S \, 1.1$ 叉积与方向判定

白话：平面几何算法问得最多的一句话是「沿着 $a$ 走到 $b$，再拐向 $c$，你往哪边拐」。回答它的工具是叉积。

**定义（叉积，三点定转）**：对有序三点 ${o, a, b}$，

$$
\operatorname{cross}(o,a,b) \;=\; (a-o)\times(b-o) \;=\; (a_x-o_x)(b_y-o_y)-(a_y-o_y)(b_x-o_x),
$$

即向量 $a-o$ 与 $b-o$ 的二维叉积标量。读法：把它想成「以 $o$ 为原点时，$a$ 到 $b$ 扫过的有向平行四边形面积」——$b$ 在有向直线 $oa$ 的**左侧**（逆时针拐）时为正，右侧为负，三点共线时恰为零。竞赛里这三种取值各有专名：左转记 $+1$，右转记 $-1$，共线记 $0$，方向谓词就是把叉积的符号折算成这三档。

数值锚（整数实算，一位不差）：

1. $\operatorname{cross}((0,0),(1,0),(0,1)) = 1\times 1 - 0\times 0 = 1$：从 $x$ 正方向拐向 $y$ 正方向，左转；
2. $\operatorname{cross}((0,0),(1,0),(0,-1)) = 1\times(-1) - 0\times 0 = -1$：右转；
3. $\operatorname{cross}((0,0),(1,1),(2,2)) = 1\times 2 - 1\times 2 = 0$：共线。

为什么不用 `atan2` 算角度再比大小？两个理由。速度上，叉积两次乘法一次减法，`atan2` 一次三角函数调用慢一个量级；正确性上，角度是浮点近似而叉积是二次多项式——整数坐标下叉积**精确**，角度在 $180^\circ$ 附近一丁点舍入就能把「左转」判成「右转」。这条「多项式优于超越函数」的纪律贯穿全册：凡能用加减乘判的，绝不开方、不取角。

叉积管侧向，点积管进度。**定义（点积与投影）**：$\operatorname{dot}(u,v) = u_x v_x + u_y v_y$；把点 $p$ 投影到有向直线 $oa$ 上，投影参数

$$
t \;=\; \frac{\operatorname{dot}(p-o,\; a-o)}{\operatorname{dot}(a-o,\; a-o)},
$$

读法：$t$ 是「$p$ 落在 $o\to a$ 路上的几分之几」——$t = 0$ 在起点 $o$，$t = 1$ 在终点 $a$，$t < 0$ 在 $o$ 身后，$t > 1$ 越过了 $a$。锚：$o=(0,0)$，$a=(2,0)$，$p=(3,1)$：$\operatorname{dot}((3,1),(2,0)) = 6$，$t = 6/4 = 1.5 > 1$，$p$ 在 $a$ 的前方。§1.3 求点到线段距离时，第一件事就是把 $t$ 夹进 $[0,1]$。

**本节小结**：叉积给「哪边」，点积给「多远」；两者都是多项式，整数域下零误差——这是后面一切算法敢于分支的底气，而底气何时失效，正是下一节的开战理由。

## $\rm \S \, 1.2$ 精度战争

白话：几何题不是算出来的，是防出来的。数值计算每一步都在舍入，而几何算法对判号零容忍——一行 `if` 走错，凸包变形、相交误判、面积偏差，而且**没有报错**，只有悄悄错的答案。本节用三起实测事故讲清敌人是谁，再给应对阶梯。

**事故一：整数恰好共线，是安全的。** 取 $a=(0,0)$，$b=(10^9,\ 10^8+3)$，$c=(2\times 10^9,\ 2\times 10^8+6)$，三点严格共线，叉积真值为 $0$。把坐标读进 `double` 再按 $\S 1.1$ 的公式算，实测输出**恰为 $0.0$**。这不像巧合，看机理就明白：两边的乘积 $10^9 \times (2\times 10^8+6)$ 与 $(10^8+3)\times 2\times 10^9$ 是**同一个实数**，IEEE 舍入是确定性规则，同一个实数必然舍到同一个 `double`，相减精确得零。整数坐标恰好共线的三点，浮点叉积恒精确为零——这条反直觉的事实值得记住，因为下一起事故会在它旁边炸开。

**事故二：整数近共线，翻车。** 取 $a=(0,0)$，$b=(999999937,\ 499999968)$，$c=(999999935,\ 499999967)$。叉积真值

$$
999999937\times 499999967 - 499999968\times 999999935 \;=\; -1,
$$

三点**不共线**（真叉积 $-1$）。`double` 实算输出 $0.0$——把不共线判成共线。机理：两个乘积都在 $5\times 10^{17}$ 量级，而 `double` 只有 52 位尾数，此量级的格距（ulp）是 $64$；真实值相差 $1$ 的两个乘积几乎必然落进同一个格，舍入后一个模样，相减得零。真值 $-1$ 被噪声吞掉，不是「误差大一点」，是**答案反了**。竞赛坐标动辄 $10^9$，这类构造就在题目数据里等着——这正是 OI 圈「坐标 $10^9$ 必须全程 `long long`」的铁律来源。

**事故三：小数坐标，入口即失守。** 取 $a=(0,0)$，$b=(3,\ 0.9)$，$c=(9,\ 2.7)$——十进制下严格共线（$y = 0.3x$）。`double` 实算叉积 $1.7763568394002505\times 10^{-15}$，非零：$0.9$ 与 $0.3$ 在二进制里本来就存不准，入口舍入破坏了事故一赖以幸免的对称性，「恰好共线」这个概念在浮点域里根本不存在。

浮点不可信，第一反应通常是加容差：$\lvert\operatorname{cross}\rvert < \varepsilon$ 就当共线。这条 $\varepsilon$ 判据有两大坑，各配一个实测。

**坑一：不可传递。** 令 $\varepsilon = 10^{-9}$，取 $x_0 = 0.1$，$x_1 = x_0 + 0.6\times 10^{-9}$，$x_2 = x_1 + 0.6\times 10^{-9}$。实测：$\lvert x_1 - x_0\rvert = 6.00\times 10^{-10} < \varepsilon$，判「相等」；$\lvert x_2 - x_1\rvert = 6.00\times 10^{-10} < \varepsilon$，判「相等」；但 $\lvert x_2 - x_0\rvert = 1.20\times 10^{-9} > \varepsilon$，判「不等」。「近似相等」不满足传递律，把它当等价关系用于去重、合并、判共线，链条一长就自相矛盾。**坑二：尺度依赖。** 把事故三那组真共线三点整体放大，$\varepsilon$ 固定 $10^{-9}$，实测判决表：

| 缩放 | `double` 叉积 | $\varepsilon = 10^{-9}$ 判决 | 真实情况 |
| --- | --- | --- | --- |
| $\times 2^0$ | $1.78\times 10^{-15}$ | 共线 | 共线（碰对） |
| $\times 2^{12}$ | $2.98\times 10^{-8}$ | 不共线 | 共线（判错） |
| $\times 2^{20}$ | $1.95\times 10^{-3}$ | 不共线 | 共线（判错） |

同一几何构形，换个单位制，判决翻转——因为叉积噪声随坐标平方增长，而 $\varepsilon$ 原地不动。图形学册第 6 章 §6.4 用米与毫米的勘测数据给过同一结论的工程版。两个坑合起来读出一句判词：$\varepsilon$ 判据不是修正，是把一个数学事实换成押注尺度的赌局。

于是有解法阶梯，一级比一级贵，也一级比一级可信：

1. **坐标放大取整**。输入保证至多 $k$ 位小数时，全部坐标乘 $10^k$ 取整，此后按整数算。代价藏在预算里：叉积把放大倍数**平方**放大——$\times 100$ 的输入让叉积翻 $10^4$ 倍，溢出预算跟着缩水（下一级的账本）。
2. **整数算术**。坐标本来是整数（或已放大取整）时，全程 `long long`，判号零误差。预算要自己数：坐标绝对值不超过 $10^9$ 时，坐标差不超过 $2\times 10^9$，单个乘积不超过 $4\times 10^{18}$，叉积绝对值不超过 $8\times 10^{18}$，而 $2^{63}-1 \approx 9.22\times 10^{18}$——装得下，余量约 $13\%$；坐标再大就换 `__int128`。事故二之所以翻车，正是因为把整数读进了 `double`：整数算术的前提是**从头到尾不碰浮点**。
3. **自适应精确谓词**。浮点输入又必须精确判号时的工业答案：先用 `double` 快算，同时算出误差预算，$\lvert\operatorname{cross}\rvert$ 超过预算则符号可信、直接返回；否则进入扩展算术精确重算（Shewchuk 1997，《Discrete \& Computational Geometry》18 卷 3 期）。绝大多数输入走快路径，退化输入多花时间但符号永真。机制在图形学册第 6 章 §6.4 已展开，本册后文默认「判号可信」即指这三级的某一级已到位。

**本节小结**：整数恰共线安全、整数近共线翻车、小数入口失守；$\varepsilon$ 不可传递又尺度依赖；解法沿「放大取整 → 整数算术 → 自适应谓词」逐级加价。本册此后各章的默认立场：坐标整数、全程整数算术——防住，才算算完。

## $\rm \S \, 1.3$ 距离、投影与线段相交

有了可信的叉积与点积，距离与相交可以写成纯代数，不需要任何三角函数。

**点到直线距离。** 直线由有序两点 ${o, a}$ 给出，点 $p$ 到它的距离：

$$
\operatorname{dist}(p,\; oa) \;=\; \frac{\lvert\operatorname{cross}(o,a,p)\rvert}{\lvert a-o\rvert},
$$

读法：$\lvert\operatorname{cross}\rvert$ 是三角形 $oap$ 面积的两倍（以 $oa$ 为底），除以底长即得高。锚：$p=(0,3)$ 到直线 $y = 0$（$o=(0,0)$，$a=(4,0)$）：$\lvert\operatorname{cross}\rvert = 12$，底长 $4$，距离 $3$。

**点到线段距离。** 线段比直线多出两个端点，先把投影参数 $t$（§1.1）夹进 $[0,1]$：

$$
\operatorname{dist}(p,\; \overline{oa}) \;=\;
\begin{cases}
\lvert p-o\rvert, & t \le 0, \\
\lvert p-a\rvert, & t \ge 1, \\
\lvert\operatorname{cross}(o,a,p)\rvert / \lvert a-o\rvert, & 0 < t < 1.
\end{cases}
$$

读法：垂足落在线段外时，最近点就是较近的端点；落在段内时退化为点到直线。三分支一枚不漏。

**线段相交的完整判定。** 白话：两条线段要么「互相跨过对方」，要么「靠端点或共线摸到对方」——判定必须把两类都接住，缺一类就漏一种相交。对线段 $\overline{p_1p_2}$ 与 $\overline{q_1q_2}$，记四个方向谓词 $d_1 = \operatorname{cross}(q_1,q_2,p_1)$、$d_2 = \operatorname{cross}(q_1,q_2,p_2)$、$d_3 = \operatorname{cross}(p_1,p_2,q_1)$、$d_4 = \operatorname{cross}(p_1,p_2,q_2)$。$d_1 d_2 < 0$ 说明 ${p_1, p_2}$ 严格分居直线 $q_1q_2$ 两侧（**跨立实验**），$d_3 d_4 < 0$ 反向同理；任何一个 $d_i = 0$ 说明对应点落在对方直线上，此时用外接框检查它是否落在线段内：

```python
def on_seg(a, b, c):                      # 已知 c 在直线 ab 上：是否落在线段 ab 内
    return min(a[0],b[0]) <= c[0] <= max(a[0],b[0]) and min(a[1],b[1]) <= c[1] <= max(a[1],b[1])
def seg_inter(p1, p2, q1, q2):            # 整数坐标下精确
    d1 = cross(q1,q2,p1); d2 = cross(q1,q2,p2)
    d3 = cross(p1,p2,q1); d4 = cross(p1,p2,q2)
    if ((d1>0 and d2<0) or (d1<0 and d2>0)) and ((d3>0 and d4<0) or (d3<0 and d4>0)):
        return True                       # 双向严格跨立：规范相交
    if d1==0 and on_seg(q1,q2,p1): return True
    if d2==0 and on_seg(q1,q2,p2): return True
    if d3==0 and on_seg(p1,p2,q1): return True
    if d4==0 and on_seg(p1,p2,q2): return True
    return False
```

四个锚案例（全部由这段代码实测，整数坐标）：

| 案例 | 线段一 | 线段二 | 判定 | 真值 |
| --- | --- | --- | --- | --- |
| 十字相交 | $(0,0)$–$(4,4)$ | $(0,4)$–$(4,0)$ | True | True |
| 端点触碰 | $(0,0)$–$(2,2)$ | $(2,2)$–$(4,0)$ | True | True |
| 共线重叠 | $(0,0)$–$(4,4)$ | $(2,2)$–$(6,6)$ | True | True |
| 平行不交 | $(0,0)$–$(4,0)$ | $(0,1)$–$(4,1)$ | False | False |

端点触碰由第二个 `d3==0` 分支接住（$q_1 = (2,2)$ 落在直线 $p_1p_2$ 上且在外接框内），共线重叠由共线分支的框重叠接住——两种「摸到」都归 `on_seg` 管，跨立实验只管「穿过」。九种符号组合的完整结局表在图形学册第 6 章 §6.2，此处不重复；竞赛口径记住一句话：跨立管穿过，补判管触碰。

**本节小结**：距离三情形、相交四谓词，全部化归叉积与点积；整数坐标下每一个分支都精确。判断交是第 4 章扫描线的原子操作，这里的正确性清单会原样搬过去。

## $\rm \S \, 1.4$ 多边形面积与点在多边形内

**鞋带公式（shoelace formula）。** 白话：把多边形切成 $n$ 个「边与原点围成的三角形」，面积带符号相加，原点的项两两相消。对顶点按序（逆时针或顺时针）给出的多边形 $P_0 P_1 \cdots P_{n-1}$：

$$
2A \;=\; \sum_{i=0}^{n-1} \big(x_i\, y_{i+1} - x_{i+1}\, y_i\big), \qquad (x_n, y_n) = (x_0, y_0),
$$

读法：每项是一次 $\operatorname{cross}(O, P_i, P_{i+1})$，即边 $P_iP_{i+1}$ 与原点围成的有向三角形面积的两倍；顶点逆时针时 $A > 0$，顺时针时 $A < 0$，取绝对值即面积。锚（实测）：三角形 $(0,0),(4,0),(0,3)$：和 $= 12$，面积 $6$；凹多边形 $(0,0),(6,0),(6,4),(3,4),(3,2),(0,2)$：和 $= 36$，面积 $18$——凹不凹，公式一视同仁，这正是它的好处。

**点在多边形内：射线法与奇偶规则。** 白话：从查询点向右开一枪，数它穿过边界的次数——奇数次在内，偶数次在外。这条「奇偶规则」对任意简单多边形成立（凹的也行），实现只有一个真正的难点：**退化情形**。从 $q = (q_x, q_y)$ 发出的水平射线，对边 $\overline{(x_1,y_1)(x_2,y_2)}$ 的穿越条件：

$$
(y_1 > q_y) \ne (y_2 > q_y)
\quad\text{且}\quad
q_x \;<\; x_1 + \frac{(q_y - y_1)(x_2 - x_1)}{y_2 - y_1},
$$

读法：第一个条件要求边在竖直方向上**严格跨越**射线所在水平线，且用半开比较（$>$ 而非 $\ge$）把高度恰等于 $q_y$ 的端点全部划到「不高于」一侧；第二个条件要求交点在查询点右侧。半开比较是整套方法的灵魂：顶点恰落在射线上时，跨越计数恰好一次或零次——一个上边一个下边的「真穿越」顶点计一次，两条边同侧的「擦碰」顶点计两次（偶数），局部几何自动对账，无需特判顶点。

边界退化处理清单（按序执行，缺一步都是坑）：

1. **先查「点在边上」**：对每条边跑 $\S 1.3$ 的共线加外接框检查，命中则直接按题目口径返回（通常算在内，或单独报「在边界上」）——射线法对边界点**没有定义**，见下面的实测。
2. **水平边不用特判**：两端 $y_1 = y_2$ 时跨越条件恒假，自动跳过。
3. **射线恰过顶点**：半开比较已处理（一次或零次，见上），不要再手写顶点特判叠加它。
4. **自交多边形**：奇偶规则失效（穿过次数不反映内外），改用绕数法（winding number）累计角度或带符号圈数。
5. **浮点坐标**：$y$ 比较与交点横坐标都带舍入，先回 §1.2 的阶梯定判号方案。
边界点为什么必须显式处理，实测最有说服力：正方形 $(0,0),(4,0),(4,4),(0,4)$，边界点 $(4,2)$ 与 $(0,2)$ 局部几何完全同构（都在竖直边的中点），射线法实测却给出 $(4,2) \to$ False、$(0,2) \to$ True——交点恰落在「$q_x < x_{\text{交}}$」比较的哪一侧，全看边界在左还是右。凹多边形的正向锚（实测）：$(1,1),(4,3),(2,1)$ 在内，$(1,3)$ 在外（缺口区），四点全对。

**本节小结**：鞋带公式把面积变成一行求和、凹凸通吃；射线法靠半开比较消化顶点退化，但边界点必须显式前置检查。面积是凸包（第 2 章）与最小矩形（第 3 章）的验收工具，射线法是本章留给一切「点在区域里吗」问题的通用答案。

## $\rm \S \, 1.5$ 平面图的欧拉公式

白话：把地图画在气球上，顶点数、边数、面数之间有一个雷打不动的账目关系。

$$
V - E + F \;=\; 2,
$$

其中 $F$ 含外部那个无限面。实算锚（三角剖分）：一个四边形加一条对角线，$V = 4$，$E = 5$（四条边加一条对角线），$F = 3$（两个三角形加外部区域），$4 - 5 + 3 = 2$ ✓。任何平面细分都守这条恒等式，它是扫描线与半边结构（DCEL）做内存记账时的对账单：结构改了千百次，$V - E + F$ 不许变。

顺手推一个竞赛常客：**极大平面图的边数上界**。平面图每个面至少 $3$ 条边，每条边恰属两个面，故 $3F \le 2E$；代入 $F = 2 - V + E$ 得 $3(2 - V + E) \le 2E$，即 $n$ 个顶点的平面图至多 $3n - 6$ 条边——平面图是「稀疏」的，这就是第 4 章扫描线敢把事件数按 $O(n)$ 预算、第 5 章 Delaunay 三角剖分敢按 $O(n)$ 数三角形记账的先验。

**本节小结**：$V - E + F = 2$ 是平面细分的守恒律，三角剖分 $4-5+3=2$ 当场对账；由它一行推出 $E \le 3V - 6$。基元、判号、相交、面积、记账——地基五件齐了，下一章开始搭主体结构：凸包。

## $\rm \S \, 1.6$ 六问与答

1. 叉积的符号回答什么问题？竞赛判向为什么不用 `atan2` 算角度？（答：$b$ 在有向直线 $oa$ 的哪一侧；角度是浮点近似、慢一个量级，叉积是二次多项式、整数域精确。）
2. 事故一里整数恰好共线判得对，事故二里真值仅差 $1$ 的近共线反而判错，机理差在哪？（答：前者两边乘积是同一实数、IEEE 舍入到同一个 `double`，相减精确得零；后者乘积在 $5\times 10^{17}$ 量级、格距 $64$，真值 $1$ 被舍入噪声吞掉。）
3. $\varepsilon$ 判据的两大坑各举一个实测例。（答：不可传递——$0.1$ 起步、每步 $0.6\times 10^{-9}$ 的链，两两相近而首尾 $1.2\times 10^{-9}$ 判不等；尺度依赖——共线三点放大 $2^{12}$ 倍后噪声从 $10^{-15}$ 涨到 $10^{-8}$，固定 $\varepsilon = 10^{-9}$ 判决翻转。）
4. 坐标放大 $10^k$ 倍取整，溢出预算怎么变？（答：叉积是坐标差的乘积，放大倍数平方——$\times 100$ 的输入让叉积放大 $10^4$ 倍。）
5. 线段相交判定的「跨立 + 四条 `on_seg` 补判」各管什么？端点触碰案例由哪个分支接住？（答：跨立管严格穿过，补判管共线与端点触碰；触碰由 $d_3 = 0$ 且外接框内那条分支接住。）
6. 射线法的半开比较解决了什么退化？边界点为什么必须前置显式检查？（答：顶点恰在射线上时跨越计数恰为一次或零次，局部几何自动对账；边界点本身无定义——正方形 $(0,2)$ 判 True、$(4,2)$ 判 False，同构局面答案相反。）

import math

def cross(o, a, b):
    return (a[0]-o[0])*(b[1]-o[1]) - (a[1]-o[1])*(b[0]-o[0])
def dot(u, v):
    return u[0]*v[0] + u[1]*v[1]
 # 1. 数值锚：左转 +1 / 右转 -1 / 共线 0
print(cross((0,0),(1,0),(0,1)), cross((0,0),(1,0),(0,-1)), cross((0,0),(1,1),(2,2)))

 # 2. 精度战争三事故（整数读进 double 的口径）
def fcross(a, b, c):
    return (float(b[0])-float(a[0]))*(float(c[1])-float(a[1])) \
         - (float(b[1])-float(a[1]))*(float(c[0])-float(a[0]))
print(fcross((0,0),(10**9,10**8+3),(2*10**9,2*10**8+6)))        # 事故一: 恰好共线 -> 0.0

    print(f"scaled by 2^{int(math.log2(s)) if s!=1 else 0}: |cross|={cr:.3e} eps-verdict={cr<eps}")

 # 4. 线段相交四案例
def on_seg(a, b, c):
    return min(a[0],b[0]) <= c[0] <= max(a[0],b[0]) and min(a[1],b[1]) <= c[1] <= max(a[1],b[1])
def seg_inter(p1, p2, q1, q2):
    d1 = cross(q1,q2,p1); d2 = cross(q1,q2,p2)
    d3 = cross(p1,p2,q1); d4 = cross(p1,p2,q2)
    if ((d1>0 and d2<0) or (d1<0 and d2>0)) and ((d3>0 and d4<0) or (d3<0 and d4>0)):
        return True
    return (d1==0 and on_seg(q1,q2,p1)) or (d2==0 and on_seg(q1,q2,p2)) \
        or (d3==0 and on_seg(p1,p2,q1)) or (d4==0 and on_seg(p1,p2,q2))

         ((0,0),(4,4),(2,2),(6,6)), ((0,0),(4,0),(0,1),(4,1))]
print([seg_inter(*c) for c in cases])                            # [True, True, True, False]

 # 5. 鞋带公式
def area2(poly):
    return sum(poly[i][0]*poly[(i+1)%len(poly)][1] - poly[(i+1)%len(poly)][0]*poly[i][1]
               for i in range(len(poly)))
print(area2([(0,0),(4,0),(0,3)]))                                # 12
print(area2([(0,0),(6,0),(6,4),(3,4),(3,2),(0,2)]))              # 36

 # 6. 射线法（含显式边界检查）
def on_edge(q, poly):
    return any(cross(poly[i], poly[(i+1)%len(poly)], q) == 0
               and min(poly[i][0],poly[(i+1)%len(poly)][0]) <= q[0] <= max(poly[i][0],poly[(i+1)%len(poly)][0])
               and min(poly[i][1],poly[(i+1)%len(poly)][1]) <= q[1] <= max(poly[i][1],poly[(i+1)%len(poly)][1])
               for i in range(len(poly)))
def pip(q, poly, boundary=True):
    if boundary and on_edge(q, poly):
        return True
    inside = False
    for i in range(len(poly)):
        x1,y1 = poly[i]; x2,y2 = poly[(i+1)%len(poly)]
        if (y1 > q[1]) != (y2 > q[1]):
            if q[0] < x1 + (q[1]-y1)*(x2-x1)/(y2-y1):
                inside = not inside
    return inside
sq = [(0,0),(4,0),(4,4),(0,4)]
cv = [(0,0),(6,0),(6,4),(3,4),(3,2),(0,2)]
print(pip((2,2),sq), pip((5,2),sq))                              # True False
print(pip((4,2),sq), pip((0,2),sq))                              # 边界: 显式检查后同答 True
print(pip((4,2),sq,boundary=False), pip((0,2),sq,boundary=False))# 无检查: False True (不一致!)
print(pip((1,1),cv), pip((4,3),cv), pip((2,1),cv), pip((1,3),cv))# True True True False

## $\rm \S \, 1.8$ 带走清单

1. 叉积 $\operatorname{cross}(o,a,b)$ 定侧向（左 $+1$、右 $-1$、共线 $0$），点积投影参数 $t$ 定进度；两者是多项式，整数域零误差，凡能不用超越函数就不用。
2. 精度三事故：整数恰共线安全（同实数同舍入）、整数近共线翻车（真值 $1$ 对格距 $64$）、小数入口失守（$0.3$ 二进制存不准）。
3. $\varepsilon$ 判据不可传递、尺度依赖，是赌局不是修正；解法阶梯为放大取整 → 全程整数算术（坐标 $10^9$ 内 `long long` 装得下，叉积上界 $8\times 10^{18}$）→ Shewchuk 自适应谓词。
4. 点到直线距离 = $\lvert\operatorname{cross}\rvert / \lvert a - o\rvert$；点到线段先夹 $t \in [0,1]$ 再三情形。
5. 线段相交 = 双向严格跨立 + 四条共线补判；跨立管穿过，补判管触碰，缺一漏判。
6. 鞋带公式一行算任意简单多边形面积，凹凸通吃、方向给符号；射线法靠半开比较消化顶点退化，边界点必须显式前置检查。
7. $V - E + F = 2$ 是平面细分守恒律，三角剖分 $4-5+3=2$ 对账，由此 $E \le 3V - 6$。
