# $\rm Chapter \, 07$ 排队网络与 Jackson 定理

第 4 章把排队网络当「接力链」初见了一遍：Burke 定理与 Jackson 乘积形式都以陈述交付，账本立了，账没算。本章把账算完。三个问题依次登场：网络里每个站的到达率是多少——它不等于外部到达率，得先解流量方程（§07.2）；解出流量之后，全网的稳态分布长什么样——Jackson 定理说它按站分解成几何分布之积，本章把乘积形式解代进全局平衡方程逐项对消，完整验一遍（§07.3）；这套验证为什么明明内部流不是泊松却仍然成立——Burke 定理的有效边界（§07.4）与 PASTA、部分平衡的分工（§07.5）负责说清。全章围绕一个三节点网络展开，每个公式都在它身上落地，数字全表收在 §07.6，章末附可当场复跑的 Python 验证。

比喻先立在这：把网络想成一家**快递分拣网**——包裹从几个入口进，每件揣着一张写死的路由单，在各分拣中心排队、盖章，按单子转往下一站或出网。干线上的包裹量从来不是「寄件量」本身：有包裹被退回重分（反馈），有几路汇成一股（合流）。Jackson 定理的承诺是一句反直觉的话：随便哪个瞬间抓拍全网，各分拣中心的排队人数互不纠缠，每一家的分布都像一间独立小店——哪怕各家门口的到货节奏早被路由单搅得不是泊松。

> **开始前自检**：本章假设你已经会：
>
> 1. □ 泊松流的叠加与稀疏（§1.5）——入口合流、按概率分流在此免费。
> 2. □ M/M/1 的生灭链、细节平衡与 $L = \frac{\rho}{1-\rho}$（§2.2–2.3）。
> 3. □ Little 定理与子系统版（§3.3–3.4）——全网平均逗留靠它换算。
> 4. □ Burke 定理与开 Jackson 网络的陈述级初见，包括「乘积形式 ≠ 独立泊松流」的反例（§4.6–4.7）。
>
> 其中第 2 条是主推导的引擎，第 4 条是待验证的结论；不熟先回第 2、4 章补齐。

## $\rm \S \, 07.1$ 为什么单站不够：流量得先解出来

先看一个真实形状的系统。一条后端链路：请求先进 Web 层的线程池（站 1），处理完分流——两成直接返回，四成调业务服务（站 2），四成查缓存（站 3）；业务服务处理完必查缓存；缓存层除接住上游，还有自己的定时任务流。这是「串联加分叉」的最简结构，三个站、几条有向边，比任何一家银行网点都简单。可第 2 章的单站公式一上来就哑火：它问「每秒多少人到达」，而这正是网络里没人能脱口而出的数——站 3 的到达者一部分来自站 1、一部分来自站 2、一部分来自定时任务，没有一项等于「外部请求数」。

白话：网络问题分两层。第一层是流量分配——每条边每秒过多少人，这是确定性的账，解线性方程组就够；第二层才是拥堵——给定每站流量，问队多长、等多久，这才轮到排队论。第一层不解，第二层无从谈起。

天真算法的代价可以先剧透。§07.2 的锚点网络（就是上面那条链路）里，站 3 的外部流量只有每秒 $\frac{1}{2}$，真实总流量却是 $\frac{13}{10}$——路由把流量放大到 2.6 倍。把外部率当总率代进 M/M/1：站 1 恰好蒙对（它的总到达确实等于外部率），站 3 得 $L = \frac{1}{7} \approx 0.14$，真值 $\frac{13}{27} \approx 0.48$，低估三倍多；站 2 的外部流量干脆是零，天真算法宣布「此站永远无人」，真值 $L = \frac{1}{4}$。单站公式一台都没错，错的是喂给它的数——而「站 1 碰巧蒙对」最危险，它让人误以为天真算法可行。

反馈还要再补一刀：失败重试、缓存未命中回源，都是「顾客回到来过的站」——某站的真实负载可以超过全网入口流量。第 4 章的应用与辨析算过最小案例：单节点以概率 $p$ 自我回灌，负载从 $\lambda$ 膨胀到 $\frac{\lambda}{1-p}$。

小结：网络的第二层公式（排队）都认识，缺的是第一层的流量账。本章路线：先解流量方程（§07.2），再证乘积形式（§07.3），然后划清 Burke 与 PASTA 的辖区（§07.4–07.5），最后全表对账（§07.6）。

## $\rm \S \, 07.2$ Jackson 网络与流量方程

抽象定义进场前，白话：要把「分拣网」变成能算的数学对象，需要三样东西——每个站的窗口与速度、外部的到货节奏、路由单上的概率。三样钉死，流量方程就是「进出平衡」的会计恒等式。

**定义 7.1（开 Jackson 网络，本章口径）**：$m$ 个节点，节点 $j$ 配一台指数服务率为 $\mu_j$ 的服务台、一条无限队列、先来先服务。外部到达是相互独立的泊松流，节点 $j$ 的外部率记 $\alpha_j$（全体记 $\alpha$）。顾客在节点 $i$ 服务完后，以概率 $p_{ij}$ 转往节点 $j$，以概率 $q_{i0} = 1 - \sum_{j} p_{ij}$ 离开系统。第 4 章的定义 4.2 允许多服务台；本章收窄到单台，为的是把验证算到每一项——多台与更宽服务规则的推广见 §07.6 的 BCMP。

三条口径：1. 路由概率只看「从哪到哪」，不看队长不看历史——顾客揣的是一张写死的路由单；2. 队列容量无限，无人被拒；3. 状态是向量 $\mathbf{n} = (n_1, \ldots, n_m)$，读作「全网快照：站 1 有 $n_1$ 人、……、站 $m$ 有 $n_m$ 人」——账本从一列变成 $m$ 列，仍是马尔可夫链，因为服务全指数（第 5 章那种「服务进度有记忆」的病在这里不存在）。

**流量方程**。白话：站 $j$ 每秒进多少人 = 外部新来的 + 从各站转来的；而「从各站转来的」又取决于各站自己的总进人流——$\lambda$ 两边都出现，这是一组方程，不是一个公式：

$$
\lambda_j = \alpha_j + \sum_{i=1}^{m} \lambda_i\, p_{ij}, \qquad j = 1, \ldots, m.
$$

读法：$\lambda_j$ 是站 $j$ 的总到达率（含一切转发），$\alpha_j$ 是外部注入，$\lambda_i p_{ij}$ 是站 $i$ 出口流量里流向 $j$ 的那一份。没有回环时按拓扑序逐站代入即可；有回环时它才是真正的方程组——最小案例就是第 4 章的 $\gamma = \frac{\lambda}{1-p}$，一般情形线性代数一步解出。

**锚点网络全算**。设定（后端链路的抽象）：外部到达 $\alpha = (1,\, 0,\, \frac{1}{2})$；路由：站 1 以概率 $0.4$ 去站 2、概率 $0.4$ 去站 3、概率 $0.2$ 离开；站 2 以概率 $1$ 去站 3；站 3 必离开。服务率 $\mu = (3,\, 2,\, 4)$。逐站解流量方程：

1. $\lambda_1 = \alpha_1 = 1$（没有站转进来）；
2. $\lambda_2 = 0.4\,\lambda_1 = \frac{2}{5}$；
3. $\lambda_3 = \frac{1}{2} + 0.4\,\lambda_1 + \lambda_2 = \frac{1}{2} + \frac{2}{5} + \frac{2}{5} = \frac{13}{10}$。

利用率 $\rho_i = \frac{\lambda_i}{\mu_i} = (\frac{1}{3},\, \frac{1}{5},\, \frac{13}{40})$，全部小于 1——网络稳定。逐站套 M/M/1 队长 $L_i = \frac{\rho_i}{1-\rho_i}$（§2.3）：$L = (\frac{1}{2},\, \frac{1}{4},\, \frac{13}{27})$，全网平均人数 $L = \frac{133}{108} \approx 1.2315$。出口总流 $\gamma = \lambda_1 q_{10} + \lambda_2 q_{20} + \lambda_3 q_{30} = \frac{1}{5} + \frac{13}{10} = \frac{3}{2}$，恰等于外部总注入——全网守恒的第一桩验证。对「整个网络」用 Little（§3.4 子系统版：子系统 = 全网，到达率 = 出口通过率 $\gamma$），平均逗留

$$
W = \frac{L}{\gamma} = \frac{133/108}{3/2} = \frac{133}{162} \approx 0.8210.
$$

读法两句：站 3 的总流 $\frac{13}{10}$ 是它外部流 $\frac{1}{2}$ 的 2.6 倍，放大的来源是「网关四成直查缓存、业务层全部回查缓存」；$W \approx 0.82$ 是一位顾客从进入到离开的平均泡网时长，换算用的分母是 $\gamma$ 而不是任何单站到达率。

小结：流量方程把「每站进多少人」变成线性代数；锚点网络给出 $\lambda = (1, \frac{2}{5}, \frac{13}{10})$ 与 $W \approx 0.82$，这组数字后面每一节都要用。

## $\rm \S \, 07.3$ 乘积形式定理：主推导

白话先行：全网稳态分布定义在 $m$ 维状态上，直接解生灭方程要面对指数级的状态空间。Jackson 定理说不用解——答案按站分解，每一站的形状就是一台 M/M/1 的几何分布。

**定理 7.1（Jackson，1957）**：定义 7.1 的开网络中，若每站 $\rho_i < 1$，则稳态分布存在、唯一，且为乘积形式

$$
\Pi(\mathbf{n}) = \prod_{i=1}^{m} (1-\rho_i)\,\rho_i^{\,n_i}.
$$

读法：第 $i$ 站人数的边缘分布恰是 $(1-\rho_i)\rho_i^{n_i}$——「到达率 $\lambda_i$、服务率 $\mu_i$ 的 M/M/1」的几何分布（定理 2.1）；联合分布按站分解，归一化常数是免费的：每站几何级数自归一，乘起来恰好是 1。存在与唯一（陈述级）：$\rho_i < 1$ 保证链正常返回；任何一站 $\rho_i \ge 1$ 则平稳分布不存在——概率质量沿那一站漏向无穷，第 2 章的浴缸搬进了网络。本节推导证明「乘积形式满足全局平衡」；「满足平衡方程的归一化解就是唯一的那个稳态」需要不可约性与正常返回的一般理论，超出本章范围，见 Jackson (1957) 原文与 Kelly《Reversibility and Stochastic Networks》第 1 章。

**反直觉点，专门讲**。「各站边缘是 M/M/1 的几何」与「网络内部流是泊松」是两句话，前真后假。

1. 真的那句：给定 $\lambda_i$ 与 $\mu_i$，站 $i$ 的人数分布与一台货真价实的孤立 M/M/1 无法区分；$L_i = \frac{\rho_i}{1-\rho_i}$ 的出处是这张边缘分布的期望，不是 PASTA。
2. 假的那句：内部弧上的到达流一般不是泊松。第 4 章 §4.7 的反例搬回来：单节点以概率 $p$ 自我回灌，它的输入 = 外部泊松流 + 自己的离开流；服务完成的一瞬队列变短、回头客同时诞生，到达与状态强相关——「完全随机的抽样时刻」这个泊松本质（§1.5）已经丢了。叠加也救不了：两股泊松相加仍泊松需要独立性，回灌流与外部流恰恰不独立。
3. 为什么两句话能同时成立：答案是下面的主推导——平衡方程的验证从头到尾只用了流量守恒（一阶矩的账），从未用到「到达流无记忆」。比喻：库存盘点只认进出总账，不认进货的节律；到货时刻表再乱，只要账目平衡，平均库存照样按公式走。

**主推导：把乘积形式代进全局平衡**。

第一步，事件清单。记 $\mathbf{e}_j$ 为第 $j$ 个坐标是 1、其余为 0 的单位向量，读作「站 $j$ 加一人」。状态 $\mathbf{n}$ 处能发生的跳跃只有四类：

1. 外部到达 $j$：$\mathbf{n} \to \mathbf{n} + \mathbf{e}_j$，率 $\alpha_j$；
2. 转发 $i \to j$（$i \ne j$）：$\mathbf{n} \to \mathbf{n} - \mathbf{e}_i + \mathbf{e}_j$，率 $\mu_i p_{ij}$（要求 $n_i \ge 1$）；
3. 反馈 $i \to i$：状态不变，率 $\mu_i p_{ii}$；
4. 离开系统：$\mathbf{n} \to \mathbf{n} - \mathbf{e}_i$，率 $\mu_i q_{i0}$（要求 $n_i \ge 1$）。

自环（第 3 类）从平衡方程两侧同时划去——它既不流出也不流入任何状态，以下账本只数真正改变状态的跳跃。

第二步，写出平衡方程的两头。先设所有 $n_i \ge 1$（边界状态见第四步）。一头是流出 $\mathbf{n}$ 的总率：

$$
\pi(\mathbf{n})\,\Bigl[\, A + \sum_{i=1}^{m} \mu_i\,(1 - p_{ii}) \Bigr], \qquad A = \sum_{j=1}^{m} \alpha_j,
$$

（外部到达全额计入——到达永远改变状态；完成只计「不回本站」的那部分，自环已划去。）另一头是从邻居流入 $\mathbf{n}$ 的总率，按来源分三族：

$$
\sum_{j=1}^{m} \pi(\mathbf{n}-\mathbf{e}_j)\,\alpha_j \;+\; \sum_{j=1}^{m}\,\sum_{i \ne j} \pi(\mathbf{n}+\mathbf{e}_i-\mathbf{e}_j)\,\mu_i\,p_{ij} \;+\; \sum_{i=1}^{m} \pi(\mathbf{n}+\mathbf{e}_i)\,\mu_i\,q_{i0}.
$$

读法：三族分别是从「站 $j$ 少一人」经外部到达、从「$i$ 多一人 $j$ 少一人」经转发、从「$i$ 多一人」经离开，三条路搬进状态 $\mathbf{n}$。

第三步，乘积形式进场。相邻状态的 $\Pi$ 只差 $\rho$ 的一次幂：

$$
\Pi(\mathbf{n}-\mathbf{e}_j) = \frac{\Pi(\mathbf{n})}{\rho_j}, \qquad \Pi(\mathbf{n}+\mathbf{e}_i-\mathbf{e}_j) = \Pi(\mathbf{n})\,\frac{\rho_i}{\rho_j}, \qquad \Pi(\mathbf{n}+\mathbf{e}_i) = \Pi(\mathbf{n})\,\rho_i.
$$

代入流入那头、提出公因子 $\Pi(\mathbf{n})$，并用 $\lambda_i = \rho_i \mu_i$ 把转发项凑成按 $j$ 归组的形状，流入头除以 $\Pi(\mathbf{n})$ 后等于

$$
\sum_{j=1}^{m} \frac{1}{\rho_j}\Bigl(\alpha_j + \sum_{i \ne j} \lambda_i\, p_{ij}\Bigr) \;+\; \sum_{i=1}^{m} \rho_i\,\mu_i\,q_{i0}.
$$

第四步，三层对消。

1. 逐站层：流量方程 $\lambda_j = \alpha_j + \lambda_j p_{jj} + \sum_{i \ne j} \lambda_i p_{ij}$ 移项给出 $\alpha_j + \sum_{i \ne j} \lambda_i p_{ij} = \lambda_j(1 - p_{jj})$，除以 $\rho_j = \frac{\lambda_j}{\mu_j}$ 恰得 $\mu_j(1 - p_{jj})$——流量方程在此以「每站的进出流配平」的身份进场。于是流入头的第一个和逐站压成 $\sum_{j} \mu_j(1-p_{jj})$，与流出头的完成项逐字相消。这行等式在说：乘积形式让每个站各自局部平账，不必全网一起平。
2. 全网层：两头各剩一项。流出头剩 $A$，流入头剩 $\sum_i \rho_i \mu_i q_{i0} = \sum_i \lambda_i q_{i0} = \gamma$（出口总流）。把流量方程对 $j$ 求和：$\sum_j \lambda_j = A + \sum_i \lambda_i(1 - q_{i0})$，移项即 $\gamma = A$，两头相等。
3. 边界层：一般状态把「$n_i \ge 1$」写成示性函数，同一套计算逐字走通——流出头第 $j$ 站的完成项与流入头「搬进 $j$」的两族在 $n_j = 0$ 时同时消失（空站无人完成，也没有哪个状态能「往空站的 $j$ 坐标上少一人」），而逐站恒等式只在 $n_j \ge 1$ 的站上被调用。两边缺项缺在同一站上，验证没有丢任何一种状态。

四步合起来：乘积形式满足一切状态的全局平衡，验证完成。∎

小结：推导的引擎是流量方程，不是泊松性；三层对消——逐站配平、全网守恒、边界同缺——把「乘积形式是稳态」变成一笔代数。

## $\rm \S \, 07.4$ Burke 定理与串联网络

白话先行：流量方程给「每站进多少人」，乘积形式给「全网长什么样」；还有第三件旧武器——直接追问流的形状：泊松进去，出来还是泊松吗？串联网络的一切便利都从这里来。

**定理 7.2（Burke，1956；陈述级，初见 §4.6）**：平稳 M/M/1（M/M/k 与 M/M/∞ 同）的离开过程是率 $\lambda$ 的泊松过程，且离开过程在时刻 $t$ 之后的部分与 $N(t)$ 独立。

反向放映的直觉（第 4 章许诺的可逆性视角，此处兑现）：把平稳 M/M/1 的影片倒放，倒片里每一次「离开」都变成一次「到达」。细节平衡（§2.2 的 $\lambda \pi_n = \mu \pi_{n+1}$）恰好说倒片与正片遵守同一条生灭律，于是倒片也是平稳 M/M/1，它的到达流是泊松流；而倒片的到达就是正片的离开——离开流是泊松。「离开与队长独立」同理：正片 $t$ 之后的离开，在倒片里是 $t$ 之前的到达，与 $N(t)$ 的牵连被泊松流的独立性剪断。严格证明（可逆性）超出本章范围，见 Kleinrock《Queueing Systems Vol.1》第 4 章与 Kelly 第 1 章。

串联网络立刻白拿。两站串联：外部泊松 $\lambda = \frac{1}{2}$ 进站 1（$\mu_1 = 1$），站 1 全部转给站 2（$\mu_2 = \frac{3}{4}$）。由 Burke，站 2 的输入是率 $\frac{1}{2}$ 的泊松流；由流量方程（$\alpha = (\frac{1}{2},\, 0)$、$p_{12} = 1$）解出 $\lambda = (\frac{1}{2},\, \frac{1}{2})$，两条路给出同一个数。于是两站各是 M/M/1：$\rho = (\frac{1}{2},\, \frac{2}{3})$，$L_1 = 1$、$L_2 = 2$，全网 $L = 3$、$\gamma = \frac{1}{2}$、$W = 6$——一位顾客平均泡 6 个单位时间，其中站 2 一家占 4（刀刃因子 $\frac{2/3}{1/3}$ 的账，§2.4）。联合分布按定理 7.1 分解：$\Pi(n_1, n_2) = (1-\rho_1)\rho_1^{n_1}\,(1-\rho_2)\rho_2^{n_2}$——「两个独立的 M/M/1」在乘积形式意义下成立。

但拿 Burke 推网络要踩住边界。从「单站离开是泊松」到「全网各条弧上是相互独立的泊松流」还差两步：1. 独立性升级——Burke 只说离开流与本站队长独立，没说与其他站独立；2. 叠加合法性——两股泊松叠加仍泊松需要两流独立（§1.5）。反馈网络里两步都会失守：回灌流与本站队长强相关（§07.3 反例），合流自然不是泊松。准确的说法（Melamed 1979 与 Whitt 1983 的经典告诫）：Burke 定理足以支撑「前馈网络（串联、树——每位顾客至多访问每站一次）内部流皆泊松」的推理；一旦有反馈，内部流非泊松，而乘积形式照样成立——理由已换成 §07.3 的平衡账。出处：Whitt 的 Queueing Network Analyzer 论文（Bell System Technical Journal, 1983）与 Kelly 第 1 章。

小结：Burke 让串联网络白拿泊松输入；它的有效期止于前馈——反馈网络里「乘积形式」与「内部流泊松」正式分家，这正是 §07.3 反直觉点的另一面。

## $\rm \S \, 07.5$ PASTA 与部分平衡

PASTA（初见 §1.5，命名与一般证明归 Wolff 1982）：泊松到达者所见的状态分布等于时间平均分布。一句话为什么：泊松到达不改变未来——到达时刻是与系统演化完全独立的随机抽样点，这次到达影响的是他自己的等待，不是他看见的世界。

网络里的适用边界，正反各一句：1. 入口处成立——外部到达是泊松，新顾客眼中的全网就是乘积形式 $\Pi(\mathbf{n})$ 本身；2. 内部弧上失效——内部到达时刻偏爱队列起落的特定瞬间（回灌流偏爱刚完成服务的一刻），不是随机抽样，「站 2 的新到者看见多少人」不能拿时间平均硬代。好在 $L_i$ 的账不受伤：它的出处是边缘分布的期望（§07.3），绕开了 PASTA。

部分平衡。白话：可逆性要求每条相邻状态边上的概率流两头配平（细节平衡，§2.2）；部分平衡把要求放宽到「每个站」——把进出同一个站的所有转移捆成一组，只要求整组的进出流配平。§07.3 第四步逐站层的那行恒等式乘上 $\Pi(\mathbf{n})$，就是站 $j$ 的部分平衡：对每个站 $j$ 与每个 $n_j \ge 1$ 的状态（$n_j = 0$ 时两边同时无项，等式平凡），

$$
\Pi(\mathbf{n})\,\mu_j\,(1-p_{jj}) \;=\; \Pi(\mathbf{n}-\mathbf{e}_j)\,\alpha_j \;+\; \sum_{i \ne j} \Pi(\mathbf{n}+\mathbf{e}_i-\mathbf{e}_j)\,\mu_i\,p_{ij},
$$

读法：使 $n_j$ 减一的流（本站完成且不回本站）与使 $n_j$ 加一的流（外部到达 + 他站转入）在每个状态上双双配平。它与细节平衡的关系一目了然：单站 M/M/1 里每组只有一条边，部分平衡退化成细节平衡——可逆；Jackson 网络里每组有多条边（路由有向，逆方向的流不存在），逐条边配平不可能，整组配平刚刚好。而部分平衡求和即全局平衡——§07.3 的三层对消正是这个求和的明细账。「部分平衡 ⟹ 全局平衡 ⟹ 乘积形式」是乘积形式网络理论通用的证明模板，下一节出口处的 BCMP 定理用的也是这一招（Kelly 第 1 章是这条线的专著）。

小结：PASTA 住在泊松的入口、进不了内部弧；部分平衡是细节平衡的按站打包版，比可逆性弱、比全局平衡强——乘积形式世界的通用钥匙。

## $\rm \S \, 07.6$ 实操与出口

**表 1：锚点网络数字锚全表**（§07.2 解出、§07.3 定理盖章；分数照抄，小数四位）：

| 站 $j$ | 角色 | 外部到达 $\alpha_j$ | 总到达 $\lambda_j$ | 服务率 $\mu_j$ | 利用率 $\rho_j$ | 队长 $L_j$ |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 网关/线程池 | $1$ | $1$ | $3$ | $\frac{1}{3}$ | $\frac{1}{2}$ |
| 2 | 业务/连接池 | $0$ | $\frac{2}{5}$ | $2$ | $\frac{1}{5}$ | $\frac{1}{4}$ |
| 3 | 缓存层 | $\frac{1}{2}$ | $\frac{13}{10}$ | $4$ | $\frac{13}{40}$ | $\frac{13}{27}$ |
| 全网 | — | $A = \frac{3}{2}$ | — | — | — | $L = \frac{133}{108} \approx 1.2315$ |

出口口径：$\gamma = \frac{3}{2} = A$（守恒盖章），平均逗留 $W = \frac{133}{162} \approx 0.8210$。串联锚（§07.4）：$\lambda = \frac{1}{2}$、$\mu = (1, \frac{3}{4})$ 给 $\rho = (\frac{1}{2}, \frac{2}{3})$、$L = 3$、$W = 6$。

读表三句：1. 站 3 的流量被路由放大到外部流的 2.6 倍——容量规划若只看「谁来找我」而不看「我把谁挡在前面」，缓存层的负载会被低估一半还多。2. 天真算法的两处翻车都在表里：站 3 得 $L = \frac{1}{7} \approx 0.14$（低估约 3.4 倍），站 2 得「永远无人」（真值 $\frac{1}{4}$）。3. 全网行没有 $\rho$——「全网利用率」不是各站利用率能平均出来的量，全网只认守恒律与 Little。

容量规划口诀一句话：先解流量方程（线性代数），再逐站套 M/M/1 闭式（第 2 章），最后用全网 Little 换算端到端延迟——内部流永远不能当外部流代。

出口两扇门（陈述级）：1. **BCMP 网络**（Baskett–Chandy–Muntz–Palacios, 1975）：顾客分多类，各类有自己的路由与服务需求；站可以是多台先来先服务、处理器共享、后到先服务或无限台，乘积形式仍在——§07.5 的部分平衡模板换套记号重跑，原文见 JACM 22(2)。2. **QNA**（Queueing Network Analyzer，Whitt 1983）：服务与到达不指数时，把第 6 章的变异系数 $c^2$ 搬进网络——流量方程之外再解一组矩方程、近似出各站合并流的 $c_a^2$，逐站套 Kingman 近似；这是非指数网络在工程里的主流路线。两条线之外，乘积形式的纵深（局部平衡与不敏感性——结论不依赖分布形状）在 Kelly《Reversibility and Stochastic Networks》全书展开。

小结：锚点全表交付；口诀「先流量方程、再逐站 M/M/1、别把内部流当外部流」；出口是 BCMP（更宽的乘积形式）与 QNA（非指数的工程近似）。

## $\rm \S \, 07.8$ 可当场复跑的验证

验证是确定性的账目问题，不需要随机模拟：用标准库 fractions 解流量方程（不动点迭代，带回环的路由同样适用）、逐站算 $\rho$ 与 $L$、按全网 Little 出 $W$，与 §07.6 表 1 逐项断言对账。

```python
from fractions import Fraction as F

m = 3
alpha = [F(1), F(0), F(1, 2)]      # 外部到达率
mu    = [F(3), F(2), F(4)]         # 服务率
p = [[F(0), F(2, 5), F(2, 5)],     # 站 1：四成去 2、四成去 3、两成离开
     [F(0), F(0),   F(1)  ],       # 站 2：必去站 3
     [F(0), F(0),   F(0)  ]]       # 站 3：必离开
q = [F(1) - sum(row) for row in p] # 各站离开概率

lam = list(alpha)                  # 解流量方程（不动点迭代）
for _ in range(50):
    lam = [alpha[j] + sum(lam[i] * p[i][j] for i in range(m)) for j in range(m)]

rho   = [lam[j] / mu[j] for j in range(m)]
L     = [r / (1 - r) for r in rho]     # M/M/1 队长（定理 7.1 的边缘）
gamma = sum(lam[j] * q[j] for j in range(m))
W     = sum(L) / gamma                 # 全网 Little

assert lam == [F(1), F(2, 5), F(13, 10)]
assert rho == [F(1, 3), F(1, 5), F(13, 40)]
assert L   == [F(1, 2), F(1, 4), F(13, 27)]
assert sum(L) == F(133, 108) and gamma == F(3, 2) and W == F(133, 162)
print("lam  =", [str(x) for x in lam])
print("rho  =", [str(x) for x in rho])
print("L    =", [str(x) for x in L])
print("L_sum= %s = %.4f" % (sum(L), float(sum(L))))
print("gamma= %s, W = %s = %.4f" % (gamma, W, float(W)))
```

某次运行输出：

```text
lam  = ['1', '2/5', '13/10']
rho  = ['1/3', '1/5', '13/40']
L    = ['1/2', '1/4', '13/27']
L_sum= 133/108 = 1.2315
gamma= 3/2, W = 133/162 = 0.8210
```

读法：四组断言全过——流量方程的解、利用率、队长、全网口径与正文分数逐字一致。不动点迭代对前馈图两步收敛；把 $p$ 换成带回环的路由（例如站 3 以概率 $\frac{1}{4}$ 回站 1、其余离开），同一脚本照样解出方程组——这正是流量方程「方程组」身份的落地。

小结：脚本与表 1 互相盖章；确定性账目用有理数一锤定音，随机性住在被解的方程里，不住在解法里。
