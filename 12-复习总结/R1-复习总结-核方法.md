# R1 复习总结：核方法

六章压成三句话：**地基**（第 1 章）——核函数＝对称＋Gram 矩阵半正定，这两条恰好等价于「某处存在特征映射使 $K$ 为内积」，RKHS 用核柱子 $K(x, \cdot)$ 盖出一座「求值＝取内积」的房子，再生性质 $f(x) = \langle f, K(x, \cdot) \rangle$ 是全册的核心齿轮；**两台降维机器**（第 2—3 章）——核技巧把「数据只以内积进场」的算法整张换成核矩阵（核 PCA 的中心化公式 $\tilde{K} = K - \mathbf{1}K - K\mathbf{1} + \mathbf{1}K\mathbf{1}$），表示定理把无穷维优化赶进训练点张成的小房间，核岭回归塌缩成一条闭式 $\alpha = (K + \lambda I)^{-1}y$；**统计与概率升级**（第 4—6 章）——均值嵌入 $\mu_p = \mathrm{E}_p K(x, \cdot)$ 把分布变成 RKHS 里的点、MMD 在特征核下是真度量，高斯过程的后验均值与核岭回归逐符号全同（$\sigma^2$ 扮演 $\lambda$）还附赠误差条，NTK 最终把无限宽网络钉在固定核的位置上。验收标准：闭卷清单答出几成、§R1.3 六条心智模型能默几条。

## $\rm \S \, R1.3$ 核心心智模型复读

1. **核是内积的压缩包**：特征空间的全部信息装进一个能 $O(1)$ 计算的双变量函数；对称＋半正定不是人为规定，而是「某处存在 $\varphi$」的充要条件——合法性一次验清，终身免检。
2. **再生性质是翻译机**：$f(x) = \langle f, K(x, \cdot) \rangle$ 把「函数在点取值」翻成「几何里取内积」，光滑度变成范数、分布变成点——关于函数的分析问题全部翻译成几何问题。
3. **判据先行再动手**：核化一个算法前先查「数据是否只以内积进场」；是则整张 Gram 矩阵换成核矩阵即可，合法性由第 1 章背书，不是逐算法重证。
4. **表示定理赶人进小房间**：正交补在训练点上隐身（再生性质）却按范数交税（勾股），最优解只能住在 $S = \mathrm{span}\{K(x_j, \cdot)\}$ 里——无穷维优化塌缩成 $n$ 维线性代数，可计算性全靠它。
5. **正则化＝对噪声的诚实报价**：KRR 的 $\lambda$ 与 GP 的 $\sigma^2$ 在公式里逐符号互换——贝叶斯世界把「正则强度」读成「噪声方差」，误差条是出厂配置不是事后补丁。
6. **核选得好不好可以检验**：特征核下 MMD $= 0 \iff p = q$，核选择从「一行显式假设」升级成分布层面的判据——这也是核方法「可解释」的延伸。

## $\rm \S \, R1.4$ 交错练习

1. 十字五点高斯核（$\gamma = 1/4$）矩阵的特征值全非负说明什么？核 PCA 中心化后特征值有几个非零？（答：核合法、特征分解有实特征值；4 个：${0.6321,\ 0.6321,\ 0.1548,\ 0.0701}$，最大者 $0$ 化为中心化降一维）
2. 判断 $K(x, z) = 1 + 2x \cdot z + (x \cdot z)^2 + 3\exp(-\lVert x - z \rVert^2/4)$ 是不是核。（答：是——常数、线性、多项式、缩放的高斯核按和与标量倍拼装）
3. 核岭回归取异或标签 $y = (+1, -1, -1, +1)$ 且 $y$ 恰是 $K$ 的特征向量，$\alpha$ 与预测值怎么手算？（答：$\alpha = y/(\mu + \lambda)$，$\mu = (1 - e^{-1/2})^2 = 0.1548$；$\alpha = \pm 3.9244$，预测 $-0.1179$）
4. 有偏 MMD 估计量的偏差账怎么对？（答：理论 $(1 - c)(1/m + 1/n)$，$c = 0.5774$、$m = n = 100$ 时约 $0.0085$）
5. GP 后验方差在测试点远离训练点时趋向什么？（答：先验方差 $K(x^*, x^*)$，均值回落到 $0$——没数据的地方老实承认没把握）
6. 无限宽网络 + lazy training 等价于什么？（答：以 NTK $\Theta(x, z) = \langle \nabla_\theta f(x), \nabla_\theta f(z) \rangle$ 为核的核回归——固定核方法）

## $\rm \S \, R1.5$ 易混点对照

1. **核技巧 vs 表示定理**：前者是算法改写机制（把内积换成核值，适用于任何「只吃内积」的算法），后者是优化问题解的结构定理（把最优解压进 $n$ 维房间）——核 PCA 用前者，核岭回归的闭式靠后者。
2. **$K(x, \cdot)$ vs $\varphi(x)$**：核柱子是 RKHS 里的函数（求值的载体），特征映射的像是抽象空间里的向量；两者通过 $K(x, \cdot) = \langle \varphi(x), \varphi(\cdot) \rangle$ 相认，不必划等号。
3. **Gram 矩阵特征值 vs Mercer 特征值**：前者是有限点集上矩阵的谱，后者是连续算子 $K$ 的谱分解 $K(x, z) = \sum_k \lambda_k \psi_k(x)\psi_k(z)$——Mercer 是「整张函数」的版本，样本谱是它的离散取样。
4. **KRR 的 $\lambda$ vs GP 的 $\sigma^2$**：公式同位、语义不同——前者是优化里的正则强度，后者是观测噪声方差；贝叶斯读法把两者焊在一起（噪声越大正则越重）。
5. **有偏 vs 无偏 MMD 估计**：有偏版含对角线项（$K(x_i, x_i)$），绝对值天生带假阳性底噪 $(1 - c)(1/m + 1/n)$；无偏版去掉对角线，检验必须配零分布（置换）——只看大小拍阈值会误报。
6. **先验方差 vs 后验方差**：$K(x^*, x^*)$ 是没有任何数据时的不确定性；后验 $s^2 = K(x^*, x^*) - k^{\mathsf T}(K + \sigma^2 I)^{-1}k$ 是先验减去「数据解释掉的部分」——被扣多少取决于测试点与训练点的亲密度。

## $\rm \S \, R1.6$ 答案与提示

### 闭卷回忆清单

1. 对称 $K(x, z) = K(z, x)$ 与任意有限点集上 Gram 矩阵半正定；任何半正定矩阵可写 Gram，二次型非负即范数平方，特征映射在有限维拼出、连续情形由完备化兜底。（§1.1）
2. 程序实测：特征值全非负；手拆：利用十字对称构造特殊向量，$v_1$ 的对立臂内积正负相消，谱为 ${3.5372,\ 0.6321,\ 0.6321,\ 0.1548,\ 0.0438}$。（§1.2）
3. 毛坯：有限组合 $\sum \alpha_i K(x_i, \cdot)$；内积：$\sum_{i,j} \alpha_i \beta_j K(x_i, z_j)$（半正定保合法）；再生：$f(x) = \langle f, K(x, \cdot) \rangle$；完备化：Cauchy 极限补全，性质按连续性延拓。（§1.3）
4. 非负标量倍、和、积（Schur，特征映射取张量 $\varphi_1 \otimes \varphi_2$）、逐点极限；链：常数核 $\to$ 线性 $\to$ 指数核 $\mathrm{e}^{x \cdot z} \to$ 乘以 $g(x)g(z)$ 得高斯核。（§1.4）
5. 判据：数据只以内积进场；机制：Gram 矩阵整张换成核矩阵；六维展开把 $(x_1z_1 + x_2z_2 + 1)^2$ 的交叉项摊开，偏置项是判据的边界案例。（§2.1）
6. $w = \sum_i \alpha_i y_i \varphi(x_i)$，判别 $f(x) = \sum_i \alpha_i y_i K(x_i, x)$——只记「被错过几次」的计件账本。（§2.2.1）
7. 主方向活在样本张成空间里 $\to$ 特征方程压成 $\tilde{K}\alpha = \nu\alpha \to$ 中心化 $\tilde{K} = K - \mathbf{1}K - K\mathbf{1} + \mathbf{1}K\mathbf{1} \to$ 归一化与新点投影。（§2.2.2）
8. 正交分解 $H_K = S \oplus S^{\perp}$；$f_{\perp}$ 在训练点上隐身（再生性质）；损失相同、范数更贵（勾股）；$\Omega$ 严格增时正交部分非零者不可能最小。（§3.1）
9. $\min \lVert y - K\alpha \rVert^2 + \lambda\alpha^{\mathsf T}K\alpha$，解 $\alpha = (K + \lambda I)^{-1}y$，预测 $f(x^*) = k(x^*)^{\mathsf T}\alpha$；$K$ 特征值全 $\ge 0$，加 $\lambda I$ 后全 $\ge \lambda$。（§3.2）
10. $\mu_p = \mathrm{E}_p K(x, \cdot)$；引理 $\langle \mu_p, f \rangle = \mathrm{E}_p f$；$\mathrm{MMD}^2 = \lVert \mu_p - \mu_q \rVert^2$ 展开成三项期望（p 内、q 内、交叉各一份）。（§4.1—4.2）
11. 有偏含对角线、无偏去对角线（分母 $m(m-1)$）；偏差 $(1 - c)(1/m + 1/n)$；零分布是权重未知的加权卡方、不可查表，置换检验洗牌重分在有限样本下精确。（§4.2—4.3）
12. 任意有限点取值联合高斯；$\mu_* = K_*(K + \sigma_n^2 I)^{-1}y$，$\Sigma_* = K_{**} - K_*(K + \sigma_n^2 I)^{-1}K_*^{\mathsf T}$；离训练点远则方差胖、近则瘦。（§5.1—5.2）
13. $\sigma^2 \leftrightarrow \lambda$，系数向量同为 $(K + \sigma^2 I)^{-1}y$；GP 多给逐点方差、完整后验（可采样函数）、边际似然（内在的模型选择标尺）。（§5.4）
14. 特征 $\varphi$ vs $\phi_\theta$、读出都线性、拟合凸 vs 非凸、交付 $\alpha$ 账本 vs 百万参数 $\theta$；NTK：宽度趋无穷时训练等价于以 $\Theta$ 为核的核回归。（§6.1）
15. 核方法：小数据（凸＋泛化保证）、可解释（核＝显式假设）、统计推断（MMD 的 p 值）；深度学习：大数据（账本爆掉）、结构化输入（先验编译进架构）。（§6.2—6.3）

## $\rm \S \, R1.7$ 衔接

向前：线性代数册的谱定理与概率论册的多元高斯是第 1、5 章的零件库；数值计算册的 $O(n^3)$ 求解账是规模化讨论的地基。向后：深度学习理论册有 NTK 的完整证明与 feature learning 分水岭；核方法册的持久核（TDA 册第 4 章）把「图间距离」接进同一套核机器；稀疏 GP 与随机特征是规模化的工程出口，贝叶斯优化（超参数搜索）是方差项的直接变现。
