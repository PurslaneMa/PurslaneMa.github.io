# $\rm Chapter \, 4$ 层、模块与损失函数

上一章拿到了每个参数的梯度，可网络本身还没搭起来：自己写 ${x@W+b}$ 意味着手动管权重、手动写每层的前向表达式，层数一多就散成一地。PyTorch 把这件事收进三个词：层（layer）把「一组一起被用到、一起被训练的参数」打包，模块（module）把层组织成能复用、能报参数的网络，损失函数把「预测离标签有多远」收成一个标量。本章前半回答「这三样在 PyTorch 里怎么写」，后半打开盖子，看一层的前向与反向各是什么矩阵公式、参数又是怎么按名字被收集起来的。全册对照实验的验证环境：WSL Ubuntu，Python 3.12，NumPy 2.5.4，PyTorch 2.14.1+cpu，除特别说明外一律 float64。

## $\rm \S \, 4.1$ 用 nn.Linear 拼一个网络

要解决的问题：不必自己管权重矩阵、自己写每层的前向表达式。`nn.Linear` 一行带来权重与偏置，激活函数一行带来非线性，`nn.Sequential` 把它们按顺序串成网络：

```python
import torch, torch.nn as nn, torch.nn.functional as F
net = nn.Sequential(nn.Linear(3, 5), nn.ReLU(), nn.Linear(5, 2))  # 3 进 5 出、5 进 2 出
print(net)   # Sequential((0): Linear(3,5) (1): ReLU() (2): Linear(5,2))
print(sum(p.numel() for p in net.parameters()))  # 32 = 3*5+5 + 5*2+2
```

| 写法 | 说明 |
| --- | --- |
| `nn.Linear(in_features, out_features)` | 全连接层，输入最后一维必须等于 `in_features` |
| `nn.ReLU()` / `nn.Sigmoid()` / `nn.Tanh()` / `nn.Dropout(p)` | 逐元素激活，无参数；`Dropout` 训练时按概率 `p` 置零 |
| `nn.Sequential(a, b, c)` | 按顺序串联；喂 `net(torch.randn(4, 3))` 得形状 ${(4,2)}$，批维保留 |
| `print(model)` / `sum(p.numel() for p in model.parameters())` | 打印逐层结构 / 统计参数总量 |

**本节小结**：一行 `nn.Linear` 免掉手动管权重与偏置，`Sequential` 免掉手动串联——能顺序堆叠就够用；要分支、要算术时，看下一节的自定义模块。

## $\rm \S \, 4.2$ 自定义模块：三个动作

要解决的问题：`Sequential` 只能顺序堆叠；需要分支、需要在 `forward` 里做算术时，就继承 `nn.Module` 自己写。标准写法只有三个动作：继承、在 `__init__` 里先 `super().__init__()` 再建层、在 `forward` 里拼数据流：

```python
class Net(nn.Module):
    def __init__(self):
        super().__init__()               # 第一句：初始化基类的记账结构
        self.l1 = nn.Linear(3, 5)        # 子层赋给 self 属性即被登记
        self.l2 = nn.Linear(5, 2)
    def forward(self, x):
        return self.l2(F.relu(self.l1(x)))   # 一行拼出两层数据流
net = Net()
y = net(x)                               # net(x) 等价于 net.forward(x)
```

| 写法 | 说明 |
| --- | --- |
| `class Net(nn.Module)` / `super().__init__()` | 继承模块基类；`super().__init__()` 写在 `__init__` 第一句，初始化基类记账结构 |
| `self.l1 = nn.Linear(...)` | 子层赋给 `self` 属性即被登记，登记名就是属性名 |
| `def forward(self, x)` / `net(x)` | 定义数据流 / 调用入口，`net(x)` 等价 `net.forward(x)` |
| `net.parameters()` | 递归报出全部参数，直接交给优化器（第 5 章） |

**本节小结**：继承、`__init__` 里先 `super().__init__()` 再建层、`forward` 拼数据流——三个动作换来分支与算术的自由；子层赋给 `self` 属性才会被登记，这条规则下一节打开给你看。

## $\rm \S \, 4.3$ 损失函数与初始化

要解决的问题：网络输出是预测，训练要知道「离标签差多少」，这个标量就是损失；它对参数可导，`backward()` 才有东西可算。三类任务配三个损失：

```python
mse = nn.MSELoss()                     # 回归：均方误差
ce  = nn.CrossEntropyLoss()            # 多分类：吃 logits，内部已含 Softmax
bce = nn.BCEWithLogitsLoss()           # 二分类：吃 logits，内部已含 Sigmoid
print(mse(torch.tensor([1., 2.]), torch.tensor([1., 3.])))   # tensor(0.5000)
print(ce(torch.tensor([[2., 1., .1]]), torch.tensor([0])))   # tensor(0.4170)
print(bce(torch.tensor([0.5]), torch.tensor([1.])))          # tensor(0.4741)
```

`CrossEntropyLoss` 吃 logits（未过 Softmax 的原始分数），Softmax 与取对数在它内部做掉；自己再套一层是常见错（§4.6）。`nn.X` 是有状态、能塞进模块的层对象，`nn.functional`（约定别名 `F`）是无状态函数式接口：`F.relu(x)` 与 `nn.ReLU()(x)` 数值一样，区别是前者只能写在 `forward` 里。初始化用 `torch.nn.init` 的 `xavier_uniform_`、`kaiming_uniform_` 等，但各层默认自带合理初始化，多数时候不用手设；真正要手写的「全零」是 bug（§4.5）。

| 写法 | 说明 |
| --- | --- |
| `nn.MSELoss()` | 回归损失，输入与目标同形状 |
| `nn.CrossEntropyLoss()` | 多分类，输入是 logits，目标是类别下标 |
| `nn.BCEWithLogitsLoss()` | 二分类，输入是 logits |

**本节小结**：损失把「离标签差多少」收成一个可导标量，`backward()` 才有起点；logits 直接喂 `CrossEntropyLoss`/`BCEWithLogitsLoss`，内部自带的 Softmax/Sigmoid 别再手套一遍。

## $\rm \S \, 4.4$ 打开盖子：一层的前向与反向

不打开盖子，`nn.Linear` 就是个黑盒，前向反向各算什么、为什么反向能对上游交代，你只能背。层是「前向 + 反向」一对方法，反向签名统一：收上游梯度 ${g=\partial L/\partial(\text{输出})}$，返回 ${\partial L/\partial(\text{输入})}$。三个基本层各 5 行：

```python
class Linear:
    def forward(self, x):
        self.x = x                      # 反向要用
        return x @ self.W + self.b
    def backward(self, g):
        self.gradW += self.x.T @ g      # dL/dW
        self.gradb += g.sum(axis=0)     # dL/db
        return g @ self.W.T             # dL/dx，传给下一层

class ReLU:
    def forward(self, x):
        self.mask = (x > 0)
        return x * self.mask
    def backward(self, g):
        return g * self.mask

class Sigmoid:
    def forward(self, x):
        self.y = 1 / (1 + np.exp(-x))
        return self.y
    def backward(self, g):
        return g * self.y * (1 - self.y)
```

每一层在反向时缺一点前向的信息，缺什么就要存什么：

| 层 | 前向保存 | 反向公式 | 保存的原因 |
| --- | --- | --- | --- |
| Linear | 输入 ${x}$ | ${\partial L/\partial W=x^{\top}g}$ | 公式里只有 ${g}$ 推不出 ${x}$ |
| ReLU | 掩码 ${x>0}$ | 逐元素 ${g\odot\mathrm{mask}}$ | 导数取 0 或 1，由前向输入决定 |
| Sigmoid | 输出 ${y}$ | ${g\odot y(1-y)}$ | 导数用输出表出最省，不必存 ${x}$ |

**本节小结**：层是「前向 + 反向」一对方法，签名统一——收上游梯度、还下游梯度；反向公式里缺什么，前向就存什么，三层的保存清单各不相同，道理是同一句。

## $\rm \S \, 4.5$ 打开盖子：迷你 Module 与参数收集

不打开盖子，`model.parameters()` 交出来的那一串参数就像凭空出现，你没法判断层有没有被漏收、嵌套网络为什么能自动展开。除了层，还需要一个容器统一「调用」（像函数一样 `net(x)`）、统一「报参数」、统一「清梯度」。25 行的迷你 Module：

```python
class Module:
    def __call__(self, x):              # net(x) 等价于 net.forward(x)
        return self.forward(x)
    def parameters(self):
        ps = []
        for name, v in self.__dict__.items():
            if isinstance(v, Module):   # 子层或子网络都算
                ps += [f"{name}.{q}" for q in v.parameters()]
        return ps
    def zero_grad(self):
        for v in self.__dict__.values():
            if isinstance(v, Module):
                v.zero_grad()
    def forward(self, x):
        raise NotImplementedError

class MLP(Module):
    def __init__(self, W1, b1, W2, b2):
        self.l1 = Linear(W1, b1)
        self.a1 = ReLU()
        self.l2 = Linear(W2, b2)
    def forward(self, x):
        return self.l2(self.a1(self.l1(x)))
```

`MLP` 实例的 `parameters()` 返回 `['l1.W', 'l1.b', 'l2.W', 'l2.b']`（ReLU 无参数，自动跳过）。这张表**带名字**，名字不是装饰：

1. 保存与恢复：checkpoint 里的参数按名字存取（PyTorch 的 `state_dict` 键就是这套名字），换台机器续训靠它对号入座；
2. 调试：梯度爆炸时，`l2.W` 比「第 10086 个数」有用得多；
3. 递归收集：`isinstance(v, Module)` 让嵌套网络自动展开，Module 里放 Module，名字用点号串起来，`net.encoder.l1.W` 这类路径就是这么来的。

`zero_grad()` 也值得一句：第 3 章说梯度要累积（`+=`），那是**同一次反向传播之内**的多路径求和；跨训练步的旧梯度必须清掉。忘记 `zero_grad()` 是常见 bug：优化器拿到的梯度悄悄混着上一步的旧账。PyTorch 里 `optimizer.zero_grad()` 每步必调，同一枚硬币的两面。

对照实验（验证环境：WSL Ubuntu，PyTorch 2.14.1+cpu，float64）：${3\to5\to2}$ 的两层 MLP，4 个样本，MSE 损失，两边用同一份权重与输入：

| 量 | 迷你（NumPy） | torch.nn | 最大差 |
| --- | --- | --- | --- |
| 损失 | 11.777685821502 | 11.777685821502 | ${1.8\times10^{-15}}$ |
| 前向输出 | 同上逐数 | 同上逐数 | ${8.9\times10^{-16}}$ |
| ${W_1}$ 梯度 | ${(3,5)}$ | ${(3,5)}$ | ${1.8\times10^{-15}}$ |
| ${b_1}$ 梯度 | ${(5,)}$ | ${(5,)}$ | ${8.9\times10^{-16}}$ |
| ${W_2}$ 梯度 | ${(5,2)}$ | ${(5,2)}$ | ${1.8\times10^{-15}}$ |
| ${b_2}$ 梯度 | ${(2,)}$ | ${(2,)}$ | ${4.4\times10^{-16}}$ |

最后是初始化。偏置可以设零（它不参与层内对称）；权重全零不行，真跑两段小实验：

1. **全零权重**：输入 ${(2,1)}$ 过 Linear(全零) 得前向值 ${(0,0)}$，ReLU 掩码全假，反传后 `gradW` 全零：参数永不更新，网络学不动；
2. **两列相同**：权重两列初始化成一样（前向值 ${(3,3)}$），反传后 `gradW` 是 `[[2, 2], [1, 1]]`，两列永远相同：两个「不同」的隐层单元步调一致，整层退化成一个单元。

第二条正是深度学习分册 §7.4.1 用归纳法证明的对称性：梯度下降只会**保持**初始对称，打破对称的唯一机会是初始化那一刻，所以权重必须随机。本册的贡献是把证明跑成了代码。

## $\rm \S \, 4.6$ 常见错误与报错翻译

1. 症状：在 `forward` 里把张量转成 NumPy 数组再送进层，报 `TypeError: linear(): argument 'input' (position 1) must be Tensor, not numpy.ndarray`。原因：层只吃张量，NumPy 数组不带计算图，`Linear` 也不认它。改法：整条数据流保持张量；确要用 NumPy，算完转回 `torch.tensor(arr)`。
2. 症状：`sum(p.numel() for p in model.parameters())` 统计出 0，优化器拿到空参数表。原因：用 Python `list` 装层，Module 只登记 `nn.Module` 类型的属性，list 不是。改法：改用 `nn.ModuleList`（真跑：`list` 版 0 个参数，`nn.ModuleList` 版 4 个）。
3. 症状：`loss` 永不下降，或降得异常慢。原因：`CrossEntropyLoss` 已经内含 Softmax，前向里又套了一层 Softmax，等于把 Softmax 做了两遍。改法：去掉最后一层的激活，直接把 logits 喂给损失（真跑：同一份 logits，套 Softmax 得 0.8021209239959717，正确得 0.4170299470424652）。

## $\rm \S \, 4.8$ 应用与辨析

1. 用 `nn.Sequential` 与自定义 `nn.Module` 各写一遍同一个 3→5→2 网络，说明什么时候必须用后者。
2. 给本章加一个 Sigmoid 版的多层网络，层数加深后梯度会怎样变化？用 Sigmoid 导数最大值 0.25 说明。

## $\rm \S \, 4.9$ 本章自测答案

### $\rm \S \, 4.9.1$ 关键概念回顾答案

1. `nn.Linear` 免去手动存取权重与偏置，`nn.Sequential` 免去手动串联与逐层调用；参数总量用 `sum(p.numel() for p in model.parameters())`。（§4.1）
2. 继承 `nn.Module`、`__init__` 里先 `super().__init__()` 再建层、`forward` 里拼数据流；子层赋给 `self` 属性才会被 Module 登记进 `parameters()`，否则收集不到。（§4.2）
3. Linear 存输入 ${x}$，ReLU 存掩码，Sigmoid 存输出；Sigmoid 的导数 ${y(1-y)}$ 可由输出直接算出，存 ${y}$ 比存 ${x}$ 省一次指数。（§4.4）
4. 保存 checkpoint、定位调试都靠名字对号；递归收集靠 `isinstance(v, Module)`。（§4.5）

### $\rm \S \, 4.9.2$ 应用与辨析答案

1. 顺序堆叠两者等价；一旦要在 `forward` 里做分支、复用同一子层或插入算术，`Sequential` 表达不了，必须自定义模块。（§4.2）
2. 每过一层梯度至少乘 0.25，$k$ 层后衰减到 ${4^{-k}}$ 以下，深网络梯度消失；这正是 Sigmoid 让位给 ReLU/tanh 的原因。（§4.4）
3. 落到 float32 机器精度即 ${10^{-7}}$ 量级，仍是「逐数一致」，只是基线变宽。（§4.5）
4. 不会变（`None` 不是 Module，跳过）；`forward` 在 `self.a1(...)` 处抛 `TypeError: 'NoneType' object is not callable`。（§4.5）
