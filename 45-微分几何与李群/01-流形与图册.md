# $\rm Chapter \, 1$ 流形与图册

你早就见过弯曲的空间：地球表面、单位球面、所有旋转摆在一起构成的集合 $\mathrm{SO}(3)$。它们的共同点是「局部看起来像 $\mathbb{R}^n$，整体却弯」——站在地面上的人觉得自己脚下是平的，可飞机一直往一个方向飞会绕回原地。微积分的全套工具（导数、泰勒展开、隐函数定理）都是在 $\mathbb{R}^n$ 上造的，怎么把它们搬到弯曲的世界里去？本章的答案是流形（manifold）：不造一套新的微积分，而是给弯曲空间配一堆「局部平纸」，把每个局部拉回 $\mathbb{R}^n$ 借用现成的微积分，再管好纸与纸之间怎么拼接。这张路线图的终点在第 3 章兑现——李群与李代数，具身智能册第 1 章用过的 $\mathrm{SO}(3)$ 语言在那里拿到一般理论。

## $\rm \S \, 1.1$ 为什么需要流形：平纸拼出来的弯曲世界

三个真实对象先摆上台面。

1. **地球表面 $S^2$**： 经纬度是最常用的坐标，可它在南北两极退化——所有经线在极点交汇，经度在那里没有意义。极点不是地球的毛病，是这张坐标表的毛病；换一张图（比如以极点为中心的极区投影）极点就好了，可那张图又在别处退化。结论：一张纸不够，得用多张。
2. **旋转群 $\mathrm{SO}(3)$**： 一个三维旋转由三个参数决定，欧拉角是最省事的取法——但具身智能册第 1 章的万向节锁已经演示过，俯仰角到 $\pm 90^\circ$ 时这张参数表塌掉。同样，毛病在表不在空间：姿态空间本身好好站着，是任何单张全局坐标表都必然在某个地方退化。
3. **机器人位形空间**： 六自由度机械臂的手部位姿由位置三个数加姿态三个数决定，取值范围是 $\mathrm{SE}(3)$——一个六维的弯曲集合。做规划、做优化时如果假装它是一块 $\mathbb{R}^6$ 平地，减一格就「越界」的姿态会悄悄出现。

白话：**流形就是用平纸拼出来的弯曲世界**。每张平纸是一张坐标卡，它把弯曲世界的一小块毫无褶皱地摊平在 $\mathbb{R}^n$ 上；纸与纸的拼接规则（重叠区怎么换算坐标）写得清清楚楚。微积分在每张纸上照常做，拼接规则负责把不同纸上的答案对上账。

这个「局部平、整体弯」的模式在数学里到处出现：曲线是一维流形（每点附近像一小段直线），曲面是二维流形，$\mathrm{SO}(3)$ 是三维流形。初学最容易拧的一处先拆掉：**流形不等于图册**。地球是一回事，地图册是另一回事——地图册可以重印、增补、换投影，地球不跟着变；流形是那个集合加「能被图册摊平」这件事本身，图册只是我们附上去的描述。后面说「光滑性依赖图册」，指的是描述里的光滑，而它恰好不因换册而变，所以归根到底还是流形自己的属性。下节把定义写严。

**小结**：本节立了动机——单张全局坐标表在弯曲空间上必然退化，出路是多张局部表加拼接规则；这份「多张表」的正式名字叫图册，下一节给定义。

## $\rm \S \, 1.2$ 定义：从拓扑流形到光滑流形

先说清楚要定义什么：一个集合 $M$，配上「每点附近像 $\mathbb{R}^n$」的结构。白话版说完了，严的版本分两级——拓扑流形管「局部摊平」，光滑流形再管「拼接够光滑、能做微积分」。

**定义（拓扑流形）**：$M$ 是一个拓扑空间，若它满足：

1. **局部欧氏**：每点 $p \in M$ 有开邻域 $U$，使得 $U$ 同胚于 $\mathbb{R}^n$ 的开集。这个 $n$ 叫 $M$ 的维数，与点无关（$M$ 连通时）。
2. **Hausdorff**：任意两个不同的点可以被不相交的开集分开。
3. **第二可数**：存在可数个开集构成拓扑的基。

条件 1 是主角；条件 2、3 是防「病态拼法」的护栏，白话各一句——条件 2 排除「两个点分不开」的粘合怪胎（把两条直线在原点外处处粘合得到的「有双原点的直线」），条件 3 排除「不可数多块碎片」这种任何图册都写不完的对象。本册遇到的对象全是欧氏空间的子集，两条护栏自动满足，真正要动手验证的只有局部欧氏。

维数 $n$ 是流形的内在属性，不是坐标的产物——一条曲线无论怎么摊都不能局部同胚于平面。这不是显然的（同胚可以剧烈变形），背后的定理叫**维数不变性**（domain invariance 的推论，证明超出本册，见任何拓扑教材）：$\mathbb{R}^n$ 的开集同胚于 $\mathbb{R}^m$ 的开集当且仅当 $n = m$。实用结论：谈流形维数前不必担心「换个图册维数变了」这种事。

**定义（坐标卡与图册）**：拓扑流形 $M$ 上的一个**坐标卡**（chart）是二元组 $(U, \varphi)$，其中 $U \subseteq M$ 是开集，$\varphi : U \to \varphi(U) \subseteq \mathbb{R}^n$ 是同胚。一族坐标卡 $\{(U_\alpha, \varphi_\alpha)\}_\alpha$ 若并起来覆盖 $M$，就叫 $M$ 的一个**图册**（atlas）。两张卡重叠处的**转移映射**（transition map）是

$$
\varphi_\beta \circ \varphi_\alpha^{-1} \;:\; \varphi_\alpha(U_\alpha \cap U_\beta) \;\longrightarrow\; \varphi_\beta(U_\alpha \cap U_\beta),
$$

读法：先在 $\alpha$ 卡的平面坐标里站好，走回弯曲世界，再摊到 $\beta$ 卡上——重叠区换算坐标的全部规则就这一条复合。

**定义（光滑流形）**：图册中任意两张卡的转移映射都是 $C^\infty$（无穷次连续可微）时，称图册为**光滑图册**，$M$ 配上它称为**光滑流形**。如果 $C^\infty$ 降为 $C^k$，就叫 $C^k$ 流形。

为什么拼接规则光滑就够定义「流形上做微积分」？直觉是：想在 $M$ 上问「这个函数光滑吗」，先拉到某张卡上看；换一张卡看，答案会不会变？转移映射光滑保证不会变——这正是下节的内容。现在先看最重要的例子，把两张卡真的写出来。

一个技术注脚：同一个拓扑流形可以配上不同的光滑图册（彼此转移映射不光滑、各造各的微积分），这时它们算不同的光滑流形。实践中不在意——通常取一个自然的图册，再取「与它相容的全部坐标卡」拼成**极大图册**作为标准配置，光滑结构就此唯一固定。本册说「光滑流形」时，心里想的都是这份极大配置。

**例（球面 $S^2$ 的球极投影图册）**：$S^2 = \{x \in \mathbb{R}^3 : x_1^2 + x_2^2 + x_3^2 = 1\}$，北极 $N = (0,0,1)$，南极 $S = (0,0,-1)$。取两张卡：

$$
U_N = S^2 \setminus \{N\}, \qquad \varphi_N(x) = \left( \frac{x_1}{1 - x_3},\ \frac{x_2}{1 - x_3} \right),
$$

$$
U_S = S^2 \setminus \{S\}, \qquad \varphi_S(x) = \left( \frac{x_1}{1 + x_3},\ \frac{x_2}{1 + x_3} \right).
$$

读法：$\varphi_N$ 的几何是把光源放在北极、把球面（除北极外）投影到赤道平面上；离北极越近的点投得越远，北极本身投到无穷远，所以干脆从 $U_N$ 里挖掉。$\varphi_S$ 是南极版的同一招。每张卡各挖掉一个点，两卡并起来恰好盖满 $S^2$。

反解 $\varphi_N$（记平面坐标 $(u,v)$，令 $r^2 = u^2 + v^2$）：

$$
\varphi_N^{-1}(u, v) = \left( \frac{2u}{r^2 + 1},\ \frac{2v}{r^2 + 1},\ \frac{r^2 - 1}{r^2 + 1} \right).
$$

验证是代入：三分量的平方和为 $\frac{4u^2 + 4v^2 + (r^2-1)^2}{(r^2+1)^2} = \frac{(r^2+1)^2}{(r^2+1)^2} = 1$，确实落回球面；再核 $x_3 = \frac{r^2-1}{r^2+1}$ 代回 $\varphi_N$ 的公式得 $u$、$v$，是真正的逆。两卡重叠区 $U_N \cap U_S = S^2 \setminus \{N, S\}$ 上算转移映射：

$$
\varphi_S \circ \varphi_N^{-1}(u, v) = \left( \frac{2u/(r^2+1)}{1 + (r^2-1)/(r^2+1)},\ \frac{2v/(r^2+1)}{1 + (r^2-1)/(r^2+1)} \right) = \left( \frac{u}{r^2},\ \frac{v}{r^2} \right),
$$

分母整理：$1 + \frac{r^2-1}{r^2+1} = \frac{2r^2}{r^2+1}$，约分后得 $\left(\frac{u}{r^2}, \frac{v}{r^2}\right)$。读法：转移映射就是平面到自身的「关于单位圆的反演」，定义域是 $\mathbb{R}^2 \setminus \{(0,0)\}$——挖掉的原点正是北极，它只存在于另一张卡里。这个映射的每个分量都是分母非零的有理函数，$C^\infty$ 没有悬念。于是 $S^2$ 配上这两张卡是二维光滑流形。$\varphi_N \circ \varphi_S^{-1}$ 是同一个反演（自己跟自己复合等于平方，仍是有理函数），对称成立。

注意一个模式：分母 $1 - x_3$ 在北极归零，这正是「单张卡必有退化点」的代数身影——退化被一张卡的挖除换成了两张卡的无缝衔接。经纬度在极点的坍塌、欧拉角在俯仰 $\pm 90^\circ$ 的万向节锁，全是同一件事的变奏。

**小结**：本节给了两级定义——拓扑流形管局部摊平，转移映射光滑升级成光滑流形；并把 $S^2$ 的两卡图册从公式到转移映射完整算了一遍。接口：现在可以谈「流形上的函数」了。

## $\rm \S \, 1.3$ 光滑函数与光滑映射：借坐标卡拉回 $\mathbb{R}^n$ 看

流形上没有天生的加法和坐标系，$\lVert f(p + h) - f(p) \rVert$ 这种式子根本写不出来——$p + h$ 是什么？出路早就在图册里：拉回平地。

**定义（光滑函数）**：$f : M \to \mathbb{R}$ 称为**光滑**，若对每张卡 $(U, \varphi)$，复合 $f \circ \varphi^{-1} : \varphi(U) \subseteq \mathbb{R}^n \to \mathbb{R}$ 是通常意义下的 $C^\infty$ 函数。

**定义（光滑映射）**：$F : M \to N$（两个流形）称为**光滑**，若对 $M$ 的每张卡 $(U, \varphi_M)$ 与 $N$ 的每张卡 $(V, \varphi_N)$，只要 $F(U) \cap V \ne \emptyset$，复合

$$
\varphi_N \circ F \circ \varphi_M^{-1} \;:\; \varphi_M(U) \longrightarrow \varphi_N(V)
$$

就是 $\mathbb{R}^n \to \mathbb{R}^m$ 的 $C^\infty$ 映射。白话：弯曲世界之间的映射，两头各摊到平纸上再看。

**「与坐标选取无关」怎么读**：定义里说「每张卡」，听着要验无穷多次，其实不然。设 $(U_\alpha, \varphi_\alpha)$、$(U_\beta, \varphi_\beta)$ 是两张卡，在重叠区上

$$
f \circ \varphi_\beta^{-1} \;=\; \left( f \circ \varphi_\alpha^{-1} \right) \circ \left( \varphi_\alpha \circ \varphi_\beta^{-1} \right),
$$

读法：右端是「光滑函数复合光滑转移映射」——$\alpha$ 卡上的视图换成 $\beta$ 卡上的视图，中间垫的正是 §1.2 那条光滑转移映射。所以只要一张卡上光滑，全部卡上自动光滑；光滑性是流形自身的属性，不是某张卡的属性。这条「换卡不变」的论证模式值得记熟：本册后面每个「与坐标无关」的断言（切空间、微分）都靠它撑腰。

光滑函数的运算照旧：两个光滑函数的和、积光滑（在卡里逐点做），光滑映射的复合光滑（在卡里用链式法则）。有一个日常可用的捷径：**环境空间里光滑函数的限制自动光滑**——设 $M \subseteq \mathbb{R}^m$ 是流形，$F : \mathbb{R}^m \to \mathbb{R}$ 通常光滑，则限制 $F|_M$ 光滑，因为取卡后 $F \circ \varphi^{-1}$ 是两个光滑映射的复合。例：高度函数 $h(x) = x_3$ 在 $S^2$ 上光滑，坐标分量在 $\mathrm{SO}(3)$ 上光滑。反过来要造「流形上不光滑的函数」反而费劲，本册用不到。微分学就此搬进了弯曲世界——但「导数」本身还欠着：$F$ 的导数该是从什么到什么的映射？它的定义域不该是流形（那里没有向量结构），而是每点长出来的一个线性空间。这是第 2 章的主角。

**小结**：本节把「光滑」从 $\mathbb{R}^n$ 推广到流形，办法是借卡拉回平地；换卡不变的担保来自转移映射光滑。接口：判光滑的地基——隐函数与反函数定理——下节登场。

## $\rm \S \, 1.4$ 隐函数定理是地基：正则值定理

具身智能册说「$\mathrm{SO}(3)$ 是三维的」，第 2 章要说「切空间是 $n$ 维的」，这些都欠着同一个问题：怎么证明一个由方程定义的集合是流形、维数是多少？答案把连续数学册第 5 章 §5.4 的两条定理升格为几何工具。

**陈述（反函数定理，cn05 §5.4）**：$F : \mathbb{R}^n \to \mathbb{R}^n$ 在 $\mathbf{x}_0$ 的邻域内 $C^1$ 且 $\det JF(\mathbf{x}_0) \ne 0$，则 $F$ 在 $\mathbf{x}_0$ 附近有 $C^1$ 的局部逆。几何读法：雅可比满秩处，映射局部不压扁、不折叠。

**陈述（隐函数定理，cn05 §5.4）**：$F : \mathbb{R}^n \to \mathbb{R}^k$（$k \le n$），$F(\mathbf{x}_0, \mathbf{y}_0) = \mathbf{0}$，且 $k \times k$ 偏雅可比 $\mathbf{D}_{\mathbf{y}}F$ 在该点可逆，则方程组 $F(\mathbf{x}, \mathbf{y}) = \mathbf{0}$ 在该点附近可解出 $\mathbf{y} = \mathbf{g}(\mathbf{x})$，且 $\mathbf{g}$ 是 $C^1$。几何读法：$k$ 个方程在条件不退化时，恰好能解出 $k$ 个坐标，剩下的 $n - k$ 个坐标自由——解集局部是 $n - k$ 维的光滑「图像」。

把两个陈述合起来，得到本章最常用的生产流形的机器：

**定理（正则值定理）**：$F : \mathbb{R}^n \to \mathbb{R}^k$ 是光滑映射，$c \in \mathbb{R}^k$ 是 $F$ 的**正则值**——即对每个 $p \in F^{-1}(c)$，雅可比 $DF_p : \mathbb{R}^n \to \mathbb{R}^k$ 都是满射（秩为 $k$）——则原像 $F^{-1}(c)$ 要么是空集，要么是 $n - k$ 维光滑流形。

证明思路一条，三步，全部材料都在 cn05：

1. 取 $p \in F^{-1}(c)$，$DF_p$ 满秩意味着 $F$ 的某 $k$ 个输出分量关于某 $k$ 个输入变量的偏雅可比可逆（满秩的列选择）。
2. 对这 $k$ 个变量用隐函数定理，把 $F^{-1}(c)$ 在 $p$ 附近解成「$n - k$ 个自由变量的光滑图像」。
3. 图像有天然的坐标卡（把自由变量当坐标），与 $\mathbb{R}^{n-k}$ 的开集同胚；不同点 $p$ 各得一张卡，卡间转移映射由隐函数解的光滑性保证光滑。局部成立、处处有卡，流形成立。

两个招牌例子，都一步到位。

1. **球面**：取 $F(x) = x_1^2 + x_2^2 + x_3^2$，则 $S^2 = F^{-1}(1)$。$DF_p = 2(p_1, p_2, p_3)$ 是 $1 \times 3$ 矩阵，在 $S^2$ 上处处非零（$p \ne 0$），秩为 1，所以 1 是正则值，$S^2$ 是 $3 - 1 = 2$ 维流形。§1.2 手工造的图册，这里由机器一键复产。
2. **正交群**：取 $F : \mathbb{R}^{n \times n} \to \mathrm{Sym}(n)$（对称矩阵空间，维数 $\frac{n(n+1)}{2}$），$F(A) = A^\top A$，则 $\mathrm{O}(n) = F^{-1}(I)$。正则性要验一下：对 $A \in \mathrm{O}(n)$，$DF_A(E) = A^\top E + E^\top A$（乘积求导，转置把第二项翻过来）；任给对称目标 $S$，取 $E = \frac{1}{2}AS$ 得 $DF_A(E) = \frac{1}{2}S + \frac{1}{2}S^\top = S$，满射成立。于是 $\mathrm{O}(n)$ 是 $n^2 - \frac{n(n+1)}{2} = \frac{n(n-1)}{2}$ 维流形。$n = 3$ 时是 3 维——具身智能册「旋转有三个自由度」这句话，在这里第一次拿到证明。
3. **隐式环面**：$\mathbb{R}^3$ 里的甜甜圈也能当正则原像：取 $F(x, y, z) = \left(\sqrt{x^2 + y^2} - 2\right)^2 + z^2$，则 $F^{-1}(1)$ 是一个环面（到 $z$ 轴距离为 2 的圆周膨胀出管径 1）。梯度 $\nabla F = \left(\frac{2(\rho - 2)x}{\rho},\ \frac{2(\rho - 2)y}{\rho},\ 2z\right)$（$\rho = \sqrt{x^2 + y^2}$）在曲面上不取零：为零要求 $z = 0$ 且 $\rho - 2 = 0$，而曲面上 $\left(\rho - 2\right)^2 + z^2 = 1$ 排除了这一组合，正则成立，环面是 2 维流形——§1.5 的乘积构造与这里的正则值机器，在同一只甜甜圈上会师。
4. **圆柱面**：最快的练手题。$F(x, y, z) = x^2 + y^2$，$F^{-1}(1)$ 是圆柱面；梯度 $(2x, 2y, 0)$ 在曲面上非零（${x, y}$ 不同时为零），正则值定理直接给 2 维流形。它是「既像球面又不像球面」的好对照：单张角坐标在割缝处断开，两三张角卡接起来照样光滑——把 §1.2 的图册手艺在更简单的对象上再练一遍。

「正则值」条件丢了会怎样：$F(x) = x^3$，$c = 0$，原像是 $\{0\}$，孤点不是一维流形；坏在 $F'(0) = 0$，0 不是正则值。正则性就是「方程在原像处不退化」的代数担保。配套的词汇也记一下：$F^{-1}(c)$ 上的点都是**正则点**，使 $DF_p$ 不满射的点叫**临界点**、对应的函数值叫临界值——正则值定理的原像里一颗临界点都没有，这正是结论这么干净的原因；而临界点处原像照样可能是流形（$F(x) = x^2$ 的原像 $\{1\}$ 无恙），只是定理不再担保，要手工另验。

**小结**：本节把隐函数定理升格为正则值定理——验一个满秩条件，换一个流形加维数公式。接口：有了流形和维数，可以谈切空间了，那是下一章；本章先把几个重要流形点名认脸。

## $\rm \S \, 1.5$ 例题花园：环面、实投影空间与 $\mathrm{SO}(3)$

三个流形各认一下脸，它们在本册后面反复出场。

1. **环面**：$\mathbb{T}^2 = S^1 \times S^1$，两个圆周的乘积。流形结构是白送的：$S^1$ 各有图册，乘积卡 $(U_1 \times U_2, \varphi_1 \times \varphi_2)$ 拼起来就是 $\mathbb{T}^2$ 的图册，维数相加得 2。它也是「两个角度」的世界：双摆的两个关节角、环面上的两个循环方向。嵌进 $\mathbb{R}^3$ 的甜甜圈参数化 $((2 + \cos v)\cos u, (2 + \cos v)\sin u, \sin v)$ 是它的一身衣服，不是它的定义——定义只需要乘积。
2. **实投影空间**：$\mathbb{RP}^2$ 是把 $S^2$ 的对径点（$p$ 与 $-p$）粘成一个点得到的商空间，直觉是「每条过原点的直线算一个点」。它是二维流形：$S^2$ 的球极投影两卡挖掉的只是 $\{N, S\}$，商空间里 $\{N, S\}$ 粘成一个点，两张卡下推到商空间仍是两张卡，转移映射还是那个反演。$\mathbb{RP}^n$ 在计算机视觉里是相机几何的家——齐次坐标 $\mathbf{x} \sim \lambda \mathbf{x}$ 的本质就是投影空间。
3. **$\mathrm{SO}(3)$ 是三维流形**：§1.4 的正则值定理已经给了维数 3。再看一张「具体卡」长什么样（具身智能册 §1.2 的轴角）：任何不等于恒等的旋转有唯一转轴 $\mathbf{n}$（单位向量，两个自由度）与转角 $\theta \in (0, \pi)$（一个自由度），三对参数（轴、角）各管 $\mathrm{SO}(3)$ 的一大块——三张卡（三种轴角约定）拼起来盖住全部，拼接规则光滑。这是「$\mathrm{SO}(3)$ 局部像 $\mathbb{R}^3$」的手工版，正则值定理是机器版，两版互证。

**双覆盖再登场**：具身智能册 §1.3 证过，单位四元数全体 $S^3$ 经 $q \mapsto q\mathbf{v}q^{-1}$ 打到 $\mathrm{SO}(3)$，局部一一、整体二对一（$q$ 与 $-q$ 同一旋转）。用本章的语言重说：这是一个光滑满射 $S^3 \to \mathrm{SO}(3)$，每点附近有光滑的局部逆——$S^3$ 的坐标卡经它「下推」就成了 $\mathrm{SO}(3)$ 的坐标卡。这给了一条判流形的捷径：想让 $X$ 是流形，找个已知流形 $Y$ 光滑地盖住它。第 3 章的指数映射 $\mathfrak{so}(3) \cong \mathbb{R}^3 \to \mathrm{SO}(3)$ 是同一招的微分版本。

花园里的四个花色（环面、投影空间、$\mathrm{SO}(3)$、圆柱面）其实只用了两副工具：一副是「乘、商、盖」——乘积、粘合、覆盖，从已知流形造新流形；另一副是「方程」——正则值定理，从约束造流形。后面遇到任何新空间，先问一句用的是哪副工具，往往就知道了答案的形状。

**小结**：本节认了三个流形并把双覆盖翻译成图册语言。接口：流形的地基打完，下一章给它长出「贴着切」的线性空间。

## $\rm \S \, 1.6$ 关键概念回顾

> 先闭卷作答本节六问，再核对 §1.7。

1. 拓扑流形的三个条件各防什么病？为什么本册的对象常常只需验证局部欧氏？
2. $S^2$ 球极投影两卡的转移映射是什么？它的定义域为什么恰好挖掉原点？
3. 「$f$ 光滑」为什么要强调与卡无关？换卡论证里哪一步用到转移映射光滑？
4. 正则值定理的条件与结论各是什么？「正则」丢了会怎样，举一个 $c = 0$ 的例子。
5. $\mathrm{O}(n)$ 的维数公式怎么来的？$n = 3$ 时它与 $\mathfrak{so}(3)$ 的维数怎么对上？
6. 双覆盖 $S^3 \to \mathrm{SO}(3)$ 怎么给 $\mathrm{SO}(3)$ 造坐标卡？这提示了判流形的什么通用捷径？

## $\rm \S \, 1.7$ 六问答案

1. Hausdorff 排除「两点分不开」的粘合（双原点直线），第二可数排除「不可数多块碎片」（图册写不完），局部欧氏是定义本体。本册对象都是 $\mathbb{R}^m$ 的子集继承拓扑，子空间的 Hausdorff 与第二可数自动继承，只剩局部欧氏要验。（§1.2）
2. $\varphi_S \circ \varphi_N^{-1}(u, v) = (u, v)/(u^2 + v^2)$，平面上的单位圆反演；定义域挖掉 $r^2 = 0$ 的原点，因为原点对应的球面点是北极，北极不在 $U_N$ 里，那张卡的坐标够不着它。（§1.2）
3. 因为「光滑」是借某张卡定义的，若答案随卡改变，属性就属于卡而不属于流形。换卡时视图的复合 $f \circ \varphi_\alpha^{-1} \circ (\varphi_\alpha \circ \varphi_\beta^{-1})$ 中，转移映射那一段必须光滑，复合才保光滑。（§1.3）
4. 条件：$DF_p$ 对每个 $p \in F^{-1}(c)$ 满射；结论：$F^{-1}(c)$ 是 $n - k$ 维光滑流形。丢失的例子 $F(x) = x^3$、$c = 0$：$F'(0) = 0$，原像 $\{0\}$ 是孤点，不流形。注意条件只在原像上验，原像外的临界点不碍事。（§1.4）
5. 环境空间 $\mathbb{R}^{n^2}$ 减方程个数 $\frac{n(n+1)}{2}$（对称矩阵的维数），得 $\frac{n(n-1)}{2}$。$n = 3$ 时 $\mathrm{O}(3)$ 是 3 维，与反对称矩阵空间 $\mathfrak{so}(3)$ 的 3 维一致——第 3 章会证明这不是巧合，是李群与李代数的维数恒等式。（§1.4）
6. $S^3$ 上取一张卡，卡内的两个四元数 $q, -q$ 打到 $\mathrm{SO}(3)$ 的同一邻域，局部逆光滑，于是该邻域继承了 $S^3$ 的坐标。捷径：找到已知流形对目标的光滑局部一一覆盖，目标自动是流形。（§1.5）

## $\rm \S \, 1.8$ 程序段：球极投影两卡互转的数值验证

下面的脚本把 §1.2 的公式全部落成数字：两卡坐标、转移映射、反解、以及「从任意球面点出发，两条路径殊途同归」。转移映射在代码里写两遍——一遍是公式 $(u, v)/r^2$，一遍是老老实实的「下球面、再南极投影」两步走——两者对得上，说明推导没骗人。

```python
import numpy as np

rng = np.random.default_rng(0)

def phi_N(p):                      # 北卡：挖掉北极 N=(0,0,1)
    return np.array([p[0]/(1 - p[2]), p[1]/(1 - p[2])])

def phi_S(p):                      # 南卡：挖掉南极 S=(0,0,-1)
    return np.array([p[0]/(1 + p[2]), p[1]/(1 + p[2])])

def phi_N_inv(uv):                 # 北卡反解（正文公式）
    r2 = uv @ uv
    return np.array([2*uv[0]/(r2+1), 2*uv[1]/(r2+1), (r2-1)/(r2+1)])

def transition_formula(uv):        # 转移映射：反演公式 (u,v)/r^2
    r2 = uv @ uv
    return uv / r2

def transition_honest(uv):         # 同一件事的两步走版
    return phi_S(phi_N_inv(uv))

# 实验 1：随机球面点（取上、下半球各若干），验证落在 |x|=1、两卡坐标互逆
worst_on_sphere, worst_inverse = 0.0, 0.0
for _ in range(10000):
    p = rng.normal(size=3); p /= np.linalg.norm(p)
    if abs(p[2] - 1) < 1e-9:       # 北极没有北卡坐标，跳过
        continue
    assert abs(np.linalg.norm(p) - 1) < 1e-12
    u = phi_N(p)
    worst_inverse = max(worst_inverse, np.abs(phi_N_inv(u) - p).max())
    # 转移映射两条路径对账（p 不在南极时南卡有定义）
    if abs(p[2] + 1) > 1e-9:
        worst_on_sphere = max(worst_on_sphere,
                              np.abs(transition_formula(u) - transition_honest(u)).max())
print("反解最大误差   :", worst_inverse)     # 期望 ~1e-16
print("转移映射对账   :", worst_on_sphere)   # 期望 0（逐点恒等）

# 实验 2：转移映射的几何含义——反演把离原点远的点拉近、近的点推远
uv = np.array([0.6, 0.8])          # r = 1 的点反演后不动
print("单位圆上的点   :", transition_formula(uv), "(应不动)")
uv2 = np.array([2.0, 0.0])
print("r=2 反演后     :", transition_formula(uv2), "(应到 (0.5, 0))")
```

实测输出：反解最大误差 $10^{-16}$ 量级（浮点噪声），转移映射对账为 0——公式版与两步走版逐点恒等；单位圆上的点经反演不动，$r = 2$ 的点被送到 $r = 1/2$。读法：转移映射不是抽象符号，它就是重叠区里「换卡」这个动作本身，而这个动作已被数值闭环。顺带预告失效现场：把采样点换成北极附近（$x_3 \to 1$），$1 - x_3 \to 0$、北卡坐标数值爆炸——坐标卡的退化不是理论隐忧，是把采样点推近挖除点就能在浮点层面亲眼看到的事。

## $\rm \S \, 1.9$ 带走清单

1. 流形 = 局部像 $\mathbb{R}^n$、整体可以弯的空间；白话是「平纸拼出来的弯曲世界」，每张纸是坐标卡，纸间换算是转移映射。
2. 光滑流形 = 转移映射全 $C^\infty$ 的拓扑流形；「局部欧氏」是主角，Hausdorff 与第二可数是护栏。
3. 流形上的光滑性全部借卡定义，且因转移映射光滑而与卡无关——「换卡不变」论证是全册的通用钥匙。
4. 正则值定理：$F : \mathbb{R}^n \to \mathbb{R}^k$、$c$ 正则 $\Rightarrow F^{-1}(c)$ 是 $n - k$ 维流形；它是隐函数定理的几何形态，一验一得。
5. $S^2 = F^{-1}(1)$（2 维）、$\mathrm{O}(n) = F^{-1}(I)$（$\frac{n(n-1)}{2}$ 维）；$\mathrm{SO}(3)$ 是 3 维流形，正则值定理与轴角卡两版互证。
6. 双覆盖 $S^3 \to \mathrm{SO}(3)$ 把已知流形的卡下推给未知者——「找光滑覆盖」是判流形的通用捷径，第 3 章的指数映射是它的微分版。
7. 流形与图册的关系是「地球与地图册」：图册可换、可重印，流形不动；光滑性借图册定义，却不因换册而变，归根到底是流形自身的属性。
