# $\rm \S \, Chapter \, 18$ 多项式方法与有限域组合：低次多项式的天花板

第 14 章的秩方法把组合对象编码成向量，请维数当天花板；本章把探针升级一档——**低次多项式**。向量只有「在与不在」两个档位，多项式的次数是一把可调的旋钮：旋得越低，容纳这些多项式的「车间」（函数空间的维数）越小，天花板压得越低。比喻：给每个组合断言配一台代数机器——多项式是机器本身，**消没**是机器在所有禁止点全部熄火，**维数账**是车间面积：能同时独立运转多少台机器，是任何构造都甩不掉的硬成本。本章四场战役：Combinatorial Nullstellensatz（Alon）与三个经典应用、Schwartz–Zippel 引理、cap set 的 Ellenberg–Gijswijt 界（偿还 §17.6 埋下的 $2.7551$ 这笔债）、有限域 Kakeya 的 Dvir 定理。这也是组合学册 cb7 阶段的收官一章。

## $\rm \S \, 18.1$ 动机：把探针从向量升级为多项式

1. **一句话纲领**。秩方法三步：把组合对象编码成向量、把组合禁令翻译成代数约束、用维数当天花板。多项式方法原样保留三步，只换中间件：编码对象 → 空间中的点，禁令 → **一个在禁止点全部熄火的多项式**，天花板 → 「低次多项式函数空间」的维数。
2. **为什么次数比秩更锋利**。向量探针（Oddtown 的 $\mathbb{F}_2^n$ 指示向量）的天花板是环境维数 $n$，硬到不能再硬但也低不下去；§14.3 的 Frankl–Wilson 已经演示过升级：探针换成多项式 $f_A$，天花板换成商空间的维数 $\sum_{i \le p-1}\binom{n}{i}$。次数预算 $d$ 换算成维数 $\binom{n+d}{d}$——**旋低次数就是在压天花板**，而组合禁令恰好经常允许把次数压到远低于 $n$。
3. **有限域是主场**。在 $\mathbb{F}_q$ 上「作为函数的多项式」可以砍次数：$x^q \equiv x$ 处处成立，每个函数有唯一的低次代表（指数各 $\le q-1$）。次数预算与函数空间维数的换算因此是**精确的有限数**，不是渐近——这是整数环上没有的奢侈，也是本章全部战役都选在有限域打的原因。

小结：多项式方法 = 秩方法换中间件；次数旋钮压维数天花板，有限域保证换算精确。

## $\rm \S \, 18.2$ Combinatorial Nullstellensatz：系数账本

1. 白话先行：什么时候能断言「一个多项式在整张网格上被迫全零」？答案是查它的**系数账本**——若某个特定单项式的系数是钱，账上还有钱，多项式就一定在网格的某个角落非零。这是本章所有「存在性」结论的记账规则。
2. **记号**：域 $F$，有限非空集 $S_i \subseteq F$，令 $g_i(x_i) = \prod_{s \in S_i}(x_i - s)$（次数 $|S_i|$）。网格指笛卡尔积 $\prod_i S_i$。对多项式 $f$，用 $g_n$ 做带余除法再用 $g_{n-1}, \ldots, g_1$ 逐个约化，得余项 $R$。
3. **引理 18.2.1（约化保系数）**（全证）：每次用 $g_i$ 约化，任何 $x_i$ 次数 $\le |S_i| - 1$ 的单项式的系数不变。证明：约化即 $f = q \cdot g_i + r$、$\deg_{x_i} r < |S_i|$，而 $q \cdot g_i$ 的每个单项式 $x_i$ 次数 $\ge |S_i| > |S_i| - 1$——两边在目标单项式上各不相干，系数相等。$\blacksquare$
4. **引理 18.2.2（低次函数网格为零则恒零）**（全证）：若 $R$ 满足 $\deg_{x_i} R \le t_i < |S_i|$（各变量独立计）且 $R$ 在整张网格上为零，则 $R \equiv 0$。证明对 $n$ 归纳。$n = 1$：单变量次数 $\le t_1$ 的多项式有 $|S_1| > t_1$ 个根，必为零。归纳步：把 $R$ 按 $x_n$ 展开 $R = \sum_{k=0}^{t_n} R_k(x_1, \ldots, x_{n-1})\, x_n^k$；在网格前 $n-1$ 个坐标的任一固定点处，$R$ 是 $x_n$ 的次数 $\le t_n < |S_n|$ 的多项式且有 $|S_n|$ 个根，故恒零，于是每个 $R_k$ 在该点为零；让固定点跑遍 $(n-1)$ 维网格，$R_k$ 在其上全零、各变量次数 $\le t_i < |S_i|$，由归纳假设 $R_k \equiv 0$。$\blacksquare$
5. **定理（Combinatorial Nullstellensatz，Alon 1999, Thm 1.1）**：$f \in F[x_1, \ldots, x_n]$，$\deg f = \sum_i t_i$，且 $\prod_i x_i^{t_i}$ 的系数非零；$S_i \subseteq F$ 满足 $|S_i| > t_i$。则存在网格点 ${s_1, \ldots, s_n} \in \prod_i S_i$ 使 $f(s_1, \ldots, s_n) \ne 0$。
6. **全证**：不妨 $|S_i| = t_i + 1$（缩小集合不破坏前提）。做第 2 条的逐级约化得余项 $R$：各变量次数 $\le t_i$，在网格上与 $f$ 相同（$g_i$ 在 $S_i$ 上全零），且由引理 18.2.1，$\prod_i x_i^{t_i}$ 的系数在 $f$ 与 $R$ 中相同、非零，故 $R \ne 0$。但 $f$ 在网格上……$f$ 并不必然在网格上为零——正确的收尾是反证：**若** $f$ 在整张网格上为零，则 $R$ 也是，由引理 18.2.2 得 $R \equiv 0$，与目标系数非零矛盾。所以定理的准确读法是反证形式：目标系数非零 $\Rightarrow$ $f$ 不可能在网格上全零。$\blacksquare$
7. **诚实注记**：上面的证明从头到尾没用 $\deg f = \sum t_i$——去掉了这个条件定理依然成立（Alon 的原始陈述保留它，因为应用里它恰好卡住次数预算）。另外 $F$ 任意：整数、有理数、有限域通吃。

小结：CN 是一条系数账本规则——账上有钱（目标系数非零），机器就一定在某处点火；两个引理分别是「约化不动低次账目」与「低次 + 网格零点 = 恒零」。

## $\rm \S \, 18.3$ 三连应用：Cauchy–Davenport、EGZ、Chevalley–Warning

1. **Cauchy–Davenport 定理**（全证，回收 §17.2）：$A, B \subseteq \mathbb{F}_p$ 非空，$|A| = k$，$|B| = l$，则 $|A + B| \ge \min(p,\, k + l - 1)$。证明分两段。第一段设 $k + l - 1 \le p$，反设 $|A + B| = s \le k + l - 2$，令 $f(x, y) = \prod_{c \in A+B}(x + y - c)$：次数 $s$，且对一切 $a \in A, b \in B$ 有 $f(a, b) = 0$（因为 $a + b \in A + B$，某个因子熄火）。取 $t_1 = k - 1$、$t_2 = s - k + 1$，则 $\deg f = s = t_1 + t_2$，且 $x^{k-1} y^{s-k+1}$ 的系数是 $\binom{s}{k-1}$（挑 $k-1$ 个因子出 $x$、$s-k+1$ 个出 $y$、其余出常数，$\binom{s}{k-1}\binom{s-k+1}{s-k+1} = \binom{s}{k-1}$）；由 $s \le p - 1 < p$ 与 Lucas 定理（$s$ 的 $p$ 进制只有一位），$\binom{s}{k-1} \not\equiv 0 \pmod p$。CN 的网格取 $A \times B$：$|A| = k > t_1$，$|B| = l > t_2$（末条即 $s \le k + l - 2$），于是 CN 断言存在 $(a, b) \in A \times B$ 使 $f(a, b) \ne 0$——与上一行矛盾。第二段 $k + l - 1 > p$：取 $B' \subseteq B$、$|B'| = p - k + 1$，对 $A + B'$ 用第一段得 $|A + B| \ge |A + B'| \ge p$。$\blacksquare$
2. **读法**：§17.2 的平移链靠整数的**序**排队，$\mathbb{F}_p$ 没有序（这正是 §17.9 第 6 问留下的缺口）；CN 重证把序换成了**系数的账本**——$\binom{s}{k-1}$ 数的是「$k-1$ 个因子交出 $x$」的组合多重性，模 $p$ 下它非零。同一个地板 $k + l - 1$，两套地基。
3. **Erdős–Ginzburg–Ziv 定理**（陈述级）：任意 $2n - 1$ 个整数中必存在 $n$ 个其和被 $n$ 整除。原始证明 Erdős–Ginzburg–Ziv 1961；Alon 1999 用 CN 给出现代证明；Kemnitz 猜想（$4n - 3$ 个整数含 $n$ 个和被 $n$ 整除）由 Reiher 2003 用 Chevalley–Warning 方法证明。完整推导超出本章范围。
4. **单项式求和引理**（全证，Chevalley–Warning 的引擎）：对 $j \ge 0$，
$$
\sum_{x \in \mathbb{F}_q} x^j \ = \ \begin{cases} 0 & j = 0 \ \text{（共 } q \text{ 项，} q \equiv 0 \pmod p\text{）} \\ 0 & 0 < j < q - 1 \ \text{（} \mathbb{F}_q^{\times} \text{ 循环，几何级数求和）} \\ -1 & j > 0 \text{ 且 } (q-1) \mid j \ \text{（非零元的 } x^j \text{ 全为 1）} \end{cases} \pmod p .
$$
读法：只有「次数是 $q-1$ 的正倍数」的单变量幂和才不熄火；推论是 $\sum_{x \in \mathbb{F}_q^n} x^{\alpha} \equiv 0 \pmod p$，只要某个 $\alpha_i < q - 1$（逐变量分解，那一维的幂和已经为零）。
5. **Chevalley–Warning 定理**（全证）：$\mathbb{F}_q$ 上多项式 $f_1, \ldots, f_r$，$\sum_i \deg f_i < n$，则公共零点个数 $N = \#\{x \in \mathbb{F}_q^n : f_i(x) = 0 \ \forall i\}$ 满足 $N \equiv 0 \pmod p$（$p = \mathrm{char}(\mathbb{F}_q)$）。证明：造消没多项式 $P(x) = \prod_{i=1}^{r}\left(1 - f_i(x)^{q-1}\right)$——由 Fermat 小定理的有限域版，$f_i(x)^{q-1}$ 在 $f_i(x) \ne 0$ 时为 1、$f_i(x) = 0$ 时为 0，所以每个因子是「$f_i$ 在此点熄火」的指示器，$P$ 在公共零点取 1、其余点取 0，故 $N \equiv \sum_x P(x) \pmod p$。而 $\deg P = (q-1)\sum_i \deg f_i < n(q-1)$，于是 $P$ 的每个单项式都有某个变量的次数 $< q-1$，由引理 4 其总和为零；逐单项式加总得 $N \equiv 0$。$\blacksquare$
6. **推论（非平凡零点）**（全证）：若再有 $f_i(0) = 0$ 对一切 $i$（各 $f_i$ 无常数项，原点是公共零点），则 $N \ge 1$ 且 $N$ 是 $p$ 的倍数，故 $N \ge p \ge 2$——除原点外还有别的零点。$\blacksquare$ 白话：方程比变量「便宜」（次数总和小于变量个数）时，有限域上的方程组不可能只有零零散散的解。

小结：CD 换地基（序 → 系数），EGZ 与 Kemnitz 陈述级挂账，Chevalley–Warning 用「消没指示器 + 幂和熄火」把解的个数钉成 $p$ 的倍数。

## $\rm \S \, 18.4$ Schwartz–Zippel 引理：随机化的零点界

1. 白话先行：非零低次多项式很难在随机点上凑巧为零——这一句话就是「多项式恒等检验」（polynomial identity testing，下称 PIT）的全部依据：想验证两个巨型多项式是否恒等，随机抽点代入即可，错判概率有硬保证。
2. **引理（Schwartz–Zippel；DeMillo–Lipton 1978、Schwartz 1980、Zippel 1979）**（全证）：$F$ 任意域，$P \in F[x_1, \ldots, x_n]$ 非零、总次数 $d$，$S \subseteq F$ 有限。则在 $\prod_i S_i$ 的均匀随机点处
$$
\Pr[P = 0] \ \le \ \frac{d}{|S|} .
$$
证明对 $n$ 归纳。$n = 1$：单变量 $d$ 次多项式至多 $d$ 个根。归纳步：按 $x_1$ 的次数展开 $P = \sum_{i=0}^{k} x_1^i P_i(x_2, \ldots, x_n)$，$P_k \ne 0$、$\deg P_k \le d - k$。先抽其余坐标：若 $P_k \ne 0$ 在该点，则 $P$ 作为 $x_1$ 的次数 $\le k$ 的多项式至多 $k$ 个根，条件概率 $\le k/|S|$；若 $P_k = 0$ 在该点，由归纳假设（$P_k$ 非零、次数 $\le d-k$）这一事件的概率 $\le (d-k)/|S|$。两类相加得 $d/|S|$。$\blacksquare$
3. **取等与用途**：界精确取到——单变量多项式在 $S$ 里配 $d$ 个根时零点概率恰为 $d/|S|$。应用：PIT（检测 $f - g$ 是否非零多项式，随机点代入，错判率 $\le d/|S|$）；图论侧的经典用法是 Tutte 矩阵：把图的邻接阵换成带随机方向的符号矩阵，行列式非零 $\Leftrightarrow$ 存在完美匹配（Edmonds/Tutte，随机化匹配算法即 Schwartz–Zippel 直接落地，出处 Lovász 1979 综述）。
4. **数值锚**（真算：$d/|S|$ 的失败概率）：

| 次数 $d$ | $|S| = 101$ | $|S| = 10^9 + 7$ | $|S| = 2^{61} - 1$ |
| --- | --- | --- | --- |
| 2 | $0.0198$ | $2.0 \times 10^{-9}$ | $8.67 \times 10^{-19}$ |
| 3 | $0.0297$ | $3.0 \times 10^{-9}$ | $1.3 \times 10^{-18}$ |

读法：素数 $2^{61} - 1$（竞赛与工程常用的 Mersenne 素数模）下，三次多项式的一次随机检验错判率已是 $10^{-18}$ 量级——随机化把「恒等」从证明问题变成抽样问题。

小结：Schwartz–Zippel 给「非零多项式不容易熄火」定价 $d/|S|$；它是 PIT 与随机化代数算法的公共地基。

## $\rm \S \, 18.5$ cap set：Croot–Lev–Pach 划分与 Ellenberg–Gijswijt 风暴

1. **问题与欠债**：$\mathbb{F}_3^n$ 中不含非平凡三项等差的集合称 cap set（$x, z \in A$、$x \ne z$ 时 $x + z = 2y$ 的中点 $y \notin A$；在 $\mathbb{F}_3$ 里 $2y = -y$，条件即 $x + y + z = 0$）。记最大尺寸 $r_3(\mathbb{F}_3^n)$，§17.6 承诺 $r_3 \le 2.7551^n$，现在还债。
2. **舞台事实（函数 = 多项式）**：$\mathbb{F}_3^n$ 上每个函数由唯一的多项式 $\prod_i x_i^{e_i}$（各 $e_i \in \{0, 1, 2\}$）表示——这类单项式共 $3^n$ 个，函数空间维数也是 $3^n$（函数由 $3^n$ 个值决定），故构成基。定义 $M_{n, \le t}$ 为总次数 $\le t$ 的此类单项式张成的空间，则维数账一步算清：
$$
\dim M_{n, \le t} \ = \ \#\{e \in \{0,1,2\}^n : |e| \le t\} \ = \ \sum_{j \le t} [x^j]\,(1 + x + x^2)^n ,
$$
读法：每个变量独立贡献次数 ${0,1,2}$，母函数逐变量相乘。
3. **切片秩**（白话先行：把三元函数拆成「一个变量单独拎出来」的项，最少要几项）。函数 $T: A \times A \times A \to \mathbb{F}_3$ 的切片秩（slice rank）是使 $T = \sum_{i=1}^m F_i(\text{另两块}) \cdot G_i(\text{单块})$ 的最小 $m$。
4. **引理 18.5.1（收缩引理）**（全证）：若 $T$ 是 $m$ 个切片项之和，则对任意 $h: A \to \mathbb{F}_3$，矩阵 $N_h(x, y) = \sum_{z \in A} h(z)\, T(x, y, z)$ 的秩 $\le m$。证明：对单个切片项 $F(u)G(v)$ 沿 $z$ 收缩，三种拎法逐一验：拎出 $z$ 得 $F(x,y)$ 乘常数（秩 $\le 1$）；拎出 $x$ 得 $G(x) \cdot \sum_z h(z)F(y,z)$——外积（秩 $\le 1$）；拎出 $y$ 同理。秩的次可加性给出 $\mathrm{rank}\, N_h \le m$。$\blacksquare$
5. **引理 18.5.2（对角张量的切片秩）**（全证）：$D(x, y, z) = [x = y = z]$ 在 $A^3$ 上的切片秩恰为 $|A|$。上界：$D = \sum_{a \in A} [x{=}a][y{=}a][z{=}a]$，每项切片秩 1。下界：取 $h \equiv 1$，$N_1(x, y) = \sum_z D(x,y,z) = [x = y]$ 是 $|A| \times |A|$ 恒等矩阵，秩 $|A|$；若 $D$ 有 $m$ 项切片分解，引理 18.5.1 强迫 $|A| \le m$。$\blacksquare$
6. **消没多项式与 CLP 划分**：造
$$
P(x, y, z) \ = \ \prod_{i=1}^{n} \left( 1 - (x_i + y_i + z_i)^2 \right) ,
$$
总次数 ${2n}$。在 $\mathbb{F}_3$ 上 $u^2 = 0$ 当且仅当 $u = 0$，故每个因子是「$x_i + y_i + z_i = 0$」的指示器：$P$ 在平面 $x + y + z = 0$ 上取 1、平面外全部熄火。cap 性质说：$x, y, z \in A$ 且 $x + y + z = 0$ 必 $x = y = z$，所以 $P$ 限制到 $A^3$ 上就是对角张量 $D$。再看次数预算：$P$ 的每个单项式 $x^a y^b z^c$ 满足 $|a| + |b| + |c| \le {2n}$，三块平摊必有一块 $\le \lfloor 2n/3 \rfloor$——按哪块最小把单项式分进 $P_x, P_y, P_z$（这就是 Croot–Lev–Pach 的划分），而 $P_x$ 展开成 $\sum_{|a| \le \lfloor 2n/3 \rfloor} x^a \cdot H_a(y, z)$，切片项至多 $\dim M_{n, \le \lfloor 2n/3 \rfloor}$ 个，于是
$$
\mathrm{srank}(P) \ \le \ 3 \cdot \dim M_{n, \le \lfloor 2n/3 \rfloor} .
$$
7. **定理（Ellenberg–Gijswijt 2016）**（全证组装）：cap set $A \subseteq \mathbb{F}_3^n$ 满足
$$
|A| \ = \ \mathrm{srank}(D) \ \le \ \mathrm{srank}\left(P\big|_{A^3}\right) \ \le \ \mathrm{srank}(P) \ \le \ 3 \cdot \dim M_{n, \le \lfloor 2n/3 \rfloor} .
$$
第一步是引理 18.5.2，中间是「限制只会降切片秩」，最后是划分引理。$\blacksquare$ 历史：Croot–Lev–Pach（arXiv:1604.08623）先在模 4 群 $(\mathbb{Z}/4\mathbb{Z})^n$ 上做成——那不是域，道具更钝；Ellenberg–Gijswijt 一周内把同样的划分搬到 $\mathbb{F}_3^n$；Tao 随后用切片秩把证明重述成上面的形状。
8. **维数账逐步算（Stieltjes 式动量技巧）**。记 $m_{n,j} = [x^j](1+x+x^2)^n$，$J = \lfloor 2n/3 \rfloor$。系数 $m_{n,j}$ 单峰、关于 $j = n$ 镜像对称——与 $(1+x)^{2n}$ 的中心系数 $\binom{2n}{n} \sim 4^n/\sqrt{\pi n}$ 同一性质：质量集中在峰附近宽度 $\sqrt{n}$ 的带子里，而切片点 $J$ 距峰 $n/3$，远在几何衰减区。逐项界：对任意 $t \in (0, 1)$，$\sum_j m_{n,j} t^j = (1+t+t^2)^n$（把测度 $\mu = \sum_j m_{n,j}\delta_j$ 的 Stieltjes 变换读出来），单项 $m_{n,j} t^j$ 不超过总和，故 $m_{n,j} \le t^{-j}(1+t+t^2)^n$；部分和用几何级数收口：
$$
\dim M_{n, \le J} \ = \ \sum_{j \le J} m_{n,j} \ \le \ (1+t+t^2)^n \sum_{j \le J} t^{-j} \ \le \ \frac{(1+t+t^2)^n}{(1-t)\, t^{2n/3}} \ = \ \frac{c(t)^n}{1-t},
$$
其中 $c(t) = \frac{1+t+t^2}{t^{2/3}}$（用 $J \le 2n/3$ 与 $t < 1$）。极小化：$\frac{d}{dt}\left[(1+t+t^2)t^{-2/3}\right] = 0$ 化为 $4t^2 + t - 2 = 0$，得 $t^* = \frac{\sqrt{33}-1}{8} \approx 0.59307$，此时
$$
c \ = \ c(t^*) \ = \ \frac{3(15+\sqrt{33})}{8(\sqrt{33}-1)^{2/3}} \ = \ 2.7551046130236 \quad (\text{真算}) .
$$
组装：$|A| \le \frac{3}{1 - t^*} \cdot c^n = 7.373 \cdot 2.7551^n$。要把常数吸进底数，用 EG 原文的头条数字 $2.756$：$(2.756/2.7551)^n \ge 7.373$ 需 $n \ge 6149$（真算）；更干净的表述是「对任意 $\varepsilon > 0$，$|A| \le C_\varepsilon (2.7551 + \varepsilon)^n$」。§17.6 引用的 $2.7551$ 即此；高精度常数 $2.7551046130236\ldots$ 见 Tao 博客 2016 年 cap set 帖讨论区（署名 NPY）与后续文献通行引用。
9. **数值锚**（真算）：

| $n$ | $3^n$ | $\dim M_{n,\le \lfloor 2n/3 \rfloor}$ | $3 \cdot \dim$ | $2.7551^n$ |
| --- | --- | --- | --- | --- |
| 6 | 729 | 168 | 504 | 437.3 |
| 9 | 19683 | 3061 | 9183 | 9146.1 |
| 12 | 531441 | 57720 | 173160 | 191270.7 |

读法一：$n = 9$ 起 $3 \cdot \dim$ 已被 $2.7551^n$ 追平反超，指数底数从 3 砍到 2.7551 在肉眼可见的尺度兑现。读法二：有限 $n$ 的精确定理 $|A| \le 3\dim$ 在 $n = 6$ 给 $504$，而组合搜索确证的精确值是 $r_3(\mathbb{F}_3^6) = 112$（见 Potechin 2007 一类的搜索文献）——上界松但指数级正确。看一眼单峰与衰减（$n = 12$，真算）：
$$
(1+x+x^2)^{12} = 1 + 12x + 78x^2 + 352x^3 + 1221x^4 + 3432x^5 + 8074x^6 + 16236x^7 + 28314x^8 + 43252x^9 + 58278x^{10} + 69576x^{11} + 73789x^{12} + \cdots
$$
系数在 $j = 12$ 处登顶 $73789$ 后镜像回落；相邻比值 $m_{n,j-1}/m_{n,j}$ 从 $0.083$ 单调爬到 $0.943$——峰左侧是稳定的几何衰减区，切片点 $J = 8$ 站在衰减带里，这正是第 8 条逐项界有效的形象原因。

小结：消没多项式在禁止点全部熄火、把 $P$ 压成对角张量；CLP 划分把次数预算三等分；维数账用单峰性与动量技巧把 $\dim M$ 钉在 $2.7551^n$——§17.6 的债连本带息还清。

## $\rm \S \, 18.6$ Finite field Kakeya：Dvir 的一击

1. **问题**：$K \subseteq \mathbb{F}_q^n$ 称 Kakeya 集，若每个方向 $u \ne 0$ 都有一条整线 $\{a + tu : t \in \mathbb{F}_q\}$ 躺在 $K$ 里。Wolff 1999 年问：$|K|$ 能多小？Dvir 2009（J. AMS）一击定音：$|K| \ge \binom{n+q-1}{n} \ge \frac{q^n}{n!}$——有限域里「处处含线」的集合必须占常比例的地盘。
2. **全证**。反着设 $|K|$ 小。1. 取 $d_0$ = 使 $\binom{n+d_0}{n} > |K|$ 的最小整数；「未知数多于方程」：次数 $\le d_0$ 的单项式有 $\binom{n+d_0}{n}$ 个，$|K|$ 个消没条件压不满，故存在非零 $P$、$\deg P \le d_0$、$P\big|_K = 0$。2. 若 $d_0 \ge q$，则最小性给 $|K| \ge \binom{n+d_0-1}{n} \ge \binom{n+q-1}{n}$，直接收工。3. 于是只剩 $d_0 \le q - 1$ 的情形，要造矛盾。先保证 $\deg P = d_0$ 恰确：次数 $\le d_0 - 1$ 且消没的多项式至多 $\binom{n+d_0-1}{n} - 1$ 个线性无关（$K$ 非空，消没条件至少吃掉一维），而由最小性 $\binom{n+d_0-1}{n} \le |K| < \binom{n+d_0}{n}$，故「次数 $\le d_0$ 且消没」的空间里必有次数恰 $d_0$ 的成员；取之，记其首齐次部分为 $P_{d_0} \ne 0$。4. 每个方向 $u \ne 0$ 有整线 $\{a + tu\} \subseteq K$；单变量 $g(t) = P(a + tu)$ 次数 $\le d_0 \le q-1 < q$ 却在全部 $q$ 个 $t$ 处为零，故 $g \equiv 0$，于是 $t^{d_0}$ 的系数 $P_{d_0}(u) = 0$ 对每个方向成立（连同 $u = 0$）。5. 首齐次部分处处零：$P_{d_0}$ 总次数 $d_0 \le q-1$，各单项式的指数每维 $\le q-1$，而「指数各 $\le q-1$」的 $q^n$ 个单项式是函数空间的基（张成：任何多项式作函数等于其模 $\prod_i (x_i^q - x_i)$ 的余项；个数恰 $q^n$ = 函数空间维数），基中成员作为函数恒零只能恒为零多项式——与 $P_{d_0} \ne 0$ 矛盾。三种情形合并：恒有 $|K| \ge \binom{n+q-1}{n}$，末不等号由 $\prod_{i=1}^n \frac{q+i-1}{i} \ge \frac{q^n}{n!}$。$\blacksquare$
3. **后续**：Dvir–Kopparty–Saraf–Sudan（2009）用重数技巧把常数从 $1/n!$ 提到 $2^{-n}$ 量级；固定 $n$、$q \to \infty$ 的最优常数问题超出本章范围。
4. **数值锚**（真算，$q = 7$）：

| $n$ | $\binom{n+q-1}{n}$ | $q^n$ | 比值 |
| --- | --- | --- | --- |
| 2 | 28 | 49 | 0.571 |
| 3 | 84 | 343 | 0.245 |
| 4 | 210 | 2401 | 0.088 |

读法：$1/n!$ 型常数在低维就已经把「测度为零」的直觉定量兑现——Kakeya 集吃不掉整个空间，但一块正比例的地盘是赖不掉的。
5. **与 Graham–Pollak 的对照（§14.4）**：同一哲学两代技术。Graham–Pollak 里 $J - I$ 的秩 $n - 1$ 是任何二部分解的代数成本；Dvir 里消没多项式的次数 $d_0$ 是任何 Kakeya 集的基因——「代数对象的不变量压住组合对象」没有变。升级点有二：天花板从环境维数换成「次数预算换算的维数」$\binom{n+d}{n}$；信息集中在首项（$J - I$ 的负定部分、$P_{d_0}$ 的方向值）——**首项承载组合，低次项只是陪跑**，这与 cap set 里对角张量独占切片秩是同一种不对称。

小结：Dvir 的证明是本章方法的纯展示——欠定造多项式、方向限制烧首项、基独立性收尾；它与 Graham–Pollak 一起把「代数天花板」这条线从第 14 章一路焊到全书终点。

## $\rm \S \, 18.7$ 关键概念回顾

1. 多项式方法纲领：编码对象为点、禁令为消没多项式、低次函数空间维数当天花板；次数旋钮压低天花板。（§18.1）
2. Combinatorial Nullstellensatz 全证：约化保系数（引理 18.2.1）+ 低次网格零点恒零（引理 18.2.2）+ 反证收尾；去次数条件仍真。（§18.2）
3. 三应用：Cauchy–Davenport 全证（$\binom{s}{k-1} \not\equiv 0$ 补上无序地基，回收 §17.2）；EGZ、Kemnitz–Reiher 陈述级挂账；Chevalley–Warning 全证（幂和引理 + $P = \prod(1 - f_i^{q-1})$ 计数，$N \equiv 0 \pmod p$）。（§18.3）
4. Schwartz–Zippel 全证（首项分解归纳）：$\Pr[P = 0] \le d/|S|$，界精确；PIT 与 Tutte 矩阵匹配算法。（§18.4）
5. cap set：函数 = 多项式（指数 $\le 2$ 的基）、$M_{n,\le t}$ 维数账、切片秩、收缩引理、对角张量、CLP 划分、$|A| \le 3\dim M_{n,\le \lfloor 2n/3 \rfloor} \le 7.37 \cdot 2.7551^n$，$c = 2.7551046130236$、$t^* = (\sqrt{33}-1)/8$。（§18.5）

## $\rm \S \, 18.8$ 应用与辨析

1. CN 证明的约化步骤里，$q \cdot g_i$ 的每个单项式 $x_i$ 次数至少是多少？这如何保证目标单项式的系数在约化中不动？
2. Cauchy–Davenport 的证明里 $\binom{s}{k-1} \not\equiv 0 \pmod p$ 用了 $s \le p-1$。如果把消没多项式换成对 $A+B$ 的补集做乘积（第一反应的「反向」构造），哪里会坏？
3. Chevalley–Warning 中 $\deg P < n(q-1)$ 用在哪一步？若 $\sum_i \deg f_i = n$（临界情形），论证在哪里断裂？找一个 $f$ 说明 $N \equiv 0 \pmod p$ 可以不成立。
4. Schwartz–Zippel 的证明为什么要按 $x_1$ 的**最高次**系数 $P_k$ 分情况？若按最低次分，归纳的天花板会变成什么？
5. cap set 证明中 $2n/3$ 从哪里来？为什么不能直接用二变量的恒等矩阵 $[x = y] = \prod_i(1 - (x_i - y_i)^2)$（次数 ${2n}$，切在 $n$）走同样的流程？
6. Dvir 证明为何必须讨论 $d_0 \ge q$ 的情形？若跳过它，第 5 步的「基独立性」论证在哪里失效？

### $\rm \S \, 18.9.2$ 应用与辨析答案

1. 至少 $|S_i| = t_i + 1$（$g_i$ 的次数下限经 $q$ 传导）。目标单项式 $x_i$ 次数 $\le t_i < t_i + 1$，与 $q \cdot g_i$ 的单项式（次数 $\ge t_i + 1$）在全单射格点上不相交，故系数互不干扰。（§18.2）
2. 对补集 $C$ 做乘积 $f = \prod_{c \in C}(x + y - c)$ 时 $f$ 在 $A \times B$ 上**恒不为零**而非恒为零（$a + b \notin C$），CN 的「非零点存在」不再是矛盾；要让 CN 出手，必须先有「网格上全熄火」，所以乘积要罩住 $A + B$ 本身。（§18.3）
3. 用在「每个单项式必有某变量次数 $< q-1$」：$\deg P = (q-1)\sum \deg f_i = n(q-1)$ 时单项式可以每维次数都 $\ge q-1$（例如全由 $x_i^{q-1}$ 撑起），幂和不再熄火。临界反例：$n = 1$、$f = x^{q-1}$，$\deg f = 1 = n$，公共零点个数 $N = 1 \not\equiv 0 \pmod p$。（§18.3）
4. 分情况的对象决定「另一侧」的归纳预算：按最高次 $P_k$ 分，失败分支的 $P_k$ 次数 $\le d - k$，与成功分支的 $k/|S|$ 拼成 $d/|S|$。若按最低次分，成功分支的天花板是 $k/|S|$（$k$ 为最低次），另一侧 $P$ 除以 $x_1^k$ 后次数仍是 $d - k$ 但结论要对「最高次系数非零」才能归纳——链条接不上。（§18.4）
5. $2n/3$ 来自「三块平摊总预算 ${2n}$」：三元结构 $(x, y, z)$ 每个单项式必有一块次数 $\le 2n/3$。二变量恒等矩阵次数 ${2n}$ 只能两块平摊到 $n$，而 $n$ 恰是 $(1+x+x^2)^n$ 系数的峰心，$\dim M_{n, \le n}$ 是总质量的大半——天花板高得毫无用处；cap 的三元等差结构正是让「三分之一」切在衰减带的原因。（§18.5）
6. $d_0 \ge q$ 时首齐次部分次数 $\ge q$，「指数各 $\le q-1$ 的单项式是函数空间的基」不再适用（$P_{d_0}$ 的单项式可能溢出基的范围），第 5 步失效。此时根本不需要多项式论证：最小性直接给 $|K| \ge \binom{n+q-1}{n}$——情形讨论是把「代数论证」用在它合法的次数区间内。（§18.6）
