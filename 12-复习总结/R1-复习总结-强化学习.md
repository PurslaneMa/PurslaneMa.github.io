# R1 复习总结：强化学习

八章压成三句话：**问题的形状与规划**（第 1—2 章）——MDP 五件套、贝尔曼方程与 $\gamma$-压缩，有模型时策略迭代与值迭代都收敛到 $V^*$；**无模型的学习**（第 3—4 章）——MC 无偏高方差、TD 自举低方差，SARSA 与 Q-learning 差一行代码（on-policy vs off-policy）；**规模、策略与探索**（第 5—8 章）——函数逼近需要回放与目标网络两把钥匙（DQN）、策略梯度定理与 PPO 裁剪、bandit 的 regret 账与 UCB、离线 RL 的悲观主义与 RLHF 三段式。验收标准：闭卷清单答出几成、§R1.3 八条心智模型能默几条。

## $\rm \S \, R1.3$ 核心心智模型复读

1. **两个反馈环**：评估环（值依赖策略）与数据环（策略依赖数据）——所有算法的难点都在破环。
2. **自举换方差**：TD 用估计当目标（有偏但低方差），MC 用真实回报（无偏但高方差）。
3. **on/off-policy 一行之差**：SARSA 用实际采取的下一个动作，Q-learning 用 $\max$——差在「信不信自己的探索」。
4. **逼近的三重张力**：函数逼近 + 自举 + off-policy 三者共存不稳定（死亡三角），DQN 的两把钥匙是工程补丁。
5. **策略梯度是加权的模仿**：$\nabla \log \pi \cdot Q$——高回报的动作被强化，靠的是对数导数技巧。
6. **探索的价格是 regret**：次线性 regret 才叫学到东西；UCB 用置信上界把「乐观」变成数学。
7. **离线必须悲观**：没机会验证的错误估值是灾难，所以压低数据外估值。
8. **RLHF = 三段式**：SFT → 奖励模型（BT 极大似然）→ PPO + KL 缰绳。

## $\rm \S \, R1.5$ 易混点对照

1. **$V$ vs $Q$**：$V$ 是状态值、$Q$ 是状态-动作值；无模型控制必须用 $Q$（$V$ 需要知道模型才能选动作）。
2. **预测 vs 控制**：预测评估固定策略、控制找最优策略——第 3 章 vs 第 4 章。
3. **on-policy vs off-policy**：on 学自己正在跑的、off 学别的策略的数据——SARSA vs Q-learning、PPO vs DQN。
4. **策略迭代 vs 值迭代**：前者每轮贵（解方程）轮数少，后者每轮便宜轮数多。
5. **探索 vs 利用**：$T$ 步里 regret 与「试错成本」的关系——$\varepsilon$-衰减是手工妥协、UCB 有理论保证。
6. **模仿 vs 强化**：模仿学动作、强化学回报；RLHF 是「模仿偏好排名」的两者混血。

## $\rm \S \, R1.6$ 答案与提示

### 闭卷回忆清单

1. 数据分布依赖策略、奖励稀疏延迟、需探索；马尔可夫性是建模选择（可以选更大的状态）。 （§1.1—1.2）
2. 利息率/生存概率/数学便利；$V^\pi(s) = \mathrm{E}[\sum \gamma^k r]$。（§1.3）
3. $V^*(s) = \max_a [r + \gamma \sum P V^*]$；$\|TV - TV'\|_\infty \le \gamma \|V - V'\|_\infty$。（§1.4）
4. 评估（解 $V^\pi$）、改进（对 $Q^\pi$ 贪心）、检查是否变化；每轮严格不降且策略有限 ⟹ 终止。（§2.2）
5. Banach 压缩映射定理；$\|V_k - V^*\| \le \frac{\gamma^k}{1-\gamma}\|V_1 - V_0\|$。（§2.3）
6. MC 无偏高方差、TD 有偏低方差；TD 不动点 $V = r + \gamma P V$。（§3.3—3.4）
7. SARSA：$r + \gamma Q(s', a')$；Q-learning：$r + \gamma \max_a Q(s', a)$；前者 on-policy、后者 off-policy。（§4.3—4.4）
8. Q-learning 学最优险路（贴边 13 步）、SARSA 学保守路（爬顶行 17 步）——SARSA 把探索风险计入。（§4.5）
9. 半梯度把目标端当常数；死亡三角＝函数逼近＋自举＋off-policy。（§5.2）
10. 经验回放（打破样本相关性）、目标网络（稳定移动靶）。（§5.3）
11. $\nabla J = \mathrm{E}[\nabla \log \pi(a|s) Q^\pi(s,a)]$；$\nabla \pi = \pi \nabla \log \pi$。（§6.2）
12. $\mathrm{E}[\nabla\log\pi \cdot b(s)] = 0$（因 $\sum_a \nabla \pi = \nabla 1 = 0$）；裁剪把越界的重要性比梯度归零。（§6.3—6.4）
13. Hoeffding 给 $\sqrt{2\ln t/n}$ 的误差棒；记账分「试得不够」与「误差棒没兜住」两块。（§7.3）
14. 数据外的估值无人能纠正，高估不可挽回；SFT（行为克隆）→ RM（BT）→ PPO + KL。（§8.1、§8.4）
