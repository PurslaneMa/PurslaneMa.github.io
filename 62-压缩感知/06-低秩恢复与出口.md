## $\rm \S \, 6.1$ 从稀疏到低秩：核范数与奇异值软阈值

白话：向量世界里「自由度少」= 坐标大多为零，凸代理是 $\ell_1$；矩阵世界里「自由度少」= 秩低，凸代理是核范数——奇异值的绝对值和。连求近端的方式都是同一个：向量对坐标软阈值，矩阵对奇异值软阈值。

把剧本逐句翻译：

| | 稀疏向量（第 1–3 章） | 低秩矩阵（本章） |
| --- | --- | --- |
| 计数型目标 | $\|x\|_0 = \#\{i : x_i \neq 0\}$ | $\mathrm{rank}(X) = \#\{i : \sigma_i > 0\}$ |
| 凸代理 | $\|x\|_1 = \sum_i |x_i|$ | $\|X\|_* = \sum_i \sigma_i$ |
| 近端算子 | 坐标软阈值 | 奇异值软阈值（SVT） |
| 典型模型 | $y = Ax$，$x$ 稀疏 | 观测 $\Omega$，$M$ 低秩 |
| 计数下界 | $s \log(n/s)$ | $r n \,\mathrm{polylog}$ |

读法：核范数 $\|X\|_* = \sum_i \sigma_i(X)$（奇异值之和）不是随手挑的——它是 rank 在谱范数单位球上的**凸包络**（Fazel 2002），正如 $\|x\|_1$ 是 $\|x\|_0$ 在 $\ell_\infty$ 单位球上的凸包络。凸包络的意思：在不撒谎（凸）的前提下最贴近原目标的松弛。SVT 定义为 $\mathrm{SVT}_\tau(X) = U\, \mathrm{diag}(\max(\sigma_i - \tau, 0))\, V^{\mathsf T}$，它是 $\min_Y \tfrac{1}{2}\|Y - X\|_{\mathrm{F}}^2 + \tau \|Y\|_*$ 的解——与软阈值解 $\min_w \tfrac{1}{2}(w - z)^2 + \tau |w|$ 的地位逐字对应。

真算一笔：$X = \mathrm{diag}(3, 1, 0.5)$，对 $\tau = 0.6, 1.2, 1.5$ 做 SVT：奇异值分别变成 $(2.4, 0.4, 0)$、$(1.8, 0, 0)$、$(1.5, 0, 0)$，秩从 3 降到 2、1、1。

读法：软阈值的「减法能减到零」在奇异值上原样重演——$\tau$ 越过某个奇异值，那个方向被整段切掉，秩真实下降。这就是「核范数造低秩」的机关，与「$\ell_1$ 造稀疏」同构：罚的对象（奇异值）被持续征税，小方向最先破产。

低秩 + 稀疏的复合模型是本章的主角：

$$
M = L_0 + S_0
$$

读法：$L_0$ 低秩（系统性的背景结构），$S_0$ 稀疏（少数大而孤立的异常）。监控视频（背景是低秩的重复画面、前景是稀疏的活动）、脸光照建模（人脸集低秩、阴影高光稀疏）、协同过滤（评分低秩 + 恶意评分稀疏）都是这个形状。麻烦在于**两个目标可以互相冒充**：把 $L_0$ 的一个方向挪进 $S_0$（单位矩阵 $e_i e_i^{\mathsf T}$ 既可以是低秩矩阵的一部分、也可以当稀疏项），解就完全不定——可辨识性需要第 5 章那个老朋友：不相干。

**本节小结**：$\mathrm{rank} \to$ 核范数（rank 的凸包络，Fazel 2002）、坐标软阈值 $\to$ SVT（真算 $\tau$ 越过奇异值秩即降）；$M = L_0 + S_0$ 里两者可互相冒充，可辨识性靠不相干。

## $\rm \S \, 6.2$ Robust PCA：定理、算法与失败面

白话：Robust PCA（PCP，principal component pursuit）是把 $M = L_0 + S_0$ 解出来的凸程序：$\min \|L\|_* + \lambda \|S\|_1$。它的定理说：不相干成立时，分解是精确且唯一的；它的算法是 ISTA 的矩阵孪生；它的失败面恰好是「低秩伪装成稀疏」的极端情形。

**定理（Candès–Li–Ma–Wright 2011，《Robust Principal Component Analysis?》）**：设 $L_0$ 秩至多 $r$、不相干（其奇异向量各行能量受 $\mu r / n$ 控制），$S_0$ 的支撑按任意分布稀疏采样、非零元幅度足够大，且支撑与 $L_0$ 的不相干结构不重合。取 $\lambda = 1/\sqrt{\max(n_1, n_2)}$，则当 $r$ 与支撑密度都小于常数阈值时，$(L_0, S_0)$ 是凸问题

$$
\min_{L, S} \; \|L\|_* + \lambda \|S\|_1 \quad \text{s.t.} \quad L + S = M
$$

的唯一最优解，且以压倒性概率精确恢复。读法：结构与第 2 章 RIP 定理同型——一个「随机性 + 不相干」条件换一个精确恢复结论；常数阈值量级是 $r \lesssim \rho_r n / \mu \log^2 n$、支撑密度 $\lesssim \rho_s$（原文精确常数见 JACM 2011 论文）。$\lambda = 1/\sqrt{\max(n_1, n_2)}$ 是平衡两项量纲的默认值，两类误差权重不同时再调。

求解用**不等式增广拉格朗日**（IALM，Lin–Chen–Ma–Liu 2010）：对增广拉格朗日量交替做两步近端——$L$ 步是一个 SVT（对 $M - S + Y/\mu$），$S$ 步是一个坐标软阈值（对 $M - L + Y/\mu$，门限 $\lambda/\mu$），再更新乘子 $Y$ 与罚参数 $\mu$。第 3 章的「梯度步 + 软阈值」原样放大成「SVT + 软阈值」。

真算一笔（本章程序段可复现）：$n = 100$，$L_0 = 10 \cdot U V^{\mathsf T}$（${U, V}$ 为 $100 \times 5$ 高斯列，$\|L_0\|_{\max} = 1.33$），$S_0$ 随机 $5\%$ 条目取 $\pm[5, 15]$（$\|S_0\|_{\mathrm{F}} = 234$，信号比 $L_0$ 大一个量级），$M = L_0 + S_0$。IALM（600 轮、$\mu$ 衰减 0.98）输出：

$$
\frac{\|\hat L - L_0\|_{\mathrm{F}}}{\|L_0\|_{\mathrm{F}}} = 3.0 \times 10^{-4}, \qquad \frac{\|\hat S - S_0\|_{\mathrm{F}}}{\|S_0\|_{\mathrm{F}}} = 1.9 \times 10^{-5}, \qquad \mathrm{rank}(\hat L) = 5
$$

读法：异常项比背景大十倍也没关系——幅度大恰恰是 $S_0$ 的特征，分解抓的是「低秩性」与「稀疏性」这两个结构差异，不是大小。$\hat L$ 的秩精确回到 5；支撑判决只有 20 个坐标出入（500 个异常条目里 $4\%$ 的边缘判决，多集中在幅度最小的异常上）。

失败面演示（不相干不可省）：把第 5 章的补全实验退化到极端——$n = 8$、秩 2 的随机低秩矩阵，只观测它的**对角线**。核范数近端迭代收敛后：相对误差 $0.87$（基本没补对）、解满秩（秩 8）；同时 $\mathrm{diag}(\hat X)$ 与观测吻合到 $10^{-3}$——求解器把「低秩」违约得干干净净也要服从「对角线吻合」的硬约束，因为对角线之外的自由度它没有任何信息，而满秩解的核范数已经做到最小。这就是 Shapiro（1985）指出的核范数松弛可能不紧致的具体形态：某些约束下核范数最优解不是秩最优解。工程结论：**观测结构必须与低秩结构正交地混在一起**——矩阵补全要随机条目，Robust PCA 要稀疏支撑不与奇异向量重合，违反则失败不在算法端、在问题端。

核范数最小化是**半定规划**（SDP）：$\|X\|_* \le t$ 等价于存在分块 $P, Q \succeq 0$ 使 $\begin{pmatrix} P & X \\ X^{\mathsf T} & Q \end{pmatrix} \succeq 0$、$\mathrm{tr}(P) + \mathrm{tr}(Q) \le 2t$——半正定约束是 LP 的谱升级（谱域里「非负」换成「半正定」），求解器从单纯形换成内点法。规模大时 SDP 不现实，实践走 IALM/SVT 这类一阶近端迭代（每次一个部分 SVD），这正是第 3 章「凸问题 + 近端迭代」配方在谱域的重演。

**本节小结**：PCP 定理（不相干 + 随机稀疏支撑 → 精确分解，$\lambda = 1/\sqrt{\max(n_1,n_2)}$）；IALM = SVT + 软阈值的交替；真算 $n = 100$：两项误差 $10^{-4} \sim 10^{-5}$、秩精确为 5；失败面真算——只看对角线时核范数解满秩、误差 0.87（Shapiro 型不紧致），不相干是硬前提；核范数最小化是 SDP，规模大走近端迭代。

## $\rm \S \, 6.3$ 稀疏正则在深度学习中的回响

白话：深度网络默认不做任何「造零」的事——weight decay 是 $\ell_2$，只缩小不归零。但全册机关（尖角造精确零、结构先验换测量数）在深度学习里到处找得到回声：显式的 $\ell_1$ 与剪枝、隐式的梯度稀疏化、以及把 ISTA 直接展开成网络。

真算一笔（第 1 章 §1.4 单坐标推导的矩阵版）：$d = 50$、$100$ 个样本，真权重 5-稀疏（系数 $3 \times N(0,1)$，最小 $|\cdot| = 0.52$），观测带 $0.1$ 高斯噪声。$\lambda = 0.1$ 时：Lasso（近端梯度）保留 5 个非零、支撑与真支撑完全一致、相对误差 $0.026$；同 $\lambda$ 的岭回归保留全部 50 个非零、相对误差 $0.188$。

读法：两层对照。统计上 Lasso 同时赢了预测与解释（5 个非零 vs 50 个）——稀疏解的可解释性不是免费的甜点，是 $\ell_1$ 尖角的直接产物（第 1 章：减法能到零，除法不能）。深度学习里 weight decay 对应的是右边的岭：AdamW 的 decay 只把权重按比例缩小、永不归零，所以**训练出来的网络天然不稀疏**，稀疏要靠额外的机制去造。

显式机制：剪枝（pruning）。训练后按 $|w|$ 幅度把小权重置零（幅度剪枝），再微调——「训练 + 剪枝 + 微调」的循环本质是硬阈值迭代（第 1 章自测题里 $\ell_0$ 惩罚的最优解就是硬阈值），彩票假设（Frankle–Carbin 2019）进一步发现剪掉 $90\%$ 权重后的子网络重新初始化训练能追平原网络——「网络里有小稀疏核」与「信号有小稀疏支撑」是同一种信仰。结构化剪枝（整通道、整块）对应 §5.4 的块稀疏：非结构化剪枝省参数不省算力，块结构才省——先验的粒度又一次决定收益的粒度。

隐式机制与展开：梯度下降本身在某些过参数化设定下会把解往低复杂度方向推（隐式正则化，[深度学习理论册第 2 章](../60-深度学习理论/02-损失景观.md)的景观语言）；更直接的回声是**把 ISTA 展开成网络**（LISTA，Gregor–LeCun 2010）：把软阈值迭代的每一步当一层、步长与门限当可学参数，几十倍少于 ISTA 的迭代次数达到同精度——压缩感知的算法结构直接变成了网络架构，MRI 重建的变分网络是同一思想在应用端的样子（第 5 章）。读法：这一条把全册的立场说透了——**经典算法是架构的先验**；网络不是替代凸松弛，是把松弛的迭代学得更省。

**本节小结**：weight decay 是岭（只缩不零），稀疏要靠显式 $\ell_1$/剪枝（硬阈值循环、彩票假设）或隐式机制；LISTA 把 ISTA 展开成网络——经典算法是架构的先验；真算：Lasso 5 非零误差 0.026 对岭 50 非零误差 0.188。

## $\rm \S \, 6.7$ 本章自测答案

> 先闭卷作答上面两节，再核对。

### $\rm \S \, 6.7.1$ 关键概念回顾答案

1. rank 在谱范数单位球上的凸包络是核范数（Fazel 2002）——凸且最贴原目标的松弛，正如 $\|x\|_1$ 对 $\|x\|_0$。SVT 是 $\min_Y \tfrac12\|Y - X\|_{\mathrm{F}}^2 + \tau\|Y\|_*$ 的解：对奇异值做减法归零，坐标软阈值对系数做减法归零——近端算子在谱域与坐标域的同构。（§6.1）
2. 条件：$L_0$ 不相干（奇异向量行能量受控）、$S_0$ 支撑稀疏且与 $L_0$ 结构不重合、$r$ 与支撑密度低于常数阈值。$\lambda = 1/\sqrt{\max(n_1,n_2)}$ 平衡核范数与 $\ell_1$ 的量纲（两项在随机矩阵下的典型尺度之比）。IALM 三步：$L$ 步 SVT、$S$ 步软阈值、$Y \leftarrow Y + \mu(M - L - S)$ 加 $\mu$ 衰减。（§6.2）
3. 说明观测结构必须与低秩结构混合：只看对角线时，核范数最小化的解是满秩的（真算：秩 8、相对误差 0.87、对角吻合 $10^{-3}$）——约束之外无信息，松弛解不紧致（Shapiro 1985 的具体形态）。这正是第 5 章不相干条件的反面：随机条目观测让信息与低秩结构正交交错，松弛才紧。（§6.2、§5.3）

### $\rm \S \, 6.7.2$ 应用与辨析答案

1. 缓慢光照变化：整帧亮度/对比度漂移对所有列几乎相同，可并入低秩（秩略升），PCP 仍稳；但快速频闪会给 $L_0$ 添高秩成分，把背景挤进 $S_0$（满屏假前景）。大面积遮挡：$S_0$ 的支撑密度超过常数阈值，定理前提破坏，遮挡块会被当成「背景的一部分」吸收进 $L_0$（低秩解释强于稀疏解释时）。两个失效方向分别是「低秩不够低」与「稀疏不够稀」——都回到前提而非算法。（§6.2）
2. 误差 $0.026$ 的来源：$\lambda = 0.1$ 的偏置（幸存系数被拉回 $\lambda/L$ 量级）加 $\lambda$ 量级的泄漏。调小 $\lambda$：偏差与泄漏都按比例缩小、支撑可能先保持后收缩，代价是迭代数上涨（第 3 章：$\lambda = 10^{-4}$ 要 $10^5$ 轮）。与 ISTA 泄漏是同一件事：Lasso 的解随 $\lambda \to 0$ 收敛到 BP 解，泄漏是 $\lambda$ 的一阶产物——真算里 $\|x^* - x_0\|_2$ 与 $\lambda$ 成正比就是这条线。（§6.3、§3.3）
3. 精确化：LISTA 学的是 ISTA 迭代的**展开结构**（软阈值算子不变），省的是迭代次数——用网络容量换收敛（几十层网络达到 ISTA 上千次迭代），前提是有训练数据覆盖信号的分布。失去的是：对分布外信号的保证（ISTA 的收敛与恢复定理对一切 $y$ 成立，LISTA 只在训练分布内可信）。所以「过时」不成立——凸方法给保证与兜底，展开网络给分布内的速度，工程上常串联使用（LISTA 热启动 + 少量精确迭代）。（§6.3）

## $\rm \S \, 6.8$ 可当场复跑的程序段

下面这段 Python（只需 NumPy）实跑 §6.1 的 SVT 演示、§6.2 的 RPCA 与对角失败演示、§6.3 的 Lasso–岭对照。

```python
 # SVT / Robust PCA (IALM) / 对角补全失败 / Lasso vs 岭
import numpy as np

rng = np.random.default_rng(20261105)

# SVT：奇异值软阈值让秩下降
sv = np.array([3.0, 1.0, 0.5])
for tau in (0.6, 1.2, 1.5):
    sv2 = np.maximum(sv - tau, 0)
    print(f"tau={tau}: sv={sv2}, rank={int((sv2 > 0).sum())}")

# Robust PCA：IALM
def rpca(M, iters=600, decay=0.98):
    mu = 1.25 / np.linalg.norm(M, 2)
    lam = 1.0 / np.sqrt(max(M.shape))
    S = np.zeros_like(M)
    Y = M / max(np.linalg.norm(M, 2), np.abs(M).max())
    for _ in range(iters):
        U, s, Vt = np.linalg.svd(M - S + Y / mu, full_matrices=False)
        L = (U * np.maximum(s - 1 / mu, 0)) @ Vt
        T = M - L + Y / mu
        S = np.sign(T) * np.maximum(np.abs(T) - lam / mu, 0)
        Y = Y + mu * (M - L - S)
        mu *= decay
    return L, S

n, r = 100, 5
U0 = rng.standard_normal((n, r)) / np.sqrt(n)
V0 = rng.standard_normal((n, r)) / np.sqrt(n)
L0 = U0 @ V0.T * 10
S0 = np.zeros((n, n))
idx = rng.choice(n * n, size=n * n // 20, replace=False)
S0.flat[idx] = rng.choice((-1.0, 1.0), size=len(idx)) * rng.uniform(5, 15, len(idx))
L, S = rpca(L0 + S0)
print(f"RPCA relL={np.linalg.norm(L - L0) / np.linalg.norm(L0):.1e} "
      f"relS={np.linalg.norm(S - S0) / np.linalg.norm(S0):.1e} "
      f"rank={np.linalg.matrix_rank(L, tol=1e-6)}")

# 只观测对角线：核范数补全失败
n2, r2 = 8, 2
M2 = rng.standard_normal((n2, r2)) @ rng.standard_normal((r2, n2))
nrm = np.linalg.norm(M2)
Om = np.eye(n2, dtype=bool)
X = np.zeros_like(M2)
for _ in range(3000):
    G = X - np.where(Om, X - M2, 0.0)
    U, s, Vt = np.linalg.svd(G, full_matrices=False)
    X = (U * np.maximum(s - 1e-3, 0)) @ Vt
print(f"diag-only: rel={np.linalg.norm(X - M2) / nrm:.2f}, "
      f"rank={np.linalg.matrix_rank(X, tol=1e-6)}, "
      f"diag ok={np.abs(np.diag(X) - np.diag(M2)).max():.0e}")

# Lasso vs 岭
d, ns, lam = 50, 100, 0.1
w = np.zeros(d); sup = rng.choice(d, size=5, replace=False)
w[sup] = 3 * rng.standard_normal(5)
Xm = rng.standard_normal((ns, d))
y = Xm @ w + 0.1 * rng.standard_normal(ns)
Ll = np.linalg.norm(Xm, 2) ** 2 / ns
wl = np.zeros(d)
for _ in range(30000):
    z = wl - (Xm.T @ (Xm @ wl - y)) / ns / Ll
    wl = np.sign(z) * np.maximum(np.abs(z) - lam / Ll, 0)
wr = np.linalg.solve(Xm.T @ Xm / ns + lam * np.eye(d), Xm.T @ y / ns)
print(f"lasso: nnz={int((np.abs(wl) > 1e-6).sum())}, "
      f"sup ok={set(np.where(np.abs(wl) > 1e-6)[0]) == set(sup)}, "
      f"err={np.linalg.norm(wl - w) / np.linalg.norm(w):.3f}")
print(f"ridge: nnz={int((np.abs(wr) > 1e-12).sum())}, "
      f"err={np.linalg.norm(wr - w) / np.linalg.norm(w):.3f}")
```

**本节小结**：SVT 秩下降、RPCA 双误差 $10^{-4} \sim 10^{-5}$、对角失败 $0.87$、Lasso 对岭 5 对 50 的支撑差——全章数字由固定种子程序钉死；至此全册数值锚的规矩走完：正文引用的每个数都能当场复现。

## $\rm \S \, 6.9$ 带走清单

1. $\mathrm{rank} \to \|X\|_*$（凸包络，Fazel 2002）；坐标软阈值 $\to$ SVT；真算 $\tau = 0.6/1.2/1.5$ 使 $\mathrm{diag}(3,1,0.5)$ 的秩 $3 \to 2 \to 1$。
2. PCP 定理（Candès–Li–Ma–Wright 2011）：不相干 + 稀疏支撑 $\Rightarrow$ $\min \|L\|_* + \lambda\|S\|_1$（$\lambda = 1/\sqrt{\max(n_1,n_2)}$）精确分解；IALM = SVT 步 + 软阈值步 + 乘子更新。真算 $n = 100$：$\mathrm{relL} = 3 \times 10^{-4}$、$\mathrm{relS} = 1.9 \times 10^{-5}$、秩精确为 5。
3. 失败面：只观测对角线时核范数解满秩、误差 0.87（Shapiro 型不紧致）——观测结构必须与低秩结构正交交错，不相干是硬前提；核范数最小化是 SDP，大规模走一阶近端迭代。
4. 深度学习回响：weight decay 是岭（只缩不零）；剪枝 = 硬阈值循环（彩票假设）；LISTA 把 ISTA 展开成网络——经典算法是架构的先验，凸方法给保证、展开网络给分布内速度。真算：Lasso 5 非零、误差 0.026、支撑全对，对岭 50 非零、误差 0.188。
5. 出口地图：第 1 章凸代理与尖角 → 第 2 章保距与上下界 → 第 3 章贪心与迭代算法 → 第 4 章相变真实边界 → 第 5 章应用插槽 → 第 6 章谱域重放；向外三条路：HP 册随机数学、凸优化语法、张量前沿。
