# R1 复习总结：代数几何

六章压成三句话：**词典**（第 1—2 章）——$V$ 与 $I$ 两个翻译官把「多项式组」与「零点集」对译，$V$ 不单射（$x$ 与 $x^2$ 撞车）、投影不闭（挖点横轴）两处撞车由根理想与 Zariski 闭包收拾，零点定理（弱式：真理想必有零点；强式 $I(V(J)) = \sqrt{J}$，Rabinowitsch 添倒数变元一招证强式）把词典焊成「簇 ↔ 根理想」的包含反转双射；**发动机**（第 3—4 章）——单项式序立好后带余除法、Gröbner 基（首项无漏网）、Buchberger 算法（S-对归零，Dickson 引理保终止）让理想可计算，消去定理、Extension 定理与结式把「解方程组」做成流水线，隐式化参数曲线是全套装备的验收例；**舞台与应用**（第 5—6 章）——齐次坐标补上无穷远、Bézout 让交点数守恒（$\sum I(p, C \cap D) = mn$）、完备性治好投影不闭，代数统计把同一条「参数化 ↔ 理想」流水线开进 Fisher 精确检验。验收标准：闭卷清单答出几成、§R1.3 六条心智模型能默几条。

## $\rm \S \, R1.3$ 核心心智模型复读

1. **代数与几何互相翻译**：$V$ 从代数掉到几何、$I$ 从几何捞回代数；理想的三种运算（和、积、交）分别镜像几何的交、并、并——词典先于一切定理。
2. **撞车由「取根」收拾**：$V$ 无视平方（$V(x^2) = V(x)$），所以「簇 ↔ 理想」必须瘦身为「簇 ↔ 根理想」才是一一对应；强零点定理 $I(V(J)) = \sqrt{J}$ 是这条对应关系的合法性证书。
3. **可计算性靠单项式序**：序立好，除法有输出、首项有理想、S-对探测漏网；Buchberger 把「理想」从存在物变成可计算物——整章只有 Dickson 引理一处抽象保险。
4. **消去是投影的代数影子**：lex 基里自动住着消去理想的基；$V(I_m)$ 切出投影像的闭包，丢解只发生在首系数例外集上——几何丢的，代数记得。
5. **射影世界补对称**：无穷远不是装饰而是账本——平行线在此相交、参数化漏点在此有户口、Bézout 守恒律在此成立；仿射的三类病（解数跳、投影不闭、特权点）一次治好。
6. **参数化 ↔ 理想是同一扇门**：隐式化（曲线）、环面理想与 Markov 基（统计）、同伦延拓的路径计数（数值）都是这扇门后的房间——出口不止三个，门是同一扇。

## $\rm \S \, R1.4$ 交错练习

1. $I = \langle x^2 - 1, y - x \rangle$ 的约化 Gröbner 基（lex $x > y$）与对应的点集？（答：$[x - y, y^2 - 1]$；$\{(1,1), (-1,-1)\}$）
2. $xy - 1$ 与 $x + y - 1$ 对该基做除法，谁在理想里？（答：前者归零在理想里；后者余 $2y - 1$ 非零，且在 $(1,1)$ 取值为 $1$，几何代数同声判否）
3. 圆 $x^2 + y^2 = 4$ 与直线 $y = x - 1$ 的交点，消去后的一元方程与解？（答：$2x^2 - 2x - 3 = 0$，$x = \frac{1 \pm \sqrt{7}}{2}$）
4. $V(xz - 1)$ 投影到 $(x, y)$ 平面丢成什么样？消去理想给出什么？（答：像 $\{x \ne 0\}$ 挖洞不闭；$I \cap k[x,y] = \{0\}$，$V(I_m) = k^2$——闭包是全平面）
5. $\mathrm{Res}_x(x^2 + ax + 1, x^2 + x + a)$ 是什么？何时为零？（答：$(a-1)^2(a+2)$；$a = 1$ 或 $a = -2$ 时有公共根）
6. 单位圆的有理参数化在射影图景里参数空间该是谁？（答：$\mathbb{P}^1$——$(-1, 0)$ 是 $t = \infty$ 的正常取值，Extension 例外集 $V(x+1, y)$ 精确指出它）
7. 两圆锥曲线 $X^2 + Y^2 - Z^2$ 与 $X^2 + XY + Y^2 - Z^2$ 的交点数？（答：4 个全在 $Z = 1$ 卡、全横截，$4 = 2 \times 2$）

## $\rm \S \, R1.5$ 易混点对照

1. **$V(I + J)$ vs $V(IJ)$**：和给交（约束取严者，$V(I+J) = V(I) \cap V(J)$），积给并（约束并联，$V({IJ}) = V(I) \cup V(J)$）——写反全错。
2. **$I(X \cup Y)$ vs $I(X \cap Y)$**：并精确（$I(X \cup Y) = I(X) \cap I(Y)$），交只有包含（$I(X \cap Y) \supseteq I(X) + I(Y)$，双抛物线给严格不等号）。
3. **弱零点定理 vs 强零点定理**：弱式管「有没有解」（$V(I) = \varnothing \iff 1 \in I$），强式管「零点上的函数是谁」（$I(V(J)) = \sqrt{J}$）；强式由弱式加 Rabinowitsch 技巧推出，不是两条独立的公理。
4. **lex vs grevlex**：lex 只认第一变元的幂次（消去专用，首项消去时次数会涨），grevlex 先比总次、从最后变元比小者胜（计算最快，软件默认）——消去理论用 lex，日常计算用 grevlex。
5. **消去理想的基 vs Gröbner 基的切片**：$G_m = G \cap k[x_{m+1}, \ldots, x_n]$ 是 $I_m$ 的 Gröbner 基，但 $I_m$ 本身是「删掉前 $m$ 个变量后仍成立的约束」，两者的对象一个是生成集、一个是理想。
6. **结式 vs 判别式**：结式判两个多项式的公共根（$(p+q)$ 阶 Sylvester 行列式），判别式是结式的特例（多项式与其导数的结式）——判重数与判参数例外都走结式这条正路。

## $\rm \S \, R1.6$ 答案与提示

### 闭卷回忆清单

1. $V(S) = \{p : f(p) = 0, \forall f \in S\}$；零点只看 $S$ 张成的理想，赘余生成元无感。（§1.1）
2. 加法封闭＋吸收乘法；$I + J$ 约束取严者、${IJ}$ 并联、$I \cap J$ 与积同几何。（§1.2）
3. $I \subseteq J \Rightarrow V(J) \subseteq V(I)$；$V(IJ) = V(I \cap J) = V(I) \cup V(J)$；任意交保翻译；$I(X \cup Y) = I(X) \cap I(Y)$ 精确、$I(X \cap Y) \supseteq I(X) + I(Y)$ 一般严格。（§1.3—1.4）
4. $X = V(y - x^2)$、$Y = V(y + x^2)$：交 $\{(0,0)\}$ 给 $\langle x, y \rangle$；$I(X) + I(Y) = \langle x^2, y \rangle \subsetneq \langle x, y \rangle$。（§1.4）
5. 代数赘余：$V(x^2) = V(x)$，$V$ 不单射——根理想瘦身；几何闭合：挖点横轴的 $V(I(X))$ 是整条横轴——Zariski 闭包。（§1.5）
6. $V(I) = \varnothing \iff 1 \in I$（$k$ 代数闭）；Zorn 塞极大理想、Zariski 引理把商压成 $k$、读出坐标点；代数闭在 Zariski 引理一步上岗。（§2.1）
7. $\sqrt{J} = \{f : f^m \in J\}$，$V$ 之后纹丝不动；强式 $I(V(J)) = \sqrt{J}$，四步：添变元 $1 - tf$、证 $V(J') = \varnothing$、弱式压入 $1 \in J'$、换 $t = 1/f$ 清算出 $f^N \in J$。（§2.2—2.3）
8. $k[V] = k[x_1, \ldots, x_n]/I(V)$；直线给 $k[x]$、抛物线给 $k[x]$（$y$ 是 $x^2$ 的化名）、两点给 $k \times k$。（§2.4）
9. 良序＋可乘；lex 比第一变元、grlex 先总次再 lex、grevlex 先总次再从尾比小者胜。（§3.1）
10. 除子顺序一换余式分岔（$xy^2 - x$ 除 $[xy-1, y^2-1]$ 得 $x+y+1$ 或 $0$）；Gröbner 基：$\langle \mathrm{LM}(G) \rangle = \langle \mathrm{LM}(I) \rangle$；判据：$f \in I \iff$ 对基除法余式为零。（§3.2—3.3）
11. $S(f, g)$ 按首项对冲组合；$G$ 是基 $\iff$ 所有 S-对余式为零；终止靠首项理想严格上升链必停（Dickson 引理）。（§3.3）
12. lex 基的切片 $G \cap k[x_{s+1}, \ldots, x_n]$ 是消去理想的基；$\langle x^2-1, xy-1 \rangle$ 磨出 $[x-y, y^2-1]$，两个方向的投影都给 $\{1, -1\}$。（§3.4）
13. $\overline{\pi(V(I))} = V(I_m)$；Extension：部分解在首系数例外集 $V(c_1, \ldots, c_s)$ 之外一律可扩。（§4.1—4.2）
14. $\mathrm{Res}(f, g) = \det S(f, g)$，零 $\iff$ 有公共根，乘积公式 $a_p^q \prod_{f(\alpha)=0} g(\alpha)$；判别式 $(a-1)^2(a+2)$。（§4.3）
15. 图理想消参数：尖点走 Gröbner/结式两条路得 $y^2 = x^3$，圆得 $x^2 + y^2 - 1$；漏点 $(-1, 0)$ 由 Extension 定理的首系数例外集 $V(x+1, y)$ 解释。（§4.4）
16. $\mathbb{P}^n$＝过原点直线模缩放；$n + 1$ 张坐标卡沿取倒数粘合；抛物线戴帽 $Y_0 Y = X^2$ 在无穷远 $[0:1:0]$ 收拢成二重点。（§5.1—5.2）
17. $\sum_p I(p, C \cap D) = mn$；横截重数 $1$、相切 $\ge 2$、可计算定义走局部环维数；圆与切线用 $\mathrm{Res}_Z = X^2$ 验出二重。（§5.3）
18. 单项式参数化 $p_i \mapsto \theta^{A_i}$ 给环面理想 $I_A$（独立模型即 $p_{00}p_{11} - p_{01}p_{10}$）；Markov 基保纤维连通；纤维内数格子即 Fisher 精确检验。（§6.1）

## $\rm \S \, R1.7$ 衔接

向前：线性代数册的行列式与秩是结式、Sylvester 矩阵的零件库；交换代数拓扑同调速通册的理想、商环语言在第 1—2 章原文照用；数论册的模算术在 $k \times k$ 样品里露脸。向后：编码理论册的商环译码、数理统计册（对数线性模型）与因果推断册的隐变量约束、数值计算册的同伦延拓——都是「参数化 ↔ 理想」这扇门后的房间；进阶读法从 Cox–Little–O'Shea 的计算线与 Hartshorne 的理论线两级台阶上去。
