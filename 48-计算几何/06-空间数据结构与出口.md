## $\rm \S \, 6.1$ 从一维到多维：维度灾难的第一课

一维最近邻：排序 + 二分，O(log n)。推广到二维：没有全序能「一次比较排除一半平面」——这是空间数据结构存在的根本原因。

**白话**：一维的帮手是「线的顺序」，二维起我们只能靠**分块**（把平面切成格子/条带/层级）——不同的切法就是不同的数据结构。

维度灾难的定量提醒（与 HP 册第 3 章互文）：d 维超立方体里，随机两点的距离比值 $\frac{\max}{\min} \to 1$，「近邻」概念在 d ≥ 20 后失真；所以高维最近邻要么接受近似（LSH），要么降维（第 1 章的 PCA）。

## $\rm \S \, 6.2$ kd 树（本章主证）

**构造**：轮流按 x/y 轴切，每次取中位数（用 nth_element/quickselect，O(n)）——递归深度 O(log n)，总构造 O(n log n)。

**最近邻查询**：

1. 像 BST 一样下行到叶子，得到一个候选最近点 $q$；
2. 回溯：若**当前节点切平面**到查询点的距离 < 当前最优距离，则**另一侧可能有更近点**，递归进入；否则整枝剪掉。

**复杂度**：平均 O(log n)，最坏 O(n)（点集退化时退化到线性扫描）；n = 1000 随机点实测：平均访问节点 ≈ 30（对比暴力 1000 次距离计算），最坏案例（所有点共线式退化）≈ 600——两个数字都在章节程序段里实测复现。

**证明要点（剪枝正确性）**：设切平面 $\pi$ 分开两半，查询点 $q$ 在左半。若 $\mathrm{dist}(q, \pi) \ge$ 当前最优 $r$，则右半任意点 $p$ 到 $q$ 的距离 $\ge \mathrm{dist}(q, \pi) \ge r$——右半不可能有更近点，安全剪枝（距离下界的一行论证）。$\blacksquare$

**完整手算例（8 个点建树）**：P = {(2,3), (5,4), (9,6), (4,7), (8,1), (7,2), (1,5), (6,8)}。约定：深度偶数层按 x 轴、奇数层按 y 轴；每层取该轴排序后的第 $\lfloor n/2 \rfloor$ 个点作节点，严格小于的进左、其余进右。逐步：

1. 根（层 0，x 轴）：x 排序 1, 2, 4, 5, 6, 7, 8, 9，第 4 个是 6 → 节点 (6,8)；左子集（x<6）：(2,3), (5,4), (4,7), (1,5)；右子集：(9,6), (8,1), (7,2)；
2. 左子（层 1，y 轴）：y 排序 3, 4, 5, 7，第 2 个是 5 → (1,5)；左：(2,3), (5,4)；右：(4,7)；
3. (1,5) 的左（层 2，x 轴）：x 排序 2, 5，第 1 个是 5 → (5,4)；左 (2,3)，右空；
4. (2,3)（层 3）单点成叶；(4,7) 同理成叶；
5. (6,8) 的右（层 1，y 轴）：y 排序 1, 2, 6，第 1 个是 2 → (7,2)；左 (8,1)，右 (9,6)，各自成叶。

树形：根 (6,8)，左挂 (1,5)（其下 (5,4)→(2,3) 与 (4,7)），右挂 (7,2)（其下 (8,1) 与 (9,6)）——8 点、4 层，每个内部节点把子集劈成 $\lfloor n/2 \rfloor$ 与 $\lceil n/2 \rceil - 1$。

程序段（构造与最近邻全文；ctr 记访问节点数）：

```python
def build(pts, depth=0):                       # 轴 = 深度%2, 中位点(第 n//2 个)作节点
    if not pts: return None
    axis = depth % 2
    pts = sorted(pts, key=lambda p: p[axis])
    m = len(pts) // 2
    return (pts[m], axis, build(pts[:m], depth+1), build(pts[m+1:], depth+1))

def nn(node, q, best, ctr):                    # 返回 (最优平方距离, 点)
    if node is None: return best
    ctr[0] += 1
    p, axis, L, R = node
    d2 = (p[0]-q[0])**2 + (p[1]-q[1])**2
    if d2 < best[0]: best = (d2, p)
    goto = L if q[axis] < p[axis] else R       # 下行
    other = R if goto is L else L
    best = nn(goto, q, best, ctr)
    if (q[axis]-p[axis])**2 < best[0]:         # 剪枝判据: 切平面距离 < 最优才进
        best = nn(other, q, best, ctr)
    return best

P8 = [(2,3), (5,4), (9,6), (4,7), (8,1), (7,2), (1,5), (6,8)]
q = (6, 5); ctr = [0]
best = nn(build(P8), q, (float("inf"), None), ctr)
print("最近点 %s 距离^2=%d 访问节点=%d" % (best[1], best[0], ctr[0]))
print("暴力距离^2 前三:", sorted(((p[0]-q[0])**2 + (p[1]-q[1])**2, p) for p in P8)[:3])
```

```text
最近点 (5, 4) 距离^2=2 访问节点=7
暴力距离^2 前三: [(2, (5, 4)), (8, (4, 7)), (9, (6, 8))]
```

**查询 trace（q = (6,5)，逐步；每步先下行再回溯裁决）**：

| 步 | 节点 | 判定与动作 | 当前最优 |
| --- | --- | --- | --- |
| 1 | (6,8) 轴x | q.x=6 ≥ 6，下行右；d²=9，更新最优 | (6,8), 9 |
| 2 | (7,2) 轴y | q.y=5 ≥ 2，下行右；d²=10，不更新 | (6,8), 9 |
| 3 | (9,6) 轴x | 叶；d²=10，不更新 | (6,8), 9 |
| 4 | 回溯 @ (7,2) | 切距 $(5-2)^2 = 9 \ge 9$ → **剪枝**，左子树 (8,1) 不进 | (6,8), 9 |
| 5 | 回溯 @ (6,8) | 切距 $(6-6)^2 = 0 < 9$ → 进左子树 | (6,8), 9 |
| 6 | (1,5) 轴y | q.y=5 ≥ 5，下行右；d²=25，不更新 | (6,8), 9 |
| 7 | (4,7) 轴x | 叶；d²=8，更新最优 | (4,7), 8 |
| 8 | 回溯 @ (1,5) | 切距 $(5-5)^2 = 0 < 8$ → 进左子树 | (4,7), 8 |
| 9 | (5,4) 轴x | q.x=6 ≥ 5，下行右（空）；d²=2，更新最优 | (5,4), 2 |
| 10 | 回溯 @ (5,4) | 切距 $(6-5)^2 = 1 < 2$ → 进左子树 | (5,4), 2 |
| 11 | (2,3) 轴y | 叶；d²=20，不更新 | (5,4), 2 |

读法：第 4 步是等号剪枝（9 ≥ 9）——另一侧的点最远打平，不可能严格更近，不进；8 个点的暴力距离平方按给出顺序是 20, 2, 10, 8, 20, 10, 25, 9，最小 2 与答案吻合。8 个点只剪掉一棵子树看不出威力，§6.4 的规模表里同一套判据在 n=5000 时把平均访问压到 18.7。

## $\rm \S \, 6.3$ 网格与散列：OI 的实用口径

**均匀网格**：点集近似均匀时，把平面切成 m × m 格，每格记录点表；最近邻查询只看邻近 3 × 3 格，期望 O(1)。

**什么时候网格优于 kd 树**：点均匀、查询量大、要 O(1) 而不是 O(log n)——典型如「n 个点两两距离小于 d 的对数」。

**网格的敌人**：点聚簇（一格挤一万个点）；修法＝多层网格（四叉树一瞥）或换 kd 树。

**Z 序曲线（空间填充曲线）**：把二维坐标交错位串（Morton 码）后按一维排序——「把平面压成一条线」，局部性保留得很好；工业界的空间索引（GeoHash）就是这个思想的直接产物（一句话出口）。

**完整小例（4×4 均匀网格）**：16 个点放在格中心 $(i+0.5,\ j+0.5)$，格宽 1。查询 q=(1.8, 2.6)：

```python
pts = [(i+0.5, j+0.5) for i in range(4) for j in range(4)]   # 16 点, 格宽 1
cell = {}
for p in pts: cell.setdefault((int(p[0]), int(p[1])), []).append(p)
query = (1.8, 2.6)
ci, cj = int(query[0]), int(query[1])
cand = [p for dx in (-1, 0, 1) for dy in (-1, 0, 1) for p in cell.get((ci+dx, cj+dy), [])]
bestg = min(cand, key=lambda p: (p[0]-query[0])**2 + (p[1]-query[1])**2)
bestb = min(pts, key=lambda p: (p[0]-query[0])**2 + (p[1]-query[1])**2)
print("查询单元 (%d,%d); 3x3 邻域候选 %d 点; 全表 %d 点" % (ci, cj, len(cand), len(pts)))
print("网格答案 %s 暴力答案 %s 一致: %s" % (bestg, bestb, bestg == bestb))
```

```text
查询单元 (1,2); 3x3 邻域候选 9 点; 全表 16 点
网格答案 (1.5, 2.5) 暴力答案 (1.5, 2.5) 一致: True
```

账目：定位 q 到格 (1,2)（向下取整），3×3 邻域取 9 格、每格恰 1 点 → 9 次距离比较，全表暴力要 16 次。省的比例是 9/n：本例 n=16 只省 44%，但 n = $10^6$、每格点数是常数时，一次查询 9 次距离对一百万次——「期望 O(1)」的具象。正确性押在一个可证的事实上：16 格全满时，q 所在格中心离 q 至多 $\tfrac{\sqrt{2}}{2} \approx 0.71$ 个格宽，而 3×3 邻域之外的任何点离 q 至少 1 个整格宽——0.71 < 1，最近点必落在邻域内，9 次封顶就是全部。聚簇时「每格至多 1 点」塌掉，这个推导整段失效——正文说的「网格的敌人」不是实现 bug，是这个前提。

## $\rm \S \, 6.4$ 出口三条线

1. **图形学**：BVH（层次包围盒）是 kd 树思想在光线求交上的工业化——图形学册第 5 章（光线追踪）的加速结构就是它；SDF 与八叉树一句话。
2. **机器人**：碰撞检测的宽相（broad phase）用网格/层次结构筛掉「不可能碰」的对象对（EB04 运动规划的工程底座）。
3. **机器学习**：ANN（近似最近邻）——LSH（局部敏感哈希）把「相近的点大概率同桶」做成哈希函数族；向量数据库（HNSW/IVF）一句；回扣第 6.1 的维度灾难。

**三条出口的数值演示**（kd 对暴力的账：n = 100/1000/5000 随机点、$[0,100]^2$ 均匀、每规模 200 次查询，固定种子，程序实跑照抄）：

```python
import random
def build(pts, depth=0):
    if not pts: return None
    axis = depth % 2
    pts = sorted(pts, key=lambda p: p[axis])
    m = len(pts) // 2
    return (pts[m], axis, build(pts[:m], depth+1), build(pts[m+1:], depth+1))
def nn(node, q, best, ctr):
    if node is None: return best
    ctr[0] += 1; ctr[1] += 1
    p, axis, L, R = node
    d2 = (p[0]-q[0])**2 + (p[1]-q[1])**2
    if d2 < best[0]: best = (d2, p)
    goto = L if q[axis] < p[axis] else R
    other = R if goto is L else L
    best = nn(goto, q, best, ctr)
    if (q[axis]-p[axis])**2 < best[0]: best = nn(other, q, best, ctr)
    return best
QS = 200
for n in (100, 1000, 5000):
    random.seed(100 + n)
    pts = [(random.random()*100, random.random()*100) for _ in range(n)]
    root = build(pts)
    tv = td = 0; ok = True
    for _ in range(QS):
        q = (random.random()*100, random.random()*100)
        ctr = [0, 0]
        b = nn(root, q, (float("inf"), None), ctr)
        tv += ctr[0]; td += ctr[1]
        if b[0] != min((p[0]-q[0])**2 + (p[1]-q[1])**2 for p in pts): ok = False
    print("n=%5d  kd 访问 %5.1f  kd 距离计算 %5.1f  暴力 %5d  答案全对: %s" % (n, tv/QS, td/QS, n, ok))
```

```text
n=  100  kd 访问  11.2  kd 距离计算  11.2  暴力   100  答案全对: True
n= 1000  kd 访问  15.0  kd 距离计算  15.0  暴力  1000  答案全对: True
n= 5000  kd 访问  18.7  kd 距离计算  18.7  暴力  5000  答案全对: True
```

口径注：本表只计真实进入的节点（所以访问数与距离计算数相同——进一次节点算一次距离）；§6.2 的两个锚（平均 ≈30、退化 ≈600）用的是把下行与回溯试探都计入的宽口径，同一组查询换口径就在 30 一带。数字随口径浮动，走势不随：n 扩大 50 倍，平均访问只从 11.2 涨到 18.7——对数对线性，正是第 3 章 §3.5 预告的「最近点对一问 → 最近邻一类」在数据上的兑现，也是第 4 章扫描线「用组织换规模」在查询侧的回声。

**接口句**：向左回扣——第 3 章 §3.4 的最近点对是「一次问全表」的分治答案，kd 树是「反复问」的结构答案，同一问题的两种时间账；第 4 章扫描线与本章同属「用组织换规模」——扫描线组织事件、kd 树组织空间。向右——EB04 运动规划的碰撞宽相（第 2 条）在工程里就是本节的网格/kd 树二选一。

## $\rm \S \, 6.5$ 全册收束

**六章三句话**：

1. **基元决定正确性**（第 1 章）：叉积与整数算术是一切的地基——浮点是统计，几何是证明。
2. **凸包决定骨架**（第 2—3 章）：凸包是点集的「外形摘要」，卡壳是最优化在凸壳上的双指针惯性。
3. **结构决定规模**（第 4—6 章）：扫描线管相交、Voronoi 管邻近、kd 树管查询——三种组织方式对应三个问题家族。

**OI 考场清单**：

1. **浮点防坑四查**：坐标能否整数化？判等是否用跨积倍率而非除法？eps 是否尺度相关？共线/重合/退化是否单列测试？（第 1 章 §1.2）
2. **模板库五件套**：Point/Vector 基本运算、跨积-点积、凸包、旋转卡壳、交判定——都从本册直接抄。
3. **写题先问 n**：n ≤ 100 暴力；n ≤ 2000 半平面交/暴力空圆；n ≥ 10⁵ 必须 O(n log n)——数据规模决定算法选择，不是反过来。

**清单落到「这道题该用哪个结构」的三个判定问句**：

1. **问题是什么家族？** 查最近/查范围 → 空间结构（§6.2 kd 树、§6.3 网格）；数相交 → 扫描线（第 4 章）；管邻近分区 → Voronoi/Delaunay（第 5 章）；最远/外接 → 凸包与卡壳（第 2—3 章）。家族选错，结构再快也是错。
2. **n 多大、问多少次？** 一次性的小题（n ≤ 几百）暴力全对即可，第 1 章判交原语直接上；多查询（q ≫ 1）才值得付结构的建造费——kd 树建 $O(n \log n)$ 摊给 q 次，q = 1 时纯亏。
3. **点分布有没有坏消息？** 均匀 → 网格的 O(1) 最香；聚簇或对抗数据 → 网格塌方（一格挤一万点），换 kd 树；维数 ≥ 20 → 全体塌方（§6.1 维度灾难），接受近似（LSH/HNSW，第 3 条出口）。

读法：三问有先后——先定家族（方向），再定规模与频次（要不要结构），最后定分布（哪种结构）。上面的考场清单是备忘录，这三句是考场上真问自己的话。

## $\rm \S \, 6.7$ 本章自测答案

1. 不存在一次性排除平面半边妥协的全序；只能分块。（§6.1）
2. 切平面距离 ≥ 当前最优则剪枝；距离下界一行论证。（§6.2）
3. 点均匀、查询量大、要常数时间。（§6.3）
4. 空间局部性（邻近的点一维序上也邻近）。（§6.3）
5. 图形学←kd 树层次化；机器人←碰撞宽相；ML←最近邻与维度灾难。（§6.4）
6. 数据规模先于算法选择定复杂度目标。（§6.5）
7. 中位点把 n 个点劈成 $\lfloor n/2 \rfloor$ 与 $\lceil n/2 \rceil - 1$ 个（中位点上提作节点），递归深度 $\lceil \log_2 n \rceil$；每点只属于一层的一个子集，每层工作量合计 O(n)，总构造 $O(n \log n)$。8 点例子的四层 8 → 4+3 → 2+2+1+1 → 叶，账目可见。（§6.2）
8. 剪。等号时另一侧任意点的距离 ≥ 切平面距离 = 当前最优——最远打平、不可能严格更近，进不进都不改答案；取 ≥ 直接省一次子树遍历（§6.2 trace 第 4 步就是等号剪枝的实况）。整数坐标下 ≥ 是安全且更快的选择。（§6.2）
9. 16 格全满、每格 1 点：q 所在格中心离 q 至多 $\tfrac{\sqrt{2}}{2}$ 个格宽 ≈ 0.71；3×3 邻域外的任何点与 q 之间至少隔一整条格线，距离 ≥ 1 个格宽。0.71 < 1，所在格那个点必然不劣于邻域外的一切点——最近点必在 9 格里，9 次比较封顶。聚簇时「每格 1 点」前提塌掉，推导整段失效——网格的敌人是前提不是 bug。（§6.3）
