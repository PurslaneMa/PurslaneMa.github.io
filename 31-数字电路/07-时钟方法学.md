# $\rm Chapter \, 7$ 时钟方法学：同步设计的世界规则

第 6 章把状态元件改成了边沿触发：每个 D 触发器在上升沿采样，其余时间冻结。本章补上另一半公约：所有触发器的上升沿必须对齐，由同一个时钟分发。有了这两条，芯片规模的爆炸才不变成时序的灾难：设计者只需保证「任意两个触发器之间，信号能在一个周期内走完」，其余时间的行为全部免检。**时钟方法学（clocking methodology）**就是这套规则的正式名字。

> **开始前自检**：本章假设你已经会：
>
> 1. □ 会用 D 触发器的行为真值表，知道建立时间的判定式（本册 §6.2、§6.3）；
> 2. □ 知道亚稳态是违反建立或保持时间的后果（本册 §6.3）；
> 3. □ 会算门延迟的加法：一条链的总延迟是各级延迟之和（本册 §3、§4）；
> 4. □ 见过流水线寄存器这个词（计算机系统结构册 §3 可以只混个脸熟）。

## $\rm \S \, 7.1$ 同步设计公约：全片一个节拍

**同步设计（synchronous design）**公约一句话：片上所有触发器接同一个时钟，在同一节拍采样。它的价值要反过来看才清楚。没有公约，两个触发器之间的数据传递要单独分析「什么时候读、什么时候写」，一亿个触发器对就是天文数字的组合；有了公约，一切传递都发生在边沿，分析问题统一收敛成一个问题：信号从触发器 A 的时钟沿出发，穿过中间的组合逻辑，能否在下一个沿之前稳定到触发器 B 的门口。设计者的全部时序工作就是给每条这样的路径盖章。

> **器件视角**：公约不是物理定律，是设计纪律。违反它的电路照样能跑，只是没人再能对它做时序保证，而芯片产业赌的就是「保证」两个字。

## $\rm \S \, 7.2$ 单周期路径的时序约束

把上一节那个问题写成不等式。信号从触发器 A 出发到触发器 B 门口，路上花三笔钱：A 的时钟沿到输出要 ${T_{clk \to q}}$，中间组合逻辑合计 ${T_{logic}}$，B 门口要提前留出建立时间 ${T_{setup}}$。周期 $T_{clk}$ 必须包住三笔之和：

$$
T_{clk} \ge T_{clk \to q} + T_{logic} + T_{setup}
$$

手算一条 3 级逻辑路径：${T_{clk \to q}}$ 取 0.30 ns，三级门各 0.40 ns，${T_{logic}} = 1.20$ ns，${T_{setup}}$ 取 0.20 ns，合计 1.70 ns；周期不得短于 1.70 ns，对应频率上限 $1/1.70\,\text{ns} \approx 588\,\text{MHz}$。想跑得更快，只能压这三笔，通常先压组合逻辑（减级数、换更快的门）。

约束有了，就能对全片路径逐条审计。Python 真跑一个时序检查器：6 条路径的 $(T_{clk \to q},\ T_{logic},\ T_{setup})$ 参数（单位 ns），周期 $T_{clk} = 2.0$ ns，**时序余量（slack）**$= T_{clk}$ 减三笔之和，核心逻辑一行：

```python
slack = T_CLK - (t_cq + t_logic + t_setup)   # 负 slack 即违例
```

| 路径 | 三笔之和 (ns) | slack (ns) | 判定 |
| --- | --- | --- | --- |
| P1 | $0.30+1.20+0.20 = 1.70$ | $+0.30$ | 通过 |
| P2 | $0.30+1.50+0.20 = 2.00$ | $+0.00$ | 通过（贴线） |
| P3 | $0.40+1.30+0.20 = 1.90$ | $+0.10$ | 通过 |
| P4 | $0.30+1.60+0.20 = 2.10$ | $-0.10$ | 违例 |
| P5 | $0.20+1.05+0.25 = 1.50$ | $+0.50$ | 通过 |
| P6 | $0.35+1.45+0.20 = 2.00$ | $+0.00$ | 通过（贴线） |

P4 的负 slack 就是死刑判决：要么砍它 0.10 ns 的逻辑，要么全片降频。工业流程里这一步叫静态时序分析（static timing analysis，STA），规模是百万条路径，算法内核与上面那行代码没有本质区别。

约束式管的是建立侧；保持侧另有一条与周期无关的检查：

$$
T_{clk \to q} + T_{logic,\min} \ge T_{hold}
$$

${T_{logic,\min}}$ 是组合逻辑在最快情形下的延迟，$T_{hold}$ 是 §6.3 的保持时间。两条检查合起来才是完整的审计：降频能修建立违例、修不了保持违例（本册 §6.3 的结论在这里兑现），所以检查器两套都要跑，一套对着周期、一套与周期无关。三笔钱各自的压缩手段也由此分明：${T_{clk \to q}}$ 换更快的触发器、${T_{logic}}$ 减级数或拆段、${T_{setup}}$ 换工艺，通常第一刀砍在逻辑上。

## $\rm \S \, 7.3$ 时钟偏斜与时钟树

公约说「所有触发器同一节拍采样」，物理上不可能分毫不差：时钟从源头出发，走导线也有延迟，到达各触发器的时间有先有后，这个差叫**时钟偏斜（clock skew）**。时钟靠**时钟树（clock tree）**分发，典型形状是 H 树：从根部反复二分，让源到每个叶子的几何长度相同，把偏斜压小。压小不等于零，预算必须为它买单。

算一笔偏斜的账。设捕获端触发器的时钟比发射端**早到** 0.20 ns：数据本来有 $T_{clk}$ 的时间赶路，现在捕获提前 0.20 ns 关门，可用预算缩成 $2.0 - 0.2 = 1.8$ ns。对 §7.2 的 6 条路径重新审计：

| 路径 | 预算 2.0 ns 时 | 预算 1.8 ns 时 |
| --- | --- | --- |
| P1 | $+0.30$ 通过 | $+0.10$ 通过 |
| P2 | $+0.00$ 通过 | $-0.20$ 违例 |
| P3 | $+0.10$ 通过 | $-0.10$ 违例 |
| P4 | $-0.10$ 违例 | $-0.30$ 违例 |
| P5 | $+0.50$ 通过 | $+0.30$ 通过 |
| P6 | $+0.00$ 通过 | $-0.20$ 违例 |

0.20 ns 的偏斜让三条原本通过的路径翻车。反过来，捕获端晚到 0.20 ns 会白送 0.20 ns 预算，但那只是把问题挪给了别的路径方向，工程上一律按最坏偏斜收费。

偏斜的两个方向记成一张小表：

| 偏斜方向 | 可用预算 | 效果 |
| --- | --- | --- |
| 捕获早到 $s$ | $T_{clk} - s$ | 吃预算，贴线路径翻车 |
| 捕获晚到 $s$ | $T_{clk} + s$ | 送预算，但反方向路径（同一条线反向传输时）反过来吃亏 |

## $\rm \S \, 7.4$ 两条禁令与一条边界

组合逻辑里不许有环。组合网络的输出应当是输入的函数，出现环之后输出参与决定自己，电路可能振荡，也可能停在取决于上电历史的某个状态，§7.2 的约束式直接失效。唯一的合法例外是锁存器的有意反馈（本册 §5）：那里反馈被使能信号看门，是存储的原理，不是失控的环。

第二条边界在时钟之间。一块现代芯片不止一个时钟域，CPU 核一个频率、外设一个频率，跨域传数据时发送域的边沿与接收域的边沿没有固定相位关系，采样必然偶尔撞上过渡区，亚稳态（本册 §6.3）无法根除。工程防线是**同步器（synchronizer）**：接收域先用两级背靠背的触发器接住数据，第一级允许进亚稳态，给它留一整个周期去稳定，第二级在下一个沿采一个大概率已经落定的值。概率没压到零，只是压到了「几十年一遇」的量级。

最后接上系统结构册：流水线（计算机系统结构册 §3）把一条指令的执行切成取指、译码、执行、访存、写回五段，段与段之间插的那排流水线寄存器，物理上就是本册 §6 的一排 D 触发器，节拍由本章的约束式卡死。该册的 CPI 指标，电路基础就是「每拍所有段并行推进一段」。

五站与四排寄存器对齐看：取指、译码、执行、访存、写回之间各插一排 D 触发器，共四排；每一排的建立检查由 §7.2 的约束式看住，段内逻辑被压短，周期跟着缩短。四排寄存器同一拍同时采样，四条指令各在一段，这是 CPI 逐拍推进一句之下的电路实况。

## $\rm \S \, 7.7$ 本章自测答案

> 先闭卷作答 §7.5 与 §7.6，再核对。

### $\rm \S \, 7.7.1$ 关键概念回顾答案

1. 收敛成：信号能否从触发器 A 的沿出发，在下一个沿之前穿过组合逻辑、稳定到触发器 B 的门口。全部路径各自回答这个问题即可，不再需要分析任意时刻的交互。（§7.1）
2. $T_{clk} \ge T_{clk \to q} + T_{logic} + T_{setup}$：第一项是发射沿到输出的延时，第二项是中间组合逻辑总延时，第三项是捕获端要求的提前稳定量。slack 等于 $T_{clk}$ 减三笔之和，负值即违例。（§7.2）
3. 时钟沿导线分发有传播延迟，到达各触发器的时间有差，所以偏斜必然存在。H 树让源到每个叶子的路径等长，把偏斜压小。（§7.3）
4. 早到使捕获提前关门，预算缩水，可能把贴线路径打成违例；晚到给捕获端多留时间，相当于白送预算，但最坏方向始终要收费。（§7.3）
5. 组合环让输出参与决定自己，电路可能振荡或停在依赖上电历史的状态，约束式失效。锁存器的反馈被使能看门，是受控的存储原理，不属于失控组合环。（§7.4）
6. 防跨时钟域采样撞上亚稳态。没有消灭，只是给第一级留一整拍稳定时间，把出错概率压到工程可忽略的量级。（§7.4）
7. 对称（H 树等长）让源到每个叶子的传播延迟相同，偏斜从源头压小；树越深、缓冲器级数越多，每级的一点失配层层累积，反而越难压，所以深树要逐级做匹配。（§7.3）

### $\rm \S \, 7.7.2$ 应用与辨析答案

1. 逻辑 $5 \times 0.3 = 1.5$ ns，三笔合计 $0.4 + 1.5 + 0.25 = 2.15$ ns，slack $= -0.15$ ns。1 GHz 对应周期 1.0 ns，三笔都得砍，单靠换门远不够，得减逻辑级数或把路径切进流水线。（§7.2）
2. 晚到 0.3 ns 白送预算，等效 $T_{clk}$ 变 2.3 ns：P1 至 P6 的 slack 依次变为 $+0.60$、$+0.30$、$+0.40$、$+0.20$、$+0.80$、$+0.30$，全部通过。（§7.3）
3. 不通过。锁存器是电平触发的，窗口内透明，等于回到本册 §6.1 的穿透灾难；同步公约明确要求边沿触发，且锁存器之间传递会绕开约束式的保护，时序无人兜底。（§6.1、§7.1、§7.4）
4. 单级亚稳概率虽小但乘上每秒十亿次采样就不可忽略，两级把稳定窗口拉长一整个周期，概率再降若干数量级，工程上压到几十年一遇即可接受。第三级再降一档概率，代价是跨域通路多一拍延迟。（§7.4）
5. 没用。保持违例与频率无关（§6.3、§7.2），降频救不了。原因方向与建立违例相反：不是逻辑太慢，是某段逻辑太快（或延迟差太大），要往插入缓冲器、改保持时间的方向修。（§7.2）
