# $\rm Chapter \, 2$ 互信息与数据处理不等式

第 1 章把熵定成「一个变量自己有多不确定」。本章问下一个问题：一个变量**关于另一个变量**说了多少？答案叫互信息，它有三副面孔（减法、减法、加减法）但只是一个数；它的内核是一个更基本的量——KL 散度，而 KL 散度非负是全章所有不等式的总源头。章末的主证是数据处理不等式：数据经过任何加工（函数、随机信道、特征工程），关于源的信息只减不增。这条定理用链式法则两行即证，却是机器学习里「特征工程不能无中生有」的守恒律。路线：互信息的定义与三副面孔（§2.1）、一个 ${2 \times 2}$ 联合分布上把所有量算到小数点后六位（§2.2）、KL 散度与 Jensen（§2.3，顺手还上第 1 章欠的「条件化不增熵」）、数据处理不等式（§2.4，主证）、ML 常客的户口本（§2.5）。

> **开始前自检**：本章假设你已经会：
>
> 1. □ 熵、联合熵、条件熵的定义与链式法则 ${H(X, Y) = H(X) + H(Y \mid X)}$（第 1 章 §1.2）；
> 2. □ Jensen 不等式与 $\log$ 的凹性（第 1 章 §1.2、§1.4 各用过一次）；
> 3. □ 条件独立 ${X \perp Z \mid Y}$ 的定义 ${p(x, z \mid y) = p(x \mid y)\, p(z \mid y)}$（概率论册第 3 章）；
> 4. □ 极大似然估计的写法（概率论册第 5 章；§2.5 只引一句）。
>

## $\rm \S \, 2.1$ 互信息：三副面孔的同一个数

**白话**：知道 $Y$ 之前 $X$ 的不确定性是 $H(X)$，知道 $Y$ 之后还剩 ${H(X \mid Y)}$——两者之差就是「$Y$ 替我消掉的那部分不确定性」，这就是 $Y$ 关于 $X$ 的信息量。奇妙的是，这个量对 ${X, Y}$ 对称：$Y$ 告诉你关于 $X$ 的，恰好等于 $X$ 告诉你关于 $Y$ 的。

**定义 2.1**（互信息）。离散随机变量 ${X, Y}$ 的**互信息（mutual information）**定义为

$$
I(X; Y) \;=\; H(X) - H(X \mid Y)
$$

读作「$Y$ 消掉了 $X$ 的多少不确定性」，单位与熵相同（比特）。

**定理 2.1**（三副面孔）。${I(X; Y) = H(X) - H(X \mid Y) = H(Y) - H(Y \mid X) = H(X) + H(Y) - H(X, Y)}$。

**推导**。链式法则有两种拆法：${H(X, Y) = H(X) + H(Y \mid X) = H(Y) + H(X \mid Y)}$。由第二种，${H(X \mid Y) = H(X, Y) - H(Y)}$，代入定义得第三副（对 ${X, Y}$ 显然对称），再由第一种拆法代入得第二副，两步连写：

$$
\begin{aligned}
I(X; Y) &= H(X) - \big[H(X, Y) - H(Y)\big] \;=\; H(X) + H(Y) - H(X, Y) \\
&= H(X) + H(Y) - H(X) - H(Y \mid X) \;=\; H(Y) - H(Y \mid X)
\end{aligned}
$$

$\blacksquare$

**求和式**（把三副面孔落到分布上）。把第三副面孔逐项展开：

$$
\begin{aligned}
I(X; Y) &= -\sum_x p(x) \log_2 p(x) \;-\; \sum_y p(y) \log_2 p(y) \;+\; \sum_{x, y} p(x, y) \log_2 p(x, y) \\
&= \sum_{x, y} p(x, y) \Big[ \log_2 p(x, y) - \log_2 p(x) - \log_2 p(y) \Big]
\;=\; \sum_{x, y} p(x, y) \log_2 \frac{p(x, y)}{p(x)\, p(y)}
\end{aligned}
$$

第一行到第二行：把 ${-\sum_x p(x) \log_2 p(x)}$ 写成 ${-\sum_{x, y} p(x, y) \log_2 p(x)}$（对 $y$ 求和把 ${p(x, y)}$ 边缘化回 $p(x)$），$y$ 那项同理。

**读法**：求和式里的比值 ${p(x, y) / (p(x) p(y))}$ 是「真实联合」与「假装独立」的比。独立时比值恒为 1、对数为零、互信息为零；越偏离独立，互信息越大。§2.3 会给这个式子一个正式名字：**联合分布到边缘乘积的 KL 散度**。

**Venn 图读法**（只作记忆钩子，不是证明）：把 $H(X)$、$H(Y)$ 画成两个圆，交集是 ${I(X; Y)}$，$H(X)$ 里去掉交集是 ${H(X \mid Y)}$，并集是 ${H(X, Y)}$。三副面孔就是「交＝圆减月牙」「交＝两圆之和减并」。三个变量以上这张图会出负面积，别推广。

**两个特例**：${I(X; X) = H(X) - H(X \mid X) = H(X)}$——熵是变量关于自己的互信息，所以熵有时被叫做「自信息量」；$Y$ 是 $X$ 的函数时 ${H(Y \mid X) = 0}$，于是 ${I(X; Y) = H(Y)}$。

**定义 2.2**（条件互信息）。给定 $Z$ 时 ${X, Y}$ 的条件互信息 ${I(X; Y \mid Z) = H(X \mid Z) - H(X \mid Y, Z)}$，读作「已知 $Z$ 的前提下，$Y$ 还能再消掉 $X$ 多少不确定性」。

**定理 2.2**（互信息链式法则）。${I(X; Y, Z) = I(X; Y) + I(X; Z \mid Y)}$。

**证明**。按定义展开再加减一项 ${H(X \mid Y)}$：

$$
I(X; Y, Z) \;=\; H(X) - H(X \mid Y, Z) \;=\; \big[H(X) - H(X \mid Y)\big] + \big[H(X \mid Y) - H(X \mid Y, Z)\big] \;=\; I(X; Y) + I(X; Z \mid Y) \;\;\blacksquare
$$

**读法**：「${(Y, Z)}$ 合起来告诉你关于 $X$ 的」＝「先听 $Y$ 说的」＋「听完 $Y$ 之后 $Z$ 再补充的」。§2.4 的主证就是把这条法则用两次。

**本节小结**：互信息＝消掉的不确定性，三副面孔由链式法则两次代入得到，求和式是「联合比独立」的对数期望；条件互信息与它的链式法则是 §2.4 的工具。

## $\rm \S \, 2.2$ 数值锚：一个 ${2 \times 2}$ 联合分布算到底

**白话**：一个具体的小表把 §2.1 所有量算一遍，三副面孔的三个数必须一模一样——不是「大致相等」，是小数点后六位全对。本节的数全部本机实测。

**锚分布**：${X, Y \in \{0, 1\}}$，联合概率

| | ${Y = 0}$ | ${Y = 1}$ | 边缘 $p(x)$ |
| --- | --- | --- | --- |
| ${X = 0}$ | 0.45 | 0.25 | 0.70 |
| ${X = 1}$ | 0.05 | 0.25 | 0.30 |
| 边缘 $p(y)$ | 0.50 | 0.50 | 1 |

**三个熵**：${H(X) = H_b(0.7) = 0.881291}$；${H(Y) = H_b(0.5) = 1.000000}$；${H(X, Y) = -(0.45 \log_2 0.45 + 0.25 \log_2 0.25 + 0.05 \log_2 0.05 + 0.25 \log_2 0.25) = 1.734498}$。

**两个条件熵**（按定义 1.3 对条件分布的熵取加权平均）：$y = 0$ 列给 ${p(x \mid y = 0) = (0.9, 0.1)}$，熵 ${H_b(0.9) = 0.468996}$——正是第 1 章 §1.1 的锚；$y = 1$ 列给 ${(0.5, 0.5)}$，熵 1。于是 ${H(X \mid Y) = 0.5 \times 0.468996 + 0.5 \times 1 = 0.734498}$。换方向：${p(y \mid x = 0) = (0.642857, 0.357143)}$ 熵 0.940286、${p(y \mid x = 1) = (0.166667, 0.833333)}$ 熵 0.650022，加权得 ${H(Y \mid X) = 0.853207}$。

**三副面孔对账**：${H(X) - H(X \mid Y) = 0.881291 - 0.734498 = 0.146793}$；${H(Y) - H(Y \mid X) = 1.000000 - 0.853207 = 0.146793}$；${H(X) + H(Y) - H(X, Y) = 1.881291 - 1.734498 = 0.146793}$。

三个数全同，${I(X; Y) = 0.146793}$ 比特。

**读法**：这张表顺手演示了第 1 章 §1.2 的一句提醒——**具体的条件可以让熵变大**：${H(X \mid Y = 1) = 1 > H(X) = 0.881291}$，因为 ${Y = 1}$ 那一列恰好是公平硬币；但对 $Y$ 取平均后 ${H(X \mid Y) = 0.734498 < H(X)}$，平均意义上条件化仍然减熵。还有一件事值得看：${H(X \mid Y) \ne H(Y \mid X)}$（0.734 对 0.853），两个条件熵不对称，但它们各自与对应边缘熵的差相等——互信息是对称的那个。

**本节小结**：锚 ${I = 0.146793}$，三副面孔六位全对；条件熵不对称、互信息对称；「具体条件可增熵、平均条件必减熵」在表上肉眼可见。

## $\rm \S \, 2.3$ KL 散度：所有不等式的总源头

**白话**：两个分布 ${P, Q}$ 之间「有多不一样」，信息论的标尺不是欧氏距离，而是「按 $Q$ 编码而真实是 $P$ 时每符号多付的位数」——第 1 章 §1.4 下界证明里那个 ${L - H}$ 就是它。这个量非负，而且几乎所有熵的不等式都是它非负的推论。

**定义 2.3**（KL 散度）。同一字母表上两个分布 ${P, Q}$ 的 **KL 散度（Kullback–Leibler divergence）**（又叫相对熵）定义为

$$
D(P \,\|\, Q) \;=\; \sum_x p(x) \log_2 \frac{p(x)}{q(x)}
$$

约定 ${0 \log_2 (0/q) = 0}$，${p \log_2 (p/0) = +\infty}$（$P$ 有的地方 $Q$ 没有，代价无穷）。它**不对称**（${D(P \| Q) \ne D(Q \| P)}$ 一般成立）、不满足三角不等式，所以叫「散度」不叫「距离」。

**定理 2.3**（信息不等式，Gibbs）。${D(P \,\|\, Q) \ge 0}$，取等当且仅当 ${P = Q}$。

**证明**（Jensen）。设 ${A = \{x : p(x) > 0\}}$ 为 $P$ 的支撑。

$$
\begin{aligned}
-D(P \,\|\, Q) &= \sum_{x \in A} p(x) \log_2 \frac{q(x)}{p(x)}
\;\le\; \log_2 \Big( \sum_{x \in A} p(x) \cdot \frac{q(x)}{p(x)} \Big) \\
&= \log_2 \sum_{x \in A} q(x) \;\le\; \log_2 \sum_{x} q(x) \;=\; \log_2 1 \;=\; 0
\end{aligned}
$$

第一个不等号是 Jensen（$\log_2$ 凹，${\mathrm{E}[\log_2 Z] \le \log_2 \mathrm{E}[Z]}$，${Z = q(X)/p(X)}$ 按 $P$ 取期望）；第二个不等号是「只在 $A$ 上求和不超过全部求和」。取等条件：Jensen 取等要求 ${q(x)/p(x)}$ 在 $A$ 上为常数 $c$；第二个不等号取等要求 ${\sum_A q = 1}$，即 $Q$ 的质量全在 $A$ 上；两者合起来 ${\sum_A q = c \sum_A p = c = 1}$，故 ${q = p}$。$\blacksquare$

**读法**：这个证明与第 1 章定理 1.6 下界的证明是**同一个**（把 ${q_i = 2^{-l_i}}$ 代进去，Kraft ${\sum q \le 1}$ 替换了这里的「$Q$ 是分布」）。第 1 章借了它的壳，本章给它正名。

**定理 2.4**（互信息＝KL 散度）。

$$
I(X; Y) \;=\; D\big(p(x, y) \,\big\|\, p(x)\, p(y)\big)
$$

**证明**。把 §2.1 的求和式与定义 2.3 并排看：${\sum_{x, y} p(x, y) \log_2 \frac{p(x, y)}{p(x) p(y)}}$ 恰是以 ${P = p(x, y)}$（联合）、${Q = p(x) p(y)}$（边缘乘积，它本身是 ${\mathcal{X} \times \mathcal{Y}}$ 上一个合法分布）代入的 KL 散度。$\blacksquare$

**读法**：互信息是「联合偏离独立的 KL 距离」——不是「相关程度」，是「真实联合与假装独立之间的编码代价差」。锚上核对：${D(p(x, y) \| p(x) p(y)) = 0.146793}$（本机实测），与 §2.2 的 $I$ 一致。

**推论 2.5**（三条一次还清）。

1. ${I(X; Y) \ge 0}$，取等当且仅当 ${X, Y}$ 独立（由定理 2.3 与定理 2.4：KL 为零当且仅当联合等于边缘乘积）。
2. **条件化不增熵**：${H(X \mid Y) \le H(X)}$，取等当且仅当独立（由 ${I = H(X) - H(X \mid Y) \ge 0}$）——第 1 章定理 1.3 的欠账到此还清。
3. **条件互信息非负**：${I(X; Y \mid Z) \ge 0}$，取等当且仅当 ${X \perp Y \mid Z}$。证明：${I(X; Y \mid Z) = \sum_z p(z)\, D\big(p(x, y \mid z) \,\|\, p(x \mid z) p(y \mid z)\big)}$，每一项是定理 2.4 在条件分布上的翻版，非负；为零当且仅当每个 ${p(z) > 0}$ 的 $z$ 处联合等于乘积，即条件独立。

**本节小结**：KL 散度＝用错分布的编码代价，Jensen 一次证非负；互信息＝联合到边缘乘积的 KL；由此互信息非负、条件化减熵、条件互信息非负（零当且仅当条件独立）。第三条是 §2.4 主证的钥匙。

## $\rm \S \, 2.4$ 数据处理不等式（本章主证）

**白话**：原始数据 $X$ 经过一次测量得到 $Y$，再把 $Y$ 喂给某个处理器（函数、模型、带噪声的信道）得到 $Z$。不管处理器多聪明，$Z$ 关于 $X$ 的信息不可能超过 $Y$ 关于 $X$ 的信息——你不能从一张模糊的照片「处理」出原本就不在照片里的细节。这是信息的守恒律：加工只能丢、不能造。

**定义 2.4**（马尔可夫链）。三个随机变量 ${X, Y, Z}$ 构成**马尔可夫链（Markov chain）**，记 ${X \to Y \to Z}$，若联合分布可以写成

$$
p(x, y, z) \;=\; p(x)\, p(y \mid x)\, p(z \mid y)
$$

读作「$Z$ 只通过 $Y$ 依赖 $X$」。三个等价说法（概率论册第 3 章条件独立的定义直接给出）：${p(z \mid x, y) = p(z \mid y)}$——给定 $Y$，$Z$ 不再看 $X$；${X \perp Z \mid Y}$，即 ${p(x, z \mid y) = p(x \mid y)\, p(z \mid y)}$；${I(X; Z \mid Y) = 0}$（由推论 2.5 第 3 条）。

第 2 条对 ${X, Z}$ 对称，所以 ${X \to Y \to Z}$ 当且仅当 ${Z \to Y \to X}$。最常见的实例：$Z$ 是 $Y$ 的确定性函数 ${Z = g(Y)}$，此时 ${p(z \mid y)}$ 是退化分布，${X \to Y \to g(Y)}$ 自动成立。

**定理 2.6**（数据处理不等式）。若 ${X \to Y \to Z}$，则

$$
I(X; Z) \;\le\; I(X; Y)
$$

取等当且仅当 ${I(X; Y \mid Z) = 0}$，即 ${X \to Z \to Y}$ 也是马尔可夫链。

**证明**。对 ${I(X; Y, Z)}$ 用定理 2.2 的链式法则，两种顺序各展开一次：

$$
\begin{aligned}
I(X; Y, Z) &= I(X; Y) + I(X; Z \mid Y) \;=\; I(X; Y) + 0 \\
I(X; Y, Z) &= I(X; Z) + I(X; Y \mid Z)
\end{aligned}
$$

第一行末尾用了马尔可夫条件的第 3 种说法 ${I(X; Z \mid Y) = 0}$。两行左边相同，于是

$$
I(X; Z) \;=\; I(X; Y) - I(X; Y \mid Z) \;\le\; I(X; Y)
$$

最后一步由推论 2.5 第 3 条 ${I(X; Y \mid Z) \ge 0}$。取等当且仅当 ${I(X; Y \mid Z) = 0}$，即 ${X \perp Y \mid Z}$，即 ${X \to Z \to Y}$。$\blacksquare$

**读法**：证明的全部内容是「同一个量 ${I(X; Y, Z)}$ 用两种顺序算，一种顺序里多出来的项被马尔可夫性杀成零，另一种顺序里多出来的项非负」。证明只有三行，但它用到了本章此前的每一件工具：链式法则（§2.1）、条件互信息非负（§2.3 推论）、马尔可夫条件的互信息表述（定义 2.4）。

**推论 2.7**（三个常用形状）。

1. **函数不增信息**：对任意函数 $g$，${I(X; g(Y)) \le I(X; Y)}$。证明：${X \to Y \to g(Y)}$ 是马尔可夫链。
2. **充分统计量**：若 ${T = T(Y)}$ 满足 ${I(X; T(Y)) = I(X; Y)}$，称 $T$ 对 $X$ **充分（sufficient）**——取等条件说这恰当于 ${X \to T(Y) \to Y}$，即「知道 $T$ 之后 $Y$ 的其余部分关于 $X$ 已无话可说」，与概率论册第 5 章的 Fisher–Neyman 因子分解定义等价（陈述级，Cover–Thomas 定理 2.9.1）。
3. **级联信道**：${X \to Y \to Z}$ 下 ${I(X; Z) \le I(Y; Z)}$（把链反过来读 ${Z \to Y \to X}$ 再用定理 2.6，$Z$ 的角色换成 $X$）。两条合起来：中间变量 $Y$ 与两端的互信息都不小于两端之间的互信息。

**ML 读法**（守恒律的三种现身）：

1. 特征工程：从原始输入 $Y$ 提取特征 ${Z = g(Y)}$ 不可能提高「特征关于标签 $X$」的互信息上限，只能避免丢失——好特征是「充分」的特征，不是「更有信息」的特征。
2. 深度网络各层：${X \to h_1 \to h_2 \to \cdots \to h_L}$ 是马尔可夫链（每层只看上一层），所以 ${I(X; h_L) \le I(X; h_{L-1}) \le \cdots \le I(X; h_1)}$，表示层逐层只减不增；信息瓶颈理论就建在这条链上。
3. 隐私：若 $Z$ 是 $Y$ 经随机扰动得到的发布版本，${I(X; Z) \le I(X; Y)}$ 给出「发布版泄漏的关于敏感属性 $X$ 的信息不超过原版」的硬上界。

**本节小结**：马尔可夫链＝「只通过中间变量依赖」，互信息表述是 ${I(X; Z \mid Y) = 0}$；DPI 的证明是链式法则两种顺序相减；推论：函数不增信息、充分统计量＝取等、级联信道逐级衰减。

## $\rm \S \, 2.5$ ML 常客的户口本

**白话**：交叉熵、KL、互信息、相关系数在机器学习里天天见，但它们的「户籍」各不相同。本节用四条短记录把它们各归各位。

**记录一：交叉熵＝熵＋KL**。定义**交叉熵（cross-entropy）** ${H(P, Q) = -\sum_x p(x) \log_2 q(x)}$，读作「真实是 $P$、却用 $Q$ 的理想码长 ${-\log_2 q(x)}$ 编码，平均每符号的位数」。两行代数：

$$
H(P, Q) \;=\; -\sum_x p(x) \log_2 q(x) \;=\; -\sum_x p(x) \log_2 p(x) \;+\; \sum_x p(x) \log_2 \frac{p(x)}{q(x)} \;=\; H(P) + D(P \,\|\, Q)
$$

于是 ${H(P, Q) \ge H(P)}$，取等当且仅当 ${Q = P}$——这正是第 1 章定理 1.6 下界的「分布版」：用 $Q$ 的码长表编 $P$ 的源，多付的恰是 KL。锚：${P = (0.7, 0.3)}$，${Q = (0.5, 0.5)}$，交叉熵 ${= 1.000000}$，熵 ${0.881291}$，KL ${0.118709}$，${0.881291 + 0.118709 = 1.000000}$（本机实测）。

**记录二：为什么分类损失用交叉熵而不是均方误差**（两行概率论证）。设数据标签分布为 $P$，模型输出分布为 $Q_\theta$。

1. 极大似然＝最小化交叉熵：样本的负对数似然平均 ${-\frac{1}{n} \sum_i \log q_\theta(y_i)}$ 是 ${H(\hat{P}, Q_\theta)}$（$\hat{P}$ 为经验分布）；由记录一，${H(\hat{P}, Q_\theta) = H(\hat{P}) + D(\hat{P} \| Q_\theta)}$，第一项与 $\theta$ 无关，所以最小化交叉熵就是最小化 ${D(\hat{P} \| Q_\theta)}$，即极大似然（概率论册第 5 章 §5.5 的同一句话）。
2. 均方误差是另一种似然：${\|y - f_\theta(x)\|^2}$ 是「${y = f_\theta(x) + \text{高斯噪声}}$」模型的负对数似然。标签是类别时真实生成模型是离散分布而非高斯，用 MSE 等于对错误的似然做极大化；外加一条实践账——交叉熵对 softmax 输入的梯度是 ${q - p}$，预测错得越自信梯度越大，MSE 经过 softmax 后在自信错误处梯度趋零，学不动。

**记录三：互信息与相关系数**。一句话：**相关系数只抓线性依赖，互信息抓一切依赖**。标准反例：$X$ 在 ${\{-1, 0, 1\}}$ 均匀，${Y = X^2}$。协方差 ${\mathrm{E}[XY] - \mathrm{E}[X]\mathrm{E}[Y] = \mathrm{E}[X^3] - 0 = 0}$，相关系数为零；但 $Y$ 是 $X$ 的函数，${I(X; Y) = H(Y) = H_b(1/3) = 0.918296}$ 比特（本机实测）——$Y$ 由 $X$ 完全决定，相关系数却说「无关」。代价是互信息需要估计整个联合分布，样本少时比相关系数难算得多。

**记录四：KL 的方向**。${D(P \| Q)}$ 与 ${D(Q \| P)}$ 不同，优化时选哪个决定行为：最小化 ${D(P \| Q)}$（$P$ 真实、$Q$ 模型，极大似然的方向）会让 $Q$ 覆盖 $P$ 的所有质量（$P$ 有的地方 $Q$ 不敢为零，否则无穷）；最小化 ${D(Q \| P)}$（变分推断的方向）会让 $Q$ 缩到 $P$ 的某一个峰上（$Q$ 为零的地方不计代价）。概率论册第 10 章的 ELBO 用的是后者。

**本节小结**：交叉熵＝熵＋KL；分类用交叉熵因为它就是极大似然且梯度不饱和；互信息抓全部依赖、相关只抓线性；KL 两个方向两种行为。

## $\rm \S \, 2.6$ 程序段：联合分布全套对账

程序（纯 Python，从联合分布出发算 §2.2 的每一个数，断言三副面孔相等、互信息等于 KL，并跑 §2.5 的两个锚）：

```python
from math import log2

J = {(0, 0): 0.45, (0, 1): 0.25, (1, 0): 0.05, (1, 1): 0.25}

def H(dist):
    return -sum(p * log2(p) for p in dist.values() if p > 0)

def KL(P, Q):
    return sum(P[k] * log2(P[k] / Q[k]) for k in P if P[k] > 0)

px = {x: sum(v for (a, _), v in J.items() if a == x) for x in (0, 1)}
py = {y: sum(v for (_, b), v in J.items() if b == y) for y in (0, 1)}
HX, HY, HXY = H(px), H(py), H(J)
# 条件熵：对条件分布的熵加权平均（定义 1.3）——与 H(X,Y)-H(Y) 是两条独立路径
HX_Y = sum(py[y] * H({x: J[(x, y)] / py[y] for x in (0, 1)}) for y in (0, 1))
HY_X = sum(px[x] * H({y: J[(x, y)] / px[x] for y in (0, 1)}) for x in (0, 1))
I1, I2, I3 = HX - HX_Y, HY - HY_X, HX + HY - HXY
I_kl = KL(J, {(x, y): px[x] * py[y] for (x, y) in J})   # 边缘乘积分布
print("H(X)=%.6f H(Y)=%.6f H(X,Y)=%.6f | H(X|Y)=%.6f H(Y|X)=%.6f"
      % (HX, HY, HXY, HX_Y, HY_X))
print("I faces: %.6f %.6f %.6f | KL(joint||prod)=%.6f" % (I1, I2, I3, I_kl))
for a, b in ((I1, I2), (I2, I3), (I3, I_kl)):
    assert abs(a - b) < 1e-12
assert abs(I1 - 0.146793) < 1e-6 and abs(HX_Y - 0.734498) < 1e-6
# 记录一：交叉熵 = H + KL
P, Q = {0: 0.7, 1: 0.3}, {0: 0.5, 1: 0.5}
CE = -sum(P[k] * log2(Q[k]) for k in P)
assert abs(CE - (H(P) + KL(P, Q))) < 1e-12 and abs(CE - 1.0) < 1e-12
# 记录三：Y = X^2，相关为零、互信息为 H(Y)
cov = sum(x**3 for x in (-1, 0, 1)) / 3 - (sum((-1, 0, 1)) / 3) * (2 / 3)
pY = {0: 1 / 3, 1: 2 / 3}
assert abs(cov) < 1e-12 and abs(H(pY) - 0.918296) < 1e-6
print("cov(X, X^2) = %.1f  I(X; X^2) = H(Y) = %.6f" % (cov, H(pY)))
```

实跑输出：

```text
H(X)=0.881291 H(Y)=1.000000 H(X,Y)=1.734498 | H(X|Y)=0.734498 H(Y|X)=0.853207
I faces: 0.146793 0.146793 0.146793 | KL(joint||prod)=0.146793
cov(X, X^2) = 0.0  I(X; X^2) = H(Y) = 0.918296
```

读这段代码核对三件事：条件熵按「条件分布的熵加权平均」算而不是按 ${H(X, Y) - H(Y)}$ 算，两条路径独立、断言相等才是对链式法则的真验证；`I_kl` 那行对边缘乘积分布求 KL、与三副面孔相等是定理 2.4 的数值现身；末段 `cov` 为零而 `H(pY)` 不为零，是记录三的反例实跑。

**自己改着跑**：把 `J` 换成独立分布（如每格 0.25）会得到 ${I = 0}$ 且 ${H(X \mid Y) = H(X)}$；把 `J` 换成 ${\{(0, 0): 0.5, (1, 1): 0.5\}}$（$Y$ 完全复制 $X$）会得到 ${I = H(X) = H(Y) = 1}$、两个条件熵都是零——互信息的两个极端。

## $\rm \S \, 2.7$ 关键概念回顾

1. 互信息的三副面孔各是什么？从定义到第三副面孔用了链式法则的哪一种拆法？（§2.1）
2. 锚分布上 ${H(X \mid Y = 1)}$ 为什么大于 $H(X)$？这与「条件化不增熵」矛盾吗？（§2.2）
3. ${D(P \| Q) \ge 0}$ 的 Jensen 证明里两个不等号各要求什么才取等？合起来为什么推出 ${P = Q}$？（§2.3）
4. 互信息是哪两个分布之间的 KL 散度？由此「独立 ⟺ 互信息为零」怎么来？（§2.3）
5. 数据处理不等式的证明把 ${I(X; Y, Z)}$ 展开了几次？马尔可夫性杀掉的是哪一项？（§2.4）
6. 为什么分类任务的损失函数是交叉熵？它与 KL、与极大似然各是什么关系？（§2.5）

## $\rm \S \, 2.8$ 本章自测答案

1. ${H(X) - H(X \mid Y)}$、${H(Y) - H(Y \mid X)}$、${H(X) + H(Y) - H(X, Y)}$；用 ${H(X, Y) = H(Y) + H(X \mid Y)}$ 把 ${H(X \mid Y)}$ 换掉得第三副，再用另一种拆法得第二副。（§2.1）
2. ${Y = 1}$ 那一列是 ${(0.5, 0.5)}$，熵 1；不矛盾——定理说的是对 $Y$ 平均后 ${H(X \mid Y) = 0.734498 < 0.881291}$，具体条件可以反向。（§2.2）
3. Jensen 取等要 ${q/p}$ 在支撑上为常数，第二个不等号取等要 $Q$ 的质量全在 $P$ 的支撑上；合起来常数只能是 1，故 ${q = p}$。（§2.3）
4. 联合分布 ${p(x, y)}$ 与边缘乘积 ${p(x) p(y)}$；KL 为零当且仅当两分布相等，即联合等于乘积，即独立。（§2.3）
5. 两次：按 ${Y}$ 先 ${Z}$ 后得 ${I(X; Y) + I(X; Z \mid Y)}$，按 ${Z}$ 先 ${Y}$ 后得 ${I(X; Z) + I(X; Y \mid Z)}$；杀掉 ${I(X; Z \mid Y)}$。（§2.4）
6. 交叉熵＝熵＋KL，熵与参数无关，最小化交叉熵＝最小化 KL＝极大似然；MSE 对应高斯噪声假设，与离散标签的生成模型不符，且梯度在自信错误处饱和。（§2.5）

**带走清单**：互信息 ${I = H(X) - H(X \mid Y)}$ 三副面孔（链式法则两次）；锚 ${I = 0.146793}$、${H(X \mid Y) = 0.734498}$、${H(Y \mid X) = 0.853207}$；KL ${\ge 0}$（Jensen）、${I = D(\text{联合} \| \text{边缘积})}$；条件化减熵、条件互信息非负；DPI ${I(X; Z) \le I(X; Y)}$（链式法则两种顺序相减）、取等＝反向也马尔可夫＝充分；交叉熵＝熵＋KL、分类用交叉熵＝极大似然；互信息抓全部依赖、相关只抓线性。
