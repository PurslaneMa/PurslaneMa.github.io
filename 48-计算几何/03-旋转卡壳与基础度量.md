## $\rm \S \, 3.1$ 对踵点对：直径的家

白话：拿两把平行直尺从两侧夹住凸包，尺子压住的那对点叫对踵点对。直觉说最远的两颗钉子一定在某组方向的夹缝里被两把尺分别顶住——本章把这句直觉证成定理。

**定义（对踵点对）**：凸包顶点 ${u, v}$ 称为对踵点对，若存在两条平行直线分别过 $u$ 与 $v$，且凸包整体落在两线之间的带形里（两条都是**支撑线**：凸包在直线一侧）。

**引理 A（最远点是顶点）**：固定点 $u$，凸包边界上距 $u$ 最远的点是顶点。证：沿边 $\overline{pq}$ 写参数式 $v(t) = p + t(q-p)$，$t \in [0,1]$：

$$
\lvert v(t) - u\rvert^2 \;=\; \lvert q-p\rvert^2\, t^2 \;+\; 2\,(p-u)\cdot(q-p)\, t \;+\; \lvert p-u\rvert^2,
$$

读法：这是 $t$ 的二次三项式，二次项系数 $\lvert q-p\rvert^2 \ge 0$，开口向上——凸函数在闭区间上的最大值只能在端点取得。每条边都如此，故最远点必为顶点。这也解释了为什么本章的度量全部在凸包**顶点**上谈。

**引理 B（直径对是对踵点对）**：设 $\lvert u - v\rvert$ 是点集直径（最远点对）。对任意输入点 $w$，直径的最大性给出：

$$
\lvert w - v\rvert^2 - \lvert u - v\rvert^2 \;=\; \lvert w-u\rvert^2 \;+\; 2\,(w-u)\cdot(u-v) \;\le\; 0,
$$

整理得 $(w-u)\cdot(v-u) \ge \lvert w-u\rvert^2 / 2 \ge 0$：整包落在过 $u$ 且垂直于 $uv$ 的直线的同一侧——该线是支撑线；对称地，过 $v$ 的平行线也是。所以直径对按定义是对踵点对，两条支撑线恰好垂直于连线。

**引理 C（可取边贴合配置）**：对踵点对的支撑方向不必垂直连线——沿边贴合的配置也存在。从 $\perp uv$ 出发把两把平行的直尺同向旋转（各自仍压住自己的顶点）：一个顶点的支撑方向集是以其两条邻边方向为端点的角区间，旋转直到**先到头**的那把尺与某条邻边平行，此时另一把尺仍在支撑位置。于是「每条凸包边 × 对面最远点」的枚举把一切边贴合对踵配置——包括直径——一网打尽。

**本节小结**：最远点在顶点上（引理 A 的凸二次函数）、直径对带平行支撑线（引理 B 的四行代数）、贴合边的配置必存在（引理 C 的旋转段）；三步合起来，直径可以在「边 × 点」的枚举里找到——下一节把这个枚举从 $O(h^2)$ 压到 $O(h)$。

## $\rm \S \, 3.2$ 旋转卡壳：算法与全推导

白话：枚举「边 × 点」最朴素的做法是双循环 $O(h^2)$；卡壳的观察是——边按逆时针走，对面的最远点也只会逆时针走，**两个指针谁都不回头**，线性扫完。

**实现**（返回直径平方；与 §3.7 的暴力对账）：

```python
def diam2_calipers(H):                        # H: 凸包顶点逆时针
    n = len(H)
    j = 1
    best = 0
    for i in range(n):                        # 枚举每条边 H[i] -> H[i+1]
        a, b = H[i], H[(i+1) % n]
        while True:
            k = (j+1) % n
            if abs(cross(a, b, H[k])) > abs(cross(a, b, H[j])):
                j = k                         # 对面候选只进不退
            else:
                break
        for u in (a, b):                      # 边两端点各与对面候选配对
            d = (u[0]-H[j][0])**2 + (u[1]-H[j][1])**2
            if d > best:
                best = d
    return best
```

`while` 条件为什么用叉积：$\operatorname{cross}(a, b, v)$ 是三角形 $abv$ 面积的两倍，底边 $\overline{ab}$ 固定，面积单调等价于高单调、等价于 $v$ 到直线 $ab$ 的距离单调——**不开方就完成距离比较**，这是平方距离口径的直接兑现。

两条引理撑起正确性与复杂度。

**引理 D（单峰性）**：线性函数 $c \cdot x$ 沿凸多边形边界逆时针走一圈，先增后减。证：对阈值 $t$，集合 $\{x \in P : c \cdot x > t\}$ 是凸集（线性不等式的交）与凸多边形的交，仍凸；它与边界 $\partial P$ 的交是一段连续弧——沿边界一圈恰好进入一次、离开一次。取 $t$ 扫过函数值的全部取值范围即得：值沿边界只有一个峰。对卡壳而言，$c$ 取边 $\overline{ab}$ 的法向，$\operatorname{cross}(a,b,v)$ 关于 $v$ 正是线性函数——对面最远点沿顶点序列无第二峰，`while` 停下的地方就是真峰。

**引理 E（支撑点随旋转单调）**：方向 $c(\theta)$ 逆时针旋转时，$\max_x c(\theta) \cdot x$ 的 argmax 顶点沿边界逆时针单调移动、绝不回退。证分两段。小步段：把 $\theta$ 转动一小步 $\varepsilon$，与旧 argmax 打平的顶点集合恰是当前支撑面（一个顶点或一条边）；连续性保证其余顶点仍落后，新 argmax 要么不动、要么是该面上沿旋转方向更远的端点——即移动到相邻面。粘合段：整圈 $2\pi$ 是有限段小步，每段不动或前进，故 argmax 路径逆时针单调。（小步段是这条引理的全部难度，粘合段只是把局部规则累加成全局秩序。）

**复杂度推导。** 外圈 $h$ 条边；内层 `while` 的 $j$ 只逆时针前进，由引理 E 它从不需要回退，而绕凸包一圈至多 ${2h}$ 步——总推进 $O(h)$，加上外圈 $O(h)$，卡壳本体 $O(h)$。这正是第 2 章 §2.3 摊还账本的翻版：单次「一步弹两个 / 一步进两个」不怕，总量有界。带上建包，全流程 $O(n \log n)$。

**数值锚**（§3.7 复跑）：seed = 11 数据集（去重 28 点、凸包 8 顶点），卡壳与 $O(h^2)$ 全对暴力同报**直径平方 $689$**，最远点对 $((0,2),\ (20,19))$——凸包左下角与右上角，恰是 §2.5 预告的那对。

**本节小结**：卡壳 = 边 × 对踵点的无回退双指针；正确性靠单峰性（引理 D：峰唯一）、 $O(h)$ 靠支撑点单调（引理 E：指针不回头）；锚点 689 由两路独立复算钉死。

## $\rm \S \, 3.3$ 最小包围矩形一瞥与凸多边形面积

1. **最小面积外接矩形**：陈述级事实（Toussaint 1983）——最小面积外接矩形必有一条边与凸包某条边平行。理由的形状与引理 C 同款：若不贴任何边，把矩形沿凸包「卡住」的方向轻微旋转，面积严格减小，与最小性矛盾。于是枚举每条凸包边、卡壳四指针（对面最远点 ×3：另两侧与对边）维护定向矩形，$O(h)$ 出全部候选——同款卡壳，不同的问题。
2. **凸多边形面积**：第 1 章 §1.4 的鞋带公式直接用在本册顶点序上。锚（实测）：§2.4 的 8 顶点凸包，鞋带和 $746$，面积 $373$——这个数在第 2 章验收过凸包，在这里给外接矩形当参照物，一章一数两处用。

**本节小结**：卡壳是框架不是算法——换要维护的量（直径、矩形宽高），框架不变；面积 373 是两章共用的验收锚。

## $\rm \S \, 3.4$ 最近点对：分治全证

白话：卡壳管「最远」，最近点对（closest pair）管「最近」——分治是这个问题的经典答案：从中线劈两半各自递归，再只处理「骑在中线附近」的跨线对。

**框架**。全部点按 $x$ 排序，递归处理 $[l, r]$：中线 $m$（左半最右点的 $x$），两半递归得 $\delta = \min(\delta_L, \delta_R)$（平方距离口径 $\delta = \min(\delta_L^2, \delta_R^2)$，正文叙述按距离读）。跨线对 $(l, r)$ 若想打败 $\delta$，必有 $\lvert l_x - r_x\rvert < \delta$，于是**候选对的两点都落在条带** $\lvert x - m\rvert < \delta$ 内——半宽 $\delta$，整宽 $2\delta$。把条带点按 $y$ 排序（预排序合并而来），对每点只查 $y$ 方向落后的候选。

防坑一句：条带半宽必须是 $\delta$，**不是 $\delta/2$**——有的笔记写窄了。反例当场可构：$l$ 在左半、离中线 $0.8\delta$，$r$ 在右半、离中线 $0.1\delta$，$\Delta y = 0.4\delta$，两点距离 $\sqrt{0.9^2 + 0.4^2}\,\delta \approx 0.985\,\delta < \delta$，是合法的更近对，但 $l$ 不在半宽 $\delta/2$ 的条带里——窄条带会**漏解**。§3.7 的代码用整宽口径。

**七邻论证（全证）。** 考察点 $p$ 与条带中它之后的点：只需查 $\Delta y < \delta$ 的（距离下界 $\lvert\Delta y\rvert$），这些点落在 $p$ 上方、宽 $2\delta$ 高 $\delta$ 的窗口里。把窗口切成 $4 \times 2$ 个边长 $\delta/2$ 的方格，**格线对齐中线**——于是每格只含一侧的点。同一侧的任意两点距离 $\ge \delta$（递归的归纳假设），而同一方格内两点距离 $\le \delta\sqrt{2}/2 < \delta$——矛盾，故**每格至多 1 点**。窗口至多 $8$ 点、其中之一是 $p$ 自己：每个点至多与后续 **7** 个点比较。这就是「查 7 邻」的全部内容——不是玄学常数，是 packing 论证数出来的格数减一。

**复杂度**。预排序（按 $x$、按 $y$ 各一次）之后，每层递归的条带抽取与 $y$ 有序合并都是线性：

$$
T(n) \;=\; 2\,T\!\left(\tfrac{n}{2}\right) \;+\; O(n) \quad\Longrightarrow\quad T(n) \;=\; O(n \log n),
$$

读法：主定理的「两半加线性合并」一层——不做预排序、每层现场排序则退化为 $O(n \log^2 n)$，预排序是这道题「配得上 $O(n \log n)$」的关键动作。算法出自 Shamos 与 Hoey（1976），CLRS 第 33 章 §33.4 是标准表述。

**数值锚**（§3.7 复跑）：seed = 11 去重 28 点，分治与 $O(n^2)$ 暴力同报最小平方距离 $1$，点对 $((6,16),\ (7,16))$；全局并列的最小对共 $4$ 对（暴力数出），分治报告其一即算对——最小值的**值**一致是验收标准。

**本节小结**：最近点对 = 分两半递归加条带修补；条带半宽 $\delta$ 是防坑点，七邻是 packing 数出来的常数，$O(n \log n)$ 靠预排序守住。至此平面点集的基础度量——最远、外接、最近——配齐。

## $\rm \S \, 3.5$ 出口：更高维与随机增量

1. **kd 树**：维度一高，「先建包再卡壳」的把戏失效（高维凸包顶点数爆炸），最近邻改由空间划分结构承担——kd 树按维度轮换切分，$O(\log n)$ 平均查询，是「最近点对」从一问变成一类的通用底座，本册第 6 章出口章展开。
2. **Welzl 最小包围圆**：平面最小包围圆有比卡壳更漂亮的算法——随机增量：点随机顺序逐个加入，当前圆装不下新点时该点必在新圆边界上，递归重解（Welzl 1991，《New Results and New Trends in Computer Science》，LNCS 555），期望 $O(n)$。陈述级收录于此，为的是记住一个反差：同一个「最小包围」问题，凸包+卡壳与随机增量是两条完全独立的武器。
3. **收束**：前三章完成了「基元可信（第 1 章）→ 骨架可建（第 2 章）→ 度量可量（本章）」，第 4 章起进入相交与扫描线的动态世界。

**本节小结**：维度升维换 kd 树、包围换随机增量——卡壳在平面度量里的统治到此为止，出口已备好。

## $\rm \S \, 3.6$ 六问与答

1. 为什么直径对必是对踵点对？（答：引理 B 四行代数——直径最大性给出 $(w-u)\cdot(v-u) \ge \lvert w-u\rvert^2/2 \ge 0$，过 $u$ 垂直于 $uv$ 的直线是支撑线，过 $v$ 的平行线同理。）
2. 卡壳的 `while` 条件为什么用叉积面积不用距离？（答：底边固定时面积单调 ⇔ 高单调 ⇔ 距离单调，全程不开方——平方距离口径。）
3. $j$ 为什么永不回退？总推进量是多少？（答：引理 E——支撑点随方向逆时针旋转单调前进；一圈至多 ${2h}$ 步，卡壳本体 $O(h)$。）
4. 最近点对条带的半宽为什么是 $\delta$ 不是 $\delta/2$？（答：$l$ 离中线 $0.8\delta$、$r$ 离 $0.1\delta$、$\Delta y = 0.4\delta$ 的对距离 $0.985\delta < \delta$，窄条带把它漏掉。）
5. 七邻的「7」从哪来？（答：$2\delta \times \delta$ 窗口切成 8 个 $\delta/2$ 方格、格线对齐中线使每格单侧、同侧两点距 $\ge \delta$ 而同格距 $< \delta$，每格至多 1 点——8 点减自己。）
6. $T(n) = 2T(n/2) + O(n)$ 里的 $O(n)$ 靠什么兑现？（答：预排序——$y$ 序在递归间线性归并，条带抽取线性；不预排序每层现场排序退化 $O(n \log^2 n)$。）

## $\rm \S \, 3.7$ 程序段：卡壳对账暴力、分治对账暴力

纯 Python，无依赖；凸包函数与第 2 章相同（复制于此保证脚本独立可跑）。

```python
import random

def cross(o, a, b):
    return (a[0]-o[0])*(b[1]-o[1]) - (a[1]-o[1])*(b[0]-o[0])

def hull_andrew(points):
    pts = sorted(set(points))
    if len(pts) <= 2:
        return pts
    def chain(seq):
        st = []
        for q in seq:
            while len(st) >= 2 and cross(st[-2], st[-1], q) <= 0:
                st.pop()
            st.append(q)
        return st
    lo = chain(pts)
    up = chain(pts[::-1])
    return lo[:-1] + up[:-1]

def diam2_brute(P):
    return max((a[0]-b[0])**2 + (a[1]-b[1])**2
               for i, a in enumerate(P) for b in P[i+1:])

def diam2_calipers(H):                        # H: 凸包顶点逆时针
    n = len(H)
    j = 1
    best = 0
    for i in range(n):
        a, b = H[i], H[(i+1) % n]
        while True:
            k = (j+1) % n
            if abs(cross(a, b, H[k])) > abs(cross(a, b, H[j])):
                j = k                         # 对面候选只进不退
            else:
                break
        for u in (a, b):
            d = (u[0]-H[j][0])**2 + (u[1]-H[j][1])**2
            if d > best:
                best = d
    return best

def d2(a, b):
    return (a[0]-b[0])**2 + (a[1]-b[1])**2

def closest_dc(points):                       # 返回 (最小平方距离, 点对)
    P = sorted(set(points))
    Px = P
    Py = sorted(P, key=lambda q: (q[1], q[0]))
    def rec(px, py):
        n = len(px)
        if n <= 3:
            best = (float("inf"), None, None)
            for i in range(n):
                for j in range(i+1, n):
                    if d2(px[i], px[j]) < best[0]:
                        best = (d2(px[i], px[j]), px[i], px[j])
            return best
        mid = n // 2
        mx = px[mid][0]
        Lx, Rx = px[:mid], px[mid:]
        Ls = set(Lx)
        Ly = [q for q in py if q in Ls]
        Ry = [q for q in py if q not in Ls]
        best = min(rec(Lx, Ly), rec(Rx, Ry), key=lambda t: t[0])
        delta = best[0]                       # 平方口径
        strip = [q for q in py if (q[0]-mx)**2 < delta]   # 条带半宽 sqrt(delta)
        for i in range(len(strip)):
            for j in range(i+1, len(strip)):
                if (strip[j][1]-strip[i][1])**2 >= delta:
                    break                     # y 窗口封顶
                if d2(strip[i], strip[j]) < best[0]:
                    best = (d2(strip[i], strip[j]), strip[i], strip[j])
        return best
    return rec(Px, Py)

def closest_brute(P):
    best = (float("inf"), None, None)
    for i in range(len(P)):
        for j in range(i+1, len(P)):
            if d2(P[i], P[j]) < best[0]:
                best = (d2(P[i], P[j]), P[i], P[j])
    return best

random.seed(11)
pts = [(random.randint(0, 20), random.randint(0, 20)) for _ in range(30)]
S = sorted(set(pts))
H = hull_andrew(pts)

print("hull size:", len(H))
print("diam2 brute   :", diam2_brute(S))
print("diam2 calipers:", diam2_calipers(H))
dbest = max((d2(a, b), a, b) for i, a in enumerate(H) for b in H[i+1:])
print("diam pair:", dbest[1], dbest[2])

dc = closest_dc(S)
bf = closest_brute(S)
ties = sum(1 for i in range(len(S)) for j in range(i+1, len(S)) if d2(S[i], S[j]) == bf[0])
print("closest dc   :", dc[0], dc[1], dc[2])
print("closest brute:", bf[0], bf[1], bf[2])
print("ties at min:", ties)
```

## $\rm \S \, 3.8$ 带走清单

1. 对踵点对 = 平行支撑线压住的顶点对；直径对必是对踵点对（引理 B 的四行代数），且存在边贴合配置（引理 C 的旋转段）——所以「边 × 对面点」的枚举完备。
2. 最远点必在顶点上：距离沿边是开口向上的二次函数（引理 A），凸函数最大值在端点。
3. 卡壳 = 无回退双指针：单峰性（引理 D 的凸弧论证）保证 `while` 停在真峰，支撑点旋转单调（引理 E 的小步加粘合）保证 $j$ 不回头，本体 $O(h)$、全流程 $O(n \log n)$。
4. 锚点：seed = 11 数据直径平方 $689$、点对 $((0,2),(20,19))$，卡壳与暴力双路一致；凸包面积 $373$ 两章共用。
5. 最小面积外接矩形必有一边贴凸包边（Toussaint 1983），四指针卡壳 $O(h)$ 枚举——卡壳是框架，换维护的量就换问题。
6. 最近点对分治：条带半宽 $\delta$（不是 $\delta/2$，防坑注），七邻 = 8 格 packing 减自己，$T(n) = 2T(n/2) + O(n) = O(n \log n)$ 靠预排序兑现；锚点最小平方距离 $1$、点对 $((6,16),(7,16))$、并列 4 对。
7. 出口：升维换 kd 树（第 6 章）、最小包围圆换 Welzl 随机增量（1991，期望 $O(n)$）。
