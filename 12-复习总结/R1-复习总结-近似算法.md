# R1 复习总结：近似算法

六章压成三句话：**比值与谱系**（第 1—2 章）——近似比 $\rho$ 的两种口径、下界证书的思路，贪心与交换论证给出第一批常数比（顶点覆盖 2、集合覆盖 $H_n$、LPT $4/3$）；**松弛与向量化**（第 3—5 章）——LP 松弛给出下界与舍入（$LP^* \le OPT \le \rho \cdot LP^*$ 四数链）、原始对偶把「同时维护两侧可行」变成对账、SDP 把标量升级成向量（GW 的 0.878567）、度量 TSP 的 1.5（匹配下界的关键账）；**下界之墙**（第 6 章）——PCP 与间隙保持归约解释「为什么某些问题连 0.9 都到不了」。验收标准：闭卷清单答出几成、§R1.3 六条心智模型能默几条。

## $\rm \S \, R1.3$ 核心心智模型复读

1. **比值是相对保证**：$\rho$-近似是与 OPT 的比例关系，不是绝对误差——因为 OPT 本身未知。
2. **下界证书**：证明近似比必须同时给出「算法解」与「OPT 的下界」；松弛（LP/SDP）是最通用的下界工厂。
3. **舍入＝从分数到整数**：松弛解是分数、真解是整数；舍入的代价换取可行性，$f$-舍入是「频次当税」。
4. **对偶是同时维护两侧**：原始对偶算法一边涨原始解一边涨对偶解，比值 ≤ ρ 时就地收网。
5. **向量化升级**：LP 到 SDP 是把标量换向量——约束更强、下界更紧，GW 的 0.878 就从这来。
6. **下界之墙**：PCP 说「某些间隙是 NP 难的」——不是算法不够聪明，是问题本身不给机会。

## $\rm \S \, R1.4$ 交错练习

1. 顶点覆盖的 2-近似在 $K_{n,n}$ 上的比值？（答：趋 2，紧例）
2. 集合覆盖贪心在 $f$-频次实例上的比值上界？（答：$H_n \le \ln n + 1$）
3. C5 上最大割的最优值与 GV 对称嵌入的期望割？（答：OPT = 4；对称嵌入期望 = 2.0，与 $5 \times (72/180)$ 吻合——不等于 GW 保证违例）
4. Christofides 的 1.5 里，匹配那笔账为什么是 $OPT/2$？（答：奇度点集在最优圈上的两交错匹配之一 ≤ 半圈长）
5. 度量 TSP 去掉三角不等式后还能常数近似吗？（答：不能，第 6 章下界）
6. PCP 定理里的「常数个比特」指什么？（答：验证者随机查常数个位即可判 3SAT 证书）
7. min 问题的 $LP^*$ 与 ${OPT}$ 的方向？（答：$LP^* \le OPT$）

## $\rm \S \, R1.5$ 易混点对照

1. **近似比 min vs max 口径**：min 问题 $\rho = ALG/OPT \ge 1$（越小越好）；max 问题 $\rho = OPT/ALG \le 1$（越大越好）——写反就全错。
2. **$LP^*$ 的方向**：min 问题松弛放宽可行域 ⟹ $LP^* \le OPT$（是下界）；max 问题才 $\ge$。
3. **PTAS vs FPTAS**：前者 $(1+\epsilon)$ 多项式（$\epsilon$ 固定）；后者对 $1/\epsilon$ 也多项式。
4. **随机舍入 vs 确定性舍入**：GW 是随机（期望比），顶点覆盖 $1/2$-舍入是确定（阈值）；条件期望可把前者去随机化。
5. **间隙保持 vs 普通归约**：前者要同时保持「满足度间隙」，才能把近似困难性搬过去。
6. **乘积 vs 加性误差**：近似算法谈乘积（比值），数值分析谈加性——两个「精度」不是一个概念。

## $\rm \S \, R1.6$ 答案与提示

### 闭卷回忆清单

1. min：$ALG \le \rho OPT$；max：$ALG \ge \rho OPT$；比值无量纲、可乘、与规模无关。（§1.1）
2. 给不出 OPT 就算出一个「比 OPT 还小的下界」；若 $ALG \le \rho \cdot LB \le \rho OPT$ 即证。（§1.2）
3. 链条 FPTAS ⊂ PTAS ⊂ APX ⊂ log-APX；PCP 说明某些问题无 PTAS（除非 P = NP）。（§1.3）
4. 每边被切概率 1/2 ⟹ 期望 ≥ m/2；$OPT \le m$ ⟹ 比 ≤ 1/2。（§1.4）
5. 极大匹配 |M|；覆盖 = 2|M|；匹配互不相交 ⟹ OPT ≥ |M|；紧例 $K_{n,n}$。（§2.1）
6. 第 $i$ 个新覆盖的元素摊 $1/(n-i+1)$，求和 ≤ $H_n$。（§2.2）
7. 临界作业是最大作业或其后的作业；两情形都给 ≤ $(4/3 - 1/(3m))OPT$。（§2.3）
8. 取贪心与最优的第一个分歧处、做局部交换、证明损失受控、迭代到无分歧、结论。（§2.3）
9. $LP^* \le OPT$；四数链 $LP^* \le OPT \le ALG \le \rho\, LP^*$。（§3.1、§3.5）
10. $x_i = 1$ 若 $x^*_i \ge 1/f$：每个被覆盖元素至少一个 $x^* \ge 1/f$；代价 ≤ $f \sum x^*$。（§3.2）
11. 同时维护原始与对偶可行解，比值 ≤ ρ 即停；对偶拟合：用对偶变量定价再舍入。（§3.4）
12. 异侧概率 = 夹角/π（球面随机超平面的几何概率）；$\alpha$ 是 $\frac{2\theta}{\pi(1-\cos\theta)}$ 的最小值，谷底 $\theta \approx 2.331$ rad = 133.6°。（§4.3）
13. $MST \le OPT$；匹配 ≤ $OPT/2$（交错匹配论证）；三角不等式把欧拉回路抄近路不增长度。（§5.3）
14. NP = PCP(log n, 1)；间隙保持要同时保持满足度与不可满足时的间隙比。（§6.1—6.2）
