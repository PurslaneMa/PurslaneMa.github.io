## $\rm \S \, 8.1$ 动机：从谱隙到电阻

第 12 章问「图上的交通快不快」，答案挂在特征值上；本章换一副物理学的问法：**图上的路网挤不挤**。比喻：两座城市之间修路，路修得越多越宽，走起来越不堵——「拥挤程度」这个量，电学工程师叫它有效电阻，随机游走理论叫它通勤时间的单价。先把双语词典摆在桌面上（每一条都在后面各节兑现）：

| 电网络 | 随机游走 |
| --- | --- |
| 电压 $v$（节点电势） | 击中概率；访问次数除以度数（§8.2、§8.4） |
| 电流 $i$（边上的流） | 概率流：期望净穿越次数（§8.4） |
| 有效电阻 $R_{\mathrm{eff}}$ | 通勤时间除以 ${2m}$（§8.4 定理 8.6） |

词典不是修辞，是可证的恒等式。预告两端的数值锚（§8.7 真算）：完全图 $K_n$ 上任意两点 $R_{\mathrm{eff}} = \frac{2}{n}$，通勤时间 ${2(n-1)}$——路网最宽，来回一趟约 ${2n}$ 步，与第 12 章「扩张图混合只要对数步」对上；一条 $n$ 个顶点的链，两端 $R_{\mathrm{eff}} = n - 1$，通勤 ${2(n-1)^2}$——唯一的路又窄又长，正是「环上游走要 $n^2$ 步」的电阻版。两极之间，扩张图靠近便宜的一端。

**小结**：本节立了双语词典与动机——图论的速度问题在电学里是拥挤问题；下面从语法开始逐条兑现。

## $\rm \S \, 8.2$ 电网络语法：电压是调和函数，电流是概率流

白话：先把电路的规矩写下来，再发现规矩的后半句恰好是马尔可夫链的语言。设 $G$ 是连通图、$n$ 个顶点、$m$ 条边，每条边是 $1\,\Omega$ 电阻。在节点 $a$ 注入 $1\mathrm{A}$ 电流、从节点 $b$ 抽走，稳态下每个节点 $x$ 有电压 $v(x)$；流过边 $\{x, y\}$（方向 $x \to y$）的电流由欧姆定律（电导为 1，无系数）给出：$i(x, y) = v(x) - v(y)$，且 $i(x, y) = -i(y, x)$。电学只关心两件事：基尔霍夫节点定律（内部节点不存电）与欧姆定律（本式）。

1. **节点定律 $=$ 调和性，一行等价。** 内部节点 $x$（非 ${a, b}$）净电流为零：

$$
0 = \sum_{y \sim x} i(x, y) = \sum_{y \sim x} \big(v(x) - v(y)\big) = d(x)\,v(x) - \sum_{y \sim x} v(y),
$$

整理即 $v(x) = \frac{1}{d(x)} \sum_{y \sim x} v(y)$：**电压在内部节点等于邻居平均值**——这正是「调和函数」的定义。所谓「电压是调和函数」，就是基尔霍夫定律改了个写法，没有新增物理。

2. **命题 8.1（极大值原理）**：设 $v$ 在连通图上于 $V \setminus \{a, b\}$ 内调和、在 ${a, b}$ 两点取边界值，则 $v$ 的最大值在边界上取到。证明：反设内部节点 $x$ 处 $v(x) = M$ 且 $M$ 超过两端边界值。调和性说 $M$ 是邻居值的平均，而每个邻居值 $\le M$——平均值追平上界当且仅当每个邻居都等于 $M$。于是极大值传染给全部邻居；由连通性一路传播，$v \equiv M$ 处处成立，连 ${a, b}$ 也是 $M$，矛盾。最小值同理（对 $-v$ 用一遍）。$\blacksquare$

读法：这一步是全章的裁判——「等号成立要求每个邻居都取到」这个非严格性，是离散世界送的低门槛礼物，它让唯一性论证两行收工。

3. **命题 8.2（击中概率 $=$ 电压，完整证明）**：设 $T_u = \min\{t \ge 0 : X_t = u\}$ 是首达时，则 $\Pr_x[T_a < T_b] = v(x)$，其中 $v$ 是边界值 $v(a) = 1$、$v(b) = 0$、内部调和的唯一解。证明四步。第一步（边界）：$\Pr_a[T_a < T_b] = 1$（$T_a = 0$ 先到）、$\Pr_b[T_a < T_b] = 0$，边界值对上。第二步（第一步分析）：对 $x \ne a, b$，按第一步落点用全概率公式拆开：

$$
\Pr_x[T_a < T_b] = \sum_{y \sim x} \Pr_x[X_1 = y]\,\Pr_y[T_a < T_b] = \frac{1}{d(x)} \sum_{y \sim x} \Pr_y[T_a < T_b],
$$

读法：走到 $y$ 之后强马尔可夫性接手——从 $y$ 出发的后续游走与过去独立，所以第二个因子就是「从 $y$ 出发」的击中概率。这说明 $h(x) := \Pr_x[T_a < T_b]$ 内部调和、边界值同 $v$。第三步（唯一性）：$h - v$ 内部调和、边界值为零；若它内部有非零点，则取到非零的最大或最小值，命题 8.1 禁止——故 $h \equiv v$。第四步：结论即得。$\blacksquare$

读法：**随机游走在用蒙特卡洛解拉普拉斯方程**。工程师解节点电压要动线性方程组；随机游走者什么方程都不解，只是瞎走，走出来的击中频率自动收敛到同一组数——概率是电路的免费数值解。

4. **电流 $=$ 概率流。** 把命题 8.2 代回欧姆定律：$i(x, y) = v(x) - v(y) = \Pr_x[T_a < T_b] - \Pr_y[T_a < T_b]$——边上的电流是两端击中概率之差。直观读法：游走者从便宜的方向走得多、从贵的方向走得少，净流量恰好是概率差；电流的流向就是游走的偏流方向。

**小结**：本节建立语法——基尔霍夫给出「电压 $=$ 调和函数」，极大值原理给唯一性，第一步分析把击中概率送进同一位置，电流读成概率流；下一节定义本章的主角：有效电阻。

## $\rm \S \, 8.3$ 有效电阻：串联、并联与对称性

白话：有了电压语法，「两点之间的拥挤程度」可以定义了。

**定义 8.3（有效电阻）**：$R_{\mathrm{eff}}(a, b) := v(a) - v(b)$，其中 $v$ 是「$a$ 注入 $1\mathrm{A}$、$b$ 抽走」问题的电压解。读法：挤 $1\mathrm{A}$ 电流过网络，看两点间要垫多高的电压差——路网越宽裕，垫的越少；比喻里它就是「两城市之间修路的拥挤程度」。由解的唯一性（命题 8.1 同款论证），这个数良定义，且反向注入的解是 $-v$ 加常数，故 $R_{\mathrm{eff}}(a, b) = R_{\mathrm{eff}}(b, a)$。

1. **串联与并联。** 两条路各 $R_1, R_2$ 首尾相接，同一电流依次穿过，电压差相加：$R = R_1 + R_2$（串联）。两条路并排接在同样的两端，电压差共用、电流按电导分摊：$\frac{1}{R} = \frac{1}{R_1} + \frac{1}{R_2}$（并联）；$m$ 条 $1\,\Omega$ 并联给出 $\frac1m$——「路多便宜」的定量版。
2. **星–三角变换（陈述级）。** 三条电阻 $r_{12}, r_{23}, r_{13}$ 接成三角形，与中心加一个新节点、三条臂 $s_1, s_2, s_3$ 接成星形，在三个外端之间等效，条件是 $s_1 = \frac{r_{12} r_{13}}{r_{12} + r_{13} + r_{23}}$（轮换对称）。验证口径：单位电阻三角形上 $R(1, 2) = 1 \parallel 2 = \frac23$（直达 $1\,\Omega$ 与绕行 $2\,\Omega$ 并联）；换成星形（每臂 $s = \frac{1 \cdot 1}{3} = \frac13$）得 $R(1, 2) = \frac13 + \frac13 = \frac23$，两口径咬合。完整推导见 Doyle–Snell《Random Walks and Electric Networks》第 2 章。用途：星–三角是「缩图」手术刀，把网状结构一片片削成串并联；不过更锋利的常常是对称性。
3. **立方体的对径点：$\frac56$，对称性全程推导。** 立方体 $Q_3$（8 顶点 12 边），$1\mathrm{A}$ 从 $000$ 进、$111$ 出。立方体的自同构保持距离，按到 $000$ 的距离分层，同层同电压：$v(000) = c_0$，距离 1 层 $c_1$，距离 2 层 $c_2$，$v(111) = 0$（钉零）。数电流：$c_0$ 的三条边对称平摊 $1\mathrm{A}$，每条 $\frac13$，故 $c_0 - c_1 = \frac13$；距离 1 层每个点（如 $001$）收到 $\frac13$，向两个距离 2 邻居对称各排 $\frac16$，故 $c_1 - c_2 = \frac16$；距离 2 层每个点收两条 $\frac16$ 共 $\frac13$，全排给 $111$，故 $c_2 - c_3 = \frac13$。沿任一条最短路把电压差加起来：$R_{\mathrm{eff}}(000, 111) = \frac13 + \frac16 + \frac13 = \frac56$。读法：全程没解方程组——对称性把 8 个未知电压压成 2 个自由度，每层电流守恒逐层报出差额；对称性是最好的缩图术。
4. **立方体的相邻点：$\frac{7}{12}$，对称类消元。** $1\mathrm{A}$ 从 $000$ 进、$001$ 出（一对邻点）。按到这对点的对称性分四类：$A = \{011, 101\}$（到两点等距）、$B = \{010, 100\}$、$C = \{110\}$、$D = \{111\}$，电压记 ${a, b, c, d}$，$v(001) = 0$。逐类写电流守恒（$A$ 类点邻居是 $001$、一个 $B$ 类点、$111$，余类推）：

$$
3a = b + d, \qquad 3b = v(000) + a + c, \qquad 3c = 2b + d, \qquad 3d = 2a + c,
$$

外加注入点的总电流 $\big(v(000) - 0\big) + 2\big(v(000) - a\big) + 2\big(v(000) - b\big) = 1$。消元：由第一、四式把 $d = 3a - b$ 与 $c = 3b - v(000) - a$ 代入第三式，得 $v(000) = 6b - 8a$；代回解出 $b = \frac{9a}{5}$，于是 $v(000) = \frac{14a}{5}$；最后由注入方程 $6a = 1$ 收出 $a = \frac16$，故 $R_{\mathrm{eff}}(000, 001) = v(000) = \frac{7}{12}$。numpy 解原始方程组给出 $0.5833 \ldots$（§8.7 表一），咬合。
5. **完全图 $K_n$：$\frac2n$，两个未知数收工。** $1\mathrm{A}$ 从 $a$ 进、$b$ 出。除 ${a, b}$ 外其余 $n - 2$ 个点对称同类，电压 $y$；设 $v(a) = x$、$v(b) = 0$。中间点守恒：邻居为 $a$、$b$ 与 $n - 3$ 个同类点（同类点之间电压差为零），得 $(y - x) + (y - 0) = 0$，即 $y = \frac{x}{2}$。注入点守恒：$x + (n-2)\big(x - \frac{x}{2}\big) = 1$，即 $\frac{n}{2}x = 1$。解出 $R_{\mathrm{eff}}(a, b) = x = \frac{2}{n}$。读法：$n$ 越大越便宜——完全图是「交通的天堂」，拥挤程度随人口增加反而下降，因为每加一个人就多修了 $n - 1$ 条路。

**小结**：本节定义了主角 $R_{\mathrm{eff}}$，用串并联、星–三角与对称性把标准例子算成闭式——工具是「对称压未知数、守恒列方程」；下一节把它与通勤时间焊死。

## $\rm \S \, 8.4$ 通勤时间恒等式：核心引理与完整证明

白话：$R_{\mathrm{eff}}$ 是电学量，通勤时间 $\mathrm{E}_x[T_y] + \mathrm{E}_y[T_x]$ 是概率量，两者的桥是一句话——**电流就是访客流**：把随机游走者当成电子，边上的电流恰好是游走者期望净穿越次数。这个引理证完，恒等式就是一次求和。

**引理 8.4（访客计流）**：设游走从 $a$ 出发，$\tau = T_b$ 为首次到达 $b$ 的时刻。对每条有向边 $\vec{xy}$ 记 $N(\vec{xy})$ 为停止前穿越该有向边的次数；记 $G_a(z) = \mathrm{E}_a\big[\#\{0 \le t < \tau : X_t = z\}\big]$（访问 $z$ 的期望次数，$G_a(b) = 0$）。定义

$$
i(\vec{xy}) = \mathrm{E}\big[N(\vec{xy})\big] - \mathrm{E}\big[N(\vec{yx})\big], \qquad v(z) = \frac{G_a(z)}{d(z)},
$$

则 $i(\vec{xy}) = v(x) - v(y)$，且 $i$ 是从 $a$ 到 $b$ 的单位电流流；特别地 $v(a) - v(b) = R_{\mathrm{eff}}(a, b)$，而 $v(b) = 0$ 给出 $\frac{G_a(a)}{d(a)} = R_{\mathrm{eff}}(a, b)$。

证明三步。第一步（访问数折算成穿越数）：每次游走停在 $z$，下一步等概率走往 $d(z)$ 个邻居、与过去独立；对每个访问时刻用期望线性性，$\mathrm{E}\big[N(\vec{zy})\big] = \frac{G_a(z)}{d(z)}$，两方向相减即 $i(\vec{xy}) = \frac{G_a(x)}{d(x)} - \frac{G_a(y)}{d(y)} = v(x) - v(y)$——欧姆定律成立。第二步（节点定律逐路径成立）：对每个具体实现，内部节点 $z \ne a, b$ 的每次到访一进一出、首尾又都在 ${a, b}$，故到达次数 $=$ 离开次数，$\sum_y \big(N(\vec{zy}) - N(\vec{yz})\big) = 0$ 逐路径成立，取期望仍是零；在 $a$ 处从出发到终结，离开次数 $=$ 到达次数 $+ 1$（多出的是 $t = 0$ 那次起跑），故 $\sum_y i(\vec{ay}) = 1$；在 $b$ 处 $= -1$。第三步（唯一性）：满足欧姆定律、节点定律、单位源汇的流唯一——两条这样的流电压相减，得内部调和且两端同值的函数，命题 8.1 压它恒零。于是 ${i, v}$ 就是那个单位电流问题，$v(a) - v(b) = R_{\mathrm{eff}}(a, b)$。$\blacksquare$

读法：第一步把「每访问一次、期望摊出 $\frac1{d(z)}$ 次去 $y$」逐时刻加总；第二步的净流量是逐路径恒等式而非仅期望意义——这正是电流与概率流的对应精确到每条边的原因。

**推论 8.5（逃离概率）**：记 $\tau_a^+$ 为首次返回 $a$ 的时刻（$t \ge 1$），则

$$
\Pr_a\big[T_b < \tau_a^+\big] = \frac{1}{d(a)\,R_{\mathrm{eff}}(a, b)}.
$$

证明：引理给出「到达 $b$ 之前回到 $a$ 的期望次数」$G_a(a) = d(a) R_{\mathrm{eff}}(a, b)$。换个记账法：每次站在 $a$（含 $t = 0$）是一次尝试——以概率 $p = \Pr_a[T_b < \tau_a^+]$ 逃出去直接成功，否则先回 $a$ 再试；尝试次数是成功概率 $p$ 的几何分布，期望 $\frac{1}{p}$。两种记账必须相等：$\frac{1}{p} = d(a) R_{\mathrm{eff}}(a, b)$。$\blacksquare$

读法：电阻大 $=$ 出门难。立方体上 $d(000) = 3$、$R_{\mathrm{eff}}(000, 001) = \frac{7}{12}$，逃离概率 $= \frac{1}{3 \cdot \frac{7}{12}} = \frac47 \approx 0.571$——门口三条路，挤出去比回来的期望略占上风。

**定理 8.6（通勤时间恒等式）**：对连通图 $G$（$m$ 条边）与任意两点 ${x, y}$：

$$
\mathrm{E}_x[T_y] + \mathrm{E}_y[T_x] = 2m\,R_{\mathrm{eff}}(x, y).
$$

证明三步。第一步（期望步数 $=$ 访问总数）：每个时刻 $0 \le t < \tau$ 游走恰站在一个顶点上，逐路径 $\tau = \sum_z \#\{t < \tau : X_t = z\}$，取期望并用引理 8.4 的电压：$\mathrm{E}_x[T_y] = \sum_z G_x(z) = \sum_z d(z)\,v(z)$，其中 $v$ 是「$x$ 注入、$y$ 抽走」的电压解，且 $v(y) = 0$、$v(x) = R_{\mathrm{eff}}(x, y)$。第二步（镜像恒等式）：反向问题里把电压换成 $\tilde v(z) = R - v(z)$（$R = R_{\mathrm{eff}}(x, y)$）：它内部调和（常数减调和），边界 $\tilde v(x) = R - R = 0$、$\tilde v(y) = R - 0 = R$，且它对应的流是 $-i$（欧姆定律逐边验证：$\tilde v(u) - \tilde v(w) = v(w) - v(u)$），恰是从 $y$ 到 $x$ 的单位电流；由唯一性它就是反向问题的解。于是对称地 $\mathrm{E}_y[T_x] = \sum_z d(z)\,\tilde v(z) = \sum_z d(z)\big(R - v(z)\big)$。第三步（合并）：两式相加，电压 profile 正负抵消，只剩常数：

$$
\mathrm{E}_x[T_y] + \mathrm{E}_y[T_x] = \sum_z d(z)\,\big(v(z) + R - v(z)\big) = R \sum_z d(z) = 2m\,R,
$$

末步用度数和 $\sum_z d(z) = 2m$。$\blacksquare$

读法：**通勤时间 $=$ 边数 $\times$ 电阻**，一步不多一步不少。完全图：$m = \frac{n(n-1)}{2}$、$R = \frac2n$，通勤 $= {2(n-1)}$——从任一点到任一点来回一趟约 ${2n}$ 步，均匀得不在乎去哪；链：两端 $R = n-1$、$m = n-1$，通勤 ${2(n-1)^2}$——第 12 章「环上 $n^2$ 对扩张图对数」的对比在电阻语言里原样重现。数值验收见 §8.7 表二：立方体上 ${2 \times 12 \times \frac{7}{12}} = 14$，十万轮模拟均值 $14.029$。本证明的完整出处是 Levin–Peres《Markov Chains and Mixing Times》第 9 章（Theorem 9.6 及其访客计数论证）；连续空间版本（电路与布朗运动）见 Lyons–Peres《Probability on Trees and Networks》。

**小结**：本节交付核心恒等式——访客计流引理把电流翻译成访问次数，镜像恒等式让双向通勤对账，求和只剩 ${2mR}$；下一节把同一套语言接到生成树上。

## $\rm \S \, 8.5$ 生成树与转移电流定理

白话：生成树是图的最省骨架——$n - 1$ 条边连起全部顶点。均匀随机抽一棵树，每条边被抽中的概率是多少？答案出人意料地电学：**就是电流**。

**定理 8.7（转移电流定理，陈述级）**：单位电阻网络 $G$ 上，$T$ 为均匀随机生成树，$e = \{x, y\}$ 为任一条边，则 $\Pr[e \in T] = i_e$，其中 $i$ 是「$x$ 注入 $1\mathrm{A}$、$y$ 抽走」的单位电流流、$i_e$ 为流过边 $e$ 的电流。一般加权网络与多边联立的形式（任意两条边的使用概率由同一组电流读出）超出本章范围，完整陈述与证明见 Lyons–Peres《Probability on Trees and Networks》第 4 章——那里它由矩阵树定理的 Cauchy–Binet 展开直接读出：组合学册第 7 章 §7.3 的电流注脚预告过「电流走所有路径按电导分配」与「树按权积求和」是同一个展开的两副面孔，本条就是那张支票的兑现。

1. **验证口径（$K_3$）**：三角形上 $1\mathrm{A}$ 从 $0$ 到 $1$，直达边分到 $\frac{1}{1 + 1/2} = \frac23$。生成树侧：$K_3$ 有 3 棵树、每条边出现在 2 棵中，$\Pr = \frac23$。两侧咬合。
2. **推论 8.8（边概率 $=$ 电阻）**：单位网络中 $\Pr\big[\{x, y\} \in T\big] = R_{\mathrm{eff}}(x, y)$。理由就在定义里：$x \to y$ 的单位流过边 $\{x, y\}$ 的电流恰是 $v(x) - v(y) = R_{\mathrm{eff}}(x, y)$（定义 8.3），与定理 8.7 拼上即得。立方体验算：$Q_3$ 边传递，每条边概率相同、12 条边的概率和须等于树边数 7，故 $\Pr = \frac{7}{12}$——恰好是 §8.3 算出的相邻电阻，双重咬合。
3. **Foster 定理（一行推论）**：把推论 8.8 对所有边求和，左边 $=$ 生成树边数 $n - 1$：$\sum_{\{x, y\} \in E} R_{\mathrm{eff}}(x, y) = n - 1$。读法：全网络边电阻的总账恒等于 $n - 1$——立方体 ${12 \times \frac{7}{12}} = 7$、三角形 ${3 \times \frac23} = 2$，两例皆中。电阻的「守恒总账」是电网络语法送给图论的免费礼物。

**小结**：本节把电流接到树上——随机生成树的边概率由电流读出，求和给出 Foster 总账；矩阵树的代数（第 7 章）与电流的物理在 Cauchy–Binet 处合流。下一节回到第 12 章的主线：扩张图。

## $\rm \S \, 8.6$ 应用：扩张图的电阻诠释与 Rayleigh 单调性

白话：现在用电阻语言重读第 12 章。主角是一个变分原理，它与第 11 章的 Rayleigh 商同宗同源——Rayleigh 商对**电压**（试探向量）取能量，Thomson 原理对**电流**（试探流）取能量，同一变分思想的两副面孔：电压版给谱隙，电流版给电阻。

1. **命题 8.9（Rayleigh 单调性，陈述级）**：把任一条边的电阻调大（删边 $=$ 电阻调到无穷），任何两点间的 $R_{\mathrm{eff}}$ 不会变小。依据是 Thomson 原理（陈述级）：$R_{\mathrm{eff}}(a, b) = \min_{\text{单位流 } i} \mathcal{E}(i)$，其中耗散能量 $\mathcal{E}(i) = \sum_{e} r_e\, i_e^2$——有效电阻是「单位流耗散能量」的最小值：电阻越大越费能，而删边只是把可选的流变小，可行域收缩、最小值不降。完整证明（能量极小与电压解互为对偶）超出本章范围，见 Doyle–Snell 第 2 章、Lyons–Peres 第 2 章。比喻：修一条新路不会让任何两座城市之间更堵，拆掉一条则处处只会更堵或持平。由定理 8.6 立刻接力：**删边不降通勤时间**——单调性从电学免费传给马尔可夫链。
2. **推论 8.10（割的电阻下界）**：$a \in S$、$b \in V \setminus S$，则 $R_{\mathrm{eff}}(a, b) \ge \frac{1}{|\partial S|}$。证明两行：把 $S$ 内部全部短接、补集内部全部短接（短接 $=$ 加边，由命题 8.9 电阻不升，故原网络电阻 $\ge$ 短接后的电阻）；短接后网络只剩 $|\partial S|$ 条 $1\,\Omega$ 并联，电阻 $\frac{1}{|\partial S|}$。$\blacksquare$
3. **Cheeger 的电阻白话。** 推论 8.10 说：割越窄，跨割电阻越高。把第 12 章的 Cheeger 常数 $h(G)$ 放进来读：$h(G)$ 大 $=$ 每个小集合的边界都宽 $=$ 处处「并联的过河路」多 $=$ 电阻山脊不存在；$h(G)$ 小 $=$ 存在窄渡口 $=$ 电阻山脊横在那里，游走者挤在山脊一侧、逃离概率（推论 8.5）被压低、通勤时间（定理 8.6）被抬高——混合慢。扩张图在电阻语言里就是「没有电阻山脊的路网」：**Cheeger 瓶颈是电阻视角的拥堵地图**。精确的定量等价（用 $h(G)$ 或谱隙给出 $R_{\mathrm{eff}}$ 的上下界）超出本章范围，见 Lyons–Peres 第 2、4 章与 Levin–Peres 第 9 章。§8.7 表三把单调性钉进数值：立方体删一条边，$R(000, 001)$ 从 $\frac{7}{12}$ 跳到 1.4——删的恰是被挤的那座桥，涨幅最大；对径点 $R(000, 111)$ 只从 $\frac56$ 涨到 1.1，远处的路多，绕行不痛。
4. **辨析一句话**：电网络的全部语法（击中概率、通勤、电流）不要求图非二分——它们只依赖第一步分析与极大值原理；第 12 章的「非二分」护栏只管混合（周期振荡防碍分布收敛），管不着电阻账本。

**小结**：本节用 Thomson 原理交付 Rayleigh 单调性与割下界，把第 12 章的瓶颈翻译成电阻山脊；下一节用真算验收全章。

## $\rm \S \, 8.10$ 本章自测答案

> 先闭卷作答 §8.8 与 §8.9，再核对。

### $\rm \S \, 8.10.1$ 关键概念回顾答案

1. $\sum_{y \sim x} (v(x) - v(y)) = 0$ 整理成 $v(x) = \frac{1}{d(x)} \sum_{y \sim x} v(y)$：节点定律是流守恒，调和性是「值 $=$ 邻居平均」，同一等式的两种读法，没有新假设。（§8.2）
2. 反设内部点取超过边界的最值 $M$：调和性给 $M$ 等于邻居平均 $\le M$，等号成立强制每个邻居也为 $M$，连通性把 $M$ 传染到边界、矛盾。它保证「内部调和 $+$ 边界钉死」的解唯一——命题 8.2 第三步与引理 8.4 第三步都靠它收尾。（§8.2）
3. 两半是两个方向的期望穿越数：每次访问 $z$ 摊 $\frac1{d(z)}$ 次去每个邻居，故 $\mathrm{E}[N(\vec{zy})] = \frac{G_a(z)}{d(z)}$。节点定律逐路径成立是因为每条具体游走路径上，内部点的到达数与离开数就是相等（首尾在 ${a, b}$），期望只是把这个逐路径恒等式搬过来。（§8.4）
4. 检查三件：边界值 $\tilde v(x) = R - R = 0$、$\tilde v(y) = R$；调和性（常数减调和）；对应的流是 $-i$（欧姆定律逐边），恰为 $y \to x$ 的单位流——由唯一性它就是反向问题的解。（§8.4）
5. $K_3$ 电学侧：直达边分到 $\frac{1}{1 + 1/2} = \frac23$；树侧：3 棵树、每边出现 2 次，$\frac23$。两步接力：定理 8.7 给 $\Pr[e \in T] = i_e$，而 $e = \{x, y\}$ 上的电流按定义恰为 $R_{\mathrm{eff}}(x, y)$，得推论 8.8；对边求和、左边 $=$ 树边数 $n - 1$，得 Foster。（§8.5）
6. Thomson 原理给 $R_{\mathrm{eff}} = \min \mathcal{E}(i)$、$\mathcal{E}(i) = \sum_e r_e i_e^2$；删边缩小可行流集合，最小值不降。通勤时间由定理 8.6 接力：$R_{\mathrm{eff}}$ 不降则 ${2m\,R_{\mathrm{eff}}}$ 也不降（$m$ 还同时变小，需逐点看：表三实测三例全部上涨）。（§8.6）

### $\rm \S \, 8.10.2$ 应用与辨析答案

1. 错。极大值原理用「$M$ 等于邻居平均 $\le M$，追平须每个邻居 $= M$」——这一步与 $d(x)$ 无关：平均再怎么加权，只要每个成员 $\le M$，追平就得全员顶格；度数大只是成员多，不改变这个逻辑。（§8.2）
2. 完全图 $m = \frac{n(n-1)}{2}$、$R_{\mathrm{eff}} = \frac2n$，乘积 ${2m R} = {2(n-1)}$ 与 $n$ 线性而非 $n^2$：边数按 $n^2$ 涨、电阻按 $\frac1n$ 跌，两者抵消后只剩线性——加边同时抬高 $m$ 与压低 $R$，恒等式的乘积结构注定「路多不堵」。（§8.3、§8.4）
3. 照常成立：击中概率对应（命题 8.2，第一步分析 $+$ 极大值原理）、通勤恒等式（定理 8.6，只用首达时与期望线性性）、全部电阻计算——它们不涉及分布收敛。需要护栏的是第 12 章的混合定理：二分图 $\lambda_n = -d$ 的振荡分量不衰减，须惰性化后才能谈混合；但「从 $x$ 到 $y$ 的通勤」这类首达时问题对周期性不敏感。（§8.2、§8.4、§8.6）
4. 推论 8.10 给 $R_{\mathrm{eff}}(a, b) \ge \frac{1}{|\partial S|} = 1$；代进推论 8.5：$\Pr_a[T_b < \tau_a^+] \le \frac{1}{d(a) \cdot 1} = \frac{1}{d(a)}$。直觉：窄走廊是电阻山脊，游走者一出门就被挤回来，逃离概率被度数封顶。（§8.6）
5. 星形：$R(1, 2) = \frac13 + \frac13 = \frac23$（两臂串联经中心）；三角形：直达 $1\,\Omega$ 与绕行 $2\,\Omega$ 并联 $= \frac23$。省力的场合：网状结构里反复出现三角形局部时，星–三角一片片削成串并联，比每次解全局方程组便宜——§8.3 的立方体例子反着示范了这一点：对称性压未知数比机械缩图更锋利。（§8.3）
