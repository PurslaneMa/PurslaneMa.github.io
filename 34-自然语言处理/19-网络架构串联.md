# $\rm Chapter \, 19$ 网络架构串联

前面十八章的模型可以用一条演化链一次带走：所有网络都是同一台机器（Encode–Transform–Predict–Train），演化只发生在 Transform 段，每一步加的模块都在修上一步的瓶颈。本章先立骨架、走完九步主干，再补 VAE 与语言 GAN 这条生成支线，最后收成一张「每个架构记三个词」的表。它是全册的收束，也是复习时的总地图。

> **开始前自检**：本章假设你已经会：
>
> 1. □ softmax 打分与隐状态的读法（§19.1 回读）；
> 2. □ 「损失＝负对数似然、优化＝SGD」这两件事从来不变（§19.1 回读）；
> 3. □ 各缩写的全称与白话（§19.1 的对照表，记不住随时回查）。

## $\rm \S \, 19.1$ 需要的前提

1. 会读三个记号：softmax 打分（深度学习分册）、条件概率 $P(y \mid x)$（数学基础大类的概率论部分）、隐状态 $h$（深度学习分册）。
2. 知道训练是永远不变的两件套：损失 = 负对数似然、交叉熵，优化 = SGD（机器学习与凸优化分册）。本章的全部「架构演化」发生在模型这一侧，训练侧从头到尾没换过。

缩写对照表（全文反复出现；每个术语首次出现处也会就地展开，记不住随时回查）：

| 缩写 | 全称 | 一句话白话 |
| --- | --- | --- |
| LR | logistic regression，逻辑回归 | 线性打分 + sigmoid 挤成概率；只会画直线边界 |
| MLP | multi-layer perceptron，多层感知机 | 把「一堆 LR」并排成层、再叠深 |
| FFN | feed-forward network，前馈网络 | 对**每个位置独立**套的两层小 MLP（Transformer 里 512→2048→512：先加宽、再压回）；白话「逐位置加工车间」 |
| RNN | recurrent neural network，循环神经网络 | 隐状态按时间接力，参数跨时间共享 |
| BPTT | back-propagation through time | 把 RNN 沿时间展开之后的普通反向传播 |
| GRU / LSTM | gated recurrent unit / long short-term memory | 带门控的 RNN 变体：给时间轴留一条不衰减的直通线 |
| seq2seq | sequence-to-sequence | 序列进、序列出（翻译、摘要）的任务与模型：编码器 + 解码器 |
| Q/K/V | query / key / value | attention 里每个位置的三种角色：想找什么 / 能被怎么找到 / 贡献什么 |
| LayerNorm（LN） | layer normalization，层归一化 | 单个位置内部按特征维做标准化，让深层好训 |
| MLE | maximum likelihood estimation | 极大似然：挑让训练数据出现概率最大的参数 |
| KL | Kullback–Leibler divergence | 「换一把分布尺子多付的代价」：非负、不对称 |
| ELBO | evidence lower bound | VAE 用来替代算不出的 $\log p(x)$ 的下界 |
| VAE | variational autoencoder | 先采「整句大意」$z$、再生成句子的生成模型 |
| GAN | generative adversarial network | 生成器造假、判别器鉴定的对弈式生成 |
| MoE | mixture of experts，混合专家 | 把 FFN 切成多份专家、门控只激活少数几份 |
| LoRA | low-rank adaptation | 冻结原权重、只学一对小矩阵补丁的微调法 |
| RLHF | reinforcement learning from human feedback | 用人类偏好排序训奖励模型、再 RL 对齐 |
| GQA | grouped-query attention | 多组 query 头共享一套 K/V 头（给 KV cache 瘦身） |
| KV cache | key/value cache | 逐 token 生成时缓存历史 K/V，避免重算 |

## $\rm \S \, 19.2$ 统一骨架：所有网络都是同一台机器

先看住一个事实，后面的架构全都是它的换装（深度学习分册 §1 的 Encode–Predict–Train）：

$$
x \;\xrightarrow{\text{Encode}}\; h \;\xrightarrow{\text{Transform}}\; h' \;\xrightarrow{\text{Predict}}\; z \;\xrightarrow{\text{softmax}}\; P(y \mid x)
$$

1. Encode：把输入（一句话、一张图）变成向量；
2. Transform：在向量上做文章，本章演化的全部动作都在这里；
3. Predict：线性层把向量压成各类打分（logits），softmax 变成概率；
4. Train：交叉熵 + SGD，永远不变。

白话：深度学习几十年来「换架构」，换的始终是中间那一截「怎么把向量变聪明」。两头的「怎么进」「怎么出」「怎么训」纹丝不动。所以记架构的正确姿势不是背结构图，而是记每一版在 Transform 段卡在哪、新模块怎么解套。

## $\rm \S \, 19.3$ 演化链：九步，每步修一个瓶颈

### $\rm \S \, 19.3.1$ LR（逻辑回归）：一条直线打天下（机器学习与凸优化分册 §2）

1. 形态（LR = logistic regression，逻辑回归）：$f_\theta(x) = \sigma(w^\top x + b)$，打分后 sigmoid 挤成概率。
2. 修的瓶颈：这是起点，没有上一个。它把「分类」第一次写成了可优化的概率模型。
3. 代价：决策边界只能是直线；只能分两类。

### $\rm \S \, 19.3.2$ MLP（多层感知机）：堆层 + 非线性（深度学习分册 §6）

1. 修的瓶颈：LR 只会画直线。
2. 加的模块：隐藏层堆叠 + 激活函数，$h_1 = \sigma(W^0 h_0 + b^0)$ 再往上叠。非线性是命根子：线性叠线性还是线性。一行证明：$W^1 W^2 W^3 x$ 还是一个矩阵乘 $x$。
3. 代价：层一深，梯度是 Jacobian 的连乘链，传到低层已被反复缩放，深层难训（深度学习分册 §8.5）。这个伏笔在后面每一代都会回来。
4. 训练侧也在这里定型：`loss.backward()` 的数学就是逆拓扑序的「误差向量 × Jacobian」（深度学习分册 §8）。

![图 1：MLP——把「一个 LR」堆成「一层 LR」再叠深（P2 p22）](assets/nlp/arch-mainllm_part2nnlm_complete-p0022.png)

### $\rm \S \, 19.3.3$ FFNNLM（前馈神经网络语言模型）：把「前文」塞进输入（第 4 章 §1）

1. 修的瓶颈：MLP 不认识「词序与历史」。语言模型要预测下一个词，输入得是前面几个词。
2. 加的模块：拼接最近两个词的嵌入当输入，其余照搬 MLP。
3. 代价：只能看固定窗口，比如两个词，长距离依赖进不来；输出层 $|V|$ 类 softmax 太贵，补救是 class-based LM、NCE。它其实更像一个过渡：真正的答案是让「历史」进入结构而不是输入，这就是 RNN。

### $\rm \S \, 19.3.4$ RNN：隐状态记住全部历史（第 4 章 §4–6）

1. 修的瓶颈：FFNNLM 的窗口太短。
2. 加的模块：循环。隐状态 $h_t = \sigma(W_{ih} x_t + W_{hh} h_{t-1} + b_h)$，参数跨时间共享，历史全部压进 $h_{t-1}$。训练沿时间展开（unfolding）后就是一张普通计算图，反向传播变成 BPTT。
3. 代价：误差沿时间也是连乘，$\partial L_t/\partial h_1 \approx \frac{\partial L_t}{\partial h_t} W_{hh}^{\,t-1}$，梯度爆炸或消失。补救是梯度裁剪，但它只治标。

![图 2：RNN 沿时间展开——历史靠隐状态一站站接力（P2 p100）](assets/nlp/arch-mainllm_part2nnlm_complete-p0100.png)

### $\rm \S \, 19.3.5$ GRU/LSTM：门控给时间轴留直通线（第 4 章 §9）

1. 修的瓶颈：RNN 的梯度沿时间衰减。
2. 加的模块：门。GRU 的更新门 $z$ 与重置门 $r$，关键是红路径 $(1 - z) \odot h_{t-1}$ 不含权重矩阵：梯度可以原样流回过去，不被 $W_{hh}$ 反复缩放。
3. 记住这个思想，它马上换个轴再出现一次：残差连接 $x + F(x)$ 是同一个「留一条不衰减通路」的想法，只是作用在深度方向（深度学习分册第 13 章 §1.4）。

### $\rm \S \, 19.3.6$ seq2seq + attention：先改接口，再修取用（深度学习分册第 13 章 §1–2）

1. 修的瓶颈：翻译这类任务要「整句进、整句出」，两个 RNN 接力（编码器 + 解码器）能解决形状问题。但接法是个瓶颈：把编码器全部隐状态池化成一个定长向量，定长且取用方式固定，解码每一步看的都是同一份压缩摘要。
2. 加的模块分两步：先不池化，全部隐状态留着；再加注意力，解码第 $t$ 步现场算一组权重 $a_{i,t}$，加权求和出这一步专用的上下文向量 $c_t$。要害性质：对齐是学出来的且可微，端到端一起训。
3. 白话：以前是「把整本字典缩成一页摘要带进考场」，现在是「字典摊开放在旁边，做题时随时按内容翻」。

![图 3：注意力——每一步重新加权取用编码器状态（P2 p131）](assets/nlp/arch-mainllm_part2nnlm_complete-p0131.png)

### $\rm \S \, 19.3.7$ Transformer：注意力当骨架（深度学习分册第 13 章 §4）

1. 修的瓶颈：RNN 句内不能并行（隐状态必须接力），注意力再强也只是挂在 RNN 上的附件。
2. 加的模块是「减法 + 组装」：扔掉 RNN，让注意力自己当骨架。骨架的零件有：self-attention（同一串序列自己看自己，Q/K/V 三个矩阵分角色）；多头（h=8 组并行学不同加权方式）；FFN（feed-forward network，对每个位置独立套的两层小 MLP，512→2048→512，白话「逐位置加工车间」——attention 负责开会交流，FFN 负责各自回工位加工）；残差 + LayerNorm（层归一化，保深度可训）；位置编码（注意力对顺序天然无感，得把位置加进词向量）。
3. 代价（笔笔有回响）：拿到句内并行，丢了顺序信息，位置编码来补；注意力是 $n \times n$ 打分、随长度平方涨，Longformer、GQA 后来来补；深层仍有梯度衰减，残差 + LayerNorm 就是 §19.3.5 那条思想换轴上岗。

![图 4：一个 Transformer block = 注意力（通信）+ FFN（变换）+ 残差与 LayerNorm（保可训）（P2 p169）](assets/nlp/arch-mainllm_part2nnlm_complete-p0169.png)

### $\rm \S \, 19.3.8$ BERT 与 GPT：同一骨架，两种朝向（第 6、7 章）

骨架不变，朝向一分叉，能力就分家：

1. BERT（编码器侧）：双向看全文 + 完形填空（MLM，15% 挖空再 80/10/10 掺假）+ 预训练–微调两段式。擅长理解，天生不会续写。
2. GPT（解码器侧）：因果掩码（未来位置打分设 $-10^9$，softmax 后权重精确为 0）让 self-attention 只准看过去，于是天生会续写；GPT2 发现数据够大时 zero-shot 提示直接干活。decoder-only 后来胜出，靠的是训练与使用同构、聊天场景零重算。

![图 5：因果掩码——同一骨架转向「只看过去」就是 decoder（P2 p218）](assets/nlp/arch-mainllm_part2nnlm_complete-p0218.png)

### $\rm \S \, 19.3.9$ 规模化之后：MoE、LoRA、RLHF（第 11、12 章）

模型定型后，演化换到了参数组织与目标上：

1. MoE：FFN 切成多个专家 + 门控 top-$k$ 激活，总参数变大、每步计算不变（条件计算）。
2. LoRA：微调不动 $W_0$、只学低秩补丁 ${AB}$（秩 $r$ 很小）。存 $m$ 个任务只需 $m$ 份增量，训练后合并回 $W_0$ 零延迟。
3. RLHF、DPO、GRPO：架构一行没改，改的是训练目标，从「模仿数据」换成「对齐偏好」。
4. 推理侧的效率两件套（第 7 章 §7.8）：KV cache（别重算历史 key、value）与 GQA（K、V 头按组共享，缓存瘦身）。

**本节小结**：九步主干走完，规律只有一句——每一代修上一代的瓶颈，自己的代价又留给下一代来修；主线之外还有一条生成支线，下一节专门走它。

## $\rm \S \, 19.4$ 生成模型支线：VAE 与语言 GAN

主干讲的全是「下一个词」。课件还有一条支线专门回答另一个问题：怎么让模型像人一样「先有整句大意、再展开成词」，或干脆换掉 MLE 这个裁判。这两支都用上了图例里最出名的两类结构图，也正好把数学基础大类的概率论部分的 KL、第 8、9 两章的 VAE/GAN 细节串起来。

### $\rm \S \, 19.4.1$ VAE：给整句一个「大意旋钮」（第 8 章）

1. 修的瓶颈：AR-LM 逐词接龙，没有「整句语义」这个可操作的对象；想直接最大化 $\log p_\theta(x)$ 又算不出（对连续隐变量 $z$ 要积分）。
2. 加的模块有三个。连续隐变量 $z$ 表示整句大意，先采 $z$ 再生成 $x$；ELBO 下界，真目标算不出就托举下界，一项重构、一项 $-\mathrm{KL}$ 正则；重参数化 $z = \mu_\theta + \sigma_\theta \odot \epsilon$，把「从参数化分布采样」拆成「无关噪声 + 含参算术」，梯度恢复流动。
3. 代价：解码器太强时 $z$ 被架空（后验坍缩），要 KL 退火、word dropout、BoW 辅助损失三补丁伺候。
4. 归宿：VAE-LM 本身已被自回归 LLM 取代，但它的两件技术资产（ELBO、重参数化）到处返场：RLHF 的 KL 正则、扩散模型、以及下面 GAN 线里的 Gumbel-softmax，都是同一套语言。

白话：VAE 给每句话配一个「大意旋钮」$z$——先拧出一个大意、再照着展开成句子；训练托举一个算得起的下界（ELBO），重参数化保证旋钮拧得动（梯度能流过随机节点）。

![图 7：重参数化——把随机节点换成确定变换（NLP2 课件 PDF 第 9 页）](assets/nlp/arch-NLPlecs_main_part2_111-p0009.png)

### $\rm \S \, 19.4.2$ 语言 GAN：换一个裁判（第 9 章）

1. 修的瓶颈：MLE 的裁判是「真句的概率」，逐 token 对答案；当年 exposure bias 假说认为训练、生成错位是大问题。GAN 把裁判换成「判别器对模型自己采样的打分」，训练信号直接落在模型样本上。
2. 加的模块：生成器 $G$（造假）＋判别器 $D$（鉴定）的对弈结构，$\min_G \max_D V(D,G)$。均衡时真假不可分、$D$ 只能瞎猜。
3. 代价一（卡点）：语言里 $G$ 末端要采 one-hot token，$\theta$ 决定的离散选择挡梯度（第 8 章 §8.4 的判据），于是有 Gumbel-softmax、straight-through、REINFORCE 三个绕法。注意前两个就是 §3.1 重参数化的同族思想换了个分布。
4. 代价二（结局）：整条「质量–多样性」曲线拉出来一比，语言 GAN 全线输给 MLE + 调温采样（Language GANs Falling Short）。根因是 MLE $=\arg\min \mathrm{KL}(P_D \,\|\, P_M)$ 天生偏多样性，而采样温度负责收拢换质量，GAN 没有生存空间。讲者的评论是 GAN、RL 都不稳，「MLE 训练 + 采样算法」是绝配。

![图 8：GAN 的对弈目标与「G 采样 → D 判别」（NLP2 课件 PDF 第 28 页）](assets/nlp/arch-NLPlecs_main_part2_111-p0028.png)

![图 9：Gumbel-softmax——把离散抽签软化成连续打分（NLP2 课件 PDF 第 30 页）](assets/nlp/arch-NLPlecs_main_part2_111-p0030.png)

### $\rm \S \, 19.4.3$ 这条支线在主干里的位置

1. VAE 与 GAN 都没能成为今天的训练主流，但它们各自留下的零件进了主干：VAE 的重参数化与 ELBO、GAN 的「判别器打分」思想。后者后来在 RLHF 的奖励模型与 DPO 里以另一种形式复活，见 第 11 章。
2. 它们还联手完成了对 exposure bias 假说的实证检验（前缀切换实验、self-recovery），结论是「MLE 训练 + 采样算法」这条主干比当年想象的要结实。这正是第 4 节那张表里「采样算法」一行的来路。

## $\rm \S \, 19.5$ 一张表收拢：每个架构记三个词

| 架构 | 修的瓶颈 | 加的模块 | 代价 / 伏笔 |
| --- | --- | --- | --- |
| LR | （起点）分类写成概率模型 | sigmoid 打分 | 只会画直线 |
| MLP | 直线边界 | 堆层 + 激活 | 深层梯度衰减 |
| FFNNLM | 输入里没有前文 | 拼接词嵌入窗口 | 窗口固定、输出层贵 |
| RNN | 窗口太短 | 隐状态循环共享 | 梯度沿时间爆炸/消失 |
| GRU/LSTM | 时间轴梯度衰减 | 门控直通路径 | 结构复杂、仍不能句内并行 |
| seq2seq+attention | 定长瓶颈、取用固定 | 不池化 + 打分加权 | 仍挂在 RNN 上、串行 |
| Transformer | RNN 不能并行 | 注意力当骨架 + FFN（逐位置小 MLP）+ 残差/LayerNorm + 位置编码 | 平方注意力、顺序信息靠外挂 |
| BERT / GPT | 理解 vs 生成要分家 | 同一骨架换朝向（双向 / 因果掩码） | 微调范式 vs 提示范式 |
| MoE / LoRA / RLHF | 参数太大、目标不对 | 专家路由 / 低秩补丁 / 偏好目标 | 工程与对齐复杂度 |
| VAE（支线） | 整句语义不可操作 | 隐变量 $z$ + ELBO + 重参数化 | 后验坍缩；主线败给 AR-LM |
| 语言 GAN（支线） | MLE 只逐 token 对答案 | 判别器对弈 | 采样挡梯度；输给 MLE+采样 |

**本节小结**：忘了哪个架构，就回这张表按「修的瓶颈 → 加的模块 → 代价/伏笔」三栏把它的故事捡回来。

## $\rm \S \, 19.6$ 怎么记：三条心法

1. 训练侧不变：永远是「负对数似然 + SGD」，只有 RLHF 那一步换了目标函数。所以读新论文先问「它动的是架构、参数组织、还是目标」。
2. 同一思想反复换轴上岗：「留一条不衰减的通路」在 GRU 里是时间轴的门、在 Transformer 里是深度轴的残差；「采样平均估计期望」在 VAE、SGD、GRPO 里是同一个 trick。
3. 每个模块都对应一个具体的病：看不懂某个模块时，先找它治的病。找不到病的模块不用记，比如 NSP 后来就被证明没病可治、直接退役，第 6 章 §6.4。

## $\rm \S \, 19.10$ 本章自测答案

> 先闭卷作答 §19.8 与 §19.9，再核对。

### $\rm \S \, 19.10.1$ 关键概念回顾答案

1. Encode（输入变向量）、Transform（向量上做文章）、Predict（线性层打分加 softmax）、Train（交叉熵加 SGD）；演化全在 Transform。（§19.2）
2. 线性叠线性还是线性：$W^1W^2W^3x$ 仍是单个矩阵乘 $x$；激活函数打破它。（§19.3.2）
3. $\partial L_t/\partial h_1$ 里 $W_{hh}^{t-1}$ 的连乘缩放；GRU 的 $(1-z)\odot h_{t-1}$ 通路不含权重矩阵，梯度不被反复缩放。（§19.3.4–§19.3.5）
4. 先不池化（全部隐状态留着），再加注意力（每步现场打分加权出专用上下文）。（§19.3.6）
5. 扔掉 RNN（串行接力）；零件：self-attention（通信）、多头（并行学不同加权）、FFN（逐位置加工）、残差与 LayerNorm（保可训）、位置编码（补顺序）。（§19.3.7）
6. 朝向：双向看全文（理解，BERT）对因果掩码只看过去（生成，GPT）；一个设计决定两家的范式。（§19.3.8）
7. MoE 动参数组织（FFN 切专家）、LoRA 动参数组织（低秩补丁）、RLHF 动目标（模仿数据换成对齐偏好）。（§19.3.9）
8. 三件：隐变量 $z$、ELBO 下界、重参数化；遗产：ELBO 语言（扩散、KL 正则）与重参数化思想（Gumbel-softmax）。（§19.4.1）
9. GAN 换裁判但离散采样挡梯度（三绕法各有代价）；即便通了，质量–多样性全谱比较仍输给 MLE＋调温，因为 MLE 的前向 KL 天生 mass-covering、温度旋钮负责收拢。（§19.4.2）

### $\rm \S \, 19.10.2$ 应用与辨析答案

1. 先问它动的是架构、参数组织还是目标，再问它修的病是什么、病的主人在哪一代；「训练方法在进步」通常是把目标侧的改动（RLHF 系）误认成架构进步，本章的训练侧从头到尾没换。（§19.6）
2. GRU 在时间轴、残差在深度轴；不衰减的路必须是「常数乘或直加」，一含权重矩阵梯度就又被缩放，直路的意义就没了。（§19.3.5、§19.3.7）
3. NSP 治的「句间关系理解」病被实证判定不存在（RoBERTa 去掉不掉分），它占着训练目标却无病可治，于是退役；判断新模块时同样先找病。（第 6 章 §6.4）
4. 「修的瓶颈」是内存与调度（不是理论复杂度），它动的是注意力计算的实施方式、Transform 段的工程层；表里应与 Flash Attention/Mamba 一行并列「不改数学，改内存与调度」。（第 16 章、§19.5）
