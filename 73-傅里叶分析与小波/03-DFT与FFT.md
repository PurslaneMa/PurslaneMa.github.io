# $\rm Chapter \, 3$ DFT 与 FFT

前两章的傅里叶分析住在连续世界：无穷级数、无穷积分。计算机只握有限个格子——$N$ 个采样点进出、$N$ 个频率分量往返，这就是**离散傅里叶变换（DFT）**；让它跑得起来的分治算法叫**快速傅里叶变换（FFT）**，$O(N^2)$ 到 $O(N \log N)$ 的落差把「能算」与「算得起」分开。本章还清两笔账：卷积定理（频域逐点乘＝时域卷积）凭什么值三次变换的票价；频谱泄漏为什么是乘矩形窗的必然罚单而非数值误差。数值锚先摆出来：$N = 1024$ 的 FFT 卷积与直接卷积最大差 $10^{-14}$ 量级（相对 $10^{-16}$，机器精度位阶）；$N = 65536$ 的 FFT 实测约 $3$ ms，直接 DFT 实测 $347.9$ s——十万倍落差。

## $\rm \S \, 3.1$ DFT：有限点列的傅里叶世界

干脆从一段数据出发：$x[0], x[1], \ldots, x[N-1]$ 是 $N$ 个采样点（不预设背后有连续函数）。**离散傅里叶变换（DFT）**定义：

$$
X[k] = \sum_{n=0}^{N-1} x[n]\, \mathrm{e}^{-2\pi \mathrm{i} k n / N}, \qquad k = 0, 1, \ldots, N - 1
$$

（读法：$k$ 是频率编号，对应角频率 $\omega_k = \frac{2\pi k}{N}$（以采样间隔为单位）；把 $N$ 个点投影到 $N$ 根「离散波」$\mathrm{e}^{2\pi \mathrm{i} k n / N}$ 上。）逆变换：

$$
x[n] = \frac{1}{N} \sum_{k=0}^{N-1} X[k]\, \mathrm{e}^{2\pi \mathrm{i} k n / N}
$$

（读法：正变换不带常数、逆变换带 $\frac{1}{N}$——第 2 章口径 1 的离散翻版，$2\pi$ 换成 $N$。）

合法性的地基是**离散正交关系**：

$$
\sum_{n=0}^{N-1} \mathrm{e}^{2\pi \mathrm{i} (k - l) n / N} = \begin{cases} N, & k \equiv l \pmod{N} \\ 0, & \text{否则} \end{cases}
$$

（读法：$k \equiv l$ 时每项都是 $1$，和为 $N$；否则是公比 $q = \mathrm{e}^{2\pi \mathrm{i}(k - l)/N} \ne 1$ 的等比数列，$N$ 项和 $\frac{q^N - 1}{q - 1} = 0$——$q^N = 1$ 正是单位根的定义。）用它验证逆变换：把 $X[k]$ 代入逆式、交换求和，正交关系把对 $k$ 的求和过滤成单个 $m = n$ 项——$N$ 个采样点与 $N$ 个频率分量是同一份信息的两套坐标，来回无损。

周期性是采样自带的（不是选项）：指数里 $k$ 与 $n$ 都只按模 $N$ 起作用，故 $X[k + N] = X[k]$，且 DFT 的世界默认 $x$ 以 $N$ 为周期延拓。第 1 章说「$[-\pi, \pi]$ 上的函数都周期延拓」，那里是约定；这里是**结构性强制**——采样点列的傅里叶世界天然是圆环 $\mathbb{Z}/N\mathbb{Z}$，不是线段。记住这一点，下一节的「循环」卷积才不突兀。

**循环卷积**登场。两列 ${x, h}$（各长 $N$）的循环卷积：

$$
(x \circledast h)[m] = \sum_{n=0}^{N-1} x[n]\, h[(m - n) \bmod N]
$$

（读法：与线性卷积唯一的区别是下标按模 $N$ 回绕——滑窗滑出右端后从左端循环进入，名字由此来。）线性代数视角一行：循环矩阵 $C$（$C_{mn} = h[(m - n) \bmod N]$）被傅里叶向量 $v_k = \big( \mathrm{e}^{2\pi \mathrm{i} k n / N} \big)_n$ 对角化，$C v_k = H[k]\, v_k$，其中 $H = \mathrm{DFT}(h)$——**循环矩阵的特征值就是首列的 DFT**（本站高维概率与矩阵分析册的谱语言在此连本带利地用）。

**本节小结**：DFT＝$N$ 点列在离散波基下的坐标变换，离散正交关系保逆变换无损；周期性是采样的结构强制，傅里叶世界天生是圆环；循环卷积有特征值解释。下一节看它在频域变成什么。

## $\rm \S \, 3.2$ 卷积定理：频域逐点乘＝时域卷积

**定理（循环卷积定理）**：$\widehat{x \circledast h}[k] = X[k] \cdot H[k]$（${X, H}$ 各为 ${x, h}$ 的 DFT）。

**证明**一行半：变换、交换有限和、换元：

$$
\sum_{m} \sum_{n} x[n]\, h[(m - n) \bmod N]\, \mathrm{e}^{-2\pi \mathrm{i} k m / N} = \Big( \sum_{n} x[n]\, \mathrm{e}^{-2\pi \mathrm{i} k n / N} \Big) \Big( \sum_{r} h[r]\, \mathrm{e}^{-2\pi \mathrm{i} k r / N} \Big) = X[k]\, H[k]
$$

（读法：指数拆成 $n$ 因子与 $m - n$ 因子，换元 $r = (m - n) \bmod N$ 后内层和恰是 $H[k]$——周期性让换元不伤求和域。有限和交换次序不需要任何合法性检查，这是离散世界对连续世界的报复性优势。）

时域 $O(N^2)$ 的卷积在频域是 $N$ 次逐点复乘——前提是变换本身要快，这正是 §3.3 的门票。**线性卷积怎么办**：真实信号不循环。两个长 ${n, m}$ 的序列做线性卷积得长 $n + m - 1$；把两序列都补零到长度至少 $n + m - 1$，再做这个更长长度上的循环卷积——非零指标的范围是 $0$ 到 $n + m - 2$，模回绕所要「借」的区间与实际占用的区间不相交，回绕永不发生，循环卷积与线性卷积相等。FFT 卷积（三次变换、两次逐点乘）由此处理线性卷积：$O(n \log n)$ 取代 $O(nm)$——**卷积定理是给 FFT 发工资的人**。

实测对账（程序全文见 §3.6；$N = 1024$，标准正态随机序列，随机种子 $0$）：

```text
circular: max diff = 4.618527782440651e-14
circular: max |c|  = 95.0322989926344
linear:   max diff = 5.3290705182007514e-14
linear:   max |c|  = 92.10756224112775
```

（读法：FFT 路线与直接路线的最大偏差在 $10^{-14}$ 量级，相对幅度 $10^{-16}$——恰是 float64 的机器精度位阶。卷积求和的浮点舍入在两条路线里排列不同，差到 $10^{-14}$ 就是「同一答案的两种浮点说法」，不是误差；泄漏那种百分之几十的能量再分布（§3.4）才是真现象，两者差十个数量级。）

**本节小结**：卷积定理一行半证完：时域卷积在频域逐点相乘；线性卷积靠补零到 $n + m - 1$ 并入循环框架；FFT 路线与直接路线之差 $10^{-14}$（相对 $10^{-16}$）是舍入走位差。下一节把「变换本身要快」兑现。

## $\rm \S \, 3.3$ FFT：分治把 $O(N^2)$ 砍成 $O(N \log N)$

白话：按定义算 DFT 是 $N$ 个输出各 $N$ 项，$N^2$ 次复数乘法。FFT 的洞见：**这 $N^2$ 项里一半是重复劳动**——偶数下标与奇数下标的子问题互为镜像，拆开各算一半，合回来只用一次修剪。Cooley–Tukey 在 1965 年把它写成算法（高斯在 1805 年的手稿里已有雏形），信号处理从「离线批处理」变成「实时可算」。

拆。记 $W_N = \mathrm{e}^{-2\pi \mathrm{i}/N}$（$N$ 次本原单位根），把 $x$ 按下标奇偶拆成偶位子列 $x_{\mathrm{even}}$ 与奇位子列 $x_{\mathrm{odd}}$，各长 $\frac{N}{2}$；${E, O}$ 记它们的 $\frac{N}{2}$ 点 DFT。对 $k = 0, 1, \ldots, \frac{N}{2} - 1$：

$$
X[k] = E[k] + W_N^k\, O[k], \qquad X \big[ k + \tfrac{N}{2} \big] = E[k] - W_N^k\, O[k]
$$

（读法：推导只走两步。其一，$\sum_n x[n] W_N^{kn} = \sum_r x[2r] W_N^{2kr} + W_N^k \sum_r x[2r + 1] W_N^{2kr}$，而 $W_N^2 = W_{N/2}$——平方把单位根降阶，偶部奇部自动缩成半长 DFT；其二，$W_N^{N/2} = -1$（旋转半圈即取反），故 $W_N^{k + N/2} = -W_N^k$，第 $k + \frac{N}{2}$ 个输出免算、直接抄前半个的差。一对 $E[k], O[k]$ 一蝶两用，这个「先乘后加减」的小结构叫蝶形（butterfly）。）

账目：规模 $N$ 的问题拆成两个 $\frac{N}{2}$ 加 $N$ 次蝶形，递归

$$
T(N) = 2\, T(N/2) + O(N) \;\Longrightarrow\; T(N) = O(N \log_2 N)
$$

（读法：递归 $\log_2 N$ 层——每层规模减半；每层蝶形总量 $O(N)$——上层的 $\frac{N}{2}$ 个蝶形与下层的 $2 \times \frac{N}{2}$ 个恰好收支相抵。$N = 65536 = 2^{16}$ 时：直接法 $N^2 = 4.295 \times 10^9$ 次复乘，FFT 层次账 $N \log_2 N = 1.049 \times 10^6$，纸面比值 $4096$。）

实测对账（程序全文见 §3.6；直接法用矩阵一次成型，BLAS 火力全开——这是给 FFT 准备的最强对手）：

```text
fft n=65536:  min = 3.19 ms,  median = 3.57 ms
direct DFT n=1024: 78.2 ms
direct DFT n=2048: 392.9 ms
direct DFT n=4096: 1489.4 ms
```

直接法耗时按 $N^2$ 走（$N$ 翻两番、耗时翻 $19$ 倍，贴着理论值 $16$），外推到 $65536$ 约 $380$ s；不肯外推的话，真跑一次的实测是 $347.9$ s——**比 FFT 慢十万倍量级**。纸面比值 $4096$ 与实测比值 $\sim 10^5$ 的差额是常数因子的战场：FFT 的每个蝶形都在跟递归寻址与内存搬运缠斗，直接法的矩阵乘则紧致吃满 BLAS 的峰值算力。大 $O$ 只管增长斜率，常数要靠测量裁决。

（注：radix-2 FFT 要求 $N$ 是 $2$ 的幂；一般 $N$ 有混合基与素数长度算法（Rader、Bluestein），NumPy 的 `np.fft.fft` 对任意 $N$ 自动选路。）

**本节小结**：奇偶分治＋单位根降阶（$W_N^2 = W_{N/2}$）＋半圈反对称（$W_N^{N/2} = -1$）把 $N^2$ 压成 $N \log_2 N$；$N = 65536$ 实测 FFT 约 $3$ ms、直接法约 $350$ s；纸面 $4096$ 倍、实测 $10^5$ 倍——渐近与常数各管一段。下一节看频率轴上多出来的那笔账：泄漏。

## $\rm \S \, 3.4$ 频谱泄漏与加窗一瞥

现象：$N = 256$、采样率 $256$，单频正弦 $\cos \frac{2\pi f_0 n}{N}$ 量 DFT。$f_0 = 10$（整周期恰好装进窗）时频谱干干净净钉在第 $10$ 根谱线；$f_0 = 10.3$（差 $0.3$ 根）时能量泼满整条频率轴。实测（程序见 §3.6）：

```text
rect off-bin  mainlobe(+/-2 bins) = 0.9469   tail peak = -19.0 dB
hann off-bin  mainlobe(+/-2 bins) = 0.9998   tail peak = -35.6 dB
rect on-bin   mainlobe(+/-2 bins) = 1.0000   tail peak = -304.3 dB
```

解释一瞥：取 $N$ 个点＝时域乘矩形窗 $\mathbf{1}_{[0, N)}$；第 2 章 §3.2 卷积定理的对偶面说——时域相乘对应频域卷积——于是频谱被卷上矩形窗的谱，而那正是 §2.1 算过的 $\frac{\sin\omega}{\omega}$、第 1 章 Dirichlet 核的本尊。真实频率夹在两根谱线之间时，谱线采样打在旁瓣上，能量按旁瓣轮廓泼漏：**泄漏不是误差，是乘窗的精确后果**。on-bin 那行的 $-304$ dB 是机器零：整周期信号与矩形窗天作之合，旁瓣只在浮点舍入里存在。

加窗：Hann 窗 $w[n] = \frac{1}{2} \big( 1 - \cos \frac{2\pi n}{N - 1} \big)$（两端渐落为零）换掉矩形窗，旁瓣峰值从 $-19.0$ dB 压到 $-35.6$ dB（降幅 $16.6$ dB；连续谱的理论第一旁瓣约 $-31.5$ dB，离散采样打在略低处），主瓣附近能量占比从 $94.7\%$ 提到 $99.98\%$。代价：主瓣加倍（矩形 $2$ 根谱线、Hann $4$ 根）——紧邻的两个频率更难分开。这笔交换没有免单：第 2 章 §2.3 的不确定性原理给一切时域窗明码标价，「主瓣窄（分辨率）」与「旁瓣低（动态范围）」不可兼得，Hann 只是比矩形更接近下界的一种付法。实践一句：确知整周期或要保瞬态陡沿用矩形；一般谱分析默认 Hann。

**本节小结**：泄漏＝矩形窗的 Dirichlet 旁瓣被真实频率采样，是乘窗的精确后果而非数值误差；Hann 用主瓣加倍换旁瓣 $16.6$ dB 的降幅，交换由不确定性原理定价。傅里叶分析至此完成从连续理论到计算机实作的落地。

## $\rm \S \, 3.5$ 关键概念回顾（六问）

1. 离散正交关系怎么证？逆变换公式的验证里，它在哪一步把对 $k$ 的求和过滤成单个 $x[n]$？
2. 循环卷积与线性卷积何时相等？补零到 $n + m - 1$ 为什么恰好让回绕永不发生？
3. 蝶式公式 $X[k] = E[k] + W_N^k O[k]$ 的推导里，$W_N^2 = W_{N/2}$ 与 $W_N^{N/2} = -1$ 各承担哪一步？缺了后者会怎样？
4. $N = 65536$：纸面复乘比 $4096$，实测时间比约 $10^5$——差额从哪来？这给「按大 $O$ 选算法」什么提醒？
5. 为什么说泄漏是「乘窗的精确后果」而非数值误差？从「时域相乘 ↔ 频域卷积」这一对偶说清。
6. 判断：长 $n$ 信号与短核（长 $m$，$m \ll n$）卷积，FFT 卷积一定更快吗？用直接法 $O(nm)$ 对 FFT 法 $O(n \log n)$ 估出胜负分界，并举一个 $m$ 极小的实际场景。

## $\rm \S \, 3.6$ 程序段：卷积定理与 FFT 计时实测

第一段：正确性与计时（§3.2、§3.3 的全部数值锚）。

```python
import numpy as np, time

rng = np.random.default_rng(0)
n = 1024
a = rng.standard_normal(n)
b = rng.standard_normal(n)

c_fft = np.fft.irfft(np.fft.rfft(a) * np.fft.rfft(b), n)                  # FFT 循环卷积
c_dir = np.array([np.dot(a, np.roll(b[::-1], s + 1)) for s in range(n)])  # 直接法 O(n^2)
print("circular: max diff =", np.max(np.abs(c_fft - c_dir)))
print("circular: max |c|  =", np.max(np.abs(c_dir)))

cl_fft = np.fft.irfft(np.fft.rfft(a, 2*n - 1) * np.fft.rfft(b, 2*n - 1), 2*n - 1)
cl_dir = np.convolve(a, b)                                                # 补零到 2n-1
print("linear:   max diff =", np.max(np.abs(cl_fft - cl_dir)))
print("linear:   max |c|  =", np.max(np.abs(cl_dir)))

z = rng.standard_normal(65536) + 1j * rng.standard_normal(65536)
ts = []
for _ in range(9):
    t0 = time.perf_counter(); np.fft.fft(z); ts.append(time.perf_counter() - t0)
print(f"fft n=65536:  min = {min(ts)*1000:.2f} ms,  median = {sorted(ts)[4]*1000:.2f} ms")

def dft_direct(v):
    j = np.arange(len(v))
    return np.exp(-2j * np.pi * np.outer(j, j) / len(v)) @ v

for m in [1024, 2048, 4096]:
    v = rng.standard_normal(m) + 1j * rng.standard_normal(m)
    ts = []
    for _ in range(3):
        t0 = time.perf_counter(); dft_direct(v); ts.append(time.perf_counter() - t0)
    print(f"direct DFT n={m}: {min(ts)*1000:.1f} ms")

print("ops: direct n^2 =", 65536**2, "  fft n*log2(n) =", 65536*16,
      "  ratio =", 65536**2 // (65536*16))
```

实跑输出（本章数值锚，照抄；计时随机器浮动，量级不变）：

```text
circular: max diff = 4.618527782440651e-14
circular: max |c|  = 95.0322989926344
linear:   max diff = 5.3290705182007514e-14
linear:   max |c|  = 92.10756224112775
fft n=65536:  min = 3.19 ms,  median = 3.57 ms
direct DFT n=1024: 78.2 ms
direct DFT n=2048: 392.9 ms
direct DFT n=4096: 1489.4 ms
ops: direct n^2 = 4294967296   fft n*log2(n) = 1048576   ratio = 4096
```

（注：直接 DFT 在 $n = 65536$ 真跑一次的实测是 $347.9$ s，与从 $n = 4096$ 外推的 $380$ s 相符；程序里只放到 $4096$，免得读者机器上白等六分钟。直接法对 FFT 的偏差在 $10^{-8}$ 绝对、$10^{-11}$ 相对——长求和的舍入积累，量级依然干净。）

读程序的四句话：循环卷积的直接法用 `roll(b[::-1], s + 1)` 把 $h[(m - n) \bmod N]$ 对齐成内积——回绕结构全在翻转与滚动里；线性卷积走 `rfft(a, 2n-1)` 补零路线，补零长度 $2n - 1 = n + n - 1$ 恰好卡在 §3.2 的条件上；直接 DFT 用 `outer(j, j)` 一次生成 $N \times N$ 复指数矩阵、交给 BLAS，是对 FFT 最有利的对手；计时取多次最速值，躲开操作系统调度的毛刺。

第二段：泄漏与加窗（§3.4 的数值锚）。

```python
import numpy as np

N, fs, f0 = 256, 256.0, 10.3
n = np.arange(N)
w_hann = 0.5 * (1 - np.cos(2 * np.pi * n / (N - 1)))

def spectrum(x):
    P = np.abs(np.fft.rfft(x))**2
    return P / P.sum()

for name, x, f0_ in [("rect off-bin", np.cos(2*np.pi*f0*n/fs), f0),
                     ("hann off-bin", np.cos(2*np.pi*f0*n/fs)*w_hann, f0),
                     ("rect on-bin ", np.cos(2*np.pi*10.0*n/fs), 10.0)]:
    P = spectrum(x)
    pk = int(round(f0_))
    mainlobe = P[pk-2:pk+3].sum()          # 峰值谱线两侧各 2 根
    tail = P.copy(); tail[pk-2:pk+3] = 0
    sl = 10*np.log10(tail.max()/P.max()) if tail.max() > 0 else float("-inf")
    print(f"{name}  mainlobe(+/-2 bins) = {mainlobe:.4f}   tail peak = {sl:.1f} dB")
```

实跑输出：

```text
rect off-bin  mainlobe(+/-2 bins) = 0.9469   tail peak = -19.0 dB
hann off-bin  mainlobe(+/-2 bins) = 0.9998   tail peak = -35.6 dB
rect on-bin   mainlobe(+/-2 bins) = 1.0000   tail peak = -304.3 dB
```

读程序的三句话：能量谱按总质量归一，「主瓣」取峰值谱线两侧各 $2$ 根——矩形主瓣 $2$ 根、Hann 主瓣 $4$ 根，统一口径才可比；旁瓣峰值抹掉主瓣后取最大、化成分贝；on-bin 信号的尾部只剩浮点噪声，`-304.3 dB` 是机器零的等外表现（代码里留了 `-inf` 分支防它取对数时报错）。

## $\rm \S \, 3.7$ 六问参考答案

1. $k \equiv l \pmod N$ 时逐项为 $1$、和为 $N$；否则公比 $q = \mathrm{e}^{2\pi \mathrm{i}(k - l)/N}$ 满足 $q^N = 1, q \ne 1$，等比和 $\frac{q^N - 1}{q - 1} = 0$。逆变换验证：$\frac{1}{N} \sum_k X[k] \mathrm{e}^{2\pi\mathrm{i}kn/N} = \frac{1}{N} \sum_m x[m] \sum_k \mathrm{e}^{2\pi \mathrm{i} k (n - m)/N} = \frac{1}{N} \cdot x[n] \cdot N = x[n]$——正交关系把对 $m$ 的求和过滤成单项。（§3.1）
2. 两列补零到长度至少 $n + m - 1$ 时相等：线性卷积的非零指标只占 $0$ 到 $n + m - 2$，这个区间与新长度上的模回绕像互不相交，回绕从未被触发；长度不够时必有指标绕回另一端污染求和，循环结果混入「从开头借来的」项。（§3.2）
3. $W_N^2 = W_{N/2}$ 把偶部（及乘 $W_N^k$ 后的奇部）的指数降阶成半长 DFT——分治结构由此成立；$W_N^{N/2} = -1$ 让第 $k + \frac{N}{2}$ 个输出免乘免算、直接取差——蝶形「一蝶两用」。缺了后者，后半输出仍要各配一次旋转因子，蝶形常数翻倍；递归骨架与 $O(N \log N)$ 不受影响——它省的是常数，不是阶。（§3.3）
4. 差额在常数因子：FFT 的蝶形伴随递归寻址与内存搬运，每个「纸面复乘」的实际成本远高于直接法矩阵乘在 BLAS 峰值算力下的成本。提醒：大 $O$ 只保增长斜率，固定规模下的胜负要实测——本题里 FFT 依然快十万倍，但「渐近优」不自动等于「常数优」， crossover 点永远靠测量。（§3.3）
5. 截断＝乘 $\mathbf{1}_{[0, N)}$，频域＝原像的谱卷上 $\frac{\sin\omega}{\omega}$（Dirichlet 核）；旁瓣轮廓是窗的确定函数，真实频率落在两根谱线之间的位置决定采样打到旁瓣的哪一点——全程确定、无随机成分。数值误差是 $10^{-16}$ 相对位阶的事（§3.2 实测），泄漏是百分之几到几十的能量再分布，两者差十个数量级。（§3.4、§2.1）
6. 不一定。直接 $O(nm)$ 对 FFT $O(n \log n)$：粗算 $m < \log_2 n$ 时直接法占优（FFT 的三次变换常数还在陪跑）。$m$ 极小的场景：图像处理里 $3 \times 3$ 卷积核的边缘检测、几十个抽头的 FIR 滤波器——直接滑窗是标配，搬 FFT 反而亏。（§3.2、§3.3）
