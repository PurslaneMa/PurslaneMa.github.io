# $\rm Chapter \, 5$ 多智能体协作

> **本章假设你已经会**
>
> 1. agent 是一个 while 循环，按感知、决策、行动、反馈四步首尾相接，上下文是循环的唯一状态；窗口装不下时要砍，砍法有滑窗、摘要、检索回填三种，见 §1.2 与 §2.1–§2.3。
> 2. 判定原语与查证约定：每次判断以概率 $p$ 正确，否则从其余选项里均匀挑一个；查证错误率按生成错误率的一半计，$v=1-(1-p)/2$，见 §4.1 与 §4.2。
> 3. 规划漂移：不复述时目标遗忘按 $(1-d)^{L^{*}}$ 收指数税，定期复述把账按段结清，见 §4.5。
> 4. 子目标分解的两条收益通道：切短上下文抬高质量、把检查外包给外部验证器，见 §4.3。
> 5. 实验环境约定同前几章：WSL2 的 python3、无外网、无 API、固定种子 20261108，脚本与完整输出在 `_uni5_work/expEA05/` 的 `exp.py` 与 `result.txt`。

第 4 章把一个循环里的推理组织出了四种范式，但从头到尾决策器只有一个：感知、规划、执行、检查、记笔记全是它在干。本章处理决策器不够用的情形。先看一个决策器卡在哪（§5.1），再立起多智能体系统的三块积木：角色、消息、共享状态（§5.2），然后给三种组织方式各立一节：分工流水线（§5.3）、辩论与仲裁（§5.4）、编排（§5.5），最后用两个锚点实验把话说成可复核的数字：两 agent 辩论对单 agent 自我一致性采样的准确率与收敛轮数（§5.6），规划者-执行者-检查者流水线对单 agent 的完成率与代价（§5.7）。学完本章你能说出每种协作范式买到的是什么、付的是什么、在什么条件下反亏。

## $\rm \S \, 5.1$ 问题：一个决策器的三重瓶颈

把第 4 章结尾的那个循环放到一个 30 步的任务里，三件事会先后顶到天花板。

1. **窗口瓶颈**。一个循环的上下文要同时装任务陈述、计划、每一步的工具观察和自查记录，账单按轮线性涨（§2.1）。第 4 章的规划漂移病根就在这里：任务陈述被几十条观察挤到桌面最底下（§4.5）。单 agent 的解法是复述，一行文本补丁；但它救不了桌面本身的拥挤。
2. **自证瓶颈**。生成者自证清白靠不住：同一个上下文喂出来的复查，带着同一套错误模式（§4.6 错误二）。ToT 的查证增益 $v$ 在真实系统里要靠不同来源兑现，而单 agent 天然只有同一个来源：它自己。
3. **单点瓶颈**。决策者同时扮演规划者、执行者、检查者和记账员。走神的人和负责拉回的人是同一个：漂移发生后，系统里没有任何一个部件还盯着原始目标。

三重瓶颈指向同一个动作：把 §1.2 的循环复制几份，让每份只背一摊事。这就是本章的主角。

定义（多智能体系统，multi-agent system）：由多个 agent 循环组成的系统，每个循环有自己的角色职责与上下文范围，彼此通过消息或共享状态交换观察与决定，共同完成一个任务。先泼一盆冷水：第 6 个字起就要警惕，「多个 agent」三个字本身不产生任何准确率，§5.6 会用实验证明不加机制的堆人头与单 agent 打平。产生收益的是分工之后长出来的结构：更短的上下文、独立的错误模式、专职的检查者。

白话：这就像一个人开会又主持又记录又汇报，三件事都会被另外两件挤掉；拆成三个人，每人一张小桌子，桌上的纸少了，出错的人也有了旁观者。

> 本节小结：单 agent 的三重瓶颈是窗口拥挤、生成者自证、决策单点；多智能体系统的定义是多个带角色与上下文范围的循环加通信，「多」本身不是收益，收益来自分工长出来的结构。

## $\rm \S \, 5.2$ 新概念：角色、消息与共享状态

角色（role）：一个 agent 循环的职责与其上下文范围的组合。两个要点把角色和「多开几个模型」区分开。其一，角色不要求多份权重：同一份模型配三套系统提示、三个独立消息列表，就是三个角色；要不要真的部署三份模型是成本问题，第 8 章算这笔账。其二，角色的本质是上下文范围：执行者的桌面只摆当前子目标，检查者的桌面只摆计划与最新位置，桌面小正是 §2.1 要花钱买的东西，分工把它变成了结构。

通信有两极。消息传递（message passing）：每个角色维护自己的上下文，按协议互发消息；共享状态（shared state）：一块公共存储，各角色读写同一份任务状态。两极可以混用，但无论站哪一极，消息都可能丢、迟、错、重，《分布式系统》§1.2 的失败三件套（网络、时钟、进程）在 agent 之间原样成立；多个角色对「现在该谁动手」争执不下时，靠决定性多数破局，这正是《分布式系统》§3.3 选举协议里一人一票加多数派的思路。本册只取接口层：把每条消息当成「可能迟到的信」，把每次表决当成「必须能数出胜负的票」。

三范式按合作紧密程度排列：分工把任务切开各管一段（流水线）；辩论让各角色答同一道题互相挑错；编排设一个调度者分派与汇总。三者的收益与代价在 §5.3 至 §5.5 逐个立起来，§5.6 与 §5.7 各用一个实验验收。

白话：消息传递是各记各的笔记本、定期互抄；共享状态是一块大家都能写的黑板。笔记本丢了只坏一个人，黑板坏了全场抓瞎，两种账法各有各的赔法。

> 本节小结：角色＝职责＋上下文范围，不要求多份权重；通信两极是消息传递与共享状态，消息的丢迟错重与多数派表决直接对接分布式系统的结论；三范式是分工、辩论、编排。

## $\rm \S \, 5.3$ 范式一：分工——规划者、执行者、检查者

分工流水线把一个任务切成三段职责，各配一个循环：

1. **规划者（planner）**：读任务与世界知识，产出子目标序列和每段的路线。它的上下文装全局信息，只在大节点被调用。
2. **执行者（executor）**：拿当前子目标与路线，一步一步走，每步产出一个观察。
3. **检查者（checker）**：持计划副本，逐条比对执行者的位置与状态，发现偏差就触发修正。

三个上下文全是常数长度：执行者的桌面只有子目标、路线余段和最新一条观察；检查者的桌面只有计划副本和执行者的最新位置。第 2 章那笔越用越贵的账单（§2.1）在这里被结构冻结了。§4.3 给分解立的两条收益通道，一条在这里兑现成设计，一条兑现成代码：

1. **切短上下文**。§4.4 用「假设质量抬升 0.15」的情景分析量过这条通道的杠杆，当时它是假设；分工把它变成岗位设置：执行者不需要复述，因为它的桌面上从来只有一段任务。
2. **检查外包给不吃 $p$ 折扣的裁判**。检查者的两种发现都是程序化比对：执行者位置不等于计划的预期位置（包括撞上「计划当它可走、现实是墙」的格子，即计划与地图冲突）；执行者走神，定义是不再读计划的执行状态。发现不用动模型，动的只有修正：把走神的执行者拉回主线要检查者重新下达子目标（质量按 $v$ 计），位置偏了要规划者从当前位置重排路线（质量按 $p$ 计）。

与 §4.5 的复述对照着看：复述是文本补丁，每 $R$ 步把目标写回窗口一次，占用桌面一行；检查者是结构补丁，比对每步都在发生，且不占执行者的桌面。两者买的是同一种东西（漂移税的按段结清），补丁位置不同，代价形态也不同，§5.7 让它们同台。

分工有一条藏得最深的边界：检查者盯的是「执行是否符合计划」，计划本身错了它看不见，它手里那份副本就是错的。审计划是另一道工序，交给谁、值不值，§5.7 的实验专门测这一格。

白话：工地上的分工是施工员照图干活、质检员拿图纸对实物。质检员能抓「墙砌歪了」，抓不住「图画错了」，因为他对的就是这张错图；所以图纸还要有人审，审图和验墙是两道工序。

> 本节小结：分工流水线的三角色各有常数长度的上下文；检查者的发现是程序化比对（位置对计划、走神对计划），修正才动模型；它兑现了 §4.3 两条通道，边界是计划本身的错误不在它的职责内。

## $\rm \S \, 5.4$ 范式二：辩论与仲裁

分工适合「任务可切」的情形；任务切不开、答案却可判定时，用第二范式。辩论（debate）协议四步：各 agent 对同一问题独立给出初始答案；逐轮交换答案与理由；答案一致即收敛停机；不一致触发复核，轮数封顶后交仲裁（arbiter）裁决。

仲裁先立一条规矩：裁决必须能数出胜负。两票一致时多数即结果，平局时本章掷硬币；《分布式系统》§3.3 选举协议用任期与多数派解决的正是同一个问题——票数持平的裁判等于没有裁判。拿《博弈论》§1.1 的三要素对齐：玩家是各 agent，策略是当前答案，支付是裁判按可检验真值打的分数。两个 agent 共享同一份支付，这是共同支付博弈，不是《博弈论》§2.1 那种你赢我输的零和对抗；辩论收敛到的是「两人都无话可说」的均衡点，不是谁压倒谁。

模拟里的辩论压成三个参数，判定原语 $q$ 沿用 §4.1：

1. **复核纠错率 $c$**：知道两人不一致后，对照可检验证据重查，把自己的错误改对的概率。这是查证不对称（§4.2）在辩论里的化身：查证一个具体答案比凭空生成容易。
2. **从众率 $f$**：不查，直接采纳对方当前答案的概率。这是辩论特有的风险通道：对的也可能被错的带跑。
3. **轮数上限 $R$**：封顶后交仲裁，防止两人各执一词无限烧轮次。

写代码前先算两笔账，免得把收益记错地方。第一笔，多数投票 $k{=}2$：两票全对概率 $q^2$，恰一票对是平局、掷硬币得半：

$$
P_{\text{SC},2}\;=\;q^{2}+2q(1-q)\cdot\tfrac{1}{2}\;=\;q
$$

与单次作答一字不差。把 agent 翻倍、举手表决，准确率纹丝不动；不加复核机制的「多 agent」就是这么一钱不值。

第二笔，辩论一轮的转移账。初始一致时直接收敛，没有账；从「甲对乙错」的不一致态出发，甲只有从众（概率 $f$）会被带错，乙复核改对（概率 $c$）或从众改对（概率 $f$，采纳对的甲）。两者独立，四种联合结局：

$$
\text{一致且对}=(1-f)(c+f),\quad \text{一致且错}=f\,(1-c-f),\quad \text{仍不一致}=\text{其余}
$$

代入 $c=0.6$、$f=0.15$：一致且对 $0.85\times0.75=0.6375$，一致且错 $0.15\times0.25=0.0375$，仍不一致 $0.325$。逐轮递推、$R{=}4$ 轮封顶后仲裁掷硬币，分歧态的最终正确率 $s_4=0.9395$，整体准确率

$$
P_{\text{辩论}}\;=\;q^{2}+2q(1-q)\,s_4\;=\;0.5625+0.375\times0.9395\;\approx\;91.5\%
$$

§5.6 的实测是 91.1%，账面与实测咬合。同样的转移账给出「一致但错」率 $8.5\%$，实测 $8.7\%$：初始两人同错的 $(1-q)^2$ 那一份没有任何复核机会，一致即停的协议会把它当成收敛确认盖章放行。

白话：辩论像两名侦探各破各的案，供词对上了就结案，对不上就回去重查卷宗；风险也有两条，两人一开始就看走眼（一致地错），或者口供一对就互相抄作业（从众）。

> 本节小结：辩论协议是「独立初始答案、一致即停、不一致复核、轮满仲裁」；$k{=}2$ 多数投票与单次等价，辩论的增益全部来自「不一致触发的复核」；失效模式是一致地错与从众带偏，两者都有转移账可算。

## $\rm \S \, 5.5$ 范式三：编排

分工与辩论的结构在任务开始时定死；任务形状事先未知、子任务数量随时变时，需要第三个角色。编排器（orchestrator）：持有任务全局视图、拆分并分派子任务、回收结果、决定下一步的调度循环。它是 §3.4 并行工具调用的 agent 版升级：独立子任务扇出（fan-out）并发执行，有依赖的串行排队，判定「独立还是依赖」的活从模型的一次判断升级为编排器的常设职责。

这个形状你在《分布式系统》§2.3 见过：MapReduce 的协调器拆任务、派 worker、收结果、做洗牌，编排器与它的差别只在 worker 换成了 agent 循环。同构也把病带过来了：协调器是单点（§2.5），编排器倒了整个编排停摆；更隐蔽的是窗口，所有子任务的状态都汇聚到编排器的上下文里，它自己最先撞上 §2.1 的账单。对策是状态外置：子任务状态写进共享存储，编排器只持索引与指针，把「记住一切」换成「知道去哪查」。

编排器还是辩论里的常设裁判：两个 agent 对下一步各执一词时，由它按规则裁决。没有这个角色，两个自封的正主会互相覆盖对方的状态，《分布式系统》§3.1 的标题就是判决书：两个正主比没有正主更糟。

白话：编排器是项目现场的总调度，任务来了一手派工一手收活；它的桌子最小化地摆着「谁在干什么」，而不是「每件事的全部细节」，后者会让它变成第一个被淹没的人。

> 本节小结：编排器＝分派、回收、裁决的调度循环；它与 MapReduce 协调器同构，连单点故障与窗口汇聚两个病一起继承过来，对策是状态外置；两个 agent 起冲突时，无裁判的僵局比单打独斗更糟。

## $\rm \S \, 5.6$ 锚点实验一：两 agent 辩论收敛 vs 自我一致性

实验问题取自同一批网格世界：每个世界里有两把钥匙，问「哪把离起点更近」。真值由 BFS 距离场直接可判，生成时距离相等的平局世界重抽（重抽 10 次），保证 150 个问题个个有唯一答案。判定原语同 §4.1：每次判断以概率 $q$ 正确。辩论约定 $c=0.6$、$f=0.15$、$R=4$，均为建模约定而非文献数字。对照组是自我一致性（self-consistency）：单 agent 对同一问题独立采样 $k$ 次、多数投票、平局掷币。每格 $150$ 世界 $\times\,100$ 回合 $=15000$ 回合，种子 20261108，整个实验在 WSL 的 python3 上不到 3 秒。

$q$ 从 0.55 扫到 0.95，主表如下（判定预算：辩论 $R{=}4$ 在 $q{=}0.75$ 时平均每回合 $3.11$ 次判定，少于自我一致 $k{=}6$ 的 6 次）：

| $q$ | 单次 | 自我一致 $k{=}4$ | 自我一致 $k{=}6$ | 辩论 $R{=}2$ | 辩论 $R{=}4$ |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 0.55 | 55.0% | 57.1% | 59.5% | 74.4% | 76.3% |
| 0.65 | 64.7% | 71.7% | 75.9% | 82.8% | 85.0% |
| 0.75 | 75.2% | 84.1% | 89.8% | 90.3% | 91.1% |
| 0.85 | 85.2% | 93.8% | 97.3% | 95.2% | 96.2% |
| 0.95 | 94.9% | 99.4% | 99.9% | 98.7% | 99.2% |

读法有五层。第一层，低质量区辩论赢面最大：$q{=}0.55$ 时自我一致 $k{=}6$ 只从 55.0% 爬到 59.5%，辩论 $R{=}4$ 到 76.3%，判定数还更少。第二层，自我一致性的账面咬合：$k{=}6$ 的二项式账面在 $q{=}0.55$、$0.75$、$0.95$ 分别为 59.3%、89.6%、99.9%，对实测 59.5%、89.8%、99.9%；$k{=}2$ 的账面就是 $q$ 本身（§5.4 第一笔账），实测 55.1% 对 55.0%。第三层，消融定位增益来源：

| $q$ | 辩论无复核（$c{=}0$） | 辩论无从众（$f{=}0$） | 一致但错率 | 平均收敛轮 |
| :--- | :--- | :--- | :--- | :--- |
| 0.55 | 56.1% | 79.5% | 23.5% | 0.71 |
| 0.75 | 75.3% | 93.4% | 8.7% | 0.55 |
| 0.95 | 95.1% | 99.6% | 0.8% | 0.14 |

无复核的辩论三个点全部退回单次水平（56.1% 对 55.0%，75.3% 对 75.2%）：从众对称地双向流动，去掉复核后两人互抄作业的净效果是零，增益归零。无从众的辩论比完整协议高 2 到 3 个百分点：从众是净损失项，留着它只因真实系统里模型确实会被对方的流畅理由带跑。第四层，失效模式有账可依：「一致但错」率实测 23.5%、8.7%、0.8%，对转移账的 $(1-q)^2$ 加从众污染一份；$q{=}0.55$ 时每四个回合就有一个是两人齐齐看走眼然后互相确认。第五层，收敛很快且边际递减：平均收敛轮 0.14 到 0.71，$R{=}2$ 到 $R{=}4$ 在 $q{=}0.75$ 只多挤出 0.8 个百分点，轮数上限设 2 到 3 就够。

异质队伍单测一组：$p_A=0.9$ 配 $p_B=0.6$，辩论 $R{=}4$ 得 93.6%，高于强者单次的 90.4%，低于强者自我一致 $k{=}6$ 的 99.1%，弱者单干的 $k{=}6$ 只有 68.4%。读法：弱队友胜过没有队友，但同预算下不如强者自己多采几次样；辩论红利的另一个前提是队友质量不能差太悬殊，否则「一致但错」与仲裁平局把优势吃掉。

边界照实声明。复核纠错率 $c$ 在模拟里是外生常数，且与 $q$ 无关；真实系统里复核由模型完成，它的质量取决于证据是否可检验：可判定问题的答案能对表，复核便宜；开放问题的复核质量会向 $q$ 靠拢，辩论对自我一致性的优势随之缩水。数字不可直接迁移，机理可以。

白话：这场比的是「一个人掷六次骰子数多数」对「两个人对答案、不对就重查」。人多不等于更准，准的是那句「咱们俩对不上，总有一个人错了」带来的回头重查；但两个人齐齐看走眼时，对答案只会更快地错到一起。

> 本节小结：15000 回合/格的扫描里，辩论 $R{=}4$ 在低质量区领先自我一致性 17 个百分点而判定数更少（3.11 对 6）；无复核消融退回单次，证明增益全部来自复核；一致但错率 23.5% 到 0.8% 是协议的固有失效，异质队伍的收益受弱队友质量拖累。

## $\rm \S \, 5.7$ 锚点实验二：分工流水线 vs 单 agent

实验二把协作放回完整任务：与第 4 章同配方的 150 个世界（$10\times10$、14 墙、两钥匙加终点），$L^{*}$ 最短 6 步、中位 21 步、最长 38 步、平均 21.1 步，预算 $B=\lceil1.8\,L^{*}\rceil$ 平均 38.5 步。判定原语同 §4.1，查证质量 $v=1-(1-p)/2$。每个执行侧都有每步 $d{=}0.02$ 的漂移概率：走神的执行者从此随机乱走。五个条件：

1. **单 agent 无复述**：第 4 章的闭环贪心，漂移无人拉回。
2. **单 agent＋复述**：每 8 步把目标写回一次，拉回概率 $r{=}0.9$（§4.5 的补丁）。
3. **流水线·只盯执行**：规划者给路线（以概率 $p$ 正确，否则按一张随机挪过墙的损坏地图规划），执行者沿路线走，检查者程序化比对位置，偏了或走神就重排路线或拉回；计划本身无人审查。
4. **流水线·盯执行＋审计划**：检查者额外逐案审查计划，查出损坏计划（概率 $v$）打回重规划。
5. **流水线·无检查者**：只留规划者与执行者，偏差无人发现。

每格 150 世界 $\times\,2$ 回合 $=300$ 回合。成功率：

| $p$ | 无复述 | ＋复述 | 只盯执行 | 盯执行＋审计划 | 无检查者 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 0.55 | 6.0% | 6.0% | 4.7% | 4.3% | 0.0% |
| 0.75 | 40.7% | 55.3% | 49.7% | 59.0% | 2.3% |
| 0.95 | 63.7% | 96.0% | 93.7% | 94.0% | 30.7% |

再压一档漂移扫描（$p{=}0.75$，$d$ 扫三档）：

| $d$ | 无复述 | ＋复述 | 只盯执行 | 盯执行＋审计划 | 无检查者 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 0.01 | 55.7% | 61.7% | 55.3% | 55.3% | 4.3% |
| 0.02 | 42.7% | 52.7% | 52.0% | 54.7% | 3.0% |
| 0.04 | 24.7% | 46.0% | 48.0% | 52.7% | 3.0% |

五层读法。第一层，无检查者的流水线全面崩塌（0.0% 到 4.3%，$p{=}0.95$ 也只有 30.7%）：分工的最惨样板。两个死因，漂移永久化（§4.5 的指数税无人结清），加上坏计划卡死：规划者的损坏地图路线可能穿过现实中是墙的格子，执行者撞墙原地打转，计划与位置的比对没人做，预算烧光也不报警。第二层，无复述单 agent 的曲线贴理论：$p{=}0.95$ 时每步几乎不出错，失败几乎全来自漂移，实测 63.7% 对 $(1-0.02)^{21.1}\approx65.3\%$ 的账面，漂移税在这个点上是唯一主犯。第三层，文本补丁与结构补丁的交叉点：低漂移区一行复述更划算（$d{=}0.01$ 时 61.7% 对 55.3%，专职检查者的重排开销换不来多少拉回机会）；漂移越大，每步盯梢的检查者优势越大（$d{=}0.04$ 时 48.0% 与 52.7% 对 46.0%）。买不买专职检查者，取决于你的任务漂得多不多。第四层，审计划补上了 §5.3 预告的盲区：$p{=}0.75$、$d{=}0.02$ 时只盯执行 49.7%、加上审计划 59.0%，$d{=}0.04$ 时 48.0% 对 52.7%；漏网的那些损坏计划「更长但可执行」，位置比对永远发现不了，只有审计划这道工序能拦。第五层，低质量区全体趴下：$p{=}0.55$ 时五个条件挤在 0% 到 6%，§4.3 的预言原样再现，分工不产生判定质量，质量不够时组织方式无从兜底。

成本账在表 2 的判定数里。$p{=}0.75$：单 agent＋复述每回合 34.9 次判定（每步一次）；只盯执行 35.1 步加 29.7 次规划判定；盯执行加审计划 34.5 步加 48.9 次，合计约 2.4 倍。$p{=}0.95$：26.3 对 30.1，只有约 1.15 倍。分工的成本倍数随质量升高而下降：质量越高，滑步与坏计划越少，检查者的复核次数越少。

白话：三个人的工地自己不会更稳。没人验货，歪了没人喊（无检查者，全崩）；图纸本身错时，验货员对的是错图（只盯执行，漏一半）；而活儿本身就干不利索时（$p{=}0.55$），人再多也是一起歪。

> 本节小结：无检查者的分工是最差配置（2.3% 对单 agent 的 40.7%）；无复述单 agent 贴 $(1-d)^{L^{*}}$ 账面；复述与检查者在 $d\approx0.02$ 处交叉，漂移越大越该上专职检查者；审计划补盲区值 9 个百分点；成本倍数 1.15 到 2.4，随 $p$ 升高而下降。

## $\rm \S \, 5.8$ 常见错误与证据式排查

错误一：把「多 agent」当成功率开关。三个循环接起来就算协作，不加任何复核与检查机制。实验已经给过两笔反账：无复核辩论 75.3% 对单次 75.2%，平手；无检查者流水线 2.3% 对单 agent 40.7%，倒退。排查方法：消融。逐个关掉角色（检查者、复核轮、仲裁），每个角色的价值等于关掉前后的成功率之差，差值为零的角色就是在白拿预算。

错误二：检查者与执行者共用一套上下文。图省事让检查者直接读执行者的消息列表，等于让生成者自证清白（§4.6 错误二的翻版）：同一份上下文养出同一套错误模式，检查者会系统性放行同类错误。健康的实现里检查者只持独立的计划副本与最新观察。排查方法：喂 20 个已知有缺陷的计划给检查者，统计拦截率；拦截率与生成准确率同量级时，检查在装饰。

错误三：只盯执行、不审计划。§5.7 第四层量过这笔税：损坏但可执行的计划在位置比对下完全隐身，9 个百分点的成功率白丢。排查方法：故意注入一条绕远路的计划，看系统几步之内发现；发现不了，就是缺审计划这道工序，或者缺一个能对表的验证器（编译、测试、schema 校验，§3.2 与 §4.3 通道二）。

错误四：把「两人一致」当「答案正确」。辩论的收敛即停机制会确认错误：$q{=}0.75$ 时一致但错率实测 8.7%，低质量区高达 23.5%。对策是给收敛加外部裁判：可检验问题对表（本章的 BFS 真值），开放问题引入第三方评审或环境验证，仲裁不能拿「吵得久」「声音大」当判据。

错误五：编排器变成新的单点。所有子任务状态涌进编排器的上下文，它同时成为窗口瓶颈与故障单点，《分布式系统》§2.5 给过同款病历。排查方法：画编排器上下文长度随任务规模的增长曲线，线性以上就要状态外置；再把编排器手动 kill 一次，看系统是停摆还是有接盘方案。

4. 把 `RESTEP` 从 `8` 改成 `4` 重跑。观察点：复述条件的成功率是否逼近流水线（更密的拉回），以及对账 §2.1 时这笔改动在真实系统里多出的窗口常驻成本，模拟里为什么不显现。

## $\rm \S \, 5.12$ 本章自测答案

概念回顾答案：

1. 窗口瓶颈卡在任务陈述被观察挤出上下文（§2.1、§4.5），自证瓶颈卡在复查与生成共用同一套错误模式（§4.6 错误二），单点瓶颈卡在走神者与拉回者是同一个部件。「多 agent」不构成答案：$k{=}2$ 多数投票准确率等于单次（§5.4 第一笔账），无复核辩论与无检查者流水线的实测都低于或等于单 agent（§5.6、§5.7），收益来自复核、独立比对这些结构（§5.1）。
2. 职责与上下文范围缺一不可；上下文范围是本质：执行者桌面只摆子目标、检查者只摆计划副本，桌面恒短把 §2.1 的账单冻结成结构，也把「不受漂移污染」变成岗位属性而非自觉（§5.2、§5.3）。
3. 两种发现（位置对计划、走神对计划）都是程序化比对，不经过模型，与 §4.3 通道二同理；盲区是计划本身的错误（含「更长但可执行」的损坏计划），由审计划工序或外部验证器补，实测补回 9 个百分点（§5.3、§5.7）。
4. $P_{\text{SC},2}=q^2+2q(1-q)\cdot\frac12=q$，与单次等价（§5.4）。增益记在复核纠错率 $c$ 名下：转移账的一致且对概率 $(1-f)(c+f)$ 随 $c$ 增长，无复核（$c{=}0$）消融退回单次实测（56.1% 对 55.0%）是直接证据（§5.6）。
5. 死因一是漂移永久化（指数税无人结清），二是坏计划卡死（撞上计划里可走、现实是墙的格子，无人比对位置）。取舍条件：漂移率低时一行复述更划算（$d{=}0.01$ 时 61.7% 对 55.3%），漂移大时专职检查者值回票价（$d{=}0.04$ 时 52.7% 对 46.0%）（§5.7）。

应用与辨析答案：

1. 6 次判定预算下：3 个人头投票是 $k{=}3$ 多数，$q{=}0.75$ 时账面 $3q^2(1-q)+q^3=84.4\%$，比单次高约 9 个百分点，但仍低于自我一致 $k{=}6$ 的实测 89.8% 与辩论 $R{=}4$ 的 91.1%，而辩论平均只用 3.11 次判定，省下的预算还能加一轮复核。把钱花在复核轮上。前提：问题可判定、复核确有独立证据可对表（$c$ 不会退化到 $q$），且队友质量不相差悬殊，否则退回强者自我一致 $k{=}6$（99.1%）更稳（§5.4、§5.6）。
2. 排查一步：检查检查者手里的信息——它有没有独立的计划副本，还是只复读执行者的消息列表；排查二步：注入一条绕远但可执行的计划，看几步内被发现。最可能落在错误三（只盯执行不审计划）：执行者沿一条损坏路线规规矩矩地绕圈，位置始终「符合」那份坏计划，盯执行的比对永不报警（§5.8 错误三、§5.7 第四层）。
3. 反例机理一：初始同错的早停，$(1-q)^2$ 的收敛被协议盖章确认，$q{=}0.75$ 时连同从众污染合计一致但错 8.7%；机理二：从众带偏，对的 agent 以概率 $f$ 被错的对手带跑，转移账里 $f(1-c-f)$ 那一格。工程条件：给收敛加不依赖两 agent 的第三方验证（对表、测试、评审模型），一致只是必要条件，可检验证据才是充分条件（§5.4、§5.6）。

**你现在能做什么**：你能对着一个协作方案说出它是分工、辩论还是编排，算出 $k{=}2$ 投票与一轮辩论的转移账，用消融判断哪个角色在真正干活，能读出检查者的职责盲区，并且知道在什么漂移水平上该把一行复述升级成一个专职角色。

协作把成功率抬上去了，但每个数字都是跑出来的，不是评出来的：换到真实模型与真实基准上，成功率怎么定义、pass@k 有什么统计陷阱、SWE-bench 的分数该怎么读，是第 6 章「评测与基准」的内容。
