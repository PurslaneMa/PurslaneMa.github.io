# $\rm Chapter \, 4$ 随机化数据结构：跳表、treap 与哈希分析

平衡树用一套确定性的旋转规则把高度钉在 $O(\log n)$，代价是每次插入删除都要维护那套规则、代码里塞满分情况讨论。本章换一条路：让结构自己掷硬币。跳表把「提升到上一层」交给独立的硬币，treap 把「谁当根」交给随机优先级，两者都只在**期望意义**下保证 $O(\log n)$ 的高度，却把实现简化到几十行。第三条路是哈希：假设键随机均匀，链长的集中性由上一章的 Chernoff 直接给出。本章把这三件事的账各自算清——跳表与 treap 是全证，哈希的通用族也只多一个计数引理。

> **开始前自检**：本章假设你已经会：
>
> 1. □ 期望线性性与指示变量（第 1 章 §1.2）：$\mathrm{E}[\sum_i X_i] = \sum_i \mathrm{E}[X_i]$。
> 2. □ 几何分布：每次成功概率 $p$、各次独立，首次成功所需次数的期望是 $1/p$（本站概率论册第 2 章）。
> 3. □ Chernoff 上尾界 $\Pr[X \ge k] \le (\mathrm{e}/k)^k$ 与联合界 $\Pr[\bigcup A_i] \le \sum \Pr[A_i]$（第 2 章 §2.2、§2.4）。
> 4. □ BST 的基本形状；模运算与「$p$ 素数时 $\mathbb{Z}_p$ 是域、非零元可逆」（本站数论册第 1 章）。
>

## $\rm \S \, 4.1$ 随机的三种用法：输入、结构与算法

随机性在算法里可以站在三个不同的位置。

1. **随机化输入假设**：不假设结构会掷硬币，而是假设**数据**（键的分布）是随机的。哈希表是这一档——「键均匀散列到各桶」这条假设一旦成立，链长、探测数的分析就变成纯粹的独立和问题。软肋是假设未必成立，一串同余的键就能把它打回线性。
2. **随机化结构**：随机性写进结构本身，任何输入都享受期望保证。跳表在插入时用硬币决定这个键出现在几层，treap 给每个键配一个随机优先级、用它当堆序的钥匙。两者对**任意**输入都给出期望 $O(\log n)$。
3. **随机化算法**：随机性写进控制流，同一个输入的两次执行路径可能不同。随机化快排、素性判定属于这一档。

白话：三种用法的差别在「谁在掷硬币」——数据掷（哈希）、结构掷（跳表/treap）、还是算法掷（快排）。本章做前两种，顺带把哈希这条「输入假设」的腿补齐；第三种已在第 1、3 章交代。

**本节小结**：随机性可落在输入、结构、算法三处；本章的两条主线是随机化结构（跳表、treap）与随机化输入假设（哈希）。

## $\rm \S \, 4.2$ 跳表：靠硬币决定层高（本章主证一）

跳表的基础是**有序链表**：一条链把键从小到大串起来。在裸链表里找键要顺着走，期望 $n/2$ 步，太慢。跳表在链表上再叠几层「高速公路」：每条高层链是低层链的稀疏子集，找键时从最高层出发，一路向右快进、撞过界就降一层，像先坐飞机、再换高铁、最后走街巷。

**结构**：每个键固定出现在第 $1$ 层；它再从第 $i$ 层**提升**到第 $i+1$ 层，概率 $p = 1/2$，各次提升互相独立。于是键的**层高** $L$ 满足

$$
\Pr[L \ge i] = p^{\,i-1} = \left(\tfrac12\right)^{i-1},\qquad \mathrm{E}[L] = \sum_{i \ge 1}\Pr[L \ge i] = \frac{1}{1-p} = 2.
$$

读法：单个键的期望层高是 $2$（几何分布的尾部求和）；高层越来越稀疏，第 $i$ 层的期望键数是 $n\,p^{\,i-1}$。

**层高与总高度**。全表的**高度** $\mathcal H$ 是最高的非空层。第 $i$ 层为空的概率是 $(1 - p^{\,i-1})^n \le \exp(-n\,p^{\,i-1})$，故 $\mathcal H$ 高概率不超过 $\log_{1/p} n + O(1)$ 层：取 $i = \lceil \log_{1/p} n \rceil + k$，该层非空的概率 $\le n p^{\,i-1} = p^{\,k-1}$（联合界），对固定 $k$ 已是指数小。$p = 1/2$ 时 $\mathcal H \approx \log_2 n$。

**查找代价的完整推导**。查找从表头最高层出发：尽可能向右，遇到下一个键更大（或到链尾）就下降一层，重复到第 $1$ 层。记比较次数为路径上访问的**节点数**（每向右看一个节点记一次）。用**反向分析**：把这条路从找到的键**倒着**走回表头。

反向每退一步，要么是「下来」（当前节点由上一层降下来，即它被提升到了上一层），要么是「向左」（当前节点与来路在同一层）。现在关键的一句：

> 站在第 $i$ 层的某个节点上反向看，上一步是「下来」当且仅当这个节点被提升到了第 $i+1$ 层——概率恰为 $p$；否则上一步是「向左」。

提升是各节点独立的硬币，所以「一直向左、直到遇见一个被提升的节点」所需的向左步数是几何分布，成功概率 $p$，期望 $(1-p)/p$ 步。把「一次上升」与「跟着的若干次向左」打包成一组，每组平均耗 $1 + (1-p)/p = 1/p$ 个节点。反向路径一共有多少次上升？恰好等于从第 $1$ 层爬到顶层的层数，即表高 $\mathcal H$。于是期望查找代价

$$
\mathrm{E}[\text{查找步数}] = \mathrm{E}[\mathcal H]\cdot\frac1p = \frac{1}{p}\,\log_{1/p} n + O(1)\;\overset{p=1/2}{=}\;2\log_2 n + O(1).
$$

读法：这就是「为什么是两倍」——第一份 $\log_2 n$ 是**垂直**穿过的高度（大约 $\log_2 n$ 层要降），第二份 $\log_2 n$ 是**水平**在每层里向右挪的步数；$p = 1/2$ 时每降一层平均要向右挪一步，水陆各一份，合起来正好两倍。$p$ 越大水平那段越省，但垂直那段 $\log_{1/p} n$ 越贵，最优在 $p = 1/\mathrm{e}$ 附近，工程选 $p = 1/2$ 只因实现最省。

**对比平衡树**：AVL、红黑树给**最坏情况** $O(\log n)$ 但要按固定规则旋转；跳表给**期望** $O(\log n)$，实现只是硬币加链表。极坏的硬币序列能压扁它，但概率随 $n$ 指数小。

**本节小结**：跳表用独立硬币决定层高，期望表高 $\log_{1/p} n$；反向分析把查找代价拆成「上升的层数」乘「每层的水平步数」，得 $\frac1p\log_{1/p}n = 2\log_2 n$（$p=1/2$）。它拿期望换实现复杂度。

## $\rm \S \, 4.3$ treap：随机优先级当堆序（本章主证二）

treap 的名字是 tree 与 heap 的合成：它同时满足两条序——对**键**是二叉搜索树（左小右大），对**优先级**是最小堆（父节点的优先级小于子节点）。键由输入给定，优先级在插入时**随机**赋予，一旦给好就不再改变。旋转是唯一维护手段：当子节点优先级比父节点小、破坏了堆序，就绕这条边旋转把它转上去。

**形状分布 = 随机 BST**。这是 treap 全部分析的支点，证明是一次一一对应：

> 给定 $n$ 个互异的随机优先级，treap 的形状被**唯一**确定，且这个形状恰等于「按优先级从小到大依次插入键」得到的 BST。

证明分两句。其一，最小优先级的键必须是整棵树的根——所有其他键的优先级都比它大，它做根才不违反堆序，而 BST 的根又必须把键分成左右两半，故根唯一确定，左右子树递归成立。其二，「按优先级从小到大插入的 BST」的根正是第一个插入者（优先级最小者），其余键按大小分到两棵子树、递归插入。两句对照，两种构造给出同一棵树。$\blacksquare$

既然优先级 $n$ 个互异值是均匀随机的，它们的**大小次序**就是一个均匀随机置换，于是「按优先级序插入」等于「按随机顺序插入」——**treap 的形状分布与随机 BST 完全相同**。这一句把 treap 的所有问题翻译成随机 BST 的经典结果。

**期望树高**。随机 BST 的高度 $H_n$ 满足（Devroye 1986）

$$
H_n = (1+o(1))\,c\ln n,\qquad c\ \text{是}\ c\ln\!\frac{2\mathrm{e}}{c} = 1\ \text{的唯一解},\quad c \approx 4.31107.
$$

读法：$c\ln\frac{2\mathrm{e}}{c}=1$ 不是凭空来的——它是一场大偏差优化的**驻点条件**；下面给半证看清来路。

**半证（不平衡概率的 Chernoff 界）**。固定一个键 $x$，看它从根到自己的路径。沿路每到一个节点，它的子树把键区间分成左右两段；若主元落在区间的中间一半，则两段都不超过原来的 $\frac34$，称这一步**好**。好主元的概率是 $\frac12$。攒够 $k$ 个好主元，区间缩到 $(\frac34)^k n$，取 $k = \log_{4/3} n$ 即缩到一个键。要把 $k$ 个好主元凑齐所需的步数服从负二项分布，用 Chernoff 压上尾得：$x$ 的深度超过 $2k(1+\delta)$ 的概率指数小。这只给 $\Theta(\log n)$ 的**阶**；把「中间一半」换成最优阈值 $\alpha$、再对 $n$ 个键取联合界，对 $\alpha$ 求极小，驻点方程恰是 $c\ln(2\mathrm{e}/c)=1$。

数值上，$n = 10^5$ 时 $4.311\ln n = 49.63$。这是**极限**常数：$\S4.5$ 实测平均树高约 $40.6$，明显低于它——$H_n/\ln n$ 收敛极慢，$n = 10^5$ 处比值才 $3.55$。所以期望树高是 $\Theta(\log n)$、极限常数 $4.311$，小规模上别当精确预测。至于维护堆序的旋转：新节点按 BST 落位后一路旋转上升，实测每次插入平均约 $2$ 次、随 $n$ 稳定在 $2$ 附近。

**本节小结**：treap 的形状分布就是随机 BST（优先级次序即随机插入序）；期望树高 $(1+o(1))c\ln n$、$c$ 解 $c\ln(2\mathrm{e}/c)=1$，半证由「好主元」的 Chernoff 加联合界给出；插入平均约 $2$ 次旋转。

## $\rm \S \, 4.4$ 哈希分析：输入随机假设下的三条账

哈希表把键映射到桶。**简单均匀哈希（simple uniform hashing）** 是最省事的假设：每个键独立地、均匀地落在 $m$ 个桶之一。三条常用账都从这条假设出发。

**(a) 分离链接的链长 Chernoff 界（回扣第 2 章）**。$n$ 个键散入 $m$ 个桶、每个桶一条链。固定桶的长度 $X \sim \mathrm{Bin}(n, 1/m)$。取 $m = n$，则 $\mu = \mathrm{E}[X] = 1$，这正是第 2 章 §2.2(b) 的哈希链。用上尾 Chernoff（$\theta$ 拧到 $\mathrm{e}^\theta = k$）得

$$
\Pr[X \ge k] \le \left(\frac{\mathrm{e}}{k}\right)^{k}:\quad k=3 \Rightarrow 0.744,\quad k=5 \Rightarrow 4.75\times10^{-2},\quad k=10 \Rightarrow 2.20\times10^{-6}.
$$

对 $n$ 个桶取联合界、取 $k = \frac{c\ln n}{\ln\ln n}$，即得最长链的高概率上界（第 2 章 §2.2(b)）。

**(b) 线性探测的期望探测数（Knuth，陈述级）**。开放定址不挂链，撞了桶就线性往后找下一个空位。装入因子 $\alpha = n/m$。Knuth 1963 给出两条闭式：

$$
\text{成功查找：}\ \tfrac12\!\left(1 + \frac{1}{1-\alpha}\right),\qquad \text{不成功查找：}\ \tfrac12\!\left(1 + \frac{1}{(1-\alpha)^2}\right).
$$

读法：$1/(1-\alpha)$ 是「平均要跨过的已占桶数」的一阶估计，成功查找沿已有键的链走、只摊到一半；不成功查找要走完整条探测簇、多一个平方因子。$\alpha \to 1$ 时两者爆炸——$90\%$ 满的表一次不成功查找要探约 $50$ 个桶，故开放定址要把 $\alpha$ 压在 $0.7$ 以下。

| $\alpha$ | 成功实测 | 成功公式 | 不成功实测 | 不成功公式 |
| --- | --- | --- | --- | --- |
| $0.5$ | $1.508$ | $1.500$ | $2.490$ | $2.500$ |
| $0.9$ | $5.384$ | $5.500$ | $47.903$ | $50.500$ |

（实测来自 $\S4.9$ 的程序，$m = 200003$，固定种子。）

**(c) 通用哈希族：万有性全证。** 简单均匀哈希是一句假设，工程里要用**能证明**的替代。一族函数 $\mathcal H = \{h : U \to [m]\}$ 称为**万有（universal）** 的，若对任意两个不同键 $x \neq y$，

$$
\Pr_{h \sim \mathcal H}\big[h(x) = h(y)\big] \le \frac1m.
$$

白话：万有族保证「随便两个键撞桶」的概率不超过「完全均匀散列」给出的 $1/m$，于是所有依赖简单均匀哈希的分析（链长、探测数）都能照搬，而不必相信数据真的均匀。

取素数 $p$，令键落在 $\mathbb{Z}_p$ 内、$m \le p$，对 $a \in \{1, \ldots, p-1\}$、$b \in \{0, \ldots, p-1\}$ 定义

$$
h_{a,b}(x) = \big((a x + b) \bmod p\big) \bmod m,
$$

$(a,b)$ 在 $(p-1)p$ 种取值上均匀抽取。**这是万有族**，证明如下。

**第一步（先看模 $p$ 的像）。** 记 $r = (a x + b) \bmod p$、$s = (a y + b) \bmod p$，两者都在 $\mathbb{Z}_p$。因 $x \neq y$ 而 $p$ 素数，$x - y$ 可逆，映射 $(a,b) \mapsto (r,s)$ 是**双射**：给定 $r \neq s$，由 $a(x-y) \equiv r-s \pmod p$ 唯一解出 $a = (r-s)(x-y)^{-1} \bmod p$（非零），再由 $b = r - a x$ 定 $b$。所以 $(r,s)$ 均匀分布在「$r \neq s$ 的有序对」上，每对概率 $1/\big(p(p-1)\big)$。

**第二步（数哪些 $(r,s)$ 会撞桶）。** $h(x) = h(y)$ 等价于 $r \equiv s \pmod m$。把 $\mathbb{Z}_p$ 按模 $m$ 的余数分成 $m$ 个类，第 $c$ 类大小记为 $n_c$（每个 $n_c$ 是 $\lfloor p/m\rfloor$ 或 $\lceil p/m\rceil$）。同类中取有序、互异的 $(r,s)$ 有 $n_c(n_c - 1)$ 对，合计

$$
N = \sum_{c=0}^{m-1} n_c(n_c - 1) = \sum_c n_c^2 - p.
$$

**第三步（上界）。** 用 $n_c \le \lceil p/m\rceil$ 与 $\sum_c n_c = p$：$\sum_c n_c^2 \le p\,\lceil p/m\rceil$，故 $N \le p\big(\lceil p/m\rceil - 1\big)$。写 $p = qm + r$、$0 \le r < m$：$r = 0$ 时 $\lceil p/m\rceil - 1 = (p-m)/m \le (p-1)/m$，$r > 0$ 时 $\lceil p/m\rceil - 1 = (p-r)/m \le (p-1)/m$——都给出 $N \le p(p-1)/m$。

**第四步（相除）。** 撞桶概率就是「$r \equiv s \pmod m$」的概率：

$$
\Pr[h(x) = h(y)] = \frac{N}{p(p-1)} \le \frac{p(p-1)/m}{p(p-1)} = \frac1m.
$$

读法：整个证明只有一处真正的技巧——「模 $p$ 的像 $(r,s)$ 均匀分布在对角线之外」这一步把均匀性搬到整张桌子上，剩下全是数同类元素、数完除以总数。这也解释了为什么需要 $m \le p$：$m > p$ 时取不到的桶破坏了「每类大小差不超过 $1$」，界就不成立了。$\blacksquare$

**本节小结**：分离链接的链长由 Chernoff 压成 $(\mathrm{e}/k)^k$；线性探测的两条期望探测数由 Knuth 闭式给出、$\alpha \to 1$ 时平方爆炸；通用哈希族在 $\mathbb{Z}_p$ 上给出可证明的 $1/m$ 冲突率，把「均匀假设」换成「定理」。

## $\rm \S \, 4.5$ 数值锚：实测与理论的对账

下面三组数来自 $\S4.9$ 的程序，全部本机实测、固定种子。

1. **跳表**（$n = 10^5$，$p = 1/2$）：成功查找平均比较 $30.875$，理论 $2\log_2 n = 33.219$——实测略低，是上界常数取松所致；最高层 $16$ 层，$\log_2 n = 16.61$。
2. **treap**（随机插入 $10^5$ 键、$200$ 次试验）：平均树高 $40.595$（最大 $49$），对照极限常数 $4.311\ln n = 49.632$——差距来自收敛慢（见 $\S4.3$）。
3. **线性探测**（$m = 200003$）：成功/不成功探测数 $\alpha = 0.5$ 为 $1.508 / 2.490$、$\alpha = 0.9$ 为 $5.384 / 47.903$，对照 $\S4.4$ 表的 Knuth 值。

**本节小结**：三条理论曲线与实测同数量级且趋势一致；treap 常数因收敛慢在 $10^5$ 处明显偏低，属极限常数的正常现象。

## $\rm \S \, 4.6$ 关键概念回顾

1. 随机性站在输入、结构、算法三处分别对应什么例子？为什么哈希的保证依赖「输入假设」而跳表的保证不依赖？
2. 跳表里 $\Pr[L \ge i] = p^{\,i-1}$ 怎么来的？单个键的期望层高为什么是 $1/(1-p)$？
3. 反向分析中，「上一步是下来」的概率为什么恰是 $p$？「一次上升 + 若干次向左」打包后每组期望几个节点？
4. treap「形状分布 = 随机 BST」的两句对应是什么？为什么「按优先级从小到大插入」等于「按随机顺序插入」？
5. 常数 $4.311$ 来自哪条方程？为什么说它是极限常数、$n = 10^5$ 处别当精确预测？
6. 通用哈希族的证明里，「模 $p$ 的像均匀分布在对角线之外」这一步解决了什么？为什么要求 $m \le p$？

## $\rm \S \, 4.7$ 应用与辨析

## $\rm \S \, 4.8$ 本章自测答案

> 先闭卷作答 $\S4.6$ 与 $\S4.7$，再核对。

### $\rm \S \, 4.8.1$ 关键概念回顾答案

1. 输入假设＝哈希、结构＝跳表/treap、算法＝快排与素性判定。哈希以「键均匀散列」为公理、敌人可破坏；跳表对任意输入只需硬币随机，无此软肋。（$\S4.1$）
2. 键从第 $1$ 层起、每次以概率 $p$ 提升，故 $\Pr[L\ge i] = p^{\,i-1}$。对 $i$ 求和得 $\mathrm{E}[L] = \sum_{i\ge1}p^{\,i-1} = 1/(1-p)$。（$\S4.2$）
3. 反向「下来」当且仅当当前节点被提升到上一层，提升是独立硬币、概率 $p$，故如此。每组（一次上升加紧跟的向左）期望耗 $1 + (1-p)/p = 1/p$ 个节点。（$\S4.2$）
4. 其一：最小优先级键必为根，左右递归；其二：「按优先级序插入」的 BST 根恰是第一个插入者（最小优先级者），左右递归。两句给出同一棵树。优先级次序均匀随机即随机置换，故等于随机插入序。（$\S4.3$）
5. $c$ 是 $c\ln(2\mathrm{e}/c)=1$ 的解（大偏差驻点条件），$c\approx4.311$。$H_n/\ln n\to c$ 收敛极慢，$n=10^5$ 处比值仅 $3.55$，故实测树高远低于 $4.311\ln n$。（$\S4.3$）
6. 它把「$\mathbb{Z}_p$ 上的均匀性」搬到「$(r,s)$ 均匀分布在 $r\neq s$ 的对上」。要求 $m\le p$ 才能让每类大小差不超过 $1$、使 $N\le p(p-1)/m$ 成立。（$\S4.4$）

### $\rm \S \, 4.8.2$ 应用与辨析答案

1. 不成立。$p$ 变大压缩**水平**那段（每层向左期望 $(1-p)/p$ 变小），但**垂直**那段 $\log_{1/p} n$ 变贵。总代价 $(1/p)\log_{1/p}n$ 在 $p = 1/\mathrm{e}$ 处取极小，不是 $1/\sqrt2$。（$\S4.2$）
2. 影响「高度 $\le \log_{1/p} n + O(1)$ 高概率」这一条：封顶后更大的 $n$ 无法再长高、退化风险上升。对 $n \le 2^{32}$ 恰好够用，是安全的工程取舍。（$\S4.2$）
3. 不影响摊还代价：单次旋转多只说明这一次贵，但期望旋转数是 $2$、总旋转数 $\Theta(n)$，摊到每次插入仍是 $O(1)$。（$\S4.3$）
4. 不能说明公式错。Knuth 公式给的是**期望值**，实测只是样本均值，$47.9$ 与 $50.5$ 的差落在涨落内；公式的均匀假设也比伪随机实现悲观。判断公式要看**大样本均值随 $\alpha$ 的趋势**。（$\S4.4$）
5. 不保证。万有性只控「任意固定一对」的冲突概率，不控「某个桶挤了 $5$ 个键」。补上高概率保证要再对 $n$ 个桶取联合界、用 Chernoff 压单桶上尾（$\S4.4(a)$）。（$\S4.4$）

## $\rm \S \, 4.9$ 程序对账

下面一段同时跑跳表、treap 与线性探测，输出与 $\S4.5$ 逐条对上（Python 3，固定种子）。

```python
import random, math
from math import log2, log
R = random.Random(20261103)                    # 固定种子，结果可复现
class Node:                                    # 跳表节点：key 加各层后继指针
    __slots__ = ("key", "fwd")
    def __init__(self, key, lv): self.key, self.fwd = key, [None]*lv
class SkipList:
    def __init__(self, p=0.5, cap=48):
        self.p, self.cap = p, cap
        self.head = Node(-1 << 60, cap)
        self.level, self.n = 1, 0
    def rand_level(self):                      # 层高 ~ 几何(1/2)
        lv = 1
        while R.random() < self.p and lv < self.cap: lv += 1
        return lv
    def insert(self, key):
        update = [None]*self.cap; x = self.head
        for i in range(self.level-1, -1, -1):
            while x.fwd[i] is not None and x.fwd[i].key < key: x = x.fwd[i]
            update[i] = x
        lv = self.rand_level()
        if lv > self.level:
            for i in range(self.level, lv): update[i] = self.head
            self.level = lv
        node = Node(key, lv)
        for i in range(lv):
            node.fwd[i] = update[i].fwd[i]; update[i].fwd[i] = node
        self.n += 1
    def search_cost(self, key):                # 查找成功的比较次数
        x, cost = self.head, 0
        for i in range(self.level-1, -1, -1):
            while x.fwd[i] is not None:
                cost += 1
                if x.fwd[i].key < key: x = x.fwd[i]
                else: break
        return cost
n = 100000; keys = list(range(n)); R.shuffle(keys)
sl = SkipList()
for k in keys: sl.insert(k)
sample = keys[:5000]
avg = sum(sl.search_cost(k) for k in sample)/len(sample)
print(f"skip-list  n={n}  avg comparisons = {avg:.3f}  vs 2*log2(n) = {2*log2(n):.3f}")

def bst_height(perm):                          # 随机置换建 BST 即 treap 形状
    left = [0]*(len(perm)+1); right = [0]*(len(perm)+1); dep = [0]*(len(perm)+1)
    root = perm[0]; dep[root] = 1; h = 1
    for k in perm[1:]:
        cur = root
        while True:
            if k < cur:
                if left[cur] == 0: left[cur] = k; break
                cur = left[cur]
            elif right[cur] == 0: right[cur] = k; break
            else: cur = right[cur]
        dep[k] = dep[cur] + 1
        if dep[k] > h: h = dep[k]
    return h
n = 100000; hs = []
for _ in range(200):
    perm = list(range(1, n+1)); R.shuffle(perm); hs.append(bst_height(perm))
print(f"treap      n={n}  avg height = {sum(hs)/len(hs):.3f} (max {max(hs)})  vs 4.311*ln(n) = {4.311*log(n):.3f}")

def linear_probing(m, ntarget, miss_trials=20000):
    table = [None]*m; keys = R.sample(range(1, 10**9), ntarget)
    for k in keys:
        h = k % m
        while table[h] is not None: h = (h+1) % m
        table[h] = k
    succ = 0
    for k in keys:                             # 成功查找探测数
        h = k % m; p = 1
        while table[h] != k: h = (h+1) % m; p += 1
        succ += p
    miss = 0
    for _ in range(miss_trials):               # 不成功查找探测数
        k = R.randrange(1, 10**9); h = k % m; p = 1
        while table[h] is not None: h = (h+1) % m; p += 1
        miss += p
    return succ/len(keys), miss/miss_trials
m = 200003
for alpha in (0.5, 0.9):
    succ, unsucc = linear_probing(m, int(alpha*m))
    print(f"lin-probe  alpha={alpha}  succ {succ:.3f} (Knuth {0.5*(1+1/(1-alpha)):.3f})"
          f"  unsucc {unsucc:.3f} (Knuth {0.5*(1+1/(1-alpha)**2):.3f})")
```

输出（本机实测）：

1. `skip-list  n=100000  avg comparisons = 30.875  vs 2*log2(n) = 33.219`——实测略低于理论上界。
2. `treap      n=100000  avg height = 40.595 (max 49)  vs 4.311*ln(n) = 49.632`——低于极限值，收敛慢所致。
3. `lin-probe  alpha=0.5  succ 1.508 (Knuth 1.500)  unsucc 2.490 (Knuth 2.500)`。
4. `lin-probe  alpha=0.9  succ 5.384 (Knuth 5.500)  unsucc 47.903 (Knuth 50.500)`——致密端略低于闭式。

**带走清单**：三种随机化用法（输入/结构/算法）；跳表层高 $\Pr[L\ge i]=p^{\,i-1}$、反向分析得 $\frac1p\log_{1/p}n = 2\log_2 n$；treap 形状 = 随机 BST 的一一对应、$c\ln(2\mathrm{e}/c)=1$ 的常数 $4.311$、插入平均 $2$ 次旋转；链长 Chernoff 界 $(\mathrm{e}/k)^k$、Knuth 的两条探测数、$\mathbb{Z}_p$ 上万有族的 $1/m$ 全证。
