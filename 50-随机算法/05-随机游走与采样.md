# $\rm Chapter \, 5$ 随机游走与采样：MCMC 与图上的混合

有些分布你想要，却抽不出来：一个 $10^{30}$ 格的自旋系统的平衡态、一张随机图上的均匀完美匹配、一个贝叶斯模型的后验。它们的共同点是**能在某个点算出相对权重、却没法直接扔骰子**。本章的机器叫马尔可夫链蒙特卡洛（MCMC）：不去直接采样，而是让一个随机游走在状态空间上跑，跑久了它自己就把目标分布「抹」在走过的路上。主证是 Metropolis–Hastings 的细致平衡——它把「想要什么分布」翻译成「怎么设计转移」，再用一步代数证明平稳。随机游走在图上怎么走、多快混合，是这台机器能不能用的全部关键。

## $\rm \S \, 5.1$ 图上的随机游走：平稳分布就是度

从最朴素的对象开始：一张无向图 $G = (V, E)$，一个游走者在顶点间移动，每一步从当前顶点 $v$ 的邻居里**等概率**挑一个走过去。这就是**简单随机游走**。把它写成一个矩阵：转移矩阵 $P$ 的第 $(v, w)$ 元

$$
P_{vw} = \begin{cases} \dfrac{1}{\deg(v)}, & \{v, w\} \in E,\\[4pt] 0, & \text{否则}, \end{cases}
$$

读法：$P_{vw}$ 是从 $v$ 一步走到 $w$ 的概率；每行元素之和为 $1$（从 $v$ 出发必落到某个邻居），这种矩阵叫**行随机**。分布随时间的演化就是行向量右乘：$\mu_{t+1} = \mu_t P$。

**定理 5.1（无向图上的平稳分布）**：简单随机游走在连通无向图上恰有一个平稳分布 $\pi$，且

$$
\pi_v = \frac{\deg(v)}{2|E|}.
$$

白话：游走者**按度数成比例**地出现在各顶点——邻居越多的顶点，越容易被走到，长期占比就越大。证明只需一步直接验算：

$$
(\pi P)_u = \sum_{v \in V} \pi_v P_{vu} = \sum_{v \sim u} \frac{\deg(v)}{2|E|}\cdot\frac{1}{\deg(v)} = \sum_{v \sim u} \frac{1}{2|E|} = \frac{\deg(u)}{2|E|} = \pi_u.
$$

读法：从每个邻居 $v$ 流向 $u$ 的概率质量都是 $\frac{1}{2|E|}$，与 $v$ 的度数无关——游走者进 $u$ 的总流量就是「$u$ 的度数」乘以这个公共单价，正好等于 $\pi_u$。所以 $\pi P = \pi$，$\pi$ 平稳。唯一性来自连通性（不可约）与非周期性；无周期性靠惰性游走（以 $1/2$ 概率原地不动）保证。$\blacksquare$

**与电网络的对照**（本站高维概率册第 8 章）：随机游走的通勤时间、命中概率与电路的有效电阻一一对应——游走者在 $s$ 到 $t$ 间来回的平均步数是 $2|E| R_{\mathrm{eff}}(s,t)$。一句话接口：图上的「慢」本质上是电阻大，而电阻大的根子又是瓶颈窄。

**本节小结**：无向图上简单随机游走的平稳分布正比于度数 $\pi_v = \deg(v)/(2|E|)$，证明是一行流量验算；它与电网络是同一件事的两副面孔。

## $\rm \S \, 5.2$ 混合时间：多快才「抹匀」

游走迟早会逼近平稳分布，但「迟早」是多久？先把「多接近」量出来。两分布 ${p, q}$ 的**总变差距离（total variation distance）** 是

$$
\lVert p - q \rVert_{\mathrm{TV}} = \frac12\sum_x |p(x) - q(x)| = \max_{A \subseteq \Omega} |p(A) - q(A)|.
$$

读法：它是两个分布在**任何事件**上概率差的最大值——「最坏的一类事件上，两者相差多少」，是一个比逐点差更贴合「能不能分辨」的度量。于是从初始分布 $\mu$ 出发的**混合时间**定义为首次把 TV 距离压到 $\epsilon$ 以内的步数：

$$
t_{\mathrm{mix}}(\epsilon) = \min\big\{\, t : \lVert \mu P^t - \pi \rVert_{\mathrm{TV}} \le \epsilon \,\big\}.
$$

**两个极端**。一个是**完全图 $K_n$**：非惰性游走在 $K_n$ 上一步就跳到均匀分布（$t_{\mathrm{mix}} = 1$）；加上惰性也只要常数步——$\S5.5$ 实测 $K_{10}$ 用 $6$ 步把 TV 压到 $0.01$。一般谱隙界给的是 $t_{\mathrm{mix}} \lesssim \frac{\log n}{1 - \lambda_2}$，$K_n$ 的谱隙是常数，这不低于 $O(\log n)$、却是个松界；真实速度快得多。

另一个是**哑铃图（dumbbell）**：两个团用一条细桥连起来。直觉很清楚——游走者在左团里转两下就混匀了，可要跨到右团去，得先**恰好踩到桥的那两个端点**。设每团 $n/2$ 个顶点、桥只有一条边，两团内部的度数是 $\Theta(n)$，于是单个端点的平稳占比只有 $\Theta(1/n)$，一步落在桥上的概率 $\Theta(1/n^2)$，跨团一次要等 $\Theta(n^2)$ 步。

这就是**瓶颈**的代价。把它写成一条半证用的下界：对任意顶点集 $S$，**电导（conductance）** $\Phi = \min_S \frac{|\partial S|}{\mathrm{vol}(S)}$（$\mathrm{vol}(S)$ 是 $S$ 内度数之和）满足

$$
t_{\mathrm{mix}}(1/4) \gtrsim \frac{1}{2\Phi}.
$$

取左团为 ${S}$，$\mathrm{vol}(S) \approx n^2/4$、$|\partial S| = 1$，于是 $\Phi \approx 4/n^2$、$t_{\mathrm{mix}} = \Omega(n^2)$。完全图的 $\Phi = \Theta(1)$、混合 $O(1)$——两端的分水岭就是电导：**瓶颈（窄割）是唯一让混合变慢的元凶**。桥越长越窄，$\Phi$ 越小、混合越慢；在高维状态空间里瓶颈可以递推地变窄，混合时间随之指数恶化，这正是 MCMC 在高维上最难缠的应用场景。

**本节小结**：混合时间用总变差距离定义 $t_{\mathrm{mix}}(\epsilon) = \min\{t: \lVert\mu P^t - \pi\rVert_{\mathrm{TV}} \le \epsilon\}$；完全图靠常数电导 $O(1)$ 收敛，哑铃图被 $1/n^2$ 的电导拖成 $\Omega(n^2)$——快慢由瓶颈电导一手决定。

## $\rm \S \, 5.3$ Metropolis–Hastings：把目标分布装进接受率（本章主证）

现在回到主问题：想要从 $\pi$ 采样，但 $\pi$ 只给到**未归一化**的 $\tilde\pi$（把每个点的相对权重算出来可以，算总配分不行，因为状态空间太大）。MCMC 的思路是搭一条链，让它的平稳分布正好是 $\pi$，然后从某个起点跑够久、把到达的点当作近似样本。难点在于：怎么设计转移，使它以 $\pi$ 为平稳分布？

**Metropolis–Hastings（MH）** 给了一个万能配方。先挑一个**提议分布（proposal）** $q(y \mid x)$（从当前状态 $x$ 提议跳到 $y$；随便挑，只要处处能提议到），再按**接受率**决定跳不跳：

$$
A(x \to y) = \min\!\left(1,\ \frac{\pi(y)\, q(x \mid y)}{\pi(x)\, q(y \mid x)}\right),\qquad P(x \to y) = q(y \mid x)\, A(x \to y).
$$

读法：接受率里只有**比值** $\pi(y)/\pi(x)$，未知的归一化常数上下约掉了——这正是「只知道相对权重」也能工作的原因；$q(x|y)/q(y|x)$ 是对「提议本身有偏」的修正，若提议对称（$q(y|x) = q(x|y)$，如 ${y = x +}$ 噪声）它就等于 $1$，接受率简化为 $A = \min(1, \pi(y)/\pi(x))$。若 $y$ 的权重更高就必接受，更低则按比例接受——像一位「宁可错杀不肯放过高地」的登山者，往下也偶尔走，免得困在局部峰。

**定理 5.2（细致平衡推出平稳）**：若链满足**细致平衡（detailed balance）**

$$
\pi(x)\, P(x \to y) = \pi(y)\, P(y \to x)\qquad (\forall x, y),
$$

则 $\pi$ 是它的平稳分布。

全证：只需一行求和。对任意 $y$，

$$
(\pi P)_y = \sum_x \pi(x)\, P(x \to y) \overset{\text{细致平衡}}{=} \sum_x \pi(y)\, P(y \to x) = \pi(y) \sum_x P(y \to x) = \pi(y).
$$

读法：细致平衡说「$x \to y$ 与 $y \to x$ 两股概率流**逐对相等**」——像每个断面上的净流量都为零，于是整体分布原地不动。最后一步用了 $P$ 的行随机性（从 $y$ 出发必落到某处，$\sum_x P(y \to x) = 1$）。$\blacksquare$

**验证 MH 满足细致平衡**（这就把配方补成定理）。设 $\pi(x), \pi(y) > 0$。若 $\pi(y)q(x|y) \ge \pi(x)q(y|x)$，则 $A(x\to y) = 1$，而 $A(y\to x) = \frac{\pi(x)q(y|x)}{\pi(y)q(x|y)} \le 1$，于是

$$
\pi(x)\,P(x \to y) = \pi(x)\,q(y|x)\cdot 1 = \pi(y)\,q(x|y)\cdot\frac{\pi(x)q(y|x)}{\pi(y)q(x|y)} = \pi(y)\,q(x|y)\,A(y\to x) = \pi(y)\,P(y \to x).
$$

另一方向完全对称。读法：无论接受率里那道 $\min$ 取到哪一边，两个方向的乘积里的「小者」总是相等的——$\min$ 的作用就是**强行拉平**两股流，这正是 MH 设计得如此之巧的地方。$\blacksquare$

**Burn-in 与自相关**一句话：链要跑一段**预热期（burn-in）**再开始收样本（丢掉起点附近还没混匀的部分）；而相邻样本是相关的，有效样本数 $\approx$ 总样本数 $/\big(1 + 2\sum_k \rho_k\big)$（$\rho_k$ 是滞后 $k$ 的自相关），所以「跑多少步」要按**有效样本**而不是原始步数来算。

**本节小结**：MH 用提议 $q$ 加接受率 $A = \min(1, \frac{\pi(y)q(x|y)}{\pi(x)q(y|x)})$ 造链，接受率里只有权重比、归一化常数自动消掉；细致平衡一行推出平稳，再一步验算证明 MH 恰好满足它。预热去偏差、自相关折算有效样本。

## $\rm \S \, 5.4$ 应用：从 MDP 到 SAT 到 HMC

1. **强化学习的采样**（本站概率论册第 20 章）：MDP 的值迭代与 Q-learning 都要对「下一步会落到哪」取期望，而当环境模型只给相对概率时，就用蒙特卡洛采样代替求和——`ε`-greedy 与 UCB 的探索本质上是在状态图上跑一条带奖励的随机游走。
2. **近似计数**：想数一张图的完美匹配数（精确计数是 `#P` 完全），可以造一条「匹配之间互相翻转」的马尔可夫链，往下端跑到均匀分布后随机采样、用命中比例估计计数（Jerrum–Sinclair 1989 的经典路线），前提是这条链混合快。
3. **SAT 的随机游走**：Papadimitriou 1991 的 2-SAT 算法每次随机挑一个**未满足**子句、随机翻它一个文字，给出 $O(n^2)$ 的期望时间——一个纯粹的随机游走在变量赋值空间上找满足解。
4. **Hamiltonian Monte Carlo（HMC）**：把目标分布写成 $\mathrm{e}^{-U(x)}$，用一条模拟哈密顿动力学的轨迹做提议，接受率因能量近似守恒而很高（本站随机微分方程册第 9 章把 Langevin/HMC 作为「用 SDE 采样」的一节展开）。它是高维贝叶斯里替代随机游走 MH 的主力。

**本节小结**：MDP、近似计数、SAT、HMC 是同一个「造链—跑链—采样」模板的四件外衣；它们的可行性都押在混合快不快上，回扣 §5.2 的电导判据。

## $\rm \S \, 5.5$ 数值锚：实测分布、直方图与混合步数

三组实测（$\S5.9$ 程序，固定种子）。

1. **路径图上的平稳分布**：$5$ 个顶点的路径（端点度 $1$、内点度 $2$），惰性游走 $4\times10^5$ 步，经验频率与 $\pi \propto \deg$ 的卡方距离 $1.03\times10^{-4}$；$n = 10$ 时 $1.09\times10^{-4}$、$n = 20$ 时 $7.00\times10^{-4}$。当作概率分布的经验估计，这个量级已经「无法与真分布区分」。$n=5$ 的频率是 $[0.1272, 0.2521, 0.2498, 0.2471, 0.1238]$，对照 $\pi = [0.125, 0.25, 0.25, 0.25, 0.125]$。
2. **Metropolis 采双峰分布**：目标 $0.5\,\mathcal N(-2, 0.6^2) + 0.5\,\mathcal N(2, 0.6^2)$，对称提议 $\mathcal N(x, 1.5^2)$。$2\times10^5$ 个样本（预热 $2\times10^4$）得均值 $0.0368$（真值 $0$）、标准差 $2.0860$（真值 $2.0881$）、左峰质量 $P(x<0) = 0.4912$（真值 $0.5$）、平均接受率 $0.4643$。分箱对照（$[-3,-2)$ 段实测 $0.2196$ 对真值 $0.2261$、$[2,3)$ 段 $0.2307$ 对 $0.2261$）逐箱贴合。
3. **混合步数对比**：惰性游走从单点出发，TV 压到 $0.01$——完全图 $K_{10}$ 用 $6$ 步（TV 从 $0.9$ 掉到 $0.0156$）；路径图 $P_{10}$ 用 $136$ 步（TV 第 $1$ 步还停在 $0.833$、第 $5$ 步才 $0.613$）。$20$ 倍以上的差距正是电导 $\Theta(1)$ 与 $\Theta(1/n)$ 的分野。

**本节小结**：经验分布与 $\pi \propto$ 度只差卡方 $10^{-4}$ 量级；MH 采出的双峰直方图逐箱贴真密度、接受率约 $0.46$；混合步数 $K_{10}$ 六步对 $P_{10}$ 一百三十六步，量级差异肉眼可见。

## $\rm \S \, 5.7$ 应用与辨析

## $\rm \S \, 5.8$ 本章自测答案

> 先闭卷作答 $\S5.6$ 与 $\S5.7$，再核对。

### $\rm \S \, 5.8.1$ 关键概念回顾答案

1. 从 $v$ 出发必落到某个邻居，各邻居概率之和 $\sum_w P_{vw} = \deg(v)\cdot\frac{1}{\deg(v)} = 1$。「与度数无关」对应 $\pi_v P_{vu} = \frac{\deg(v)}{2|E|}\cdot\frac{1}{\deg(v)} = \frac{1}{2|E|}$ 这一步——单价对每个 $v$ 相同，故求和只数邻居个数。（$\S5.1$）
2. $\lVert p-q\rVert_{\mathrm{TV}} = \frac12\sum|p-q| = \max_A|p(A)-q(A)|$（把一半的过剩质量集中到最优事件集上）。$\epsilon$ 是「多接近算混合」的阈值，越小要求步数越多。（$\S5.2$）
3. 完全图 $O(1)$（谱隙界给 $O(\log n)$，实际更快）、哑铃图 $\Omega(n^2)$。电导 $\Phi$：完全图 $\Theta(1)$、哑铃 $4/n^2$；$t_{\mathrm{mix}} \gtrsim 1/(2\Phi)$ 把 $1/n^2$ 的电导翻成 $n^2$ 的等待。（$\S5.2$）
4. 接受率里只有 $\pi(y)/\pi(x)$，分子分母的归一化常数 $Z$ 上下相消；未知 $Z$ 也能算。提议对称时 $q(x|y)/q(y|x) = 1$，$A = \min(1, \pi(y)/\pi(x))$。（$\S5.3$）
5. 细致平衡把 $\sum_x \pi(x)P(x\to y)$ 换成 $\sum_x \pi(y)P(y\to x) = \pi(y)\sum_x P(y\to x)$；行随机给出 $\sum_x P(y\to x) = 1$，于是 $(\pi P)_y = \pi(y)$。（$\S5.3$）
6. 若 $\pi(y)q(x|y) \ge \pi(x)q(y|x)$ 则 $A(x\to y) = 1$、$A(y\to x) = \frac{\pi(x)q(y|x)}{\pi(y)q(x|y)}$，代进 $\pi(x)P(x\to y)$ 与 $\pi(y)P(y\to x)$ 两边都等于 $\pi(x)q(y|x)$。burn-in 丢起点偏差，自相关把相关样本折算成有效样本数。（$\S5.3$）

### $\rm \S \, 5.8.2$ 应用与辨析答案

1. 漏洞一：**起点**——若起点落在转移不到的（或极难到达的）区域，链永远到不了该处，样本有系统偏差。漏洞二：**步数**——平稳分布是极限，跑得不够久就还在瞬态，样本接近的是 $\mu P^t$ 而非 $\pi$；故必须 burn-in 加足够长。（$\S5.3$）
2. 不能直接成立。只向右跳时 $q(x|y) = 0$ 而 $q(y|x) \neq 0$，接受率公式里分母为 $0$。修法是让被拒时**原地不动**、并把接受率取 $\min(1, \frac{\pi(y)q(x|y)}{\pi(x)q(y|x)})$ 在 $q(x|y) = 0$ 处按极限理解（即对「回不来」的方向只保留单向流，仍靠细致平衡的对称式成立）——本质是要么提议对称化、要么显式把拒绝留在原地保证行随机。（$\S5.3$）
3. 加宽到常数条桥：$|\partial S| = \Theta(1)$、$\mathrm{vol}(S) = \Theta(n^2)$，$\Phi = \Theta(1/n^2)$ 不变，混合仍是 $\Omega(n^2)$。把桥拉长为长度 $L$ 的路径：游走者要在桥上扩散，跨桥时间 $\Theta(L^2)$，混合时间进一步涨到 $\Theta(L^2)$ 量级（$L = \Theta(n)$ 时约 $\Theta(n^2)$，与团的规模共同决定）。（$\S5.2$）
4. $\sigma$ 极小：提议几乎原地、接受率接近 $1$ 但每步移动极小，链在状态空间里爬得极慢，自相关接近 $1$、有效样本稀少。$\sigma$ 极大：提议常跳到低密度区、接受率趋近 $0$，链频繁原地不动，同样几乎不探索。两者与瓶颈同理——一个「走不动」，一个「被弹回」，都要在步长上做权衡（这就是 HMC 优于随机游走 MH 的地方）。（$\S5.3$、$\S5.4$）
5. 「收敛到平稳」是**极限**性质，但估计计数需要一个**独立/近似独立**的样本集合；若链混合慢，样本高度相关，命中比例估计的方差极大、样本量要按自相关时间放大。MCMC 的实践困境是：**没有一般办法知道链是否已经混合**（收敛的诊断只有启发式的），所以慢混合的链用起来是「不知道对不对」。（$\S5.3$、$\S5.4$）

## $\rm \S \, 5.9$ 程序对账

下面一段重算 §5.5 的三组锚：路径图经验分布、MH 双峰采样、$K_{10}$ 与 $P_{10}$ 的混合步数。固定种子可复现。

```python
import random, math
from math import erf, sqrt, pi

R = random.Random(20261103)                    # 固定种子，结果可复现

def path_walk(n, steps):                       # 惰性随机游走，停留概率 1/2
    deg = [1] + [2]*(n-2) + [1]
    cnt = [0]*n; v = R.randrange(n)
    for _ in range(steps):
        cnt[v] += 1
        if R.random() < 0.5:
            continue
        if v == 0: v = 1
        elif v == n-1: v = n-2
        else: v = v-1 if R.random() < 0.5 else v+1
    s = sum(deg); stat = [d/s for d in deg]
    emp = [c/steps for c in cnt]
    chi2 = sum((emp[i]-stat[i])**2/stat[i] for i in range(n))
    return stat, emp, chi2

for n in (5, 10, 20):
    stat, emp, chi2 = path_walk(n, 400000)
    print(f"path-walk  n={n:2d}  chi2 distance to pi ~ degree = {chi2:.3e}")
    if n == 5:
        print("  pi  =", [f"{p:.4f}" for p in stat])
        print("  emp =", [f"{e:.4f}" for e in emp])

def npdf(x, mu, sd): return math.exp(-0.5*((x-mu)/sd)**2)/(sd*sqrt(2*pi))
def target(x): return 0.5*npdf(x, -2.0, 0.6) + 0.5*npdf(x, 2.0, 0.6)

def metro(nsamp, burn, prop_sd):               # 对称提议 N(x, prop_sd^2)
    x, acc, out = -2.0, 0, []
    for i in range(nsamp+burn):
        y = x + R.gauss(0, prop_sd)
        if R.random() < min(1.0, target(y)/target(x)):
            x = y; acc += 1
        if i >= burn: out.append(x)
    return out, acc/(nsamp+burn)

samples, accrate = metro(200000, 20000, 1.5)
m = sum(samples)/len(samples)
var = sum((s-m)**2 for s in samples)/len(samples)
left = sum(1 for s in samples if s < 0)/len(samples)
print(f"metro      mean={m:.4f} (true 0)  std={sqrt(var):.4f} (true {sqrt(0.36+4):.4f})")
print(f"metro      P(x<0)={left:.4f} (true 0.5000)  accept={accrate:.4f}")

def Phi(z): return 0.5*(1+erf(z/sqrt(2)))
def cdf_true(a, b):
    return 0.5*(Phi((b+2)/0.6)-Phi((a+2)/0.6)) + 0.5*(Phi((b-2)/0.6)-Phi((a-2)/0.6))
edges = [-5,-3,-2,-1,0,1,2,3,5]
for i in range(len(edges)-1):
    a, b = edges[i], edges[i+1]
    emp = sum(1 for s in samples if a <= s < b)/len(samples)
    print(f"  bin [{a:+.0f},{b:+.0f})  emp {emp:.4f}  true {cdf_true(a,b):.4f}")

def tv_K(n, tmax=100):                          # 惰性 K_n，从 delta_0 起步
    p = [0.0]*n; p[0] = 1.0; stat = 1.0/n; tv = []
    for _ in range(tmax):
        tv.append(0.5*sum(abs(pi_-stat) for pi_ in p))
        q = [0.0]*n
        for i in range(n):
            q[i] += 0.5*p[i]
            for j in range(n):
                if j != i: q[j] += 0.5*p[i]/(n-1)
        p = q
    return tv

def tv_P(n, tmax=4000):                         # 惰性路径图，从 delta_0 起步
    deg = [1] + [2]*(n-2) + [1]; s = sum(deg); stat = [d/s for d in deg]
    p = [0.0]*n; p[0] = 1.0; tv = []
    for _ in range(tmax):
        tv.append(0.5*sum(abs(p[i]-stat[i]) for i in range(n)))
        q = [0.0]*n
        for i in range(n):
            if p[i] == 0: continue
            q[i] += 0.5*p[i]
            nb = [j for j in (i-1, i+1) if 0 <= j < n]
            for j in nb: q[j] += 0.5*p[i]/len(nb)
        p = q
    return tv

for name, arr in (("K10", tv_K(10)), ("P10", tv_P(10))):
    step = next(t for t, v in enumerate(arr) if v <= 0.01)
    print(f"mixing  {name}: TV<=0.01 at t={step}  TV[1]={arr[1]:.4f}  TV[5]={arr[5]:.4f}")
```

输出（本机实测）：

1. `path-walk  n= 5  chi2 distance to pi ~ degree = 1.034e-04`，并给出 `pi` 与 `emp` 两行；`n=10` 为 `1.087e-04`、`n=20` 为 `7.003e-04`。
2. `metro      mean=0.0368 (true 0)  std=2.0860 (true 2.0881)`、`metro      P(x<0)=0.4912 (true 0.5000)  accept=0.4643`；各分箱 `emp` 与 `true` 相差不超过约 $0.006$。
3. `mixing  K10: TV<=0.01 at t=6  TV[1]=0.4000  TV[5]=0.0156`、`mixing  P10: TV<=0.01 at t=136  TV[1]=0.8333  TV[5]=0.6128`。

**带走清单**：无向图随机游走的平稳分布 $\pi_v = \deg(v)/(2|E|)$ 与电网络对照；总变差距离与混合时间定义；完全图 $O(1)$ 与哑铃图 $\Omega(n^2)$ 由电导 $\Phi$ 分野、$t_{\mathrm{mix}} \gtrsim 1/(2\Phi)$；MH 接受率 $A = \min(1, \frac{\pi(y)q(x|y)}{\pi(x)q(y|x)})$ 与对称提议简化；细致平衡一行推出平稳、MH 满足细致平衡的验算；burn-in 与自相关折算有效样本。
