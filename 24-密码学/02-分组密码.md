# $\rm Chapter \, 2$ 分组密码与工作模式

第 1 章留下了两个待办：OTP 证明完美保密可行，代价是等长密钥；计算安全把目标放宽为「破不动」，于是核心问题变成：能不能用一把 $128$ 位的密钥，把任意长的消息加密得比 OTP 便宜千倍。本章的主角是分组密码：先看它的内部构造直觉（AES-128），再看真正决定成败的外层用法（工作模式），最后演示一个 CBC 的篡改漏洞，为第 4 章的认证埋下伏笔。

> **开始前自检**：本章假设你已经会：
>
> 1. □ 异或与模运算（竞赛通用；§2.2 的 GF$(2^8)$ 乘法与 §2.4 的位翻转全靠它们）；
> 2. □ 快速幂与扩展欧几里得求逆元（竞赛通用；§2.2 与 §2.4 都要用一次求逆）；
> 3. □ 攻击模型四档（本册第 1 章；§2.4 是 CCA 思路的第一个实战例）；
> 4. □ 两密异或的论证：同一密钥流下密文异或等于明文异或（本册第 1 章；§2.3 的 CTR 模式是它的工程化身）。

## $\rm \S \, 2.1$ 问题：比 OTP 省的确定性构造

要的方案规格很明确：密钥 $128$ 位（而不是与消息等长）、消息任意长、加解密快到能进内核。**分组密码（block cipher）**就是为此设计的确定性构造：固定块长（AES 为 $128$ 位），在密钥控制下给出一个可逆替换 $E_k: {\{0,1\}^{128}} \to {\{0,1\}^{128}}$，密钥从 $2^{128}$ 个可能的替换中选定一个。

设计目标可以用两个词分开说。**混淆（confusion）**：让密文与密钥的关系尽量复杂，攻击者看到密文变化推不出密钥的任何一位；实现手段是替换层，按字节查表（S 盒）。**扩散（diffusion）**：让明文的每一位影响密文的很多位，一处改动雪崩式扩散到全块；实现手段是置换与线性混合层，挪动字节位置、按域乘法混合。把这两种层交替叠若干轮，就是**替换-置换网络（substitution–permutation network，SPN）**：替换层负责混淆，混合层负责扩散，轮数足够多后，除暴力枚举 $2^{128}$ 外没有已知的短路径。

到达 SPN 之前，两个更朴素的方案值得先看死法，它们各自排除了一整类思路：

1. **短密钥直接异或**：取 $128$ 位密钥重复平铺当密钥流，与明文异或。密钥流周期只有 $128$ 位，长消息必然重用，第 1 章的两密论证立刻生效，「像 OTP」但丢掉了 OTP 的前提；
2. **整块替换表**：把 $128$ 位块到 $128$ 位块的替换直接做成一张表。混淆与扩散倒是一步到位，可这张表有 $2^{128}$ 个表项，密钥就是表本身，存储与分发彻底不可行。

SPN 的答案是折中：用小的 S 盒（$8$ 位进、$8$ 位出，表项 $256$ 个）提供混淆，用可公开的置换与线性混合提供扩散，密钥只负责控制「每轮的 S 盒换一张小表」（轮密钥异或）。小零件、多轮次、密钥轻量，三个朴素方案救不出的矛盾在这里解开。

## $\rm \S \, 2.2$ AES-128 概览：结构而非推导

AES-128 是 SPN 的标准实现：$10$ 轮，状态是 $4\times4$ 的字节矩阵，每轮依次做四件事。目标是看懂结构，不逐轮推导：

1. **SubBytes**：每字节查 S 盒替换。S 盒的数学来源是 GF$(2^8)$ 上求逆再套一个仿射变换：「在域里求逆」保证替换层高度非线性，这是混淆的来源；
2. **ShiftRows**：第 $i$ 行循环左移 $i$ 字节，让列与列交叉，服务扩散；
3. **MixColumns**：每列在 GF$(2^8)$ 上乘一个固定矩阵，一个字节的变化搅动整列；
4. **AddRoundKey**：状态与轮密钥异或；轮密钥由 $128$ 位主密钥经**轮密钥扩展**派生，每轮不同。

四个步骤各占一条腿，分工可以钉成一张表：

| 步骤 | 类型 | 服务于 | 一句话读法 |
| --- | --- | --- | --- |
| SubBytes | 非线性替换 | 混淆 | 唯一的非线性部件，没有它全方案塌成线性代数 |
| ShiftRows | 置换 | 扩散 | 把字节挪位，让列与列交叉 |
| MixColumns | 域上线性混合 | 扩散 | 一个字节的变化搅动整列 |
| AddRoundKey | 密钥注入 | 混淆 | 密钥进入状态的唯一入口 |

补一句轮密钥扩展的读法：派生过程自身也用 S 盒与循环移位，保证任何一轮的轮密钥都与其他轮统计独立，攻击者哪怕恢复出一轮轮密钥，也推不出主密钥。

竞赛连接在此处最密：GF$(2^8)$ 的乘法你在竞赛里早写过：多项式系数取字节各位，乘法就是异或加移位，溢出时对不可约多项式 $x^8+x^4+x^3+x+1$ 取模（字节 `0x1B` 正是它的低八位）。两个手算例：`0x53` 乘 `0x02` 就是左移一位，最高位是 $0$ 不溢出，得 `0xA6`；`0x80` 乘 `0x02` 左移后溢出 $x^8$，代入 $x^8 = x^4+x^3+x+1$ 得 `0x1B`。完整乘法脚本：

```python
def gmul(a, b):
    p = 0
    for _ in range(8):
        if b & 1: p ^= a
        hi = a & 0x80
        a = (a << 1) & 0xFF
        if hi: a ^= 0x1B
        b >>= 1
    return p
print(hex(gmul(0x53, 0x02)), hex(gmul(0x80, 0x02)))  # 0xa6 0x1b
print(hex(gmul(0x53, 0xCA)))                          # 0x1
```

最后一个是 AES 论文里的经典例：`0x53 · 0xCA = 0x01`，S 盒里 `0x53` 的逆元恰好是 `0xCA`，一次 gmul 就能验证。这层「异或移位模多项式」与你在树状数组里写的位运算没有本质区别，只是模的多项式换成了八次。

## $\rm \S \, 2.3$ 工作模式：一块一块怎么连

分组密码只会加密一个 $128$ 位块。任意长消息靠**工作模式（mode of operation）**拼接。模式选错，再强的分组密码也会失效。三种经典模式对比着看。

**电子密码本模式（electronic codebook，ECB）**：每块独立加密 $C_i = E_k(P_i)$。用玩具版分组密码演示它的致命伤（$8$ 位块，$E(x) = (17x+41) \bmod 256$，密钥为 $(17, 41)$）：

```python
E = lambda x: (17 * x + 41) % 256           # 玩具「分组密码」，密钥 = (17, 41)
pt = [0x41, 0x41, 0x41, 0x41, 0x42, 0x43]   # 前四块相同
print([hex(E(x)) for x in pt])              # 0x7a, 0x7a, 0x7a, 0x7a, 0x8b, 0x9c
```

相同明文块得到相同密文块，第 1 章「结构泄漏」的死法原样回归：密文没有泄露内容，但泄露了「哪里重复」。对图像加密时轮廓肉眼可辨（著名的 ECB 企鹅图就是这个效果），所以 ECB 在新系统里不该出现。

**密码分组链接模式（cipher block chaining，CBC）**：给每块引入依赖，$C_i = E_k(P_i \oplus C_{i-1})$，首块用一个公开的随机数**初始向量（initialization vector，IV）**顶替 $C_0$。相同的 $P_1$ 配上不同 IV，密文就不同，ECB 的重复泄漏消失；解密时 $P_i = D(C_i) \oplus C_{i-1}$，可以并行，加密则必须逐块等待。

**计数器模式（counter mode，CTR）**：干脆把分组密码当流密码用：把一个**nonce（number used once）**加计数器送进分组密码得到密钥流，再与明文异或：$C_i = P_i \oplus E_k(\text{nonce} \| i)$。加密解密都能并行、支持随机访问任意块、没有填充。注意它与 OTP 只差一步：密钥流由 $E_k$ 生成，第 1 章的纪律原样生效，同一密钥下 nonce 绝不能重用，否则两条消息共享同一段密钥流。nonce 的管理纪律在第 4 章展开成生死线。

三种模式的账并排一算，选择逻辑就清楚了：

| 模式 | 加密并行 | 解密并行 | 随机访问 | 典型失效方式 |
| --- | --- | --- | --- | --- |
| ECB | 是 | 是 | 是 | 重复结构泄漏 |
| CBC | 否（等上一块） | 是 | 弱 | 无认证时的位翻转；IV 固定退化 |
| CTR | 是 | 是 | 是 | nonce 重用退化为两密 |

ECB 只剩「块级随机访问」一个优点，代价是结构裸奔；CBC 在历史上曾是默认选项；CTR 兼得并行与随机访问，前提是把 nonce 管住，安全性的重心从「算法选谁」滑向「参数怎么管」，这条线在第 4 章收口。

## $\rm \S \, 2.4$ CCA 伏笔：CBC 的位翻转攻击

CBC 的解密式 $P_i = D(C_i) \oplus C_{i-1}$ 有一扇侧门：密文块在解密前要先与上一块异或，而这个异或不受任何保护。攻击者翻转 IV 的某一位，解密出的 $P_1$ 就恰好翻转同一位，其余块纹丝不动。脚本演示（沿用 §2.3 的玩具密码，$E$ 的逆是 $D(y) = (241(y-41)) \bmod 256$，因 $17 \times 241 \equiv 1 \pmod{256}$）：

```python
E = lambda x: (17 * x + 41) % 256
D = lambda y: (241 * (y - 41)) % 256        # 17*241 ≡ 1 (mod 256)
IV, P1 = 0x50, 0xF0
C1 = E(P1 ^ IV)
print(hex(D(C1) ^ IV))                      # 0xf0：正常解密
print(hex(D(C1) ^ (IV ^ 0x01)))             # 0xf1：IV 翻转哪一位，P1 就翻转哪一位
```

设真实指令是 `P1 = 0xF0`（比如「向甲转账」），攻击者不需要知道密钥，把 IV 的最低位翻一下，解密结果就变成 `0xF1`（「向乙转账」）。这个攻击落在第 1 章的哪一档？攻击者提交了篡改后的密文并观察解密结果，这是 CCA 的动作，CBC 单独使用时扛不住它。把「攻击者能动的三个对象」的可检测性列成清单更直观：

1. **改 IV**：只影响首块解密结果，对应位翻转，全程无报错；
2. **改中间密文块 $C_i$**：$P_i$ 解密成乱码，且 $P_{i+1} = D(C_{i+1}) \oplus C_i$ 也跟着乱，接收方多半能看出「坏了」，却分不清是传输损坏还是蓄意篡改；
3. **重放整条旧密文**：解密完全正常，内容也是合法历史内容，唯一错的是「现在又来一遍」。

三种动作都指向同一个缺口：解密成功与否回答不了「消息是否原样出自发送方、是否仍在有效期内」。教训分两层：能被正确解密不等于没有被篡改，保密性对完整性与新鲜性只字未提；修补办法不是给模式打补丁，而是给消息配上认证。这正是第 4 章的主题。

## $\rm \S \, 2.5$ 关键概念回顾

1. 混淆与扩散各自指什么？在 SPN 里分别由哪类层实现？
2. AES 的 S 盒为什么要在 GF$(2^8)$ 上求逆？`0x80 · 0x02 = 0x1B` 这一步的模多项式运算发生在哪？
3. ECB 死于什么？为什么 CBC 的随机 IV 能治好它？
4. CTR 与 OTP 的联系与区别是什么？它继承了 OTP 的哪条使用纪律？
5. 位翻转攻击为什么属于 CCA？它攻破的是保密性还是完整性？

## $\rm \S \, 2.6$ 应用与辨析

1. 同学说：「AES 密钥 $128$ 位，所以随便找个工作模式都是 $128$ 位安全。」用 ECB 反驳他，并指出安全的完整表述应该是怎样的句子。
2. 一个日志系统用 CBC 加密记录，IV 固定为全零。指出两个后果：一个关于重复泄漏，一个关于首块篡改。
3. 视频点播系统要求「从任意位置开始解码」。比较 CBC 与 CTR 哪个合适，说出决定性的技术性质。

## $\rm \S \, 2.7$ 本章自测答案

> 先闭卷作答上面两节，再核对。

### $\rm \S \, 2.7.1$ 关键概念回顾答案

1. 混淆＝密文与密钥的关系复杂化，由替换层（S 盒）实现；扩散＝明文单个位的变化散布到整个块，由置换与线性混合层（ShiftRows、MixColumns）实现。（§2.1）
2. 求逆保证替换层高度非线性，攻击者无法用线性关系逼近 S 盒；`0x80` 左移溢出出 $x^8$ 项，用 $x^8 \equiv x^4+x^3+x+1$ 把它折回八位，对应异或 `0x1B`。（§2.2）
3. 相同明文块映射到相同密文块，泄漏重复结构；随机 IV 使同一明文在不同次加密中密文不同，重复泄漏消失。（§2.3）
4. 两者都是「明文异或密钥流」；CTR 的密钥流由 $E_k(\text{nonce} \| i)$ 生成而非真随机，安全性换成计算安全。继承的纪律：同一密钥下 nonce 不得重用，否则退化为两密问题。（§2.3）
5. 攻击者提交篡改密文并观察解密差异，符合 CCA 的动作描述；它攻破的是完整性：解密全程「成功」，只是解出了被改过的明文。（§2.4）

### $\rm \S \, 2.7.2$ 应用与辨析答案

1. ECB 下相同块产生相同密文，攻击成本与密钥长度无关。完整表述要补全模型与对象：例如「AES-GCM 在 nonce 不重用前提下，于 CPA 模型下提供计算安全的保密性」。（§2.3）
2. 重复泄漏：相同首段且后续差分一致的记录会产生相同或可分析的密文（IV 恒定，CBC 退化）；首块篡改：$P_1 = D(C_1) \oplus \text{IV}$，全零 IV 使攻击者对 $C_1$ 做的修改直接命中 $P_1$，且无法被察觉。（§2.4）
3. CTR。决定性性质是随机访问：第 $i$ 块的密钥流 $E_k(\text{nonce} \| i)$ 可独立计算，无需解出前面的块；CBC 解密虽可并行，但定位第 $i$ 块仍需要它依赖的 $C_{i-1}$ 整条链在，灵活性差一档。（§2.3）
