# $\rm Chapter \, 5$ Mapper：把数据压成一张图

前四章的流水线是「点云 → 复形 → 同调 → 持久图」，产出的是不变量与定理。本章换一条完全不同的赛道：**Mapper**（Singh–Mémoli–Carlsson 2007）不数洞、不证稳定性，它直接把数据集压成一张小图——节点是一团团真实的数据点，边是团与团的交叠——让形状**以肉眼可读的方式**摆在纸上。这是 TDA 在生物数据上最出名的脸面（第 6 章的乳腺癌与单细胞案例都是它），也是被批评得最狠的对象。本章讲清三件事：算法怎么转（§5.1–§5.2）、六个点的例子真算一遍（§5.3）、它与持久同调各管什么（§5.4）。

## $\rm \S \, 5.1$ 动机：持久同调看不见的与太贵的

先说清 Mapper 补什么缺口。持久同调的输出是一张持久图——抽象的点集，告诉你「有几个洞、各活多长」，但不告诉你**洞在数据的哪里、由哪些样本围成**；持久同调的计算也要对全体点两两跑距离，样本一上十万，$O(n^2)$ 起步的距离矩阵先扛不住。而分析数据的科学家常要的是另一种东西：一张图，节点标着「这群样本」，能顺着看数据怎么分流、哪里分叉、哪个团和哪个团接壤。

白话：**Mapper 是数据的压缩草图**——把几千个点压成几十个节点，节点=一团相似的样本，边=两团样本有成员互相渗透。画出来像地铁线路图：丢了细节，但拓扑骨架（连不连、有几个圈、哪些站是枢纽）一眼可读。

一个预览性的问题值得先抛出来：第 1 章的 Nerve 定理说「好覆盖的神经复形与原空间同伦等价」——那把 Nerve 定理直接用在数据上不就完了？答案是 Nerve 定理要的「好」太奢侈：要求每个覆盖元素及其所有交都可缩，而数据的覆盖是人为画的，谁也不保证可缩。Mapper 的立场是：**不保证等价，但保留骨架，并把每一步的旋钮交给用户**——这份自由既是它的实用价值，也是它不稳定的根源（§5.4 的主题）。

**本节小结**：Mapper 补两个缺口——持久同调不告诉洞在哪儿、大样本算不动；它输出带数据成员的压缩图；与 Nerve 定理的关系是「放弃等价保证、保留骨架」。下一节拆算法的三个旋钮。

## $\rm \S \, 5.2$ 算法三步：透镜、覆盖、聚类

设数据是有限点集 $X$（带距离 $d$）。Mapper 的全部流程只有三步加一步装配。

**第一步：透镜（lens / filter function）。** 选一个函数 $f : X \to \mathbb{R}^k$（实用中 $k = 1$ 或 $2$），把每个数据点映成一个低维坐标。透镜是 Mapper 的**世界观**：它决定「按什么标准摊开数据」。常用选择：

1. 坐标投影：取某个属性列（本章 §5.3 用 $x$ 坐标），最直白，解释性最强；
2. PCA 主成分：摊开方差最大的方向，无监督时的默认项；
3. 密度或离心率（eccentricity）：$f(x) = \frac{1}{n}\sum_{y} d(x, y)$ 一类的量，让「数据密集处」与「稀疏处」分开；
4. 已有的统计量：比如基因表达数据的某个marker基因值（第 6 章 Rizvi 等的案例即此类）。

**第二步：覆盖（cover）。** 用一族互相交叠的区间 $\{I_1, \ldots, I_r\}$ 盖住透镜的值域 $f(X) \subseteq \mathbb{R}$（$k = 1$ 时；$k = 2$ 用矩形格）。两个参数定天下：区间宽度（resolution）与相邻区间的重叠比例（gain，实践常用 $20\%$ 到 $50\%$）。重叠不是可省的装饰——**没有重叠就没有边**：两个区间不相交，两边的聚类永远碰不上，图退化成一盘散沙。每个数据点至少落进一个区间，通常落进一至两个。

**第三步：聚类（clustering）。** 对每个区间 $I_j$，取出纤维 $f^{-1}(I_j)$（透镜值落进 $I_j$ 的全部样本），跑任意一种聚类算法，得到的每个簇成为图的一个**节点**。注意节点记录的是**簇内全部样本**，不是几个代表点。同一段数据如果被两个区间同时罩住，它会同时出现在两个区间的聚类里——这正是下一步的原料。

**第四步：装配。** 两个节点之间连一条边，当且仅当对应的两个簇**共享至少一个数据点**。没有共享点的簇互不相连。

白话：**Mapper ＝ 先按透镜把数据切成薄片，每片各自聚类，凡是「同一个人在两片里都出现」就把两片的簇缝起来**。缝出来的图，节点是数据的部落，边是部落的联姻。

这套构造与 Nerve 定理的血缘一眼可见：把「每个簇」当成覆盖元素（簇确实盖住了 $X$），Mapper 图恰好是这层覆盖的神经复形的 $1$-骨架——簇有公共点就连边，正是 Nerve 的组合规则。差别在 Nerve 定理要求覆盖元素与所有交可缩，而 Mapper 的簇只是聚类算法的输出，**没有几何保证**；所以 Mapper 图上的「环」只能当 strongly 建议性的证据（数据里真有个圈状结构），不能当同伦等价的定理（§5.4 回来结账）。

算法总账：三个旋钮（透镜、覆盖、聚类）各管一摊——透镜管「按什么摊开」，覆盖管「切多碎、缝多密」，聚类管「一团的门槛」。三个旋钮全是用户选择，这既是 Mapper 灵活到能挖出各种结构的原因，也是它难以安定的病根。

**本节小结**：Mapper 四步：透镜把点映成低维坐标、交叠区间盖住值域、每片纤维各自聚类得节点、簇共享样本就连边；它是「被聚类精修的神经复形」，继承 Nerve 的组合规则但不继承等价定理；三个旋钮全在用户手里。下一节把六个点喂进机器，真算一遍。

## $\rm \S \, 5.3$ 六个点走一遍：真算出一个环

空谈三步不如真跑一遍。数据：平面上六个点摆成一个环（相当于给圆采样了六刀，上弧三点、下弧三点、左右两端各一点封口）：

1. $L = (0, 0)$（左端封口点）；
2. $T_1 = (0.5, 1)$、$T_2 = (1, 1)$（上弧两点）；
3. $R = (1.5, 0)$（右端封口点）；
4. $B_2 = (1, -1)$、$B_1 = (0.5, -1)$（下弧两点）。

环的走法：$L \to T_1 \to T_2 \to R \to B_2 \to B_1 \to L$。任务：Mapper 要把「这是个环」读出来。

**第一步，透镜**：取 $x$ 坐标。六个点的透镜值：

$$
f(L) = 0, \quad f(T_1) = f(B_1) = 0.5, \quad f(T_2) = f(B_2) = 1, \quad f(R) = 1.5
$$

**第二步，覆盖**：三个区间，宽度 $0.9$、重叠 $0.4$（重叠约占宽度的四成）：

$$
I_1 = [-0.2,\, 0.7], \qquad I_2 = [0.3,\, 1.2], \qquad I_3 = [0.8,\, 1.7]
$$

（读法：$I_1$ 罩左端，$I_3$ 罩右端，$I_2$ 罩中间，相邻区间交叠 $0.4$——$I_1 \cap I_2 = [0.3, 0.7]$ 罩住 $f = 0.5$ 的点，$I_2 \cap I_3 = [0.8, 1.2]$ 罩住 $f = 1$ 的点。）各区间收到谁：$I_1$ 收 $\{L, T_1, B_1\}$，$I_2$ 收 $\{T_1, T_2, B_1, B_2\}$，$I_3$ 收 $\{T_2, R, B_2\}$。

**第三步，聚类**：每个区间内跑单 linkage 聚类，阈值 $\tau = 1.2$（两点距离 $\le \tau$ 归一团）。先把要用到的点距算清（欧氏）：$L$ 到 $T_1$ 与 $L$ 到 $B_1$ 都是 $\sqrt{1.25} \approx 1.118$；$T_1$ 到 $T_2$ 与 $B_1$ 到 $B_2$ 都是 $0.5$；$T_2$ 到 $R$ 与 $R$ 到 $B_2$ 都是 $1.118$；跨弧的 $T_1$ 到 $B_1$ 是 $2$，$T_2$ 到 $B_2$ 是 $2$，$T_1$ 到 $B_2$ 与 $T_2$ 到 $B_1$ 都是 $\sqrt{4.25} \approx 2.062$。于是：

1. $I_1$ 内 $\{L, T_1, B_1\}$：$L$ 到 $T_1$、$L$ 到 $B_1$ 均 $\le 1.2$，单 linkage 传染，全并一团——**左右弧在封口点 $L$ 处合流**，得节点 $N_0 = \{L, T_1, B_1\}$；
2. $I_2$ 内 $\{T_1, T_2, B_1, B_2\}$：上下弧各自抱团（$0.5 \le 1.2$），跨弧最近的也有 $2 > 1.2$，得两个节点 $N_1 = \{T_1, T_2\}$（上弧）、$N_2 = \{B_1, B_2\}$（下弧）；
3. $I_3$ 内 $\{T_2, R, B_2\}$：$R$ 到 $T_2$、$R$ 到 $B_2$ 均 $\le 1.2$，全并一团——**上下弧在封口点 $R$ 处合流**，得节点 $N_3 = \{T_2, R, B_2\}$。

**第四步，装配**：找共享样本。$N_0$ 与 $N_1$ 共享 $T_1$，$N_0$ 与 $N_2$ 共享 $B_1$，$N_1$ 与 $N_3$ 共享 $T_2$，$N_2$ 与 $N_3$ 共享 $B_2$。四条边首尾咬合：

$$
N_0 - N_1 - N_3 - N_2 - N_0
$$

一个四边形环。完整程序与实跑：

```python
import numpy as np

pts = np.array([[0., 0.], [0.5, 1.], [1., 1.], [1.5, 0.], [1., -1.], [0.5, -1.]])
names = ['L', 'T1', 'T2', 'R', 'B2', 'B1']
f = pts[:, 0]                                  # 透镜：x 坐标
intervals = [(-0.2, 0.7), (0.3, 1.2), (0.8, 1.7)]
tau = 1.2                                      # 单 linkage 阈值

def clusters(idx, thr):
    parent = list(range(len(idx)))
    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]; x = parent[x]
        return x
    for i in range(len(idx)):
        for j in range(i + 1, len(idx)):
            if np.linalg.norm(pts[idx[i]] - pts[idx[j]]) <= thr:
                parent[find(i)] = find(j)      # 单 linkage：距离够近就并
    groups = {}
    for i in range(len(idx)):
        groups.setdefault(find(i), []).append(idx[i])
    return [frozenset(g) for g in groups.values()]

nodes = []                                     # (区间编号, 簇)
for k, (a, b) in enumerate(intervals):
    idx = [i for i in range(6) if a <= f[i] <= b]
    for cl in clusters(idx, tau):
        nodes.append((k, cl))

edges = [(i, j) for i in range(len(nodes)) for j in range(i + 1, len(nodes))
         if nodes[i][1] & nodes[j][1]]         # 共享样本就连边

parent = list(range(len(nodes)))
def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]; x = parent[x]
    return x
for i, j in edges:
    parent[find(i)] = find(j)
comps = len({find(i) for i in range(len(nodes))})

for k, (a, cl) in enumerate(nodes):
    print("N%d: interval %d, cluster %s" % (k, a, sorted(names[i] for i in cl)))
print("edges:", [("N%d" % i, "N%d" % j) for i, j in edges])
print("nodes=%d edges=%d comps=%d cyclomatic=%d"
      % (len(nodes), len(edges), comps, len(edges) - len(nodes) + comps))
```

实跑输出（本章数值锚，照抄）：

```text
N0: interval 0, cluster ['B1', 'L', 'T1']
N1: interval 1, cluster ['T1', 'T2']
N2: interval 1, cluster ['B1', 'B2']
N3: interval 2, cluster ['B2', 'R', 'T2']
edges: [('N0', 'N1'), ('N0', 'N2'), ('N1', 'N3'), ('N2', 'N3')]
nodes=4 edges=4 comps=1 cyclomatic=1
```

**四个节点、四条边、一个连通片、圈数（cyclomatic number，边数 $-$ 节点数 $+$ 连通片数）$= 1$**——Mapper 图是一个四边形的环，环上六个原始数据点一个不丢（$N_0$ 携带 $3$ 个、$N_1$、$N_2$ 各 $2$ 个、$N_3$ 携带 $3$ 个，重叠区的成员重复计入）。环为什么必然出现？拆开看分工：两个封口区间 $I_1$、$I_3$ 里上下弧通过封口点合流（$N_0$、$N_3$ 各是「三合一」节点），中间区间 $I_2$ 里上下弧因为跨弧距离 $2$ 超阈值而**保持分离**（$N_1$、$N_2$ 分立）——「两端合流、中间分叉」正是环的拓扑签名。透镜 $x$ 坐标沿着环走一圈只拐两次头，中间一片必然同时切到环的两臂，两臂的距离成了唯一的开关。

### 拧一下旋钮：环会怎样

把聚类阈值 $\tau$ 扫一遍（其余全不动），每个值都真跑：

```text
tau=0.9  nodes=8 edges=4 comps=4 cyclomatic=0   （打碎：所有跨点距离超阈，环裂成 4 片）
tau=1.2  nodes=4 edges=4 comps=1 cyclomatic=1   （环活着）
tau=1.5  nodes=4 edges=4 comps=1 cyclomatic=1   （环活着）
tau=1.9  nodes=4 edges=4 comps=1 cyclomatic=1   （环活着）
tau=2.1  nodes=3 edges=2 comps=1 cyclomatic=0   （塌掉：I2 上下弧被并，环被填死）
```

三个读数。其一，$\tau \in [1.2, 1.9]$ 是环的**稳定窗口**——窗口内图纹丝不动，这与第 4 章「噪声有界则失真有界」的精神遥相呼应，但注意：这个窗口是**本例的具体数字**，换数据得重新找，Mapper 没有定理告诉你窗口在哪。其二，$\tau = 0.9$ 打碎成八节点四片：透镜重叠区里的 $T_1$、$B_1$ 被切成孤立点，缝不起来。其三，$\tau = 2.1$ 最阴险——不是碎了，而是**错**：$I_2$ 里上下弧被跨弧距离 $2$ 拉进一团，环被一记 clustering 填死，图变成一条三点路径，cyclomatic 从 $1$ 掉到 $0$。Mapper 的失败模式通常是「给错答案」而不是「给不出答案」，这就是第 6 章要正面处理的批评。

**本节小结**：六点环例全程真算——透镜取 $x$ 坐标、三区间覆盖、单 linkage 阈值 $1.2$，输出四节点四边一圈（cyclomatic $= 1$）；环的成因是「封口区间合流、中间区间分叉」；阈值扫描给出稳定窗口 $[1.2, 1.9]$，窗外或碎（$0.9$）或错（$2.1$）。下一节把它与持久同调摆上台面对账。

## $\rm \S \, 5.4$ 与持久同调的分工：两种仪器各量什么

同一个六点环，第 1 章的仪器也会给答案：VR 复形在边长尺度附近也数出一个 $H_1$ 洞（对照本册第 1 章四点正方形在 $[1, \sqrt{2}]$ 的窗口）。那 Mapper 图什么便宜？两台仪器的差异列清楚。

1. **输出形态**。持久同调给不变量（条形码、持久图）：抽象、无参数副作用、可进定理；Mapper 给带数据的图：节点背着一团真实样本，能直接点开看「这个部落是谁」。前者回答「有没有洞」，后者回答「洞在哪儿、由谁组成」。
2. **尺度观**。持久同调天然多尺度：一次计算扫遍所有 $\varepsilon$，洞的生灭全程在案（第 3 章）。Mapper 是**单尺度仪器**：透镜、覆盖、聚类阈值定好后只看一个切面——想看别的尺度得重跑。多尺度是免费午餐的地方，Mapper 没有。
3. **旋钮与稳定性**。持久同调（VR 过滤）只有距离矩阵一个输入，第 4 章的稳定性定理保证函数扰动 $\varepsilon$ 只值图上 $\varepsilon$ 的失真。Mapper 有三个旋钮，§5.3 刚演示过拧动后果；它**没有**对等的稳定性定理——Carrière–Michel–Oudot（2018）证明了 Mapper 图在特定意义下收敛于一个「极限 Mapper」，且对样本量有统计一致性结果，但前提是对数据分布与聚类行为加了正则性条件，远不如第 4 章定理的普适。
4. **成本**。Mapper 主开销是透镜后的聚类与共享检查，样本量 $n$ 时是准线性到 $O(n \log n)$ 量级（取决于聚类算法），且天然抗大样本——先压缩后细看；持久同调的 VR 过滤要对全体点跑距离并处理可达 $O(2^n)$ 的复形（实践中靠稀疏化与降维续命）。数据越大，Mapper 的性价比越明显。

分工结论可以一句话钉住：**Mapper 用来发现与呈现，持久同调用来确认与量度**。标准工作流是两段式：先用 Mapper 低成本扫出「数据像是有什么结构」（几个环、几条臂、哪团样本扎堆），再对可疑结构上持久同调（或统计检验）确认它不是旋钮拧出来的幻觉。第 6 章的生物案例全是这两段式的实战。

**本节小结**：持久同调给不变量、多尺度、有稳定性、成本高；Mapper 给带样本的图、单尺度、旋钮多而无普适稳定性、便宜快速；分工是「Mapper 发现、持久同调确认」，两段式工作流是实践标配。

## $\rm \S \, 5.6$ 程序段：可复用的迷你 Mapper

把 §5.3 的散装代码收拢成一个函数（两点云、透镜、覆盖、阈值，吐节点边表）：

```python
import numpy as np

def mapper_1d(pts, lens, intervals, tau):
    # pts: (n, d) 点云；lens: (n,) 透镜值；intervals: [(a, b)]；tau: 单 linkage 阈值
    n = len(pts)

    def clusters(idx):
        parent = list(range(len(idx)))
        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]; x = parent[x]
            return x
        for i in range(len(idx)):
            for j in range(i + 1, len(idx)):
                if np.linalg.norm(pts[idx[i]] - pts[idx[j]]) <= tau:
                    parent[find(i)] = find(j)
        groups = {}
        for i in range(len(idx)):
            groups.setdefault(find(i), []).append(idx[i])
        return [frozenset(v) for v in groups.values()]

    nodes = []
    for k, (a, b) in enumerate(intervals):
        for cl in clusters([i for i in range(n) if a <= lens[i] <= b]):
            nodes.append((k, cl))
    edges = [(i, j) for i in range(len(nodes)) for j in range(i + 1, len(nodes))
             if nodes[i][1] & nodes[j][1]]

    parent = list(range(len(nodes)))
    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]; x = parent[x]
        return x
    for i, j in edges:
        parent[find(i)] = find(j)
    comps = len({find(i) for i in range(len(nodes))})
    cycl = len(edges) - len(nodes) + comps
    return nodes, edges, comps, cycl

pts = np.array([[0., 0.], [0.5, 1.], [1., 1.], [1.5, 0.], [1., -1.], [0.5, -1.]])
nodes, edges, comps, cycl = mapper_1d(pts, pts[:, 0],
                                      [(-0.2, 0.7), (0.3, 1.2), (0.8, 1.7)], 1.2)
print("nodes=%d edges=%d comps=%d cyclomatic=%d" % (len(nodes), len(edges), comps, cycl))
```

实跑输出：

```text
nodes=4 edges=4 comps=1 cyclomatic=1
```

读程序的四句话：函数只支持一维透镜（二维覆盖换矩形格与双层循环即可，结构不变）；聚类用并查集实现单 linkage，复杂度对每片纤维是平方级——纤维小（压缩后通常几十点）所以无碍，原始大样本从不进聚类；`cyclomatic` 用公式「边 $-$ 点 $+$ 连通片」现场数圈，六问第 5 题会问它为什么等于圈的个数；生产环境用 `giotto-tda` 或 `kmapper`，它们的节点属性、增益自动布点与绘图一应俱全，但**三个旋钮的语义与本章完全一致**。

## $\rm \S \, 5.7$ 六问参考答案

1. 透镜 $f$（定世界观）、覆盖（区间宽度与重叠比例 gain）、聚类（算法与阈值 $\tau$）。重叠是边的唯一来源：边=两簇共享样本，而样本跨簇只能靠跨区间——没有重叠则每点只属一个区间，图必是散沙。（§5.2）
2. Mapper 以「簇」为覆盖元素，边规则（共享样本就连边）正是神经复形的组合规则，所以 Mapper 图是这层覆盖的 Nerve 的 $1$-骨架；但 Nerve 定理要求覆盖元素与其一切交可缩，聚类的簇无此保证，故 Mapper 图与数据原形之间没有同伦等价承诺。（§5.2）
3. 单 linkage 按「距离 $\le \tau$ 可传染」并团：$L$ 到 $T_1$、$L$ 到 $B_1$ 都是 $1.118 \le 1.2$，两步传染把三点缝进一团——封口点 $L$ 是传染中介。完全 linkage 要求团内全对距离 $\le \tau$，而 $T_1$ 到 $B_1$ 距离 $2 > 1.2$，只能各留孤点，$I_1$ 内聚成三团——Mapper 图随之整个改写。聚类算法不是实现细节，是旋钮。（§5.3）
4. $\tau = 2.1$ 时 $I_2$ 内上下弧最近跨弧距离 $2 \le 2.1$ 被并进一团，中间不再分叉，「两端合流、中间分叉」的签名消失，cyclomatic 从 $1$ 掉到 $0$。与 $\tau = 0.9$ 的碎裂本质不同：碎裂是「给不出结构」（图散成四片，至少不撒谎），塌环是「给出假结构」（一条路径，看着无害实则在撒谎）——后者危害大得多。（§5.3）
5. Mapper 段防「成本错误」：用便宜的压缩先扫一遍，避免在大样本上盲跑昂贵仪器；确认段防「旋钮幻觉」：Mapper 的环可能只是聚类阈值恰好留出的缝，要靠持久同调（多尺度在案）或统计检验证明它在参数扰动下存活。建议性而非定理性的原因：Mapper 没有同伦等价承诺，图上数出的圈数不等于数据的 Betti 数。（§5.4）
6. 持久同调一次计算扫遍全部尺度、洞的生灭全程在案；Mapper 只看透镜与覆盖定好的单一尺度，换尺度要重跑。Carrière–Michel–Oudot 的结果是对「极限 Mapper」的收敛与统计一致性，且要求数据分布与聚类满足正则性；第 4 章定理只要求 tame 函数与 $\lVert f - g \rVert_{\infty}$ 有界——普适性差了一个量级，这正是「Mapper 无普适稳定性」的确切含义。（§5.4）
