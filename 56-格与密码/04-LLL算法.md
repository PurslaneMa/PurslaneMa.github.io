# $\rm Chapter \, 4$ LLL 算法

第 3 章的 Minkowski 球界把话说到「存在」为止：每个格里都躺着一条不超过 $\sqrt{d}\,(\det L)^{1/d}$ 的短向量，可它不负责把这条向量递到你手里。把「存在」变成「可算」的，是 1982 年的 Lenstra–Lenstra–Lovász 算法，缩写 LLL（三人姓氏的叠加）。有个常被略去的史实：原论文的题目是「Factoring polynomials with rational coefficients」——分解有理系数多项式才是它的出生证明，短向量只是手段。本章是全册的主证章：先把二维 Gauss 归约的判据升级成高维的 Lovász 条件（§4.1），然后全证 LLL 的终止性——核心是一只精心设计的势函数在每次交换时至少缩水 $\frac{3}{4}$，而它只能取正整数值（§4.2，全册最重的一段推导）；接着算清输出承诺的两条界、核对复杂度与数值锚（§4.3）；最后巡礼 LLL 在密码分析史上的战绩（§4.4）。第 5 章立刻兑现红利：拿归约好的基去近似解 CVP（Babai）与找小根（Coppersmith）。

> **开始前自检**：本章假设你已经会：
>
> 1. □ 本册第 1 章的 Gauss 归约（§1.2）与 Gram–Schmidt 记号 $b_i^*$（§1.4）——全章的工作语言；
> 2. □ $\lambda_1$ 与 $\det L$ 的定义、基不变性（本册第 1 章）——两条输出界的两端各站一个；
> 3. □ 本册第 2 章的 CVP 定义与 Babai 舍入的失手记录——§4.4 应用出口的靶子；
> 4. □ 本册第 3 章的 Minkowski 界 $\lambda_1 \le \sqrt{d}\,(\det L)^{1/d}$——与 LLL 的界对照着读；
> 5. □ 数学归纳法，以及「取正整数值且每次至少缩水 $\frac{3}{4}$ 的量只能缩有限次」这条鸽笼逻辑——终止性证明的全部逻辑都在这两件工具里。

## $\rm \S \, 4.1$ 从 Gauss 到 LLL：Lovász 条件

白话：第 1 章的 Gauss 归约是二维专属的，因为它的终态判据「$\|b_1\| \le \|b_2\|$ 且 $|\mu| \le \frac{1}{2}$」比较的是两条基向量的**全长**。高维里全长这个量太粗：两根基向量可以各自不长，却斜在同一个平面里，凑出一条远比它们短的组合向量的影子。真正要管的是每根基向量「掰直之后」还剩多长。LLL 的全部智慧浓缩成一句话：**把 Gauss 归约的末端比较，换成逐层的温和递减**。

先回忆工作语言（本册第 1 章 §1.4）。对基 $b_1, \ldots, b_d$，Gram–Schmidt 给出正交化向量 $b_1^*, \ldots, b_d^*$ 与系数

$$
\mu_{i,j} = \frac{\langle b_i, b_j^*\rangle}{\|b_j^*\|^2}, \qquad b_i = b_i^* + \sum_{j < i} \mu_{i,j}\, b_j^*
$$

读法：$\mu_{i,j}$ 读作「$b_i$ 里含有几份 $b_j^*$」，对照第 1 章 Gauss 归约里那个一维版的 $\mu$；$b_i^*$ 是 $b_i$ 砍掉全部斜成分后的正交残余，$\|b_i^*\| \le \|b_i\|$ 恒成立，$\|b_1^*\| = \|b_1\|$。二维归约的消减动作「$b_2 \leftarrow b_2 - \lfloor\mu\rceil b_1$」在高维的自然推广是：对每根 $b_i$，把所有 $\mu_{i,j}$ 取整消掉——这一步叫 **size-reduce**。但消减只管「消干净」，不管「修整齐」：消完之后各 $\|b_i^*\|$ 仍可以参差到天上地下。缺的那半是**交换**：什么时候值得交换相邻两根？二维的答案是比较全长，高维的正确答案是比较正交化长度。

**定义（LLL 约化基，$\delta = \frac{3}{4}$）**：基 $b_1, \ldots, b_d$ 叫 LLL 约化的，若

1. 对一切 $j < i$ 有 $|\mu_{i,j}| \le \frac{1}{2}$（消减到位）；
2. 对一切 $i \ge 2$ 有 $\|b_i^*\|^2 \ge \left(\frac{3}{4} - \mu_{i,i-1}^2\right)\|b_{i-1}^*\|^2$（Lovász 条件）。

逐符号读法：第 2 条只看相邻一对。$\mu_{i,i-1}^2 \le \frac{1}{4}$ 由第 1 条保证，于是右端至少是 $\frac{1}{2}\|b_{i-1}^*\|^2$，即整组条件等价于 $\|b_i^*\|^2 \ge \frac{1}{2}\|b_{i-1}^*\|^2$。读法：**正交化长度每前进一根，至多缩到前一根的 $\frac{1}{\sqrt{2}} \approx 0.707$ 倍**——序列 $\|b_1^*\|, \|b_2^*\|, \ldots$ 允许下降，但不许跳水，这就是「温和递减」的精确含义。为什么常数取 $\frac{3}{4}$ 而不是更贴近 $1$？$\delta$ 越大输出越好，可交换也越频繁；$\delta = \frac{3}{4}$ 是让 §4.2 的势函数论证恰好闭合的经典折中——那个 $\frac{3}{4}$ 会原样出现在势函数的缩水因子里，读到这里先记住它的存在。

**本节小结**：高维归约的关键从「比较全长」换成「相邻正交化长度温和递减」；Lovász 条件在消减配合下等价于 $\|b_i^*\|^2 \ge \frac{1}{2}\|b_{i-1}^*\|^2$。下一节把「消减＋交换」写成算法，并证明它必然停机、停得快、停得好。

## $\rm \S \, 4.2$ LLL 算法全证（本章主证）

白话：算法只有两个动作来回切——「消减」把斜成分取整减掉，「交换」让正交化残量短的站到前面去。难的不是写它，是证明它**会停**：交换看起来可以无限翻烧饼。本节的主证就是给翻烧饼计费：设计一只只取正整数值的势函数，每翻一次至少削掉四分之一，无限就此被逼成有限。

**算法（LLL，$\delta = \frac{3}{4}$）**：

1. 输入整基 $b_1, \ldots, b_d$，计算 GSO（各 $b_i^*$ 与 $\mu_{i,j}$）。置 $k = 2$。
2. **消减**：对 $j = k-1, k-2, \ldots, 1$，令 $b_k \leftarrow b_k - \lfloor\mu_{k,j}\rceil\, b_j$（同步更新 $\mu$）。
3. **检查**：若 $\|b_k^*\|^2 \ge \left(\frac{3}{4} - \mu_{k,k-1}^2\right)\|b_{k-1}^*\|^2$，则 $k \leftarrow k+1$；当 $k$ 超出 $d$，输出并停机。
4. **交换**：否则交换 $b_{k-1}, b_k$（GSO 局部重算），$k \leftarrow \max(k-1, 2)$，回到第 2 步。

终止性证明分四步走。第一步立「整值性」。

**引理（前缀 Gram 行列式）**：对整基，$D_i = \det\left(\langle b_a, b_b\rangle\right)_{a, b \le i}$（前 $i$ 根基向量的 Gram 行列式）是正整数，且 $D_i = \prod_{k=1}^{i} \|b_k^*\|^2$。

证：Gram 矩阵的元素是整向量的点积，行列式是整数；线性无关的向量组 Gram 矩阵正定，故 $D_i > 0$。乘积式来自 GSO 的三角结构：把展开式 $b_k = b_k^* + \sum_{l < k} \mu_{k,l} b_l^*$ 排成矩阵语言，基行组等于「对角线全 $1$ 的下三角矩阵」乘上「正交化行组」，而下三角阵的行列式是 $1$，正交化行组的 Gram 是对角阵 $\mathrm{diag}(\|b_1^*\|^2, \ldots, \|b_i^*\|^2)$，两者相乘的行列式正是右边。$\blacksquare$

第二步立势函数。

**定义（势函数）**：$D = \prod_{i=1}^{d-1} D_i$。由引理它是正整数，且展开为

$$
D = \prod_{k=1}^{d-1} \|b_k^*\|^{2(d-k)}
$$

读法：每根正交化向量按「离起点多近」加权——$b_1^*$ 权重 $2(d-1)$ 重，$b_{d-1}^*$ 只剩 $2$ 重，**越靠前权重越高**（任务提纲口径 $\prod_i \|b_i^*\|^{d-i}$ 的平方，平方是为了拿到整数）。前重后轻是整个证明的机关：交换会把一根短的正交化向量挪到前面，而前面的位置权重大，于是总账必然缩水。

第三步：两类动作各对 $D$ 做什么。

1. **消减不动 $D$**：$b_k \leftarrow b_k - m\,b_j$（$j < k$，$m$ 整数）只改 $\mu$ 值——$b_k^*$ 是 $b_k$ 砍掉前面方向后的残量，减掉前面方向的整数倍不改变残量与投影比，GSO 原封不动，$D_i$ 与 $D$ 纹丝不动。
2. **交换使 $D$ 至少缩到 $\frac{3}{4}$ 倍**：设交换发生在 $b_{k-1}, b_k$（Lovász 检查失败）。记 $a = \|b_{k-1}^*\|^2$，$c = \|b_k^*\|^2$，$\mu = \mu_{k,k-1}$。逐项清点 $D_j$：$j < k-1$ 的前缀没被碰，不动；$j \ge k$ 的前缀包含交换的全体成员，张成空间不变，Gram 行列式不动；唯一的变量是 $D_{k-1}$，旧值 $= W a$，其中 $W = \prod_{l < k-1} \|b_l^*\|^2$。交换后的第 $k-1$ 根基向量是旧 $b_k$，它在 $\operatorname{span}(b_1, \ldots, b_{k-2})$ 上的投影与旧 $b_k$ 相同，所以新的正交残量是

$$
b_{k-1}^{*,\text{新}} = b_k^* + \mu\, b_{k-1}^*
$$

读法：旧 $b_k$ 的残量 $b_k^*$ 里本就含着一份沿 $b_{k-1}^*$ 的成分 $\mu b_{k-1}^*$（GSO 展开式说的正是这件事）；交换后这份成分不再被砍掉，留在新残量里。于是新 $D_{k-1} = W\,\|b_k^* + \mu b_{k-1}^*\|^2 = W(c + \mu^2 a)$，而交换的触发条件恰是它的反向：

$$
c + \mu^2 a < \frac{3}{4}\,a
$$

所以 $D_{k-1}^{\text{新}} < \frac{3}{4}\, D_{k-1}^{\text{旧}}$。$\blacksquare$

第四步收口：$D$ 是不小于 $1$ 的正整数，每次交换至少缩到 $\frac{3}{4}$ 倍，故交换次数小于 $\log_{4/3} D_0$——一个只依赖输入的有限数。消减步夹在交换之间做有限工作（每轮至多 $d$ 次、每次常数条向量运算；两次交换之间每对 $\mu$ 至多被削有限刀，原论文用第二个计 $\mu$ 的势函数把这一步也封死——详见 §4.3 的复杂度账）。终止性证毕。

读法：整个证明只用了三个事实——$D$ 是正整数、消减不动它、交换按 $\frac{3}{4}$ 缩水。$d$ 维空间里没有无限翻烧饼的余地：翻一次付一次 $\frac{4}{3}$ 的利钱，本金 $D_0$ 有限。

停机之外还要「停得好」。LLL 终态满足 Lovász 条件，两条输出界都是几行不等式链。

**定理（LLL 的两条输出界）**：LLL 约化基满足

1. $\|b_1\| \le 2^{(d-1)/4}\,(\det L)^{1/d}$；
2. $\|b_1\| \le 2^{(d-1)/2}\,\lambda_1$。

证。先铺主链：由消减的 $|\mu_{i,i-1}| \le \frac{1}{2}$ 与 Lovász 条件，

$$
\|b_i^*\|^2 \ge \left(\frac{3}{4} - \frac{1}{4}\right)\|b_{i-1}^*\|^2 = \frac{1}{2}\,\|b_{i-1}^*\|^2 \quad\Longrightarrow\quad \|b_i^*\|^2 \ge 2^{-(i-1)}\,\|b_1\|^2
$$

读法：从 $b_1^* = b_1$ 出发逐代打折，第 $i$ 代至少剩 $\|b_1\|$ 的 $2^{-(i-1)/2}$ 倍——「温和递减」反过来读，就是 $\|b_1\|$ 被所有后代托底。

界 1：用第 1 章 §1.4 的 GSO 体积恒等式 $\det L^2 = \prod_{i=1}^{d} \|b_i^*\|^2$，把主链逐项代入：

$$
\det L^2 \ge \prod_{i=1}^{d} 2^{-(i-1)}\,\|b_1\|^2 = 2^{-d(d-1)/2}\,\|b_1\|^{2d}
$$

整理得 $\|b_1\|^2 \le 2^{(d-1)/2}(\det L)^{2/d}$，开方即界 1。对照第 3 章：Minkowski 给的是存在性的 $\sqrt{d}\,(\det L)^{1/d}$，LLL 给的是可计算性的 $2^{(d-1)/4}(\det L)^{1/d}$——$d \le 5$ 时后者更紧，$d$ 大时前者更紧，两条界各管一段。

界 2：设 $v$ 是最短非零格向量，$\|v\| = \lambda_1$，写 $v = \sum_i z_i b_i$，取**最大下标** $j$ 使 $z_j \ne 0$。由 GSO 展开式，$v$ 沿 $b_j^*$ 的系数恰为 $z_j$：下标大于 $j$ 的项系数全为零，而 $b_j$ 自己沿 $b_j^*$ 的系数是 $1$。正交性把平方和拆开：

$$
\lambda_1^2 = \|v\|^2 = \sum_{l \le j} (\text{系数}_l)^2\,\|b_l^*\|^2 \ge z_j^2\,\|b_j^*\|^2 \ge \|b_j^*\|^2
$$

再串主链回推：$\|b_1\|^2 \le 2^{j-1}\,\|b_j^*\|^2 \le 2^{j-1}\lambda_1^2 \le 2^{d-1}\lambda_1^2$，开方即界 2。顺手兑现第 1 章 §1.4 埋的预告：同样的论证给出 $\lambda_1 \ge \|b_j^*\| \ge \min_i \|b_i^*\|$——**最短向量被某根正交化向量的长度压住**，好基的本质就是让这些长度彼此靠近。$\blacksquare$

**本节小结**：势函数 $D = \prod_k \|b_k^*\|^{2(d-k)}$ 用前重后轻的权重把每次交换计费成 $\frac{3}{4}$ 的几何缩水，正整数性封死无限循环；输出侧，Lovász 主链把 $\|b_1\|$ 同时钉在 $\det L$ 与 $\lambda_1$ 两把尺子上。

## $\rm \S \, 4.3$ 复杂度与数值锚

复杂度账分三层（前一层全证，后两层陈述级）：

1. **交换次数**：$\le \log_{4/3} D_0$（§4.2 全证）。$D_0 = \prod_{i=1}^{d-1} D_i \le \prod_{i=1}^{d-1} \|b_i\|^{2i}$，设输入各系数绝对值不超过 $2^B$，则 $\log D_0 = O(d^2 B)$，交换次数 $O(d^2 B)$。
2. **消减工作量**：两次交换之间每对 $(k, j)$ 至多被削常数刀（每次削掉至少一份整数），总计 $O(d^3 B)$ 级算术运算、每次运算位长 $O(dB)$。原论文的总界是 $O(d^5 B^3)$ 比特运算（LLL 1982），后续细化到 $O(d^4 B^2)$ 级——多项式时间，这才是 1982 年真正震动数论界的部分，此前连「三维以上是否存在好的归约算法」都不清楚。工程上浮点 GSO 会丢精度，严肃实现（fplll 等）用 $G = B B^{\mathsf T}$ 的 Cholesky 分解做增量更新——一句话记住即可，第 6 章攻击脚本用的都是这类实现。

数值锚（§4.8 程序实跑照抄）。主例是第 1 章 §1.4 幺模坏基构造的三维版：$b_1 = (123, 1, 0)$、$b_2 = (123, 0, 1)$、$b_3 = (0, 0, 4)$。$\det = -492$，$|\det|^{1/3} = 7.894$，格的最短向量 $\lambda_1 = \sqrt{2}$（$b_2 - b_1 = (0, -1, 1)$）。LLL 只跑两轮交换就收工：

| | 势函数 $D$ | $b_1$ | $\|b_1\|$ |
| --- | --- | --- | --- |
| 初态 | $457\,818\,670$ | $(123, 1, 0)$ | $123.004$ |
| 第 1 次交换前 | $60\,518$ | — | — |
| 第 2 次交换前 | $32$ | — | — |
| 终态 | $32$ | $(0, -1, 1)$ | $1.414$ |

读法：两次交换把势函数从 $4.6 \times 10^8$ 压到 $32$，每一刀的实际缩水因子 $(c + \mu^2 a)/a$ 远好于 $\frac{3}{4}$ 的保底（第一刀就缩了几千倍）；终态 $b_1$ 长 $\sqrt{2}$，恰好命中 $\lambda_1$。两条理论界的读数：$2^{(d-1)/4}(\det L)^{1/d} = \sqrt{2} \times 7.894 = 11.16$，$2^{(d-1)/2}\lambda_1 = 2\sqrt{2} = 2.828$——实测 $1.414$ 都在界内且远好于界。再抽两个三维基对账：

| 基（各行） | $\|b_1\|$ 前 | LLL 后 $b_1$ | $\|b_1\|$ 后 | $|\det|^{1/3}$ | $\lambda_1$ |
| --- | --- | --- | --- | --- | --- |
| $(123,1,0),(123,0,1),(0,0,4)$ | $123.004$ | $(0,-1,1)$ | $1.414$ | $7.894$ | $1.414$ |
| $(11,10,10),(10,11,10),(10,10,11)$ | $17.917$ | $(-1,1,0)$ | $1.414$ | $3.141$ | $1.414$ |
| $(5,4,-5),(4,4,1),(-5,-2,-5)$ | $8.124$ | $(-2,2,2)$ | $3.464$ | $4.481$ | $3.464$ |

三维实跑三发三中 $\lambda_1$——小维数下 LLL 常常直接拿到最短向量，这正是第 5、6 章攻击脚本能工作的现实基础。二维上与 Gauss 归约对照：手选 6 组基（含第 1 章 §1.2 的 $(1,0),(1234567,1)$ 型斜基）两者输出全部一致，至多差符号与顺序。穷举系数在 $\{-5, \ldots, 5\}$ 的全部 $13\,808$ 组二维整基：$93.2\%$ 的 LLL 终态同时满足 Gauss 判据，其余 $6.8\%$ 停在临界情形——例如 $((-5,-5),(-5,4))$ 是 LLL 终态（$\mu = 0.1$，$\|b_2^*\|^2 = 40.5 \ge 37$），但 $\|b_1\| = \sqrt{50} > \|b_2\| = \sqrt{41}$，Gauss 还会再交换一步。差距被理论罩住：二维 LLL 保证 $\|b_1\| \le \sqrt{2}\,\lambda_1$（界 2 的 $d = 2$ 特例），临界例的实测比值 $\sqrt{50}/\sqrt{41} = 1.105$ 远在保证之内。一句话：**二维上 LLL 与 Gauss 几乎总是输出同一组基，临界处差一个 $\sqrt{2}$ 以内的常数**。

**本节小结**：交换 $O(d^2 B)$ 次、总复杂度多项式；主例两次交换、势函数 $4.6 \times 10^8$ 缩到 $32$、$\|b_1\|$ 从 $123$ 压到 $\sqrt{2}$；二维穷举 $93.2\%$ 与 Gauss 重合，其余差在常数内。

## $\rm \S \, 4.4$ 应用巡礼

1. **多项式因式分解（出生证明）**：原论文标题就是「Factoring polynomials with rational coefficients」——整系数多项式在 $\mathbb{Q}$ 上有多项式时间的分解算法，这在 1982 年之前连算法存在的可能性都没有。机制一句话：把「找整数关系」排成格，短向量给出低次数候选因子。
2. **$2^{(d-1)/4}$ 的实际意义**：最坏界随维数指数增长（$d = 100$ 时约 $2^{24.75}$），但实测输出远好于最坏界——随机格上通常贴近高斯启发式的读数（第 3 章 §3.4），近似因子接近常数。「最坏界悲观、平均表现温柔」是所有 LLL 使用者的共同体感，也是第 6 章参数账必须两头都算的原因。
3. **Coppersmith 小根方法（一句话）**：把多项式的幂次系数排成格，LLL 的短向量给出「在模 $N^m$ 意义下取值为零、绝对值又够小」的多项式，从而把 $|x_0| \le N^{1/d}$ 的根实打实找出来——第 5 章给骨架与 RSA 应用。
4. **Knapsack 密码的击破（一句话）**：1982 年 Shamir 用归约思想击破 Merkle–Hellman 背包密码，随后 Lagarias–Odlyzko 把低密度子集和化成格上的短向量问题——「把组合难题翻译成 SVP/CVP 再交给 LLL」从此成为密码分析的常备套路，这套翻译手册在第 6 章的 LWE 攻击面继续用。

**本节小结**：LLL 是一把万能扳手——拿在手里只要多项式时间，拧出来的是短向量；分解多项式、破背包、找小根、攻 LWE，拧的是同一颗螺丝。

## $\rm \S \, 4.5$ 关键概念回顾

1. 复述 LLL 的循环体（消减、检查、交换各自的触发条件与终态条件），并说明 Lovász 条件在 $\delta = \frac{3}{4}$ 与消减配合时等价于 $\|b_i^*\|^2 \ge \frac{1}{2}\|b_{i-1}^*\|^2$。
2. 势函数 $D = \prod_i D_i$ 为什么是正整数？交换为什么只动 $D_{k-1}$ 一项、且恰好缩水 $\frac{3}{4}$ 倍以上？
3. 写出两条输出界；界 2 的证明里「最大下标 $j$」起什么作用？§4.2 顺手兑现了第 1 章的哪个预告？

## $\rm \S \, 4.6$ 应用与辨析

1. 判断并说理：「LLL 输出的 $b_1$ 一定是格的最短向量。」
2. 若把 $\delta$ 取成 $1$（Lovász 条件变成 $\|b_i^*\|^2 \ge (1 - \mu^2)\|b_{i-1}^*\|^2$），输出质量与运行时间保证各发生什么？
3. 验证基 $((4,0),(2,3))$ 是 LLL 终态但不是 Gauss 既约基，并算出两者 $\|b_1\|$ 的差距。

## $\rm \S \, 4.7$ 本章自测答案

> 先闭卷作答上面两节，再核对。

### $\rm \S \, 4.7.1$ 关键概念回顾答案

1. 循环体：对当前 $k$，先把 $b_k$ 对 $j = k-1, \ldots, 1$ 逐个消减（$b_k \leftarrow b_k - \lfloor\mu_{k,j}\rceil b_j$）；若 $\|b_k^*\|^2 \ge (\frac{3}{4} - \mu_{k,k-1}^2)\|b_{k-1}^*\|^2$ 则 $k \leftarrow k+1$，否则交换 $b_{k-1}, b_k$ 并回退 $k$；$k$ 走出 $d$ 即终态。等价性：消减给 $|\mu_{k,k-1}| \le \frac{1}{2}$，故 $\frac{3}{4} - \mu^2 \ge \frac{1}{2}$。（§4.1、§4.2）
2. $D_i$ 是整基 Gram 矩阵的顺序主子式——元素是整点积，行列式是整数；线性无关给正定性，故为正。交换把 $b_{k-1}, b_k$ 换位：$j < k-1$ 的前缀未动、$j \ge k$ 的前缀张成空间不变，只有 $D_{k-1}$ 换内容；新残量 $b_{k-1}^{*,\text{新}} = b_k^* + \mu b_{k-1}^*$，平方长 $c + \mu^2 a < \frac{3}{4}a$（交换触发条件），故 $D_{k-1}$ 缩到 $\frac{3}{4}$ 倍以下。（§4.2）
3. 界 1：$\|b_1\| \le 2^{(d-1)/4}(\det L)^{1/d}$；界 2：$\|b_1\| \le 2^{(d-1)/2}\lambda_1$。$j$ 是 $v = \sum z_i b_i$ 中最大非零系数下标，它保证 $v$ 沿 $b_j^*$ 的系数恰为 $z_j \ne 0$，于是 $\lambda_1 \ge \|b_j^*\|$，再用主链回推 $\|b_1\|$。兑现的预告：$\min_i \|b_i^*\| \le \lambda_1$ 的走廊。（§4.2）

### $\rm \S \, 4.7.2$ 应用与辨析答案

1. 不一定。LLL 只保证 $\|b_1\| \le 2^{(d-1)/2}\lambda_1$；$d = 2$ 的临界基 $((4,0),(2,3))$ 有 $\|b_1\| = 4 > \lambda_1 = \sqrt{13} \approx 3.606$，比值 $1.109$。小维数实测命中率高（§4.3 三发三中），但那是运气加成，不是定理。（§4.2、§4.3）
2. 输出质量：$\delta$ 贴近 $1$ 时主链更紧，$\|b_1\|$ 的界趋近 Hermite 最优率。时间保证：终止性仍然成立——势函数 $D$ 是严格递减的正整数序列，必在 $D_0$ 步内停机；但缩水因子可以任意贴近 $1$，$\log_{4/3}$ 型的交换次数界失效。经典结果要求 $\delta \in (\frac{1}{4}, 1)$ 才有多项式时间保证（LLL 1982）：$\delta = 1$ 是「能停、未必快」。（§4.2、§4.3）
3. $\mu_{2,1} = \frac{\langle(2,3),(4,0)\rangle}{16} = \frac{1}{2} \le \frac{1}{2}$（消减到位）；$b_2^* = (2,3) - \frac{1}{2}(4,0) = (0,3)$，$\|b_2^*\|^2 = 9 \ge (\frac{3}{4} - \frac{1}{4}) \cdot 16 = 8$（Lovász 成立）——两项都过，LLL 停在这里。Gauss 判据要求 $\|b_1\| \le \|b_2\|$：$4 > \sqrt{13} \approx 3.606$，不满足，Gauss 会交换并继续消减，终态 $((2,3),(2,-3))$，$\|b_1\| = \sqrt{13}$。差距 $4 - \sqrt{13} \approx 0.394$，比值 $1.109$。（§4.1、§4.3）

## $\rm \S \, 4.8$ 可当场复跑的程序段

下面这段纯 Python（不依赖第三方库）实现完整的 LLL 循环，带势函数打点，并把 §4.3 的两笔账（主例、二维对照）一次算全：

```python
 # LLL：size-reduce + swap 循环，含势函数打点（纯 Python）
import itertools

def gso(B):
    d = len(B)
    bs, mu = [], [[0.0]*d for _ in range(d)]
    for i in range(d):
        v = list(B[i])
        for j in range(i):
            mu[i][j] = sum(v[k]*bs[j][k] for k in range(len(v))) / sum(x*x for x in bs[j])
            v = [v[k] - mu[i][j]*bs[j][k] for k in range(len(v))]
        bs.append(v)
    return bs, mu

def n2(v):
    return sum(x*x for x in v)

def potential(B):
 # D = prod_{i=1}^{d-1} D_i, D_i = 前 i 根的 Gram 行列式（整数）
    d = len(B); n = len(B[0])
    G = [[sum(B[a][t]*B[b][t] for t in range(n)) for b in range(d)] for a in range(d)]
    def det(M):
        if len(M) == 1: return M[0][0]
        return sum((-1)**j * M[0][j] * det([r[:j] + r[j+1:] for r in M[1:]])
                   for j in range(len(M)))
    D = 1
    for i in range(1, d):
        D *= det([[G[a][b] for b in range(i)] for a in range(i)])
    return D

def lll(B, delta=0.75, trace=None):
    B = [list(v) for v in B]; k = 1
    while k < len(B):
        bs, mu = gso(B)
        for j in range(k-1, -1, -1):
            q = round(mu[k][j])
            if q:
                B[k] = [B[k][t] - q*B[j][t] for t in range(len(B[k]))]
                bs, mu = gso(B)
        bs, mu = gso(B)
        if n2(bs[k]) >= (delta - mu[k][k-1]**2) * n2(bs[k-1]): k += 1
        else:
            if trace is not None: trace.append(potential(B))
            B[k-1], B[k] = B[k], B[k-1]
            k = max(k-1, 1)
    return B

 # 主例：三维坏基（第 1 章幺模构造的三维版）
B0 = [(123, 1, 0), (123, 0, 1), (0, 0, 4)]
tr = []
R = lll(B0, trace=tr)
print("before norms:", [round(n2(v)**0.5, 4) for v in B0])
print("swap-time potentials:", tr, " final potential:", potential(R))
print("after basis:", R, " norms:", [round(n2(v)**0.5, 4) for v in R])
print("bounds: 2^((d-1)/4)*det^(1/d) =", round(2**0.5 * 492**(1/3), 4),
      " 2^((d-1)/2)*lambda1 =", round(2 * 2**0.5, 4))

 # 二维对照：LLL 终态与 Gauss 判据
def gauss2(b1, b2):
    while True:
        if n2(b2) < n2(b1): b1, b2 = b2, b1
        mu = round((b1[0]*b2[0] + b1[1]*b2[1]) / n2(b1))
        if mu == 0: return b1, b2
        b2 = (b2[0] - mu*b1[0], b2[1] - mu*b1[1])
for (u, v) in [((1,0),(1234567,1)), ((123,1),(122,1)), ((19,7),(5,2)),
               ((100,1),(101,1)), ((2,0),(1,3)), ((7,11),(13,17))]:
    g, l = gauss2(u, v), lll([list(u), list(v)])
    print(f"{u},{v}: gauss {g} | lll {[tuple(x) for x in l]}")
agree = tot = 0; ex = None
for a, b, c, dd in itertools.product(range(-5, 6), repeat=4):
    if a*dd - b*c == 0: continue
    l = lll([list((a, b)), list((c, dd))])
    ok = n2(l[0]) <= n2(l[1]) and 2*abs(l[0][0]*l[1][0] + l[0][1]*l[1][1]) <= n2(l[0])
    tot += 1; agree += ok
    if not ok and ex is None: ex = ((a, b), (c, dd))
print("sweep: total", tot, " LLL terminal && Gauss-reduced:", agree,
      " critical:", tot - agree, " first critical:", ex)
```

## $\rm \S \, 4.9$ 带走清单

1. LLL 约化基：消减 $|\mu_{i,j}| \le \frac{1}{2}$ 加 Lovász 条件 $\|b_i^*\|^2 \ge (\frac{3}{4} - \mu_{i,i-1}^2)\|b_{i-1}^*\|^2$，后者等价于「正交化长度每前进一根至多缩 $\frac{1}{\sqrt{2}}$ 倍」。
2. 终止性（本章主证）：势函数 $D = \prod_{i=1}^{d-1} D_i = \prod_k \|b_k^*\|^{2(d-k)}$ 是正整数，消减不动它，交换使它至少缩水 $\frac{3}{4}$ 倍（新残量 $= b_k^* + \mu b_{k-1}^*$，触发条件正是 $c + \mu^2 a < \frac{3}{4}a$），故交换次数 $\le \log_{4/3} D_0$。
3. 两条输出界：$\|b_1\| \le 2^{(d-1)/4}(\det L)^{1/d}$ 与 $\|b_1\| \le 2^{(d-1)/2}\lambda_1$；证明的引擎是主链 $\|b_i^*\|^2 \ge 2^{-(i-1)}\|b_1\|^2$ 与「最大下标」论证；副产品 $\min_i \|b_i^*\| \le \lambda_1$ 兑现第 1 章预告。
4. 复杂度：交换 $O(d^2 B)$ 次，总界 $O(d^5 B^3)$ 比特运算（LLL 1982），后续 $O(d^4 B^2)$ 级；工程实现用 Cholesky 增量更新防浮点丢精度。
5. 数值锚——基 $((123,1,0),(123,0,1),(0,0,4))$：$|\det|^{1/3} = 7.894$，$\|b_1\|$ 从 $123.004$ 压到 $1.414 = \lambda_1$，势函数 $457818670 \to 32$，两次交换收工；二维穷举 $13808$ 组基，$93.2\%$ 与 Gauss 输出重合，其余差在 $\sqrt{2}$ 常数内（临界例 $((-5,-5),(-5,4))$）。
6. 应用史：分解有理系数多项式（原论文主题）、击破 Knapsack（Shamir 1982、Lagarias–Odlyzko）、Coppersmith 小根（第 5 章）、LWE 对偶攻击（第 6 章）——同一把扳手。
