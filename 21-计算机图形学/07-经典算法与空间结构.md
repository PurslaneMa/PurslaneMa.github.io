## $\rm \S \, 7.1$ 凸包的两个用途视角

Andrew 单调链你已经写到肌肉记忆，本章不碰它的实现，只换问题：凸包在竞赛之外拿来干什么。第一个用途是碰撞检测。两个任意网格模型直接判交是 $O(nm)$ 的逐三角形比较，物理引擎的做法是先把每个物体压缩成凸包，在凸包对上用 GJK（Gilbert–Johnson–Keerthi）距离算法判交与测距；更粗糙也更常用的一层是轴对齐包围盒（axis-aligned bounding box，AABB）——把物体沿坐标轴框起来的最小盒子，一次六次比较就能建，先盒后物的两级筛选把绝大多数不可能相撞的物体对在常数时间挡掉。凸包与 AABB 是同一个思想在「精度换速度」坐标轴上的两个取值：凸包是最紧的凸外壳，AABB 是最便宜的外壳。

第二个用途是把散点问题转成凸问题。平面点集上沿任意方向取极值的点必是凸包顶点、最远点对必是凸包顶点对（旋转卡壳在包上 $O(h)$ 扫完）——「先花 $O(n\log n)$ 取凸包，再在只有 $h$ 个顶点的凸结构上回答查询」是通用的配方。竞赛用它拿部分分，图形学用它把连续的物体边界压缩成可索引的离散结构，同一步棋。

## $\rm \S \, 7.2$ 最近点对分治：带内常数后继

平面上 $n$ 个点的最近点对，朴素要算 $\binom{n}{2}$ 对距离。分治解法骨架：按 $x$ 排序后对半分，递归得到左右两半内部的最近距离 $\delta_L$ 与 $\delta_R$，令 $\delta=\min(\delta_L,\delta_R)$；剩下的麻烦只在跨越分界线的对。它们必然落在分界带（strip）内——到中位线 $x$ 距离小于 $\delta$ 的竖直窄条。

关键引理：把带内点按 $y$ 排序后，每个点只需与 $y$ 方向距离小于 $\delta$ 的后继算距离，这样的后继不超过 7 个。论证是装箱计数：某点 $p$ 的候选后继全部落在以 $p$ 为底、宽 $2\delta$（分界带全宽）、高 $\delta$ 的矩形里；矩形切成两个 $\delta\times\delta$ 方块，同一方块内的点同属一半，两两距离不小于 $\delta_L$（或 $\delta_R$），均 $\ge\delta$——边长 $\delta$ 的方块里两两距离 $\ge\delta$ 的点至多 4 个（四个角附近各一个）。两块合计至多 8 个点，扣除 $p$ 自身剩 7 个。于是每个点只做常数次距离计算。

复杂度 $T(n)=2T(n/2)+O(n)$，解为 $O(n\log n)$；前提是带内的 $y$ 序从左右两半的 $y$ 序归并继承（归并排序的套路），若每层重新排序则是 $O(n\log^2 n)$。

8 个点手工走一遍（坐标见下表，全部实跑验证过）：

| $i$ | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| $(x,y)$ | (0,0) | (1,3) | (2,1) | (4,2) | (5,2.6) | (6,0.5) | (7,4) | (8,1) |

| 步骤 | 计算 | 结果 |
| --- | --- | --- |
| 左半递归（$P_1$ 至 $P_4$） | 6 对距离取最小 | $\delta_L=\sqrt5\approx2.2361$ |
| 右半递归（$P_5$ 至 $P_8$） | 6 对距离取最小 | $\delta_R=\sqrt{4.25}\approx2.0616$ |
| 分界带 $2.4384<x<6.5616$ | 按 $y$ 排序 | 带内 3 点：$P_6,P_4,P_5$ |
| 带内扫描 | $P_6$ 对 $P_4$：2.5000；$P_4$ 对 $P_5$：1.1662 | 最近对 $P_4P_5$，$\sqrt{1.36}\approx1.1662$ |

用 28 对距离的暴力核对过，答案一致；带内只算了 2 次距离，连「后继 y 差超过 $\delta$ 就停」的剪枝都用上了（$P_6$ 到 $P_5$ 的 $y$ 差 2.1 已超过 $\delta$，直接停）——引理不是渐近装饰，是逐点生效的机制。

## $\rm \S \, 7.3$ 扫描线、Voronoi 与 Delaunay

**扫描线（sweep line）**是一个把静态问题改写成事件序列的通用视角：一根竖直线从左往右扫过平面，几何只在若干「事件点」处发生变化，用一个按 $y$ 组织的状态结构维护当前与扫描线相交的对象，只对相邻对象做检查。线段求交就是这样从 $O(n^2)$ 降到 $O\big((n+k)\log n\big)$（$k$ 为交点数）：事件是端点与交点，状态结构是活跃线段集，检查只在相邻线段间发生。你写过的「排序事件、维护集合、只查邻居」都是这个模板的实例。

同一根扫描线以更精巧的事件规则推进，就得到 **Voronoi 图（Voronoi diagram）**：平面上 $n$ 个站点（site）各占一块区域，区域内任何点到自己站点的距离严格小于到其他站点的距离——它是「最近邻」这个概念的几何化身。把相邻区域的站点连边，得到对偶的 **Delaunay 三角剖分（Delaunay triangulation）**：一个三角形属于 Delaunay，当且仅当它的外接圆内部不含任何其他站点（这个空圆特征是它最重要的判据）。非退化点集上它还有一个昂贵的性质：在所有三角剖分中最大化最小角，天然避开薄片三角形——上一章刚见过 sliver 是判号毒药。

用途至少三件。其一，最近邻查询：Voronoi 图建好后，「给任意查询点找最近站点」就是定位它落在哪块区域里。其二，三角网格生成：有限元与渲染的网格前处理普遍先做 Delaunay 剖分，避免病态三角形。其三，插值：自然邻域插值按查询点「切掉」各邻居 Voronoi 区域的面积加权，比距离反比插值更平滑。Fortune 的扫描线算法 $O(n\log n)$ 建图，细节不在此展开；实践中直接调用 CGAL 或 scipy 的现成实现。

## $\rm \S \, 7.4$ 空间加速结构：把求交从 $n$ 降到 $\log n$

第 5 章的循环是「每条光线对每个三角形求交」：一百万三角形、一百万像素、每像素上千条路径，每帧 $10^{12}$ 量级的求交——线性扫描必须死。三种结构给出三种活法。

均匀网格（uniform grid）把空间切成等大的格子，每个三角形登记进它覆盖的格子；查询时光线沿格子序列步进，只对经过的格子里的三角形求交。建树成本近乎零，但收益押注在分布均匀上：物体稀疏处浪费格子，聚集处一格塞进成千上万个三角形（「茶壶体育场」问题）。

KD 树（kd-tree）属于点结构：递归沿最宽的轴按中位数切开点集。最近邻查询时维护当前最优半径，若查询球与切平面不相交就整侧剪掉，期望 $O(\log n)$；维度一高（几十维以上）剪枝失效，退化到近线性——维数灾难的标准受害者。

包围体层次（bounding volume hierarchy，BVH）是物体结构的王者：每个节点用 AABB 框住一包三角形，递归对半分（实践中按质心沿最宽轴中位数切），叶子留少量三角形；查询时光线先做盒测试（slab 法），命中盒子才下潜，三角形求交只发生在叶子上。它不押注分布，是生产渲染器与物理引擎的默认结构。

| 结构 | 建树成本 | 查询方式 | 适合的分布 |
| --- | --- | --- | --- |
| 均匀网格 | $O(n)$ | 光线沿格子步进 | 均匀铺开 |
| KD 树 | $O(n\log n)$ | 切平面剪枝下潜 | 点集、低维（≲20 维） |
| BVH | $O(n\log n)$ | 盒测试下潜 | 任意物体集合 |

实测一把。固定种子生成 2000 个边长量级为 1 的三角形，散布在边长 10 的立方体内；2000 条从盒外出发的随机射线；暴力与 BVH 用同一套第 5 章的 Möller–Trumbore 判号，BVH 按质心最宽轴中位数建树、叶至多 4 片三角形：

```python
import random, time
random.seed(20261024)
n_t, n_r = 2000, 2000
tris = []
for _ in range(n_t):
    c = [random.uniform(0, 10) for _ in range(3)]
    tris.append(tuple(tuple(c[k] + random.uniform(-.5, .5) for k in range(3)) for _ in range(3)))
rays = []
for _ in range(n_r):
    o = tuple(-5 + random.uniform(0, 3) for _ in range(3))
    rays.append((o, tuple(random.uniform(0, 10) - o[k] for k in range(3))))

def sub(a, b): return (a[0]-b[0], a[1]-b[1], a[2]-b[2])
def dot(a, b): return a[0]*b[0]+a[1]*b[1]+a[2]*b[2]
def crs(a, b): return (a[1]*b[2]-a[2]*b[1], a[2]*b[0]-a[0]*b[2], a[0]*b[1]-a[1]*b[0])

def ray_tri(o, d, v):                    # 第 5 章的判号链
    e1, e2 = sub(v[1], v[0]), sub(v[2], v[0])
    p = crs(d, e2); det = dot(e1, p)
    if abs(det) < 1e-12: return None
    s = sub(o, v[0]); u = dot(s, p)/det
    if u < -1e-9 or u > 1+1e-9: return None
    q = crs(s, e1); w = dot(d, q)/det
    if w < -1e-9 or u+w > 1+1e-9: return None
    t = dot(e2, q)/det
    return t if t > 1e-6 else None

def aabb(ids):
    lo = [min(tris[i][j][k] for i in ids for j in range(3)) for k in range(3)]
    hi = [max(tris[i][j][k] for i in ids for j in range(3)) for k in range(3)]
    return tuple(lo), tuple(hi)

def build(ids):                          # 质心沿最宽轴中位数二分
    lo, hi = aabb(ids)
    if len(ids) <= 4:
        return (lo, hi, None, None, ids)
    ax = max(range(3), key=lambda k: hi[k]-lo[k])
    ids.sort(key=lambda i: tris[i][0][ax]+tris[i][1][ax]+tris[i][2][ax])
    m = len(ids)//2
    return (lo, hi, build(ids[:m]), build(ids[m:]), None)

def ray_box(o, inv, lo, hi):             # slab 法盒测试
    t0, t1 = 1e-6, 1e30
    for k in range(3):
        a, b = (lo[k]-o[k])*inv[k], (hi[k]-o[k])*inv[k]
        if a > b: a, b = b, a
        t0, t1 = max(t0, a), min(t1, b)
    return t0 <= t1

def traverse(node, o, d, inv, cnt):      # 最近命中查询
    if not ray_box(o, inv, node[0], node[1]): return None
    if node[4] is not None:
        best = None
        for i in node[4]:
            cnt[0] += 1
            t = ray_tri(o, d, tris[i])
            if t is not None and (best is None or t < best): best = t
        return best
    tl = traverse(node[2], o, d, inv, cnt); tr = traverse(node[3], o, d, inv, cnt)
    if tl is None: return tr
    if tr is None: return tl
    return min(tl, tr)

root = build(list(range(n_t)))
cnt = [0]; t0 = time.perf_counter()
for o, d in rays:
    traverse(root, o, d, tuple(1/x for x in d), cnt)
print(cnt[0], time.perf_counter()-t0)    # 111742 次；暴力同法计满 4000000 次
```

本机实测结果（Python 3.12，数字为量级参考，重跑会有小幅波动）：

| 方案 | 三角形求交测试 | 2000 条射线耗时 | 最近命中判定 |
| --- | --- | --- | --- |
| 暴力 | 4 000 000（每射线 2000） | 3.950 s | 命中 1400 条 |
| BVH | 111 742（每射线平均 55.9） | 0.435 s | 命中 1400 条 |

读表三句。测试次数降了 35.8 倍：树深约 $\log_2(2000/4)\approx9$ 层，每层只对常数个盒子做测试，三角形测试只在少数叶子发生——这就是「从 $n$ 到 $\log n$」的具体长相。耗时只降 9.1 倍而不是 35.8 倍：盒测试与递归调用本身有开销，省下的次数一部分被它们吃掉，这也是为什么生产渲染器还要做宽节点、SIMD 化盒测试等二阶优化。两条射线的最近命中逐条核对过，暴力与 BVH 结果零分歧——加速没有改变答案，只改变了访问路径。

## $\rm \S \, 7.8$ 本章自测答案

> 先闭卷作答上面两节，再核对。

### $\rm \S \, 7.8.1$ 关键概念回顾答案

1. 带内点按 $y$ 排序后，每个点只与 $y$ 差小于 $\delta$ 的后继算距离。候选后继落在 $2\delta\times\delta$ 矩形内，切成两个 $\delta\times\delta$ 方块；同侧点两两距离 $\ge\delta$，每块至多容纳 4 个，合计 8 个，扣除自身剩 7 个。（§7.2）
2. Voronoi 区域相邻的两个站点在 Delaunay 中连边，Delaunay 三角剖分是 Voronoi 图的直线对偶；Delaunay 三角形的外接圆内部不含任何其他站点，非退化点集上它最大化最小角。（§7.3）
3. 均匀网格 $O(n)$ 建立等大格子、光线沿格子步进，押注分布均匀；KD 树沿最宽轴中位数切点集、查询用切平面剪枝，押注低维；BVH 用 AABB 递归包住物体、命中盒才下潜，不押注分布。（§7.4）
4. 差额消耗在盒测试与递归调用的固定开销上：省下的是 35.8 倍三角形测试，但每层还要做常数个 slab 盒测试与函数调用，这些成本在暴力版里不存在。（§7.4）

### $\rm \S \, 7.8.2$ 应用与辨析答案

1. 均匀网格失效：格子尺寸按整体范围定，小盒里上千个三角形挤在同一格，查询退回格内线性扫描，即「茶壶体育场」问题。BVH 会自适应地把密集区切深、稀疏区切浅，密集处树深只增加常数层。（§7.4）
2. 全量重建 $O(n\log n)$ 每帧做一遍，正确但贵；只更新包围盒（refit）把树结构视为不变、自底向上重算 AABB，$O(n)$ 且对拓扑缓慢变化的场景通常足够好，代价是长年累积后树形与分布脱节、查询变慢；不更新则包围盒失效，可能漏检——正确性先于速度，至少要 refit。（§7.4）
3. 退化为每点 $O(n)$ 次距离计算，分治的总代价变成 $T(n)=2T(n/2)+O(n^2)=O(n^2)$，等于白分。引理把它压成每点常数次，这是整个算法成立的支点。（§7.2）
