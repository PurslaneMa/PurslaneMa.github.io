## $\rm \S \, 1.1$ 问题：把「问题」写成数学对象

一台机器要机械地判定问题，输入必须是一串符号。于是先固定三个对象。**字母表（alphabet）**是非空有穷符号集，记作 $\Sigma$，例如二进制字母表 ${\{0,1\}}$。**串（string）**是 $\Sigma$ 中符号的有限序列，如 `1001`；不含任何符号的串叫空串，记 $\varepsilon$；串 $w$ 的长度记 ${\lvert w\rvert}$；$\Sigma^*$ 表示 $\Sigma$ 上全体串的集合。**语言（language）**就是 $\Sigma^*$ 的一个子集：$L\subseteq\Sigma^*$。这三个对象没有任何深意，深意在下一步的转译。

一个判定问题的实例（一道 OJ 题的一组输入数据）可以编码成一个串——你在 OJ 上读入的数据本身就是这个编码。把所有答案是「是」的实例的编码收集起来，得到一个语言；于是**判定问题（decision problem）＝语言**：「解这个问题」与「判串 $w$ 是否属于 $L$」是同一件事。例如「图 $G$ 有没有哈密顿回路」：把 $G$ 编码成 01 串，语言 ${\text{HAM}={\{\text{编码}\,w:\,w\text{ 对应的图有哈密顿回路}\}}}$。一台判定机器逐字符读完 $w$，停在「接受」或「拒绝」；接受当且仅当 ${w\in L}$。竞赛生熟悉的「判定版与构造版可以互推」（先判可行性，再逐位构造方案）正是这个身份的日常用法：本册从头到尾只谈判定版，因为构造版总能由判定版带多项式开销地导出（第 9 章回到这一点）。

## $\rm \S \, 1.2$ 正则表达式：三种运算造出的语言

现在给一小类语言起名字。**正则表达式（regular expression）**按归纳定义：基础情形是 $\varnothing$（空语言）、$\varepsilon$（只含空串的语言）与单个符号 $a$（语言 ${\{a\}}$）；若 ${r,s}$ 是正则表达式，则 ${r\mid s}$、$rs$、$r^*$ 也是。三种运算的语义直接作用在语言上：

$$
L(r\mid s)=L(r)\cup L(s),\qquad L(rs)=L(r)\,L(s),\qquad L(r^*)=\bigcup_{k\ge0}L(r)^k
$$

其中语言 $L(r)L(s)$ 表示「从 $L(r)$ 取一个串接上 $L(s)$ 取一个串」的全体，$L(r)^0={\{\varepsilon\}}$。三种运算一张表钉住：

| 运算 | 语义 | 最小例 |
| --- | --- | --- |
| 并 | 两侧语言取并集 | 「0 或 1」：恰一个字符的两种可能 |
| 连接 | 依次拼接 | 「两个字符」：00、01、10、11 |
| 星 | 重复零次或任意多次 | 「重复 01」：$\varepsilon$、01、0101、… |

优先级：星最高、连接次之、并最低，括号可覆盖。

> **易混点**：$\varepsilon$、$\varnothing$、${\{\varepsilon\}}$ 三者两两不同——第一个是长度为 0 的**串**，第二个是不含任何串的**语言**，第三个是恰含空串的语言。混掉它们，星运算就读不通：$L(r^*)$ 永远含 $\varepsilon$，再「空」的表达式加上星也不再空。

一个能手算的例子：「倒数第二位是 1」的二进制串语言。思路：前缀随便长（`(0|1)*`），然后强制一个 1，再留恰好一个符号收尾，正则式是 `(0|1)*1(0|1)`。核对不能靠眼睛，用脚本把两种独立说法（正则式语义与直接谓词）对全部长度 $0$ 到 $8$ 的串（共 $511$ 个）比对：

```python
from itertools import product

def ok(s):                     # 谓词：倒数第二位是 1
    return len(s) >= 2 and s[-2] == '1'

def nfa(s):                    # (0|1)*1(0|1) 的 NFA：q0 自环；q0 -1-> q1；q1 -0/1-> q2
    st = {0}
    for c in s:
        st = {0} | ({1} if c == '1' else set()) | ({2} if 1 in st else set())
    return 2 in st

assert all(nfa(''.join(t)) == ok(''.join(t))
           for n in range(9) for t in product('01', repeat=n))
print([s for s in ['0', '10', '11', '010', '1100'] if nfa(s)])
```

运行输出 `['10', '11', '010']`，与谓词逐一相符：`10`、`11`、`010` 接受，`0` 太短、`1100` 倒数第二位是 0，都拒绝。`assert` 不报错说明 $511$ 个串上两种判定零分歧。这段代码里已经出现了「机器」的影子（`st` 是活跃状态的集合），§1.3 给它正式身份。

## $\rm \S \, 1.3$ 有穷自动机

### $\rm \S \, 1.3.1$ 确定型有穷自动机

**确定型有穷自动机（deterministic finite automaton, DFA）**是五元组 ${M=(Q,\Sigma,\delta,q_0,F)}$：

| 组件 | 含义 |
| --- | --- |
| $Q$ | 有穷状态集 |
| $\Sigma$ | 输入字母表 |
| $\delta$ | 转移函数 ${\delta:Q\times\Sigma\to Q}$：当前状态与当前符号唯一确定下一状态 |
| ${q_0\in Q}$ | 起始状态 |
| ${F\subseteq Q}$ | 接受状态集 |

运行读法：从 $q_0$ 出发，按输入串逐字符走 $\delta$；读完整个串，落在 $F$ 中则接受，否则拒绝。注意 ${q_0\in F}$ 时空串 $\varepsilon$ 被接受。「当前状态＋当前符号决定下一步」——你在竞赛里手写的每一个状态机都是它。

最小例：判定二进制串表示的数模 $3$ 的余数。状态就是余数本身，${Q={\{q_0,q_1,q_2\}}}$；读到第 $k$ 位时已有前缀值 $v$，读入 $b$ 后值变 $2v+b$，故余数转移为 ${r\leftarrow(2r+b)\bmod 3}$：

| 状态 | 读 0 | 读 1 | 接受？ |
| --- | --- | --- | --- |
| $q_0$（余 0） | $q_0$ | $q_1$ | 是 |
| $q_1$（余 1） | $q_2$ | $q_0$ | 否 |
| $q_2$（余 2） | $q_1$ | $q_2$ | 否 |

手核 `1010`（十进制 $10$，$10\bmod3=1$）：${q_0\to q_1\to q_2\to q_2\to q_1}$，停在接受态？$q_1$ 不是接受态——而 $10\bmod3=1$ 本来就不该接受，判定正确。脚本核对 `11`、`110`、`1001`、`111`、`1010`、`0` 六个串，DFA 终态余数与 `int(s, 2) % 3` 全部一致。状态数为什么恰好是 $3$：机器需要记住的唯一信息就是余数，余数只有三种；§2.3 会把这个直觉变成定理。

### $\rm \S \, 1.3.2$ 非确定型有穷自动机与子集构造

判「以 `01` 结尾」时，DFA 不好直接写：读到 0 时，这个 0 是否是结尾 `01` 的开头，取决于未来。**非确定型有穷自动机（nondeterministic finite automaton, NFA）**放开这一步：转移函数改为 ${\delta:Q\times\Sigma\to 2^Q}$（$2^Q$ 是 $Q$ 的幂集），同一个状态读同一个符号可以同时走向**多个**状态；输入被接受当且仅当存在**某一条**运行路径落在 $F$ 中。直觉是把机器复制成多份同时押注所有可能。

例：三状态 NFA 判「以 `01` 结尾」——$q_0$ 对 0、1 都自环（前缀随便走），$q_0$ 读 0 分岔到 $q_1$（押注这个 0 是开头），$q_1$ 读 1 走到接受态 $q_2$。把「押注」逐字符并行执行，每步手里握着的是一个**状态的集合**。既然如此，干脆把这个集合当作一个新状态——这就是**子集构造（subset construction）**。从起始子集 ${\{q_0\}}$ 出发，只追踪可达的子集：

| 可达子集 | 读 0 | 读 1 | 接受？（含 $q_2$） |
| --- | --- | --- | --- |
| $A={\{q_0\}}$ | $B$ | $A$ | 否 |
| ${B={\{q_0,q_1\}}}$ | $B$ | $C$ | 否 |
| ${C={\{q_0,q_2\}}}$ | $B$ | $A$ | 是 |

三个可达子集得到一台三状态 DFA。理论上子集最多 ${2^3}=8$ 个（一般上界 ${2^{|Q|}}$），实际常远小于上界——不可达的子集直接扔掉。脚本核验：上述 DFA 与原 NFA 在长度不超过 $10$ 的全部 $2047$ 个串上判定零分歧。

> **易混点**：子集构造后的 DFA 状态是「NFA 状态的集合」，不再是单个状态；同一个 $q_0$ 出现在 $A$、$B$、$C$ 三个子集里是正常现象，不是三台机器。

注意 NFA 与 DFA 认识的语言类完全一样（下一小节），NFA 的好处只是**写得短**。

### $\rm \S \, 1.3.3$ Kleene 定理

**Kleene 定理（Kleene's theorem）**：一个语言能由正则表达式描述，当且仅当它能被某台有穷自动机识别。两个方向各一句机制。正则式到自动机：对表达式做归纳，三种运算各对应一次小规模拼装（并用 §1.3.2 的子集构造抹平非确定性）。自动机到正则式：**逐状态删去法（state elimination）**——把中间状态一个个删去，每删一个，就用带星的正则式把「经过它的一切绕行走法」折叠进边的标签；全删完后，起点到接受态边的标签并起来就是答案。因此本册此后说「正则语言」，不再区分用正则式还是自动机来表述——三种写法（正则式、DFA、NFA）能力完全相同。

## $\rm \S \, 1.4$ 竞赛连接：你早就在写自动机

1. **KMP 就是手写 DFA**。匹配「文本中是否出现模式 $P$」的自动机有 ${\lvert P\rvert+1}$ 个状态（已匹配的前缀长度），KMP 预处理出的失败函数正是在补全这张转移表：失配时跳到「最长的既是后缀又是前缀」的状态。你手算过的 `next` 数组就是 $\delta$。
2. **位压 DP 是以子集为状态的有穷自动机**。`f[S]` 以二进制子集为状态、以「加入一个元素」为转移，整张表是一台状态数为 ${2^n}$ 的自动机上的递推。自动机视角顺带解释了它的复杂度：状态空间被 $Q$ 的指数大小封顶，轮廓线优化、剪枝本质是在缩小 $Q$。
3. **「禁止模式计数」类 DP**（如数不含连续 `11` 的串）把 KMP/AC 自动机的状态塞进 DP 维度，是「自动机 × 逐位计数」的直接组合——§1.3 的机器加上计数，竞赛里你已经写过。

## $\rm \S \, 1.7$ 本章自测答案

> 先闭卷作答上面两节，再核对。

### $\rm \S \, 1.7.1$ 关键概念回顾答案

1. 把每个实例编码成 $\Sigma^*$ 中的串，「答案是是的实例」的编码全体的集合就是语言 $L$；解问题＝判 ${w\in L}$。例：「串 $s$ 中是否出现子串 `01`」的语言为 ${\{w:\ w\text{ 以 }01\text{ 结尾或中间含 }01\}}$，更干净的写法是补集思路——不含 `01` 的串形如 $1^*0^*$。（§1.1）
2. 并 ${r\mid s}$ 对应「两个语言取一个」，连接 $rs$ 对应「串的拼接」，星 $r^*$ 对应「重复零次或任意次」。「以 `11` 结尾」写作 `(0|1)*11`。（§1.2）
3. ${M=(Q,\Sigma,\delta,q_0,F)}$：状态集、字母表、转移函数、起始态、接受态集。空串读入零个字符，机器停在 $q_0$；它属于 $F$ 故接受。（§1.3.1）
4. NFA 的转移是 $\delta:Q\times\Sigma\to2^Q$，一步可同时走多个状态，有一条路径接受即接受。子集构造把「当前活跃状态集」整体当状态，每步对集合逐元素取并，恰好复现了 NFA 的并行语义，故语言不变。（§1.3.2）
5. 正则表达式可识别的语言＝有穷自动机可识别的语言。逐状态删去法把中间状态删掉，用带星表达式把「经过该状态的所有绕行路径」折进边标签，最终起点到接受态的标签并集即正则式。（§1.3.3）

### $\rm \S \, 1.7.2$ 应用与辨析答案

1. 语言能力上 NFA 不比 DFA 强：子集构造把任何 NFA 变成等价 DFA（§1.3.2 的三状态实例）。NFA 的好处是**描述紧凑**——指数小的机器写起来短，且「存在一条路径」的语义常让构造直接得多。（§1.3.2）
2. 模 5 需要 5 个状态。状态数由机器必须记住的信息量决定：当前余数有 5 种取值，每种都要一个状态；§2.3 的 Myhill–Nerode 定理会证明 5 是最小值，不是写法浪费。（§1.3.1、§2.3）
3. 正则式：`((0|1)(0|1))*`；DFA：两个状态 $q_0$（偶，起始且接受）、$q_1$（奇），读任何符号在两者间翻转。按 Kleene 定理，能写出正则式的语言必有自动机识别，且上述 DFA 逐字符核对该正则式的语义：每两个字符一组，读完整数组回到 $q_0$。（§1.2、§1.3.3）
