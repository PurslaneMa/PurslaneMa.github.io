# $\rm \S \, Chapter \, 17$ 加性组合：和集与 Freiman

前两章的机器都在「求渐近」上运转；本章换问题形态：两个集合做加法，$A + B = \{a + b : a \in A, b \in B\}$——不问和的数值，问**和集有多大、多整齐**。这个问题朴素到近乎幼稚，却是素数分布与算法竞赛共用的底座：偶数几乎都是两个素数之和（Goldbach），全部 $\ge 9$ 的奇数都是三个奇素数之和（弱 Goldbach，Helfgott 2013 完整证明）——密度归零的素数集泼洒两三次就铺满整数轴，这说明「加法生成力」与「密度」是两个独立的量。竞赛一侧，集合卷积的支撑大小、$A + B \subseteq C$ 型覆盖构造、$|A+A|$ 偏小时的集合形状，问的是同一件事。本章建立这套语言（和集、Ruzsa 距离、Plünnecke），陈述两座大山（Freiman 结构定理、Roth 定理），并在 cap set 一节埋下第 18 章多项式方法的引线。

> **开始前自检**：本章假设你已经会：
>
> 1. □ 第 2 章的形式幂级数乘法：卷积系数 $\sum_{a+b=n}$ 与「支撑」概念。
> 2. □ 第 13 章期望的线性性与一阶矩（Roth 一节与它握手）。
> 3. □ 初等数论：最大公约数、同余类（$3k-4$ 的数值验证与有限域一节的门槛）。
> 4. □ 第 14 章「维数当天花板」的语感（本章只借用，第 18 章正式回归）。
>
> 有限交换群与向量空间的初等语言（子空间、陪集）作为标准工具引用。核心参考：Tao–Vu《Additive Combinatorics》(2006) 第 2 章（Ruzsa 演算与 Plünnecke–Ruzsa 不等式，§2.3–2.5）、第 10 章（Roth 型密度增量）；Nathanson《Additive Number Theory: Inverse Problems and the Geometry of Sumsets》(GTM 165)。

## $\rm \S \, 17.1$ 动机：素数的加法与集合卷积是同一道题

1. **素数侧**。素数集 $P$ 在 $[N]$ 里的密度 $\frac{\pi(N)}{N} \approx \frac{1}{\ln N}$ 趋于零，但泼洒一次：$P + P$ 覆盖 $[4, 5000]$ 内全部偶数（本章真算通过；Goldbach 猜想已被验证到 $4 \times 10^{18}$，出处 Oliveira–Silva 等 2014 综述）；泼洒两次：每个 $\ge 9$ 的奇数都是三个奇素数之和（$[9, 5000]$ 真算通过；全体情形即弱 Goldbach 定理，Helfgott 2013）。稀疏的集合加法生成力惊人——「盖得多齐」与「本身多密」解耦，是加性组合（additive combinatorics）的第一课。
2. **竞赛侧**。值域 $[0, M]$ 上，集合卷积 $(\mathbf{1}_A * \mathbf{1}_B)(n) = \#\{(a, b) \in A \times B : a + b = n\}$ 是第 2 章幂级数乘法的 0-1 版；它的支撑大小就是 $|A + B|$，表示数的分布就是覆盖结构。覆盖构造题、极值题（$|A+B|$ 的最大最小）、结构题（$|A+A|$ 小则 $A$ 像什么）共用这一层。
3. **量尺**。一切从两端钉死：$|A + B|$ 最大是 $|A||B|$（每对组合各溅出一个不同的点），最小是 $|A| + |B| - 1$（下节全证）。比喻：$A + B$ 是**两袋数互相泼洒后的混合物**——泼得越散越像随机，几乎不溅开则两袋数是同一条骨架的拷贝。加性组合研究倍增常数 $K = \frac{|A+A|}{|A|}$ 偏小时的世界的几何；「小和集」不是巧合，是**结构化的代价**：想让泼洒不膨胀，每个成员必须放弃排布上的自由。

小结：两个世界共享一把尺——$|A+B|$ 从 $|A|+|B|-1$ 到 $|A||B|$ 之间的位置，量出集合的结构含量。

## $\rm \S \, 17.2$ 和集语法：最小值定理与三档标尺

1. **记号**：$2A = A + A$（注意不是标量乘 $\{2a\}$，那是 $2 \cdot A$）；$kA$ 同理逐层泼洒。本章集合均为整数集（无挠），有限域情形在 §17.7 另说。
2. **最小值定理**：$A = \{a_1 < \cdots < a_k\}$，$B = \{b_1 < \cdots < b_m\}$，则 $|A + B| \ge k + m - 1$。证明（平移链）：序列
$$
a_1 + b_1 < a_2 + b_1 < \cdots < a_k + b_1 < a_k + b_2 < \cdots < a_k + b_m
$$
前段同加 $b_1$、随 $a$ 递增；衔接处 $a_k + b_1 < a_k + b_2$（$b_1 < b_2$）；后段同加 $a_k$、随 $b$ 递增。这是 $k + m - 1$ 个互不相同的 $A+B$ 成员。$\blacksquare$ 读法：先让 $A$ 整队从 $b_1$ 的门口各走一遍（贡献 $k$ 个点），再让队长 $a_k$ 陪 $B$ 的其余成员各走一步（每步至少溅出一个新点，贡献 $m - 1$ 个）。
3. **取等**：$A = B = \{0, d, 2d, \ldots\}$ 型等差数列时 ${2A}$ 恰是同一公差的等差数列，$|2A| = 2k - 1$。更一般地 $|A+B| = |A| + |B| - 1$（整数集）当且仅当 $A$、$B$ 是公差相同的等差数列（必要性陈述级，技法同 §17.4，出处 Nathanson GTM 165）。
4. **最大与天花板**：$|A + B| \le |A||B|$ 平凡（映射 $(a,b) \mapsto a+b$ 只是未必单）。逼近上限的标本是 **Sidon 集**：所有 $a \le b$ 的和 $a + b$ 两两不同，此时 $|2A| = \frac{k(k+1)}{2}$（$k$ 个平方项加 $\binom{k}{2}$ 个交叉项）。$2$ 的幂 $\{1, 2, 4, \ldots\}$ 就是 Sidon 集——二进制表示唯一。
5. **数值锚**（真算，固定种子可复现）：随机集取自 $[0, k^2)$ 均匀抽 $k$ 个（种子 20261031）：

| $k$ | 等差（地板 $2k-1$） | 随机 | Sidon $\{2^i\}$ | 天花板 $\frac{k(k+1)}{2}$ |
| --- | --- | --- | --- | --- |
| 8 | 15 | 32 | 36 | 36 |
| 16 | 31 | 121 | 136 | 136 |
| 32 | 63 | 443 | 528 | 528 |

随机集紧贴天花板（$k = 8$ 时 $32/36$），等差压在地板上——同一把尺量出三档结构。

小结：$|A+B|$ 的两端各有一句白话——上限是随机性，下限是等差骨架；本节的平移链是全书无数次复用的「排序 + 链式枚举」技法。

## $\rm \S \, 17.3$ Ruzsa 距离与三角不等式

1. 白话先行：想把「$A$ 与 $B$ 像不像」变成一个能做三角测量的数——$A$ 离 $B$ 近、$B$ 离 $C$ 近，能否推出 $A$ 离 $C$ 近？和集本身不对称（没有 $A+B$ 与 $B$ 的三角关系可言），幸运的是**差集**有。
2. **Ruzsa 三角不等式**（全证）：对有限整数集 ${A, B, C}$，
$$
|A - C| \cdot |B| \ \le \ |A - B| \cdot |B - C| .
$$
证明：对每个 $x \in A - C$ 固定一个表示 $x = a_x - c_x$（选择公理的有限版，随手一挑）。定义
$$
\Phi : (A - C) \times B \to (A - B) \times (B - C), \qquad \Phi(x, b) = (a_x - b, \; b - c_x).
$$
单射：若 $\Phi(x,b) = \Phi(x',b') = (u,v)$，则 $u + v = a_x - c_x = x$，先收回 $x$（进而固定表示 $a_x, c_x$ 也收回），再由 $u = a_x - b$ 收回 $b$。单射把左边的 $(|A-C| \cdot |B|)$ 个对子缝进右边的乘积，得不等式。$\blacksquare$ 读法：每个「差值 × $B$ 中元素」的对子，都能无损编码成「$A-B$ 中一个差 × $B-C$ 中一个差」。
3. **Ruzsa 距离**：$d(A, B) = \ln\frac{|A - B|}{\sqrt{|A| \, |B|}}$。写成 $|A + (-B)|$ 是提醒：差集也是和集，只是对象换成了 $-B$。三角不等式：对引理取对数，
$$
d(A, C) \le \left[ \ln |A-B| - \tfrac12 \ln |A||B| \right] + \left[ \ln |B-C| - \tfrac12 \ln |B||C| \right] = d(A, B) + d(B, C).
$$
特别 $d(A, A) = \ln \frac{|A-A|}{|A|}$ 是差分倍增常数，距离为零当且仅当 $A$ 与 $B$ 同尺寸且互为最优平移拷贝。
4. **数值锚**（真算）：等差集 $A = \{0, 1, 2, 3\}$ 的 $|A - A| = 7$，$d(A, A) = \ln\frac{7}{4} \approx 0.56$；Sidon 集 $A = \{1, 2, 4, 8\}$ 的 $|A - A| = 13$（差值 $\{0, \pm1, \pm2, \pm3, \pm4, \pm6, \pm7\}$），$d(A, A) = \ln\frac{13}{4} \approx 1.18$。同样四个元素，距离差了一倍——尺子确实在量结构。
5. **和集工作马**（全推导）：引理中把 $B$ 换成 $-B$，右边 $|A - (-B)|\cdot|(-B) - C| = |A+B| \cdot |B+C|$：
$$
|A - C| \ \le \ \frac{|A+B| \, |B+C|}{|B|} .
$$
取 $B = C = A$：$|A - A| \le \frac{|2A|^2}{|A|} = K^2 |A|$——**倍增常数平方控制差集**，加性组合的第一条免费午餐。
6. **诚实注记**：若不减负号、改用 $|A+B|$ 定义距离，三角不等式的标准证明与表述都在差集一侧（Tao–Vu 第 2 章）；我们在 $\{0, \ldots, 7\}$ 全部非空子集构成的 $16387064$ 个有序三元组上穷举，和集版的三角不等式同样零违反，但本书不做超出文献证明能力的断言，采用差集版——这是和与差的第一处不对称，后文还会遇到（§17.7）。

小结：Ruzsa 距离把「像不像」变成可三角测量的量，承载它的是差集的单射论证；一切「小倍增传染」的定理都从这一条流出。

## $\rm \S \, 17.4$ 小和集的结构：从 $2k-1$ 到 Freiman 定理

1. **刻画定理**（全证双向）：$|A| = k$ 时 $|2A| = 2k - 1$ 当且仅当 $A$ 是等差数列。反向：$A = a + [0, k-1]d$ 则 $2A = 2a + [0, 2k-2]d$。正向证明：链
$$
a_1 + a_1 < a_1 + a_2 < \cdots < a_1 + a_k < a_2 + a_k < \cdots < a_k + a_k
$$
含 $2k - 1$ 个严格递增的 ${2A}$ 成员，故 $|2A| \ge 2k-1$；若恰等于 $2k-1$，则 ${2A}$ 就是这条链。看中层：对 $i = 2, \ldots, k-1$，和 $a_2 + a_i$ 落在 $a_1 + a_2$ 与 $a_2 + a_k$ 之间（左：$a_2 > a_1, i \ge 2$；右：$i < k$），而链中介于这两者之间的元素恰是 $a_1 + a_3, \ldots, a_1 + a_k$。于是 $\{a_2 + a_2, \ldots, a_2 + a_{k-1}\} \subseteq \{a_1 + a_3, \ldots, a_1 + a_k\}$，两边都是 $k-2$ 个互异递增的数，必相等且按序配对：$a_2 + a_i = a_1 + a_{i+1}$ 对 $i = 2, \ldots, k-1$。读出全部空档 $a_{i+1} - a_i = a_2 - a_1$，$A$ 是等差数列。$\blacksquare$
2. **Freiman $3k-4$ 定理**（陈述级）：$|2A| = 2k - 1 + b < 3k - 4$ 时，$A$ 含于一个长为 $k + b$ 的等差数列。出处：Freiman 1959/1973；表述取 Nathanson GTM 165；边界 $|2A| = 3k-4$ 由 Lev–Smeliansky（1994）与 Stanchescu 的 $3k-3$ 定理接管。证明超出本章范围。**陷阱注记**：「长」按步长 $d$ 的**项数**算，$d$ 可以大于 1——$A = \{0, 2, 4, 8, 12\}$ 跨度 13，却藏在长 7 的等差数列（$d = 2$，$\{0, 2, \ldots, 12\}$）里。本章验证脚本第一版就栽在这里：量了跨度、没量步长。
3. **数值锚**（真算）：穷举 $[0, 12]$ 的全部 $k$-子集，$k = 5, \ldots, 10$：最小 $|2A| = 2k - 1$ 恒成立；满足 $|2A| \le 3k - 5$ 的集合全部满足等差长度 $\le k + b$（零违反）；边界 $|2A| = 3k - 4$ 同样零违反。天花板是紧的：$\{0,1,2,3,6\}$（$k=5$）、$\{0,1,2,3,4,8\}$（$k=6$）、$\{0,\ldots,5,10\}$（$k=7$）、$\{0,\ldots,6,12\}$（$k=8$）的等差长度恰为 $k + b$。
4. **Freiman 一般定理**（陈述级）：$|2A| \le K k$ 时，$A$ 含于一个维数 $d(K)$ 的广义等差级数（generalized arithmetic progression，GAP：$a_0 + [0, l_1] v_1 + \cdots + [0, l_d] v_d$，允许 $d > 1$）中，其尺寸 $\le f(K) k$。出处：Freiman 1973；现代量化见 Chang 与 Tao–Vu 第 5 章。白话：小和集的骨架可以是一张高维「等差网」，维数只由 $K$ 决定，与 $k$ 无关——结构化的代价被定价成了维数。
5. **Ruzsa 覆盖引理**（陈述级）：$|A + B| \le K|A|$ 时，存在 $T \subseteq A + B$、$|T| \le K$，使 $A \subseteq T + (B - B)$（Tao–Vu 第 2 章）。白话：小倍增意味着整袋 $A$ 能被区区 $K$ 份「$B$ 的差集拷贝」装下——接力链的第一环，就是把全局统计换成有限覆盖。
6. 为什么逆定理难：正向（结构 ⟹ 小和集）是 §17.2 的算术；反向要从「泼洒不溅开」这个全局统计反推出逐点骨架，中间隔着覆盖引理、Plünnecke 与维数论证的接力——Freiman 定理是这条接力链的终点，本章只验收它的两端。

小结：$|2A| = 2k-1$ 的刻画全证在手，$3k-4$ 与一般 Freiman 定理按「陈述级＋出处」入账；「长度不是跨度」是本节留下的作业级陷阱。

## $\rm \S \, 17.5$ Plünnecke 不等式：便宜的复利

1. 白话先行：$|A + B| \le K|A|$ 说明「往 $A$ 里加一个 $B$，只付 $K$ 倍的膨胀」。这个折扣能续期吗——加 $m$ 次呢？
2. **放大率**：$D_j = \min_{\varnothing \ne Z \subseteq A} \frac{|Z + jB|}{|Z|}$——允许先挑一个最顺手的子集再泼洒。**Plünnecke 不等式**（陈述级）：
$$
D_{i + j} \ \le \ D_i \, D_j, \qquad \text{特别地} \ D_j \le D_1^{\,j} .
$$
推论：$|A + B| \le K|A|$ 时存在非空 $X \subseteq A$，使 $|X + mB| \le K^m |X|$ 对一切 $m$ 成立；$B$ 换成 $-B$ 再来一次，得 $|X + mB - lB| \le K^{m+l} |X|$。出处：Plünnecke 1970；Tao–Vu §2.5；Petridis 2011 给出最短的现代证明。
3. **倍增原理的直觉**：汇率一旦压到 $K$，复利 $K^m$ 自动成立——但最优汇率属于「最顺手的那批客户」（子集 $X$），全集 $A$ 未必享受，这就是结论里必须换子集的原因。工程直觉：这是加性组合版的「摊还分析」——单步便宜，则整段便宜。
4. 用途一瞥：$3k-4$ 定理的证明、Roth 型论证的能量增量、以及竞赛里「$A+B$ 小则 $A + mB$ 也可控」的放大技巧，全部走这条管道。

小结：Plünnecke 把单步折扣变成复利，代价是允许换子集；它与 Ruzsa 演算合称加性组合的「初等语法」。

## $\rm \S \, 17.6$ Roth 定理：密度增量与对数屏障

1. **设定**：$r_3(N)$ = $[N]$ 中不含非平凡三项等差级数（$x, x+d, x+2d$，$d > 0$）的子集的最大尺寸。**Roth 定理**（1953）：任何固定密度 $\delta > 0$，$N$ 充分大时 $[N]$ 的 $\delta$-密度子集必含三项等差级数；等价地 $r_3(N) = o(N)$。Roth 的定量版：$r_3(N) \ll \frac{N}{\ln \ln N}$。
2. **密度增量思想**（陈述级，出处 Roth 1953；现代阐述 Tao–Vu 第 10 章）：反设 $A$ 无三项级数、密度 $\delta$。用 Fourier 分析找一个 $A$ 局部超密的子舞台（短区间或其谱类似物），其上密度升高 $c\delta^2$，而舞台长度只缩一个可控因子。密度只能升 $O(1/\delta)$ 层就爆过 1——矛盾。总账把「迭代深度」换算成 $r_3(N)$ 的上界：每层付一个对数，深度 $1/\delta$ 层就是 $\ln\ln N$ 层屏障的来历。
3. **定量阶梯**（逐级标注出处，上界一侧）。每前进一步，都要给密度增量的迭代账本换一本更精细的：
   1. Roth（1953）：$r_3(N) \ll \frac{N}{\ln \ln N}$。
   2. Heath-Brown 与 Szemerédi（1987）：把 $\ln\ln N$ 换成 $\ln N$ 的固定幂。
   3. Bourgain（1999）：$N (\ln\ln N)^2 / (\ln N)^{2/3}$。
   4. Sanders（2011）：$N (\ln \ln N)^5 / \ln N$——贴住**对数屏障**。
   5. Bloom–Sisask（2020，arXiv:2007.03528）：$r_3(N) \ll N / (\ln N)^{1 + c}$，首次破屏障。
   6. Kelley–Meka（2023，FOCS）：$r_3(N) \ll N \, \mathrm{e}^{-c (\ln N)^{1/12}}$；Bloom–Sisask（2023，arXiv:2309.02353）把指数改进到 $1/9$。
4. **下界一侧**：Behrend（1946）构造给出 $r_3(N) \ge N \, \mathrm{e}^{-C \sqrt{\ln N}}$——把整数点塞进高维球面，球面上没有三项级数（球面方程吃掉 $x - 2y + z$ 型关系）；Elkin（2011）改进常数。与上界一侧之间仍隔指数级空白。
5. **数值锚**（量级读法，真算）。把常见于题目中的形状 $\frac{N}{\ln N \cdot 2^{\sqrt{\ln N}}}$ 读成数：
$$
N = 10^3: \quad \ln N = 6.91, \quad 2^{\sqrt{\ln N}} = 2^{2.63} \approx 6.2, \quad \text{屏障因子} \approx 42.7, \quad \text{量级} \approx 23;
$$
$$
N = 10^6: \quad \ln N = 13.82, \quad 2^{3.72} \approx 13.1, \quad \text{屏障因子} \approx 181.7, \quad \text{量级} \approx 5.5 \times 10^3 .
$$
读法一：$N$ 涨 1000 倍，屏障因子只涨 4.3 倍——对数层惩罚消失极慢，「屏障」之名由此而来。读法二（诚实声明）：这两个层各有归属——$\ln N$ 层是上界一侧（Sanders 到 Bloom–Sisask）的底座，$\sqrt{\ln N}$ 层（$\mathrm{e}^{\sqrt{\ln N}} = 13.8$ 与 $41.1$）是 Behrend 下界的标尺；把它们乘在一起只是量级练习，**没有任何已知定理给出这个形状的上界**——它比 Kelley–Meka 的 $\mathrm{e}^{(\ln N)^{1/9}}$ 强得多。上下界的夹逼现状：$N \mathrm{e}^{-C\sqrt{\ln N}} \le r_3(N) \le N \mathrm{e}^{-c(\ln N)^{1/9}}$。
6. **cap set 一瞥**。换舞台 $\mathbb{F}_3^n$：三项级数即 $x + z = 2y$，不含者称 cap set。Ellenberg–Gijswijt（2016）证明 $|A| \le c^n$，其中
$$
c \ = \ \min_{0 < t < 1} \frac{1 + t + t^2}{t^{2/3}} \ = \ 2.7551 \quad (\text{真算，极值点 } t = 0.5931),
$$
底数 $3$ 被砍到 $2.7551$。证明武器是多项式方法——在函数空间里造一个多项式探针，用维数当天花板（第 14 章秩方法的亲儿子），正是下一章的主角。同一个「三项级数」问题：整数里卡了七十年仍在 $\mathrm{e}^{-(\ln N)^{1/9}}$ 与 $\mathrm{e}^{-\sqrt{\ln N}}$ 之间拉锯，有限域向量空间里被一次代数风暴干净解决——舞台选择本身就是武器。

小结：Roth 定理是「大和集 ⟹ 富含模式」方向的旗舰；密度增量给思想，定量阶梯给敬畏，cap set 给下一章的悬念。

## $\rm \S \, 17.7$ 有限域里的加性组合：子空间与 Bogolyubov–Ruzsa 一瞥

1. **换舞台 $\mathbb{F}_2^n$**：$-x = x$，加法即减法，Ruzsa 演算照常运转而符号争议消失。特征 2 里 $2y = 0$，非平凡三项级数不存在——§17.6 的问题在这里免费蒸发，研究对象换成子空间与更长的模式。
2. **完美标本**：子空间 $H \le \mathbb{F}_2^n$ 满足 $H + H = H$，倍增常数 $1$——泼洒之后原地不动，因为骨架本身封闭。数值锚（真算，$\mathbb{F}_2^8$ 按异或实现，种子 20261031）：随机 64 元集的 $|2A| = 256$，恰好泼满整个群（$K = 4$）；6 维子空间及其任何陪集的 $|2A| = 64 = |A|$（$K = 1$）。这也是「地板由环境的子群结构决定」的演示：整数里没有非平凡有限子群，地板是 $2k - 1$（§17.2）；$\mathbb{F}_2^n$ 里地板降到 $|A|$（$|A + A| = |A|$ 迫使 $A$ 是子空间的陪集，一般交换群的正确地板由 Kneser 定理（1953）$|A+B| \ge |A{+}H| + |B{+}H| - |H|$ 给出，$H$ 是和集的稳定子）。
3. **有限域 Freiman 定理**（陈述级）：$\mathbb{F}_2^n$ 中 $|A + A| \le K|A|$ 时，$A$ 含于某个子空间 $V$ 的陪集且 $|V| \le 2^{2K+2} |A|$（Green–Tao 2010，Combinatorica）。白话：小和集在 $\mathbb{F}_2^n$ 里近似就是子空间——Freiman 的高维 GAP 在这里塌缩成最纯净的代数对象。
4. **Bogolyubov–Ruzsa 引理**（陈述级）：$|A + A| \le K|A|$ 时，$2A - 2A$ 包含一个维数只比 $n$ 低一个由 $K$ 决定的量的子空间（Bogolyubov 1939 的原始想法用 Fourier 大谱撑出周期骨架；量化是现代重镇，出处 Sanders 2012 综述《On the Bogolyubov–Ruzsa lemma》、Tao–Vu 第 4 章）。白话：泼洒两次再对称回倒一次，骨架就现形——先放大、再对焦。它是从「小倍增」通往 Roth/Szemerédi 型结论的桥。

小结：有限域把「结构」字典翻译成子空间语言；本章的整数定理在这里几乎都有更干净的对应物。

## $\rm \S \, 17.8$ 关键概念回顾

1. 和集量尺：$|A+B| \in [|A|+|B|-1,\ |A||B|]$；平移链全证下界；等差/随机/Sidon 三档标尺表（$k = 8, 16, 32$）。（§17.2）
2. Ruzsa 三角不等式全证（固定表示 + 单射）；$d(A,B) = \ln\frac{|A-B|}{\sqrt{|A||B|}}$ 的三角不等式；和集工作马 $|A-C| \le \frac{|A+B||B+C|}{|B|}$ 与 $|A-A| \le K^2|A|$。（§17.3）
3. $|2A| = 2k-1 \iff$ 等差数列（链论证全证）；Freiman $3k-4$（陈述级：长 $k+b$，不是跨度）＋穷举验证零违反且紧；一般 Freiman 定理＝广义等差级数。（§17.4）
4. Plünnecke：$D_{i+j} \le D_i D_j$；最优汇率与复利；换子集的必要性。（§17.5）
5. Roth 定理：陈述＋密度增量思想＋定量阶梯（Roth $\to$ Sanders $\to$ Bloom–Sisask $\to$ Kelley–Meka；Behrend 下界）＋量级读法＋cap set 常数 $2.7551$。（§17.6）
6. $\mathbb{F}_2^n$：子空间标本与 Kneser 地板；有限域 Freiman（Green–Tao）；Bogolyubov–Ruzsa 一瞥。（§17.7）

### $\rm \S \, 17.10.1$ 关键概念回顾答案

### $\rm \S \, 17.10.2$ 应用与辨析答案

1. 成立——反向链 $a_k + b_m > a_k + b_{m-1} > \cdots > a_k + b_1 > a_{k-1} + b_1 > \cdots > a_1 + b_1$ 同样是 $k + m - 1$ 个互异元素，只是「先走 $B$ 再走 $A$」。起点选择只用到实数的全序：整数集可排序，这一点在 $\mathbb{F}_2^n$ 里失效（无序），所以 §17.7 的地板论证改走 Kneser 路线。（§17.2）
2. 用在单射的收回阶段：$u + v = a_x - c_x = x$ 只识别差值 $x$，要把 $b$ 也收回必须知道 $a_x$，这要求每个 $x$ 的表示事先钉死。若不钉死，同一个 $x$ 的两个表示 $(a, c) \ne (a', c')$ 会让 $(x, b)$ 与 $(x, b')$（$b = a - u$，$b' = a' - u$）映到同一对 $(u, v)$——单射断裂。（§17.3）
3. 长度允许步长 $d > 1$，跨度不允许：跨度 $13$ 的 $\{0, 2, 4, 8, 12\}$ 藏在 $d = 2$、长 7 的等差数列里。其和集 $2A = \{0, 2, 4, 6, 8, 10, 12, 14, 16, 20, 24\}$ 共 11 个，恰为 $2k - 1 + b$、$b = 2 = k - 3$，即 $|2A| = 3k - 4$ 的边界情形（由 $3k-3$ 定理接管），等差长度 $7 = k + b$ 仍成立——与 §17.4 第 3 条「边界上零违反」的穷举一致，同时是紧例。（§17.4）
4. 取 $A$ 为等差数列（§17.2 地板档）与一个泼洒很散的 $B$ 的混合情形即知：$\frac{|A+B|}{|A|}$ 量的是全集平均，而 $D_1$ 取最优子集——例如 $A$ 由一段长等差数列与一个远处的 Sidon 尾巴拼成，$A + B$ 的膨胀几乎全由尾巴贡献，砍掉尾巴的 $Z \subseteq A$ 汇率骤降，故 $D_1$ 严格小于全集汇率。复利只保给享受最优汇率的 $X$。（§17.5）
5. 特征 2 里 $2y = 0$，任何 ${x, y, z}$ 满足 $x + z = 2y$ 化为 $x + z = 0$，即 $z = x$——退化为平凡级数，「无三项级数」约束变空话，密度增量找不到可收紧的模式。cap set 因此搬到 $\mathbb{F}_3^n$（${2y}$ 不退化）：§17.6 第 6 条的 $2.7551^n$ 正是那个舞台上的答案；$\mathbb{F}_2^n$ 里对应的问题是四项级数与子空间结构（§17.7）。（§17.6–17.7）
6. Ruzsa 三角不等式原样成立：§17.3 的单射论证只用「交换群 + 有限集」，没碰过序。最小值定理失效：取 $A = B$ 为子空间 $H$，$|H + H| = |H| < 2|H| - 1$——整数地板靠「无挠」（没有非平凡有限子群可让泼洒原地吸收），一般交换群的地板由 Kneser 定理给出（§17.7 第 2 条），$H$ 恰是那条陈述里稳定子项 $|H|$ 的来源。（§17.2–17.3、§17.7）
