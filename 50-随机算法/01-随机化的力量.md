# $\rm Chapter \, 1$ 随机化的力量：期望线性性与指示变量

试除法判素要对每个候选因子逐个除过去，$10^{18}$ 附近的数没有一个能活着走出试除；可一个几行的程序掷几十次硬币，就能把「是不是素数」答到几乎不出错。随机化的威力不在碰运气，而在两件硬邦邦的工具：**期望线性性**，把一堆纠缠在一起的事件拆成一根根独立的细线，让「期望」这个难算的量变得可以逐段累加；**概率方法**，用「随机对象里存在好实例」证明「好实例真的存在」，再把这条存在性论证拧成算法。本章讲透这两件工具，主证是指示变量加期望线性性——它不需要任何独立性假设，是后面每一章记账的母机。

> **开始前自检**：本章假设你已经会：
>
> 1. □ 期望与条件期望的定义 $\mathrm{E}[X] = \sum_x x\,\Pr[X = x]$，以及「期望是对概率的加权求和」（本站概率论册第 2、3 章）。
> 2. □ 几何分布：每次尝试成功概率为 $p$、各次独立，则首次成功所需次数的期望是 $1/p$（概率论册第 2 章）。
> 3. □ 二项系数 $\binom{k}{2} = k(k-1)/2$，以及对数 $\ln$ 与调和数 $H_n = 1 + \frac12 + \cdots + \frac1n \approx \ln n$（任意组合学入门材料）。
> 4. □ 快速排序的递归结构：取一个主元、把比它小的和比它大的分开、再各自递归（任意算法入门材料）。
>
> 第 1、2 条是本章主证的两条腿，不熟先回概率论册补齐。

## $\rm \S \, 1.1$ 什么是随机算法：Monte Carlo 与 Las Vegas

普通算法的每一步由输入定死，随机算法额外握着一枚硬币：同一条输入跑两次，中间过程可能不同。这不是让它听天由命，而是把「选择」这件难事交给概率去摆平——随机化快排靠随机主元躲开最坏划分，素性判定靠随机基躲开伪素数的陷阱。硬币一进来，正确性的口径就分成两类：

1. **Monte Carlo 算法**：一定在限定的时间（或期望时间）内停机，但**允许以某个小的概率给出错误答案**。代价换来的是速度；素性判定、指纹比对、随机化舍入都属这一档。
2. **Las Vegas 算法**：**永远给正确答案**，但运行时间是随机的、只有期望有界。随机化快排是标准例子——无论主元怎么抽，排出来的序都对，只是比较次数在随机。

> **白话**：Monte Carlo 是「快但偶尔看走眼」，Las Vegas 是「一定看准但耗时忽长忽短」。两者可以互相转化：对一个 Monte Carlo 算法，只要它能自检答案，重复跑并取多数票就能把错误率压到任意低、代价是时间；反过来，给 Las Vegas 算法加一个时间上限、超时就报「不知道」，就成了单边错误的 Monte Carlo。

错误率通常按输入规模记账。若存在常数 $\varepsilon < 1/2$，使对**每个**输入算法出错概率不超过 $\varepsilon$，且运行时间关于 $n$ 多项式有界，就把它归入后面 $\S1.5$ 的 $\mathrm{BPP}$ 一类。单边错误（只可能把「否」误判为「是」，反过来永远不错）更省事，重复 $k$ 次取「只要有一次说是就说是」，错误率立刻从 $\varepsilon$ 掉到 $\varepsilon^k$——这是把随机性当杠杆的全部算术。

**本节小结**：随机算法按「错不错、快不快」分成 Monte Carlo（可能错、必快）与 Las Vegas（必对、期望快）；本节立起这两个口径，下面造记账的工具。

## $\rm \S \, 1.2$ 指示变量与期望线性性（本章主证）

分析随机算法最缺的往往不是聪明，而是把一个「总和型」的随机量算出来。**指示变量（indicator variable）** 是拆解它的螺丝刀：给定事件 $A$，定义

$$
\mathbf{1}_{A}(\omega) = \begin{cases} 1, & \omega \in A, \\ 0, & \omega \notin A. \end{cases}
$$

读法：$\mathbf{1}_{A}$ 是一枚开关，$A$ 发生就通电取 $1$、不发生就断路取 $0$。它有两个立刻要记住的等式：其一，$\mathrm{E}[\mathbf{1}_{A}] = 1\cdot\Pr[A] + 0\cdot\Pr[A^c] = \Pr[A]$——**指示变量的期望就是它的事件概率**，这条把概率问题翻译成期望问题；其二，对一串事件 $A_1, \ldots, A_m$，恰好发生的事件个数是 $\sum_i \mathbf{1}_{A_i}$，因为每个发生的事件贡献一个 $1$、没发生贡献 $0$。

**命题 1.1（期望线性性）**：对任意随机变量 $X_1, \ldots, X_m$（**不要求独立**），

$$
\mathrm{E}\!\left[\sum_{i=1}^m X_i\right] = \sum_{i=1}^m \mathrm{E}[X_i].
$$

全证：把期望写成对样本空间逐点求和，$\mathrm{E}[\sum_i X_i] = \sum_{\omega} \Pr[\omega] \big(\sum_i X_i(\omega)\big)$。两个有限和可以交换次序（有限个数的加法满足分配律），

$$
\sum_{\omega} \Pr[\omega] \sum_{i=1}^m X_i(\omega) = \sum_{i=1}^m \sum_{\omega} \Pr[\omega]\, X_i(\omega) = \sum_{i=1}^m \mathrm{E}[X_i].
$$

读法：整个证明只有「交换两个有限求和」这一下，**独立性根本没出场**——这就是线性性廉价又刚猛的地方。方差做不到这一点（$\mathrm{Var}(X+Y) = \mathrm{Var}X + \mathrm{Var}Y$ 要独立），所以凡是能用「和」表达的随机量，都优先走期望这条路。

下面两个例题把这条命题的两种典型用法走全。第一个把随机量拆成**几何等待时间之和**，第二个把随机量拆成**逐对指示变量之和**。

**例题 1.2（优惠券收集）**：盲盒共 $n$ 种等概率的券，每抽一次随机得到一种（可能重复），问集齐全部 $n$ 种所需次数的期望。

拆法：设 $T$ 为集齐所需抽数，$T_i$ 为「已集齐 $i-1$ 种、再抽到第 $i$ 种新券所需次数」。则 $T = T_1 + T_2 + \cdots + T_n$（把整段过程切成 $n$ 个阶段）。在「已有 $i-1$ 种」的状态下，每次抽到新券的概率是 $\frac{n-(i-1)}{n}$，各次独立，于是 $T_i$ 服从成功概率 $p_i = \frac{n-i+1}{n}$ 的几何分布，$\mathrm{E}[T_i] = \frac1{p_i} = \frac{n}{n-i+1}$。由线性性（这里 $T_i$ **并不独立**——但不需要），

$$
\mathrm{E}[T] = \sum_{i=1}^n \frac{n}{n-i+1} = n\sum_{k=1}^n \frac1k = n\,H_n.
$$

读法：第 $i$ 阶段的等待只依赖「还缺几种」，$n/n-i+1$ 是「命中稀缺新券要等的次数」；末几阶段 $n-i+1$ 很小，等一张新券的代价飙升到 $n$，但只有常数多个这样的阶段，所以总期望只多一个 $\ln n$ 量级的尾巴。$n=10$ 时 $10H_{10} = 29.2897$，$n=50$ 时 $50H_{50} = 224.9603$。固定种子重复 $1000$ 次的模拟给出 $29.689$ 与 $226.335$（四舍五入到两位即 $29.69$ 与 $226.34$，见 $\S1.9$ 程序），与理论吻合。

**例题 1.3（生日悖论）**：$k$ 个人的生日独立均匀落在 $365$ 天，求「至少有一对生日相同」的概率，并定出该概率首次超过 $1/2$ 的 $k$。

先看**逐对指示变量**的用法：对每一对 $\{i, j\}$ 令 $X_{ij} = \mathbf{1}\{\text{第 } i,j \text{ 人生日相同}\}$，则 $\Pr[X_{ij} = 1] = \frac{1}{365}$，撞上的对数 $X = \sum_{i<j} X_{ij}$ 满足

$$
\mathrm{E}[X] = \sum_{i<j} \mathrm{E}[X_{ij}] = \binom{k}{2}\cdot\frac{1}{365}.
$$

读法：$\mathrm{E}[X]$ 是**期望撞车对数**，$k = 23$ 时等于 $\binom{23}{2}/365 = 253/365 = 0.693$。注意「期望对数大于 $1/2$」不等于「撞车概率大于 $1/2$」——$X$ 取多值时 $\Pr[X \ge 1] \le \mathrm{E}[X]$（Markov，见第 2 章），这个上界偏松。

要精确值就得算「全不相同」的概率。第一个人随便选，第二个人避开第一个人（概率 $\frac{364}{365}$），第三个人避开前两人（$\frac{363}{365}$），依此类推，前 $k$ 人**没有**任何重复的概率是连乘

$$
\Pr[\text{无重复}] = \prod_{i=0}^{k-1}\left(1 - \frac{i}{365}\right).
$$

逐项手算：$k = 22$ 时该乘积为 $0.5243$，故撞车概率 $1 - 0.5243 = 0.4757 < 1/2$；$k = 23$ 时乘积为 $0.4927$，撞车概率 $1 - 0.4927 = 0.5073 > 1/2$。**所以阈值是 $k = 23$**。对比 $\mathrm{E}[X] = 0.693$ 与真概率 $0.507$ 的差距，正是「对数期望」与「存在概率」之间的那道松紧缝。

**本节小结**：指示变量的期望等于事件概率、线性性不要求独立，这两条合起来把「和」拆成单品。优惠券收集拆几何等待、生日悖论拆逐对指示，是两种最常用的拆法。

## $\rm \S \, 1.3$ 期望分析的两件武器：停时与递归期望

上一节的线性性拆「和」，可很多随机量的定义里带着「等它停下来」的意味——快排要等递归触底、随机游走要等首次到达。这时要靠**停时（stopping time）** 与**递归期望（recursive expectation）** 两件武器。

**停时与 Wald 等式**。随机变量 $\tau$ 是停时，指「$\tau = t$ 与否只由前 $t$ 步的信息决定」——「集齐所有券」是停时，「第三次抽到重复券」也是停时；反过来「最后一次抽到的是新券」这种回头看才知道的事件不是。对独立同分布、期望有限的增量序列，停时 $\tau$ 满足 $\mathrm{E}[\sum_{t=1}^{\tau} X_t] = \mathrm{E}[\tau]\,\mathrm{E}[X_1]$（Wald 等式的期望形式）。优惠券收集的拆法本质就是 Wald：把总步数切成若干段、每段是「等下一张新券」的一段停时。

**递归期望**。设随机量满足一个「自身出现在两边」的方程，直接解它。**随机化快速排序**是标准战场：每次取一个随机主元，把数组分成比它小、比它大的两段，再递归。设 $C(n)$ 为长度为 $n$ 的数组的期望比较次数。主元是 $n$ 个元素里等概率的一个，若它恰好是第 $k$ 小（$k = 1, \ldots, n$，每种概率 $1/n$），则左段长 $k-1$、右段长 $n-k$，本轮的划分代价是 $n-1$ 次比较（除主元外每个元素与主元比一次）。于是

$$
C(n) = (n-1) + \frac{2}{n}\sum_{k=0}^{n-1} C(k),\qquad C(0) = C(1) = 0,
$$

其中 $\frac2n\sum_{k=0}^{n-1} C(k)$ 把左右两段的期望合并（$\sum_{k=1}^n [C(k-1)+C(n-k)] = 2\sum_{k=0}^{n-1} C(k)$，除以 $n$）。这条方程两边都含 $C$，要解它就做「错位相减」：把原式乘 $n$，再减去 $n-1$ 时的同式，

$$
n\,C(n) - (n-1)\,C(n-1) = (n+1)\,C(n-1) + 2(n-1),
$$

整理解出 $\frac{C(n)}{n+1} = \frac{C(n-1)}{n} + \frac{2(n-1)}{n(n+1)}$。令 $D(n) = \frac{C(n)}{n+1}$，从 $D(1) = 0$ 起逐层累加，用部分分式 $\frac{2(n-1)}{n(n+1)} = \frac{4}{n+1} - \frac2n$：

$$
D(n) = \sum_{m=2}^n\left(\frac{4}{m+1} - \frac2m\right) = 2H_n + \frac{4}{n+1} - 4,
$$

于是 $C(n) = (n+1)D(n) = 2(n+1)H_n - 4n$。读法：主元划分每层总代价 $n-1$、递归深度期望 $\Theta(\log n)$，但更紧的账由 $H_n$ 给出。代渐近 $H_n = \ln n + \gamma + o(1)$（$\gamma \approx 0.5772$ 是 Euler 常数），

$$
C(n) = 2n\ln n + n(2\gamma - 4) + O(\log n) \approx 2n\ln n - 2.846\,n.
$$

数值核对：$n = 100$ 时精确式给 $2\cdot101\cdot H_{100} - 400 = 647.85$，而只保留主项的 $2n\ln n = 921.03$——主项不错，但常数项 $-\Theta(n)$ 不可忽略，这也是「$2n\ln n$ 只是量级」该被记住的原因。相对归并排序的 $n\log_2 n = 1.443\,n\ln n$，随机化快排的常数约为它的 $1.4$ 倍。

**带权采样**一句话：要从权重 $w_1, \ldots, w_m$ 里按比例抽样，把权重求前缀和、取一个 $[0, \sum w_i)$ 的均匀随机数做二分定位，$O(\log m)$ 出样本；等价地可预先归一化成概率。它是很多随机算法的「按需分配随机性」接口。

**本节小结**：停时让「等它停」的长过程可以按段用 Wald 求和，递归期望让「自己写自己」的方程可以解出来。快排的 $2(n+1)H_n - 4n$ 是后者的样板。

## $\rm \S \, 1.4$ 概率法到算法：存在性论证的模板

有些问题问的不是「怎么算」，而是「至少有多大」——最大割、最大可满足子句数、最大独立集。这类**下界**常可以先用一个随机对象证明「存在一个够好的解」，再把证明改造成构造。

**命题 1.4（随机分配给出 $m/2$ 的割）**：给定含 $m$ 条边的无向图（可带权），存在一个割至少切掉总权重的一半。

证明：把每个顶点独立地、各以 $\frac12$ 的概率染成黑或白。一条边被「割掉」当且仅当它两端异色，概率恰为 $\frac12$。令 $X_e = \mathbf{1}\{\text{边 } e \text{ 被割}\}$，割的总权重是 $\sum_e w_e X_e$。由线性性（边是否被割彼此并不独立，但线性性不管），

$$
\mathrm{E}\Big[\sum_e w_e X_e\Big] = \sum_e w_e\,\mathrm{E}[X_e] = \frac12\sum_e w_e = \frac{W}{2}.
$$

读法：随机染色的**期望**割权是全部权重的一半。一个随机变量的期望为 $W/2$，则必存在某个染色使割权**至少** $W/2$（否则所有取值都 $< W/2$，期望也 $< W/2$，矛盾）。$\blacksquare$

这个论证直接给了 $1/2$ 近似比的 MaxCut 算法壳子：真的随机染一次色，割权只是**期望**为 $W/2$，单次结果可能低于它。要把它变成确定性算法，用**条件期望法（method of conditional expectations）** 去随机化：逐个顶点决定颜色，每步比较「钉成黑」与「钉成白」两种情形下的条件期望，选不低于当前平均的那种。于是每步条件期望不下降、第一步是 $W/2$，作完 $n$ 个决定就得到一个割权 $\ge W/2$ 的确定解。**去随机化**一般比随机版本贵（这里要能对每个顶点快速算条件期望），但它说明概率法给出的存在性是「可兑现」的，不只是「有解存在」的空头支票。

这套模板不止用于 MaxCut：加权 MAX-SAT 里给每个变量随机取真假，含 $k$ 个文字的子句被满足的概率是 $1 - 2^{-k} \ge \frac12$，于是期望满足权重 $\ge \frac12\sum w_c$；最大可满足子句数、最大二分子图都有同型的随机分配论证。共同点是「随机对象在每个局部单元上以至少一半的概率讨好」，线性性把这些局部承诺加总。

**本节小结**：概率法先证「随机对象平均地好」，由期望的存在性推出「至少有一个好解」；条件期望法再把这个存在性改成构造。MaxCut 的 $W/2$ 是这套模板的最小样板。

## $\rm \S \, 1.5$ 与复杂度类的关系：RP、BPP、PP 谱系

随机算法的错误率口径可以精确定义成一族复杂度类，本站计算理论册第 7 章展开，这里只给坐标。设多项式时间随机算法，对长度 $n$ 的输入：

1. $\mathrm{RP}$（单边错误）：答案是「是」时以 $\ge 1/2$ 接受，「否」时永不接受。错只可能错在把「否」说成「是」。
2. $\mathrm{co\text{-}RP}$：把 $\mathrm{RP}$ 的是非对调。
3. $\mathrm{BPP}$（双边错误）：任何情形下出错概率 $\le 1/3$（可压到任意小）。
4. $\mathrm{PP}$（概率多项式）：只要求「是」的接受概率 $> 1/2$、「否」的接受概率 $\le 1/2$，允许差距小到 $2^{-\Omega(n)}$。

谱系是 $\mathrm{P} \subseteq \mathrm{RP} \subseteq \mathrm{BPP} \subseteq \mathrm{PP} \subseteq \mathrm{PSPACE}$。重复取多数票能把 $\mathrm{BPP}$ 的错误率指数级压下（Chernoff，见第 2 章），所以 $\mathrm{BPP}$ 的界可以写成 $1 - 2^{-\Omega(n)}$；而 $\mathrm{PP}$ 的 $1/2$ 差距小到没有间隔，重复采样也补不回来，这是它与 $\mathrm{BPP}$ 的分水岭。第 3 章的 Miller–Rabin 素数判定落在 $\mathrm{co\text{-}RP}$：它永不会把一个素数判成合数（单边错在「合数误判成素数」那一侧）。

还有一条常被引用的猜想要摆在这里：多数复杂度理论家相信 $\mathrm{P} = \mathrm{BPP}$，即随机性无法在多项式时间内带来本质加速，Nisan–Wigderson 的伪随机生成器路线给的是条件性证据。但**无条件**的 $\mathrm{P} \ne \mathrm{BPP}$ 至今未证。这不影响随机算法在实践里的统治地位：随机版本的常数往往更小、实现更短，即使原则上可去随机化，随机版本仍常是首选。

**本节小结**：随机算法的错误率口径对应 $\mathrm{RP}/\mathrm{BPP}/\mathrm{PP}$ 一族类，$\mathrm{BPP}$ 可靠多数票自放大、$\mathrm{PP}$ 不能。素性判定是 $\mathrm{co\text{-}RP}$ 的经典成员。

## $\rm \S \, 1.6$ 关键概念回顾

1. Monte Carlo 与 Las Vegas 在「是否正确」「运行时间」两个维度上各承诺什么？为什么单边错误重复取「或」就能把错误率压到 $\varepsilon^k$？
2. 写出指示变量的两个基本等式；期望线性性的证明只用到哪一步操作？为什么它**不需要**独立性？
3. 优惠券收集为什么能把 $T$ 拆成 $\sum_i T_i$？各 $T_i$ 的期望是多少、总期望为什么是 $nH_n$？
4. 生日悖论里，「期望撞车对数 $= \binom{k}{2}/365$」与「至少一对撞车的概率」差在哪里？阈值 $k = 23$ 是怎么定出来的？
5. 随机化快排的递归式 $C(n) = (n-1) + \frac2n\sum_{k=0}^{n-1}C(k)$ 里，$\frac2n\sum C(k)$ 合并的是哪两段？解出的闭式是什么？

## $\rm \S \, 1.8$ 本章自测答案

> 先闭卷作答 $\S1.6$ 与 $\S1.7$，再核对。

### $\rm \S \, 1.8.1$ 关键概念回顾答案

1. Monte Carlo 承诺「必定/期望时间有界但可能错」，Las Vegas 承诺「必定正确但运行时间随机」。单边错误下「取或」只在正确时应不误报、在错误侧至多以 $\varepsilon$ 漏判为「是」，$k$ 次都漏判的概率是 $\varepsilon^k$。（$\S1.1$）
2. 两个等式：$\mathrm{E}[\mathbf{1}_A] = \Pr[A]$，以及「恰好发生的事件数 $= \sum_i \mathbf{1}_{A_i}$」。证明只交换两个有限求和。交换求和与分配律不涉及联合分布，故不需要独立。（$\S1.2$）
3. 按「已集齐种数」把过程切成阶段，每段是等下一张新券的等待；$\mathrm{E}[T_i] = \frac{n}{n-i+1}$。求和得 $nH_n$。各 $T_i$ 不独立（下一阶段从哪开始依赖上一阶段），但线性性不要求独立。（$\S1.2$）
4. $\mathrm{E}[X]$ 是**期望对数**（可大于 $1$）、不等于 $\Pr[X \ge 1]$；$\Pr[X\ge1] \le \mathrm{E}[X]$ 只是上界。精确概率走连乘 $\prod(1 - i/365)$，$k = 23$ 首次超过 $1/2$。（$\S1.2$）
5. $\frac2n\sum_{k=0}^{n-1}C(k)$ 合并左段 $C(k-1)$ 与右段 $C(n-k)$ 的期望。闭式 $C(n) = 2(n+1)H_n - 4n \approx 2n\ln n - 2.846n$。（$\S1.3$）
6. 关键推理是「期望为 $W/2$ 的随机变量必有取值 $\ge W/2$」。条件期望法逐个顶点定色、每步取「不降低条件期望」的那种，起点 $W/2$、终点是确定解，故 $\ge W/2$。（$\S1.4$）

### $\rm \S \, 1.8.2$ 应用与辨析答案

1. 错。线性性对任意随机变量成立，只要求各自期望存在。优惠券收集的 $T_i$ 确实相关（阶段起点依赖前段），但 $\mathrm{E}[\sum T_i] = \sum \mathrm{E}[T_i]$ 照旧成立。独立性是**方差可加**才需要的条件，不是期望可加的条件。（$\S1.2$）
2. 错在把「期望对数」当「至少一对存在」的概率。Markov 给 $\Pr[X \ge 1] \le \mathrm{E}[X]$，$\mathrm{E}[X] = 1.03$ 只说明概率不超过某个 $\le 1$ 的数，推不出概率为 $1$。真阈值是 $k = 23$（精确概率 $0.5073$）。（$\S1.2$）
3. 是 Las Vegas：无论主元怎么抽，排序结果都对，随机性只体现在比较次数上。改成固定位置主元就不再是随机算法——对已排序输入退化到 $O(n^2)$、期望分析失效，最坏情况严格变差。（$\S1.1$、$\S1.3$）
4. 随机染色的期望是 $W/2$，单次可能低于它，无保证。逐顶点决策时，两种颜色的条件期望的**加权平均**恰是当前条件期望，两者不可能都低于平均值，故至少一种颜色使期望不降，选它即可。（$\S1.4$）
5. 取多数票 $k$ 次，错误率的上界按 Chernoff 指数下降（第 2 章）；要把 $1/4$ 压到 $10^{-6}$ 大约需 $k = 35$ 量级（由 $\exp(-2k(1 - 2\cdot1/4)^2)$ 估算，精确账见第 2 章）。改成「单边取或」需要算法本身是单边错误（$\mathrm{RP}$ 型），否则「或」会放大另一侧的错误。（$\S1.5$）

## $\rm \S \, 1.9$ 程序对账

下面一段同时跑优惠券收集与生日悖论，输出与正文锚逐条对上。运行环境为 Python 3 加 numpy，种子固定可复现。

```python
import numpy as np

def coupon_sim(n, trials, seed):
    # 向量化模拟：trials 个收集者并行推进，各自记录步数
    rng = np.random.default_rng(seed)
    seen = np.zeros((trials, n), dtype=bool)
    cnt = np.zeros(trials, dtype=np.int64)
    steps = np.zeros(trials, dtype=np.int64)
    active = np.arange(trials)
    while active.size:                       # 未集齐的收集者继续抽
        draws = rng.integers(n, size=active.size)
        newly = ~seen[active, draws]         # 记录本步新见到的券
        seen[active, draws] = True
        cnt[active] += newly
        steps[active] += 1
        active = active[cnt[active] < n]     # 集齐的退出
    return steps.mean()

for n in (10, 50):
    H = sum(1.0 / i for i in range(1, n + 1))
    sim = coupon_sim(n, 1000, 45501)         # 1000 次重复、固定种子
    print(f"n={n:2d}  理论 n*H_n={n*H:.4f}  模拟={sim:.3f}")

    # 生日悖论：精确连乘，阈值首次超过 1/2
p_no = 1.0
for k in range(1, 60):
    p_no *= (1 - (k - 1) / 365.0)            # 加入第 k 人后的无重复概率
    if 1 - p_no > 0.5:
        print(f"生日阈值 k={k}  撞车概率={1 - p_no:.4f}")
        break
```

输出（本机实测）：

1. `n=10  理论 n*H_n=29.2897  模拟=29.689`——四舍五入到两位是 $29.69$，对理论 $29.29$。
2. `n=50  理论 n*H_n=224.9603  模拟=226.335`——四舍五入到两位是 $226.34$，对理论 $224.96$。两次模拟都略高于理论，这是 $1000$ 次重复的随机涨落（$n = 50$ 时单次方差约 $n^2\pi^2/6 \approx 4112$，均值的标准差约 $2$），换种子末位会变。
3. `生日阈值 k=23  撞车概率=0.5073`——与 $\S1.2$ 的精确连乘一致。

**带走清单**：随机算法的两类口径（Monte Carlo / Las Vegas）；指示变量的两条等式与线性性的「交换求和」证明（不需独立性）；优惠券收集 $= nH_n$ 的几何拆解；生日悖论 $\prod(1 - i/365)$ 与阈值 $k = 23$；快排递归式解到 $2(n+1)H_n - 4n \approx 2n\ln n$；概率法到算法的「期望存在性」模板与条件期望去随机化；$\mathrm{P} \subseteq \mathrm{RP} \subseteq \mathrm{BPP} \subseteq \mathrm{PP}$ 的坐标。
