# $\rm \S \, Chapter \, 6$ GI/G/1 与 Kingman 重交通近似

第 5 章把服务分布放开成任意的 $G$，到达侧却还住在泊松的特权里——PASTA 与第 1 章的红利撑着半边天。本章把第一个 M 也放开：到达间隔独立同分布但形状任意（Kendall 记号写成 GI/G/1），生灭账本与到达者视角同时报废，闭式彻底消失。可工程里的系统偏偏就长这样：定时任务整点齐发、缓存过期掀起请求风暴、故障恢复后的重试洪峰——到达既不泊松也不规矩。出路是换一种问法：不再追问完整分布，只在重交通（heavy traffic，$\rho \to 1$ 的临界区）里要一个均值近似。Kingman (1961) 给出的答案是排队论里性价比最高的一条公式：到达过程的全部信息压缩成一个数 $c_a^2$，服务过程的全部信息压缩成一个数 $c_s^2$，等待时间写成三因子乘积。路线五步：Lindley 递推把 GI/G/1 的全部动力学压进一行标量式（§6.2），Kingman 近似与两极端验证（§6.3），$c^2$ 怎么从真实数据量出来（§6.4），误差为什么随 $\rho \to 1$ 集中又消失（§6.5），最后是容量规划实战与数值锚（§6.6–6.7）。

比喻先立在这：重交通是一家刚好满座的餐厅——座位一个不空、厨师一刻不停。这个临界世界里，队伍多长不再由某位客人的怪癖或某道慢菜单独决定，只剩两个数说了算：客人赴约的散漫程度 $c_a^2$ 与厨房出菜节奏的乱度 $c_s^2$。Kingman 公式把这一切压成一句白话：等待时间 ≈ 利用率的平方 × 变异性。俚语版的「平方」要钉准：排队时间乘的刀刃因子是 $\frac{\rho}{1-\rho}$，两边乘 $\lambda$ 换成队长口径后才是 $\frac{\rho^2}{1-\rho}$——平方出现在队长那里，变异因子 $\frac{c_a^2+c_s^2}{2}$ 则两处共用。

> **开始前自检**：本章假设你已经会：
>
> 1. □ M/M/1 的 $W_q = \frac{\rho}{1-\rho}\,E[S]$ 与 $\frac{1}{1-\rho}$ 爆炸（§2.3–2.4）。
> 2. □ Pollaczek–Khinchine 公式与「方差罚款」的成分表读法（§5.4–5.5）。
> 3. □ 二阶矩与方差的换算 $E[X^2] = \mathrm{Var}[X] + E[X]^2$（§5.4）。
> 4. □ Little 定理与子系统版，以及窗口分工 $W = W_q + E[S]$（§3.3–3.5）。
> 5. □ 检验悖论：一般到达流里到达者所见与时间平均脱钩（§3.6）。
>
> 其中第 1、2 条是本章的两个对话对象，第 4 条是应用的主角；不熟先回对应章补齐。

## $\rm \S \, 6.1$ 动机：把第一个 M 也放开

先盘到达侧这份家底依赖什么。第 2 章推 $W$ 用了 PASTA——泊松到达者所见等于时间平均（§1.5）；第 3 章说清了这是泊松的专属特权：一般到达流里，到达时刻与系统状态相关（§3.6 的长度偏倚），到达者视角与摄像头视角脱钩。而真实到达流几乎从不守规矩：1. 批量与整点效应——定时爬虫整点齐发、消息队列攒批发送，间隔成串出现；2. 相关性——故障后的重试风暴一次压出一串短间隔，间隔之间不再独立；3. 形状——人工操作的间隔比指数更「规整」或更「爆发」，两个方向都有。

白话先行：我们要一个「到达侧最宽、但还剩一点结构」的模型，好让分析仍有抓手。

**定义 6.1（GI/G/1）**：Kendall 记号（§2.1）第一个槽位换成 GI（general independent）：到达间隔 $\{A_n\}$ 独立同分布、分布任意（均值 $E[A] = \frac{1}{\lambda}$）；第二槽位 $G$ 沿第 5 章（服务时间 $\{S_n\}$ 独立同分布、均值 $E[S]$，与到达过程独立）；单服务台、先来先服务。M/M/1 与 M/G/1 都是它的特例——指数间隔只是 $A$ 的分布族里一个成员。

两点边界先交代：1. 独立性是底线——再放开（相关到达）连重交通近似的推导地基都会松动，本章全部结论默认 GI，相关性只在 §6.4 当口径备注处理；2. GI/G/1 的平稳分布没有任何闭式，这条负面事实本身就是路标：精确求解这条路正式关闭，剩下的武器是递推（下一节）与近似（§6.3）。

小结：GI/G/1 = 两侧分布全放开、只留独立性；没有闭式，但动力学即将被一行递推接住。

## $\rm \S \, 6.2$ Lindley 递推：一行写尽全部动力学

白话先行：没有平稳分布，还能不能精确地说点什么？能。把镜头从「时刻 $t$ 店里几个人」换成「第 $n$ 位顾客等了多久」，等待时间沿着顾客队列一代一代传下去，传法只有一行。

顾客按到达顺序编号 $n = 1, 2, \ldots$：$T_n$ 是第 $n$ 位到达时刻，$A_{n+1} = T_{n+1} - T_n$ 是到达间隔，$S_n$ 是第 $n$ 位的服务时长，$W_n$ 是第 $n$ 位的排队时间（不含自己的服务）。

**命题 6.1（Lindley 递推，Lindley recursion）**：FIFO 单台 GI/G/1 中，

$$
W_{n+1} = \max(0,\; W_n + S_n - A_{n+1}).
$$

**推导**（两情形的守恒账，逐项交代）。第 $n+1$ 位最早能上台的时刻，是「前一位离开」与「自己到达」两者中较晚者；前一位的离开时刻是他自己的到达加排队加服务，即 $T_n + W_n + S_n$。于是第 $n+1$ 位的排队开始时刻是 $\max(T_{n+1},\, T_n + W_n + S_n)$，减去自己的到达时刻就是排队时长：

$$
W_{n+1} = \max(T_{n+1},\, T_n + W_n + S_n) - T_{n+1} = \max(0,\, W_n + S_n - A_{n+1}),
$$

末步用了 $T_{n+1} - T_n = A_{n+1}$。两种情形各是一句白话：1. 台还忙（$W_n + S_n > A_{n+1}$）：第 $n+1$ 位等的是「第 $n$ 位留下的余压」，全部排队历史被 $W_n$ 一项接管；2. 台已闲（$W_n + S_n \le A_{n+1}$）：到达撞上空台，零等待，历史就地清零。读法：递推像传水桶——每位顾客把自己没倒完的工作量余压传给下一位，$S_n$ 是新添的水，$A_{n+1}$ 是间隔期倒掉的水，$\max(0,\cdot)$ 是水桶的容量地板。∎

三条性质值得停一停：1. **不挑分布**——推导只用了「离开时刻」的会计恒等式，$A$ 与 $S$ 的分布从头到尾没进场，指数、确定性、重尾一视同仁；这是 GI/G/1 还能精确说事的最后一小块自留地。2. **与 §5.3 的关系**——那边在离开时刻数人数（嵌入链），这边按顾客传等待，同一队列的两本账，递推是更朴素的一本。3. **一维标量**——到达、服务、排队规则的全部动力学压缩进一行标量递推，这是它既可分析又可模拟（§6.7 全靠它）的原因。

**定理 6.2（稳定性，陈述级）**：设 $E[S] < E[A]$（即 $\rho = \frac{E[S]}{E[A]} < 1$）且二阶矩有限。则对任意初值，$W_n$ 依分布收敛到与初值无关的稳态变量 $W_\infty$，且 $E[W_\infty] < \infty$；若 $E[S] \ge E[A]$，则 $W_n$ 依概率趋于无穷（$\rho = 1$ 的临界情形更细致，超出本章范围）。

直觉读法（随机游走）：记 $U_n = S_n - A_{n+1}$，递推即 $W_{n+1} = (W_n + U_n)^+$；迭代展开得 $W_n = \max(0,\, U_0,\, U_0 + U_1,\, \ldots,\, U_0 + \cdots + U_{n-1})$——一条每步平均下沉 $E[A] - E[S] > 0$ 的随机游走的历史最高水位。漂移向下，水位有稳态分布；漂移非负，水位迟早漫过任何堤坝。严格证明见 Lindley (1952) 原文与 Gallager《Stochastic Processes: Theory for Applications》第 5 章，超出本章范围。

小结：Lindley 递推用离开时刻的会计恒等式把 GI/G/1 压成一行，稳定条件 $\rho < 1$ 在随机游走语言里就是漂移向下。

## $\rm \S \, 6.3$ Kingman 重交通近似

白话先行：递推能模拟、能判稳定，但工程要的是「平均等多久」这个数。精确解不存在，近似只在满座区承诺精度——那恰好是 §2.1 里 $\rho = 0.9$ 冲击所在的、工程最痛的区。

先备一个量。**定义 6.2（变异系数，coefficient of variation）**：非负随机变量 $X$ 的变异系数平方 $c_X^2 = \frac{\mathrm{Var}[X]}{E[X]^2}$，是无量纲的「相对乱度」。三个校准点：指数分布 $c^2 = 1$（§1.2），确定性 $c^2 = 0$，两点分布 $\{0.5,\,5.5\}$ @ $\{0.9,\,0.1\}$（均值 1）$c^2 = 2.25$（§5.5 的作坊）。到达间隔的记 $c_a^2$，服务时间的记 $c_s^2$。

**定理 6.3（Kingman 重交通近似，陈述级）**：稳态 GI/G/1（FIFO，$\rho \to 1$，矩条件成立），平均排队时间

$$
W_q \;\approx\; \frac{\rho}{1-\rho}\cdot\frac{c_a^2 + c_s^2}{2}\cdot E[S].
$$

三因子读法，每个因子都有前章的户口：1. 刀刃因子 $\frac{\rho}{1-\rho}$——第 2 章的临界恶化曲线；2. 变异因子 $\frac{c_a^2+c_s^2}{2}$——第 5 章「方差罚款」的一般化，那里的 $\frac{1+c_s^2}{2}$ 正是 $c_a^2 = 1$ 的特例；3. 尺度因子 $E[S]$——一切以平均服务时间为单位计价。公式为什么长这样，本节末尾的重交通极限给直觉；现在先干工程师该干的事：验证它两头都对。

**极端一：$c_a = c_s = 1$，退回 M/M/1**。指数到达、指数服务，代入：

$$
W_q \approx \frac{\rho}{1-\rho}\cdot\frac{1+1}{2}\cdot E[S] = \frac{\rho\,E[S]}{1-\rho}.
$$

第 2 章的闭式（§2.4）是 $W_q = \frac{\rho}{\mu-\lambda}$。由 $E[S] = \frac{1}{\mu}$ 与 $\rho = \lambda E[S]$：$\frac{\rho E[S]}{1-\rho} = \frac{\rho/\mu}{1-\lambda/\mu} = \frac{\rho}{\mu-\lambda}$，逐字吻合。更强的一步：到达泊松（$c_a^2 = 1$）而服务任意时，Kingman 恰好**精确**。把 $E[X^2] = E[X]^2(1+c_s^2)$ 代回 P-K 公式（定理 5.1）：

$$
W_q = \frac{\lambda\,E[X^2]}{2(1-\rho)} = \frac{\rho\,E[X]\,(1+c_s^2)}{2(1-\rho)} = \frac{\rho}{1-\rho}\cdot\frac{1+c_s^2}{2}\cdot E[S],
$$

与 Kingman 右端逐字相同。读法：本章一切近似误差都来自非泊松到达——服务侧的账，P-K 早已算平。

**极端二：$c_a = c_s = 0$，确定性世界零等待**。到达间隔恒为 $E[A]$、服务恒为 $E[S]$, 且 $E[S] < E[A]$。Lindley 递推一步定乾坤：$U_n = S_n - A_{n+1} = E[S] - E[A] < 0$ 是同一个负常数，而首位顾客撞上空台 $W_0 = 0$（更准确说从空系统出发 $W_1 = \max(0, S_0 - A_1) = 0$）；归纳：$W_{n+1} = \max(0,\, W_n + \text{负常数}) = 0$，队列从未形成——节拍器餐厅没人等位。Kingman 右端 $\frac{\rho}{1-\rho}\cdot 0 = 0$，两头锁死。

公式为什么长这样（重交通极限的直觉，陈述级）：Kingman (1961) 证明，$\rho \to 1$ 时缩放后的等待 $(1-\rho)W_q$ 依分布收敛到一个指数分布，均值恰为 $\frac{c_a^2+c_s^2}{2}\,E[S]$。把极限分布的均值当作整个 $W_q$、除以缩放因子 $1-\rho$，就是定理 6.3。换句话说：满座世界里等待的「形状」永远是同一颗指数，剩下的自由度只有均值，而均值被两个 $c^2$ 钉死——这就是「两个数概括全部信息」的出处。严格叙述与矩条件超出本章范围，见 Kingman (1961) 原文与 Gallager 同书第 5 章。

小结：Kingman 近似 = 刀刃 × 变异 × 尺度；一头锁回 M/M/1（且在整个 M/G/1 族上精确），一头锁死确定性零等待，中间地带由 §6.7 的模拟验货。

## $\rm \S \, 6.4$ 测量：从真实数据估 $c_a^2$ 与 $c_s^2$

白话先行：公式要上生产，先得会量。$c^2$ 的好消息是它只要一阶矩与二阶矩——普通日志就够，不需要拟合任何分布。

**估计量**：给独立同分布的间隔样本 $A_1, \ldots, A_n$，取样本均值、样本方差、相除：

$$
\bar{A} = \frac{1}{n}\sum_{i=1}^n A_i, \qquad \hat{\sigma}_A^2 = \frac{1}{n-1}\sum_{i=1}^n (A_i - \bar{A})^2, \qquad \hat{c}_a^2 = \frac{\hat{\sigma}_A^2}{\bar{A}^{\,2}},
$$

服务侧把 $A$ 全部换成 $S$ 即得 $\hat{c}_s^2$。数值验收（各 $10^6$ 样本，Python 真算，§6.7 表 3）：1. $U(0.5,\,1.5)$ 到达间隔：$\hat{c}_a^2 = 0.08349$，真值 $\frac{1}{12} = 0.08333$；2. 两点服务 $\{0.5,\,5.5\}$ @ $\{0.9,\,0.1\}$：$\hat{c}_s^2 = 2.2501$，真值 2.2500。第 5 章用过的服务数据（$E[X] = 0.2$、$E[X^2] = 0.06$）折算 $c_s^2 = \frac{0.06}{0.04} - 1 = 0.5$——同一份数据，两章各取所需。

口径三条（量的坑）：1. **无量纲性**：$c^2$ 不随时间单位变，日志里毫秒与秒混用不翻车——这是它比方差适合进报表的原因。2. **间隔口径 vs 计数口径**：上面估的是间隔口径；若监控只有窗口计数（每秒请求数），计数方差与间隔变异的换算关系超出本章范围（见 Whitt《Stochastic-Process Limits》），拿得到时间戳就一律用间隔口径。3. **独立性口径**：GI 假设间隔独立；真实到达常相关（重试风暴里一次故障压出一串短间隔），$c^2$ 照样可量、Kingman 照样可用，但精度打折——相关性是近似误差的额外来源（陈述级）。

比喻：$c^2$ 是系统的节拍器指数——0 是节拍器，1 是洗匀的歌单（完全随机），大于 1 是一整张专辑只火一首歌（爆发型：长间隔里憋着，短间隔里齐发）。

小结：$c^2$ = 方差除以均值的平方，日志三行可估；量的时候盯住间隔口径与独立性口径。

## $\rm \S \, 6.5$ 误差分析：误差随 $\rho \to 1$ 集中并消失

白话先行：「近似」二字必须配一句「错在哪、什么时候错得小」。Kingman 近似的误差结构异常干净：高负载区相对误差趋于零，低负载区绝对误差小但相对误差可以难看。

主链三步。

1. **近似抓的是领头项**。由重交通极限定理（§6.3，陈述级）：$(1-\rho)W_q$ 依分布收敛到均值 $\frac{c_a^2+c_s^2}{2}E[S]$ 的指数分布，用展开式写就是

$$
W_q = \frac{(c_a^2 + c_s^2)\,E[S]}{2\,(1-\rho)} + o\!\left(\frac{1}{1-\rho}\right),
$$

   Kingman 近似取的正是第一项，相对误差是 $o(1)$：$\rho \to 1$ 时趋于零。「误差随 $\rho \to 1$ 集中」的准确含义：近似只在 $\frac{1}{1-\rho}$ 这一项上做文章，而这一项恰好在满座区吞掉其余一切——近似把最难算的项算对了，把好算的项扔给了误差。
2. **低负载区：绝对误差小、相对误差大**。$\rho$ 小时分母 $1-\rho \approx 1$，$W_q$ 本身接近零，近似的绝对误差被压在零附近；但相对误差没有这种保护——§6.7 表 1 里 $\rho = 0.5$ 处最大偏差 $-56\%$，绝对偏差却只有 0.16 个平均服务时间，对容量规划是噪音级别的差。
3. **严格上界垫底**。Kingman 同一时期还证明了一条真不等式（陈述级）：$E[W_q] \le \frac{\mathrm{Var}[A] + \mathrm{Var}[S]}{2\,(E[A] - E[S])}$。把它按 $c^2$ 折算再取 $\rho \to 1$，上界恰趋于 $\frac{(c_a^2+c_s^2)E[S]}{2(1-\rho)}$——近似值坐在一条严格上界的重交通极限上。这解释了 §6.7 表 1 的系统性方向：十六格误差十五格为负（高估），唯一正值落在模拟噪声带内。推导见 Gallager 同书第 5 章，超出本章范围。

诚实备注：高估不是普适定律——存在低变异下低估的构造（陈述级）；但「相对误差随 $\rho \to 1$ 收缩到零」是定理不是经验。与 §2.6 呼应：重交通既是理论最难算的区，也是测量最难做的区——本章 $\rho = 0.95$ 行动用了 48 个种子 × $4\times10^6$ 位顾客才把模拟噪声压到误差以下，第 2 章「临界恶化有第二张脸」在此兑现。

小结：误差主链 = 领头项近似 ＋ 低负载无相对保护 ＋ 上界极限定方向；用法口诀：$\rho \ge 0.9$ 放心用，$\rho$ 低时只当量级参考。

## $\rm \S \, 6.6$ 应用：SLA 反推、变异削减与 Little × Kingman

白话先行：Kingman 公式在工程里最值钱的用法是反向——从 SLA 出发问「要多少容量、多少变异削减」，因为它把问题拆成两个互不纠缠的旋钮。

**应用一（SLA 反推，两杠杆）**。场景：API 服务，平均服务 $E[S] = 0.2$ 秒，实测 $c_s^2 = 0.5$（§6.4 的算法），到达接近泊松 $c_a^2 = 1$。当前 $\rho = 0.9$，Kingman 给

$$
W_q \approx \frac{0.9}{0.1}\cdot\frac{1+0.5}{2}\cdot 0.2 = 1.35 \text{ 秒}.
$$

SLA 要求 $W_q \le 0.3$ 秒。两个杠杆各值多少？

1. 杠杆一（压利用率）：变异因子固定为 $\frac{1.5}{2}\times 0.2 = 0.15$，需 $\frac{\rho}{1-\rho} \le 2$，即 $\rho \le \frac{2}{3}$——利用率从九成让到六成七；核对：$\frac{2/3}{1/3}\times 0.15 = 0.30$ 秒，压线达标。
2. 杠杆二（降变异）：固定 $\rho = 0.9$，需 $\frac{c_a^2+c_s^2}{2} \le \frac{0.3}{9\times 0.2} = \frac{1}{6}$，即 $c_a^2 + c_s^2 \le \frac{1}{3}$——从 1.5 压到 0.33，接近节拍器。把两者都砍到 0.25：$W_q = 9\times 0.25\times 0.2 = 0.45$ 秒，仍不达标。

结论是本节的主课：满座区变异旋钮拧不动 SLA，利用率才是第一杠杆；两杠杆联用才有戏——$\rho = 0.8$ 配 $c_a^2 = c_s^2 = 0.25$：$W_q = 4\times 0.25\times 0.2 = 0.2$ 秒，达标。实战手段各拧哪个旋钮：1. **请求合并**：$k$ 个请求攒一批，批间隔是 $k$ 段独立间隔之和，方差相加而均值也乘 $k$，故 $c_a^2$ 除以 $k$，服务侧同理 $c_s^2$ 除以 $k$——但 $E[S]$ 乘 $k$，Kingman 分子 $(c_a^2+c_s^2)E[S]$ 不变：批处理只在摊薄固定开销（一次磁盘寻道、一次网络往返）时才真降等待（§6.9 辨析第 1 题验算）；2. **缓存与预取**：命中的请求服务近零且极稳，同时压 $E[S]$ 与 $c_s^2$，双因子收益；3. **整形**（限速器按固定节拍放行）：主动把 $c_a^2$ 往 0 拧，用一点延迟换掉队列的方差燃料。

**应用二（Little × Kingman 联用，回收第 3 章）**。两条旧账各取所长：Little 定理管换算（$L_q = \lambda W_q$），Kingman 管预测。联用一（正向）：$L_q \approx \frac{\rho^2}{1-\rho}\cdot\frac{c_a^2+c_s^2}{2}$——「利用率的平方 × 变异性」的队长口径，容量规划里的并发槽位数由此反推。联用二（反向，近似当测量仪）：监控只给 $\rho$、$E[S]$ 与实测 $W_q$ 时，倒解变异水平：

$$
\frac{c_a^2+c_s^2}{2} \approx \frac{W_q\,(1-\rho)}{\rho\,E[S]}.
$$

例（真算）：$\rho = 0.85$、$E[S] = 0.05$ 秒、实测 $W_q = 0.6$ 秒，得 $\frac{c_a^2+c_s^2}{2} = \frac{0.6\times 0.15}{0.85\times 0.05} = 2.12$，即 $c_a^2 + c_s^2 = 4.24$——指数世界的合计是 2，这里翻了一倍：系统在爆发型运行，优化目标从「加机器」改成「找出到达的成串来源」。这把第 3 章「Little 反推并发」的测量学又推了一层：不装任何探针，三个监控数就把变异水平审了出来（精度受 §6.5 误差结构约束，$\rho$ 越高越可信）。

小结：SLA 反推先拧利用率再拧变异；Little 负责换算、Kingman 负责预测，反向联用把监控数据变成变异审计。

## $\rm \S \, 6.10$ 本章自测答案

> 先闭卷作答 §6.8 与 §6.9，再核对。

### $\rm \S \, 6.10.1$ 关键概念回顾答案

1. 台忙（$W_n + S_n > A_{n+1}$）时第 $n+1$ 位等「第 $n$ 位留下的余压」，全部排队历史被 $W_n$ 接管；台闲时撞上空台零等待、历史清零。分布假设从未进场——推导只用了离开时刻的会计恒等式 $T_n + W_n + S_n$，这正是它对任意 $A$、$S$ 分布成立的原因。（§6.2）
2. 记 $U_n = S_n - A_{n+1}$，迭代展开得 $W_n = \max(0, U_0, U_0+U_1, \ldots)$，是负漂移随机游走的历史最高水位；漂移向下（$E[A] > E[S]$）水位有稳态分布，漂移非负则水位无界——两条命运的分界就是 $\rho < 1$。（§6.2）
3. 刀刃因子 $\frac{\rho}{1-\rho}$ 来自第 2 章的临界恶化，变异因子 $\frac{c_a^2+c_s^2}{2}$ 是第 5 章方差罚款的一般化，尺度因子 $E[S]$ 把一切折成平均服务时间单位。$c^2 = \frac{\mathrm{Var}[X]}{E[X]^2}$：指数 1、确定性 0、两点 $\{0.5,5.5\}$ @ $\{0.9,0.1\}$ 给 2.25。（§6.3）
4. 极端一验证指数世界：$c_a = c_s = 1$ 时退回 M/M/1 闭式，且到达泊松时 Kingman 与 P-K 逐字重合（误差为零）；极端二验证确定性世界：Lindley 递推归纳出 $W_n \equiv 0$，Kingman 右端同为零。既然 $c_a^2 = 1$（泊松）时公式精确，残差只能来自 $c_a^2 \ne 1$ 的到达侧。（§6.3）
5. 定理说 $(1-\rho)W_q$ 依分布收敛到均值 $\frac{c_a^2+c_s^2}{2}E[S]$ 的指数分布；Kingman 取领头项，相对误差为 $o(1)$。低负载时 $W_q$ 本身近零，绝对误差小但相对误差无保护。方向上近似坐在严格上界 $E[W_q] \le \frac{\mathrm{Var}[A]+\mathrm{Var}[S]}{2(E[A]-E[S])}$ 的重交通极限上，故多为高估。（§6.5）
6. 批处理把 $c_a^2, c_s^2$ 除以 $k$ 但 $E[S]$ 乘以 $k$，Kingman 分子不变，只有摊薄固定开销时才真降等待。正向联用：$L_q \approx \frac{\rho^2}{1-\rho}\cdot\frac{c_a^2+c_s^2}{2}$ 反推并发槽位；反向联用：由实测 $W_q$ 倒解 $\frac{c_a^2+c_s^2}{2} = \frac{W_q(1-\rho)}{\rho E[S]}$，把监控数据变成变异审计。（§6.6）

### $\rm \S \, 6.10.2$ 应用与辨析答案

1. $\rho = 8\times 0.1 = 0.8$；$W_q = \frac{0.8}{0.2}\cdot\frac{1+1}{2}\cdot 0.1 = 0.4$ 秒。合并后批间隔是 4 段指数之和，$c_a^2 = \frac{1}{4}$；每批服务是 4 段独立指数之和，$E[S] = 0.4$ 秒、$c_s^2 = \frac{1}{4}$；$W_q = \frac{0.8}{0.2}\cdot\frac{0.25+0.25}{2}\cdot 0.4 = 0.4$ 秒——分毫不差。分子对账：合并前 $(1+1)\times 0.1 = 0.2$，合并后 $(0.25+0.25)\times 0.4 = 0.2$，$c^2$ 除以 $k$ 与 $E[S]$ 乘 $k$ 恰好相消；题设无固定开销，故无收益。（§6.3、§6.6）
2. a 错：5% 的承诺只在重交通区兑现——表 1 的 $\rho = 0.5$ 处误差达 56%，低负载只能当量级参考。b 错：$c^2$ 只锁定二阶矩，形状不唯一（如 $\{0, 2\}$ 各半概率，均值 1、$c^2 = 1$，却非指数）；Kingman 只看两个矩，这是它「便宜」与「糙」同源。（§6.5、§6.4）
3. $\frac{c_a^2+c_s^2}{2} = \frac{0.6\times 0.15}{0.85\times 0.05} = 2.12$，即 $c_a^2 + c_s^2 = 4.24$。解读：指数世界合计是 2，这里翻倍——系统在爆发型运行，先查重试与批量来源，再考虑扩容；且 $\rho = 0.85$ 偏高，反推结果较可信。（§6.6）
4. $W_2 = \max(0,\, 0 + 0.9 - 0.4) = 0.5$；$W_3 = \max(0,\, 0.5 + 0.8 - 1.5) = 0$（台闲了一截，历史清零）；$W_4 = \max(0,\, 0 + 1.1 - 0.6) = 0.5$。接桶的是第 2 位（接过第 1 位的 0.5 段余压）与第 4 位（接过第 3 位的 0.5 段）。（§6.2）
5. a 错：7% 对一条重交通近似是好成绩，且方向可预期——高估在容量规划里是安全侧（宁可多备容量）。b 对：相对误差随 $\rho \to 1$ 收缩是定理（§6.5 主链），表 1 中该场景从 −49%（$\rho = 0.5$）单调降到 −3.7%（$\rho = 0.95$），外推 $\rho = 0.98$ 更小。（§6.5、§6.7）
