# $\rm Chapter \, 3$ 持久同调

本册前两章备齐了原料与仪器：VR 复形把点云粘成账本，同调群数出洞的个数。但第 1 章 §1.3 留了一个刺：四点正方形的洞只活在 $[1, \sqrt{2}]$ 这个窗口里——换个 $\varepsilon$ 洞就没了。真实数据的 $\varepsilon$ 没有人告诉你，噪声还会把每个临界值抖一抖。本章的答案是持久同调：**不选 $\varepsilon$，全扫；不数某一帧的洞，给每个洞开一份生卒户口**。长户口是信号，短户口是噪声——分界线由稳定性定理背书。本章主证仍然是四点正方形：$H_1$ 的那条 bar，birth $= 1$、death $= \sqrt{2}$，手推与 numpy 双路验证。

> **开始前自检**：本章假设你已经会：
>
> 1. □ 第 1 章 VR 复形的定义与单调性（本册第 1 章 §1.2），过滤就是它的连续版；
> 2. □ 第 2 章的 $\beta_k$、$\ker$、$\operatorname{im}$ 与图情形闭式解（本册第 2 章 §2.2、§2.4），条形码的每一项都由它们算出；

## $\rm \S \, 3.1$ 过滤：给复形装时间轴

先说清单尺度快照的两宗罪。其一，选错即失真：四点正方形在 $\varepsilon = 0.5$ 时是四个孤点（什么洞都没有），在 $\varepsilon = 2$ 时是实心四面体（洞被填死）——快照的成败全押在一次盲选上。其二，噪声让"对的 $\varepsilon$"根本不存在：真实点云里信号环的最长边与噪声环的最长边常常只差一点，一个阈值顾此失彼。两条罪同源：快照把"形状随尺度生长"这件事压扁成了一帧。

解法是把镜头慢放。**过滤（filtration）**是一列嵌套复形：

$$
\emptyset \;=\; K(t_0) \;\subseteq\; K(t_1) \;\subseteq\; \cdots \;\subseteq\; K(t_m)
$$

（读法：参数 $t$ 从小到大，复形只增不减。）VR 复形的单调性（第 1 章 §1.2 性质 2）保证 $\{\mathrm{VR}(X, \varepsilon)\}_\varepsilon$ 天然是一条过滤；复形只在两两距离的取值处跳变，所以有限点集的 VR 过滤只有有限个**临界值** $\varepsilon_1 < \varepsilon_2 < \cdots < \varepsilon_m$（主例只有 $1$ 与 $\sqrt{2}$ 两个）。第 1 章 §1.3 那张面数表，其实就是这条过滤的逐帧快照。

白话：**过滤是生长史，持久同调是户口簿**。沿着生长史盯住同调类的动向：某个圈在 $\varepsilon = 1$ 闭合——一个 $H_1$ 类**出生**；它在 $\varepsilon = \sqrt{2}$ 被三角形填死——**死亡**。每个类记一对数 $(\mathrm{birth}, \mathrm{death})$，这本户口簿就是持久同调。

最粗糙的摘要叫**持久 Betti 函数** $\beta_k(\varepsilon) = \dim H_k(K(\varepsilon))$，一个阶梯函数。主例实算（第 2 章 §2.4 的工具，扫描代码见 §3.3）：$\beta_1(\varepsilon)$ 在 $\varepsilon < 1$ 时为 $0$、在 $[1, \sqrt{2})$ 上为 $1$、在 $\varepsilon \ge \sqrt{2}$ 时为 $0$；$\beta_0(\varepsilon)$ 从 $4$ 起跳、在 $\varepsilon = 1$ 处落到 $1$。但 $\beta_k(\varepsilon)$ 是**有损压缩**：它只报告"此刻有几个洞"，不报告"是哪个洞、活了多久"。设想同一时刻一个洞出生、另一个洞死亡——阶梯函数纹丝不动，两个类互相冒充。要恢复配对信息，需要沿时间逐类跟踪，这就是下一节。

**本节小结**：过滤是嵌套复形序列，VR 天然给出一条、临界值有限；$\beta_k(\varepsilon)$ 阶梯函数是粗摘要，但同刻生死的洞会互相冒充——必须逐类开户口。下一节定义户口簿：条形码与持久图。

## $\rm \S \, 3.2$ 条形码与持久图：户口簿的两种画法

定义来了。固定维数 $k$，沿过滤 $\{K(\varepsilon)\}$ 跟踪 $H_k$ 的类：一个类在某 $\varepsilon$ 首次出现，记 $\mathrm{birth}$；它与别的类合并、不再作为独立类存在时，记 $\mathrm{death}$。$H_k$ 的**持久同调**就是全体 $(\mathrm{birth}, \mathrm{death})$ 对组成的多重集。两种等价画法：

1. **条形码（barcode）**：每对 $(b, d)$ 画一条水平 bar，从 $b$ 延伸到 $d$；
2. **持久图（persistence diagram）**：每对 $(b, d)$ 画一个点，全部落在对角线 $d = b$ 上方——离对角线越远，这个洞越持久。

配对**定理（陈述级）**：过滤给定后，每个类的 $(\mathrm{birth}, \mathrm{death})$ 配对唯一确定，与用什么算法算出无关。配对服从**长者法则（elder rule）**：新类出现并导致合并时，死掉的是年轻者，长者存活。两个方向各看一眼：

1. $H_0$ 方向：一条新边接通两条连通分支，按长者法则死掉年轻的分支。紧数据的 $H_0$ 条形码恰有一条 bar 活到 $\infty$——最后一个分支，永不合并；
2. $H_1$ 方向：一个新高维面把环填死，环上的类当场死亡；若填死的是本就瞬生的类，则 bar 长度为零。

条形码可算：把全部单纯形按出现时间排序、逐列约化边界矩阵（$\mathbb{F}_2$ 系数下加法即异或，最省事），非零约化列配出一对、空列宣布一个新生儿。最坏复杂度约 $O(m^3)$（$m$ 为单纯形总数），工程实现有大量加速，本册 §3.6 给出可直接跑的朴素版。为什么要强调"与算法无关"：条形码是过滤的**内在量**，不是某段代码的产物——这一条由配对定理保证，也是它可以被赋几何含义的前提。

白话：**条形码是形状的成分表**。长 bar 是骨架——它在宽窗口里存在，不可能是噪声抖出来的；短 bar 是呼吸——阈值稍动就生灭。持久图上离对角线远的点值钱，贴着对角线的点是碎屑。§3.4 把这个直觉升级成定理。

主例条形码先睹为快（程序与输出见 §3.6）：

1. $H_0$：三条有限 bar $[0, 1]$（四条边在 $\varepsilon = 1$ 同刻到齐，三次合并同刻发生）+ 一条 $[0, \infty)$（最后一个分支，永不死）；
2. $H_1$：一条 bar $[1, \sqrt{2}]$，持久度 $\sqrt{2} - 1 \approx 0.4142$——正方形的洞的一生；另有三条**零长 bar** $[\sqrt{2}, \sqrt{2}]$：对角线进来的瞬间，新三角形的边界成了新闭链、又被同刻入账的另一个三角形填死，生与死同刻，画图时省略。

**本节小结**：持久同调是 $(\mathrm{birth}, \mathrm{death})$ 的多重集，条形码与持久图两种画法；配对唯一、服从长者法则、由列约化算出；主例的户口簿已经拿到——$H_0$ 三短一无穷，$H_1$ 一条 $[1, \sqrt{2}]$ 加三条零长 bar。下一节把 $[1, \sqrt{2}]$ 的两个端点从手到机各证一遍。

## $\rm \S \, 3.3$ 主证：正方形 $H_1$ 的 birth $= 1$、death $= \sqrt{2}$

断言：四点正方形（$p_0, \ldots, p_3$ 如第 1 章）的 VR 过滤中，$H_1$ 恰有一条非零长 bar，birth $= 1$、death $= \sqrt{2}$。手推三步，每步只动用已建立的定理：

1. **birth $= 1$**。$\varepsilon < 1$ 时无边，$C_1 = 0$，$H_1 = 0$。$\varepsilon = 1$ 时四条边同刻入账（四条边等长，这是对称点的跳变挤在同一处），四边首尾相接成环：$Z_1$ 从 $0$ 维跳到 $1$ 维。此刻复形没有任何三角形——每个三角形都含一条长 $\sqrt{2}$ 的对角线——故 $B_1 = 0$，新类不是任何东西的边缘，是真的洞。类在此刻出生，birth $= 1$；
2. **death $= \sqrt{2}$**。$\varepsilon \in [1, \sqrt{2})$ 时复形恒为"4 点 4 边"，$\beta_1 = E - V + C = 4 - 4 + 1 = 1$（图情形闭式解，第 2 章 §2.4），类活着。$\varepsilon = \sqrt{2}$：两条对角线入账，旗复形性质（第 1 章 §1.2 性质 1）自动补出 $4$ 个三角形。取被一条对角线切开的两个相邻三角形：它们的边缘之和恰是那个 4-环——公共对角线在两个边缘中出现两次、方向相反，相消；剩下的正是四条外边。环沦为边缘，类死亡，death $= \sqrt{2}$；
3. **之后无新生**。$\varepsilon > \sqrt{2}$ 复形已是全复形（实心四面体），可缩，$H_1 = 0$ 恒成立，再无 $H_1$ 类出生或死亡。

数值验证走两条独立的路。**路一：$\beta_1$ 扫描**（第 2 章 §2.3 的秩计算，在临界值两侧各探一针）：

```python
import numpy as np
from itertools import combinations

P = np.array([[0., 0.], [1., 0.], [0., 1.], [1., 1.]])
n = len(P)
D = np.linalg.norm(P[:, None, :] - P[None, :, :], axis=2)

def beta1_of(eps):
    edges = [S for S in combinations(range(n), 2) if D[np.ix_(S, S)].max() <= eps + 1e-12]
    tris = [S for S in combinations(range(n), 3) if D[np.ix_(S, S)].max() <= eps + 1e-12]
    if not edges:
        return 0
    d1 = np.zeros((n, len(edges)))
    for j, (a, b) in enumerate(edges):
        d1[a, j], d1[b, j] = 1.0, -1.0
    d2 = np.zeros((len(edges), len(tris)))
    for j, (t0, t1, t2) in enumerate(tris):
        d2[edges.index((t0, t1)), j] = 1.0
        d2[edges.index((t1, t2)), j] = 1.0
        d2[edges.index((t0, t2)), j] = -1.0
    r1 = np.linalg.matrix_rank(d1)
    r2 = np.linalg.matrix_rank(d2) if d2.size else 0
    return (len(edges) - r1) - r2

for eps in [0.999, 1.001, 1.413, np.sqrt(2)]:
    print(f"eps={eps:.4f}: beta1 = {beta1_of(eps)}")
```

实跑输出（本章数值锚，照抄）：

```text
eps=0.9990: beta1 = 0
eps=1.0010: beta1 = 1
eps=1.4130: beta1 = 1
eps=1.4142: beta1 = 0
```

（读法：$1$ 的两侧从 $0$ 跳到 $1$、$\sqrt{2}$ 两侧从 $1$ 跳到 $0$——birth $= 1$、death $= \sqrt{2}$ 的数值指纹。）**路二：条形码直接读出**（§3.6 程序段的 $\mathbb{F}_2$ 约化），输出里 $H_1$ 那条 bar 就是 $[1.0, 1.4142]$。两条路一个说"阶梯长这样"、一个说"bar 长这样"，端点一致。

顺带把 bar 的两端点提炼成一般规律，它们都是点云几何的硬量：VR 过滤中 $H_1$ 类的 **birth 是环上最长边的长度**（环闭合的那一步卡在最长的边上），**death 是最先填环的高维面的最小直径**（填死的工具一到，环就死）。圆的采样点阵：birth 约为相邻采样点的最大间隙，death 约为内接等边三角形的边长 $\sqrt{3}\,r$（$r$ 为半径）——条形码的两端不是数值技巧，是被点云几何硬钉住的形状量。§3.4 的噪声实验会再见到这个 $\sqrt{3}$。

**本节小结**：birth $= 1$ 卡在环上最长边（四条边等长故同刻），death $= \sqrt{2}$ 卡在最先填环的对角线；手推三步与数值两路全部咬合，持久度 $\sqrt{2} - 1 \approx 0.4142$。下一节回答本册的终极问题：这么算出来的 bar，凭什么信？

## $\rm \S \, 3.4$ 持久度：信号与噪声的分界线

白话：真实数据 = 信号 + 噪声。信号的形状要长 bar，噪声也要开花——它自己会造出成堆的小环、小分支。**持久度（persistence）** $\mathrm{pers} = \mathrm{death} - \mathrm{birth}$ 就是给 bar 定价的尺子：贵的是信号，贱的是噪声。这句直觉需要背书，先看实验再上定理。

实验：单位圆上均匀采 $30$ 个点，叠加 $\sigma = 0.12$ 的高斯噪声（固定随机种子 $42$），跑同一条 VR 过滤加 $\mathbb{F}_2$ 约化（代码见 §3.6）。实跑结果：

1. $H_1$ 共 $406$ 条 bar；最长的一条 $(0.6123, 1.6437)$，持久度 $1.0312$；**第二名持久度只有 $0.0021$**，其余 $404$ 条的中位持久度为 $0.0000$；
2. $H_0$：$29$ 条有限 bar、最长持久度 $0.6037$，外加一条 $[0, \infty)$。

长 bar 与碎屑之间隔着**三个数量级**，中间没有过渡带。读这条长 bar：birth $0.6123$ 约为采样间隙加噪声抖动（$30$ 个随机点的最大空隙量级），death $1.6437$ 紧挨 $\sqrt{3} \approx 1.7321$——§3.3 结尾预告的内接等边三角形边长，噪声把填死时刻往下拉了一点。**圆的指纹被噪声污染了 birth 与 death 的具体数值，却没能把 bar 拉短**：持久度 $1.0312$ 与噪声尺度（$0.12$）之间隔着近十倍。

背书是**稳定性定理（陈述级）**：设两个过滤的输入相差不超过 $\delta$（点云取 Hausdorff 距离、函数取上确界范数 $\lVert f - g \rVert_\infty$），则两者的持久图在**瓶颈距离** $d_B$ 下满足

$$
d_B\big(\mathrm{dgm}(f),\; \mathrm{dgm}(g)\big) \;\le\; \lVert f - g \rVert_\infty
$$

（读法：$d_B$ 是"配对移动点所需的最小平移量"——两张图各自选一个点配对、连移带删，最费劲的那一对挪了多远。定理说：输入抖 $\delta$，条形码至多整体挪 $\delta$。）对噪声的推论立刻成型：**大小为 $\delta$ 的扰动只能创造或摧毁持久度不超过 $\delta$ 量级的 bar**——要无中生有造一条持久度 $1.03$ 的 bar，噪声得大十倍。反过来，持久度远超噪声尺度的 bar 只能来自信号。这就是"长 bar = 信号、短 bar = 噪声"的定理版。

实践工作流三步，每步都已在前面备好零件：

1. 建过滤：全程扫 $\varepsilon$，不预选尺度（第 1 章的 VR 单调性）；
2. 算条形码、画持久图（§3.6 程序段）；
3. 读特征：取离对角线远的点，报告它们的 $(\mathrm{birth}, \mathrm{death})$ 与持久度排序。相比固定阈值的做法，持久同调交付的是"尺度无关"的特征——这是它相对聚类、谱方法的独门卖点。

应用一瞥，同一套动作换数据就换行当：分子动力学构象里数原子环（$H_1$ 的长 bar 是环结构），传感器网络里查覆盖空洞（Čech 复形加 Nerve 定理，第 1 章 §1.4 的合龙处），图像与网络嵌入的形状分析里提拓扑特征喂给下游模型。条形码还能进一步压成持久景观、持久统计量再进机器学习，那是本册之外的后续章节。

**本节小结**：持久度 $= \mathrm{death} - \mathrm{birth}$ 给 bar 定价；带噪圆实验里信号 bar 与噪声 bar 的持久度隔着三个数量级；稳定性定理保证小扰动只动小 bar——"持久度远超噪声尺度"是信号身份的数学证明。三章至此合龙：点云进、条形码出，中间每一步都真算过。

## $\rm \S \, 3.6$ 程序段：从点云到条形码

把 §3.2 到 §3.4 的全部计算装进一个可复跑的程序（$\mathbb{F}_2$ 标准列约化，点云规模几十点量级直接跑）：

```python
import numpy as np
from itertools import combinations

def vr_bars(P, max_dim=2):
    """VR 过滤的 GF(2) 标准列约化；返回 H0 与 H1 的 (birth, death) 列表"""
    n = len(P)
    D = np.linalg.norm(P[:, None, :] - P[None, :, :], axis=2)
    simplices = [(0.0, (i,)) for i in range(n)]
    simplices += [(float(D[i, j]), (i, j)) for i, j in combinations(range(n), 2)]
    simplices += [(float(D[np.ix_(t, t)].max()), t) for t in combinations(range(n), 3)]
    simplices.sort(key=lambda s: s[0])
    idx = {sx: i for i, (t, sx) in enumerate(simplices)}
    bars = {0: [], 1: []}
    cols, lowmap = [], {}
    for t, sx in simplices:
        k = len(sx) - 1
        if k == 0:
            cols.append(set())
            continue
        c = {idx[tuple(sorted(r))] for r in combinations(sx, k)}
        while c and max(c) in lowmap:            # 约化: 异或掉同低的列
            c ^= cols[lowmap[max(c)]]
        cols.append(c)
        if c:                                    # 杀死了 max(c) 处的类
            lowmap[max(c)] = len(cols) - 1
            if k - 1 in (0, 1):
                bars[k - 1].append((simplices[max(c)][0], t))
    return bars[0], bars[1], n - len(bars[0])    # 最后一项 = 无穷 H0 bar 条数

def fmt(bars):
    return [(round(b, 4), round(d, 4)) for b, d in bars]

P = np.array([[0., 0.], [1., 0.], [0., 1.], [1., 1.]])
h0, h1, ess = vr_bars(P)
print("干净正方形 H0 有限 bar:", fmt(h0), "| 无穷 bar:", ess, "条")
print("干净正方形 H1 bar:", fmt(h1))
print("H1 持久度 = ", round(h1[-1][1] - h1[-1][0], 4), "= sqrt(2)-1 =", round(np.sqrt(2) - 1, 4))

rng = np.random.default_rng(42)
th = rng.uniform(0, 2 * np.pi, 30)
Pc = np.column_stack([np.cos(th), np.sin(th)]) + rng.normal(0, 0.12, (30, 2))
h0c, h1c, essc = vr_bars(Pc)
lens = sorted((d - b for b, d in h1c), reverse=True)
print("\n带噪圆(30点, sigma=0.12): H1 bar 总数 =", len(h1c))
print("最长的两条 H1 bar:", fmt(sorted(h1c, key=lambda x: x[1] - x[0], reverse=True)[:2]))
print("H1 持久度中位数 =", round(float(np.median(lens)), 4))
print("H0: 无穷 bar", essc, "条, 有限 bar 最长", round(max(d - b for b, d in h0c), 4))
```

## $\rm \S \, 3.7$ 六问参考答案

1. 两宗罪：选错 $\varepsilon$ 则洞消失或冒充；噪声让"对的 $\varepsilon$"不存在。过滤把全部 $\varepsilon$ 一齐扫过、逐类记生卒，不押注单一尺度；临界值只能取两两距离的取值，有限点集只有有限个。（§3.1）
2. $\beta_k(\varepsilon)$ 只报维数。主例改造成：两个独立的圈在 $\varepsilon = c$ 同时闭合、又被两个同刻入账的三角形同时填死——$\beta_1$ 始终如一，户口簿里却是两条分开的 bar。（§3.1、§3.2）
3. 新类出现引发合并时，死的总是年轻的，长者存活。紧数据合并次数有限（每次恰死一条 $H_0$ bar），$n$ 个顶点只死 $n - 1$ 次，剩一条永不合并——最后幸存的分支。零长 bar：类在 $\varepsilon$ 出生、同 $\varepsilon$ 被填死（新三角形的边界瞬间又被另一个三角形覆盖），$b = d$。（§3.2）
4. 等长来自正方形对称（四条边同为 $1$），"无三角形"来自对角线 $\sqrt{2} > 1$ 尚未入账。压成长方形（边 $1, a > 1$）：长边对应的环闭合推迟到 birth $= a$；death 仍是对角线 $\sqrt{1 + a^2}$（flag 性质：对角线一到，四个三角形齐到）。持久度变成 $\sqrt{1 + a^2} - a$，随 $a$ 增大而缩小——拉长的四边形洞更"瘦"。（§3.3）
5. $d_B$ 度量持久图空间（配对移动的最小平移量），右端度量输入空间（函数的上确界范数或点云的 Hausdorff 距离）。推论：噪声 $\delta$ 造出的新 bar 与旧图的距离至多 $\delta$，而新 bar 若要"凭空"，必须从对角线附近出发——它能达到的持久度至多 $\delta$ 量级；持久度远大于 $\delta$ 的 bar 在旧图中必有对应，动不了。（§3.4）
6. 圆上最"挤"的三个采样点构成接近内接等边三角形的组态，VR 的三角形（填环的工具）在直径达到 $\sqrt{3}\,r$ 时出现；$2$ 是外切尺度的直觉误导，填环只需要等边三角形那么大的面。加密到 $300$ 点：最大采样间隙缩小约十倍，birth 随之下降；death 仍锁在 $\sqrt{3}\,r$ 附近——bar 变长，持久度更干净地指向圆本身。（§3.3、§3.4）
